# Round 5 brief: 250 objects per category for hospitals, construction, mining, excavation and aviation (2026-11-03)

Same job, framework and rules as round 4. **Read `tools/library/detail/R4-BRIEF.md` first** (the API of `fam()`, `Acc`, `cab`, `tbl`, the kit namespaces, the rules that do not bend, the privacy patterns, the look-before-you-publish workflow) and `docs/LIBRARY-BLOCKS-REPORT-ROUND4-2026-11-03.md`. The differences:

- You own ONE block and write `tools/library/detail/r5-<block>.mjs` with **exactly 250 variants** (at least 30 families; every family draws something real, variants differ in real size or configuration).
- Every command takes `--round 5`: `node tools/library/detail/make-round4.mjs --round 5 --check --files r5-<block>.mjs`, then `--round 5 --files r5-<block>.mjs --expect <block> --write --groups <block>` (writes `tools/library/blocks/<block>-6.csv`). Preview: `node tools/library/detail/r4-preview.mjs tools/library/detail/r5-<block>.mjs <scratch-dir> --all` (view the sheets with Read; front elevations; one sheet = 30 objects). Then `node tools/library/detail/detail.mjs --check` must pass.
- Your themes this round: **hospitals and healthcare, construction, mining, excavation and earthmoving, aviation**, spread roughly evenly over your block. Names must be unique across ALL existing block CSVs (about 2,800 names, including round 4's `*-5.csv`): use setting words ("operating room", "mine", "site", "hangar", "ward") in labels to stay distinct. Grep `tools/library/blocks/*.csv` before you pick a title.
- Five new categories exist (with sub-categories; `cat` must be one of these keys or an existing one belonging to your block):
  `medical/patientcare`, `medical/surgical`, `medical/imaging`, `medical/laboratory`, `medical/support`;
  `construction/equipment`, `construction/temporary`, `construction/formwork`, `construction/tools`;
  `earthmoving/excavators`, `earthmoving/loaders`, `earthmoving/haulage`, `earthmoving/compaction`, `earthmoving/attachments`;
  `mining/surface`, `mining/underground`, `mining/processing`, `mining/support`;
  `aviation/aircraft`, `aviation/groundsupport`, `aviation/airfield`, `aviation/hangar`, `aviation/rescue`.
  The block name is the part before the slash (a block of `medical` uses only `medical/*`). Blocks `foodservice`, `casework`, `furniture`, `plumbing`, `electrical`, `mechanical`, `appliances`, `site`, `people`, `other` keep using their existing categories, themed on the five industries.
- Names stay generic: no maker, model, brand, airline, hospital chain, or standard. Machines are by type and size class ("20 ton class", "narrow-body", "shovel, 1.5 m³ bucket"), never by manufacturer. Heavy machines are big: write the real size in inches (a 100-ton haul truck is about 400 in long); keep each variant under about 8,000 triangles; keep geometry inside the body box. Tracks, wheels, booms, buckets, cabs, ladders, rails, hydraulics (cylinders as `a.cyl`/`a.ycyl`), guards and lights are what make these read as the machine, so draw them.
- Medical objects are generic equipment shapes, never clinical claims: say what is drawn ("two-section bed frame with side rails and a raised head section"), not what it does to a patient.

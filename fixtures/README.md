# Public test fixtures

Drawings written by us for the tests that ship (0.4 item 0.7). They replace client drawings the tests used to read from
outside the repo, which can never go into a public one. Every file here is generated by code in `tools/fixtures/` — invented project, makers and models — and
`node bin/test-fixtures.mjs` re-measures them with the apps' own modules against `facts.json`.

**Assert the numbers in `facts.json`, not the client drawings' numbers.** Each app session swaps its own tests (the
inbox notes say which lines).

The Revit-format files are our own compound files (`tools/fixtures/cfb.mjs`, from the MS-CFB spec) holding the
streams BimCraft reads — BasicFileInfo, TransmissionData, ProjectInformation, PartAtom, RevitPreview4.0 — plus filler
partitions. They have no model geometry (BimCraft never reads it) and open in an independent reader (Python `olefile`).

**File dates.** The folder scan uses file dates ("newest saved work"), and git does not keep them: after a clone run
`node tools/fixtures/make-folder.mjs --touch` (dates from `folder/manifest.json`).

## Rebuilding

```sh
node tools/fixtures/make-fixtures.mjs [--only pdf|dwg|rvt]   # as root: ezdxf venv + ODA File Converter for the DWGs
node bin/test-fixtures.mjs --write                          # re-measure, rewrite facts.json
node public_html/assets/apps/cadcraft/dev/addons/electrical/test/make-sample.mjs --out fixtures/electrical
```

The PDF and the folder are byte-for-byte reproducible (the test checks). The DWGs come from the ODA File Converter,
which stamps its own dates and GUIDs, so a rebuild changes their bytes (not what they contain): rebuild only when the
generator changes, then `--write` and tell the app sessions.

## Not covered here

- `testfiles/dwg-samples/` (sample drawings published by a CAD vendor) and `testfiles/samples/` (public IFC/RVT/RFA
  samples from vendors and buildingSMART) are not client data, but whether their licenses allow putting them in a public
  repo is for the owner to settle (noted in `docs/0.4-sessions/lang.md`). Until then, tests that ship should skip them
  when absent.
- `testfiles/dwg-corpus/` (outside the repo) holds copies of client drawings in six versions (built by
  `tools/dwg-test/corpus.mjs`); session `cad-files` rebuilds it from these fixtures.

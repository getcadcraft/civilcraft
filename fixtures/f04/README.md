# F04 deterministic layered plan fixture

`layered-plans.ifc` is generated by `node tests/features/f04/fixture.mjs` with deterministic
GlobalIds and header time. It is synthetic and contains no user model data.

Nine walls: four isolated (straight, reversed straight, positive/negative curve), a straight
L pair, a straight T pair, and an isolated service-cavity partition. Five hosted doors/windows.
Two custom explicit-core assemblies contain ventilated cavities and zero-thickness membranes.
The rainscreen totals 209.55 mm (139.7 mm core, 25.4 mm cavity); the partition totals 155.575 mm.
All six location lines occur. Two associative dimensions measure the first wall/core.

Open the file, enable Draw and set View range → Plan detail → Fine. Old views intentionally
default to Coarse. See `docs/features/F04-HANDOFF.md` for supported geometry and pending browser
acceptance. F01/F02/F03 fixtures are not used as writable F04 artifacts.

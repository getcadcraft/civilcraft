# CivilCraft for Android

CivilCraft comes inside CadCraft Studio for Android: the signed APK is on the [download page](https://getcadcraft.com/download#studio) and in the [Studio 0.7 release](https://github.com/getcadcraft/studio/releases/tag/studio-v0.7.0). It is not in Google Play yet (0.8 at the earliest).

## Com s'escriuen les dreceres

L'ajuda escriu cada drecera tal com la etiqueta el vostre teclat.

| Escrit | En un Mac | En Windows i Linux |
|---|---|---|
| {{key:Mod+S}} | Command (⌘) i S | Ctrl i S |
| {{key:Ctrl+Shift+F}} | Control (⌃), Shift (⇧) i F | Ctrl, Shift i F |
| {{key:Alt+Left}} | Option (⌥) i ← | Alt i ← |
| {{key:Backspace}} | la tecla Delete | Backspace |
| {{key:Delete}} | fn i Delete (suprimeix endavant) | Delete |
| {{key:Enter}} | Return | Enter |

Un signe més vol dir mantenir les tecles juntes. "Després" vol dir prémer-les una darrere l'altra.

La majoria de dreceres de les aplicacions accepten Command o Control en un Mac, així que {{key:Mod+Z}} funciona de les dues maneres. Algunes, com la pantalla completa ({{key:Ctrl+Shift+F}}), fan servir la tecla Control en tots els ordinadors; l'ajuda ho indica quan s'aplica.

## Tecles de funció en un Mac

En la majoria de teclats de Mac, la fila superior canvia la brillantor, el volum i el contingut multimèdia. Per enviar F1 a F12:

- mantingueu premuda la tecla **fn** (o la tecla del globus) mentre premeu la tecla, o
- obriu **Configuració del sistema**, després **Teclat**, després **Dreceres de teclat**, després **Tecles de funció**, i activeu "Usa les tecles F1, F2, etc. com a tecles de funció estàndard".

Algunes tecles F també les reclama el mateix macOS (per exemple, Control de missió). Si una tecla no fa res a l'aplicació, proveu-la amb fn, o feu servir el botó de la barra d'eines.

## Dreceres que es queda el navegador

Una pàgina web no pot agafar algunes dreceres del navegador, faci el que faci. En totes les aplicacions:

- {{key:Mod+N}}, {{key:Mod+T}} i {{key:Mod+W}} sempre obren o tanquen finestres i pestanyes del navegador. Les aplicacions fan servir botons per a Nou i Tanca en lloc d'aquestes.
- {{key:Mod+Q}} en un Mac i {{key:Alt+F4}} a Windows surten del navegador. Si teniu feina sense desar, el navegador pregunta primer ("Deixar el lloc?"); trieu quedar-vos i després deseu.
- La pantalla completa del mateix navegador ({{pick:mac=Control-Command-F, o el botó verd de la finestra|windows linux=F11}}) encara funciona. Les aplicacions també tenen els seus propis modes de pantalla amb {{key:Ctrl+Shift+F}}, que també poden amagar les barres de l'aplicació.

## Botons del ratolí en un trackpad

Les aplicacions fan servir el botó dret i el botó del mig. Sense un ratolí de tres botons:

:::mac
- **Clic dret:** feu clic amb dos dits. Activeu "Clic secundari" a **Configuració del sistema**, després **Trackpad**, si el clic amb dos dits no fa res. Mantenir {{key:Ctrl}} mentre hi feu clic obre el menú del navegador, però dins d'un dibuix algunes aplicacions ho interpreten com un clic normal (amb Control premut), així que és millor el clic amb dos dits.
- **Arrossegament amb el botó del mig (desplaçament):** cada aplicació ofereix una altra manera de desplaçar-se, com mantenir {{key:Space}} premut mentre arrossegueu o arrossegar amb el botó dret. La pàgina de teclat de l'aplicació indica quina.
- **Zoom amb la roda:** el desplaçament amb dos dits al trackpad fa zoom a la majoria d'aplicacions. La pessigada també fa zoom on l'aplicació la suporta.
:::

:::windows linux
- **Clic dret:** feu clic amb dos dits, o feu clic a la cantonada inferior dreta del trackpad. Depèn de la configuració del vostre trackpad.
- **Arrossegament amb el botó del mig (desplaçament):** cada aplicació ofereix una altra manera de desplaçar-se, com mantenir {{key:Space}} premut mentre arrossegueu o arrossegar amb el botó dret. La pàgina de teclat de l'aplicació indica quina.
- **Zoom amb la roda:** el desplaçament amb dos dits al trackpad fa zoom a la majoria d'aplicacions.
:::

## Escriure en un quadre de text

Mentre escriviu en un quadre (un nom, una nota, una cerca), les dreceres d'una sola lletra de l'aplicació estan desactivades, així que escriure "L" escriu una L. Premeu {{key:Esc}} o feu clic al dibuix per tornar les tecles a l'aplicació.

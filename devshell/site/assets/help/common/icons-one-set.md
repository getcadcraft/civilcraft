Every tool has one picture, and the picture is the same wherever you meet the tool: in the ribbon, in a row of tool buttons, in the toolbox, in the File menu, in a menu opened from a panel's {{ui:⋯}} button, and in the palettes of the Vector and Sketch layouts. Switch the layout and the picture stays put, so you learn each tool once.

:::note
This is in the lab builds first. A tool the set has no drawing for yet shows its old picture until the drawing is added, and the lab keeps a list of those so none is forgotten.
:::

## Choose how the icons look

1. Open {{ui:Settings}} (Ctrl+,) and find {{ui:Icons}}.
2. Pick one:
   - {{ui:Full colour}}: two-tone drawings with colour fills.
   - {{ui:Outline}}: line drawings in one colour. {{ui:Outline colour}} sets the colour; {{ui:Use the theme colour}} puts it back.
   - {{ui:Each app's own drawings}}: the pictures the app drew for itself, as before. Every layout then shows those instead of the set.

The drawings are vectors, so they stay sharp at any size and follow {{ui:Interface size}}. They follow the light and dark theme too.

## What stays the same

- The tool's name, tooltip, keys and position do not change; only its picture.
- Arrows that open or close a list (the small carets) are not tool pictures and keep their own shape.
- The pictures inside a drawing or a model (symbols, hatches, textures) are yours or the library's and are not touched.

## If a picture is wrong

Hover the tool to read its name, then use {{ui:Report a problem}} from the Help menu and name the tool; the name tells us which drawing to change.

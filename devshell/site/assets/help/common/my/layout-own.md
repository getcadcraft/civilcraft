ထုတ်ပေးထားသော အပြင်အဆင်သုံးမျိုးအပြင် ကိုယ်ပိုင်တစ်ခုကို စီစဉ်နိုင်ပြီး သင့် setup တစ်ခုလုံးကို အမည်ဖြင့် သိမ်းထားကာ တစ်ချက်နှိပ်ဖြင့် ပြန်ပြောင်းနိုင်ပါသည်။

## ကိုယ်ပိုင်အပြင်အဆင် စီစဉ်ရန်

1. {{ui:Settings}} (ဂီယာ သို့မဟုတ် {{key:Mod+,}}) ကို ဖွင့်ပါ၊ {{ui:Global}} ကို ရွေးပြီး ထို့နောက် {{ui:Layout}} ကို ရွေးပါ။
2. {{ui:Arrange your own layout…}} ကို ရွေးပါ။ Dialog သည် သင် ယခု သုံးနေသော အပြင်အဆင်မှ စတင်ပါမည်။
3. အမည်ပေးပြီး အောက်ပါတို့ကို ရွေးပါ:
   - **ပုံဆွဲအပေါ်:** အက်ပ်၏ ကိရိယာဘား၊ ribbon သို့မဟုတ် တစ်ခုမျှမရှိ; title bar; info box နှင့် ၎င်းတွင် ပါမည့် ထိန်းချုပ်ချက်များ။
   - **ပုံဆွဲဘေးတွင်:** toolbox ကို ဘယ်၊ ညာ သို့မဟုတ် မထားဘဲ၊ {{ui:My tools}} ပါ သို့မဟုတ် မပါ; palette များကို မည်သည့်ပန်နယ်က ကိုင်မည်၊ မည်သည်က အပေါ်ဆုံးဖြစ်မည် (ဥပမာ ပရောဂျက် ဘရောက်ဇာ သို့မဟုတ် Properties) နှင့် အောက်တွင် မည်သည်တို့ tab များ ဖြစ်မည်။
   - **ပုံဆွဲနေရာ:** view tabs၊ quick bar နှင့် သင်အမှန်ခြစ်ထားသော ထိန်းချုပ်ချက်များပါဝင်သည့် view bar၊ edit palette၊ status bar။
   - **အသွင်အပြင်:** အရွယ်အစား၊ ခလုတ် ဘောင်များနှင့် tab ပုံစံ။
4. {{ui:Use this layout}} ကို ရွေးပါ။ အက်ပ်သည် ချက်ချင်း ထိုအပြင်အဆင်သို့ ပြောင်းပြီး အပြင်အဆင် ရှိသော အက်ပ်အားလုံးကလည်း ထိုအတိုင်း သုံးပါမည်။

ဤအက်ပ်တွင် ရှိသည်များကိုသာ ပေးထားပါသည်။ သင့်အပြင်အဆင်ကို {{ui:From add-ons and files}} အောက်တွင် ဖော်ပြပါမည်။ {{ui:Export this layout}} က ၎င်းကို လုပ်ဖော်ကိုင်ဖက်အား ပေးနိုင်သော ဖိုင်အဖြစ် သိမ်းပေးပြီး ဖယ်ရှားခလုတ်က ၎င်းကို ဖယ်ရှားပေးပါသည်။ ထိုအပြင်အဆင်တွင် ပါသော ပန်နယ်များသည် [ပန်နယ်များကို စီစဉ်ရန်](common:arrange-panels) တွင် ဖော်ပြထားသည့်အတိုင်း ချိတ်၊ မျော၊ ကိုယ်ပိုင်ဝင်းဒိုးသို့ ရွှေ့နိုင်ဆဲ ဖြစ်ပါသည်။

## အပြင်အဆင်ကို အလုပ်ပတ်ဝန်းကျင်အဖြစ် သိမ်းရန်

အလုပ်ပတ်ဝန်းကျင်သည် ဤဘရောက်ဇာရှိ အက်ပ်အားလုံးအတွက် သင့် setup တစ်ခုလုံး ဖြစ်ပါသည်: အပြင်အဆင်၊ menu ပုံစံနှင့် ကီးများ၊ ကိရိယာဘား ပုံစံ၊ ပန်နယ်များနှင့် ၎င်းတို့၏ အရွယ်အစားများ၊ နှင့် {{ui:My tools}}။ Theme နှင့် ဘာသာစကားတို့ ပါဝင်ခြင်း မရှိပါ။

- **သိမ်းရန်:** {{ui:Work environments}} အောက်တွင် အမည်ရိုက်ထည့်ပြီး {{ui:Save my setup}} ကို ရွေးပါ။ ရှိပြီးသား အမည်ဖြင့် သိမ်းလျှင် ထို setup ကို အစားထိုးပါမည်။
- **ပြောင်းရန်:** စာရင်းမှ setup တစ်ခုကို ရွေးပြီး {{ui:Switch to it}} ကို ရွေးပါ။ အက်ပ်သည် ထို setup ဖြင့် ပြန်စတင်ပါမည်; မသိမ်းရသေးသော အလုပ်ရှိလျှင် အက်ပ်က အရင်မေးပါမည်၊ ပြန်စတင်တိုင်း လုပ်သည့်အတိုင်းပင် ဖြစ်ပါသည်။
- **မျှဝေရန်:** {{ui:Export}} သည် ရွေးထားသော setup ကို `.ccenv.json` ဖိုင်အဖြစ် သိမ်းပါမည်; {{ui:Import a setup…}} က ဖိုင်တစ်ခုမှ ထည့်ပေးပါမည်။ ဖိုင်သည် ဤရွေးချယ်ချက်များကိုသာ သတ်မှတ်ပြီး အခြားမည်သည့်အရာကိုမျှ မသတ်မှတ်ပါ။
- **ဖယ်ရှားရန်:** setup တစ်ခုကို ရွေးပြီး {{ui:Remove}} ကို ရွေးပါ။

setup 12 ခုအထိ သိမ်းနိုင်ပါသည်။

Dialog မဖွင့်ဘဲ အပြင်အဆင်ကို ပြောင်းလိုလျှင် (block ကို ဆွဲခြင်း၊ ကိရိယာကို ညာကလစ်နှိပ်ခြင်း) [ပုံပေါ်တွင် အပြင်အဆင် ပြောင်းရန်](common:layout-edit) ကို ကြည့်ပါ။ ဆောက်ထားပြီးသား စီစဉ်မှုများကို အရင်စမ်းလိုလျှင် [toolbox နှင့် info box အပြင်အဆင်](common:layout-toolbox)၊ [ribbon နှင့် ပရောဂျက် ဘရောက်ဇာ အပြင်အဆင်](common:layout-ribbon) နှင့် [Drafting အပြင်အဆင်](common:layout-drafting) ကို ကြည့်ပါ။

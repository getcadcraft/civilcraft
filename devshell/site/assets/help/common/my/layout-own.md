built-in အပြင်အဆင် သုံးခုအပြင် ကိုယ်ပိုင်တစ်ခု စီစဉ်နိုင်ပြီး setup အပြည့်ကို အမည်ဖြင့် သိမ်းကာ တစ်ချက်နှိပ်ဖြင့် ပြန်ပြောင်းနိုင်ပါသည်။

## ကိုယ်ပိုင် အပြင်အဆင် စီစဉ်ရန်

1. {{ui:Settings}} (ဂီယာ၊ သို့မဟုတ် {{key:Mod+,}}) ကို ဖွင့်ပြီး {{ui:Global}} ကို ရွေးကာ {{ui:Layout}} ကို ရွေးပါ။
2. {{ui:Arrange your own layout…}} ကို ရွေးပါ။ dialog သည် သင် ယခု သုံးနေသော အပြင်အဆင်မှ စတင်ပါမည်။
3. အမည်ပေးပြီး ရွေးပါ-
   - **ပုံဆွဲ၏ အပေါ်တွင်:** app ၏ toolbar၊ ribbon သို့မဟုတ် တစ်ခုမျှ မပါ၊ title bar၊ info box နှင့် ၎င်းတွင် ထားမည့် ထိန်းချုပ်ချက်များ။
   - **ပုံဆွဲ၏ ဘေးတွင်:** ကိရိယာသေတ္တာကို ဘယ်၊ ညာ သို့မဟုတ် မထားဘဲ၊ {{ui:My tools}} ပါ သို့မဟုတ် မပါ၊ palette များကို မည်သည့် ပန်နယ်က ထားမည်၊ အပေါ်ဆုံးက ဘာဖြစ်မည် (ဥပမာ project browser သို့မဟုတ် Properties)၊ နှင့် အောက်တွင် မည်သည်တို့ tab များ ဖြစ်မည်။
   - **ပုံဆွဲနေရာ:** view tab များ၊ သင် tick လုပ်သော ထိန်းချုပ်ချက်များပါသည့် quick bar နှင့် view bar၊ တည်းဖြတ် palette၊ status bar။
   - **အသွင်အပြင်:** အရွယ်အစား၊ ခလုတ် outline နှင့် tab ပုံစံ။
4. {{ui:Use this layout}} ကို ရွေးပါ။ app သည် ချက်ချင်း ပြောင်းပြီး အပြင်အဆင် ရှိသော app တိုင်းကလည်း ၎င်းကို သုံးပါမည်။

ဤ app တွင် ရှိသည်များကိုသာ ပေးပါသည်။ သင့်အပြင်အဆင်ကို {{ui:From add-ons and files}} အောက်တွင် ဖော်ပြပါသည်; {{ui:Export this layout}} က လုပ်ဖော်ကိုင်ဖက်အား ပေးနိုင်သော ဖိုင်အဖြစ် သိမ်းပေးပြီး၊ ဖယ်ရှားခလုတ်က ၎င်းကို ဖယ်ရှားပေးပါသည်။ ၎င်းဖြည့်ထားသော ပန်နယ်များသည် [ပန်နယ်များ စီစဉ်ရန်](common:arrange-panels) တွင် ပြောခဲ့သည့်အတိုင်း ချိတ်နိုင်၊ မျောနိုင်ပြီး ကိုယ်ပိုင် window သို့ ရွှေ့နိုင်ပါသည်။

## အလုပ်ပတ်ဝန်းကျင်အဖြစ် setup ကို သိမ်းရန်

အလုပ်ပတ်ဝန်းကျင် ဆိုသည်မှာ ဤ browser ရှိ app အားလုံးအတွက် သင့် setup အပြည့် ဖြစ်ပါသည်- အပြင်အဆင်၊ menu ပုံစံနှင့် ကီးများ၊ toolbar ပုံစံ၊ ပန်နယ်များနှင့် ၎င်းတို့၏ အရွယ်အစား၊ နှင့် {{ui:My tools}}။ theme နှင့် ဘာသာစကားမှာ ပါဝင်ခြင်း မရှိပါ။

- **သိမ်းရန်:** {{ui:Work environments}} အောက်တွင် အမည်ရိုက်ပြီး {{ui:Save my setup}} ကို ရွေးပါ။ ရှိပြီးသား အမည်ဖြင့် သိမ်းလျှင် ထို setup ကို အစားထိုးပါမည်။
- **ပြောင်းရန်:** စာရင်းတွင် setup တစ်ခု ရွေးပြီး {{ui:Switch to it}} ကို ရွေးပါ။ app သည် ထို setup ဖြင့် ပြန်တင်ပါမည်; သိမ်းမထားသော အလုပ် ရှိလျှင် app က အရင်မေးပါမည်၊ reload မည်သည့်အချိန်မဆို ပြုလုပ်သကဲ့သို့ ဖြစ်ပါသည်။
- **မျှဝေရန်:** {{ui:Export}} က ရွေးထားသော setup ကို `.ccenv.json` ဖိုင်အဖြစ် သိမ်းပါသည်; {{ui:Import a setup…}} က ဖိုင်မှ တစ်ခု ထည့်ပေးပါသည်။ ဖိုင်က ဤရွေးချယ်ချက်များကိုသာ သတ်မှတ်ပြီး အခြားမည်သည့်အရာကိုမျှ မပြောင်းပါ။
- **ဖယ်ရှားရန်:** setup တစ်ခု ရွေးပြီး {{ui:Remove}} ကို ရွေးပါ။

setup ၁၂ ခုအထိ သိမ်းထားနိုင်ပါသည်။

built-in စီစဉ်မှုများကို အရင်စမ်းလိုပါက [ကိရိယာသေတ္တာနှင့် အချက်အလက်အကွက် အပြင်အဆင်](common:layout-toolbox) နှင့် [ရစ်ဘန်နှင့် ပရောဂျက် ဘရောက်ဇာ အပြင်အဆင်](common:layout-ribbon) ကို ကြည့်ပါ။

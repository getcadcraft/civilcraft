**ကိရိယာသေတ္တာနှင့် အချက်အလက်အကွက်** သည် app ၏ workspace အပြင်အဆင် သုံးခုအနက် တစ်ခု ဖြစ်ပါသည်။ ပုံဆွဲကိရိယာများသည် ဘယ်ဘက်တွင် ကော်လံအဖြစ် ရပ်ထားပြီး၊ အပေါ်ရှိ အချက်အလက်အကွက်က လည်ပတ်နေသော ကိရိယာ လိုအပ်သည်ကို သို့မဟုတ် ရွေးထားသည်ကို ပြသပါသည်၊ view တိုင်းတွင် tab ရှိပြီး ပုံဆွဲအောက်ရှိ quick bar က နေ့စဉ် ရွေးချယ်ချက် အနည်းငယ်ကို ထားပါသည်။ ကိရိယာများသည် app ၏ ကိုယ်ပိုင် ဖြစ်ပါသည်- classic အပြင်အဆင်တွင် လုပ်နိုင်သမျှ ဤနေရာတွင်လည်း လုပ်နိုင်ပြီး၊ သင့်ပုံဆွဲ၊ menu ပုံစံနှင့် ကီးများ မူလအတိုင်း ရှိနေပါမည်။

## ရွေးရန်

1. {{ui:Settings}} (ဂီယာ၊ သို့မဟုတ် {{key:Mod+,}}) ကို ဖွင့်ပါ။
2. {{ui:Global}} tab ကို ရွေးပြီး {{ui:Layout}} › {{ui:Workspace}} သို့ သွားပါ။
3. {{ui:ကိရိယာသေတ္တာနှင့် အချက်အလက်အကွက်}} ကို ရွေးပါ။

အပြင်အဆင်သည် ချက်ချင်း ပြောင်းပါမည်။ ရွေးချယ်ချက်သည် ဤ browser ရှိ app အားလုံးအတွက် တစ်ခုတည်း ဖြစ်ပြီး၊ ထိုအချိန်မှစ၍ app တိုင်း ၎င်းဖြင့် ဖွင့်ပါမည်။ ပုံမဆွဲမီ ၎င်းအဆင်သင့် ဖြစ်နေသဖြင့် classic အပြင်အဆင်ကို ပထမ မမြင်ရပါ။

## ဘယ်နေရာတွင် ဘာရှိသလဲ

- **Toolbar:** app ၏ ကိုယ်ပိုင် toolbar သည် ပုံဆွဲနေရာ၏ အပေါ်ဘက်တွင် menu များနှင့်အတူ ရှိနေပါသည်။
- **အချက်အလက်အကွက်:** toolbar အောက်တွင်။ ကိရိယာ လည်ပတ်နေစဉ် ၎င်းနှင့် ၎င်းလိုအပ်သည်များကို ပြပါသည်။ တစ်ခုခု ရွေးလျှင် ၎င်း၏ အဓိက ဆက်တင်များကို ပြပါသည် (နံရံဆိုလျှင် အမျိုးအစား၊ အထူ၊ အလျား၊ location line နှင့် အမြင့်)၊ ထိုနေရာတွင်ပင် ပြောင်းနိုင်ပါသည်၊ ထိုပြောင်းလဲမှုသည် Properties တွင် ပြောင်းသကဲ့သို့ပင် ဖြစ်ပြီး {{key:Mod+Z}} ဖြင့် ပြန်ရုတ်နိုင်ပါသည်။ ဘာမှ မရွေးထားလျှင် "Nothing selected" ဟု ပြပါသည်။ app တိုင်းက ဤနေရာတွင် ကိုယ်ပိုင် box များ ထည့်ပါသည်၊ ဥပမာ လက်ရှိ layer သို့မဟုတ် level၊ ဖွင့်ထားသော document။
- **ကိရိယာသေတ္တာ:** ဘယ်ဘက်ရှိ ကော်လံ၊ app ၏ ကိရိယာများကို group များဖြင့်။ group ၏ အမည်ကို နှိပ်ပြီး ခေါက်ရန် သို့မဟုတ် ပြန်ဖွင့်ရန်။ လည်ပတ်နေသော ကိရိယာသည် မီးလင်းပါသည်။
- **{{ui:My tools}}:** ကိရိယာသေတ္တာ၏ ပထမ group၊ သင် အများဆုံး သုံးသော ကိရိယာအတွက် အလွတ် slot ရှစ်ခု။ အလွတ် slot ကို နှိပ်ပြီး app ၏ ကိရိယာ သို့မဟုတ် command မည်သည့်ကိုမဆို ရွေးပါ; သို့မဟုတ် ကိရိယာသေတ္တာရှိ ကိရိယာကို right-click လုပ်ပြီး {{ui:Add to My tools}} ကို ရွေးပါ; သို့မဟုတ် ကိရိယာကို slot ပေါ်သို့ ဆွဲချပါ။ slot ကို right-click လုပ်ပြီး ပြောင်းရန် သို့မဟုတ် ရှင်းရန်။ သင့် slot များကို ဤ browser ရှိ app တစ်ခုစီအတွက် သိမ်းထားပါသည်။
- **Navigator:** ညာဘက် ပန်နယ်။ app ၏ project browser သည် အပေါ်တွင် ရှိပါသည် (plan၊ section၊ elevation၊ 3D view၊ schedule၊ sheet၊ app တွင် ရှိသည့်အတိုင်း)- နှိပ်လိုက်လျှင် ဖွင့်ပါမည်။ ၎င်းအောက်တွင် {{ui:Properties}} နှင့် ညာဘက် ပန်နယ်၏ အခြား အကြောင်းအရာပါသော tab။
- **View tab များ:** ဖွင့်ထားသော ဖိုင်၏ view တိုင်းအတွက် tab (sheet၊ plan၊ scene…)၊ ပုံဆွဲ၏ အပေါ်တွင်။
- **Quick bar:** ပုံဆွဲအောက်တွင်၊ app တွင် ရှိသော view ဆက်တင်များနှင့် နေ့စဉ် ရွေးချယ်ချက်များ၊ ဥပမာ scale၊ detail level၊ view range၊ fit၊ plan၊ split သို့မဟုတ် 3D၊ snap များနှင့် unit များ။
- **တည်းဖြတ် palette:** ပုံဆွဲတွင် တစ်ခုခုကို နှိပ်လျှင် pointer ဘေးတွင် အသေးစား palette တစ်ခု ပေါ်လာပြီး ထိုအတွက် app ၏ တည်းဖြတ်ခြင်း command များ ပါသည်၊ ဥပမာ move၊ copy၊ rotate၊ mirror၊ duplicate သို့မဟုတ် delete နှင့် {{ui:Properties}}။ {{key:Esc}}၊ mouse wheel၊ နောက်တစ်ချက် နှိပ်ခြင်း သို့မဟုတ် ၎င်း၏ close ခလုတ်က ၎င်းကို ပြန်ဖျောက်ပါသည်။

လည်ပတ်၍ မရနိုင်သော ကိရိယာကို မီးခိုးရောင်ပြပြီး tooltip က အကြောင်းပြပါသည်။ ၎င်းကို နှိပ်ပါ သို့မဟုတ် {{key:Enter}} ကို နှိပ်ပြီး အကြောင်းရင်းကို box တွင် ဖတ်ပါ။

{{key:Esc}} က classic အပြင်အဆင်ကဲ့သို့ ပထမဆုံး လည်ပတ်နေသော ကိရိယာကို ရပ်ပါသည်၊ shortcut အားလုံးနှင့် {{key:Ctrl+Shift+F}} (screen mode များ) က ယခင်အတိုင်း အလုပ်လုပ်ပါသည်။

## ကိရိယာသေတ္တာကို ကိုယ်ပိုင် window ပေးရန်

ကိရိယာသေတ္တာ၏ အပေါ်ဆုံးရှိ {{ui:Move the toolbox}} ခလုတ်တွင် {{ui:Move to a new window}} ပါသည်- ကိရိယာသေတ္တာသည် app ၏ ဘေးတွင် သို့မဟုတ် ဒုတိယ မော်နီတာပေါ်တွင် ထားနိုင်သော ကျဉ်းသည့် ကိုယ်ပိုင် window တွင် ဖွင့်ပါသည်။ ထိုနေရာတွင် နှိပ်သော ကီးများသည် app သို့ ရောက်ပါသည်။ {{ui:Put the toolbox back}} သို့မဟုတ် ထို window ကို ပိတ်ခြင်းက ပြန်ရောက်စေပါသည်။

toolbar ဆက်တင်များသည် ကိရိယာသေတ္တာကိုလည်း သက်ရောက်ပါသည်- {{ui:Settings}} › {{ui:Global}} › {{ui:Toolbar}} › {{ui:Icons and labels}}၊ {{ui:Icons only}} သို့မဟုတ် {{ui:Labels only}}၊ နှင့် {{ui:Show group names (File, Draw, …)}}။

## သင့်ပန်နယ်များ သင့်ထံတွင် ဆက်ရှိသည်

ဘယ်နှင့် ညာ ပန်နယ်များသည် [ပန်နယ်များ စီစဉ်ရန်](common:arrange-panels) တွင် ဖော်ပြထားသော အရာအားလုံးကို ဆက်ထားပါသည်- ချိတ်ခြင်း၊ မျောခြင်း၊ ပင်ထိုးခြင်း၊ ဝှက်ခြင်း၊ tab များ၊ {{ui:Move to a new window}} နှင့် {{ui:Reset layout}}။

## classic အပြင်အဆင်သို့ ပြန်သွားရန်

{{ui:Settings}} › {{ui:Global}} › {{ui:Layout}} › {{ui:Workspace}} ကို ဖွင့်ပြီး {{ui:CadCraft classic}} ကို ရွေးပါ။ toolbar၊ tab နှင့် ပန်နယ်တိုင်း မူလနေရာသို့ ပြန်ရောက်ပါမည်။

:::note
ဖုန်းတွင်၊ သို့မဟုတ် 760 pixel ထက် ကျယ်မှု သေးငယ်သော window တွင် app က သင်ရွေးထားသည်ကို မည်သို့ပင် ဖြစ်စေ ဖုန်း အပြင်အဆင်ကို သုံးပါသည်။ window ပိုကျယ်လျှင် သင့်အပြင်အဆင် ပြန်ပေါ်ပါမည်။
:::

အခြား အပြင်အဆင်ကို စမ်းရန် [ရစ်ဘန်နှင့် ပရောဂျက် ဘရောက်ဇာ အပြင်အဆင်](common:layout-ribbon) ကို ကြည့်ပါ။

## သင့်ဖိုင်များ သင့်ကွန်ပျူတာပေါ်တွင် ရှိနေသည်

ပုံဆွဲ၊ မော်ဒယ် သို့မဟုတ် PDF ကို ဖွင့်သောအခါ app သည် browser အတွင်းမှ ဖတ်ပါသည်။ **ဖိုင်ကို တင်ခြင်း မရှိပါ။** ကျွန်ုပ်တို့ ဘယ်တော့မှ မမြင်ပါ၊ ချိတ်ဆက်မှု မရှိလည်း အတူတူ အလုပ်လုပ်ပါသည်။

## သိမ်းပုံ

browser စာမျက်နှာသည် သင့်ကွန်ပျူတာရှိ ဖိုင်များကို ကိုယ်တိုင် အစားထိုးနိုင်ခြင်း မရှိသဖြင့် app များသည် ဖိုင်အသစ်ကို **ဒေါင်းလုဒ်** လုပ်ခြင်းဖြင့် သိမ်းပါသည်-

- ဒေါင်းလုဒ်သည် browser က ဒေါင်းလုဒ်များ ထားသော နေရာသို့ သွားပါသည်၊ များသောအားဖြင့် Downloads ဖိုလ်ဒါ ဖြစ်ပြီး browser ကို ဖိုင်တိုင်း မေးရန် သတ်မှတ်ထားခြင်း မရှိလျှင် ဖြစ်ပါသည် ([ဘရောက်ဇာနှင့် ကွန်ပျူတာများ](common:browsers#what-differs-between-browsers) ကို ကြည့်ပါ)။
- ဖိုင်ကို ပြောင်းသော app များသည် "(edited)" သို့မဟုတ် "(marked up)" ကဲ့သို့ အမည်အသစ်ဖြင့် မိတ္တူ သိမ်းပါသည်၊ သင့်မူရင်းဖိုင် မပြောင်းလဲဘဲ ရှိနေပါမည်။
- သိမ်းမထားသော အလုပ်ရှိစဉ် tab ကို ပိတ်လျှင် browser က အရင်မေးပါမည် ("Leave site?")။

## browser မှတ်ထားသည်များ

app အချို့သည် သင့် browser တွင် အသေးစား ဆက်တင်များကို မှတ်ထားပါသည်၊ ဥပမာ သင့်အမည် သို့မဟုတ် tool style များ။ ၎င်းတို့သည် ထို browser နှင့် ထို ကွန်ပျူတာတွင် ကျန်ရှိပြီး site data ကို ရှင်းလျှင် ပျက်ပါသည်။ app တစ်ခုစီ၏ help က မည်သည်ကို မှတ်ထားသလဲ ပြောပါသည်။

## Cloud သိမ်းခြင်း

ကွန်ပျူတာများကြား cloud သိမ်းခြင်းနှင့် sync သည် စီးပွားဖြစ် လိုင်စင်၏ အစိတ်အပိုင်း ဖြစ်ပါသည်။ ယခု မရရှိနိုင်သေးပါ။ ထိုအချိန်အထိ သင့်ဖိုင်များကို အခြား project ဖိုင်များ သိမ်းသည့်နေရာတွင် ထားပြီး ပုံမှန်နည်းလမ်းဖြင့် backup လုပ်ပါ။

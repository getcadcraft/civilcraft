## shortcut များ မည်သို့ ရေးသားသလဲ

help က shortcut တစ်ခုစီကို သင့်ကီးဘုတ်က အညွှန်းတပ်ထားသည့်အတိုင်း ရေးပါသည်။

| ရေးထားပုံ | Mac တွင် | Windows နှင့် Linux တွင် |
|---|---|---|
| {{key:Mod+S}} | Command (⌘) နှင့် S | Ctrl နှင့် S |
| {{key:Ctrl+Shift+F}} | Control (⌃)၊ Shift (⇧) နှင့် F | Ctrl၊ Shift နှင့် F |
| {{key:Alt+Left}} | Option (⌥) နှင့် ← | Alt နှင့် ← |
| {{key:Backspace}} | Delete ကီး | Backspace |
| {{key:Delete}} | fn နှင့် Delete (forward delete) | Delete |
| {{key:Enter}} | Return | Enter |

အပေါင်းသင်္ကေတ (+) ဆိုသည်မှာ ကီးများကို အတူတကွ ဖိထားရန် ဖြစ်ပါသည်။ "ထို့နောက်" ဆိုသည်မှာ တစ်ခုပြီးတစ်ခု နှိပ်ရန် ဖြစ်ပါသည်။

shortcut အများစုသည် Mac တွင် Command သို့မဟုတ် Control နှစ်မျိုးလုံးကို လက်ခံသဖြင့် {{key:Mod+Z}} သည် နည်းနှစ်မျိုးလုံးဖြင့် အလုပ်လုပ်ပါသည်။ အချို့မှာမူ၊ ဥပမာ full screen ({{key:Ctrl+Shift+F}}) သည် ကွန်ပျူတာတိုင်းတွင် Control ကီးကို သုံးပါသည်; ထိုနေရာတွင် help က ထိုအကြောင်း ပြောပြပါသည်။

## Mac ပေါ်ရှိ function ကီးများ

Mac ကီးဘုတ်အများစုတွင် အပေါ်ဆုံးတန်းသည် အလင်းရောင်၊ အသံနှင့် media ကို ပြောင်းပါသည်။ F1 မှ F12 ကို ပို့ရန်-

- ကီးကို နှိပ်စဉ် **fn** (သို့မဟုတ် globe ကီး) ကို ဖိထားပါ၊ သို့မဟုတ်
- **System Settings** ကို ဖွင့်ပြီး **Keyboard**၊ ထို့နောက် **Keyboard Shortcuts**၊ ထို့နောက် **Function Keys** ကို ရွေးကာ "Use F1, F2, etc. keys as standard function keys" ကို ဖွင့်ပါ။

F-ကီး အချို့ကို macOS ကိုယ်တိုင်က သိမ်းထားပါသည် (ဥပမာ Mission Control)။ ကီးတစ်ခုသည် app တွင် ဘာမှမလုပ်ပါက fn ဖြင့် စမ်းကြည့်ပါ၊ သို့မဟုတ် toolbar ခလုတ်ကို သုံးပါ။

## ဘရောက်ဇာ ထိန်းထားသော shortcut များ

ဝဘ်စာမျက်နှာသည် ဘာပဲလုပ်လုပ် ဘရောက်ဇာမှ shortcut အချို့ကို ယူနိုင်မည် မဟုတ်ပါ။ app အားလုံးတွင်-

- {{key:Mod+N}}၊ {{key:Mod+T}} နှင့် {{key:Mod+W}} သည် အမြဲ ဘရောက်ဇာ window နှင့် tab များကို ဖွင့်ခြင်း သို့မဟုတ် ပိတ်ခြင်း ဖြစ်ပါသည်။ app များက New နှင့် Close အတွက် ခလုတ်များကို သုံးပါသည်။
- Mac တွင် {{key:Mod+Q}} နှင့် Windows တွင် {{key:Alt+F4}} သည် ဘရောက်ဇာကို ပိတ်ပါသည်။ သိမ်းမထားသော အလုပ် ရှိလျှင် ဘရောက်ဇာက ("Leave site?") ဟု အရင်မေးပါမည်; ဆက်မနေရန် ရွေးပြီး သိမ်းပါ။
- ဘရောက်ဇာ၏ ကိုယ်ပိုင် full screen ({{pick:mac=Control-Command-F, သို့မဟုတ် window ပေါ်ရှိ အစိမ်းရောင် ခလုတ်|windows linux=F11}}) သည် ဆက်အလုပ်လုပ်ပါသည်။ app များတွင် {{key:Ctrl+Shift+F}} ဖြင့် ကိုယ်ပိုင် screen mode များလည်း ရှိပြီး app ၏ bar များကိုပါ ဝှက်နိုင်ပါသည်။

## Trackpad ပေါ်ရှိ mouse ခလုတ်များ

app များသည် right ခလုတ်နှင့် middle ခလုတ်ကို သုံးပါသည်။ ခလုတ်သုံးခုပါသော မောက်စ် မရှိလျှင်-

:::mac
- **Right-click:** လက်ညှိုးနှစ်ချောင်းဖြင့် နှိပ်ပါ။ လက်ညှိုးနှစ်ချောင်းနှိပ်ခြင်း အလုပ်မလုပ်ပါက **System Settings** ထဲရှိ **Trackpad** တွင် "Secondary click" ကို ဖွင့်ပါ။ {{key:Ctrl}} ကို ဖိထားပြီး နှိပ်ခြင်းသည် ဘရောက်ဇာ menu ကို ဖွင့်ပါသည်၊ သို့သော် ပုံဆွဲအတွင်း app အချို့က Control ဖိထားသော ရိုးရိုး click အဖြစ် ဖတ်နိုင်ပါသည်၊ ထို့ကြောင့် လက်ညှိုးနှစ်ချောင်းနှိပ်ခြင်းကို ဦးစားပေးပါ။
- **Middle-button drag (pan):** app တစ်ခုစီက pan လုပ်ရန် နည်းလမ်းအခြားတစ်ခု ပေးပါသည်၊ ဥပမာ {{key:Space}} ကို ဖိထားပြီး ဆွဲခြင်း သို့မဟုတ် right ခလုတ်ဖြင့် ဆွဲခြင်း။ app ၏ ကီးဘုတ် စာမျက်နှာက မည်သည်ကို သုံးရမည်ကို ပြောပါသည်။
- **Wheel zoom:** trackpad ပေါ်တွင် လက်ညှိုးနှစ်ချောင်း scroll လုပ်ခြင်းသည် app အများစုတွင် zoom in လုပ်ပါသည်။ app က ထောက်ပံ့ပါက pinch လည်း zoom လုပ်ပါသည်။
:::

:::windows linux
- **Right-click:** လက်ညှိုးနှစ်ချောင်းဖြင့် နှိပ်ပါ၊ သို့မဟုတ် touchpad ၏ ညာအောက်ထောင့်ကို နှိပ်ပါ။ ၎င်းသည် touchpad ဆက်တင်များပေါ် မူတည်ပါသည်။
- **Middle-button drag (pan):** app တစ်ခုစီက pan လုပ်ရန် နည်းလမ်းအခြားတစ်ခု ပေးပါသည်၊ ဥပမာ {{key:Space}} ကို ဖိထားပြီး ဆွဲခြင်း သို့မဟုတ် right ခလုတ်ဖြင့် ဆွဲခြင်း။ app ၏ ကီးဘုတ် စာမျက်နှာက မည်သည်ကို သုံးရမည်ကို ပြောပါသည်။
- **Wheel zoom:** touchpad ပေါ်တွင် လက်ညှိုးနှစ်ချောင်း scroll လုပ်ခြင်းသည် app အများစုတွင် zoom လုပ်ပါသည်။
:::

## စာသားအကွက်တွင် စာရိုက်ခြင်း

စာရိုက်နေစဉ် (အမည်၊ မှတ်ချက်၊ ရှာဖွေရေး) app ၏ အက္ခရာတစ်လုံးတည်း shortcut များ ပိတ်ထားပါသည်၊ ထို့ကြောင့် "L" ကို ရိုက်လျှင် L ဟုသာ ပေါ်ပါသည်။ ကီးများကို app သို့ ပြန်ပေးရန် {{key:Esc}} ကို နှိပ်ပါ သို့မဟုတ် ပုံဆွဲပေါ်တွင် နှိပ်ပါ။

ပုံဆွဲနားရှိ ပန်နယ်များကို ရွှေ့နိုင်ပါသည်။ သင့်အတွက် အဆင်ပြေရာတွင် ထားနိုင်သလို၊ ဒုတိယ မော်နီတာပေါ်တွင် ကိုယ်ပိုင် window ပေးပြီး ပထမ မော်နီတာတွင် ပုံဆွဲကို အပြည့် ပြသနိုင်ပါသည်။

:::note
ပန်နယ်တိုင်းတွင် title bar ရှိပါသည်- ပန်နယ်၏ အမည်၊ {{ui:⋯}} menu၊ ပင်နှင့် ပိတ်ခလုတ်တို့ပါသော ပါးလွှာသည့် bar ဖြစ်ပြီး ပန်နယ်၏ အပေါ်ဆုံးတွင် ရှိပါသည်။ ဗားရှင်း 0.7 မတိုင်မီတွင် အမည်နှင့် {{ui:⋯}} menu သာ ရှိပါသည်။
:::

## window အတွင်း ပန်နယ်ကို ရွှေ့ရန်

1. ပန်နယ်ကို အပေါ်ရှိ အမည်ဖြင့် ဆွဲပါ။
2. ဆွဲနေစဉ် ပုံဆွဲ၏ ဘယ်၊ ညာနှင့် အောက်ခြေတွင် ဘောင်ခတ်ထားသော နေရာများ ပေါ်လာပါမည်။ ထိုနေရာတစ်ခုပေါ်တွင် ပန်နယ်ကို ချလိုက်ပါက ထိုနေရာတွင် ချိတ်ပါမည်။ သင် ရောက်နေသော နေရာ မှိန်ပါမည်။
3. ပုံဆွဲပေါ်ရှိ အခြားနေရာတွင် ချလိုက်ပါက မျောနေပါမည်။

ပန်နယ်များသည် တစ်ဘက်တည်းတွင် ပေါင်းနိုင်ပါသည်- ၎င်းတို့ စုကြပြီး ပန်နယ်နှစ်ခုကြားရှိ မျဉ်းတစ်ခုစီကို ဆွဲ၍ နေရာကို မျှဝေနိုင်ပါသည် (မျဉ်းကို focus ထားစဉ် မြားကီးများက ရွှေ့ပေးပြီး၊ နှစ်ချက်နှိပ်လျှင် နေရာကို ညီညီမျှမျှ မျှဝေပေးပါမည်)။ ချိတ်ထားသော ဘေးတစ်ဖက်၏ အတွင်းအစွန်းကို ဆွဲ၍ ပိုကျယ် သို့မဟုတ် ကျဉ်းအောင် ပြင်နိုင်ပြီး၊ အစွန်းကို နှစ်ချက်နှိပ်လျှင် မူလအတိုင်း ပြန်ထားပါမည်။

မျောနေသော ပန်နယ်သည် ပုံဆွဲပေါ်တွင် အမြဲရှိနေပါသည်။ အမည်ဖြင့် ရွှေ့ပါ၊ ညာအောက်ထောင့်ကို ဆွဲ၍ အရွယ်အစား ပြင်ပါ (သို့မဟုတ် ထောင့်သို့ tab နှိပ်ပြီး မြားကီးများ သုံးပါ)။ အမည်ကို နှစ်ချက်နှိပ်လျှင် ယခင်နေရာတွင် ပြန်ချိတ်ပါမည်။

:::touch
ပန်နယ်၏ အမည်ပေါ်တွင် လက်ညှိုးတစ်ချောင်းဖြင့် ဆွဲပါ။ မျောနေသော ပန်နယ်၏ ညာအောက်ထောင့်ကို လက်တစ်ချောင်းဖြင့် ဆွဲ၍ အရွယ်ပြင်နိုင်ပြီး၊ ချိတ်ထားသော ပန်နယ်များကြား အစွန်းများကိုလည်း အလားတူ ပြင်နိုင်ပါသည်။ ဆွဲစရာမလိုဘဲ မျောခြင်း သို့မဟုတ် ချိတ်ခြင်း လုပ်လိုပါက {{ui:⋯}} menu ကို သုံးပါ။
:::

## ပန်နယ်များကို tab အဖြစ် အုပ်စုဖွဲ့ရန်

ပန်နယ်နှစ်ခုသည် frame တစ်ခုတည်းကို မျှဝေပြီး တစ်ကြိမ်လျှင် တစ်ခုသာ ပြနိုင်ပါသည်။ ပန်နယ်တစ်ခုကို အမည်ဖြင့် ဆွဲ၍ အခြားပန်နယ်၏ title bar ပေါ်သို့ ချပါ (ရောက်နေစဉ် bar ကို ဘောင်ခတ်ပြပါသည်) ပြီး လွှတ်ပါ။ ထိုအခါ frame ၏ title bar တွင် ပန်နယ်တစ်ခုစီအတွက် tab ရှိလာပါမည်။ tab ကို နှိပ်လျှင် ထိုပန်နယ်ကို ပြပါသည်။ tab ကို focus ထားစဉ် {{key:Left}} နှင့် {{key:Right}} က tab များကို ပြောင်းပြီး၊ {{key:Home}} နှင့် {{key:End}} က ပထမ နှင့် နောက်ဆုံး tab သို့ သွားပါသည်။

အုပ်စုမှ ပန်နယ်တစ်ခုကို ထုတ်လိုပါက ၎င်း၏ {{ui:⋯}} menu တွင် {{ui:Move out of the tab group}} ကို ရွေးပါ၊ သို့မဟုတ် အခြားနေရာသို့ ဆွဲပါ။ ဆွဲစရာမလိုဘဲ အုပ်စုဖွဲ့လိုပါက {{ui:Tab with}} ကို ရွေးပြီး ပန်နယ်အမည်ကို ရွေးပါ။

## ပင်ထိုးခြင်း၊ ဝှက်ခြင်းနှင့် ပြန်ခေါ်ခြင်း

- ပန်နယ်၏ title bar ရှိ ပင်သည် ပန်နယ်ကို **auto-hide** ဖြစ်စေပါသည်။ ပန်နယ်သည် ချိတ်ထားသော နေရာမှ ထွက်ပြီး ထိုအစွန်းတွင် tab ငယ်တစ်ခု ဖြစ်လာပါမည်။ tab ပေါ်ကို ညွှန်လိုက်၊ focus လုပ်လိုက် သို့မဟုတ် နှိပ်လိုက်လျှင် ပန်နယ်သည် ပုံဆွဲပေါ်သို့ ထွက်လာပါမည်။ အပြင်သို့ ရွှေ့လိုက် (သို့မဟုတ် {{key:Esc}} ကို နှိပ်လိုက်) လျှင် ပြန်ဝင်သွားပါမည်။ ပင်ကို ထပ်နှိပ်ခြင်း သို့မဟုတ် {{ui:Unpin}} ကို ရွေးခြင်းဖြင့် အပြီးတိုင် ချိတ်ထားနိုင်ပါသည်။
- ပိတ်ခလုတ် သို့မဟုတ် menu ရှိ {{ui:Hide this panel}} သည် ပန်နယ်ကို ဝှက်ပြီး ၎င်း၏ ချိတ်ထားသော နေရာကို ပိတ်ပါသည်။ အစွန်းရှိ မျဉ်းတိုက်ထားသော tab က ပြန်ခေါ်ပေးပါသည်- ၎င်းကို နှိပ်ပါ၊ သို့မဟုတ် focus လုပ်ပြီး {{key:Enter}} ကို နှိပ်ပါ။

## အပြင်အဆင်ကို ပို သိပ်သည်းအောင် လုပ်ရန်

{{ui:Settings}} › {{ui:General}} › {{ui:Layout density}} တွင် ရွေးချယ်စရာ နှစ်ခု ရှိပါသည်။ {{ui:Comfortable}} သည် ပုံသေ ဖြစ်ပါသည်။ {{ui:Compact}} က ထို app ၏ အတန်းအမြင့်၊ ပန်နယ် padding၊ toolbar ခလုတ်များနှင့် ပန်နယ်စာသားကို တင်းစေပြီး မျက်နှာပြင်ပေါ်တွင် ပိုမို ဝင်စေပါသည်။ ၎င်းကို app တစ်ခုစီအတွက် သိမ်းထားပါသည်။ touch screen သည် ခလုတ်ကြီးများကို နှစ်မျိုးလုံးတွင် ထားပြီး ဖုန်းသည် ကိုယ်ပိုင် အပြင်အဆင်ကို ထားပါသည်။ {{ui:Reset layout}} သည် သင် သတ်မှတ်ထားသော သိပ်သည်းမှုကို ဆက်ထားပါသည်။

## toolbar ဘယ်နှစ်တန်း သုံးမလဲ ရွေးရန်

{{ui:Settings}} › {{ui:General}} › {{ui:Toolbar rows}} တွင် ရွေးချယ်စရာ သုံးခု ရှိပါသည်။ {{ui:Wrap}} သည် ပုံသေ ဖြစ်ပါသည်- tool group အားလုံး ပြပြီး လိုသလောက် အတန်းများဖြင့် ပြပါသည်။ {{ui:2 rows}} က toolbar ကို အတန်း ၂ တန်းတွင်၊ {{ui:1 row}} က အတန်း ၁ တန်းတွင် ထားပေးပြီး ပုံဆွဲအတွက် အမြင့် ပိုရစေပါသည်။ မကိုက်ညီသော group များသည် toolbar အတွင်း ဘေးသို့ scroll လုပ်နိုင်ပါသည် (mouse wheel၊ လက်ချောင်းနှစ်ချောင်း swipe သို့မဟုတ် ကိရိယာသို့ {{key:Tab}} ကို သုံးပါ)။ အတန်း ၂ တန်းအတွင်း ကိုက်ညီနေပြီးသား toolbar သည် {{ui:2 rows}} အောက်တွင် မပြောင်းပါ၊ ဘာကြောင့်ဆိုတော့ grid က အမြင့်ကိုသာ တိုးစေမှာ ဖြစ်သည်။ ရွေးချယ်ချက်ကို app တစ်ခုစီအတွက် သိမ်းပါသည်။ touch screen နှင့် ဖုန်းတို့သည် ကိုယ်ပိုင် အပြင်အဆင်ကို ထားပါသည်။ CadCraft တွင် ၎င်း၏ toolbar အတွက် {{ui:Settings}} › {{ui:CadCraft}} အောက်တွင် သီးခြား ဆက်တင် ရှိပါသည်။

## ကီးဘုတ်ဖြင့် သုံးရန်

ပန်နယ်တိုင်း၏ {{ui:⋯}} ခလုတ်သည် menu တစ်ခု ဖွင့်ပေးပါသည်- {{ui:Dock on the left}}၊ {{ui:Dock on the right}}၊ {{ui:Dock at the bottom}}၊ {{ui:Float over the drawing}}၊ {{ui:Pin to the edge}}၊ {{ui:Hide this panel}}၊ အခြားပန်နယ်နှင့် {{ui:Tab with}}၊ {{ui:Move to a new window}} နှင့် {{ui:Put it back}}။ {{key:Tab}} ဖြင့် ခလုတ်သို့ သွား၊ {{key:Enter}} ကို နှိပ်၊ မြားကီးများဖြင့် ရွှေ့ပြီး {{key:Enter}} ကို ထပ်နှိပ်ပါ။ {{key:Esc}} က menu ကို ပိတ်ပါသည်။

## ဒုတိယ မော်နီတာပေါ်တွင် ပန်နယ်များ ထားရန်

1. ပန်နယ်တစ်ခုပေါ်ရှိ {{ui:⋯}} ကို ရွေးပြီး {{ui:Move all panels to a new window}} ကို ရွေးပါ။ {{ui:Settings}} တွင် {{ui:Move panels to a new window}} ကိုလည်း ရွေးနိုင်ပါသည်။
2. ပန်နယ်များပါသော window ငယ်တစ်ခု ဖွင့်လာပါမည်။ ၎င်းကို သင့်အခြား မော်နီတာသို့ ဆွဲပြီး လိုသလောက် ကြီးအောင် လုပ်ပါ။
3. ဆက်လုပ်ပါ- ပန်နယ်များသည် ယခင်အတိုင်း ပုံဆွဲအပေါ် လုပ်ဆောင်ပြီး၊ ပုံဆွဲက main window ကို ပြည့်ပါသည်။

panels window ရှေ့ဆုံးတွင် ရှိနေစဉ် shortcut များ ဆက်အလုပ်လုပ်ပါသည်- ထိုနေရာတွင် နှိပ်သော ကီးများ (box တွင် စာရိုက်ခြင်းမှလွဲ၍) သည် ပုံဆွဲသို့ ရောက်ပါသည်။ app မေးသော မေးခွန်းများနှင့် dialog များသည် main window တွင် ဖွင့်ပါသည်၊ ပေါ်လာသည့်အခါ ထိုနေရာကို ကြည့်ပါ။ theme နှင့် ပန်နယ်စာသား အရွယ်အစားသည် main window ကို လိုက်ပါသည်။

:::chromium
Chrome နှင့် Edge သည် window ကို အခြားမျက်နှာပြင်တွင် သင့်အတွက် ထားပေးနိုင်ပါသည်။ ဒုတိယ မျက်နှာပြင် ချိတ်ဆက်ထားလျှင် panels window တွင် {{ui:Put it on my other screen}} ကို ရွေးပါ (သို့မဟုတ် ပန်နယ်၏ {{ui:⋯}} menu တွင် {{ui:Put the panels on my other screen}})။ browser က ဝဘ်ဆိုဒ်က သင့်မျက်နှာပြင်များကို ကြည့်ခွင့် ရှိမရှိ တစ်ကြိမ်မေးပါမည်၊ ခွင့်ပြုပြီးနောက် panels window သည် ထို မျက်နှာပြင်တွင် အမြဲ ဖွင့်ပါမည်။
:::

:::firefox safari
panels window ကို အခြား မော်နီတာသို့ ကိုယ်တိုင် ဆွဲပါ။ နောက်တစ်ကြိမ် ဖွင့်သောအခါ ၎င်းသည် တူညီသော နေရာနှင့် အရွယ်အစားဖြင့် ဖွင့်ပါမည်။
:::

## panels window တစ်ခုထက်ပို

ပန်နယ်တစ်ခုစီသည် ကိုယ်ပိုင် window ရနိုင်ပါသည်- panels window ၄ ခုအထိ ရှိနိုင်ပြီး ဥပမာ မော်နီတာတစ်ခုလျှင် တစ်ခု။

- ပန်နယ်၏ {{ui:⋯}} menu တွင် {{ui:Move to a new window}} က ထိုပန်နယ်အတွက် window အသစ် ဖွင့်ပေးပြီး၊ {{ui:Move to panels window 2}} (နှင့် ဆက်တိုက်) က ဖွင့်ထားပြီးသား window တစ်ခုထဲသို့ ရွှေ့ပေးပါသည်။ ဒုတိယ window ကို "panels 2" ဟု ခေါ်ပါသည်။
- ပန်နယ်ကို အမည်ဖြင့် window တစ်ခုမှ အခြားတစ်ခုသို့ ဆွဲပါ- main window ပေါ်တွင် လွှတ်လျှင် ထိုနေရာတွင် ချိတ်မည် (ရောက်နေစဉ် ဘောင်ခတ်ပြသည်) သို့မဟုတ် မျောမည်၊ အခြား panels window ပေါ်တွင် လွှတ်လျှင် ထိုထဲသို့ ရွှေ့မည်။ အခြားနေရာတွင် လွှတ်လျှင် မူလနေရာတွင် ဆက်နေမည်။
- ပန်နယ် မကျန်တော့သော panels window သည် ကိုယ်ဘာသာ ပိတ်သွားပါမည်။

app ကို reload လုပ်ပြီးနောက် သင်၏ panels window များကို ပြန်ဖွင့်ရန် app က ကမ်းလှမ်းပါမည်။ browser များသည် click တစ်ကြိမ်လျှင် window တစ်ခု ဖွင့်သဖြင့်၊ window တစ်ခုစီအတွက် {{ui:နောက်တစ်ခု ဖွင့်ရန်}} ကို တစ်ကြိမ်စီ ရွေးပါ။

## dialog ကို ရွှေ့ရန်

dialog တိုင်းကို ပုံဆွဲနှင့် မတိုက်စေရန် ရွှေ့နိုင်ပါသည်- ၎င်း၏ title bar ကို နှိပ်ပြီး ဆွဲပါ။ dialog သည် သင်ထားခဲ့သော နေရာကို မှတ်ထားပြီး dialog တစ်ခုစီ ကိုယ်ပိုင်ဖြစ်ပါသည်၊ နောက်တစ်ကြိမ် ဖွင့်သောအခါ ထိုနေရာသို့ ပြန်ရောက်ပါမည်။ title bar ကို နှစ်ချက်နှိပ်လျှင် အလယ်သို့ ပြန်ထားပါမည်။

ကီးဘုတ်ဖြင့်ဆိုလျှင် dialog အတွင်း focus ရှိစဉ် {{key:Alt}}+{{key:Shift}} နှင့် မြားကီးတစ်ခုကို နှိပ်ပါက pixel ၁၆ ခုစီ ရွှေ့ပါမည်; {{key:Ctrl}} ထည့်လျှင် ၆၄ ခုစီ ရွှေ့ပါမည်။ မျက်နှာပြင်အပြင်ရောက်သွားသော dialog (window သို့မဟုတ် မျက်နှာပြင် ငယ်သွားပြီးနောက်) ကို ပြန်ယူပေးပါမည်။

ဖုန်းတွင် dialog များသည် အပြည့်အကျယ် sheet အဖြစ် ဆက်နေပြီး ရွှေ့ခြင်း မရှိပါ။

CadCraft Studio တွင် CadCraft ၏ {{ui:Plot to PDF}} dialog (အလုပ်လုပ်စဉ် ဖွင့်ထားနိုင်သည်) သည် title bar တွင် {{ui:Open in its own window}} ခလုတ် ရှိပါသည်။ dialog သည် ကိုယ်ပိုင် window သို့ ရွှေ့သွားပြီး အခြားမော်နီတာပေါ်တွင် ထားနိုင်ပါသည်။ dialog ကို ပိတ်လျှင် window ပိတ်ပါမည်၊ window ကို ပိတ်လျှင် dialog ပိတ်ပါမည်။

## ပန်နယ်များ ပြန်ထားရန်

- panels window တွင် {{ui:Put the panels back}} ကို ရွေးပါ၊ သို့မဟုတ် ရိုးရိုး ပိတ်ပါ။ ပန်နယ်များသည် ယခင်နေရာသို့ ပြန်ရောက်ပါမည်။
- main window ကို ပိတ်ခြင်း သို့မဟုတ် reload လုပ်ခြင်းသည် panels window ကိုလည်း ပိတ်ပါသည်။ app ပြန်ဖွင့်သောအခါ သင့်ပန်နယ်များသည် ကိုယ်ပိုင် window တွင် ရှိကြောင်း ပြောပါမည်; window ကို ပြန်ဖွင့်ရန် {{ui:Open it}} ကို ရွေးပါ၊ သို့မဟုတ် {{ui:Keep them here}} ကို ရွေးပါ။
- {{ui:Settings}} › {{ui:General}} › {{ui:Reset layout}} သည် ပန်နယ်အားလုံးကို စတင်ခဲ့သော နေရာသို့ ပြန်ထားပါသည်။

:::tip
ပန်နယ်များကို window အသစ်သို့ ရွှေ့သောအခါ ဘာမှ မဖွင့်လျှင် browser က pop-up ကို ပိတ်ထားခြင်း ဖြစ်နိုင်ပါသည်။ app က ထိုအကြောင်း ပြောပြပြီး ပန်နယ်များကို ယခင်နေရာတွင် ထားပါမည်။ getcadcraft.com အတွက် pop-up များကို ခွင့်ပြုပြီး ထပ်ကြိုးစားပါ။
:::

အပြင်အဆင်ကို ဤ browser တွင် app တစ်ခုစီအတွက်၊ အခြား ဆက်တင်များနှင့်အတူ သိမ်းထားပါသည်။

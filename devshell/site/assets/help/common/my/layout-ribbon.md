**ရစ်ဘန်နှင့် ပရောဂျက် ဘရောက်ဇာ** သည် app ၏ workspace အပြင်အဆင် သုံးခုအနက် တစ်ခု ဖြစ်ပါသည်။ tab များပါသော ရစ်ဘန်သည် အပေါ်တွင် ပြေးနေပြီး၊ Properties နှင့် ပရောဂျက် ဘရောက်ဇာက ဘယ်ဘက် ပန်နယ်ကို မျှဝေပါသည်၊ ဖွင့်ထားသော view တိုင်းသည် ပုံဆွဲအပေါ်တွင် tab ရရှိပြီး၊ status bar က အောက်ခြေတွင် ရှိပါသည်။ ကိရိယာများသည် app ၏ ကိုယ်ပိုင် ဖြစ်ပါသည်- classic အပြင်အဆင်တွင် လုပ်နိုင်သမျှ ဤနေရာတွင်လည်း လုပ်နိုင်ပြီး၊ သင့်ပုံဆွဲ၊ menu ပုံစံနှင့် ကီးများ မူလအတိုင်း ရှိနေပါမည်။

## ရွေးရန်

1. {{ui:Settings}} (ဂီယာ၊ သို့မဟုတ် {{key:Mod+,}}) ကို ဖွင့်ပါ။
2. {{ui:Global}} tab ကို ရွေးပြီး {{ui:Layout}} › {{ui:Workspace}} သို့ သွားပါ။
3. {{ui:ရစ်ဘန်နှင့် ပရောဂျက် ဘရောက်ဇာ}} ကို ရွေးပါ။

အပြင်အဆင်သည် ချက်ချင်း ပြောင်းပါမည်။ ရွေးချယ်ချက်သည် ဤ browser ရှိ app အားလုံးအတွက် တစ်ခုတည်း ဖြစ်ပြီး၊ ထိုအချိန်မှစ၍ app တိုင်း ၎င်းဖြင့် ဖွင့်ပါမည်။ ပုံမဆွဲမီ ၎င်းအဆင်သင့် ဖြစ်နေသဖြင့် classic အပြင်အဆင်ကို ပထမ မမြင်ရပါ။

## ဘယ်နေရာတွင် ဘာရှိသလဲ

- **Title bar:** app ၏ အမည်၊ quick access ခလုတ်များ (ဖွင့်၊ သိမ်း၊ undo၊ redo)၊ ဖွင့်ထားသော ဖိုင်အမည်၊ {{ui:What each tool does here}} (ရှာဖွေရေး အကွက်ပါသော ကိရိယာအားလုံး၏ စာရင်း၊ အသင့်ရှိသည်များနှင့် မရသည့် အကြောင်းပြချက်)၊ full screen၊ {{ui:Help}} နှင့် {{ui:Settings}}။ ဤအပြင်အဆင်တွင် title bar သည် app bar ၏ နေရာကို ယူပါသည်။
- **Ribbon:** app ၏ ကိရိယာများ tab များတွင်၊ tab တစ်ခုစီတွင် group များ။ ဘယ်ဘက်ရှိ {{ui:File}} က ဖွင့်၊ သိမ်းနှင့် အခြားများကို ပေးပါသည်။ app အချို့က အလုပ်လုပ်စဉ် mode သို့မဟုတ် workspace တစ်ခုအတွက် ကိုယ်ပိုင် tab ထည့်ပေးပါသည်; ထို tab သည် သက်ဆိုင်စဉ် မီးလင်းပြီး ပြီးလျှင် ပျောက်ပါသည်။
- **Options bar:** ribbon အောက်တွင်၊ လည်ပတ်နေသော ကိရိယာက သင့်ထံ လိုအပ်သည့်အရာ သို့မဟုတ် ရွေးထားသည့်အရာ။
- **ဘယ်ဘက် ပန်နယ်:** အပေါ်တွင် {{ui:Properties}}၊ အောက်တွင် palette များ (project browser နှင့် ပန်နယ်၏ ကိုယ်ပိုင် အကြောင်းအရာ) tab များအဖြစ်။ ၎င်းတို့ကြား မျဉ်းကို ဆွဲ၍ နေရာ မျှဝေပါ။
- **View tab များ:** ဖွင့်ထားသော view တစ်ခုစီအတွက် tab တစ်ခု (sheet၊ plan၊ scene…)။ ၎င်း၏ close ခလုတ်ဖြင့် တစ်ခု ပိတ်ပါ; ဖိုင်ကတော့ ဖွင့်ထားဆဲ ဖြစ်ပါသည်။
- **View bar နှင့် status bar:** ပုံဆွဲအောက်တွင် view ၏ ကိုယ်ပိုင် ထိန်းချုပ်ချက်များ (scale၊ zoom); အောက်ခြေတွင် app ၏ မက်ဆေ့ချ်များ။

ယခု လည်ပတ်၍ မရသော ကိရိယာကို မီးခိုးရောင်ပြပြီး tooltip က အကြောင်းပြပါသည် (ဥပမာ "Open a file first" သို့မဟုတ် app တွင် ထိုကိရိယာ မရှိသေးကြောင်း)။ ၎င်းကို နှိပ်ပါ သို့မဟုတ် {{key:Enter}} ကို နှိပ်ပြီး အကြောင်းရင်းကို box တွင် ဖတ်ပါ။

## ကီးဘုတ်ဖြင့် ribbon သုံးရန်

ribbon tab ကို focus ထားစဉ် {{key:Left}} နှင့် {{key:Right}} က tab များကြား ရွှေ့ပြီး {{key:Home}} နှင့် {{key:End}} က ပထမ နှင့် နောက်ဆုံးသို့ သွားပါသည်။ {{key:Esc}} က classic အပြင်အဆင်ကဲ့သို့ ပထမဆုံး လည်ပတ်နေသော ကိရိယာကို ရပ်ပါသည်၊ shortcut အားလုံးနှင့် {{key:Ctrl+Shift+F}} (screen mode များ) က ယခင်အတိုင်း အလုပ်လုပ်ပါသည်။

## ribbon ကို ခေါက်ရန် သို့မဟုတ် ကိုယ်ပိုင် window ပေးရန်

- ribbon tab ကို နှစ်ချက်နှိပ်လျှင် ribbon သည် tab များသို့ ခေါက်သွားပါသည်; tab ကို နှိပ်လျှင် ထို tab ၏ ကိရိယာများ ပြပါသည်၊ နောက်တစ်ခုသို့ မသွားမချင်း။ ပြန်ဖွင့်ရန် နှစ်ချက်ထပ်နှိပ်ပါ။ ribbon ၏ ညာဘက်အဆုံးရှိ {{ui:Move the ribbon}} ခလုတ်တွင် {{ui:Collapse the ribbon}} နှင့် {{ui:Keep the ribbon open}} လည်း ရှိပါသည်။ app တိုင်းက ၎င်းကို မှတ်ထားပါသည်။
- {{ui:Move the ribbon}} › {{ui:Move to a new window}} က ribbon ကို ကိုယ်ပိုင် window တွင် ထားပေးပါသည်၊ ဥပမာ ဒုတိယ မော်နီတာပေါ်တွင်။ ထိုနေရာတွင် နှိပ်သော ကီးများသည် app သို့ ရောက်ပါသည်။ {{ui:Put the ribbon back}} သို့မဟုတ် ထို window ကို ပိတ်လျှင် ribbon ပြန်ရောက်ပါမည်။

toolbar ဆက်တင်များသည် ribbon ကို သက်ရောက်ပါသည်- {{ui:Settings}} › {{ui:Global}} › {{ui:Toolbar}} › {{ui:Icons and labels}}၊ {{ui:Icons only}} (ထိုအခါ ribbon သည် group တစ်ခုစီအတွက် အိုင်ကွန်သေး နှစ်တန်း ပြပါသည်) သို့မဟုတ် {{ui:Labels only}}၊ နှင့် {{ui:Show group names (File, Draw, …)}}။

## သင့်ပန်နယ်များ သင့်ထံတွင် ဆက်ရှိသည်

ဘယ်နှင့် ညာ ပန်နယ်များသည် [ပန်နယ်များ စီစဉ်ရန်](common:arrange-panels) တွင် ဖော်ပြထားသော အရာအားလုံးကို ဆက်ထားပါသည်- ချိတ်ခြင်း၊ မျောခြင်း၊ ပင်ထိုးခြင်း၊ ဝှက်ခြင်း၊ tab များ၊ {{ui:Move to a new window}} နှင့် {{ui:Reset layout}}။

## classic အပြင်အဆင်သို့ ပြန်သွားရန်

{{ui:Settings}} › {{ui:Global}} › {{ui:Layout}} › {{ui:Workspace}} ကို ဖွင့်ပြီး {{ui:CadCraft classic}} ကို ရွေးပါ။ toolbar၊ tab နှင့် ပန်နယ်တိုင်း မူလနေရာသို့ ပြန်ရောက်ပါမည်။

:::note
ဖုန်းတွင်၊ သို့မဟုတ် 760 pixel ထက် ကျယ်မှု သေးငယ်သော window တွင် app က သင်ရွေးထားသည်ကို မည်သို့ပင် ဖြစ်စေ ဖုန်း အပြင်အဆင်ကို သုံးပါသည်။ window ပိုကျယ်လျှင် သင့်အပြင်အဆင် ပြန်ပေါ်ပါမည်။
:::

app တိုင်းတွင် ကိုယ်ပိုင် help ပါသည်။ ၎င်းသည် app ၏ အစိတ်အပိုင်း ဖြစ်သဖြင့် ချိတ်ဆက်မှု မလိုဘဲ ဖွင့်နိုင်ပြီး သင် လည်ပတ်နေသော ဗားရှင်းကို အမြဲ ဖော်ပြပါသည်။

## help ဖွင့်ရန်

- {{key:F1}} ကို နှိပ်ပါ၊ သို့မဟုတ် app ၏ အပေါ်ဘားရှိ {{ui:Help}} ကို ရွေးပါ။
- {{key:Esc}} ကို နှိပ်ပါ သို့မဟုတ် {{ui:Close}} ကို ရွေးပြီး ပိတ်ပါ။ သင့်ပုံဆွဲ မူလအတိုင်း ရှိနေပါမည်။

:::mac
Mac ကီးဘုတ်အများစုတွင် အပေါ်ဆုံးတန်းသည် အလင်းရောင်နှင့် အသံကို ထိန်းပါသည်။ {{key:F1}} ကို **fn** ကီး (သို့မဟုတ် globe ကီး) နှင့်အတူ နှိပ်ပါ၊ သို့မဟုတ် {{ui:Help}} ခလုတ်ကို သုံးပါ။ [Mac ပေါ်ရှိ ကီးများ](common:keys#function-keys-on-a-mac) ကို ကြည့်ပါ။
:::

## topic ရှာရန်

- help ၏ အပေါ်ရှိ ရှာဖွေရေး အကွက်တွင် ရိုက်ပါ။ ရလဒ်များသည် ရိုက်သည်နှင့်အမျှ ပြောင်းလဲပြီး အခြား program များ၏ command အမည်များကိုလည်း ပါဝင်စေသဖြင့်၊ အခြားနေရာတွင် ရိုက်လေ့ရှိသည့်အရာကို ရိုက်လျှင် မှန်ကန်သော စာမျက်နှာကို ပုံမှန် တွေ့ရပါသည်။
- topic များကို app အားလုံးတွင် တူညီစွာ အုပ်စုဖွဲ့ထားပါသည်- စတင်ခြင်း၊ လမ်းညွှန်ချက်များ၊ အခြား software မှ ရောက်လာခြင်း၊ ကိုးကားချက်နှင့် ပြဿနာဖြေရှင်းခြင်း။
- topic တစ်ခုအတွင်း link များသည် နောက် topic ကို ဤ ပန်နယ်တွင် ဖွင့်ပါသည်။ {{ui:Back}} က သင်ရောက်ခဲ့သော နေရာသို့ ပြန်သွားပါသည်။

## သင့်ကွန်ပျူတာအတွက် အဆင့်များ

အဆင့် အချို့သည် Mac၊ Windows နှင့် Linux အကြား၊ ဘရောက်ဇာများအကြား၊ နှင့် online သို့မဟုတ် offline ဖြစ်ခြင်းအကြား ကွာခြားပါသည်။ help က သင်နှင့် သက်ဆိုင်သော အဆင့်များကို ရွေးပြီး ပြပါသည်။ topic ၏ အပေါ်ဆုံးလိုင်းက ၎င်းရွေးထားသည်ကို ပြောပါသည်၊ ဥပမာ "Showing steps for Mac, Chrome or Edge, online"။

- ထိုလိုင်းပေါ်ရှိ {{ui:Change}} ကို ရွေးပြီး အခြား ကွန်ပျူတာ သို့မဟုတ် ဘရောက်ဇာ ရွေးနိုင်ပါသည်၊ ဥပမာ လုပ်ဖော်ကိုင်ဖက်ကို ကူညီရန်။
- {{ui:Show all}} ကို ရွေးပြီး အဆင့်တိုင်း၏ ဗားရှင်းအားလုံးကို အမည်တပ်ပြီး ကြည့်ပါ။

ကီးဘုတ် shortcut များကို သင့်ကီးဘုတ်က အညွှန်းတပ်ထားသည့်အတိုင်း ရေးပါသည်- {{key:Mod+S}} ကို Mac တွင် ⌘S၊ Windows နှင့် Linux တွင် Ctrl+S ဟု ဖတ်ပါသည်။

## ဝက်ဆိုက်ပေါ်ရှိ တူညီသော help

ဝက်ဆိုက်တွင် တူညီသော topic များကို getcadcraft.com/tutorials တွင် platform အားလုံး၏ အဆင့်များနှင့်အတူ ပြပါသည်။ app တွင် topic ၏ အောက်ခြေရှိ {{ui:Open on the website}} က online ဖြစ်သည့်အခါ ထိုစာမျက်နှာကို ဖွင့်ပေးပါသည်။

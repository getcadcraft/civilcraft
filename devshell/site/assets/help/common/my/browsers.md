app များသည် web browser အတွင်း လည်ပတ်ပါသည်။ အလုပ်ကို သင့်ကွန်ပျူတာပေါ်တွင် လုပ်ဆောင်ပါသည်- သင့်ဖိုင်များကို ထိုနေရာတွင် ဖွင့်ပြီး ကျွန်ုပ်တို့ထံ ဘယ်တော့မှ မပို့ပါ ([သင့်ဖိုင်များ ဘယ်သွားသလဲ](common:your-files) ကို ကြည့်ပါ)။

## ဘယ်ဘရောက်ဇာ သုံးမလဲ

ဤတို့ထဲမှ နောက်ဆုံးဗားရှင်းတစ်ခုကို သုံးပါ-

| ဘရောက်ဇာ | အင်ဂျင် | မှတ်ချက် |
|---|---|---|
| Chrome, Edge, Brave, Opera, Vivaldi | Chromium | အပြည့်အစုံဆုံး- ဖိုလ်ဒါ ရွေးခြင်း၊ အော့ဖ်လိုင်း အသုံးအတွက် သိမ်းခြင်း၊ ဖိုင် ကိုင်တွယ်ခြင်း။ |
| Firefox | Gecko | အလုပ်လုပ်ပါသည်။ ဖိုလ်ဒါတစ်ခုလုံး ဖွင့်ရာတွင် ပိုရိုးရှင်းသော ရွေးချယ်ကိရိယာ သုံးသည်။ အော့ဖ်လိုင်း သိမ်းခြင်းသည် private window များတွင် အလုပ်မလုပ်နိုင်ပါ။ |
| Safari | WebKit | Mac နှင့် iPad တွင် အလုပ်လုပ်ပါသည်။ ဖိုလ်ဒါတစ်ခုလုံး ဖွင့်ရာတွင် ပိုရိုးရှင်းသော ရွေးချယ်ကိရိယာ သုံးသည်။ Safari သည် သင် အသုံးမပြုသော အော့ဖ်လိုင်းမိတ္တူကို အပတ်အနည်းငယ်အကြာတွင် ဖျက်နိုင်ပါသည်။ |

သုံးခုလုံးသည် နေ့စဉ်အလုပ်အတွက် ကောင်းပါသည်။ app တစ်ခုက တစ်ခုတွင် အခြားနည်းဖြင့် လုပ်ဆောင်ပါက၊ ၎င်း၏ help တွင် သင့်ဘရောက်ဇာအတွက် အဆင့်များ ပြပါသည်။

## ဘရောက်ဇာ တစ်ခုနှင့်တစ်ခု ဘာကွာသလဲ

- **ဖိုလ်ဒါဖွင့်ခြင်း။** Chromium ဘရောက်ဇာများသည် အမှန်ဖိုလ်ဒါ ရွေးကိရိယာ ပြပြီး ဖိုလ်ဒါကို တိုက်ရိုက် ဖတ်နိုင်ပါသည်။ Firefox နှင့် Safari က ဖိုလ်ဒါတစ်ခု ရွေးရန် မေးပြီး ထိုဖိုလ်ဒါထဲရှိ ဖိုင်အားလုံးကို ဖတ်ပါသည်၊ ၎င်းက ပရောဂျက် ဖိုလ်ဒါကြီးများအတွက် ပိုကြာပါသည်။ ဖိုလ်ဒါကို app ပေါ် ဆွဲချခြင်းသည် သုံးခုလုံးတွင် အလုပ်လုပ်ပါသည်။
- **သိမ်းခြင်း။** app များသည် ဖိုင်ကို ဒေါင်းလုဒ်လုပ်ခြင်းဖြင့် သိမ်းပါသည်။ ဒေါင်းလုဒ်များ ဘယ်သို့ သွားမလဲနှင့် အရင်မေးမလား ဆိုသည်ကို ဘရောက်ဇာက ဆုံးဖြတ်ပါသည်။

:::chromium
Chrome သို့မဟုတ် Edge တွင် Settings (Downloads အောက်) ရှိ "Ask where to save each file before downloading" ကို ဖွင့်ပါ၊ ထိုသို့ဆိုလျှင် ဖိုင်တိုင်းအတွက် ဖိုလ်ဒါကို ရွေးနိုင်ပါသည်။
:::

:::firefox
Firefox တွင် Settings၊ ထို့နောက် General၊ ထို့နောက် Downloads ကို ဖွင့်ပြီး "Always ask you where to save files" ကို ရွေးပါ၊ ထိုသို့ဆိုလျှင် ဖိုင်တိုင်းအတွက် ဖိုလ်ဒါ ရွေးနိုင်ပါသည်။
:::

:::safari
Safari တွင် Settings၊ ထို့နောက် General ကို ဖွင့်ပြီး "File download location" ကို "Ask for each download" ထားပါ၊ ထိုသို့ဆိုလျှင် ဒေါင်းလုဒ်တိုင်းအတွက် ဖိုလ်ဒါ ရွေးနိုင်ပါသည်။
:::

## Mac၊ Windows နှင့် Linux

app များသည် ကွန်ပျူတာတိုင်းတွင် တူညီပါသည်။ ကွာသွားသည်မှာ ကီးဘုတ်ဖြစ်ပြီး shortcut များကို သင့်ကွန်ပျူတာအတွက် အလိုအလျောက် ရေးပေးပါသည်။ [ကီး၊ မောက်စ်နှင့် trackpad များ](common:keys) ကို ကြည့်ပါ။

## တက်ဘလက်နှင့် touch screen များ

app အချို့သည် touch ကို လက်ခံပါသည် (လက်ချောင်းတစ်ချောင်းဖြင့် ဆွဲ သို့မဟုတ် ရွေးပါ၊ လက်ချောင်းနှစ်ချောင်းဖြင့် pinch လုပ်ပြီး ချဲ့ကာ pan လုပ်ပါ)။ app တစ်ခုစီ၏ help က ထိုအရာ ရှိမရှိ ပြောပါသည်။ iPad တွင် Safari သို့မဟုတ် Chrome ကို သုံးပါ။ ကီးဘုတ်သည် command ရိုက်သော app များအတွက် အထောက်အကူ ဖြစ်ပါသည်။

## အဟောင်းဆုံး ဘရောက်ဇာနှင့် စနစ်

ဤနံပါတ်များကို 0.7 app များ၏ code မှ ဖတ်ထားခြင်း ဖြစ်ပြီး ခန့်မှန်းချက် မဟုတ်ပါ- ဖိုင်တိုင်းကို parse လုပ်ပြီး ၎င်းသုံးထားသော language feature တစ်ခုစီကို ဘရောက်ဇာများ၏ ထုတ်ပြန်ထားသော compatibility data တွင် ရှာဖွေခဲ့ပါသည်။ ဤဗားရှင်းများအောက်တွင် ဘရောက်ဇာသည် code ကို နားမလည်နိုင်သဖြင့် app များ စတင်ပင် မနိုင်ပါ။

| | စတင်နိုင်သော အဟောင်းဆုံး ဗားရှင်း |
|---|---|
| Chrome, Edge, Brave, Opera, Vivaldi | Chromium 94 |
| Firefox | 93 |
| Safari (Mac, iPad, iPhone) | 16.4 (macOS 13.3, iPadOS and iOS 16.4) |

CadCraft Studio သည် Windows တွင် ကိုယ်ပိုင် web engine ပါဝင်သဖြင့် Windows 10 သို့မဟုတ် 11 လိုအပ်ပါသည်; Mac တွင် system ၏ engine ကို သုံးသဖြင့် macOS 13.3 သို့မဟုတ် နောက်ပိုင်း လိုအပ်ပါသည်။ Studio ရှိ Settings › Updates တွင် သင့်မိတ္တူ မည်သည့်စနစ်ပေါ် လည်ပတ်သလဲ ပြပါသည်။

ဤသည်မှာ *စတင်*နိုင်သော အဟောင်းဆုံး ဗားရှင်း ဖြစ်ပြီး code မှ ဖတ်ထားခြင်း ဖြစ်သည်။ ဟောင်းသော ဘရောက်ဇာများ၏ စာရင်း မဟုတ်ပါ၊ ထို့ကြောင့် စတင်နိုင်သော ဟောင်းဗားရှင်းတစ်ခုတွင် feature တစ်ခု ပျောက်နေနိုင်ပါသည်။

## ကွန်ပျူတာ ဘာလိုသလဲ

ဤသည်များသည် app များအတွက် စီစဉ်ထားသော အနည်းဆုံး လိုအပ်ချက်များ ဖြစ်ပြီး တိုင်းတာထားသော လိုအပ်ချက် မဟုတ်ပါ-

- မှတ်ဉာဏ် 8 GB (ကြီးမားသော federated model များအတွက် 16 GB အကြံပြုသည်)။
- 3D app များအတွက် WebGL 2 ပါသော graphics chip။ 3D view ဗလာဖြစ်နေလျှင် ဘရောက်ဇာ ဆက်တင်တွင် hardware acceleration ဖွင့်ထားခြင်း ရှိမရှိ စစ်ပါ။
- toolbar အပြည့်အစုံအတွက် အနည်းဆုံး 1280 pixel အကျယ် မျက်နှာပြင်; ပိုငယ်သော မျက်နှာပြင်များတွင် toolbar များ ပတ်ပြီး ပြပါသည်။

ဖိုင်အရွယ်ကြီးများ (ပုံဆွဲ အစုံ၊ မော်ဒယ်ကြီးများ) သည် ဘရောက်ဇာ tab တွင် မှတ်ဉာဏ် အများအပြား သုံးပါသည်။ app နှေးလာလျှင် အခြား လေးလံသော tab များကို ပိတ်ပါ။

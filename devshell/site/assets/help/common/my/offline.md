app များသည် သင့်ကွန်ပျူတာပေါ်တွင် အလုပ်လုပ်သဖြင့် အများစုမှာ ချိတ်ဆက်မှု မရှိဘဲ အလုပ်လုပ်ပါသည်။ browser သည် app ၏ ဖိုင်များကို ကြိုသိမ်းထားရန်သာ လိုပါသည်။

## app ကို အော့ဖ်လိုင်း သိမ်းရန်

1. online ရှိစဉ် app ကို ဖွင့်ပါ။
2. အပေါ်ဘားရှိ {{ui:Save for offline}} ကို ရွေးပါ။
3. "Offline ready" ကို စောင့်ပါ။ app ၏ ဖိုင်များ၊ ၎င်း၏ ဖိုင်ဖတ်ကိရိယာများနှင့် ဤ help ကို ယခု သင့် browser တွင် သိမ်းပြီးပါပြီ။ DWG သို့မဟုတ် PDF ဖိုင် ဖတ်သော app များသည် ၎င်းတို့၏ ဖတ်ကိရိယာများကိုပါ သိမ်းသဖြင့် ပထမအကြိမ်တွင် တစ်မိနစ်ခန့် ကြာနိုင်ပါသည်။

ဤကို app တစ်ခုစီအတွက်၊ သုံးသော browser တစ်ခုစီတွင် တစ်ကြိမ် လုပ်ပါ။ နောက်ပိုင်း ချိတ်ဆက်မှု မရှိဘဲ app သို့ ပြန်သွားရန်၊ အရင်သုံးခဲ့သော လိပ်စာ သို့မဟုတ် ၎င်း၏ bookmark ကို ဖွင့်ပါ။

:::offline
ယခု သင် offline ဖြစ်နေပါသည်။ ဤ app ကို အော့ဖ်လိုင်း သိမ်းထားပါက အောက်ပါအရာအားလုံး အလုပ်လုပ်ပါမည်။ မသိမ်းထားပါက ဤ tab တွင် ရှိပြီးသား ဖွင့်ထားသည်များကို ဆက်သုံးနိုင်သော်လည်း ချိတ်ဆက်မှု ပြန်ရမချင်း ပြန်မတင်ပါနှင့်။
:::

## အော့ဖ်လိုင်းဖြင့် ဘာအလုပ်လုပ်သလဲ

- ကွန်ပျူတာမှ ဖိုင်များဖွင့်ခြင်း၊ ပုံဆွဲခြင်း၊ တည်းဖြတ်ခြင်း၊ တိုင်းတာခြင်းနှင့် စစ်ဆေးခြင်း။
- သိမ်းခြင်းနှင့် ထုတ်ခြင်း- သိမ်းသမျှသည် ကွန်ပျူတာသို့ ဒေါင်းလုဒ် ဖြစ်ပါသည်။
- ဤ help၊ ရှာဖွေရေးအပါအဝင်။

## ချိတ်ဆက်မှု လိုအပ်သည်များ

- app ကို ပထမဆုံးအကြိမ် ဖွင့်ခြင်းနှင့် အော့ဖ်လိုင်း သိမ်းခြင်း။
- app ၏ ပိုသစ်သော ဗားရှင်း ရယူခြင်း။ online ရှိစဉ် app သည် နောက်ဖွင့်သည့်အခါ နောက်ဆုံးဗားရှင်းကို ယူပြီး {{ui:Save for offline}} က သိမ်းထားသော မိတ္တူကို ပြန်လည်ပြင်ဆင်ပါသည်။
- ဝက်ဆိုက်သို့ လင့်ခ်များ၊ ဥပမာ {{ui:Open on the website}} နှင့် အခြား စာမျက်နှာ လင့်ခ်များ။
- ကွန်ပျူတာများကြား cloud သိမ်းခြင်းနှင့် sync၊ ၎င်းတို့ ယခု မရရှိနိုင်သေးပါ။

## သိထားသင့်သည်များ

- သိမ်းထားသော မိတ္တူသည် ကွန်ပျူတာတစ်လုံးပေါ်ရှိ browser တစ်ခုတည်းနှင့် သက်ဆိုင်ပါသည်။ browser ၏ site data ကို ရှင်းလျှင် ၎င်း ပျောက်ပါမည်။
- browser အချို့၏ private window များနှင့် လုပ်ငန်းသုံး ကွန်ပျူတာ အချို့တွင် အော့ဖ်လိုင်း သိမ်းခြင်း မရနိုင်ပါ။ သိမ်း၍ မရလျှင် ခလုတ်က ပြောပြပါသည်။

:::safari
Safari သည် သင် အပတ်အနည်းငယ် မသွားသော site များမှ သိမ်းထားသည့် site data ကို ဖျက်ပါသည်။ ချိတ်ဆက်နေစဉ် app ကို တစ်ခါတစ်ရံ ဖွင့်ပါ၊ သို့မဟုတ် ခရီးမထွက်မီ ပြန်သိမ်းပါ။
:::

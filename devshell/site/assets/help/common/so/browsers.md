App-yadu waxay ku shaqeeyaan browser web. Shaqada kombiyuutarkaaga ayey ku sameeyaan: faylalkaagu halkaas ayaa la furaa oo weligood ma nala soo dirin (eeg [Meesha ay faylalkaagu aadaan](common:your-files)).

## Browserka

Isticmaal nooca cusub ee mid ka mid ah kuwan:

| Browser | Engine | Faahfaahin |
|---|---|---|
| Chrome, Edge, Brave, Opera, Vivaldi | Chromium | Kan ugu buuxsamaya: doorashada folder-ka, kaydinta offline-ka, maaraynta faylasha. |
| Firefox | Gecko | Way shaqeysaa. Furidda folder oo dhan waxay isticmaashaa doorasho fudud. Kaydinta offline-ka waxa laga yaabaa inaysan ku shaqeynin daaqadaha gaarka ah. |
| Safari | WebKit | Way shaqeysaa Mac iyo iPad. Furidda folder oo dhan waxay isticmaashaa doorasho fudud. Safari waxay tirtiri kartaa nuqul offline ah oo aanad isticmaalin dhowr toddobaad. |

Dhammaan saddexdan engine way wanaagsan yihiin shaqada maalinlaha ah. Meel app uu wax ku kala duwan sameeyo mid ka mid ah, caawinta uu ku leeyahay waxay tusinaysaa tillaabooyinka browserkaaga.

## Waxa browserada ku kala duwan

- **Furidda folder-ka.** Browserada Chromium waxay tusaan doorashada folder-ka dhabta ah, folder-kana si toos ah ayey u akhriyaan. Firefox iyo Safari waxay kugu weydiinayaan inaad folder dooratid kadibna mid kasta oo ku jira way akhriyaan, taas oo qaadanaysa waqti dheer folderada mashruucyada waaweyn; folder-ka app-ka ku jiid waxay ku shaqeysaa saddexdaba.
- **Kaydinta.** Apps-yadu waxay kaydiyaan iyagoo fayl soo dejinaya. Browserkaagu wuxuu go'aaminayaa meesha soo dejintu tagto iyo inuu hore u weydiiyo mise uusan weydiin.

:::chromium
Chrome ama Edge, shid "Ask where to save each file before downloading" (Settings gudaheeda, hoosta Downloads) si aad mar kasta folder u dooratid.
:::

:::firefox
Firefox, fur Settings, kadibna General, kadibna Downloads, kadibna dooro "Always ask you where to save files" si aad mar kasta folder u dooratid.
:::

:::safari
Safari, fur Settings, kadibna General, kadibna deji "File download location" "Ask for each download" si aad mar kasta folder u dooratid.
:::

## Mac, Windows iyo Linux

Apps-yadu kombiyuutar kasta waa isku mid. Waxa isbedela waa kiiboodhka: gaadhka furayaasha si toos ah ayaa loogu qoraa kombiyuutarkaaga. Eeg [Furayaasha, mouse-yada iyo trackpad-yada](common:keys).

## Taabletyada iyo shaashadaha taabashada

Qaar ka mid ah apps-yada waxay aqbalaan taabashada (hal farta ayaa sawirta ama doortaa, labo farood ayaa weynaysa oo dhaqaajiya). Caawinta app kasta ayaa sheegaysa inay taasi jirto. iPad-ka, isticmaal Safari ama Chrome. Kiiboodhku wuxuu caawiyaa apps-yada isticmaala amarro la qoro.

## Browserka iyo nidaamka ugu duqsan

Waxaan kuwan ka akhrinnay koodka apps-yada 0.7, ma aha malo-malo: fayl kasta waa la falanqeeyay, astaamo kasta oo luqadda ah oo ay isticmaalaan waxaa laga eegay xogta isku-habaynta ee browserrada ee la daabacay. Nooca ka hooseeya kuwan, apps-yadu ma bilaabi karaan, sababtoo ah browserku koodka ma fahmo.

| | Nooca ugu duqsan ee apps-yada bilaabi kara |
|---|---|
| Chrome, Edge, Brave, Opera, Vivaldi | Chromium 94 |
| Firefox | 93 |
| Safari (Mac, iPad, iPhone) | 16.4 (macOS 13.3, iPadOS and iOS 16.4) |

CadCraft Studio waxa uu Windows-ka ku leeyahay engine web-kiisa, sidaas darteed wuxuu u baahan yahay Windows 10 ama 11; Mac-ka wuxuu isticmaalaa kan nidaamka, sidaas darteed wuxuu u baahan yahay macOS 13.3 ama ka cusub. Dejinta › Cusboonaysiinta ee Studio waxa ay muujinaysaa nidaamka nuqulkaagu ku shaqeeyo.

Tanu waa nooca ugu duqsan ee *bilaabmo*, laga akhriyay koodka. Ma aha liis browserro duq ah oo aan apps-yada ku shaqeynay, sidaas darteed browser duq ah oo bilaabmi kara ayaa laga yaabaa inuu weli maqan yahay astaamo.

## Waxa kombiyuutarkaagu u baahan yahay

Kuwani waa qadarka ugu yar ee la qorsheeyay apps-yada, ma aha shuruudo la cabbiray:

- 8 GB oo xusuus ah (16 GB ayaa lagu talinayaa moodallada isku-dhafan ee waaweyn).
- Chip garaafyada oo leh WebGL 2 apps-yada 3D-ga. Haddii muuqaalka 3D-ga madhan yahay, hubi in hardware acceleration uu shaqeynayo dejinta browserkaaga.
- Shaashad ugu yaraan 1280 pixel ballaadhka leh si qalabyada oo dhan u buuxaan; shaashadaha yar safaf badan ayay u qaybiyaan.

Faylal aad u waaweyn (qorshe-tiro waaweyn, moodallo waaweyn) xusuus badan ayey ku isticmaalaan tab-ka browserka. Haddii app-ku gaabiyo, xir tab-yada kale ee culus.

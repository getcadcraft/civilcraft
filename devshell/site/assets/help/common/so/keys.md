## Sida gaadhka furayaasha loo qoro

Caawintu gaadh kasta waxa ay u qorta siyaabta kiiboodhkaagu u calaamadeeyo.

| Qoran | Mac-ka | Windows iyo Linux |
|---|---|---|
| {{key:Mod+S}} | Command (⌘) iyo S | Ctrl iyo S |
| {{key:Ctrl+Shift+F}} | Control (⌃), Shift (⇧) iyo F | Ctrl, Shift iyo F |
| {{key:Alt+Left}} | Option (⌥) iyo ← | Alt iyo ← |
| {{key:Backspace}} | furaha Delete | Backspace |
| {{key:Delete}} | fn iyo Delete (tirtirka hore) | Delete |
| {{key:Enter}} | Return | Enter |

Calaamadda plus waxa ay ka dhigan tahay in furayaasha si wada jir ah loo hayo. "Kadib" waxa ay ka dhigan tahay in mid mid ka dib la riixo.

Gaadhka apps-yada badankiisa Mac-ka waxa ay aqbalaan Command ama Control, sidaas darteed {{key:Mod+Z}} labada siyaabood ayuu shaqeeyaa. Yar oo ka mid ah, sida shaashadda buuxda ({{key:Ctrl+Shift+F}}), furaha Control ayey kombiyuutar kasta isticmaalaan; caawintu waxa ay sheegtaa meesha ay khuseyso.

## Furayaasha function ee Mac-ka

Kiiboodhka Mac-ka badankiisa safka sare wuxuu beddelaa iftiinka, codka iyo warbaahinta. Si aad F1 ilaa F12 u dirto:

- hay **fn** (ama furaha globe-ka) intaad furaha riixayso, ama
- fur **System Settings**, kadibna **Keyboard**, kadibna **Keyboard Shortcuts**, kadibna **Function Keys**, oo shid "Use F1, F2, etc. keys as standard function keys".

Qaar ka mid ah furayaasha F-ka macOS-ku lafteeda ayuu leeyahay (tusaale ahaan Mission Control). Haddii furaha app-ka aan wax samaynin, ku isku day fn, ama isticmaal badhanka qalabka halkii.

## Gaadhka browserku hayo

Bog web ah ma qaadi karo qaar ka mid ah gaadhka browserka, wax kasta oo ay samaysa. App kasta:

- {{key:Mod+N}}, {{key:Mod+T}} iyo {{key:Mod+W}} had iyo jeer daaqadaha iyo tab-yada browserka ayey furaan ama xiraan. Apps-yadu waxay isticmaalaan badhamo ah Cusub iyo Xir halkaas.
- {{key:Mod+Q}} Mac-ka iyo {{key:Alt+F4}} Windows-ka browserka way xiraan. Haddii aad shaqo aan la kaydin haysato, browserku marka hore wuu weydiin doonaa ("Leave site?"); dooro inaad joogto, kadibna kaydi.
- Shaashadda buuxda ee browserka ({{pick:mac=Control-Command-F, ama badhanka cagaaran ee daaqadda|windows linux=F11}}) weli way shaqeysaa. Apps-yadu waxay leeyihiin qaabab shaashad oo gaar ah oo {{key:Ctrl+Shift+F}} ku, kuwaas oo sidoo kale barrada app-ka qarin kara.

## Badhamada mouse-ka ee trackpad-ka

Apps-yadu waxay isticmaalaan badhanka midig iyo badhanka dhexe. Haddii aadan mouse saddex-badhan ah lahayn:

:::mac
- **Riix midig:** guji labo farood. Shid "Secondary click" **System Settings** gudaha, kadibna **Trackpad**, haddii guji labo farood aan waxba samaynin. {{key:Ctrl}} la hayo markaad gujinayso waxay furaysaa menu-ga browserka, laakiin naqshadda gudaheeda qaar ka mid ah apps-yada waxay u akhriyaan guji caadi ah (Control la hayo), sidaas darteed guji labo farood ayaa ka wanaagsan.
- **Jiidida badhanka dhexe (pan):** app kasta wuxuu bixiyaa siyaabo kale oo loo dhaqaajiyo, sida {{key:Space}} la hayo intaad jiidayso ama jiidida badhanka midig. Bogga kiiboodhka app-ka ayaa sheegaya kan.
- **Weynaynta wheel-ka:** kor-u-dhaaf labo farood oo trackpad-ka ku sawiran badankiisa apps-yada ayey weynaysaa. Labo farood oo isku soo dhowaynaya ayaa sidoo kale weynayn meesha app-ku taageero.
:::

:::windows linux
- **Riix midig:** guji labo farood, ama guji geeska hoose ee midig ee touchpad-ka. Tani waxay ku xiran tahay dejinta touchpad-kaaga.
- **Jiidida badhanka dhexe (pan):** app kasta wuxuu bixiyaa siyaabo kale oo loo dhaqaajiyo, sida {{key:Space}} la hayo intaad jiidayso ama jiidida badhanka midig. Bogga kiiboodhka app-ka ayaa sheegaya kan.
- **Weynaynta wheel-ka:** kor-u-dhaaf labo farood oo touchpad-ka ku sawiran badankiisa apps-yada ayey weynaysaa.
:::

## Qorista sanduuq qoraal

Intaad sanduuq ku qorayso (magac, faallo, baadhis), gaadhka app-ka ee xarfo keliya ahi way damaan, sidaas darteed qorista "L" waxay qortaa L. Riix {{key:Esc}} ama guji naqshadda si aad furayaasha app-ka dib ugu celiso.

## نوشته شدن میانبرها

راهنما هر میانبر را همان‌طور می‌نویسد که صفحه‌کلید شما برچسب زده است.

| نوشته‌شده | روی Mac | روی Windows و Linux |
|---|---|---|
| {{key:Mod+S}} | Command (⌘) و S | Ctrl و S |
| {{key:Ctrl+Shift+F}} | Control (⌃)، Shift (⇧) و F | Ctrl، Shift و F |
| {{key:Alt+Left}} | Option (⌥) و ← | Alt و ← |
| {{key:Backspace}} | کلید Delete | Backspace |
| {{key:Delete}} | fn و Delete (حذف به جلو) | Delete |
| {{key:Enter}} | Return | Enter |

علامت + یعنی کلیدها را با هم نگه دارید. «سپس» یعنی یکی را پس از دیگری بزنید.

بیشتر میانبرهای برنامه روی Mac هم Command و هم Control را می‌پذیرند، پس {{key:Mod+Z}} به هر دو شکل کار می‌کند. چند میانبر، مثل تمام‌صفحه ({{key:Ctrl+Shift+F}})، روی همه رایانه‌ها از کلید Control استفاده می‌کنند؛ راهنما هر جا لازم باشد آن را می‌گوید.

## کلیدهای تابعی روی Mac

روی بیشتر صفحه‌کلیدهای Mac، ردیف بالا روشنایی، صدا و رسانه را تغییر می‌دهد. برای ارسال F1 تا F12:

- کلید **fn** (یا کلید کره‌ای) را نگه دارید و کلید را بزنید، یا
- **System Settings** را باز کنید، سپس **Keyboard**، سپس **Keyboard Shortcuts**، سپس **Function Keys**، و گزینه "Use F1, F2, etc. keys as standard function keys" را روشن کنید.

بعضی کلیدهای F را خود macOS هم برای خودش نگه داشته است (برای نمونه Mission Control). اگر کلیدی در برنامه کاری نمی‌کند، آن را همراه با fn امتحان کنید، یا از دکمه نوار ابزار استفاده کنید.

## میانبرهایی که مرورگر نگه می‌دارد

یک صفحه وب نمی‌تواند بعضی میانبرها را، هر کاری که بکند، از مرورگر بگیرد. در همه برنامه‌ها:

- {{key:Mod+N}}، {{key:Mod+T}} و {{key:Mod+W}} همیشه پنجره‌ها و زبانه‌های مرورگر را باز یا بسته می‌کنند. برنامه‌ها برای «جدید» و «بستن» از دکمه استفاده می‌کنند.
- {{key:Mod+Q}} روی Mac و {{key:Alt+F4}} روی Windows مرورگر را می‌بندند. اگر کار ذخیره‌نشده دارید، مرورگر اول می‌پرسد ("Leave site?")؛ بمانید و ذخیره کنید.
- تمام‌صفحه‌ی خود مرورگر ({{pick:mac=Control-Command-F، یا دکمه سبز روی پنجره|windows linux=F11}}) همچنان کار می‌کند. برنامه‌ها حالت‌های نمایش خودشان را هم با {{key:Ctrl+Shift+F}} دارند، که نوارهای برنامه را هم پنهان می‌کند.

## ماوس و تاچ‌پد

برنامه‌ها از دکمه راست و دکمه وسط استفاده می‌کنند. بدون ماوس سه‌دکمه‌ای:

:::mac
- **راست‌کلیک:** با دو انگشت کلیک کنید. اگر کلیک با دو انگشت کار نکرد، در **System Settings** و سپس **Trackpad** گزینه "Secondary click" را روشن کنید. نگه داشتن {{key:Ctrl}} هنگام کلیک منوی مرورگر را باز می‌کند، اما داخل نقشه بعضی برنامه‌ها آن را یک کلیک معمولی (با Control فشرده) می‌خوانند؛ پس کلیک با دو انگشت را ترجیح دهید.
- **کشیدن با دکمه وسط (جابه‌جایی):** هر برنامه روش دیگری برای جابه‌جایی دارد، مثل نگه داشتن {{key:Space}} هنگام کشیدن، یا کشیدن با دکمه راست. صفحه کلیدهای برنامه می‌گوید کدام.
- **بزرگ‌نمایی با چرخ:** اسکرول دو انگشتی روی تاچ‌پد در بیشتر برنامه‌ها بزرگ‌نمایی می‌کند. در جایی که برنامه پشتیبانی می‌کند، نیشگون هم بزرگ‌نمایی می‌کند.
:::

:::windows linux
- **راست‌کلیک:** با دو انگشت کلیک کنید، یا روی گوشه پایین-راست تاچ‌پد کلیک کنید. این به تنظیمات تاچ‌پدتان بستگی دارد.
- **کشیدن با دکمه وسط (جابه‌جایی):** هر برنامه روش دیگری برای جابه‌جایی دارد، مثل نگه داشتن {{key:Space}} هنگام کشیدن، یا کشیدن با دکمه راست. صفحه کلیدهای برنامه می‌گوید کدام.
- **بزرگ‌نمایی با چرخ:** اسکرول دو انگشتی روی تاچ‌پد در بیشتر برنامه‌ها بزرگ‌نمایی می‌کند.
:::

## تایپ در کادر متن

وقتی در یک کادر تایپ می‌کنید (یک نام، یادداشت یا جستجو)، میانبرهای تک‌حرفی برنامه خاموش‌اند، پس تایپ «L» همان حرف L را می‌نویسد. {{key:Esc}} را بزنید یا روی نقشه کلیک کنید تا کلیدها دوباره به برنامه بروند.

## 단축키 표기 방법

도움말은 각 단축키를 사용 중인 키보드에 표시된 대로 적습니다.

| 표기 | Mac | Windows 및 Linux |
|---|---|---|
| {{key:Mod+S}} | Command(⌘)와 S | Ctrl과 S |
| {{key:Ctrl+Shift+F}} | Control(⌃), Shift(⇧), F | Ctrl, Shift, F |
| {{key:Alt+Left}} | Option(⌥)과 ← | Alt와 ← |
| {{key:Backspace}} | Delete 키 | Backspace |
| {{key:Delete}} | fn과 Delete(앞으로 지우기) | Delete |
| {{key:Enter}} | Return | Enter |

더하기 기호는 키를 함께 누른다는 뜻입니다. "다음에"는 하나를 누른 뒤 이어서 다른 키를 누른다는 뜻입니다.

대부분의 앱 단축키는 Mac에서 Command와 Control 중 어느 쪽이든 받아들이므로 {{key:Mod+Z}}는 둘 다 작동합니다. 전체 화면({{key:Ctrl+Shift+F}})처럼 일부는 모든 컴퓨터에서 Control 키를 사용하며, 해당하는 경우 도움말에 그렇게 적혀 있습니다.

## Mac의 기능 키

대부분의 Mac 키보드에서는 맨 윗줄이 밝기, 음량, 미디어를 조절합니다. F1부터 F12를 보내려면 다음과 같이 합니다.

- 키를 누르는 동안 **fn**(또는 지구본 키)을 누르고 있거나,
- **시스템 설정**, **키보드**, **키보드 단축키**, **기능 키**를 차례로 열고 "F1, F2 등의 키를 표준 기능 키로 사용"을 켭니다.

일부 F 키는 macOS 자체에서도 사용합니다(예: Mission Control). 키를 눌러도 앱에서 아무 반응이 없으면 fn과 함께 눌러 보거나 도구 모음의 버튼을 대신 사용하십시오.

## 브라우저가 유지하는 단축키

웹 페이지는 어떻게 해도 브라우저의 일부 단축키를 가져올 수 없습니다. 모든 앱에서 다음이 적용됩니다.

- {{key:Mod+N}}, {{key:Mod+T}}, {{key:Mod+W}}는 항상 브라우저 창과 탭을 열거나 닫습니다. 앱은 새로 만들기와 닫기에 버튼을 사용합니다.
- Mac의 {{key:Mod+Q}}와 Windows의 {{key:Alt+F4}}는 브라우저를 종료합니다. 저장하지 않은 작업이 있으면 브라우저가 먼저 묻습니다("사이트에서 나가시겠습니까?"). 머무르기를 선택한 다음 저장하십시오.
- 브라우저 자체의 전체 화면({{pick:mac=Control-Command-F 또는 창의 녹색 버튼|windows linux=F11}})은 그대로 작동합니다. 앱에도 {{key:Ctrl+Shift+F}}로 쓰는 자체 화면 모드가 있으며, 이 모드는 앱의 표시줄까지 숨길 수 있습니다.

## 트랙패드에서의 마우스 버튼

앱은 오른쪽 버튼과 가운데 버튼을 사용합니다. 버튼이 세 개인 마우스가 없을 때는 다음과 같이 합니다.

:::mac
- **오른쪽 클릭:** 손가락 두 개로 클릭합니다. 두 손가락 클릭이 작동하지 않으면 **시스템 설정**, **트랙패드**에서 "보조 클릭"을 켜십시오. 클릭하는 동안 {{key:Ctrl}}을 누르면 브라우저의 메뉴가 열리지만, 도면 안에서는 일부 앱이 이를 (Control을 누른) 일반 클릭으로 읽으므로 두 손가락 클릭을 권장합니다.
- **가운데 버튼 끌기(초점 이동):** 각 앱에는 {{key:Space}}를 누른 채 끌거나 오른쪽 버튼으로 끄는 등 초점 이동의 다른 방법이 있습니다. 앱의 키보드 페이지에 안내되어 있습니다.
- **휠 줌:** 대부분의 앱에서 트랙패드의 두 손가락 스크롤로 줌이 됩니다. 앱이 지원하면 손가락을 모으거나 벌려서도 줌이 됩니다.
:::

:::windows linux
- **오른쪽 클릭:** 손가락 두 개로 클릭하거나 터치패드의 오른쪽 아래 모서리를 클릭합니다. 터치패드 설정에 따라 다릅니다.
- **가운데 버튼 끌기(초점 이동):** 각 앱에는 {{key:Space}}를 누른 채 끌거나 오른쪽 버튼으로 끄는 등 초점 이동의 다른 방법이 있습니다. 앱의 키보드 페이지에 안내되어 있습니다.
- **휠 줌:** 대부분의 앱에서 터치패드의 두 손가락 스크롤로 줌이 됩니다.
:::

## 입력란에 입력하기

입력란(이름, 메모, 검색)에 입력하는 동안에는 앱의 한 글자 단축키가 꺼지므로 "L"을 누르면 L이 입력됩니다. {{key:Esc}}를 누르거나 도면을 클릭하면 키가 다시 앱으로 돌아갑니다.

앱은 사용자의 컴퓨터에서 작업을 처리하므로 대부분의 기능은 연결 없이도 작동합니다. 브라우저에 앱 파일이 미리 저장되어 있기만 하면 됩니다.

## 오프라인용으로 앱 저장하기

1. 온라인일 때 앱을 엽니다.
2. 맨 위 표시줄에서 {{ui:오프라인용 저장}}을 선택합니다.
3. "오프라인 준비 완료"가 나올 때까지 기다립니다. 앱 파일, 파일 리더, 이 도움말이 브라우저에 저장됩니다. DWG나 PDF 파일을 읽는 앱은 해당 리더도 함께 저장하므로 처음에는 1분 정도 걸릴 수 있습니다.

앱마다, 사용하는 브라우저마다 한 번씩 하면 됩니다. 나중에 연결 없이 앱으로 돌아가려면 이전에 사용한 주소 또는 그 북마크를 여십시오.

:::offline
지금은 오프라인입니다. 이 앱을 오프라인용으로 저장해 두었다면 아래 내용이 모두 작동합니다. 저장하지 않았다면 이 탭에 이미 불러온 것은 계속 사용할 수 있지만, 다시 온라인이 될 때까지 새로 고침하지 마십시오.
:::

## 오프라인에서 되는 것

- 컴퓨터의 파일 열기, 그리기, 편집, 측정, 검사.
- 저장과 내보내기: 모든 저장은 컴퓨터로의 다운로드입니다.
- 검색을 포함한 이 도움말.

## 연결이 필요한 것

- 앱을 처음 여는 것과 오프라인용으로 저장하는 것.
- 앱의 새 버전 받기. 온라인이면 앱은 다음에 열릴 때 최신 버전을 받아 오고, {{ui:오프라인용 저장}}은 저장된 사본을 새로 고칩니다.
- {{ui:웹사이트에서 열기}}나 다른 페이지로 가는 링크 같은 웹사이트 링크.
- 클라우드 저장과 컴퓨터 간 동기화(아직 사용할 수 없습니다).

## 알아 둘 점

- 저장된 사본은 한 컴퓨터의 한 브라우저에 속합니다. 브라우저의 사이트 데이터를 지우면 사본도 삭제됩니다.
- 일부 브라우저의 사생활 보호 창과 일부 보안이 강화된 업무용 컴퓨터에서는 오프라인 저장이 허용되지 않습니다. 저장할 수 없을 때는 버튼이 알려 줍니다.

:::safari
Safari는 몇 주 동안 방문하지 않은 사이트의 저장된 사이트 데이터를 삭제합니다. 온라인일 때 가끔 앱을 열거나, 이동 전에 다시 저장해 두십시오.
:::

- 여덟 개의 앱을 하나로 설치하는 데스크톱 앱인 CadCraft Studio는 getcadcraft.com/download에 있습니다.

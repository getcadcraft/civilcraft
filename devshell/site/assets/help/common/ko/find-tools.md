모든 앱에는 도구, 설정, 이 도움말을 찾는 검색 상자가 있습니다. 도구가 도구 모음 어디에 있는지 알 필요가 없습니다.

## 찾아서 실행하기

1. {{key:Mod+K}}를 누르거나 맨 위 표시줄에서 {{ui:찾기}}를 선택합니다.
2. 원하는 것의 몇 글자를 입력합니다. 예: "모깎기", "패널 글자", "단위". 입력한 단어가 모두 일치해야 하므로, 목록을 좁히려면 단어를 하나 더 추가하십시오.
3. {{key:Enter}}를 누르면 첫 번째 일치 항목이 실행됩니다. 먼저 방향키로 이동해도 됩니다. {{key:Esc}}는 상자를 닫습니다.

도구는 도구 모음에서 클릭한 것과 똑같이 실행됩니다. 설정은 {{ui:설정}}이 해당 설정 위치에서 열립니다. 도움말 항목은 여기, 도움말 패널에서 열립니다.

## 알아 둘 점

- 마지막으로 사용한 항목이 다음에 맨 위에 나오므로, 자주 쓰는 도구는 키 한 번이면 실행됩니다.
- 지금 실행할 수 없는 도구(예: 파일을 열기 전)는 목록에 표시되지만 회색으로 나타납니다.
- 애드온의 도구는 애드온을 켜면 목록에 함께 나타납니다.

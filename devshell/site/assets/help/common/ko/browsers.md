앱은 웹 브라우저 안에서 실행됩니다. 작업은 사용자의 컴퓨터에서 처리되며, 파일은 그곳에서 열릴 뿐 우리에게 전송되지 않습니다([파일이 가는 곳](common:your-files) 참조).

## 어떤 브라우저를 쓸까

다음 중 하나의 최신 버전을 사용하십시오.

| 브라우저 | 엔진 | 참고 |
|---|---|---|
| Chrome, Edge, Brave, Opera, Vivaldi | Chromium | 가장 완전합니다. 폴더 선택, 오프라인용 저장, 파일 처리를 지원합니다. |
| Firefox | Gecko | 작동합니다. 폴더 전체 열기는 더 단순한 선택기를 사용합니다. 사생활 보호 창에서는 오프라인 저장이 작동하지 않을 수 있습니다. |
| Safari | WebKit | Mac과 iPad에서 작동합니다. 폴더 전체 열기는 더 단순한 선택기를 사용합니다. Safari는 몇 주 동안 사용하지 않은 오프라인 사본을 삭제할 수 있습니다. |

세 엔진 모두 일상적인 작업에는 문제가 없습니다. 앱이 엔진마다 다르게 동작하는 부분은 앱의 도움말에 해당 브라우저의 단계가 나와 있습니다.

## 브라우저마다 다른 점

- **폴더 열기.** Chromium 기반 브라우저는 실제 폴더 선택기를 보여 주고 폴더를 직접 읽을 수 있습니다. Firefox와 Safari는 폴더를 고르게 한 다음 그 안의 모든 파일을 읽으므로, 큰 프로젝트 폴더는 시간이 더 걸립니다. 폴더를 앱 위로 끌어 놓는 방법은 세 엔진 모두에서 작동합니다.
- **저장.** 앱은 파일을 다운로드하는 방식으로 저장합니다. 다운로드가 어디로 가는지, 먼저 묻는지는 브라우저가 정합니다.

:::chromium
Chrome 또는 Edge에서는 설정의 다운로드 항목에서 "다운로드 전에 각 파일의 저장 위치 확인"을 켜면 매번 폴더를 선택할 수 있습니다.
:::

:::firefox
Firefox에서는 설정, 일반, 파일 및 다운로드 순서로 열고 "항상 파일을 저장할 위치 선택"을 선택하면 매번 폴더를 선택할 수 있습니다.
:::

:::safari
Safari에서는 설정, 일반 순서로 열고 "파일 다운로드 위치"를 "매번 묻기"로 설정하면 매번 폴더를 선택할 수 있습니다.
:::

## Mac, Windows, Linux

앱은 어느 컴퓨터에서나 같습니다. 달라지는 것은 키보드입니다. 단축키는 사용 중인 컴퓨터에 맞게 자동으로 표시됩니다. [키, 마우스, 트랙패드](common:keys)를 참조하십시오.

## 태블릿과 터치 화면

일부 앱은 터치를 지원합니다(손가락 하나로 그리거나 선택하고, 손가락 두 개로 모으거나 벌려 줌과 초점 이동을 합니다). 지원 여부는 각 앱의 도움말에 나와 있습니다. iPad에서는 Safari 또는 Chrome을 사용하십시오. 입력한 명령을 쓰는 앱에서는 키보드가 도움이 됩니다.

## 가장 오래된 브라우저와 시스템

이 정보는 추측이 아니라 0.7 앱의 코드에서 읽은 것입니다. 모든 파일을 구문 분석하고 사용된 각 언어 기능을 브라우저의 공개 호환성 데이터에서 조회했습니다. 아래 버전보다 낮으면 브라우저가 코드를 이해하지 못해 앱이 시작조차 되지 않습니다.

| | 앱을 시작할 수 있는 가장 오래된 버전 |
|---|---|
| Chrome, Edge, Brave, Opera, Vivaldi | Chromium 94 |
| Firefox | 93 |
| Safari (Mac, iPad, iPhone) | 16.4 (macOS 13.3, iPadOS 및 iOS 16.4) |

CadCraft Studio는 Windows에서 자체 웹 엔진을 포함하므로 Windows 10 또는 11이 필요합니다. Mac에서는 시스템의 엔진을 사용하므로 macOS 13.3 이상이 필요합니다. Studio의 설정 › 업데이트에서 사용 중인 사본이 어떤 엔진에서 실행되는지 확인할 수 있습니다.

이것은 코드를 읽어 알아낸, 앱이 *시작되는* 가장 오래된 버전입니다. 앱을 실제로 실행해 본 오래된 브라우저의 목록이 아니므로, 시작은 되더라도 일부 기능이 빠져 있을 수 있습니다.

## 컴퓨터에 필요한 사양

다음은 앱의 계획된 최소 사양이며, 측정한 요구 사양이 아닙니다.

- 메모리 8 GB(대형 연합 모델에는 16 GB 권장).
- 3D 앱에는 WebGL 2를 지원하는 그래픽 칩이 필요합니다. 3D 뷰가 계속 비어 있으면 브라우저 설정에서 하드웨어 가속이 켜져 있는지 확인하십시오.
- 도구 모음 전체를 표시하려면 너비 1280픽셀 이상의 화면이 필요합니다. 더 작은 화면에서는 도구 모음이 줄바꿈됩니다.

아주 큰 파일(큰 도면 세트, 큰 모델)은 브라우저 탭에서 메모리를 많이 사용합니다. 앱이 느려지면 무거운 다른 탭을 닫으십시오.

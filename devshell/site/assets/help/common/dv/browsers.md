އެޕްތައް ހިންގަނީ ވެބް ބްރައުޒަރއެއްގެ ތެރޭގައެވެ. މަސައްކަތް ހިންގަނީ ތިޔަ ކޮމްޕިއުޓަރުގައެވެ: ތިޔަ ފައިލްތައް އެތަނުގައި ހުޅުވެއެވެ، އަދި އެއީ އަހަރެމެންނަށް ފޮނުވާ ނުވެއެވެ (ބަލާށެވެ [ތިޔަ ފައިލްތައް ދާ ތަން](common:your-files)).

## ކޮން ބްރައުޒަރު

މި ބްރައުޒަރުތަކުންކޮންމެ ތާޒާ ވާރޝަނެއް ބޭނުން ކުރާށެވެ:

| ބްރައުޒަރ | އިންޖިން | ނޯޓްސް |
|---|---|---|
| Chrome, Edge, Brave, Opera, Vivaldi | Chromium | ފުރިހަމަ ގޮތުން: ފޯލްޑަރ ހޮވުން، އޮފްލައިން ގޮތަށް ރައްކާކުރުން، ފައިލް ހެންޑަލްކުރުން. |
| Firefox | Gecko | މަސައްކަތް ކުރެއެވެ. ފޯލްޑަރެއް ހުޅުވާއިރު ސާދާ ޕިކަރެއް ބޭނުންވޭ. ޕްރައިވެޓް ވިންޑޯތަކުގައި އޮފްލައިން ރައްކާކުރުން ކަމެއް ނުވެވިދާނެ. |
| Safari | WebKit | Mac އާއި iPad ގައި މަސައްކަތް ކުރެއެވެ. ފޯލްޑަރެއް ހުޅުވާއިރު ސާދާ ޕިކަރެއް ބޭނުންވޭ. ތިޔަ އޮފްލައިން ކޮޕީއެއް އެއްވެސް މުއްދަތެއް ބޭނުން ނުކުރާނަމަ Safari ކެނޑިދާނެ. |

ތިން އިންޖިންވެސް ދުވަހުގެ މަސައްކަތަށް ރަނގަޅެވެ. އެޕެއް އެއަކުން އެހެން ގޮތަކަށް ކަމެއް ކުރާ ތަނުގައި، އެ ގައިޑްގައި ތިޔަ ބްރައުޒަރަށް ވަކި ގޮތް ދައްކާނެއެވެ.

## ބްރައުޒަރުތަކުގެ ތަފާތު

- **ފޯލްޑަރ ހުޅުވުން.** Chromium ބްރައުޒަރުން ޙަޤީޤީ ފޯލްޑަރ ޕިކަރެއް ދައްކައި، ފޯލްޑަރ ސީދާ ކިޔަވާ ފަދައިން ހުންނެވެ. Firefox އަދި Safari ފޯލްޑަރެއް ހޮވާ ކިޔައި އެތަނުގެ ހުރިހާ ފައިލެއް ކިޔަވައެވެ، ބޮޑު ޕްރޮޖެކްޓް ފޯލްޑަރުތަކަށް ވަގުތު ގިނަ ނެރެއެވެ؛ ފޯލްޑަރ އެޕަށް ޑްރެގް ކުރުމުން ތިން ބްރައުޒަރަށް ވެސް ކަންތައް ކުރެއެވެ.
- **ރައްކާކުރުން.** އެޕްތައް ފައިލް ޑައުންލޯޑް ކުރުމުން ރައްކާ ކުރެއެވެ. ޑައުންލޯޑްތައް ކޮތަން ދާނީ ބްރައުޒަރު ގަވާއިދަށެވެ، އަދި ސުވާލު ކުރާކަށް ހެއްދެވީ ނޫނެވެ.

:::chromium
Chrome ނުވަތަ Edge ގައި، (Settings ގައި، Downloads ގެ ދަށުން) "Ask where to save each file before downloading" އާއްމަތު ކުރައްވާ، ކޮންމެ ފަހަރަކު ފޯލްޑަރ ހޮވުމަށް.
:::

:::firefox
Firefox ގައި، Settings ހުޅުވައި، ފަހުން General، ފަހުން Downloads ހޮވާ، "Always ask you where to save files" ހޮވާ، ކޮންމެ ފަހަރަކު ފޯލްޑަރ ހޮވުމަށް.
:::

:::safari
Safari ގައި، Settings ހުޅުވައި، ފަހުން General ހޮވާ، "File download location" "Ask for each download" ކަށަވަރު ކުރާށެވެ، ކޮންމެ ޑައުންލޯޑަކަށް ފޯލްޑަރ ހޮވުމަށް.
:::

## Mac، Windows އަދި Linux

އެޕްތައް ކޮންމެ ކޮމްޕިއުޓަރުގައި އެއްގޮތެވެ. ބަދަލުވާ ރަނގަޅު ކީބޯޑެވެ: ޝޯޓްކަޓްތައް ތިޔަ ކޮމްޕިއުޓަރަށް ސްވަޔަރ ލިޔެވިފައި ހުރެއެވެ. ބަލާށެވެ [ކީ، މައުސް އަދި ޓްރެކްޕެޑް](common:keys).

## ޓެބްލެޓް އަދި ޓަޗް ސްކްރީން

އެއްފަހަރު އެޕްތައް ޓަޗް ބޭނުން ކުރެއެވެ (އެއް ފިންގަރަކުން ޑްރޯ ނުވަތަ ސެލެކްޓް ކުރެއެވެ، ދެ ފިންގަރުން ޕިންޗް ކޮށް ޒޫމް ކުރެއެވެ). ކޮންމެ އެޕަކުގެ ގައިޑް ބުނެއެވެ. iPad މަތީގައި Safari ނުވަތަ Chrome ބޭނުން ކުރާށެވެ. ޓައިޕް ކުރާ ކޮމާންޑުތައް ބޭނުން ކުރާ އެޕްތަކަށް ކީބޯޑެއް މަދަދުކާރެކެވެ.

## ހުރިހާ ހުރި ބްރައުޒަރ އަދި ސިސްޓަމް

މި ވާރޝަންތައް ކިޔަވާފައި ހުންނަނީ 0.7 އެޕްތަކުގެ ކޯޑުން، ގުޅާފައި ނޫން ގޮތަކުން: ކޮންމެ ފައިލެއް ޕާސްކޮށް، ކޮންމެ ލޭންގުއޭޖް ފީޗަރެއް ބްރައުޒަރުތަކުގެ ޚާއްސަ ކޮމްޕެޓިބިލިޓީ ޑޭޓާއާ ބެހިގެން ހޯދިއެވެ. މި ވާރޝަންތަކަށް ދަށުން އެޕްތައް ފަށާކަށް ނުފެންނާނެއެވެ، ސަބަބަކީ ބްރައުޒަރު އެ ކޯޑް ނުހަނދާންކުރޭ.

| | ފުރަތަމަ ވާރޝަން އެޕްތައް ފަށާނެ |
|---|---|
| Chrome, Edge, Brave, Opera, Vivaldi | Chromium 94 |
| Firefox | 93 |
| Safari (Mac, iPad, iPhone) | 16.4 (macOS 13.3, iPadOS and iOS 16.4) |

CadCraft Studio ވިންޑޯސްގައި އެކަމަކު އިންޖިނެއް ގެންގުޅެއެވެ، އެނބުރި Windows 10 ނުވަތަ 11 ބޭނުންވޭ؛ Mac ގައި އެ ސިސްޓަމްގެ އިންޖިން ބޭނުން ކުރުމުން macOS 13.3 ނުވަތަ އޭގެ ފަހުން ބޭނުންވޭ. Studio ގައި Settings › Updates ގައި ތިޔަ ކޮޕީ ކޮން ސިސްޓަމް ގައި ރަން ވެނީކަން ދައްކާނެއެވެ.

މިއީ ފަށާ ފުރަތަމަ ވާރޝަން، ކޯޑުން ކިޔާފައިވާ ޑޭޓާ. އެއީ އަވަސް ހިސާބުގައި ސަލާމަތީ ބްރައުޒަރުތަކުގެ ލިސްޓެއް ނޫން؛ ފަހަތަށް ދާ ބްރައުޒަރަކު ފަށައިފިނަމަވެސް ފީޗަރެއް ނެތިދާނެއެވެ.

## ތިޔަ ކޮމްޕިއުޓަރަށް ބޭނުންވާ އެއްޗެހި

މި ނުރަސް ހަދާފައިވާ މިނިމަމްތަކެވެ، ސަރާހަތު ނޫނެވެ:

- 8 GB މެމަރީ (16 GB ގިނަ ބޮޑު ފެޑަރޭޓެޑް މޮޑެލްތަކަށް ރެކޮމެންޑް ކުރެވެއެވެ).
- 3D އެޕްތަކަށް WebGL 2 ގެ ގްރާފިކްސް ޗިޕް. 3D ވިއު ހުސްވެފައި ހުރިނަމަ ބްރައުޒަރުގެ ސެޓިންގްސްގައި ހާރޑްވެއާ އެކްސެލެރޭޝަން އޮންކޮށްފައި ހުންނަނެތް ބަލާށެވެ.
- ފުރިހަމަ ޓޫލްބާތަކަށް 1280 ޕިކްސެލް ފުޅާ ސްކްރީނެއް. ކުޑަ ސްކްރީނުގައި ރޯތައް ރެޕް ކުރެއެވެ.

ބޮޑު ފައިލްތައް (ބޮޑު ޕްލޭން ސެޓްތަކާއި ބޮޑު މޮޑެލްތައް) ބްރައުޒަރު ޓެބްގައި ގިނަ މެމަރީ ބޭނުން ކުރެއެވެ. އެޕެއް ސުސްތަވެއްޖެނަމަ އެހެން ބަރު ޓެބްތައް ބަންދު ކުރާށެވެ.

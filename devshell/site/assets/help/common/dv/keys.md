## ޝޯޓްކަޓްތައް ލިޔެވޭ ގޮތް

ހެލްޕް ކޮންމެ ޝޯޓްކަޓެއް ލިޔެވޭނީ ތިޔަ ކީބޯޑް ލޭބަލްކުރާ ގޮތަށެވެ.

| ލިޔެވިފައި | Mac ގައި | Windows އާއި Linux ގައި |
|---|---|---|
| {{key:Mod+S}} | Command (⌘) އަދި S | Ctrl އަދި S |
| {{key:Ctrl+Shift+F}} | Control (⌃)، Shift (⇧) އަދި F | Ctrl، Shift އަދި F |
| {{key:Alt+Left}} | Option (⌥) އަދި ← | Alt އަދި ← |
| {{key:Backspace}} | Delete ކީ | Backspace |
| {{key:Delete}} | fn އަދި Delete (ފޮރުވާ ކޮޕީ ނޫން) | Delete |
| {{key:Enter}} | Return | Enter |

ޕްލަސް ސައިން މާނައަކީ ކީތައް އެކުގައި ހިފުން. "Then" މާނައަކީ އެއް ފަހުން އަނެއް ފިރުން.

ގިނަ އެޕް ޝޯޓްކަޓްތައް Mac ގައި Command ނުވަތަ Control ހަމަ ކުރެއެވެ، އެހެންކަމުން {{key:Mod+Z}} ދެ ގޮތަކުން މަސައްކަތް ކުރެއެވެ. ކުޑަ ގިނައެއް، މިސާލަކަށް ފުރިހަމަ ސްކްރީން ({{key:Ctrl+Shift+F}})، ކޮންމެ ކޮމްޕިއުޓަރުގައި Control ބޭނުން ކުރެއެވެ؛ ހެލްޕް ކަން ދައްކާނެއެވެ.

## Mac ގައި ފަންކްޝަން ކީތައް

ގިނަ Mac ކީބޯޑުތަކުގެ މަތީ ޢަރުޝާ ބްރައިޓްނަސް، ސައުންޑް އަދި މީޑިއާ ކޮންޓްރޯލްކުރެއެވެ. F1 އިން F12 ހުށަހެޅުމަށް:

- ކީ ފިރުމުގައި **fn** (ނުވަތަ globe ކީ) ހިފާށެވެ، ނުވަތަ
- **System Settings** ހުޅުވާ، ފަހުން **Keyboard**، ފަހުން **Keyboard Shortcuts**، ފަހުން **Function Keys** ހޮވާ، "Use F1, F2, etc. keys as standard function keys" އޮންކުރާށެވެ.

ކަށަވަރު F-ކީތަކެއް macOS ސަރުގައި ވެސް ހުންނާނެ (މިސާލަކަށް Mission Control). ކީއެއް އެޕުގައި ކަމެއް ނުކުރާނަމަ fn އެކު ފިރާށެވެ، ނުވަތަ ޓޫލްބާގެ ބަޓަން ބޭނުން ކުރާށެވެ.

## ބްރައުޒަރު ހިފާ ޝޯޓްކަޓްތައް

ވެބް ޞަފްޙާއެއް ބްރައުޒަރުން ޝޯޓްކަޓްތަކެއް ނެގޭކަށް ނެތެވެ، ކޮންމެ ކަމެއް ކުރިޔަސް. ހުރިހާ އެޕެއްގައި:

- {{key:Mod+N}}، {{key:Mod+T}} އަދި {{key:Mod+W}} އަބަދުވެސް ބްރައުޒަރ ވިންޑޯތަކާއި ޓެބްތައް ހުޅުވައި ނުވަތަ ބަންދު ކުރެއެވެ. އެޕްތައް New އަދި Close އަށް ބަޓަންތައް ބޭނުން ކުރެއެވެ.
- Mac ގައި {{key:Mod+Q}} އަދި Windows ގައި {{key:Alt+F4}} ބްރައުޒަރ ބަންދުކުރެއެވެ. ސޭވް ނުކުރާ މަސައްކަތެއް ހުރިނަމަ ބްރައުޒަރު "Leave site?" އެވެ؛ ހުރި ތަނުގައި ހުރުން ހޮވާ، ފަހުން ރައްކާކުރާށެވެ.
- ބްރައުޒަރގެ އަމިއްލަ ފުރިހަމަ ސްކްރީން ({{pick:mac=Control-Command-F, or the green button on the window|windows linux=F11}}) މަސައްކަތް ކުރެއެވެ. އެޕްތަކުގައި ވެސް {{key:Ctrl+Shift+F}} ގައި އަމިއްލަ ސްކްރީން މޯޑްތައް ވެސް ހުރެއެވެ، އެއީ އެޕުގެ ބާރުތައްވެސް ފޮރުވާނެއެވެ.

## ޓްރެކްޕެޑުގައި މައުސް ބަޓަންތައް

އެޕްތައް ރައިޓް ބަޓަންއާއި މިޑްލް ބަޓަން ބޭނުން ކުރެއެވެ. ތިން ބަޓަން މައުސެއް ނެތިނަމަ:

:::mac
- **ރައިޓް ކްލިކް:** ދެ ފިންގަރުން ކްލިކް ކުރާށެވެ. ދެ ފިންގަރު ކްލިކް މަސައްކަތް ނުކުރާނަމަ **System Settings** ގައި **Trackpad** ހުޅުވައި "Secondary click" އޮންކުރާށެވެ. {{key:Ctrl}} ހިފައި ކްލިކް ކުރުމުން ބްރައުޒަރ މެނޫ ހުޅުވެއެވެ، ނަމަވެސް ޑްރޯއިންގ ތެރޭގައި ކޮޅުގެ ޢާއްމު ކްލިކް (Control ހިފައި) ކިޔައިދާނެ އެޕްތައް ހުރެއެވެ، އެހެންކަމުން ދެ ފިންގަރު ކްލިކް އަށް ޕްރެފަރެންސް ދީ ބާއްވާށެވެ.
- **މިޑްލް-ބަޓަން ޑްރެގް (ޕޭން):** ކޮންމެ އެޕަކަށް ޕޭން ކުރުމަށް އެހެން ގޮތެއް ހުރެއެވެ، މިސާލަކަށް {{key:Space}} ހިފައި ޑްރެގް ކުރުން ނުވަތަ ރައިޓް ބަޓަނުން ޑްރެގް ކުރުން. އެޕުގެ ކީބޯޑް ޞަފްޙާ ކަން ދައްކާނެއެވެ.
- **ވީލް ޒޫމް:** ޓްރެކްޕެޑުގެ ދެ ފިންގަރު ސްކްރޯލް ގިނަ އެޕްތަކުގައި ޒޫމް ކުރެއެވެ. ފިންޗް ފަދަ ގޮތް އެޕް ގެ ބާރުވެސް ޒޫމް ކުރެއެވެ.
:::

:::windows linux
- **ރައިޓް ކްލިކް:** ދެ ފިންގަރުން ކްލިކް ކުރާށެވެ، ނުވަތަ ޓަޗްޕެޑުގެ ތަނަވަސް ކަނޑާ ކުރާ ކުޑަ ކަނާތު ކޯޓަރުން ކްލިކް ކުރާށެވެ. މިއީ ޓަޗްޕެޑު ސެޓިންގްސްއާ ބެހޭ ކަމެކެވެ.
- **މިޑްލް-ބަޓަން ޑްރެގް (ޕޭން):** ކޮންމެ އެޕަކަށް ޕޭން ކުރުމަށް އެހެން ގޮތެއް ހުރެއެވެ، މިސާލަކަށް {{key:Space}} ހިފައި ޑްރެގް ކުރުން ނުވަތަ ރައިޓް ބަޓަނުން ޑްރެގް ކުރުން. އެޕުގެ ކީބޯޑް ޞަފްޙާ ކަން ދައްކާނެއެވެ.
- **ވީލް ޒޫމް:** ޓަޗްޕެޑުގެ ދެ ފިންގަރު ސްކްރޯލް ގިނަ އެޕްތަކުގައި ޒޫމް ކުރެއެވެ.
:::

## ޓެކްސްޓް ބޮކްސެއްގައި ލިޔުން

ބޮކްސެއްގައި (ނަމެއް، ނޯޓެއް، ސާޗެއް) ލިޔާއިރު އެޕުގެ އެއް އަކުރު ޝޯޓްކަޓްތައް ބަންދު ހުންނާނެއެވެ، އެހެންކަމުން "L" ލިޔުމުން L ލިޔެވިދާނެއެވެ. {{key:Esc}} ފިރާށެވެ، ނުވަތަ ޑްރޯއިންގ ކްލިކް ކުރާށެވެ، ކީތައް އެޕަށް އަލުން ދިނުމަށް.

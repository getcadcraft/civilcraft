Приложения работают внутри веб-браузера. Они выполняют работу на вашем компьютере: ваши файлы открываются там и никогда не отправляются нам (см. [Куда попадают ваши файлы](common:your-files)).

## Какой браузер

Используйте актуальную версию одного из этих браузеров:

| Браузер | Движок | Примечания |
|---|---|---|
| Chrome, Edge, Brave, Opera, Vivaldi | Chromium | Самый полный: выбор папки, сохранение для работы офлайн, обработка файлов. |
| Firefox | Gecko | Работает. Для открытия целой папки используется более простое окно выбора. В приватных окнах сохранение для офлайн может не работать. |
| Safari | WebKit | Работает на Mac и iPad. Для открытия целой папки используется более простое окно выбора. Safari может удалить офлайн-копию, которой вы не пользовались несколько недель. |

Все три движка подходят для повседневной работы. Если в одном из них приложение работает иначе, справка показывает шаги для вашего браузера.

## Чем отличаются браузеры

- **Открытие папки.** Браузеры на Chromium показывают настоящее окно выбора папки и могут читать папку напрямую. Firefox и Safari просят выбрать папку и затем читают каждый файл в ней, что занимает больше времени для больших папок проектов; перетаскивание папки на приложение работает во всех трех.
- **Сохранение.** Приложения сохраняют, скачивая файл. Браузер сам решает, куда попадают загрузки и спрашивает ли он об этом.

:::chromium
В Chrome или Edge включите «Всегда указывать место для сохранения файлов» (в настройках, в разделе «Скачанные файлы»), чтобы каждый раз выбирать папку.
:::

:::firefox
В Firefox откройте «Настройки», затем «Основные», затем «Загрузки» и выберите «Всегда выдавать запрос на сохранение файлов», чтобы каждый раз выбирать папку.
:::

:::safari
В Safari откройте «Настройки», затем «Основные» и установите для «Расположение загруженных файлов» значение «Спрашивать для каждой загрузки», чтобы каждый раз выбирать папку.
:::

## Mac, Windows и Linux

Приложения одинаковы на любом компьютере. Меняется только клавиатура: сочетания клавиш записываются для вашего компьютера автоматически. См. [Клавиши, мыши и трекпады](common:keys).

## Планшеты и сенсорные экраны

Некоторые приложения поддерживают касание (один палец рисует или выбирает, два пальца сводятся для изменения масштаба и панорамирования). В справке каждого приложения сказано, так ли это. На iPad используйте Safari или Chrome. Клавиатура пригодится в приложениях, где используются вводимые команды.

## Самый старый браузер и система

Эти данные мы взяли из кода приложений версии 0.7, а не на глаз: каждый файл был разобран, и для каждой используемой в нем возможности языка найдены опубликованные данные о совместимости браузеров. В версиях ниже указанных приложения не могут даже запуститься, потому что браузер не понимает код.

| | Самая старая версия, в которой приложения запускаются |
|---|---|
| Chrome, Edge, Brave, Opera, Vivaldi | Chromium 94 |
| Firefox | 93 |
| Safari (Mac, iPad, iPhone) | 16.4 (macOS 13.3, iPadOS и iOS 16.4) |

CadCraft Studio содержит собственный веб-движок в Windows, поэтому ему нужна Windows 10 или 11; на Mac он использует системный, поэтому нужна macOS 13.3 или новее. В Studio раздел Настройки › Обновления показывает, на чем работает ваша копия.

Это самая старая версия, в которой приложения *запускаются*, определенная по коду. Это не список старых браузеров, в которых мы запускали приложения, поэтому в более старом браузере, где приложение запустилось, какой-то возможности все равно может не хватать.

## Что нужно вашему компьютеру

Это планируемые минимальные требования к приложениям, а не измеренные:

- 8 GB памяти (для больших сводных моделей рекомендуется 16 GB).
- Графический чип с WebGL 2 для 3D-приложений. Если 3D-вид остается пустым, проверьте, включено ли аппаратное ускорение в настройках браузера.
- Экран шириной не менее 1280 пикселей для полных панелей инструментов; на меньших экранах они переносятся на несколько строк.

Очень большие файлы (большие комплекты планов, большие модели) занимают много памяти во вкладке браузера. Закройте другие тяжелые вкладки, если приложение начало тормозить.

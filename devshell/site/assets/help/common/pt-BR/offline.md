Os apps fazem o trabalho no seu computador, então a maior parte funciona sem conexão. O navegador só precisa ter os arquivos do app salvos antes.

## Salvar um app para uso offline

1. Abra o app enquanto estiver online.
2. Escolha {{ui:Salvar para uso offline}} na barra no alto.
3. Aguarde "Pronto para uso offline". Os arquivos do app, seus leitores de arquivo e esta ajuda agora estão salvos no seu navegador. Apps que leem arquivos DWG ou PDF salvam também seus leitores, então na primeira vez isso pode levar um minuto.

Faça isso uma vez por app, em cada navegador que você usa. Para voltar ao app depois sem conexão, abra o mesmo endereço usado antes ou um favorito dele.

:::offline
Você está offline agora. Se este app foi salvo para uso offline, tudo abaixo funciona. Se não foi, você ainda pode usar o que já foi carregado nesta guia, mas não a recarregue até estar online de novo.
:::

## O que funciona offline

- Abrir arquivos do seu computador, desenhar, editar, medir e verificar.
- Salvar e exportar: todo salvamento é um download para o seu computador.
- Esta ajuda, inclusive a pesquisa.

## O que precisa de conexão

- Abrir o app pela primeira vez e salvá-lo para uso offline.
- Obter uma versão mais nova do app. Quando você está online, o app pega a versão mais recente na próxima vez que abre, e {{ui:Salvar para uso offline}} atualiza a cópia salva.
- Links para o site, como {{ui:Abrir no site}} e links para outras páginas.
- O salvamento na nuvem e a sincronização entre computadores, que ainda não estão disponíveis.

## O que saber

- Uma cópia salva pertence a um navegador em um computador. Limpar os dados de site do navegador a remove.
- Janelas privadas de alguns navegadores e alguns computadores de trabalho com restrições não permitem o salvamento offline. O botão avisa quando não consegue salvar.

:::safari
O Safari remove os dados salvos de sites que você não visita há várias semanas. Abra o app de vez em quando, online, ou salve-o de novo antes de uma viagem.
:::

図面の横にあるパネルは移動できます。好みの位置に配置するか、2つ目のモニターに専用のウィンドウを与えて、1つ目のモニター全体を図面に使えるようにできます。

:::note
各パネルの上部には、パネルの名前、{{ui:⋯}}メニュー、ピン、閉じるボタンを備えた細いタイトルバーがあります。バージョン0.7より前では、パネル名と{{ui:⋯}}メニューのみです。
:::

## ウィンドウ内でパネルを移動する

1. パネル上部のパネル名をドラッグします。
2. ドラッグ中、図面の左、右、下に枠線の領域が表示されます。いずれかの領域にパネルをドロップすると、そこにドッキングします。ポインターが重なっている領域は濃くなります。
3. 図面上の別の場所にドロップすると、フローティングになります。

パネルは1つの辺を共有できます。パネルは積み重なり、パネル同士の境界線をドラッグするとスペースを分け合えます（境界線にフォーカスがあるときは矢印キーで移動でき、ダブルクリックすると均等に分け合います）。ドッキングした辺の内側の端をドラッグすると幅を広げたり狭めたりできます。端をダブルクリックすると元に戻ります。

フローティングしたパネルは図面の上に表示されたままです。パネル名で移動し、右下の角をドラッグしてサイズを変更できます（角までタブで移動して矢印キーを使うこともできます）。パネル名をダブルクリックすると、元の位置に再びドッキングします。

:::touch
パネル名を一本指でドラッグします。フローティングパネルの右下の角を一本指でドラッグするとサイズを変更でき、ドッキングしたパネル同士の境界も同じ方法で変更できます。ドラッグせずにフローティングやドッキングをするには、{{ui:⋯}}メニューを使います。
:::

## パネルをタブにまとめる

2つのパネルは1つの枠を共有し、一度に1つずつ表示できます。パネル名でパネルをドラッグし、別のパネルのタイトルバーの上にドロップします（ポインターが重なっている間、タイトルバーに枠線が表示されます）。すると、枠のタイトルバーにパネルごとのタブが表示されます。タブをクリックすると、そのパネルが表示されます。タブにフォーカスがある状態で {{key:Left}} と {{key:Right}} を押すとタブを切り替えられ、{{key:Home}} と {{key:End}} で最初と最後のタブに移動します。

グループからパネルを外すには、そのパネルの{{ui:⋯}}メニューで{{ui:タブグループから移動}}を選ぶか、別の場所にドラッグします。{{ui:タブにまとめる}}を選んでパネル名を選ぶと、ドラッグせずにグループ化できます。

## ピン留め、非表示、再表示

- パネルのタイトルバーにあるピンを押すと**自動非表示**になります。パネルはドッキング位置から離れ、その辺に小さなタブとして残ります。タブにポインターを合わせる、フォーカスする、またはクリックすると、パネルが図面の上にスライドして表示されます。離れると（または {{key:Esc}} を押すと）元に戻ります。ピンをもう一度押すか、{{ui:ピン留めを解除}}を選ぶと、そのままドッキングされます。
- 閉じるボタン、またはメニューの{{ui:このパネルを非表示}}を選ぶと、パネルは非表示になり、ドッキング領域は詰められます。辺にある破線のタブをクリックするか、フォーカスして {{key:Enter}} を押すと、パネルが戻ります。

## レイアウトの密度を高める

{{ui:設定}} › {{ui:全般}} › {{ui:レイアウトの密度}} には2つの選択肢があります。既定は{{ui:ゆったり}}です。{{ui:コンパクト}}は、そのアプリの行の高さ、パネルの余白、ツールバーのボタン、パネルの文字を詰め、画面により多くが収まるようにします。この設定はアプリごとに保存されます。タッチ画面では両方の設定で大きなボタンが保たれ、スマートフォンでは独自のレイアウトが保たれます。{{ui:レイアウトをリセット}}を選んでも、密度の設定はそのままです。

## ツールバーの行数を選ぶ

{{ui:設定}} › {{ui:全般}} › {{ui:ツールバーの行数}} には3つの選択肢があります。既定は{{ui:折り返し}}で、すべてのツールグループが必要な行数で表示されます。{{ui:2行}}を選ぶとツールバーは2行に、{{ui:1行}}を選ぶと1行に収まり、図面の高さが確保されます。収まらないグループは、ツールバーの中で横にスクロールします（マウスホイール、2本指でのスワイプ、または {{key:Tab}} でツールに移動して使います）。すでに2行に収まっているツールバーは、{{ui:2行}}でもそのままです。グリッドにするとかえって高くなるためです。この設定はアプリごとに保存されます。タッチ画面とスマートフォンでは独自のレイアウトが保たれます。CadCraft にはツールバー専用の設定があり、{{ui:設定}} › {{ui:CadCraft}} にあります。

## キーボードで操作する

各パネルの{{ui:⋯}}ボタンを選ぶとメニューが開きます。メニューには、{{ui:左にドッキング}}、{{ui:右にドッキング}}、{{ui:下にドッキング}}、{{ui:図面の上にフローティング}}、{{ui:端にピン留め}}、{{ui:このパネルを非表示}}、別のパネルとの {{ui:タブにまとめる}}、{{ui:新しいウィンドウに移動}}、{{ui:元に戻す}} があります。ボタンまで {{key:Tab}} で移動し、{{key:Enter}} を押し、矢印キーで移動して、もう一度 {{key:Enter}} を押します。{{key:Esc}} でメニューを閉じます。

## 2つ目のモニターにパネルを置く

1. パネルの{{ui:⋯}}を選び、{{ui:すべてのパネルを新しいウィンドウに移動}}を選びます。{{ui:設定}}にある{{ui:パネルを新しいウィンドウに移動}}を選ぶこともできます。
2. パネルを含む小さなウィンドウが開きます。そのウィンドウを2つ目のモニターにドラッグし、好みの大きさにします。
3. 作業はそのまま続けられます。パネルは以前と同じように図面に作用し、図面はメインウィンドウを埋めます。

パネルのウィンドウが前面にあるときも、ショートカットは引き続き使えます。そこで押したキーは、ボックスへの入力を除き、図面に送られます。アプリが表示する質問やダイアログは、引き続きメインウィンドウに開くため、表示されたらそちらを確認してください。テーマとパネルの文字サイズは、メインウィンドウに従います。

:::chromium
Chrome と Edge では、ブラウザーが2つ目の画面にウィンドウを配置できます。2つ目の画面を接続した状態で、パネルのウィンドウで{{ui:もう一方の画面に移動}}を選びます（またはパネルの{{ui:⋯}}メニューで{{ui:パネルをもう一方の画面に移動}}を選びます）。ブラウザーは、このサイトが画面を見ることを許可するかどうか一度尋ねます。許可すると、以後パネルのウィンドウはその画面に毎回開きます。
:::

:::firefox safari
Firefox と Safari では、パネルのウィンドウを2つ目のモニターに自分でドラッグしてください。次回は、同じ位置と同じ大きさで開きます。
:::

## 複数のパネルウィンドウ

各パネルには専用のウィンドウを持たせられます。パネルウィンドウは最大4つまで（たとえばモニターごとに1つ）使えます。

- パネルの{{ui:⋯}}メニューで{{ui:新しいウィンドウに移動}}を選ぶと、そのパネル用の別のウィンドウが開きます。{{ui:パネルウィンドウ 2 に移動}}（以下同様）を選ぶと、開いているウィンドウにパネルが移動します。2つ目のウィンドウは「パネル 2」と呼ばれます。
- パネル名をドラッグして、あるウィンドウから別のウィンドウへ移動できます。メインウィンドウの上でドロップするとそこにドッキングし（ポインターが重なっている間、枠線の領域が表示されます）、またはフローティングになります。別のパネルウィンドウの上でドロップすると、そのウィンドウに移動します。それ以外の場所でドロップすると、元の場所に残ります。
- パネルが残っていないパネルウィンドウは、自動的に閉じます。

再読み込みの後、アプリはパネルウィンドウを再び開くよう提案します。ブラウザーは1回のクリックにつき1つのウィンドウを開くため、{{ui:次のウィンドウを開く}}をウィンドウごとに1回ずつ選んでください。

## レイアウトの各部分も同じ操作で

リボン、ツールボックス、ツールの行、ステータスバーも、パネルと同じ方法で専用のウィンドウに移せます。その部分の{{ui:⋯}}メニューを開き、{{ui:新しいウィンドウに移動}}を選びます。{{ui:元に戻す}}（またはウィンドウを閉じる）で元の位置に戻ります。そのウィンドウで押したキーは、パネルのウィンドウから押した場合と同様にアプリに届きます。各部分には、このようなメニューが1つずつあります。

## ダイアログを移動する

どのダイアログも、図面の邪魔にならないように移動できます。タイトルバーを押したままドラッグします。ダイアログは、それぞれ個別に位置を記憶し、次に開いたときもその位置に戻ります。タイトルバーをダブルクリックすると、中央に戻ります。

キーボードで操作する場合は、ダイアログ内にフォーカスがある状態で {{key:Alt}}+{{key:Shift}}+矢印キーを押すと、16ピクセルずつ移動します。{{key:Ctrl}} を追加すると64ピクセルずつ移動します。ウィンドウや画面が小さくなった後に画面外に出てしまったダイアログは、画面内に戻されます。

スマートフォンでは、ダイアログは全幅のシートのままで、移動されません。

CadCraft Studio では、作業中に開いたままにできる CadCraft の{{ui:PDFに印刷}}ダイアログのタイトルバーに、{{ui:別ウィンドウで開く}}ボタンがあります。ダイアログは、別のモニターに置ける専用のウィンドウに移動します。ダイアログを閉じるとウィンドウも閉じ、ウィンドウを閉じるとダイアログも閉じます。

## パネルを元に戻す

- パネルウィンドウで{{ui:パネルを元に戻す}}を選ぶか、単にパネルウィンドウを閉じます。パネルは元の位置に戻ります。
- メインウィンドウを閉じる、または再読み込みすると、パネルウィンドウも閉じます。アプリが再び開くと、パネルが専用のウィンドウにあったことを知らせるので、{{ui:開く}}を選んでウィンドウを戻すか、{{ui:ここに残す}}を選びます。
- {{ui:設定}} › {{ui:全般}} › {{ui:レイアウトをリセット}}を選ぶと、すべてのパネルが最初の位置に戻ります。

:::tip
パネルを新しいウィンドウに移動しても何も開かない場合は、ブラウザーがポップアップをブロックしています。アプリがそれを知らせ、パネルは元の位置に残ります。getcadcraft.com のポップアップを許可してから、もう一度試してください。
:::

レイアウトは、このブラウザーの中でアプリごとに、他の設定と一緒に保存されます。

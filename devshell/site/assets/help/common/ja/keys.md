## ショートカットの表記

ヘルプでは、各ショートカットをお使いのキーボードの表記で書きます。

| 表記 | Mac | WindowsとLinux |
|---|---|---|
| {{key:Mod+S}} | Command(⌘)とS | CtrlとS |
| {{key:Ctrl+Shift+F}} | Control(⌃)、Shift(⇧)、F | Ctrl、Shift、F |
| {{key:Alt+Left}} | Option(⌥)と← | Altと← |
| {{key:Backspace}} | Deleteキー | Backspace |
| {{key:Delete}} | fnとDelete(前方削除) | Delete |
| {{key:Enter}} | Return | Enter |

プラス記号は、キーを同時に押したままにすることを表します。「続けて」は、1つずつ順番に押すことを表します。

アプリのショートカットの多くは、MacではCommandとControlのどちらでも使えるので、{{key:Mod+Z}} はどちらでも動作します。全画面表示({{key:Ctrl+Shift+F}})のように、どのコンピューターでもControlキーを使うものもあります。該当する場合は、ヘルプにそう書かれています。

## Macのファンクションキー

多くのMacのキーボードでは、最上段のキーは画面の明るさ、音量、メディアの操作になっています。F1からF12を送るには、次のどちらかを行います。

- キーを押すときに **fn**(または地球儀キー)を押したままにする。
- **システム設定**、**キーボード**、**キーボードショートカット**、**ファンクションキー**の順に開き、「F1、F2などのキーを標準のファンクションキーとして使用」をオンにする。

一部のFキーは、macOS自身も使っています(たとえばMission Control)。アプリでキーが何も起こさない場合は、fnと一緒に押すか、ツールバーのボタンを使ってください。

## ブラウザーが保持するショートカット

Webページが、ブラウザーから奪えないショートカットがあります。どのアプリでも、次のとおりです。

- {{key:Mod+N}}、{{key:Mod+T}}、{{key:Mod+W}} は、常にブラウザーのウィンドウやタブを開閉します。アプリでは、新規作成と閉じる操作に代わりにボタンを使います。
- Macの {{key:Mod+Q}} とWindowsの {{key:Alt+F4}} は、ブラウザーを終了します。保存していない作業がある場合は、ブラウザーが先に確認します(「このサイトを離れますか?」)。留まることを選び、保存してください。
- ブラウザー自身の全画面表示({{pick:mac=Control-Command-F、またはウィンドウの緑のボタン|windows linux=F11}})も使えます。アプリには {{key:Ctrl+Shift+F}} の独自の画面モードもあり、アプリのバーも隠せます。

## トラックパッドでのマウスボタン

アプリは右ボタンと中ボタンを使います。3ボタンマウスがない場合は、次のようにします。

:::mac
- **右クリック:** 指2本でクリックします。指2本のクリックで何も起こらない場合は、**システム設定**の**トラックパッド**で「副ボタンのクリック」をオンにしてください。{{key:Ctrl}} を押しながらクリックするとブラウザーのメニューが開きますが、図面の中では、一部のアプリがこれを(Controlを押した)通常のクリックとして読み取るため、指2本のクリックをおすすめします。
- **中ボタンのドラッグ(パン):** 各アプリに別のパン方法があります。たとえば、{{key:Space}} キーを押しながらドラッグする、右ボタンでドラッグする、などです。どれかは、アプリのキーボードのページに書かれています。
- **ホイールによるズーム:** ほとんどのアプリで、トラックパッドを指2本でスクロールするとズームします。アプリが対応していれば、ピンチでもズームします。
:::

:::windows linux
- **右クリック:** 指2本でクリックするか、タッチパッドの右下の角をクリックします。これはタッチパッドの設定によります。
- **中ボタンのドラッグ(パン):** 各アプリに別のパン方法があります。たとえば、{{key:Space}} キーを押しながらドラッグする、右ボタンでドラッグする、などです。どれかは、アプリのキーボードのページに書かれています。
- **ホイールによるズーム:** ほとんどのアプリで、タッチパッドを指2本でスクロールするとズームします。
:::

## テキストボックスへの入力

ボックス(名前、メモ、検索など)に入力している間は、アプリの1文字ショートカットは無効になるので、「L」と打てばLが入力されます。キーをアプリに戻すには、{{key:Esc}} キーを押すか、図面をクリックします。

アプリはWebブラウザーの中で動作します。処理はお使いのコンピューター上で行われ、ファイルはそこで開かれるだけで、当社に送信されることはありません([ファイルの行き先](common:your-files)を参照)。

## どのブラウザーを使うか

次のいずれかの最新版をお使いください。

| ブラウザー | エンジン | 備考 |
|---|---|---|
| Chrome、Edge、Brave、Opera、Vivaldi | Chromium | 最も機能がそろっています。フォルダーの選択、オフライン用の保存、ファイルの関連付けに対応しています。 |
| Firefox | Gecko | 動作します。フォルダー全体を開くときは、より簡易な選択画面になります。プライベートウィンドウでは、オフライン用の保存ができない場合があります。 |
| Safari | WebKit | MacとiPadで動作します。フォルダー全体を開くときは、より簡易な選択画面になります。数週間使っていないオフライン用のコピーは、Safariが削除することがあります。 |

日常の作業なら、3つのエンジンのどれでも問題ありません。アプリの動作がエンジンによって異なる場合は、そのアプリのヘルプにお使いのブラウザー向けの手順が表示されます。

## ブラウザー間の違い

- **フォルダーを開く。** Chromium系のブラウザーでは、本物のフォルダー選択画面が表示され、フォルダーを直接読み込めます。FirefoxとSafariでは、フォルダーを選んでからその中のすべてのファイルを読み込むため、大きなプロジェクトフォルダーでは時間がかかります。フォルダーをアプリにドラッグする方法は、3つとも使えます。
- **保存。** アプリは、ファイルをダウンロードする形で保存します。ダウンロードの保存先と、保存前に確認するかどうかは、ブラウザーの設定によります。

:::chromium
ChromeまたはEdgeでは、設定の「ダウンロード」にある「ダウンロード前に各ファイルの保存場所を確認する」をオンにすると、毎回フォルダーを選べます。
:::

:::firefox
Firefoxでは、設定を開き、「一般」の「ファイルとアプリケーション」にある「ダウンロード」で「常にファイルを保存する場所を確認する」を選ぶと、毎回フォルダーを選べます。
:::

:::safari
Safariでは、設定を開き、「一般」の「ファイルのダウンロード先」を「毎回尋ねる」にすると、毎回フォルダーを選べます。
:::

## Mac、Windows、Linux

アプリはどのコンピューターでも同じです。違うのはキーボードで、ショートカットはお使いのコンピューターに合わせて自動的に表記されます。[キー、マウス、トラックパッド](common:keys)を参照してください。

## タブレットとタッチ画面

一部のアプリはタッチ操作に対応しています(指1本で作図や選択、指2本のピンチでズームとパン)。対応しているかどうかは、各アプリのヘルプに記載されています。iPadではSafariまたはChromeを使ってください。コマンドを入力するタイプのアプリでは、キーボードがあると便利です。

## 起動できる最も古いブラウザーとシステム

以下は推測ではなく、0.7アプリのコードから読み取ったものです。すべてのファイルを解析し、使われている各言語機能をブラウザーの公開互換性データで調べました。これより古いバージョンでは、ブラウザーがコードを理解できないため、アプリは起動すらできません。

| | アプリを起動できる最も古いバージョン |
|---|---|
| Chrome、Edge、Brave、Opera、Vivaldi | Chromium 94 |
| Firefox | 93 |
| Safari(Mac、iPad、iPhone) | 16.4(macOS 13.3、iPadOSとiOS 16.4) |

CadCraft Studio は、Windowsでは独自のWebエンジンを内蔵しているため、Windows 10または11が必要です。Macではシステムのエンジンを使うため、macOS 13.3以降が必要です。お使いのコピーが何の上で動いているかは、Studio の 設定 › 更新 で確認できます。

これは、コードから読み取った、アプリが*起動する*最も古いバージョンです。古いブラウザーでアプリを実際に動かして確かめた一覧ではないため、起動できても一部の機能が使えない場合があります。

## コンピューターに必要なもの

以下はアプリの想定する最小値であり、実測した動作要件ではありません。

- 8 GBのメモリ(大きな統合モデルには16 GBを推奨)。
- 3DアプリにはWebGL 2に対応したグラフィックスチップ。3Dビューが空白のままの場合は、ブラウザーの設定でハードウェアアクセラレーションがオンになっているか確認してください。
- ツールバーをすべて表示するには、幅1280ピクセル以上の画面。それより小さい画面では、ツールバーが折り返されます。

非常に大きなファイル(大きな図面セットや大きなモデル)は、ブラウザーのタブで多くのメモリを使います。アプリの動作が遅くなったら、重い他のタブを閉じてください。

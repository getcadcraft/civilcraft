## Тез баскычтар кантип жазылат

Жардам ар бир тез баскычты сиздин клавиатураңызда жазылгандай көрсөтөт.

| Жазылышы | Mac'та | Windows жана Linux'та |
|---|---|---|
| {{key:Mod+S}} | Command (⌘) жана S | Ctrl жана S |
| {{key:Ctrl+Shift+F}} | Control (⌃), Shift (⇧) жана F | Ctrl, Shift жана F |
| {{key:Alt+Left}} | Option (⌥) жана ← | Alt жана ← |
| {{key:Backspace}} | Delete баскычы | Backspace |
| {{key:Delete}} | fn жана Delete (алдыга өчүрүү) | Delete |
| {{key:Enter}} | Return | Enter |

Кошулган белги баскычтарды бирге басып туруу дегенди билдирет. «Андан кийин» деген сөз болсо, алар бири-бирден басылат.

Колдонмонун көпчүлүк тез баскычтары Mac'та Command же Control менен иштейт, ошондуктан {{key:Mod+Z}} эки жол менен иштейт. Айрымдары, мисалы толук экран ({{key:Ctrl+Shift+F}}), ар бир компьютерде Control баскычын колдонот; жардам муну керек жеринде айтат.

## Mac'тагы функциялык баскычтар

Mac клавиатураларынын көбүндө үстүнкү катар жарыктыкты, үндү жана медианы башкарат. F1дан F12гө чейинки баскычтарды жөнөтүү үчүн:

- Баскычты басып жатканда **fn** (же глобус баскычын) кармаңыз, же
- **Системанын жөндөөлөрү**, андан кийин **Клавиатура**, андан кийин **Клавиатуранын тез баскычтары**, андан кийин **Функциялык баскычтар** ачыңыз жана «F1, F2 ж.б. баскычтарды стандарттуу функциялык баскыч катары колдонуу» дегенди күйгүзүңүз.

Айрым F-баскычтарын macOS өзү да ээлейт (мисалы Mission Control). Эгер баскыч колдонмодо эч нерсе кылбаса, аны fn менен басып көрүңүз же аспаптар тилкесиндеги баскычты колдонуңуз.

## Браузер сактаган тез баскычтар

Веб-барак браузердин кээ бир тез баскычтарын, колдонмо эмне кылса дагы, ала албайт. Ар бир колдонмодо:

- {{key:Mod+N}}, {{key:Mod+T}} жана {{key:Mod+W}} ар дайым браузердин терезелерин жана өтмөктөрүн ачат же жабат. Колдонмолор Жаңы жана Жабуу үчүн баскычтарды колдонот.
- Mac'та {{key:Mod+Q}} жана Windows'та {{key:Alt+F4}} браузерди жабат. Сактабаган ишиңиз болсо, браузер алгач сурайт («Баракты таштайсызбы?»); калуу үчүн тандап, андан кийин сактаңыз.
- Браузердин өз толук экраны ({{pick:mac=Control-Command-F, терезедеги жашыл баскыч|windows linux=F11}}) иштей берет. Колдонмолордун да өз экран режимдери бар, алар {{key:Ctrl+Shift+F}} менен күйгүзүлөт жана колдонмонун тилкелерин да жашыра алат.

## Сенсордук панелдеги чычкан баскычтары

Колдонмолор оң жана ортоңку баскычты колдонот. Үч баскычтуу чычкан болбосо:

:::mac
- **Оң чыкылдатуу:** эки манжа менен басыңыз. Эки манжалуу басуу иштебесе, **Системанын жөндөөлөрү**, андан кийин **Сенсордук панель** ичинен «Экинчи чыкылдатуу» дегенди күйгүзүңүз. {{key:Ctrl}} басып чыкылдатуу браузердин менюсун ачат, бирок чийменин ичинде кээ бир колдонмолор муну кадимки чыкылдатуу катары окуйт (Control басылган абалда), ошондуктан эки манжалуу басууну тандаңыз.
- **Ортоңку баскыч менен сүйрөө (жылдыруу):** ар бир колдонмо жылдырыштын башка жолун сунуштайт, мисалы {{key:Space}} басып туруп сүйрөө же оң баскыч менен сүйрөө. Колдонмонун баскычтар барагы кайсынысы экенин айтат.
- **Дөңгөлөк менен чоңойтуу:** сенсордук панелде эки манжа менен сыпыруу көпчүлүк колдонмодо чоңойтат. Колдоого алса, чымчып басуу да чоңойтат.
:::

:::windows linux
- **Оң чыкылдатуу:** эки манжа менен басыңыз же сенсордук панелдин төмөнкү оң бурчун басыңыз. Бул сенсордук панелдин жөндөөлөрүнө жараша болот.
- **Ортоңку баскыч менен сүйрөө (жылдыруу):** ар бир колдонмо жылдырыштын башка жолун сунуштайт, мисалы {{key:Space}} басып туруп сүйрөө же оң баскыч менен сүйрөө. Колдонмонун баскычтар барагы кайсынысы экенин айтат.
- **Дөңгөлөк менен чоңойтуу:** сенсордук панелде эки манжа менен сыпыруу көпчүлүк колдонмодо чоңойтат.
:::

## Текст кутусуна терүү

Кутуга (аты, эскертүү, издөө) терип жатканыңызда колдонмонун бир тамгалуу тез баскычтары өчүп турат, ошондуктан «L» терсеңиз, L тамгасы жазылат. Баскычтарды колдонмого кайтаруу үчүн {{key:Esc}} басыңыз же чийменин үстүн чыкылдатыңыз.

Հավելվածները աշխատում են վեբ դիտարկչի ներսում։ Դրանք աշխատանքը կատարում են ձեր սեփական համակարգչում․ ձեր ֆայլերը բացվում են այնտեղ և երբեք չեն ուղարկվում մեզ (տես [Ուր են գնում ձեր ֆայլերը](common:your-files))։

## Ո՞ր դիտարկիչը

Օգտագործեք այս դիտարկիչներից մեկի թարմ տարբերակը.

| Դիտարկիչ | Շարժիչ | Նշումներ |
|---|---|---|
| Chrome, Edge, Brave, Opera, Vivaldi | Chromium | Ամենալիարժեքը՝ թղթապանակի ընտրություն, անցանց օգտագործման համար պահում, ֆայլերի մշակում։ |
| Firefox | Gecko | Աշխատում է։ Ամբողջ թղթապանակը բացելու համար օգտագործվում է ավելի պարզ ընտրիչ։ Անցանց պահումը կարող է չաշխատել մասնավոր պատուհաններում։ |
| Safari | WebKit | Աշխատում է Mac-ում և iPad-ում։ Ամբողջ թղթապանակը բացելու համար օգտագործվում է ավելի պարզ ընտրիչ։ Safari-ն կարող է ջնջել անցանց պատճենը, որն ըստ ձեզ մի քանի շաբաթ չի օգտագործվել։ |

Երեք շարժիչներն էլ հարմար են առօրյա աշխատանքի համար։ Եթե հավելվածը որևէ բան այլ կերպ է անում դրանցից մեկում, նրա օգնությունը ցույց է տալիս քայլերը ձեր դիտարկիչի համար։

## Ինչով են դիտարկիչները տարբերվում

- **Թղթապանակը բացելը։** Chromium դիտարկիչները ցույց են տալիս իսկական թղթապանակի ընտրիչ և կարող են թղթապանակը ուղիղ կարդալ։ Firefox-ը և Safari-ն խնդրում են ընտրել թղթապանակ, ապա կարդում են դրա բոլոր ֆայլերը, ինչը մեծ նախագծային թղթապանակների դեպքում ավելի երկար է տևում․ թղթապանակը հավելվածի վրա քաշելը աշխատում է բոլոր երեքում։
- **Պահելը։** Հավելվածները պահում են ֆայլը ներբեռնելով։ Ձեր դիտարկիչը որոշում է, թե ներբեռնումները որտեղ գնան և արդյոք նախ հարցնի։

:::chromium
Chrome-ում կամ Edge-ում միացրեք «Ask where to save each file before downloading» (Settings-ում, Downloads-ի տակ)՝ յուրաքանչյուր անգամ թղթապանակ ընտրելու համար։
:::

:::firefox
Firefox-ում բացեք Settings, ապա General, ապա Downloads, և ընտրեք "Always ask you where to save files"՝ յուրաքանչյուր անգամ թղթապանակ ընտրելու համար։
:::

:::safari
Safari-ում բացեք Settings, ապա General, և "File download location"-ը դրեք "Ask for each download"՝ յուրաքանչյուր անգամ թղթապանակ ընտրելու համար։
:::

## Mac, Windows և Linux

Հավելվածները նույնն են բոլոր համակարգիչներում։ Փոխվում է ստեղնաշարը․ դյուրանցումները ավտոմատ գրվում են ձեր համակարգչի համար։ Տես [Ստեղներ, մկներ և թրեքփեդներ](common:keys)։

## Պլանշետներ և հպող էկրաններ

Որոշ հավելվածներ ընդունում են հպում (մեկ մատը գծում կամ ընտրում է, երկու մատով կծկել-բացելը մասշտաբավորում և տեղաշարժում է)։ Յուրաքանչյուր հավելվածի օգնությունը ասում է, արդյոք այն դա անում է։ iPad-ում օգտագործեք Safari-ն կամ Chrome-ը։ Ստեղնաշարը օգնում է այն հավելվածներում, որոնք օգտագործում են մուտքագրվող հրամաններ։

## Ամենահին դիտարկիչն ու համակարգը

Սրանք կարդացվել են 0.7 հավելվածների կոդից, ոչ թե ենթադրությունից. յուրաքանչյուր ֆայլ վերլուծվել է, և նրա օգտագործած լեզվական յուրաքանչյուր հատկություն ստուգվել է դիտարկիչների հրապարակված համատեղելիության տվյալներում։ Այս տարբերակներից ցածր հավելվածները չեն կարող նույնիսկ սկսել, քանի որ դիտարկիչը կոդը չի հասկանում։

| | Ամենահին տարբերակը, որի վրա հավելվածները կարող են սկսել |
|---|---|
| Chrome, Edge, Brave, Opera, Vivaldi | Chromium 94 |
| Firefox | 93 |
| Safari (Mac, iPad, iPhone) | 16.4 (macOS 13.3, iPadOS և iOS 16.4) |

CadCraft Studio-ն Windows-ում ունի սեփական վեբ շարժիչ, ուստի պահանջում է Windows 10 կամ 11․ Mac-ում այն օգտագործում է համակարգի շարժիչը, ուստի պահանջում է macOS 13.3 կամ ավելի նոր։ Studio-ի {{ui:Կարգավորումներ}} › Թարմացումներ բաժինը ցույց է տալիս, թե ինչի վրա է աշխատում ձեր տարբերակը։

Սա այն ամենահին տարբերակն է, որը *սկսվում է*, կարդացված կոդից․ սա ցանկ չէ այն հին դիտարկիչների, որոնց վրա մենք փորձարկել ենք հավելվածները, ուստի ավելի հին, բայց սկսող դիտարկիչից կարող է բացակայել որևէ հատկություն։

## Ինչ է պետք ձեր համակարգչին

Սրանք հավելվածների նախատեսված նվազագույն պահանջներն են, ոչ թե չափված պահանջներ․

- 8 GB հիշողություն (մեծ համադաշնային մոդելների համար խորհուրդ է տրվում 16 GB)։
- WebGL 2-ով գրաֆիկական չիպ 3D հավելվածների համար։ Եթե 3D տեսքը դատարկ է մնում, ստուգեք, որ ապարատային արագացումը միացված է ձեր դիտարկիչի կարգավորումներում։
- Առնվազն 1280 պիքսել լայնությամբ էկրան՝ գործիքագոտիները ամբողջությամբ տեսնելու համար. փոքր էկրաններում դրանք փաթաթվում են։

Շատ մեծ ֆայլերը (մեծ հատակագծային հավաքածուներ, մեծ մոդելներ) շատ հիշողություն են օգտագործում դիտարկիչի ներդիրում։ Փակեք մյուս ծանր ներդիրները, եթե հավելվածը դանդաղում է։

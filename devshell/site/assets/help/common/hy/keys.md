## Ինչպես են գրվում դյուրանցումները

Օգնությունը յուրաքանչյուր դյուրանցում գրում է այնպես, ինչպես ձեր ստեղնաշարն է այն նշում։

| Գրված | Mac-ում | Windows-ում և Linux-ում |
|---|---|---|
| {{key:Mod+S}} | Command (⌘) և S | Ctrl և S |
| {{key:Ctrl+Shift+F}} | Control (⌃), Shift (⇧) և F | Ctrl, Shift և F |
| {{key:Alt+Left}} | Option (⌥) և ← | Alt և ← |
| {{key:Backspace}} | Delete ստեղնը | Backspace |
| {{key:Delete}} | fn և Delete (առաջ ջնջում) | Delete |
| {{key:Enter}} | Return | Enter |

Գումարած նշանը նշանակում է պահել ստեղները միասին։ «Հետո»-ն նշանակում է սեղմել մեկը մյուսից հետո։

Հավելվածների դյուրանցումների մեծ մասը Mac-ում ընդունում է կամ Command, կամ Control, ուստի {{key:Mod+Z}}-ը աշխատում է երկու ձևով։ Մի քանիսը, ինչպես լիաէկրան ռեժիմը ({{key:Ctrl+Shift+F}}), բոլոր համակարգիչներում օգտագործում են Control ստեղնը. օգնությունը ասում է դա այնտեղ, որտեղ կիրառվում է։

## Ֆունկցիոնալ ստեղներ Mac-ում

Mac-ի մեծամասնության ստեղնաշարերում վերևի շարքը փոխում է պայծառությունը, ձայնը և մեդիան։ F1-ից F12 ուղարկելու համար՝

- պահեք **fn** (կամ գլոբուս ստեղնը) միաժամանակ ստեղնը սեղմելիս, կամ
- բացեք **System Settings**, ապա **Keyboard**, ապա **Keyboard Shortcuts**, ապա **Function Keys**, և միացրեք "Use F1, F2, etc. keys as standard function keys" տարբերակը։

Որոշ F-ստեղներ նաև զբաղեցված են macOS-ի կողմից (օրինակ՝ Mission Control)։ Եթե ստեղնը հավելվածում ոչինչ չի անում, փորձեք այն fn-ով կամ օգտագործեք գործիքագոտու կոճակը։

## Դյուրանցումներ, որ պահում է դիտարկիչը

Վեբ էջը չի կարող վերցնել որոշ դյուրանցումներ դիտարկիչից, ինչ էլ որ անի. բոլոր հավելվածներում՝

- {{key:Mod+N}}, {{key:Mod+T}} և {{key:Mod+W}}-ը միշտ բացում կամ փակում են դիտարկիչի պատուհաններն ու ներդիրները։ Հավելվածները փոխարենը օգտագործում են կոճակներ՝ Նոր և Փակել։
- Mac-ում {{key:Mod+Q}}-ը և Windows-ում {{key:Alt+F4}}-ը դուրս են բերում դիտարկիչից։ Եթե ունեք չպահված աշխատանք, դիտարկիչը նախ հարցնում է («Leave site?»)․ ընտրեք մնալ, ապա պահեք։
- Դիտարկիչի սեփական լիաէկրան ռեժիմը ({{pick:mac=Control-Command-F, կամ պատուհանի կանաչ կոճակը|windows linux=F11}}) դեռ աշխատում է։ Հավելվածներն ունեն նաև սեփական էկրանի ռեժիմներ {{key:Ctrl+Shift+F}}-ով, որոնք կարող են թաքցնել նաև հավելվածի գոտիները։

## Մկնիկի կոճակները թրեքփեդով

Հավելվածները օգտագործում են աջ և միջին կոճակները. առանց երեք կոճակով մկնիկի՝

:::mac
- **Աջ սեղմում։** սեղմեք երկու մատով։ Եթե երկու մատի սեղմումը ոչինչ չի անում, միացրեք "Secondary click"-ը **System Settings**-ում, ապա **Trackpad**-ում։ {{key:Ctrl}}-ը պահելով սեղմելը բացում է դիտարկիչի ընտրացանկը, բայց գծագրի ներսում որոշ հավելվածներ այն կարդում են որպես սովորական սեղմում (Control պահած), ուստի նախընտրեք երկու մատի սեղմումը։
- **Միջին կոճակով քաշելը (տեղաշարժ)։** յուրաքանչյուր հավելված առաջարկում է տեղաշարժի այլ եղանակ, օրինակ՝ {{key:Space}}-ը պահելով քաշելը կամ աջ կոճակով քաշելը։ Հավելվածի ստեղնաշարի էջը ասում է, թե որը։
- **Անիվով մասշտաբավորում։** թրեքփեդի վրա երկու մատով ոլորումը մասշտաբավորում է հավելվածների մեծ մասում։ Կծկել-բացելը նույնպես մասշտաբավորում է, որտեղ հավելվածն աջակցում է դրան։
:::

:::windows linux
- **Աջ սեղմում։** սեղմեք երկու մատով կամ թրեքփեդի ներքևի աջ անկյունը։ Սա կախված է ձեր թրեքփեդի կարգավորումներից։
- **Միջին կոճակով քաշելը (տեղաշարժ)։** յուրաքանչյուր հավելված առաջարկում է տեղաշարժի այլ եղանակ, օրինակ՝ {{key:Space}}-ը պահելով քաշելը կամ աջ կոճակով քաշելը։ Հավելվածի ստեղնաշարի էջը ասում է, թե որը։
- **Անիվով մասշտաբավորում։** թրեքփեդի վրա երկու մատով ոլորումը մասշտաբավորում է հավելվածների մեծ մասում։
:::

## Տեքստ մուտքագրելը տուփում

Երբ տուփում եք մուտքագրում (անուն, նշում, որոնում), հավելվածի մեկ տառանոց դյուրանցումները անջատված են, ուստի "L" մուտքագրելը գրում է L։ Սեղմեք {{key:Esc}} կամ սեղմեք գծագրի վրա՝ ստեղները նորից հավելվածին տալու համար։

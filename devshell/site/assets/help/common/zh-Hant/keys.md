## 快速鍵的寫法

說明會依鍵盤上的標示來書寫每個快速鍵。

| 寫法 | 在 Mac 上 | 在 Windows 與 Linux 上 |
|---|---|---|
| {{key:Mod+S}} | Command (⌘) 與 S | Ctrl 與 S |
| {{key:Ctrl+Shift+F}} | Control (⌃)、Shift (⇧) 與 F | Ctrl、Shift 與 F |
| {{key:Alt+Left}} | Option (⌥) 與 ← | Alt 與 ← |
| {{key:Backspace}} | Delete 鍵 | Backspace |
| {{key:Delete}} | fn 與 Delete（向後刪除） | Delete |
| {{key:Enter}} | Return | Enter |

加號表示同時按住這些按鍵。「再」表示依序按下。

多數應用程式快速鍵在 Mac 上可用 Command 或 Control，所以{{key:Mod+Z}}兩種方式都有效。少數快速鍵（例如全螢幕{{key:Ctrl+Shift+F}}）在所有電腦上都使用 Control 鍵；適用時說明會特別指出。

## Mac 上的功能鍵

多數 Mac 鍵盤最上排的按鍵用來調整亮度、音量與媒體播放。若要送出 F1 到 F12：

- 按鍵時同時按住 **fn**（或地球儀鍵），或
- 開啟**系統設定**，依序選擇**鍵盤**、**鍵盤快速鍵**、**功能鍵**，然後開啟「將 F1、F2 等鍵用作標準功能鍵」。

有些功能鍵也被 macOS 本身占用（例如 Mission Control）。若某個按鍵在應用程式中沒有反應，請搭配 fn 試試，或改用工具列按鈕。

## 瀏覽器保留的快速鍵

網頁無法從瀏覽器手中拿走某些快速鍵，不論網頁怎麼做。在每個應用程式中：

- {{key:Mod+N}}、{{key:Mod+T}}與{{key:Mod+W}}一律會開啟或關閉瀏覽器視窗與索引標籤。應用程式改用按鈕來執行「新增」與「關閉」。
- Mac 上的{{key:Mod+Q}}與 Windows 上的{{key:Alt+F4}}會結束瀏覽器。若有尚未儲存的內容，瀏覽器會先詢問（「要離開網站嗎？」）；請選擇留下，然後儲存。
- 瀏覽器本身的全螢幕（{{pick:mac=Control-Command-F，或視窗上的綠色按鈕|windows linux=F11}}）仍然有效。應用程式也有自己的螢幕模式，使用{{key:Ctrl+Shift+F}}，可連應用程式的工具列一併隱藏。

## 觸控板上的滑鼠按鈕

應用程式會用到右鍵與中鍵。沒有三鍵滑鼠時：

:::mac
- **按右鍵：**用兩指點按。若兩指點按沒有反應，請在**系統設定**的**觸控板**中開啟「輔助按一下」。按住{{key:Ctrl}}再點按會開啟瀏覽器的選單，但在圖形內，有些應用程式會把它當成一般點按（同時按著 Control），所以建議使用兩指點按。
- **中鍵拖曳（平移）：**每個應用程式都提供另一種平移方式，例如拖曳時按住{{key:Space}}，或用右鍵拖曳。該應用程式的鍵盤頁面會說明是哪一種。
- **滾輪縮放：**在多數應用程式中，於觸控板上用兩指捲動即可縮放。應用程式支援時，也可用兩指張合縮放。
:::

:::windows linux
- **按右鍵：**用兩指點按，或點按觸控板的右下角。實際情況取決於觸控板設定。
- **中鍵拖曳（平移）：**每個應用程式都提供另一種平移方式，例如拖曳時按住{{key:Space}}，或用右鍵拖曳。該應用程式的鍵盤頁面會說明是哪一種。
- **滾輪縮放：**在多數應用程式中，於觸控板上用兩指捲動即可縮放。
:::

## 在文字方塊中輸入

在方塊（名稱、附註、搜尋）中輸入時，應用程式的單字母快速鍵會暫時停用，所以輸入「L」就是輸入字母 L。按{{key:Esc}}或在圖形上按一下，即可把按鍵還給應用程式。

每個應用程式都附有自己的說明。說明是應用程式的一部分，所以不需要網路連線也能開啟，而且描述的一定是正在執行的版本。

## 開啟說明

- 按{{key:F1}}，或選擇應用程式最上方列中的{{ui:說明}}。
- 按{{key:Esc}}或選擇{{ui:關閉}}即可收起說明。圖形維持原樣。

:::mac
多數 Mac 鍵盤最上排的按鍵用來控制亮度和音量。請同時按{{key:F1}}與 **fn** 鍵（或地球儀鍵），或使用{{ui:說明}}按鈕。請見[Mac 上的按鍵](common:keys#function-keys-on-a-mac)。
:::

## 尋找主題

- 在說明最上方的搜尋方塊中輸入文字。結果會隨輸入即時更新，也包含其他程式的指令名稱，所以輸入在別處慣用的指令，通常就能找到對應的頁面。
- 每個應用程式的主題都以相同方式分組：入門、逐步教學、從其他軟體轉換、參考資料，以及疑難排解。
- 主題內的連結會在同一個面板中開啟下一個主題。{{ui:返回}}可回到先前的位置。

## 適合所用電腦的步驟

有些步驟會因 Mac、Windows 與 Linux 的不同、瀏覽器的不同，以及線上或離線而有差異。說明會判斷哪一種適用，並顯示對應的步驟。主題最上方的一行會說明它的選擇，例如「顯示 Mac、Chrome 或 Edge、線上的步驟」。

- 選擇該行的{{ui:變更}}可改選其他電腦或瀏覽器，例如要協助同事時。
- 選擇{{ui:全部顯示}}可看到每個步驟的所有版本，並各自附上標示。

鍵盤快速鍵會依鍵盤上的標示來書寫：{{key:Mod+S}}在 Mac 上顯示為 ⌘S，在 Windows 與 Linux 上則為 Ctrl+S。

## 網站上的相同說明

網站在 getcadcraft.com/tutorials 提供相同的主題，並附上各平台的步驟。在應用程式中，連線時選擇主題底部的{{ui:在網站上開啟}}即可開啟該頁面。

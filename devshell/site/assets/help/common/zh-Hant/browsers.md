應用程式在網頁瀏覽器中執行。它們在自己的電腦上完成工作：檔案在那裡開啟，不會傳送給我們（請見[檔案去了哪裡](common:your-files)）。

## 使用哪種瀏覽器

請使用下列其中一種瀏覽器的最新版本：

| 瀏覽器 | 引擎 | 備註 |
|---|---|---|
| Chrome、Edge、Brave、Opera、Vivaldi | Chromium | 功能最完整：可選取資料夾、儲存供離線使用、檔案處理。 |
| Firefox | Gecko | 可使用。開啟整個資料夾時使用較簡單的選取器。在私密視窗中可能無法離線儲存。 |
| Safari | WebKit | 可在 Mac 與 iPad 上使用。開啟整個資料夾時使用較簡單的選取器。Safari 可能會刪除數週未使用的離線複本。 |

三種引擎都適合日常作業。若應用程式在其中某一種引擎上的做法不同，它的說明會顯示適用於所用瀏覽器的步驟。

## 瀏覽器之間的差異

- **開啟資料夾。**Chromium 系瀏覽器會顯示真正的資料夾選取器，並能直接讀取資料夾。Firefox 與 Safari 會要求選擇資料夾，然後讀取其中的每個檔案，對大型專案資料夾來說比較費時；把資料夾拖曳到應用程式上，在三種瀏覽器中都可行。
- **儲存。**應用程式以下載檔案的方式儲存。下載內容放在哪裡、是否先詢問，由瀏覽器決定。

:::chromium
在 Chrome 或 Edge 中，開啟「下載前詢問每個檔案的儲存位置」（位於設定的「下載」之下），即可每次選擇資料夾。
:::

:::firefox
在 Firefox 中，開啟設定，再選擇「一般」，然後在「下載」中選擇「一律詢問儲存檔案的位置」，即可每次選擇資料夾。
:::

:::safari
在 Safari 中，開啟設定，再選擇「一般」，並將「檔案下載位置」設為「每次下載都詢問」，即可每次選擇資料夾。
:::

## Mac、Windows 與 Linux

應用程式在每種電腦上都相同。會變的是鍵盤：快速鍵會自動依所用的電腦書寫。請見[按鍵、滑鼠與觸控板](common:keys)。

## 平板與觸控螢幕

有些應用程式支援觸控（一指繪圖或選取，兩指張合縮放與平移）。每個應用程式的說明會寫明是否支援。在 iPad 上請使用 Safari 或 Chrome。對於使用輸入指令的應用程式，搭配鍵盤會有幫助。

## 最舊的瀏覽器與系統

下列資料取自 0.7 版應用程式的程式碼，而不是憑猜測：我們解析了每個檔案，並對照瀏覽器公開的相容性資料，查出它用到的每項語言功能。低於這些版本時，瀏覽器看不懂程式碼，應用程式連啟動都做不到。

| | 可啟動應用程式的最舊版本 |
|---|---|
| Chrome、Edge、Brave、Opera、Vivaldi | Chromium 94 |
| Firefox | 93 |
| Safari（Mac、iPad、iPhone） | 16.4（macOS 13.3、iPadOS 與 iOS 16.4） |

CadCraft Studio 在 Windows 上自帶網頁引擎，所以需要 Windows 10 或 11；在 Mac 上則使用系統內建的引擎，所以需要 macOS 13.3 或更新版本。Studio 中的「設定」›「更新」會顯示這份複本執行於什麼之上。

這是從程式碼判讀出的、能「啟動」的最舊版本。它並不是我們實際執行過應用程式的舊版瀏覽器清單，因此能啟動的較舊瀏覽器仍可能缺少某些功能。

## 電腦需要什麼

這些是應用程式規劃的最低需求，不是實測的需求：

- 8 GB 記憶體（處理大型聯合模型建議 16 GB）。
- 3D 應用程式需要支援 WebGL 2 的顯示晶片。若 3D 檢視一直是空白，請檢查瀏覽器設定中的硬體加速是否已開啟。
- 螢幕寬度至少 1280 像素才能顯示完整的工具列；較小的螢幕會讓工具列換行。

非常大的檔案（大型圖紙集、大型模型）會在瀏覽器分頁中占用大量記憶體。若應用程式變慢，請關閉其他耗資源的分頁。

ທຸກແອັບມີຄູ່ມືຂອງຕົນເອງ. ມັນເປັນສ່ວນໜຶ່ງຂອງແອັບ, ດັ່ງນັ້ນມັນເປີດໄດ້ໂດຍບໍ່ມີການເຊື່ອມຕໍ່ ແລະ ອະທິບາຍເວີຊັນທີ່ທ່ານກຳລັງໃຊ້ຢູ່ສະເໝີ.

## ເປີດຄູ່ມື

- ກົດ {{key:F1}}, ຫຼື ເລືອກ {{ui:ຊ່ວຍເຫຼືອ}} ໃນແຖບດ້ານເທິງຂອງແອັບ.
- ກົດ {{key:Esc}} ຫຼື ເລືອກ {{ui:ປິດ}} ເພື່ອເກັບມັນໄວ້. ແບບແຕ້ມຂອງທ່ານຈະຢູ່ຄືເກົ່າ.

:::mac
ຢູ່ແປ້ນພິມ Mac ສ່ວນໃຫຍ່, ແຖວເທິງຄວບຄຸມຄວາມສະຫວ່າງ ແລະ ສຽງ. ກົດ {{key:F1}} ພ້ອມກັບປຸ່ມ **fn** (ຫຼື ປຸ່ມ globe), ຫຼື ໃຊ້ປຸ່ມ {{ui:ຊ່ວຍເຫຼືອ}}. ເບິ່ງ [ປຸ່ມຢູ່ Mac](common:keys#function-keys-on-a-mac).
:::

## ຊອກຫາຫົວຂໍ້

- ພິມໃນກ່ອງຄົ້ນຫາຢູ່ດ້ານເທິງຂອງຄູ່ມື. ຜົນລັບຈະອັບເດດຂະນະທີ່ທ່ານພິມ ແລະ ລວມເຖິງຊື່ຄຳສັ່ງຂອງໂປຣແກຣມອື່ນ, ດັ່ງນັ້ນການພິມສິ່ງທີ່ທ່ານຈະພິມຢູ່ບ່ອນອື່ນມັກຈະພົບໜ້າທີ່ຖືກຕ້ອງ.
- ຫົວຂໍ້ຖືກຈັດກຸ່ມແບບດຽວກັນໃນທຸກແອັບ: ການເລີ່ມຕົ້ນ, ບົດສອນ, ການມາຈາກຊອບແວອື່ນ, ເອກະສານອ້າງອີງ ແລະ ການແກ້ໄຂບັນຫາ.
- ລິ້ງພາຍໃນຫົວຂໍ້ຈະເປີດຫົວຂໍ້ຕໍ່ໄປໃນແຜງດຽວກັນ. {{ui:ກັບ}} ຈະພາທ່ານກັບໄປບ່ອນທີ່ທ່ານຢູ່.

## ຂັ້ນຕອນສຳລັບຄອມພິວເຕີຂອງທ່ານ

ບາງຂັ້ນຕອນແຕກຕ່າງກັນລະຫວ່າງ Mac, Windows ແລະ Linux, ລະຫວ່າງບຣາວເຊີ, ແລະ ລະຫວ່າງການອອນລາຍ ແລະ ອອບໄລນ໌. ຄູ່ມືຈະຄິດວ່າອັນໃດໃຊ້ກັບທ່ານ ແລະ ສະແດງຂັ້ນຕອນເຫຼົ່ານັ້ນ. ແຖວເທິງສຸດຂອງຫົວຂໍ້ບອກສິ່ງທີ່ມັນເລືອກ, ຕົວຢ່າງ "ກຳລັງສະແດງຂັ້ນຕອນສຳລັບ Mac, Chrome ຫຼື Edge, ອອນລາຍ".

- ເລືອກ {{ui:ປ່ຽນ}} ໃນແຖວນັ້ນເພື່ອເລືອກຄອມພິວເຕີ ຫຼື ບຣາວເຊີອື່ນ, ຕົວຢ່າງເພື່ອຊ່ວຍເພື່ອນຮ່ວມງານ.
- ເລືອກ {{ui:ສະແດງທັງໝົດ}} ເພື່ອເບິ່ງທຸກເວີຊັນຂອງທຸກຂັ້ນຕອນ, ແຕ່ລະອັນມີປ້າຍຊື່ກຳກັບ.

ປຸ່ມລັດຖືກຂຽນຕາມທີ່ແປ້ນພິມຂອງທ່ານຕິດປ້າຍໄວ້: {{key:Mod+S}} ອ່ານວ່າ ⌘S ຢູ່ Mac ແລະ Ctrl+S ຢູ່ Windows ແລະ Linux.

## ຄູ່ມືດຽວກັນໃນເວັບໄຊ

ເວັບໄຊສະແດງຫົວຂໍ້ດຽວກັນທີ່ getcadcraft.com/tutorials, ພ້ອມຂັ້ນຕອນຂອງທຸກແພລດຟອມ. ໃນແອັບ, {{ui:ເປີດໃນເວັບໄຊ}} ຢູ່ລຸ່ມຂອງຫົວຂໍ້ຈະເປີດໜ້ານັ້ນເມື່ອທ່ານອອນລາຍ.

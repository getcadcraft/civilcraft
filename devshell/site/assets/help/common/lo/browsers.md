ແອັບແລ່ນຢູ່ໃນບຣາວເຊີເວັບ. ມັນເຮັດວຽກຢູ່ໃນຄອມພິວເຕີຂອງທ່ານເອງ: ໄຟລ໌ຂອງທ່ານຖືກເປີດຢູ່ທີ່ນັ້ນ ແລະ ບໍ່ເຄີຍຖືກສົ່ງໄປຫາພວກເຮົາ (ເບິ່ງ [ໄຟລ໌ຂອງທ່ານໄປໃສ](common:your-files)).

## ບຣາວເຊີໃດ

ໃຊ້ເວີຊັນທີ່ອັບເດດແລ້ວຂອງໜຶ່ງໃນເຫຼົ່ານີ້:

| ບຣາວເຊີ | ເອນຈິນ | ໝາຍເຫດ |
|---|---|---|
| Chrome, Edge, Brave, Opera, Vivaldi | Chromium | ສົມບູນທີ່ສຸດ: ການເລືອກໂຟນເດີ, ການບັນທຶກເພື່ອໃຊ້ແບບອອບໄລນ໌, ການຈັດການໄຟລ໌. |
| Firefox | Gecko | ໃຊ້ໄດ້. ການເປີດໂຟນເດີທັງໝົດໃຊ້ຕົວເລືອກທີ່ງ່າຍກວ່າ. ການບັນທຶກແບບອອບໄລນ໌ອາດບໍ່ເຮັດວຽກໃນໜ້າຕ່າງສ່ວນຕົວ. |
| Safari | WebKit | ໃຊ້ໄດ້ຢູ່ Mac ແລະ iPad. ການເປີດໂຟນເດີທັງໝົດໃຊ້ຕົວເລືອກທີ່ງ່າຍກວ່າ. Safari ອາດລຶບສຳເນົາແບບອອບໄລນ໌ທີ່ທ່ານບໍ່ໄດ້ໃຊ້ມາເປັນເວລາຫຼາຍອາທິດ. |

ທັງສາມເອນຈິນໃຊ້ໄດ້ດີສຳລັບການເຮັດວຽກປະຈຳວັນ. ເມື່ອແອັບເຮັດບາງຢ່າງແຕກຕ່າງໃນເອນຈິນໃດໜຶ່ງ, ຄູ່ມືຂອງມັນຈະສະແດງຂັ້ນຕອນສຳລັບບຣາວເຊີຂອງທ່ານ.

## ແຕກຕ່າງກັນແນວໃດລະຫວ່າງບຣາວເຊີ

- **ການເປີດໂຟນເດີ.** ບຣາວເຊີ Chromium ສະແດງຕົວເລືອກໂຟນເດີແທ້ ແລະ ອ່ານໂຟນເດີໄດ້ໂດຍກົງ. Firefox ແລະ Safari ຂໍໃຫ້ທ່ານເລືອກໂຟນເດີ ແລ້ວອ່ານທຸກໄຟລ໌ໃນນັ້ນ, ເຊິ່ງໃຊ້ເວລານານກວ່າສຳລັບໂຟນເດີໂຄງການໃຫຍ່; ການລາກໂຟນເດີໃສ່ແອັບໃຊ້ໄດ້ໃນທັງສາມ.
- **ການບັນທຶກ.** ແອັບບັນທຶກໂດຍການດາວໂຫຼດໄຟລ໌. ບຣາວເຊີຂອງທ່ານເປັນຜູ້ກຳນົດວ່າການດາວໂຫຼດຈະໄປໄວ້ໃສ ແລະ ຈະຖາມກ່ອນຫຼືບໍ່.

:::chromium
ໃນ Chrome ຫຼື Edge, ເປີດ "Ask where to save each file before downloading" (ໃນການຕັ້ງຄ່າ, ພາຍໃຕ້ Downloads) ເພື່ອເລືອກໂຟນເດີທຸກຄັ້ງ.
:::

:::firefox
ໃນ Firefox, ເປີດການຕັ້ງຄ່າ, ແລ້ວ General, ແລ້ວ Downloads, ແລະ ເລືອກ "Always ask you where to save files" ເພື່ອເລືອກໂຟນເດີທຸກຄັ້ງ.
:::

:::safari
ໃນ Safari, ເປີດການຕັ້ງຄ່າ, ແລ້ວ General, ແລະ ຕັ້ງ "File download location" ເປັນ "Ask for each download" ເພື່ອເລືອກໂຟນເດີທຸກຄັ້ງ.
:::

## Mac, Windows ແລະ Linux

ແອັບຄືກັນໃນທຸກຄອມພິວເຕີ. ສິ່ງທີ່ປ່ຽນແປງຄືແປ້ນພິມ: ປຸ່ມລັດຖືກຂຽນສຳລັບຄອມພິວເຕີຂອງທ່ານໂດຍອັດຕະໂນມັດ. ເບິ່ງ [ປຸ່ມ, ເມົ້າ ແລະ ແທັກແພດ](common:keys).

## ແທັບເລັດ ແລະ ໜ້າຈໍສຳຜັດ

ບາງແອັບຮັບການສຳຜັດ (ນິ້ວດຽວແຕ້ມ ຫຼື ເລືອກ, ສອງນິ້ວບີບເພື່ອຊູມ ແລະ ເລື່ອນມຸມມອງ). ຄູ່ມືຂອງແຕ່ລະແອັບບອກວ່າມັນຮັບຫຼືບໍ່. ໃນ iPad, ໃຊ້ Safari ຫຼື Chrome. ແປ້ນພິມຊ່ວຍກັບແອັບທີ່ໃຊ້ຄຳສັ່ງທີ່ພິມ.

## ບຣາວເຊີ ແລະ ລະບົບທີ່ເກົ່າທີ່ສຸດ

ພວກເຮົາອ່ານຂໍ້ມູນເຫຼົ່ານີ້ຈາກໂຄດຂອງແອັບເວີຊັນ 0.7, ບໍ່ແມ່ນຈາກການເດົາ: ທຸກໄຟລ໌ຖືກວິເຄາະ ແລະ ແຕ່ລະຄຸນສົມບັດພາສາທີ່ມັນໃຊ້ຖືກກວດກັບຂໍ້ມູນຄວາມເຂົ້າກັນໄດ້ທີ່ບຣາວເຊີເຜີຍແຜ່. ຕ່ຳກວ່າເວີຊັນເຫຼົ່ານີ້, ແອັບຈະເລີ່ມເຮັດວຽກບໍ່ໄດ້ເລີຍ ເພາະບຣາວເຊີບໍ່ເຂົ້າໃຈໂຄດ.

| | ເວີຊັນທີ່ເກົ່າທີ່ສຸດທີ່ເລີ່ມແອັບໄດ້ |
|---|---|
| Chrome, Edge, Brave, Opera, Vivaldi | Chromium 94 |
| Firefox | 93 |
| Safari (Mac, iPad, iPhone) | 16.4 (macOS 13.3, iPadOS ແລະ iOS 16.4) |

CadCraft Studio ມີເອນຈິນເວັບຂອງມັນເອງຢູ່ Windows, ດັ່ງນັ້ນມັນຕ້ອງການ Windows 10 ຫຼື 11; ຢູ່ Mac ມັນໃຊ້ເອນຈິນຂອງລະບົບ, ດັ່ງນັ້ນມັນຕ້ອງການ macOS 13.3 ຫຼືໃໝ່ກວ່າ. {{ui:ການຕັ້ງຄ່າ}} › {{ui:ການອັບເດດ}} ໃນ Studio ສະແດງວ່າສຳເນົາຂອງທ່ານແລ່ນຢູ່ເທິງຫຍັງ.

ນີ້ແມ່ນເວີຊັນທີ່ເກົ່າທີ່ສຸດທີ່ *ເລີ່ມ* ໄດ້, ອ່ານຈາກໂຄດ. ມັນບໍ່ແມ່ນລາຍຊື່ບຣາວເຊີເກົ່າທີ່ພວກເຮົາເຄີຍທົດສອບແອັບ, ດັ່ງນັ້ນບຣາວເຊີເກົ່າທີ່ເລີ່ມໄດ້ອາດຍັງຂາດຄຸນສົມບັດບາງຢ່າງ.

## ຄອມພິວເຕີຂອງທ່ານຕ້ອງການຫຍັງ

ນີ້ແມ່ນຂັ້ນຕ່ຳທີ່ວາງແຜນໄວ້ສຳລັບແອັບ, ບໍ່ແມ່ນຄວາມຕ້ອງການທີ່ວັດໄດ້:

- ໜ່ວຍຄວາມຈຳ 8 GB (ແນະນຳ 16 GB ສຳລັບໂມເດວລວມທີ່ໃຫຍ່).
- ຊິບກຣາຟິກທີ່ຮອງຮັບ WebGL 2 ສຳລັບແອັບ 3D. ຖ້າມຸມມອງ 3D ວ່າງເປົ່າ, ໃຫ້ກວດວ່າການເລັ່ງດ້ວຍຮາດແວເປີດຢູ່ໃນການຕັ້ງຄ່າບຣາວເຊີຂອງທ່ານ.
- ໜ້າຈໍທີ່ກວ້າງຢ່າງໜ້ອຍ 1280 ພິກເຊວ ສຳລັບແຖບເຄື່ອງມືເຕັມ; ໜ້າຈໍທີ່ນ້ອຍກວ່ານັ້ນຈະຫໍ່ແຖບເຄື່ອງມືລົງ.

ໄຟລ໌ທີ່ໃຫຍ່ຫຼາຍ (ຊຸດແບບແຕ້ມໃຫຍ່, ໂມເດວໃຫຍ່) ໃຊ້ໜ່ວຍຄວາມຈຳຫຼາຍໃນແທັບບຣາວເຊີ. ປິດແທັບອື່ນທີ່ໜັກໆຖ້າແອັບຊ້າລົງ.

## ປຸ່ມລັດຖືກຂຽນແນວໃດ

ຄູ່ມືຂຽນແຕ່ລະປຸ່ມລັດຕາມທີ່ແປ້ນພິມຂອງທ່ານຕິດປ້າຍໄວ້.

| ຂຽນເປັນ | ຢູ່ Mac | ຢູ່ Windows ແລະ Linux |
|---|---|---|
| {{key:Mod+S}} | Command (⌘) ແລະ S | Ctrl ແລະ S |
| {{key:Ctrl+Shift+F}} | Control (⌃), Shift (⇧) ແລະ F | Ctrl, Shift ແລະ F |
| {{key:Alt+Left}} | Option (⌥) ແລະ ← | Alt ແລະ ← |
| {{key:Backspace}} | ປຸ່ມ Delete | Backspace |
| {{key:Delete}} | fn ແລະ Delete (ລຶບໄປທາງໜ້າ) | Delete |
| {{key:Enter}} | Return | Enter |

ເຄື່ອງໝາຍບວກໝາຍຄວາມວ່າກົດປຸ່ມພ້ອມກັນ. ຄຳວ່າ "Then" ໝາຍຄວາມວ່າກົດປຸ່ມທີລະອັນຕາມລຳດັບ.

ປຸ່ມລັດຂອງແອັບສ່ວນໃຫຍ່ຮັບ Command ຫຼື Control ໄດ້ທັງໃນ Mac, ດັ່ງນັ້ນ {{key:Mod+Z}} ໃຊ້ໄດ້ທັງສອງວິທີ. ບາງອັນ, ເຊັ່ນເຕັມຈໍ ({{key:Ctrl+Shift+F}}), ໃຊ້ປຸ່ມ Control ໃນທຸກຄອມພິວເຕີ; ຄູ່ມືບອກເມື່ອສິ່ງນັ້ນໃຊ້ໄດ້.

## ປຸ່ມຟັງຊັນຢູ່ Mac

ຢູ່ແປ້ນພິມ Mac ສ່ວນໃຫຍ່, ແຖວເທິງປ່ຽນຄວາມສະຫວ່າງ, ສຽງ ແລະ ສື່. ເພື່ອສົ່ງ F1 ເຖິງ F12:

- ກົດປຸ່ມ **fn** (ຫຼື ປຸ່ມ globe) ຄ້າງໄວ້ໃນຂະນະທີ່ທ່ານກົດປຸ່ມນັ້ນ, ຫຼື
- ເປີດ **System Settings**, ແລ້ວ **Keyboard**, ແລ້ວ **Keyboard Shortcuts**, ແລ້ວ **Function Keys**, ແລະ ເປີດ "Use F1, F2, etc. keys as standard function keys".

ປຸ່ມ F ບາງອັນຖືກ macOS ເອງຈັບໄວ້ (ຕົວຢ່າງ Mission Control). ຖ້າປຸ່ມບໍ່ເຮັດຫຍັງໃນແອັບ, ລອງໃຊ້ກັບ fn, ຫຼື ໃຊ້ປຸ່ມແຖບເຄື່ອງມືແທນ.

## ທາງລັດທີ່ບຣາວເຊີເກັບໄວ້

ໜ້າເວັບບໍ່ສາມາດເອົາທາງລັດບາງອັນຈາກບຣາວເຊີໄດ້, ບໍ່ວ່າມັນຈະເຮັດຫຍັງ. ໃນທຸກແອັບ:

- {{key:Mod+N}}, {{key:Mod+T}} ແລະ {{key:Mod+W}} ຈະເປີດ ຫຼື ປິດໜ້າຕ່າງ ແລະ ແທັບຂອງບຣາວເຊີສະເໝີ. ແອັບໃຊ້ປຸ່ມ ໃໝ່ ແລະ ປິດ ແທນ.
- {{key:Mod+Q}} ຢູ່ Mac ແລະ {{key:Alt+F4}} ຢູ່ Windows ຈະອອກຈາກບຣາວເຊີ. ຖ້າທ່ານມີວຽກທີ່ຍັງບໍ່ໄດ້ບັນທຶກ, ບຣາວເຊີຈະຖາມກ່ອນ ("ອອກຈາກເວັບໄຊ?"); ເລືອກຢູ່ຕໍ່, ແລ້ວບັນທຶກ.
- ໂໝດເຕັມຈໍຂອງບຣາວເຊີເອງ ({{pick:mac=Control-Command-F, ຫຼື ປຸ່ມສີຂຽວຢູ່ໜ້າຕ່າງ|windows linux=F11}}) ຍັງໃຊ້ໄດ້. ແອັບຍັງມີໂໝດຈໍຂອງຕົນເອງທີ່ {{key:Ctrl+Shift+F}}, ເຊິ່ງອາດຊ່ອນແຖບຂອງແອັບນຳ.

## ປຸ່ມເມົ້າຢູ່ແທັກແພດ

ແອັບໃຊ້ປຸ່ມຂວາ ແລະ ປຸ່ມກາງ. ຖ້າບໍ່ມີເມົ້າສາມປຸ່ມ:

:::mac
- **ຄລິກຂວາ:** ຄລິກດ້ວຍສອງນິ້ວ. ເປີດ "Secondary click" ໃນ **System Settings**, ແລ້ວ **Trackpad**, ຖ້າການຄລິກສອງນິ້ວບໍ່ເຮັດຫຍັງ. ການກົດ {{key:Ctrl}} ຄ້າງໄວ້ໃນຂະນະທີ່ຄລິກຈະເປີດເມນູຂອງບຣາວເຊີ, ແຕ່ພາຍໃນແບບແຕ້ມ ບາງແອັບອ່ານມັນເປັນການຄລິກທຳມະດາ (ດ້ວຍ Control ຖືຢູ່), ດັ່ງນັ້ນໃຫ້ເລືອກການຄລິກສອງນິ້ວ.
- **ລາກດ້ວຍປຸ່ມກາງ (ເລື່ອນມຸມມອງ):** ແຕ່ລະແອັບມີວິທີອື່ນໃນການເລື່ອນມຸມມອງ, ເຊັ່ນການກົດ {{key:Space}} ຄ້າງໄວ້ໃນຂະນະທີ່ລາກ ຫຼື ລາກດ້ວຍປຸ່ມຂວາ. ໜ້າແປ້ນພິມຂອງແອັບບອກວ່າອັນໃດ.
- **ຊູມດ້ວຍລໍ້:** ການເລື່ອນສອງນິ້ວເທິງແທັກແພດຈະຊູມເຂົ້າໃນແອັບສ່ວນໃຫຍ່. ການບີບກໍຊູມໄດ້ບ່ອນທີ່ແອັບຮອງຮັບ.
:::

:::windows linux
- **ຄລິກຂວາ:** ຄລິກດ້ວຍສອງນິ້ວ, ຫຼື ຄລິກມຸມລຸ່ມຂວາຂອງແທັກແພດ. ຂຶ້ນກັບການຕັ້ງຄ່າແທັກແພດຂອງທ່ານ.
- **ລາກດ້ວຍປຸ່ມກາງ (ເລື່ອນມຸມມອງ):** ແຕ່ລະແອັບມີວິທີອື່ນໃນການເລື່ອນມຸມມອງ, ເຊັ່ນການກົດ {{key:Space}} ຄ້າງໄວ້ໃນຂະນະທີ່ລາກ ຫຼື ລາກດ້ວຍປຸ່ມຂວາ. ໜ້າແປ້ນພິມຂອງແອັບບອກວ່າອັນໃດ.
- **ຊູມດ້ວຍລໍ້:** ການເລື່ອນສອງນິ້ວເທິງແທັກແພດຈະຊູມເຂົ້າໃນແອັບສ່ວນໃຫຍ່.
:::

## ການພິມໃນກ່ອງຂໍ້ຄວາມ

ໃນຂະນະທີ່ທ່ານພິມໃນກ່ອງ (ຊື່, ໝາຍເຫດ, ການຄົ້ນຫາ), ປຸ່ມລັດຕົວດຽວຂອງແອັບຈະປິດ, ດັ່ງນັ້ນການພິມ "L" ຈະພິມຕົວ L. ກົດ {{key:Esc}} ຫຼື ຄລິກທີ່ແບບແຕ້ມເພື່ອໃຫ້ປຸ່ມກັບຄືນໄປຫາແອັບ.

应用在网页浏览器中运行，所有工作都在你自己的计算机上完成：文件在本机打开，绝不会发送给我们（见[文件去向](common:your-files)）。

## 选用哪种浏览器

请使用以下浏览器之一的最新版本：

| 浏览器 | 引擎 | 说明 |
|---|---|---|
| Chrome、Edge、Brave、Opera、Vivaldi | Chromium | 功能最完整：支持选择文件夹、保存以供离线使用、文件关联打开。 |
| Firefox | Gecko | 可用。打开整个文件夹时使用较简单的选择器。在隐私窗口中可能无法离线保存。 |
| Safari | WebKit | 可在 Mac 和 iPad 上使用。打开整个文件夹时使用较简单的选择器。Safari 可能会删除数周未使用的离线副本。 |

三种引擎都能满足日常工作。如果某个应用在其中一种浏览器里的做法不同，它的帮助会给出对应你所用浏览器的步骤。

## 浏览器之间的差异

- **打开文件夹。** Chromium 内核浏览器会显示真正的文件夹选择器，并可直接读取该文件夹。Firefox 和 Safari 则要求你选择文件夹，然后读取其中的每个文件，对于大型项目文件夹耗时更长；把文件夹拖到应用上，在三种浏览器中都可行。
- **保存。** 应用通过下载文件来保存。下载到哪里、是否先询问，由浏览器决定。

:::chromium
在 Chrome 或 Edge 中，打开“设置”，在“下载内容”下打开“下载前询问每个文件的保存位置”，即可每次选择文件夹。
:::

:::firefox
在 Firefox 中，打开“设置”，进入“常规”，在“文件与应用程序”下的“下载”处选择“总是询问您保存文件的位置”，即可每次选择文件夹。
:::

:::safari
在 Safari 中，打开“设置”，进入“通用”，将“文件下载位置”设为“每次下载前询问”，即可每次选择文件夹。
:::

## Mac、Windows 和 Linux

应用在每种计算机上都一样。不同的是键盘：快捷键会自动按你的计算机来书写。见[键盘、鼠标和触控板](common:keys)。

## 平板和触摸屏

部分应用支持触摸（单指绘制或选择，双指捏合缩放和平移）。各应用的帮助会说明是否支持。在 iPad 上请使用 Safari 或 Chrome。对于使用键入命令的应用，配上键盘会更方便。

## 最低浏览器和系统版本

这些版本是从 0.7 应用的代码中读出的，不是估计：我们解析了每个文件，并对照浏览器公布的兼容性数据，查证了其中用到的每一项语言特性。低于这些版本，应用连启动都做不到，因为浏览器无法理解代码。

| | 能启动应用的最低版本 |
|---|---|
| Chrome、Edge、Brave、Opera、Vivaldi | Chromium 94 |
| Firefox | 93 |
| Safari（Mac、iPad、iPhone） | 16.4（macOS 13.3、iPadOS 和 iOS 16.4） |

CadCraft Studio 在 Windows 上自带网页引擎，因此需要 Windows 10 或 11；在 Mac 上使用系统自带的引擎，因此需要 macOS 13.3 或更高版本。Studio 中的“设置 › 更新”会显示你的副本运行在什么之上。

这是从代码中读出的、能够*启动*的最低版本。它并不是我们实际运行过应用的旧浏览器清单，所以能启动的较旧浏览器仍可能缺少某些功能。

## 你的计算机需要什么

以下是应用的计划最低配置，而非实测要求：

- 8 GB 内存（处理大型联合模型时建议 16 GB）。
- 3D 应用需要支持 WebGL 2 的显卡。如果 3D 视图一直空白，请检查浏览器设置中是否已开启硬件加速。
- 屏幕宽度至少 1280 像素，才能完整显示工具栏；较小的屏幕会让工具栏换行。

非常大的文件（大型图纸集、大型模型）在浏览器标签页中会占用大量内存。如果应用变慢，请关闭其他占用资源的标签页。

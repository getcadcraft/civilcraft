## 快捷键的写法

帮助按你的键盘上的标注来书写每个快捷键。

| 写法 | 在 Mac 上 | 在 Windows 和 Linux 上 |
|---|---|---|
| {{key:Mod+S}} | Command（⌘）和 S | Ctrl 和 S |
| {{key:Ctrl+Shift+F}} | Control（⌃）、Shift（⇧）和 F | Ctrl、Shift 和 F |
| {{key:Alt+Left}} | Option（⌥）和 ← | Alt 和 ← |
| {{key:Backspace}} | Delete 键 | Backspace |
| {{key:Delete}} | fn 和 Delete（向前删除） | Delete |
| {{key:Enter}} | Return | Enter |

加号表示同时按住这些键。“然后”表示依次按下。

大多数应用快捷键在 Mac 上既可用 Command 也可用 Control，所以 {{key:Mod+Z}} 两种方式都行。少数快捷键，例如全屏（{{key:Ctrl+Shift+F}}），在所有计算机上都使用 Control 键；适用时帮助会特别说明。

## Mac 上的功能键

在大多数 Mac 键盘上，顶行按键用于调节亮度、音量和媒体。若要发送 F1 到 F12：

- 按键时同时按住 **fn**（或地球键），或者
- 打开**系统设置**，依次进入**键盘**、**键盘快捷键**、**功能键**，并开启“将 F1、F2 等键用作标准功能键”。

部分 F 键也被 macOS 自身占用（例如调度中心）。如果某个键在应用中没有反应，请配合 fn 试一试，或改用工具栏按钮。

## 浏览器保留的快捷键

网页无法从浏览器手中夺走某些快捷键，不论它怎么做。在每个应用中：

- {{key:Mod+N}}、{{key:Mod+T}} 和 {{key:Mod+W}} 始终是打开或关闭浏览器窗口和标签页。应用改用按钮来完成“新建”和“关闭”。
- Mac 上的 {{key:Mod+Q}} 和 Windows 上的 {{key:Alt+F4}} 会退出浏览器。如果有未保存的工作，浏览器会先询问（“要离开此网站吗？”）；请选择留下，然后保存。
- 浏览器自带的全屏（{{pick:mac=Control-Command-F，或窗口上的绿色按钮|windows linux=F11}}）仍然有效。应用也有自己的屏幕模式，快捷键为 {{key:Ctrl+Shift+F}}，它还可以隐藏应用的各种栏。

## 触控板上的鼠标按键

应用会用到右键和中键。没有三键鼠标时：

:::mac
- **右键单击：**用双指单击。如果双指单击没有反应，请在**系统设置**的**触控板**中开启“辅助点按”。单击时按住 {{key:Ctrl}} 会打开浏览器的菜单，但在图形内部，有些应用会把它当作普通单击（带着 Control 键），所以建议使用双指单击。
- **中键拖动（平移）：**每个应用都提供另一种平移方式，例如拖动时按住 {{key:Space}}，或用右键拖动。具体见该应用的键盘页面。
- **滚轮缩放：**在大多数应用中，在触控板上双指滑动即可缩放。在支持的应用中，捏合也可以缩放。
:::

:::windows linux
- **右键单击：**用双指单击，或单击触摸板的右下角。这取决于你的触摸板设置。
- **中键拖动（平移）：**每个应用都提供另一种平移方式，例如拖动时按住 {{key:Space}}，或用右键拖动。具体见该应用的键盘页面。
- **滚轮缩放：**在大多数应用中，在触摸板上双指滑动即可缩放。
:::

## 在文本框中输入

在框中输入时（名称、备注、搜索），应用的单字母快捷键会暂时关闭，所以键入“L”就是输入字母 L。按 {{key:Esc}} 或单击图形，即可把按键交还给应用。

每个应用都自带帮助。它是应用的一部分，因此无需联网即可打开，并且始终描述你正在运行的版本。

## 打开帮助

- 按 {{key:F1}}，或选择应用顶部栏中的{{ui:帮助}}。
- 按 {{key:Esc}} 或选择{{ui:关闭}}即可收起。你的图形保持原样。

:::mac
在大多数 Mac 键盘上，顶行按键控制亮度和音量。请同时按 {{key:F1}} 和 **fn** 键（或地球键），也可以使用{{ui:帮助}}按钮。见[Mac 上的按键](common:keys#function-keys-on-a-mac)。
:::

## 查找主题

- 在帮助顶部的搜索框中输入。结果会随输入实时更新，并包含其他软件的命令名称，所以输入你在别处会输入的内容，通常就能找到对应页面。
- 主题在每个应用中的分组方式都相同：入门、分步指南、从其他软件转来、参考和故障排除。
- 主题内的链接会在同一面板中打开下一个主题。{{ui:返回}}可回到之前的位置。

## 适合你计算机的步骤

有些步骤在 Mac、Windows 和 Linux 之间、在不同浏览器之间、在联网和离线之间会有所不同。帮助会判断哪一种适用于你，并显示对应的步骤。主题顶部的一行会说明它的选择，例如“正在显示适用于 Mac、Chrome 或 Edge、在线的步骤”。

- 选择该行上的{{ui:更改}}可选择另一种计算机或浏览器，例如为同事提供帮助时。
- 选择{{ui:显示全部}}可查看每一步的所有版本，并各自带有标注。

键盘快捷键按你的键盘标注来书写：{{key:Mod+S}} 在 Mac 上显示为 ⌘S，在 Windows 和 Linux 上显示为 Ctrl+S。

## 网站上的同一份帮助

网站在 getcadcraft.com/tutorials 上显示相同的主题，包含各平台的步骤。联网时，在应用中选择主题底部的{{ui:在网站上打开}}即可打开该页面。

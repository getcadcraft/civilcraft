កម្មវិធីដំណើរការនៅក្នុងកម្មវិធីរុករកអ៊ីនធឺណិត។ ពួកវាធ្វើការនៅលើកុំព្យូទ័ររបស់អ្នកផ្ទាល់៖ ឯកសាររបស់អ្នកត្រូវបានបើកនៅទីនោះ ហើយមិនដែលត្រូវបានផ្ញើទៅយើងទេ (សូមមើល [កន្លែងដែលឯកសាររបស់អ្នកទៅ](common:your-files))។

## កម្មវិធីរុករកមួយណា

ប្រើកំណែថ្មីបំផុតនៃមួយក្នុងចំណោមទាំងនេះ៖

| កម្មវិធីរុករក | ម៉ាស៊ីន | កំណត់សម្គាល់ |
|---|---|---|
| Chrome, Edge, Brave, Opera, Vivaldi | Chromium | ពេញលេញបំផុត៖ ការជ្រើសថត ការរក្សាទុកសម្រាប់ក្រៅបណ្ដាញ ការដោះស្រាយឯកសារ។ |
| Firefox | Gecko | ដំណើរការបាន។ ការបើកថតទាំងមូលប្រើអ្នកជ្រើសសាមញ្ញជាង។ ការរក្សាទុកក្រៅបណ្ដាញអាចមិនដំណើរការនៅក្នុងបង្អួចឯកជន។ |
| Safari | WebKit | ដំណើរការនៅលើ Mac និង iPad។ ការបើកថតទាំងមូលប្រើអ្នកជ្រើសសាមញ្ញជាង។ Safari អាចលុបច្បាប់ចម្លងសម្រាប់ក្រៅបណ្ដាញដែលអ្នកមិនបានប្រើប៉ុន្មានសប្ដាហ៍។ |

ម៉ាស៊ីនទាំងបីសុទ្ធតែល្អសម្រាប់ការងារប្រចាំថ្ងៃ។ នៅកន្លែងណាដែលកម្មវិធីធ្វើអ្វីខុសគ្នានៅក្នុងម៉ាស៊ីនមួយ ជំនួយរបស់វាបង្ហាញជំហានសម្រាប់កម្មវិធីរុករករបស់អ្នក។

## អ្វីដែលខុសគ្នារវាងកម្មវិធីរុករក

- **ការបើកថត។** កម្មវិធីរុករកក្នុងក្រុម Chromium បង្ហាញអ្នកជ្រើសថតពិតប្រាកដ ហើយអាចអានថតផ្ទាល់។ Firefox និង Safari សួរឲ្យអ្នកជ្រើសថត ហើយអានឯកសារគ្រប់ទាំងអស់ក្នុងនោះ ដែលចំណាយពេលយូរសម្រាប់ថតគម្រោងធំ; ការអូសថតទៅកម្មវិធីដំណើរការនៅទាំងបីម៉ាស៊ីន។
- **ការរក្សាទុក។** កម្មវិធីរក្សាទុកដោយទាញយកឯកសារ។ កម្មវិធីរុករករបស់អ្នកកំណត់ថាការទាញយកទៅទីណា និងថាតើវាសួរជាមុនឬអត់។

:::chromium
នៅក្នុង Chrome ឬ Edge បើក "Ask where to save each file before downloading" (នៅក្នុង Settings ក្រោម Downloads) ដើម្បីជ្រើសថតរាល់ពេល។
:::

:::firefox
នៅក្នុង Firefox បើក Settings បន្ទាប់ General បន្ទាប់ Downloads ហើយជ្រើស "Always ask you where to save files" ដើម្បីជ្រើសថតរាល់ពេល។
:::

:::safari
នៅក្នុង Safari បើក Settings បន្ទាប់ General ហើយកំណត់ "File download location" ទៅ "Ask for each download" ដើម្បីជ្រើសថតរាល់ពេល។
:::

## Mac, Windows និង Linux

កម្មវិធីដូចគ្នានៅលើកុំព្យូទ័រគ្រប់ប្រភេទ។ អ្វីដែលផ្លាស់ប្ដូរគឺក្ដារចុច៖ ផ្លូវកាត់ត្រូវបានសរសេរសម្រាប់កុំព្យូទ័ររបស់អ្នកដោយស្វ័យប្រវត្តិ។ សូមមើល [ក្ដារចុច កណ្ដុរ និងបន្ទះប៉ះ](common:keys)។

## ថេប្លេត និងអេក្រង់ប៉ះ

កម្មវិធីខ្លះទទួលការប៉ះ (ម្រាមមួយគូរ ឬជ្រើស ម្រាមពីរច្បិចដើម្បីពង្រីក និងរំកិល)។ ជំនួយរបស់កម្មវិធីនីមួយៗប្រាប់ថាវាធ្វើឬអត់។ នៅលើ iPad សូមប្រើ Safari ឬ Chrome។ ក្ដារចុចជួយកម្មវិធីដែលប្រើពាក្យបញ្ជាដែលបានវាយ។

## កម្មវិធីរុករក និងប្រព័ន្ធចាស់បំផុត

នេះជាកំណែចាស់បំផុតដែលចាប់ផ្ដើមបាន ដែលអានពីកូដ។ វាមិនមែនជាបញ្ជីកម្មវិធីរុករកចាស់ៗដែលយើងបានដំណើរការកម្មវិធីនៅក្នុងនោះទេ ដូច្នេះកម្មវិធីរុករកចាស់ដែលចាប់ផ្ដើមបានអាចនៅតែខ្វះលក្ខណៈពិសេសមួយ។

## កុំព្យូទ័ររបស់អ្នកត្រូវការអ្វី

ទាំងនេះជាអប្បបរមាដែលបានគ្រោងទុកសម្រាប់កម្មវិធី មិនមែនតម្រូវការដែលបានវាស់ទេ៖

- អង្គចងចាំ 8 GB (ណែនាំ 16 GB សម្រាប់ម៉ូដែលធំៗដែលបានភ្ជាប់)។
- ឈីបក្រាហ្វិកដែលមាន WebGL 2 សម្រាប់កម្មវិធី 3D។ ប្រសិនបើទិដ្ឋភាព 3D នៅទទេ សូមពិនិត្យថាការបង្កើនល្បឿនដោយផ្នែកឧបករណ៍ត្រូវបានបើកនៅក្នុងការកំណត់កម្មវិធីរុករករបស់អ្នក។
- អេក្រង់ដែលមានទទឹងយ៉ាងហោចណាស់ 1280 ភីកសែល សម្រាប់របារឧបករណ៍ពេញលេញ; អេក្រង់តូចជាងនឹងបត់របារទាំងនោះ។

ឯកសារធំៗ (សំណុំប្លង់ធំ ម៉ូដែលធំ) ប្រើអង្គចងចាំច្រើនក្នុងផ្ទាំងកម្មវិធីរុករក។ បិទផ្ទាំងធ្ងន់ៗផ្សេងទៀតប្រសិនបើកម្មវិធីយឺត។

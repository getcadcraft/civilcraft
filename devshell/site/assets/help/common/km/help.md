កម្មវិធីនីមួយៗមានជំនួយរបស់ខ្លួន។ វាជាផ្នែកមួយនៃកម្មវិធី ដូច្នេះវាបើកដោយមិនមានការតភ្ជាប់ ហើយតែងតែពិពណ៌នាអំពីកំណែដែលអ្នកកំពុងដំណើរការ។

## បើកជំនួយ

- ចុច {{key:F1}} ឬជ្រើស {{ui:ជំនួយ}} នៅក្នុងរបារខាងលើនៃកម្មវិធី។
- ចុច {{key:Esc}} ឬជ្រើស {{ui:បិទ}} ដើម្បីបិទវា។ គំនូរប្លង់របស់អ្នកនៅដដែល។

## ស្វែងរកប្រធានបទ

- វាយនៅក្នុងប្រអប់ស្វែងរកនៅកំពូលជំនួយ។ លទ្ធផលកែប្រែខណៈអ្នកវាយ ហើយរួមបញ្ចូលឈ្មោះពាក្យបញ្ជារបស់កម្មវិធីផ្សេងៗ ដូច្នេះការវាយអ្វីដែលអ្នកនឹងវាយនៅកន្លែងផ្សេង ជាធម្មតារកឃើញទំព័រត្រឹមត្រូវ។
- ប្រធានបទត្រូវបានរៀបចំដូចគ្នានៅគ្រប់កម្មវិធី៖ ការចាប់ផ្ដើម មេរៀន ការមកពីកម្មវិធីផ្សេង ឯកសារយោង និងការដោះស្រាយបញ្ហា។
- តំណភ្ជាប់នៅក្នុងប្រធានបទបើកប្រធានបទបន្ទាប់ក្នុងផ្ទាំងដដែល។ {{ui:ថយក្រោយ}} ត្រឡប់ទៅកន្លែងដែលអ្នកនៅ។

## ជំហានសម្រាប់កុំព្យូទ័ររបស់អ្នក

ជំហានខ្លះខុសគ្នារវាង Mac, Windows និង Linux, រវាងកម្មវិធីរុករក, និងរវាងការតភ្ជាប់ និងក្រៅបណ្ដាញ។ ជំនួយគណនាថាអ្វីអនុវត្តចំពោះអ្នក ហើយបង្ហាញជំហានទាំងនោះ។ បន្ទាត់នៅកំពូលប្រធានបទនិយាយថាវាបានជ្រើសអ្វី ឧទាហរណ៍ "កំពុងបង្ហាញជំហានសម្រាប់ Mac, Chrome ឬ Edge, លើបណ្ដាញ"។

- ជ្រើស {{ui:ប្ដូរ}} លើបន្ទាត់នោះ ដើម្បីជ្រើសកុំព្យូទ័រ ឬកម្មវិធីរុករកផ្សេង ឧទាហរណ៍ដើម្បីជួយមិត្តរួមការងារ។
- ជ្រើស {{ui:បង្ហាញទាំងអស់}} ដើម្បីមើលជំហានគ្រប់កំណែ ហើយកំណែនីមួយៗមានស្លាក។

ផ្លូវកាត់ក្ដារចុចត្រូវបានសរសេរតាមរបៀបដែលក្ដារចុចរបស់អ្នកដាក់ស្លាក៖ {{key:Mod+S}} អានថា ⌘S លើ Mac និង Ctrl+S លើ Windows និង Linux។

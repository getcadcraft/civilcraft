## របៀបសរសេរផ្លូវកាត់

កម្មវិធីសរសេរផ្លូវកាត់នីមួយៗតាមរបៀបដែលក្ដារចុចរបស់អ្នកដាក់ស្លាក។

| សរសេរ | នៅលើ Mac | នៅលើ Windows និង Linux |
|---|---|---|
| {{key:Mod+S}} | Command (⌘) និង S | Ctrl និង S |
| {{key:Ctrl+Shift+F}} | Control (⌃), Shift (⇧) និង F | Ctrl, Shift និង F |
| {{key:Alt+Left}} | Option (⌥) និង ← | Alt និង ← |
| {{key:Backspace}} | ប៊ូតុង Delete | Backspace |
| {{key:Delete}} | fn និង Delete (លុបទៅមុខ) | Delete |
| {{key:Enter}} | Return | Enter |

សញ្ញាបូកមានន័យថាចុចគ្រាប់ចុចជាមួយគ្នា។ "Then" មានន័យថាចុចម្ដងមួយ បន្តបន្ទាប់គ្នា។

ផ្លូវកាត់កម្មវិធីភាគច្រើនទទួល Command ឬ Control លើ Mac ដូច្នេះ {{key:Mod+Z}} ដំណើរការទាំងពីរយ៉ាង។ ផ្លូវកាត់មួយចំនួន ដូចជាអេក្រង់ពេញ ({{key:Ctrl+Shift+F}}) ប្រើគ្រាប់ Control នៅលើកុំព្យូទ័រគ្រប់ប្រភេទ; ជំនួយបញ្ជាក់នៅកន្លែងដែលវាអនុវត្ត។

## គ្រាប់ចុចមុខងារនៅលើ Mac

នៅលើក្ដារចុច Mac ភាគច្រើន ជួរខាងលើផ្លាស់ប្ដូរពន្លឺ សំឡេង និងមេឌៀ។ ដើម្បីផ្ញើ F1 ដល់ F12៖

- សង្កត់ **fn** (ឬគ្រាប់ globe) ខណៈចុចគ្រាប់ចុចនោះ ឬ
- បើក **System Settings** បន្ទាប់ **Keyboard** បន្ទាប់ **Keyboard Shortcuts** បន្ទាប់ **Function Keys** ហើយបើក "Use F1, F2, etc. keys as standard function keys"។

គ្រាប់ចុច F ខ្លះត្រូវបាន macOS ខ្លួនឯងកាន់កាប់ផងដែរ (ឧទាហរណ៍ Mission Control)។ ប្រសិនបើគ្រាប់ចុចមិនធ្វើអ្វីនៅក្នុងកម្មវិធី សូមសាកវាជាមួយ fn ឬប្រើប៊ូតុងនៅរបារឧបករណ៍ជំនួសវិញ។

## ផ្លូវកាត់ដែលកម្មវិធីរុករកទុកសម្រាប់ខ្លួន

ទំព័របណ្ដាញមិនអាចយកផ្លូវកាត់មួយចំនួនពីកម្មវិធីរុករកបានទេ ទោះជាវាធ្វើអ្វីក៏ដោយ។ នៅគ្រប់កម្មវិធី៖

- {{key:Mod+N}}, {{key:Mod+T}} និង {{key:Mod+W}} តែងតែបើក ឬបិទបង្អួច និងផ្ទាំងកម្មវិធីរុករក។ កម្មវិធីប្រើប៊ូតុង ថ្មី និង {{ui:បិទ}} ជំនួសវិញ។
- {{key:Mod+Q}} លើ Mac និង {{key:Alt+F4}} លើ Windows បិទកម្មវិធីរុករក។ ប្រសិនបើអ្នកមានការងារមិនបានរក្សាទុក កម្មវិធីរុករកសួរជាមុនថា ("Leave site?"); ជ្រើសនៅ ហើយរក្សាទុក។
- អេក្រង់ពេញរបស់កម្មវិធីរុករក ({{pick:mac=Control-Command-F, ឬប៊ូតុងពណ៌បៃតងលើបង្អួច|windows linux=F11}}) នៅតែដំណើរការ។ កម្មវិធីក៏មានរបៀបអេក្រង់របស់ខ្លួនលើ {{key:Ctrl+Shift+F}} ដែលអាចលាក់របារកម្មវិធីផងដែរ។

## ប៊ូតុងកណ្ដុរនៅលើបន្ទះប៉ះ

កម្មវិធីប្រើប៊ូតុងខាងស្ដាំ និងប៊ូតុងកណ្ដាល។ បើគ្មានកណ្ដុរបីប៊ូតុង៖

:::mac
- **ចុចខាងស្ដាំ៖** ចុចដោយម្រាមពីរ។ បើក "Secondary click" នៅ **System Settings** បន្ទាប់ **Trackpad** ប្រសិនបើការចុចដោយម្រាមពីរមិនធ្វើអ្វី។ ការសង្កត់ {{key:Ctrl}} ខណៈចុចបើកម៉ឺនុយកម្មវិធីរុករក ប៉ុន្តែនៅក្នុងគំនូរប្លង់ កម្មវិធីខ្លះអានវាជាការចុចធម្មតា (ជាមួយ Control ដែលសង្កត់) ដូច្នេះសូមចូលចិត្តការចុចដោយម្រាមពីរ។
- **អូសកណ្ដាល (រំកិល)៖** កម្មវិធីនីមួយៗផ្ដល់វិធីមួយទៀតដើម្បីរំកិល ដូចជាការសង្កត់ {{key:Space}} ខណៈអូស ឬអូសដោយប៊ូតុងខាងស្ដាំ។ ទំព័រក្ដារចុចរបស់កម្មវិធីប្រាប់ថាមួយណា។
- **ពង្រីកដោយកង់៖** ការរំកិលដោយម្រាមពីរលើបន្ទះប៉ះពង្រីកនៅកម្មវិធីភាគច្រើន។ ការច្បិចក៏ពង្រីកនៅកន្លែងដែលកម្មវិធីគាំទ្រ។
:::

:::windows linux
- **ចុចខាងស្ដាំ៖** ចុចដោយម្រាមពីរ ឬចុចមុំខាងក្រោមខាងស្ដាំនៃបន្ទះប៉ះ។ វាអាស្រ័យលើការកំណត់បន្ទះប៉ះរបស់អ្នក។
- **អូសកណ្ដាល (រំកិល)៖** កម្មវិធីនីមួយៗផ្ដល់វិធីមួយទៀតដើម្បីរំកិល ដូចជាការសង្កត់ {{key:Space}} ខណៈអូស ឬអូសដោយប៊ូតុងខាងស្ដាំ។ ទំព័រក្ដារចុចរបស់កម្មវិធីប្រាប់ថាមួយណា។
- **ពង្រីកដោយកង់៖** ការរំកិលដោយម្រាមពីរលើបន្ទះប៉ះពង្រីកនៅកម្មវិធីភាគច្រើន។
:::

## ការវាយក្នុងប្រអប់អក្សរ

ខណៈអ្នកវាយក្នុងប្រអប់ (ឈ្មោះ ចំណាំ ការស្វែងរក) ផ្លូវកាត់មួយអក្សររបស់កម្មវិធីត្រូវបានបិទ ដូច្នេះការវាយ "L" វាយអក្សរ L។ ចុច {{key:Esc}} ឬចុចលើគំនូរប្លង់ ដើម្បីប្ដូរគ្រាប់ចុចត្រឡប់ទៅកម្មវិធី។

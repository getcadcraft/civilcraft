## කෙටි මං ලියැවෙන ආකාරය

උදව් සෑම කෙටි මගක්ම ඔබේ යතුරු පුවරුව ඒවා ලේබල් කරන ආකාරයට ලියයි.

| ලියා ඇති ආකාරය | Mac මත | Windows සහ Linux මත |
|---|---|---|
| {{key:Mod+S}} | Command (⌘) සහ S | Ctrl සහ S |
| {{key:Ctrl+Shift+F}} | Control (⌃), Shift (⇧) සහ F | Ctrl, Shift සහ F |
| {{key:Alt+Left}} | Option (⌥) සහ ← | Alt සහ ← |
| {{key:Backspace}} | Delete යතුර | Backspace |
| {{key:Delete}} | fn සහ Delete (ඉදිරියට මකන්න) | Delete |
| {{key:Enter}} | Return | Enter |

ප්ලස් ලකුණ යතුරු එකට අල්ලා ගැනීම අදහස් කරයි. "ඉන්පසු" යනු එකින් එක ඔබීම අදහස් කරයි.

බොහෝ යෙදුම් කෙටි මං Mac මත Command හෝ Control ඕනෑම එකක් පිළිගනී, එබැවින් {{key:Mod+Z}} දෙආකාරයෙන්ම ක්‍රියා කරයි. සමහරක්, උදාහරණයක් ලෙස පූර්ණ තිරය ({{key:Ctrl+Shift+F}}), සෑම පරිගණකයකම Control යතුර භාවිත කරයි; එය අදාළ වන තැන උදව් එය කියයි.

## Mac මත ශ්‍රිත යතුරු

බොහෝ Mac යතුරු පුවරුවල ඉහළ පේළිය දීප්තිය, ශබ්දය සහ මාධ්‍ය වෙනස් කරයි. F1 සිට F12 දක්වා යැවීමට:

- යතුර ඔබන අතරතුර **fn** (හෝ ගෝලය යතුර) අල්ලා සිටින්න, හෝ
- **පද්ධති සැකසීම්** විවෘත කර, ඉන්පසු **යතුරු පුවරුව**, ඉන්පසු **යතුරු පුවරු කෙටි මං**, ඉන්පසු **ශ්‍රිත යතුරු** වෙත යන්න, සහ "F1, F2, ආදී යතුරු සම්මත ශ්‍රිත යතුරු ලෙස භාවිත කරන්න" ක්‍රියාත්මක කරන්න.

සමහර F-යතුරු macOS විසින්ම ද භාවිත කරයි (උදාහරණයක් ලෙස Mission Control). යතුරක් යෙදුමේ කිසිවක් නොකරන්නේ නම්, එය fn සමඟ උත්සාහ කරන්න, නැතහොත් ඒ වෙනුවට මෙවලම් පටි බොත්තම භාවිත කරන්න.

## බ්‍රවුසරය තබා ගන්නා කෙටි මං

වෙබ් පිටුවකට, එය කුමක් කළත්, බ්‍රවුසරයෙන් සමහර කෙටි මං ගත නොහැක. සෑම යෙදුමකම:

- {{key:Mod+N}}, {{key:Mod+T}} සහ {{key:Mod+W}} සැමවිටම බ්‍රවුසර කවුළු සහ ටැබ් විවෘත හෝ වසයි. යෙදුම් ඒ වෙනුවට නව සහ වසන බොත්තම් භාවිත කරයි.
- Mac මත {{key:Mod+Q}} සහ Windows මත {{key:Alt+F4}} බ්‍රවුසරය වසයි. සුරකින නොලැබූ වැඩ තිබේ නම්, බ්‍රවුසරය පළමුව අසයි ("අඩවියෙන් ඉවත් වන්නද?"); රැඳී සිටීමට තෝරන්න, ඉන්පසු සුරකින්න.
- බ්‍රවුසරයේ තමන්ගේම පූර්ණ තිරය ({{pick:mac=Control-Command-F, කවුළුවේ කොළ බොත්තම|windows linux=F11}}) තවමත් ක්‍රියා කරයි. යෙදුම් වලට {{key:Ctrl+Shift+F}} මත තමන්ගේම තිර ප්‍රකාරද ඇත, ඒවා යෙදුමේ පටිද සඟවිය හැක.

## ට්‍රැක්පෑඩ් මත මූෂික බොත්තම්

යෙදුම් දකුණු බොත්තම සහ මැද බොත්තම භාවිත කරයි. බොත්තම් තුනේ මූෂිකයක් නැතිව:

:::mac
- **දකුණු-ක්ලික්:** ඇඟිලි දෙකකින් ක්ලික් කරන්න. ඇඟිලි දෙකේ ක්ලික් කිරීම කිසිවක් නොකරන්නේ නම්, **පද්ධති සැකසීම්** හි **ට්‍රැක්පෑඩ්** යටතේ "ද්විතීයික ක්ලික්" ක්‍රියාත්මක කරන්න. ක්ලික් කරන අතරතුර {{key:Ctrl}} අල්ලා සිටීම බ්‍රවුසරයේ මෙනුව විවෘත කරයි, නමුත් ඇඳීමක ඇතුළත සමහර යෙදුම් එය (Control අල්ලා සිටින) සාමාන්‍ය ක්ලික් එකක් ලෙස කියවයි, එබැවින් ඇඟිලි දෙකේ ක්ලික් කිරීම වඩා හොඳයි.
- **මැද බොත්තම ඇදීම (දසුන ගෙන යාම):** සෑම යෙදුමක්ම දසුන ගෙන යාමට වෙනත් ක්‍රමයක් ඇත, උදාහරණයක් ලෙස ඇදීමේදී {{key:Space}} අල්ලා සිටීම හෝ දකුණු බොත්තමෙන් ඇදීම. යෙදුමේ යතුරු පුවරු පිටුව කුමක්දැයි කියයි.
- **රෝද විශාලනය:** බොහෝ යෙදුම් වල ට්‍රැක්පෑඩ් මත ඇඟිලි දෙකේ අනුචලනය විශාල කරයි. යෙදුම සහාය දක්වන තැනක ඇඟිලි දෙකින් පිංච් ද විශාල කරයි.
:::

:::windows linux
- **දකුණු-ක්ලික්:** ඇඟිලි දෙකකින් ක්ලික් කරන්න, හෝ ට්‍රැක්පෑඩයේ පහළ-දකුණු කෙළවර ක්ලික් කරන්න. මෙය ඔබේ ට්‍රැක්පෑඩ් සැකසීම් මත රඳා පවතී.
- **මැද බොත්තම ඇදීම (දසුන ගෙන යාම):** සෑම යෙදුමක්ම දසුන ගෙන යාමට වෙනත් ක්‍රමයක් ඇත, උදාහරණයක් ලෙස ඇදීමේදී {{key:Space}} අල්ලා සිටීම හෝ දකුණු බොත්තමෙන් ඇදීම. යෙදුමේ යතුරු පුවරු පිටුව කුමක්දැයි කියයි.
- **රෝද විශාලනය:** බොහෝ යෙදුම් වල ට්‍රැක්පෑඩ් මත ඇඟිලි දෙකේ අනුචලනය විශාල කරයි.
:::

## පෙළ පෙට්ටියක ටයිප් කිරීම

පෙට්ටියක (නමක්, සටහනක්, සෙවීමක්) ටයිප් කරන අතරතුර, යෙදුමේ එක් අකුරු කෙටි මං ක්‍රියාවිරහිත වේ, එබැවින් "L" ටයිප් කිරීම L අකුර ටයිප් කරයි. යතුරු යෙදුමට ආපසු ලබා දීමට {{key:Esc}} ඔබන්න හෝ ඇඳීම මත ක්ලික් කරන්න.

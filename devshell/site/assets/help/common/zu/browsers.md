Izinhlelo zisebenza ngaphakathi kwesiphequluli sewebhu. Zenza umsebenzi kukhompyutha yakho: amafayela akho avulwa lapho futhi awathunyelwa kithi (bona [Lapho amafayela akho aya khona](common:your-files)).

## Isiphequluli esingasetshenziswa

Sebenzisa inguqulo esisha yesinye salezi:

| Isiphequluli | Injini | Amanothi |
|---|---|---|
| Chrome, Edge, Brave, Opera, Vivaldi | Chromium | Eyiphelele kakhulu: ukukhetha ifolda, ukulondoloza ukuze usebenze ngaphandle kwe-inthanethi, ukuphatha amafayela. |
| Firefox | Gecko | Iyasebenza. Ukuvula ifolda yonke kusebenzisa isikhethi esilula. Ukulondoloza ngaphandle kwe-inthanethi kungenzeka kungasebenzi emawindini angasese. |
| Safari | WebKit | Iyasebenza kuMac naseiPad. Ukuvula ifolda yonke kusebenzisa isikhethi esilula. I-Safari ingasusa ikhophi yangaphandle kwe-inthanethi ongayisebenzisanga amasonto ambalwa. |

Zombili izinjini ezintathu ziyanele emsebenzini wansuku zonke. Lapho uhlelo lwenza into ngendlela ehlukile kwenye yazo, usizo lwalo lubonisa izinyathelo zesiphequluli sakho.

## Okwehlukile phakathi kwezisebenzi

- **Ukuvula ifolda.** Izisebenzi ze-Chromium zibonisa isikhethi sefolda langempela futhi zingafunda ifolda ngqo. I-Firefox ne-Safari zikucela ukuthi ukhethe ifolda bese zifunda wonke amafayela kuyo, okuthatha isikhathi eside kumafolda amakhulu ephrojekthi; ukuhudula ifolda kuhlelo kuyasebenza kuzo zonke ezintathu.
- **Ukulondoloza.** Izinhlelo zilondoloza ngokulanda ifayela. Isiphequluli sakho sinquma lapho okulandwayo kuya khona nokuthi sibuza ngaphambili yini.

:::chromium
Ku-Chrome noma ku-Edge, vula "Ask where to save each file before downloading" (ku-Settings, ngaphansi kwe-Downloads) ukuze ukhethe ifolda njalo.
:::

:::firefox
Ku-Firefox, vula Settings, bese General, bese Downloads, bese khetha "Always ask you where to save files" ukuze ukhethe ifolda njalo.
:::

:::safari
Ku-Safari, vula Settings, bese General, bese usetha "File download location" ibe "Ask for each download" ukuze ukhethe ifolda njalo.
:::

## Mac, Windows ne-Linux

Izinhlelo zifana kukhompyutha yonke. Okushintshayo ikhibhodi: izinqamulelo zibhalwa ngokuzenzakalelayo ukuze zifaneleke kukhompyutha yakho. Bona [Okhiye, ama-mouse nama-trackpad](common:keys).

## Amathebulethi nezikrini zokuthinta

Ezinye izinhlelo zamukela ukuthinta (umunwe owodwa udweba noma ukhethe, iminwe emibili icindezela ukuze usondeze futhi ushelelise). Usizo lohlelo ngalunye luyasho ukuthi uyakwenza yini. Ku-iPad, sebenzisa Safari noma Chrome. Ikhibhodi isiza ngezinhlelo ezisebenzisa imiyalo ebhalwayo.

## Isiphequluli nesistimu zakudala kakhulu

Sizifunde kukhodi yezinhlelo ze-0.7, hhayi ngokuqagela: wonke amafayela ahlaziywa futhi isici ngasinye solimi esisisebenzisayo sabhekwa kudatha yokuhambisana eshicilelwe yezisebenzi. Ngaphansi kwalezi zinguqulo, izinhlelo azikwazi nokuqala, ngoba isiphequluli asiqondi ikhodi.

| | Inguqulo yakudala kakhulu esingaqala ngayo izinhlelo |
|---|---|
| Chrome, Edge, Brave, Opera, Vivaldi | Chromium 94 |
| Firefox | 93 |
| Safari (Mac, iPad, iPhone) | 16.4 (macOS 13.3, iPadOS and iOS 16.4) |

I-CadCraft Studio ithwala injini yayo yewebhu ku-Windows, ngakho idinga i-Windows 10 noma 11; ku-Mac isebenzisa eyesistimu, ngakho idinga i-macOS 13.3 noma ephakeme. Izilungiselelo › Izibuyekezo ku-Studio ibonisa okuqhuba ikhophi yakho.

Lena inguqulo yakudala kakhulu *eqala*, efundwe kukhodi. Akuyona uhlu lwezisebenzi zakudala esizisebenzise izinhlelo kuzo, ngakho owendala oqalayo kungenzeka ungabi nesici.

## Okudingwa ikhompyutha yakho

Lezi yizinga ezincane ezihleliwe zezinhlelo, hhayi izidingo ezilinganisiwe:

- I-8 GB yenkumbulo (i-16 GB iyanconywa emamodeli amakhulu ahlanganisiwe).
- Ichip yezithombe enesekela le-WebGL 2 ezinhlelweni ze-3D. Uma ukubuka kwe-3D kuhlala kungenalutho, hlola ukuthi ukusheshisa kwe-hardware kuvuliwe kuzilungiselelo zesiphequluli sakho.
- Isikrini esingenani-1280 pixels ububanzi ukuze kuboniswe ibha yamathuluzi ephelele; izikrini ezincane ziyayiphindisela.

Amafayela amakhulu kakhulu (amasethi amapulani amakhulu, amamodeli amakhulu) asebenzisa inkumbulo eningi ethebhini lesiphequluli. Vala amanye amathebhu anzima uma uhlelo lunciphisa isivinini.

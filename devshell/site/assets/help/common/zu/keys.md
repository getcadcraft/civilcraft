## Indlela izinqamulelo ezibhalwa ngayo

Usizo lubhala inqamulelo ngayinye ngendlela ikhibhodi yakho eyibiza ngayo.

| Ukubhalwa | Ku-Mac | Ku-Windows ne-Linux |
|---|---|---|
| {{key:Mod+S}} | Command (⌘) kanye S | Ctrl kanye S |
| {{key:Ctrl+Shift+F}} | Control (⌃), Shift (⇧) kanye F | Ctrl, Shift kanye F |
| {{key:Alt+Left}} | Option (⌥) kanye ← | Alt kanye ← |
| {{key:Backspace}} | Inkinobho ye-Delete | Backspace |
| {{key:Delete}} | fn kanye Delete (ukususa phambili) | Delete |
| {{key:Enter}} | Return | Enter |

Uphawu lwe-plus kusho ukubamba okhiye ndawonye. "Bese" kusho ukucindezela elandelanayo.

Izinqamulelo eziningi zohlelo zamukela i-Command noma i-Control ku-Mac, ngakho {{key:Mod+Z}} isebenza ngazo zombili izindlela. Ezimbalwa, njengesikrini esigcwele ({{key:Ctrl+Shift+F}}), zisebenzisa ukhiye we-Control kukhompyutha yonke; usizo luyasho lapho lokho kusebenza khona.

## Okhiye bomsebenzi ku-Mac

Ezikhibhodini eziningi ze-Mac umugqa ophezulu ushintsha ukukhanya, ivolumu nemidiya. Ukuze uthumele u-F1 kuya ku-F12:

- bamba **fn** (noma ukhiye we-globe) ngenkathi ucindezela okhiye, noma
- vula **System Settings**, bese **Keyboard**, bese **Keyboard Shortcuts**, bese **Function Keys**, bese uvula "Use F1, F2, etc. keys as standard function keys".

Ezinye izinkinobho ze-F zibanjwa ye-macOS ngokwayo (njengesibonelo Mission Control). Uma ukhiye ungenzi lutho ohlelweni, zama ngo-fn, noma sebenzisa inkinobho yebha yamathuluzi esikhundleni salokho.

## Izinqamulelo isiphequluli esizigcinayo

Ikhasi lewebhu alikwazi ukuthatha ezinye izinqamulelo kusiphequluli, noma yini eyenzayo. Kuzo zonke izinhlelo:

- {{key:Mod+N}}, {{key:Mod+T}} kanye {{key:Mod+W}} njalo ziyavula noma zivale amawindi namathebhu esiphequluli. Izinhlelo zisebenzisa izinkinobho zokuthi Okusha kanye Vala esikhundleni salokho.
- {{key:Mod+Q}} ku-Mac kanye {{key:Alt+F4}} ku-Windows ziphuma kusiphequluli. Uma unomsebenzi ongalondolozwanga, isiphequluli sibuza kuqala ("Leave site?"); khetha ukuhlala, bese ulondoloza.
- Isikrini esigcwele sesiphequluli ({{pick:mac=Control-Command-F, noma inkinobho eluhlaza ewindini|windows linux=F11}}) sisasebenza. Izinhlelo zinemodi zazo zesikrini ku-{{key:Ctrl+Shift+F}}, ezingafihla namabha ohlelo nazo.

## Izinkinobho ze-mouse ku-trackpad

Izinhlelo zisebenzisa inkinobho yesokudla nenkinobho ephakathi. Uma ungenayo i-mouse enezinkinobho ezintathu:

:::mac
- **Ukuchofoza ngesokudla:** chofoza ngeminwe emibili. Vula "Secondary click" ku-**System Settings**, bese **Trackpad**, uma ukuchofoza ngeminwe emibili kungenzi lutho. Ukubamba {{key:Ctrl}} ngenkathi uchofoza kuvula imenyu yesiphequluli, kodwa ngaphakathi komdwebo ezinye izinhlelo zilifunda njengokuchofoza okujwayelekile (kuba ukhiye we-Control ubanjiwe), ngakho kungcono ukuchofoza ngeminwe emibili.
- **Ukuhudula ngenkinobho ephakathi (ukushelelisa):** inhlelo ngayinye inikeza enye indlela yokushelelisa, njengokubamba {{key:Space}} ngenkathi uhudula noma ukuhudula ngenkinobho yesokudla. Ikhasi lekhibhodi lohlelo luyasho ukuthi yiyiphi.
- **Ukusondeza ngevili:** ukuskrola ngeminwe emibili ku-trackpad kusondeza ezinhlelweni eziningi. Ukucindezela nakho kuyasondeza lapho uhlelo lukwamukela.
:::

:::windows linux
- **Ukuchofoza ngesokudla:** chofoza ngeminwe emibili, noma chofoza ikhona eliphansi ngakwesokudla se-touchpad. Lokhu kuncike ezilungiselelweni zakho ze-touchpad.
- **Ukuhudula ngenkinobho ephakathi (ukushelelisa):** inhlelo ngayinye inikeza enye indlela yokushelelisa, njengokubamba {{key:Space}} ngenkathi uhudula noma ukuhudula ngenkinobho yesokudla. Ikhasi lekhibhodi lohlelo luyasho ukuthi yiyiphi.
- **Ukusondeza ngevili:** ukuskrola ngeminwe emibili ku-touchpad kusondeza ezinhlelweni eziningi.
:::

## Ukubhala ebhokisini lombhalo

Lapho ubhala ebhokisini (igama, inothi, ukusesha), izinqamulelo zohlelo zenhlamvu eyodwa zivalwa, ngakho ukubhala "L" kubhala u-L. Cindezela {{key:Esc}} noma chofoza emdwebweni ukuze ubuyisele okhiye kuhlelo.

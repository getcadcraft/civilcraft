Аппууд веб хөтчийн дотор ажилладаг. Ажлыг таны өөрийн компьютер дээр хийдэг: таны файлууд тэнд нээгдэж, бидэнд хэзээ ч илгээгддэггүй (үзнэ үү: [Таны файлууд хаашаа очдог вэ](common:your-files)).

## Аль хөтөч вэ

Эдгээрийн аль нэгний хамгийн сүүлийн хувилбарыг ашиглана уу:

| Хөтөч | Хөдөлгүүр | Тэмдэглэл |
|---|---|---|
| Chrome, Edge, Brave, Opera, Vivaldi | Chromium | Хамгийн бүрэн: фолдер сонгох, офлайнд хадгалах, файл боловсруулах. |
| Firefox | Gecko | Ажилладаг. Бүтэн фолдер нээхэд энгийн сонгогч ашиглана. Офлайн хадгалалт хувийн цонхонд ажиллахгүй байж болно. |
| Safari | WebKit | Mac болон iPad дээр ажилладаг. Бүтэн фолдер нээхэд энгийн сонгогч ашиглана. Safari нь хэдэн долоо хоногт ашиглаагүй офлайн хуулбарыг устгаж болно. |

Гурвын хөдөлгүүр бүр өдөр тутмын ажилд сайн. Аппын хэрэгсэл хөдөлгүүр тус бүрт өөр ажилладаг бол түүний тусламж таны хөтөчид зориулсан алхмуудыг харуулна.

## Хөтөчүүд юугаараа ялгаатай вэ

- **Фолдер нээх.** Chromium хөтчүүд жинхэнэ фолдер сонгогчийг харуулж, фолдерыг шууд уншиж чадна. Firefox ба Safari таныг фолдер сонгохыг хүсч, дараа нь доторх файл бүрийг уншина; энэ нь том төслийн фолдерт илүү удаан үргэлжилнэ. Фолдерыг аппад чирэх нь гурав дээр тэр чигээрээ ажиллана.
- **Хадгалах.** Аппууд файлыг татаж хадгалдаг. Хөтөч татсан файлыг хаана байрлуулах, мөн эхлээд асуух эсэхийг өөрөө шийднэ.

:::chromium
Chrome эсвэл Edge дээр «Татахаасаа өмнө файл бүрийг хаана хадгалахыг асуух» (Тохиргоо дотор, Downloads-ийн доор)-ийг асаавал, файл бүрт фолдер сонгоно.
:::

:::firefox
Firefox дээр Тохиргоо, дараа нь General, дараа нь Downloads-ийг нээгээд «Файлыг хаана хадгалахыг үргэлж асуух»-ыг сонгоно; тэгвэл файл бүрт фолдер сонгоно.
:::

:::safari
Safari дээр Тохиргоо, дараа нь General-ийг нээгээд «File download location»-ийг «Ask for each download» болгож тохируулбал файл бүрт фолдер сонгоно.
:::

## Mac, Windows ба Linux

Аппууд компьютер бүр дээр адил. Ялгаа нь товчлуурт байна: товчлолууд таны компьютерт автоматаар зориулагдсан байдлаар бичигдэнэ. Харна уу: [Товчлуур, хулгана, трекпад](common:keys).

## Таблет ба мэдрэгчтэй дэлгэц

Зарим апп мэдрэгчийг хүлээн авдаг (нэг хуруугаар зурна эсвэл сонгоно, хоёр хуруугаар томруулж, гүйлгэнэ). Аппын тусламж энэ нь мэдрэгчийг дэмждэг эсэхийг хэлнэ. iPad дээр Safari эсвэл Chrome ашиглана уу. Гарын товчлуур нь текстээр команд ашигладаг аппуудад туслана.

## Хамгийн хуучин хөтөч ба систем

Эдгээр хувилбаруудыг 0.7 аппын кодноос уншсан, таамаглаагүй: файл бүрийг задлан шинжилж, ашигласан хэл бүрийн онцлогийг хөтчүүдийн нийтэлсэн нийцлийн мэдээллээс хайсан. Эдгээр хувилбараас доош аппууд огт эхлэхгүй, учир нь хөтөч кодыг ойлгохгүй.

| | Аппыг эхлүүлж чадах хамгийн хуучин хувилбар |
|---|---|
| Chrome, Edge, Brave, Opera, Vivaldi | Chromium 94 |
| Firefox | 93 |
| Safari (Mac, iPad, iPhone) | 16.4 (macOS 13.3, iPadOS ба iOS 16.4) |

CadCraft Studio өөрийн веб хөдөлгүүртэй Windows дээр, тиймээс Windows 10 эсвэл 11 шаардана; Mac дээр системийнхийг ашигладаг тул macOS 13.3 эсвэл түүнээс хойшхи хувилбар шаардана. Studio-ийн Settings › Updates хэсэг таны хуулбар ямар дээр ажиллаж байгааг харуулна.

Энэ нь аппыг *эхлүүлж* чадах хамгийн хуучин хувилбар бөгөөд кодоос уншсан. Энэ нь бидний аппыг ажиллуулсан хуучин хөтчүүдийн жагсаалт биш, тиймээс эхэлдэг хуучин хөтөч нь зарим онцлогийг дутуу дэмжиж магадгүй.

## Таны компьютерт юу хэрэгтэй вэ

Эдгээр нь аппуудын төлөвлөсөн доод шаардлага, хэмжсэн шаардлага биш:

- 8 GB санах ой (том холимог загваруудад 16 GB санал болгоно).
- 3D аппуудад WebGL 2-тэй график чип. Хэрэв 3D харагдац хоосон хэвээр байвал хөтчийнхөө тохиргоонд hardware acceleration асаалттай эсэхийг шалгана уу.
- Бүтэн багажны мөрийн тулд 1280 пикселээс өргөн дэлгэц; жижиг дэлгэц мөрийг олон мөрөнд хуваана.

Маш том файлууд (том зурагт багц, том загвар) хөтчийн табад их санах ой ашигладаг. Апп удаашрах бол бусад хүнд табуудыг хаана уу.

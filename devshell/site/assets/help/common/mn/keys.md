## Товчлолыг яаж бичдэг вэ

Тусламж товчлол бүрийг таны гарын шошгоор бичнэ.

| Бичигдэх хэлбэр | Mac дээр | Windows ба Linux дээр |
|---|---|---|
| {{key:Mod+S}} | Command (⌘) ба S | Ctrl ба S |
| {{key:Ctrl+Shift+F}} | Control (⌃), Shift (⇧) ба F | Ctrl, Shift ба F |
| {{key:Alt+Left}} | Option (⌥) ба ← | Alt ба ← |
| {{key:Backspace}} | Delete товч | Backspace |
| {{key:Delete}} | fn ба Delete (урагш устгах) | Delete |
| {{key:Enter}} | Return | Enter |

Нэмэх тэмдэг нь товчнуудыг хамт барихыг илэрхийлнэ. «Дараа нь» гэвэл нэг нэгээр нь дарахыг хэлнэ.

Ихэнх аппын товчлол Mac дээр Command эсвэл Control аль алиныг хүлээн авдаг тул {{key:Mod+Z}} хоёр аргаар ажиллана. Цөөн хэдэн товчлол, жишээлбэл бүтэн дэлгэц ({{key:Ctrl+Shift+F}}), компьютер бүр дээр Control товчийг ашигладаг; тусламж үүнийг шаардлагатай газарт хэлнэ.

## Mac дээрх функцын товчлуурууд

Ихэнх Mac-ийн гарын дээд эгнээ гэрэл, дуу, медиаг өөрчилдөг. F1-ээс F12 хүртэлх товчийг илгээхийн тулд:

- товчийг дарахдаа **fn** (эсвэл глобус) товчийг барих, эсвэл
- **System Settings** нээгээд, дараа нь **Keyboard**, дараа нь **Keyboard Shortcuts**, дараа нь **Function Keys**-ийг сонгоод «Use F1, F2, etc. keys as standard function keys»-ийг асаана.

Зарим F товчийг macOS өөрөө эзэлдэг (жишээлбэл Mission Control). Хэрэв товч аппад юу ч хийхгүй бол fn-тэй туршина уу, эсвэл багажны мөрний товчийг ашиглана уу.

## Хөтөчийн хадгалдаг товчлолууд

Веб хуудас хөтчийн зарим товчлолыг хэдий тэр хүссэн ч авч чадахгүй. Бүх аппад:

- {{key:Mod+N}}, {{key:Mod+T}} ба {{key:Mod+W}} үргэлж хөтчийн цонх, табыг нээж эсвэл хаана. Аппууд Шинэ ба Хаах-ын товчийг ашигладаг.
- Mac дээр {{key:Mod+Q}} ба Windows дээр {{key:Alt+F4}} хөтчийг хаана. Хадгалаагүй ажил байвал хөтөч эхлээд асууна («Сайтаас гарах уу?»); гарахгүй байхаа сонгоод хадгална.
- Хөтчийн өөрийн бүтэн дэлгэц ({{pick:mac=Control-Command-F, эсвэл цонхны ногоон товчлуур|windows linux=F11}}) ажилладаг. Аппууд мөн {{key:Ctrl+Shift+F}} дээр өөрсдийн дэлгэцийн горимтой бөгөөд тэр нь аппын мөрүүдийг нуух боломжтой.

## Трекпад дээрх хулганы товчлуурууд

Аппууд баруун ба дунд товчийг ашигладаг. Гурван товчтой хулганагүй бол:

:::mac
- **Баруун товч дарах:** хоёр хуруугаараа дарна. Хоёр хурууны дарлага ажиллахгүй бол **System Settings** дээр, дараа нь **Trackpad** дээр «Secondary click»-ийг асаана. {{key:Ctrl}}-ийг барьж дарвал хөтчийн цэс нээгдэнэ, гэвч зурагт зарим апп үүнийг энгийн дарлага (Control дарагдсан үед) гэж уншдаг тул хоёр хурууны дарлагыг илүүд үзнэ.
- **Дунд товчоор чирэх (гүйлгэх):** апп бүр гүйлгэх өөр арга санал болгодог, жишээлбэл {{key:Space}}-ийг барьж чирэх эсвэл баруун товчоор чирэх. Аппын товчлуурын хуудас аль нь болохыг хэлнэ.
- **Дугуйгаар томруулах:** трекпад дээр хоёр хурууны гүйлгэлт ихэнх аппад томруулдаг. Хоёр хурууг нийлүүлэх (pinch) нь дэмжигдсэн аппад мөн ажиллана.
:::

:::windows linux
- **Баруун товч дарах:** хоёр хуруугаар дарах, эсвэл трекпадын баруун доод буланг дарна. Энэ нь трекпадын тохиргооноос хамаарна.
- **Дунд товчоор чирэх (гүйлгэх):** дээрхтэй адил.
- **Дугуйгаар томруулах:** трекпад дээр хоёр хуруугаар гүйлгэхэд ихэнх аппад томрууллаа.
:::

## Текст оруулах хайрцагт бичих

Хайрцагт (нэр, тэмдэглэл, хайлт) бичих үед аппын нэг үсгийн товчлолууд унтарна, тиймээс «L» бичвэл L үсэг бичигдэнэ. Товчлуурыг аппад буцаахын тулд {{key:Esc}} дарах эсвэл зурган дээр дарна уу.

**Toolbox at info box** ay isa sa tatlong workspace layout ng app. Nakatayo ang mga tool sa pagguhit sa hanay sa kaliwa, ipinapakita ng info box sa itaas ang kailangan ng tumatakbong tool o ang napili mo, may tab ang bawat view, at may quick bar sa ilalim ng drawing na naglalaman ng ilang pang-araw-araw na opsyon. Mga tool ng app mismo ang mga ito: lahat ng magagawa mo sa classic layout ay gumagana rin dito, at nananatili ang drawing, estilo ng menu at mga key mo.

## Piliin ito

1. Buksan ang {{ui:Mga setting}} (ang gear, o {{key:Mod+,}}).
2. Piliin ang tab na {{ui:Global}}, pagkatapos pumunta sa {{ui:Layout}} › {{ui:Workspace}}.
3. Piliin ang {{ui:Toolbox and info box}}.

Agad magbabago ang layout. Iisa ang pagpili para sa bawat app sa browser na ito: bubuksan ng bawat app ang layout na ito mula noon, at nasa lugar na ito bago gumuhit ang pahina, kaya hindi mo nakikita muna ang classic layout.

## Ano ang nasaan

- **Toolbar:** nananatili sa itaas ng drawing area ang sariling toolbar ng app, kasama ang mga menu nito.
- **Info box:** sa ilalim ng toolbar. Habang tumatakbo ang tool, ipinapakita nito ang tool at ang hinihingi nito. Kapag pumili ka ng isang bagay, ipinapakita nito ang pangunahing setting nito (para sa wall: uri, kapal, haba, location line at taas nito), at puwede mo itong baguhin doon mismo: pareho ang pagbabago roon sa Properties, at ibinabalik ito ng {{key:Mod+Z}}. Kapag walang napili, sinasabi nitong "Walang napili". Nagdaragdag ang bawat app ng sarili nitong kahon dito, gaya ng kasalukuyang layer o level, o ang bukas na dokumento.
- **Toolbox:** ang hanay sa kaliwa, ang mga tool ng app sa mga grupo. I-click ang pangalan ng grupo para itupi o buksan muli ito. Naiilawan ang tool na tumatakbo.
- **Mga tool ko:** ang unang grupo ng toolbox, walong walang lamang puwang para sa mga tool na pinakamadalas mong gamitin. I-click ang bakanteng puwang para pumili ng anumang tool o command ng app; o i-right-click ang tool sa toolbox at piliin ang {{ui:Add to My tools}}; o i-drag ang tool papunta sa puwang. I-right-click ang puwang para palitan ito o alisan ng laman. Naka-save ang mga puwang mo para sa bawat app sa browser na ito.
- **Navigator:** ang kanang panel. Nasa itaas ang project browser ng app (plan, section, elevation, 3D view, schedule, sheet, ayon sa mayroon ang app): i-click ang isa para buksan ito. Sa ilalim nito, ang {{ui:Properties}} at isang tab na may iba pang nilalaman ng kanang panel.
- **View tabs:** isang tab para sa bawat view ng bukas na file (sheet, Plano, eksena...), sa ibabaw ng drawing.
- **Quick bar:** sa ilalim ng drawing, ang mga setting ng view at pang-araw-araw na opsyon na mayroon ang app, gaya ng scale, detail level, view range, fit, plan, split o 3D, snaps at units.
- **Edit palette:** i-click ang isang bagay sa drawing at may lilitaw na maliit na palette sa tabi ng pointer na may mga edit command ng app para dito, gaya ng move, copy, rotate, mirror, duplicate o delete, at ang {{ui:Properties}}. Itinatago ito ng {{key:Esc}}, ng mouse wheel, ng isa pang click o ng close button nito.

Naka-grey ang tool na hindi tumatakbo ngayon, at ipinapaliwanag ng tooltip nito kung bakit. I-click ito, o pindutin ang {{key:Enter}} dito, para mabasa ang dahilan sa isang kahon.

{{key:Esc}} ang unang tumatapos sa tumatakbong tool, gaya sa classic layout, at gumagana pa rin ang bawat shortcut at ang {{key:Ctrl+Shift+F}} (screen modes).

## Bigyan ng sariling window ang toolbox

Ang {{ui:Move the toolbox}} button sa itaas ng toolbox ay may {{ui:Move to a new window}}: bubukas ang toolbox sa makitid na window na sarili nito na maaari mong ilagay sa tabi ng app o sa pangalawang monitor. Umaabot sa app ang mga key na pinindot doon. Ang {{ui:Put the toolbox back}}, o ang pagsara sa window na iyon, ang nagbabalik nito.

Nalalapat din sa toolbox ang mga setting ng toolbar: {{ui:Mga setting}} › {{ui:Global}} › {{ui:Toolbar}} › {{ui:Icons and labels}}, {{ui:Icons only}} o {{ui:Labels only}}, at {{ui:Show group names (File, Draw, …)}}.

## Nananatili sa iyo ang mga panel mo

Pinapanatili ng kaliwa at kanang panel ang lahat ng inilarawan sa [Ayusin ang mga panel](common:arrange-panels): dock, float, pin, itago, tab, {{ui:Move to a new window}} at {{ui:Reset layout}}.

## Bumalik sa classic layout

Buksan ang {{ui:Mga setting}} › {{ui:Global}} › {{ui:Layout}} › {{ui:Workspace}} at piliin ang {{ui:CadCraft classic}}. Babalik ang bawat toolbar, tab at panel sa dating lugar.

:::note
Sa phone, o sa window na 760 pixels ang lapad o mas makitid, ginagamit ng app ang phone layout anuman ang pinili mo. Ibinabalik ng mas malapad na window ang layout mo.
:::

Para subukan ang ibang ayos, tingnan ang [ang layout ng ribbon at project browser](common:layout-ribbon).

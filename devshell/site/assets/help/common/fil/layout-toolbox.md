**Toolbox and info box** ay isa sa tatlong workspace layout ng app. Nakatayo ang mga tool sa pagguhit sa isang hanay sa kaliwa, may info box sa itaas na nagpapakita ng kailangan ng tumatakbong tool o ng napili mo, may tab ang bawat view, at may quick bar sa ilalim ng drawing na naglalaman ng ilang karaniwang opsyon. Sariling tool ng app ang mga ito: gumagana rin dito ang lahat ng magagawa mo sa classic layout, at mananatili ang drawing, istilo ng menu at mga susi mo.

## Piliin ito

1. Buksan ang {{ui:Mga setting}} (ang gear, o {{key:Mod+,}}).
2. Piliin ang {{ui:Global}} na tab, pagkatapos pumunta sa {{ui:Layout}} › {{ui:Workspace}}.
3. Piliin ang {{ui:Toolbox at info box}}.

Agad magbabago ang layout. Iisa ang pagpipiliang ito para sa bawat app sa browser na ito: magbubukas na ang bawat app dito mula noon, at nasa lugar na ito bago pa gumuhit ang pahina, kaya hindi mo muna nakikita ang classic layout.

## Nasaan ang bawat isa

- **Toolbar:** nananatili ang sariling toolbar ng app sa itaas ng drawing area, kasama ang mga menu nito.
- **Info box:** sa ilalim ng toolbar. Habang tumatakbo ang tool, ipinapakita nito ang tool at kung ano ang kailangan nito. Kapag pumili ka ng isang bagay, ipinapakita nito ang pangunahing setting nito (para sa wall: uri, kapal, haba, location line at taas), at puwede mo itong baguhin doon mismo: pareho ang epekto ng pagbabago rito sa Properties, at ibinabalik ito ng {{key:Mod+Z}}. Kapag walang napili, sinasabi nitong "Nothing selected". Nagdaragdag ang bawat app ng sarili nitong kahon dito, gaya ng kasalukuyang layer o level, o ang bukas na dokumento.
- **Toolbox:** ang hanay sa kaliwa, ang mga tool ng app sa mga grupo. I-click ang pangalan ng grupo para itupi o buksan ulit ito. Naiilawan ang tool na tumatakbo.
- **My tools:** ang unang grupo ng toolbox, na may walong walang lamang puwang para sa mga tool na madalas mong gamitin. I-click ang walang lamang puwang para pumili ng anumang tool o command ng app; o mag-right-click sa isang tool sa toolbox at piliin ang {{ui:Idagdag sa Mga tool ko}}; o i-drag ang tool papunta sa puwang. Mag-right-click sa puwang para palitan ito o alisan ng laman. Nananatili ang iyong mga puwang para sa bawat app sa browser na ito.
- **Navigator:** ang kanang panel. Nasa itaas ang project browser ng app (mga plan, section, elevation, 3D view, schedule, sheet, ayon sa mayroon ang app): i-click ang isa para buksan ito. Sa ilalim nito, ang {{ui:Properties}} at isang tab na may iba pang laman ng kanang panel.
- **View tabs:** isang tab para sa bawat view ng bukas na file (sheet, plan, scene…), sa ibabaw ng drawing.
- **Quick bar:** sa ilalim ng drawing, ang mga setting ng view at karaniwang opsyon na mayroon ang app, gaya ng scale, detail level, view range, fit, plan, split o 3D, snaps at units.
- **Edit palette:** i-click ang isang bagay sa drawing at may maliit na palette na lalabas sa tabi ng pointer, may mga edit command ng app para dito, gaya ng move, copy, rotate, mirror, duplicate o delete, at ang {{ui:Properties}}. Itatago ito ng {{key:Esc}}, ng mouse wheel, ng isa pang click o ng close button nito.

Naka-grey ang tool na hindi maaaring tumakbo ngayon, at sinasabi ng tooltip nito kung bakit. I-click ito, o pindutin ang {{key:Enter}} dito, para mabasa ang dahilan sa isang kahon.

Tinatapos muna ng {{key:Esc}} ang tumatakbong tool, gaya ng sa classic layout, at gumagana pa rin ang bawat shortcut at ang {{key:Ctrl+Shift+F}} (screen modes).

## Bigyan ng sariling window ang toolbox

Ang {{ui:Ilipat ang toolbox}} button sa itaas ng toolbox ay may {{ui:Ilipat sa bagong window}}: magbubukas ang toolbox sa makitid na window na sarili nitong puwedeng ilagay sa tabi ng app o sa pangalawang monitor. Nakakarating sa app ang mga susing pipindutin doon. Ibinabalik ito ng {{ui:Ibalik ang toolbox}}, o ng pagsara sa window na iyon.

Nalalapat din sa toolbox ang mga setting ng toolbar: {{ui:Mga setting}} › {{ui:Global}} › {{ui:Toolbar}} › {{ui:Mga icon at label}}, {{ui:Mga icon lang}} o {{ui:Mga label lang}}, at {{ui:Ipakita ang pangalan ng grupo (File, Draw, …)}}.

## Nananatiling sa iyo ang mga panel mo

Ang kaliwa at kanang panel ay nagtataglay ng lahat ng nakasaad sa [Ayusin ang mga panel](common:arrange-panels): i-dock, lumutang, i-pin, itago, tab, {{ui:Ilipat sa bagong window}} at {{ui:I-reset ang layout}}.

## Bumalik sa classic layout

Buksan ang {{ui:Mga setting}} › {{ui:Global}} › {{ui:Layout}} › {{ui:Workspace}} at piliin ang {{ui:CadCraft classic}}. Babalik ang bawat toolbar, tab at panel sa dati nitong lugar.

:::note
Sa phone, o sa window na 760 pixels ang lapad o mas makitid, ginagamit ng app ang phone layout anuman ang napili mo. Ibabalik ng mas malapad na window ang layout mo.
:::

Para subukan ang ibang ayos, tingnan ang [ang ribbon at project browser layout](common:layout-ribbon).

Para baguhin ang ipinapakita ng layout na ito, tingnan ang [Baguhin ang layout sa screen](common:layout-edit); para sa madilim na ayos na may menu bar at ribbon, tingnan ang [ang Drafting layout](common:layout-drafting).

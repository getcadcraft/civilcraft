Ginagawa ng mga app ang trabaho nila sa sarili mong computer, kaya karamihan dito ay gumagana nang walang koneksyon. Kailangan lang ng browser na naka-save na ang mga file ng app.

## I-save ang app para sa offline na paggamit

1. Buksan ang app habang online ka.
2. Piliin ang {{ui:Save for offline}} sa bar sa itaas.
3. Hintayin ang "Offline ready". Naka-save na ngayon sa browser mo ang mga file ng app, ang mga file reader nito, at ang help na ito. Ang mga app na nagbabasa ng DWG o PDF na file ay sine-save din ang mga reader nila, kaya maaaring tumagal ng isang minuto ang unang pagkakataon.

Gawin ito minsan kada app, sa bawat browser na ginagamit mo. Para bumalik sa app kalaunan nang walang koneksyon, buksan ang parehong address na ginamit mo dati, o isang bookmark nito.

:::offline
Offline ka ngayon. Kung na-save para sa offline na paggamit ang app na ito, gumagana ang lahat ng nasa ibaba. Kung hindi, magagamit mo pa rin ang nai-load na sa tab na ito, pero huwag itong i-reload hanggang maging online ka muli.
:::

## Ano ang gumagana offline

- Pagbukas ng mga file mula sa computer mo, pag-drawing, pag-edit, pagsukat at pagsuri.
- Pag-save at pag-export: bawat save ay isang download sa computer mo.
- Ang help na ito, kasama ang paghahanap.

## Ano ang nangangailangan ng koneksyon

- Pagbukas ng app sa unang pagkakataon, at pag-save nito para sa offline na paggamit.
- Pagkuha ng mas bagong bersyon ng app. Kapag online ka, kukunin ng app ang pinakabagong bersyon sa susunod nitong pagbukas, at nire-refresh ng {{ui:Save for offline}} ang naka-save na kopya.
- Mga link papunta sa website, gaya ng {{ui:Open on the website}} at mga link sa ibang pahina.
- Cloud saving at sync sa pagitan ng mga computer, na hindi pa available.

## Mga dapat malaman

- Ang naka-save na kopya ay nasa isang browser sa isang computer. Ang paglilinis ng site data ng browser ay nag-aalis nito.
- Ang private windows sa ilang browser, at ang ilang naka-lock na work computer, ay hindi pinapayagan ang offline saving. Sinasabi ng button kapag hindi ito makapag-save.

:::safari
Inaalis ng Safari ang naka-save na site data mula sa mga site na hindi mo nabisita nang ilang linggo. Buksan paminsan-minsan ang app habang online, o i-save muli bago bumiyahe.
:::

## Nananatili sa computer mo ang mga file

Kapag nagbukas ka ng drawing, model o PDF, binabasa ito ng app sa loob ng browser mo. **Hindi ina-upload ang file.** Hindi namin ito nakikita, at pareho ang gumagana nito kahit walang koneksyon.

## Paano gumagana ang pag-save

Hindi kayang i-overwrite ng web page ang mga file sa computer mo nang mag-isa, kaya nagse-save ang mga app sa pamamagitan ng **pag-download** ng bagong file:

- Pupunta ang download kung saan inilalagay ito ng browser mo, kadalasan sa folder na Downloads, maliban kung itinakda mo ang browser na magtanong sa bawat pagkakataon (tingnan ang [Mga browser at computer](common:browsers#ano-ang-pagkakaiba-ng-mga-browser)).
- Ang mga app na nagbabago ng file ay nagse-save ng kopya na may bagong pangalan, gaya ng "(edited)" o "(marked up)", para manatiling buo ang orihinal mo.
- Kung isasara mo ang tab na may hindi pa nasi-save na gawa, itatanong muna ito ng browser ("Leave site?").

## Ano ang inaalala ng browser

May ilang app na nag-aalala ng maliliit na setting sa browser mo, gaya ng pangalan ng may-akda o estilo ng tool. Nananatili ang mga ito sa browser na iyon sa computer na iyon, at inaalis sila ng paglilinis ng site data. Sinasabi ng help ng bawat app kung ano ang iniingatan nito.

## Cloud saving

Ang cloud saving at sync sa pagitan ng mga computer ay bahagi ng commercial license. Hindi pa ito available. Hanggang noon, itago ang mga file mo kung saan mo itinatago ang iba mong project file, at i-back up ang mga ito sa karaniwang paraan.

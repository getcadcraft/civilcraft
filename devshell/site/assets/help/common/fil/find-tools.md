Bawat app ay may search box para sa mga tool nito, mga setting nito at sa help na ito. Hindi mo kailangang malaman kung saan nakalagay ang tool sa toolbar.

## Hanapin at patakbuhin

1. Pindutin ang {{key:Mod+K}}, o piliin ang {{ui:Hanapin}} sa bar sa itaas.
2. Mag-type ng ilang letra ng hinahanap mo: "fillet", "panel text", "units". Dapat tumugma ang bawat salitang ita-type mo, kaya magdagdag ng pangalawang salita para paliitin ang listahan.
3. Pindutin ang {{key:Enter}} para patakbuhin ang unang tugma, o gumalaw muna gamit ang arrow keys. Isinasara ng {{key:Esc}} ang box.

Tumatakbo ang tool na parang na-click mo ito sa toolbar. Ang setting ay nagbubukas ng {{ui:Mga setting}} sa mismong setting na iyon. Ang help topic ay bumubukas dito, sa help panel.

## Mga dapat malaman

- Ang ginamit mo nang huli ang nasa unahan sa susunod, kaya ang tool na madalas mong gamitin ay isang key press lang ang layo.
- Nakalista pero naka-grey out ang mga tool na hindi tumatakbo ngayon, halimbawa bago pa may bukas na file.
- Kasama rin sa listahan ang mga tool ng add-on, kapag naka-on na ang add-on.

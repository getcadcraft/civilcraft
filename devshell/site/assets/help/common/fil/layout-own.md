Bukod sa tatlong nakahandang layout, puwede kang mag-ayos ng sarili mong layout, at i-save ang buo mong setup sa ilalim ng pangalan para makabalik dito sa isang hakbang lang.

## Ayusin ang sarili mong layout

1. Buksan ang {{ui:Mga setting}} (ang gear, o {{key:Mod+,}}), piliin ang {{ui:Global}}, pagkatapos {{ui:Layout}}.
2. Piliin ang {{ui:Ayusin ang sarili kong layout…}}. Nagsisimula ang dialog sa layout na ginagamit mo ngayon.
3. Bigyan ito ng pangalan, pagkatapos piliin:
   - **Sa ibabaw ng drawing:** ang toolbar ng app, ribbon o wala; title bar; info box at kung aling kontrol ang hawak nito.
   - **Sa tabi ng drawing:** ang toolbox sa kaliwa, sa kanan o wala, kasama o walang {{ui:Mga tool ko}}; aling panel ang may mga palette, alin ang nasa itaas (ang project browser o Properties, halimbawa), at alin ang mga tab sa ilalim nito.
   - **Ang drawing area:** view tabs, quick bar at view bar na may mga kontrol na pipiliin mo, ang edit palette, status bar.
   - **Itsura:** laki, outline ng button at estilo ng tab.
4. Piliin ang {{ui:Gamitin ang layout na ito}}. Agad lilipat ang app dito, at gagamitin ito ng bawat app na may layout.

Ang inaalok lang ay ang mayroon sa app na ito. Lalabas ang layout mo sa ilalim ng {{ui:Mula sa mga add-on at file}}; ang {{ui:I-export ang layout na ito}} ay nagse-save nito bilang file na maibibigay mo sa kasamahan, at ang Alisin button ang nag-aalis nito. Ang mga panel na pinupunan nito ay nagda-dock, lumulutang at lumilipat pa rin sa sarili nilang window, gaya ng nasa [Ayusin ang mga panel](common:arrange-panels).

## I-save ang setup mo bilang work environment

Ang work environment ay ang buong setup mo para sa bawat app sa browser na ito: ang layout, ang estilo ng menu at mga key mo, ang estilo ng toolbar, ang mga panel at ang laki ng mga ito, at ang {{ui:Mga tool ko}}. Hindi kasama rito ang tema at wika.

- **I-save:** mag-type ng pangalan sa ilalim ng {{ui:Mga work environment}} at piliin ang {{ui:I-save ang setup ko}}. Ang pag-save sa pangalang mayroon na ay pumapalit sa setup na iyon.
- **Lumipat:** pumili ng setup sa listahan at piliin ang {{ui:Lumipat dito}}. Ni-reload ng app sa setup na iyon; kung may hindi pa nasi-save na gawa, itatanong muna ito ng app, gaya ng sa anumang reload.
- **Ibahagi:** ang {{ui:Export}} ay nagse-save ng piniling setup bilang `.ccenv.json` na file; ang {{ui:Import a setup…}} ay nagdadagdag ng isa mula sa file. Ang file ay nagtatakda lamang ng mga pagpiling ito, wala nang iba.
- **Alisin:** pumili ng setup at piliin ang {{ui:Remove}}.

Hanggang labindalawang setup ang puwede mong itago.

Para subukan muna ang mga nakahandang ayos, tingnan ang [ang layout ng toolbox at info box](common:layout-toolbox) at [ang layout ng ribbon at project browser](common:layout-ribbon).

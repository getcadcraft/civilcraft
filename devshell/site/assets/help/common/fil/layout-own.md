Bukod sa tatlong nakahandang layout, puwede kang mag-ayos ng sarili mong layout, at i-save ang buong setup mo sa ilalim ng pangalan para makabalik dito sa isang hakbang lang.

## Ayusin ang sarili mong layout

1. Buksan ang {{ui:Mga setting}} (ang gear, o {{key:Mod+,}}), piliin ang {{ui:Global}}, pagkatapos {{ui:Layout}}.
2. Piliin ang {{ui:Ayusin ang sarili kong layout…}}. Nagsisimula ang dialog sa layout na ginagamit mo ngayon.
3. Bigyan ito ng pangalan, pagkatapos piliin ang:
   - **Sa ibabaw ng drawing:** ang toolbar ng app, isang ribbon o wala; isang title bar; isang info box at kung aling mga control ang laman nito.
   - **Sa tabi ng drawing:** ang toolbox sa kaliwa, sa kanan o wala, kasama o walang {{ui:Mga tool ko}}; aling panel ang may hawak ng mga palette, alin ang nasa itaas (ang project browser o Properties, halimbawa), at alin ang mga tab sa ilalim nito.
   - **Ang drawing area:** mga view tab, isang quick bar at view bar na may mga control na lagyan mo ng tsek, ang edit palette, isang status bar.
   - **Itsura:** laki, button outline at istilo ng tab.
4. Piliin ang {{ui:Gamitin ang layout na ito}}. Agad lilipat ang app dito, at gagamitin din ito ng bawat app na may layout.

Tanging ang mayroon sa app na ito ang iaalok. Makikita ang layout mo sa ilalim ng {{ui:Mula sa mga add-on at file}}; ise-save ng {{ui:I-export ang layout na ito}} ito bilang file na maibibigay mo sa katrabaho, at inaalis ito ng remove button. Ang mga panel na sakop nito ay nagdo-dock, lumulutang at napupunta sa sarili nilang window, gaya ng nasa [Ayusin ang mga panel](common:arrange-panels).

## I-save ang setup mo bilang work environment

Ang work environment ay ang buong setup mo para sa bawat app sa browser na ito: ang layout, istilo ng menu at mga susi mo, istilo ng toolbar, mga panel at ang laki ng mga ito, at ang {{ui:Mga tool ko}}. Hindi kasama rito ang tema at wika.

- **I-save:** mag-type ng pangalan sa ilalim ng {{ui:Mga work environment}} at piliin ang {{ui:I-save ang setup ko}}. Ang pag-save sa pangalang mayroon na ay papalitan ang setup na iyon.
- **Lumipat:** pumili ng setup sa listahan at piliin ang {{ui:Lumipat dito}}. Mag-re-reload ang app sa setup na iyon; kung may hindi pa na-save na gawa, magtatanong muna ang app, gaya ng ginagawa nito sa anumang reload.
- **Ibahagi:** ise-save ng {{ui:I-export}} ang napiling setup bilang file na `.ccenv.json`; ang {{ui:Mag-import ng setup…}} ay nagdadagdag ng isa mula sa file. Ang file ay nagtatakda lang ng mga pagpipiliang ito, wala nang iba.
- **Alisin:** pumili ng setup at piliin ang {{ui:Alisin}}.

Puwede kang magkaroon ng hanggang labindalawang setup.

Para baguhin ang layout nang hindi binubuksan ang dialog (mag-drag ng block, mag-right-click ng tool), tingnan ang [Baguhin ang layout sa screen](common:layout-edit). Para subukan muna ang mga nakahandang ayos, tingnan ang [ang toolbox at info box layout](common:layout-toolbox), [ang ribbon at project browser layout](common:layout-ribbon) at [ang Drafting layout](common:layout-drafting).

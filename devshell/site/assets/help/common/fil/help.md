Bawat app ay may sarili nitong help. Bahagi ito ng app, kaya nabubuksan ito kahit walang koneksyon at palaging inilalarawan ang bersyong ginagamit mo.

## Buksan ang help

- Pindutin ang {{key:F1}}, o piliin ang {{ui:Help}} sa bar sa itaas ng app.
- Pindutin ang {{key:Esc}} o piliin ang {{ui:Close}} para itago ito. Nananatili ang drawing mo gaya ng dati.

:::mac
Sa karamihan ng Mac keyboard, kinokontrol ng itaas na row ang liwanag at tunog. Pindutin ang {{key:F1}} kasama ang **fn** key (o ang globe key), o gamitin ang {{ui:Help}} button. Tingnan ang [Mga key sa Mac](common:keys#function-keys-sa-mac).
:::

## Maghanap ng topic

- Mag-type sa search box sa itaas ng help. Nag-a-update ang mga resulta habang nagta-type ka, at kasama rito ang command names ng ibang programa, kaya kadalasang nahahanap ang tamang pahina sa pag-type ng kung ano ang ita-type mo sa ibang lugar.
- Pareho ang pagkakapangkat ng mga topic sa bawat app: pagsisimula, mga walkthrough, galing sa ibang software, reference, at troubleshooting.
- Ang mga link sa loob ng topic ay nagbubukas ng susunod na topic sa parehong panel. Ibinabalik ka ng {{ui:Back}} sa pinanggalingan mo.

## Mga hakbang para sa iyong computer

May ilang hakbang na nagkakaiba sa pagitan ng Mac, Windows at Linux, sa pagitan ng mga browser, at sa pagitan ng online at offline. Tinutukoy ng help kung alin ang angkop sa iyo at ipinapakita ang mga iyon. Sinasabi ng linya sa itaas ng topic kung ano ang pinili nito, halimbawa "Nagpapakita ng mga hakbang para sa Mac, Chrome o Edge, online".

- Piliin ang {{ui:Change}} sa linyang iyon para pumili ng ibang computer o browser, halimbawa para tulungan ang kasamahan.
- Piliin ang {{ui:Show all}} para makita ang bawat bersyon ng bawat hakbang, bawat isa may label.

Isinusulat ang mga keyboard shortcut ayon sa pagkakalagay ng label sa keyboard mo: ang {{key:Mod+S}} ay binabasa bilang ⌘S sa Mac at Ctrl+S sa Windows at Linux.

## Ang parehong help sa website

Ipinapakita ng website ang parehong topic sa getcadcraft.com/tutorials, kasama ang mga hakbang ng bawat platform. Sa app, binubuksan ng {{ui:Open on the website}} sa ibaba ng topic ang pahinang iyon kapag online ka.

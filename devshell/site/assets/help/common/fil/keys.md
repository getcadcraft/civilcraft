## Paano isinusulat ang mga shortcut

Isinusulat ng help ang bawat shortcut ayon sa pagkakalagay ng label nito sa keyboard mo.

| Nakasulat | Sa Mac | Sa Windows at Linux |
|---|---|---|
| {{key:Mod+S}} | Command (⌘) at S | Ctrl at S |
| {{key:Ctrl+Shift+F}} | Control (⌃), Shift (⇧) at F | Ctrl, Shift at F |
| {{key:Alt+Left}} | Option (⌥) at ← | Alt at ← |
| {{key:Backspace}} | ang Delete key | Backspace |
| {{key:Delete}} | fn at Delete (forward delete) | Delete |
| {{key:Enter}} | Return | Enter |

Ang plus sign ay nangangahulugang pindutin nang sabay ang mga key. Ang "Then" ay nangangahulugang pindutin ang isa, saka ang susunod.

Karamihan sa shortcut ng app ay tumatanggap ng Command o Control sa Mac, kaya gumagana ang {{key:Mod+Z}} sa dalawang paraan. Ang ilan, gaya ng full screen ({{key:Ctrl+Shift+F}}), ay gumagamit ng Control key sa bawat computer; sinasabi ito ng help kung saan ito naaangkop.

## Function keys sa Mac

Sa karamihan ng Mac keyboard, binabago ng itaas na row ang liwanag, volume at media. Para maipadala ang F1 hanggang F12:

- pindutin ang **fn** (o ang globe key) habang pinipindot ang key, o
- buksan ang **System Settings**, pagkatapos **Keyboard**, pagkatapos **Keyboard Shortcuts**, pagkatapos **Function Keys**, at i-on ang "Use F1, F2, etc. keys as standard function keys".

Inaangkin din ng macOS mismo ang ilang F-key (halimbawa ang Mission Control). Kung walang nangyayari sa app ang isang key, subukan ito gamit ang fn, o gamitin ang button sa toolbar.

## Mga shortcut na pinananatili ng browser

Hindi makukuha ng web page ang ilang shortcut mula sa browser, anuman ang gawin nito. Sa bawat app:

- {{key:Mod+N}}, {{key:Mod+T}} at {{key:Mod+W}} ay palaging nagbubukas o nagsasara ng browser windows at tabs. Gumagamit ang mga app ng button para sa Bago at Isara.
- {{key:Mod+Q}} sa Mac at {{key:Alt+F4}} sa Windows ay nagsasara ng browser. Kung may hindi pa nasi-save na gawa, itatanong muna ng browser ("Leave site?"); piliin ang manatili, pagkatapos i-save.
- Gumagana pa rin ang sariling full screen ng browser ({{pick:mac=Control-Command-F, o ang berdeng button sa window|windows linux=F11}}). May sariling screen mode din ang mga app sa {{key:Ctrl+Shift+F}}, na maaari ring magtago ng mga bar ng app.

## Mga mouse button sa trackpad

Ginagamit ng mga app ang kanang button at ang gitnang button. Kung walang three-button mouse:

:::mac
- **Right-click:** mag-click gamit ang dalawang daliri. I-on ang "Secondary click" sa **System Settings**, pagkatapos **Trackpad**, kung walang nangyayari sa two-finger click. Ang pagpindot ng {{key:Ctrl}} habang nag-click ay nagbubukas ng menu ng browser, pero sa loob ng drawing ay binabasa ito ng ilang app bilang ordinaryong click (may hawak na Control), kaya mas mabuting gamitin ang two-finger click.
- **Middle-button drag (pan):** may iba't ibang paraan ang bawat app para mag-pan, gaya ng pagpindot sa {{key:Space}} habang nag-drag o pag-drag gamit ang kanang button. Sinasabi ng keyboard page ng app kung alin.
- **Wheel zoom:** ang two-finger scroll sa trackpad ay nag-zoom in sa karamihan ng app. Nag-zoom din ang pinch kung sinusuportahan ito ng app.
:::

:::windows linux
- **Right-click:** mag-click gamit ang dalawang daliri, o i-click ang kanang ibabang sulok ng touchpad. Nakadepende ito sa setting ng touchpad mo.
- **Middle-button drag (pan):** may iba't ibang paraan ang bawat app para mag-pan, gaya ng pagpindot sa {{key:Space}} habang nag-drag o pag-drag gamit ang kanang button. Sinasabi ng keyboard page ng app kung alin.
- **Wheel zoom:** ang two-finger scroll sa touchpad ay nag-zoom in sa karamihan ng app.
:::

## Pag-type sa text box

Habang nagta-type ka sa kahon (pangalan, tala, paghahanap), naka-off ang mga one-letter shortcut ng app, kaya ang pag-type ng "L" ay nagta-type ng L. Pindutin ang {{key:Esc}} o i-click ang drawing para maibalik sa app ang mga key.

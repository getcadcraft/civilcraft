هره برنامه خپله مرسته لري. دا د برنامې برخه ده، نو له اړیکې پرته پرانیستل کېږي او تل هغه نسخه بیانوي چې تاسو یې چلوئ.

## مرسته خلاصه کړئ

- {{key:F1}} کېږئ، یا د برنامې پورنۍ بار کې {{ui:مرسته}} وټاکئ.
- {{key:Esc}} کېږئ یا {{ui:بندول}} وټاکئ ترڅو یې لرې کړئ. ستاسو نقشه همغسې پاتې کېږي.

:::mac
په ډېرو Mac کیبورډونو کې پورتنۍ قطار رڼا او غږ کنټرولوي. {{key:F1}} د **fn** کیلي (یا کره کیلي) سره ووهئ، یا د {{ui:مرسته}} تڼۍ وکاروئ. وګورئ [کیلي په Mac کې](common:keys#function-keys-on-a-mac).
:::

## یوه موضوع ومومئ

- د مرستې پورتنۍ برخې کې لټون بکس ته ولیکئ. پایلې ستاسو د ټایپ کولو سره تازه کېږي او نورې برنامې ته د کمانډ نومونه هم شامل دي، نو هغه څه چې بل ځای ټایپ کوئ معمولاً سمه پاڼه موندلی شي.
- موضوعات په هرې برنامه کې په ورته ډول ګروپ شوي دي: پیل کول، لارښوونې، د بلې سافټویر څخه راتلل، حوالې، او ستونزې.
- د موضوع دننه لینکونه په ورته پینل کې راتلونکی موضوع خلاصوي. {{ui:بېرته}} تاسو هغه ځای ته بیرته راولي چېرې چې وۀ.

## ستاسو کمپیوټر لپاره ګامونه

ځینې ګامونه د Mac، Windows او Linux ترمنځ، د براوزرونو ترمنځ، او د اړیکې سره یا پرته توپیر لري. مرسته دا معلوموي چې ستاسو لپاره کوم پلي کېږي او هغه ګامونه ښيي. د موضوع په پورتنۍ کرښه کې لیکل شوي دي هغه څه چې غوره کړي، د مثال په توګه "Mac، Chrome یا Edge لپاره ګامونه ښودل کېږي، آنلاین".

- د دې کرښې {{ui:بدلول}} وټاکئ ترڅو بل کمپیوټر یا براوزر وټاکئ، د مثال په توګه کله چې همکار سره مرسته کوئ.
- {{ui:ټول ښکاره کول}} وټاکئ ترڅو د هرې ګام هره نسخه وګورئ، هر یو لیبل شوی.

د کیبورډ لنډلارې هغسې لیکل کېږي لکه څنګه چې ستاسو کیبورډ یې لیبل کوي: {{key:Mod+S}} په Mac کې ⌘S او په Windows او Linux کې Ctrl+S ښيي.

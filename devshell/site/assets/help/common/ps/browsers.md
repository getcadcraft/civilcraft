برنامې د ویب براوزر دننه چلېږي. دوی کار ستاسو په خپل کمپیوټر کې کوي: ستاسو فایلونه هلته پرانیستل کېږي او هېڅکله موږ ته نه لېږل کېږي (وګورئ [ستاسو فایلونه چیرې ځي](common:your-files)).

## کومه براوزر

یو له دې څخه تازه نسخه وکاروئ:

| براوزر | انجن | یادښتونه |
|---|---|---|
| Chrome، Edge، Brave، Opera، Vivaldi | Chromium | ترټولو بشپړ: د فولډر ټاکل، د افلاین کارولو لپاره خوندي کول، د فایلونو اداره. |
| Firefox | Gecko | کار کوي. د بشپړ فولډر پرانیستل ساده ټاکونکی کاروي. افلاین خوندي کول ممکن په خصوصي کړکیو کې کار ونه کړي. |
| Safari | WebKit | د Mac او iPad کې کار کوي. د بشپړ فولډر پرانیستل ساده ټاکونکی کاروي. Safari ممکن هغه افلاین کاپي ړنګه کړي چې د څو اونیو لپاره مو ونه کارولې. |

ټول درې انجنونه د ورځنۍ کار لپاره ښه دي. که یوه برنامه په یو انجن کې بل ډول کار وکړي، د هغې مرسته به ستاسو براوزر لپاره ګامونه وښيي.

## د براوزرونو ترمنځ توپیر

- **فولډر پرانیستل.** Chromium براوزرونه ریښتیني فولډر ټاکونکی ښيي او فولډر په مستقیم ډول لوستلی شي. Firefox او Safari له تاسو غواړي یو فولډر وټاکئ او بیا هر فایل لولي، چې د لویو پروژو فولډرونو لپاره ډېر وخت نیسي؛ فولډر په برنامه کې کش کول په ټولو درې کې کار کوي.
- **خوندي کول.** برنامې فایل ښکته کولو له لارې خوندي کوي. ستاسو براوزر پریکړه کوي چې ښکته کېدونه چیرې ځي او ایا لومړی پوښتي.

:::chromium
په Chrome یا Edge کې، "Ask where to save each file before downloading" فعال کړئ (په Settings کې، Downloads لاندې) ترڅو هر ځل فولډر وټاکئ.
:::

:::firefox
په Firefox کې Settings خلاص کړئ، بیا General، بیا Downloads، او "Always ask you where to save files" وټاکئ ترڅو هر ځل فولډر وټاکئ.
:::

:::safari
په Safari کې Settings خلاص کړئ، بیا General، او "File download location" په "Ask for each download" وټاکئ ترڅو هر ځل فولډر وټاکئ.
:::

## Mac، Windows او Linux

برنامې په هر کمپیوټر کې یوې ډول دي. هغه څه چې بدلېږي کیبورډ دی: لنډلارې ستاسو کمپیوټر لپاره اتومات لیکل شوې دي. وګورئ [کیلي، ماوسونه او ټچ پډونه](common:keys).

## ټابلټونه او ټچ سکرینونه

ځینې برنامې ټچ مني (یوه ګوته نقشه کاږي یا ټاکي، دوه ګوتې زوم او خوځول کوي). د هرې برنامې مرسته وایي چې دا کار کوي که نه. په iPad کې Safari یا Chrome وکاروئ. کیبورډ د هغو برنامو سره مرسته کوي چې ټایپ شوي کمانډونه کاروي.

## لرغونې براوزر او سیستم

موږ دا د 0.7 برنامو له کوډ څخه لولو، نه له اټکل: هر فایل تحلیل شو او هر ژبنۍ ځانګړتیا چې کاروي د براوزرونو خپرې شوي مطابقت معلوماتو کې وکتل شوه. دې نسخو ته ښکته برنامې اصلاً نشي پیلېدلی، ځکه براوزر کوډ نه پوهیږي.

| | ترټولو زوړه نسخه چې برنامې پیلولی شي |
|---|---|
| Chrome، Edge، Brave، Opera، Vivaldi | Chromium 94 |
| Firefox | 93 |
| Safari (Mac، iPad، iPhone) | 16.4 (macOS 13.3، iPadOS او iOS 16.4) |

CadCraft Studio په Windows کې خپل وب انجن لري، نو Windows 10 یا 11 ته اړتیا لري؛ په Mac کې د سیستم انجن کاروي، نو macOS 13.3 یا نوي ته اړتیا لري. په Studio کې Settings › Updates ښيي چې ستاسو نسخه پرې چلېږي.

دا ترټولو زوړه نسخه ده چې *پیلېږي*، له کوډ څخه لوستل شوې. دا د زړو براوزرونو لیست نه دی چې موږ پکې برنامې چلولې؛ نو زوړ براوزر چې پیلېږي بیا هم ممکن یوه ځانګړتیا ونه لري.

## ستاسو کمپیوټر ته څه اړتیا ده

دا د برنامو پلان شوي لږ ترلږه اړتیاوې دي، نه اندازه شوې اړتیاوې:

- 8 GB حافظه (لویو یوځای شوو ماډلونو لپاره 16 GB وړاندیز کېږي).
- د 3D برنامو لپاره WebGL 2 ملاتړ کوونکی ګرافیک چپ. که 3D لید تور پاتې شي، وګورئ چې ستاسو د براوزر په امستنو کې ګړندی کول فعال دي.
- د بشپړو وسیلو پټو لپاره لږ تر لږه 1280 پکسله پلن سکرین. کوچني سکرینونه یې قطارونو ته اړوي.

خورا لوی فایلونه (لوی پلان سیټونه، لوی ماډلونه) په براوزر ټب کې ډېر حافظه کاروي. که برنامه ورو شي، نور ګرانې ټبونه وتړئ.

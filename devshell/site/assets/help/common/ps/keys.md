## لنډلارې څنګه لیکل کېږي

مرسته هره لنډلاره داسې لیکي لکه څنګه چې ستاسو کیبورډ یې لیبل کوي.

| لیکل شوې | په Mac | په Windows او Linux |
|---|---|---|
| {{key:Mod+S}} | Command (⌘) او S | Ctrl او S |
| {{key:Ctrl+Shift+F}} | Control (⌃)، Shift (⇧) او F | Ctrl، Shift او F |
| {{key:Alt+Left}} | Option (⌥) او ← | Alt او ← |
| {{key:Backspace}} | د Delete کیلي | Backspace |
| {{key:Delete}} | fn او Delete (forward delete) | Delete |
| {{key:Enter}} | Return | Enter |

د جمع نښه یعنې کیلي یوځای ونیسئ. "بیا" یعنې یو په یو ووهئ.

اکثره د برنامې لنډلارې په Mac کې Command یا Control مني، نو {{key:Mod+Z}} په دواړو لارو کار کوي. ځینې، لکه بشپړ سکرین ({{key:Ctrl+Shift+F}})، په هر کمپیوټر کې Control کاروي؛ مرسته ښيي چیرې چې دا پلي کېږي.

## د Mac فعالیت کیلي

په ډېرو Mac کیبورډونو کې پورتنۍ قطار رڼا، غږ او رسنۍ بدلوي. د F1 څخه تر F12 پورې لېږلو لپاره:

- د F-کیلي پرمهال **fn** (یا کره کیلي) ونیسئ، یا
- **System Settings** خلاص کړئ، بیا **Keyboard**، بیا **Keyboard Shortcuts**، بیا **Function Keys**، او "F1، F2 او نور کیلي د معیاري فعالیت کیلي په توګه وکاروئ" فعال کړئ.

ځینې F-کیلي د macOS لخوا هم ادعا کېږي (مثلاً Mission Control). که کیلي په برنامه کې هېڅ ونه کړي، هغه د fn سره وازمویئ، یا د وسیلې پټې تڼۍ وکاروئ.

## هغه لنډلارې چې براوزر یې ساتي

ویب پاڼه نشي کولی ځینې لنډلارې له براوزره واخلي، هر څه چې وکړي. په هره برنامه کې:

- {{key:Mod+N}}، {{key:Mod+T}} او {{key:Mod+W}} تل براوزر کړکۍ او ټبونه پرانیزي یا تړي. برنامې د نوي او تړلو لپاره تڼۍ کاروي.
- {{key:Mod+Q}} په Mac کې او {{key:Alt+F4}} په Windows کې براوزر بندوي. که ستاسو کار نه دی خوندي شوی، براوزر لومړی پوښتي ("Leave site?")؛ پاتې کېږئ، بیا خوندي کړئ.
- د براوزر بشپړ سکرین ({{pick:mac=Control-Command-F، یا د کړکۍ شنه تڼۍ|windows linux=F11}}) اوس هم کار کوي. برنامې خپل سکرین حالتونه په {{key:Ctrl+Shift+F}} کې لري، کوم چې د برنامې بارونه هم پټولی شي.

## د ټچ پډ ماوس تڼۍ

برنامې ښۍ تڼۍ او منځنۍ تڼۍ کاروي. که درې تڼۍ ماوس نه لرئ:

:::mac
- **ښی کلیک:** په دوو ګوتو کلیک وکړئ. که دوه ګوتې کلیک کار ونه کړي، په **System Settings** کې **Trackpad** ته ولاړ شئ او "Secondary click" فعال کړئ. د {{key:Ctrl}} ساتل کله چې کلیک کوئ د براوزر مینو پرانیزي، خو په نقشه کې ځینې برنامې دا د عادي کلیک په توګه لولي (د Control سره)، نو دوه ګوتې کلیک ترجیح ورکړئ.
- **منځنۍ تڼۍ کش (خوځول):** هره برنامه د خوځولو بله لاره وړاندې کوي، لکه {{key:Space}} ساتل پداسې حال کې چې کش کوئ یا د ښۍ تڼۍ سره کش کول. د برنامې د کیبورډ پاڼه ووایي کومه.
- **د څرخ زوم:** په ټچ پډ کې دوه ګوتو سکرول په ډېرو برنامو کې زوم کوي. پینچ هم زوم کوي که برنامه یې ملاتړ کوي.
:::

:::windows linux
- **ښی کلیک:** په دوو ګوتو کلیک وکړئ، یا د ټچ پډ ښکته ښي کنج کلیک کړئ. دا ستاسو د ټچ پډ امستنو پورې اړه لري.
- **منځنۍ تڼۍ کش (خوځول):** هره برنامه د خوځولو بله لاره وړاندې کوي، لکه {{key:Space}} ساتل پداسې حال کې چې کش کوئ یا د ښۍ تڼۍ سره کش کول. د برنامې د کیبورډ پاڼه ووایي کومه.
- **د څرخ زوم:** په ټچ پډ کې دوه ګوتو سکرول په ډېرو برنامو کې زوم کوي.
:::

## په متن بکس کې ټایپ کول

کله چې په بکس کې ټایپ کوئ (نوم، یادښت، لټون)، د برنامې یو تور لنډلارې بندې وي، نو "L" ټایپ کول L لیکي. {{key:Esc}} وټاکئ یا په نقشه کلیک وکړئ ترڅو کیلي بیرته برنامې ته ورکړئ.

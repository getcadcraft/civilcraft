ஆப்கள் ஒரு இணைய உலாவிக்குள் இயங்குகின்றன. அவை வேலையை உங்கள் சொந்தக் கணினியிலேயே செய்கின்றன: உங்கள் கோப்புகள் அங்கேயே திறக்கப்படுகின்றன, எங்களுக்கு ஒருபோதும் அனுப்பப்படுவதில்லை ([உங்கள் கோப்புகள் எங்கே செல்கின்றன](common:your-files) பகுதியைப் பார்க்கவும்).

## எந்த உலாவி

இவற்றில் ஒன்றின் புதுப்பிக்கப்பட்ட பதிப்பைப் பயன்படுத்தவும்:

| உலாவி | இயந்திரம் | குறிப்புகள் |
|---|---|---|
| Chrome, Edge, Brave, Opera, Vivaldi | Chromium | மிகவும் முழுமையானது: கோப்புறைத் தேர்வு, இணைப்பின்றிப் பயன்படுத்தச் சேமித்தல், கோப்புக் கையாளுதல். |
| Firefox | Gecko | செயல்படும். முழு கோப்புறையைத் திறக்க எளிய தேர்வியைப் பயன்படுத்துகிறது. தனிப்பட்ட சாளரங்களில் இணைப்பின்றிச் சேமிப்பு செயல்படாமல் போகலாம். |
| Safari | WebKit | Mac மற்றும் iPad இல் செயல்படும். முழு கோப்புறையைத் திறக்க எளிய தேர்வியைப் பயன்படுத்துகிறது. சில வாரங்களாகப் பயன்படுத்தாத இணைப்பின்றி நகலை Safari நீக்கிவிடலாம். |

அன்றாட வேலைக்கு மூன்று இயந்திரங்களுமே போதுமானவை. ஒரு ஆப் அவற்றில் ஒன்றில் மட்டும் வேறுபட்டுச் செயல்பட்டால், அதன் உதவி உங்கள் உலாவிக்கான படிகளைக் காட்டும்.

## உலாவிகளுக்கிடையே என்ன வேறுபடுகிறது

- **கோப்புறையைத் திறத்தல்.** Chromium உலாவிகள் உண்மையான கோப்புறைத் தேர்வியைக் காட்டி, கோப்புறையை நேரடியாகப் படிக்க முடியும். Firefox மற்றும் Safari ஒரு கோப்புறையைத் தேர்ந்தெடுக்கச் சொல்லி, அதிலுள்ள ஒவ்வொரு கோப்பையும் படிக்கின்றன; பெரிய திட்டக் கோப்புறைகளுக்கு இது அதிக நேரம் எடுக்கும். கோப்புறையை ஆப்பின் மேல் இழுத்துவிடுவது மூன்றிலும் செயல்படும்.
- **சேமித்தல்.** ஆப்கள் ஒரு கோப்பைப் பதிவிறக்குவதன் மூலம் சேமிக்கின்றன. பதிவிறக்கங்கள் எங்கே செல்லும், முதலில் கேட்கப்படுமா என்பதை உங்கள் உலாவி தீர்மானிக்கிறது.

:::chromium
Chrome அல்லது Edge இல், ஒவ்வொரு முறையும் கோப்புறையைத் தேர்ந்தெடுக்க, "Ask where to save each file before downloading" (அமைப்புகளில், Downloads பகுதியில்; "பதிவிறக்கும் முன் ஒவ்வொரு கோப்பையும் எங்கு சேமிப்பது எனக் கேள்") என்பதை இயக்கவும்.
:::

:::firefox
Firefox இல், ஒவ்வொரு முறையும் கோப்புறையைத் தேர்ந்தெடுக்க, Settings, பிறகு General, பிறகு Downloads ஐத் திறந்து, "Always ask you where to save files" ("கோப்புகளை எங்கு சேமிப்பது எனப் பயன்படுத்துபவரிடம் எப்போதும் கேள்") என்பதைத் தேர்ந்தெடுக்கவும்.
:::

:::safari
Safari இல், ஒவ்வொரு முறையும் கோப்புறையைத் தேர்ந்தெடுக்க, Settings, பிறகு General ஐத் திறந்து, "File download location" என்பதை "Ask for each download" என அமைக்கவும்.
:::

## Mac, Windows மற்றும் Linux

ஆப்கள் எல்லாக் கணினிகளிலும் ஒரே மாதிரியானவை. மாறுவது விசைப்பலகை மட்டுமே: குறுக்குவழிகள் உங்கள் கணினிக்கு ஏற்ப தானாகவே எழுதப்படுகின்றன. [விசைகள், சுட்டிகள் மற்றும் டிராக்பேடுகள்](common:keys) பகுதியைப் பார்க்கவும்.

## டேப்லெட்டுகளும் தொடுதிரைகளும்

சில ஆப்கள் தொடுதலை ஏற்கின்றன (ஒரு விரல் வரையும் அல்லது தேர்ந்தெடுக்கும், இரண்டு விரல்கள் பிஞ்ச் செய்து பெரிதாக்கும், நகர்த்தும்). ஒவ்வொரு ஆப்பின் உதவியும் அது ஏற்கிறதா என்பதைக் கூறும். iPad இல் Safari அல்லது Chrome ஐப் பயன்படுத்தவும். தட்டச்சு செய்யும் கட்டளைகளைப் பயன்படுத்தும் ஆப்களுக்கு விசைப்பலகை உதவும்.

## மிகப் பழைய உலாவியும் கணினியும்

இவற்றை நாங்கள் ஊகத்திலிருந்து அல்ல, 0.7 ஆப்களின் குறியீட்டிலிருந்து படித்தோம்: ஒவ்வொரு கோப்பும் பகுப்பாய்வு செய்யப்பட்டது, அது பயன்படுத்தும் ஒவ்வொரு மொழி அம்சமும் உலாவிகளின் வெளியிடப்பட்ட இணக்கத்தன்மைத் தரவில் தேடப்பட்டது. இந்தப் பதிப்புகளுக்குக் கீழே, உலாவிக்குக் குறியீடு புரியாததால் ஆப்கள் தொடங்கவே முடியாது.

| | ஆப்களைத் தொடங்கக்கூடிய மிகப் பழைய பதிப்பு |
|---|---|
| Chrome, Edge, Brave, Opera, Vivaldi | Chromium 94 |
| Firefox | 93 |
| Safari (Mac, iPad, iPhone) | 16.4 (macOS 13.3, iPadOS மற்றும் iOS 16.4) |

CadCraft Studio Windows இல் தனது சொந்த இணைய இயந்திரத்தைக் கொண்டுள்ளது, எனவே Windows 10 அல்லது 11 தேவை; Mac இல் அது கணினியின் இயந்திரத்தைப் பயன்படுத்துகிறது, எனவே macOS 13.3 அல்லது அதற்குப் பிந்தையது தேவை. Studio இல் Settings › Updates உங்கள் நகல் எதில் இயங்குகிறது என்பதைக் காட்டும்.

இது குறியீட்டிலிருந்து படித்த, *தொடங்கக்கூடிய* மிகப் பழைய பதிப்பு. இதில் நாங்கள் ஆப்களை இயக்கிப் பார்த்த பழைய உலாவிகளின் பட்டியல் இல்லை, எனவே தொடங்கும் பழைய உலாவியில் ஒரு அம்சம் இல்லாமல் போகலாம்.

## உங்கள் கணினிக்கு என்ன தேவை

இவை ஆப்களுக்கான திட்டமிட்ட குறைந்தபட்சங்கள், அளவிடப்பட்ட தேவைகள் அல்ல:

- 8 GB நினைவகம் (பெரிய ஒருங்கிணைந்த மாதிரிகளுக்கு 16 GB பரிந்துரைக்கப்படுகிறது).
- 3D ஆப்களுக்கு WebGL 2 உள்ள கிராபிக்ஸ் சிப். 3D காட்சி காலியாக இருந்தால், உங்கள் உலாவி அமைப்புகளில் ஹார்டுவேர் முடுக்கம் இயக்கப்பட்டுள்ளதா எனச் சரிபார்க்கவும்.
- முழுக் கருவிப்பட்டைகளுக்கு குறைந்தது 1280 பிக்சல் அகலமுள்ள திரை; சிறிய திரைகளில் அவை மடிக்கப்படும்.

மிகப் பெரிய கோப்புகள் (பெரிய திட்டத் தொகுப்புகள், பெரிய மாதிரிகள்) உலாவித் தாவலில் அதிக நினைவகத்தைப் பயன்படுத்தும். ஒரு ஆப் மெதுவாகும்போது மற்ற கனமான தாவல்களை மூடவும்.

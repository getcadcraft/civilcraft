## குறுக்குவழிகள் எப்படி எழுதப்படுகின்றன

உங்கள் விசைப்பலகை ஒவ்வொரு விசையையும் எப்படிக் குறிப்பிடுகிறதோ அப்படியே உதவி குறுக்குவழிகளை எழுதுகிறது.

| எழுதப்பட்டது | Mac இல் | Windows மற்றும் Linux இல் |
|---|---|---|
| {{key:Mod+S}} | Command (⌘) மற்றும் S | Ctrl மற்றும் S |
| {{key:Ctrl+Shift+F}} | Control (⌃), Shift (⇧) மற்றும் F | Ctrl, Shift மற்றும் F |
| {{key:Alt+Left}} | Option (⌥) மற்றும் ← | Alt மற்றும் ← |
| {{key:Backspace}} | Delete விசை | Backspace |
| {{key:Delete}} | fn மற்றும் Delete (முன்னோக்கி நீக்கு) | Delete |
| {{key:Enter}} | Return | Enter |

கூட்டல் குறி என்றால் விசைகளை ஒன்றாகப் பிடித்துக்கொள்ளுதல். "பிறகு" என்றால் ஒன்றன்பின் ஒன்றாக அழுத்துதல்.

பெரும்பாலான ஆப் குறுக்குவழிகள் Mac இல் Command அல்லது Control இரண்டில் எதையும் ஏற்கும், எனவே {{key:Mod+Z}} இரண்டு வழியிலும் செயல்படும். முழுத்திரை ({{key:Ctrl+Shift+F}}) போன்ற சில, எல்லாக் கணினிகளிலும் Control விசையைப் பயன்படுத்துகின்றன; அது பொருந்தும் இடத்தில் உதவி அதைக் கூறும்.

## Mac இல் செயல்பாட்டு விசைகள்

பெரும்பாலான Mac விசைப்பலகைகளில் மேல் வரிசை ஒளிர்வு, ஒலி மற்றும் ஊடகத்தை மாற்றும். F1 முதல் F12 வரை அனுப்ப:

- விசையை அழுத்தும்போது **fn** (அல்லது குளோப் விசை) ஐப் பிடித்துக்கொள்ளவும், அல்லது
- **System Settings** ஐத் திறந்து, பிறகு **Keyboard**, பிறகு **Keyboard Shortcuts**, பிறகு **Function Keys** ஐத் தேர்ந்தெடுத்து, "Use F1, F2, etc. keys as standard function keys" ஐ இயக்கவும்.

சில F விசைகளை macOS தானே எடுத்துக்கொள்கிறது (எடுத்துக்காட்டாக Mission Control). ஒரு விசை ஆப்பில் எதுவும் செய்யவில்லை என்றால், fn உடன் முயலவும், அல்லது அதற்குப் பதிலாக கருவிப்பட்டைப் பொத்தானைப் பயன்படுத்தவும்.

## உலாவி வைத்திருக்கும் குறுக்குவழிகள்

ஒரு இணையப் பக்கம் என்ன செய்தாலும், சில குறுக்குவழிகளை உலாவியிடமிருந்து எடுக்க முடியாது. ஒவ்வொரு ஆப்பிலும்:

- {{key:Mod+N}}, {{key:Mod+T}} மற்றும் {{key:Mod+W}} எப்போதும் உலாவிச் சாளரங்களையும் தாவல்களையும் திறக்கும் அல்லது மூடும். புதியது மற்றும் மூடு என்பதற்கு ஆப்கள் பொத்தான்களைப் பயன்படுத்துகின்றன.
- Mac இல் {{key:Mod+Q}} மற்றும் Windows இல் {{key:Alt+F4}} உலாவியிலிருந்து வெளியேறும். சேமிக்காத வேலை இருந்தால் உலாவி முதலில் கேட்கும் ("Leave site?"); தங்குவதைத் தேர்ந்தெடுத்து, பிறகு சேமிக்கவும்.
- உலாவியின் சொந்த முழுத்திரை ({{pick:mac=Control-Command-F, or the green button on the window|windows linux=F11}}) தொடர்ந்து செயல்படும். ஆப்களுக்கும் {{key:Ctrl+Shift+F}} இல் தங்கள் சொந்தத் திரை முறைகள் உள்ளன; அவை ஆப்பின் பட்டைகளையும் மறைக்கலாம்.

## டிராக்பேடில் சுட்டிப் பொத்தான்கள்

ஆப்கள் வலது பொத்தானையும் நடுப் பொத்தானையும் பயன்படுத்துகின்றன. மூன்று பொத்தான் சுட்டி இல்லாமல்:

:::mac
- **வலது கிளிக்:** இரண்டு விரல்களால் கிளிக் செய்யவும். இரண்டு விரல் கிளிக் எதுவும் செய்யவில்லை என்றால், **System Settings** இல், பிறகு **Trackpad** இல் "Secondary click" ஐ இயக்கவும். கிளிக் செய்யும்போது {{key:Ctrl}} ஐப் பிடித்தால் உலாவியின் பட்டி திறக்கும், ஆனால் வரைபடத்துக்குள் சில ஆப்கள் அதை (Control பிடித்த) சாதாரண கிளிக்காகப் படிக்கும்; எனவே இரண்டு விரல் கிளிக்கையே விரும்பவும்.
- **நடுப் பொத்தான் இழுத்தல் (நகர்த்துதல்):** இழுக்கும்போது {{key:Space}} ஐப் பிடித்தல் அல்லது வலது பொத்தானால் இழுத்தல் போன்ற நகர்த்துவதற்கான வேறு வழியை ஒவ்வொரு ஆப்பும் வழங்குகிறது. ஆப்பின் விசைப்பலகைப் பக்கம் எது என்பதைக் கூறும்.
- **சக்கரத்தால் பெரிதாக்குதல்:** டிராக்பேடில் இரண்டு விரல் ஸ்க்ரோல் பெரும்பாலான ஆப்களில் பெரிதாக்கும். ஆப் ஆதரிக்கும் இடங்களில் பிஞ்சும் பெரிதாக்கும்.
:::

:::windows linux
- **வலது கிளிக்:** இரண்டு விரல்களால் கிளிக் செய்யவும், அல்லது டச்பேடின் கீழ் வலது மூலையில் கிளிக் செய்யவும். இது உங்கள் டச்பேட் அமைப்புகளைப் பொறுத்தது.
- **நடுப் பொத்தான் இழுத்தல் (நகர்த்துதல்):** இழுக்கும்போது {{key:Space}} ஐப் பிடித்தல் அல்லது வலது பொத்தானால் இழுத்தல் போன்ற நகர்த்துவதற்கான வேறு வழியை ஒவ்வொரு ஆப்பும் வழங்குகிறது. ஆப்பின் விசைப்பலகைப் பக்கம் எது என்பதைக் கூறும்.
- **சக்கரத்தால் பெரிதாக்குதல்:** டச்பேடில் இரண்டு விரல் ஸ்க்ரோல் பெரும்பாலான ஆப்களில் பெரிதாக்கும்.
:::

## உரைப் பெட்டியில் தட்டச்சு செய்தல்

ஒரு பெட்டியில் (பெயர், குறிப்பு, தேடல்) தட்டச்சு செய்யும்போது, ஆப்பின் ஓர்-எழுத்துக் குறுக்குவழிகள் அணைக்கப்படும், எனவே "L" என்று தட்டச்சு செய்தால் L என்றே விழும். விசைகளை ஆப்புக்குத் திரும்பக் கொடுக்க {{key:Esc}} ஐ அழுத்தவும் அல்லது வரைபடத்தின் மேல் கிளிக் செய்யவும்.

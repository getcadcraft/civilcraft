מלבד שלוש הפריסות המובנות, אפשר לסדר פריסה משלכם, ולשמור את כל ההגדרה שלכם בשם כדי לחזור אליה בצעד אחד.

## סידור פריסה משלכם

1. פתחו את {{ui:הגדרות}} (גלגל השיניים, או {{key:Mod+,}}), בחרו {{ui:גלובלי}}, ואז {{ui:פריסה}}.
2. בחרו {{ui:סידור פריסה משלכם…}}. התיבה מתחילה מהפריסה שאתם משתמשים בה כעת.
3. תנו לה שם, ואז בחרו:
   - **מעל השרטוט:** סרגל הכלים של האפליקציה, רצועה או שום דבר מהם; שורת כותרת; תיבת מידע ואילו פקדים היא מכילה.
   - **בצד השרטוט:** ארגז הכלים משמאל, מימין או בכלל לא, עם {{ui:הכלים שלי}} או בלעדיו; איזו חלונית מחזיקה את הלוחות, איזו נמצאת למעלה (דפדפן הפרויקט או מאפיינים, למשל), ואילו הן כרטיסיות מתחתיה.
   - **אזור השרטוט:** כרטיסיות תצוגה, סרגל מהיר וסרגל תצוגה עם הפקדים שתסמנו, לוח העריכה, שורת מצב.
   - **מראה:** גודל, קווי מתאר של כפתורים וסגנון כרטיסיות.
4. בחרו {{ui:שימוש בפריסה הזו}}. האפליקציה עוברת אליה מיד, וכל אפליקציה שיש לה פריסות משתמשת בה גם כן.

מוצע רק מה שיש לאפליקציה הזו. הפריסה שלכם מופיעה תחת {{ui:מתוספים וקבצים}}; {{ui:ייצוא הפריסה הזו}} שומר אותה כקובץ שאפשר לתת לעמית, וכפתור ההסרה מוחק אותה. החלוניות שהפריסה ממלאת עדיין עוגנות, צפות ועוברות לחלונות משלהן, כמתואר ב[סידור החלוניות](common:arrange-panels).

## שמירת ההגדרה כסביבת עבודה

סביבת עבודה היא ההגדרה המלאה שלכם לכל האפליקציות בדפדפן הזה: הפריסה, סגנון התפריטים והמקשים שלכם, סגנון סרגל הכלים, החלוניות וגודלן, ו{{ui:הכלים שלי}}. ערכת הנושא והשפה אינן חלק ממנה.

- **שמירה:** הקלידו שם תחת {{ui:סביבות עבודה}} ובחרו {{ui:שמירת ההגדרה שלי}}. שמירה תחת שם קיים מחליפה את ההגדרה הזו.
- **מעבר:** בחרו הגדרה ברשימה ובחרו {{ui:החלפה אליה}}. האפליקציה נטענת מחדש בהגדרה הזו; אם יש לכם עבודה שלא נשמרה, האפליקציה שואלת קודם, כפי שהיא עושה בכל טעינה מחדש.
- **שיתוף:** {{ui:ייצוא}} שומר את ההגדרה שנבחרה כקובץ `.ccenv.json`; {{ui:ייבוא הגדרה…}} מוסיף הגדרה מקובץ. קובץ מגדיר רק את הבחירות האלה, ולא שום דבר אחר.
- **הסרה:** בחרו הגדרה ובחרו {{ui:הסרה}}.

אפשר לשמור עד שתים-עשרה הגדרות.

כדי לנסות קודם את הסידורים המובנים, ראו [פריסת ארגז כלים ותיבת מידע](common:layout-toolbox) ו[פריסת רצועה ודפדפן הפרויקט](common:layout-ribbon).

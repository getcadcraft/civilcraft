แอปทำงานภายในเว็บเบราว์เซอร์ โดยประมวลผลบนคอมพิวเตอร์ของคุณเอง ไฟล์ของคุณถูกเปิดที่นั่นและไม่ถูกส่งมาให้เรา (ดู [ไฟล์ของคุณไปที่ไหน](common:your-files))

## เบราว์เซอร์ที่ใช้

ใช้เวอร์ชันล่าสุดของเบราว์เซอร์ตัวใดตัวหนึ่งต่อไปนี้

| เบราว์เซอร์ | เอนจิน | หมายเหตุ |
|---|---|---|
| Chrome, Edge, Brave, Opera, Vivaldi | Chromium | สมบูรณ์ที่สุด: เลือกโฟลเดอร์ได้ บันทึกไว้ใช้แบบออฟไลน์ได้ และเปิดไฟล์ได้โดยตรง |
| Firefox | Gecko | ใช้งานได้ การเปิดทั้งโฟลเดอร์ใช้ตัวเลือกแบบง่ายกว่า การบันทึกแบบออฟไลน์อาจใช้ไม่ได้ในหน้าต่างส่วนตัว |
| Safari | WebKit | ใช้งานได้บน Mac และ iPad การเปิดทั้งโฟลเดอร์ใช้ตัวเลือกแบบง่ายกว่า Safari อาจลบสำเนาออฟไลน์ที่คุณไม่ได้ใช้มาหลายสัปดาห์ |

เอนจินทั้งสามใช้งานประจำวันได้ดี หากแอปทำงานต่างกันในเอนจินใดเอนจินหนึ่ง วิธีใช้ของแอปจะแสดงขั้นตอนสำหรับเบราว์เซอร์ของคุณ

## เบราว์เซอร์ต่างกันอย่างไร

- **การเปิดโฟลเดอร์** เบราว์เซอร์ Chromium แสดงตัวเลือกโฟลเดอร์จริงและอ่านโฟลเดอร์ได้โดยตรง Firefox และ Safari ให้คุณเลือกโฟลเดอร์แล้วอ่านทุกไฟล์ในโฟลเดอร์นั้น ซึ่งใช้เวลานานกว่าสำหรับโฟลเดอร์โครงการขนาดใหญ่ การลากโฟลเดอร์มาวางบนแอปใช้ได้ทั้งสามแบบ
- **การบันทึก** แอปบันทึกด้วยการดาวน์โหลดไฟล์ เบราว์เซอร์ของคุณเป็นผู้กำหนดว่าไฟล์ดาวน์โหลดไปอยู่ที่ใดและจะถามก่อนหรือไม่

:::chromium
ใน Chrome หรือ Edge ให้เปิด "ถามว่าจะบันทึกไฟล์ไว้ที่ใดก่อนดาวน์โหลด" (ในการตั้งค่า ส่วนดาวน์โหลด) เพื่อเลือกโฟลเดอร์ทุกครั้ง
:::

:::firefox
ใน Firefox ให้เปิดการตั้งค่า แล้วเลือกทั่วไป แล้วเลือกการดาวน์โหลด และเลือก "ถามที่จะบันทึกไฟล์เสมอ" เพื่อเลือกโฟลเดอร์ทุกครั้ง
:::

:::safari
ใน Safari ให้เปิดการตั้งค่า แล้วเลือกทั่วไป และตั้ง "ตำแหน่งดาวน์โหลดไฟล์" เป็น "ถามทุกครั้ง" เพื่อเลือกโฟลเดอร์ทุกครั้ง
:::

## Mac, Windows และ Linux

แอปเหมือนกันบนคอมพิวเตอร์ทุกเครื่อง สิ่งที่เปลี่ยนคือคีย์บอร์ด: ปุ่มลัดจะเขียนให้ตรงกับคอมพิวเตอร์ของคุณโดยอัตโนมัติ ดู [คีย์ เมาส์ และทัชแพด](common:keys)

## แท็บเล็ตและหน้าจอสัมผัส

บางแอปรองรับการสัมผัส (นิ้วเดียววาดหรือเลือก สองนิ้วถ่างเพื่อซูมและแพน) วิธีใช้ของแต่ละแอปบอกว่ารองรับหรือไม่ บน iPad ให้ใช้ Safari หรือ Chrome คีย์บอร์ดช่วยได้กับแอปที่ใช้คำสั่งแบบพิมพ์

## เบราว์เซอร์และระบบที่เก่าที่สุด

ข้อมูลนี้อ่านมาจากโค้ดของแอปรุ่น 0.7 ไม่ได้คาดเดา: เราแยกวิเคราะห์ทุกไฟล์ และค้นหาคุณลักษณะภาษาแต่ละอย่างที่ใช้ในข้อมูลความเข้ากันได้ของเบราว์เซอร์ที่เผยแพร่ ต่ำกว่าเวอร์ชันเหล่านี้ แอปไม่สามารถเริ่มทำงานได้เลย เพราะเบราว์เซอร์ไม่เข้าใจโค้ด

| | เวอร์ชันเก่าที่สุดที่เริ่มแอปได้ |
|---|---|
| Chrome, Edge, Brave, Opera, Vivaldi | Chromium 94 |
| Firefox | 93 |
| Safari (Mac, iPad, iPhone) | 16.4 (macOS 13.3, iPadOS และ iOS 16.4) |

CadCraft Studio มีเอนจินเว็บของตัวเองบน Windows จึงต้องใช้ Windows 10 หรือ 11 บน Mac ใช้เอนจินของระบบ จึงต้องใช้ macOS 13.3 ขึ้นไป การตั้งค่า › อัปเดต ใน Studio แสดงสิ่งที่สำเนาของคุณใช้อยู่

นี่คือเวอร์ชันเก่าที่สุดที่*เริ่มได้* อ่านจากโค้ด ไม่ใช่รายการเบราว์เซอร์เก่าที่เราเคยรันแอป ดังนั้นเบราว์เซอร์ที่เก่ากว่าซึ่งเริ่มได้ก็อาจยังขาดบางคุณลักษณะ

## คอมพิวเตอร์ของคุณต้องมีอะไร

ค่าเหล่านี้เป็นขั้นต่ำที่วางแผนไว้สำหรับแอป ไม่ใช่ความต้องการที่วัดจริง

- หน่วยความจำ 8 GB (แนะนำ 16 GB สำหรับโมเดลรวมขนาดใหญ่)
- ชิปกราฟิกที่รองรับ WebGL 2 สำหรับแอป 3D หากมุมมอง 3D ว่างเปล่า ให้ตรวจว่าเปิดการเร่งด้วยฮาร์ดแวร์ในการตั้งค่าเบราว์เซอร์แล้ว
- หน้าจอกว้างอย่างน้อย 1280 พิกเซลเพื่อแสดงแถบเครื่องมือครบ หน้าจอที่เล็กกว่าจะตัดแถบเครื่องมือขึ้นบรรทัดใหม่

ไฟล์ขนาดใหญ่มาก (ชุดแบบขนาดใหญ่ โมเดลขนาดใหญ่) ใช้หน่วยความจำมากในแท็บเบราว์เซอร์ ปิดแท็บหนัก ๆ อื่นหากแอปช้าลง

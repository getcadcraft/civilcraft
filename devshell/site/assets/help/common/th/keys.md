## ปุ่มลัดเขียนอย่างไร

วิธีใช้เขียนปุ่มลัดแต่ละอันตามที่คีย์บอร์ดของคุณระบุ

| ที่เขียน | บน Mac | บน Windows และ Linux |
|---|---|---|
| {{key:Mod+S}} | Command (⌘) และ S | Ctrl และ S |
| {{key:Ctrl+Shift+F}} | Control (⌃), Shift (⇧) และ F | Ctrl, Shift และ F |
| {{key:Alt+Left}} | Option (⌥) และ ← | Alt และ ← |
| {{key:Backspace}} | ปุ่ม Delete | Backspace |
| {{key:Delete}} | fn และ Delete (ลบไปข้างหน้า) | Delete |
| {{key:Enter}} | Return | Enter |

เครื่องหมายบวกหมายถึงกดปุ่มพร้อมกัน "แล้ว" หมายถึงกดทีละปุ่มต่อกัน

ปุ่มลัดของแอปส่วนใหญ่รับได้ทั้ง Command และ Control บน Mac ดังนั้น {{key:Mod+Z}} ใช้ได้ทั้งสองแบบ บางปุ่ม เช่น เต็มหน้าจอ ({{key:Ctrl+Shift+F}}) ใช้ปุ่ม Control บนคอมพิวเตอร์ทุกเครื่อง วิธีใช้จะบอกไว้ในที่ที่เกี่ยวข้อง

## ปุ่มฟังก์ชันบน Mac

บนคีย์บอร์ด Mac ส่วนใหญ่ แถวบนสุดเปลี่ยนความสว่าง ระดับเสียง และสื่อ เพื่อส่ง F1 ถึง F12:

- กด **fn** (หรือปุ่มลูกโลก) ค้างไว้ขณะกดปุ่ม หรือ
- เปิด **การตั้งค่าระบบ** แล้วเลือก **แป้นพิมพ์** แล้วเลือก **ทางลัดแป้นพิมพ์** แล้วเลือก **แป้นฟังก์ชัน** และเปิด "ใช้แป้น F1, F2 ฯลฯ เป็นแป้นฟังก์ชันมาตรฐาน"

macOS เองก็ใช้ปุ่ม F บางปุ่มด้วย (เช่น Mission Control) หากปุ่มไม่ทำอะไรในแอป ให้ลองกดพร้อม fn หรือใช้ปุ่มในแถบเครื่องมือแทน

## ปุ่มลัดที่เบราว์เซอร์เก็บไว้

หน้าเว็บไม่สามารถแย่งปุ่มลัดบางอย่างจากเบราว์เซอร์ได้ ไม่ว่าจะทำอะไร ในทุกแอป:

- {{key:Mod+N}}, {{key:Mod+T}} และ {{key:Mod+W}} เปิดหรือปิดหน้าต่างและแท็บของเบราว์เซอร์เสมอ แอปใช้ปุ่มสำหรับสร้างใหม่และปิดแทน
- {{key:Mod+Q}} บน Mac และ {{key:Alt+F4}} บน Windows ออกจากเบราว์เซอร์ หากมีงานที่ยังไม่ได้บันทึก เบราว์เซอร์จะถามก่อน ("Leave site?") ให้เลือกอยู่ต่อ แล้วบันทึก
- โหมดเต็มหน้าจอของเบราว์เซอร์เอง ({{pick:mac=Control-Command-F หรือปุ่มสีเขียวบนหน้าต่าง|windows linux=F11}}) ยังใช้ได้ แอปยังมีโหมดหน้าจอของตัวเองที่ {{key:Ctrl+Shift+F}} ซึ่งซ่อนแถบของแอปได้ด้วย

## ปุ่มเมาส์บนทัชแพด

แอปใช้ปุ่มขวาและปุ่มกลาง หากไม่มีเมาส์สามปุ่ม:

:::mac
- **คลิกขวา:** คลิกด้วยสองนิ้ว เปิด "คลิกรอง" ใน **การตั้งค่าระบบ** แล้วเลือก **แทร็กแพด** หากการคลิกสองนิ้วไม่ทำอะไร การกด {{key:Ctrl}} ค้างขณะคลิกจะเปิดเมนูของเบราว์เซอร์ แต่ภายในแบบ บางแอปอ่านเป็นการคลิกธรรมดา (พร้อม Control) จึงควรใช้การคลิกสองนิ้วมากกว่า
- **ลากด้วยปุ่มกลาง (แพน):** แต่ละแอปมีวิธีแพนอีกแบบ เช่น กด {{key:Space}} ค้างขณะลาก หรือลากด้วยปุ่มขวา หน้าคีย์บอร์ดของแอประบุไว้
- **ซูมด้วยล้อ:** เลื่อนสองนิ้วบนแทร็กแพดจะซูมในแอปส่วนใหญ่ การถ่างนิ้วก็ซูมได้ในแอปที่รองรับ
:::

:::windows linux
- **คลิกขวา:** คลิกด้วยสองนิ้ว หรือคลิกที่มุมล่างขวาของทัชแพด ขึ้นอยู่กับการตั้งค่าทัชแพดของคุณ
- **ลากด้วยปุ่มกลาง (แพน):** แต่ละแอปมีวิธีแพนอีกแบบ เช่น กด {{key:Space}} ค้างขณะลาก หรือลากด้วยปุ่มขวา หน้าคีย์บอร์ดของแอประบุไว้
- **ซูมด้วยล้อ:** เลื่อนสองนิ้วบนทัชแพดจะซูมในแอปส่วนใหญ่
:::

## การพิมพ์ในช่องข้อความ

ขณะพิมพ์ในช่อง (ชื่อ หมายเหตุ การค้นหา) ปุ่มลัดตัวอักษรเดียวของแอปจะปิดอยู่ ดังนั้นการพิมพ์ "L" จะได้ตัว L กด {{key:Esc}} หรือคลิกที่แบบเพื่อคืนปุ่มให้แอป

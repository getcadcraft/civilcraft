ทุกแอปมีวิธีใช้ของตัวเอง เป็นส่วนหนึ่งของแอป จึงเปิดได้โดยไม่ต้องเชื่อมต่อ และอธิบายเวอร์ชันที่คุณใช้อยู่เสมอ

## เปิดวิธีใช้

- กด {{key:F1}} หรือเลือก {{ui:ช่วยเหลือ}} ในแถบด้านบนของแอป
- กด {{key:Esc}} หรือเลือก {{ui:ปิด}} เพื่อเก็บ แบบของคุณยังอยู่เหมือนเดิม

:::mac
บนคีย์บอร์ด Mac ส่วนใหญ่ แถวบนสุดควบคุมความสว่างและเสียง กด {{key:F1}} พร้อมกับปุ่ม **fn** (หรือปุ่มลูกโลก) หรือใช้ปุ่ม {{ui:ช่วยเหลือ}} ดู [ปุ่มบน Mac](common:keys#function-keys-on-a-mac)
:::

## ค้นหาหัวข้อ

- พิมพ์ในช่องค้นหาที่ด้านบนของวิธีใช้ ผลลัพธ์จะอัปเดตขณะที่พิมพ์ และรวมชื่อคำสั่งของโปรแกรมอื่นด้วย ดังนั้นการพิมพ์สิ่งที่คุณเคยพิมพ์ที่อื่นมักพบหน้าที่ใช่
- หัวข้อถูกจัดกลุ่มเหมือนกันในทุกแอป: เริ่มต้นใช้งาน คำแนะนำทีละขั้น การย้ายมาจากซอฟต์แวร์อื่น เอกสารอ้างอิง และการแก้ปัญหา
- ลิงก์ภายในหัวข้อจะเปิดหัวข้อถัดไปในพาเนลเดียวกัน {{ui:กลับ}} พาคุณกลับไปที่เดิม

## ขั้นตอนสำหรับคอมพิวเตอร์ของคุณ

บางขั้นตอนต่างกันระหว่าง Mac, Windows และ Linux ระหว่างเบราว์เซอร์ และระหว่างการออนไลน์กับออฟไลน์ วิธีใช้จะหาว่าแบบใดตรงกับคุณและแสดงขั้นตอนเหล่านั้น บรรทัดที่ด้านบนของหัวข้อบอกว่าเลือกอะไร เช่น "Showing steps for Mac, Chrome or Edge, online"

- เลือก {{ui:เปลี่ยน}} ที่บรรทัดนั้นเพื่อเลือกคอมพิวเตอร์หรือเบราว์เซอร์อื่น เช่นเพื่อช่วยเพื่อนร่วมงาน
- เลือก {{ui:แสดงทั้งหมด}} เพื่อดูทุกเวอร์ชันของทุกขั้นตอน พร้อมป้ายกำกับ

ปุ่มลัดเขียนตามที่คีย์บอร์ดของคุณระบุ: {{key:Mod+S}} อ่านเป็น ⌘S บน Mac และ Ctrl+S บน Windows และ Linux

እያንዳንዱ መተግበሪያ የራሱ እገዛ አለው። የመተግበሪያው አካል ስለሆነ ያለ ግንኙነት ይከፈታል እና ሁልጊዜ እያሄዱት ያለውን ስሪት ይገልጻል።

## እገዛውን ክፈት

- {{key:F1}} ይጫኑ፣ ወይም በመተግበሪያው ላይኛው አሞሌ ውስጥ {{ui:እገዛ}} ይምረጡ።
- ለማስቀመጥ {{key:Esc}} ይጫኑ ወይም {{ui:ዝጋ}} ይምረጡ። ንድፍዎ እንደነበረው ይቆያል።

:::mac
በአብዛኛዎቹ የMac ቁልፍ ሰሌዳዎች የላይኛው ረድፍ ብሩህነትንና ድምፅን ይቆጣጠራል። {{key:F1}}ን ከ**fn** ቁልፍ (ወይም የግሎብ ቁልፍ) ጋር አብረው ይጫኑ፣ ወይም የ{{ui:እገዛ}} አዝራሩን ይጠቀሙ። ይመልከቱ [በMac ላይ ያሉ ቁልፎች](common:keys#function-keys-on-a-mac)።
:::

## ርዕስ ፈልግ

- በእገዛው ላይኛው ክፍል ባለው የፍለጋ ሳጥን ይጻፉ። ውጤቶች ሲጽፉ ይዘምናሉ እና የሌሎች ፕሮግራሞች ትዕዛዞችንም ያካትታሉ፤ ስለዚህ ሌላ ቦታ የሚጽፉትን በመጻፍ ብዙውን ጊዜ ትክክለኛውን ገጽ ያገኛሉ።
- ርዕሶች በእያንዳንዱ መተግበሪያ ተመሳሳይ መንገድ ይደረደራሉ: መጀመሪያ ማድረግ፣ የደረጃ በደረጃ መመሪያዎች፣ ከሌላ ሶፍትዌር መምጣት፣ ማጣቀሻ እና ችግር መፍቻ።
- በርዕስ ውስጥ ያሉ ማገናኛዎች ቀጣዩን ርዕስ በዚያው ፓነል ይከፍታሉ። {{ui:ተመለስ}} ወደነበሩበት ይመልሰዎታል።

## ለኮምፒውተርዎ ደረጃዎች

አንዳንድ ደረጃዎች በMac፣ Windows እና Linux መካከል፣ በአሳሾች መካከል እና በመስመር ላይ ወይም ከመስመር ውጭ በሚሆኑበት ጊዜ ይለያያሉ። እገዛው የሚመለከቱዎትን ይለያል እና እነዚያን ደረጃዎች ያሳያል። በርዕሱ አናት ያለው መስመር ምን እንደመረጠ ይናገራል፣ ለምሳሌ "ለMac፣ Chrome ወይም Edge፣ በመስመር ላይ ያሉ ደረጃዎችን በማሳየት ላይ"።

- ለምሳሌ ለሥራ ባልደረባዎ ለመርዳት ሌላ ኮምፒውተር ወይም አሳሽ ለመምረጥ በዚያ መስመር ላይ {{ui:ቀይር}} ይምረጡ።
- የእያንዳንዱን ደረጃ ሁሉንም ስሪቶች፣ እያንዳንዳቸው በስያሜ፣ ለማየት {{ui:ሁሉንም አሳይ}} ይምረጡ።

የቁልፍ ሰሌዳ አቋራጮች ቁልፍ ሰሌዳዎ በሚሰይማቸው መንገድ ተጽፈዋል: {{key:Mod+S}} በMac ላይ ⌘S ሆኖ፣ በWindows እና Linux ላይ Ctrl+S ሆኖ ይነበባል።

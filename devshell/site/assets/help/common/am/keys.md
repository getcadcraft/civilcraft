## አቋራጮች እንዴት እንደሚጻፉ

እገዛው እያንዳንዱን አቋራጭ ቁልፍ ሰሌዳዎ በሚሰይመው መንገድ ይጽፋል።

| የተጻፈው | በMac ላይ | በWindows እና Linux ላይ |
|---|---|---|
| {{key:Mod+S}} | Command (⌘) እና S | Ctrl እና S |
| {{key:Ctrl+Shift+F}} | Control (⌃)፣ Shift (⇧) እና F | Ctrl፣ Shift እና F |
| {{key:Alt+Left}} | Option (⌥) እና ← | Alt እና ← |
| {{key:Backspace}} | የDelete ቁልፍ | Backspace |
| {{key:Delete}} | fn እና Delete (ወደ ፊት ሰርዝ) | Delete |
| {{key:Enter}} | Return | Enter |

የመደመር ምልክት ማለት ቁልፎቹን በአንድነት ይያዙ ማለት ነው። "ከዚያ" ማለት አንዱን ከሌላው በኋላ ይጫኑ ማለት ነው።

አብዛኞቹ የመተግበሪያ አቋራጮች በMac ላይ Command ወይም Control ይቀበላሉ፣ ስለዚህ {{key:Mod+Z}} በሁለቱም መንገድ ይሰራል። ጥቂቶቹ፣ ለምሳሌ ሙሉ ማያ ({{key:Ctrl+Shift+F}})፣ በሁሉም ኮምፒውተር ላይ Control ቁልፉን ይጠቀማሉ፤ ተፈጻሚ በሆነበት እገዛው ይናገራል።

## በMac ላይ ያሉ የተግባር ቁልፎች

በአብዛኛዎቹ የMac ቁልፍ ሰሌዳዎች የላይኛው ረድፍ ብሩህነት፣ ድምፅና ሚዲያ ይቀይራል። F1 እስከ F12 ለመላክ:

- ቁልፉን እየጫኑ **fn** (ወይም የግሎብ ቁልፉን) ይያዙ፣ ወይም
- **የስርዓት ቅንብሮች**ን፣ ከዚያ **ቁልፍ ሰሌዳ**ን፣ ከዚያ **የቁልፍ ሰሌዳ አቋራጮች**ን፣ ከዚያ **የተግባር ቁልፎች**ን ይክፈቱ፣ እና "F1፣ F2 ወዘተ ቁልፎችን እንደ መደበኛ የተግባር ቁልፎች ተጠቀም" የሚለውን ያብሩ።

አንዳንድ F ቁልፎች በmacOS ራሱ ይያዛሉ (ለምሳሌ Mission Control)። ቁልፍ በመተግበሪያው ውስጥ ምንም ካላደረገ፣ በfn ይሞክሩ፣ ወይም በምትኩ የመሳሪያ አሞሌ አዝራሩን ይጠቀሙ።

## አሳሹ የሚይዛቸው አቋራጮች

ድር ገጽ ምን ቢያደርግም አንዳንድ አቋራጮችን ከአሳሹ መውሰድ አይችልም። በሁሉም መተግበሪያ:

- {{key:Mod+N}}፣ {{key:Mod+T}} እና {{key:Mod+W}} ሁልጊዜ የአሳሽ መስኮቶችንና ትሮችን ይከፍታሉ ወይም ይዘጋሉ። መተግበሪያዎቹ በምትኩ ለአዲስና ለመዝጊያ አዝራሮችን ይጠቀማሉ።
- በMac ላይ {{key:Mod+Q}} እና በWindows ላይ {{key:Alt+F4}} አሳሹን ይዘጋሉ። ያልተቀመጠ ስራ ካለዎት አሳሹ መጀመሪያ ይጠይቃል ("ገጹን ልውጣ?")፤ መቆየትን ይምረጡ፣ ከዚያም ያስቀምጡ።
- የአሳሹ የራሱ ሙሉ ማያ ({{pick:mac=Control-Command-F, ወይም በመስኮቱ ላይ ያለው አረንጓዴ አዝራር|windows linux=F11}}) አሁንም ይሰራል። መተግበሪያዎቹ በ{{key:Ctrl+Shift+F}} የራሳቸው የማያ ሁነታዎችም አሏቸው፣ እነዚህም የመተግበሪያውን አሞሌዎች ሊደብቁ ይችላሉ።

## በትራክፓድ ላይ ያሉ የአይጥ ቁልፎች

መተግበሪያዎቹ የቀኝ ቁልፍና የመካከለኛ ቁልፍ ይጠቀማሉ። ባለሶስት-ቁልፍ አይጥ ከሌለዎት:

:::mac
- **በቀኝ ጠቅ ማድረግ:** በሁለት ጣቶች ጠቅ ያድርጉ። በሁለት ጣት ጠቅታ ምንም ካልሆነ፣ **የስርዓት ቅንብሮች**ን፣ ከዚያ **ትራክፓድ**ን ውስጥ "ሁለተኛ ጠቅታ" ያብሩ። {{key:Ctrl}}ን እየያዙ ጠቅ ካደረጉ የአሳሹ ምናሌ ይከፈታል፣ ነገር ግን በንድፍ ውስጥ አንዳንድ መተግበሪያዎች እንደ ተራ ጠቅታ (Control ተይዞ) ያነቡታል፣ ስለዚህ በሁለት ጣት ጠቅታውን ይምረጡ።
- **የመካከለኛ ቁልፍ መጎተት (ማንሸራተት):** እያንዳንዱ መተግበሪያ ለማንሸራተት ሌላ መንገድ ይሰጣል፣ ለምሳሌ ሲጎትቱ {{key:Space}}ን መያዝ ወይም በቀኝ ቁልፍ መጎተት። የመተግበሪያው የቁልፍ ሰሌዳ ገጽ የትኛው እንደሆነ ይናገራል።
- **በጎማ ማጉላት:** በትራክፓድ ላይ በሁለት ጣት ማሸብለል በአብዛኛዎቹ መተግበሪያዎች ያጎላል። መተግበሪያው በሚደግፍበት ቦታ ቆንጥጦ ማጉላትም ይሰራል።
:::

:::windows linux
- **በቀኝ ጠቅ ማድረግ:** በሁለት ጣቶች ጠቅ ያድርጉ፣ ወይም የንክኪ ሰሌዳውን ታችኛውን ቀኝ ጥግ ጠቅ ያድርጉ። ይህ በንክኪ ሰሌዳዎ ቅንብሮች ላይ የተመሰረተ ነው።
- **የመካከለኛ ቁልፍ መጎተት (ማንሸራተት):** እያንዳንዱ መተግበሪያ ለማንሸራተት ሌላ መንገድ ይሰጣል፣ ለምሳሌ ሲጎትቱ {{key:Space}}ን መያዝ ወይም በቀኝ ቁልፍ መጎተት። የመተግበሪያው የቁልፍ ሰሌዳ ገጽ የትኛው እንደሆነ ይናገራል።
- **በጎማ ማጉላት:** በንክኪ ሰሌዳ ላይ በሁለት ጣት ማሸብለል በአብዛኛዎቹ መተግበሪያዎች ያጎላል።
:::

## በጽሑፍ ሳጥን ውስጥ መጻፍ

በሳጥን ውስጥ (ስም፣ ማስታወሻ፣ ፍለጋ) በሚጽፉበት ጊዜ የመተግበሪያው የአንድ-ፊደል አቋራጮች ይጠፋሉ፣ ስለዚህ "L" ብለው ሲጽፉ L ይጻፋል። ቁልፎቹን ወደ መተግበሪያው ለመመለስ {{key:Esc}} ይጫኑ ወይም በንድፉ ላይ ጠቅ ያድርጉ።

መተግበሪያዎቹ የሚሰሩት በድር አሳሽ ውስጥ ነው። ስራውን በእርስዎ ኮምፒውተር ላይ ይሰራሉ: ፋይሎችዎ እዚያ ይከፈታሉ እና ወደ እኛ አይላኩም (ይመልከቱ [ፋይሎችዎ የት ይሄዳሉ](common:your-files))።

## የትኛው አሳሽ

ከእነዚህ ውስጥ የአንዱን የቅርብ ጊዜ ስሪት ይጠቀሙ:

| አሳሽ | ሞተር | ማስታወሻ |
|---|---|---|
| Chrome, Edge, Brave, Opera, Vivaldi | Chromium | በጣም የተሟላ: አቃፊ መምረጥ፣ ከመስመር ውጭ ለመጠቀም ማስቀመጥ፣ ፋይል አያያዝ። |
| Firefox | Gecko | ይሰራል። ሙሉ አቃፊ ሲከፈት ቀለል ያለ መምረጫ ይጠቀማል። ከመስመር ውጭ ማስቀመጥ በግል መስኮቶች ላይ ላይሰራ ይችላል። |
| Safari | WebKit | በMac እና iPad ላይ ይሰራል። ሙሉ አቃፊ ሲከፈት ቀለል ያለ መምረጫ ይጠቀማል። Safari ለጥቂት ሳምንታት ያልተጠቀሙበትን ከመስመር ውጭ ቅጂ ሊሰርዝ ይችላል። |

ሦስቱም ሞተሮች ለዕለት ተዕለት ስራ ጥሩ ናቸው። መተግበሪያ በአንዱ ውስጥ የተለየ ነገር ሲያደርግ፣ እገዛው ለአሳሽዎ ደረጃዎቹን ያሳያል።

## በአሳሾች መካከል የሚለያየው

- **አቃፊ ሲከፈት።** Chromium አሳሾች እውነተኛ የአቃፊ መምረጫ ያሳያሉ እና አቃፊውን በቀጥታ ማንበብ ይችላሉ። Firefox እና Safari አቃፊ እንዲመርጡ ይጠይቃሉ ከዚያም በውስጡ ያለውን ፋይል ሁሉ ያነባሉ፤ ይህም ለትላልቅ የፕሮጀክት አቃፊዎች የበለጠ ይወስዳል። አቃፊውን ወደ መተግበሪያው መጎተት በሦስቱም ይሰራል።
- **ማስቀመጥ።** መተግበሪያዎቹ ፋይል በማውረድ ያስቀምጣሉ። አሳሽዎ ማውረዶች የት እንደሚሄዱ እና ከመውረዱ በፊት ይጠይቅ እንደሆነ ይወስናል።

:::chromium
በChrome ወይም Edge ውስጥ "ከማውረዱ በፊት እያንዳንዱን ፋይል የት እንደሚቀመጥ ጠይቅ" የሚለውን አብራ ("ቅንብሮች" ውስጥ፣ "ማውረዶች" ስር) በእያንዳንዱ ጊዜ አቃፊ ለመምረጥ።
:::

:::firefox
በFirefox ቅንብሮችን ይክፈቱ፣ ከዚያ አጠቃላይ፣ ከዚያ ማውረዶች ይሂዱ፣ እና በእያንዳንዱ ጊዜ አቃፊ ለመምረጥ "ፋይሎችን የት እንደሚቀመጥ ሁልጊዜ ጠይቀኝ" ይምረጡ።
:::

:::safari
በSafari ቅንብሮችን ይክፈቱ፣ ከዚያ አጠቃላይ ይሂዱ፣ እና "የፋይል ማውረጃ ቦታ" ን "ለእያንዳንዱ ማውረድ ጠይቅ" ያድርጉ፣ በእያንዳንዱ ጊዜ አቃፊ ለመምረጥ።
:::

## Mac, Windows እና Linux

መተግበሪያዎቹ በሁሉም ኮምፒውተሮች ላይ ተመሳሳይ ናቸው። የሚለያየው የቁልፍ ሰሌዳው ነው: አቋራጮች ለኮምፒውተርዎ በራስ-ሰር ተጽፈዋል። ይመልከቱ [ቁልፎች፣ አይጦችና ትራክፓዶች](common:keys)።

## ታብሌቶችና የንክኪ ማያ ገጾች

አንዳንድ መተግበሪያዎች ንክኪን ይቀበላሉ (አንድ ጣት ይስላል ወይም ይመርጣል፣ ሁለት ጣቶች ቆንጥጠው ያጎላሉ እና ያንሸራትታሉ)። የእያንዳንዱ መተግበሪያ እገዛ ይህን ይነግርዎታል። በiPad ላይ Safari ወይም Chrome ይጠቀሙ። በተየቡ ትዕዛዞች የሚሰሩ መተግበሪያዎች ላይ የቁልፍ ሰሌዳ ይረዳል።

## ዝቅተኛው አሳሽና ስርዓት

እነዚህን ከ0.7 መተግበሪያዎች ኮድ አንብበናቸዋል፣ በግምት አይደለም: እያንዳንዱ ፋይል ተተንትኗል፣ የሚጠቀምበትም እያንዳንዱ የቋንቋ ባህሪ በአሳሾቹ በታተመው የተኳሃኝነት መረጃ ተፈልጓል። ከእነዚህ ስሪቶች በታች መተግበሪያዎቹ እንኳን ሊጀምሩ አይችሉም፣ ምክንያቱም አሳሹ ኮዱን አይረዳውም።

| | መተግበሪያዎቹን ማስጀመር የሚችል ዝቅተኛው ስሪት |
|---|---|
| Chrome, Edge, Brave, Opera, Vivaldi | Chromium 94 |
| Firefox | 93 |
| Safari (Mac, iPad, iPhone) | 16.4 (macOS 13.3, iPadOS እና iOS 16.4) |

CadCraft Studio በWindows ላይ የራሱን የድር ሞተር ይዞ ስለሚመጣ Windows 10 ወይም 11 ያስፈልገዋል፤ በMac ላይ ግን የሲስተሙን ይጠቀማል፣ ስለዚህ macOS 13.3 ወይም ከዚያ በኋላ ያስፈልገዋል። በStudio ውስጥ ቅንብሮች › ዝማኔዎች የእርስዎ ቅጂ በምን ላይ እንደሚሰራ ያሳያል።

ይህ ከኮዱ የተነበበ፣ *የሚጀምር* ዝቅተኛው ስሪት ነው። መተግበሪያዎቹን ያሄድንባቸው የቆዩ አሳሾች ዝርዝር አይደለም፤ ስለዚህ የሚጀምር ይበልጥ የቆየ አሳሽ አሁንም አንድ ባህሪ ሊጎድለው ይችላል።

## ኮምፒውተርዎ ምን ያስፈልገዋል

እነዚህ ለመተግበሪያዎቹ የታቀዱ ዝቅተኛ ደረጃዎች ናቸው፣ የተለኩ መስፈርቶች አይደሉም:

- 8 GB ማህደረ ትውስታ (ለትላልቅ የተዋሃዱ ሞዴሎች 16 GB ይመከራል)።
- ለ3D መተግበሪያዎች WebGL 2 ያለው የግራፊክስ ቺፕ። የ3D እይታ ባዶ ሆኖ ከቀረ፣ በአሳሽዎ ቅንብሮች ውስጥ የሃርድዌር ማፋጠን መብራቱን ያረጋግጡ።
- ሙሉ የመሳሪያ አሞሌዎችን ለማየት ቢያንስ 1280 ፒክስል ስፋት ያለው ማያ ገጽ። ትናንሽ ማያ ገጾች ይጠቅላሉ።

በጣም ትላልቅ ፋይሎች (ትልልቅ የፕላን ስብስቦች፣ ትልልቅ ሞዴሎች) በአሳሽ ትር ውስጥ ብዙ ማህደረ ትውስታ ይወስዳሉ። መተግበሪያው ከዘገየ ሌሎች ከባድ ትሮችን ይዝጉ።

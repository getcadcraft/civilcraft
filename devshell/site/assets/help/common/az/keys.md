## Qısayollar necə yazılır

Kömək hər qısayolu klaviaturanızın etiketlədiyi kimi yazır.

| Yazılış | Mac-də | Windows və Linux-da |
|---|---|---|
| {{key:Mod+S}} | Command (⌘) və S | Ctrl və S |
| {{key:Ctrl+Shift+F}} | Control (⌃), Shift (⇧) və F | Ctrl, Shift və F |
| {{key:Alt+Left}} | Option (⌥) və ← | Alt və ← |
| {{key:Backspace}} | Delete düyməsi | Backspace |
| {{key:Delete}} | fn və Delete (irəli silmə) | Delete |
| {{key:Enter}} | Return | Enter |

Plus işarəsi düymələri birlikdə saxlamaq deməkdir. "Sonra" isə bir-birinin ardınca basmaq deməkdir.

Əksər tətbiq qısayolları Mac-də Command və ya Control qəbul edir, ona görə {{key:Mod+Z}} hər iki yolla işləyir. Bəziləri, məsələn tam ekran ({{key:Ctrl+Shift+F}}), hər kompüterdə Control düyməsindən istifadə edir; kömək bunun tətbiq olunduğu yerdə bunu deyir.

## Mac-də funksiya düymələri

Əksər Mac klaviaturalarda üst sıra parlaqlığı, səsi və mediani dəyişir. F1-dən F12-yə göndərmək üçün:

- düyməni basarkən **fn** (və ya qlobus düyməsi) saxlayın, və ya
- **System Settings** açın, sonra **Keyboard**, sonra **Keyboard Shortcuts**, sonra **Function Keys** və "Use F1, F2, etc. keys as standard function keys" seçimini aktivləşdirin.

Bəzi F düymələri macOS-un özü tərəfindən də istifadə olunur (məsələn Mission Control). Düymə tətbiqdə heç nə etmirsə, fn ilə cəhd edin, ya da alətlər panelindəki düymədən istifadə edin.

## Brauzerin saxladığı qısayollar

Veb səhifə bəzi qısayolları, nə etsə də, brauzerdən ala bilmir. Hər tətbiqdə:

- {{key:Mod+N}}, {{key:Mod+T}} və {{key:Mod+W}} həmişə brauzer pəncərələrini və sekmələri açır və ya bağlayır. Tətbiqlər Yeni və Bağla üçün düymələrdən istifadə edir.
- Mac-də {{key:Mod+Q}} və Windows-da {{key:Alt+F4}} brauzerdən çıxır. Saxlanılmamış işiniz varsa, brauzer əvvəlcə soruşur ("Leave site?"); qalmağı seçin, sonra saxlayın.
- Brauzerin öz tam ekranı ({{pick:mac=Control-Command-F və ya pəncərədəki yaşıl düymə|windows linux=F11}}) hələ də işləyir. Tətbiqlərin öz ekran rejimləri də {{key:Ctrl+Shift+F}} ilə var; bu, tətbiqin zolaqlarını da gizlədə bilər.

## Trekpadda siçan düymələri

Tətbiqlər sağ və orta düymədən istifadə edir. Üç düymәli siçanınız yoxdursa:

:::mac
- **Sağ klik:** iki barmaqla klik edin. İki barmaq klik işləmirsə, **System Settings** açın, sonra **Trackpad** bölməsində "Secondary click" seçimini aktivləşdirin. {{key:Ctrl}} basıb klik etmək brauzerin menyusunu açır, lakin çertyojun içində bəzi tətbiqlər bunu adi klik kimi oxuyur (Control basılı olduqda), ona görə iki barmaq klikini üstün tutun.
- **Orta düymə ilə sürükləmə (sürüşdürmə):** hər tətbiq sürüşdürmənin başqa yolunu təklif edir, məsələn {{key:Space}} basıb sürükləmək və ya sağ düymə ilə sürükləmək. Tətbiqin klaviatura səhifəsi hansının olduğunu deyir.
- **Çarx ilə miqyas:** trekpadda iki barmaqla sürüşdürmə əksər tətbiqlərdə miqyası böyüdür. Tətbiq dəstəkləyirsə, barmaqları yaxınlaşdırıb-uzaqlaşdırma da miqyası dəyişir.
:::

:::windows linux
- **Sağ klik:** iki barmaqla klik edin və ya trekpadın sağ-aşağı küncünə klik edin. Bu trekpad parametrlərinizdən asılıdır.
- **Orta düymə ilə sürükləmə (sürüşdürmə):** hər tətbiq sürüşdürmənin başqa yolunu təklif edir, məsələn {{key:Space}} basıb sürükləmək və ya sağ düymə ilə sürükləmək. Tətbiqin klaviatura səhifəsi hansının olduğunu deyir.
- **Çarx ilə miqyas:** trekpadda iki barmaqla sürüşdürmə əksər tətbiqlərdə miqyası böyüdür.
:::

## Mətn qutusuna yazmaq

Mətn qutusuna (ad, qeyd, axtarış) yazanda tətbiqin bir hərfli qısayolları söndürülür, ona görə "L" yazsanız, L hərfi yazılır. Düymələri tətbiqə geri vermək üçün {{key:Esc}} basın və ya çertyoja klik edin.

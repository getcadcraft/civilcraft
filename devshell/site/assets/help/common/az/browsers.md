Tətbiqlər veb brauzerin içində işləyir. İşi sizin öz kompüterinizdə görürlər: fayllarınız orada açılır və heç vaxt bizə göndərilmir (bax [Fayllarınız hara gedir](common:your-files)).

## Hansı brauzer

Bunlardan birinin yenilənmiş versiyasını istifadə edin:

| Brauzer | Mühərrik | Qeydlər |
|---|---|---|
| Chrome, Edge, Brave, Opera, Vivaldi | Chromium | Ən tam: qovluq seçimi, oflayn üçün saxlama, fayl idarəsi. |
| Firefox | Gecko | İşləyir. Bütün qovluğu açmaq üçün daha sadə seçici istifadə olunur. Oflayn saxlama məxfi pəncərələrdə işləməyə bilər. |
| Safari | WebKit | Mac və iPad-də işləyir. Bütün qovluğu açmaq üçün daha sadə seçici istifadə olunur. Safari bir neçə həftə istifadə etmədiyiniz oflayn nüsxəni silə bilər. |

Üç mühərrik də gündəlik iş üçün yaxşıdır. Tətbiq onlardan birində fərqli iş gördükdə, onun kömək bölməsi sizin brauzeriniz üçün addımları göstərir.

## Brauzerlər arasında nə fərqlənir

- **Qovluq açmaq.** Chromium brauzerləri əsl qovluq seçicisi göstərir və qovluğu birbaşa oxuya bilir. Firefox və Safari sizdən qovluq seçməyi tələb edir və sonra onun bütün fayllarını oxuyur; bu, böyük layihə qovluqlarında daha uzun çəkir. Qovluğu tətbiqin üzərinə sürükləmək isə hər üç brauzerdə işləyir.
- **Saxlama.** Tətbiqlər faylı yükləməklə saxlayır. Yükləmələrin harada yerləşəcəyini və əvvəlcədən soruşub-soruşmayacağını brauzeriniz müəyyən edir.

:::chromium
Chrome və ya Edge-də Parametrlər altında, Downloads bölməsində "Ask where to save each file before downloading" seçimini aktivləşdirin ki, hər dəfə qovluq seçəsiniz.
:::

:::firefox
Firefox-da Parametrlər, sonra General, sonra Downloads açın və "Always ask you where to save files" seçin ki, hər dəfə qovluq seçəsiniz.
:::

:::safari
Safari-də Parametrlər, sonra General açın və "File download location" seçimini "Ask for each download" olaraq təyin edin ki, hər dəfə qovluq seçəsiniz.
:::

## Mac, Windows və Linux

Tətbiqlər hər kompüterdə eynidir. Dəyişən klaviaturadır: qısayollar avtomatik olaraq sizin kompüteriniz üçün yazılır. Bax [Düymələr, siçanlar və trekpadlər](common:keys).

## Planşetlər və sensor ekranlar

Bəzi tətbiqlər toxunuşu qəbul edir (bir barmaq çəkir və ya seçir, iki barmaq miqyas və sürüşdürmə üçün). Hər tətbiqin kömək bölməsi bunu etdiyini-etmədiyini deyir. iPad-də Safari və ya Chrome istifadə edin. Yazılı əmrlərlə işləyən tətbiqlər üçün klaviatura kömək edir.

## Ən köhnə brauzer və sistem

Bunları 0.7 tətbiqlərinin kodundan oxuduq, təxminən yox: hər fayl təhlil edildi və istifadə etdiyi hər dil xüsusiyyəti brauzerlərin dərc olunmuş uyğunluq məlumatında axtarıldı. Bu versiyalardan aşağıda tətbiqlər heç başlaya bilmir, çünki brauzer kodu anlamır.

| | Tətbiqləri başlada bilən ən köhnə versiya |
|---|---|
| Chrome, Edge, Brave, Opera, Vivaldi | Chromium 94 |
| Firefox | 93 |
| Safari (Mac, iPad, iPhone) | 16.4 (macOS 13.3, iPadOS və iOS 16.4) |

CadCraft Studio Windows-da öz veb mühərrikini özü daşıyır, ona görə Windows 10 və ya 11 lazımdır; Mac-də sistemin mühərrikindən istifadə edir, ona görə macOS 13.3 və ya daha yeni lazımdır. Studio-da Parametrlər › Yeniləmələr (Updates) bölməsi nüsxənizin hansı sistemdə işlədiyini göstərir.

Bu, koddan oxunmuş, *başlaya bilən* ən köhnə versiyadır. Bu, tətbiqləri sınadığımız köhnə brauzerlərin siyahısı deyil, ona görə başlaya bilən daha köhnə brauzerdə bir xüsusiyyət əskik ola bilər.

## Kompüteriniz nəyə ehtiyac duyur

Bunlar tətbiqlər üçün planlaşdırılmış minimumlardır, ölçülmüş tələblər deyil:

- 8 GB yaddaş (böyük birləşdirilmiş modellər üçün 16 GB tövsiyə olunur).
- 3D tətbiqlər üçün WebGL 2 dəstəkli qrafik çip. 3D görünüş boş qalırsa, brauzerinizin parametrlərində aparat sürətləndirməsinin açıq olduğunu yoxlayın.
- Tam alətlər paneli üçün ən azı 1280 piksel enli ekran; daha kiçik ekranlarda paneller sətirlərə bölünür.

Çox böyük fayllar (böyük plan dəstləri, böyük modellər) brauzer sekmesində çox yaddaş istifadə edir. Tətbiq yavaşıdırsa, digər ağır sekmələri bağlayın.

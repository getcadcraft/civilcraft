## Cara pintasan ditulis

Bantuan menulis setiap pintasan mengikut cara papan kekunci anda melabelkannya.

| Ditulis | Pada Mac | Pada Windows dan Linux |
|---|---|---|
| {{key:Mod+S}} | Command (⌘) dan S | Ctrl dan S |
| {{key:Ctrl+Shift+F}} | Control (⌃), Shift (⇧) dan F | Ctrl, Shift dan F |
| {{key:Alt+Left}} | Option (⌥) dan ← | Alt dan ← |
| {{key:Backspace}} | kekunci Delete | Backspace |
| {{key:Delete}} | fn dan Delete (padam ke hadapan) | Delete |
| {{key:Enter}} | Return | Enter |

Tanda tambah bermaksud tekan kekunci bersama-sama. "Kemudian" bermaksud tekan satu selepas satu.

Kebanyakan pintasan aplikasi menerima sama ada Command atau Control pada Mac, jadi {{key:Mod+Z}} berfungsi kedua-dua cara. Beberapa pintasan, seperti skrin penuh ({{key:Ctrl+Shift+F}}), menggunakan kekunci Control pada setiap komputer; bantuan menyatakannya di tempat yang berkenaan.

## Kekunci fungsi pada Mac

Pada kebanyakan papan kekunci Mac, baris atas menukar kecerahan, kelantangan dan media. Untuk menghantar F1 hingga F12:

- tahan **fn** (atau kekunci glob) semasa anda menekan kekunci itu, atau
- buka **System Settings**, kemudian **Keyboard**, kemudian **Keyboard Shortcuts**, kemudian **Function Keys**, dan hidupkan "Use F1, F2, etc. keys as standard function keys".

Sesetengah kekunci F juga dituntut oleh macOS sendiri (contohnya Mission Control). Jika kekunci tidak berbuat apa-apa dalam aplikasi, cuba dengan fn, atau guna butang bar alat.

## Pintasan yang dikekalkan oleh pelayar

Halaman web tidak dapat mengambil alih sesetengah pintasan daripada pelayar, walau apa pun yang dilakukannya. Dalam setiap aplikasi:

- {{key:Mod+N}}, {{key:Mod+T}} dan {{key:Mod+W}} sentiasa membuka atau menutup tetingkap dan tab pelayar. Aplikasi menggunakan butang untuk Baharu dan Tutup.
- {{key:Mod+Q}} pada Mac dan {{key:Alt+F4}} pada Windows menutup pelayar. Jika anda ada kerja yang belum disimpan, pelayar bertanya dahulu ("Tinggalkan laman?"); pilih untuk kekal, kemudian simpan.
- Skrin penuh pelayar sendiri ({{pick:mac=Control-Command-F, atau butang hijau pada tetingkap|windows linux=F11}}) masih berfungsi. Aplikasi juga mempunyai mod skrinnya sendiri pada {{key:Ctrl+Shift+F}}, yang boleh menyembunyikan bar aplikasi juga.

## Butang tetikus pada pad sentuh

Aplikasi menggunakan butang kanan dan butang tengah. Tanpa tetikus tiga butang:

:::mac
- **Klik kanan:** klik dengan dua jari. Hidupkan "Secondary click" dalam **System Settings**, kemudian **Trackpad**, jika klik dua jari tidak berfungsi. Menahan {{key:Ctrl}} semasa anda klik membuka menu pelayar, tetapi dalam lukisan sesetengah aplikasi membacanya sebagai klik biasa (dengan Control ditahan), jadi utamakan klik dua jari.
- **Seret butang tengah (pan):** setiap aplikasi menawarkan cara lain untuk pan, seperti menahan {{key:Space}} semasa anda menyeret atau menyeret dengan butang kanan. Halaman papan kekunci aplikasi memberitahu yang mana.
- **Zum dengan roda:** leret dua jari pada pad sentuh untuk zum masuk dalam kebanyakan aplikasi. Cubit juga berfungsi untuk zum di tempat aplikasi menyokongnya.
:::

:::windows linux
- **Klik kanan:** klik dengan dua jari, atau klik sudut kanan bawah pad sentuh. Ini bergantung pada tetapan pad sentuh anda.
- **Seret butang tengah (pan):** setiap aplikasi menawarkan cara lain untuk pan, seperti menahan {{key:Space}} semasa anda menyeret atau menyeret dengan butang kanan. Halaman papan kekunci aplikasi memberitahu yang mana.
- **Zum dengan roda:** leret dua jari pada pad sentuh untuk zum masuk dalam kebanyakan aplikasi.
:::

## Menaip dalam kotak teks

Semasa anda menaip dalam kotak (nama, nota, carian), pintasan satu huruf aplikasi dimatikan, jadi menaip "L" menaip huruf L. Tekan {{key:Esc}} atau klik lukisan untuk memberi kekunci kembali kepada aplikasi.

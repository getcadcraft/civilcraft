## როგორ იწერება მალსახმობები

დახმარება ყოველ მალსახმობს ისე წერს, როგორც თქვენი კლავიატურა მას აღნიშნავს.

| ჩაწერილი | Mac-ზე | Windows-ზე და Linux-ზე |
|---|---|---|
| {{key:Mod+S}} | Command (⌘) და S | Ctrl და S |
| {{key:Ctrl+Shift+F}} | Control (⌃), Shift (⇧) და F | Ctrl, Shift და F |
| {{key:Alt+Left}} | Option (⌥) და ← | Alt და ← |
| {{key:Backspace}} | Delete ღილაკი | Backspace |
| {{key:Delete}} | fn და Delete (წინ წაშლა) | Delete |
| {{key:Enter}} | Return | Enter |

ნიშანი + ნიშნავს, რომ კლავიშები ერთად უნდა დააჭიროთ. „შემდეგ“ ნიშნავს, რომ ერთი მეორის მიყოლებით დააჭიროთ.

აპების უმეტესობის მალსახმობი Mac-ზე მუშაობს როგორც Command-ით, ისე Control-ით, ამიტომ {{key:Mod+Z}} ორივენაირად მუშაობს. ზოგი, მაგალითად სრული ეკრანი ({{key:Ctrl+Shift+F}}), ყველა კომპიუტერზე Control-ს იყენებს; დახმარება ამას იმ ადგილას ამბობს, სადაც ეს ეხება.

## ფუნქციური კლავიშები Mac-ზე

Mac-ის უმეტეს კლავიატურაზე ზედა რიგი სიკაშკაშეს, ხმასა და მედიას არეგულირებს. F1-დან F12-მდე კლავიშების გასაგზავნად:

- დააჭირეთ **fn**-ს (ან გლობუსის კლავიშს) და ამავდროულად დააჭირეთ საჭირო კლავიშს, ან
- გახსენით **სისტემის პარამეტრები**, შემდეგ **კლავიატურა**, შემდეგ **კლავიატურის მალსახმობები**, შემდეგ **ფუნქციური კლავიშები**, და ჩართეთ „F1, F2 და ა.შ. კლავიშების გამოყენება სტანდარტულ ფუნქციურ კლავიშებად“.

ზოგი F-კლავიში macOS-საც უკავია (მაგალითად Mission Control). თუ კლავიში აპში არაფერს აკეთებს, სცადეთ fn-თან ერთად, ან გამოიყენეთ ხელსაწყოების ზოლის ღილაკი.

## ბრაუზერის მიერ დაკავებული მალსახმობები

ვებგვერდს ზოგიერთ მალსახმობს ბრაუზერისგან ვერ წაართმევს, რაც არ უნდა აკეთოს. ყველა აპში:

- {{key:Mod+N}}, {{key:Mod+T}} და {{key:Mod+W}} ყოველთვის ბრაუზერის ფანჯრებსა და ჩანართებს ხსნის ან ხურავს. აპები ახლის და დახურვის ღილაკებს იყენებენ.
- {{key:Mod+Q}} Mac-ზე და {{key:Alt+F4}} Windows-ზე ბრაუზერს თიშავს. თუ შეუნახავი სამუშაო გაქვთ, ბრაუზერი ჯერ იკითხავს („საიტის დატოვება?“); აირჩიეთ დარჩენა და შემდეგ შეინახეთ.
- ბრაუზერის საკუთარი სრული ეკრანი ({{pick:mac=Control-Command-F, ან ფანჯრის მწვანე ღილაკი|windows linux=F11}}) კვლავ მუშაობს. აპებს აქვთ საკუთარი ეკრანის რეჟიმებიც {{key:Ctrl+Shift+F}}-ზე, რომლებიც აპის ზოლებსაც შეიძლება დამალავდეს.

## მაუსის ღილაკები სენსორულ პანელზე

აპები მარჯვენა და შუა ღილაკს იყენებენ. სამღილიანი მაუსის გარეშე:

:::mac
- **მარჯვენა დაწკაპუნება:** დააწკაპუნეთ ორი თითით. ჩართეთ „მეორადი დაწკაპუნება“ **სისტემის პარამეტრებში**, შემდეგ **თრექფედში**, თუ ორი თითით დაწკაპუნება არ მუშაობს. {{key:Ctrl}}-ის დაჭერა დაწკაპუნებისას ბრაუზერის მენიუს ხსნის, მაგრამ ნახაზში ზოგი აპი ამას ჩვეულებრივ დაწკაპუნებად კითხულობს (Control-ით), ამიტომ ურჩევნია ორი თითით დაწკაპუნება.
- **შუა ღილაკით გადათრევა (ხედის გადაადგილება):** თითოეული აპი სხვა გზას სთავაზობს, მაგალითად {{key:Space}}-ის დაჭერას გადათრევისას ან მარჯვენა ღილაკით გადათრევას. აპის კლავიატურის გვერდი ამბობს, რომელი.
- **ბორბლით მასშტაბირება:** ორი თითით სქროლი სენსორულ პანელზე უმეტეს აპში მასშტაბს ზრდის. შეკუმშვა (pinch) ასევე მასშტაბირებს, სადაც აპი მხარს უჭერს.
:::

:::windows linux
- **მარჯვენა დაწკაპუნება:** დააწკაპუნეთ ორი თითით, ან სენსორული პანელის ქვედა-მარჯვენა კუთხეზე. ეს თქვენი სენსორული პანელის პარამეტრებზეა დამოკიდებული.
- **შუა ღილაკით გადათრევა (ხედის გადაადგილება):** თითოეული აპი სხვა გზას სთავაზობს, მაგალითად {{key:Space}}-ის დაჭერას გადათრევისას ან მარჯვენა ღილაკით გადათრევას. აპის კლავიატურის გვერდი ამბობს, რომელი.
- **ბორბლით მასშტაბირება:** ორი თითით სქროლი სენსორულ პანელზე უმეტეს აპში მასშტაბს ზრდის.
:::

## ტექსტის ველში წერა

სანამ ველში წერთ (სახელი, შენიშვნა, ძიება), აპის ერთასოიანი მალსახმობები გამორთულია, ასე რომ „L“-ის აკრეფისას L იწერება. დააჭირეთ {{key:Esc}}-ს ან დააწკაპუნეთ ნახაზზე, რომ კლავიშები აპს დაუბრუნოთ.

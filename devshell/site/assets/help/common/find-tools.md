Every app has a search box for its tools, its settings and this help. You don't need to know where a tool sits in the toolbar.

## Find and run

1. Press {{key:Mod+K}}, or choose {{ui:Find}} in the bar at the top.
2. Type a few letters of what you want: "fillet", "panel text", "units". Every word you type has to match, so add a second word to narrow the list.
3. Press {{key:Enter}} to run the first match, or move with the arrow keys first. {{key:Esc}} closes the box.

A tool runs as if you had clicked it in the toolbar. A setting opens {{ui:Settings}} at that setting. A help topic opens here, in the help panel.

## Things to know

- What you used last comes first the next time, so a tool you use often is one key press away.
- Tools that can't run right now, for example before a file is open, are listed but greyed out.
- Add-ons' tools are in the list too, once the add-on is switched on.

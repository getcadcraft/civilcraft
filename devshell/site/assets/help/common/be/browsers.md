Праграмы працуюць у інтэрнэт-браўзеры. Яны выконваюць работу на вашым уласным кампутары: вашы файлы адкрываюцца там і ніколі не адпраўляюцца нам (гл. [Куды трапляюць вашы файлы](common:your-files)).

## Які браўзер

Карыстайцеся актуальнай версіяй аднаго з гэтых:

| Браўзер | Рухавік | Заўвагі |
|---|---|---|
| Chrome, Edge, Brave, Opera, Vivaldi | Chromium | Найпаўнейшы: выбар папкі, захаванне для працы па-за сеткай, апрацоўка файлаў. |
| Firefox | Gecko | Працуе. Адкрыццё цэлай папкі выкарыстоўвае прасцейшы выбар. Захаванне для працы па-за сеткай можа не працаваць у прыватных вокнах. |
| Safari | WebKit | Працуе на Mac і iPad. Адкрыццё цэлай папкі выкарыстоўвае прасцейшы выбар. Safari можа выдаліць аўтаномную копію, якой вы не карысталіся некалькі тыдняў. |

Усе тры рухавікі падыходзяць для штодзённай працы. Калі праграма робіць нешта інакш у адным з іх, яе даведка паказвае крокі для вашага браўзера.

## Чым браўзеры адрозніваюцца

- **Адкрыццё папкі.** Браўзеры на Chromium паказваюць сапраўдны выбар папкі і могуць чытаць папку напрамую. Firefox і Safari просяць выбраць папку, а потым чытаюць кожны файл у ёй, што займае больш часу для вялікіх праектных папак; перацягванне папкі ў праграму працуе ва ўсіх трох.
- **Захаванне.** Праграмы захоўваюць файлы, спампоўваючы іх. Браўзер сам вырашае, куды ідуць спампоўкі і ці пытае ён спачатку.

:::chromium
У Chrome або Edge уключыце «Ask where to save each file before downloading» («Пытаць, куды захаваць кожны файл перад спампоўваннем») у Наладах, у раздзеле Спампоўкі, каб выбіраць папку кожны раз.
:::

:::firefox
У Firefox адкрыйце Налады, затым Агульныя, затым Спампоўкі, і абярыце «Always ask you where to save files» («Заўсёды пытаць, куды захоўваць файлы»), каб выбіраць папку кожны раз.
:::

:::safari
У Safari адкрыйце Налады, затым Агульныя, і ўстанавіце «File download location» («Размяшчэнне спампаваных файлаў») на «Ask for each download» («Пытаць для кожнай спампоўкі»), каб выбіраць папку кожны раз.
:::

## Mac, Windows і Linux

Праграмы аднолькавыя на кожным кампутары. Мяняецца клавіятура: спалучэнні клавіш запісаны для вашага кампутара аўтаматычна. Гл. [Клавішы, мышы і тачпады](common:keys).

## Планшэты і сэнсарныя экраны

Некаторыя праграмы прымаюць дотык (адзін палец малюе або выбірае, два пальцы сціскаюцца для маштабавання і панарамавання). Даведка кожнай праграмы кажа, ці робіць яна гэта. На iPad выкарыстоўвайце Safari або Chrome. Клавіятура дапамагае з праграмамі, якія выкарыстоўваюць набраныя каманды.

## Самы стары браўзер і сістэма

Мы ўзялі гэтыя версіі з кода праграм 0.7, а не з здагадкі: кожны файл быў разабраны, і кожная моўная магчымасць, якую ён выкарыстоўвае, была праверана па апублікаваных даных сумяшчальнасці браўзераў. Ніжэй гэтых версій праграмы нават не запускаюцца, бо браўзер не разумее код.

| | Самая старая версія, якая можа запусціць праграмы |
|---|---|
| Chrome, Edge, Brave, Opera, Vivaldi | Chromium 94 |
| Firefox | 93 |
| Safari (Mac, iPad, iPhone) | 16.4 (macOS 13.3, iPadOS і iOS 16.4) |

CadCraft Studio мае ўласны вэб-рухавік у Windows, таму патрабуе Windows 10 або 11; на Mac ён выкарыстоўвае сістэмны, таму патрабуе macOS 13.3 або новейшую. Налады › Абнаўленні ў Studio паказваюць, на чым працуе ваша копія.

Гэта самая старая версія, якая *запускаецца*, паводле кода. Гэта не спіс старых браўзераў, у якіх мы запускалі праграмы, таму старэйшы браўзер, які запускаецца, можа ўсё яшчэ не мець некаторых магчымасцяў.

## Што патрэбна вашаму кампутару

Гэта плануемыя мінімумы для праграм, а не вымераныя патрабаванні:

- 8 GB памяці (16 GB рэкамендуецца для вялікіх федэратыўных мадэляў).
- Графічны чып з WebGL 2 для 3D-праграм. Калі 3D-від застаецца пустым, праверце, ці ўключана апаратнае паскарэнне ў наладах браўзера.
- Экран шырынёй не менш за 1280 пікселяў для поўных панэляў інструментаў; меншыя экраны іх пераносяць.

Вельмі вялікія файлы (вялікія наборы планаў, вялікія мадэлі) займаюць шмат памяці ў укладцы браўзера. Закрыйце іншыя цяжкія ўкладкі, калі праграма запавольваецца.

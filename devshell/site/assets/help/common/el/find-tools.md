Κάθε εφαρμογή έχει ένα πλαίσιο αναζήτησης για τα εργαλεία της, τις ρυθμίσεις της και αυτή τη βοήθεια. Δεν χρειάζεται να ξέρετε πού βρίσκεται ένα εργαλείο στη γραμμή εργαλείων.

## Εύρεση και εκτέλεση

1. Πατήστε {{key:Mod+K}} ή επιλέξτε {{ui:Εύρεση}} στη γραμμή στο πάνω μέρος.
2. Πληκτρολογήστε μερικά γράμματα από αυτό που θέλετε: «στρογγύλευση», «κείμενο πλαισίων», «μονάδες». Κάθε λέξη που πληκτρολογείτε πρέπει να ταιριάζει, οπότε προσθέστε δεύτερη λέξη για να περιορίσετε τη λίστα.
3. Πατήστε {{key:Enter}} για να εκτελέσετε την πρώτη αντιστοιχία ή κινηθείτε πρώτα με τα πλήκτρα βελών. Το {{key:Esc}} κλείνει το πλαίσιο.

Ένα εργαλείο εκτελείται σαν να το είχατε επιλέξει στη γραμμή εργαλείων. Μια ρύθμιση ανοίγει τις {{ui:Ρυθμίσεις}} σε εκείνη τη ρύθμιση. Ένα θέμα βοήθειας ανοίγει εδώ, στο πλαίσιο βοήθειας.

## Καλό είναι να γνωρίζετε

- Αυτό που χρησιμοποιήσατε τελευταίο εμφανίζεται πρώτο την επόμενη φορά, οπότε ένα εργαλείο που χρησιμοποιείτε συχνά απέχει ένα πάτημα πλήκτρου.
- Τα εργαλεία που δεν μπορούν να εκτελεστούν αυτή τη στιγμή, για παράδειγμα πριν ανοίξει ένα αρχείο, εμφανίζονται στη λίστα αλλά είναι γκριζαρισμένα.
- Τα εργαλεία των πρόσθετων βρίσκονται επίσης στη λίστα, μόλις ενεργοποιηθεί το πρόσθετο.

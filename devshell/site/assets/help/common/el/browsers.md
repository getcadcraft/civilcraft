Οι εφαρμογές τρέχουν μέσα σε πρόγραμμα περιήγησης. Κάνουν τη δουλειά στον δικό σας υπολογιστή: τα αρχεία σας ανοίγουν εκεί και δεν στέλνονται ποτέ σε εμάς (δείτε [Πού πηγαίνουν τα αρχεία σας](common:your-files)).

## Ποιο πρόγραμμα περιήγησης

Χρησιμοποιήστε μια ενημερωμένη έκδοση ενός από αυτά:

| Πρόγραμμα περιήγησης | Μηχανή | Σημειώσεις |
|---|---|---|
| Chrome, Edge, Brave, Opera, Vivaldi | Chromium | Το πληρέστερο: επιλογή φακέλου, αποθήκευση για χρήση εκτός σύνδεσης, χειρισμός αρχείων. |
| Firefox | Gecko | Λειτουργεί. Το άνοιγμα ολόκληρου φακέλου χρησιμοποιεί απλούστερο εργαλείο επιλογής. Η αποθήκευση εκτός σύνδεσης μπορεί να μη λειτουργεί σε ιδιωτικά παράθυρα. |
| Safari | WebKit | Λειτουργεί σε Mac και iPad. Το άνοιγμα ολόκληρου φακέλου χρησιμοποιεί απλούστερο εργαλείο επιλογής. Το Safari μπορεί να διαγράψει ένα αντίγραφο εκτός σύνδεσης που δεν έχετε χρησιμοποιήσει για μερικές εβδομάδες. |

Και οι τρεις μηχανές είναι εντάξει για την καθημερινή δουλειά. Όταν μια εφαρμογή κάνει κάτι διαφορετικά σε μία από αυτές, η βοήθειά της δείχνει τα βήματα για το πρόγραμμα περιήγησής σας.

## Τι διαφέρει ανάμεσα στα προγράμματα περιήγησης

- **Άνοιγμα φακέλου.** Τα προγράμματα περιήγησης Chromium εμφανίζουν πραγματικό εργαλείο επιλογής φακέλου και μπορούν να διαβάσουν τον φάκελο απευθείας. Το Firefox και το Safari σάς ζητούν να επιλέξετε φάκελο και μετά διαβάζουν κάθε αρχείο μέσα του, κάτι που διαρκεί περισσότερο για μεγάλους φακέλους έργων· η μεταφορά του φακέλου πάνω στην εφαρμογή λειτουργεί και στα τρία.
- **Αποθήκευση.** Οι εφαρμογές αποθηκεύουν κατεβάζοντας ένα αρχείο. Το πρόγραμμα περιήγησής σας αποφασίζει πού πηγαίνουν οι λήψεις και αν θα ρωτήσει πρώτα.

:::chromium
Στο Chrome ή το Edge, ενεργοποιήστε την επιλογή «Ερώτηση για τη θέση αποθήκευσης κάθε αρχείου πριν από τη λήψη» (στις Ρυθμίσεις, στις Λήψεις) για να επιλέγετε φάκελο κάθε φορά.
:::

:::firefox
Στο Firefox, ανοίξτε τις Ρυθμίσεις, μετά Γενικά, μετά Αρχεία και εφαρμογές, και επιλέξτε «Να ερωτάται πάντα πού θα αποθηκεύονται τα αρχεία» για να επιλέγετε φάκελο κάθε φορά.
:::

:::safari
Στο Safari, ανοίξτε τις Ρυθμίσεις, μετά Γενικά, και ορίστε την «Τοποθεσία λήψης αρχείων» σε «Ερώτηση για κάθε λήψη» για να επιλέγετε φάκελο κάθε φορά.
:::

## Mac, Windows και Linux

Οι εφαρμογές είναι ίδιες σε κάθε υπολογιστή. Αυτό που αλλάζει είναι το πληκτρολόγιο: οι συντομεύσεις γράφονται αυτόματα για τον υπολογιστή σας. Δείτε [Πλήκτρα, ποντίκια και trackpad](common:keys).

## Tablet και οθόνες αφής

Ορισμένες εφαρμογές δέχονται αφή (ένα δάχτυλο σχεδιάζει ή επιλέγει, δύο δάχτυλα τσιμπούν για ζουμ και μετατόπιση). Η βοήθεια κάθε εφαρμογής λέει αν το κάνει. Σε iPad, χρησιμοποιήστε Safari ή Chrome. Ένα πληκτρολόγιο βοηθά στις εφαρμογές που χρησιμοποιούν πληκτρολογούμενες εντολές.

## Το παλαιότερο πρόγραμμα περιήγησης και σύστημα

Τα διαβάσαμε από τον κώδικα των εφαρμογών 0.7, δεν τα εικάσαμε: κάθε αρχείο αναλύθηκε και κάθε γλωσσικό χαρακτηριστικό που χρησιμοποιεί αναζητήθηκε στα δημοσιευμένα δεδομένα συμβατότητας των προγραμμάτων περιήγησης. Κάτω από αυτές τις εκδόσεις οι εφαρμογές δεν μπορούν καν να ξεκινήσουν, επειδή το πρόγραμμα περιήγησης δεν καταλαβαίνει τον κώδικα.

| | Παλαιότερη έκδοση που μπορεί να ξεκινήσει τις εφαρμογές |
|---|---|
| Chrome, Edge, Brave, Opera, Vivaldi | Chromium 94 |
| Firefox | 93 |
| Safari (Mac, iPad, iPhone) | 16.4 (macOS 13.3, iPadOS και iOS 16.4) |

Το CadCraft Studio φέρνει τη δική του μηχανή ιστού στα Windows, οπότε χρειάζεται Windows 10 ή 11· σε Mac χρησιμοποιεί αυτήν του συστήματος, οπότε χρειάζεται macOS 13.3 ή νεότερο. Το Ρυθμίσεις › Ενημερώσεις στο Studio δείχνει σε τι τρέχει το αντίγραφό σας.

Αυτή είναι η παλαιότερη έκδοση που *ξεκινά*, όπως διαβάστηκε από τον κώδικα. Δεν είναι κατάλογος παλαιών προγραμμάτων περιήγησης στα οποία τρέξαμε τις εφαρμογές, οπότε ένα παλαιότερο που ξεκινά μπορεί και πάλι να στερείται κάποιου χαρακτηριστικού.

## Τι χρειάζεται ο υπολογιστής σας

Αυτά είναι προγραμματισμένα ελάχιστα για τις εφαρμογές, όχι μετρημένες απαιτήσεις:

- 8 GB μνήμης (συνιστώνται 16 GB για μεγάλα ομοσπονδιακά μοντέλα).
- Μια κάρτα γραφικών με WebGL 2 για τις εφαρμογές 3D. Αν μια προβολή 3D μένει κενή, ελέγξτε ότι η επιτάχυνση υλικού είναι ενεργοποιημένη στις ρυθμίσεις του προγράμματος περιήγησής σας.
- Οθόνη πλάτους τουλάχιστον 1280 pixel για τις πλήρεις γραμμές εργαλείων· οι μικρότερες οθόνες τις αναδιπλώνουν.

Πολύ μεγάλα αρχεία (μεγάλα σύνολα σχεδίων, μεγάλα μοντέλα) χρησιμοποιούν πολλή μνήμη σε μια καρτέλα προγράμματος περιήγησης. Κλείστε άλλες βαριές καρτέλες αν μια εφαρμογή γίνει αργή.

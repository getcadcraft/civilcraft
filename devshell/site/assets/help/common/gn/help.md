Opaite aplicación oguereko ipropio ayuda. Ha'e aplicación parte, upévare conexión ndaipóri ojepyrũ, ha ojehechauka version ojeporúva.

## Ejepyrũ ayuda

- Eapreta {{key:F1}}, térã eheja {{ui:Ayuda}} barra ryepýpe.
- Eapreta {{key:Esc}} térã eheja {{ui:Cerrar}} ayuda omboguejy. Nde plano ikatu ojehaicha.

:::mac
Mac teclado heta-pe, pa'ũ fila brillo ha sonido omoĩ. Eapreta {{key:F1}} ha **fn** tecla (térã globo tecla) ndive, térã eheja botón {{ui:Ayuda}}. Ver [Teclas Mac-pe](common:keys#function-keys-on-a-mac).
:::

## Tema ojehecha

- Emboheʼa cuadro de búsqueda ayuda ryepýpe. Resultado ojehechauka embohéra jave, ha ikatu oike ambue programa comando-kuéra; upéicha emboheʼa ndeporuvéva ambue-pe, ohupyty pe tembiapo ojeporúva.
- Temakuéra opaite aplicación-pe ojehayhápe ojeikepa: ojepyrũ, tutoriales, ambue programakuéra-gui oñemoĩ, referencia ha solución problema.
- Enlace ayuda tema ryepýpe ohasa siguiente tema mismo panel-pe. {{ui:Atrás}} ombohasa hendápe.

## Pasos nde computadora-pe

Ojehecha pasos hikuái Mac, Windows ha Linux-pe, navegador-kuéra ha conexión ojehasáva jey. Ayuda ohupyty mbaʼépa ojeporu ha ohechauka pe pasos. Tema ryepý línea oĩ ohechaukáva mbaʼépa ojesegi, peteĩ ejemplo "Mostrando pasos para Mac, Chrome o Edge, en línea".

- Eheja {{ui:Cambiar}} línea-pe ambue computadora térã navegador esgoge hag̃ua, ejemplo colega ayuda hag̃ua.
- Eheja {{ui:Mostrar todo}} opaite versión opaite pasos ohechauka, cada uno ojehechaha.

Atajo teclado oñemoĩ teclado ojehechaháicha: {{key:Mod+S}} Mac-pe ⌘S ha Windows ha Linux-pe Ctrl+S.

## Ayuda sitio web-pe

Sitio web ohechauka tembiapo temakuéra getcadcraft.com/tutorials-pe, opaite plataforma pasos ndive. Aplicación-pe {{ui:Abrir en el sitio web}} tema ryepýpe ojehecha pagina conectado jave.

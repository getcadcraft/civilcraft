## Mbaʼépa atajo oñemoĩ

Ayuda ohechauka atajo cada tecla ojehechaháicha nde teclado-pe.

| Oñemoĩ | Mac-pe | Windows ha Linux-pe |
|---|---|---|
| {{key:Mod+S}} | Command (⌘) ha S | Ctrl ha S |
| {{key:Ctrl+Shift+F}} | Control (⌃), Shift (⇧) ha F | Ctrl, Shift ha F |
| {{key:Alt+Left}} | Option (⌥) ha ← | Alt ha ← |
| {{key:Backspace}} | tecla Delete | Backspace |
| {{key:Delete}} | fn ha Delete (adelante borra) | Delete |
| {{key:Enter}} | Return | Enter |

Signo más ojehecha teclas mokõi ojejoguaʼỹ hag̃ua. "Upéi" ojehecha peteĩ peteĩ jey ojapo.

Atajo aplicación heta-pe oiko Command térã Control Mac-pe, upévare {{key:Mod+Z}} ombohasa mokõigui. Pocos, ejemplo pantalla completa ({{key:Ctrl+Shift+F}}), Control ojeporu opaite computadora-pe; ayuda ohechauka upéicha ojeporu-va jave.

## Función teclas Mac-pe

Mac teclado heta-pe pa'ũ fila brillo, volumen ha media omoĩ. F1 ha F12 ombohasa hag̃ua:

- eapreta **fn** (térã globo tecla) F-tecla ndive, térã
- eike **Preferencias del Sistema**, upéi **Teclado**, upéi **Atajos de teclado**, upéi **Teclas de función**, ha omoĩ "Usar las teclas F1, F2, etc. como teclas de función estándar".

Macos ipropio ojeporu F-tecla heta (ejemplo Mission Control). Tecla aplicación-pe ndojapói jave, eheja fn ndive térã barra botón.

## Atajo navegador ombotape'ava

Web página ndaikatúi ojagarra atajo navegador-gui, mboʼépa jave. Opaite aplicación-pe:

- {{key:Mod+N}}, {{key:Mod+T}} ha {{key:Mod+W}} ojeipyrũ térã ojeheka navegador ventana ha pestaña. Aplicación botón oporu Nuevo ha {{ui:Cerrar}}.
- Mac-pe {{key:Mod+Q}} ha Windows-pe {{key:Alt+F4}} navegador ojeheka. Archivo ndojehaiha jave, navegador pregunta ("¿Salir del sitio?"); eheja quedar ha guardar.
- Navegador pantalla completa ({{pick:mac=Control-Command-F, o el botón verde de la ventana|windows linux=F11}}) ojapo. Aplicación-pe ipropio pantalla modo {{key:Ctrl+Shift+F}}, aplicación barra oñemboguejy ikatu.

## Mouse botones trackpad-pe

Aplicación ojeporu botón derecho ha botón central. Mouse mbohapy botón ndaiporiva:

:::mac
- **Clic derecho:** ejapo mokõi dedo. Eheja "Clic secundario" **Preferencias del Sistema**-pe, upéi **Trackpad**-pe, mokõi dedo clic ndojapóiha jave. {{key:Ctrl}} ndive clic ojeheja navegador menú, pero plano ryepýpe aplicación ohupyty ojeporúa ojejoguaʼỹ (Control ndive), upévare mokõi dedo clic ojeporu.
- **Botón central arrastrar (desplazar):** aplicación heta ambue ñemboʼe, ejemplo {{key:Space}} ndive arrastra térã botón derecho ndive. Teclado página ohechauka mbaʼépa.
- **Rueda zoom:** mokõi dedo trackpad-pe zoom ojapo heta aplicación-pe. Pellizcar zoom oikoporã oĩ jave.
:::

:::windows linux
- **Clic derecho:** ejapo mokõi dedo, térã eapreta touchpad ñuguasu mboʼe pokatu. Tu ajuste touchpad-pe oñemoĩ.
- **Botón central arrastrar (desplazar):** aplicación heta ambue ñemboʼe, ejemplo {{key:Space}} ndive arrastra térã botón derecho ndive. Teclado página ohechauka mbaʼépa.
- **Rueda zoom:** mokõi dedo touchpad-pe zoom heta aplicación-pe.
:::

## Texto cuadro-pe escribir

Cuadro-pe escribí (nombre, nota, búsqueda), aplicación peteĩ letra atajo ojeheka, upévare "L" ojeporu L-ichaite. {{key:Esc}} térã plano-pe clic ojapo aplicación-pe teclas ojeporu jey.

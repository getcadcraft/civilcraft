Aplicaciones oĩ navegador ryepýpe. Ha'e ojapo tembiapo nde computadora-pe: nde archivokuéra ho'ãva upépe ha ndojeity ndéve ndojejuhúi (ver [Moʼãpa oho ne archivokuéra](common:your-files)).

## Mboʼépa navegador

Eheja peteĩ hetaiterei ndahasyvéva ko'ã-gui:

| Navegador | Motor | Ñemoñare |
|---|---|---|
| Chrome, Edge, Brave, Opera, Vivaldi | Chromium | Hetaiterei oikoveha: carpeta eheja, guardar para usar sin conexión, archivo ojeporu. |
| Firefox | Gecko | Oikoporãva. Carpeta peteĩ jey ojeheja selector ivaiʼỹva. Guardar sin conexión ndojapóiha ventana privada-pe. |
| Safari | WebKit | Oikoporãva Mac ha iPad-pe. Carpeta peteĩ jey ojeheja selector ivaiʼỹva. Safari ikatu omboguejy copia sin conexión ndojeporúiva heta semana. |

Mbohapy motor oikoporã ára ára tembiapo-pe. Aplicación ojapo ambue ojapoháicha peteĩ motor-pe, ayuda ohechauka pasos nde navegador-pe.

## Mboʼépa ojeʼẽ navegador-kuéra

- **Carpeta ojeheja.** Chromium navegador-kuéra ohechauka carpeta eheja verdadero, ha ikatu oikuaa carpeta directamente. Firefox ha Safari oñeporandu carpeta eheja, upéi oipapa opaite archivo carpeta-pe, ojeapumbývo carpeta tuichaiterei; carpeta arrastra aplicación-pe ojapo opaite mbohapy-pe.
- **Guardar.** Aplicación guardar ojapo archivo descargando. Navegador ojeporúta ikatu descarga oho, ha ikatu ohupi.

:::chromium
Chrome térã Edge-pe, eheja "Preguntar dónde guardar cada archivo antes de descargarlo" (Configuración-pe, Descargas ryepýpe) carpeta ojeheja opaite jey.
:::

:::firefox
Firefox-pe, eike Configuración, upéi General, upéi Descargas, ha eheja "Preguntar siempre dónde guardar archivos" carpeta ojeheja opaite jey.
:::

:::safari
Safari-pe, eike Configuración, upéi General, ha omoĩ "Ubicación de descargas de archivos" "Preguntar en cada descarga" carpeta ojeheja opaite jey.
:::

## Mac, Windows ha Linux

Aplicación opaite computadora-pe oĩ peteĩichaite. Ojeporu teclado oñemoambue: atajo ojapo nde computadora-pe automáticamente. Ver [Teclas, mouse ha trackpad](common:keys).

## Tableta ha pantalla touch

Heta aplicación oikoporã touch (peteĩ dedo dibuja térã eheja, mokõi dedo ojoaju zoom ha desplazar). Cada aplicación ayuda oñemboʼe mbaʼépa oikoporã. iPad-pe ojeporu Safari térã Chrome. Teclado oikoporã aplicación comando escribidos ojeporúva.

## Navegador tuichave ha sistema

Ko'ãva ojeporuvaʼekue 0.7 aplicación código-gui, ndaha'eʼỹi ñemoʼã: archivo opaite oñemoñepyrũ, ojeporu cada lengua ojehecha navegador-kuéra compatibilidad ojuehegua publicado. Ko versión gui ojeporúva ndaikatúi ojepyrũ, navegador ndoikuaáiva código.

| | Versión tuichave ojepyrũva aplicación |
|---|---|
| Chrome, Edge, Brave, Opera, Vivaldi | Chromium 94 |
| Firefox | 93 |
| Safari (Mac, iPad, iPhone) | 16.4 (macOS 13.3, iPadOS ha iOS 16.4) |

CadCraft Studio imperativo Windows-pe ohupytýva motor web, upévare Windows 10 térã 11 oikotevẽ; Mac-pe sistema motor ojeporu, upévare macOS 13.3 térã ambue ojeporu oikotevẽ. Studio-pe Configuración › Actualizaciones ohechauka mbaʼépa nde kópia ojapo.

Ko versión tuichave ojepyrũva, ndaha'éi navegador tuichave ojeporúva aplicación. Ambue ivaʼekue ojepyrũ ikatu ndoguerekói ambue tembiapo.

## Mbaʼépa oikotevẽ nde computadora-pe

Ko'ã ha'e plan mínimo aplicación-pe, ndaha'éi medido requisitos:

- 8 GB memoria (16 GB oñemoĩ modelo grande federados-pe).
- Gráfico WebGL 2 3D aplicaciónpe. 3D pantalla hyʼã jave, eaiko navegador ajuste-pe aceleración hardware oĩ hag̃ua.
- Pantalla 1280 píxel tuichave barras completas-pe; pantalla michĩve barra ohasa ambue fila-pe.

Archivo tuichave (plano hetaiterei, modelo tuichave) oĩ memoria heta navegador pestaña-pe. Ambue pestaña ojehecha aplicación ivaiʼỹ jave, eheja.

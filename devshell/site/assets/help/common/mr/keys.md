## शॉर्टकट कसे लिहिले जातात

मदत प्रत्येक शॉर्टकट तुमचा कीबोर्ड ज्या प्रकारे लेबल करतो त्या प्रकारे लिहिते.

| लिहिलेले | Mac वर | Windows आणि Linux वर |
|---|---|---|
| {{key:Mod+S}} | Command (⌘) आणि S | Ctrl आणि S |
| {{key:Ctrl+Shift+F}} | Control (⌃), Shift (⇧) आणि F | Ctrl, Shift आणि F |
| {{key:Alt+Left}} | Option (⌥) आणि ← | Alt आणि ← |
| {{key:Backspace}} | Delete की | Backspace |
| {{key:Delete}} | fn आणि Delete (पुढे डिलीट) | Delete |
| {{key:Enter}} | Return | Enter |

+ चिन्ह म्हणजे कळा एकत्र धरा. "मग" म्हणजे एकापाठोपाठ एक दाबा.

बहुतेक ॲप शॉर्टकट Mac वर Command किंवा Control दोन्ही स्वीकारतात, म्हणून {{key:Mod+Z}} दोन्ही प्रकारे चालतो. काही, जसे पूर्ण स्क्रीन ({{key:Ctrl+Shift+F}}), प्रत्येक संगणकावर Control की वापरतात; जेथे लागू असेल तेथे मदत तसे सांगते.

## Mac वरील फंक्शन की

Mac कीबोर्डच्या बहुतेक वरच्या ओळीत ब्राइटनेस, व्हॉल्यूम आणि मीडिया बदलते. F1 ते F12 पाठवण्यासाठी:

- कळ दाबताना **fn** (किंवा globe की) धरा, किंवा
- **System Settings** उघडा, मग **Keyboard**, मग **Keyboard Shortcuts**, मग **Function Keys**, आणि "Use F1, F2, etc. keys as standard function keys" चालू करा.

काही F-कळा macOS स्वतःही वापरते (उदाहरणार्थ Mission Control). कळ ॲपमध्ये काही करत नसेल, तर fn सोबत वापरून पहा, किंवा त्याऐवजी टूलबार बटण वापरा.

## ब्राउझरने राखलेले शॉर्टकट

वेब पेज ब्राउझरकडून काही शॉर्टकट, ते काहीही करो, घेऊ शकत नाही. प्रत्येक ॲपमध्ये:

- {{key:Mod+N}}, {{key:Mod+T}} आणि {{key:Mod+W}} नेहमी ब्राउझर विंडो आणि टॅब उघडतात किंवा बंद करतात. ॲप्स नवीन आणि बंद करण्यासाठी बटणे वापरतात.
- Mac वर {{key:Mod+Q}} आणि Windows वर {{key:Alt+F4}} ब्राउझर बंद करतात. सेव्ह न केलेले काम असल्यास ब्राउझर आधी विचारतो ("साइट सोडायची?"); राहण्याचा पर्याय निवडा, मग जतन करा.
- ब्राउझरची स्वतःची पूर्ण स्क्रीन ({{pick:mac=Control-Command-F, किंवा विंडोवरील हिरवे बटण|windows linux=F11}}) अजूनही चालते. ॲप्समध्ये {{key:Ctrl+Shift+F}} वर स्वतःचे स्क्रीन मोड देखील आहेत, जे ॲपच्या पट्ट्याही लपवू शकतात.

## ट्रॅकपॅडवरील माऊस बटणे

ॲप्स उजवे बटण आणि मधले बटण वापरतात. तीन-बटणी माऊस नसल्यास:

:::mac
- **उजवे-क्लिक:** दोन बोटांनी क्लिक करा. दोन-बोटांचा क्लिक काम करत नसल्यास, **System Settings** मध्ये, मग **Trackpad** मध्ये "Secondary click" चालू करा. {{key:Ctrl}} धरून क्लिक केल्याने ब्राउझरचा मेनू उघडतो, पण ड्रॉइंगमध्ये काही ॲप्स त्याला साधा क्लिक (Control धरलेला) मानतात, म्हणून दोन-बोटांचा क्लिक प्राधान्याने वापरा.
- **मधले-बटण ड्रॅग (पॅन):** प्रत्येक ॲप पॅन करण्याचा दुसरा मार्ग देते, जसे {{key:Space}} धरून ड्रॅग करणे किंवा उजव्या बटणाने ड्रॅग करणे. ॲपचे कीबोर्ड पान कोणता ते सांगते.
- **चाकाने झूम:** ट्रॅकपॅडवर दोन-बोटांचे स्क्रोल बहुतेक ॲप्समध्ये झूम इन करते. ॲप समर्थन देत असल्यास चिमटा घेऊनही झूम होते.
:::

:::windows linux
- **उजवे-क्लिक:** दोन बोटांनी क्लिक करा, किंवा टचपॅडच्या खालच्या उजव्या कोपऱ्यावर क्लिक करा. हे तुमच्या टचपॅड सेटिंग्जवर अवलंबून असते.
- **मधले-बटण ड्रॅग (पॅन):** प्रत्येक ॲप पॅन करण्याचा दुसरा मार्ग देते, जसे {{key:Space}} धरून ड्रॅग करणे किंवा उजव्या बटणाने ड्रॅग करणे. ॲपचे कीबोर्ड पान कोणता ते सांगते.
- **चाकाने झूम:** टचपॅडवर दोन-बोटांचे स्क्रोल बहुतेक ॲप्समध्ये झूम इन करते.
:::

## मजकूर बॉक्समध्ये टाइप करणे

तुम्ही बॉक्समध्ये (नाव, नोंद, शोध) टाइप करत असताना ॲपचे एका-अक्षरी शॉर्टकट बंद असतात, त्यामुळे "L" टाइप केल्यास L टाइप होतो. ॲपकडे कळा परत देण्यासाठी {{key:Esc}} दाबा किंवा ड्रॉइंगवर क्लिक करा.

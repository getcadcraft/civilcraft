## شارٹ کٹس کیسے لکھے جاتے ہیں

مدد ہر شارٹ کٹ کو اسی طرح لکھتی ہے جس طرح آپ کا کی بورڈ اسے لیبل کرتا ہے۔

| لکھا ہوا | Mac پر | Windows اور Linux پر |
|---|---|---|
| {{key:Mod+S}} | Command (⌘) اور S | Ctrl اور S |
| {{key:Ctrl+Shift+F}} | Control (⌃)، Shift (⇧) اور F | Ctrl، Shift اور F |
| {{key:Alt+Left}} | Option (⌥) اور ← | Alt اور ← |
| {{key:Backspace}} | Delete کلید | Backspace |
| {{key:Delete}} | fn اور Delete (آگے کی طرف حذف) | Delete |
| {{key:Enter}} | Return | Enter |

+ کا نشان مطلب ہے کہ کلیدیں ایک ساتھ دبائے رکھیں۔ "پھر" کا مطلب ہے کہ ایک کے بعد ایک دبائیں۔

ایپ کے زیادہ تر شارٹ کٹس Mac پر Command یا Control دونوں قبول کرتے ہیں، اس لیے {{key:Mod+Z}} دونوں طرح کام کرتا ہے۔ کچھ، جیسے مکمل اسکرین ({{key:Ctrl+Shift+F}})، ہر کمپیوٹر پر Control کلید استعمال کرتے ہیں؛ جہاں یہ لاگو ہو وہاں مدد یہ بتاتی ہے۔

## Mac پر فنکشن کلیدیں

زیادہ تر Mac کی بورڈز پر اوپر والی قطار چمک، آواز اور میڈیا بدلتی ہے۔ F1 سے F12 بھیجنے کے لیے:

- **fn** (یا گلوب کلید) دباتے ہوئے کلید دبائیں، یا
- **System Settings** کھولیں، پھر **Keyboard**، پھر **Keyboard Shortcuts**، پھر **Function Keys**، اور "Use F1, F2, etc. keys as standard function keys" آن کریں۔

کچھ F-کلیدیں macOS خود بھی استعمال کرتا ہے (مثلاً Mission Control)۔ اگر کوئی کلید ایپ میں کچھ نہ کرے تو اسے fn کے ساتھ آزمائیں، یا اس کی جگہ ٹول بار کا بٹن استعمال کریں۔

## وہ شارٹ کٹس جو براؤزر اپنے پاس رکھتا ہے

ویب صفحہ براؤزر سے کچھ شارٹ کٹس لے نہیں سکتا، چاہے وہ کچھ بھی کرے۔ ہر ایپ میں:

- {{key:Mod+N}}، {{key:Mod+T}} اور {{key:Mod+W}} ہمیشہ براؤزر کی ونڈوز اور ٹیبز کھولتے یا بند کرتے ہیں۔ ایپس نئے اور بند کرنے کے لیے بٹن استعمال کرتی ہیں۔
- Mac پر {{key:Mod+Q}} اور Windows پر {{key:Alt+F4}} براؤزر بند کرتے ہیں۔ اگر آپ کا کام محفوظ نہ ہو تو براؤزر پہلے پوچھتا ہے ("Leave site?")؛ رہنے کا انتخاب کریں، پھر محفوظ کریں۔
- براؤزر کی اپنی مکمل اسکرین ({{pick:mac=Control-Command-F, یا ونڈو پر سبز بٹن|windows linux=F11}}) اب بھی کام کرتی ہے۔ ایپس کے اپنے اسکرین موڈز {{key:Ctrl+Shift+F}} پر ہیں، جو ایپ کی پٹیاں بھی چھپا سکتے ہیں۔

## ٹریک پیڈ پر ماؤس کے بٹن

ایپس دائیں بٹن اور درمیانی بٹن استعمال کرتی ہیں۔ تین بٹن والے ماؤس کے بغیر:

:::mac
- **دائیں کلک:** دو انگلیوں سے کلک کریں۔ اگر دو انگلیوں کا کلک کام نہ کرے تو **System Settings** میں، پھر **Trackpad** میں "Secondary click" آن کریں۔ {{key:Ctrl}} دباتے ہوئے کلک کرنے سے براؤزر کا مینو کھلتا ہے، مگر ڈرائنگ کے اندر کچھ ایپس اسے عام کلک (Control کے ساتھ) سمجھتی ہیں، اس لیے دو انگلیوں والے کلک کو ترجیح دیں۔
- **درمیانی بٹن سے گھسیٹنا (پین):** ہر ایپ پین کرنے کا ایک اور طریقہ دیتی ہے، جیسے گھسیٹتے ہوئے {{key:Space}} دبائے رکھنا یا دائیں بٹن سے گھسیٹنا۔ ایپ کا کی بورڈ صفحہ بتاتا ہے کہ کون سا۔
- **پہیے سے زوم:** ٹریک پیڈ پر دو انگلیوں سے اسکرول زیادہ تر ایپس میں زوم ان کرتا ہے۔ جہاں ایپ سپورٹ کرے وہاں پنچ بھی زوم کرتا ہے۔
:::

:::windows linux
- **دائیں کلک:** دو انگلیوں سے کلک کریں، یا ٹچ پیڈ کے نچلے دائیں کونے پر کلک کریں۔ یہ آپ کی ٹچ پیڈ کی ترتیبات پر منحصر ہے۔
- **درمیانی بٹن سے گھسیٹنا (پین):** ہر ایپ پین کرنے کا ایک اور طریقہ دیتی ہے، جیسے گھسیٹتے ہوئے {{key:Space}} دبائے رکھنا یا دائیں بٹن سے گھسیٹنا۔ ایپ کا کی بورڈ صفحہ بتاتا ہے کہ کون سا۔
- **پہیے سے زوم:** ٹچ پیڈ پر دو انگلیوں سے اسکرول زیادہ تر ایپس میں زوم کرتا ہے۔
:::

## ٹیکسٹ باکس میں ٹائپ کرنا

جب آپ کسی باکس میں ٹائپ کرتے ہیں (نام، نوٹ، سرچ)، تو ایپ کے ایک حرف والے شارٹ کٹس بند ہوتے ہیں، اس لیے "L" ٹائپ کرنے سے L ہی لکھا جاتا ہے۔ کلیدیں ایپ کو واپس دینے کے لیے {{key:Esc}} دبائیں یا ڈرائنگ پر کلک کریں۔

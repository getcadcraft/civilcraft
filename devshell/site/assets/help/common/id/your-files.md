## File Anda tetap di komputer Anda

Saat Anda membuka gambar, model, atau PDF, app membacanya di dalam peramban Anda. **File tidak diunggah.** Kami tidak pernah melihatnya, dan cara kerjanya sama saja tanpa koneksi.

## Cara kerja penyimpanan

Halaman web tidak dapat menimpa file di komputer Anda dengan sendirinya, jadi app menyimpan dengan **mengunduh** file baru:

- Hasil unduhan masuk ke tempat peramban Anda menaruh unduhan, biasanya folder Downloads, kecuali Anda mengatur peramban agar bertanya setiap kali (lihat [Peramban dan komputer](common:browsers#what-differs-between-browsers)).
- App yang mengubah file menyimpan salinan dengan nama baru, seperti "(edited)" atau "(marked up)", sehingga file asli Anda tidak tersentuh.
- Jika Anda menutup tab saat masih ada pekerjaan yang belum disimpan, peramban bertanya dulu ("Tinggalkan situs?").

## Yang diingat peramban

Sebagian app mengingat pengaturan kecil di peramban Anda, seperti nama penulis atau gaya alat. Semuanya tetap di peramban itu pada komputer itu, dan menghapus data situs akan menghilangkannya. Bantuan setiap app menyebutkan apa yang disimpannya.

## Penyimpanan cloud

Penyimpanan cloud dan sinkronisasi antarkomputer adalah bagian dari lisensi komersial. Fitur ini belum tersedia. Sampai saat itu, simpan file Anda di tempat Anda menyimpan file proyek lainnya dan cadangkan dengan cara biasa.

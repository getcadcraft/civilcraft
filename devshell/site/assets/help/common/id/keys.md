## Cara pintasan ditulis

Bantuan menulis setiap pintasan sesuai label pada keyboard Anda.

| Tertulis | Di Mac | Di Windows dan Linux |
|---|---|---|
| {{key:Mod+S}} | Command (⌘) dan S | Ctrl dan S |
| {{key:Ctrl+Shift+F}} | Control (⌃), Shift (⇧), dan F | Ctrl, Shift, dan F |
| {{key:Alt+Left}} | Option (⌥) dan ← | Alt dan ← |
| {{key:Backspace}} | tombol Delete | Backspace |
| {{key:Delete}} | fn dan Delete (hapus ke depan) | Delete |
| {{key:Enter}} | Return | Enter |

Tanda plus berarti tombol ditahan bersamaan. "Lalu" berarti ditekan satu per satu.

Sebagian besar pintasan app menerima Command atau Control di Mac, jadi {{key:Mod+Z}} berfungsi dengan keduanya. Beberapa, seperti layar penuh ({{key:Ctrl+Shift+F}}), memakai tombol Control di semua komputer; bantuan menyebutkannya di tempat yang berlaku.

## Tombol fungsi di Mac

Pada sebagian besar keyboard Mac, baris paling atas mengatur kecerahan, volume, dan media. Untuk mengirim F1 sampai F12:

- tahan **fn** (atau tombol globe) sambil menekan tombolnya, atau
- buka **Pengaturan Sistem**, lalu **Keyboard**, lalu **Pintasan Keyboard**, lalu **Tombol Fungsi**, dan nyalakan "Gunakan tombol F1, F2, dsb. sebagai tombol fungsi standar".

Beberapa tombol F juga dipakai oleh macOS sendiri (misalnya Mission Control). Jika sebuah tombol tidak berfungsi di app, coba dengan fn, atau pakai tombol di bilah alat.

## Pintasan yang dipertahankan peramban

Halaman web tidak dapat mengambil sebagian pintasan dari peramban, apa pun yang dilakukannya. Di setiap app:

- {{key:Mod+N}}, {{key:Mod+T}}, dan {{key:Mod+W}} selalu membuka atau menutup jendela dan tab peramban. App memakai tombol untuk Baru dan Tutup.
- {{key:Mod+Q}} di Mac dan {{key:Alt+F4}} di Windows menutup peramban. Jika ada pekerjaan yang belum disimpan, peramban bertanya dulu ("Tinggalkan situs?"); pilih untuk tetap di halaman, lalu simpan.
- Layar penuh milik peramban ({{pick:mac=Control-Command-F, atau tombol hijau pada jendela|windows linux=F11}}) tetap berfungsi. App juga punya mode layar sendiri di {{key:Ctrl+Shift+F}}, yang dapat menyembunyikan bilah app juga.

## Tombol mouse pada trackpad

App memakai tombol kanan dan tombol tengah. Tanpa mouse tiga tombol:

:::mac
- **Klik kanan:** klik dengan dua jari. Nyalakan "Klik sekunder" di **Pengaturan Sistem**, lalu **Trackpad**, jika klik dua jari tidak berefek. Menahan {{key:Ctrl}} saat mengklik membuka menu peramban, tetapi di dalam gambar sebagian app membacanya sebagai klik biasa (dengan Control ditahan), jadi pilih klik dua jari.
- **Seret tombol tengah (geser):** setiap app menawarkan cara lain untuk menggeser, seperti menahan {{key:Space}} sambil menyeret atau menyeret dengan tombol kanan. Halaman keyboard app menyebutkannya.
- **Zoom roda:** gulir dua jari di trackpad memperbesar atau memperkecil di sebagian besar app. Cubit juga melakukan zoom bila app mendukungnya.
:::

:::windows linux
- **Klik kanan:** klik dengan dua jari, atau klik sudut kanan bawah touchpad. Ini bergantung pada pengaturan touchpad Anda.
- **Seret tombol tengah (geser):** setiap app menawarkan cara lain untuk menggeser, seperti menahan {{key:Space}} sambil menyeret atau menyeret dengan tombol kanan. Halaman keyboard app menyebutkannya.
- **Zoom roda:** gulir dua jari di touchpad memperbesar atau memperkecil di sebagian besar app.
:::

## Mengetik di kotak teks

Saat Anda mengetik di sebuah kotak (nama, catatan, pencarian), pintasan satu huruf milik app dimatikan, jadi mengetik "L" menghasilkan huruf L. Tekan {{key:Esc}} atau klik pada gambar untuk mengembalikan tombol ke app.

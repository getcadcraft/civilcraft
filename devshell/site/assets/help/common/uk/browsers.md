Застосунки працюють у веббраузері. Вони виконують роботу на вашому компʼютері: ваші файли відкриваються там і ніколи не надсилаються нам (див. [Куди потрапляють ваші файли](common:your-files)).

## Який браузер

Використовуйте актуальну версію одного з цих:

| Браузер | Рушій | Примітки |
|---|---|---|
| Chrome, Edge, Brave, Opera, Vivaldi | Chromium | Найповніший: вибір папки, збереження для роботи без зʼєднання, обробка файлів. |
| Firefox | Gecko | Працює. Для відкриття цілої папки використовується простіший засіб вибору. Збереження для роботи без зʼєднання може не працювати у приватних вікнах. |
| Safari | WebKit | Працює на Mac та iPad. Для відкриття цілої папки використовується простіший засіб вибору. Safari може видалити копію для роботи без зʼєднання, якою ви не користувалися кілька тижнів. |

Усі три рушії годяться для щоденної роботи. Якщо застосунок у якомусь із них робить щось інакше, його довідка показує кроки для вашого браузера.

## Чим відрізняються браузери

- **Відкриття папки.** Браузери на Chromium показують справжній засіб вибору папки й можуть читати папку напряму. Firefox і Safari просять вибрати папку, а потім читають кожен файл у ній, що триває довше для великих папок проєктів; перетягування папки на застосунок працює в усіх трьох.
- **Збереження.** Застосунки зберігають, завантажуючи файл. Браузер вирішує, куди потрапляють завантаження і чи питає він спочатку.

:::chromium
У Chrome або Edge увімкніть «Запитувати, куди зберігати кожен файл перед завантаженням» (в Налаштуваннях, у розділі «Завантаження»), щоб щоразу вибирати папку.
:::

:::firefox
У Firefox відкрийте Налаштування, потім Загальні, потім Файли й програми та виберіть «Завжди запитувати, куди зберігати файли», щоб щоразу вибирати папку.
:::

:::safari
У Safari відкрийте Налаштування, потім Загальні та встановіть «Розташування завантажених файлів» на «Запитувати для кожного завантаження», щоб щоразу вибирати папку.
:::

## Mac, Windows і Linux

Застосунки однакові на кожному компʼютері. Змінюється лише клавіатура: комбінації клавіш пишуться для вашого компʼютера автоматично. Див. [Клавіші, миші та трекпади](common:keys).

## Планшети та сенсорні екрани

Деякі застосунки підтримують дотик (один палець малює або вибирає, два пальці зводяться для масштабування й зсуву). Довідка кожного застосунку каже, чи це так. На iPad використовуйте Safari або Chrome. Клавіатура допомагає в застосунках, які використовують команди, що вводяться текстом.

## Найстаріший браузер і система

Ми взяли це з коду застосунків 0.7, а не навмання: кожен файл було розібрано, і кожну мовну можливість, яку він використовує, знайдено в опублікованих даних сумісності браузерів. Нижче цих версій застосунки не можуть навіть запуститися, бо браузер не розуміє код.

| | Найстаріша версія, що може запустити застосунки |
|---|---|
| Chrome, Edge, Brave, Opera, Vivaldi | Chromium 94 |
| Firefox | 93 |
| Safari (Mac, iPad, iPhone) | 16.4 (macOS 13.3, iPadOS та iOS 16.4) |

CadCraft Studio має власний вебрушій у Windows, тому потребує Windows 10 або 11; на Mac він використовує системний, тому потребує macOS 13.3 або новішої. Налаштування › Оновлення в Studio показують, на чому працює ваша копія.

Це найстаріша версія, що *запускається*, визначена за кодом. Це не перелік старих браузерів, у яких ми запускали застосунки, тож старіший браузер, що запускається, усе одно може не мати якоїсь можливості.

## Що потрібно вашому компʼютеру

Це планові мінімальні вимоги до застосунків, а не виміряні:

- 8 ГБ памʼяті (для великих федеративних моделей рекомендовано 16 ГБ).
- Графічний чип із WebGL 2 для 3D-застосунків. Якщо 3D-вигляд лишається порожнім, перевірте, чи ввімкнено апаратне прискорення в налаштуваннях браузера.
- Екран завширшки щонайменше 1280 пікселів для повних панелей інструментів; на менших екранах їх переносить на кілька рядків.

Дуже великі файли (великі набори планів, великі моделі) використовують багато памʼяті у вкладці браузера. Закрийте інші важкі вкладки, якщо застосунок сповільнюється.

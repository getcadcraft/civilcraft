Some checks need a real computer, a real file or a real device. The Community testing page lists them so anyone can help.

## Send a result

1. Open the **Community testing** page on the website and choose a test.
2. Use the public build named in **Before you start**, never a lab build.
3. Follow the **Steps** and compare with the **Expected result**.
4. Fill in **Send a result**: passed, still failing, partly works, or could not run it. Say which system you used and what happened.

You do not need an account to send a result. A signed-in account is needed only to send files.

## Sending files

When a test asks for files, drag them into the framed area (or click it, or press Enter or Space on it to choose them). You can send several at once; each shows its name and size and a Remove button. The form says which file types and sizes we take. We never take programs, scripts or web pages.

## Your privacy

- A result sent while you are signed in carries your account so we can write back. It is never shown on the page.
- Your first name is shown next to a result only if you tick **Show my first name**.
- Notes are shown to others only if you tick **Anyone may read my notes**.
- Files are seen only by the CadCraft team, kept privately and deleted automatically after the number of days the form states. Remove anything private from a file first.

## What counts as "known not to work"

Each test lists what is not built yet. Please do not report those as bugs.

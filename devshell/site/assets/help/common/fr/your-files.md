## Vos fichiers restent sur votre ordinateur

Lorsque vous ouvrez un dessin, un modèle ou un PDF, l'application le lit dans votre navigateur. **Le fichier n'est pas téléversé.** Nous ne le voyons jamais, et tout fonctionne de la même façon sans connexion.

## Comment fonctionne l'enregistrement

Une page de navigateur ne peut pas écraser seule des fichiers sur votre ordinateur ; les applications enregistrent donc en **téléchargeant** un nouveau fichier :

- Le téléchargement va là où votre navigateur place les téléchargements, généralement votre dossier Téléchargements, sauf si vous l'avez réglé pour demander à chaque fois (voir [Navigateurs et ordinateurs](common:browsers#what-differs-between-browsers)).
- Les applications qui modifient un fichier enregistrent une copie sous un nouveau nom, par exemple « (modifié) » ou « (annoté) », afin que votre original reste intact.
- Si vous fermez l'onglet avec un travail non enregistré, le navigateur vous demande d'abord confirmation (« Quitter le site ? »).

## Ce dont le navigateur se souvient

Certaines applications mémorisent de petits paramètres dans votre navigateur, comme le nom de l'auteur ou les styles d'outils. Ils restent dans ce navigateur sur cet ordinateur, et l'effacement des données du site les supprime. L'aide de chaque application indique ce qu'elle conserve.

## Enregistrement dans le cloud

L'enregistrement dans le cloud et la synchronisation entre ordinateurs font partie de la licence commerciale. Ils ne sont pas encore disponibles. D'ici là, gardez vos fichiers là où vous rangez vos autres fichiers de projet et sauvegardez-les de la façon habituelle.

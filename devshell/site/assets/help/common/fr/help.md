Chaque application embarque sa propre aide. Elle fait partie de l'application : elle s'ouvre donc sans connexion et décrit toujours la version que vous utilisez.

## Ouvrir l'aide

- Appuyez sur {{key:F1}}, ou choisissez {{ui:Aide}} dans la barre en haut de l'application.
- Appuyez sur {{key:Esc}} ou choisissez {{ui:Fermer}} pour la ranger. Votre dessin reste tel qu'il était.

:::mac
Sur la plupart des claviers Mac, la rangée du haut commande la luminosité et le son. Appuyez sur {{key:F1}} avec la touche **fn** (ou la touche globe), ou utilisez le bouton {{ui:Aide}}. Voir [Touches sur un Mac](common:keys#function-keys-on-a-mac).
:::

## Trouver une rubrique

- Saisissez du texte dans la zone de recherche en haut de l'aide. Les résultats se mettent à jour pendant la saisie et incluent les noms de commandes d'autres programmes : saisir ce que vous auriez saisi ailleurs trouve donc généralement la bonne page.
- Les rubriques sont regroupées de la même façon dans chaque application : premiers pas, pas à pas, venir d'un autre logiciel, référence et dépannage.
- Les liens dans une rubrique ouvrent la rubrique suivante dans le même panneau. {{ui:Retour}} vous ramène là où vous étiez.

## Étapes pour votre ordinateur

Certaines étapes diffèrent entre Mac, Windows et Linux, entre navigateurs, et selon que vous êtes en ligne ou hors ligne. L'aide détermine ce qui vous concerne et affiche ces étapes. La ligne en haut d'une rubrique indique ce qu'elle a choisi, par exemple « Étapes affichées pour Mac, Chrome ou Edge, en ligne ».

- Choisissez {{ui:Modifier}} sur cette ligne pour sélectionner un autre ordinateur ou navigateur, par exemple pour aider un collègue.
- Choisissez {{ui:Tout afficher}} pour voir chaque version de chaque étape, chacune avec son étiquette.

Les raccourcis clavier sont écrits comme votre clavier les nomme : {{key:Mod+S}} se lit ⌘S sur un Mac et Ctrl+S sous Windows et Linux.

## La même aide sur le site web

Le site web affiche les mêmes rubriques sur getcadcraft.com/tutorials, avec les étapes de chaque plateforme. Dans l'application, {{ui:Ouvrir sur le site web}} en bas d'une rubrique ouvre cette page lorsque vous êtes en ligne.

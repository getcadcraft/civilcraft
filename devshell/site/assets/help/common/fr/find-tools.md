Chaque application a une zone de recherche pour ses outils, ses paramètres et cette aide. Inutile de savoir où se trouve un outil dans la barre d'outils.

## Rechercher et lancer

1. Appuyez sur {{key:Mod+K}}, ou choisissez {{ui:Rechercher}} dans la barre en haut.
2. Saisissez quelques lettres de ce que vous voulez : « raccord », « texte du panneau », « unités ». Chaque mot saisi doit correspondre ; ajoutez donc un second mot pour réduire la liste.
3. Appuyez sur {{key:Enter}} pour lancer le premier résultat, ou déplacez-vous d'abord avec les flèches. {{key:Esc}} ferme la zone.

Un outil se lance comme si vous aviez cliqué dessus dans la barre d'outils. Un paramètre ouvre {{ui:Paramètres}} à cet endroit. Une rubrique d'aide s'ouvre ici, dans le panneau d'aide.

## À savoir

- Ce que vous avez utilisé en dernier arrive en premier la fois suivante : un outil que vous utilisez souvent est donc à une touche.
- Les outils qui ne peuvent pas s'exécuter pour le moment, par exemple avant l'ouverture d'un fichier, figurent dans la liste mais sont grisés.
- Les outils des modules complémentaires figurent aussi dans la liste, une fois le module activé.

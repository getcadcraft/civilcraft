Les applications font leur travail sur votre ordinateur ; la plupart des fonctions marchent donc sans connexion. Le navigateur a seulement besoin d'avoir enregistré d'abord les fichiers de l'application.

## Enregistrer une application pour le hors ligne

1. Ouvrez l'application lorsque vous êtes en ligne.
2. Choisissez {{ui:Enregistrer pour le hors ligne}} dans la barre en haut.
3. Attendez « Prêt hors ligne ». Les fichiers de l'application, ses lecteurs de fichiers et cette aide sont maintenant enregistrés dans votre navigateur. Les applications qui lisent des fichiers DWG ou PDF enregistrent aussi leurs lecteurs ; la première fois, cela peut donc prendre une minute.

Faites-le une fois par application, dans chaque navigateur que vous utilisez. Pour revenir plus tard à l'application sans connexion, ouvrez la même adresse que la fois précédente, ou un signet de celle-ci.

:::offline
Vous êtes hors ligne. Si cette application a été enregistrée pour le hors ligne, tout ce qui suit fonctionne. Sinon, vous pouvez quand même utiliser ce qui est déjà chargé dans cet onglet, mais ne le rechargez pas avant d'être de nouveau en ligne.
:::

## Ce qui fonctionne hors ligne

- Ouvrir des fichiers de votre ordinateur, dessiner, modifier, mesurer et vérifier.
- Enregistrer et exporter : chaque enregistrement est un téléchargement vers votre ordinateur.
- Cette aide, recherche comprise.

## Ce qui demande une connexion

- Ouvrir l'application pour la première fois et l'enregistrer pour le hors ligne.
- Obtenir une version plus récente de l'application. Lorsque vous êtes en ligne, l'application récupère la version la plus récente à sa prochaine ouverture, et {{ui:Enregistrer pour le hors ligne}} actualise la copie enregistrée.
- Les liens vers le site web, comme {{ui:Ouvrir sur le site web}}, et les liens vers d'autres pages.
- L'enregistrement dans le cloud et la synchronisation entre ordinateurs, qui ne sont pas encore disponibles.

## À savoir

- Une copie enregistrée appartient à un navigateur sur un ordinateur. L'effacement des données de site de votre navigateur la supprime.
- Les fenêtres privées de certains navigateurs, et certains ordinateurs de travail verrouillés, n'autorisent pas l'enregistrement hors ligne. Le bouton vous prévient lorsqu'il ne peut pas enregistrer.

:::safari
Safari supprime les données enregistrées des sites que vous n'avez pas visités depuis plusieurs semaines. Ouvrez l'application de temps en temps en ligne, ou enregistrez-la de nouveau avant un déplacement.
:::

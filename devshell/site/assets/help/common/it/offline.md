Le app svolgono il lavoro sul computer, quindi quasi tutto funziona senza connessione. Al browser basta aver salvato prima i file dell'app.

## Salvare un'app per l'uso offline

1. Aprire l'app quando si è online.
2. Scegliere {{ui:Salva per l'uso offline}} nella barra in alto.
3. Attendere "Pronto per l'uso offline". I file dell'app, i suoi lettori di file e questa guida sono ora salvati nel browser. Le app che leggono file DWG o PDF salvano anche i relativi lettori, quindi la prima volta può occorrere un minuto.

Farlo una volta per app, in ogni browser usato. Per tornare all'app più tardi senza connessione, aprire lo stesso indirizzo usato prima, oppure un suo segnalibro.

:::offline
Al momento si è offline. Se questa app è stata salvata per l'uso offline, tutto ciò che segue funziona. In caso contrario, è ancora possibile usare ciò che è già caricato in questa scheda, ma senza ricaricarla finché non si è di nuovo online.
:::

## Che cosa funziona offline

- Aprire file dal computer, disegnare, modificare, misurare e verificare.
- Salvare ed esportare: ogni salvataggio è un file scaricato sul computer.
- Questa guida, ricerca compresa.

## Che cosa richiede una connessione

- Aprire l'app per la prima volta e salvarla per l'uso offline.
- Ottenere una versione più recente dell'app. Quando si è online, l'app preleva la versione più recente alla successiva apertura e {{ui:Salva per l'uso offline}} aggiorna la copia salvata.
- I collegamenti al sito web, come {{ui:Apri sul sito web}}, e i collegamenti ad altre pagine.
- Il salvataggio nel cloud e la sincronizzazione tra computer, non ancora disponibili.

## Da sapere

- Una copia salvata appartiene a un solo browser su un solo computer. Cancellando i dati dei siti del browser viene rimossa.
- Le finestre private di alcuni browser e alcuni computer aziendali con restrizioni non consentono il salvataggio offline. Il pulsante segnala quando non può salvare.

:::safari
Safari rimuove i dati salvati dei siti non visitati da diverse settimane. Aprire l'app ogni tanto quando si è online, oppure salvarla di nuovo prima di un viaggio.
:::

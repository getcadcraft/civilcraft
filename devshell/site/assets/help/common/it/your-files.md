## I file restano sul proprio computer

Quando si apre un disegno, un modello o un PDF, l'app lo legge all'interno del browser. **Il file non viene caricato.** Non lo vediamo mai e funziona allo stesso modo senza connessione.

## Come funziona il salvataggio

Una pagina del browser non può sovrascrivere da sola i file del computer, quindi le app salvano **scaricando** un nuovo file:

- Il file scaricato va dove il browser mette i download, di solito la cartella Download, a meno che il browser non sia impostato per chiedere ogni volta (vedere [Browser e computer](common:browsers#what-differs-between-browsers)).
- Le app che modificano un file ne salvano una copia con un nuovo nome, come "(modificato)" o "(annotato)", così l'originale resta intatto.
- Se si chiude la scheda con lavoro non salvato, il browser chiede prima conferma ("Uscire dal sito?").

## Che cosa ricorda il browser

Alcune app ricordano piccole impostazioni nel browser, come il nome dell'autore o gli stili degli strumenti. Restano in quel browser su quel computer e vengono rimosse cancellando i dati dei siti. La guida di ogni app indica che cosa conserva.

## Salvataggio nel cloud

Il salvataggio nel cloud e la sincronizzazione tra computer fanno parte della licenza commerciale. Non sono ancora disponibili. Nel frattempo, conservare i file dove si tengono gli altri file di progetto ed eseguirne il backup nel modo consueto.

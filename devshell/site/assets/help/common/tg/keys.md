## Роҳҳои кӯтоҳ чӣ гуна навишта мешаванд

Роҳнамо ҳар роҳи кӯтоҳро тавре менависад, ки клавиатураи шумо онро нишон медиҳад.

| Навишта | Дар Mac | Дар Windows ва Linux |
|---|---|---|
| {{key:Mod+S}} | Command (⌘) ва S | Ctrl ва S |
| {{key:Ctrl+Shift+F}} | Control (⌃), Shift (⇧) ва F | Ctrl, Shift ва F |
| {{key:Alt+Left}} | Option (⌥) ва ← | Alt ва ← |
| {{key:Backspace}} | тугмаи Delete | Backspace |
| {{key:Delete}} | fn ва Delete (нест кардани пеш) | Delete |
| {{key:Enter}} | Return | Enter |

Нишони «+» маънои онро дорад, ки тугмаҳоро якҷоя нигоҳ доред. «Then» маънои онро дорад, ки яке пас аз дигаре пахш кунед.

Аксари роҳҳои кӯтоҳи барнома дар Mac Command ё Control-ро қабул мекунанд, пас {{key:Mod+Z}} ҳар ду роҳ кор мекунад. Баъзеҳо, масалан экрани пурра ({{key:Ctrl+Shift+F}}), дар ҳар компютер тугмаи Control-ро истифода мебаранд; роҳнамо ҷое, ки ин татбиқ мешавад, мегӯяд.

## Тугмаҳои функсионалӣ дар Mac

Дар аксари клавиатураҳои Mac радифи боло равшанӣ, садо ва васоитро иваз мекунад. Барои фиристодани F1 то F12:

- **fn** (ё тугмаи globe)-ро нигоҳ доред ва ҳамзамон тугмаро пахш кунед, ё
- **Танзимоти системаро** кушоед, пас **Клавиатура**, пас **Роҳҳои кӯтоҳи клавиатура**, пас **Тугмаҳои функсионалӣ**, ва «Тугмаҳои F1, F2 ва ғайраро ҳамчун тугмаҳои функсионалии стандартӣ истифода бурдан»-ро фаъол кунед.

Баъзе тугмаҳои F низ аз ҷониби худи macOS истифода мешаванд (масалан Mission Control). Агар тугма дар барнома коре накунад, онро бо fn санҷед ё тугмаи абзорро истифода баред.

## Роҳҳои кӯтоҳе, ки браузер нигоҳ медорад

Саҳифаи веб баъзе роҳҳои кӯтоҳро аз браузер гирифта наметавонад, ҳар қадар ки кӯшиш кунад. Дар ҳар барнома:

- {{key:Mod+N}}, {{key:Mod+T}} ва {{key:Mod+W}} ҳамеша тиреза ва табҳои браузерро мекушоянд ё мепӯшанд. Барномаҳо барои Нав ва Пӯшидан тугмаҳо истифода мебаранд.
- {{key:Mod+Q}} дар Mac ва {{key:Alt+F4}} дар Windows браузерро мебароянд. Агар корҳои захиранашуда дошта бошед, браузер аввал мепурсад («Тарк кардани сайт?»); бимонед ва пас захира кунед.
- Экрани пурраи худи браузер ({{pick:mac=Control-Command-F, ё тугмаи сабз дар тиреза|windows linux=F11}}) кор мекунад. Барномаҳо инчунин ҳолатҳои экрани худро дар {{key:Ctrl+Shift+F}} доранд, ки онҳо метавонанд лавҳаҳои барномаро низ пинҳон кунанд.

## Тугмаҳои мушук дар тачпад

Барномаҳо тугмаи рост ва тугмаи миёнаро истифода мебаранд. Бе мушуки се тугма:

:::mac
- **Клики рост:** бо ду ангушт клик кунед. Агар клики ду ангушт кор накунад, «Клики дуюмдараҷа»-ро дар **Танзимоти система**, пас **Trackpad**, фаъол кунед. Нигоҳ доштани {{key:Ctrl}} ҳангоми клик менюи браузерро мекушояд, аммо дар нақша баъзе барномаҳо онро ҳамчун клики оддӣ (бо Control нигоҳ дошташуда) мехонанд, пас клики ду ангушт афзалтар аст.
- **Кашидани тугмаи миёна (панорама):** ҳар барнома роҳи дигари панорамакуниро медиҳад, масалан нигоҳ доштани {{key:Space}} ҳангоми кашидан ё кашидан бо тугмаи рост. Саҳифаи клавиатураи барнома мегӯяд, кадомаш.
- **Калонкунӣ бо чарх:** скролли ду ангушт дар тачпад дар аксари барномаҳо калон мекунад. Pinch низ дар ҷое, ки барнома дастгирӣ мекунад, калон мекунад.
:::

:::windows linux
- **Клики рост:** бо ду ангушт клик кунед, ё ба кунҷи поёни рости тачпад клик кунед. Ин ба танзимоти тачпади шумо вобаста аст.
- **Кашидани тугмаи миёна (панорама):** ҳар барнома роҳи дигари панорамакуниро медиҳад, масалан нигоҳ доштани {{key:Space}} ҳангоми кашидан ё кашидан бо тугмаи рост. Саҳифаи клавиатураи барнома мегӯяд, кадомаш.
- **Калонкунӣ бо чарх:** скролли ду ангушт дар тачпад дар аксари барномаҳо калон мекунад.
:::

## Навиштан дар қуттии матн

Ҳангоми навиштан дар қуттӣ (ном, ёддошт, ҷустуҷӯ), роҳҳои кӯтоҳи як ҳарфии барнома хомӯш мешаванд, пас навиштани «L» ҳарфи L менависад. Барои бозгардонидани тугмаҳо ба барнома {{key:Esc}}-ро пахш кунед ё ба нақша клик кунед.

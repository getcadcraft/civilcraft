Барномаҳо дар дохили браузери веб кор мекунанд. Онҳо корро дар компютери худатон иҷро мекунанд: файлҳои шумо дар он ҷо кушода мешаванд ва ҳеҷ гоҳ ба мо фиристода намешаванд (ниг. [Файлҳои шумо куҷо мераванд](common:your-files)).

## Кадом браузер

Версияи навсозишудаи яке аз инҳоро истифода баред:

| Браузер | Муҳаррик | Ёддоштҳо |
|---|---|---|
| Chrome, Edge, Brave, Opera, Vivaldi | Chromium | Пурраттарин: интихоби папка, захира барои истифодаи офлайн, коркарди файлҳо. |
| Firefox | Gecko | Кор мекунад. Кушодани папкаи пурра интихобгари содатареро истифода мебарад. Захираи офлайн дар тирезаҳои хусусӣ шояд кор накунад. |
| Safari | WebKit | Дар Mac ва iPad кор мекунад. Кушодани папкаи пурра интихобгари содатареро истифода мебарад. Safari метавонад нусхаи офлайнеро, ки чанд ҳафта истифода нашудааст, нест кунад. |

Ҳар се муҳаррик барои корҳои ҳаррӯза хубанд. Ҷое, ки барнома дар яке аз онҳо коре фарқ мекунад, роҳнамоаш қадамҳоро барои браузери шумо нишон медиҳад.

## Чӣ фарқ дорад дар браузерҳо

- **Кушодани папка.** Браузерҳои Chromium интихобгари воқеии папканро нишон медиҳанд ва папкаро мустақиман хонда метавонанд. Firefox ва Safari аз шумо мепурсанд, ки папкаро интихоб кунед ва баъд ҳар файли онро мехонанд, ки барои папкаҳои бузурги лоиҳа дер мекашад; кашидани папка ба барнома дар ҳар се кор мекунад.
- **Захира кардан.** Барномаҳо бо зеркашии файл захира мекунанд. Браузери шумо муайян мекунад, ки зеркашиҳо ба куҷо мераванд ва оё аввал мепурсад.

:::chromium
Дар Chrome ё Edge, «Пеш аз зеркашӣ пурсидан, ҳар файлро дар куҷо захира кунам» -ро фаъол кунед (дар Танзимот, зери Зеркашиҳо), то ки ҳар бор папка интихоб кунед.
:::

:::firefox
Дар Firefox, Танзимотро кушоед, пас Умумӣ, пас Зеркашиҳо ва «Ҳамеша аз ман пурсидан, ки файлҳоро дар куҷо захира кунам»-ро интихоб кунед, то ки ҳар бор папка интихоб кунед.
:::

:::safari
Дар Safari, Танзимотро кушоед, пас Умумӣ, ва «Ҷои зеркашии файл»-ро ба «Барои ҳар зеркашӣ пурсидан» танзим кунед, то ки ҳар бор папка интихоб кунед.
:::

## Mac, Windows ва Linux

Барномаҳо дар ҳар компютер якхелаанд. Чизе, ки фарқ мекунад, клавиатура аст: роҳҳои кӯтоҳ барои компютери шумо худкор навишта мешаванд. Ниг. [Тугмаҳо, мушукҳо ва тачпадҳо](common:keys).

## Планшетҳо ва экранҳои тамосӣ

Баъзе барномаҳо тамосро қабул мекунанд (як ангушт мекашад ё интихоб мекунад, ду ангушт барои калонкунӣ ва ҷойивазкунӣ). Роҳнамои ҳар барнома мегӯяд, ки он мекунад ё не. Дар iPad, Safari ё Chrome-ро истифода баред. Клавиатура барои барномаҳое, ки фармонҳои навиштанӣ истифода мебаранд, кӯмак мекунад.

## Кӯҳнатарин браузер ва система

Мо инҳоро аз рамзи барномаҳои 0.7 хондем, на аз тахмин: ҳар файл таҳлил шуд ва ҳар хусусияти забон, ки истифода мешавад, дар маълумоти мувофиқати нашршудаи браузерҳо ҷустуҷӯ шуд. Аз пасти ин версияҳо барномаҳо ҳатто оғоз шуда наметавонанд, зеро браузер рамзро намефаҳмад.

| | Кӯҳнатарин версия, ки барномаҳоро оғоз карда метавонад |
|---|---|
| Chrome, Edge, Brave, Opera, Vivaldi | Chromium 94 |
| Firefox | 93 |
| Safari (Mac, iPad, iPhone) | 16.4 (macOS 13.3, iPadOS ва iOS 16.4) |

CadCraft Studio муҳаррики веби худро дар Windows дорад, пас ба Windows 10 ё 11 ниёз дорад; дар Mac он муҳаррики системаро истифода мебарад, пас ба macOS 13.3 ё навтар ниёз дорад. Танзимот › Навсозӣ дар Studio нишон медиҳад, ки нусхаи шумо дар чӣ кор мекунад.

Ин кӯҳнатарин версияе аст, ки *оғоз* мешавад, аз рамз хонда шудааст. Ин рӯйхати браузерҳои кӯҳна нест, ки мо барномаҳоро дар онҳо иҷро кардаем, пас браузери кӯҳнае, ки оғоз мешавад, ҳанӯз шояд хусусиятеро надошта бошад.

## Чӣ лозим аст компютери шумо

Инҳо минимумҳои ба нақша гирифташудаи барномаҳо мебошанд, на талаботи ченшуда:

- 8 GB хотира (16 GB барои моделҳои федеративии калон тавсия мешавад).
- Чипи график бо WebGL 2 барои барномаҳои 3D. Агар намуди 3D холӣ монад, санҷед, ки тезонии сахтафзорӣ дар танзимоти браузери шумо фаъол аст.
- Экрани на камтар аз 1280 pixels паҳн барои абзорҳои пурра; экранҳои хурдтар онҳоро печонда ба якчанд сатр мегузоранд.

Файлҳои хеле калон (маҷмӯаҳои калони нақша, моделҳои калон) дар табби браузер хотираи зиёд истифода мебаранд. Агар барнома суст шавад, табҳои дигари вазнинро бипӯшед.

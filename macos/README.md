# CivilCraft for macOS

CivilCraft comes inside [CadCraft Studio](https://github.com/getcadcraft/studio). Studio 0.6 for macOS follows; Studio 0.5 for macOS (universal, not code-signed) is on the [download page](https://getcadcraft.com/download#studio) until then. Every app also runs in the browser: https://getcadcraft.com/use/civilcraft.

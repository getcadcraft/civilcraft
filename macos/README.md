# CivilCraft for macOS

**Coming in 0.5.** Until then, use the [browser edition](../web/) or https://getcadcraft.com/try/civilcraft.

The Mac app will be the same browser edition in a WKWebView window, built by [getcadcraft/desktop-shell](https://github.com/getcadcraft/desktop-shell), as a direct download and in the Mac App Store. Apple builds go live once Apple approves them, usually after the other platforms.

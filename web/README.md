# CivilCraft: browser edition

CivilCraft as plain files: put the folder on any web server and open it in your browser. No account, no install, nothing to build. Your files stay on your computer.

- **Get it:** `civilcraft-browser-edition-v0.6.0.zip` from [Releases](https://github.com/getcadcraft/civilcraft/releases) (checksum beside it). It unzips to a folder with an INSTALL.md that covers servers and updating.
- **Older edition:** the [`v0.4/`](v0.4/) folder from a clone ([v0.4/INSTALL.md](v0.4/INSTALL.md)).
- **Use it now:** https://getcadcraft.com/use/civilcraft

On the desktop, CivilCraft runs inside [CadCraft Studio](https://github.com/getcadcraft/studio).

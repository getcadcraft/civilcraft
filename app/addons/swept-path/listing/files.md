Reads the alignments, lines and parcels already in the project. Reads a vehicle description from a text box (a small JSON file in metres and degrees). Writes plain lines into the project (the envelope, the wheel, wing tip or bogie tracks, the start and end bodies, a roundabout, parking bays), which export to DXF and DWG like any other line, and a CSV report. Everything it draws is one step that Undo takes back.

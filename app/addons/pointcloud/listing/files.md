Reads LAS 1.0 to 1.4 and LAZ. Writes a cleaned, classified LAS 1.4 (point format 6, or 7 with colour; the coordinate system is written in the file) or LAZ (point format 0, or 2 with colour, in a LAS 1.4 file, compressed without loss by CadCraft's own compressor) and CSV tables for volumes. The ground goes into the project as survey points, and from there out through CivilCraft's own exports (LandXML, DXF, IFC, GeoTIFF). The project does not yet remember which cloud it used.

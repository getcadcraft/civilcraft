Open a LAS or LAZ file from a drone survey or a scanner, look at all of it, clean it, sort it into ground, vegetation and buildings, and build the ground and the contours from the points that really are ground. The file is never changed, and nothing leaves your computer: the cloud is cut into tiles that are kept in this browser's own storage, or in a folder you choose.

The cloud is shown from the coarse tiles first and refines as you move closer, within a point budget you set, so a very large file can be inspected without loading it all. Cleaning is an edit log on top of the file (crop, delete, change class, find noise), so every step undoes. The ground you build goes into the CivilCraft project as Existing ground, the same way a LAS import does, so contours, sections, grading and volumes work on it at once. The numbers it reports (how far the points sit from the ground, how much a pile holds) are numbers from your data, not a certificate.

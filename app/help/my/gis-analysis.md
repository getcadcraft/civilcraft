ပရောဂျက်တွင် GIS အလွှာများ ရှိပြီးသည်နှင့် (see [GIS ဒေတာ သွင်းခြင်း](topic:gis-import)), GIS အုပ်စုရှိ **Analyze** ခလုတ် (`GISANALYSIS`, `ANALYZE` သို့မဟုတ် `BUFFER` ဟု ရိုက်ပါ) က တဘ ငါးခုပါသော panel ကို ဖွင့်ပေးသည်။ ၎င်းသည် plan ဘေးတွင် ဖွင့်ထားနိုင်ပြီး သင်ရွေးသည်များကို လုပ်ဆောင်နေစဉ် plan ပေါ်တွင် ဆွဲပြသည်။

ဘာအရာတစ်ခုကို ထုတ်သော tool တိုင်းသည် **အလွှာအသစ်တစ်ခု ထည့်ပြီး** ဖတ်ခဲ့သော အလွှာများကို မူလအတိုင်း ထားရှိသည်။ တစ်ခုစီသည် undo အဆင့်တစ်ခု ဖြစ်သည်: panel ရှိ {{ui:Undo}} (သို့မဟုတ် Ctrl+Z) က အလွှာအသစ်ကို ဖယ်ရှားသည်။ ရလဒ်ကို အခြားအလွှာကဲ့သို့ [GIS အတွက် as-built ဒေတာ ထုတ်ခြင်း](topic:gis-export) ဖြင့် shapefile၊ GeoJSON သို့မဟုတ် GeoPackage အဖြစ် ထုတ်နိုင်သည်။

အလွှာတစ်ခု၏ အပြည့်အစုံ table (စီခြင်း၊ တည်းဖြတ်ခြင်းနှင့် field calculator ပါဝင်သည်) ကို [အလွှာတစ်ခု၏ attribute table နှင့် အလုပ်လုပ်ခြင်း](topic:gis-table) တွင် ရှိသည်။ field တစ်ခုဖြင့် အရောင်ခွဲခြင်းကို [အလွှာကို attribute ဖြင့် ပုံစံချခြင်း](topic:gis-symbology) တွင် ရှိသည်။

အားလုံးကို plan ပေါ်တွင် ပရောဂျက်၏ ယူနစ် (feet သို့မဟုတ် meter) ဖြင့် လုပ်ဆောင်သည်။ ပရောဂျက်သည် အမြဲ projected သို့မဟုတ် local စနစ်တွင် ရှိသောကြောင့် 50 ဟူသော အကွာအဝေးသည် 50 feet သို့မဟုတ် 50 meter ကို ဆိုလိုပြီး ဒီဂရီ ဟု ဘယ်တော့မှ မဆိုလိုပါ။ အဖြေများတွင် အမြင့် (z) ကို မသိမ်းဆည်းပါ။

## Buffer

အင်္ဂါရပ်တိုင်း၏ ပတ်လည်တွင် သတ်မှတ်ထားသော အကွာအဝေးဖြင့် ဇုန်တစ်ခုကို polygon အလွှာအသစ်အဖြစ် ဆွဲသည်။ အမှတ်များသည် စက်ဝိုင်းများ ဖြစ်လာပြီး မျဉ်းများသည် အဆုံးများ ဝိုင်းနေသော လမ်းကြောင်းများ ဖြစ်လာသည်၊ polygon များသည် ကြီးလာသည်။ **အနုတ်** အကွာအဝေးက polygon များကို ကျုံ့စေသည် (100 by 100 စတုရန်းကို 5 ဖြင့် ကျုံ့လျှင် 90 by 90 ဖြစ်သည်; 60 ဖြင့် ကျုံ့လျှင် ဘာမျှ မကျန်တော့ပါ၊ panel က ထိုသို့ ပြောသည်)။ အင်္ဂါရပ်တစ်ခုစီအတွက် ကိုယ်ပိုင်အကွာအဝေးရရန် number field မှ အကွာအဝေးကို ယူပါ၊ သို့မဟုတ် **buffer အားလုံးကို ပုံသဏ္ဍာန်တစ်ခုတည်းသို့ ပေါင်းပါ** ကို အမှန်ခြစ်ပြီး ၎င်းတို့ကို ပေါင်းပါ။

စက်ဝိုင်းကွေးသော အပိုင်းများကို အမှန်ကွေးမျဉ်း၏ အတွင်းဘက်တွင် ဖြောင့်အပိုင်းများဖြင့် ဆွဲသဖြင့် buffer သည် တိကျသော စက်ဝိုင်းထက် အနည်းငယ် ငယ်သည်: ပုံမှန်ဆက်တင်တွင် ဧရိယာ 0.6 % ခန့်၊ Fine တွင် 0.16 % ခန့်။ တိုင်းတာမည့် မည်သည့်အရာအတွက်မဆို Fine ကို သုံးပါ။

## Overlay

| ကိရိယာ | ရရှိမည့်အရာ |
|---|---|
| Intersect | ထည့်သွင်းအလွှာ၏ အလုပ်ပေါ်သော polygon များနှင့် တွေ့ဆုံသည့် အပိုင်းများ၊ နှစ်ဖက်စလုံး၏ field များပါသည်။ မျဉ်းများနှင့် အမှတ်များကို polygon များအတွင်းသို့ ဖြတ်သည်။ |
| Union | polygon အလွှာနှစ်ခုလုံးကို တစ်ခု၏ အနားစွန်းအတိုင်း အခြားတစ်ခုကို ဖြတ်သည်: ဝေမျှသော အပိုင်းများတွင် နှစ်ဖက်စလုံး၏ field များ ပါ၍ ကျန်သည်များတွင် အလွှာတစ်ခု၏ field တစ်ခုသာ ပါသည် (အခြားအလွှာ၏ field များသည် ဗလာ)။ |
| Erase | polygon ထည့်သွင်းအလွှာမှ overlay polygon များကို ဖယ်ထုတ်သည်။ Field များသည် ထည့်သွင်းအလွှာတွင် ကျန်ရှိသည်။ လုံးဝ ဖယ်ထုတ်ခံရသော အင်္ဂါရပ်ကို ထုတ်ပစ်သည် (panel က အရေအတွက် ရေတွက်ပြသည်)။ |
| Dissolve | ထိသော သို့မဟုတ် ထပ်နေသော polygon များကို အားလုံး သို့မဟုတ် field တန်ဖိုးတစ်ခုစီအတွက် ပုံသဏ္ဍာန်တစ်ခုစီ ပေါင်းသည်။ `COUNT` နှင့် `AREA` ကို ထည့်သည်။ |

နှစ်ခုစလုံးတွင် ရှိသော field အမည်ကို ပထမအလွှာအတွက် ထားပြီး ဒုတိယအလွှာ၏ အမည်ကို `_2` ဖြင့် ရေးသည်။ အလွှာတစ်ခုတည်းအတွင်းရှိ အင်္ဂါရပ်များသည် အချင်းချင်း မထပ်သင့်ပါ: ထပ်နေလျှင် Union က ထပ်နေမှုကို နှစ်ဖက်စလုံးတွင် ရေတွက်သည်။

## Join

spatial join သည် **source** အလွှာမှ attribute များကို ထိတွေ့သော **target** အင်္ဂါရပ်တစ်ခုစီသို့ ကူးယူပြီး target ၏ ပုံသဏ္ဍာန်များဖြင့် အလွှာအသစ် ပေးသည်။ ဘယ်အချိန် တွေ့ဆုံသည်ကို ရွေးပါ: ထိခြင်း သို့မဟုတ် ထပ်ခြင်း၊ target သည် source polygon အတွင်း ရှိခြင်း၊ target က source အင်္ဂါရပ်ကို ပိုင်ဆိုင်ခြင်း၊ အနီးဆုံး source အင်္ဂါရပ် (ကန့်သတ်ချက် ရွေးနိုင်သည်)၊ သို့မဟုတ် အကွာအဝေးအတွင်း source အင်္ဂါရပ် မည်သည့်တစ်ခုမဆို။

source အင်္ဂါရပ်များ အများအပြား တိုက်ဆိုင်ပါက ပထမအင်္ဂါရပ်၏ attribute ကို ယူသည် (အနီးဆုံး နှင့် အကွာအဝေး join များအတွက် အနီးဆုံး; `DISTANCE` ကို ထည့်သည်)၊ သို့မဟုတ် **ရေတွက်ပြီး ၎င်းတို့၏ number field များကို ပေါင်းသည်**: `COUNT` နှင့် number field တစ်ခုစီအတွက် `SUM_`၊ `MEAN_`၊ `MIN_`၊ `MAX_`။ **Keep target features that found no match** ကို ဖြုတ်ပါက ထိုအင်္ဂါရပ်များကို ထုတ်ပစ်သည်။ ပေါင်းထားသော field များသည် တိုက်ဆိုင်မှု မရှိသည့်နေရာတွင် ဗလာဖြစ်ပြီး panel က မတိုက်ဆိုင်သည့် အရေအတွက်ကို ရေတွက်ပြသည်။

## Select

attribute သို့မဟုတ် ပုံသဏ္ဍာန်အကြောင်း မေးခွန်းတစ်ခု ရိုက်ပြီး **Select** ကို နှိပ်ပါ၊ အင်္ဂါရပ်များကို plan ပေါ်တွင် ၎င်းတို့၏ အရေအတွက်၊ table နှင့် စုစုပေါင်း ဧရိယာ၊ အလျား သို့မဟုတ် အရေအတွက်ဖြင့် ဆွဲပြသည်။ ထို့နောက် ၎င်းတို့ကို ကိုယ်ပိုင်အလွှာအဖြစ် ပြုလုပ်နိုင်၊ ၎င်းတို့ဆီ zoom လုပ်နိုင်၊ သို့မဟုတ် ရွေးချယ်မှုကို ရှင်းနိုင်သည်။

| သင်ရေးနိုင်သည် | ဥပမာ |
|---|---|
| အမည်ဖြင့် field; အမည်တွင် space ပါလျှင် "quotes" သို့မဟုတ် [brackets] ကို သုံးပါ | `VALUE`, `"Lot Number"` |
| ဂဏန်းများ၊ 'စာသား'၊ true၊ false၊ null | `Use_ = 'Res'` |
| `=` `!=` `<>` `<` `<=` `>` `>=` | `VALUE >= 250` |
| `contains` `startswith` `endswith` `like` `ilike` (စာသားသည် အကြီးအသေး ခွဲမခြားပါ; `like` တွင် `%` သည် စာလုံးအစုံ ဖြစ်ပြီး `_` သည် စာလုံးတစ်လုံး ဖြစ်သည်) | `Notes contains 'corner'` |
| `is null`, `is not null` (ဗလာတန်ဖိုးကို null ဟု ရေတွက်သည်) | `Notes is null` |
| `in (…)`, `not in (…)`, `between … and …` | `Use_ in ('Com', 'Ind')` |
| `+ - * /` နှင့် ကွင်းများ | `VALUE / 2 > 100` |
| `and`, `or`, `not` | `Use_ = 'Res' and VALUE > 200` |
| ပုံသဏ္ဍာန်တန်ဖိုးများ `$area` `$perimeter` `$length` `$x` `$y` `$vertices` | `$area > 5000` |

မပြည့်စုံသော မေးခွန်း သို့မဟုတ် အလွှာတွင် မရှိသော field ကို အမည်ပေးသော မေးခွန်းကို နေရာကို ပြသော စာကြောင်းဖြင့် ငြင်းပယ်သည်။

## Measure

အလွှာ၏ စုစုပေါင်း ဧရိယာနှင့် perimeter၊ အလျား သို့မဟုတ် အရေအတွက်ကို ပြသပြီး **field များ ထည့်သည်**: polygon အတွက် `AREA` နှင့် `PERIMETER`၊ မျဉ်းအတွက် `LENGTH` (plan အလျား)၊ အမှတ်အတွက် `X` နှင့် `Y`။ ရှိပြီးသား field ကို ဘယ်တော့မှ မရေးထားပါ: အသစ်ကို `AREA_2` ဟု ခေါ်သည်။ ဤသည်မှာ undo အဆင့်တစ်ခု ဖြစ်သည်။ **Statistics** က number field တစ်ခု၏ အရေအတွက်၊ ပေါင်းလဒ်၊ ပျမ်းမျှ၊ အနိမ့်ဆုံးနှင့် အမြင့်ဆုံးကို ပေးပြီး၊ လိုအပ်လျှင် အခြား field တစ်ခု၏ တန်ဖိုးတစ်ခုစီအလိုက် ပေးသည်။

:::note
ဤကိရိယာများနောက်ကွယ်ရှိ စစ်ဆေးချက်များကို test (`node bin/test-civilcraft-gisanalysis.mjs`) တွင် လက်ဖြင့် လုပ်ဆောင်သည်: ဥပမာ 100 by 100 မြေကွက်များကို 100 by 80 ဇုန်အောက်တွင် intersect လုပ်လျှင် 3,000 နှင့် 3,000 ပေါင်းပြီး၊ 10 ဖြင့် buffer လုပ်သော 100 အလျား မျဉ်းသည် 2,000 နှင့် စက်ဝိုင်းတစ်ခု ဖြစ်သည်။
:::

စစ်တမ်းပုံဆွဲ (topographic) သည် မကြာခဏ ပုံဆွဲအဖြစ် ရောက်လာသည်: contour များသည် ၎င်းတို့၏ elevation ဖြင့် polyline များ၊ breakline များသည် 3D polyline များ၊ ဆိုက်နယ်နမိတ်သည် ပိတ်ထားသော polyline ဖြစ်သည်။ CivilCraft က ပုံဆွဲ၏ **model space** ကို ပလန်ပေါ် layer များအဖြစ် ဖွင့်ပြီး ထိုမျဉ်းများကို မျက်နှာပြင်အဖြစ် တိုက်ရိုက် ပြောင်းနိုင်သည်။

## ပုံဆွဲကို ဖွင့်ခြင်း

1. **Surface** အုပ်စု၏ {{ui:Linework}} ကို နှိပ်ပါ (သို့မဟုတ် {{ui:Open}}၊ သို့မဟုတ် ဖိုင်ကို ပလန်ပေါ် ချပါ) ပြီး `.dwg` သို့မဟုတ် `.dxf` ဖိုင်ကို ရွေးပါ။ ပုံဆွဲကို ဤကွန်ပျူတာပေါ်တွင် ဖတ်သည်; ဘာမျှ upload မလုပ်ပါ။ 2000 မှ 2018 DWG နှင့် ASCII DXF ကို ဖတ်သည်။
2. **Linework** dialog က မျဉ်း၊ ပိတ်ထားသော ပုံသဏ္ဍာန် သို့မဟုတ် အမှတ်များပါသော ပုံဆွဲ layer များကို စာရင်းပြပြီး ၎င်းတို့တွင် **elevation** ရှိမရှိ ပြသည်။ ပုံဆွဲတွင် ပိတ်ထားသော layer များသည် အမှန်ခြစ်မပါဘဲ စတင်သည်။ စာသား၊ hatch၊ dimension နှင့် linework မဟုတ်သော အခြားအရာများကို ရေတွက်ပြီး ဖယ်ထားသည် (dialog က ဘာတွေဖြစ်သည်ကို ပြောသည်)။
3. **Drawing units** ကို စစ်ပါ။ ပုံဆွဲက ယူနစ်ကို ပြောသောအခါ CivilCraft က စီမံကိန်း၏ ယူနစ်သို့ ပြောင်းသည် (millimeter မှ meter၊ meter မှ feet၊ inch မှ feet)။ feet ဖြင့် ပုံဆွဲကို US survey feet အဖြစ် အတိုင်းအတာမပြောင်းဘဲ ဖတ်သည်: ၎င်းတို့သည် မီလီယံတစ်ခုတွင် အပိုင်း ၂ ခြား ကွာသည်၊ state plane coordinate ကို ထိုအတိုင်း scale လုပ်လျှင် feet အနည်းငယ် ရွေ့သွားမည်။ ပုံဆွဲက ယူနစ် မပြောသောအခါ ၎င်း၏ ဂဏန်းများကို စီမံကိန်း၏ ယူနစ်ဖြင့် ဖတ်သည်; မှားနေလျှင် စာရင်းထဲမှ မှန်ကန်သော ယူနစ်ကို ရွေးပါ။
4. **Use for the surface** တွင် layer တစ်ခုစီက မျက်နှာပြင်အတွက် ဘာပေးမည်ကို ရွေးပါ (သို့မဟုတ် **Only show it** ကို ထားပါ)။ contour နာမည်ရှိ layer များ (TOPO၊ CONT၊ CNTR) ဖြစ်ပြီး elevation ရှိလျှင် breakline အဖြစ် စတင်သည်။
5. {{ui:Add}} ကို နှိပ်ပါ။ layer များသည် **GIS layers** အောက်တွင် ဘယ်ဘက် panel တွင် ပေါ်လာသည်; အသုံးပြုမှုတိုင်းကို မျက်နှာပြင်ထဲ ထည့်သည်။ အပိုင်းတစ်ခုစီသည် သီးခြား အဆင့်ဖြစ်သည်: {{key:Mod+Z}} က တစ်ခုချင်းစီ ပြန်ယူသည်။

## Layer တစ်ခုက ဘာပေးနိုင်သလဲ

| Layer တွင်ပါသည် | မျက်နှာပြင်အတွက် သုံးပုံ |
|---|---|
| Contour (elevation ရှိ polyline) | မျဉ်းတို့၏ ကိုယ်ပိုင် elevation သို့မဟုတ် ELEV field တွင် breakline များ |
| 3D polyline | ၎င်းတို့၏ ကိုယ်ပိုင် elevation တွင် breakline များ |
| ပိတ်ထားသော outline | မျက်နှာပြင်နယ်နမိတ် (အကြီးဆုံးပိတ်ပုံ သို့မဟုတ် သင်ရွေးထားသည့်တစ်ခု) |
| Elevation ရှိ အမှတ်များ | စစ်တမ်းအမှတ်များ၊ layer အမည်ဖြင့် ဖော်ပြသည် |
| Elevation 0 ရှိ မျဉ်းများ (ပလန်မျဉ်း) | ဘာမျှမပေး: ပလန်ပေါ် base ပုံဆွဲအဖြစ် ကျန်နေသည် |

CivilCraft ရေးထားသော ပုံဆွဲတွင် feature line များကို arc များ မှတ်ထားသော 3D polyline များအဖြစ် ထားသည်။ ထိုအခါ dialog တွင် **Feature lines** ပေါ်လာသည်: arc များနှင့် အသုံးပြုမှုများပါသော feature line အဖြစ် ပြန်ယူလိုလျှင် အမှန်ခြစ်ထားပါ (undo အဆင့်တစ်ခု)၊ သို့မဟုတ် အခြား layer များကဲ့သို့ linework အဖြစ် ဖတ်လိုလျှင် ဖယ်ထားပါ။

နောက်ပိုင်း ပလန်တွင်သာ ပြထားသော layer တစ်ခုအတွက် **GIS layers** အောက်ရှိ layer ၏ menu မှ {{ui:Use for the surface}} ကို သုံးပြီး အတူတူ လုပ်နိုင်သည်။

## Block များမှ စစ်တမ်းအမှတ်များ

စစ်တမ်းပုံဆွဲများသည် အမှတ်များကို block အဖြစ် မကြာခဏ ထားသည်: တိုင်းတာချက်တိုင်းတွင် သင်္ကေတငယ်တစ်ခု၊ အမှတ်နံပါတ်၊ ဖော်ပြချက်နှင့် elevation အတွက် attribute များပါသည်။ ပုံဆွဲတွင် block reference ရှိသောအခါ dialog တွင် **Survey points from blocks** အပိုင်း ရှိသည်:

1. ယူမည့် block များကို အမှန်ခြစ်ပါ (ဇယားက reference တစ်ခုစီ အရေအတွက်၊ အဘယ် layer များတွင်နှင့် အဘယ် attribute များ ရှိသည်ကို ပြသည်)၊ သို့မဟုတ် အတွင်းရှိ block reference အားလုံးကို ယူရန် layer များကို အမှန်ခြစ်ပါ။
2. အမှတ်တစ်ခုစီ၏ **နံပါတ်**၊ **ဖော်ပြချက်** နှင့် **elevation** ကို ဘယ်ကယူမည် ရွေးပါ: attribute၊ block သို့မဟုတ် layer အမည်၊ နောက်ဆုံးပိုင်းခြားမဲ့ နံပါတ်များ၊ သို့မဟုတ် insertion point ၏ Z။ CivilCraft က attribute ဖြစ်နိုင်ချေများ (PT၊ DESC၊ ELEV နှင့် ဆင်တူသည်များ) ကို အရင်ရွေးသည်၊ block များသည် သုည၌သာ ရှိလျှင် elevation ကို attribute မှ ယူသည်။
3. အမှတ်များသာ လိုလျှင် linework layer များကို ဖယ်ပြီး {{ui:Add}} ကို နှိပ်ပါ။

reference တစ်ခုစီသည် ၎င်း၏ insertion point တွင် စစ်တမ်းအမှတ်တစ်ခု ဖြစ်လာသည်။ model space တွင် ချထားသော reference များသာ ရေတွက်သည်; အခြား block အတွင်း ထားသော block များ မပါ။ စီမံကိန်းတွင် ရှိပြီးသား နံပါတ်များ သို့မဟုတ် ပုံဆွဲတွင် နှစ်ကြိမ်သုံးထားသော နံပါတ်များသည် အမြင့်ဆုံးနောက်တွင် နံပါတ်အသစ် ရကြသည်; နံပါတ်မဟုတ်သော elevation attribute ရှိသော အမှတ်သည် elevation မရှိဘဲ ကျန်သည်; အခြေအနေလိုင်းက နှစ်ခုလုံးကို ရေတွက်ပြသည်။ ပုံဆွဲကို ဘယ်တော့မှ မပြောင်းလဲပါ၊ အမှတ်တစ်ခုစီသည် ၎င်း၏ block ကို မှတ်ထားသည်: Properties တွင် **From block** ကို block၊ layer နှင့် handle ဖြင့် ပြသည်။ အမှတ်များ ထည့်ခြင်းသည် အဆင့်တစ်ခုဖြစ်ပြီး {{key:Mod+Z}} က အားလုံးကို ဖယ်ထုတ်သည်။

## စာသားဖြင့် ရေးထားသော အဆင့်များနှင့် စစ်ဆေးခြင်း

စာသားအဖြစ် ရေးထားသော spot level များ (သို့မဟုတ် စစ်တမ်းအမှတ် block မဟုတ်သော block attribute ထဲရှိ) သည် linework မဟုတ်ပါ။ **Survey levels and check** အပိုင်းက ၎င်းတို့ကို စစ်တမ်းအမှတ်များအဖြစ် ယူနိုင်ပြီး ပုံဆွဲ၏ မှားနိုင်သည်များကို ဖော်ပြသည်: ယူနစ်၊ coordinate system၊ သုည မှ အကွာအဝေး၊ ပြားနေသော contour၊ ထူးခြားသော elevation၊ နှစ်ကြိမ်ထားသော အမှတ်များ။ [Check a survey drawing on import](topic:survey-check) ကို ကြည့်ပါ။

## ပုံဆွဲကို ဖတ်ပုံ

- Arc၊ circle၊ ellipse၊ bulge ပါသော polyline အပိုင်းများနှင့် spline များကို တိုတိုတည့်တည့် အပိုင်းများ (အများဆုံး 5° တိုင်း) အဖြစ် ပြောင်းသည်။
- Block reference များကို ချထားသည့်နေရာတွင် ဆွဲသည်၊ အတွင်းရှိ block များလည်း ပါသည်; layer 0 ပေါ်ရှိ block အရာများက reference ၏ layer ကို ယူသည်။
- အခြား ပြားပြင် (မတူညီသော extrusion ဦးတည်ချက်) တွင် ဆွဲထားသော အရာများကို world coordinate များဖြင့် ချထားသည်။
- အရာတစ်ခုစီသည် field သုံးခု ရသည်: LAYER၊ TYPE (အရာ အမျိုးအစား) နှင့် ELEV (အမှတ်အားလုံး တူညီသော elevation ရှိလျှင် ၎င်း)။
- Coordinate များကို ရှိသည့်အတိုင်း ယူသည်: ပုံဆွဲသည် စီမံကိန်းနှင့် coordinate တူရမည် (ဥပမာ state plane zone တူရမည်)။ Linked drawing (xref) များကို မဖွင့်ပါ: သီးခြား ဖွင့်ပါ။

:::tip
Contour ပုံဆွဲက တောင်ထိပ်များနှင့် အပြိုင်းများတွင် spot elevation အနည်းငယ်ဖြင့် အကောင်းဆုံး မျက်နှာပြင် ပေးသည်၊ contour တစ်ခုတည်းကဆိုလျှင် ပြားသော တြိဂံများ ကျန်နိုင်သည်။ ၎င်းတို့ကို စစ်တမ်းအမှတ်အဖြစ် ထည့်ပါ၊ သို့မဟုတ် ပုံဆွဲရှိ အမှတ် layer မှ ထည့်ပါ။
:::

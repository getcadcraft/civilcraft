3D view သည် ၎င်းပြသသည်ကို အခြား program တစ်ခုက ဖွင့်နိုင်သော 3D မော်ဒယ်အဖြစ် ထုတ်သည်: 3D viewer, modeler, game engine သို့မဟုတ် ကြည့်ရှုပုံဖော်ရေး tool။

## ထုတ်ရန်

1. 3D view ({{key:D}}) ကို ဖွင့်ပြီး {{ui:Show}} ဖြင့် ပြမည့်အရာကို ရွေးပါ။ ဖျောက်ထားသည်များကို မထုတ်ပါ။
2. Bar ပေါ်ရှိ {{ui:GLB}} သို့မဟုတ် {{ui:OBJ}} ကို နှိပ်ပါ။
   ဖိုင်က "*ပရောဂျက်အမည်*-3d.glb" သို့မဟုတ် "-3d.obj" အဖြစ် ဒေါင်းလုဒ်ဆွဲသည်၊ နှင့် status bar က origin ကို ပြောသည်။

## ဖိုင်များတွင် ပါဝင်သည်များ

| | GLB | OBJ |
|---|---|---|
| မျက်နှာပြင်များ | Normal နှင့်အတူ mesh များ၊ အပြင်/မျက်နှာပြင် အရောင်များ | Normal နှင့်အတူ mesh များ (အရောင် မပါ) |
| ပိုက်များနှင့် structure များ | အဝိုင်း mesh များ၊ ပြဿနာရှိသည်များ အနီရောင် | အဝိုင်း mesh များ |
| ကွန်တူများ၊ breakline များ၊ alignment များ၊ tick များ၊ corridor နှင့် pad မျဉ်းများ | မျဉ်းများ၊ အစုတစ်ခုစီ၏ အရောင်ဖြင့် | Line record များ (`l`) |
| Survey point များ | Points | Point record များ (`p`) |

အစုတစ်ခုစီသည် ၎င်း၏ အမည် ("Existing ground", "Pipes", "Major contours" စသည်) ကို ထိန်းသိမ်းသဖြင့် အခြား program တွင် ဖျောက်ခြင်း သို့မဟုတ် ပုံစံချခြင်း လုပ်နိုင်သည်။

## ယူနစ်၊ ဝင်ရိုးများနှင့် origin

- **မီတာ**။ Feet ပရောဂျက်ကို US survey feet (1 ft = 1200/3937 m) မှ ပြောင်းသည်။
- **Y up**၊ ဤဖော်မတ်များအတွက် ပုံမှန် ညီလာခံ: easting သည် +X၊ elevation သည် +Y၊ နှင့် northing သည် −Z ဖြစ်သည်။
- **မှန်ကန်သော စကေး**။ View ၏ ဒေါင်လိုက် ကြီးမြှင့်မှုကို မသုံးပါ။
- **Local origin**။ State plane coordinates များသည် သန်းပေါင်းများစွာ feet ဖြစ်ပြီး ဤဖော်မတ်များ သိမ်းသည့် single-precision နံပါတ်များအတွက် ကြီးလွန်းသဖြင့် ဖိုင်ကို အနီးရှိ origin နှင့် နှိုင်းယှဉ်၍ ရေးသည်: easting နှင့် northing အတွက် ရှိပြီးသား မြေပြင်၏ ကိုယ်ပိုင် origin၊ နှင့် ၎င်း၏ အနိမ့်ဆုံး အမြင့်ကို အောက်သို့ ဝန်းကျင်ပြောင်းထားသည်။ Origin ကို ပရောဂျက် ယူနစ်ဖြင့် ဖိုင်တွင် မှတ်ထားသည်: GLB တွင် scene နှင့် ၎င်း၏ top node ပေါ်ရှိ `extras` အဖြစ်၊ OBJ တွင် အပေါ်အနားရှိ comment line အဖြစ် (`# origin easting … northing … elevation …`)။ မော်ဒယ်ကို ပရောဂျက် coordinates သို့ ပြန်ထားရန် origin ကို ပေါင်းပါ (feet ပရောဂျက်တွင် မီတာမှ feet သို့ ပြန်ပြောင်းပြီးနောက်)။

## မတည်ဆောက်ရသေးသော အရာများ

- ကြီးမြှင့်ထားသော view ကို ထုတ်ခြင်း၊ သို့မဟုတ် ပရောဂျက် ယူနစ်ဖြင့် မီတာအစား ထုတ်ခြင်း။
- Texture များ၊ OBJ အတွက် material ဖိုင် (.mtl) နှင့် object တစ်ခုချင်းစီ၏ property များ (ပိုက်နှင့် structure များ၏ အမည်များသည် CivilCraft တွင်သာ ရှိသည်)။
- Corridor ကို သီးခြား solid များအဖြစ် ထုတ်ခြင်း၊ သို့မဟုတ် profile view ကို 3D ဖြင့် ထုတ်ခြင်း။

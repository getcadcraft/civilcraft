အလွှာ၏ table ကို GIS layers စာရင်းရှိ **အစက်သုံးခု** မီနူးမှ ({{ui:Attribute table…}}), Surface › More › {{ui:Attribute table}} မှ, သို့မဟုတ် `ATTRIBUTES`, `ATTTABLE` သို့မဟုတ် `TABLE` ဟု ရိုက်ခြင်းဖြင့် ဖွင့်သည်။ table သည် plan ဘေးတွင် ဖွင့်ပြီး သင်အလုပ်လုပ်နေစဉ် ဖွင့်ထားနိုင်သည်။ မြင်ရသော အတန်းများကိုသာ ဆွဲသဖြင့် အင်္ဂါရပ်ထောင်ပေါင်းများစွာ ရှိသော အလွှာတစ်ခုကိုလည်း မြန်မြန် ဖွင့်ပြီး ရွှေ့နိုင်သည်။

## စီခြင်း၊ စစ်ထုတ်ခြင်းနှင့် ရွေးခြင်း

- **Sort:** column ခေါင်းစဉ်ကို နှိပ်ပါ။ ဒုတိယအကြိမ် နှိပ်လျှင် ပြောင်းပြန်လှန်ပြီး တတိယအကြိမ်တွင် ဖိုင်၏ မူလအစီအစဉ် ပြန်ရောက်သည်။ ဗလာတန်ဖိုးများသည် အမြဲ အောက်ဆုံးတွင် ရှိနေသည်။ စီခြင်းသည် မြင်ရသည်ကိုသာ ပြောင်းပြီး အလွှာကို ဘယ်တော့မှ မပြောင်းပါ။
- **Filter:** filter အကွက်တွင် ရိုက်ပါ။ `AREA > 500 and USE = 'Res'` ကဲ့သို့ expression သည် မှန်သော အတန်းများကို ထားသည် ([GIS အလွှာများကို ခွဲခြမ်းစိတ်ဖြာခြင်း](topic:gis-analysis) ၏ Select tab နှင့် တူသော စကားလုံးများ: `=`, `<`, `like`, `contains`, `is null`, `in`, `between`, `and`, `or`, `not`, `$area`, `$length`)။ `oak maple` ကဲ့သို့ expression မဟုတ်သော စာသားသည် column တိုင်းတွင် ထိုစကားလုံးများကို ရှာသည်။
- **Select rows:** အတန်းကို နှိပ်ပါ။ Ctrl+နှိပ်ခြင်းသည် အတန်းတစ်ခု ထည့်သို့မဟုတ် ဖယ်သည်၊ Shift+နှိပ်ခြင်းသည် ဆက်တိုက်အစုကို ရွေးသည်၊ {{ui:Select shown rows}} က filter ကို ဖြတ်သန်းသော အတန်းအားလုံးကို ရွေးသည်။ ရွေးထားသော အင်္ဂါရပ်များကို plan ပေါ်တွင် ဆွဲပြပြီး plan ပေါ်ရှိ အင်္ဂါရပ်ကို နှိပ်လျှင် ဤနေရာရှိ ၎င်း၏ အတန်းကို ရွေးသည်။
- ရွေးထားသော အတန်းများဖြင့် ၎င်းတို့ဆီ {{ui:Zoom}} လုပ်နိုင်၊ ရွေးချယ်မှုမှ **layer from the selection** ကို ပြုလုပ်နိုင်၊ status line တွင် စုစုပေါင်း ဧရိယာ သို့မဟုတ် အလျားကို ဖတ်နိုင်သည်။

## တန်ဖိုးများ ပြင်ခြင်း

cell ကို နှစ်ချက်နှိပ်ပါ (သို့မဟုတ် မြားခလုတ်ဖြင့် သွားပြီး Enter ကို နှိပ်ပါ)၊ တန်ဖိုးအသစ် ရိုက်ပြီး Enter ကို နှိပ်ပါ။ Escape က မူလအတိုင်း ထားသည်။ တန်ဖိုးသည် column နှင့် ကိုက်ညီရမည်: ဂဏန်းများကို ဂဏန်းအဖြစ်၊ ရက်စွဲများကို `YYYY-MM-DD` အဖြစ်၊ yes/no ကို yes, no, true သို့မဟုတ် false အဖြစ်။ မကိုက်ညီသော တန်ဖိုးကို စာကြောင်းဖြင့် ငြင်းပြီး ဘာမျှ မပြောင်းပါ။ အကွက်ကို ဗလာထားလျှင် တန်ဖိုး ဗလာ ဖြစ်သည်။ တည်းဖြတ်မှုတိုင်းသည် undo အဆင့်တစ်ခု ဖြစ်သည်: {{ui:Undo}} နှင့် {{ui:Redo}} သည် table ၏ အောက်ဆုံးတွင် ရှိပြီး Ctrl+Z သည် plan ပေါ်တွင် အလုပ်လုပ်သည်။

## Fields

**Fields** အောက်တွင် field တစ်ခု ထည့်နိုင်သည် (စာသား၊ ဂဏန်း၊ ရက်စွဲ သို့မဟုတ် yes/no)၊ အမည်ပြောင်းနိုင်သည်၊ ဖယ်ရှားနိုင်သည်။ field အသစ်သည် ဗလာဖြင့် စသည်။ အမည်ပြောင်းခြင်းသည် နောက်ဆက်တွဲ ပြောင်းသည်: အလွှာ၏ label field နှင့် [attribute ဖြင့် ပုံစံချခြင်း](topic:gis-symbology) သည် အမည်အသစ်သို့ ရွှေ့သည်၊ field ဖယ်ရှားခြင်းသည် ထို field ကို သုံးသော label နှင့် ပုံစံကို ဖျက်သည်။ တစ်ခုစီသည် အရာအားလုံးကို ပြန်ရောက်စေသော undo အဆင့်တစ်ခု ဖြစ်သည်။

## Field calculator

အတန်းတိုင်း (သို့မဟုတ် ရွေးထားသော အတန်းများသာ) အတွက် အတန်း၏ အခြား field များ၊ ဂျီသြမေတြီနှင့် function အနည်းငယ်မှ တန်ဖိုးကို ရေးသည်။ ရှိပြီးသား field ကို ရွေးပါ သို့မဟုတ် **A new field…** ကို ရွေးပြီး အမည်နှင့် အမျိုးအစား ပေးပါ။ ဘာမျှ code အဖြစ် မလည်ပတ်ပါ: expression ကို function စာရင်း ပုံသေရှိသော အသေးစား parser က ဖတ်သည်။

| အုပ်စု | စကားလုံးများ |
|---|---|
| ဂဏန်းများ | `+ - * /`၊ ကွင်းများ၊ `abs round(x, digits) floor ceil sqrt pow min max` |
| စာသား | `upper lower trim len substr(text, from, count) left right replace concat` (စာသားကို 'single quotes' တွင်; space ပါသော field အမည်ကို "double quotes" သို့မဟုတ် [square brackets] တွင် ထည့်ပါ) |
| ရွေးချယ်ခြင်း | `if(test, then, else)`, `coalesce(a, b, …)`, `num(x)`, `str(x)` |
| ရက်စွဲများ | `YYYY-MM-DD` တန်ဖိုး၏ `year month day` |
| ဂျီသြမေတြီ | `$area $perimeter $length $x $y $vertices`၊ ပရောဂျက်ယူနစ်ဖြင့် |

field အမျိုးအစားအတွင်း သိမ်း၍မရသော ရလဒ် (ဂဏန်း field ထဲ စာသား) ကို ဗလာထားပြီး message တွင် ရေတွက်သည်။ သုညဖြင့် စားလျှင် တန်ဖိုး ဗလာ ဖြစ်သည်။ ဥပမာ `round($area / 43560, 2)` က စတုရန်း feet မှ acre များကို ရေးသည်။

## ထုတ်ခြင်း

{{ui:Export CSV}} က မြင်ရသော အတန်းများကို (filter နှင့် စီပြီးနောက်) UTF-8 CSV ဖိုင်အဖြစ် သိမ်းသည်၊ ပထမစာကြောင်းတွင် field အမည်များ ပါသည်။ `=`, `+`, `-` သို့မဟုတ် `@` ဖြင့် စသော စာသားတွင် spreadsheet က formula အဖြစ် မလုပ်ဆောင်စေရန် ရှေ့တွင် apostrophe ထည့်သည်။ အလွှာကိုယ်တိုင် သိမ်းရန် [GIS အတွက် as-built ဒေတာ ထုတ်ခြင်း](topic:gis-export) ကို သုံးပါ။

## ကန့်သတ်ချက်များ

table သည် အလွှာကို စီခြင်းအစီအစဉ်တစ်ခုနှင့် filter တစ်ခုတည်းဖြင့်သာ ပြသည်။ ဤနေရာတွင် အတန်းထည့်ခြင်း သို့မဟုတ် ဖျက်ခြင်း မရှိ (ရွေးချယ်မှုမှ အလွှာအသစ် ပြုလုပ်ပါ)၊ ဂျီသြမေတြီကို မတည်းဖြတ်နိုင်၊ field ၏ အမျိုးအစားကို ပြုလုပ်ပြီးနောက် မပြောင်းနိုင်ပါ။

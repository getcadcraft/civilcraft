အက္ခရာတစ်လုံးတည်းပါသော ကီးများသည် ကွင်းတစ်ခုထဲ စာမရိုက်နေချိန်တွင် အလုပ်လုပ်သည်။ {{key:Mod}} ပါသော ဖြတ်လမ်းများသည် Mac တွင် Command ကို၊ အခြားနေရာတွင် Ctrl ကို သုံးသည်။ [Browser တွင် ကီးများ](common:keys) ကိုလည်း ကြည့်ပါ။

## ဖိုင်များနှင့် တည်းဖြတ်ခြင်း

| ကီး | လုပ်ဆောင်ချက် |
|---|---|
| {{key:Mod+O}} | အမှတ်ဖိုင်၊ LandXML သို့မဟုတ် စီမံကိန်း ဖွင့်ရန် |
| {{key:Mod+S}} | စီမံကိန်း သိမ်းရန် (`.civilcraft.json` ဖိုင် ဒေါင်းလုတ်ဆွဲသည်) |
| {{key:Mod+P}} | ပလန်ကို PDF သို့ ပလော့လုပ်ရန် (ပလော့ဒိုင်ယာလော့ဂ် ဖွင့်သည်၊ browser ၏ print မဟုတ်) |
| {{key:Mod+Z}} | ပြန်ဖျက်ရန် |
| {{key:Mod+Y}} | ပြန်လုပ်ရန် |
| {{key:Delete}} | ရွေးထားသော စစ်တမ်းအမှတ်များ၊ လမ်းကြောင်း၊ ခင်းကျင်းမြေ၊ ဆောက်လုပ်ချက်၊ ပိုက်၊ သို့မဟုတ် PVI ကို ဖျက်ရန် |
| {{key:Mod+C}} | ရွေးထားသော စစ်တမ်းအမှတ်များကို ကူးရန် (spreadsheet အတွက် အမှတ်တန်းများအဖြစ်လည်း) |
| {{key:Mod+X}} | ရွေးထားသော စစ်တမ်းအမှတ်များကို ဖြတ်ရန် |
| {{key:Mod+V}} | အမှတ်များ ကူးထည့်ရန်: ညွှန်ပြချက်ကို လိုက်သည်၊ သွားရာနေရာကို နှိပ်ပါ |
| {{key:Mod+Shift+V}} | နေရာတွင် ကူးထည့်ရန်: အမှတ်များ၏ ကိုယ်ပိုင် ကိုဩဒိနိတ်များတွင် |
| {{key:Mod+D}} | ရွေးထားသော အမှတ်များကို ပွားရန်: မိတ္တူသည် ညွှန်ပြချက်ကို လိုက်သည် |
| {{key:Mod+A}} | စစ်တမ်းအမှတ်အားလုံး ရွေးရန် |
| {{key:Esc}} | ဘာမျှ မရွေးရန် (နှင့် ကူးထည့်ခြင်း ပယ်ဖျက်ရန်) |

{{key:Mod+S}}၊ {{key:Mod+O}} နှင့် {{key:Mod+P}} သည် ကွင်းတစ်ခုထဲ စာရိုက်နေချိန်တွင်ပင် အလုပ်လုပ်သည်။ ကွင်းထဲရှိ {{key:Mod+Z}} နှင့် {{key:Mod+Y}} သည် ပုံမှန်အတိုင်း ၎င်းတို့၏ စာရိုက်ချက်ကို ပြန်ဖျက်/ပြန်လုပ်သည်၊ {{key:Mod+C}}၊ {{key:Mod+X}}၊ {{key:Mod+V}} နှင့် {{key:Mod+A}} လည်း အလားတူပင်: ကွင်းထဲတွင် ၎င်းတို့က စာသားကို ကူး၊ ဖြတ်၊ ကူးထည့်၊ ရွေးသည်။ စာမျက်နှာပေါ်တွင် (panel ထဲ) စာသား ရွေးထားပါက {{key:Mod+C}} က ထိုစာသားကို ကူးသည်။ {{key:Mod+Shift+Z}} သည် CivilCraft တွင် ဘာမျှ မလုပ်ပါ: {{key:Mod+Y}} သို့မဟုတ် {{ui:Redo}} ခလုတ်ကို သုံးပါ။

:::mac
Mac တွင် **delete** ဟု အမည်ပေးထားသော ကီးသည် browser အတွက် {{key:Backspace}} ဖြစ်သည်။ ရွေးချယ်မှုကို ဖျက်ရန် {{key:Delete}} (Fn နှင့် delete) ကို နှိပ်ပါ၊ သို့မဟုတ် toolbar ၏ {{ui:More}} မီနူးတွင် {{ui:Delete}} ကို ရွေးပါ။
:::

| {{key:I}} | {{ui:Add PVIs}} ကို ဖွင့်/ပိတ်ရန် (ပိတ်ထားပါက ပရိုဖိုင်အမြင်ကို ဖွင့်သည်) |

| {{key:E}} | feature line တိုင်းတလျှောက် စောက်ချိုးနှင့် အမြင့်များကို ပြ သို့မဟုတ် ဝှက်ရန် (မျက်နှာပြင်ပေါ်တွင်သာ) |

အသက်ဝင်နေသော ကိရိယာ၏ ကီးကို ထပ်နှိပ်ပါက {{ui:Select}} သို့ ပြန်သွားသည်။ Shift ဖြင့် အက္ခရာများ ဘာမျှ မလုပ်ပါ။

## ရေးဆွဲနေစဉ်

| ကီး | လုပ်ဆောင်ချက် |
|---|---|
| {{key:Enter}} | လမ်းကြောင်း၊ ခင်းကျင်းမြေ၊ ပိုက်အပြေး၊ breakline သို့မဟုတ် နယ်နမိတ်ကို ပြီးစီးရန် |
| {{key:Backspace}} | နောက်ဆုံး နှိပ်ထားသော အမှတ်ကို ဖယ်ရှားရန် |
| {{key:C}} | Feature line: ကွေးလမ်းများကို ဖွင့်/ပိတ်ရန် (vertex နောက်တွင်၊ ကွေးပေါ်ရှိ အမှတ်ကို နှိပ်ပြီးနောက် ၎င်း၏ အဆုံးကို နှိပ်ပါ) |
| {{key:Esc}} | ဆွဲခြင်း (သို့မဟုတ် ကူးထည့်ခြင်း) ကို ပယ်ဖျက်ရန်; ထပ်နှိပ်ပါက (သို့မဟုတ် ဘာမျှ ဆွဲမထားပါက) {{ui:Select}} သို့ ပြန်သွားပြီး ရွေးချယ်မှုကို ရှင်းရန် |

## ပလန်အမြင်

| ကီး သို့မဟုတ် လုပ်ဆောင်ချက် | ရလဒ် |
|---|---|
| Wheel | ညွှန်ပြချက်နေရာတွင် ချဲ့ သို့မဟုတ် ချုံ့ရန် |
| လွတ်နေသော နေရာပေါ် ဆွဲခြင်း | ရွှေ့ကြည့်ရန် (ကိရိယာမရွေးဘဲ၊ တိုတိုနှိပ်ခြင်းသည် ကျန်နိုင်သည်; {{key:Shift}} ကိုင်ထားလျှင် ရွေးချယ်မှု အကွက် ဆွဲသည်) |
| အလယ်ခလုတ် ဖြင့် ဆွဲခြင်း | ရွှေ့ကြည့်ရန် |
| ညာခလုတ် ဖြင့် ဆွဲခြင်း | ရွှေ့ကြည့်ရန် (မီနူး မဖွင့်ပါ) |
| {{key:Space}} နှင့် ဆွဲခြင်း | ရွှေ့ကြည့်ရန် |
| နှိပ်ခြင်း | ရွေးရန် ({{ui:Select}} ဖြင့်)၊ သို့မဟုတ် အမှတ်ချရန် (ဆွဲကိရိယာဖြင့်) |
| {{key:Shift}} နှင့် နှိပ်ခြင်း | စစ်တမ်းအမှတ်ကို ရွေးချယ်မှုထဲ ထည့်ရန် သို့မဟုတ် ထုတ်ရန် |
| {{key:Shift}} နှင့် ဆွဲခြင်း | အကွက်ဆွဲရန်: အတွင်းရှိ စစ်တမ်းအမှတ်များကို ရွေးချယ်မှုထဲ ထည့်သည်။ ၎င်းတို့ပတ်လည် ဆွဲ၍ [လာဆို](topic:lasso-selection) ရနိုင်သည် |
| လာဆို ဆွဲနေစဉ် {{key:Space}} | window၊ ထို့နောက် crossing၊ ထို့နောက် fence |
| ကူးထည့်နေစဉ် နှိပ်ခြင်း | ကူးထည့်ထားသော အမှတ်များကို ထိုနေရာတွင် ထားရန် ({{key:Enter}} က ၎င်းတို့၏ ကိုယ်ပိုင် ကိုဩဒိနိတ်တွင် ထားသည်) |
| grip ကို ဆွဲခြင်း | PI၊ ခင်းကျင်းမြေ ထောင့် သို့မဟုတ် ဆောက်လုပ်ချက်ကို ရွှေ့ရန် (ပြန်ဖျက်ခြင်း တစ်ဆင့်) |
| {{key:Up}} {{key:Down}} {{key:Left}} {{key:Right}} | ရွှေ့ကြည့်ရန်၊ ပလန်တွင် focus ရှိသည့်အခါ (ဦးစွာ နှိပ်ပါ) |
| {{key:Plus}} နှင့် {{key:Minus}} | အလယ်တွင် ချဲ့ နှင့် ချုံ့ရန်၊ ပလန်တွင် focus ရှိသည့်အခါ |

= ကီးသည် {{key:Plus}} ကဲ့သို့ ချဲ့သည်၊ ထို့ကြောင့် Shift မလိုပါ။

## ပရိုဖိုင်အမြင်

| လုပ်ဆောင်ချက် | ရလဒ် |
|---|---|
| {{ui:Add PVIs}} ဖွင့်ထားစဉ် နှိပ်ခြင်း | ထိုနေရာတွင် PVI ထည့်ရန် |
| PVI ကို နှိပ်ခြင်း | ရွေးရန် |
| PVI ကို ဆွဲခြင်း | ရွှေ့ရန် (ပြန်ဖျက်ခြင်း တစ်ဆင့်) |
| {{key:Delete}} သို့မဟုတ် {{key:Backspace}} | ရွေးထားသော PVI ကို ဖယ်ရှားရန် ({{key:Backspace}} ကို ပရိုဖိုင်အမြင်တွင် focus ရှိမှသာ) |

ပရိုဖိုင်အမြင်သည် ချဲ့/ချုံ့ခြင်း သို့မဟုတ် ရွှေ့ကြည့်ခြင်း မရှိပါ။

## မျက်နှာပြင်နှင့် အကူအညီ

| ကီး | လုပ်ဆောင်ချက် |
|---|---|
| {{key:F1}} | ဤအကူအညီကို ဖွင့်/ပိတ်ရန် (ဘေးအကန့်); app bar ရှိ {{ui:Help}} ကလည်း အလားတူ လုပ်သည် |
| {{key:Esc}} | အကူအညီအကန့် ဖွင့်နေပါက ပိတ်ရန် |
| {{key:Ctrl+Shift+F}} | မျက်နှာပြင်ပုံစံများကို ပတ်ရန်: ဖန်သားပြင်အပြည့်၊ ဘားများ ဝှက်ထားသော ဖန်သားပြင်အပြည့်၊ ပုံမှန် |
| {{key:Esc}} | ဖန်သားပြင်အပြည့်မှ ထွက်ရန် (browser ၏ ကိုယ်ပိုင် ကီး) |

{{key:F1}} သည် CivilCraft မမြင်မီ အကူအညီသို့ ရောက်သဖြင့် ကိရိယာမည်သည့်အခါမဆို အလုပ်လုပ်သည်။ Mac ကီးဘုတ် အများစုတွင် fn နှင့် F1 ကို နှိပ်ပါ၊ သို့မဟုတ် {{ui:Help}} ကို နှိပ်ပါ။ {{key:Ctrl+Shift+F}} သည် Mac အပါအဝင် platform အားလုံးတွင် Control ကီးကို သုံးသည်။ ဤအကူအညီကို ရှာဖွေနည်းအတွက် [အကူအညီကို အသုံးပြုခြင်း](common:help) ကို ကြည့်ပါ။

## မောက်စ်၊ trackpad နှင့် touch

:::mouse
- Wheel သည် ညွှန်ပြချက်နေရာတွင် ချဲ့သည်။ လွတ်လွတ်လပ်လပ် လည်သော wheel ရှိ မောက်စ်သည် မြန်မြန် ချဲ့သည်: တိုတိုသာ လှည့်ပါ။
- လွတ်နေသော နေရာပေါ် မည်သည့် ဆွဲခြင်း၊ အလယ်ခလုတ်၊ ညာခလုတ်၊ သို့မဟုတ် {{key:Space}} နှင့် ဆွဲခြင်းဖြင့် ရွှေ့ကြည့်ပါ။
:::

:::mac
Mac trackpad တွင်:

- လက်ညှိုး နှစ်ချောင် scroll လုပ်ခြင်းသည် **ချဲ့သည်** (ရွှေ့ကြည့်ခြင်း မဟုတ်)၊ ညှစ်ခြင်းလည်း ချဲ့သည်။
- ရွှေ့ကြည့်ရန်၊ လက်ညှိုးတစ်ချောင်းဖြင့် လွတ်နေသော နေရာပေါ် နှိပ်ဆွဲပါ၊ သို့မဟုတ် {{key:Space}} ကို ဖိထားပြီး ဆွဲပါ။
- လက်ချောင်း နှစ်ချောင် နှိပ်ခြင်း (right-click) သည် မီနူး မဖွင့်ပါ၊ ၎င်းတစ်ခုတည်းဖြင့် ဘာမျှ မလုပ်ပါ။
:::

:::touch
Touch screen တွင်:

- ပထမ ထိခြင်းသည် ခလုတ်များနှင့် မီနူးအတန်းများကို လက်ညှိုးအရွယ်ဖြစ်စေသည်။
- ရွေး သို့မဟုတ် အမှတ်ချရန် ထိပါ; လွတ်နေသော နေရာပေါ် လက်ညှိုးတစ်ချောင်း ဆွဲခြင်းက ရွှေ့ကြည့်သည်။ ထိခြင်းတွင် အနည်းငယ် ယိမ်းနိုင်သည်: လက်ညှိုးသည် ~10 pixel ရွေ့မှသာ ရွှေ့ကြည့်သည်။
- လက်ညှိုး နှစ်ချောင်းဖြင့် ညှစ်ခြင်းဖြင့် ချဲ့ပြီး အတူရွှေ့ခြင်းဖြင့် ရွှေ့ကြည့်သည်။
- grip သို့မဟုတ် PVI ကို လက်ညှိုးတစ်ချောင်းဖြင့် ဆွဲပါ။ Grip များသည် ၎င်းတို့ပတ်လည် လက်ညှိုး အကျယ်ကို ယူသည်။
- လမ်းကြောင်း၊ ခင်းကျင်းမြေ၊ breakline၊ နယ်နမိတ်၊ ပိုက်အပြေး၊ feature line သို့မဟုတ် parcel ဆွဲနေစဉ် ပလန်ပေါ်ရှိ ဘားက {{ui:Finish}} ({{key:Enter}})၊ {{ui:Undo point}} ({{key:Backspace}}) နှင့် {{ui:Cancel}} ({{key:Esc}}) ကို ပေးသည်။ ရှည်ရှည် နှိပ်ခြင်း (စက္ကန့်ဝက် မရွေ့ဘဲ) လည်း ပြီးစီးစေသည်။
- {{ui:Select}} တွင် စစ်တမ်းအမှတ်ပေါ် ရှည်ရှည်နှိပ်ခြင်းက {{key:Shift}}+နှိပ်ခြင်း ကဲ့သို့ ရွေးချယ်မှုထဲ ထည့်သည် သို့မဟုတ် ထုတ်သည်။
- 3D မြင်ကွင်းတွင် လက်ညှိုးတစ်ချောင်းက ပတ်ပြေးသည်၊ နှစ်ချောင်းက ညှစ်ပြီး ရွှေ့သည်၊ ထိခြင်းက ရွေးသည်။
- Touch တွင် hover မရှိပါ၊ ထို့ကြောင့် အခြေအနေဘား ဖတ်ချက်များသည် လက်ညှိုး ဖိထားစဉ်သာ အပ်ဒိတ်လုပ်သည်။
:::

## Browser က အနိုင်ရသော ကီးများ

ကီးအချို့သည် browser ပိုင်ဖြစ်ပြီး CivilCraft သို့ ဘယ်တော့မှ မရောက်ပါ၊ ဥပမာ {{key:Mod+W}} (tab ပိတ်)၊ {{key:Mod+T}} (tab အသစ်)၊ {{key:Mod+N}} (window အသစ်) နှင့် {{key:F11}} (Windows နှင့် Linux browser များတွင် ဖန်သားပြင်အပြည့်)။ CivilCraft က ၎င်းတို့ကို မသုံးပါ။ ဖြတ်လမ်းတစ်ခုက browser တွင် တစ်ခုခု ဖွင့်ပါက ပလန်ကို တစ်ချက် နှိပ်ပြီး page ကို focus ပေးကာ ထပ်စမ်းပါ။

## Move ရှိသည့်နေရာ

Move command မရှိပါ: {{ui:Select}} ကို ရွေး၍ အမှတ် သို့မဟုတ် vertex ကို ဆွဲပါ၊ သို့မဟုတ် {{ui:Properties}} တွင် ၎င်း၏ ကိုဩဒိနိတ်များကို တည်းဖြတ်ပါ။ [အမှတ်များ တည်းဖြတ်ခြင်း](topic:edit-points) ကို ကြည့်ပါ။

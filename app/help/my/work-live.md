## သင် သိရမည့်အရာ

စီမံကိန်းတစ်ခုသည် လူများစွာ တစ်ပြိုင်နက် လုပ်ဆောင်စဉ်တွင် ဘာဖြစ်သည်ကို ဖော်ပြသည်။ CadCraft Studio သည် Live TeamWork session ကို စတင်ပြီး ဝင်ရောက်သည် (**မျှဝေရန်** နှင့် **ဝင်ရန်**); ဤစာမျက်နှာသည် စီမံကိန်းကိုယ်တိုင်အကြောင်း ဖြစ်သည်။

## လူတိုင်း တစ်ပြိုင်နက် လုပ်ဆောင်သည်

host ၏ အမှတ်များနှင့် ဒီဇိုင်းသည် ဝင်ရောက်သူ အားလုံးထံ ရောက်ရှိသည်။ အမှတ်များကို တည်းဖြတ်ပါ၊ ဖြောင့်ညွှန်း၊ ပလက်ဖောင်း၊ feature line နှင့် မြေကွက်များကို ပုံမှန်အတိုင်း ဆွဲပါ။ သင်၏ ကိုယ်ပိုင် တည်းဖြတ်မှုများ ချက်ချင်း ပေါ်သည်; အခြားသူများ၏ ပြောင်းလဲမှုများ ၎င်းတို့ ပြုလုပ်ပြီးနောက် အချိန်တိုအတွင်း ပေါ်လာသည်။

- **အမှတ်များ** တစ်ခုချင်း ပေါင်းစည်းသည်: လူနှစ်ဦးက အမှတ်နှစ်ခု ရွှေ့လျှင် နှစ်ဦးလုံး ၎င်းတို့၏ ပြောင်းလဲမှုကို ထိန်းထားသည်။
- **ဖြောင့်ညွှန်းများ၊ ပလက်ဖောင်းများ၊ feature line များနှင့် မြေကွက်များ** အရာဝတ္ထုနှင့် ချိန်ညှိချက်အလိုက် ပေါင်းစည်းသည်; တူညီသော ချိန်ညှိချက်ကို နောက်ပိုင်း ပြောင်းလဲမှုက ရရှိသည်။
- **မျက်နှာပြင်** ကို ဝင်းဒိုးတိုင်းတွင် တူညီသော အမှတ်များနှင့် breakline များမှ တည်ဆောက်သဖြင့် contour များနှင့် ထုထည်များ ကိုက်ညီသည်။

Session တွင် မျှဝေခြင်း မရှိ: grid ဖိုင်မှ load လုပ်သော မျက်နှာပြင်၊ GIS အလွှာ features၊ မြေပုံ ပုံများနှင့် grid shift ဖိုင်များ။ ၎င်းတို့သည် ဖွင့်ခဲ့သော ဝင်းဒိုးတွင်သာ ရှိနေသည်။

## တစ်ဦးနှင့်တစ်ဦး မြင်ခြင်း

Session ရှိ လူတိုင်းတွင် ကိုယ်ပိုင် အရောင် ရှိသည်။ အစီအစဉ်ပေါ်တွင် လူတစ်ဦးစီ၏ pointer ကို ၎င်းတို့ အရောင်ဖြင့် မြားအဖြစ်၊ ၎င်းတို့၏ အမည်ကို ဘေးတွင် ပါ၍ မြင်ရသည်၊ နှင့် ၎င်းတို့ ရွေးထားသော အမှတ်များနှင့် အရာဝတ္ထု ပတ်လည် ၎င်းတို့ အရောင်ဖြင့် အစက်ကြောင်း အကွက်ကို မြင်ရသည်။ 3D အမြင်ကို အစီအစဉ်အပေါ် ဖွင့်ထားစဉ် pointer များသည် သင်ပိတ်သည်အထိ စောင့်ဆိုင်းသည်။

Pointer၊ အမည်နှင့် ရွေးချယ်မှုများသည် session အတွက်သာ ဖြစ်သည်: ဖိုင်တွင် တစ်ခါမျှ မသိမ်းပါ၊ မည်သူ၏ undo ထဲမျှ မဝင်ပါ။ ၎င်းတို့သည် လူတစ်ဦးစီရှိရာ နေရာသို့ ချောချောမွေ့မွေ့ ရွေ့သဖြင့် ဆက်သွယ်မှု နှေးသည့်အခါတွင်ပင် ချောမွေ့နေသည်။

## Undo သည် သင့်ကိုယ်ပိုင် အလုပ်ကို ပြန်ဖျက်သည်

{{key:Mod+Z}} သည် သင်၏ နောက်ဆုံး တည်းဖြတ်မှုကို ပြန်ဖျက်ပြီး အခြားသူများ၏ အရာကို ထားသည်။ တစ်စုံတစ်ဦးက တူညီသော အရာကို ပြောင်းလဲထားပြီးဖြစ်ပါက ဘာမျှ မပြန်ဖျက်ပါ၊ status bar က ဘယ်သူလဲဟု ပြောသည်။

## browser မှ ဝင်ရောက်ခြင်း

Studio မပါသော အသင်းဝင်တစ်ဦးသည် တူညီသော ကွန်ရက်ပေါ်ရှိ ဖုန်း၊ tablet သို့မဟုတ် ကွန်ပျူတာဖြင့် host ၏ ကုဒ်အောက်ရှိ ပုံကို စကင်ဖတ်နိုင်သည်။ CivilCraft သည် browser တွင် ဖွင့်ပြီး host က ခွင့်ပြုပြီးနောက် host ၏ စီမံကိန်းဖြင့် ဖြည့်သည်။ ဖိတ်ခေါ်လင့်ခ်သည် အခြား ကွန်ရက်မှ ဝင်ရောက်စေသည်: host သည် အက်ပ်အတွက် Team Cloud Plan နေရာ လိုအပ်ပြီး အခြားသူအားလုံး အခမဲ့ ဝင်ရောက်သည်၊ နှင့် လင့်ခ်သည် host ၏ session ဖွင့်ထားသည့်အချိန်တွင်သာ အလုပ်လုပ်သည်။

## session ပြီးဆုံးသည့်အခါ

host သာ စီမံကိန်းကို သိမ်းသည်။ အခြားသူအားလုံးသည် မသိမ်းရသေးသော မိတ္တူကို ထားသည်: ထိန်းထားချင်ပါက သိမ်းပါ။

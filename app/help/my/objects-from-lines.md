{{ui:From a line}} (Landscape › {{ui:More}}): feature line တစ်ခု သို့မဟုတ် တင်သွင်းထားသော DWG/DXF layer ၏ မျဉ်း သို့မဟုတ် outline ကို နှိပ်ပါ။ ပိတ်ထားသော မျဉ်းက ခင်းကျင်းမှု၊ မြက်ခင်း၊ အပင်ခင်းထားသော နေရာ၊ meadow၊ groundcover၊ bed သို့မဟုတ် platform ဖန်တီးနိုင်သည်; ဖွင့်ထားသော မျဉ်းက လမ်းကြောင်း၊ နံရံ၊ ကာဘ်၊ လှေကား (ပထမနှင့် နောက်ဆုံးအမှတ်)၊ ramp၊ ခြံစည်း သို့မဟုတ် swale ဖန်တီးနိုင်သည်။ အမျိုးအစားနှစ်မျိုးလုံးက **feature line** ဖန်တီးနိုင်သည်၊ feature line ကိုယ်တိုင်မှလွဲ၍။

## မျဉ်းမှ feature line

မျဉ်းမှ ဖန်တီးထားသော feature line သည် မျဉ်း၏ အမှတ်များကို ယူပြီး မျဉ်းပိတ်ထားလျှင် ပိတ်ထားသည်။ ၎င်း၏ အဆင့်များကို ရှိပြီးသား မြေပြင်ပေါ် ချထားသည် (မရှိသေးလျှင် 0); ၎င်း၏ အသုံးပြုမှုမှာ **Off** ဖြစ်ပြီး၊ အသုံးပြုမှု ရွေးပြီး ၎င်း၏ Properties တွင် အဆင့်များ မသတ်မှတ်မချင်း မြေပြင်ကို မပြောင်းပါ။ မျဉ်း ရွှေ့သောအခါ အမှတ်အရေအတွက် တူသော feature line သည် သင် သတ်မှတ်ထားသော အဆင့်တိုင်းကို ထိန်းထားသည်; မျဉ်းက အမှတ် ထပ်တိုးသို့မဟုတ် လျော့သွားလျှင် အဆင့်များကို မြေပြင်ပေါ် ပြန်ချထားသည်။ [Feature lines](topic:feature-lines) ကို ကြည့်ပါ။

ဖန်တီးထားသော ပစ္စည်းသည် ၎င်း၏ မျဉ်းသို့ **link** ကို ထိန်းထားသည်။ မျဉ်းရွှေ့သောအခါ (အမှတ်များကို ဆွဲခြင်း၊ သို့မဟုတ် ပုံဆွဲကို ရွှေ့ခြင်း သို့မဟုတ် ပြန်ဖတ်ခြင်း)၊ ပစ္စည်းက ပုံသဏ္ဍာန်အသစ်ကို တူညီသော undo အဆင့်တွင် ယူသည်၊ ပြီးလျှင် ground modifier များမှတဆင့် အဆိုပြုမြေပြင်ကလည်း လိုက်ပါသည်။ Properties က ၎င်းချိတ်ထားသည့်အရာကို ပြသည်; {{ui:Break link}} က လွတ်လပ်စေသည်။

မျဉ်းများကို အရင်စစ်ဆေးသည်: မျဉ်းတွင် အမှတ်အနည်းဆုံး 2 (outline အတွက် 3)၊ အများဆုံး 5000၊ ကိန်းဂဏန်းအမှန်များ ဖြစ်ရမည်; outline သည် ပိတ်ထားရမည်ဖြစ်ပြီး ကိုယ်ဖြတ်ကျော်ခြင်း မရှိရ။ မအောင်မြင်သော မျဉ်းကို မသုံးပါ: ပစ္စည်းသည် မူလအတိုင်း ရှိနေပြီး Problems panel က အကြောင်းပြသည်။ မျဉ်းကို ဖျက်လျှင် ပစ္စည်းကျန်နေပြီး Problems panel တွင် မှတ်ထားသည်။

## SuperCad Studio တွင်

ဆိုက်နှင့် 2D ပုံဆွဲကို စီမံကိန်းတစ်ခုတည်းတွင် ဖွင့်ပါ။ 2D ပုံဆွဲတွင် မျဉ်း သို့မဟုတ် polyline တစ်ခုကို ရွေးပြီး Ctrl+K နှိပ်ကာ {{ui:Landscape object from the picked drawing line}} ကို run ပါ: CivilCraft က အထက်ပါအတိုင်း ဘာဖန်တီးမလဲ မေးသည်၊ ပစ္စည်းသည် ထိုပုံဆွဲ၏ မျဉ်းနှင့် link ရှိနေဆဲ ဖြစ်သည်။ ပုံဆွဲရှိ မျဉ်းများကို ပြောင်းပြီးနောက် Ctrl+K ဖြင့် {{ui:Update the landscape from the drawing}} က ပစ္စည်းများကို လိုက်ပါစေသည်၊ မျဉ်းတစ်ကြောင်းစီအတွက် undo အဆင့်တစ်ခုစီ။ စီမံကိန်း၏ link ဖိုင်က မည်သည့်ပစ္စည်းက မည်သည့်မျဉ်းကို လိုက်သည်ကို မှတ်ထားသည်။ SuperCad Studio ၏ ကိုယ်ပိုင် အကူအညီတွင် Landscape အပိုင်း ရှိသည်။

CivilCraft သည် သင့်ကွန်ပျူတာမှ ဖိုင်များကို ဖွင့်ပြီး ဖိုင်များကို ဒေါင်းလုဒ်ဖြင့် ပြန်သိမ်းသည်။ မည်သည့်အရာမျှ upload မလုပ်ပါ၊ server တွင်လည်း မသိမ်းထားပါ။ [သင်၏ ဖိုင်များ](common:your-files) ကိုလည်း ကြည့်ပါ။

## ဖွင့်နိုင်သည်များ

{{ui:ဖွင့်ရန်}} ကို နှိပ်ပါ (သို့မဟုတ် {{key:Mod+O}} ကို နှိပ်ပါ) ပြီး ဖိုင်တစ်ခုကို ရွေးပါ၊ သို့မဟုတ် ဖိုင်ကို {{pick:mac=Finder|windows=File Explorer|linux=ဖိုင်မန်နေဂျာ}} မှ ပလန်ပေါ်သို့ ဆွဲချပါ။ တစ်ကြိမ်လျှင် ဖိုင်တစ်ခု; 200 MB ထက်ကြီးသော ဖိုင်များကို လက်မခံပါ။ 32 MB ထက်ကြီးသော LandXML သို့မဟုတ် project ဖိုင်ကို အစိတ်အပိုင်း 4 MB ခန့်ဖြင့် ဖတ်ပြီး စာသား တစ်ခုတည်းအဖြစ် တစ်ကြိမ်တည်း မဖတ်ပါ; LandXML ဖွင့်နေစဉ် ၎င်းသည် memory တွင် ဖိုင်အရွယ်အစား၏ 13 ဆခန့် သုံးနိုင်ကြောင်း မျှော်လင့်ပါ (ကျွန်ုပ်တို့၏ စမ်းသပ်မှုတွင် 69 MB ဖိုင်က 0.9 GB ခန့် သုံးခဲ့သည်)။

| အမျိုးအစား | ဖိုင်အမည်များ | ဖြစ်ပျက်ပုံ |
|---|---|---|
| အမှတ်ဖိုင် | `.csv`, `.txt`, `.pnt`, `.xyz` (မည်သည့် စာသားဖိုင်မဆို) | **အမှတ်များ တင်သွင်းရန်** dialog ပွင့်လာသည်။ အမှတ်များက project ၏ အမှတ်များကို အစားထိုးသည်; alignment, pad နှင့် pipe များ ကျန်ရှိသည်။ |
| LandXML | `.xml`, `.landxml` | ဖိုင်မှ **project အသစ်** တစ်ခု ဖန်တီးသည် (လက်ရှိတွင် သိမ်းရန်မကျန်သော ပြောင်းလဲမှုများ ရှိပါက အရင်မေးမည်)။ |
| CivilCraft project | `.civilcraft.json` (မည်သည့် `.json`မဆို) | Project ကို သိမ်းခဲ့သည့်အတိုင်း ဖွင့်သည် (လက်ရှိတွင် သိမ်းရန်မကျန်သော ပြောင်းလဲမှုများ ရှိပါက အရင်မေးမည်)။ |

CivilCraft က ဖိုင်၏ အဆုံးသတ်ကို အရင်ကြည့်ပြီး ထို့နောက် ပထမ စာလုံးများဖြင့် ဆုံးဖြတ်သည်: `{` ဖြင့် စသော စာသားကို project အဖြစ်၊ `<` ဖြင့် စသော စာသားကို LandXML အဖြစ်၊ အခြားအရာတိုင်းကို အမှတ်ဖိုင်အဖြစ် ဖတ်သည်။ ဖွင့်သော အကွက်က မှိန်ထားသော ဖိုင်ကိုလည်း ပလန်ပေါ်သို့ ဆွဲချနိုင်ပါသည်။

:::note
အမှတ်ရှိပြီးသား project ထဲသို့ အမှတ်ဖိုင် တင်သွင်းပါက မေးမြန်းခြင်းမရှိဘဲ ၎င်းတို့ကို အစားထိုးပြီး undo သမိုင်းကို ရှင်းလင်းသည် (ဖိုင်မည်သည့်အရာကို ဖွင့်ဖွင့် undo အတွက် အသစ်စတင်ခြင်း ဖြစ်သည်)။ မျက်နှာပြင်သည် LandXML မှ ဖြစ်ခဲ့လျှင် အမှတ်များ တင်သွင်းခြင်းက ၎င်းကို အမှတ်များမှ တည်ဆောက်ထားသော မျက်နှာပြင်အဖြစ် ပြန်ပြောင်းသည်။ ဟောင်းအမှတ်များကို ပြန်လိုချင်နိုင်လျှင် အရင် သိမ်းပါ။
:::

အသေးစိတ်: [အမှတ်ဖိုင် ပုံစံများ](topic:point-file-formats), [LandXML: ဖတ်ခြင်းနှင့် ရေးခြင်း](topic:landxml-reference)။

## သိမ်းပုံ

{{ui:သိမ်းရန်}} ({{key:Mod+S}}) က ဖိုင်နှစ်ခုကို ဘေးတိုက် ရေးသည်၊ ဘယ်ဘက်ပြတင်းပေါ်ရှိ **Name** အမည်ဖြင့် အမည်ပေးသည်: ဆက်တည်းတည်းဖြတ်နေမည့် project ဖြစ်သော `<name>.civilcraft.json` နှင့် အခြားသူများအတွက် IFC 4.3 ဖြင့် ဒီဇိုင်းတူသော `<name>.ifc` ([IFC export and import](topic:ifc) ကို ကြည့်ပါ)။ ဖိုင်တစ်ခုစီက အခြားဖိုင်ကို မှတ်တမ်းတင်ထားပြီး IFC တွင် project ၏ ချုံ့ထားသော မိတ္တူလည်း ပါသဖြင့် တစ်ခုတည်း ပို့ထားသော IFC ကိုလည်း အပြည့်အဝ တည်းဖြတ်နိုင်သော အနေအထားဖြင့် ပြန်ဖွင့်နိုင်သည်။

- **Studio** တွင် ဖိုင်နှစ်ခုစလုံးကို ၎င်းတို့ရှိနေသော နေရာတွင် ဘေးချင်းကပ်၍ သိမ်းသည်။
- **Chrome နှင့် Edge** တွင် ပထမ သိမ်းချက်သည် ဖိုင်တွဲတစ်ခု မေးပြီး နှစ်ခုလုံးကို ထိုဖိုင်တွဲထဲ ရေးသည်; နောက်ထပ် သိမ်းမှုများသည် တူညီသော ဖိုင်တွဲသို့ သွားသည်။ ဖိုင်တွဲမေးခွန်းကို Cancel လုပ်ပါက နှစ်ခုလုံးကို ဒေါင်းလုဒ်လုပ်သည်။
- **အခြား browser များတွင်** ဖိုင်နှစ်ခုလုံး ဒေါင်းလုဒ်ဖြစ်သည်၊ project ဖိုင်ကို ပထမ။

ဖိုင်တစ်ခုခုကို ဖွင့်သည့်အခါ အခြားဖိုင်ကို ရှာသည်။ နှစ်ခုလုံးကို အတူ ဖွင့်ပါ (သို့မဟုတ် နှစ်ခုလုံး ဆွဲချပါ)၊ သို့မဟုတ် တစ်ခုကို ဖွင့်ပါ: **Studio** တွင် အခြားဖိုင်ကို ဖိုင်တွဲတူတွင် တွေ့သည်; browser တွင် CivilCraft က ၎င်းကို ထည့်ရန် သို့မဟုတ် သင့်ဘက်ရှိဖိုင်ဖြင့် ဆက်လုပ်ရန် မေးသည်။ CivilCraft သိမ်းပြီးနောက် IFC ကို အခြားပရိုဂရမ်က ပြောင်းလဲခဲ့ပါက၊ သို့မဟုတ် ဖိုင်တစ်ခုသည် အခြားဖိုင်ထက် ဟောင်းနေပါက project ကို ပို အသစ်သော ဒီဇိုင်းမှ ဖွင့်ပြီး ပြဿနာများ panel က ဖြစ်ပျက်ခဲ့သည်ကို ပြောပြသည်၊ **ယခု သိမ်းရန်** (နှစ်ခုလုံးကို ထပ်ရေးသည်) နှင့် **IFC ၏ ပုံသဏ္ဍာန်ကို ရည်ညွှန်းအဖြစ် ပြရန်** ပါရှိသည်။ အခြားပရိုဂရမ်က ပြောင်းထားသော IFC တစ်ခုတည်းကို ၎င်း၏ project မိတ္တူမှ ကိုက်ညီသည့်အရာများဖြင့် ဖွင့်သည်: ပြောင်းလဲထားသော alignment များသည် ၎င်း၏ ပုံသဏ္ဍာန်ကို ယူသည်၊ ဖျက်ထားသော object များကို ချန်ထားသည်၊ ကျန်ပြောင်းလဲမှုများကို စာရင်းပြသည် သို့ရာတွင် အလိုအလျောက် မယူပါ။ 0.7.1 မတိုင်မီ project ဖိုင်ကို ယခင်အတိုင်း ဖွင့်သည်။

Project ဖိုင်တွင် အောက်ပါတို့ကို သိမ်းထားသည်:

- အမှတ်တိုင်း (နံပါတ်၊ ကိုဩဒိနိတ်၊ အမြင့်၊ ဖော်ပြချက်) နှင့် ၎င်းတို့ ထွက်လာသော အမှတ်ဖိုင်၏ အမည်
- မျက်နှာပြင် ဆက်တင်များ: အုပ်စုရွေးချယ်မှုများ၊ ဆွဲထားသော breakline များ၊ နယ်နမိတ်၊ အပြင်ဘက်အရှည်ဆုံး အစွန်းနှင့် LandXML မှ ဖတ်ထားသော TIN
- ပြသမှု ဆက်တင်များ
- alignment များ၊ ၎င်းတို့၏ PI များ၊ radius များနှင့် စတင် station; ဒီဇိုင်း profile များ (PVI များနှင့် curve အရှည်များ) နှင့် corridor ဆက်တင်များ
- pad များနှင့် ၎င်းတို့၏ စည်းမျဉ်းများပါဝင်သော pipe network

Undo သမိုင်းကို မသိမ်းပါ။ မျက်နှာပြင်များ၊ contour များ၊ daylight line များနှင့် ထုထည်များကို သိမ်းမထားပါ; project ဖွင့်သည့်အခါ သိမ်းထားသော input များမှ ပြန်တည်ဆောက်သည်။ CivilCraft အသစ်မှ project ဖိုင်ကို ၎င်း၏ ဗားရှင်းကို အမည်ပေးသော မက်ဆေ့ချ်ဖြင့် ငြင်းပယ်သည်။

## ထုတ်ပို့သည်များ

| ခလုတ် | ဖိုင် | အကြောင်းအရာ |
|---|---|---|
| {{ui:LandXML}} | `<name>.xml` | LandXML 1.2: အမှတ်များ၊ ရှိပြီးသား မြေပြင် (ပြင်ထားသော မျက်နှာပြင် ရှိလျှင် ၎င်းပါ) TIN မျက်နှာပြင်များအဖြစ်၊ alignment များ၊ မြေပြင်နှင့် ဒီဇိုင်း profile များ၊ pipe network |
| {{ui:DXF}} | `<name>.dxf` | ပြသထားသည့်အတိုင်း ပလန် linework ၏ R12 DXF၊ အမည်ပေးထားသော layer များပေါ်တွင် |
| {{ui:DWG}} | `<name>.dwg` | တူညီသော linework ကို DWG ပုံဆွဲအဖြစ်၊ သင်ရွေးသော ပုံစံ (2000 မှ 2018) ဖြင့် |
| {{ui:PDF}} | `<name>.pdf` | စာရွက်ပေါ်ရှိ ပလန်၏ vector plot၊ သင်ရွေးသော စကေးဖြင့် |
| {{ui:GLB}} သို့မဟုတ် {{ui:OBJ}} (3D view ၏ bar တွင်) | `<name>-3d.glb`, `<name>-3d.obj` | 3D view က 3D model အဖြစ် ပြသသည့်အရာ: meters၊ Y အပေါ်၊ မှန်ကန်သော စကေး၊ မှတ်တမ်းတင်ထားသော local origin ပတ်လည် |

တစ်ခုစီက ဘာကို ချန်လှပ်ထားသလဲ: [LandXML ဖလှယ်ခြင်း](topic:landxml), [ပလန်ကို DXF သို့ ထုတ်ပို့ခြင်း](topic:dxf-export) (DWG လည်း), [ပလန်ကို PDF သို့ plot လုပ်ခြင်း](topic:plot-pdf), [ဆိုက်ကို 3D သို့ ထုတ်ပို့ခြင်း](topic:export-3d)။

သိမ်းထားသော နှင့် ထုတ်ပို့ထားသော ဖိုင်များသည် browser က ဒေါင်းလုဒ်များကို ထားရာ နေရာသို့ သွားသည်၊ များသောအားဖြင့် Downloads ဖိုင်တွဲ။ အကြိမ်တိုင်း ဖိုင်တွဲရွေးရန်:

Browser ၏ **Settings** ကို ဖွင့်ပြီး **Downloads** ကို ရွေးကာ **ဒေါင်းလုဒ်မလုပ်မီ ဖိုင်တစ်ခုစီကို မည်သည့်နေရာတွင် သိမ်းမလဲ မေးပါ** ကို ဖွင့်ပါ။
:::

:::firefox
**Settings** ကို ဖွင့်ပြီး **General** ကို ရွေးကာ **Files and Applications** အောက်တွင် **ဖိုင်များ သိမ်းမည့်နေရာကို အမြဲမေးပါ** ကို ရွေးပါ။
:::

:::safari
**Safari > Settings > General** ကို ဖွင့်ပြီး **File download location** ကို **Ask for each download** ဟု သတ်မှတ်ပါ။
:::

အမည်တူဖြင့် နှစ်ကြိမ်သိမ်းပါက browser က ဒုတိယဖိုင်တွင် နံပါတ်တစ်ခု ထည့်နိုင်သည်၊ ဥပမာ `Site (1).civilcraft.json`။ နောက်တစ်ကြိမ် နောက်ဆုံးဖိုင်ကို ဖွင့်ပါ။

## အွန်လိုင်းနှင့် အော့ဖ်လိုင်း

CivilCraft သည် မည်သို့ပင်ဖြစ်စေ သင့်ကွန်ပျူတာပေါ်တွင်သာ အလုပ်လုပ်သည်: ဖွင့်ခြင်းသည် browser တွင် ဖိုင်ကို ဖတ်ပြီး သိမ်းခြင်းသည် ၎င်းကို ဒေါင်းလုဒ်လုပ်သည်။ ချိတ်ဆက်မှု လုံးဝမရှိဘဲ CivilCraft ကို ဖွင့်ရန် ပထမ အော့ဖ်လိုင်းအသုံးပြုရန် သိမ်းပါ:

1. အွန်လိုင်းရှိစဉ် ထိပ်ရှိ app bar တွင် {{ui:အော့ဖ်လိုင်းအတွက် သိမ်းရန်}} ကို နှိပ်ပါ။
2. ခလုတ်က "30 ထဲမှ 12 သိမ်းနေသည်" ဟု ရေတွက်ပြီး ထို့နောက် {{ui:အော့ဖ်လိုင်း အဆင်သင့်}} ကို ပြသသည်။ CivilCraft သည် သေးငယ်သည် (ခန့်မှန်း 0.6 MB)၊ ထို့ကြောင့် ခဏ ကြာသည်။ သိမ်းထားသော မိတ္တူတွင် ဤ help နှင့် နမူနာဆိုက် ပါဝင်သည်။
3. ချိတ်ဆက်မှု မရှိဘဲ တူညီသော လိပ်စာ (သို့မဟုတ် ၎င်း၏ bookmark) ကို ဖွင့်ပါ။ အားလုံး အလုပ်လုပ်သည်၊ {{ui:နမူနာဆိုက်ကို ဖွင့်ရန်}} အပါအဝင်။

ခလုတ်၏ အခြား အခြေအနေများ:

- {{ui:သိမ်း၍ မရပါ}}: ဖိုင်အချို့ ဒေါင်းလုဒ်မရခဲ့ပါ။ ချိတ်ဆက်မှုကို စစ်ပြီး ထပ်ကြိုးစားရန် နှိပ်ပါ။
- {{ui:အော့ဖ်လိုင်း မရနိုင်ပါ}}: ဤ browser window သည် အော့ဖ်လိုင်းမိတ္တူကို ထိန်းသိမ်းနိုင်ခြင်း မရှိပါ (private window များနှင့် စီမံထားသော ကွန်ပျူတာအချို့က ပိတ်ဆို့ထားသည်)။ ပုံမှန် window ကို သုံးပါ။

မိတ္တူ သိမ်းခဲ့သည့်အချိန်ကို ကြည့်ရန် {{ui:အော့ဖ်လိုင်း အဆင်သင့်}} ကို နှိပ်ပါ၊ ရွေးချယ်မှု နှစ်ခုဖြင့်: {{ui:ထပ်သိမ်းရန် (နောက်ဆုံးဗားရှင်း ယူရန်)}} နှင့် {{ui:အော့ဖ်လိုင်းမိတ္တူကို ဖယ်ရှားရန်}}။ ဆိုက်သွားရောက်မှု မတိုင်မီ ထပ်သိမ်းပါ၊ မိတ္တူသည် နောက်ဆုံး build နှင့် ကိုက်ညီစေရန်။ နောက်ထပ်: [Offline](common:offline)။

:::offline
ယခု အော့ဖ်လိုင်းဖြစ်နေပါသည်။ CivilCraft ကို အော့ဖ်လိုင်းအသုံးအတွက် သိမ်းထားပါက နမူနာဆိုက်အပါအဝင် အားလုံး အလုပ်လုပ်သည်။ မသိမ်းထားပါက ဤ tab တွင် ဆက်လုပ်နိုင်သော်လည်း အွန်လိုင်းပြန်ရောက်မှ ပြန်မလုပ်ပါနှင့်; သိမ်းထားသော မိတ္တူ မရှိပါက {{ui:နမူနာဆိုက်ကို ဖွင့်ရန်}} သည် "နမူနာကို ဖွင့်၍ မရပါ" ဖြင့် ပျက်သည်။
:::

:::tip
နေရာပြင်ပ အသုံးပြုရန် CivilCraft ကို အော့ဖ်လိုင်းအသုံးအတွက် သိမ်းပြီး အမှတ်ဖိုင်များကို laptop ပေါ်တွင် ကိုယ်တိုင် ယူလာပါ။ Project များနှင့် ထုတ်ပို့မှုများသည် ချိတ်ဆက်မှုမရှိဘဲ ဒေါင်းလုဒ်အဖြစ် သိမ်းသောကြောင့် တစ်ရက်စာ တိုင်းတာချက်များကို တင်သွင်းပြီး မျက်နှာပြင်ကို စစ်ဆေးကာ ဆိုက်တွင် project ကို သိမ်းနိုင်သည်။
:::

Cloud သိမ်းဆည်းခြင်း မရနိုင်သေးပါ၊ desktop build များလည်း မထွက်ရှိသေးပါ။ ယနေ့ သင်သိမ်းသော ဖိုင်များသည် တစ်ခုတည်းသော မိတ္တူ ဖြစ်သည်: backup ရှိသော နေရာတွင် သိမ်းထားပါ။

## ဖိုင်က သုံးသော add-on များ

Add-on မှ ဒေတာပါဝင်သော project ကို သိမ်းသည့်အခါ (Building regulations tick များ၊ သို့မဟုတ် Address to site source)၊ ဖိုင်က မည်သည့် add-on နှင့် ဗားရှင်းကို မှတ်တမ်းတင်သည်။ တစ်ခုမရှိသော ကွန်ပျူတာတွင် ဖွင့်ပါက ပလန်အထက်ရှိ bar က ၎င်းကို ပြောပြပြီး သင့်အကောင့်စာရင်းမှ ထည့်ရန် ကမ်းလှမ်းသည်။ မှတ်တမ်းမှာ မှတ်ချက်သာ ဖြစ်ပြီး ဖိုင်သည် မည်သို့ပင်ဖြစ်စေ ဖွင့်သည်။

## Studio မှ Undo

CadCraft Studio အတွင်း CivilCraft တွင် သင်ပြီးစီးသော အဆင့်တိုင်းကို Studio သို့ ပြောပြသည်၊ ထို့ကြောင့် ၎င်း၏ project-level undo သည် app များတစ်လျှောက် နောက်ဆုံးအဆင့်ကို ပြန်ဖျက်နိုင်သည်။ CivilCraft ၏ ကိုယ်ပိုင် undo stack သည် ထိုအဆင့် ချန်ထားခဲ့သည့်အတိုင်း တိတိကျကျ ရှိနေမှသာ Studio သည် အဆင့်ကို undo လုပ်သည်; အခြားဖိုင်ဖွင့်ပြီးနောက် ဤ window ကို ကျော်သွားသည်။

## သိမ်းရန်မကျန်သော ပြောင်းလဲမှုများဖြင့် ပိတ်ခြင်း

Project တွင် သိမ်းရန်မကျန်သော ပြောင်းလဲမှုများရှိပြီး tab ကို ပိတ်ခြင်း၊ reload လုပ်ခြင်း သို့မဟုတ် စာမျက်နှာမှ ထွက်ခြင်း ပြုလုပ်သည့်အခါ browser က ထွက်လိုသလား မေးသည်။ ၎င်း၏ စာသားနှင့် ပုံစံသည် browser ၏ ဖြစ်ပြီး CivilCraft က ပြောင်းလဲ၍ မရပါ။ {{ui:အသစ်}} နှင့် project သို့မဟုတ် LandXML ဖိုင် ဖွင့်ခြင်းတို့ကမူ CivilCraft ၏ ကိုယ်ပိုင် **သိမ်းရန်မကျန်သော ပြောင်းလဲမှုများ** အကွက်တွင် မေးသည်၊ {{ui:ပယ်ဖျက်ရန်}}၊ {{ui:မသိမ်းပါနှင့်}} နှင့် {{ui:မိတ္တူသိမ်းရန်}} ဖြင့်။

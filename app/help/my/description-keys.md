စစ်တမ်းအဖွဲ့များက လယ်ကွင်းရှိ ရိုက်ချက်တိုင်းကို ကုဒ်ပေးသည်: `EP` ကတ္တရာအစွန်းအတွက်၊ `TC` ဘောင်ခံ အပေါ်ပိုင်းအတွက်၊ `BLDG` အဆောက်အအုံ ထောင့်အတွက်။ ကုဒ်သည် အမှတ်၏ ဖော်ပြချက်၏ ပထမ စကားလုံး ဖြစ်သည်။ CivilCraft က ၎င်းဖြင့် အမှတ်များကို အုပ်စုဖွဲ့ပြီး ၎င်းနောက်ရှိ line codes များကို မျဉ်းများအဖြစ် ပြောင်းသည်။

## Line codes

Line code သည် field code နောက်တွင် ချက်ချင်း ရှိသော စကားလုံး ဖြစ်သည်:

| ဖော်ပြချက် | အဓိပ္ပာယ် |
|---|---|
| `EP B` | ဤအမှတ်တွင် ကတ္တရာအစွန်း မျဉ်းအသစ် စတင်သည် |
| `EP` | လက်ရှိ EP မျဉ်းကို ဆက်သည် |
| `EP E` | ဤအမှတ်တွင် လက်ရှိ EP မျဉ်းကို အဆုံးသတ်သည် |
| `BLDG C` | အဆောက်အအုံကို ပိတ်သည်: ဤအမှတ်ကို မျဉ်း၏ ပထမ အမှတ်သို့ ပြန်ချိတ်သည် |

ကုဒ်တူ အမှတ်များကို အမှတ်နံပါတ် အစဉ်အတိုင်း ချိတ်သည်။ ကုဒ်မတူလျှင် အုပ်စု တူသော်လည်း မတူသော မျဉ်းများ ဖြစ်သည်၊ ထို့ကြောင့် `EP1` နှင့် `EP2` သည် တစ်ပြိုင်နက် အစွန်းနှစ်ခု ပေးသည်။ line code ကို ဘယ်တော့မျှ မသုံးသော ကုဒ်ကို ယခင် ဗားရှင်းများကဲ့သို့ ၎င်း၏ အမှတ်အားလုံးမှ ဆက်ချိတ်သည်။

**Breakline** အဖြစ် သုံးသော အုပ်စုရှိ မျဉ်းများသည် ဖြတ်မျဉ်းများ ဖြစ်လာပြီး မျဉ်းတစ်ခုလျှင် တစ်ခု ဖြစ်သည်၊ ထို့ကြောင့် ကွက်လပ်ပါသော ဘောင်ခံကို ကွက်လပ်ပေါ် မဆန့်ပါ။ အခြားအုပ်စုရှိ မျဉ်းများကို အစီအစဉ်ပေါ်တွင် ဆွဲပြီး (အလွှာ V-NODE-LINE) DXF, DWG နှင့် PDF သို့ ထွက်သည်။

စတင်၊ အဆုံး နှင့် ပိတ်အတွက် စကားလုံးများမှာ `B`၊ `BEG`၊ `START`; `E`၊ `END`; နှင့် `C`၊ `CLO`၊ `CLOSE` ဖြစ်သည်။ အောက်ပါ ဒိုင်ယာလော့ဂ်တွင် ၎င်းတို့ကို ပြောင်းပါ၊ သို့မဟုတ် line codes ကို ပိတ်ပါ။

## Description keys

Description key သည် ကုဒ်တစ်ခုကို အမှတ် အုပ်စု၊ အသုံးပြုမှုနှင့် ရှည်လျားသော ဖော်ပြချက်အဖြစ် ပြောင်းသည်။

1. **အမှတ်များ** အောက်တွင် {{ui:Description keys နှင့် line codes}} ကို နှိပ်ပါ။
2. {{ui:Key တစ်ခု ထည့်ရန်}} ကို နှိပ်ပြီး အတန်းကို ဖြည့်ပါ:
   - **ကုဒ်**: ကိုက်ညီရမည့် field code။ `*` က မည်သည့် စာလုံးမဆို၊ `?` က တစ်လုံးကို ကိုယ်စားပြုသည်၊ ထို့ကြောင့် `EP*` က EP၊ EP1 နှင့် EP12 ကို ဖမ်းသည်။
   - **အုပ်စု**: ဤအမှတ်များ ချိတ်ဆက်သော အမှတ် အုပ်စု (ဗလာ = ကုဒ် ကိုယ်တိုင်)။ အုပ်စု `EP` ပါသော `EP*` က EP1 နှင့် EP2 ကို အုပ်စုတစ်ခုတည်းတွင် ထားသည်၊ သို့သော် ၎င်းတို့သည် သီးခြား မျဉ်းများ ဖြစ်နေဆဲ။
   - **အသုံးပြုမှု**: အမှတ်များ၊ ဖြတ်မျဉ်း သို့မဟုတ် ချန်ထား၊ အုပ်စု ပထမဆုံး ပေါ်လာသည့်အခါအတွက် (သို့မဟုတ် **အမှတ်များ** ဇယားသို့ ထားပါ)။
   - **ဖော်ပြချက်**: အမည်ရှည်၊ အမှတ်၏ **ဂုဏ်သတ္တိများ** တွင် ပြသည်။
3. **အမှတ်များ** ကော်လံက သင်ရိုက်သည့်အတိုင်း သော့တစ်ခုစီ ဖမ်းသော အမှတ်များကို ရေတွက်သည်။ ကုဒ်နှင့် ကိုက်ညီသော ပထမ သော့ က အနိုင်ရသည်။
4. {{ui:အသုံးပြုရန်}} ကို နှိပ်ပါ။ အုပ်စုများ၊ မျက်နှာပြင်နှင့် အစီအစဉ်သည် အဆင့်တစ်ခုတည်းဖြင့် လိုက်ပြောင်းသည်: {{key:Mod+Z}} က ပြန်ဖျက်သည်။

အုပ်စုတစ်ခုသည် **အမှတ်များ** ဇယားတွင် သင်ပေးထားသော အသုံးပြုမှုကို ထိန်းသည်; သော့၏ အသုံးပြုမှုသည် အသစ်ဖြစ်သော အုပ်စုအတွက်သာ သတ်မှတ်သည်။ သော့များနှင့် line codes များကို ပရောဂျက်ဖိုင်တွင် သိမ်းသည်။

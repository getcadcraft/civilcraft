survey drawing သည် မှန်ကန်ပုံပေါက်နိုင်သော်လည်း မြေပြင်အတွက် မှားနေနိုင်ပါသည်: ၎င်း၏ ယူနစ်များကို ခန့်မှန်းထားနိုင်သည်၊ contours များသည် အမြင့် 0 တွင် ပြားနေနိုင်သည်၊ သို့မဟုတ် အမြင့်များကို ဂျီသြမေတြီ မဟုတ်သော စာသားအဖြစ် ရေးထားနိုင်ပါသည်။ {{ui:Linework}} ဒိုင်ယာလော့ခ်ရှိ **Survey levels and check** အပိုင်း (အောက်ပါ [DWG သို့မဟုတ် DXF ကို linework အဖြစ် ဖွင့်ခြင်း](topic:open-dwg-dxf) ကို ကြည့်ပါ) က ထိုအမြင့်များကို ဖတ်ပြီး မည်သို့ မှားနေသည်ကို မထည့်မီ ပြောပြပါသည်။

## စာသား သို့မဟုတ် attributes အဖြစ် ရေးထားသော အမြင့်များ

survey drawing များစွာတွင် spot level ကို ကြယ်ပွင့်ပုံ (cross) ၏ ဘေးရှိ `104.37` သို့မဟုတ် `EL 104.37` ကဲ့သို့ စာသားငယ်အဖြစ်၊ သို့မဟုတ် point block ၏ attribute အဖြစ် ပေးထားပါသည်။ ၎င်းတို့သည် မျဉ်းများ မဟုတ်သဖြင့် linework reader က ချန်ထားပါသည်။ အပိုင်းက တွေ့ရှိသော အရေအတွက်ကို ပြပြီး ၎င်းတို့ကို **survey points** အဖြစ် ယူခွင့် ပေးပါသည်:

1. **Take … levels as survey points** ကို အမှန်ခြစ်ပါ။ ၎င်းတို့သည် မူလ အမှန်ခြစ်မထားပါ၊ အကြောင်းမှာ drawing ရှိ ဂဏန်းတိုင်းသည် အမြင့်မဟုတ်သောကြောင့်ပါ။
2. စာသားကို အမြင့်တစ်ခုအဖြစ် တစ်ခုတည်း ရှိမှသာ ဖတ်ပါသည်: ဒဿမပိုင်းပါသော ဂဏန်း (`104.37`၊ `+104,37`၊ `-3.50`)၊ သို့မဟုတ် `EL`၊ `ELEV`၊ `RL`၊ `FFL`၊ `GL`၊ `TW`၊ `BW`၊ `INV`၊ `Z` သို့မဟုတ် `LEVEL` နောက်ရှိ ဂဏန်း၊ နောက်တွင် ရွေးချယ်စရာ `m`၊ `ft` သို့မဟုတ် `'`။ ဂဏန်းတစ်ခုတည်း (`12`) ကို အမြင့်မဟုတ်ဘဲ lot သို့မဟုတ် sheet နံပါတ်အဖြစ် ဖတ်ပါသည်၊ `GATE 3` ကဲ့သို့ စာသား သို့မဟုတ် ရက်စွဲကို ဘယ်တော့မှ မဖတ်ပါ။ စာသား ဖော်မတ်ကုဒ်များကို လျစ်လျူရှုပါသည်။
3. block attributes အတွက် **Block attribute that holds the level** ကို ရွေးပါ။ CivilCraft က ELEV၊ Z၊ LEVEL၊ RL စသည့် tag ကို ကိုယ်တိုင် ရှာပါသည်; drawing က ကိုယ်ပိုင် tag သုံးထားပါက စာရင်းမှ တစ်ခုကို ရွေးပါ။ ရွေးချယ်မှုကို ဤကွန်ပျူတာပေါ်ရှိ ထို file name အတွက် မှတ်ထားပြီး၊ ထို့ကြောင့် နောက်တစ်ကြိမ် ဖွင့်သည့်အခါ တူညီသော tag မှ စပါမည်။ သင်ရွေးသော tag သည် ဂဏန်းပြည့်များကိုလည်း အမြင့်အဖြစ် ယူပါသည်။
4. {{ui:Add}} ကို နှိပ်ပါ။ points များကို ပရောဂျက်ရှိ အမြင့်ဆုံး နံပါတ်ပြီးနောက် နံပါတ်ပေးပြီး၊ point တစ်ခုစီကို ၎င်း၏ layer (သို့မဟုတ် block) ဖြင့် ဖော်ပြကာ၊ အမြင့်များကို drawing ၏ အခြားအရာများကဲ့သို့ ပရောဂျက်ယူနစ်သို့ ပြောင်းပါသည်။ အားလုံးသည် အဆင့်တစ်ခုတည်းဖြစ်ပြီး {{key:Mod+Z}} ဖြင့် points များကို ဖယ်ရှားနိုင်ပါသည်။

စာသားသည် ၎င်း၏ ကိုယ်ပိုင် insertion point (သို့မဟုတ် ပါဝင်ပါက alignment point) တွင် ရှိပါသည်။ block အတွင်းရှိ စာသားကို မဖတ်ပါ၊ drawing ကို ဘယ်တော့မှ မပြောင်းပါ။

## စစ်ဆေးခြင်း

စစ်ဆေးမှုသည် သင်ယူတော့မည့်အရာပေါ်တွင် လည်ပတ်ပြီး တွေ့ရှိသည်များကို ပြဿနာအမျိုးအစားတစ်ခုစီအလိုက် တစ်ကြောင်းစီ စာရင်းပြုစုပါသည်:

| ဘာပြောသလဲ | ဘာကိုဆိုလိုသလဲ |
|---|---|
| **Units not stated** | drawing က ၎င်း၏ယူနစ်ကို မဖော်ပြထားပါ၊ ထို့ကြောင့် ၎င်း၏ ဂဏန်းများကို ပရောဂျက်ယူနစ်အဖြစ် ဖတ်ပါသည်။ သင်သိသော အကွာအဝေးတစ်ခုကို စစ်ဆေးပါ။ |
| **Units converted** | drawing ၏ ယူနစ်များသည် ပရောဂျက်နှင့် ကွဲပြားပြီး စကေးချိန်ညှိထားပါသည် (မှတ်ချက် ဖြစ်ပြီး အမှား မဟုတ်ပါ)။ |
| **The data spans … km** သို့မဟုတ် **… m** | အကျယ်အဝန်းသည် 200 km ထက် ကြီးသည် သို့မဟုတ် တစ်ဝက်မီတာထက် သေးသည်၊ ၎င်းသည် မှားသော ယူနစ် (မီလီမီတာကို မီတာအဖြစ် ဖတ်ခြင်း၊ သို့မဟုတ် ပြောင်းပြန်) ဖြစ်နိုင်ပါသည်။ |
| **No coordinate system** | ပရောဂျက်တွင် မရှိပါ။ state plane သို့မဟုတ် national grid coordinates ကဲ့သို့ ဒေတာသည် သုညမှ ဝေးနေသောအခါ သတိပေးချက် ဖြစ်ပါသည်။ [Coordinate systems](topic:coordinate-systems) ကို ကြည့်ပါ။ |
| **Far from the origin** | ဒေတာသည် သုညမှ 100 km ထက် ဝေးသည်။ သုညမှ ဝေးသောအခါ 3D view များနှင့် export များသည် တိကျမှု ဆုံးရှုံးပြီး တုန်ခါပါသည်။ |
| **Contour layer … has no height** | contours ဟု အမည်ပေးထားသော layer (TOPO၊ CONT၊ CNTR၊ CONTOUR) တွင် အမြင့် 0 ရှိသော မျဉ်းများ ရှိပြီး၊ ၎င်းမှ တည်ဆောက်သော မြေပြင်သည် ပြားနေမည်။ |
| **Levels exactly 0** | အမြင့်အချို့သည် 0 ဖြစ်ပြီး ပုံမှန်အမြင့်မှာ ထိုမှ ဝေးနေသည်: အမြင့်များ ပျောက်နေနိုင်ပါသည်။ |
| **Levels far from the rest** | အမြင့်အနည်းငယ်သည် အခြားများမှ အလွန်ဝေးနေသည် (အမြင့်အားလုံး၏ အလယ်ဗဟိုနှင့် နှိုင်းယှဉ်ထားသည်၊ ထို့ကြောင့် ကျယ်ပြန့်သော အမြင့်ရှိသည့် စောက်စိမ်းဆိုက်ကို အမှတ်အသား မပြုပါ)၊ သို့မဟုတ် 9,000 m အထက် သို့မဟုတ် -11,000 m အောက်။ |
| **Points on top of another point** | နေရာတူတွင် point နှစ်ခု၊ အမြင့်တူ သို့မဟုတ် အမြင့်မတူ။ |

**Add** ကို နှိပ်ပြီးနောက် တူညီသော စာကြောင်းများသည် **Problems** သို့ ပို့ပါသည်၊ အမျိုးအစားတစ်ခုစီအတွက် တစ်ကြောင်းစီ၊ ဖိုင်အမည်ဖြင့်၊ ထို့ကြောင့် နောက်မှ ပြန်ကြည့်နိုင်ပါသည်။ စစ်ဆေးမှုသည် drawing ကို အကဲဖြတ်ပြီး ၎င်းထဲတွင် ဘာမျှ မပြောင်းပါ၊ drawing ကို အသုံးပြုခြင်းကိုလည်း မတားဆီးပါ။

:::tip
စစ်ဆေးမှုက contours များ 0 တွင် ပြားနေပြီး စာသားအဖြစ် ရေးထားသော အမြင့်များ ရှိသည်ဟု ပြောပါက၊ ထိုအမြင့်များကို survey points အဖြစ် ယူပါ: ၎င်းတို့တွင် contour လိုင်းများ မရှိသော အမှန်တကယ် အမြင့်များ မကြာခဏ ပါဝင်ပါသည်။
:::

## မစစ်ဆေးသော အရာများ

စစ်ဆေးမှုသည် drawing ကို ဒုတိယ survey နှင့် နှိုင်းယှဉ်ခြင်း မလုပ်ပါ၊ drawing သည် မည်သည့် coordinate system တွင် ရှိသည်ကိုလည်း မပြောနိုင်ပါ: သတ်မှတ်ထားခြင်း မရှိကြောင်းသာ ပြောပါသည်။

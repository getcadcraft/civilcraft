**ပုံစံ** ဆိုသည်မှာ တစ်ကြိမ် ဆွဲပြီး ပြန်သုံးသော အပိုင်းဖြတ်ပုံငယ်တစ်ခု ဖြစ်သည်: offset၊ slope နှင့် point code ပါသော အမှတ်များ၊ ပစ္စည်းပါသော ဒြပ်စင်များ။ ကော်ရီဒါကို စတေးရှင်အလိုက် ပုံစံများမှ တည်ဆောက်နိုင်သည်၊ ဘက်တစ်ခုစီတွင် ကိုယ်ပိုင် ကတ္တရာ ပုံစံများနှင့် ကိုယ်ပိုင် အဆုံးအခြေအနေ ရှိသည်၊ တူညီသော ပုံစံများကို မြေပြင်ပေါ် ဖြန့်ချနိုင်သည်။

:::warning
ဥပမာ ပုံစံများသည် စတင်ရန် နေရာယူ တန်ဖိုးများ ဖြစ်သည်။ ၎င်းတို့၏ နံပါတ်များကို စံ သို့မဟုတ် အေဂျင်စီမှ မယူထားပါ။ ဒီဇိုင်းတွင် အသုံးပြုမီ အင်ဂျင်နီယာတစ်ဦးက ပုံစံတိုင်းနှင့် ၎င်းအတွက် ပေးသော တန်ဖိုးတိုင်းကို စစ်ဆေးရမည်။
:::

## ပုံစံများကို ဖွင့်ရန်

{{ui:မျက်နှာပြင်}} › {{ui:နောက်ထပ်}} › {{ui:ကော်ရီဒါ ပုံစံများ…}} ကို ဖွင့်ပါ (သို့မဟုတ် {{cmd:TEMPLATES}} ကို ရိုက်ပါ)။ ဝင်းဒိုးတွင် စာရင်းသုံးခု ရှိသည်:

- **ဤပရောဂျက်တွင်**: ဤပရောဂျက်၏ ကော်ရီဒါများနှင့် မြေပြင် ပုံစံများ သုံးသော ပုံစံများ။ ၎င်းတို့ကို ပရောဂျက်ဖိုင်တွင် သိမ်းသည်။
- **ကျွန်ုပ်၏ စာကြည့်တိုက်**: ဤ browser တွင် သိမ်းထားပြီး ပရောဂျက်တိုင်းတွင် ပေးသော ပုံစံများ။ ပရောဂျက်ပုံစံတစ်ခုကို သိမ်းရန် ၎င်းပေါ်တွင် {{ui:ကျွန်ုပ်၏ စာကြည့်တိုက်သို့ သိမ်းရန်}} ကို သုံးပါ။
- **ဥပမာများ**: အလွှာပါသော လမ်းသွား နှစ်ခု၊ ဘောင်ခံ နှင့် ရေမြောင်း၊ ခြေလျင်လမ်း၊ နေ့ရောင်၊ မြောင်း၊ ထိန်းသိမ်းနံရံ၊ မြေပြင်အောက် မြေဆွေးမြေနု၊ နှင့် မြေပြင်ပေါ် ကတ္တရာ။ တစ်ခုစီကို "အင်ဂျင်နီယာက စစ်ဆေးရန်" ဟု အမှတ်အသားပြုထားသည်။

{{ui:ဤစီမံကိန်းတွင် သုံးရန်}} သည် စာကြည့်တိုက် သို့မဟုတ် ဥပမာ ပုံစံကို ပရောဂျက်သို့ ကူးသည်။ {{ui:ဤစီမံကိန်း၏ ပုံစံများကို ထုတ်ယူရန်}} က ၎င်းတို့ကို `.cctemplates.json` ဖိုင်အဖြစ် သိမ်းသည်၊ ထို့နောက် {{ui:ဖိုင်တင်ရန်}} က တစ်ခုကို ပရောဂျက်နှင့် ကျွန်ုပ်၏ စာကြည့်တိုက်သို့ ဖတ်သည်။ ပုံစံများကို မျှဝေရန် သို့မဟုတ် အခြားကွန်ပျူတာသို့ ရွှေ့ရန် ဖိုင်ကို သုံးပါ။

## ပုံစံတစ်ခု ဖန်တီးရန်

{{ui:ပုံစံအသစ်}} (သို့မဟုတ် ပရောဂျက်ပုံစံပေါ်ရှိ {{ui:တည်းဖြတ်ရန်}}) က ပုံစံ တည်းဖြတ်သူကို ဖွင့်သည်။ ညာဘက်ခြမ်းကို ပုံစံ၏ 0,0 အမှတ်မှ အပြင်သို့ ဆွဲပါ; ဘယ်ဘက်ခြမ်းသည် တူညီသော ပုံစံကို ဘယ်ဘက်အပြင်သို့ သုံးသည်။

1. အမည်နှင့် အမျိုးအစား ပေးပါ: **ကတ္တရာ** (နောက်ပုံစံက ၎င်း၏ အဆုံးတွင် ချိတ်သည်)၊ **အဆုံးအခြေအနေ** (မြေပြင်ကို ထိသည်) သို့မဟုတ် **မြေပြင် ပုံစံ**။
2. **တန်ဖိုးများ** ထည့်ပါ: အကျယ် `w` သို့မဟုတ် slope `s` ကဲ့သို့ အမည်ပေးထားသော ဂဏန်းများ။ ပုံစံ မည်သည့်နေရာတွင်မဆို ဂဏန်းအကွက်သည် ဂဏန်း သို့မဟုတ် တန်ဖိုး အမည်ကို လက်ခံသည်; `-t` သည် အနုတ်လုပ်ထားသော `t` တန်ဖိုး ဖြစ်သည်။ ကော်ရီဒါတစ်ခုသည် ပုံစံ၏ အသုံးပြုမှုတိုင်းကို ကိုယ်ပိုင် တန်ဖိုးများ ပေးနိုင်သည်၊ ထို့ကြောင့် ဘောင်ခံ ပုံစံတစ်ခုသည် ဘောင်ခံ အမြင့်တိုင်းကို ဝန်ဆောင်သည်။
3. **အမှတ်များ** ကို အစဉ်လိုက် ထည့်ပါ။ တစ်ခုစီကို ၎င်း၏ ကန့်သတ်ချက်ဖြင့် အစောပိုင်း အမှတ် (သို့မဟုတ် 0,0 အမှတ်) မှ နေရာချသည်:

| ကန့်သတ်ချက် | အမှတ်ကို နေရာချသည် |
|---|---|
| Slope ဖြင့် offset | အပြင်သို့ offset နှင့် slope (run တစ်ခုလျှင် rise; −0.02 သည် 2% ကျသည်) |
| Offset နှင့် rise | offset နှင့် rise |
| အထက် သို့မဟုတ် အောက် တည့်တည့် | rise တစ်ခုတည်းသာ |
| မြေပြင်သို့ Side slope | အမှတ်မှ မြေပြင်သို့ အပြင်ထွက်၊ မြေပြင် အထက်ရှိသည့်နေရာတွင် cut ratio၊ အောက်ရှိသည့်နေရာတွင် fill ratio |
| မြေပြင်သို့ | offset ပြီးနောက် မြေပြင်သို့ တည့်တည့် အထက် သို့မဟုတ် အောက် |
| ထိန်းသိမ်းနံရံ | သင်ပေးသော အထူ၏ နံရံ: cut တွင် ၎င်း၏ အထက်သည် လမ်းမျက်နှာစွပ်တွင် မြေပြင်ကို ထိသည်၊ fill တွင် လမ်းသည် ၎င်းပေါ်မှ ဖြတ်သွားပြီး ၎င်း၏ အပြင်မျက်နှာသည် မြေပြင်သို့ ကျသည် |

   ပြီးသော မျက်နှာပြင် ဖြတ်သွားသည့် အမှတ်များအတွက် **Top** ကို အမှန်ခြစ်ပါ။ နောက်ဆုံး top အမှတ်သည် ထိုဘက်ရှိ နောက်ပုံစံ စတင်သည့်နေရာ ဖြစ်သည်။ **Target** က ကော်ရီဒါက အမှတ်ကို ရွှေ့ခွင့်ပြုသည်: ၎င်း၏ offset သို့မဟုတ် အမြင့်သည် မျဉ်းတစ်ခုမှ လာသည်။
4. **ဒြပ်စင်များ** ထည့်ပါ: point code များမှတစ်ဆင့် ပိတ်ထားသော ပုံသဏ္ဍာန်များ (`0` သည် 0,0 အမှတ်ဖြစ်သည်)၊ တစ်ခုစီတွင် အမည်၊ ပစ္စည်းနှင့် အမျိုးအစား ရှိသည်။ ၎င်းတို့၏ ဧရိယာများက ထုထည်များကို ပေးသည်။

ပုံဆွဲချက်သည် ပြောင်းလဲမှုတိုင်းကို အမှန် စကေးအတိုင်း လိုက်သည်၊ ၎င်းအောက်ရှိ စာရင်းက မှားနေသည်ကို ပြောသည် (အဆုံးမတိုင်မီ မြေပြင်ကို ထိသော အမှတ်၊ ပုံစံတွင် မရှိသော တန်ဖိုး၊ ဧရိယာ မရှိသော ဒြပ်စင်)။ {{ui:ဤပရောဂျက်သို့ ထည့်ရန်}} သို့မဟုတ် {{ui:သိမ်းရန်}} က ၎င်းကို ပြန်ဖျက်ရန် အဆင့်တစ်ခုအဖြစ် သိမ်းသည်။

## ပုံစံများမှ ကော်ရီဒါ တည်ဆောက်ရန်

ကော်ရီဒါပါသော alignment ကို ရွေးပြီး ၎င်း၏ ဂုဏ်သတ္တိများတွင် {{ui:စတေးရှင်အလိုက် ပုံစံများမှ တည်ဆောက်ရန်}} ကို ဖွင့်ပါ။ ကော်ရီဒါသည် ဘက်နှစ်ဖက်စလုံးတွင် လမ်းသွား နှစ်ခုနှင့် နေ့ရောင် ဥပမာများဖြင့် စတင်သည်။

- **ဒေသများ။** ဒေသတိုင်းသည် စတေးရှင်တစ်ခုတွင် စတင်ပြီး နောက်ဒေသ၏ စတေးရှင်အထိ ဆက်သွားသည်။ {{ui:ဒေသတစ်ခု ထည့်ရန်}} က တစ်ခု ထည့်သည်; ၎င်း၏ ဘောက်စ်တွင် စတင်စတေးရှင်ကို ပြောင်းပါ။
- **ဘယ်နှင့် ညာ သီးခြား။** ဒေသတိုင်းရှိ ဘက်တိုင်းတွင် ကိုယ်ပိုင် **ကတ္တရာ** စာရင်း ရှိသည် (centerline မှ အပြင်သို့)၊ ကိုယ်ပိုင် **အဆုံးအခြေအနေ** ရှိသည်: နေ့ရောင်၊ မြောင်း၊ နံရံ၊ သို့မဟုတ် မြေပြင်ကို ထိသော မည်သည့် ပုံစံ။ အဆုံးအခြေအနေ မရှိပါက ဘက်သည် ကော်ရီဒါ၏ cut နှင့် fill slope များတွင် နေ့ရောင်ထွက်သည်။ {{ui:ဘယ်မှ ညာသို့ ကူးရန်}} က ဘက်တစ်ခုကို ကူးသည်။
- **တန်ဖိုးများနှင့် ပစ်မှတ်များ။** ဘက်ပေါ်ရှိ ပုံစံတိုင်းအောက်တွင် တန်ဖိုးတစ်ခုစီအတွက် ဘောက်စ် (ဗလာ = ပုံစံ၏ ကိုယ်ပိုင် တန်ဖိုး) နှင့် ပစ်မှတ်ယူသော အမှတ်အတွက် ၎င်းကို ရွှေ့သော feature line သို့မဟုတ် အခြားကော်ရီဒါ၏ မျဉ်း။
- **From နှင့် To** က ကော်ရီဒါကို alignment ၏ အစိတ်အပိုင်းသို့ ကန့်သတ်သည်။

အပိုင်းဖြတ်များ၊ point code တိုင်းအတွက် အစီအစဉ်မျဉ်းများ၊ အဆိုပြုမျက်နှာပြင်၊ staking နှင့် မြေလုပ်ငန်း အားလုံး လိုက်သည်။ ဂုဏ်သတ္တိများက ဘက်နှင့် ဒေသအလိုက် ဒြပ်စင်တစ်ခုစီ၏ ထုထည်ကို ပြသည် (centerline တလျှောက် ပျမ်းမျှ အဆုံးဧရိယာများ)။ ကော်ရီဒါကို ပုံစံများမှ တည်ဆောက်နေစဉ် Superelevation နှင့် ကော်ရီဒါ၏ အစွန်း ပစ်မှတ်များကို အသုံးမပြုပါ။

## alignment တစ်ခုပေါ်ရှိ ကော်ရီဒါ အများအပြား

**ဤ alignment ရှိ ကော်ရီဒါများ** အောက်တွင် {{ui:ကော်ရီဒါတစ်ခု ထည့်ရန်}} က alignment ၏ ကျန်ရှိသော အပိုင်းပေါ်တွင် ကော်ရီဒါတစ်ခု ထည့်သည်: ပထမကော်ရီဒါသည် အလယ်တွင် အဆုံးစတေးရှင်ကို ရရှိသည် (သို့မဟုတ် ၎င်း၏ ကိုယ်ပိုင်ကို ထိန်းသည်)၊ ပြီးလျှင် အသစ်သည် ထိုနေရာမှ ပထမကော်ရီဒါ၏ နောက်ဆုံး ဒေသ ပုံစံများဖြင့် စတင်သည်။ ကော်ရီဒါတိုင်းတွင် ကိုယ်ပိုင် အမည်၊ စတေးရှင် အကွာအဝေး၊ ပုံစံများနှင့် မြေလုပ်ငန်း ရှိသည်။ တစ်ခုကို {{ui:ဖွင့်}} ဘောက်စ်ဖြင့် ပိတ်ပါ။ အကွာအဝေး နှစ်ခု ထပ်နေလျှင် နောက်ကော်ရီဒါသည် ရှေ့ကော်ရီဒါပေါ်တွင် မြေညီအောင် လုပ်သည်။

## မြေပြင် ပုံစံများ

မြေပြင် ပုံစံသည် ပုံစံ၏ အလွှာများကို 0,0 အမှတ်မှ မြေပြင်ပေါ် ဖြန့်ချသည်: 0,0 အမှတ်အောက်ရှိ အလွှာသည် မြေအတွင်းသို့ ဝင်သည် (ဖယ်ရမည့် မြေဆွေးမြေနု)၊ အထက်ရှိ အလွှာသည် မြေပြင်ပေါ် ထိုင်သည် (ကားရပ်နေရာပေါ်ရှိ အခြေနှင့် ကတ္တရာ)။ အကျယ်နှင့် slope များသည် အရေးမကြီးပါ၊ ဒြပ်စင်တစ်ခုစီ၏ 0,0 အမှတ်အထက် သို့မဟုတ် အောက်ရှိ အနက်သာ အရေးကြီးသည်။

{{ui:မျက်နှာပြင်}} › {{ui:နောက်ထပ်}} › {{ui:မြေပြင် ပုံစံများ…}} ကို ဖွင့်ပါ (သို့မဟုတ် {{cmd:TERRAINTEMPLATES}} ကို ရိုက်ပါ); block သည် ပရောဂျက်၏ ဂုဏ်သတ္တိများတွင်လည်း ရှိသည်။ {{ui:မြေပြင်ပုံစံ ထည့်ရန်}} က မြေဆွေးမြေနု ဥပမာဖြင့် တစ်ခု ထည့်သည်။ တစ်ခုစီအတွက် ရွေးပါ:

- **ပုံစံ** (၎င်း၏ တန်ဖိုးများကို ဤတစ်ခုအတွက် ပြောင်းနိုင်သည်)၊
- **မြေပြင်**: လက်ရှိ မြေပြင် သို့မဟုတ် အဆိုပြု မျက်နှာပြင်၊
- ဖြတ်သော **ပုံသဏ္ဍာန်**: မြေပြင်တစ်ခုလုံး၊ မြေကွက်၊ ခင်းကျင်းမြေ သို့မဟုတ် ပိတ်ထားသော feature line။ မြေပြင် ပုံစံများ အများအပြားသည် တူညီသော မြေပြင်ပေါ်တွင် မတူသော ပုံသဏ္ဍာန်များ သုံးနိုင်သည်။

အလွှာတစ်ခုစီသည် အထူ၊ အစီအစဉ် ဧရိယာနှင့် ထုထည်ကို ပြသည်။ ထုထည်သည် အစီအစဉ်ဧရိယာ × အထူ ဖြစ်ပြီး အထူကို တိုက်ရိုက် အောက်သို့ တိုင်သည်; ဧရိယာကို ဂရစ်ပေါ် တိုင်သည်၊ ဖြန့်ချထားသော (slope) ဧရိယာကိုလည်း ပေးသည်။ ပုံသဏ္ဍာန်များကို C-TOPO-TMPL အလွှာပေါ်ရှိ အစီအစဉ်တွင် ဆွဲသည်။ မြေပြင် ပုံစံများသည် အဆိုပြု မျက်နှာပြင်ကို မပြောင်းပါ။

## ပစ္စည်းများနှင့် ပမာဏများ

ပရောဂျက်၏ Earthwork block သည် **ပုံစံများမှ ပစ္စည်းများ** ကို စာရင်းပြုသည်: ကော်ရီဒါ ဒြပ်စင်နှင့် မြေပြင် ပုံစံ အလွှာတိုင်း ထုထည်ဖြင့်။ {{ui:TakeoffCraft သို့ ပို့ရန်}} က cut နှင့် fill ပြီးနောက် ၎င်းတို့ကို ပမာဏ ဖိုင်ထဲ ရေးသည်၊ ပစ္စည်းတစ်ခုစီ၊ ကုဗယားဒ် (ပေပရောဂျက်) သို့မဟုတ် ကုဗမီတာဖြင့်။

## ဖိုင်များ

ပုံစံများ၊ ဒေသများ၊ အပို ကော်ရီဒါများနှင့် မြေပြင် ပုံစံများကို ပရောဂျက်ဖိုင်တွင် သိမ်းသည်။ ၎င်းတို့ကို မသုံးသော ပရောဂျက်ကို ယခင်အတိုင်း သိမ်းသည်၊ ဟောင်း CivilCraft ဗားရှင်းများသည် ၎င်းတို့ကို သုံးသော ပရောဂျက်ကို ဖွင့်နိုင်သည် (ပုံစံများကို လျစ်လျူရှု၍ ကော်ရီဒါ၏ ကိုယ်ပိုင် assembly ကို တည်ဆောက်သည်)။

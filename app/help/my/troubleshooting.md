စာများသည် အောက်ညာဘက် status bar၊ ဘယ်နှင့် ညာ panel များရှိ အကွက်များနှင့် dialog များတွင် ပေါ်သည်။ ၎င်းတို့ကို အက်ပ်က ပြသသည့်အတိုင်း ဤတွင် ကိုးကားထားသည်။

## ဖိုင်များ ဖွင့်ခြင်း

**"ဤဖိုင်သည် 200 MB ထက် ကြီးသည်; CivilCraft သည် ယခုအချိန်တွင် ထိုသို့ကြီးသော ဖိုင်များကို မဖွင့်နိုင်သေးပါ။"**
point ဖိုင်ကို ခွဲပါ၊ သို့မဟုတ် ဖွင့်ခြင်းမပြုမီ data ကို လျှော့ပါ။

**"site.json ကို ဖွင့်၍ မရပါ: ဤသည်မှာ CivilCraft project ဖိုင် မဟုတ်ပါ။"**
ဖိုင်သည် `.json` ဖြင့် အဆုံးသတ်သည် သို့မဟုတ် `{` ဖြင့် စသော်လည်း CivilCraft project မဟုတ်ပါ။ point ဖိုင်များသည် `{` ဖြင့် မစရပါ။

**"ဖွင့်၍ မရပါ … ဤ project ဖိုင်သည် CivilCraft အသစ် (version 2) မှ ဖြစ်သည်။"**
project ကို နောက်ဆုံးဗားရှင်းမှ သိမ်းထားသည်။ ထိုနေရာတွင် ဖွင့်ပါ၊ သို့မဟုတ် ၎င်းမှ LandXML ထုတ်ပါ။

**"ဖွင့်၍ မရပါ … ၎င်းသည် XML ဖြစ်သော်လည်း LandXML မဟုတ်ပါ (root element သည် <…> ဖြစ်သည်)။"**
ဖိုင်သည် အခြားအမျိုးအစား XML ဖြစ်သည်။ အခြား program မှ LandXML ထုတ်ပါ။

**"… တွင် CivilCraft ဖတ်နိုင်သော point၊ TIN surface သို့မဟုတ် alignment မရှိပါ။"**
ဖိုင်ထဲရှိ အရာအားလုံးကို CivilCraft က ကျော်သွားသည် (ဥပမာ grid surface သာ၊ သို့မဟုတ် spiral alignment သာ)။ ကျန်စာသားက ဘာရှိသည်ကို ပြောသည်။ [LandXML- ဖတ်ခြင်းနှင့် ရေးခြင်း](topic:landxml-reference) ကို ကြည့်ပါ။

**"နမူနာကို load လုပ်၍ မရပါ: …"**
{{ui:နမူနာ ဆိုဒ်ကို ဖွင့်ရန်}} သည် CadCraft ဆိုဒ်မှ ဖိုင်ကို ဖတ်သည်။ ချိတ်ဆက်မှု မရှိလျှင် CivilCraft ကို အော့ဖ်လိုင်း အသုံးပြုရန် သိမ်းထားမှသာ အလုပ်လုပ်သည် (app bar ခလုတ်တွင် {{ui:အော့ဖ်လိုင်း အဆင်သင့်}} ပြသသည်)။ အင်တာနက်သို့ ချိတ်ပြီး {{ui:အော့ဖ်လိုင်းအတွက် သိမ်းရန်}} ကို နှိပ်ပါ၊ ထို့နောက် အော့ဖ်လိုင်းတွင်ပါ အလုပ်လုပ်မည်။ [အော့ဖ်လိုင်း](common:offline) ကို ကြည့်ပါ။

**{{ui:အော့ဖ်လိုင်းအတွက် သိမ်းရန်}} သည် {{ui:သိမ်း၍ မရပါ}} ပြသသည်။**
ဖိုင်အချို့ ဒေါင်းလုဒ်မလုပ်ရသေးပါ။ ချိတ်ဆက်မှုကို စစ်ပြီး ခလုတ်ကို ထပ်နှိပ်ပါ။

**{{ui:အော့ဖ်လိုင်းအတွက် သိမ်းရန်}} သည် {{ui:အော့ဖ်လိုင်း မရနိုင်ပါ}} ပြသသည်။**
ဤ browser window တွင် အော့ဖ်လိုင်းမိတ္တူ မသိမ်းနိုင်ပါ၊ များသောအားဖြင့် private window ဖြစ်သည် သို့မဟုတ် ကွန်ပျူတာကို စီမံထားသည်။ ပုံမှန် window တွင် CivilCraft ကို ဖွင့်ပါ။

**အော့ဖ်လိုင်းတွင် အက်ပ် လုံးဝ မဖွင့်ပါ။**
browser ဤနေရာတွင် အော့ဖ်လိုင်းအတွက် မသိမ်းထားခဲ့ပါ၊ သို့မဟုတ် browser က site data ကို ရှင်းလင်းခဲ့သည် (Safari သည် ရက်သတ္တပတ်အနည်းငယ် မလည်ပတ်သော site များကို ဤသို့ လုပ်သည်)။ အင်တာနက်သို့ ချိတ်ပြီး CivilCraft ကို ဖွင့်ကာ {{ui:အော့ဖ်လိုင်းအတွက် သိမ်းရန်}} ကို နှိပ်ပါ။

**အော့ဖ်လိုင်းမိတ္တူသည် ဗားရှင်းဟောင်း ဖြစ်နေသည်။**
{{ui:အော့ဖ်လိုင်း အဆင်သင့်}} ကို နှိပ်ပြီး အင်တာနက်ရှိစဉ် {{ui:ထပ်သိမ်းရန် (နောက်ဆုံးဗားရှင်း ယူရန်)}} ကို နှိပ်ပါ။

**ဖွင့်သည့်အကွက်တွင် ဖိုင်သည် မှိုင်းနေသည်။**
အကွက်သည် point ဖိုင်များ၊ LandXML နှင့် project ဖိုင်များကိုသာ ၎င်းတို့၏ အဆုံးသတ်ဖြင့် ပြသသည်။ ဖိုင်ကို plan ပေါ်သို့ ဆွဲချပါ၊ သို့မဟုတ် `.txt` ဟု အမည်ပြောင်းပါ။

## point များ သွင်းခြင်း

**"ဤဖိုင်မှ point တစ်ခုမှ ဖတ်၍ မရပါ။"**
**Columns** တွင် ကော်လံအစဉ်ကို ကိုယ်တိုင် ရွေးပါ။ မရလျှင် ဖိုင်ကို စာသားတည်းဖြတ်ကိရိယာဖြင့် ဖွင့်ပြီး စာကြောင်းတစ်ကြောင်းတွင် point တစ်ခု၊ နံပါတ်များပါရှိခြင်းကို စစ်ပါ။

**site သည် ပုံပြောင်းနေသည်၊ လှည့်နေသည် သို့မဟုတ် မျဉ်းတစ်ကြောင်းအဖြစ် ဆန့်နေသည်။**
Northing နှင့် easting လဲလှယ်ထားသည်။ အနှစ်ချုပ်တွင် "ကော်လံအရေအတွက်ဖြင့် ခန့်မှန်းထားသည်" ဟု ပြောခဲ့သည်။ **Columns** တွင် PNEZD အစား PENZD (သို့မဟုတ် ဆန့်ကျင်ဘက်) ကို ရွေးပါ၊ သို့မဟုတ် ထပ်သွင်းပါ။

**point များသည် အခြားများနှင့်ဝေးနေပြီး plan သည် အစက်တစ်ခုအထိ ချဲ့ထွက်သွားသည်။**
အတန်းတစ်ခုတွင် coordinate စာလုံးပေါင်း အမှားရှိသည် သို့မဟုတ် ဖိုင်သည် coordinate system များ ရောနှော်ထားသည်။ point ကို ရှာပါ (နံပါတ်ကြည့်ရန် နှိပ်ပါ) ပြီး ဖိုင်ကို ပြင်ပါ။

**"Rows not read" အောက်ရှိ အတန်းများ။**
[survey point များ သွင်းခြင်း](topic:import-points#rows-that-are-not-read) ရှိ ဇယားကို ကြည့်ပါ။

**ကျွန်ုပ်၏ အဟောင်း point များ ပျောက်သွားသည်။**
point ဖိုင် သွင်းခြင်းသည် point အားလုံးကို အစားထိုးပြီး undo ကို ရှင်းလင်းသည်။ ပြန်ယူရန် သိမ်းထားသော project ကို ဖွင့်ပါ။

## မျက်နှာပြင်

**"Surface: Not built" နှင့် အနီရောင်ဘောက်စ်။**
ဘောက်စ်က အကြောင်းပြချက်ကို ပြသည်- "A surface needs at least three points with elevations.", "The points are all on one line: no triangles.", "No points with elevations.", "The boundary does not overlap the points." သို့မဟုတ် "No triangles are left inside the boundary."။ ကော်လံအစဉ်၊ point အုပ်စုများ ({{ui:ချန်ထားရန်}} ဖြစ်နေသလား) နှင့် boundary ကို စစ်ပါ။

**Contour များသည် ကျွန်းအစွန်း သို့မဟုတ် တောင်ကြောကို ဖြတ်ပြီး ဖြတ်သည်။**
ထိုမျဉ်းသည် breakline မဟုတ်ပါ။ ၎င်း၏ အုပ်စုကို {{ui:Breakline}} ဟု သတ်မှတ်ပါ၊ သို့မဟုတ် {{ui:Breakline}} tool ဖြင့် ဆွဲပါ။ [မျက်နှာပြင် တည်ဆောက်ပြီး ပြင်ဆင်ခြင်း](topic:build-surface) ကို ကြည့်ပါ။

**breakline အုပ်စုသည် zig-zag ဆွဲသည်။**
အုပ်စုတွင် မျဉ်းတစ်ကြောင်းထက်ပို၍ ရှိသည် သို့မဟုတ် ၎င်း၏ point များသည် မျဉ်းတလျှောက် နံပါတ်မတပ်ထားပါ။ အုပ်စုကို {{ui:အမှတ်များ}} သို့ ပြန်သတ်မှတ်ပြီး မျဉ်းတစ်ကြောင်းစီကို {{ui:Breakline}} tool ဖြင့် ဆွဲပါ။

**ပြင်ပအစွန်းတလျှောက် ရှည်ပြီး ပါးသော တြိဂံများ။**
boundary တစ်ခု ({{key:O}}) ဆွဲပါ၊ သို့မဟုတ် **အပြင်ဘက် အရှည်ဆုံး အစွန်း** ကို သတ်မှတ်ပါ။

**မျက်နှာပြင် တည်ဆောက်ပြီးသော်လည်း contour မရှိပါ။**
**Display** အောက်တွင် {{ui:ကွန်တိုင်များ}} ပိတ်ထားသည်၊ သို့မဟုတ် အကွာအဝေးသည် အလွန်သေးသဖြင့် contour အဆင့် 2,000 ထက် ပိုလာမည်။ ပိုကြီးသော အကွာအဝေးကို ရွေးပါ။

**breakline သို့မဟုတ် boundary များက ဘာမျှ မပြောင်းပါ။**
မျက်နှာပြင်သည် LandXML မှ ဖြစ်သည် ("Surface (from LandXML)")။ ၎င်းကို ရှိသည့်အတိုင်း သုံးသည်။ point များမှ တည်ဆောက်ရန် {{ui:အမှတ်များမှ မျက်နှာပြင်ကို ပြန်တည်ဆောက်ရန်}} ကို နှိပ်ပါ။

**"There is no surface yet: open survey points first."**
Breakline၊ boundary နှင့် pad သည် မြေပြင် မျက်နှာပြင် ရှိရန် လိုအပ်သည်။ point များကို အရင်သွင်းပါ။

**"Click a survey point with an elevation: a breakline takes the points' elevations."**
{{ui:Breakline}} tool သည် survey point များကိုသာ ရွေးသည်။ ဇူးမ်ချဲ့ပြီး point ပေါ်တွင် နှိပ်ပါ (လတ်တလော ယူမည့် point ကို လိမ္မော်ရောင် စတုရန်းက ပြသသည်)။

## ဆွဲခြင်း

**ဘာဆွဲသည့်အခါ နောက်ဆုံး point ပျောက်သွားသည်။**
ဤ build တွင် double-click သည် alignment၊ pad၊ breakline သို့မဟုတ် boundary ကို ပြီးစီးစေသော်လည်း double-click လုပ်ထားသော point ကို ချန်ထားသည်။ နောက်ဆုံး point ကို တစ်ကြိမ်နှိပ်ပြီး {{key:Enter}} ကို နှိပ်ပါ။ ဖြစ်ပြီးသားဆိုလျှင် {{key:Mod+Z}} ကို သုံးပြီး ထပ်ဆွဲပါ။

**tablet ပေါ်တွင် ဆွဲမှု မပြီးနိုင်ပါ။**
ပြီးစီးရန် {{key:Enter}} လိုသည်; on-screen ခလုတ် မရှိသေးပါ။ keyboard ချိတ်ပါ။ [မောက်စ်၊ trackpad နှင့် touch](topic:keyboard#mouse-trackpad-and-touch) ကို ကြည့်ပါ။

**point ထည့်ရန် ဆွဲသည့်အခါ plan ရွေ့သွားသည်။**
pixel အနည်းငယ်ထက် ပိုဆွဲလျှင် tool အားလုံးတွင် plan ကို ရွှေ့သည်။ မရွှေ့ဘဲ နှိပ်ပါ။

**"An alignment needs at least two points." / "A pad needs at least three corners." / "A pipe run needs at least two structures."**
{{key:Enter}} ကို စောလွန်းစွာ နှိပ်ခဲ့သည်။ ဆွဲမှုကို ပယ်ဖျက်ပြီး အစမှ ပြန်စပါ။

**A သို့မဟုတ် G ကဲ့သို့ ခလုတ်များ အလုပ်မလုပ်ပါ။**
panel ရှိ စာသားအကွက် သို့မဟုတ် စာရင်းသည် အာရုံရှိနေဆဲဖြစ်သဖြင့် စာလုံးများသည် ထိုနေရာသို့ ရောက်သည်။ plan ကို တစ်ကြိမ်နှိပ်ပြီး ခလုတ်ကို နှိပ်ပါ။ Mac တွင် delete ခလုတ်သည် browser အတွက် Backspace ဖြစ်သည်: ရွေးထားသည်ကို ဖျက်ရန် Fn နှင့် delete ကို သုံးပါ။

## alignment နှင့် profile များ

**"The curves at PI 2 and PI 3 overlap: … Use smaller radii."**
curve နှစ်ခုသည် ၎င်းတို့ PI များကြားရှိ tangent ထက် ပိုလိုအပ်သည်။ PI table တွင် radius တစ်ခု သို့မဟုတ် နှစ်ခုကို လျှော့ပါ၊ သို့မဟုတ် PI များကို ခွာပါ။

**"PI 3 turns straight back; it cannot take a curve."**
alignment သည် ထို PI တွင် ကိုယ်တိုင် ပြန်ကွေ့နေသည်။ PI ကို ရွှေ့ပါ သို့မဟုတ် ဖျက်ပါ။

**"This alignment has no ground under it to start from."**
alignment သည် မျက်နှာပြင်ပြင်ပတွင် ရှိသည်။ မျက်နှာပြင်ပေါ်သို့ ရွှေ့ပါ၊ သို့မဟုတ် {{ui:PVI များ ထည့်ရန်}} ကို ဖွင့်ပြီး နှိပ်၍ PVI များ ထည့်ပါ။

**"The vertical curve at PVI 3 (L = …) starts before the curve or PVI before it ends." / "… runs past the next PVI."**
curve အရှည်ကို တိုပါ သို့မဟုတ် PVI များကို ခွာပါ။

**"There is already a PVI at …"**
ထို station တွင် PVI ရှိပြီးသား ဖြစ်သည်။ နေရာတစ်ခြားကို နှိပ်ပါ၊ သို့မဟုတ် ရှိပြီးသားကို ဆွဲရွှေ့ပါ။

**profile view ဗလာဖြစ်သည်: "Draw an alignment to see its profile."**
alignment မရှိပါ၊ သို့မဟုတ် ရွေးထားသော alignment တွင် အမှားများရှိသည်။

## corridor နှင့် pad များ

**"The corridor needs a design profile without errors."**
design profile တစ်ခု စတင်ပါ ({{ui:မြေပြင်မှ စတင်ရန်}}) ပြီး curve overlap များကို ပြင်ပါ။

**"… side slopes run off the surface before meeting the ground." / "… slope lines run off the surface before meeting it …"**
grading သည် မြေပြင်ကို မတွေ့မီ မျက်နှာပြင်အစွန်းသို့ ရောက်သည်။ ဒီဇိုင်းကို အစွန်းမှ ဝင်ရွှေ့ပါ၊ သို့မဟုတ် မြေပြင်နှင့် ပိုနီးအောင် ယူလာပါ။ မျက်နှာပြင်အပြင်ဘက် တစ်စိတ်တစ်ပိုင်းတွင် ဆွဲထားသော pad အသစ်သည် elevation 0 မှ စနိုင်သည်: အမှန်တကယ် elevation ကို ရိုက်ထည့်ပါ။

**"The corridor's daylight lines cross …" / "The daylight line crosses itself …"**
မတူညီသော ဘက်များမှ slope များ တိုက်ဆိုင်နေသည်: curve တင်းကျပ်ခြင်း၊ pad ကျဉ်းခြင်း၊ နက်သော ဖြတ်ခြင်း သို့မဟုတ် မြင့်သော ဖြည့်ခြင်း။ radius ကြီးတစ်ခု၊ assembly ကျဉ်းတစ်ခု၊ pad ကျယ်တစ်ခု သို့မဟုတ် slope ပိုမတ်သော တစ်ခုကို သုံးပါ။

**"ထုထည် မရှိသေး: pad သည် ပြဿနာမရှိဘဲ ပြင်ဆင်ရမည်။"**
အထက်ရှိ အနီရောင်ဘောက်စ်တွင် ဖော်ပြထားသော ပြဿနာများကို ပြင်ပါ။

**{{ui:အဆင့်သတ်မှတ်ထားသော အစီအစဉ်}} မှိုင်းနေသည်။**
pad သို့မဟုတ် corridor တစ်ခုမျှ မပြင်ဆင်ရသေးပါ။

## ပိုက်များ

**"P2 has no inverts yet."**
{{ui:စည်းမျဉ်းအလိုက် ၎င်း၏ invert များ သတ်မှတ်ရန်}} ကို နှိပ်ပါ သို့မဟုတ် invert များကို ရိုက်ထည့်ပါ။

**"P1: no ground at S1 to start from."**
အထက်ရေစီးရှိ structure သည် မျက်နှာပြင်ပြင်ပတွင် ရှိပြီး rim မရှိပါ။ ၎င်းအတွက် rim ကို ရိုက်ထည့်ပါ။

**structure ရွှေ့ပြီးနောက် ပိုက်တိုင်း အမှတ်အသားပြုသည်။**
structure ရွှေ့ခြင်းသည် invert များကို မပြောင်းပါ။ {{ui:စည်းမျဉ်းအလိုက် invert အားလုံး သတ်မှတ်ရန်}} ကို နှိပ်ပါ။

ကွန်ရက်စာများအားလုံးကို [gravity ပိုက်ကွန်ရက် ဖော်ဆောင်ခြင်း](topic:pipe-network#read-and-fix-problems) တွင် ရှင်းပြထားသည်။

## သိမ်းခြင်းနှင့် ထုတ်ခြင်း

**"Nothing to export yet." / "Nothing to plot yet."**
project ဗလာဖြစ်သည်။ point များကို အရင်သွင်းပါ။

**သိမ်းထားသော ဖိုင်ကို ရှာမတွေ့ပါ။**
browser ၏ ဒေါင်းလုဒ်များ (များသောအားဖြင့် Downloads ဖိုင်တွဲ) တွင် ရှိသည်။ [ဖွင့်၊ သိမ်းနှင့် ထုတ်နိုင်သော ဖိုင်များ](topic:files#where-the-files-go) ကို ကြည့်ပါ။

**PDF အတိုင်းအတာ ကတ်ပြားပေါ်တွင် မှားနေသည်။**
100% သို့မဟုတ် actual size ဖြင့် ပရင့်ထုတ်ပါ၊ "fit to page" မဟုတ်ပါ။

**PDF စာသားတွင် မေးခွန်းအမှတ်များ ပေါ်သည်။**
နာမည် သို့မဟုတ် ဖော်ပြချက်များတွင် Western European အစုအဝေးပြင်ပ စာလုံးများ ပါသည်။ status စာက ၎င်းတို့ကို ရေတွက်သည်။ ရိုးရိုး စာလုံးများဖြင့် အမည်ပြောင်းပါ။

**plot သည် အစွန်းများတွင် ဖြတ်ထားသည်။**
အတိုင်းအတာသည် စာရွက်အတွက် ကြီးလွန်းသည်။ "(fits)" ဟု မှတ်ထားသော အတိုင်းအတာ၊ စာရွက်ကြီးတစ်ခု၊ သို့မဟုတ် {{ui:ဖန်သားပြင်ပေါ်ရှိအရာ}} ကို ရွေးပါ။

**{{key:Mod+P}} သည် browser ၏ print dialog ကို ဖွင့်ခဲ့သည်။**
စာမျက်နှာသည် အာရုံမရှိခဲ့ပါ။ dialog ကို ပိတ်ပါ၊ plan ကို နှိပ်ပြီး {{key:Mod+P}} ကို ထပ်နှိပ်ပါ၊ သို့မဟုတ် {{ui:PDF}} ကို နှိပ်ပါ။

## အက်ပ်ကိုယ်တိုင်

**မျက်နှာပြင် ဗလာဖြစ်သည် သို့မဟုတ် toolbar အလုပ်မလုပ်ပါ။**
Chrome၊ Edge၊ Firefox သို့မဟုတ် Safari ၏ လက်ရှိဗားရှင်းကို သုံးပြီး ပြန်လည် load လုပ်ပါ။ [browser များ](common:browsers) ကို ကြည့်ပါ။

**point ဖိုင်ကြီးဖြင့် အက်ပ် နှေးသည်။**
{{ui:တြိဂံများ}}၊ {{ui:အမှတ် အမည်ပေးချက်များ}} နှင့် {{ui:အမြင့်အဆင့်များ}} ကို ပိတ်ပါ၊ contour အကွာအဝေးကို ပိုကြီးအောင် သုံးပါ။ အလွန်ကြီးသော မျက်နှာပြင်များသည် ပြောင်းလဲမှုတိုင်းပြီးနောက် ပြန်တည်ဆောက်ရန် အချိန်ယူသည်။

**browser က "Leave site?" ဟု မေးသည်။**
project တွင် မသိမ်းရသေးသော ပြောင်းလဲမှုများ ရှိသည်။ ဆက်နေပါ၊ {{key:Mod+S}} ဖြင့် သိမ်းပြီးမှ ထွက်ပါ။

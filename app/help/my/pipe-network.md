Project တစ်ခုတွင် gravity pipe network တစ်ခု (storm သို့မဟုတ် sanitary) ရှိသည်။ ၎င်းသည် ဖွဲ့စည်းပုံများ (manhole၊ inlet) နှင့် ၎င်းတို့ကြား ဖြောင့်သော ပိုက်များဖြင့် ဖွဲ့ထားသည်။ စီးဆင်းမှုသည် သင်ဆွဲသော ဦးတည်ချက်အတိုင်း သွားသည်။ CivilCraft က ပိုက်နှင့် ဖွဲ့စည်းပုံတိုင်းကို သင်သတ်မှတ်ထားသော စည်းမျဉ်း သုံးခုဖြင့် စစ်ဆေးပြီး invert အားလုံးကို ထိုစည်းမျဉ်းများမှ သတ်မှတ်ပေးနိုင်သည်။

## လမ်းကြောင်းတစ်ခု ဆွဲခြင်း

မြေပြင်မရှိဘဲ ပိုက်များ ဆွဲနိုင်သည်၊ သို့သော် rim၊ cover နှင့် အလိုအလျောက် invert များအတွက် မြေပြင် လိုအပ်သည်။

1. {{key:P}} ကို နှိပ်ပါ၊ သို့မဟုတ် **Design** အုပ်စုရှိ {{ui:Pipes}} ကို နှိပ်ပါ။
   အရိပ်အမြွက်က "Pipes: လမ်းကြောင်း၏ ထိပ်မှ အောက်သို့ ဖွဲ့စည်းပုံများကို နှိပ်ပါ (ရှိပြီးသားတစ်ခုကို နှိပ်လျှင် ချိတ်ဆက်သည်)။ Enter က ပြီးဆုံးစေသည်။" ဟု ဖတ်ရသည်။
2. အထက်စီးရှိ ဖွဲ့စည်းပုံ ထားမည့်နေရာကို နှိပ်ပါ။ ဖွဲ့စည်းပုံတစ်ခု ထားသည်။
3. ရေစီးအောက်ဘက် ဖွဲ့စည်းပုံတစ်ခုစီကို နှိပ်ပါ။ ရှိပြီးသား ဖွဲ့စည်းပုံနှင့် ချိတ်ဆက်လိုလျှင် ၎င်းကို နှိပ်ပါ: အခြေအနေဘားက "Joined S3." ဟု ပြသည်။
4. {{key:Enter}} ကို နှိပ်ပါ။
   ပိုက်များကို ဆွဲပြီး၊ ၎င်းတို့၏ invert များကို စည်းမျဉ်းများမှ သတ်မှတ်ပြီး၊ အခြေအနေဘားက ဥပမာ "3 pipes drawn, 12 inverts set from the rules; every check passes." ဟု ပြသည်။

ဖွဲ့စည်းပုံအသစ်များကို S1၊ S2 … ဟု အမည်ပေးပြီး 48 in (1200 mm) အချင်းဖြင့် ထားသည်။ ပိုက်အသစ်များကို P1၊ P2 … ဟု အမည်ပေးပြီး 12 in (300 mm) အချင်းဖြင့် ထားသည်။ အချင်းများသည် feet project တွင် inch ဖြင့်၊ meter project တွင် millimeter ဖြင့် ဖြစ်သည်။

{{key:Enter}} ဖြင့် အဆုံးသတ်ပါ။ နှစ်ချက်နှိပ်ခြင်းလည်း အလုပ်လုပ်သည်၊ သို့သော် လမ်းကြောင်းကို ရှိပြီးသား ဖွဲ့စည်းပုံ ပေါ်တွင် နှစ်ချက်နှိပ်ပြီး ဖြတ်လျှင် ချိတ်ဆက်မှု ပျက်သွားသည်: တစ်ကြိမ်နှိပ်ပြီး {{key:Enter}} နှိပ်ပါ။

## သင့်စည်းမျဉ်းများ သတ်မှတ်ခြင်း

ဘာမျှ ရွေးမထားသောအခါ ညာဘက် panel (**Project**) တွင် **Pipe network** block ရှိသည်:

| ဆက်တင် | မူလတန်ဖိုး | အဓိပ္ပာယ် |
|---|---|---|
| Type | Storm | {{ui:Storm}} သို့မဟုတ် {{ui:Sanitary}}; LandXML သို့ ရေးသည် |
| Least slope | 0.50% | ပိုက်တိုင်းသည် အနည်းဆုံး ဤမျှ ကျရမည် |
| Least cover | 2 ft (0.6 m) | မြေပြင်မှ ပိုက်အမိုးအထိ၊ ပိုက်တလျှောက်လုံး |
| Drop in structures | 0.10 ft (0.03 m) | အထွက် invert သည် အဝင် invert တိုင်းထက် အနည်းဆုံး ဤမျှ နိမ့်ရမည် |

**ဤမူလတန်ဖိုးများသည် နေရာယူထားသော တန်ဖိုးများဖြစ်ပြီး စံသတ်မှတ်ချက် မဟုတ်ပါ။** သင့်အေဂျင်စီ သို့မဟုတ် project က လိုအပ်သော တန်ဖိုးများကို သတ်မှတ်ပါ။ Cover ကို မြေပြင်မှ အမိုး (invert နှင့် အတွင်းအချင်း ပေါင်း) အထိ တိုင်းသည်; နံရံအထူကို မရေတွက်ပါ။ Pad သို့မဟုတ် corridor များကို grade လုပ်ထားလျှင် grade လုပ်ထားသော မျက်နှာပြင်သည် မြေပြင်ဖြစ်သည်။

## CivilCraft က invert များ သတ်မှတ်စေခြင်း

- {{ui:Set every invert from the rules}} (**Pipe network** block တွင်) က ပိုက်အားလုံးကို သတ်မှတ်သည်။
- {{ui:Set its inverts from the rules}} (ပိုက်တစ်ခုကို ရွေးထားစဉ်) က ထိုပိုက်တစ်ခုတည်းကို သတ်မှတ်သည်။

ရေစီးအောက်ဘက်သို့ တွက်ချက်ရာတွင် လမ်းကြောင်းတစ်ခုစီသည် ၎င်း၏ထိပ်ဖွဲ့စည်းပုံတွင် အနည်းဆုံး cover ရှိ၍ စတင်သည်၊ အနည်းဆုံး slope ဖြင့် ကျသည်၊ ဖွဲ့စည်းပုံတစ်ခုစီ၌ drop အနည်းဆုံးကို ကျသည်၊ မြေပြင်က ပိုက်တလျှောက်တွင် least cover ထက် နည်းမည့်နေရာတိုင်းတွင် ပိုနက်သည်။ Invert များကို 0.01 အထိ အောက်သို့ ဖြတ်သည်၊ ဘယ်တော့မှ အပေါ်သို့ မဖြတ်ပါ။ အခြေအနေဘားက "Inverts set: least cover at the top of each run, at least the least slope, at least the drop in each structure." ဟု ပြောသည် သို့မဟုတ် မလုပ်နိုင်သောအရာကို ဖော်ပြသည်။

## ဖွဲ့စည်းပုံနှင့် ပိုက်များကို တည်းဖြတ်ခြင်း

ဖွဲ့စည်းပုံ သို့မဟုတ် ပိုက်ကို {{ui:Select}} ဖြင့် နှိပ်၍ ညာဘက် panel တွင် ကြည့်ပါ။

**Structure**: **Name**၊ **Rim**၊ **Sump depth**၊ **Diameter**၊ ထို့နောက် **Rim used**၊ **Sump**၊ **Easting** နှင့် **Northing**၊ နှင့် ဝင်/ထွက် ပိုက်များ ၎င်းတို့၏ invert များဖြင့်။

- **Rim** ကို ဗလာထားလျှင် မြေပြင်မှ ယူသည်; ထိုအခါ အကွက်က မြေပြင်တန်ဖိုးကို မီးခိုးရောင်ဖြင့် ပြသည်။ rim ကို ပြင်ရန် တန်ဖိုးရိုက်ပါ။
- ဖွဲ့စည်းပုံ၏ grip ကို ပလန်ပေါ် ဆွဲ၍ ရွှေ့ပါ။ ၎င်း၏ပိုက်များ လိုက်ပါသည်; ၎င်းတို့၏ invert များသည် မူလအတိုင်း ရှိနေသည်၊ ထို့ကြောင့် နောက်မှ ပြဿနာများကို စစ်ပါ။

**Type**: ကွန်ရက်၏ ဖွဲ့စည်းပုံ အမျိုးအစားတစ်ခု (အောက်တွင်) ကို ရွေးပါ၊ သို့မဟုတ် ကိုယ်ပိုင် အချင်းရှိ စက်ဝိုင်းဖွဲ့စည်းပုံအတွက် none။

**Pipe**: **Name**၊ ၎င်းချိတ်ဆက်သော ဖွဲ့စည်းပုံများ၊ **Diameter**၊ **Upper invert**၊ **Lower invert**၊ ထို့နောက် **Length**၊ **Slope** နှင့် **Least cover**။

တန်ဖိုးတိုင်းပြီးနောက် {{key:Enter}} ကို နှိပ်ပါ။

## ပြဿနာများကို ဖတ်ပြီး ပြင်ခြင်း

**Pipe network** block သည် ပြဿနာတိုင်း (အများဆုံး 40) ကို စာရင်းပြသည်; တစ်ခုကို နှိပ်လျှင် ပိုက် သို့မဟုတ် ဖွဲ့စည်းပုံကို ရွေးသည်။ ရွေးထားသော ပိုက် သို့မဟုတ် ဖွဲ့စည်းပုံသည် ၎င်း၏ ကိုယ်ပိုင်ပြဿနာများကို ပြသည်။ ဘာမျှမရှိလျှင် "Every pipe and structure passes the rules." ဟု ပြောသည်။

| မက်ဆေ့ခ်ျ (ဥပမာများ) | ဘာလုပ်ရမလဲ |
|---|---|
| "P2 runs uphill (-0.40%)." သို့မဟုတ် "… runs flat …" | Invert များကို လဲပါ၊ သို့မဟုတ် စည်းမျဉ်းမှ သတ်မှတ်ပါ။ |
| "P2 at 0.30% is flatter than the minimum 0.50%." | ရေစီးအောက်ဘက် invert ကို နိမ့်ချပါ သို့မဟုတ် ရေစီးအထက်ဘက်ကို မြှင့်ပါ။ |
| "P3 has 1.40 of cover 35 along it, less than the minimum 2." | ပိုက်ကို နိမ့်ချပါ; invert များကို စည်းမျဉ်းမှ သတ်မှတ်ပါ။ |
| "In S3, P4 leaves at 245.20, less than 0.1 below P3 coming in at 245.25." | အထွက်ပိုက်၏ upper invert ကို နိမ့်ချပါ။ |
| "P1's crown is above S1's rim." | ပိုက်သည် ဖွဲ့စည်းပုံအတွက် မြင့်လွန်းသည်။ |
| "S2 has 2 pipes leaving it; a gravity network should have one way out of each structure." | အထွက်ပိုက်တစ်ခုကို ဖယ်ရှားပါ၊ သို့မဟုတ် မှန်ကန်သော ဦးတည်ချက်ဖြင့် ပြန်ဆွဲပါ။ |
| "The pipes form a loop; flow has to end at an outlet." | လမ်းကြောင်းကို ကိုယ်ဘက်သို့ ပြန်ဆွဲထားသည်; ပိုက်တစ်ခုကို ဖျက်ပါ။ |
| "S5 is off the surface and has no rim elevation." | Rim ကို ရိုက်ထည့်ပါ၊ သို့မဟုတ် ဖွဲ့စည်းပုံကို မျက်နှာပြင်ပေါ် ရွှေ့ပါ။ |
| "P6 runs partly off the surface; cover there is unknown." | မျက်နှာပြင်ကို တိုးချဲ့ပါ၊ သို့မဟုတ် ထိုနေရာတွင် cover ကို မစစ်ဆေးဘဲ လက်ခံပါ။ |
| "P7 has no inverts yet." | ရိုက်ထည့်ပါ၊ သို့မဟုတ် စည်းမျဉ်းမှ သတ်မှတ်ပါ။ |

ပြဿနာရှိသော ပိုက်နှင့် ဖွဲ့စည်းပုံများကို ပလန်ပေါ် အနီရောင်ဖြင့်လည်း အမှတ်အသားပြုသည်။

## ဖွဲ့စည်းပုံ အမျိုးအစားများ

ဖွဲ့စည်းပုံ အမျိုးအစားသည် ၎င်း၏ parameter များမှ တည်ဆောက်ထားသော ဖွဲ့စည်းပုံဖြစ်သည်: manhole၊ inlet၊ junction box သို့မဟုတ် outlet၊ **round** (အတွင်းအချင်း) သို့မဟုတ် **rectangular** (အတွင်းအကျယ်နှင့် အရှည်) ဖြင့်၊ ၎င်း၏ **wall thickness**၊ **floor slab**၊ အနိမ့်ဆုံးပိုက်အောက်ရှိ **sump**၊ နှင့် **frame and cover** (round သို့မဟုတ် rectangular အဖွင့်၊ frame အမြင့်)။ အမျိုးအစားများသည် ကွန်ရက်နှင့် ပိုင်သည်၊ project ၏ Properties ရှိ **Structure types** အောက်တွင်ရှိသည်။

1. {{ui:New structure type}} ကို နှိပ်ပါ။ dialog က ရိုက်သည်နှင့် ပလန်နှင့် အပိုင်းဖြတ်တွင် ဖွဲ့စည်းပုံကို ဆွဲပြသည်။
2. {{ui:Add the type}} ကို နှိပ်ပါ။
3. ဖွဲ့စည်းပုံတစ်ခုကို ရွေးပြီး **Type** အောက်တွင် အမျိုးအစားကို ရွေးပါ။ ၎င်းသည် အမျိုးအစား၏ အရွယ်အစားနှင့် sump ကို ယူသည်; ၎င်း၏ကိုယ်ပိုင် sump ကိုတော့ ပြောင်းနိုင်သေးသည်။

အမျိုးအစားကို တည်းဖြတ်လျှင် ထိုအမျိုးအစားရှိ ဖွဲ့စည်းပုံအားလုံးသည် ၎င်း၏ အရွယ်အစားကို လိုက်ပါသည်။ အမျိုးအစားကို ဖယ်ရှားလျှင် ၎င်း၏ဖွဲ့စည်းပုံများသည် အချင်းတူ စက်ဝိုင်းဖွဲ့စည်းပုံများအဖြစ် ကျန်နေသည်။ ပြောင်းလဲမှုတိုင်းသည် အဆင့်တစ်ခု: {{key:Mod+Z}} က ပြန်ဖျက်သည်။

Rectangular ဖွဲ့စည်းပုံကို ပလန်၊ DXF၊ DWG နှင့် PDF တွင် ဆွဲသည်၊ 3D တွင် ၎င်း၏ အရှည်ကို outlet ပိုက်ဘက်သို့ ထားသော ထောင့်မှန်အဖြစ်; ပိုက်များသည် နံရံမှ စသည်။ LandXML က ၎င်းကို wall thickness ဖြင့် rectangular ဖွဲ့စည်းပုံ (`RectStruct`) အဖြစ် ရေးပြီး ထိုကဲ့သို့ ဖွဲ့စည်းပုံများကို အမျိုးအစားများအဖြစ် ပြန်ဖတ်သည်။

### အမျိုးအစားတစ်ခုကို စာကြည့်တိုက်မှတဆင့် မျှဝေခြင်း

{{ui:Save as library item}} က အမျိုးအစားကို CadCraft စာကြည့်တိုက်ပစ္စည်း (`.json` ဖိုင်) အဖြစ် ရေးသည်: ၎င်း၏ ပလန်သင်္ကေတ၊ သင့်တော်သော အနက်အထိ 3D ခန္ဓာကိုယ်နှင့် အရွယ်အစားအားလုံး။ မျှဝေရန် စာကြည့်တိုက်သို့ တင်ပါ။ {{ui:Open a library item}} က ဤနည်းဖြင့် သိမ်းထားသော ဖွဲ့စည်းပုံကို ကွန်ရက်ထဲ ပြန်ဖတ်ပြီး project ၏ ယူနစ်သို့ ပြောင်းသည်။ CivilCraft တွင် မဖန်တီးထားသော ဖွဲ့စည်းပုံ စာကြည့်တိုက်ပစ္စည်းများကို အကြောင်းပြချက်ဖြင့် လက်မခံပါ။

## ဖျက်ခြင်း

ပိုက်တစ်ခုကို ရွေးပြီး {{key:Delete}} နှိပ်ပါ။ ဖွဲ့စည်းပုံကို ဖျက်လျှင် ၎င်းနှင့် ချိတ်ဆက်ထားသော ပိုက်များကိုလည်း ဖျက်သည်။ Mac တွင် Fn နှင့် delete နှိပ်ပါ၊ သို့မဟုတ် {{ui:Delete}} ကို နှိပ်ပါ။

## မလုပ်နိုင်သေးသော အရာများ

စီးဆင်းမှု၊ ပိုက်အရွယ်အစားနှင့် hydraulic grade line တို့ကို [Storm drainage](topic:storm-drainage) တွင် ရှိသည်။ Pipe catalog များ၊ စက်ဝိုင်းမဟုတ်သော ပိုက်များ၊ profile view ရှိ ပိုက်များ၊ မွေ့ကွေးသော ပိုက်များနှင့် project တစ်ခုလျှင် ကွန်ရက်တစ်ခုထက်ပို တို့ကို မရနိုင်သေးပါ။ [Not built yet](topic:not-built-yet) ကို ကြည့်ပါ။

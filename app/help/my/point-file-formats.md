Point ဖိုင်သည် စာသားဖိုင်ရိုးရိုးဖြစ်ပြီး အမှတ်တစ်ခုကို စာကြောင်းတစ်ကြောင်းစီဖြင့် ရေးထားပါသည်။ CivilCraft သည် ၎င်းကို ဘရောက်ဆာတွင် ဖတ်ပါသည်; မည်သည့်အရာမျှ အပ်လုဒ်မလုပ်ပါ။

## ကော်လံအစီအစဉ်များ

အက္ခရာများသည် ကော်လံများကို ဘယ်မှ ညာသို့ အမည်ပေးပါသည်: **P** အမှတ်နံပါတ် သို့မဟုတ် အမည်၊ **N** northing၊ **E** easting၊ **Z** elevation၊ **D** ဖော်ပြချက်။

| အစီအစဉ် | ကော်လံများ | ဥပမာ စာကြောင်း |
|---|---|---|
| PNEZD | အမှတ်၊ northing၊ easting၊ elevation၊ ဖော်ပြချက် | `101,2080000.00,6150000.00,250.00,GRD` |
| PENZD | အမှတ်၊ easting၊ northing၊ elevation၊ ဖော်ပြချက် | `101,6150000.00,2080000.00,250.00,GRD` |
| PNEZ | အမှတ်၊ northing၊ easting၊ elevation | `101,2080000.00,6150000.00,250.00` |
| PENZ | အမှတ်၊ easting၊ northing၊ elevation | `101,6150000.00,2080000.00,250.00` |
| NEZD | northing၊ easting၊ elevation၊ ဖော်ပြချက် | `2080000.00,6150000.00,250.00,GRD` |
| ENZD | easting၊ northing၊ elevation၊ ဖော်ပြချက် | `6150000.00,2080000.00,250.00,GRD` |
| NEZ | northing၊ easting၊ elevation | `2080000.00 6150000.00 250.00` |
| ENZ | easting၊ northing၊ elevation | `6150000.00 2080000.00 250.00` |

P မပါသော အစီအစဉ်များတွင် အမှတ်များကို ဖိုင်အစဉ်အတိုင်း 1၊ 2၊ 3 … ဟု နံပါတ်ပေးပါသည်။ X သည် easting ဖြစ်ပြီး Y သည် northing ဖြစ်ပါသည်။

## Separator များ

CivilCraft သည် ပထမ လိုင်း ၂၀ ကို ကြည့်ပြီး ၎င်းတို့ထဲမှ အနည်းဆုံး 60% တွင် ပေါ်သော ပထမဆုံးတစ်ခုကို ရွေးပါသည်: comma၊ tab၊ semicolon။ မဟုတ်ပါက space အစုံဖြင့် ခွဲပါသည်။

- comma၊ tab နှင့် semicolon ဖိုင်များတွင် double quote ထဲရှိ field သည် separator ကို ပါစေနိုင်ပါသည် (`"FL, NORTH"`), နှင့် quote အတွင်းရှိ `""` သည် quote အမှတ်တစ်ခုဖြစ်ပါသည်။
- space ဖြင့် ခွဲသော ဖိုင်များတွင် စာကြောင်းအဆုံးရှိ ဖော်ပြချက်တွင် space ပါနိုင်ပါသည်: နောက်ဆုံး coordinate ကော်လံအပြီးရှိ အရာအားလုံးသည် ဖော်ပြချက် ဖြစ်ပါသည်။
- `#`၊ `;` သို့မဟုတ် `//` ဖြင့် စသော လိုင်းများနှင့် အလွတ်လိုင်းများကို ကျော်ပါသည်။
- ဖိုင်အစရှိ byte-order mark ကို လျစ်လျူရှုပါသည်။

## Header row

ပထမလိုင်းကို header အဖြစ် သတ်မှတ်သည်မှာ ၎င်း၏ field နှစ်ခုထက် နည်းသော အရေအတွက်သည် ဂဏန်းဖြစ်သည့်အခါဖြစ်ပါသည်။ header ၏ field အားလုံးသည် CivilCraft အသိအမှတ်ပြုသော အမည်ဖြစ်ပါက ကော်လံအစီအစဉ်ကို ၎င်းမှ ယူပါသည် ("header row မှ")။ အမည်များကို အကြီးအသေး၊ space၊ dot၊ underscore၊ hyphen နှင့် bracket များကို ပြဿနာမရှိဘဲ ကိုက်ညီအောင် ရှာပါသည်:

| ကော်လံ | အသိအမှတ်ပြုသော အမည်များ |
|---|---|
| P | pt, pnt, point, point no, point number, number, no, id, name, pt#, point#, # |
| N | n, north, northing, y, y coord, lat, latitude |
| E | e, east, easting, x, x coord, lon, long, longitude |
| Z | z, elev, elevation, el, height, h, z coord, rl |
| D | d, desc, description, code, raw description, full description, note, notes, feature |

header အမည်တစ်ခုမျှ အသိအမှတ်မပြုပါက သို့မဟုတ် အမည်များသည် အစီအစဉ် ရှစ်ခုထဲမှ တစ်ခုကို မဖွဲ့စည်းပါက header ကို ကျော်ပြီး ကော်လံအရေအတွက်ဖြင့် အစီအစဉ်ကို ခန့်မှန်းပါသည်။

:::warning
latitude ကော်လံ (`lat`၊ `latitude`) နှင့် longitude ကော်လံ (`lon`၊ `long`၊ `longitude`) နှစ်ခုလုံးကို ဖော်ပြသော header ကို northing နှင့် easting အဖြစ် မဖတ်ပါဘဲ ဒီဂရီအဖြစ် ဖတ်ပါသည်။ {{ui:Import}} တွင် အမှတ်များကို project ၏ coordinate system မှတစ်ဆင့် ပြောင်းပါသည်၊ coordinate system မရှိသော project သည် ဦးစွာ ရွေးရန် မေးပါမည်။ latitude ±90° or longitude ±180° အပြင်ဘက်ရှိ အတန်းများကို ငြင်းပါသည်။ ကြည့်ရန် [GIS ဒေတာ သွင်းခြင်း](topic:gis-import#point-files-with-latitude-and-longitude).
:::

## ကော်လံအရေအတွက်ဖြင့် ခန့်မှန်းခြင်း

အသုံးဝင်သော header မရှိပြီး **Columns** ကို {{ui:Detect}} တွင် ထားခဲ့လျှင်:

- ကော်လံ 5 ခုနှင့်အထက်: PNEZD။
- ကော်လံ 4 ခု: ပထမကော်လံသည် လိုင်းတိုင်းတွင် ကိန်းပြည့်ဖြစ်ပြီး စတုတ္ထကော်လံသည် ဂဏန်းဖြစ်ပါက PNEZ၊ မဟုတ်ပါက NEZD။
- ကော်လံ 3 ခု: NEZ။

PNEZD နှင့် PENZD ကို ဂဏန်းများဖြင့် ခွဲခြားမရနိုင်ပါ။ ခန့်မှန်းချက်သည် [CivilCraft ဆက်တင်များ](topic:settings) ရှိ **Point rows** ကို လိုက်ပါသည်: စတင်တွင် P၊ N၊ E၊ Z၊ D၊ သို့မဟုတ် P၊ E၊ N၊ Z၊ D (ထို့နောက် ကော်လံလေးခုကို PENZ၊ သုံးခုကို ENZ ဟု ဖတ်ပါသည်)။ dialog က "ကော်လံအရေအတွက်ဖြင့် ခန့်မှန်းထားသည် — northing နှင့် easting မလွှဲနေကြောင်း စစ်ဆေးပါ" ဟု ပြပါသည်။ preview မှားနေပါက **Columns** တွင် မှန်ကန်သော အစီအစဉ်ကို ရွေးပါ။

## အတန်းများကို စစ်ဆေးပုံ

- အတန်းတစ်ခုတွင် ဖော်ပြချက်ကို ချန်ထားနိုင်ပါသည်။
- Northing နှင့် easting သည် ဂဏန်းဖြစ်ရပါမည်။ Elevation ကို လွတ်ထားနိုင်ပါသည် (အမှတ်ကို ထားသော်လည်း မျက်နှာပြင်တွင် မသုံးပါ)။
- အမှတ်နံပါတ်သည် မည်သည့် စာသားမဆို ဖြစ်နိုင်ပါသည် (အက္ခရာများ၊ ဥပမာ `CP1` ပါ) သို့သော် အလွတ်မဖြစ်ရပါ။
- အမှတ်နံပါတ် ထပ်လျှင် ပထမအတန်းကို ထားပြီး အခြားအတန်းများကို မဖတ်ရသေးဟု စာရင်းပြုလုပ်ပါသည်။
- ဖော်ပြချက်များကို စာလုံး 200 အထိ ထားပါသည်; control character များကို space ဖြစ်စေပါသည်။
- dialog အတွက် မဖတ်ရသေးသော အတန်း 200 အထိ ထားပါသည် (25 ခု ပြပါသည်)၊ အားလုံးကို ရေတွက်ပါသည်။

## အုပ်စုများ

အမှတ်တစ်ခု၏ အုပ်စုသည် ၎င်း၏ ဖော်ပြချက်၏ ပထမစကားလုံးကို အကြီးအက္ခရာဖြင့် ဖြစ်ပါသည်။ "GRD"၊ "grd shot" နှင့် "Grd" တို့ အားလုံးသည် အုပ်စု GRD ဖြစ်ပါသည်။ ဖော်ပြချက်မရှိသော အမှတ်သည် "(no description)" တွင် ရှိပါသည်။ [survey အမှတ်များ သွင်းခြင်း](topic:import-points) ကို ကြည့်ပါ။

## အမှတ်များ ရေးခြင်း

CivilCraft သည် point text ဖိုင်ကို မထုတ်ရသေးပါ။ အမှတ်များကို LandXML (CgPoints အဖြစ်)၊ project ဖိုင်တွင်၊ နှင့် GIS {{ui:Export}} မှတစ်ဆင့် P၊ N၊ E၊ Z နှင့် D field များပါသော shapefile၊ GeoPackage သို့မဟုတ် GeoJSON အဖြစ် ထွက်ပါသည် ([as-built ဒေတာကို GIS အတွက် ထုတ်ခြင်း](topic:gis-export))။ ကြည့်ရန် [မတည်ဆောက်ရသေးသော အရာများ](topic:not-built-yet).

ဤအရာကို အများစု မလိုအပ်ကြပါ၊ ထို့ကြောင့် add-on ဖြစ်ပါသည်။ Settings › Add-ons တွင် {{ui:Point clouds}} ကို ဖွင့်ပါ။ ညာဘက်ပန်နယ်တွင် {{ui:Point clouds}} tab ပေါ်လာပါမည်။ ဖိုင်ကို သင့်ဘရောက်ဆာတွင် ဖတ်ပြီး ဘရောက်ဆာ၏ ကိုယ်ပိုင် သိုလှောင်မှု (သို့မဟုတ် သင်ရွေးချယ်သော ဖိုင်တွဲ) တွင် သိမ်းထားသည့် tile များအဖြစ် ခွဲထားပါသည်။ **မည်သည့်အရာမျှ အပ်လုဒ်မလုပ်ပါ။**

:::warning
ဤ tab ပြသသည့် အရာအားလုံးသည် သင့်ဒေတာမှ ဂဏန်းတစ်ခုသာ ဖြစ်ပြီး လက်မှတ် မဟုတ်ပါ။ ၎င်းကို အတုပြုထားသော ဆိုက်တွင် စမ်းသပ်ထားပြီး အမှန်တကယ် drone survey တွင် မစမ်းသပ်ရသေးပါ။ ပထမ ရလဒ်များကို ဂရုတစ်စိုက် ကြည့်ပြီး သင်တွေ့ရှိသည်ကို ကျွန်ုပ်တို့အား ပြောပြပါ။ မြေပြင်၊ contour နှင့် ပမာဏများ၏ တန်ဖိုးကို မှတ်ပုံတင်ထားသော အင်ဂျင်နီယာက ဆုံးဖြတ်ပါသည်။
:::

## Cloud ဖွင့်ရန်

{{ui:Open a cloud}} အောက်တွင် LAS သို့မဟုတ် LAZ ဖိုင်ကို ရွေးပါ။ tab က အမှတ်မည်မျှ ပါဝင်သည်၊ ၎င်း၏ coordinate system နှင့် ယူနစ်များ၊ တည်ဆောက်ရန် နေရာမည်မျှ လိုအပ်သည်ကို ပြောပြပါမည်။ ထို့နောက် {{ui:Build the cloud}} ကို နှိပ်ပါ။ တည်ဆောက်မှုကို ရပ်နိုင်ပြီး {{ui:Resume}} ဖြင့် ဆက်လုပ်နိုင်ပါသည် (ဖိုင်တူကို ပြန်ရွေးပါ)။ ဖိုင်ကို ဘယ်တော့မှ ပြောင်းလဲခြင်း မရှိပါ။ အမှတ် ၁ သန်းပါသော ဖိုင်ကို workstation တစ်ခုပေါ်တွင် မိနစ်အနည်းငယ်ဖြင့် တည်ဆောက်နိုင်ပြီး နေရာကလည်း ဖိုင်အရွယ်အစားခန့်သာ လိုအပ်ပါသည်။

{{ui:Clouds on this computer}} အောက်တွင် cloud ကို ဖွင့်ခြင်း သို့မဟုတ် ဖျက်ခြင်း ပြုလုပ်နိုင်ပါသည်။ {{ui:Keep clouds in a folder…}} (Chrome, Edge နှင့် Studio app) ကို ရွေးလျှင် tile များကို သင်ရွေးသော ဖိုင်တွဲတွင် သိမ်းပါမည်၊ ဥပမာ Documents ထဲရှိ CadCraft clouds ဖိုင်တွဲ။ ထို့ကြောင့် 10 GB cloud သည် ဘရောက်ဆာ သိုလှောင်မှုထဲ ဝင်ရန် မလိုအပ်ပါ။ အစောပိုင်းက တည်ဆောက်ထားသော cloud များသည် တည်ဆောက်ခဲ့သည့် နေရာတွင် ဆက်ရှိနေပါမည်။ ဘရောက်ဆာသည် ပြန်စတင်ပြီးနောက် ခွင့်ပြုချက်ကို ထပ်မေးပါမည်– {{ui:Use the folder … again}} ကို နှိပ်ပါ။

## ကြည့်ရန်

{{ui:Look at it in 3D}} သည် cloud ကို ကြမ်းသော tile များဖြင့် ဆွဲပြပြီး သင်နီးကပ်လာသည်နှင့်အမျှ ပိုကောင်းအောင် ပြင်ပါသည်။ တစ်ကြိမ်တွင် {{ui:Most points drawn}} ထက် ပို၍ ဆွဲမည် မဟုတ်ပါ (2.5 သန်း; ဖုန်းပေါ်တွင် 500 ထောင်)။ ဖိုင်၏ ကိုယ်ပိုင်အရောင်၊ အမြင့်၊ အတန်း၊ intensity သို့မဟုတ် residual ဖြင့် အရောင်ခွဲနိုင်ပါသည်။ {{ui:Eye-dome lighting}} သည် အနားသတ်များကို အနက်အလိုက် အရိပ်ပေးပြီး normal မရှိဘဲ ပုံသဏ္ဌာန်ကို ပေါ်စေပါသည် (ဖုန်းပေါ်တွင် ပိတ်ထားသည်)။ {{ui:Points shrink with distance}} သည် အဝေးရှိ အမှတ်များကို ပိုသေးစေပြီး နီးသည့် အမှတ်များကို ပိုကြီးစေပါသည်။ {{ui:Point size}} သည် အရွယ်အစားကို သတ်မှတ်ပါသည်။ ပုံစံ(plan) တွင် cloud ကို သင့်ပုံဆွဲချက်အောက်ရှိ raster အဖြစ် ပြပြီး အပိုင်းတစ်ခုသို့ zoom in လုပ်သည့်အခါ **ပိုရှင်းလင်းစွာ ပြန်ဖော်ပြပါသည်**။

## သန့်စင်ရန်

{{ui:Clean}} အောက်တွင် plan ပေါ်တွင် lasso၊ box သို့မဟုတ် polygon ဆွဲပါ (သို့မဟုတ် 3D တွင် အပေါ်မှ top view ဖြင့်ဆွဲပါ– 3D တွင် outline ကို တိုက်ရိုက် အောက်သို့ ယူသဖြင့် အပေါ်မှ ကြည့်သည့်အခါသာ တိကျပါသည်)။ tab က မလုပ်ခင် **မတိုင်မီ** အတွင်းရှိ အမှတ်အရေအတွက်ကို ပြပါသည်– {{ui:Delete these points}}၊ {{ui:Change their class}}၊ {{ui:Restore deleted points}} သို့မဟုတ် {{ui:Crop to this boundary}}။ {{ui:Undo}} နှင့် {{ui:Redo}} သည် တည်းဖြတ်မှတ်တမ်းကို လျှောက်သွားပါသည်; ဖိုင်ကိုယ်တိုင်ကို ဘယ်တော့မှ ပြောင်းလဲခြင်း မရှိပါ။ {{ui:Noise filter…}} သည် ပျံ့လွင့်နေသော အမှတ်များကို အနိမ့်အမှတ် (class 7) သို့မဟုတ် အမြင့် noise (class 18) အဖြစ် မှတ်သားပါသည်။

## စီခွဲရန်

{{ui:Find the ground}} သည် tile တစ်ခုချင်းစီဖြင့် အလုပ်လုပ်ပြီး မြေပြင် (class 2) နှင့် အနိမ့်အမှတ်များကို မှတ်ပါသည်; tolerance သည် 0.15 m ဖြစ်ပြီး survey-grade switch ဖွင့်ထားလျှင် 0.08 m ဖြစ်ပါသည်။ မကိုက်ညီသော tile ဆက်စပ်နေရာများကိုလည်း အစီရင်ခံပါသည်။ {{ui:Classify vegetation and buildings}} သည် မြေပြင်မှ အမြင့်နှင့် ပတ်ဝန်းကျင်၏ ညီညာမှုအပေါ် အခြေခံ၍ အနိမ့်၊ အလယ်အလတ်နှင့် အမြင့် အပင်များနှင့် အဆောက်အအုံများကို မှတ်ပါသည်။ machine learning မပါဝင်သဖြင့် သစ်ပင်အောက်ရှိ အမိုးပြားဆိုင်ခန်းကို မှားနိုင်ပါသည်– ကြည့်ပါ။

## မြေပြင်၊ contour၊ breaklines

{{ui:Build ground}} သည် မြေပြင်အမှတ်များမှ ရှိပြီးသား မြေပြင်ကို ဖန်တီးပြီး LAS import ကဲ့သို့ပင် project သို့ ထည့်ပါသည် (undo တစ်ဆင့်)။ ထို့နောက် အမှတ်များနှင့် နှိုင်းယှဉ်ပြီး mean၊ RMS၊ 95th percentile၊ tolerance အတွင်းရှိ အစိတ်အပိုင်းနှင့် အကွာဆုံး ကွာခြားသော နေရာ ၁၀ ခု ကို {{ui:Go there}} နှင့်အတူ ပြပါသည်။ {{ui:Residual}} အရောင်ဖြင့် မြေပြင်နှင့် cloud မညီညွတ်သည့် နေရာများကို ပြပါသည်။

**breakline** (ကန်ဆုံး၊ မြောင်း သို့မဟုတ် မြေကြီး အထက်ဆုံး) ကို cloud ပေါ်တွင် ရွေးပါသည်: 3D view တွင် {{ui:Pick a breakline on the cloud}} သည် နှိပ်တိုင်းတွင် အနီးဆုံး ဆွဲထားသော အမှတ်ကို ယူပြီး၊ {{ui:Pick a breakline in the plan}} သည် နှိပ်သည့်နေရာအောက်ရှိ အနီးဆုံး cloud အမှတ် (မြေပြင်ကို ဦးစားပေး) ကို ယူပါသည်; double-click သို့မဟုတ် Enter ဖြင့် မျဉ်းကို ပြီးဆုံးပါသည်။ နောက်တစ်ကြိမ် {{ui:Build ground}} သည် ၎င်းကို အသုံးပြုပါမည်။ {{ui:Show contours}} သည် cloud အပေါ်တွင် contour များကို ပုံငယ်တစ်ခုတွင် ဆွဲပြပြီး project ၏ interval ကို သတ်မှတ်ပါသည်။

## ပမာဏများ

{{ui:Stockpile volume…}} သည် သင်ဆွဲသော နယ်နိမိတ်အတွင်း အခြေခံအထက်ရှိ မျက်နှာပြင်၏ ပမာဏကို တွက်ချက်ပါသည်။ ပုံပတ်ပတ်လည် ညီညာသော မြေပြင်ပေါ်တွင် နယ်နိမိတ်ကို ဆွဲပြီး အခြေခံကို ရွေးပါ: နယ်နိမိတ်၏ အနိမ့်ဆုံးအမှတ်၊ ပလိန်း၊ ချောမွေ့သော ကွေးသည့် အခြေခံ၊ နယ်နိမိတ်ကို ဖြတ်သော မျက်နှာပြင်၊ သို့မဟုတ် သင်ရိုက်ထည့်သော အမြင့်။ ပြားချပ်ချပ် မဟုတ်သော သို့မဟုတ် ကွေးသော မြေပြင်ပေါ်တွင် ပလိန်း သို့မဟုတ် ကွေးသော အခြေခံကို သုံးပါ; အနိမ့်ဆုံးအမှတ်သည် မြင့်လွန်းအောင် ဖတ်ပါသည်။ အခြားတစ်ဝိုက်ထက် မြင့်နေသော နယ်နိမိတ်အမှတ်များ (မျဉ်းပေါ်ရှိ သစ်ပင်) ကို အခြေခံမှ ဖယ်ထားပါသည်။ {{ui:Flight to flight}} သည် cloud နှစ်ခုကြား cut နှင့် fill ကို ပေးပါသည်။ နှစ်ခုလုံးကို CSV အဖြစ် သိမ်းနိုင်ပါသည်။

## Orthomosaic

{{ui:Orthomosaic (picture from above)}} အောက်တွင် ဒရုန်၏ orthomosaic ကို ရှိလျှင် ၎င်း၏ world file နှင့် `.prj` ဖိုင်နှင့်အတူ ရွေးပါ: GeoTIFF၊ သို့မဟုတ် PNG သို့မဟုတ် JPEG။ ၎င်းသည် project ၏ **မြေပုံအလွှာ** ဖြစ်လာပြီး plan တွင် သင့်ပုံဆွဲချက်အောက်တွင် ပြပါသည်၊ 3D view (အရောင် {{ui:Map}}) သည် သင်တည်ဆောက်ထားသော မြေပြင်ပေါ်တွင် ၎င်းကို ဆေးသုတ်ပေးပါသည်၊ ထို့ကြောင့် {{ui:Build ground}} ကို အရင်လုပ်ပါ။ tab က ဓာတ်ပုံက cloud ၏ မည်မျှကို ဖုံးသည်ကို ပြပြီး မဖုံးပါက သတိပေးပါသည်: အဖြစ်များသော အကြောင်းမှာ မတူသော coordinate system ဖြစ်ပြီး ထို့ကြောင့် `.prj` ဖိုင်ကို ထည့်ပေးပါ။ `.prj` မရှိပါက program က coordinates ဘယ်မှာလဲ မေးပါမည်။ ဓာတ်ပုံကို project ဖိုင်အတွင်း သိမ်းထားပါသည်; 200 MB ထက်ကြီးသော GeoTIFF ကို လက်မခံပါ၊ အလွန်ကြီးသော mosaic ကို 16 megapixels သို့ လျှော့ချပါမည်၊ ထို့ကြောင့် survey ကြီးများအတွက် mosaic ကို အရင် နေရာလိုက် ဖြတ်ပါ။

## ထုတ်ရန်

{{ui:Export}} သည် သန့်စင်ပြီး အမျိုးအစားခွဲထားသော cloud ကို ဖိုင်အသစ်အဖြစ် ရေးပါသည် (အမှတ်အားလုံး၊ သန့်စင်ထားသော class များ၊ သို့မဟုတ် မြေပြင်သာ)။ {{ui:File type}} အောက်တွင် ရွေးပါ:

- **LAS 1.4 (compress မလုပ်ထား)**: point format 6၊ သို့မဟုတ် အရောင်ပါလျှင် 7။
- **LAZ (compress လုပ်ထား)**: အမှတ်တူကို ဆုံးရှုံးမှုမရှိစေဘဲ compress လုပ်ထားသဖြင့် အမှတ်တိုင်း တိတိကျကျ ပြန်ရပါသည်။ LAS 1.4 ဖိုင်ထဲ point format 0၊ အရောင်ပါလျှင် 2 အဖြစ် ရေးပါသည်။ အတုပြုထားသော 300 m ဆိုက်တွင် LAZ သည် LAS 1.4 ဖိုင်၏ ငါးပုံတစ်ပုံခန့်သာ ဖြစ်ပါသည်။ LAZ format 0 နှင့် 2 တွင် class 0 မှ 31 သာ ထည့်နိုင်ပြီး ပိုမြင့်သော class ပါသည့် အမှတ်ကို မက်ဆေ့ချ်ဖြင့် ငြင်းပယ်ပါသည်၊ ထို့ကြောင့် ထို cloud ကို LAS 1.4 အဖြစ် ထုတ်ပါ။

LAZ ကို CadCraft ၏ ကိုယ်ပိုင် compressor ဖြင့် ရေးပြီး ထုတ်ပြန်ထားသော LAZ specification မှ ပြုလုပ်ထားပါသည်။ ကျွန်ုပ်တို့၏ ကိုယ်ပိုင် reader နှင့် လွတ်လပ်သော LAZ reader နှစ်ခု (အက်ပ်က LAZ ဖိုင်ဖွင့်ရန် သုံးသော laz-perf နှင့် lazrs ပါဝင်သော laspy) တို့က အမှတ်တိုင်းကို တိတိကျကျ ပြန်ဖတ်နိုင်ကြောင်း၊ laspy ဖြင့် ပြုလုပ်ထားသော LAZ ဖိုင်များသည် အမှတ်များကို ပြန်ရေးသည့်အခါ byte အတိအကျ အတူတူ ဖြစ်ကြောင်း စစ်ဆေးပြီးပါပြီ။ အခြား program များကို မစမ်းသေးပါ၊ ထို့ကြောင့် ဖိုင်တစ်ခုကို မဖွင့်နိုင်ပါက ကျွန်ုပ်တို့အား မည်သည့် program ဖြစ်ကြောင်း ပြောပြပါ။

ဘရောက်ဆာက ဖိုင်ကို တစ်ဆင့်ချင်း ရေးနိုင်ပါက ဖိုင်ကို အရင်ရွေးပါ၊ အလွန်ကြီးသော cloud ကို tile တစ်ခုချင်းစီဖြင့် memory တွင် စုမထားဘဲ ရေးပါမည်; မဟုတ်ပါက ဖိုင်ကို စုပြီး download လုပ်ပါမည်၊ ၎င်းမှာ မီဂါဘိုက် ရာချီအထိ ကောင်းပါသည်။

## မလုပ်နိုင်သော အရာများ

LAS နှင့် LAZ ကိုသာ ဖတ်ပါသည် (E57၊ PLY နှင့် PCD ကို ဤ tab တွင် မချိတ်ဆက်ရသေးပါ၊ ပျံသန်းမှုတစ်ခု၏ ဖိုင်များစွာကို မပေါင်းထားပါ)၊ cloud ကို reproject မလုပ်ပါ (project ၏ system နှင့် မီတာကို ယူဆထားပါသည်)၊ Autodesk ၏ RCP သို့မဟုတ် RCS ဖိုင်များကို မဖတ်ပါ၊ ဓာတ်ပုံများမှ မျက်နှာပြင် မဖန်တီးပါ၊ တိုင်၊ ဘောင်ခုံ သို့မဟုတ် ပိုက်များကို ကိုယ်တိုင် ရှာမတွေ့ပါ။

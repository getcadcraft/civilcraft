## ဘာလုပ်မည်နည်း

project သို့ ဖိုင်တစ်ခု သွင်းပြီး မှန်ကန်သော အရွယ်အစားဖြင့် ဝင်လာကြောင်း သေချာစေခြင်း။

## အဆင့်များ

1. ဖိုင်ကို ပုံမှန်အတိုင်း ဖွင့်ပါ: {{ui:ဖွင့်ရန်}}၊ plan ပေါ်သို့ ချပါ၊ သို့မဟုတ် CAD ဒရော်ဝင်း command ကို သုံးပါ။
2. ဖိုင်က ၎င်း၏ ယူနစ်များကို ဖော်ပြလျှင် ဘာမျှ မမေးပါ: သွင်းသည့် dialog က ၎င်းတို့ကို **ဒရော်ဝင်း ပြောသည့်အတိုင်း** ဟု ပြသည်။
3. မဖော်ပြလျှင် သွင်းသည့် dialog မဖွင့်မီ ဖိုင်၏ **ယူနစ်များ** ကို မေးသော dialog ပေါ်လာသည်။ ဖိုင်တွင် ယူနစ်တစ်ခုသည် ဘာဖြစ်သည်ကို ရွေးပြီး {{ui:ဤ unit များကို သုံးရန်}} ကို နှိပ်ပါ။
4. {{ui:ပယ်ဖျက်ရန်}} (သို့မဟုတ် {{key:Esc}}) သည် ဖိုင်ကို ကျော်သည်။ ၎င်း၏ မည်သည့်အရာမျှ project သို့ ဖတ်ဝင်မည် မဟုတ်ပါ။

## မည်သည့်ဖိုင်များက ယူနစ်ကို ဖော်ပြသနည်း

- **DWG နှင့် DXF**: ဒရော်ဝင်း၏ insertion unit (`$INSUNITS`)။ မပါသော ဖိုင်ကို မေးသည်။ သွင်းသည့် dialog ရှိ **ဒရော်ဝင်း ယူနစ်များ** စာရင်းသည် သင့်အဖြေဖြင့် စသည်၊ ပြောင်းနိုင်သေးသည်။
- **STL နှင့် OBJ** (landscape free-form ပုံသဏ္ဍာန်များ): ယူနစ်ကို ဘယ်တော့မှ မဖော်ပြပါ။ မေးသည်။
- **point စာရင်းများ** (CSV၊ TXT) နှင့် progress survey စာရင်းများ: ပထမစာကြောင်းများတွင် ယူနစ်ကို ဖော်ပြသော စာရင်းကို ပြောင်းပြီး status စာတွင် ပြောသည်။ ဘာမျှ မဖော်ပြသော စာရင်းကို {{ui:သွင်းရန်}} ကို နှိပ်သည့်အခါ point များ မဝင်မီ မေးသည်။ latitude နှင့် longitude ကော်လံများသည် coordinate system ကို ဖြတ်သွားသည်။
- **Point clouds add-on**: ယူနစ် မဖော်ပြသော cloud တစ်ခုကို တည်ဆောက်သည့်အခါ မေးပြီး cloud ၏ နံပါတ်များကို ၎င်းသယ်ဆောင်သော ယူနစ်ဖြင့် အမှတ်အသားပြုသည်။
- **IFC နှင့် LandXML**: ၎င်းတို့ ယူနစ်ကို ဖော်ပြသည်; project ၏ ယူနစ်များသို့ ပြောင်းသည်။
- **LAS၊ LAZ နှင့် elevation raster များ**: coordinate system ဖြင့် နေရာချသည်; ဖိုင်က မဖော်ပြလျှင် terrain dialog က elevation ယူနစ်ကို မေးသည်။

## သိထားရန်

- အဖြေကို ဤကွန်ပျူတာပေါ်ရှိ ထိုဖိုင်အတွက် CadCraft အက်ပ်တိုင်းတွင် မှတ်ထားသည်။ နောက်တစ်ကြိမ် ဝင်လာသည့်အခါ မမေးပါ။
- ထပ်မေးလိုလျှင်: command palette ({{key:Mod+K}}) › **သွင်းထားသော ဖိုင်များ၏ ယူနစ်များကို ထပ်မေးရန်**။
- ဖိုင်စာရင်းက ယူနစ်ကို ပထမစာကြောင်း ရှစ်ကြောင်းမှ ဖတ်သည်: ဥပမာ `units: ft` ကဲ့သို့ စာကြောင်း၊ သို့မဟုတ် ကွင်းတွင် ယူနစ်တူတူ ပါသော ကော်လံခေါင်းစဉ်များ၊ ဥပမာ `Elevation (m)`။

ဤသည်မှာ CivilCraft 0.9 တွင် 0.8.1 နှင့် နှိုင်းယှဉ်လျှင် ပြောင်းလဲချက်များ ဖြစ်သည်။ CivilCraft 0.9 သည် CadCraft Studio 0.9 နှင့် ၎င်း၏ app ရှစ်ခု၏ အစိတ်အပိုင်း ဖြစ်သည်။ အဓိက အစိတ်အပိုင်းများမှာ corridor နှင့် terrain ပုံစံများ၊ ရေးဆွဲစဉ် snap များ၊ GIS ခွဲခြမ်းစိတ်ဖြာမှု၊ ဆိုက်၏ နေရောင်၊ နေရောင်အထွက်၊ အအေးဓာတ်နှင့် လေ လေ့လာမှုများ၊ နှင့် add-on နှစ်ခု- Point clouds နှင့် WaterCraft။

## အသစ်

### corridor နှင့် terrain ပုံစံများ

- **Corridor templates။** {{ui:Surface}} › {{ui:More}} › {{ui:ကော်ရီဒါ ပုံစံများ…}} ကို ဖွင့်ပါ (သို့မဟုတ် {{cmd:TEMPLATES}} ကို ရိုက်ပါ)။ ပုံစံမှာ component များ၊ offset များ၊ slope များ၊ ပစ္စည်းများနှင့် point code များပါသော အသေးစား cross-section တစ်ခု ဖြစ်သည်။ ပရောဂျက်ထဲ၊ {{ui:ကျွန်ုပ်၏ စာကြည့်တိုက်}} ထဲ သို့မဟုတ် `.cctemplates.json` ဖိုင်အဖြစ် သိမ်းထားပါ။ template editor က အစစ်အမှန် အတိုင်းသော ပုံဆွဲကို ပြပြီး ရိုက်နေစဉ် ပြဿနာများကို ဖော်ပြသည်။
- **ပုံစံများမှ station အလိုက် တည်ဆောက်ခြင်း။** alignment ကို ရွေးပြီး ၎င်း၏ Properties တွင် {{ui:စတေးရှင်အလိုက် ပုံစံများမှ တည်ဆောက်ရန်}} ကို ဖွင့်ပါ။ region တစ်ခုစီ၏ ဘက်တစ်ခုစီတွင် ကိုယ်ပိုင် pavement စာရင်းနှင့် ကိုယ်ပိုင် အဆုံးအခြေအနေ ရှိသည်။ {{ui:ဤဖြောင့်ညွှန်းပေါ်ရှိ ကော်ရီဒါများ}} အောက်ရှိ {{ui:ကော်ရီဒါတစ်ခု ထည့်ရန်}} သည် alignment တစ်ခုပေါ် corridor အများအပြား ထားသည်။
- **Terrain templates။** {{ui:Surface}} › {{ui:More}} › {{ui:မြေပြင် ပုံစံများ…}} (သို့မဟုတ် {{cmd:TERRAINTEMPLATES}} ကို ရိုက်ပါ) သည် မြေပြင်ပေါ် ထုပ်လုပ်ထားသော ပစ္စည်းများ (ဥပမာ မြေဆီလွှာ သို့မဟုတ် ကတ္တရာနှင့် base) ကို အလွှာလိုက် ဧရိယာနှင့် ပမာဏဖြင့် ချပေးသည်။ [Corridor templates and terrain templates](topic:corridor-templates) ကို ကြည့်ပါ။

### ရေးဆွဲခြင်း

- **Snap များ။** Alignment၊ Pad၊ Parcel၊ Mass၊ Feature line၊ Measure၊ Boundary နှင့် Catchment ကိရိယာများသည် survey အမှတ်များ၊ PI များ၊ ထောင့်များ၊ vertex များနှင့် structure များသို့ snap လုပ်သည်၊ marker ဘေးတွင် label ရှိသည်။ အခမဲ့ အမှတ်အတွက် {{key:Alt}} ကို ဖိထားပါ။
- **Pick ခလုတ်များ၊ tangent နှင့် move၊ copy၊ rotate။** Pad၊ parcel နှင့် feature-line ထောင့်များတွင် ရိုက်ထည့်နိုင်သော Easting နှင့် Northing အကွက်များနှင့် crosshair Pick ခလုတ် ရှိသည်။ Properties တွင် alignment များအတွက် {{ui:အမှတ်နှစ်ခုမှ တိုက်ရိုက်မျဉ်း}} နှင့် alignment၊ pad၊ parcel နှင့် feature line များအတွက် {{ui:ရွှေ့ခြင်း၊ ကူးခြင်းနှင့် လည်ခြင်း}} လည်း ရှိသည်။ [Draft with snaps, picked corners and move, copy, rotate](topic:draft-with-snaps) ကို ကြည့်ပါ။
- **3D တွင် Render view။** 3D bar ရှိ {{ui:ပုံဖော်ရန်}} ခလုတ်သည် မြေကို သဘာဝအရောင်၊ ကောင်းကင်၊ မှိုင်းမှုနှင့် ပျော့ပျောင်းသော အရိပ်များဖြင့် ဆွဲသည်။ မော်ဒယ်ကို မပြောင်းပါ။ {{ui:နေ}} မီနူးတွင် ယခု {{ui:အသုံးပြုရန်}} နှင့် {{ui:ပိတ်ရန်}} ခလုတ်များ ရှိသည်။ [View the site in 3D](topic:site-3d) ကို ကြည့်ပါ။
- **Panel များ တစ်ခုချင်းစီ ဖွင့်ခြင်း။** ဘယ်ဘက် panel နှင့် Properties panel သည် အပိုင်းတစ်ခုကိုသာ ဖွင့်ပြီး အခြားများကို ပိတ်သည်၊ Landscape ribbon ရှိ ကိရိယာများစွာ ပါသော tile များသည် split ခလုတ်များ ဖြစ်သည်။

### GIS ခွဲခြမ်းစိတ်ဖြာမှု

- **Analyze။** {{ui:Surface}} › {{ui:More}} › {{ui:ခွဲခြမ်းစိတ်ဖြာ}} တွင် buffer၊ overlay၊ spatial join၊ attribute သို့မဟုတ် shape ဖြင့် ရွေးခြင်းနှင့် တိုင်းတာခြင်း ရှိသည်။ ကိရိယာတစ်ခုစီသည် layer အသစ်တစ်ခု ဖန်တီးပြီး undo အဆင့်တစ်ခု ဖြစ်သည်။
- **Attribute table။** layer ၏ သုံးစက်ချက် menu တွင် {{ui:Attribute table…}} နှင့် {{ui:attribute ဖြင့် ပုံစံချရန်…}} ရှိသည်။ [Analyze GIS layers](topic:gis-analysis) နှင့် [Work with a layer's attribute table](topic:gis-table) ကို ကြည့်ပါ။

### ဆိုက်- နေ၊ နေရောင်၊ အအေးဓာတ်နှင့် လေ

- **Environment အပိုင်း။** mass တစ်ခုကို ရွေးပါ- {{ui:ပတ်ဝန်းကျင်}} အပိုင်းသည် Properties ရှိ {{ui:နေရောင်ခံချိန်များ}} ၏ အောက်တွင် ရှိသည်။ အရိပ် လေ့လာမှု (မြေပုံ၊ ဇယား၊ animation၊ CSV)၊ typical-year ရာသီဥတု ဖိုင် (.epw) မှ နေရောင်အထွက်နှင့် အပြင်ဘက် အအေးဓာတ် (UTCI) ရှိသည်။
- **လေ၊ ကြည့်ရှုရန်သာ။** {{ui:လေ လေ့လာမှု ပြေးရန်}} သည် ရာသီဥတုဖိုင်ထဲရှိ လေတိုက်ရာ အရပ်တစ်ခုစီအတွက် မြေကို ထိုင်နိုင်မှုမှ မသက်သာမှုအထိ အရောင်ချသည်။ မစမ်းသပ်ရသေးပါ၊ panel က ထိုသို့ ပြောသည်။
- **ခြေကျင်သွားလာသူ လေ (OpenFOAM) add-on။** {{ui:ဆက်တင်များ}} › {{ui:ထပ်ဆောင်းများ}} တွင် ဖွင့်မချင်း ပိတ်ထားသည်။ OpenFOAM သည် သင်ကိုယ်တိုင် ထည့်ရမည့် software ဖြစ်သည်။ [Shade, solar yield and outdoor comfort](topic:environment) ကို ကြည့်ပါ။

### Point clouds (add-on)

- {{ui:ဆက်တင်များ}} › {{ui:ထပ်ဆောင်းများ}} တွင် {{ui:Point clouds}} ကို ဖွင့်ပါ; ညာဘက် panel တွင် Point clouds tab ပေါ်လာသည်။ LAS သို့မဟုတ် LAZ ဖိုင် ဖွင့်၊ ရှင်းလင်း၊ မြေပြင်၊ ရှုခင်းနှင့် အဆောက်အအုံအဖြစ် စီ၊ မြေပြင်၊ contours နှင့် ပမာဏများ တည်ဆောက်ပြီး LAS သို့မဟုတ် LAZ ထုတ်ပါ။ [Point clouds from a drone or scanner](topic:point-clouds) ကို ကြည့်ပါ။

### WaterCraft (add-on)

- {{ui:ဆက်တင်များ}} › {{ui:ထပ်ဆောင်းများ}} တွင် {{ui:WaterCraft (ရေဖြန့်ဝေမှု)}} ကို ဖွင့်ပါ; WaterCraft tab ပေါ်လာသည်။ ဖောက်သူများမှ ဝယ်လိုအား၊ hydrant တိုင်းရှိ မီးသတ် စီးဆင်းမှု၊ မည်သည့် main ရပ်ဆိုင်းမှုက အရေးကြီးသလဲ၊ နှင့် ရေအသက်နှင့် ကလိုရင်း၊ တစ်ခုစီကို CSV အဖြစ် သိမ်းနိုင်သည်။ [WaterCraft: demands, fire flow, outages and water age](topic:watercraft) ကို ကြည့်ပါ။

### အတူတကွ လုပ်ခြင်း

- Live session တွင် အခြားသူတို့၏ cursor နှင့် အမည်များကို plan တွင် မြင်ရသည်။ Library ပင်များ- CivilCraft Landscape သည် ၎င်း၏ မူရင်း Library စုဆောင်းမှုမှ စတင်သည်၊ {{ui:CivilCraft landscape}}။

## app အားလုံးတွင်

- အကြံပြုချက်များကို Bootstrap tooltip များအဖြစ် ပြသည်၊ စတင်အကြံပြုချက်ကို ပိတ်နိုင်သည်။
- panel ၏ tab အတန်းသည် မကိုက်ညီလျှင် ဖြတ်ခံရမည့်အစား scroll လုပ်သည်။
- browser tab ခေါင်းစဉ်များသည် `<document> - CivilCraft | CadCraft` ဟု ဖတ်ရသည်။
- {{ui:ဆက်တင်များ}} တွင် Layout အပိုင်း ရှိပြီး layout များသည် စာကြောင်းနှစ်ကြောင်းရွေးချယ်မှုများ ပါသော drop-down ဖြစ်သည်။
- အလေးချိန်နှင့် အပူချိန် ယူနစ်များသည် {{ui:ဆက်တင်များ}} › {{ui:ကမ္ဘာလုံးဆိုင်ရာ}} › {{ui:ယူနစ်များ}} တွင် ရှိသည်။
- ဘာသာစကား စာရင်းသည် build တွင် ဖိုင်ရှိသော ဘာသာစကားများကို ပြသည်။ အင်္ဂလိပ်မှ အခြား ဘာသာစကားများသည် စက်ဖြင့် ဆွဲထားသော မူကြမ်းများ ဖြစ်သည်။

## ပြင်ဆင်ပြီး

- Address lookup နှင့် EnergyPlus စစ်ဆေးမှု add-on များကို ဖွင့်၍ မရခဲ့ပါ; ယခုဖွင့်နိုင်ပြီ။
- အကူအညီက Point clouds add-on သည် ရှင်းလင်းထားသော cloud ကို LAS 1.4 သို့မဟုတ် LAZ အဖြစ် ရေးသည်ဟု ယခု ပြောသည်။
- ရွေးထားသော object ၏ ကိုယ်ပိုင် grip ကို နှိပ်ခြင်းသည် စောင့်နေသော Pick ကို ရပ်စေသော grip drag ကို စတင်မည် မဟုတ်တော့ပါ။

## အကန့်အသတ်များ ရိုးရိုးသားသား

- ဥပမာ corridor ပုံစံများသည် စံမှ မဟုတ်သော နေရာယူထားသော တန်ဖိုးများ ဖြစ်ပြီး အင်ဂျင်နီယာက စစ်ရမည်။ Terrain ပုံစံများသည် မျက်နှာပြင် မထည့်ပါ၊ 3D တွင် သို့မဟုတ် section view တွင် မဆွဲပါ။ alignment ပေါ်ရှိ ဒုတိယ corridor သည် IFC export ထဲ မပါ။ ပုံစံ နှစ်ခုကြား station အလိုက် taper မရှိပါ။
- Point clouds ကို ပြုလုပ်ထားသော ဖိုင်များ ပေါ်တွင် စမ်းသပ်ခဲ့ပြီး အမှန်တကယ် drone စစ်တမ်း မဟုတ်ပါ။ LAS နှင့် LAZ ကိုသာ ဖတ်သည်။
- GIS ခွဲခြမ်းစိတ်ဖြာမှုကို ပြုလုပ်ထားသော layer များပေါ်တွင် စမ်းသပ်ခဲ့သည်။
- အရိပ်၊ နေရောင်နှင့် အအေးဓာတ်တို့သည် ဆိုက်အတွက် ခန့်မှန်းချက်များ ဖြစ်ပြီး လေမှာ မစစ်ဆေးရသေးသော ကြည့်ရှုမှု ဖြစ်သည်။ ဤအရာများ မည်သည်မျှ ဒီဇိုင်းတန်ဖိုး မဟုတ်ပါ။
- WaterCraft သည် ပြုလုပ်ထားသော ကွန်ရက်များပေါ် စစ်ဆေးထားသော တွက်ချက်မှု အကူအညီ ဖြစ်သည်။ ရေအင်ဂျင်နီယာက ဂဏန်းများ၏ တန်ဖိုးကို ဆုံးဖြတ်သည်။
- အင်္ဂလိပ်မှ အခြား ဘာသာစကားများသည် စက်ဖြင့် ဆွဲထားသော မူကြမ်းများ ဖြစ်သည်။
- Windows installer များကို code-signed မလုပ်ထားပါ၊ macOS disk image ကို notarized မလုပ်ထားပါ။

## အစောပိုင်း- 0.8 နှင့် 0.8.1

ဤသည်မှာ CivilCraft 0.8 (2026-11-01) နှင့် 0.8.1 (2026-11-02) တွင် 0.7 နှိုင်းယှဉ်လျှင် ပြောင်းလဲချက်များ ဖြစ်သည်။ အဓိက အသစ်အစိတ်အပိုင်းများမှာ မြေပြင်နှင့် လမ်းကို စမ်းသပ်သော ကိရိယာများ (မိုး၊ မြေထုလုပ်ငန်း၊ လမ်းကြောင်းများ၊ ရေကန်များ၊ တိုးတက်မှု) နှင့် မြေပြင်၊ လမ်း၊ စစ်တမ်း၊ သတ္တုတွင်း၊ ချိတ်ဆက်မှုနှင့် ရထားလမ်း အတွက် တွက်ချက်သော ပြတင်းပေါက် ခြောက်ခုတို့ ဖြစ်သည်။

### အသစ်

**မြေပြင် ပြင်ဆင်မှုကို စမ်းသပ်ခြင်း**

- **မိုးရွာစေရန်။** {{ui:မိုးရွာစေရန်…}} (အောက်တွင် {{ui:မျက်နှာပြင်}}) သည် grade လုပ်ထားသော မြေပြင်ပေါ် မုန်တိုင်း ကျစေသည်။ ရေသည် pad များမှ စီးဆင်းပြီး အနိမ့် ထောင့်များတွင် ရေကန်ဖြစ်ကာ ငယ်သေးသော ရေကန်များကို ကျော်ရသည်ကို ကြည့်ရသည်။ run သည် animation ဖြစ်ပြီး ပမာဏများ၊ အမြင့်ဆုံး ထွက်ရှိမှုနှင့် ရေကန်တိုင်း၏ CSV ကို ပေးသည်။ မူရင်း cell သည် ကြမ်းသည်၊ ပထမဆုံး ကြည့်ရန် မြန်စေရန်; ပိုသေးသော cell သည် ပိုနှေးသည်။ ကျော်သွားသော ရေကန်များက Problems panel တွင်လည်း ပေါ်သည်။
- **မြေထုညှိကိရိယာ။** {{ui:မြေထုညှိကိရိယာ…}} သည် cut ညီသည်အထိ pad ကို မြှင့်ခြင်း သို့မဟုတ် နှိမ့်ခြင်း ပြုလုပ်ပြီး ၎င်းတို့ကြား သယ်ယူမှု ဇယားကို ပြသည်။
- **အကောင်းဆုံး လမ်းကြောင်း။** {{ui:အကောင်းဆုံး လမ်းကြောင်း…}}: စတင်ရာနှင့် အဆုံးကို ရွေးပါ၊ CivilCraft က သင်၏ grade နှင့် curve ကန့်သတ်ချက်များကို ထိန်းသော terrain ပေါ် အစွန်းအသက်သာဆုံး လမ်းကြောင်းကို ရှာပြီး ထိုမှ alignment ကို ဖန်တီးသည်။
- **ရေလှောင်ကန်များ။** {{ui:ရေလှောင်ကန်များ…}} သည် သင်၏ မြေပြင်မှ အဆင့်နှင့် သိုလှောင်မှုကို တွက်ချက်၊ outlet ကိရိယာများ (orifice၊ weir၊ V-notch၊ spillway) ကို ယူ၊ မုန်တိုင်းကို ရေကန်ထဲ ဖြတ်သွားစေပြီး ထိန်းထားသော အမြင့်ဆုံးကို၊ ရေလျော့ချိန် နှင့် freeboard ကို စစ်ဆေးသည်။
- **စစ်တမ်းများမှ တိုးတက်မှု။** {{ui:စစ်တမ်းများမှ တိုးတက်မှု…}} သည် ရက်စွဲမတူသော drone သို့မဟုတ် scan မျက်နှာပြင်များကို ယခင် မြေပြင်နှင့် design နှင့် နှိုင်းယှဉ်သည်: ပမာဏအရ ရာခိုင်နှုန်း ပြီးစီးမှု၊ အလွန်တူး နှင့် အလွန်ဖြည့် ဧရိယာများ၊ ကုန်ပစ္စည်း ပုံများနှင့် ဤအရှိန်ဖြင့် အလုပ်ပြီးမည့်အချိန် (ခန့်မှန်းချက်အဖြစ် အမှတ်အသားပြုထားသည်)။

**ဆိုက်ကို သိခြင်း**

- **လိပ်စာမှ ဆိုက်။** {{ui:လိပ်စာမှ နေရာ…}} သည် ဖွင့်ထားသော ကိုယ်စားလှယ်ပိုင်း၊ အဆောက်အအုံ၊ ဇုန်ဖွဲ့ခြင်း၊ မြေဆီလွှာ၊ ရေလွှမ်းမိုးမှုနှင့် မြေပြင် ဒေတာများကို ဆိုက်တစ်ခုတည်းတွင် စီပေးသည်။ ဆိုက်ကို ပရောဂျက်ဖိုင်ထဲ သိမ်းနိုင်သည်: ရိုက်ထည့်ထားသော လိပ်စာ၊ ရယူထားသော ရက်စွဲနှင့် လိုင်စင်ပါ အရင်းအမြစ်တိုင်း၊ နှင့် ပြန်ရလာသည်များ။ ပရောဂျက်ကို ပြန်ဖွင့်ခြင်း သို့မဟုတ် မျှဝေခြင်း ပြုလုပ်လျှင် ဆိုက်သည် ရှိနေဆဲ ဖြစ်ပြီး ဘာမျှ ထပ်မယူရပါ။ ဆိုက်ဖိုင်အဖြစ် သိမ်းနိုင်သည် သို့မဟုတ် BimCraft သို့ ပို့နိုင်သည်။ [Address to site](topic:address-to-site) ကို ကြည့်ပါ။

**မြေပြင်၊ လမ်း၊ စစ်တမ်း၊ သတ္တုတွင်း၊ ချိတ်ဆက်မှုနှင့် ရထားလမ်း**

- **မြေဆီလွှာနှင့် စောင်းများ။** {{ui:မြေဆီလွှာနှင့် စောင်းများ…}} သည် သင်ရိုက်ထည့်သော တူးတွင်းများကြား မြေဆီလွှာ ပရိုဖိုင်ကို ဆွဲသည်။ Bishop ၏ နည်းလမ်းက သင်၏ မြေပြင်ပေါ် အရေးကြီးသော စက်ဝိုင်းကို ရှာသည်၊ ရေစားပွဲ၊ surcharge နှင့် ငလျင် coefficient ဖြင့်; footing ၏ settlement တွင် consolidation၊ immediate settlement နှင့် အချိန် ပါဝင်သည်။
- **လမ်းဆုံများနှင့် မျဉ်းဆွဲခြင်း။** {{ui:လမ်းဆုံများနှင့် မျဉ်းဆွဲခြင်း…}} သည် legs များကို curb return များ (leg တစ်ခုလျှင် radius တစ်ခု၊ သို့မဟုတ် three-centre return များ)၊ design speed အတွက် sight distance၊ sight triangle များ၏ စစ်ဆေးမှု၊ crosswalk များ၊ stop bar များ၊ အမှတ်အသားများနှင့် sign များ၊ sign schedule ဖြင့် ပေါင်းသည်။ ၎င်းတို့ကို plan ပေါ် ဆွဲပြီး အမည်ပေးထားသော layer များပါ .dxf အဖြစ် သိမ်းသည်။
- **စစ်တမ်း ချိန်ညှိခြင်း။** {{ui:စစ်တမ်းချိန်ညှိခြင်း…}} သည် traverse သို့မဟုတ် network ၏ least-squares ညှိခြင်းကို လုပ်သည်: ညှိပြီး coordinate များ၊ error ellipse များ၊ chi-squared စမ်းသပ်မှုနှင့် မကိုက်ညီသော တိုင်းတာချက်ပေါ် အလံ။ ကိုယ်တိုင်ရပ်သော network များ၊ compass rule နှင့် RW5 ဖြင့် traverse ပိတ်ခြင်း၊ GSI၊ JobXML သို့မဟုတ် CSV field ဖိုင်များ ပါဝင်ပြီး ညှိပြီး အမှတ်များကို CSV အဖြစ် သိမ်းသည်။
- **ဖွင့်တူးတွင်းများ။** {{ui:ဖွင့်တူးတွင်းများ…}} သည် drill နမူနာများကို block model နှင့် သင်၏ စောင်းထောင့်အတွင်းရှိ နောက်ဆုံး တူးတွင်းအဖြစ် ပြောင်းသည်၊ strip ratio၊ bench အလိုက် ဇယားနှင့် grade နှင့် tonnage curve ပါသည်။ revenue factor အလိုက် ဆင့်ကဲ တူးတွင်းများနှင့် discounted cash flow ပါသော ထုတ်လုပ်မှု အစီအစဉ်လည်း ရှိသည်။
- **ရေဒီယို လင့်ခ်များ။** {{ui:ရေဒီယို လင့်ခ်များ…}} သည် ကမ္ဘာ၏ ဖောင်းကားမှု၊ ပထမ Fresnel ဇုန်၊ link budget၊ fade margin နှင့် multipath outage ဖြင့် သင်၏ မြေပြင်ပေါ် မြင်ကွင်း လိုင်းကို စစ်ဆေးပြီး လမ်းကြောင်းကို ရှင်းစေမည့် မာစ် အမြင့်ကို ပေးသည်။ fibre loss budget၊ route ပမာဏများနှင့် ကျောက်တိုင်ပေါ် လေအားလည်း ပါသည်။
- **ရထားလမ်း ခွဲများ။** {{ui:ရထားလမ်းခွဲများ…}} သည် frog နံပါတ်မှ turnout ဖန်တီးသည်၊ ဘေးကပ်လမ်းများကြား crossover များနှင့် cant ဖြင့် စောင်းထားပြီး ကွေးတွင် ကျယ်ပြန့်သော structure gauge ကို ပြုလုပ်သည်။ turnout ကို alignment ၏ station တစ်ခုတွင် ထားနိုင်သည်။

### 0.8.1 တွင် ပြင်ဆင်ပြီး

- **DWG class အပိုင်း။** အမျိုးအစား မှားဖတ်ခံခဲ့ရသည် (GitHub cadcraft#5)။ CadCraft၊ BimCraft၊ ModelCraft နှင့် TakeoffCraft နှင့်အတူ CivilCraft တွင် ပြင်ဆင်ပြီး။
- **အလုပ်လုပ်စဉ် ဘာသာစကား ပြောင်းခြင်း။** CadCraft Studio နှင့် ထုပ်ပိုးထားသော edition များသည် run အချိန်တွင် ဘာသာစကား ပြောင်းနိုင်သည်။ ယခင်က အင်္ဂလိပ်တစ်ခုတည်းသာ ရှိခဲ့သည်။ ပလက်ဖောင်းတိုင်းပေါ် မစမ်းသပ်ရသေးပါ; ဘာသာစကား မပြောင်းလျှင် ပြောပါ။

### ဤဗားရှင်းတွင် မရှိသေးသောအရာများ

- **ဤအရာများသည် တွက်ချက်မှု အကူအညီများ ဖြစ်သည်။** ပြတင်းပေါက်အသစ်များတွင် ရလဒ်တိုင်းကို အင်ဂျင်နီယာ စစ်ဆေးရမည်။ မြေဆီလွှာ ခိုင်ခံမှုများသည် မြေဆီလွှာအုပ်စုအတွက် ပုံမှန်တန်ဖိုးများမှ စတင်ပြီး ပြတင်းပေါက်က ထိုသို့ ပြောသည်။
- **မိုးရွာစေရန်။** နမူနာဆိုက်ပေါ် run တစ်ခုသည် browser တွင် fine cell ဖြင့် မိနစ် ၂ ကျော် ယူနိုင်သည်။ လက်ဖြင့် ကိစ္စများနှင့် V-ပုံ catchment တွင် စစ်ဆေးထားသည်၊ အမှန်တကယ် grade လုပ်ထားသော ဆိုက်တွင် မဟုတ်သေးပါ။
- **လိပ်စာမှ ဆိုက်။** သင်ယူလာသော ဖွင့်ထားသော ဒေတာဖိုင်များကို ဖတ်ပြီး ကျွန်ုပ်တို့၏ ကိုယ်ပိုင်ဖိုင်များပေါ်တွင်သာ စမ်းသပ်ထားသည်။ သစ်ပင်များသည် အရင်းအမြစ် မဟုတ်ပါ။ အရင်းအမြစ်များကို ကိုယ်စား ရယူခြင်းသည် privacy စာသား အတည်ပြုမှု ကို စောင့်သည်။
- **စစ်တမ်းမှ တိုးတက်မှု။** မှန်ကန်ရန် ဖန်တီးထားသော စစ်တမ်းများပေါ် သာ စမ်းသပ်ထားသည်။ စာရွက်များနှင့် markup များ (MarkupCraft) အရ တိုးတက်မှု နှင့် မော်ဒယ်နှင့် scan နှိုင်းယှဉ်ခြင်း (BimCraft) တို့ မတည်ဆောက်ရသေးပါ။
- **မြေဆီလွှာနှင့် စောင်းများ။** စက်ဝိုင်းပုံ မျက်နှာပြင်များသာ- wedge သို့မဟုတ် block ရှာဖွေခြင်း မရှိပါ၊ tension crack မရှိပါ။
- **Junctions။** leg တစ်ခုလျှင် radius တစ်ခု၊ truck swept path မရှိပါ၊ corridor ထဲ မဝင်သေးပါ။
- **ကွင်းဆင်းဖိုင်များ။** readers များကို အများပြည်သူ ဖော်မတ် ဖော်ပြချက်များမှ ရေးထားပြီး ကျွန်ုပ်တို့ ပြုလုပ်ထားသော ဖိုင်များပေါ် စမ်းသပ်ထားသည်။ အမှန်တကယ် instrument ဖိုင်များ လိုအပ်သည်။
- **Links နှင့် rail။** Radio links: free-space loss နှင့် multipath သာ (မိုးကြောင့် fade သို့မဟုတ် antenna pattern မရှိ)၊ ရထားလမ်း စံချိန် မရှိ: ကန့်သတ်ချက်တိုင်း နေရာယူထားသော တန်ဖိုးများ ဖြစ်ပြီး ရထားလမ်းအင်ဂျင်နီယာ မစစ်ဆေးရသေးသော ကြမ်းဂဏန်းများ ဖြစ်သည်။
- **Windows နှင့် macOS။** 0.8 ကို code-signed မလုပ်ထားပါ။ Windows က သတိပေးနိုင်သည်၊ macOS က right-click ပြီး Open ဟု မေးသည်။

## ဘာတွေ သင်ယူရမလဲ

မပြန့်ပြူးသော ဆိုက်ပေါ်တွင် ဆိုလာဇယား အကွက်ကို မည်သို့ခင်းရမလဲ၊ နံပါတ်တွေရဲ့ အဓိပ္ပာယ်ကို ဘာလဲဆိုတာ သင်ယူပါ။ Surface › နောက်ထပ် › Solar arrays မှ ဖွင့်ပါ။

## ဇယားများ ခင်းကျင်းခြင်း

1. **Where** ကို ရွေးပါ - ပရောဂျက်၏ parcel သို့မဟုတ် pad တစ်ခု၊ ဒါမှမဟုတ် ဧရိယာ၏ cornerများကို ရိုက်ထည့်ပါ။ **ဗလာ** ဖြစ်နေရမည့် pad သို့မဟုတ် parcel များကို (အဆောက်အအုံ၊ ကန်) အမှန်ခြစ်ပါ။
2. ဆိုက်၏ **latitude နှင့် longitude** ကို ရိုက်ထည့်ပါ။ နေရောင်သည် ၎င်းတို့ပေါ် မူတည်သည်၊ ခန့်မှန်းခြင်း မပြုပါ။ ပရောဂျက်တွင် coordinate system ရှိပါက **Place from the coordinate system** က ၎င်းတို့ကို ဖြည့်ပေးပါမည်။
3. tilt၊ facing (ဗလာသည် ညီမျှခြားဘက်သို့ ဖြစ်သည်)၊ ဇယားတစ်ခုတွင် module မည်မျှပါမည်၊ module ၏ power နှင့် အရွယ်အစားကို သတ်မှတ်ပါ။ module နံပါတ်များသည် အထွေထွေတန်ဖိုးများဖြင့် စတင်ပြီး ထိုသို့ အမှတ်အသားပြုထားပါသည်၊ သင့်ကိုယ်ပိုင်တန်ဖိုးကို ရိုက်ထည့်ပါ။
4. **Lay out tables** ကို နှိပ်ပါ။ window တွင် ဇယားနှင့် module အရေအတွက်၊ kWp အရွယ်အစားနှင့် အတန်းမှ အတန်းသို့ အကွာအဝေးကို ပြပါမည်။

ဇယားတစ်ခုစီသည် ဧရိယာအတွင်းရှိ ကော်လံတစ်ခု ဖြစ်ပြီး၊ ရှေ့မှ စတင်ချထားကာ နောက်သို့ လှမ်းချထားပါသည်။ ဇယားကို အောက်ရှိမြေသည် slope limit အတွင်း၊ ဧရိယာနှင့် setback အတွင်းရှိပြီး၊ လိုအပ်သော မြှုပ်တိုင်များသည် သင်သတ်မှတ်ထားသော limit ထက် မမြင့်သည့်နေရာတွင်သာ ထားပါသည်။ မအောင်မြင်သော နေရာများကို ဗလာထားပြီး၊ အရေအတွက်နှင့် အကြောင်းရင်းကို window က ပြပါမည်။

## အတန်းများကို မြေပြင်အလိုက် ချထားခြင်း

ပြားညီသော မြေပေါ်တွင် အတန်းများသည် ပုံမှန် no-shade စည်းမျဉ်းအတိုင်း ခွဲခြားထားပါသည်။ အတန်းတစ်ခု၏ အရိပ်သည် ဆောင်းရာသီ နေ့လည်ခင်း winter solstice တွင် နောက်ရှိအတန်း၏ အောက်ခြေအနားသို့ မရောက်ရပါ။ slope ပေါ်တွင် CivilCraft သည် နောက်အတန်း တကယ်ရပ်တည်နေသော မြေပြင်အတွက် တူညီသော စည်းမျဉ်းကို အသုံးပြုပါသည်။ ဇယားနောက်ရှိ မြေက မြင့်တက်နေလျှင် အတန်းများ ပိုနီးနိုင်ပြီး၊ ဆင်းသက်နေလျှင် ပိုဝေးပါသည်။ window တွင် အနီးဆုံး၊ အဝေးဆုံးနှင့် ပျမ်းမျှ အကွာအဝေးကို ပြန့်ပြားသော မြေအတွက် အကွာအဝေးနှင့်အတူ ပြပါသည်၊ ထို့ကြောင့် terrain က ဘာလုပ်သွားသည်ကို မြင်နိုင်ပါသည်။

ဇယားအလျား ဖြန့်ကျက်မှုကို ၎င်းအောက်ရှိ နမူနာတိုင်းသည် သတ်မှတ်ထားသော clearance ဖြင့် မြေပြင်ကို ရှင်းသွားသည်အထိ မြှုပ်တိုင်ပေါ်တွင် မြှင့်ထားပါသည်။ အမြင့်ဆုံး မြှုပ်တိုင်ကို ရလဒ်တွင် ပြပါသည်။

## တစ်နှစ်စာ စွမ်းအင်

**Year's energy** သည် လတစ်လချင်းစီ၏ ကိုယ်စားပြုနေ့တစ်နေ့အတွက် tilt plane ပေါ်ရှိ အလင်းကို တွက်ချက်ပြီး၊ cell အပူချိန်၊ ရိုက်ထည့်ထားသော ဆုံးရှုံးမှုများ၊ ဇယားများ အချင်းချင်း အရိပ်ထိခြင်းနှင့် ကွယ်ထားသော နေရောင်ကို ဆွဲယူသော တောင်ကုန်းများ၏ horizon ကို ထည့်သွင်းတွက်ပါသည်။ ကောင်းကင်သည် ရှင်းလင်းသော ကောင်းကင် ဖြစ်သောကြောင့် အဖြေသည် အမြင့်ဆုံးကန့်သတ်ချက် ဖြစ်ပါသည်၊ လက်တွေ့ ရာသီဥတုတွင် ပိုနည်းပါမည်။ ၎င်းသည် ဒီဇိုင်းအစောပိုင်း ခန့်မှန်းချက်ဖြစ်ပြီး၊ အထွက်နှုန်း အစီရင်ခံစာ မဟုတ်ပါ။

## သိမ်းဆည်းခြင်း

**Save to the project** သည် inputs နှင့် နံပါတ်များကို ပရောဂျက်ဖိုင်တွင် သိမ်းပါသည်။ ဇယားများကို ဖိုင်ဖွင့်သည့်အခါ မြေပြင်မှ ထပ်မံတွက်ချက်ပါသည်၊ ထို့ကြောင့် မြေမျက်နှာပြင် ပြောင်းလဲပါက ဇယားများလည်း ရွေ့ပါမည်။ plan နှင့် 3D (Show › Solar arrays) တွင် ပြပါသည်။ ဇယားစာရင်းကို CSV အဖြစ် ဒေါင်းလုဒ်ဆွဲနိုင်ပါသည်။ undo အဆင့်တစ်ခုဖြင့် array တစ်ခုကို ဖယ်ရှားခြင်း သို့မဟုတ် ပြန်ထားခြင်း ပြုလုပ်နိုင်ပါသည်။

## မတည်ဆောက်ရသေးသော အရာများ

ရှင်းလင်းသော ကောင်းကင်အစား ရာသီဥတုဒေတာ၊ အရှေ့-အနောက် ဦးတည်ချက်တွင် မြေပြင်ကို လိုက်သော ဇယားများ၊ tracker များနှင့် CivilCraft ရှိ လျှပ်စစ်ဒီဇိုင်း (strings၊ wire၊ inverters) တို့ ပါဝင်ပါသည်။ BimCraft ၏ Solar PV pane တွင် strings နှင့် အမိုးများအတွက် one-line ရှိပါသည်။

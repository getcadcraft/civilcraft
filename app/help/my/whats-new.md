CivilCraft 0.8 (2026-11-01) နှင့် 0.8.1 (2026-11-02) တွင် ပြောင်းလဲချက်များဖြစ်ပြီး 0.7 နှင့် နှိုင်းယှဉ်ထားသည်။ အဓိက အသစ်အပိုင်းများမှာ သင့် grading နှင့် ဆိုဒ်ကို စမ်းသပ်သော ကိရိယာများ (မိုး၊ မြေထု၊ လမ်းကြောင်း၊ ရေကန်၊ တိုးတက်မှု) နှင့် မြေ၊ လမ်း၊ စစ်တမ်း၊ သတ္တုတွင်း၊ link နှင့် မီးရထား အတွက် တွက်ချက်ဝင်းဒိုး ခြောက်ခု ဖြစ်သည်။

## အသစ်

### သင့် grading ကို စမ်းသပ်ခြင်း

- **Make it rain.** {{ui:မိုးရွာစေရန်…}} (အောက်တွင် {{ui:Surface}}) သည် grade လုပ်ထားသော မြေပေါ် မိုးချသည်။ ရေသည် pads မှ စီးဆင်းပြီး နိမ့်သော ထောင့်များတွင် ရေကန်ဖြစ်ပြီး ငယ်လွန်းသော ကန်များကို လျှံစေသည်ကို ကြည့်နိုင်သည်။ run က animation ဖြစ်ပြီး volumes၊ peak outflow နှင့် ကန်တစ်ခုစီ၏ CSV ကို ပေးသည်။ မူလ cell ကြမ်းသဖြင့် ပထမကြည့်ရှုမှု မြန်သည်; cell ပိုသေးလျှင် ပိုနှေးသည်။ လျှံသော ကန်များသည် Problems panel တွင်လည်း ပေါ်သည်။
- **မြေထုညှိကိရိယာ။** {{ui:မြေထုညှိကိရိယာ…}} သည် cut နှင့် fill ညီသည်အထိ pad ကို မြှင့် သို့မဟုတ် နှိမ့်ပြီး ၎င်းတို့ကြား haul ဇယားကို ပြသည်။
- **အကောင်းဆုံး လမ်းကြောင်း။** {{ui:အကောင်းဆုံး လမ်းကြောင်း…}}: စတင်နေရာနှင့် အဆုံးကို ရွေးပါ၊ CivilCraft က သင့် grade နှင့် curve ကန့်သတ်ချက်များကို ထိန်းသော terrain တစ်လျှောက် အနည်းဆုံးကုန်ကျစရိတ် လမ်းကြောင်းကို ရှာပြီး ထိုမှ alignment ဖန်တီးသည်။
- **ရေလှောင်ကန်များ။** {{ui:ရေလှောင်ကန်များ…}} သည် သင့် ground မှ stage နှင့် storage ကို တွက်ချက်သည်၊ outlet devices (orifice, weir, V-notch, spillway) ကို ယူသည်၊ မိုးကို ကန်ထဲ ဖြတ်စီးစေပြီး peak ထိန်းထားမှု၊ drawdown အချိန်နှင့် freeboard ကို စစ်ဆေးသည်။
- **စစ်တမ်းမှ တိုးတက်မှု။** {{ui:စစ်တမ်းများမှ တိုးတက်မှု…}} သည် ရက်စွဲ မတူသော drone သို့မဟုတ် scan မျက်နှာပြင်များကို မူလ ground နှင့် design နှင့် နှိုင်းယှဉ်သည်: ထုထည်အလိုက် ရာခိုင်နှုန်း ပြီးစီးမှု၊ အလွန်တူးထားသော နှင့် အလွန်ဖြည့်ထားသော ဧရိယာများ၊ stockpiles၊ နှင့် ဤအရှိန်ဖြင့် အလုပ်ပြီးမည့်အချိန် (ခန့်မှန်းချက်အဖြစ် အမှတ်အသားပြ)။

### ဆိုဒ်ကို သိခြင်း

- **လိပ်စာမှ ဆိုဒ်။** {{ui:လိပ်စာမှ နေရာ…}} သည် ဖွင့်ထားသော parcel၊ အဆောက်အအုံ၊ zoning၊ မြေဆီ၊ ရေလွှမ်းမိုးမှုနှင့် terrain ဒေတာများကို ဆိုဒ်တစ်ခုတည်းပေါ် ညှိသည်။ ဆိုဒ်ကို စီမံကိန်းဖိုင်တွင် ထားနိုင်သည်: ရိုက်ထည့်ထားသော လိပ်စာ၊ ရင်းမြစ်တစ်ခုစီနှင့် ရယူသော နေ့နှင့် လိုင်စင်၊ ပြန်လာသည့်အရာ။ စီမံကိန်းကို ပြန်ဖွင့် သို့မဟုတ် မျှဝေပါက ဆိုဒ်သည် ဆက်ရှိနေပြီး ထပ်မရယူရ။ site ဖိုင်အဖြစ် သိမ်းနိုင်သည် သို့မဟုတ် BimCraft သို့ ပို့နိုင်သည်။ [လိပ်စာမှ ဆိုဒ်](topic:address-to-site) ကို ကြည့်ပါ။

### မြေ၊ လမ်း၊ စစ်တမ်း၊ သတ္တုတွင်း၊ link နှင့် မီးရထား

- **မြေဆီနှင့် စောင်းများ။** {{ui:မြေဆီလွှာနှင့် စောင်းများ…}} သည် သင်ရိုက်ထည့်သော borings များကြား မြေဆီလွှာ profile ကို ဆွဲသည်။ Bishop ၏ နည်းလမ်းက သင့်မြေပေါ်တွင် critical circle ကို ရှာသည်၊ water table၊ surcharge နှင့် ငလျင် coefficient ပါသည်; footing ၏ settlement တွင် consolidation၊ immediate settlement နှင့် အချိန်ပါသည်။
- **လမ်းဆုံများနှင့် မျဉ်းဆွဲခြင်း။** {{ui:လမ်းဆုံများနှင့် မျဉ်းဆွဲခြင်း…}} သည် legs များကို curb returns (leg တစ်ခုလျှင် radius တစ်ခု၊ သို့မဟုတ် three-centre returns) ဖြင့် ပေါင်းသည်၊ design speed အတွက် sight distance၊ sight triangles စစ်ဆေးမှု၊ crosswalks၊ stop bars၊ markings နှင့် sign schedule ပါသော signs။ ၎င်းတို့ကို plan ပေါ် ဆွဲပြီး အမည်ပေး layers ပါသော .dxf အဖြစ် သိမ်းသည်။
- **Survey adjustment။** {{ui:စစ်တမ်းချိန်ညှိခြင်း…}} သည် traverse သို့မဟုတ် network ၏ least-squares adjustment ကို လုပ်သည်: adjusted coordinates၊ error ellipses၊ chi-squared test နှင့် မကိုက်ညီသော တိုင်းတာချက်ပေါ်ရှိ flag။ Free networks၊ compass rule ဖြင့် traverse ကို ပိတ်ခြင်းနှင့် RW5၊ GSI၊ JobXML သို့မဟုတ် CSV field ဖိုင်များ ပါဝင်ပြီး adjusted အမှတ်များကို CSV အဖြစ် သိမ်းသည်။
- **ဖွင့်တူးတွင်းများ။** {{ui:ဖွင့်တူးတွင်းများ…}} သည် drill နမူနာများကို block model နှင့် သင့် slope angle အတွင်းရှိ နောက်ဆုံး pit အဖြစ် ပြောင်းသည်၊ strip ratio၊ bench အလိုက် ဇယားနှင့် grade နှင့် tonnage curve ပါသည်။ revenue factor အလိုက် nested pits နှင့် discounted cash flow ပါသော production schedule လည်း ရှိသည်။
- **ရေဒီယို လင့်ခ်များ။** {{ui:ရေဒီယို လင့်ခ်များ…}} သည် မြေကြီး၏ bulge၊ ပထမ Fresnel zone၊ link budget၊ fade margin နှင့် multipath outage ဖြင့် သင့်မြေပေါ် line of sight ကို စစ်ပြီး လမ်းကြောင်းကို ရှင်းနိုင်သော mast အမြင့်ကို ပေးသည်။ fibre loss budgets၊ route quantities နှင့် တာဝါပေါ်ရှိ လေတိုက်အားလည်း လုပ်နိုင်သည်။
- **မီးရထား လမ်းခွဲများ။** {{ui:ရထားလမ်းခွဲများ…}} သည် ၎င်း၏ frog နံပါတ်မှ လမ်းခွဲတစ်ခု၊ အပြိုင်လမ်းများကြား crossovers နှင့် cant ဖြင့် စောင်းပြီး curve တွင် ကျယ်လာသော structure gauge ကို ပြုလုပ်သည်။ လမ်းခွဲတစ်ခုကို alignment ၏ station တစ်ခုတွင် ထားနိုင်သည်။

ကြည့်ပါ: [မြေဆီ၊ လမ်းဆုံ၊ စစ်တမ်းချိန်ညှိခြင်း၊ တူးတွင်း၊ ရေဒီယို လင့်ခ်နှင့် လမ်းခွဲများ](topic:soils-roads-survey-mines-links)။

## အက်ပ်တိုင်းတွင်

- **ဘာသာစကားများ။** ဘာသာစကား 54 မျိုး၊ ၎င်းတို့ထဲမှ 10 မျိုး အသစ်။ အင်္ဂလိပ်မဟုတ်သော ဘာသာစကားများသည် ဘာသာစကား ပိုင်ရှင်က မဖတ်မချင်း machine မူကြမ်းများ ဖြစ်သည်။ အကူအညီ အကြောင်းအရာများသည် အများစု အင်္ဂလိပ်ဖြစ်ဆဲ။
- **Toolbar အတန်းများ။** {{ui:ဆက်တင်များ}} › {{ui:အထွေထွေ}} › {{ui:ကိရိယာဘား အတန်းများ}}: Wrap (ယခင်ကဲ့သို့), 2 rows သို့မဟုတ် 1 row။ CivilCraft ၏ Ribbon က အသုံးအများဆုံး ကိရိယာကို ကြီးကြီးပြ၊ နောက်ထပ်များကို သေးသေးပြ၊ ကျန်သည်များကို အုပ်စုအမည်၏ မြားနောက်ကွယ်တွင် ထားသည်။
- **Input devices။** Trackpad, pen, 3D mouse, controller နှင့် MIDI ဖြင့် app များကို ထိန်းနိုင်သည်။
- **Problems။** အက်ပ်တိုင်းတွင် သတိပေးသော ပြဿနာများ အကန့် ရှိပြီး regulation packs ကို ဖတ်သော စစ်ဆေးချက်များ ပါသည်။
- **Live။** Live session တွင် ဘယ်သူ ဘယ်နေရာရှိသည်ကို ကြည့်နိုင်သည်။
- **Add-ons။** add-on စာရင်း၊ lighting add-ons ပါသည်။
- **သင့် AI ချိတ်ဆက်ခြင်း။** သင်ချိတ်ဆက်သော assistant မည်သည့်ပါ CivilCraft ၏ ကိရိယာများကို မောင်းနိုင်သည်။ CadCraft Studio အတွင်း တစ်ချက်နှိပ် ချိတ်ဆက်ခြင်းနှင့် hosted connector မပြင်ဆင်ရသေးကြောင်း မှတ်ချက် ပါသည်။ [AI assistant ဖြင့် သင့်ဆိုဒ်ပေါ် အလုပ်လုပ်ခြင်း](topic:assistants) ကို ကြည့်ပါ။

## 0.8.1 တွင် ပြင်ဆင်ထားသည်များ

- **DWG classes အပိုင်း။** ၎င်းကို မှားသော အမျိုးအစားအဖြစ် ဖတ်ခဲ့သည် (GitHub cadcraft#5)။ CadCraft, BimCraft, ModelCraft နှင့် TakeoffCraft နှင့်အတူ CivilCraft တွင် ပြင်ဆင်ထားသည်။
- **အလုပ်လုပ်နေချိန် ဘာသာစကား ပြောင်းခြင်း။** CadCraft Studio နှင့် packed editions များက run time တွင် ဘာသာစကား ပြောင်းနိုင်သည်။ ယခင်က အင်္ဂလိပ်တစ်မျိုးတည်းသာ ရှိခဲ့သည်။ platform အားလုံးတွင် မစမ်းသပ်ရသေးပါ: ဘာသာစကား မပြောင်းပါက ကျွန်ုပ်တို့ကို အသိပေးပါ။

## ဤဗားရှင်းတွင် မပါသေးသည်များ

- **ဤသည်များမှာ တွက်ချက်ကိရိယာများ ဖြစ်သည်။** အသစ်ဝင်းဒိုးများရှိ ရလဒ်တိုင်း အင်ဂျင်နီယာ၏ စစ်ဆေးမှု လိုသည်။ မြေဆီခွန်အား typical တန်ဖိုးများကို မြေဆီအုပ်စုအလိုက် စတင်သည်၊ ဝင်းဒိုးက ထိုသို့ ပြောသည်။
- **မိုးရွာစေရန်။** ဘရောက်ဆာတွင် နမူနာဆိုဒ်ပေါ် run တစ်ခုသည် fine cell တွင် မိနစ်နှစ်ခုကျော် ကြာနိုင်သည်။ လက်ဖြင့် ဖြစ်ရပ်များနှင့် V-shaped catchment ဖြင့် စစ်ဆေးထားသော်လည်း အမှန်တကယ် graded ဆိုဒ်ပေါ် မစစ်ရသေးပါ။
- **လိပ်စာမှ ဆိုဒ်။** ဖွင့်ထားသော open data ဖိုင်များကို ဖတ်သည်၊ ကျွန်ုပ်တို့၏ကိုယ်ပိုင်ဖိုင်များပေါ်တွင်သာ စမ်းသပ်ထားသည်။ သစ်ပင်များသည် ရင်းမြစ် မဟုတ်ပါ။ သင့်အတွက် ရင်းမြစ်များ ယူခြင်းသည် privacy စကားလုံးများ ပြီးမှ ဖြစ်မည်။
- **စစ်တမ်းမှ တိုးတက်မှု။** ဖန်တီးထားသော စစ်တမ်းများပေါ်တွင်သာ စမ်းသပ်ထားသည်။ စာရွက်များနှင့် markups (MarkupCraft) ပေါ်ရှိ တိုးတက်မှု နှင့် scan နှင့် model (BimCraft) နှိုင်းယှဉ်ခြင်းကို မတည်ဆောက်ရသေးပါ။
- **မြေဆီနှင့် စောင်းများ။** စက်ဝိုင်းမျက်နှာပြင်များသာ: wedge သို့မဟုတ် block ရှာဖွေမှု မရှိ၊ tension crack မရှိ။
- **လမ်းဆုံများ။** leg တစ်ခုလျှင် radius တစ်ခု၊ truck swept paths မရှိ၊ corridor ထဲ မဝင်သေး။
- **Field ဖိုင်များ။** readers များကို public format ဖော်ပြချက်များမှ ရေးထားပြီး ကျွန်ုပ်တို့ ဖန်တီးသော ဖိုင်များပေါ် စမ်းထားသည်။ အမှန်တကယ် instrument ဖိုင်များ လိုအပ်သည်။
- **Links နှင့် မီးရထား။** ရေဒီယို လင့်ခ်များ: free-space loss နှင့် multipath သာ (မိုးကြောင့် fade သို့မဟုတ် antenna pattern မရှိ)၊ မီးရထား စံချိန်စံညွှန်း မရှိ: ရထား ကန့်သတ်ချက်တိုင်း placeholder ဖြစ်ပြီး မည်သည့် ရထားအင်ဂျင်နီယာမျှ မစစ်ဆေးရသေးသော မူကြမ်းနံပါတ်များ ဖြစ်သည်။
- **Windows နှင့် macOS။** 0.8 သည် code-signed မဟုတ်ပါ။ Windows က သတိပေးနိုင်ပြီး macOS က right-click ပြီး Open ရန် မေးသည်။

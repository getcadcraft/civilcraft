မြေပုံအလွှာများသည် သင့်ဒီဇိုင်းအောက်တွင် ဆွဲထားသော ပုံများဖြစ်သည်: world file ပါသော လေယာဉ်မှ ဓာတ်ပုံ၊ သို့မဟုတ် အင်တာနက်ပေါ်ရှိ ဆာဗာများမှ မြေပုံများ။ ၎င်းတို့သည် မျက်နှာပြင်ပေါ်တွင်သာ ဆိုက်အကြောင်းအရာ ဖြစ်သည်: PDF ပလော့၊ DXF သို့မဟုတ် DWG ထုတ်ယူမှုများ၊ သို့မဟုတ် 3D view တွင် **မပါ**။

{{ui:GIS}} အုပ်စုတွင် {{ui:Map}} ကို ရွေးပါ။ **မြေပုံအလွှာများ** ဒိုင်ယာလော့ခ်သည် စီမံကိန်း၏ အလွှာများကို စာရင်းပြပြီး အသစ်များ ထည့်သည်။ မြေပုံအလွှာများသည် စီမံကိန်း၏ ကိုဩဒိနိတ်စနစ် လိုအပ်သည် ([စီမံကိန်း၏ ကိုဩဒိနိတ်စနစ်ကို သတ်မှတ်ခြင်း](topic:coordinate-systems)), world file သည် စီမံကိန်း၏ ကိုယ်ပိုင် ကိုဩဒိနိတ်များကို သုံးထားသော ပုံမှလွဲ၍။

## အင်တာနက် ဆက်တင်

သင်ခွင့်မပြမချင်း CivilCraft သည် မြေပုံဆာဗာကို တစ်ခုခုမှ ဘယ်တော့မှ မတောင်းပါ: {{ui:Settings}}၊ {{ui:CivilCraft}}၊ **အင်တာနက်မှ မြေပုံအလွှာများ**: **Off** (စတင်ချိန်) သို့မဟုတ် **On**။

:::note
On ဖြစ်သောအခါ CivilCraft သည် သင်ထည့်သော မြေပုံဆာဗာများထံ ဖန်သားပြင်ပေါ်ရှိ ဧရိယာ၏ ပုံများကို တောင်းသည်။ သင့်ပုံဆွဲသည် ဤကွန်ပျူတာတွင်သာ ရှိနေသည်; ဆာဗာသည် ဧရိယာနှင့် သင့် အင်တာနက် လိပ်စာကို မြင်သည်။
:::

ပိတ်ထားစဉ် အင်တာနက် အလွှာများကို ဒိုင်ယာလော့ခ်တွင် စာရင်းပြသော်လည်း အကြောင်းရင်းနှင့်အတူ မှိန်ထားပြီး၊ တစ်ခုမှ ဆွဲခြင်း သို့မဟုတ် တောင်းခြင်း မရှိပါ။ မြေပုံဆာဗာများကို အမည်ပေးထားသော စီမံကိန်းကို ဖွင့်သည့်အခါလည်း ၎င်းတို့ထံ ဆက်သွယ်မည် မဟုတ်ပါ။ ဖိုင်မှ ပုံသည် နည်းလမ်းနှစ်ခုလုံးဖြင့် အလုပ်လုပ်သည်။ ဒိုင်ယာလော့ခ်၏ {{ui:Open Settings}} ခလုတ်က သင့်ကို ထိုနေရာသို့ ခေါ်သွားသည်။

## တည်နေရာ သတ်မှတ်ထားသော ပုံ (အင်တာနက်မလိုပါ)

1. **အလွှာ ထည့်ရန်** အတွင်း **တည်နေရာ သတ်မှတ်ထားသော ပုံ** ကို ထားပြီး ဖိုင်များကို ရွေးပါ: ပုံ (PNG သို့မဟုတ် JPEG) **နှင့်အတူ** ၎င်း၏ world file (PNG အတွက် `.pgw`၊ JPEG အတွက် `.jgw`၊ သို့မဟုတ် `.wld`) နှင့် ရှိလျှင် ၎င်း၏ `.prj`။ ၎င်းတို့ကို အစီအစဉ်ပေါ်သို့ အတူ ချနိုင်သည်။
2. `.prj` မပါလျှင် CivilCraft က world file သုံးသော စနစ်ကို မေးသည်: {{ui:စီမံကိန်း၏ စနစ်}} (အများဆုံး)၊ {{ui:Pick a system…}}၊ သို့မဟုတ် စနစ်မပါသော စီမံကိန်းတွင် **စီမံကိန်း ကိုဩဒိနိတ်များ**။
3. ပုံသည် အစီအစဉ်အောက်တွင် ပေါ်လာပြီး {{ui:Fit}} တွင် ပါဝင်သည်။

RGB GeoTIFF (GeoTIFF အဖြစ် သိမ်းထားသော လေယာဉ်မှ ဓာတ်ပုံ) သည် ၎င်း၏ကိုယ်ပိုင် နေရာနှင့် စနစ်ကို ဆောင်သည်: ၎င်းကို သီးခြားဖွင့်ပါ။ ပုံကို **စီမံကိန်းဖိုင်အတွင်း** ထားသည် (25 MB အထိ); ပိုကြီးသောပုံကို ၎င်း၏ အရွယ်အစားဖြင့် ငြင်းပယ်သည်၊ ထို့ကြောင့် ပိုသေးသော မိတ္တူ (pixel နည်းနည်း၊ သို့မဟုတ် JPEG) သိမ်းပါ။

## Tile၊ WMS၊ WMTS နှင့် မြေပုံဝန်ဆောင်မှုများ

ပထမ **အင်တာနက်မှ မြေပုံအလွှာများ** ကို ဖွင့်ပါ။ ထို့နောက် **အလွှာ ထည့်ရန်** တွင်:

| မှ | ကူးထည့်ရမည့်အရာ | CivilCraft ဘာလုပ်သလဲ |
|---|---|---|
| Tile URL | `{z}`၊ `{x}` နှင့် `{y}` (သို့မဟုတ် `{-y}`) ပါသော ပုံစံ၊ နှင့် ဆာဗာစာလုံးအတွက် `{s}`၊ ဥပမာ `https://tile.example.org/{z}/{x}/{y}.png`။ အမည်နှင့် ၎င်း၏ attribution ပေးပါ။ | ဖန်သားပြင်ပေါ်ရှိ ဧရိယာနှင့် zoom အတွက် web Mercator တွင် tile များ။ |
| WMS ဆာဗာ | ဆာဗာ၏ လိပ်စာ၊ သို့မဟုတ် ၎င်း၏ GetCapabilities လင့်ခ်။ {{ui:အလွှာများ ရယူရန်}} ကို ရွေးပြီး အလွှာကို ရွေးပါ။ | ဖန်သားပြင်ပေါ်ရှိ ဧရိယာ၏ ပုံတစ်ပုံ၊ ဆာဗာက ပံ့ပိုးလျှင် စီမံကိန်း EPSG ကုဒ်ဖြင့် တောင်းသည်၊ မဟုတ်လျှင် web Mercator သို့မဟုတ် WGS 84 ဖြင့်။ |
| WMTS ဆာဗာ | ဆာဗာ၏ လိပ်စာ၊ သို့မဟုတ် ၎င်း၏ `WMTSCapabilities.xml`။ {{ui:အလွှာများ ရယူရန်}} ကို ရွေးပြီး အလွှာနှင့် tile matrix set ကို ရွေးပါ။ | စီမံကိန်း၏ စနစ်ရှိလျှင် ထို set မှ tile များ၊ မဟုတ်လျှင် web Mercator။ |
| ArcGIS မြေပုံဝန်ဆောင်မှု (REST) | `/MapServer` သို့မဟုတ် `/ImageServer` ဖြင့် အဆုံးသတ်သော URL။ {{ui:ဝန်ဆောင်မှုကို ဖတ်ရန်}} ကို ရွေးပါ။ | cache ထားသော web Mercator ဝန်ဆောင်မှုများကို ၎င်းတို့၏ tile များမှ ဆွဲသည်; အခြားများကို ဖန်သားပြင်ပေါ်ရှိ ဧရိယာ၏ ပုံတစ်ပုံ တောင်းသည်။ |

ဆာဗာများကို ကြိုသတ်မှတ်ထားခြင်း မရှိပါ။ အများပြည်သူ ဥပမာများ၊ အားလုံးသည် USGS National Map မှ ဖြစ်သည် (public domain):

- WMS: `https://basemap.nationalmap.gov/arcgis/services/USGSTopo/MapServer/WMSServer`
- WMTS: `https://basemap.nationalmap.gov/arcgis/rest/services/USGSTopo/MapServer/WMTS/1.0.0/WMTSCapabilities.xml`
- မြေပုံဝန်ဆောင်မှု: `https://basemap.nationalmap.gov/arcgis/rest/services/USGSTopo/MapServer` (လေယာဉ်မှ ဓာတ်ပုံအတွက် `USGSImageryOnly` လည်း)

မြို့နှင့် ခရိုင် GIS ဌာနများစွာသည် ၎င်းတို့၏ကိုယ်ပိုင် WMS သို့မဟုတ် မြေပုံဝန်ဆောင်မှုများကို ထုတ်ပြန်သည်; ၎င်းတို့၏ GIS စာမျက်နှာများတွင် လိပ်စာ ရှိသည်။ အကောင့်ဝင်ရန် သို့မဟုတ် ကီးတောင်းသော ဆာဗာသည် အလုပ်မလုပ်ပါ: CivilCraft သည် အသုံးပြုသူအမည်၊ စကားဝှက် သို့မဟုတ် ကီး မပို့ပါ။

## အလွှာများ ဆွဲပုံ

- စီမံကိန်းမှ အခြားစနစ်ရှိ ပုံများကို ၎င်းထဲသို့ ပြောင်းလဲ (warp) သည်: ပုံကို အပိုင်းများ ဖြတ်ထားပြီး တစ်ခုစီကို တိကျသော ပြောင်းလဲမှု ထားရာနေရာမှ ဖန်သားပြင် pixel လေးပုံတစ်ပုံအတွင်း ရှိစေရန် နေရာချသည်။
- Tile များကို ဖန်သားပြင်ပေါ်ရှိ ဧရိယာနှင့် zoom အတွက် ရွေးသည်: မြင်ကွင်းတစ်ခုအတွက် 64 ထက် ဘယ်တော့မှ မပိုပါ၊ တစ်ကြိမ်လျှင် 6 ခု။ ရွှေ့ သို့မဟုတ် zoom လုပ်သည့်အခါ ဟောင်းသော မြင်ကွင်းအတွက် တောင်းဆိုမှုများကို ဖျက်သည်။ Tile ၂၀၀ ခန့်ကို မှတ်ဉာဏ်တွင် ထားသည် (disk တွင် ဘာမှ မသိမ်းပါ)။
- WMS သို့မဟုတ် မြေပုံဝန်ဆောင်မှု ပုံကို မြင်ကွင်း ရပ်သွားသည့်အခါ တစ်ကြိမ် တောင်းသည်; ရောက်လာသည်အထိ နောက်ဆုံးပုံ နေရာတွင် ရှိနေသည်။
- ဖန်သားပြင်ပေါ်ရှိ အလွှာတစ်ခုစီ၏ attribution ကို အစီအစဉ်၏ ညာဘက်အောက်ထောင့်တွင် သေးသေးလေး ပြသည်။

## အလွှာများ ပြောင်း၊ စီ၊ ဖယ်

ဒိုင်ယာလော့ခ်တွင် အလွှာတစ်ခုစီတွင် ပြ/ဖျောက် checkbox၊ **အလင်းမှိန်ပမာဏ** slider၊ အလွှာကို စောစောဆွဲရန် (အောက်) သို့မဟုတ် နောက်ကျမှ (အပေါ်) အမြှားများ၊ zoom ခလုတ် (ပုံများ) နှင့် ဖယ်ရှားခလုတ် ရှိသည်။ စာရင်းထဲရှိ ပထမအလွှာကို အောက်ဆုံးတွင် ဆွဲသည်။ ပြောင်းလဲမှု တစ်ခုစီသည် ပြန်ဖျက်ခြင်း အဆင့်တစ်ခု။

## အလွှာ ဘာမှ မပြသောအခါ

အကြောင်းရင်းကို အခြေအနေ မျဉ်းတွင် တစ်ကြိမ် ပေါ်ပြီး ဒိုင်ယာလော့ခ်တွင် အလွှာ၏ အမည်အောက်တွင် ဆက်ရှိနေသည်:

| မက်ဆေ့ချ် | ဘာလုပ်ရမည် |
|---|---|

## စစ်ဆေးထားသည်များ

- Tile နံပါတ်များကို စံ web Mercator tiling နှင့် စစ်ဆေးထားသည်; WMS 1.1.1 နှင့် 1.3.0၊ WMTS နှင့် မြေပုံဝန်ဆောင်မှု ဖြေချက်များကို လက်ဖြင့်ရေးသားထားသော ဖိုင်များနှင့် USGS National Map နှင့် terrestris OpenStreetMap ဆာဗာများမှ သိမ်းထားသော အမှန်တကယ် ဖြေချက်များမှ ဖတ်ထားသည်; WMS 1.3.0 တောင်းဆိုမှုများသည် စံအတိုင်း EPSG:4326 အတွက် latitude ကို ပထမ ထားသည်။
- Warping ကို PROJ ၏ နံပါတ်များမှတဆင့် pixel တစ်ခုချင်းစီ တိကျသော ပြောင်းလဲမှုနှင့် နှိုင်းယှဉ်ထားသည်: tile များ၊ WMS ပုံများနှင့် ခရိုင်အရွယ် ပုံအတွက် 0.13 px အတွင်း၊ ဆိုက်စကေးနှင့် zoom ထွက်သည့်အခါ။
- world file ပါသော ပုံနှင့် GDAL (rasterio မှတဆင့်) ရေးသား သော RGB GeoTIFF ကို ၎င်းတို့၏ နေရာ ပြောသည့်နေရာတွင် ဆွဲထားသည်၊ ဘရောက်ဇာတွင် pixel တစ်ခုချင်းစီ စစ်ဆေးထားသည်။
- ဘရောက်ဇာတွင် စမ်းသပ်ကွန်ပျူတာပေါ်ရှိ ယာယီဆာဗာနှင့် ဆန့်ကျင်၍: tile များသည် PROJ က အမှတ်တစ်ခုစီ ထည့်သော tile တွင် ကျရောက်သည်၊ WMS ပုံသည် 2 px အတွင်း ကျရောက်သည်၊ တောင်းဆိုမှု အများဆုံး 6 ခု တစ်ပြိုင်နက် လည်ပတ်သည်၊ ဆက်တင် ပိတ်ထားစဉ် မည်သည့် တောင်းဆိုမှုမှ စာမျက်နှာကို မထွက်ပါ။ အထက်ပါ USGS National Map မြေပုံဝန်ဆောင်မှုကိုလည်း ဘရောက်ဇာတွင် တိုက်ရိုက် တစ်ကြိမ် ဖတ်ပြီး ဆွဲခဲ့သည် (tile များ ရောက်ပြီး ဆွဲခဲ့သည်၊ ၎င်း၏ မူပိုင်ခွင့် စာသားဖြင့်); အခြား အများပြည်သူ ဆာဗာများကို သိမ်းထားသော ဖြေချက်များမှသာ ဖတ်ခဲ့သည်။

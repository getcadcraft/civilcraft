{{ui:အလုပ်စာရွက်များ}} (ရှုခင် › နောက်ထပ်) သည် ဤစီမံကိန်း၏ အလုပ်စာရွက်များကို ဖွင့်သည်။ ပထမဆုံးအကြိမ်တွင် **အပင်ဇယား** နှင့် **ခင်းကျင်းမှုနှင့် ဧရိယာ ဇယား** ကို သင့်အတွက် ပြုလုပ်ပေးသည်။ အလုပ်စာရွက်တစ်ခုကို ပြသသည်၊ ရေးထုတ်သည် သို့မဟုတ် စာမျက်နှာပေါ် ထည့်သည့်အချိန်တိုင်း အရာဝတ္ထုများမှ တွက်ချက်သည်: စိုက်ခင်းတစ်ခုကို ပြောင်းလိုက်လျှင် ၎င်း၏ အရေအတွက်များ နေရာအနှံ့ ပြောင်းသည်။

- **အတန်းများ အရင်းအမြစ်**: အပင်များ (မျိုးစိတ်၊ cultivar နှင့် အရွယ်အစားတစ်ခုစီအတွက် အတန်းတစ်ခု)၊ စိုက်ထားသော ဧရိယာများ၊ ခင်းကျင်းမှု၊ နံရံများ၊ လှေကားများ၊ မြေပြင် ပြင်ဆင်ကိရိယာများ (ဖြတ်နှင့် ဖြည့်) သို့မဟုတ် ပမာဏအားလုံး။
- **ကော်လံများ**: အကွက် (`qty`၊ `area`၊ `botanical`၊ သို့မဟုတ် `[Net area]` ကဲ့သို့ ကွင်းထဲရှိ အမည်) သို့မဟုတ် ပုံသေနည်း: `+ - * / ^ %`၊ စာသား ပေါင်းရန် `&`၊ `= <> < <= > >=`၊ နှင့် `round`၊ `ceil`၊ `floor`၊ `abs`၊ `sqrt`၊ `min`၊ `max`၊ `if`၊ `and`၊ `or`၊ `not`၊ `concat`၊ `upper`၊ `lower`၊ `len`၊ `text`။ တွက်မရသော ပုံသေနည်းသည် ၎င်း၏ဆဲလ်တွင် `#ERR` (သို့မဟုတ် `#DIV/0`) ပြသည်။ ပုံသေနည်းများကို CadCraft ၏ ကိုယ်ပိုင် parser က ဖတ်သည်; ၎င်းတို့ထဲမှ ဘာမျှ code အဖြစ် မလုပ်ဆောင်ပါ။
- **စုစုပေါင်း** ကော်လံတစ်ခုစီအတွက် (ပေါင်း၊ ရေတွက်၊ ပျမ်းမျှ၊ အသေးဆုံး၊ အကြီးဆုံး)၊ **အုပ်စုဖွဲ့ရန်** (အုပ်စုတစ်ခုစီအတွက် ခွဲစုစုပေါင်း) နှင့် **ဤအတန်းများသာ** ။
- {{ui:CSV အဖြစ် သိမ်းရန်}}၊ {{ui:XLSX အဖြစ် သိမ်းရန်}} နှင့် **ဤအလုပ်စာရွက်ကို စာမျက်နှာများပေါ် ထားပါ** (စာမျက်နှာများ › အလုပ်စာရွက်များ သည် ၎င်းကို ဇယားအဖြစ် ဆွဲပြီး လိုအပ်သလောက် စာမျက်နှာများအပေါ် ဖြန့်သည်)။

အပင်များနှင့် ဧရိယာများပေါ်ရှိ တံဆိပ်များသည် တူညီသော field အမည်များကို ဖတ်သည် (`{botanical}`၊ `{cultivar}`၊ `{size}`၊ `{qty}`)။

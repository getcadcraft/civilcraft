**Surface › More** ကို ဖွင့်ပြီး ဝင်းဒိုးတစ်ခုကို ရွေးပါ။ တစ်ခုစီသည် ၎င်း၏ အရာများကို သင့်ပရောဂျက်ဖိုင်တွင် ထိန်းထားပြီး assistant က လုပ်သော တွက်ချက်မှုအတိုင်း လုပ်ဆောင်ပြီး တန်ဖိုးတစ်ခုသည် စတင်တန်ဖိုးသာ ဖြစ်ကြောင်း ပြောသည်။ ဤတို့သည် တွက်ချက်ကိရိယာများ ဖြစ်ပြီး အင်ဂျင်နီယာက ရလဒ်တိုင်းကို စစ်ဆေးရမည်။

**Junctions နှင့် striping။** Junction ဆိုသည်မှာ အစွန်းများ အမှတ်တစ်ခုတွင် တွေ့သော လမ်းဆုံဖြစ်သည်။ အစွန်းတိုင်းကို ၎င်း၏ curb return radius ကိုယ်ပိုင် ပေးနိုင်သည်၊ သို့မဟုတ် လှည့်သော ထရပ်ကားလိုအပ်သော compound return အတွက် *Three centres (2:1:2)* ကို ရွေးပါ။ *Crosswalks* သည် အစွန်းတိုင်းတွင် crosswalk နှင့် stop bar ထည့်သည်။ Striping နှင့် signs များသည် alignment တလျှောက် သွားသည်။ *Show on the plan* ကို yes သတ်မှတ်ထားသော အရာများကို plan ပေါ် ဆွဲသည်၊ နှင့် **Save the road drawing (.dxf)** သည် named layers (`C-ROAD-EDGE`၊ `C-ROAD-MARK-YELLOW`၊ `C-ROAD-XWALK`၊ `C-ROAD-SIGN`၊ `C-RAIL-TURNOUT`) ပါသော တူညီသော ပုံဆွဲချက်ကို ရေးသည်။ Setbacks၊ အကျယ်များနှင့် sign codes များသည် placeholders ဖြစ်ပြီး သင့်အာဏာပိုင်၏ ကိုင်ထားသော manual က ဆုံးဖြတ်သည်။

**Survey adjustment။** Points နှင့် တိုင်းတာချက်များကို ထည့်ပါ၊ သို့မဟုတ် data collector ဖိုင် (RW5၊ GSI၊ JobXML၊ CSV) ကို တင်ပါ။ Point တစ်ခုမျှ မကိုင်ထားသောအခါ *Free network: yes* ကို ရွေးပါ: datum ကို လိုအပ်သော အနည်းဆုံးဖြင့် သတ်မှတ်သည်၊ ထို့ကြောင့် coordinates များသည် ထိုရွေးချယ်မှုအပေါ် မူတည်သော်လည်း residuals၊ variance factor နှင့် blunder test တို့ မပြောင်းပါ။ **Save adjusted points (.csv)** သည် ရလဒ်ကို ရေးသည်။ ဖတ်ကိရိယာများကို ဖော်မတ်များ၏ အများပြည်သူ ဖော်ပြချက်မှ ရေးထားပြီး ကျွန်ုပ်တို့ ပြုလုပ်ထားသော ဖိုင်များပေါ်တွင် စမ်းသပ်ထားသည်; နားမလည်သော လိုင်းတိုင်းကို ၎င်းတို့ စာရင်းပြုသည်။ *Traverses* သည် traverse ကို compass rule ဖြင့် ပိတ်ပြီး misclosure နှင့် တိကျမှုကို 1 : n အဖြစ် ပေးသည်။

**ဖွင့်ထားသော တူးဖြတ်ရာများ။** မြေတူးနမူနာများသည် block model နှင့် အပြီးသတ် pit ဖြစ်လာသည်။ *Pit phases* ကို 0 အထက် သတ်မှတ်ပါက revenue factor အလိုက် ထပ်ဆင့် pits များ ရရှိမည်၊ ပြီးလျှင် ကြိတ်ဆိုင်စက်ရုံနှင့် ကားအင်အားကို ကာလအလိုက် schedule အတွက် discounted cash flow ဖြင့် ပေးပါ။ စျေးနှုန်း၊ ကုန်ကျစရိတ်နှင့် slope တိုင်းသည် သင့်ကိုယ်ပိုင် ဖြစ်သည်။

**ရေဒီယို ဆက်သွယ်လိင်းများ။** မြင်ကွင်းလိုင်းနှင့် margin အပြင်၊ လိင်းတစ်ခုသည် multipath outage ကို (Vigants–Barnett ခန့်မှန်းချက်၊ မိုးမရွာသည့်အခြေအနေ) ဖော်ပြသည်။ ပို့ကိုယ်ပေါ်ရှိ face width ကို ပေးပါက ၎င်း၏ အောက်ခြေတွင် wind shear နှင့် moment နှင့် overturning factor ရရှိမည်။

**ရထားလမ်း turnouts။** Alignment နှင့် station ကို ရွေးပါက turnout ကို ၎င်းပေါ် ဆွဲသည်။ ကန့်သတ်ချက်အားလုံးသည် သင့်ရထားလမ်း၏ ကိုယ်ပိုင်စံနှုန်းမှ သတ်မှတ်သည်အထိ placeholders ဖြစ်သည်။

**တံခါး ramp နှင့် pit 3D တွင်။** Pit သို့ ramp width ပေးပါက pit ဝင်းဒိုးသည် ramp grade အတိုင်း နံရံများပေါ် haul ramp ကို ခင်းသည်: bench တစ်ခုစီ၏ နံရံကို bench အမြင့် ခြေလှမ်းအတိုင်း grade အရ ဆင်းပြီး နောက် bench သို့ ဝင်သွားသည်။ ဓာတ်ပုံတစ်ခုက bench rim တိုင်းနှင့် ၎င်းတို့အပေါ် ramp ကို ပြသည်။ "Ramp lane flattens the pit wall" က ramp တိုင်း bench တွင် လိုအပ်သည့် ပိုပြားသော နံရံကို pit ကန့်သတ်ချက်က သုံးစေသည်။ Ramp သည် ခြေလှမ်းပါသော block နံရံများပေါ် ပုံဖော်ချက်ဖြစ်ပြီး haul-road ဒီဇိုင်း မဟုတ်ပါ; လမ်းသည် pit ကို တစ်ကြိမ်ထက်ပို ထပ်ခြုံရလျှင်၊ နိမ့်သော bench ပေါ် ကျော်လျှင် သို့မဟုတ် ကြမ်းပြင်နှင့် မကိုက်ညီလျှင် ဝင်းဒိုးက ပြောပြသည်။ "Cut the pit into the ground" က pit ကို ရှိပြီးသား မြေပြင်မှ တူးထုတ်ပြီး ဘယ်လောက်ဖြစ်သည် ပြောသည်; "Show in the 3D view" က ဖြတ်ထားသော မြေပြင်၊ bench rims နှင့် ramp ကို 3D view တွင် ဆွဲသည် (Open pits and haul ramps ခလုတ်များ)။

**Coverage။** Radio links အောက်ရှိ Coverage tab တွင် ပို့ကိရိယာ၊ ၎င်း၏ power နှင့် gains၊ receiver sensitivity၊ radius နှင့် cell size ကို ထည့်ပြီး ရရောက်နိုင်သော ဧရိယာကို ရှိပြီးသား မြေပြင်ပေါ် plan နှင့် သိမ်းနိုင်သော ပုံတွင် အရိပ်ထားသည်။ Cell တိုင်းတွင် free-space loss နှင့် straight path ပေါ် အဆိုးဆုံး ridge (knife-edge diffraction, ITU-R P.526) ပါသည်; ridges အများအပြား တစ်ဆက်တည်းကို ထည့်မတွက်၊ မိုးနှင့် antenna patterns မပါ၊ ထို့ကြောင့် အနည်းငယ် အလွန်အကျွံ ကောင်းမြင်သည်။ Link ပေါ်ရှိ ပို့ကိုလည်း leg စစ်ဆေးချက် ရသည်: လေ moment နှင့် အလေးချိန်မှ leg compression နှင့် uplift၊ သင်ပေးသော leg capacity နှင့် load factor နှင့် နှိုင်းယှဉ်ပြီး၊ section ကို ပေးလျှင် Euler buckling။ ၎င်းသည် statics သက်သက်သာ ဖြစ်သည်: ပို့ကိုဒ် တစ်ခု၏ နံပါတ်များကို မထည့်ထားသဖြင့် သင့်ကိုယ်ပိုင် ကုဒ်က ဆုံးဖြတ်ရမည်။

**ဖိုင်များ အစစ်ဖြင့် မစမ်းသပ်ရသေးပါ။** RW5၊ GSI၊ JobXML နှင့် CSV ဖတ်ကိရိယာများကို ဖော်မတ်တစ်ခုစီ၏ အများပြည်သူ ဖော်ပြချက်မှ ရေးပြီး ကျွန်ုပ်တို့ ပြုလုပ်ထားသော ဖိုင်များပေါ်တွင်သာ စမ်းသပ်ထားသည်၊ ပျက်စီးနေသော ဖိုင်များ အပါအဝင် ၎င်းတို့ ပျက်မသွားရမည်။ စစ်တမ်းဝင်းဒိုးက import လုပ်တိုင်း ထိုသို့ ပြောသည်။ Points နှင့် မြင်တွေ့ချက်များကို သင့် instrument ၏ ကိုယ်ပိုင် အစီရင်ခံစာနှင့် စစ်ဆေးပါ; အစစ်အမှန်ဖိုင် မဖတ်နိုင်ပါက ကျွန်ုပ်တို့ထံ ပို့ပါ (community test note သည် docs/community-tests/EG.11.md တွင် ရှိသည်)။

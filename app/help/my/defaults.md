CivilCraft တွင် ဆက်တင် ဒိုင်ယာလော့ဂ် သို့မဟုတ် ပုံစံ မရှိပါ။ ဤသည်မှာ အရာများ စတင်သော တန်ဖိုးများ ဖြစ်သည်။ **နေရာယူ** ဟု အမှတ်အသားပြုထားသော တန်ဖိုးများသည် မည်သည့်စံမှ မယူထားပါ: စစ်ဆေးချက် သို့မဟုတ် ပမာဏကို မှီခိုမီ ၎င်းတို့ကို သင့်ပရောဂျက်၏ စံနှုန်းများဖြင့် အစားထိုးပါ။

## ပရောဂျက်အသစ်

|---|---|
| အမည် | အမည်မပေးရသေးသော ဆိုက် (ပထမ အမှတ်ဖိုင်၏ အမည်က အစားထိုးသည်) |
| ယူနစ်များ | US feet |
| မျက်နှာပြင် အမည် | {{ui:လက်ရှိ မြေပြင်}} |
| အမှတ် အုပ်စုများ | အုပ်စု တိုင်းသည် {{ui:အမှတ်များ}} အဖြစ် စတင်သည် |
| အပြင်ဘက် အရှည်ဆုံး အစွန်း | 0 (တြိဂံ အားလုံး ထိန်းသည်) |
| ထိန်းထားသော ပြန်ဖျက်ရန် အဆင့်များ | 200 |

overhead လိုင်းပရိုဂရမ် အချို့သည် လေ့လာမှုတစ်ခုကို `.DON` ဖိုင် (XML စာသား) တွင် သိမ်းပါသည်။ CivilCraft သည် လိုင်းတစ်ခုကို ထိုကဲ့သို့ ဖိုင်အဖြစ် ရေးနိုင်ပြီး တစ်ခု၏ ထောက်ပံ့ချက်များကို ဖတ်နိုင်ပါသည်။

:::warning
**မစမ်းသပ်ရသေးပါ။** ကျွန်ုပ်တို့သည် အသုံးပြုသူတစ်ဦး မျှဝေထားသော format ၏ field အမည်စာရင်းမှ ဤအရာကို တည်ဆောက်ထားပြီး အမှန်တကယ် ဖိုင်မှ မဟုတ်ပါ၊ ကျွန်ုပ်တို့၏ ဖိုင်များကို ဖတ်သည့် ပရိုဂရမ်တွင် မဖွင့်ရသေးပါ။ ထိုပရိုဂရမ်တွင် ဖိုင်ကို ဖွင့်ပြီး တန်ဖိုးတိုင်းကို မယုံကြည်မီ စစ်ဆေးပါ။ ဖောက်သည်၏ အသေးစိတ်များ ဖယ်ထားသော `.DON` ဖိုင်ကို မျှဝေနိုင်ပါက ကျွန်ုပ်တို့ ဤအရာကို မှန်ကန်အောင် ပြင်ရာတွင် ကူညီပါမည်။
:::

## လေ့လာမှုဖိုင် သိမ်းခြင်း

1. လိုင်းကို conductor တစ်ခု ပေးပါ၊ ရလဒ်များ ရှိကြောင်း သေချာစေပါ (Properties တွင် "not worked out" မရှိရ)။
2. {{ui:More}} › {{ui:Save a study file (.DON)…}} ကို ရွေးပြီး လိုင်းကို ရွေးကာ ဖော်ပြချက်နှင့် အလုပ်နံပါတ် ထည့်ပါ။
3. {{ui:Save the study file}} ကို နှိပ်ပါ။

ဖိုင်တွင် လိုင်း၏ ထောက်ပံ့ချက်များ (သြဒိနိတ်၊ မြေပြင်၊ အမြင့်၊ အခန်းကဏ္ဍ၊ crossarm၊ ထိန်းထားသော သို့မဟုတ် အကြံပြုထားသော ထောက်ပံ့ချက်၊ load case အလိုက် load၊ အုတ်မြစ်) ပါသည်၊ dead-end များကြား အပိုင်းတစ်ခုချင်းစီ (conductor၊ voltage၊ ruling span၊ span များ၊ tension နှင့် catenary parameter၊ load case အလိုက် အကြီးဆုံး tension) နှင့် ဆွဲတပ်ဇယားများ။ အလျားများကို မီတာဖြင့် နှင့် အားများကို daN ဖြင့် ရေးပြီး စာသားကို Latin-1 ဖြင့် ရေးသဖြင့် ထိုအပြင် အက္ခရာတစ်လုံးသည် `?` ဖြစ်ပါသည်။

## လေ့လာမှုဖိုင် ဖတ်ခြင်း

{{ui:More}} › {{ui:Open a study file (.DON)…}} သည် ထောက်ပံ့ချက်များကို လိုင်းအသစ်တစ်ခုသို့ ဖတ်ပါသည်။ conductor၊ ထောက်ပံ့ချက်များနှင့် crossarm များကို သင့်စာကြည့်တိုက်နှင့် အမည်ဖြင့် ကိုက်ညီစေပါသည်; မတွေ့သည့် အရာများကို Properties တွင် သင်ရွေးရန် ထားခဲ့ပါမည်။

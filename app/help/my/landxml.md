LandXML သည် အများ civil ပရိုဂရမ်များ ဖတ်ပြီး ရေးသော ပွင့်လင်းသော ဖလှယ်ဖော်မတ် ဖြစ်သည်။ CivilCraft သည် LandXML 1.2 ကို ဖတ်ပြီး ရေးသည်။ Civil 3D ကို သုံးဖူးလျှင် ၎င်း၏ LandXML သွင်းယူနှင့် ထုတ်ယူ ဒိုင်ယာလော့ခ်များသည် အနီးစပ်ဆုံး ဖြစ်သည်; ဤနေရာတွင် ရွေးစရာ မရှိပါ၊ မှတ်ချက်များက ဘာကျန်ခဲ့သလဲ ပြောပြသည်။

## LandXML ဖိုင်ကို ဖွင့်ခြင်း

1. {{ui:Open}} (သို့မဟုတ် {{key:Mod+O}}) ကို နှိပ်ပြီး `.xml` သို့မဟုတ် `.landxml` ဖိုင်ကို ရွေးပါ၊ သို့မဟုတ် အစီအစဉ်ပေါ်သို့ ချပါ။
2. လက်ရှိ စီမံကိန်းတွင် မသိမ်းရသေးသော ပြောင်းလဲမှုများ ရှိလျှင် CivilCraft က ဦးစွာ မေးသည်။ {{ui:Save a copy}}၊ {{ui:Don’t save}} သို့မဟုတ် {{ui:Cancel}} ကို ရွေးပါ။
3. **စီမံကိန်းအသစ်** ဖန်တီးသည်။ အခြေအနေ ဘား က ဘာဖတ်ခဲ့သလဲ ပြောပြသည်၊ ဥပမာ "site.xml ဖွင့်ပြီး: 412 အမှတ်၊ 2 မျက်နှာပြင်၊ 3 ဖြောင့်မျဉ်း"။
4. **မျက်နှာပြင်** အချက်အလက်များအောက်ရှိ ဘောက်စ်ကို ကြည့်ပါ။ ကျော်သွားသော သို့မဟုတ် ပြောင်းလဲသွားသော အရာအားလုံးကို ဖော်ပြသည်၊ ဥပမာ:
   - "ပထမ မျက်နှာပြင် ("EG") ကိုသာ ဖွင့်သည်; ဖိုင်တွင် နောက်ထပ် 1 ခု ရှိသည်။"
   - "ဖြောင့်မျဉ်း "Ramp A" တွင် CivilCraft မဆွဲနိုင်သေးသော element များ ရှိသည် (မျဉ်း၊ ကွေး သို့မဟုတ် clothoid spiral မဟုတ်သော); ကျော်သွားသည်။"
   - "ပိုက်ကွန်ရက် စည်းမျဉ်းများ ဖိုင်တွင် မရှိပါ; နေရာယူထားသော တန်ဖိုးများ (placeholders) ကို သုံးနေသည် — Project အောက်တွင် သင့်ကိုယ်ပိုင်ကို သတ်မှတ်ပါ။"

ဘာဘာ ဘာဖြစ်လာသလဲ:

| ဖိုင်တွင် | CivilCraft တွင် |
|---|---|
| Units (Imperial သို့မဟုတ် Metric) | စီမံကိန်း၏ **Units** (ပေ သို့မဟုတ် မီတာ) |
| စီမံကိန်းအမည် | စီမံကိန်း **Name** |
| CgPoints | စီမံကိန်း၏ အမှတ်များ; ဖော်ပြချက် (သို့မဟုတ် code) က အုပ်စုကို ပေးသည် |
| ပထမ TIN မျက်နှာပြင် | ရှိပြီးသား မြေပြင်၊ ဖြစ်ပြီးသည့်အတိုင်း သုံးသည် ("Surface (from LandXML)") |
| မျဉ်း၊ ကွေးနှင့် clothoid spiral များ၏ ဖြောင့်မျဉ်းအားလုံး | PI များ၊ radius များနှင့် spiral အရှည်များပါသော ဖြောင့်မျဉ်း၊ ကွေးများမှ ပြန်တည်ဆောက်သည် |
| ဖြောင့်မျဉ်းတစ်ခုစီ၏ ပထမ ဒီဇိုင်း ပရိုဖိုင် | ၎င်း၏ ဒီဇိုင်း ပရိုဖိုင်၊ parabolic ဒေါင်လိုက်ကွေးများပါသော |
| ပထမ ပိုက်ကွန်ရက် | ပိုက်ကွန်ရက်၊ အပေါ်ဘောင်များ၊ sump များနှင့် invert များပါသော |
| မျဉ်းနှင့် ကွေး၏ အစီအစဉ် feature များ | အင်္ဂါရပ်မျဉ်းများ၊ ကွေးများ ထားသည်; အခြားပရိုဂရမ်မှ ဆိုလျှင် **ဆွဲထားသည်သာ** အဖြစ် စသည် |

element နှင့် attribute အပြည့်အစုံစာရင်းကို [LandXML: ဖတ်ခြင်းနှင့် ရေးခြင်း](topic:landxml-reference) တွင် ရှိသည်။

:::note
LandXML မှ ဖတ်ထားသော မျက်နှာပြင်ကို အမှတ်အုပ်စုများ ပြောင်းလဲသည့်အခါ သို့မဟုတ် breakline များ ဆွဲသည့်အခါ ပြန်တည်ဆောက်မည် မဟုတ်ပါ။ အမှတ်များမှ ပြန်တည်ဆောက်ရန် **မျက်နှာပြင်** အပိုင်းရှိ {{ui:အမှတ်များမှ မျက်နှာပြင်ကို ပြန်တည်ဆောက်ရန်}} ကို နှိပ်ပါ ({{key:Mod+Z}} သည် LandXML မျက်နှာပြင်ကို ပြန်ယူသည်)။
:::

## LandXML ထုတ်ယူခြင်း

1. **ထုတ်ယူ** အုပ်စုရှိ {{ui:LandXML}} ကို နှိပ်ပါ။
2. ဘရောက်ဇာသည် `<name>.xml` ကို ဒေါင်းလုဒ်ဆွဲသည်။ အခြေအနေ ဘား က ဘာ ထည့်ခဲ့သလဲ ပြောပြသည်၊ ဥပမာ "LandXML 1.2 ထုတ်ယူပြီး: 276 အမှတ်၊ 2 မျက်နှာပြင်၊ 1 ဖြောင့်မျဉ်း၊ ပိုက်ကွန်ရက်။ Pad များသည် ဤနေရာတွင် LandXML အစိတ်အပိုင်း မဟုတ်ပါ; မြေညှိထားသော မျက်နှာပြင် ဟုတ်သည်။"

ဖိုင်တွင်:

- **Units**: US survey feet သို့မဟုတ် မီတာ။
- **CgPoints**: အမှတ်တိုင်း၊ နံပါတ်ကို အမည်အဖြစ်၊ ၎င်း၏ ဖော်ပြချက်နှင့် အုပ်စုကို code အဖြစ်။
- **Surfaces**: ရှိပြီးသား မြေပြင်ကို TIN အဖြစ်၊ ၎င်း၏ breakline များနှင့် အပြင်ဘက် နယ်နိမိတ်ကို source data အဖြစ်; pad သို့မဟုတ် corridor မြေညှိသည့်အခါ "Proposed" အမည်ရှိ TIN မျက်နှာပြင် ဒုတိယတစ်ခု။
- **Alignments**: မျဉ်း၊ ကွေးနှင့် clothoid spiral များ၊ ၎င်းတို့၏ station များဖြင့်၊ PVI အနည်းဆုံး နှစ်ခုရှိသည့်အခါ၊ တစ်ခုစီတွင် ၎င်းတလျှောက် နမူနာယူထားသော ရှိပြီးသား မြေပြင်နှင့် ဒီဇိုင်း ပရိုဖိုင် (PVI များနှင့် parabolic ကွေးများ) ပါသော ပရိုဖိုင်။
- **PipeNetworks**: အပေါ်ဘောင်၊ sump များနှင့် ပိုက်တစ်ခုစီ၏ invert ပါသော structure များ၊ နှင့် အချင်း၊ အရှည်နှင့် စောက်ကျမှု ပါသော ပိုက်များ။
- **PlanFeatures**: အင်္ဂါရပ်မျဉ်းတိုင်းကို မျဉ်းနှင့် ကွေးများအဖြစ် အဆုံးတစ်ခုစီရှိ အမြင့်ပါ၊ နှင့် ၎င်း၏ အသုံးပြုမှု။

## LandXML တွင် မပါဝင်သော အရာများ

- Pad နှင့် corridor များ အရာဝတ္ထုအဖြစ်။ ၎င်းတို့၏ ရလဒ်သည် "Proposed" မျက်နှာပြင်တွင် ရှိသည်။
- အမှား ပါသော ဖြောင့်မျဉ်းများ (ဥပမာ ထပ်နေသော ကွေးများ): ချန်ထားပြီး အခြေအနေ မက်ဆေ့ချ်တွင် ရေတွက်သည်။
- invert နှစ်ခုလုံး မပါသော ပိုက်များ၊ နှင့် structure နှစ်ခုအောက် ကွန်ရက်များ။
- မျက်နှာပြင်မှ ယူထားသော အပေါ်ဘောင်ကို ပုံသေ အပေါ်ဘောင်အဖြစ် ရေးသည်။ ထပ်မံဖွင့်သည့်အခါ၊ မျက်နှာပြင် ပြောင်းလဲသော်လည်း structure သည် ထိုနံပါတ်ကို ဆက်ထားသည်။
- ကွန်ရက် စည်းမျဉ်းများ (အနည်းဆုံး စောက်ကျမှု၊ အုပ်မှု၊ ကျဆင်းမှု): LandXML တွင် နေရာမရှိပါ။
- ဖော်ပြမှု ဆက်တင်များနှင့် အမှတ်အုပ်စု၏ မျက်နှာပြင် ရွေးချယ်မှုများ: ၎င်းတို့အတွက် CivilCraft စီမံကိန်း သိမ်းပါ။

ဖွင့်သည့်အခါ CivilCraft သည် clothoid မဟုတ်သော spiral များ၊ grid မျက်နှာပြင်များ၊ အခြားအမှတ်များကိုသာ ရည်ညွှန်းသော အမှတ်များ၊ parcel များ၊ အစီအစဉ် feature များထဲရှိ spiral များ၊ roadway များ သို့မဟုတ် survey ဒေတာကို မဖတ်ပါ။ ၎င်းတို့တစ်ခုစီကို မှတ်ချက်များတွင် အမည်ပေးသည်၊ ဘယ်တော့မှ မခန့်မှန်းပါ။

## သွားပြန်လာ ပြောင်းလဲမှု

အခြား civil ဆော့ဖ်ဝဲကို သုံးသူတစ်ဦးထံ အလုပ်ပေးပြီး ပြန်ယူလိုလျှင် LandXML ကို ထုတ်ယူ၊ သူ့အား တည်းဖြတ်ခွင့်ပေးပြီး သူ၏ LandXML ကို စီမံကိန်းအသစ်အဖြစ် ဖွင့်ပါ။ သင့်ကိုယ်ပိုင် `.civilcraft.json` ကိုလည်း ထားပါ: CivilCraft သိသော အရာအားလုံးကို သိမ်းထားသော တစ်ခုတည်းသော ဖိုင် ဖြစ်သည်။

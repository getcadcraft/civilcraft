CivilCraft သည် CadCraft မိသားစု၏ civil နှင့် site design app ဖြစ်သည်။ survey အမှတ်များကို ယူပြီး contours ပါသော မျက်နှာပြင် (TIN) ဖြစ်အောင် လုပ်ပေးသည်၊ ထို့နောက် design profiles ဖြင့် alignments ကို ချထားနိုင်ပြီး ရိုးရှင်းသော လမ်း corridor ကို sweep လုပ်နိုင်သည်၊ pads ကို daylight သို့ grade လုပ်နိုင်သည်၊ gravity ပိုက်ကွန်ရက်ကို သင့်စည်းမျဉ်းများနှင့် စစ်နိုင်သည်၊ cut နှင့် fill ထုထည်များကို ကြည့်နိုင်သည်။ LandXML ကို ဖတ်ပြီး ရေးသည်၊ plan ကို DXF အဖြစ် ထုတ်ပြီး PDF သို့ plot လုပ်သည်။

Civil 3D ကို အသုံးပြုဖူးပါက အယူအဆများ ရင်းနှီးမည်ဖြစ်သည်: အမှတ်များ၊ point အုပ်စုများ၊ breaklines၊ PI ဖြင့် alignments၊ PVI ဖြင့် profiles၊ corridors၊ grading၊ ပိုက်ကွန်ရက်များ။ လုပ်ဆောင်ပုံမှာ ကွဲပြားပြီး ပိုသေးငယ်သည်: command line မရှိ၊ style မရှိ၊ ပုံဆွဲဖိုင် မရှိ။ သင့်ပထမ အမှန်တကယ် အလုပ်မတိုင်မီ [အခြား civil software မှ လာခြင်း](topic:coming-from) ကို တစ်ကြိမ် ဖတ်ပါ။

## လိုအပ်သည်များ

- ခေတ်မီ desktop browser: Chrome, Edge, Firefox သို့မဟုတ် Safari။ [ဘရောက်ဆာများ](common:browsers) ကို ကြည့်ပါ။
- မောက်စ် သို့မဟုတ် trackpad နှင့် keyboard၊ သို့မဟုတ် touch screen: ဆွဲခြင်းတွင် on-screen {{ui:ပြီးရန်}}၊ {{ui:အမှတ်ပြန်ဖျက်ရန်}} နှင့် {{ui:ပယ်ဖျက်ရန်}} ခလုတ်များ ရှိသည် ([Mouse, trackpad နှင့် touch](topic:keyboard#mouse-trackpad-and-touch) ကို ကြည့်ပါ)။
- plan သည် browser ၏ canvas ဖြင့် 2D ဆွဲသည်။ [3D view](topic:site-3d) သည် browser ၏ WebGL graphics ကို သုံးသည်; စတင်၍ မရပါက status bar က အကြောင်းပြပြီး plan ကတော့ ဆက်အလုပ်လုပ်သည်။
- အကောင့် မလို၊ upload မလို။ ဖိုင်များ သင့်ကွန်ပျူတာပေါ်တွင် ဖွင့်ပြီး ဒေါင်းလုဒ်အဖြစ် သိမ်းသည်။ [သင့်ဖိုင်များ](common:your-files) ကို ကြည့်ပါ။

:::note
CivilCraft သည် ယခုအချိန်တွင် တည်ဆောက်နေဆဲ ကြိုတင် browser build အဖြစ် အလုပ်လုပ်သည်။ Desktop build များ ယခုမရနိုင်သေး၊ cloud သိမ်းခြင်းလည်း မရနိုင်သေး။ သင်ပြုလုပ်သမျှ သိမ်းသည် သို့မဟုတ် ထုတ်သည်အထိ သင့်ကွန်ပျူတာပေါ်တွင်သာ ရှိနေမည်။
:::

## CivilCraft ဖွင့်ခြင်း

1. browser တွင် CivilCraft ကို ဖွင့်ပါ။
2. စခရင် ပြည့်သည်အထိ စောင့်ပါ: အပေါ်တွင် toolbar၊ ဘယ်ဘက်တွင် panel၊ အလယ်တွင် plan နှင့် ညာဘက်တွင် **Properties** panel ရှိသည်။
3. ဗလာ plan ပေါ်တွင် **Survey အမှတ်များဖြင့် စတင်ရန်** ခေါင်းစဉ်ရှိ ဘောက်စ်ကို တွေ့ရမည်။ ၎င်းက ပထမအဆင့်များကို စာရင်းပြပြီး {{ui:နမူနာ ဆိုဒ်ကို ဖွင့်ပါ}} လင့်ခ် ရှိသည်။

ချိတ်ဆက်မှု မရှိဘဲ နောက်မှ သုံးရန် app bar ရှိ {{ui:အော့ဖ်လိုင်းအတွက် သိမ်းရန်}} ကို နှိပ်ပြီး {{ui:အော့ဖ်လိုင်း အဆင်သင့်}} ကို စောင့်ပါ။ ၎င်းတွင် ဤ help၊ နမူနာဆိုဒ်နှင့် 3D နှင့် GIS libraries များ ပါဝင်သည်။ [အော့ဖ်လိုင်း](common:offline) ကို ကြည့်ပါ။ {{key:F1}} ကို နှိပ်ပါ သို့မဟုတ် {{ui:အကူအညီ}} ကို နှိပ်ပါက အချိန်မရွေး ဤ help ကို app ဘေးတွင် ဖွင့်ပေးသည်။

## ပထမ ဆယ်မိနစ်: နမူနာဆိုဒ်

နမူနာဆိုဒ်သည် US feet ဖြင့် သေးငယ်သော survey ဖြစ်သည်: state plane coordinates ပေါ်ရှိ အမှတ် 276 ခု၊ ridge တစ်ခု၊ flowline ပါသော swale တစ်ခုနှင့် bank အထက်ပိုင်း နှစ်ခု။ app နှင့်အတူ ပါလာသဖြင့် သင့်ကိုယ်ပိုင် ဖိုင်မလိုဘဲ လိုက်လုပ်နိုင်သည်။

1. plan ပေါ်ရှိ ဘောက်စ်တွင် {{ui:နမူနာ ဆိုဒ်ကို ဖွင့်ပါ}} ကို နှိပ်ပါ။
   **အမှတ်များ သွင်းရန်** ဒိုင်ယာလော့ဂ် ဖွင့်လာသည်။ "အမှတ် 276 ခုကို PNEZD (ခေါင်းစီးအတန်းမှ) အဖြစ် ဖတ်ပြီး ကော်မာဖြင့် ခွဲထားသည်။" ဟု ပြပြီး ပထမ အတန်းများကို ပြသည်။
2. {{ui:သွင်းရန်}} ကို နှိပ်ပါ။
   plan တွင် အမှတ်များ၊ contours နှင့် မျက်နှာပြင်အစွန်း ပြည့်လာသည်။ status bar က အမှတ်များ သွင်းပြီးကြောင်းနှင့် မျက်နှာပြင်တွင် တြိဂံ အရေအတွက် (546) ကို ပြသည်။
3. ဘယ်ဘက် panel ရှိ **Points** အောက်ကို ကြည့်ပါ။ အမှတ်များကို ဖော်ပြချက်၏ ပထမစကားလုံးအလိုက် အုပ်စုဖွဲ့ထားသည်: CP, FL, GRD, RIDGE, TBN, TBS နှင့် TREE။
4. ထိုဇယား၏ **Surface** ကော်လံတွင် **FL**, **RIDGE**, **TBN** နှင့် **TBS** ကို {{ui:Breakline}} သို့ သတ်မှတ်ပါ။
   မျက်နှာပြင် ချက်ချင်း ပြန်တည်ဆောက်သည်။ **Surface** အချက်အလက်များက "Breaklines: 4" ဟု ယခု ပြပြီး contours များသည် flowline နှင့် ridge တလျှောက် ထိုးကွေးပြီး ဖြတ်မကျော်တော့ပါ။
5. pointer ကို plan အပေါ် ရွှေ့ပါ။ status bar က pointer အောက်ရှိ easting နှင့် northing နှင့် ထိုနေရာ၏ ground elevation ကို ပြသည်။
6. **Display** အောက်တွင် {{ui:ဆင့်ကောက်မျဉ်း ခြားရန်}} ကို 0.5 ft သို့ သတ်မှတ်ပြီး {{ui:အမြင့်အဆင့်များ}} ကို ဖွင့်ပါ။ အရောင်ramp နှင့် legend checkboxes အောက်တွင် ပေါ်လာသည်။ ပြီးလျှင် bands များကို ပြန်ပိတ်ပါ။

ယခု သင့်တွင် ရှိပြီးသား မြေပြင် မျက်နှာပြင် ရှိပြီ။ နောက်တစ်ခုမှာ လမ်း။

## တိုတောင်းသော လမ်းတစ်ခု ချထားခြင်း

1. {{key:A}} ကို နှိပ်ပါ (သို့မဟုတ် **Design** အုပ်စုရှိ {{ui:Alignment}} ကို နှိပ်ပါ)။
2. site တစ်လျှောက် အမှတ်သုံးခုကို တစ်ခုပြီးတစ်ခု နှိပ်ပါ။ အနီရောင်မျဉ်းက pointer နောက်သို့ လိုက်ပြီး နောက် tangent ၏ အရှည်နှင့် bearing ကို ပြသည်။
3. {{key:Enter}} ကို နှိပ်ပြီး ပြီးစီးပါ။
   alignment သည် stationing ဖြင့် ပေါ်လာသည်။ ညာဘက် panel က **Alignment** ကို ပြသည်: အရှည်၊ PI ဇယား နှင့် အလယ် PI ရှိ curve (100 ft radius၊ 100 ft မကိုက်ညီပါက ပိုသေးသည်)။
4. ညာဘက် panel ရှိ **Design profile** အောက်တွင် {{ui:Start from the ground}} ကို နှိပ်ပါ။
   profile view သည် plan အောက်တွင် ဖွင့်ပြီး ရှိပြီးသား မြေပြင်နှင့် အစမှ အဆုံးထိ straight design grade ကို ပြသည်။
5. {{key:I}} ကို နှိပ်၍ {{ui:PVI များ ထည့်ရန်}} ကို ဖွင့်ပါ၊ ထို့နောက် profile view အလယ်အနီးတွင် တစ်ကြိမ် နှိပ်ပါ။ PVI တစ်ခု ပေါ်လာသည်။
6. ညာဘက် PVI ဇယားတွင် အလယ် PVI ၏ **Curve L** ကွက်ထဲ curve အရှည် (ဥပမာ 100) ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။ profile တွင် vertical curve ရှိလာပြီး ၎င်း၏ K တန်ဖိုးကို အညွှန်းတပ်ထားသည်။
7. **Corridor** အောက်တွင် **Sweep an assembly along the design profile** ကို အမှန်ခြစ်ပါ။
   လမ်းကို မြေထဲသို့ grade လုပ်ထားသည်: လမ်းသွား၊ ပုခုံးများနှင့် daylight သို့ side slopes။ **မြေထု** block က cut နှင့် fill ကို ပြသည်။

တိကျသော တန်ဖိုးများကို မစိုးရိမ်ပါနှင့်။ နံပါတ်တိုင်းကို ညာဘက် panel တွင် ပြောင်းနိုင်ပြီး {{key:Mod+Z}} က နောက်ဆုံးပြောင်းလဲမှုကို ပြန်ဖျက်သည်။

## သင့်အလုပ်ကို သိမ်းခြင်း

1. ဘယ်ဘက် panel ထိပ်ရှိ **Name** တွင် အမည်ရိုက်ပါ။
2. {{key:Mod+S}} ကို နှိပ်ပါ (သို့မဟုတ် {{ui:သိမ်းရန်}})။
   browser က ဆိုဒ်အမည်ဖြင့် `.civilcraft.json` ဖြင့် အဆုံးသတ်သော ဖိုင်ကို ဒေါင်းလုဒ်ဆွဲသည်။ ၎င်းတွင် အမှတ်များ၊ မျက်နှာပြင် ဆက်တင်များ၊ alignments၊ profiles၊ corridors၊ pads နှင့် pipes ပါဝင်သည်။
3. နောက်မှ ဆက်လုပ်ရန် {{ui:ဖွင့်ရန်}} (သို့မဟုတ် {{key:Mod+O}}) ကို နှိပ်ပြီး ထိုဖိုင်ကို ရွေး၊ သို့မဟုတ် plan ပေါ် ချပါ။

:::warning
အလိုအလျောက် သိမ်းခြင်း မရှိပါ။ မသိမ်းရသေးသော ပြောင်းလဲမှုဖြင့် tab ကို ပိတ်ပါက browser က ထွက်ရန် မေးမည်; ထွက်ပါက ပြောင်းလဲမှုများ ပျက်သွားမည်။ မကြာခဏ သိမ်းပါ။
:::

တိုင်းတာမှု မှားခြင်း၊ rod height မှား‌ခြင်း၊ ဖော်ပြချက် မှားရိုက်ခြင်း: point တစ်ခုကိုသာ ပြင်ပါ၊ မျက်နှာပြင်က လိုက်ပြောင်းပါမည်။

## Point ၏ တန်ဖိုးများ ပြောင်းရန်

1. {{ui:Select}} ဖြင့် ပလန်ပေါ်ရှိ point ကို နှိပ်ပါ။ **Properties** တွင် ၎င်း၏ နံပါတ်၊ easting၊ northing၊ elevation နှင့် description ကို အကွက်များတွင် ပြသသည်။
2. တန်ဖိုးအသစ်ကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ (သို့မဟုတ် အပြင်ကို နှိပ်ပါ)။ elevation မရှိသော point အတွက် **Elevation** ကို ဗလာထားပါ။
3. မျက်နှာပြင်၊ ကွန်တူများနှင့် ၎င်းတို့ပေါ် တည်ဆောက်ထားသည်များအားလုံး ချက်ချင်း update ဖြစ်သည်။

ပြောင်းလဲမှု တစ်ခုစီသည် အဆင့်တစ်ခု ဖြစ်သည်: {{key:Mod+Z}} က ပြန်ဖျက်ပြီး {{key:Mod+Y}} က ပြန်လုပ်သည်။ CivilCraft မသုံးနိုင်သော တန်ဖိုး (point အခြားတစ်ခုတွင် ရှိပြီးသား နံပါတ်၊ coordinate ထဲ အက္ခရာ) ကို လက်မခံပါ- အကွက်ကို ဘောင်ခတ်ပြီး status bar က အကြောင်းပြသည်။

Description code အသစ် ထည့်လျှင် import လုပ်သည့်နည်းတူ point group အသစ် ဖြစ်သည် (see [မျက်နှာပြင် တည်ဆောက်ခြင်း](topic:build-surface))။

## ပလန်ပေါ်တွင် point ကို ရွှေ့ရန်

1. Point ကို ရွေးပါ (ring ပေါ်လာသည်)။
2. Ring ကို ဆွဲပါ။ Status bar က ရောက်မည့် easting နှင့် northing ကို ပြသသည်။
3. ရွှေ့ရန် လွှတ်ပါ၊ elevation မပြောင်းပါ။ မလွှတ်မီ {{key:Esc}} ကို နှိပ်လျှင် ပြန်ရောက်သွားသည်။

## Breakline များက point ကို လိုက်သည်

{{ui:Breakline}} tool ဖြင့် ဆွဲထားသော breakline သည် ၎င်းဖြတ်သွားသော point များ၏ coordinates ကို ကူးယူသည်။ point ကို ရွှေ့ခြင်း သို့မဟုတ် elevation ပြောင်းသည့်အခါ ၎င်းပေါ်ရှိ breakline corner များလည်း အဆင့်တစ်ခုတည်းတွင် အတူ ရွှေ့သည်။ ဖော်ပြချက်မှ ပြုလုပ်ထားသော breakline group များကို အမြဲ point များမှ ပြန်တည်ဆောက်သည်။

:::note
LandXML ဖိုင်မှ ဖတ်ထားသော မျက်နှာပြင်သည် ၎င်း၏ကိုယ်ပိုင် တြိဂံများကို ထိန်းသိမ်းထားသည်: point တည်းဖြတ်မှုများက {{ui:Rebuild the surface from the points}} ကို လုပ်ပြီးမှသာ ပြောင်းလဲသည်။
:::

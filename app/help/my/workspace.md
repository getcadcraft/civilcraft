CivilCraft တွင် စခရင် တစ်ခုတည်း ရှိသည်။ tab များ မရှိ၊ layout များ မရှိ။ ဘေးဘက် panel များကို ရွှေ့နိုင်၊ မျောနိုင် သို့မဟုတ် ကိုယ်ပိုင်ဝင်းဒိုးသို့ ထွက်နိုင်သည်: [panels များကို စီစဉ်ခြင်းနှင့် ဒုတိယမော်နီတာ သုံးခြင်း](common:arrange-panels) ကို ကြည့်ပါ။ အပေါ်မှ အောက်၊ ဘယ်မှ ညာသို့:

- **app bar** (CadCraft အမှတ်တံဆိပ်၊ app အမည်၊ ဗားရှင်း၊ CivilCraft အကြောင်း၊ စခရင် mode၊ အကူအညီ၊ အော့ဖ်လိုင်းအတွက် သိမ်းရန်၊ Paper နှင့် Model)
- ခလုတ် အုပ်စု ခုနစ်ခုပါသော **toolbar**
- **ဘယ်ဘက် panel**: Site၊ အမှတ်များ၊ မျက်နှာပြင်၊ ပြသမှု နှင့် ကိုယ်တိုင်သွင်းပြီးနောက် GIS အလွှာများ
- အလယ်ရှိ **plan**၊ ဖွင့်ထားလျှင် ၎င်းအောက်တွင် **profile view**
- **ညာဘက် panel**: ရွေးထားသည်များ၏ **Properties**
- အောက်ဘက်ရှိ **status bar**

## App bar

အပေါ်ဆုံး ပါးလွှာသော bar သည် CivilCraft ကိုယ်တိုင်မဟုတ်ဘဲ CadCraft site နှင့် သက်ဆိုင်သည်။

- ဗားရှင်း menu က သင် run နေသော build ကို ပြသည်။
- {{ui:CivilCraft အကြောင်း}} က site ရှိ app ၏ စာမျက်နှာကို ဖွင့်သည်။
- {{ui:Full screen}} က စခရင် mode များကို လည်ပတ်သည်: full screen၊ ထို့နောက် bars ဖျောက်ထားသော full screen၊ ထို့နောက် ပုံမှန်သို့။ {{key:Ctrl+Shift+F}} သည် Mac အပါအဝင် platform အားလုံးတွင် အတူတူ လုပ်သည် (Mac တွင် Control ကီး ဖြစ်ပြီး Command မဟုတ်)။ bars ဖျောက်ထားချိန်တွင် pointer ကို ထိပ်ဘက်အစွန်းသို့ ရွှေ့ပါက ပြန်ပေါ်လာသည်။
- {{ui:အကူအညီ}} (သို့မဟုတ် {{key:F1}}) က ဤ help ကို ဘေးဘက် panel တွင် ဖွင့်သည်; {{key:F1}} သို့မဟုတ် {{key:Esc}} က ပိတ်သည်။
- {{ui:အော့ဖ်လိုင်းအတွက် သိမ်းရန်}} က CivilCraft ကို ဤ browser တွင် ထားသဖြင့် ချိတ်ဆက်မှုမရှိဘဲ ဖွင့်နိုင်သည်; ထို့နောက် {{ui:အော့ဖ်လိုင်း အဆင်သင့်}} ကို ပြသည်။ [ဖိုင်များ ဖွင့်၊ သိမ်း၊ ထုတ်ခြင်း](topic:files#online-and-offline) ကို ကြည့်ပါ။
- {{ui:Paper}} နှင့် {{ui:Model}} က light နှင့် dark theme အကြား ပြောင်းသည်။ plan နှင့် profile က theme ကို လိုက်သည်; PDF များသည် အမြဲ အဖြူပေါ်တွင် ပရင့်ထုတ်သည်။

## Toolbar

ခလုတ်အုပ်စုတိုင်းတွင် ခလုတ်များ အပေါ်တွင် အမည်သေးငယ် ရှိသည်။ ခလုတ်ပေါ် mouse ထားလျှင် tooltip နှင့် ကီးကို မြင်ရသည်။

| အုပ်စု | ခလုတ်များ | ဘာလုပ်သလဲ |
|---|---|---|
| File | {{ui:အသစ်}}, {{ui:ဖွင့်ရန်}}, {{ui:သိမ်းရန်}} | အစမှ ပြန်စ၊ point ဖိုင်၊ LandXML သို့မဟုတ် စီမံကိန်း ဖွင့်၊ စီမံကိန်းကို ဒေါင်းလုဒ်အဖြစ် သိမ်း |
| Export | {{ui:LandXML}}, {{ui:DXF}}, {{ui:DWG}}, {{ui:PDF}} | LandXML 1.2၊ R12 DXF သို့မဟုတ် plan ၏ DWG ရေး၊ သို့မဟုတ် plan ကို PDF သို့ plot |
| Surface | {{ui:Breakline}}, {{ui:Boundary}} | survey အမှတ်များမှ breakline ဆွဲ; အပြင်ဘက် နယ်နမိတ်ဆွဲ |
| Design | {{ui:Alignment}}, {{ui:Pad}}, {{ui:Pipes}}, {{ui:Profile}} | alignment၊ pad၊ ပိုက်လိုင်း ဆွဲ; profile view ကို ပြ/ဖျောက် |
| Edit | {{ui:Undo}}, {{ui:Redo}}, {{ui:Copy}}, {{ui:Paste}}, {{ui:More}} | survey အမှတ်များကို undo၊ redo၊ copy နှင့် paste; {{ui:နောက်ထပ်}} တွင် ဖြတ်ရန်၊ နေရာတွင် ကူးထည့်ရန်၊ ပွားရန်၊ ဖျက်ရန်၊ အမှတ်အားလုံး ရွေးရန်နှင့် ဘာမျှ မရွေးရန် ပါသည် |
| GIS | {{ui:Coordinates}}, {{ui:Import}}, {{ui:Export}}, {{ui:Map}} | coordinate system သတ်မှတ်၊ GIS ဖိုင်များ သွင်း/ထုတ်၊ plan အောက်တွင် map layers ပြ |
| View | {{ui:Select}}, {{ui:Fit}}, {{ui:3D}} | ရွေး၍ ရွှေ့; အားလုံးကို မြင်အောင် zoom; ဆိုဒ်ကို 3D ဖြင့် ပြ ([ဆိုဒ်ကို 3D ဖြင့် ကြည့်ခြင်း](topic:site-3d)) |

ဆွဲကိရိယာတစ်ခု active ဖြစ်နေစဉ် ၎င်းကို နှိပ်ထားသည်။ ၎င်းကို နောက်တစ်ကြိမ် နှိပ်ခြင်း၊ {{key:Esc}} နှိပ်ခြင်း သို့မဟုတ် {{key:V}} နှိပ်ခြင်းတို့က {{ui:Select}} သို့ ပြန်ပြောင်းသည်။ {{ui:Undo}}၊ {{ui:Redo}}၊ {{ui:Copy}} နှင့် {{ui:More}} ထဲရှိ ပစ္စည်းများသည် လုပ်နိုင်ခြင်း မရှိသောအခါ မှိန်နေသည်; tooltip က အကြောင်းပြသည် (ဥပမာ "ပထမ survey အမှတ်များကို ရွေးပါ")။ ခလုတ်အားလုံးကို [Toolbar ကိုးကား](topic:toolbar) တွင် စာရင်းပြထားသည်။

ကျဉ်းသော ဝင်းဒိုးတွင် toolbar သည် ဘေးသို့ scroll လုပ်သည်။

## ဘယ်ဘက် panel

### Site

- **Name**: စီမံကိန်းအမည်။ သိမ်းသည် သို့မဟုတ် ထုတ်သည့် ဖိုင်တိုင်းကို အမည်ပေးပြီး PDF ခေါင်းစဉ်ဘားတွင် ပရင့်ထုတ်သည်။
- **Units**: {{ui:US feet}} သို့မဟုတ် {{ui:မီတာ}}။ ၎င်းက နံပါတ်များ ဆိုလိုသည်ကို ပြောသည်။ ပြောင်းခြင်းသည် ကိုဩဒိနိတ်များကို **မပြောင်း**ပါ; [ယူနစ်များ၊ stations နှင့် နံပါတ်ပုံစံများ](topic:units-and-stations) ကို ကြည့်ပါ။

### အမှတ်များ

ဗလာဖြစ်လျှင် point ဖိုင် ဖွင့်ပုံကို ပြောပြသည်။ အမှတ်များရှိလျှင် ဖိုင်အမည်၊ အမှတ်အရေအတွက်နှင့် elevation ရှိသော အမှတ် အရေအတွက်ကို ပြပြီး **point အုပ်စုများ** ဇယားကို ပြသည်: ဖော်ပြချက်၏ ပထမစကားလုံးတစ်ခုစီအတွက် အတန်းတစ်ခု (GRD, FL, TBS …)၊ အရေအတွက်နှင့် **Surface** ရွေးချယ်မှု:

- {{ui:အမှတ်များ}}: အမှတ်များသည် မျက်နှာပြင်ထဲ ဝင်သည် (အုပ်စုတိုင်း၏ မူလ)။
- {{ui:Breakline}}: အုပ်စု၏ အမှတ်များကို point နံပါတ် အစဉ်လိုက် ဆက်၍ breakline တစ်ခုအဖြစ် ဆက်သည်။
- {{ui:ချန်ထားရန်}}: အုပ်စုသည် မျက်နှာပြင်ကို မထိပါ။

### မျက်နှာပြင်

မြေပြင်ရှိပြီးသား အချက်အလက်များ: အမှတ်များ၊ တြိဂံများ၊ အနိမ့်ဆုံးနှင့် အမြင့်ဆုံး elevation၊ ပျမ်းမျှ elevation၊ 2D နှင့် 3D ဧရိယာ၊ breaklines နှင့် နယ်နမိတ် ရှိ/မရှိ။ အချက်အလက်များအောက်တွင် မျက်နှာပြင် တည်ဆောက်သူက ပြင်ရခြင်း သို့မဟုတ် မလုပ်နိုင်ခြင်း ရှိသည့်အရာများကို စာရင်းပြသော ဘောက်စ် ရှိသည်။ ထို့နောက်:

- **Longest outside edge**: 0 သည် အပြင်ဘက် တြိဂံအားလုံးကို ထားသည်; နံပါတ်တစ်ခုက အပြင်ဘက်မှ ရှည်ပြီး ပါးသော တြိဂံများကို ဖြတ်သည်။
- လိုအပ်သည့်အခါ ပေါ်လာသော လင့်ခ်များ: {{ui:နယ်နိမိတ်ကို ဖယ်ရှားရန်}}၊ {{ui:ဆွဲထားသော breakline များကို ဖယ်ရှားရန်}} နှင့် LandXML မှ ဖတ်ထားသော မျက်နှာပြင်အတွက် {{ui:အမှတ်များမှ မျက်နှာပြင်ကို ပြန်တည်ဆောက်ရန်}}။

### ပြသမှု

- **Surface**: {{ui:Existing ground}} သို့မဟုတ် {{ui:Proposed (graded)}}။ ဒုတိယတစ်ခုကို pad သို့မဟုတ် corridor က ပြဿနာမရှိ grade လုပ်ပြီးနောက် ရနိုင်သည်။
- **Contours every**၊ **Major every** နှင့် **Bands** (အရောင် band အရေအတွက်)။
- checkboxes: {{ui:ကွန်တိုင်များ}}၊ {{ui:ကွန်တူ အမည်ပေးချက်များ}}၊ {{ui:တြိဂံများ}}၊ {{ui:အမြင့်အဆင့်များ}}၊ {{ui:စောက်ခြေမြားများ}}၊ {{ui:အမှတ်များ}}၊ {{ui:အမှတ် အမည်ပေးချက်များ}}၊ {{ui:Breaklines}}၊ {{ui:Surface edge}}၊ {{ui:Pipes}}။
- bands ဖွင့်ထားသောအခါ band elevation legend ပေါ်လာသည်။

ပြသမှု ဆက်တင်များကို စီမံကိန်းနှင့်အတူ သိမ်းသော်လည်း ပြန်ဖျက်အဆင့် မဟုတ်ပါ: {{key:Mod+Z}} က checkbox ကို ဘယ်တော့မှ ပြန်မပြောင်းပေးပါ။

## Plan

plan က အမှတ်များ၊ မျက်နှာပြင်နှင့် သင်ဒီဇိုင်းဆွဲသမျှကို မြောက်ဘက် ညွှန်ထားသော plan view ဖြင့် ပြသည်။ pointer ရှိနေရာတွင် wheel ဖြင့် zoom လုပ်; အလွတ်နေရာကို ဆွဲ၍ pan လုပ်။ အပြည့်အစုံ စာရင်းကို [ခလုတ်များနှင့် mouse](topic:keyboard) တွင် ကြည့်ပါ။

- စီမံကိန်း ဗလာဖြစ်သောအခါ **Survey အမှတ်များဖြင့် စတင်ရန်** ခေါင်းစဉ်ဘောက်စ်က ပထမအဆင့်များကို စာရင်းပြပြီး {{ui:နမူနာ ဆိုဒ်ကို ဖွင့်ပါ}} ကို ပေးသည်။
- ဆွဲကိရိယာတစ်ခု active ဖြစ်နေစဉ် plan ထိပ်တွင် ဘာကို နှိပ်ရမလဲ နှင့် ဘယ်လို ပြီးစီးရမလဲဟူသော အရိပ်အမြွက် ရှိသည်။
- plan ပေါ် ဖိုင်ဆွဲချသောအခါ "point ဖိုင်၊ LandXML သို့မဟုတ် စီမံကိန်းကို ချပါ" ဟု ပြသည်။
- ရွေးထားသော အရာများ မီးမောင်းပြသည်။ ရွေးထားသော alignment သို့မဟုတ် pad တွင် PI များ သို့မဟုတ် ထောင့်များ၌ စတုရန်းလက်ကိုင်များ ပြသည်; ရွေးထားသော structure တွင် လက်ကိုင်တစ်ခု ပြသည်။ လက်ကိုင်ကို ဆွဲ၍ ရွှေ့ပါ။
- ရွေးထားသော survey အမှတ်များတွင် ring ရှိသည်။ {{key:Shift}} နှင့် click က အမှတ်တစ်ခုကို ထည့်/ဖယ်; {{key:Shift}} နှင့် ဆွဲခြင်းက box (သို့မဟုတ် ပတ်ဝိုင်းဆွဲလျှင် lasso) ဆွဲပြီး အတွင်းရှိ အမှတ်များကို ထည့်သည်။ [Survey အမှတ်များကို ရွေး၊ copy နှင့် paste](topic:copy-paste-points) ကို ကြည့်ပါ။

## Profile view

{{key:R}} ကို နှိပ်ပါ သို့မဟုတ် {{ui:Profile}} ကို နှိပ်၍ plan အောက်တွင် ဖွင့်ပါ။ ၎င်း၏ bar တွင်:

- alignment စာရင်း (alignment နှစ်ခု သို့မဟုတ် ထို့ထက်ပိုရှိသောအခါ ဖွင့်သည်)
- {{ui:PVI များ ထည့်ရန်}}: ဖိနှိပ်ထားစဉ် profile ထဲ click တစ်ကြိမ်က PVI ထည့်သည် ({{key:I}} က ဖွင့်/ပိတ်)
- pointer အောက်ရှိ station၊ ground၊ design elevation၊ grade နှင့် cut or fill ဖတ်ခြင်း
- ပိတ်ခလုတ်

profile တွင် ရှိပြီးသား မြေပြင်၊ design profile၊ tangent တစ်ခုစီ၏ grade၊ PVI တစ်ခုစီ၏ station နှင့် elevation၊ vertical curve တစ်ခုစီ၏ L နှင့် K နှင့် BVC နှင့် EVC၊ high နှင့် low points များနှင့် vertical exaggeration ကို ပြသည်။ alignment တစ်ခုလုံးနှင့် အမြဲ ကိုက်ညီသည်: zoom သို့မဟုတ် pan မလုပ်ပါ။ profile တလျှောက် pointer ရွှေ့လျှင် plan ပေါ်ရှိ alignment တွင် အစက်တစ်ခု ပေါ်လာသည်။

## ညာဘက် panel: Properties

heading က ဘာကို ပြနေသလဲ ပြောသည်။

- **Project** (ဘာမျှ မရွေးထားသောအခါ): alignments နှင့် pads များကို လင့်ခ်အဖြစ်၊ **မြေထု** block၊ နှင့် စည်းမျဉ်းများနှင့် ပြဿနာများပါသော **Pipe network** block။
- **Alignment**: အမည်၊ စတင် station၊ အရှည်၊ PI ဇယား၊ curves၊ design profile ၏ PVI ဇယားနှင့် အချက်အလက်များ၊ နှင့် **Corridor** ဆက်တင်များ။
- **Pad**: အမည်၊ elevation၊ cut နှင့် fill slopes၊ ဧရိယာ၊ daylight အချက်အလက်များနှင့် မြေထု။
- **Structure** သို့မဟုတ် **Pipe**: အရွယ်အစားများ၊ rims၊ inverts၊ slope၊ cover နှင့် ပြဿနာများ။
- **Point** နှင့် ၎င်း၏ နံပါတ်: point ၏ ကိုဩဒိနိတ်၊ elevation၊ ဖော်ပြချက်နှင့် group (ဖတ်ရုံသာ)။

Fields များသည် {{key:Enter}} နှိပ်သည့်အခါ သို့မဟုတ် field မှ ထွက်သည့်အခါ ထိရောက်သည်။ လက်မခံသော တန်ဖိုးကို invalid ဟု အမှတ်အသားပြပြီး ဘာမျှ မပြောင်းပါ။

## Status bar

- **E** နှင့် **N**: pointer အောက်ရှိ easting နှင့် northing။
- ထိုနေရာ၏ **Ground** elevation (pad သို့မဟုတ် corridor ပြောင်းထားသော နေရာတွင် **Graded** ပါ) သို့မဟုတ် "မျက်နှာပြင်ပြင်ပ"။
- အနီးဆုံး alignment (သို့မဟုတ် ရွေးထားသည်) နှင့် pointer အောက်ရှိ **Sta** နှင့် offset (**L** သို့မဟုတ် **R**)။
- ညာဘက်တွင် မက်ဆေ့ချ်များ: ယခုဖြစ်ပွားသည်များ သို့မဟုတ် အဘယ်ကြောင့် တစ်ခုခု ငြင်းပယ်သည်ဆိုသည်။ မက်ဆေ့ချ်သည် စက္ကန့်အနည်းငယ်အကြာတွင် အလိုအလျောက် ပျောက်သည်။

## ဒိုင်ယာလော့ဂ်များ

- **အမှတ်များ သွင်းရန်**: point ဖိုင်အားလုံးဖြင့် ဖွင့်သည်။ [Survey အမှတ်များ သွင်းခြင်း](topic:import-points) ကို ကြည့်ပါ။
- **plan ကို PDF သို့ plot**: [plan ကို PDF သို့ plot လုပ်ခြင်း](topic:plot-pdf) ကို ကြည့်ပါ။
- **မသိမ်းရသေးသော ပြောင်းလဲမှုများ**: {{ui:အသစ်}} သို့မဟုတ် စီမံကိန်း/LandXML ဖိုင် ဖွင့်ခြင်းက မသိမ်းရသေးသော အလုပ်ကို ပစ်ရမည်ဖြစ်ပါက မေးသည်။ {{ui:မိတ္တူသိမ်းရန်}} က စီမံကိန်းကို ဦးစွာ ဒေါင်းလုဒ်ဆွဲသည်။

## ကျဉ်းသော စခရင်များ

760 pixel အထိ ကျယ်သော (ဖုန်းကဲ့သို့) ဝင်းဒိုးတွင် plan က စခရင်ကို ထိန်းသည်: toolbar သည် ဘေးသို့ scroll လုပ်သော တစ်တန်းတည်း ဖြစ်ပြီး panels များသည် အောက်ဘက် bar မှ sheets အဖြစ် ဖွင့်သည်။ {{ui:ကိရိယာများ}} က toolbar ကို ဖျောက်ပြီး {{ui:ရွှေ့ရန်}} က အောက်ဘက်သို့ ရွှေ့ထားသည်။

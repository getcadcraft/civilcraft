CivilCraft ၏ command များသည် ဘယ်လမ်းကြောင်းဖြင့် ရောက်ရောက် တူညီသည်။ **menu style** သည် ၎င်းတို့ ဖန်သားပြင်ပေါ် ဘယ်နေရာတွင် ရှိမည်၊ ၎င်းတို့ကို ဘာနာမည်ဖြင့် ခေါ်မည်နှင့် ဘယ် key က run မည်ကိုသာ ဆုံးဖြတ်သည်၊ ထို့ကြောင့် သင့်အလုပ်လုပ်ပုံ အကျင့်များကို ဆက်ထားနိုင်သည်။ {{ui:Settings}} ({{key:Mod+,}}) › {{ui:CivilCraft}} › {{ui:Menus, keys and mouse}} တွင် ရွေးပါ; ပြောင်းလဲမှုသည် ချက်ချင်းဖြစ်ပြီး ဤ browser က မှတ်ထားသည်။

## စတိုင်သုံးမျိုး

| စတိုင် | ရရှိမည့်အရာ |
|---|---|
| {{ui:CivilCraft}} | CivilCraft ၏ ကိုယ်ပိုင် toolbar (File, Export, Surface, Design, Edit, GIS, View) နှင့် တစ်လုံးတည်း key များ — {{key:A}} alignment၊ {{key:G}} pad၊ {{key:P}} ပိုက်၊ {{key:B}} breakline၊ {{key:O}} နယ်နမိတ်၊ {{key:L}} feature line၊ {{key:R}} ပရိုဖိုင်၊ {{key:X}} အပိုင်းဖြတ်၊ {{key:E}} ခြေစောင်း၊ {{key:D}} 3D၊ {{key:F}} ကိုက်ညီအောင်၊ {{key:V}} ရွေးရန်။ မူလစတိုင် ဖြစ်သည်။ |
| {{ui:Drafting classic}} | ribbon အသေး ({{ui:Home}}, {{ui:Insert}}, {{ui:Output}}) နှင့် command line — command ရိုက်သူများအတွက်၊ ALIGNMENT, PAD, PIPE, FEATURELINE, BREAKLINE, PROFILE, SECTIONS, U (ပြန်ဖျက်), ZOOM, 3D, PLOT, LANDXML, XATTACH, MAPIMPORT, HELP။ မည်သည့်နေရာတွင်မဆို ရိုက်ထည့်ပါ၊ စာလုံးများသည် command line သို့ ရောက်သွားသည်; {{key:Enter}} က run၊ ဘာမျှ မရွေးဘဲ {{key:Enter}} နှိပ်လျှင် နောက်ဆုံး command ကို ထပ်လုပ်သည်၊ {{key:Esc}} က ရှင်းလင်းသည်။ အလယ်ခလုတ်က ပလန်ကို pan လုပ်သည်။ |
| {{ui:Civil ribbon}} | ခလုတ်ကြီးများ tab များအဖြစ်၊ အင်ဂျင်နီယာ ဒီဇိုင်းပရိုဂရမ်များ၏ ကိရိယာများ အုပ်စုဖွဲ့ပုံအတိုင်း — {{ui:Home}} (မြေပြင်ဒေတာ၊ ဒီဇိုင်းဖန်တီးခြင်း၊ ပရိုဖိုင်နှင့် အပိုင်းကြည့်ခြင်း)၊ {{ui:Surfaces}}၊ {{ui:Modify}}၊ {{ui:Geolocation}}၊ {{ui:View}} နှင့် {{ui:Output}}၊ {{ui:File}} menu နှင့် ညာဘက်ရှိ အမြန်ခလုတ်များပါသည်။ တစ်လုံးတည်း key များ ကျန်ရှိသည်။ အလယ်ခလုတ်က ပလန်ကို pan လုပ်သည်; 3D တွင် အလယ်ခလုတ်က pan လုပ်ပြီး {{key:Shift}} နှင့် အလယ်ခလုတ်က orbit လုပ်သည်။ |

စတိုင်တိုင်းသည် {{key:Mod}} key များကို ဆက်ထားသည်: {{key:Mod+Z}}, {{key:Mod+Y}}, {{key:Mod+S}}, {{key:Mod+O}}, {{key:Mod+P}}, {{key:Mod+C}}, {{key:Mod+X}}, {{key:Mod+V}}, {{key:Mod+D}}, {{key:Mod+A}}။

:::tip
CivilCraft ၏ ကိုယ်ပိုင် အပြင်အဆင်နှင့် ပိုင်သော key တစ်ခုကို သင့်စတိုင်က အခြား command တစ်ခုအတွက် ပေးထားလျှင် ဘာမျှ မဖြစ်ပါ၊ အခြေအနေလိုင်းက command ကို ဘယ်ကို ရောက်သွားသည်ကို ပြသည် (\"In My keys, Pad is Ctrl+Alt+G\")။ {{key:Delete}}၊ {{key:Esc}}၊ {{key:Enter}}၊ {{key:Tab}}၊ {{key:Space}} နှင့် မြားခလုတ်များသည် အမြဲ မူလအဓိပ္ပာယ်ကို ဆက်ထားသည်၊ လိုင်းတစ်ကြောင်းဆွဲနေစဉ် ၎င်း၏အမှတ်များသည် ၎င်းတို့၏ key များ ({{key:Backspace}}၊ {{key:Enter}}) ကို ဆက်ထားသည်။
:::

## ကိုယ်ပိုင်ပြုလုပ်ခြင်း

1. သင် လိုချင်သည်နှင့် အနီးဆုံး စတိုင်ကို ရွေးပြီး {{ui:Customize…}} ကို နှိပ်ပါ။
2. {{ui:Keys and menus}} တွင် command ကို ရှာပါ (ရှာဖွေရေးအကွက်က အထောက်အကူပြုသည်)။ {{ui:Add a key}} ကို နှိပ်ပြီး key ကို နှိပ်ပါ၊ သို့မဟုတ် တစ်ဆက်တည်း key နှစ်ခု နှိပ်ပါ (အက္ခရာနှစ်လုံး key အတွက်)။ key ကို နှိပ်လျှင် ဖယ်ရှားသည်။
3. ribbon ရှိလျှင် {{ui:Where it sits}} က command ကို အခြား tab နှင့် panel သို့၊ {{ui:File}} menu သို့၊ သို့မဟုတ် {{ui:Keys only}} သို့ ရွှေ့သည်။
4. {{ui:Mouse}} တွင် ဘီး၊ ပလန်ကို pan လုပ်သည့် ခလုတ်များနှင့် 3D view တွင် ခလုတ်တစ်ခုစီက ဘာလုပ်မည်ကို သတ်မှတ်ပါ။
5. နာမည်ပေးပြီး {{ui:Save}} ကို နှိပ်ပါ။

built-in စတိုင်ကို သိမ်းလျှင် သင့်ကိုယ်ပိုင်မိတ္တူ (\"My Civil ribbon\") ဖန်တီးသည်; built-in ကတော့ ဘယ်တော့မှ မပြောင်းပါ။ key တစ်ခုကို command နှစ်ခုအတွက် ပေးထားလျှင်၊ သို့မဟုတ် အက္ခရာနှစ်လုံး key မရိုက်မီ run မည့် key ဖြစ်လျှင် အနီရောင်ဖြင့် ပြပြီး သိမ်းခင် ပြင်ရမည်။

## Mouse

- **ဘီး**: {{ui:Scroll up zooms in}} (မူလ) သို့မဟုတ် {{ui:Scroll up zooms out}}၊ နှင့် မြန်နှုန်း၊ ပလန်နှင့် 3D တွင်။ trackpad pinch က အမြဲ သင့်လက်ရွှေ့သည့်လမ်းကြောင်းအတိုင်း zoom လုပ်သည်။
- **ပလန်ကို pan လုပ်ရန်**: အလယ်ခလုတ်၊ ညာခလုတ်၊ သို့မဟုတ် နှစ်ခုလုံး။ {{key:Space}} နှင့် ဆွဲခြင်းလည်း pan လုပ်သည်။ ဘယ်ခလုတ်က အမြဲ ရွေးပြီး ဆွဲသည်။
- **3D view တွင် ဆွဲခြင်း**: {{ui:View တစ်ခုစီ၏ ကိုယ်ပိုင်}} က CivilCraft ၏ ခလုတ်များကို ထားသည် (ဘယ်က orbit၊ ညာက pan)။ သို့မဟုတ် ခလုတ်တစ်ခုစီကို orbit၊ pan၊ zoom သို့မဟုတ် ဘာမျှမလုပ်ရန် သတ်မှတ်နိုင်သည်; {{key:Shift}} နှင့် ခလုတ်က orbit နှင့် pan ကို လဲလှယ်သည်။ ဆွဲခြင်းမရှိဘဲ နှိပ်ခြင်းက ရွေးသည်။

## ယူသွားရန်

{{ui:Export}} က အသုံးပြုနေသော စတိုင်ကို `.ccinput.json` ဖိုင်ငယ်အဖြစ် သိမ်းသည်; {{ui:Import…}} က အခြားကွန်ပျူတာ သို့မဟုတ် လုပ်ဖော်ကိုင်ဖက်ထံမှ တစ်ခုကို ထည့်သည်။ ထည့်သွင်းသော ဖိုင်သည် CivilCraft ၏ ကိုယ်ပိုင် command များကိုသာ ညွှန်ပြနိုင်သည်; အခြားအရာများကို ဖယ်ထုတ်ပြီး အခြေအနေလိုင်းတွင် ရေတွက်ပြသည်။ {{ui:Delete this style}} က သင့်ကိုယ်ပိုင် တစ်ခုကို ဖျက်သည်။

:::note
ဤဆက်တင်များသည် ဤ browser တွင်သာ ရှိနေသည်။ style ကဒ်များအောက်ရှိ {{ui:Use this style in every app}} က အက်ပ်တိုင်းကို ၎င်းနှင့်ကိုက်ညီသော စတိုင် (ကိုယ်ပိုင် toolbar၊ ribbon သို့မဟုတ် Drafting classic) ဖြင့် ဖွင့်စေပြီး၊ အက်ပ်တစ်ခုစီတွင် သင်ပြုလုပ်ခဲ့သော ပြောင်းလဲမှုများကို ထည့်ထားသည်။ CivilCraft တွင် menu bar စတိုင် မရှိပါ; အခြား အက်ပ်၏ menu bar ကို အက်ပ်အားလုံးအတွက် ရွေးထားလျှင် CivilCraft သည် ၎င်း၏ ကိုယ်ပိုင် toolbar ကို ဆက်ထားသည်။
:::

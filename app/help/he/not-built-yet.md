CivilCraft נמצאת בשלבים מוקדמים. העמוד הזה מפרט מה הגרסה הנוכחית לא עושה, כדי שלא תחפשו זאת. שום דבר כאן לא מובטח לתאריך כלשהו.

## נקודות

| טרם נבנה | במקום, היום |
|---|---|
| הוספת קובץ נקודות שני לראשון | חברו את הקבצים בעורך טקסט או בגיליון אלקטרוני קודם |
| ייצוא קובץ טקסט של נקודות | ייצוא LandXML (הנקודות יוצאות כ-CgPoints), או {{ui:Export}} ב-GIS (נקודות עם השדות P, N, E, Z ו-D), או {{ui:Copy}} של הנקודות לגיליון אלקטרוני |
| סגנונות תוויות לנקודות, סמלים לפי מפתח תיאור, עקומים (קשתות) מקודי קו, קובץ מפתח תיאורים לשיתוף בין פרויקטים | תוויות מציגות את המספר, הגובה והתיאור, או פחות ([הגדרות CivilCraft](topic:settings)); המפתחות נשמרים בקובץ הפרויקט |
| המרת יחידות | המירו את הקובץ לפני הייבוא; **יחידות** רק משנה את התווית |

## משטחים

| טרם נבנה | במקום, היום |
|---|---|
| יותר ממשטח אחד שנבנה מנקודות | פרויקט אחד לכל משטח |
| הסתרת גבולות (פנימיים) | השתמשו ב-**הקצה החיצוני הארוך ביותר** או בגבול חיצוני |
| בחירה או עריכה של קו שבר בודד שצויר | {{key:Mod+Z}}, או {{ui:Remove drawn breaklines}} וציור מחדש |
| עריכת משטח שנקרא מ-LandXML (קווי שבר, גבול) | {{ui:Rebuild the surface from the points}} |
| עריכת משטח שנוצר מרשת גבהים | ייבוא הרשת מחדש עם בחירות אחרות |
| המרת משטח שנקרא מ-LandXML כשמערכת הקואורדינטות משתנה | {{ui:Rebuild the surface from the points}} קודם |
| גבהים נקודתיים מסומנים וערכי שיפוע | קראו אותם בשורת מצב, או צבעו את המשטח לפי שיפוע עם **ניתוח שיפועים** בסביבת העבודה Landscape ([פיתוח לגינון](topic:landscape-grading#grading-checks)) |

| חתכים ב-DWG או ב-LandXML | גיליונות חתכים כ-PDF; {{ui:CSV}} של השטחים והנפחים |
| קווי דגימה בזווית, או ברוחב משתנה לאורך הכביש | רוחב אחד מכל צד לכל היישור |

## מסדרונות

| טרם נבנה | במקום, היום |
|---|---|
| שטחי הפרדה, מחסומים, ושיפוע רוחב (superelevation) שמסובב תבניות | צרו אותם כתבניות ([תבניות מסדרון](topic:corridor-templates)); תבניות לפי תחנה עדיין לא לוקחות שיפוע רוחב |
| שינוי הדרגתי בין תבניות של שני אזורים (מעברים, טייפרים) | שנו את התבנית בתחנה, או תנו לנקודה יעד רוחב לקו שצויר כטייפר |
| סיבוב סביב קצה, שיפוע רוחב ב-LandXML | שיפוע רוחב מסתובב סביב קו המרכז בעקומים מעגליים; הרחיבו נתיב עם יעד רוחב לקו מאפיין |
| יעדים לשיפועי הצדדים (חיתוך עד קו או משטח), משטחי מסדרון משלהם | היעדים מזיזים את קצוות הכביש והשוליים ([מסדרונות](topic:corridor)); המסדרון מפותח אל המשטח המתוכנן |
| ייצוא מסדרונות כ-roadways של LandXML; מסדרון שני על יישור בייצוא IFC | יוצא המשטח המתוכנן |
| תבניות שטח שמשנות את המשטח המתוכנן, בתלת-ממד או בחתכים | הן נותנות שטחים ונפחים של כל שכבה ([תבניות שטח](topic:corridor-templates#terrain-templates)) |
| מסלולי סחיפה עם מהירות, החלקת צמיגים, זמן היגוי, גוררות היגוי או מרווח גוף; ספרייה של כלי רכב תכנון סטנדרטיים; מסלול סחיפה שמצויר בגרירת הרכב | מסלולי סחיפה במהירות נמוכה לאורך קו מאפיין או יישור, עם גודלי רכב משלכם ([מסלולי סחיפה לרכב](topic:swept-paths)) |

## פיתוח ונפחים

| טרם נבנה | במקום, היום |
|---|---|
| מדרגות (benches), קווי מאפיין פתוחים שמפותחים לתכנון, פיתוח אל קו מאפיין ממקום אחר | סגרו את קו המאפיין ([קווי מאפיין](topic:feature-lines)), או השתמשו בו כקו שבר של הקרקע הקיימת |
| הוספה או הסרה של קודקוד בקו מאפיין | ציירו את הקו מחדש, או צרו ממנו היסט מדורג |
| קשתות בקווי שבר שצוירו (דרך נקודות מדידה), ספירלות בקווי מאפיין | צרו קו מאפיין עם קשתות והשתמשו בו כקו שבר של הקרקע הקיימת |
| פיתוח למרחק, לגובה או למשטח אחר | חיתוך עם הקרקע הקיימת בלבד |
| הוספה או הסרה של פינת משטח בנייה | מחקו את המשטח וציירו אותו מחדש |
| נפחי TIN-ל-TIN (פריזמה), בחירת גודל תא הרשת | שיטת רשת, וגודל התא נבחר בשבילכם |
| נפח תפיחה וכיווץ, אדמה עליונה, עובי מבנה כביש | החילו מקדמים על המספרים המדווחים בעצמכם |
| עלויות הובלה חופשית והובלה מעבר למרחק החופשי, הובלה בין יישורים שונים, בורות השאלה ואתרי פסולת שממוקמים בתוכנית | דיאגרמת הובלה המונית (mass-haul) עם נקודות איזון, נפחים שהוזזו ומרחקי הובלה ממוצעים |

## רשתות צינורות

| טרם נבנה | במקום, היום |
|---|---|
| יותר מרשת אחת לכל פרויקט | פרויקטים נפרדים למי נגר ולביוב |
| קווי מים ראשיים: איכות מים וגיל, בקרות מבוססות כללים, סוגי שסתומים אחרים (בקרת זרימה, חניקה, תמיכה), משאבות שנתונות בהספק, ביקוש התלוי בלחץ, אפשרות Darcy–Weisbach, קטלוג צינורות עם עובי דופן ומחלקות לחץ. שאר רשתות הלחץ נמצאות במעבדה: [קווי מים ראשיים](topic:water-mains) | בדקו אותם בתוכנת תכנון אספקת מים; ספיקות תכנון לביוב נמצאות ב[ספיקות תכנון לביוב](topic:sanitary-design) |
| זרימות ביוב לאורך זמן (הידרוגרפים, ניתוב דינמי, אגירה, משאבות, גלישות) | [ספיקות תכנון לביוב](topic:sanitary-design) נותן את שיא הספיקה היציבה שגיליון התכנון משתמש בו |
| קיבולת שוחות כניסה, פיזור במרזב, ניתוב אגירה, הידרוגרפים, אובדני אנרגיה חוץ ממקדם צומת אחד | בדקו בתוכנות אחרות; הספיקות, הגדלים וקווי הגרדיאנט ההידראולי נמצאים ב[ניקוז מי נגר](topic:storm-drainage) |
| אגני ניקוז בהדפסת PDF, ב-DWG, ב-DXF או ב-LandXML; אגני ניקוז מהמשטח (אגני היקוות) | צייר אגני ניקוז ביד; הם נשמרים בקובץ הפרויקט |
| קטלוגי צינורות, צינורות לא עגולים, מבנים שאינם קופסאות או גלילים זקופים (חרוטים, מדרגות, benching), קטגוריית ניקוז בספרייה | סוגי מבנים מפרמטרים ([רשת צינורות](topic:pipe-network)); צינורות עם קוטר |
| צינורות בתצוגת חתך האורך, צינורות מעוקלים | קראו את התחתיות והכיסוי בחלונית הימנית |

| טרנספורמציות SVG בסמלים משלכם; מרקמים וצבעים של מודלי צמחים GLB משלכם; גיאומטריית GLB דחוסה | פשטו את הטרנספורמציות בתוכנית השרטוט שלכם קודם; מודלים מצוירים בצבע הצמח; ייצאו את ה-GLB בלי דחיסה ([גרפיקה של צמחים](topic:plant-graphics)) |

| דירוג תרמי של כבלים קבורים (זרם מותר לפי אופן ההנחה) | הזינו את דירוג הזרם של הספק על פריט הכבל |
| חישובי קצר, הגנה והארקה | השתמשו בתוכנה חשמלית ייעודית; CivilCraft נותן את אורכי הרשת והכבלים |
| מגדלי סבכה שמתוכננים אלמנט אחר אלמנט, ועוגני חיזוק בקרקע | עמודים נבדקים לפי עומס נומינלי; חיזוקים (stay) לפי עומס הדירוג שלהם |
| קובץ חישוב `.DON` שנבדק בתוכנה שקוראת אותו | בדקו אותו שם; שלחו לנו דוגמה כדי שנוכל לבדוק מול קובץ אמיתי |
| קווי חשמל בתצוגה התלת-ממדית וב-IFC | התוכנית, חתך האורך של הקו, הגיליונות ושכבות ה-GIS |
| כלי קווי החשמל לעוזרים בלי החלון | הם פועלים כשחלון CivilCraft פתוח ([תנו לעוזר AI לעבוד עם האתר שלכם](topic:assistants)) |

## GIS ומערכות קואורדינטות

| טרם נבנה | במקום, היום |
|---|---|
| File Geodatabase; סגנונות KML, סמלים, שכבות על הקרקע וקישורי רשת | המירו ל-GeoPackage, ל-shapefile או ל-GeoJSON קודם; סמני KML נקראים בלי הסגנונות שלהם |
| עריכת אובייקטים של GIS או המאפיינים שלהם | ערכו אותם בתוכנת GIS וייבאו שוב. חלונית הניתוח יוצרת שכבות חדשות (buffer, overlay, join, selection) ומוסיפה שדות שטח ואורך, אבל לא עורכת אובייקט במקום |
| ניתוח רשתות ורסטר, אזורי חיץ (buffers) עם קצוות שטוחים או מרובעים ואזורי חיץ חד-צדדיים, הוספה או מחיקה של שורות ושינוי סוג שדה בטבלת המאפיינים, צבעי מחלקות ידניים, מקרא סגנון בהדפסות | השתמשו ב-{{ui:Select}} כדי לבחור אובייקטים וליצור מהם שכבה; קצוות שטוחים לא מוצעים. צביעה לפי מאפיין וטבלת המאפיינים כבר קיימות: ראו [סגנון שכבה לפי מאפיין](topic:gis-symbology) ו-[עבודה עם טבלת המאפיינים של שכבה](topic:gis-table) |
| סגנונות תוויות (גודל, מיקום) ותוויות שנמנעות זו מזו | התוויות בגודל אחד, ועשויות להתכסות כשהאובייקטים צפופים |
| בסיסי גובה (vertical datums) ומודלי גאואיד | הגבהים נלקחים כפי שהקובץ נותן אותם; בדקו את בסיס הגובה בעצמכם |
| הזזות רשת חוץ מ-NAD27 ל-NAD83 שמוצעות לפי אזור (OSTN15; NTv2 לבסיסי נתונים אחרים עובד כשמוסיפים את הקובץ), כמה רשתות בבת אחת, רשתות גובה | הוסיפו בעצמכם את קובץ הרשת של בסיס הנתונים שלכם; רשת אחת לכל פרויקט |
| שכבות מפה בייצוא DXF או בתלת-ממד | שכבות המפה נכנסות להדפסת ה-PDF, וליד ה-DWG כתמונה |
| שרתי מפות שדורשים כניסה, מפתח או טוקן | השתמשו בשירותים ציבוריים, או בקובץ תמונה עם גאו-רפרנס |
| כתיבת קובצי LAS או LAZ ממשטח, ממודל הקרקע או מכלי רשת הגבהים ו-LiDAR | ייצאו משטחים כרשת גבהים GeoTIFF. התוספת [ענני נקודות](topic:point-clouds) כותבת ענן נקודות מנוקה כ-LAS 1.4 או LAZ |
| עוצמת LiDAR, צבע והחזרות; רשתות גבהים עם כמה פסים; קובצי רשת או LiDAR מעל 200 MB | LiDAR מסונן לפי סיווג בלבד, ורשתות משתמשות בפס הראשון; חתכו קבצים גדולים לאריחים קודם |

|---|---|

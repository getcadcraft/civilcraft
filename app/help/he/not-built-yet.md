CivilCraft היא בשלב מוקדם. עמוד זה מפרט מה הגרסה הנוכחית אינה עושה, כדי שלא תחפשו את זה. דבר מכל זה אינו מובטח לתאריך כלשהו.

## נקודות

| טרם נבנה | במקום זאת, כיום |
|---|---|
| הוספת קובץ נקודות שני לקובץ הראשון | אחדו את הקבצים בעורך טקסט או בגיליון אלקטרוני תחילה |
| ייצוא קובץ טקסט של נקודות | ייצאו LandXML (הנקודות יוצאות כ-CgPoints), השתמשו ב-GIS {{ui:ייצוא}} (נקודות עם שדות P, N, E, Z ו-D), או {{ui:העתקה}} את הנקודות לגיליון אלקטרוני |
| סגנונות תוויות נקודה, סמלים לפי מפתח תיאור, עקומים (קשתות) מקודי קווים, קובץ מפתח תיאור לשיתוף בין פרויקטים | התוויות מציגות את המספר, הגובה והתיאור, או פחות מכך ([הגדרות CivilCraft](topic:settings)); המפתחות נשמרים בקובץ הפרויקט |
| המרת יחידות | המירו את הקובץ לפני היבוא; **יחידות** רק משנה את התווית |

| מגדלי סורג שמתוכננים אלמנט אחר אלמנט, ועוגני מתיחה באדמה | התמיכות נבדקות לפי העומס הנומינלי שלהן; המתיחות לפי העומס המדורג שלהן |
| קובץ חקר `.DON` שנבדק בתוכנה שקוראת אותו | בדקו את הקובץ שם; שלחו לנו דוגמה כדי שנוכל לבדוק מול קובץ אמיתי |

| כלי קווי החשמל לעוזרים ללא החלון | הם פועלים כאשר חלון CivilCraft פתוח ([תנו לעוזר AI לעבוד עם האתר שלכם](topic:assistants)) |

## GIS ומערכות קואורדינטות

| טרם נבנה | במקום זאת, כיום |
|---|---|
| File Geodatabase; סגנונות KML, סמלים, שכבות על הקרקע וקישורי רשת | המירו ל-GeoPackage, ל-shapefile או ל-GeoJSON תחילה; סמני KML נקראים בלי הסגנונות שלהם |
| עריכת אובייקטי GIS או התכונות שלהם | ערכו אותם בתוכנת GIS וייבאו שוב. לוח הניתוח יוצר שכבות חדשות (חיץ, שכבת-על, חיבור, בחירה) ומוסיף שדות שטח ואורך, אבל אינו עורך אובייקט במקומו |
| ניתוח רשת ורסטר, חיץ (buffer) עם קצוות שטוחים או מרובעים וחיץ חד־צדדי, הוספה או מחיקה של שורות ושינוי סוג שדה בטבלת התכונות, צבעי מחלקה ידניים, מקרא סגנון בשרטוטים | השתמשו ב{{ui:בחירה}} כדי לבחור אובייקטים וליצור מהם שכבה; קצוות שטוחים אינם מוצעים. צביעה לפי תכונה וטבלת התכונות כבר בנויות: ראו [עיצוב שכבה לפי תכונה](topic:gis-symbology) ו[עבודה עם טבלת התכונות של שכבה](topic:gis-table) |
| סגנונות תוויות (גודל, מיקום) ותוויות שנמנעות זו מזו | התוויות בגודל אחד ועשויות להתחפף במקומות צפופים |
| מישורי ייחוס אנכיים ומודלי גיאואיד | הגבהים נמצאים כפי שהקובץ נותן אותם; בדקו את מישור הייחוס האנכי בעצמכם |
| הזזות רשת מלבד NAD27 ל-NAD83 שמוצעות לפי אזור (OSTN15, NTv2 למישורי נתונים אחרים פועלים כשמוסיפים את הקובץ), כמה רשתות בבת אחת, רשתות אנכיות | הוסיפו בעצמכם את קובץ הרשת למישור הנתונים שלכם; רשת אחת לפרויקט |
| שכבות מפה ב-DXF או בייצואי תלת־ממד | שכבות המפה נכנסות ל-PDF, ו-DWG כתמונה לצד |
| שרתי מפה שדורשים כניסה, מפתח או אסימון | השתמשו בשירותים ציבוריים, או בקובץ תמונה עם גיאורפרנס |
| כתיבת קובצי LAS או LAZ ממשטח, ממודל הקרקע או מכלי רשת הגבהים ו-LiDAR | ייצאו משטחים כרשת גבהים GeoTIFF. התוסף [ענני נקודות](topic:point-clouds) כותב ענן מנוקה כ-LAS 1.4 או LAZ |
| עוצמת LiDAR, צבע והחזרות; רשתות גבהים עם כמה פסים; קובצי רשת או LiDAR מעל 200 MB | LiDAR מסונן לפי מחלקה בלבד, רשתות משתמשות בפס הראשון; חתכו קבצים גדולים לאריחים תחילה |

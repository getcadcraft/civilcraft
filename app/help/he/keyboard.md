מקשי אות בודדת עובדים כשאינכם מקלידים בתיבה. קיצורים עם {{key:Mod}} משתמשים ב-Command במק וב-Ctrl בשאר המערכות. ראו גם [מקשים בדפדפן](common:keys).

## קבצים ועריכה

| מקש | פעולה |
|---|---|
| {{key:Mod+O}} | פתיחת קובץ נקודות, LandXML או פרויקט |
| {{key:Mod+S}} | שמירת הפרויקט (מוריד קובץ `.civilcraft.json`) |
| {{key:Mod+P}} | הדפסת התוכנית ל-PDF (פותח את תיבת ההדפסה, לא את ההדפסה של הדפדפן) |
| {{key:Mod+Z}} | ביטול |
| {{key:Mod+Y}} | ביצוע חוזר |
| {{key:Delete}} | מחיקת נקודות המדידה, הציר, המשטח, המבנה, הצינור או ה-PVI שנבחרו |
| {{key:Mod+C}} | העתקת נקודות המדידה שנבחרו (גם כשורות נקודה לגיליון אלקטרוני) |
| {{key:Mod+X}} | גזירת נקודות המדידה שנבחרו |
| {{key:Mod+V}} | הדבקת נקודות: הן עוקבות אחרי הסמן, לחצו היכן שהן צריכות להיות |
| {{key:Mod+Shift+V}} | הדבקה במקום: במיקום הקואורדינטות של הנקודות עצמן |
| {{key:Mod+D}} | שכפול הנקודות שנבחרו: עותק עוקב אחרי הסמן |
| {{key:Mod+A}} | בחירת כל נקודות המדידה |
| {{key:Esc}} | ביטול הבחירה (וביטול הדבקה) |

{{key:Mod+S}}, {{key:Mod+O}} ו-{{key:Mod+P}} פועלים גם כשאתם מקלידים בתיבה. {{key:Mod+Z}} ו-{{key:Mod+Y}} בתיבת טקסט מבטלים את ההקלדה שלכם במקום זאת, כרגיל, וכך גם {{key:Mod+C}}, {{key:Mod+X}}, {{key:Mod+V}} ו-{{key:Mod+A}}: בתיבה הם מעתיקים, גוזרים, מדביקים ובוחרים את הטקסט שבה. כאשר טקסט מסומן בעמוד (בחלונית), {{key:Mod+C}} מעתיק את הטקסט הזה. {{key:Mod+Shift+Z}} אינו עושה דבר ב-CivilCraft: השתמשו ב-{{key:Mod+Y}} או בכפתור {{ui:ביצוע חוזר}}.

:::mac
במק, המקש המסומן **delete** הוא {{key:Backspace}} בעיני הדפדפן. כדי למחוק בחירה, לחצו {{key:Delete}} (Fn ומחיקה), או בחרו {{ui:מחיקה}} בתפריט {{ui:עוד}} שבסרגל הכלים.
:::

## בזמן ציור

| מקש | פעולה |
|---|---|
| {{key:Enter}} | סיום הציר, המשטח, קו הצנרת, קו השבירה או הגבול |
| {{key:Backspace}} | הסרת הנקודה האחרונה שנלחצה |
| {{key:C}} | קו מאפיין: הפעלה או כיבוי של קשתות (אחרי קודקוד, לחצו על נקודה בעקום, ואז על הקצה שלו) |
| {{key:Esc}} | ביטול הציור (או ההדבקה); בלחיצה נוספת (או כשאין דבר מצויר), חזרה ל-{{ui:בחירה}} וניקוי הבחירה |

## תצוגת התוכנית

| מקש או פעולה | תוצאה |
|---|---|
| גלגלת | זום פנימה או החוצה בסמן |
| גרירה על מקום ריק | הזזה (בכל כלי; קליק קצר עדיין לוחץ; עם {{key:Shift}} לחוץ, מצייר תיבת בחירה במקום) |
| גרירה עם הכפתור האמצעי | הזזה |
| גרירה עם הכפתור הימני | הזזה (אין תפריט נפתח) |
| {{key:Space}} וגרירה | הזזה |
| קליק | בחירה (עם {{ui:בחירה}}), או הצבת נקודה (עם כלי ציור) |
| {{key:Shift}} וקליק | הוספת נקודת מדידה לבחירה, או הוצאתה ממנה |
| {{key:Shift}} וגרירה | ציור תיבה: נקודות המדידה שבתוכה מתווספות לבחירה. גררו סביבן ל[לאסו](topic:lasso-selection) |
| {{key:Space}} בזמן ציור לאסו | חלון, אחריו חוצה, ואחריו גדר |
| קליק בזמן הדבקה | הנחת הנקודות המודבקות שם ({{key:Enter}} מניח אותן במיקום הקואורדינטות שלהן) |
| גרירת ידית | הזזת PI, פינת משטח או מבנה (צעד ביטול אחד) |
| {{key:Up}} {{key:Down}} {{key:Left}} {{key:Right}} | הזזה, כשלתוכנית יש את הפוקוס (לחצו עליה קודם) |
| {{key:Plus}} ו-{{key:Minus}} | זום פנימה והחוצה במרכז, כשלתוכנית יש את הפוקוס |

מקש = מגדיל זום כמו {{key:Plus}}, כך שאינכם צריכים Shift.

## תצוגת הפרופיל

| פעולה | תוצאה |
|---|---|
| קליק כש{{ui:הוספת PVI}} פועל | הוספת PVI שם |
| קליק על PVI | בחירתו |
| גרירת PVI | הזזתו (צעד ביטול אחד) |
| {{key:Delete}} או {{key:Backspace}} | הסרת ה-PVI שנבחר ({{key:Backspace}} רק כשלתצוגת הפרופיל יש את הפוקוס) |

תצוגת הפרופיל אינה מגדילה זום ואינה מזיזה.

## מסך ועזרה

| מקש | פעולה |
|---|---|
| {{key:F1}} | פתיחה או סגירה של העזרה הזו (החלונית הצדדית); {{ui:עזרה}} בסרגל היישום עושה את אותו הדבר |
| {{key:Esc}} | סגירת חלונית העזרה כשהיא פתוחה |
| {{key:Ctrl+Shift+F}} | מעבר מחזורי בין מצבי המסך: מסך מלא, מסך מלא עם הפסים מוסתרים, רגיל |
| {{key:Esc}} | יציאה ממסך מלא (המקש של הדפדפן עצמו) |

{{key:F1}} מגיע לעזרה לפני ש-CivilCraft רואה אותו, כך שהוא עובד בכל כלי. במקלדות מק רוב הדגמים לוחצים על fn יחד עם F1, או לוחצים על {{ui:עזרה}}. {{key:Ctrl+Shift+F}} משתמש במקש Control בכל מערכת, כולל במק. ראו [שימוש בעזרה](common:help) כדי לדעת כיצד לחפש בעזרה הזו.

## עכבר, משטח מגע ומגע

:::mouse
- גלגלת מזיזה זום בסמן. עכבר עם גלגלת שמסתובבת חופשי מזום מהר: תנו לו סיבובים קצרים.
- הזזה בכל גרירה על מקום ריק, בכפתור האמצעי, בכפתור הימני, או {{key:Space}} וגרירה.
:::

:::mac
במשטח מגע של מק:

- גלילה בשתי אצבעות **מבצעת זום** (היא אינה מזיזה), וצביטה מבצעת זום גם כן.
- כדי להזיז, לחצו וגררו על מקום ריק באצבע אחת, או החזיקו {{key:Space}} וגררו.
- לחיצה בשתי אצבעות (לחיצה ימנית) אינה פותחת תפריט ואינה עושה דבר בפני עצמה.
:::

:::touch
במסך מגע:

- המגע הראשון הופך כפתורים ושורות תפריט לגודל אצבע.
- הקישו כדי לבחור או להציב נקודה; אצבע אחת הנגררת על מקום ריק מזיזה. הקשה עשויה לנוע מעט: ההזזה מתחילה רק אחרי שהאצבע זזה כ-10 פיקסלים.
- שתי אצבעות צובטות לזום ונעות יחד להזזה.
- גררו ידית או PVI באצבע אחת. לידיות יש רווח בגודל אצבע סביבן.
- בזמן ציור ציר, משטח, קו שבירה, גבול, קו צנרת, קו מאפיין או חלקה, פס מעל התוכנית מציע את {{ui:סיום}} ({{key:Enter}}), {{ui:ביטול נקודה}} ({{key:Backspace}}) ו-{{ui:ביטול}} ({{key:Esc}}). לחיצה ארוכה (חצי שנייה בלי לזוז) מסיימת גם היא.
- ב-{{ui:בחירה}}, לחיצה ארוכה על נקודת מדידה מוסיפה אותה לבחירה, או מוציאה אותה, כמו {{key:Shift}}+קליק.
- בתצוגת 3D, אצבע אחת מסובבת, שתיים צובטות ומזיזות, והקשה בוחרת.
- במגע אין ריחוף, ולכן קריאות שורת הסטטוס מתעדכנות רק כשאצבע לחוצה.
:::

## מקשי דפדפן שגוברים

יש מקשים ששייכים לדפדפן ואינם מגיעים ל-CivilCraft לעולם, למשל {{key:Mod+W}} (סגירת לשונית), {{key:Mod+T}} (לשונית חדשה), {{key:Mod+N}} (חלון חדש) ו-{{key:F11}} (מסך מלא בדפדפנים של Windows ו-Linux). CivilCraft אינו משתמש בהם. אם קיצור פותח משהו בדפדפן במקום, לחצו פעם אחת על התוכנית כדי שלדף יהיה הפוקוס, ונסו שוב.

## איפה נמצאת ההזזה

אין פקודת Move: בחרו {{ui:בחירה}} וגררו נקודה או קודקוד, או ערכו את הקואורדינטות שלהם ב-{{ui:מאפיינים}}. ראו [עריכת נקודות](topic:edit-points).

{{ui:DXF}} כותב את מה שהתוכנית מציגה כקובץ DXF בפורמט R12, הגרסה שכל תוכנת CAD פותחת. אם עבדתם עם AutoCAD או Civil 3D, פתחו או הוסיפו אותו כמו כל קובץ DXF אחר.

## ייצוא

1. הגדירו את התוכנית כפי שאתם רוצים את השרטוט: תחת **תצוגה**, בחרו את המשטח (קיים או מתוכנן), מרווח קווי הגובה, ואילו דברים מופעלים (קווי גובה, תוויות, נקודות, תוויות נקודות, משולשים, קווי שבירה, קצה המשטח, צינורות, חיצי שיפוע).
2. לחצו על {{ui:DWG/DXF}} בקבוצה **ייצוא** ובחרו {{ui:DXF (R12, text) — the plain exchange file}}, ואז {{ui:Download}}.
3. הדפדפן מוריד את `<name>.dxf`. שורת המצב מציגה, למשל, "יוצא R12 DXF: 2,140 אובייקטים; תוויות בגודל ל-1" = 40'. רצועות אינן מיוצאות."

הקואורדינטות נכתבות ביחידות הפרויקט, בערכיהן האמיתיים (קואורדינטות State Plane נשארות כמות שהן). דבר אינו מוקטן או מוזז.

## מה יש בקובץ

| פריט | ישות DXF | שכבה |
|---|---|---|
| קווי גובה קטנים וגדולים | פוליליינים דו-ממדיים בגובהם | C-TOPO-MINR, C-TOPO-MAJR |
| תוויות קווי גובה | טקסט | C-TOPO-TEXT |
| משולשים | פוליליינים | C-TOPO-TINN |
| קווי שבירה וגבול | פוליליינים תלת-ממדיים | C-TOPO-BRKL |
| קצה המשטח | פוליליינים | C-TOPO-BNDY |
| חיצי שיפוע | פוליליינים | C-TOPO-SLOP |
| נקודות מדידה ותוויותיהן | נקודות (עם גובה), טקסט | V-NODE, V-NODE-TEXT |
| קווים לפי קודי קו | פוליליינים תלת-ממדיים | V-NODE-LINE |
| קווי ציר יישור | קווים וקשתות | C-ROAD-CNTR |
| סימוני תחנות ותוויות | פוליליינים, טקסט | C-ROAD-STAN |
| קצוות מסדרון | פוליליינים | C-ROAD-CORR |
| קווי דגימה | פוליליינים | C-ROAD-SCTN |
| משטחי בנייה, קווי פגישה עם הקרקע, קווי שיפוע | פוליליינים | C-GRAD-PADS, C-GRAD-DAYL, C-GRAD-SLOP |
| קווי מאפיין | פוליליינים תלת-ממדיים (קשתות כקטעים בתוך 0.01; ראו [קווי מאפיין](topic:feature-lines)) | C-GRAD-FEAT |

לכל שכבה יש צבע. הרשימה המלאה נמצאת ב-[שכבות התוכנית](topic:plan-layers).

## גודל התוויות

טקסט חייב להיות בעל גודל ביחידות השרטוט. CivilCraft קובע את גודל התוויות לפי קנה המידה שבו כל התוכנית נכנסת לדף Tabloid (רגל) או לדף A3 (מטר), ומציין את קנה המידה בהודעת המצב. אם תדפיסו בקנה מידה אחר בתוכנת ה-CAD, שנו שם את גודל הטקסט.

## מה לא מיוצא

- רצועות גובה (על המסך בלבד).
- תצוגת הפרופיל. פרופילים יוצאים כ-LandXML, לא כשרטוט.
- המשטח עצמו כאובייקט תלת-ממדי. השתמשו ב-LandXML עבור ה-TIN, או הפעילו את {{ui:Triangles}} כדי לקבל את קצוות המשטח כקווים.
- כל מה שכיביתם תחת **תצוגה**.

## DWG

{{ui:DWG/DXF}} כותב את אותם קווים גם כשרטוט DWG. תיבת הדו-שיח שלו שואלת על הפורמט: DXF, או DWG בגרסת 2000, 2004, 2007, 2010, 2013 או 2018. גרסת 2000 נפתחת כמעט בכל תוכנת CAD, ישנה וחדשה; בחרו גרסה חדשה יותר כשמי שמקבל את השרטוט מבקש זאת. הבחירה נשמרת בדפדפן זה.

1. לחצו על {{ui:DWG}} בקבוצה **ייצוא**.
2. בחרו את **פורמט** ולחצו על **הורדת DWG**.
3. הדפדפן מוריד את `<name>.dwg`. שורת המצב מציגה מה נכנס, למשל "יוצא DWG (פורמט 2018): 12 פוליליינים, 40 תוויות ב-9 שכבות".

השרטוט ב-DWG כולל את אותן שכבות, צבעים, קווי גובה (כפוליליינים בגובהם), קווי שבירה תלת-ממדיים, תוויות ונקודות כמו ה-DXF, באותן קואורדינטות. שמות שכבות ש-DWG אינו יכול להכיל משתנים, וההודעה בשורת המצב אומרת זאת. CivilCraft כותב DWG בקוד משלו, כך שדבר אינו יוצא מהמחשב שלכם.

### שכבות מפה ב-DWG

שרטוט DWG אינו יכול להכיל תמונה בתוכו: תוכנות CAD מציגות תמונה שיושבת לצד השרטוט. כשמוצגות שכבות מפה, תיבת הדו-שיח מציעה **שכבות מפה כתמונה לצד השרטוט**. כשהאפשרות מסומנת, ההורדה היא קובץ `.zip` שמכיל את `<name>.dwg`, את `<name>-map.png` (שכבות המפה על כל השרטוט, עד 4,096 פיקסלים לרוחב) ואת `<name>-map.pgw` (קובץ העולם שלו, לתוכנות GIS). השרטוט מציג את התמונה כתמונה בשכבה G-MAP-IMAG, במקומה. פתחו את הקבצים לתיקייה אחת ושמרו אותם יחד.

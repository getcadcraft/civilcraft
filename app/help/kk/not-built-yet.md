CivilCraft әлі ерте нұсқада. Бұл бет ағымдағы нұсқа не істемейтінін тізеді, сондықтан оны іздемеңіз. Мұнда тізілгеннің ешқайсысына күн уәде етілмеген.

## Нүктелер

| Әзірге жасалмаған | Бүгін, орнына |
|---|---|
| Екінші нүкте файлын бірінші файлға қосу | Файлдарды алдымен мәтін редакторында немесе кестеде біріктіріңіз |
| Нүкте мәтін файлын экспорттау | LandXML экспорттаңыз (нүктелер CgPoints ретінде шығады), GIS {{ui:Export}} пайдаланыңыз (P, N, E, Z және D өрістері бар нүктелер), немесе нүктелерді кестеге {{ui:Copy}} жасаңыз |
| Нүкте белгілерінің стильдері, сипаттама кілті бойынша символдар, сызық кодтарынан қисықтар (доғалар), жобалар арасында бөлісетін сипаттама кілті файлы | Белгілерде нөмір, биіктік және сипаттама көрсетіледі, немесе одан азы ([CivilCraft баптаулары](topic:settings)); кілттер жоба файлында сақталады |
| Бірлік түрлендіру | Импорттамас бұрын файлды түрлендіріңіз; **Өлшем бірліктері** тек белгіні өзгертеді |

## Беттер

| Әзірге жасалмаған | Бүгін, орнына |
|---|---|
| Нүктелерден салынған бірнеше бет | Бір жоба — бір бет |
| (ішкі) шекараларды жасыру | **Ең ұзын сыртқы жиек** немесе сыртқы шекараны пайдаланыңыз |
| Салынған бір үзу сызығын таңдау немесе өңдеу | {{key:Mod+Z}}, немесе {{ui:Remove drawn breaklines}} және қайта сызыңыз |
| LandXML-ден оқылған бетті өңдеу (үзу сызықтары, шекара) | {{ui:Rebuild the surface from the points}} |
| Биіктік торынан жасалған бетті өңдеу | Торды басқа таңдаулармен қайта импорттаңыз |
| Координаттар жүйесі өзгергенде LandXML-ден оқылған бетті түрлендіру | Алдымен {{ui:Rebuild the surface from the points}} |
| Белгіленген нүктелік биіктіктер және еңіс мәндері | Оларды күй жолағында оқыңыз, немесе Ландшафт жұмыс аймағындағы **Еңіс талдауы** көмегімен бетті еңіс бойынша бояңыз ([Ландшафтқа арналған тік жоспарлау](topic:landscape-grading#grading-checks)) |

|---|---|

| Екі басқаның арасына PI қосу | Трассаны қайта сызыңыз, немесе PI координаттарын қайта теріңіз |
| Нысандардан, ығысулардан, кеңейтулерден трассалар | PI арқылы сызыңыз |
| Тік қисық үшін K теру | L теріңіз (K көрсетіледі) |
| Шеңберлі және симметриялы емес тік қисықтар | Тек симметриялы парабола қисықтары |
| Бір трассаға бірнеше жобалық профиль | Әр нұсқаға бір трасса |
| Профиль көрінісін масштабтау, профиль астындағы профиль жолақтары | Профиль көрінісі бүкіл трассаға сыяды; оны [жоспар және профиль парақтарында](topic:plan-profile-sheets) басып шығарыңыз |
| DWG немесе LandXML-дегі қималар | PDF-тегі қима парақтары; аудандар мен көлемдердің {{ui:CSV}} |
| Бұрыштағы үлгі сызықтары, немесе жол бойындағы әртүрлі ендер | Бүкіл трасса үшін әр жағында бір ен |

| Екі аймақтың шаблондары арасындағы біртіндеп өзгеріс (өтулер, тарылулар) | Станциядағы шаблонды өзгертіңіз, немесе тарылу ретінде салынған сызыққа нүктеге ен мақсатын беріңіз |
| Жиек бойынша айналу, LandXML-дегі аударым | Қисықтардағы аударым орталық сызық бойынша айналады; жолақты ен мақсатымен ерекшелік сызығына кеңейтіңіз |
| Бүйір беткейлерге арналған мақсаттар (сызыққа немесе бетке дейін), дәліздің өз беттері | Мақсаттар жол жиектері мен иінтіректерді жылжытады ([Дәліздер](topic:corridor)); дәліз жобалық бетке тегістеледі |
| LandXML-де жол жүрісі ретінде экспортталған дәліздер; IFC экспортындағы трассадағы екінші дәліз | Жобалық бет экспортталады |
| Жобалық бетті өзгертетін жер шаблондары, 3D-де немесе қималарда | Олар әр қабаттың аудандары мен көлемдерін береді ([Жер шаблондары](topic:corridor-templates#terrain-templates)) |
| Жылдамдығы, шина сырғанауы, басқару уақыты, басқару тіркемелері немесе кузов клиренсі бар бұрылыс траекториялары; стандартты жобалық көліктер кітапханасы; көлікті сүйрей отырып салынған бұрылыс траекториясы | Өз көлік өлшемдеріңізбен, ерекшелік сызығы немесе трасса бойымен төмен жылдамдықтағы бұрылыс траекториялары ([Көлік бұрылыс траекториялары](topic:swept-paths)) |

## Жер жұмыстары және көлемдер

| Әзірге жасалмаған | Бүгін, орнына |
|---|---|
| Скамейкалар, жобаға тегістелген ашық ерекшелік сызықтары, басқа жерден ерекшелік сызығына тегістеу | Ерекшелік сызығын жабыңыз ([Ерекшелік сызықтары](topic:feature-lines)), немесе оны қолданыстағы жердің үзу сызығы ретінде пайдаланыңыз |
| Ерекшелік сызығының төбесін қосу немесе алып тастау | Сызықты қайта салыңыз, немесе оның сатылы ығысуын жасаңыз |
| Салынған үзу сызықтарындағы доғалар (геодезиялық нүктелер арқылы), ерекшелік сызықтарындағы спиральдар | Доғалары бар ерекшелік сызығын салып, оны қолданыстағы жердің үзу сызығы ретінде пайдаланыңыз |
| Қашықтыққа, биіктікке немесе басқа бетке тегістеу | Қолданыстағы жерге ғана ашық жерге тегістеу |
| Алаң бұрышын қосу немесе алып тастау | Алаңды жойып, қайта салыңыз |
| TIN-ден TIN-ге (призма) көлемдер, торлы ұяшық өлшемін таңдау | Тор әдісі, ұяшық өлшемі сізге таңдалады |
| Ісіну және қысқару, топырақ беті, жол төсемінің қалыңдығы | Есептелген сандарға коэффициенттерді өзіңіз қолданыңыз |
| Еркін тасымалдау және қайта тасымалдау шығындары, басқа трассалар арасында тасымалдау, жоспарда орналастырылған қарыз карьерлері мен қалдық орындары | Тепе-теңдік нүктелері бар масса тасымалдау диаграммасы, жылжытылған көлемдер және орташа тасымалдау қашықтықтары |

Қысымды желілердің қалғаны зертханада: [Су құбырлары](topic:water-mains) | Оларды су тарату бағдарламаларында тексеріңіз; санитарлық есептік ағындар — [Санитарлық есептік ағындар](topic:sanitary-design) |
| Уақыт бойынша кәріз ағындары (гидрографтар, динамикалық бағыттау, сақтау, сорғылар, асып кету) | [Санитарлық есептік ағындар](topic:sanitary-design) есептік парақ пайдаланатын тұрақты шың ағынды береді |
| Кіріс сыйымдылығы, науа таралуы, ұстау бағыттауы, гидрографтар, түйіспе коэффициентінен басқа энергия шығындары | Басқа бағдарламада тексеріңіз; ағындар, өлшемдер және градиент сызықтары — [Жаңбыр суының дренажы](topic:storm-drainage) |
| PDF басып шығарудағы, DWG, DXF немесе LandXML-дегі сулану алаңдары; беттен алынған сулану алаңдары (су бөлгіштер) | Сулану алаңдарын қолмен салыңыз; олар жоба файлында сақталады |
| Құбыр каталогтары, дөңгелек емес құбырлар, тік қорапшалар немесе цилиндрлерден басқа құрылымдар (конустар, баспалдақтар, сатылар), кітапхана ішіндегі дренаж санаты | Параметрлер бойынша құрылым түрлері ([Құбыр желісі](topic:pipe-network)); диаметрі бар құбырлар |
| Профиль көрінісіндегі құбырлар, қисық құбырлар | Оң панельдегі түбін және жабынын оқыңыз |

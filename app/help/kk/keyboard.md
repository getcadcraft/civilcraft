Мәтін жазатын өрісте болмасаңыз, бір әріпті пернелер жұмыс істейді. {{key:Mod}} бар жылдам пернелер Mac-та Command, басқа жүйелерде Ctrl пернесін пайдаланады. Сондай-ақ қараңыз: [Браузердегі пернелер](common:keys).

## Файлдар және өңдеу

| Перне | Әрекет |
|---|---|
| {{key:Mod+O}} | Нүкте файлын, LandXML немесе жобаны ашу |
| {{key:Mod+S}} | Жобаны сақтау (`.civilcraft.json` файлын жүктейді) |
| {{key:Mod+P}} | Жоспарды PDF-ке шығару (браузердің баспасы емес, шығару диалогын ашады) |
| {{key:Mod+Z}} | Болдырмау |
| {{key:Mod+Y}} | Қайтару |
| {{key:Delete}} | Таңдалған геодезиялық нүктелерді, осьті, алаңшаны, құрылымды, құбырды немесе PVI-ді жою |
| {{key:Mod+C}} | Таңдалған геодезиялық нүктелерді көшіру (электрондық кестеге нүкте жолдары ретінде де) |
| {{key:Mod+X}} | Таңдалған геодезиялық нүктелерді кесу |
| {{key:Mod+V}} | Нүктелерді қою: олар көрсеткішті ілестіреді, орналасатын жерін басыңыз |
| {{key:Mod+Shift+V}} | Орнында қою: нүктелердің өз координаталарында |
| {{key:Mod+D}} | Таңдалған нүктелерді көшіру: көшірме көрсеткішті ілестіреді |
| {{key:Mod+A}} | Барлық геодезиялық нүктелерді таңдау |
| {{key:Esc}} | Ештеңені таңдамау (және қоюды болдырмау) |

{{key:Mod+S}}, {{key:Mod+O}} және {{key:Mod+P}} жазу өрісінде теріп жатқанда да жұмыс істейді. Мәтін өрісінде {{key:Mod+Z}} және {{key:Mod+Y}} әдеттегідей теруіңізді болдырмайды; {{key:Mod+C}}, {{key:Mod+X}}, {{key:Mod+V}} және {{key:Mod+A}} да солай: өрісте олар мәтінді көшіреді, кеседі, қояды және таңдайды. Бет бойынша мәтін таңдалған болса (панельде), {{key:Mod+C}} сол мәтінді көшіреді. {{key:Mod+Shift+Z}} CivilCraft-та ештеңе істемейді: {{key:Mod+Y}} немесе {{ui:Қайтару}} түймесін пайдаланыңыз.

:::mac
Mac пернетақтасындағы **delete** деп таңбаланған перне браузер үшін {{key:Backspace}} болып табылады. Таңдауды жою үшін {{key:Delete}} басыңыз (Fn және delete), немесе құрал тақтасындағы {{ui:Көбірек}} мәзірінен {{ui:Жою}} таңдаңыз.
:::

| {{key:I}} | {{ui:PVI қосу}} қосулы немесе өшірулі (бейіндік көрініс жабық болса, оны ашады) |

Белсенді құралдың пернесін қайта басу {{ui:Таңдау}} құралына қайтарады. {{key:Shift}} арқылы берілген әріптер ештеңе істемейді.

## Сызу кезінде

| Перне | Әрекет |
|---|---|
| {{key:Enter}} | Ось, алаңша, құбыр желісі, бұзу сызығы немесе шекараны аяқтау |
| {{key:Backspace}} | Соңғы басылған нүктені жою |
| {{key:C}} | Сипаттамалық сызық: доғаларды қосу немесе өшіру (төбеден кейін қисықтағы нүктені, содан кейін оның соңын басыңыз) |
| {{key:Esc}} | Сызуды (немесе қоюды) болдырмау; қайта басқанда (немесе ештеңе сызылмаған болса) {{ui:Таңдау}} құралына қайтып, таңдауды тазалау |

## Жоспар көрінісі

| Перне немесе әрекет | Нәтиже |
|---|---|
| Дөңгелек | Көрсеткіш жанында масштабтау ұлғайту немесе кішірейту |
| Бос кеңістікте сүйреу | Жылжыту (кез келген құралда; қысқа басу әлі басады; {{key:Shift}} басулы тұрса, таңдау жәшігін салады) |
| Орта батырманы сүйреу | Жылжыту |
| Оң батырманы сүйреу | Жылжыту (мәзір ашылмайды) |
| {{key:Space}} және сүйреу | Жылжыту |
| Басу | Таңдау ({{ui:Таңдау}} арқылы), немесе нүкте орналастыру (сызу құралымен) |
| {{key:Shift}} және басу | Геодезиялық нүктені таңдауға қосу немесе одан алу |
| {{key:Shift}} және сүйреу | Жәшік салу: ішіндегі геодезиялық нүктелер таңдауға қосылады. Айналасын сүйреп [арқан таңдауы](topic:lasso-selection) жасаңыз |
| Арқан салып жатқанда {{key:Space}} | Терезе, содан кейін қиылысу, содан кейін қоршау |
| Қою кезінде басу | Қойылған нүктелерді сол жерге орналастыру ({{key:Enter}} оларды өз координаталарына қояды) |
| Тұтқаны сүйреу | PI, алаң бұрышы немесе құрылымды жылжыту (бір болдырмау қадамы) |
| {{key:Up}} {{key:Down}} {{key:Left}} {{key:Right}} | Жоспар фокуста болғанда жылжыту (алдымен оны басыңыз) |
| {{key:Plus}} және {{key:Minus}} | Жоспар фокуста болғанда ортасында ұлғайту және кішірейту |

{{key:Plus}} сияқты = перне де ұлғайтады, сондықтан Shift керек емес.

## Бейіндік көрініс

| Әрекет | Нәтиже |
|---|---|
| {{ui:PVI қосу}} қосулы кезде басу | Сол жерге PVI қосады |
| PVI-ді басу | Оны таңдайды |
| PVI-ді сүйреу | Жылжытады (бір болдырмау қадамы) |
| {{key:Delete}} немесе {{key:Backspace}} | Таңдалған PVI-ді жояды ({{key:Backspace}} тек бейіндік көрініс фокуста болғанда) |

Бейіндік көрініс масштабталмайды және жылжымайды.

## Экран және анықтама

| Перне | Әрекет |
|---|---|
| {{key:F1}} | Осы анықтаманы ашу немесе жабу (бүйірлік панель); қолданба жолағындағы {{ui:Анықтама}} да осылай істейді |
| {{key:Esc}} | Анықтама панелі ашық болғанда жабу |
| {{key:Ctrl+Shift+F}} | Экран режимдерін айналдыру: толық экран, сызықтары жасырылған толық экран, қалыпты |
| {{key:Esc}} | Толық экраннан шығу (браузердің өз пернесі) |

{{key:F1}} CivilCraft-қа жетпей тұрып браузерге жетеді, сондықтан ол кез келген құралда жұмыс істейді. Көптеген Mac пернетақталарында fn пернесін F1-мен бірге басыңыз, немесе {{ui:Анықтама}} түймесін басыңыз. {{key:Ctrl+Shift+F}} барлық платформада, соның ішінде Mac-та да Control пернесін пайдаланады. Анықтаманы қалай іздеу керектігі үшін қараңыз: [Анықтаманы пайдалану](common:help).

## Тінтуір, трекпад және сенсор

:::mouse
- Дөңгелек көрсеткіш жанында масштабтайды. Еркін айналатын дөңгелегі бар тінтуір тез масштабтайды: қысқа бұрылыстар жасаңыз.
- Бос кеңістікте кез келген сүйреумен, орта батырмамен, оң батырмамен немесе {{key:Space}} және сүйреумен жылжыңыз.
:::

:::mac
Mac трекпадында:

- Екі саусақпен сырғыту жылжытпайды, **масштабтайды**. Қысу да масштабтайды.
- Жылжыту үшін бір саусақпен бос кеңістікті басып сүйреңіз, немесе {{key:Space}} ұстап сүйреңіз.
- Екі саусақпен басу (оң басу) мәзір ашпайды және өзінен ештеңе істемейді.
:::

:::touch
Сенсорлық экранда:

- Алғашқы жанасу түймелерді және мәзір жолдарын саусаққа ыңғайлы етеді.
- Таңдау немесе нүкте қою үшін түртіңіз; бос кеңістікте бір саусақпен сүйреу жылжытады. Түрту аздап ауытқуы мүмкін: саусақ шамамен 10 пиксель жылжығанда ғана жылжыту басталады.
- Екі саусақпен қысу масштабтайды, бірге жылжу жылжытады.
- Тұтқаны немесе PVI-ді бір саусақпен сүйреңіз. Тұтқалардың айналасында саусақ ені бойынша орын бар.
- Осьті, алаңшаны, бұзу сызығын, шекараны, құбыр желісін, сипаттамалық сызықты немесе парцельді сызған кезде жоспардың үстінде жолақ {{ui:Аяқтау}} ({{key:Enter}}), {{ui:Нүктені болдырмау}} ({{key:Backspace}}) және {{ui:Бас тарту}} ({{key:Esc}}) ұсынады. Ұзақ басу (жылжымай жарты секунд) да аяқтайды.
- {{ui:Таңдау}} құралында геодезиялық нүктені ұзақ басу оны {{key:Shift}} + басу сияқты таңдауға қосады немесе одан алады.
- 3D көрінісінде бір саусақ айналдырады, екі саусақ қысып жылжытады, ал түрту таңдайды.
- Сенсорда көрсеткіш жоқ, сондықтан күй жолағының көрсеткіштері тек саусақ басып тұрғанда жаңарады.
:::

## Браузердің жеңетін пернелері

Кейбір пернелер браузерге тиесілі, олар CivilCraft-қа ешқашан жетпейді, мысалы {{key:Mod+W}} (қойындыны жабу), {{key:Mod+T}} (жаңа қойынды), {{key:Mod+N}} (жаңа терезе) және {{key:F11}} (Windows және Linux браузерлеріндегі толық экран). CivilCraft оларды пайдаланбайды. Егер жылдам перне браузерде бірдеңе ашса, бетте фокус болуы үшін жоспарды бір рет басып, қайта көріңіз.

## Жылжыту қай жерде

CivilCraft-та Жылжыту командасы жоқ: {{ui:Таңдау}} таңдап, нүктені немесе төбені сүйреңіз, немесе координаталарын {{ui:Қасиеттерде}} өңдеңіз. Қараңыз: [Нүктелерді өңдеу](topic:edit-points).

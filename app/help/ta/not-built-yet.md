CivilCraft ஆரம்ப நிலையில் உள்ளது. இந்தப் பக்கம் தற்போதைய உருவாக்கம் செய்யாதவற்றைப் பட்டியலிடுகிறது, எனவே நீ அவற்றைத் தேடாமல் இருக்கலாம். இங்குள்ள எதற்கும் தேதி உறுதியளிக்கப்படவில்லை.

|---|---|
| நடுப்பட்டைகள், தடுப்புகள், வார்ப்புருக்களைச் சுழற்றும் வளைவுச் சாய்வு | வார்ப்புருக்களாக வரை ([வழித்தட வார்ப்புருக்கள்](topic:corridor-templates)); நிலையத்தின்படி வார்ப்புருக்கள் இன்னும் வளைவுச் சாய்வை எடுப்பதில்லை |
| இரண்டு பகுதிகளின் வார்ப்புருக்களுக்கு இடையே படிப்படியான மாற்றம் (மாற்றங்கள், குறுகல்கள்) | நிலையத்தில் வார்ப்புருவை மாற்று, அல்லது குறுகலாக வரையப்பட்ட கோட்டுக்கு ஒரு புள்ளிக்கு அகல இலக்கு கொடு |
| ஓர் ஓரத்தைப் பற்றிய சுழற்சி, LandXML இல் வளைவுச் சாய்வு | வட்ட வளைவுகளில் வளைவுச் சாய்வு மைய அச்சைச் சுற்றிச் சுழலும்; அம்சக் கோட்டுக்கு அகல இலக்குடன் ஒரு பாதையை அகலப்படுத்து |
| பக்கச் சரிவுகளுக்கான இலக்குகள் (ஒரு கோடு அல்லது மேற்பரப்புக்கு பகல் கோடு), வழித்தடங்களுக்குத் தனி மேற்பரப்புகள் | இலக்குகள் நடைபாதை மற்றும் தோள்பட்டை விளிம்புகளை நகர்த்தும் ([வழித்தடங்கள்](topic:corridor)); வழித்தடம் முன்மொழியப்பட்ட மேற்பரப்பில் சமன்படுத்தப்படும் |
| சந்திப்பில் சமன்படுத்தப்பட்ட ஓரத் திருப்பங்கள், திருப்பப் பாதைகள் மற்றும் தீவுகள்; சாய்வில் பக்கச் சாலையின் முனையை பிரதான சாலையின் விளிம்புக்கு வெட்டுவது; திட்டத்தில் சாலையுடன் இணைந்த ஒரு பாதை, அதன் நீளத்திலும் பரப்பளவிலும் | ஒன்றிணையும் சாலைகள் சதுரமாக இணைக்கப்படும், பிரதான சாலையின் விளிம்பு திறக்கப்பட்டு பக்கச் சாலை அதற்கு மென்மையாக்கப்படும் ([சாலைகள் சந்திக்கும் இடம்](topic:corridor#where-roads-meet-roads-pads-and-paths)); ஒரு பாதை முன்மொழியப்பட்ட மேற்பரப்பிலும் 3D யிலும் சாலையின் விளிம்பில் நிற்கும் |
| LandXML சாலைப் பாதைகளாக ஏற்றுமதி செய்யப்படும் வழித்தடங்கள்; IFC ஏற்றுமதியில் ஓர் அச்சில் இரண்டாவது வழித்தடம் | முன்மொழியப்பட்ட மேற்பரப்பு ஏற்றுமதி செய்யப்படும் |
| முன்மொழியப்பட்ட மேற்பரப்பை மாற்றும் நிலப்பரப்பு வார்ப்புருக்கள், 3D யிலோ குறுக்குவெட்டுகளிலோ | அவை ஒவ்வொரு அடுக்கின் பரப்பளவுகளையும் கன அளவுகளையும் தரும் ([நிலப்பரப்பு வார்ப்புருக்கள்](topic:corridor-templates#terrain-templates)) |
| வேகம், டயர் நழுவல், திருப்ப நேரம், திருப்பும் டிரெய்லர்கள் அல்லது உடல் இடைவெளியுடன் ஸ்வீப்ட் பாதைகள்; நிலையான வடிவமைப்பு வாகனங்களின் நூலகம்; வாகனத்தை இழுப்பதன் மூலம் வரையப்படும் ஸ்வீப்ட் பாதை | ஓர் அம்சக் கோடு அல்லது அச்சின் வழியே குறைந்த வேக ஸ்வீப்ட் பாதைகள், உன் சொந்த வாகன அளவுகளுடன் ([வாகன ஸ்வீப்ட் பாதைகள்](topic:swept-paths)) |

## குழாய் வலையமைப்புகள்

| இன்னும் உருவாக்கப்படவில்லை | அதற்குப் பதிலாக, இன்று |
|---|---|
| ஒரு திட்டத்திற்கு ஒன்றுக்கு மேற்பட்ட வலையமைப்புகள் | புயல் நீர் மற்றும் கழிவுநீருக்குத் தனித் திட்டங்கள் |
| நீர்க்குழாய்கள்: நீரின் தரம் மற்றும் வயது, விதி அடிப்படையிலான கட்டுப்பாடுகள், பிற வால்வு வகைகள் (ஓட்டக் கட்டுப்பாடு, த்ரோட்டில், தக்கவைப்பு), சக்தியால் கொடுக்கப்படும் பம்புகள், அழுத்தத்தைச் சார்ந்த தேவை, Darcy–Weisbach விருப்பம், சுவர் தடிமன்கள் மற்றும் அழுத்த வகுப்புகளுடன் குழாய் பட்டியல். அழுத்த வலையமைப்புகளின் மீதமுள்ளவை ஆய்வகத்தில் உள்ளன: [நீர்க்குழாய்கள்](topic:water-mains) | அவற்றை நீர் விநியோக மென்பொருளில் சரிபார்; கழிவுநீர் வடிவமைப்புப் பாய்வுகள் [கழிவுநீர் வடிவமைப்புப் பாய்வுகளில்](topic:sanitary-design) உள்ளன |
| காலப்போக்கில் கழிவுநீர்ப் பாய்வுகள் (ஹைட்ரோகிராஃப்கள், இயக்கவியல் வழித்தடம், சேமிப்பு, பம்புகள், நிரம்பி வழிதல்) | [கழிவுநீர் வடிவமைப்புப் பாய்வுகள்](topic:sanitary-design) வடிவமைப்புத் தாள் பயன்படுத்தும் நிலையான உச்சப் பாய்வைத் தரும் |
| உள்வாய் திறன், வடிகால் ஓரப் பரவல், தேக்க வழித்தடம், ஹைட்ரோகிராஃப்கள், ஒரு சந்திப்புக் குணகத்தைத் தவிர்த்த ஆற்றல் இழப்புகள் | மற்ற மென்பொருளில் சரிபார்; பாய்வுகள், அளவுகள் மற்றும் நிலைக் கோடுகள் [புயல் நீர் வடிகால்](topic:storm-drainage) இல் உள்ளன |
| PDF வரைபடம், DWG, DXF அல்லது LandXML இல் நீர்ப்பிடிப்புகள்; மேற்பரப்பிலிருந்து நீர்ப்பிடிப்புகள் (நீர்நிலைப் பிரிப்புகள்) | நீர்ப்பிடிப்புகளைக் கையால் வரை; அவை திட்டக் கோப்பில் சேமிக்கப்படும் |
| குழாய்ப் பட்டியல்கள், வட்டமற்ற குழாய்கள், நேர்குத்துப் பெட்டிகளோ உருளைகளோ அல்லாத கட்டமைப்புகள் (கூம்புகள், படிகள், பெஞ்சிங்), நூலகத்தில் ஒரு வடிகால் வகை | அளவுருக்களிலிருந்து கட்டமைப்பு வகைகள் ([குழாய் வலையமைப்பு](topic:pipe-network)); விட்டத்துடன் கூடிய குழாய்கள் |
| நீள்வெட்டுக் காட்சியில் குழாய்கள், வளைந்த குழாய்கள் | வலது பலகத்தில் உட்புற மட்டங்களையும் மூடு ஆழத்தையும் படி |

## 3D பார்வை

| இன்னும் உருவாக்கப்படவில்லை | அதற்குப் பதிலாக, இன்று |
|---|---|
| 3D பார்வையில் வரைவது அல்லது திருத்துவது | திட்டத்தில் வரைந்து திருத்து; 3D பார்வை ஒவ்வொரு திருத்தத்தையும் பின்தொடரும் |
| 3D இல் கிளிக் செய்து வழித்தட அம்சக் கோடுகள் அல்லது GIS அம்சங்களைத் தேர்ந்தெடுப்பது | அவற்றைத் திட்டத்தில் கிளிக் செய் |
| பெரிதுபடுத்தப்பட்ட பார்வையையோ feet இலோ ஏற்றுமதி செய்வது | ஏற்றுமதிகள் மீட்டரில் உண்மை அளவில் இருக்கும்; [3D இல் தளத்தை ஏற்றுமதி செய்](topic:export-3d) பார்க்கவும் |
| GLB அல்லது OBJ ஏற்றுமதிகளில் லேபிள்கள், 3D யில் லேபிள் அளவுகளும் பாணிகளும் | லேபிள்கள் 3D பார்வையில் மட்டும், ஒரே அளவில் காட்டப்படும்; [தளத்தை 3D இல் பார்](topic:site-3d) பார்க்கவும் |
| புகைப்படங்களிலிருந்து அமைப்புகள், ஓட்டத்தை வீடியோவாகப் பதிவு செய்வது, தளத்துக்கு அப்பாலிருந்து நிழல்கள், 3D பார்வையில் காட்டப்படும் சூரிய ஒளி நேரம் | மேற்பரப்புகளின் மேல் விரிக்கப்படும் வரைபட அடுக்குகள்; ஒரு நேரத்தில் ஓட்டமும் சூரியனின் நிலையும்; ஒரு நாள் அல்லது பருவத்திற்கு [சூரிய ஒளி நேரம்](topic:sun-hours) திட்டத்தில் |

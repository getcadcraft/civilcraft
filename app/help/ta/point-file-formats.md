புள்ளிக் கோப்பு என்பது எளிய உரைக் கோப்பு, ஒரு வரிக்கு ஒரு புள்ளி. CivilCraft அதை உங்கள் உலாவியிலேயே படிக்கும்; எதுவும் பதிவேற்றப்படாது.

## நெடுவரிசை வரிசைகள்

எழுத்துகள் நெடுவரிசைகளை இடமிருந்து வலமாகப் பெயரிடுகின்றன: **P** புள்ளி எண் அல்லது பெயர், **N** வடக்கு, **E** கிழக்கு, **Z** உயரம், **D** விளக்கம்.

| வரிசை | நெடுவரிசைகள் | எடுத்துக்காட்டு வரி |
|---|---|---|
| PNEZD | point, northing, easting, elevation, description | `101,2080000.00,6150000.00,250.00,GRD` |
| PENZD | point, easting, northing, elevation, description | `101,6150000.00,2080000.00,250.00,GRD` |
| PNEZ | point, northing, easting, elevation | `101,2080000.00,6150000.00,250.00` |
| PENZ | point, easting, northing, elevation | `101,6150000.00,2080000.00,250.00` |
| NEZD | northing, easting, elevation, description | `2080000.00,6150000.00,250.00,GRD` |
| ENZD | easting, northing, elevation, description | `6150000.00,2080000.00,250.00,GRD` |
| NEZ | northing, easting, elevation | `2080000.00 6150000.00 250.00` |
| ENZ | easting, northing, elevation | `6150000.00 2080000.00 250.00` |

P இல்லாத வரிசைகளில் புள்ளிகள் கோப்பு வரிசைப்படி 1, 2, 3 … என எண்ணப்படும். X என்பது கிழக்கு, Y என்பது வடக்கு.

## பிரிப்பான்கள்

CivilCraft முதல் 20 வரிகளைப் பார்த்து, அவற்றில் குறைந்தது 60% இல் தோன்றும் முதல் ஒன்றைத் தேர்ந்தெடுக்கிறது: கமா, டேப், அரைப்புள்ளி. இல்லையெனில், இடைவெளிகளின் தொடர்களில் பிரிக்கிறது.

- கமா, டேப் மற்றும் அரைப்புள்ளி கோப்புகளில், இரட்டை மேற்கோள்களுக்குள் உள்ள புலம் பிரிப்பானைக் கொண்டிருக்கலாம் (`"FL, NORTH"`), மேலும் மேற்கோள்களுக்குள் `""` ஒரு மேற்கோள் குறியாகும்.
- இடைவெளி பிரிக்கப்பட்ட கோப்புகளில், வரியின் இறுதியில் உள்ள விளக்கத்தில் இடைவெளிகள் இருக்கலாம்: கடைசி ஆயத்தொலை நெடுவரிசைக்குப் பிறகு உள்ள அனைத்தும் விளக்கம்.
- `#`, `;` அல்லது `//` இல் தொடங்கும் வரிகளும், வெற்று வரிகளும் தவிர்க்கப்படும்.
- கோப்பின் தொடக்கத்தில் உள்ள பைட் வரிசைக் குறி (BOM) புறக்கணிக்கப்படும்.

## தலைப்பு வரி

முதல் வரியில் அதன் புலங்களில் இரண்டுக்கும் குறைவாக எண்கள் இருந்தால் அது தலைப்பாகக் கருதப்படும். தலைப்பின் ஒவ்வொரு புலமும் CivilCraft அடையாளம் காணும் பெயராக இருந்தால், நெடுவரிசை வரிசை அதிலிருந்து எடுக்கப்படும் ("தலைப்பு வரியிலிருந்து"). பெயர்கள் எழுத்துவகை, இடைவெளிகள், புள்ளிகள், அடிக்கோடுகள், கோடுகள் மற்றும் அடைப்புக்குறிகளைப் பொருட்படுத்தாமல் பொருத்தப்படும்:

| நெடுவரிசை | அடையாளம் காணப்படும் பெயர்கள் |
|---|---|
| P | pt, pnt, point, point no, point number, number, no, id, name, pt#, point#, # |
| N | n, north, northing, y, y coord, lat, latitude |
| E | e, east, easting, x, x coord, lon, long, longitude |
| Z | z, elev, elevation, el, height, h, z coord, rl |
| D | d, desc, description, code, raw description, full description, note, notes, feature |

தலைப்பில் அடையாளம் காணப்படாத பெயர் இருந்தால், அல்லது பெயர்கள் மேலே உள்ள எட்டு வரிசைகளில் ஒன்றை உருவாக்கவில்லை என்றால், தலைப்பு தவிர்க்கப்பட்டு வரிசை நெடுவரிசை எண்ணிக்கையிலிருந்து ஊகிக்கப்படும்.

:::warning
தலைப்பு அட்சரேகை நெடுவரிசையையும் (`lat`, `latitude`) தீர்க்கரேகை நெடுவரிசையையும் (`lon`, `long`, `longitude`) குறிப்பிட்டால், அது வடக்கு மற்றும் கிழக்கு அல்ல, டிகிரிகளாகப் படிக்கப்படும். {{ui:Import}} இல் புள்ளிகள் திட்டத்தின் ஆயத்தொலை அமைப்பு வழியாக மாற்றப்படும்; அது இல்லாத திட்டம் முதலில் அதைத் தேர்ந்தெடுக்கக் கேட்கும். ±90° அட்சரேகைக்கு அல்லது ±180° தீர்க்கரேகைக்கு வெளியே உள்ள வரிசைகள் மறுக்கப்படும். பார்க்க [GIS தரவை இறக்குமதி செய்](topic:gis-import#point-files-with-latitude-and-longitude).
:::

## எண்ணிக்கையிலிருந்து ஊகித்தல்

பயன்படுத்தக்கூடிய தலைப்பு இல்லாமல், மற்றும் **நெடுவரிசைகள்** {{ui:Detect}} இல் இருந்தால்:

- 5 அல்லது அதற்கு மேற்பட்ட நெடுவரிசைகள்: PNEZD.
- 4 நெடுவரிசைகள்: முதல் நெடுவரிசை ஒவ்வொரு மாதிரி வரியிலும் முழு எண்ணாகவும், நான்காவது எண்ணாகவும் இருந்தால் PNEZ; இல்லையெனில் NEZD.
- 3 நெடுவரிசைகள்: NEZ.

PNEZD மற்றும் PENZD எண்களிலிருந்து வேறுபடுத்த முடியாது. ஊகம் [CivilCraft அமைப்புகளில்](topic:settings) உள்ள **புள்ளி வரிசைகளை** பின்பற்றுகிறது: தொடக்கத்தில் P, N, E, Z, D, அல்லது P, E, N, Z, D (அப்போது நான்கு நெடுவரிசைகள் PENZ ஆகவும், மூன்று ENZ ஆகவும் படிக்கப்படும்). உரையாடல் "நெடுவரிசை எண்ணிக்கையிலிருந்து ஊகிக்கப்பட்டது — வடக்கும் கிழக்கும் மாற்றப்படவில்லை என்பதைச் சரிபார்க்கவும்" என்று கூறும். முன்னோட்டம் தவறாகத் தெரிந்தால் **நெடுவரிசைகளில்** சரியான வரிசையைத் தேர்ந்தெடுக்கவும்.

## வரிசைகள் எவ்வாறு சரிபார்க்கப்படுகின்றன

- ஒரு வரி விளக்கத்தை விட்டுவிடலாம்.
- வடக்கும் கிழக்கும் எண்களாக இருக்க வேண்டும். உயரம் காலியாக இருக்கலாம் (புள்ளி வைக்கப்படும், ஆனால் மேற்பரப்பில் பயன்படுத்தப்படாது).
- புள்ளி எண் எந்த உரையாகவும் இருக்கலாம் (`CP1` போன்ற எழுத்துகளும்), ஆனால் காலியாக இருக்கக்கூடாது.
- ஒரு புள்ளி எண் மீண்டும் வந்தால், முதல் வரி வைக்கப்படும், மற்றவை படிக்கப்படாதவை எனப் பட்டியலிடப்படும்.
- விளக்கங்கள் 200 எழுத்துகள் வரை வைக்கப்படும்; கட்டுப்பாட்டு எழுத்துகள் இடைவெளிகளாக மாறும்.
- உரையாடலுக்கு 200 படிக்கப்படாத வரிகள் வரை வைக்கப்படும் (25 காட்டப்படும்), அனைத்தும் எண்ணப்படும்.

## புள்ளிக் குழுக்கள்

புள்ளியின் குழு அதன் விளக்கத்தின் முதல் சொல், பெரிய எழுத்துகளில். "GRD", "grd shot" மற்றும் "Grd" அனைத்தும் குழு GRD. விளக்கம் இல்லாத புள்ளி "(விளக்கம் இல்லை)" இல் இருக்கும். பார்க்க [கணக்கெடுப்புப் புள்ளிகளை இறக்குமதி செய்](topic:import-points).

## புள்ளிகளை எழுதுதல்

CivilCraft இன்னும் புள்ளி உரைக் கோப்பை ஏற்றுமதி செய்யவில்லை. புள்ளிகள் LandXML இல் (CgPoints ஆக), திட்டக் கோப்பில், மற்றும் GIS {{ui:Export}} மூலம் P, N, E, Z மற்றும் D புலங்களுடன் shapefile, GeoPackage அல்லது GeoJSON ஆக வெளிவரும் ([கட்டப்பட்ட தரவை GIS க்கு ஏற்றுமதி செய்](topic:gis-export)). பார்க்க [இன்னும் உருவாக்கப்படவில்லை](topic:not-built-yet).

ஒரு சாலை அச்சைத் தேர்ந்தெடுத்து, அதன் **பண்புகள்** பகுதியில் **குறிக்கம்பு அறிக்கை** என்பதைச் சொடுக்கு.

## நிலையங்களிலும் பக்கவிலகல்களிலும் குறிக்கம்புகள்

1. **இருந்து** மற்றும் **வரை**: குறிக்க வேண்டிய நிலையங்கள் (1+50 அல்லது 150).
2. **ஒவ்வொன்றும்**: இடைவெளி. குறிக்கம்புகள் அதன் ஒவ்வொரு மடங்கிலும், இரு முனைகளிலும், (பெட்டி குறியிடப்பட்டிருந்தால்) சாலை அச்சின் வளைவுகள் தொடங்கும் மற்றும் முடியும் இடங்களிலும் நடப்படும்.
3. **பக்கவிலகல்கள்**: நிலையம் நோக்கிப் பார்க்கும்போது சாலை அச்சின் இடது மற்றும் வலது: `12 L, 0, 12 R`, `L12 CL R12` அல்லது `-12, 0, 12` (இடது என்பது கழித்தல்). ஒரு வழித்தடம் உள்ள சாலை அச்சு, சாலைப் பரப்பு மற்றும் தோள்பட்டைகளின் ஓரங்களிலிருந்து தொடங்கும்.
4. **இதிலிருந்து எண்ணிடு** மற்றும் **முன்னொட்டுடன்** குறிக்கம்புகளுக்குப் பெயரிடும்: 1, 2, 3, அல்லது S101, S102.

## சாலை அச்சுக்கு அருகிலுள்ள அளவைப் புள்ளிகள்

**சாலை அச்சுக்கு அருகிலுள்ள அளவைப் புள்ளிகளை** தேர்ந்தெடுத்து, எவ்வளவு அருகில் என்பதையும் தேர்ந்தெடு. அந்தத் தூரத்துக்குள் உள்ள ஒவ்வொரு புள்ளிக்கும் அதன் நிலையம் மற்றும் பக்கவிலகல், அங்குள்ள வடிவமைப்பு, மற்றும் அதன் சொந்த உயரம் தரையாகக் கொடுக்கப்படும்: குறிக்கம்பு நடப்பட்ட அல்லது கட்டப்பட்ட நிலையில் அளந்த புள்ளிகளின் சரிபார்ப்பு இது.

## அறிக்கை என்ன காட்டுகிறது

| நெடுவரிசை | அது என்ன |
|---|---|
| புள்ளி | குறிக்கம்பின் பெயர், அல்லது அளவைப் புள்ளியின் எண் |
| நிலையம், பக்கவிலகல் | சாலை அச்சில் அதன் இடம்: L இடது, R வலது |
| வடக்கு, கிழக்கு | அதன் ஆயத்தொலைகள் |
| வடிவமைப்பு உயரம் | அங்குள்ள சமன்படுத்தப்பட்ட வழித்தடத்தின் மேற்பரப்பு (பகல் கோடு முதல் பகல் கோடு வரை); இல்லையெனில் மையக் கோட்டிலுள்ள வடிவமைப்பு நீள்வெட்டு |
| தரை உயரம் | அங்குள்ள தற்போதைய மேற்பரப்பு, அல்லது அளவைப் புள்ளியின் சொந்த உயரம் |
| வெட்டு/நிரப்பு | தரை வடிவமைப்புக்கு மேலே இருந்தால் C (வெட்டி இறக்கு), கீழே இருந்தால் F (நிரப்பி உயர்த்து); நூற்றில் ஒன்று வரை |

வடிவமைப்பு உயரம் இல்லாத குறிக்கம்புக்கு (வழித்தடத்துக்கு வெளியே, அல்லது மையக் கோட்டிலிருந்து விலகி வடிவமைப்பு இல்லாத சாலை அச்சில்) வெட்டு அல்லது நிரப்பு இருக்காது; உரையாடல் பெட்டி எத்தனை என்பதைக் காட்டும்.

## சேமி

- **CSV**: ஒரு தலைப்பு வரி, பின்னர் மேலே உள்ள நெடுவரிசைகள், மற்றும் வெட்டு அல்லது நிரப்பை குறியுடன் கூடிய எண்ணாக (தரை கழித்தல் வடிவமைப்பு), விரிதாள்களுக்கும் தரவு சேகரிப்பான்களுக்கும்.
- **PDF**: நீங்கள் தேர்ந்தெடுக்கும் தாளில் அட்டவணைப் பக்கங்கள், ஒரு வரிசைக்கு ஒரு குறிக்கம்பு, வெட்டுகள் ஆரஞ்சு நிறத்திலும் நிரப்புகள் பச்சை நிறத்திலும், மற்ற தாள்களின் தலைப்புப் பட்டையுடன்.

:::note
குறிக்கம்புகள் திட்டத்தின் வடிவமைப்பிலிருந்து கணக்கிடப்படுகின்றன. எதையும் கட்டுவதற்கு முன் அவற்றை அங்கீகரிக்கப்பட்ட திட்டங்களுடன் ஒப்பிட்டுச் சரிபார்.

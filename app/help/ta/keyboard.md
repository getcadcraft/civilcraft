தட்டச்சு செய்யாத போது ஒற்றை எழுத்து விசைகள் வேலை செய்யும். {{key:Mod}} உடன் உள்ள குறுக்குவழிகள் Mac இல் Command ஐப் பயன்படுத்தும், மற்ற இடங்களில் Ctrl ஐ. மேலும் பார்க்கவும் [உலாவியில் விசைகள்](common:keys).

## கோப்புகளும் திருத்தமும்

| விசை | செயல் |
|---|---|
| {{key:Mod+O}} | ஒரு புள்ளிக் கோப்பு, LandXML அல்லது திட்டத்தைத் திற |
| {{key:Mod+S}} | திட்டத்தைச் சேமி (`.civilcraft.json` கோப்பைப் பதிவிறக்கும்) |
| {{key:Mod+P}} | வரைபடத்தை PDF ஆக வரைந்து அச்சிடு (உலாவியின் அச்சுப்பொறி அல்ல, வரைந்து அச்சிடு உரையாடல் பெட்டியைத் திறக்கும்) |
| {{key:Mod+Z}} | செயல்தவிர் |
| {{key:Mod+Y}} | மீண்டும்செய் |
| {{key:Delete}} | தேர்ந்தெடுத்த அளவைப் புள்ளிகள், சீரமைப்பு, மேடை, அமைப்பு, குழாய் அல்லது PVI ஐ நீக்கு |
| {{key:Mod+C}} | தேர்ந்தெடுத்த அளவைப் புள்ளிகளை நகலெடு (விரிதாளுக்கான புள்ளி வரிசைகளாகவும்) |
| {{key:Mod+X}} | தேர்ந்தெடுத்த அளவைப் புள்ளிகளை வெட்டு |
| {{key:Mod+V}} | புள்ளிகளை ஒட்டு: அவை சுட்டியைப் பின்தொடரும், அவை செல்ல வேண்டிய இடத்தில் சொடுக்கவும் |
| {{key:Mod+Shift+V}} | அதே இடத்தில் ஒட்டு: புள்ளிகளின் சொந்த ஆயங்களில் |
| {{key:Mod+D}} | தேர்ந்தெடுத்த புள்ளிகளை நகலாக்கு: ஒரு நகல் சுட்டியைப் பின்தொடரும் |
| {{key:Mod+A}} | ஒவ்வொரு அளவைப் புள்ளியையும் தேர்ந்தெடு |
| {{key:Esc}} | எதுவும் தேர்ந்தெடுக்காதே (மற்றும் ஒட்டுதலை ரத்துசெய்) |

{{key:Mod+S}}, {{key:Mod+O}} மற்றும் {{key:Mod+P}} ஒரு பெட்டியில் தட்டச்சு செய்யும்போதும் வேலை செய்யும். ஒரு உரைப் பெட்டியில் {{key:Mod+Z}} மற்றும் {{key:Mod+Y}} வழக்கம்போல் உங்கள் தட்டச்சை செயல்தவிர்க்கும்; {{key:Mod+C}}, {{key:Mod+X}}, {{key:Mod+V}} மற்றும் {{key:Mod+A}} அதேபோல: ஒரு பெட்டியில் அவை அதன் உரையை நகலெடுக்கும், வெட்டும், ஒட்டும், தேர்ந்தெடுக்கும். பக்கத்தில் (ஒரு பலகத்தில்) உரை தேர்ந்தெடுக்கப்பட்டிருந்தால், {{key:Mod+C}} அந்த உரையை நகலெடுக்கும். {{key:Mod+Shift+Z}} CivilCraft இல் எதுவும் செய்யாது: {{key:Mod+Y}} அல்லது {{ui:Redo}} பொத்தானைப் பயன்படுத்தவும்.

:::mac
Mac இல் **delete** எனக் குறிக்கப்பட்ட விசை உலாவிக்கு {{key:Backspace}} ஆகும். ஒரு தேர்வை நீக்க, {{key:Delete}} ஐ அழுத்தவும் (Fn மற்றும் delete), அல்லது கருவிப்பட்டியின் {{ui:More}} பட்டியில் {{ui:Delete}} ஐத் தேர்ந்தெடுக்கவும்.
:::

| {{key:Esc}} | வரைவதை ரத்துசெய் (அல்லது ஒட்டுதலை); மீண்டும் அழுத்தினால் (அல்லது எதுவும் வரையப்படாவிட்டால்), {{ui:Select}} க்குத் திரும்பித் தேர்வை நீக்கு |

## திட்டக் காட்சி

| விசை அல்லது செயல் | முடிவு |
|---|---|
| சக்கரம் | சுட்டியில் பெரிதாக்கு அல்லது சிறிதாக்கு |
| வெற்றிடத்தில் இழுத்தல் | நகர்த்து (எந்தக் கருவியிலும்; குறுகிய சொடுக்கு இன்னும் சொடுக்கும்; {{key:Shift}} அழுத்தியிருந்தால் அதற்குப் பதிலாக ஒரு தேர்வுப் பெட்டியை வரையும்) |
| நடு பொத்தானுடன் இழுத்தல் | நகர்த்து |
| வலது பொத்தானுடன் இழுத்தல் | நகர்த்து (பட்டி எதுவும் திறக்காது) |
| {{key:Space}} அழுத்தி இழுத்தல் | நகர்த்து |
| சொடுக்கு | தேர்ந்தெடு ({{ui:Select}} உடன்), அல்லது ஒரு புள்ளியை வை (ஒரு வரையும் கருவியுடன்) |
| {{key:Shift}} அழுத்தி சொடுக்கு | ஓர் அளவைப் புள்ளியை தேர்வில் சேர், அல்லது அதை நீக்கு |
| {{key:Shift}} அழுத்தி இழுத்தல் | ஒரு பெட்டி வரை: உள்ளே உள்ள அளவைப் புள்ளிகள் தேர்வில் சேரும். அவற்றைச் சுற்றி இழுத்தால் ஒரு [வளைய தேர்வு](topic:lasso-selection) |
| வளையம் வரையும்போது {{key:Space}} | சாளரம், பின்னர் குறுக்கு, பின்னர் வேலி |
| ஒட்டும்போது சொடுக்கு | ஒட்டிய புள்ளிகளை அங்கே வை ({{key:Enter}} அவற்றை அவற்றின் சொந்த ஆயங்களில் வைக்கும்) |
| ஒரு பிடிப்பை இழுத்தல் | ஒரு PI, மேடை மூலை அல்லது அமைப்பை நகர்த்து (ஒரு செயல்தவிர் படி) |
| {{key:Up}} {{key:Down}} {{key:Left}} {{key:Right}} | திட்டத்துக்கு கவனம் இருக்கும்போது நகர்த்து (முதலில் அதைச் சொடுக்கவும்) |
| {{key:Plus}} மற்றும் {{key:Minus}} | திட்டத்துக்கு கவனம் இருக்கும்போது நடுவில் பெரிதாக்கு மற்றும் சிறிதாக்கு |

= விசை {{key:Plus}} போலப் பெரிதாக்கும், அதனால் Shift தேவையில்லை.

## திரையும் உதவியும்

| விசை | செயல் |
|---|---|
| {{key:F1}} | இந்த உதவியைத் திற அல்லது மூடு (பக்கப் பலகம்); செயலிப் பட்டியில் உள்ள {{ui:Help}} அதையே செய்யும் |
| {{key:Esc}} | உதவிப் பலகம் திறந்திருக்கும்போது அதை மூடு |
| {{key:Ctrl+Shift+F}} | திரை முறைகளை மாற்று: முழுத் திரை, பட்டிகள் மறைக்கப்பட்ட முழுத் திரை, சாதாரண |
| {{key:Esc}} | முழுத் திரையிலிருந்து வெளியேறு (உலாவியின் சொந்த விசை) |

{{key:F1}} CivilCraft பார்ப்பதற்கு முன் உதவியைச் சென்றடையும், அதனால் அது எந்தக் கருவியிலும் வேலை செய்யும். பெரும்பாலான Mac விசைப்பலகைகளில், fn உடன் F1 ஐ அழுத்தவும், அல்லது {{ui:Help}} ஐச் சொடுக்கவும். {{key:Ctrl+Shift+F}} ஒரு Mac உட்பட ஒவ்வொரு தளத்திலும் Control விசையைப் பயன்படுத்தும். இந்த உதவியில் தேடுவது பற்றி [உதவியைப் பயன்படுத்துதல்](common:help) ஐப் பார்க்கவும்.

## சுட்டி, டிராக்பேட் மற்றும் தொடுதல்

:::mouse
- சக்கரம் சுட்டியில் பெரிதாக்கும். சுதந்திரமாகச் சுழலும் சக்கரமுள்ள சுட்டி விரைவாகப் பெரிதாக்கும்: குறுகிய சுழற்சிகளைக் கொடுக்கவும்.
- வெற்றிடத்தில் எந்த இழுத்தலுடனும், நடு பொத்தானுடனும், வலது பொத்தானுடனும், அல்லது {{key:Space}} அழுத்தி இழுப்பதுடனும் நகர்த்தவும்.
:::

:::mac
Mac டிராக்பேடில்:

- இரண்டு விரல் உருட்டல் **பெரிதாக்கும்** (அது நகர்த்தாது), கிள்ளுதலும் பெரிதாக்கும்.
- நகர்த்த, ஒரு விரலால் வெற்றிடத்தில் அழுத்தி இழுக்கவும், அல்லது {{key:Space}} ஐப் பிடித்து இழுக்கவும்.
- இரண்டு விரல் சொடுக்கு (வலது சொடுக்கு) எந்தப் பட்டியையும் திறக்காது, தானாக எதுவும் செய்யாது.
:::

:::touch
தொடுதிரையில்:

- முதல் தொடுதல் பொத்தான்களையும் பட்டி வரிகளையும் விரல் அளவுக்கு மாற்றும்.
- தேர்ந்தெடுக்க அல்லது ஒரு புள்ளியை வைக்கத் தட்டவும்; வெற்றிடத்தில் ஒரு விரலை இழுத்தால் நகர்த்தும். தட்டுதல் சிறிது அசையலாம்: விரல் ஏறத்தாழ 10 பிக்சல் நகர்ந்த பின்னரே அது நகர்த்தும்.
- இரண்டு விரல்களால் கிள்ளி பெரிதாக்கு; ஒன்றாக நகர்த்தி நகர்த்து.
- ஒரு விரலால் ஒரு பிடிப்பையோ PVI ஐயோ இழு. பிடிப்புகள் சுற்றி ஒரு விரல் அகலம் எடுத்துக்கொள்ளும்.
- ஒரு சீரமைப்பு, மேடை, breakline, எல்லை, குழாய் ஓட்டம், அம்சக் கோடு அல்லது மனையை வரையும்போது, வரைபடத்தின் மேல் ஒரு பட்டி {{ui:Finish}} ({{key:Enter}}), {{ui:Undo point}} ({{key:Backspace}}) மற்றும் {{ui:Cancel}} ({{key:Esc}}) ஐ வழங்கும். நீண்ட அழுத்தம் (நகராமல் அரை வினாடி) வரைவதையும் முடிக்கும்.
- {{ui:Select}} இல், ஓர் அளவைப் புள்ளியில் நீண்ட அழுத்தம் அதை தேர்வில் சேர்க்கும், அல்லது {{key:Shift}}+சொடுக்கு போல அதை நீக்கும்.
- 3D காட்சியில், ஒரு விரல் சுற்றும், இரண்டு கிள்ளி நகர்த்தும், தட்டுதல் தேர்ந்தெடுக்கும்.
- தொடுதலில் சுட்டி மேல் நகர்த்தல் இல்லை, அதனால் நிலைப்பட்டி அளவீடுகள் ஒரு விரல் அழுத்தியிருக்கும்போது மட்டுமே புதுப்பிக்கப்படும்.

## வெற்றி பெறும் உலாவி விசைகள்

சில விசைகள் உலாவிக்குச் சொந்தமானவை, அவை ஒருபோதும் CivilCraft ஐ அடையாது, உதாரணமாக {{key:Mod+W}} (தாவலை மூடு), {{key:Mod+T}} (புதிய தாவல்), {{key:Mod+N}} (புதிய சாளரம்) மற்றும் {{key:F11}} (Windows மற்றும் Linux உலாவிகளில் முழுத் திரை). CivilCraft அவற்றைப் பயன்படுத்துவதில்லை. ஒரு குறுக்குவழி அதற்குப் பதிலாக உலாவியில் ஏதாவது திறந்தால், பக்கத்துக்கு கவனம் இருக்குமாறு திட்டத்தை ஒருமுறை சொடுக்கி மீண்டும் முயற்சிக்கவும்.

## Move எங்கே உள்ளது

Move கட்டளை இல்லை: {{ui:Select}} ஐத் தேர்ந்தெடுத்து ஒரு புள்ளியையோ ஒரு முனையையோ இழுக்கவும், அல்லது {{ui:Properties}} இல் அதன் ஆயங்களைத் திருத்தவும். பார்க்கவும் [புள்ளிகளைத் திருத்து](topic:edit-points).

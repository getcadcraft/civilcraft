CivilCraft அதிகாரப்பூர்வ பெயர்வெளியுடனும் ஸ்கீமா இருப்பிடத்துடனும் LandXML 1.2 ஐ எழுதுகிறது. ரூட் உறுப்பு `LandXML` ஆக உள்ள எந்தக் கோப்பையும் அது படிக்கும், கீழே உள்ள உறுப்புகளைப் பெயரால் எடுக்கும் (பெயர்வெளி முன்னொட்டுகள் புறக்கணிக்கப்படும்; பதிப்பு சரிபார்க்கப்படாது). அதன் XML வாசிப்பான் ஐந்து நிலையான என்டிட்டிகளையும் எண் எழுத்துக் குறிப்புகளையும் மட்டுமே ஏற்கும்; DTD அல்லது வெளிக் கோப்பை அது ஒருபோதும் ஏற்றாது. படிகளுக்கு, பார்க்க [LandXML ஐப் பரிமாறுதல்](topic:landxml).

LandXML ஆயங்களை வடக்கு முதலில் எழுதுகிறது: ஒரு புள்ளி "N E" அல்லது "N E Z" ஆகும்.

## எழுதப்படுபவை

| உறுப்பு | CivilCraft எழுதுவது |
|---|---|
| `Units` | `Imperial` (linearUnit USSurveyFoot, பரப்பளவு சதுர அடியில், கனஅளவு கன யார்டில், விட்டம் அங்குலத்தில்) அல்லது `Metric` (meter, square meter, cubic meter, millimeter) |
| `Project` | `name` = திட்டப் பெயர் |
| `Application` | பெயர் CivilCraft, உற்பத்தியாளர் CadCraft |
| `CgPoints` / `CgPoint` | `name` = புள்ளி எண், `desc` = விளக்கம், `code` = குழு; உரை "N E Z" (அல்லது உயரம் இல்லாமல் "N E") |
| `Alignments` / `Alignment` | `name`, `length`, `staStart` |
| `CoordGeom` / `Line` | `staStart`, `length`, `Start`, `End` |
| `CoordGeom` / `Curve` | `crvType` arc, `rot` cw அல்லது ccw, `radius`, `length`, `staStart`, `chord`, `delta` (டிகிரியில்), `tangent`, `external`, `midOrd`; `Start`, `Center`, `End`, `PI` |
| `Profile` / `ProfSurf` | அலைன்மெண்டின் வழியே இருக்கும் தரை, நிலைய மற்றும் உயர இணைகளாக (`PntList2D`), மேற்பரப்பை விட்டு வெளியேறும் இடத்தில் பிரிக்கப்பட்டு |
| `Profile` / `ProfAlign` | வடிவமைப்புச் சுயவிவரம் ("<alignment> design" எனப் பெயரிடப்பட்டு): முனைகளுக்கும் கோணப் புள்ளிகளுக்கும் `PVI`, செங்குத்து வளைவுகளுக்கு `length` உடன் `ParaCurve` |
| `Surfaces` / `Surface` | `name` மற்றும் `desc`; முதலில் இருக்கும் தரை, பின்னர் பேடுகளோ வழித்தடங்களோ தரையைச் சமன் செய்யும்போது "Proposed" |
| `SourceData` / `Breaklines` / `Breakline` | `brkType` standard, `name`, `PntList3D` (இருக்கும் தரை மட்டும்) |
| `SourceData` / `Boundaries` / `Boundary` | `bndType` outer, `edgeTrim` true, `PntList2D` (இருக்கும் தரை மட்டும், இருந்தால்) |
| `Definition` | `surfType` TIN, `area2DSurf`, `area3DSurf`, `elevMax`, `elevMin`; `id` உடன் `Pnts` / `P`; `Faces` / `F` |
| `PipeNetworks` / `PipeNetwork` | `name`, `pipeNetType` storm அல்லது sanitary |
| `Struct` | `name`, `elevRim` (பயன்படுத்தப்பட்ட மேல்விளிம்பு, அமைக்கப்பட்டது அல்லது மேற்பரப்பிலிருந்து), `elevSump`; `Center`; `diameter` உடன் `CircStruct`; `elev`, `flowDir` in அல்லது out, `refPipe` உடன் `Invert` |
| `Pipe` | `name`, `refStart`, `refEnd`, `length`, `slope`; `diameter` உடன் `CircPipe` |
| `PlanFeatures` / `PlanFeature` | ஒவ்வோர் அம்சக் கோட்டுக்கும் ஒன்று: `name`; `Line` (`length`, `Start`, `End`) மற்றும் `Curve` (`rot`, `crvType` arc, `radius`, `length`, `chord`, `delta`; `Start` மற்றும் `End` "N E Z" ஆக, `Center` "N E" ஆக) கொண்ட `CoordGeom`; பயன்பாடும் closed உம் கொண்ட `Feature` `code="CivilCraft"` `Property` |

எழுதப்படாதவை: பொருட்களாகப் பேடுகளும் வழித்தடங்களும் (அவற்றின் முடிவு "Proposed" மேற்பரப்பு), பிழைகள் உள்ள அலைன்மெண்டுகள், இரண்டு invert களும் இல்லாத குழாய்கள், பிணைய விதிகள்.

## படிக்கப்படுபவை

| உறுப்பு | CivilCraft எடுப்பது |
|---|---|
| `Units` | `Imperial` அல்லது `Metric`, அவற்றின் `linearUnit` அடியா மீட்டரா என்பதை முடிவு செய்யும். அறியப்படாத அலகு குறிக்கப்படும். |
| `Project` | `name` திட்டப் பெயராகும். |
| `CgPoints` / `CgPoint` (உள்ளமைந்தவையும்) | பெயர் (அல்லது `oID`), "N E" அல்லது "N E Z", `desc` (அல்லது `code`) விளக்கமாக |
| `Surface` உடன் `Definition surfType="TIN"` | `Pnts` மற்றும் `Faces` இருக்கும் தரையாக (முதல் மேற்பரப்பு மட்டும்); தெரியாத முகங்கள் (`i="1"`) விடப்படும் |
| `SourceData` / `Breaklines` | 3D முறிவுக் கோடுகள், மேற்பரப்புடன் வைக்கப்படும் |
| `SourceData` / `Boundaries` | வெளி எல்லை |
| `Alignment` / `CoordGeom` | `Line` மற்றும் `Curve` உறுப்புகள்; ஒவ்வொரு வளைவின் `PI` இலிருந்து PI கள் மீண்டும் கட்டப்படும், அல்லது அதன் `Center` மற்றும் தொடுகோடுகளிலிருந்து; `staStart` |
| `Profile` / `ProfAlign` | `PVI` மற்றும் `ParaCurve` (`length` உடன்); குறைந்தது இரண்டு PVI கள் உள்ள முதல் வடிவமைப்புச் சுயவிவரம் |
| `PlanFeatures` / `PlanFeature` | ஒவ்வொன்றும் ஓர் அம்சக் கோடாக: `Line`, `Curve` (அதன் `Start`, `Center`, `End` மற்றும் `rot`) மற்றும் `IrregularLine` (`PntList3D` அல்லது `PntList2D`) முனைக்கு முனையாக இணைக்கப்பட்டவை (இடைவெளி ஒரு நேர்கோட்டுப் பகுதியால் இணைக்கப்பட்டு குறிக்கப்படும்); அது தொடங்கிய இடத்திலேயே முடிந்தால் மூடப்படும்; CivilCraft இன் சொந்த `Feature` இலிருந்து பயன்பாடும் மூடலும், இல்லையெனில் **வரைந்தது மட்டும்**. உயரம் இல்லாத புள்ளிகள் 0 பெறும் (குறிக்கப்படும்). |
| `Spiral` | `Curve` அருகே கிளோதாய்டு சுருள்கள் (உள்ளேயும் வெளியேயும்; ஆரமும் சுருள் நீளங்களும் கொண்ட PI ஆகப் படிக்கப்படும், `theta`, `totalX`, `totalY`, `tanLong`, `tanShort`, `constant` உடன் மீண்டும் எழுதப்படும்) |
| `PipeNetwork` | குழாய்கள் உள்ள முதல் வலையமைப்பு: `Struct` (`Center`, `elevRim`, `elevSump`, `CircStruct` விட்டம், குழாய் ஒன்றுக்கு `Invert`) மற்றும் `Pipe` (`refStart`, `refEnd`, `CircPipe` விட்டம்) |

## தவிர்க்கப்பட்டவை, குறிப்புகளில் பெயரிடப்பட்டவை

- முதலுக்குப் பின் உள்ள மேற்பரப்புகள், கட்ட மேற்பரப்புகள் மற்றும் TIN அல்லாத பிற மேற்பரப்புகள்
- `IrregularLine` அல்லது `Chain` உறுப்புகள் உள்ள அலைன்மெண்டுகள், clothoid அல்லாத சுருள்கள், இரண்டு வளைவுகளுக்கு இடையே ஒரு சுருள், அல்லது வடிவவியல் இல்லாதவை
- முதலுக்குப் பின் உள்ள வடிவமைப்புச் சுயவிவரங்கள்; `CircCurve` மற்றும் `UnsymParaCurve` செங்குத்து வளைவுகள் (அவற்றின் PVI கள் வளைவு இல்லாமல் வைக்கப்படும்)
- மற்ற புள்ளிகளை மட்டுமே குறிக்கும் புள்ளிகள் (`pntRef`), படிக்கக்கூடிய ஆயங்கள் இல்லாத புள்ளிகள்
- மீண்டும் வரும் புள்ளிப் பெயர்கள் (முதலாவது வைக்கப்படும்)
- மறை, காட்டு மற்றும் தரவு-கிளிப் எல்லைகள்; 3D புள்ளிகள் இல்லாத முறிவுக் கோடுகள்
- முதலுக்குப் பின் உள்ள பிணையங்கள்; storm மற்றும் sanitary அல்லாத பிணைய வகைகள் (storm எனப் படிக்கப்படும்)
- செவ்வக, உள்வாய் மற்றும் வெளிவாய் கட்டமைப்புகள் (வட்டமாகப் படிக்கப்படும்); முட்டை, நீள்வட்ட மற்றும் பெட்டிக் குழாய்கள் மற்றும் கால்வாய்கள் (அளவில்லா வட்டக் குழாய்களாகப் படிக்கப்படும்)
- அம்சக் கோடுகளில் உள்ள `Spiral` உறுப்புகள்
- `Parcels`, `Roadways`, `GradeModel` மற்றும் `Survey`

கோப்பிலுள்ள தரைச் சுயவிவரங்கள் (`ProfSurf`) பயன்படுத்தப்படுவதில்லை: CivilCraft தரையை மேற்பரப்பிலிருந்தே மாதிரியெடுக்கும்.

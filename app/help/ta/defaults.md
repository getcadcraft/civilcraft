CivilCraft க்கு அமைப்புகள் உரையாடலோ வார்ப்புருவோ இல்லை. இவை விஷயங்கள் தொடங்கும் மதிப்புகள். **தற்காலிக மதிப்பு** எனக் குறிக்கப்பட்ட மதிப்புகள் எந்தத் தரத்திலிருந்தும் எடுக்கப்படவில்லை: ஒரு சோதனையையோ அளவையோ நம்புவதற்கு முன் அவற்றை உங்கள் திட்டத்தின் அளவுகோல்களுடன் மாற்றவும்.

## புதிய திட்டம்

| அமைப்பு | மதிப்பு |
|---|---|
| பெயர் | பெயரிடப்படாத தளம் (முதல் புள்ளிக் கோப்பின் பெயர் அதை மாற்றும்) |
| அலகுகள் | US feet |
| மேற்பரப்பு பெயர் | இருக்கும் தரை |
| புள்ளி குழுக்கள் | ஒவ்வொரு குழுவும் {{ui:புள்ளிகள்}} ஆகத் தொடங்கும் |
| நீளமான வெளி விளிம்பு | 0 (ஒவ்வொரு முக்கோணத்தையும் வைத்திரு) |
| வைத்திருக்கப்படும் செயல்தவிர் படிகள் | 200 |

| முதன்மை இடைவெளி | 5வது சம உயரக் கோடு |

| அணைக்கப்பட்டவை | முக்கோணங்கள், உயரப் பட்டைகள், சரிவு அம்புகள், புள்ளி லேபிள்கள் |

## சீரமைப்புகளும் சுயவிவரங்களும்

| அமைப்பு | மதிப்பு |
|---|---|
| பெயர் | சீரமைப்பு 1, சீரமைப்பு 2 … |
| தொடக்க நிலையம் | 0+00 |
| ஒவ்வொரு உள் PI யிலும் வளைவு ஆரம் | 100 ft அல்லது 30 m; ஒவ்வொரு தொடுகோட்டின் பாதியில் பொருந்தவில்லை என்றால் சிறியது |
| வடிவமைப்புச் சுயவிவரம் | நீங்கள் ஒன்றைத் தொடங்கும் வரை எதுவுமில்லை; {{ui:தரையிலிருந்து தொடங்கு}} ஒவ்வொரு முனையிலும் தரையில் ஒரு PVI ஐ வைக்கிறது |
| செங்குத்து வளைவு நீளம் | 0 (வளைவு இல்லை) நீங்கள் ஒன்றைத் தட்டச்சு செய்யும் வரை |

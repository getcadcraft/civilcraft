Մեկ տառի ստեղները աշխատում են, երբ տուփում չեք մուտքագրում։ {{key:Mod}}-ով դյուրանցումները օգտագործում են Command Mac-ում և Ctrl մնացած բոլոր հարթակներում։ Տես նաև [Ստեղները բրաուզերում](common:keys)։

## Ֆայլեր և խմբագրում

| Ստեղն | Գործողություն |
|---|---|
| {{key:Mod+O}} | Բացել կետերի ֆայլ, LandXML կամ նախագիծ |
| {{key:Mod+S}} | Պահել նախագիծը (ներբեռնում է `.civilcraft.json` ֆայլ) |
| {{key:Mod+P}} | Տպել պլանը PDF-ով (բացում է տպման երկխոսությունը, ոչ բրաուզերի տպումը) |
| {{key:Mod+Z}} | Հետարկել |
| {{key:Mod+Y}} | Կրկնել |
| {{key:Delete}} | Ջնջել ընտրված հանույթի կետերը, երթուղին, հարթակը, կառույցը, խողովակը կամ PVI-ը |
| {{key:Mod+C}} | Պատճենել ընտրված հանույթի կետերը (նաև որպես կետերի տողեր աղյուսակի համար) |
| {{key:Mod+X}} | Կտրել ընտրված հանույթի կետերը |
| {{key:Mod+V}} | Տեղադրել կետերը․ դրանք հետևում են սլաքին, սեղմեք, որտեղ պետք է գնան |
| {{key:Mod+Shift+V}} | Տեղադրել տեղում՝ կետերի սեփական կոորդինատներով |
| {{key:Mod+D}} | Կրկնօրինակել ընտրված կետերը․ պատճենը հետևում է սլաքին |
| {{key:Mod+A}} | Ընտրել բոլոր հանույթի կետերը |
| {{key:Esc}} | Ոչինչ չընտրել (և չեղարկել տեղադրումը) |

{{key:Mod+S}}, {{key:Mod+O}} և {{key:Mod+P}} աշխատում են նույնիսկ այն ժամանակ, երբ տուփում եք մուտքագրում։ {{key:Mod+Z}} և {{key:Mod+Y}}-ը տեքստային տուփում հետարկում և կրկնում են ձեր մուտքագրումը, ինչպես սովորաբար, և նույնպես՝ {{key:Mod+C}}, {{key:Mod+X}}, {{key:Mod+V}} և {{key:Mod+A}}․ տուփում դրանք պատճենում, կտրում, տեղադրում և ընտրում են իր տեքստը։ Երբ էջում (վահանակում) տեքստ է ընտրված, {{key:Mod+C}}-ը պատճենում է այդ տեքստը։ {{key:Mod+Shift+Z}}-ը CivilCraft-ում ոչինչ չի անում․ օգտագործեք {{key:Mod+Y}}-ը կամ {{ui:Կրկնել}} կոճակը։

:::mac
Mac-ի ստեղնը, որի վրա գրված է **delete**, բրաուզերի համար {{key:Backspace}} է։ Ընտրությունը ջնջելու համար սեղմեք {{key:Delete}} (Fn և delete), կամ ընտրեք {{ui:Ջնջել}}-ը գործիքագոտու {{ui:Ավելին}} ցանկից։
:::

## Գծելու ժամանակ

| Ստեղն | Գործողություն |
|---|---|
| {{key:Enter}} | Ավարտել երթուղին, հարթակը, խողովակի գիծը, կոտրվող գիծը կամ սահմանը |
| {{key:Backspace}} | Հեռացնել վերջին սեղմած կետը |
| {{key:C}} | Գծային հատկանիշ․ միացնել կամ անջատել աղեղները (գագաթից հետո սեղմեք կորի վրա կետ, ապա դրա վերջը) |
| {{key:Esc}} | Չեղարկել գծումը (կամ տեղադրումը)․ նորից սեղմելիս (կամ երբ ոչինչ չի գծված) վերադառնալ {{ui:Ընտրել}}-ին և մաքրել ընտրությունը |

## Պլանի տեսք

| Ստեղն կամ գործողություն | Արդյունք |
|---|---|
| Անիվ | Մեծացնել կամ փոքրացնել ցուցիչի մոտ |
| Քաշել դատարկ տարածքի վրա | Տեղաշարժել (ցանկացած գործիքով․ կարճ սեղմումը դեռ սեղմում է; Shift պահած՝ գծում է ընտրության տուփ) |
| Քաշել միջին կոճակով | Տեղաշարժել |
| Քաշել աջ կոճակով | Տեղաշարժել (ցանկ չի բացվում) |
| {{key:Space}} և քաշել | Տեղաշարժել |
| Սեղմել | Ընտրել ({{ui:Ընտրել}}-ով), կամ տեղադրել կետ (գծման գործիքով) |
| {{key:Shift}} և սեղմել | Ավելացնել հանույթի կետ ընտրությանը, կամ հանել այն |
| {{key:Shift}} և քաշել | Գծել տուփ․ դրա ներսի հանույթի կետերը ավելանում են ընտրությանը։ Քաշեք դրանց շուրջը [լասո](topic:lasso-selection)-ով |
| {{key:Space}} լասո գծելիս | Պատուհան, ապա խաչում, ապա ցանկապատ |
| Սեղմել տեղադրելիս | Տեղադրել տեղադրված կետերը այնտեղ ({{key:Enter}}-ը դնում է դրանք իրենց սեփական կոորդինատներում) |
| Քաշել բռնակը | Տեղաշարժել PI-ը, հարթակի անկյունը կամ կառույցը (մեկ հետարկման քայլ) |
| {{key:Up}} {{key:Down}} {{key:Left}} {{key:Right}} | Տեղաշարժել, երբ պլանը ունի ֆոկուս (նախ սեղմեք դրա վրա) |
| {{key:Plus}} և {{key:Minus}} | Մեծացնել և փոքրացնել մեջտեղում, երբ պլանը ունի ֆոկուս |

= ստեղնը մեծացնում է ինչպես {{key:Plus}}-ը, ուստի Shift պետք չէ։

| Սեղմել {{ui:Ավելացնել PVI-ներ}}-ը միացված | Այնտեղ ավելացնել PVI |
| Սեղմել PVI-ը | Ընտրել այն |

Պրոֆիլի տեսքը չի մեծացնում և չի տեղաշարժում։

## Էկրան և օգնություն

| Ստեղն | Գործողություն |
|---|---|
| {{key:F1}} | Բացել կամ փակել այս օգնությունը (կողային վահանակը)․ {{ui:Օգնություն}}-ը վերևի գոտում անում է նույնը |
| {{key:Esc}} | Փակել օգնության վահանակը, երբ այն բաց է |
| {{key:Ctrl+Shift+F}} | Անցնել էկրանի ռեժիմների միջև՝ լիաէկրան, լիաէկրան՝ թաքցված գոտիներով, նորմալ |
| {{key:Esc}} | Դուրս գալ լիաէկրանից (բրաուզերի սեփական ստեղն է) |

{{key:F1}}-ը օգնությանը հասնում է CivilCraft-ից առաջ, ուստի աշխատում է ցանկացած գործիքում։ Mac-ի մեծ մասի ստեղնաշարերում սեղմեք fn-ը F1-ի հետ, կամ սեղմեք {{ui:Օգնություն}}-ը։ {{key:Ctrl+Shift+F}}-ը բոլոր հարթակներում օգտագործում է Control ստեղնը, ներառյալ Mac-ը։ Տես [Օգնության օգտագործում](common:help), թե ինչպես որոնել այս օգնության մեջ։

## Մկնիկ, թրեքփադ և հպում

:::mouse
- Անիվը մեծացնում է ցուցիչի մոտ։ Ազատ պտտվող անիվով մկնիկը մեծացնում է արագ․ տվեք կարճ պտույտներ։
- Տեղաշարժեք ցանկացած քաշումով դատարկ տարածքի վրա, միջին կոճակով, աջ կոճակով կամ {{key:Space}} և քաշել։
:::

:::mac
Mac-ի թրեքփադում․
- Երկու մատի սքրոլ **մեծացնում** է (չի տեղաշարժում), և մատների մերձեցումը նույնպես մեծացնում է։
- Տեղաշարժելու համար սեղմեք և քաշեք դատարկ տարածքի վրա մեկ մատով, կամ պահեք {{key:Space}}-ը և քաշեք։
- Երկու մատի սեղմումը (աջ սեղմում) ցանկ չի բացում և ինքնին ոչինչ չի անում։
:::

:::touch
Հպման էկրանի վրա․
- Առաջին հպումը կոճակներն ու ցանկի տողերը դարձնում է մատի չափի։
- Հպեք ընտրելու կամ կետ տեղադրելու համար․ մեկ մատով քաշած դատարկ տարածքի վրա տեղաշարժում է։ Հպումը մի փոքր կարող է դողալ․ տեղաշարժվում է միայն այն բանից հետո, երբ մատը շարժվի մոտ 10 պիքսել։
- Երկու մատով մերձեցնելը մեծացնում է, իսկ միասին շարժելը՝ տեղաշարժում։
- Քաշեք բռնակը կամ PVI-ը մեկ մատով։ Բռնակները շուրջը վերցնում են մատի լայնությունը։
- Երբ երթուղի, հարթակ, կոտրվող գիծ, սահման, խողովակի գիծ, գծային հատկանիշ կամ հողամաս եք գծում, պլանի վրայի գոտին առաջարկում է {{ui:Ավարտել}} ({{key:Enter}}), {{ui:Հետարկել կետը}} ({{key:Backspace}}) և {{ui:Չեղարկել}} ({{key:Esc}})։ Երկար սեղմումը (կես վայրկյան՝ առանց շարժվելու) նույնպես ավարտում է։
- {{ui:Ընտրել}}-ում երկար սեղմումը հանույթի կետի վրա ավելացնում է այն ընտրությանը կամ հանում, ինչպես {{key:Shift}}+սեղմումը։
- 3D տեսքում մեկ մատը պտտում է, երկուսը մերձեցնում և տեղաշարժում են, իսկ հպումը ընտրում է։
- Հպման վրա hover չկա, ուստի կարգավիճակի գոտու ցուցանիշները թարմանում են միայն մատը սեղմած ժամանակ։

## Բրաուզերի ստեղները, որոնք հաղթում են

Որոշ ստեղներ բրաուզերինն են և երբեք չեն հասնում CivilCraft-ին, օրինակ՝ {{key:Mod+W}} (փակել ներդիրը), {{key:Mod+T}} (նոր ներդիր), {{key:Mod+N}} (նոր պատուհան) և {{key:F11}} (լիաէկրան Windows-ում և Linux բրաուզերներում)։ CivilCraft-ը դրանք չի օգտագործում։ Եթե դյուրանցումը բրաուզերում որևէ բան է բացում, սեղմեք պլանը մեկ անգամ, որպեսզի էջը ունենա ֆոկուսը, և նորից փորձեք։

## Որտեղ է Տեղափոխել-ը

Տեղափոխել հրաման չկա․ ընտրեք {{ui:Ընտրել}} և քաշեք կետը կամ գագաթը, կամ խմբագրեք դրա կոորդինատները {{ui:Հատկություններ}}-ում։ Տես [Խմբագրել կետերը](topic:edit-points)։

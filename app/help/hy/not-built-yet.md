CivilCraft-ը վաղ փուլում է։ Այս էջը թվարկում է այն, ինչ ընթացիկ տարբերակը չի անում, որպեսզի չփնտրեք դա։ Այստեղ ոչինչ ժամկետով չի խոստացվում։

## Կետեր

| Դեռ չկառուցված | Փոխարենը, այսօր |
|---|---|
| Երկրորդ կետային ֆայլի ավելացում առաջինին | Նախ միացրեք ֆայլերը տեքստային խմբագրիչում կամ աղյուսակում |
| Կետերի տեքստային ֆայլի արտահանում | Արտահանեք LandXML (կետերը գնում են որպես CgPoints), օգտագործեք GIS {{ui:Արտահանել}}-ը (կետերը P, N, E, Z և D դաշտերով) կամ {{ui:Պատճենել}}-ը կետերը աղյուսակ |
| Կետերի պիտակների ոճեր, խորհրդանիշներ ըստ նկարագրության բանալիի, կորեր (աղեղներ) գծային կոդերից, նկարագրության բանալիի ֆայլ, որը կիսվում է նախագծերի միջև | Պիտակները ցույց են տալիս համարը, նիշը և նկարագրությունը, կամ ավելի քիչ ([CivilCraft-ի կարգավորումներ](topic:settings)); բանալիները պահվում են նախագծի ֆայլում |
| Միավորների փոխարկում | Փոխարկեք ֆայլը նախքան ներմուծումը․ **Միավորներ**-ը միայն վերանվանում է |

## Մակերևույթներ

| Դեռ չկառուցված | Փոխարենը, այսօր |
|---|---|
| Մեկից ավելի մակերևույթ կետերից | Մեկ նախագիծ յուրաքանչյուր մակերևույթի համար |
| Ներքին սահմանների թաքցնում | Օգտագործեք **Ամենաերկար արտաքին եզրը** կամ արտաքին սահման |
| Մեկ նկարված կոտրման գծի ընտրում կամ խմբագրում | {{key:Mod+Z}}, կամ {{ui:Հեռացնել գծված կոտրման գծերը}} և նորից գծել |
| LandXML-ից կարդացված մակերևույթի խմբագրում (կոտրման գծեր, սահման) | {{ui:Վերակառուցել մակերևույթը կետերից}} |
| Բարձրության ցանցից ստեղծված մակերևույթի խմբագրում | Նորից ներմուծեք ցանցը այլ ընտրանքներով |
| LandXML-ից կարդացված մակերևույթի փոխարկում, երբ կոորդինատային համակարգը փոխվում է | Նախ {{ui:Վերակառուցել մակերևույթը կետերից}} |
| Պիտակավորված կետային նիշեր և թեքության արժեքներ | Կարդացեք դրանք կարգավիճակի գոտում, կամ գունավորեք մակերևույթը թեքությամբ՝ **Թեքության վերլուծություն**-ով Լանդշաֆտի աշխատանքային տարածքում ([Լանդշաֆտի հողաշարժ](topic:landscape-grading#grading-checks)) |

## Երթուղիներ և պրոֆիլներ

| Դեռ չկառուցված | Փոխարենը, այսօր |
|---|---|
| Պարույրներ, որոնք բացի կլոտոիդից; պարույր երկու կորերի միջև (բարդ անցումներ) | Կլոտոիդ պարույրներ կորի ծայրերում հասանելի են; մյուսները անվանվում են և բաց են թողնվում LandXML ներմուծման ժամանակ |
| PI տեղադրում երկու մյուսների միջև | Նորից գծեք երթուղին կամ նորից մուտքագրեք PI կոորդինատները |
| Երթուղիներ օբյեկտներից, օֆսեթներից, լայնացումներից | Գծեք PI-ներով |
| K մուտքագրում ուղղահայաց կորի համար | Մուտքագրեք L (K-ն ցուցադրվում է) |
| Շրջանաձև և ոչ սիմետրիկ ուղղահայաց կորեր | Միայն սիմետրիկ պարաբոլիկ կորեր |
| Մեկից ավելի նախագծային պրոֆիլ մեկ երթուղու համար | Մեկ երթուղի յուրաքանչյուր տարբերակի համար |
| Պրոֆիլի տեսքի մասշտաբավորում, պրոֆիլի գոտիներ պրոֆիլի տակ | Պրոֆիլի տեսքը տեղավորում է ամբողջ երթուղին․ գծեք այն [պլանի և պրոֆիլի թերթերի](topic:plan-profile-sheets) վրա |
| Կտրվածքներ DWG-ում կամ LandXML-ում | Կտրվածքների թերթերը՝ որպես PDF; {{ui:CSV}} մակերեսների և ծավալների համար |
| Նմուշային գծեր անկյունով կամ տարբեր լայնություններով ճանապարհի երկայնքով | Յուրաքանչյուր կողմում մեկ լայնություն ամբողջ երթուղու համար |

## Միջանցքներ

| Դեռ չկառուցված | Փոխարենը, այսօր |
|---|---|
| Միջնագծեր, արգելապատնեշներ և գոտիների թեքում, որը պտտում է ձևանմուշները | Նկարեք դրանք որպես ձևանմուշներ ([Միջանցքի ձևանմուշներ](topic:corridor-templates)); ձևանմուշները ըստ պիկետի դեռ չեն վերցնում գոտիների թեքում |
| Աստիճանական փոփոխություն երկու տարածաշրջանների ձևանմուշների միջև (անցումներ, նեղացումներ) | Փոխեք ձևանմուշը պիկետում, կամ տվեք լայնության թիրախ կետին դեպի գիծ, որը գծված է որպես նեղացում |
| Պտույտ եզրի շուրջ, գոտիների թեքում LandXML-ում | Գոտիների թեքումը պտտվում է կենտրոնական գծի շուրջ շրջանաձև կորերի վրա; լայնացրեք գոտին լայնության թիրախով դեպի բնութագրային գիծ |
| Թիրախներ լանջերի համար (լուսաբացում դեպի գիծ կամ մակերևույթ), միջանցքի սեփական մակերևույթներ | Թիրախները տեղափոխում են ծածկույթի եզրերը և ուսնակները ([Միջանցքներ](topic:corridor)); միջանցքը թեքվում է նախագծային մակերևույթի մեջ |
| Կորի պատյաններ, շրջադարձի գոտիներ և կղզիներ, որոնք թեքվում են հանգույցում; կողմնային ճանապարհի ծայրը, որը կտրվում է գլխավոր ճանապարհի եզրին շեղ անկյան տակ; արահետը, որը միացված է ճանապարհին պլանում՝ իր երկարության և մակերեսի մեջ | Միացված ճանապարհները միացվում են ուղղանկյունաբար՝ բացելով գլխավոր ճանապարհի եզրը և հարթեցնելով կողմնային ճանապարհը դրան ([Որտեղ ճանապարհները հանդիպում են](topic:corridor#where-roads-meet-roads-pads-and-paths)); արահետը կանգնում է ճանապարհի եզրին նախագծային մակերևույթում և 3D-ում |
| Միջանցքները LandXML ճանապարհների տեսքով; երկրորդ միջանցքը երթուղու վրա IFC արտահանման մեջ | Արտահանվում է նախագծային մակերևույթը |
| Տեղանքի ձևանմուշներ, որոնք փոխում են նախագծային մակերևույթը, 3D-ում կամ կտրվածքներում | Դրանք տալիս են յուրաքանչյուր շերտի մակերեսներն ու ծավալները ([Տեղանքի ձևանմուշներ](topic:corridor-templates#terrain-templates)) |
| Շարժվող հետքեր՝ արագությամբ, անվադողերի սահքով, ղեկավարման ժամանակով, ղեկավարվող կցորդներով կամ մարմնի ազատ տարածությամբ; ստանդարտ նախագծային մեքենաների գրադարան; շարժվող հետք, որը գծվում է մեքենան քաշելով | Ցածր արագությամբ շարժվող հետքեր բնութագրային գծի կամ երթուղու երկայնքով, ձեր սեփական մեքենայի չափերով ([Մեքենայի շարժվող հետքեր](topic:swept-paths)) |

## Հողաշարժ և ծավալներ

| Դեռ չկառուցված | Փոխարենը, այսօր |
|---|---|
| Նստարաններ, բաց բնութագրային գծեր, որոնք հարթեցվում են նախագծում, հարթեցում դեպի բնութագրային գիծ այլ տեղից | Փակեք բնութագրային գիծը ([Բնութագրային գծեր](topic:feature-lines)), կամ օգտագործեք այն որպես գոյություն ունեցող գետնի կոտրման գիծ |
| Բնութագրային գծի գագաթի ավելացում կամ հեռացում | Նորից գծեք գիծը, կամ ստեղծեք դրա աստիճանավոր օֆսեթը |
| Աղեղներ գծված կոտրման գծերում (գոտկետների միջով), պարույրներ բնութագրային գծերում | Գծեք բնութագրային գիծ աղեղներով և օգտագործեք այն որպես գոյություն ունեցող գետնի կոտրման գիծ |
| Հարթեցում մինչև հեռավորություն, նիշ կամ այլ մակերևույթ | Լուսաբացում միայն գոյություն ունեցող գետնին |
| Հարթակի անկյուն ավելացնել կամ հեռացնել | Ջնջեք հարթակը և նորից գծեք |

| Մուտքի հզորություն, ջրահոսքի տարածում, ջրահեռացման երթուղավորում, հիդրոգրաֆներ, էներգիայի կորուստներ, բացի մեկ հանգույցի գործակցից | Ստուգեք դրանք այլ ծրագրում․ հոսքերը, չափերը և ճնշման գծերը կան [Փոթորկային ջրահեռացում](topic:storm-drainage)-ում |
| Ջրհավաք տարածքներ PDF գծագրում, DWG-ում, DXF-ում կամ LandXML-ում; ջրհավաք տարածքներ մակերևույթից (ջրբաժաներ) | Գծեք ջրհավաք տարածքները ձեռքով․ դրանք պահվում են նախագծի ֆայլում |
| Խողովակների կատալոգներ, ոչ կլոր խողովակներ, ոչ ուղղաձիգ տուփերի կամ գլանների կառուցվածքներ (կոներ, աստիճաններ, նստարաններ), ջրահեռացման կատեգորիա գրադարանում | Կառուցվածքի տեսակները պարամետրերից ([Խողովակաշարային ցանց](topic:pipe-network)); խողովակներ տրամագծով |
| Խողովակներ պրոֆիլի տեսքում, կորավոր խողովակներ | Կարդացեք ներքին մակարդակները և ծածկույթը աջ վահանակում |

## GIS և կոորդինատային համակարգեր

| Դեռ չկառուցված | Փոխարենը, այսօր |
|---|---|
| File Geodatabase; KML-ի ոճեր, պատկերակներ, գետնային շերտեր և ցանցային կապեր | Նախ փոխարկեք GeoPackage, shapefile կամ GeoJSON; KML նշանները կարդացվում են առանց իրենց ոճերի |

| Պիտակների ոճեր (չափ, տեղադրում) և պիտակներ, որոնք խուսափում են իրար | Պիտակները մեկ չափի են և կարող են համընկնել, երբ օբյեկտները խիտ են |
| Ուղղաձիգ տվյալային մակարդակներ և geoid մոդելներ | Նիշերն օգտագործվում են այնպես, ինչպես ֆայլն է տալիս; ստուգեք ուղղաձիգ տվյալային մակարդակը ինքներդ |
| Ցանցային տեղաշարժեր՝ բացի NAD27-ից NAD83-ի վրա, որը առաջարկվում է տարածքով (OSTN15, NTv2՝ այլ տվյալների համար, երբ ավելացնում եք ֆայլը), մի քանի ցանց միաժամանակ, ուղղաձիգ ցանցեր | Ավելացրեք ցանցի ֆայլը ձեր տվյալների համար ինքներդ; մեկ ցանց նախագծի համար |
| Քարտեզի շերտեր DXF-ում կամ 3D արտահանումներում | Քարտեզի շերտերը գնում են PDF գծագրում, և DWG-ի կողքին՝ որպես նկար |

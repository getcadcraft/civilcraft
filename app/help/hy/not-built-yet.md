CivilCraft-ը վաղ փուլում է։ Այս էջը թվարկում է, թե ընթացիկ տարբերակը ինչ չի անում, որպեսզի դուք դրանք չփնտրեք։ Այստեղ որևէ բան չի խոստացվում որևէ ամսաթվի համար։

## Կետեր

| Դեռ չկառուցված | Փոխարենը, այսօր |
|---|---|
| Երկրորդ կետային ֆայլը առաջինին ավելացնելը | Նախ միացրեք ֆայլերը տեքստային խմբագրիչում կամ աղյուսակում |
| Կետային տեքստային ֆայլի արտահանում | Արտահանեք LandXML (կետերը դուրս են գալիս որպես CgPoints), օգտագործեք GIS {{ui:Export}} (կետերը՝ P, N, E, Z և D դաշտերով), կամ {{ui:Copy}} արեք կետերը աղյուսակի մեջ |
| Կետերի պիտակների ոճեր, նկարագրության բանալիներով խորհրդանիշներ, կորեր (աղեղներ) գծային կոդերից, նախագծերի միջև կիսվելու համար նկարագրության բանալիների ֆայլ | Պիտակները ցույց են տալիս համարը, բարձրությունը և նկարագրությունը, կամ ավելի քիչ ([CivilCraft-ի կարգավորումներ](topic:settings)); բանալիները պահվում են նախագծի ֆայլում |
| Միավորների փոխարկում | Փոխարկեք ֆայլը նախքան ներմուծելը․ **Միավորները** միայն անվանափոխում են |

## Մակերևույթներ

| Դեռ չկառուցված | Փոխարենը, այսօր |
|---|---|
| Մեկից ավելի մակերևույթ կետերից | Մեկ նախագիծ յուրաքանչյուր մակերևույթի համար |
| Ներքին սահմանների թաքցնելը | Օգտագործեք **Longest outside edge** կամ արտաքին սահման |
| Գծված մեկ կոտրման գծի ընտրում կամ խմբագրում | {{key:Mod+Z}}, կամ {{ui:Remove drawn breaklines}} և նորից գծել |
| LandXML-ից կարդացված մակերևույթի խմբագրում (կոտրման գծեր, սահման) | {{ui:Rebuild the surface from the points}} |
| Բարձրության ցանցից ստեղծված մակերևույթի խմբագրում | Նորից ներմուծեք ցանցը այլ ընտրանքներով |
| LandXML-ից կարդացված մակերևույթի փոխարկում, երբ կոորդինատային համակարգը փոխվում է | Նախ {{ui:Rebuild the surface from the points}} |
| Պիտակավորված կետային բարձրություններ և թեքության արժեքներ | Կարդացեք դրանք կարգավիճակի տողում, կամ գունավորեք մակերևույթը թեքությամբ՝ **Թեքության վերլուծություն**-ով Լանդշաֆտ աշխատանքային տարածքում ([Լանդշաֆտի ուղղաձիգ հարթեցում](topic:landscape-grading#grading-checks)) |

## Երթուղիներ և պրոֆիլներ

| Դեռ չկառուցված | Փոխարենը, այսօր |
|---|---|
| Պարույրներ, բացի կլոտոիդից; պարույր երկու կորերի միջև (բաղադրյալ անցումներ) | Կլոտոիդ պարույրները հասանելի են կորի ծայրերում; մյուսները անվանվում և բաց են թողնվում LandXML ներմուծման ժամանակ |
| PI տեղադրում երկու այլ PI-ների միջև | Նորից գծեք երթուղին, կամ նորից մուտքագրեք PI-ի կոորդինատները |
| Երթուղիներ օբյեկտներից, օֆսեթներ, լայնացումներ | Գծեք PI-ներով |
| K մուտքագրելը ուղղաձիգ կորի համար | Մուտքագրեք L (K-ն է ցուցադրվում) |
| Շրջանաձև և ոչ սիմետրիկ ուղղաձիգ կորեր | Միայն սիմետրիկ պարաբոլիկ կորեր |
| Մեկից ավելի նախագծային պրոֆիլ մեկ երթուղու համար | Մեկ երթուղի յուրաքանչյուր տարբերակի համար |
| Պրոֆիլի տեսքի մասշտաբավորում, պրոֆիլի տակ գոտիներ | Պրոֆիլի տեսքը տեղավորում է ամբողջ երթուղին; գծեք այն [պլանի և պրոֆիլի թերթերում](topic:plan-profile-sheets) |
| Կտրվածքներ DWG-ում կամ LandXML-ում | Կտրվածքի թերթեր PDF-ով; {{ui:CSV}}՝ տարածքների և ծավալների համար |
| Անկյան տակ նմուշային գծեր, կամ տարբեր լայնություններով նմուշային գծեր ճանապարհի երկայնքով | Մեկ լայնություն յուրաքանչյուր կողմում ամբողջ երթուղու համար |

## Միջանցքներ

| Դեռ չկառուցված | Փոխարենը, այսօր |
|---|---|
| Միջնաշերտեր, արգելքներ և գերբարձրացում, որ պտտում է ձևանմուշները | Գծեք դրանք որպես ձևանմուշներ ([Միջանցքի ձևանմուշներ](topic:corridor-templates)); կայանով ձևանմուշները դեռ չեն ընդունում գերբարձրացում |
| Աստիճանական փոփոխություն երկու տարածքի ձևանմուշների միջև (անցումներ, նեղացումներ) | Փոխեք ձևանմուշը կայանում, կամ տվեք կետին լայնության թիրախ՝ նեղացման տեսքով գծված գծին |
| Պտույտ եզրի շուրջ, գերբարձրացում LandXML-ում | Գերբարձրացումը պտտվում է կենտրոնական գծի շուրջ շրջանաձև կորերում; լայնացրեք գոտին լայնության թիրախով մինչև բնութագրող գիծ |
| Թիրախներ կողային թեքությունների համար (հատում գծին կամ մակերևույթին), միջանցքի սեփական մակերևույթներ | Թիրախները տեղափոխում են ասֆալտի և ուսի եզրերը ([Միջանցքներ](topic:corridor)); միջանցքը հարթեցվում է ձևավորված մակերևույթի մեջ |
| Միջանցքներ՝ որպես LandXML ճանապարհներ; երկրորդ միջանցք երթուղու վրա IFC արտահանման մեջ | Արտահանվում է ձևավորված մակերևույթը |
| Ձևանմուշներ, որոնք փոխում են ձևավորված մակերևույթը 3D-ում կամ կտրվածքներում | Դրանք տալիս են յուրաքանչյուր շերտի տարածքներ և ծավալներ ([Գետնի ձևանմուշներ](topic:corridor-templates#terrain-templates)) |
| Շրջագծեր արագությամբ, անիվի սահքով, ղեկավարման ժամանակով, ղեկավարվող կցորդներով կամ մարմնի ազատ տարածությամբ; ստանդարտ նախագծային մեքենաների գրադարան; շրջագիծ՝ քաշելով մեքենան | Ցածր արագության շրջագծեր բնութագրող գծի կամ երթուղու երկայնքով՝ ձեր սեփական մեքենայի չափերով ([Մեքենայի շրջագծեր](topic:swept-paths)) |

## Հարթեցում և ծավալներ

| Դեռ չկառուցված | Փոխարենը, այսօր |
|---|---|
| Նստարաններ, բաց բնութագրող գծեր, որ հարթեցվում են նախագծի մեջ, հարթեցում դեպի բնութագրող գիծ այլ տեղից | Փակեք բնութագրող գիծը ([Բնութագրող գծեր](topic:feature-lines)), կամ օգտագործեք այն որպես գոյություն ունեցող գետնի կոտրման գիծ |
| Բնութագրող գծի գագաթի ավելացում կամ հեռացում | Նորից գծեք գիծը, կամ արեք դրա աստիճանավոր օֆսեթ |
| Աղեղներ գծված կոտրման գծերում (հանույթի կետերով), պարույրներ բնութագրող գծերում | Գծեք բնութագրող գիծ աղեղներով և օգտագործեք այն որպես գոյություն ունեցող գետնի կոտրման գիծ |
| Հարթեցում մինչև հեռավորություն, բարձրություն կամ այլ մակերևույթ | Միայն դեպի գոյություն ունեցող գետինը |
| Հարթակի անկյուն ավելացնել կամ հեռացնել | Ջնջեք հարթակը և նորից գծեք |
| TIN-ից-TIN (պրիզմայի) ծավալներ, ցանցի բջջի չափի ընտրություն | Ցանցային մեթոդ, բջջի չափը ընտրվում է ձեզ համար |
| Ուռչում և կրճատում, հողաշերտ, ասֆալտի խորություններ | Կիրառեք գործակիցները հաշվետու թվերի վրա ինքներդ |
| Ազատ-տարածման և գերտարածման արժեքներ, տեղափոխում տարբեր երթուղիների միջև, գծագրի վրա դրված փոսեր և թափոնի տեղեր | Զանգվածի տեղափոխման դիագրամը՝ հավասարակշռության կետերով, տեղափոխված ծավալները և միջին հեռավորությունները |

## Խողովակաշարեր

| Դեռ չկառուցված | Փոխարենը, այսօր |
|---|---|
| Մեկից ավելի ցանց մեկ նախագծում | Առանձին նախագծեր անձրևաջրերի և կոյուղու համար |
| Ջրմուղներ՝ ջրի որակ և տարիք, կանոններով կառավարում, այլ փականների տեսակներ (հոսքի կառավարում, խեղդուկ, պահող), պոմպեր՝ հզորությամբ տրված, ճնշումից կախված պահանջարկ, Darcy–Weisbach տարբերակ, խողովակների կատալոգ՝ պատերի հաստություններով և ճնշման դասերով։ Ճնշման ցանցերի մնացած մասը լաբորատորիայում է՝ [Ջրմուղներ](topic:water-mains) | Ստուգեք դրանք ջրաբաշխման ծրագրերում; կոյուղու նախագծային հոսքերը [Կոյուղու նախագծային հոսքեր](topic:sanitary-design)-ում են |
| Կոյուղու հոսքեր ժամանակի ընթացքում (հիդրոգրաֆներ, դինամիկ երթուղավորում, պահեստավորում, պոմպեր, գերհոսքեր) | [Կոյուղու նախագծային հոսքեր](topic:sanitary-design)-ը տալիս է կայուն գագաթային հոսքը, որը օգտագործում է նախագծային թերթը |
| Մուտքի հզորություն, ծորակի տարածում, հետաձգված երթուղավորում, հիդրոգրաֆներ, էներգիայի կորուստներ՝ բացի մեկ հանգույցի գործակցից | Ստուգեք դրանք այլ ծրագրերում; հոսքերը, չափերը և գրավիտացիոն գծերը [Անձրևաջրերի հեռացում](topic:storm-drainage)-ում են |
| Ջրավազաններ PDF գծագրում, DWG, DXF կամ LandXML-ում; ջրավազաններ մակերևույթից (ջրբաժաններ) | Գծեք ջրավազանները ձեռքով; դրանք պահվում են նախագծի ֆայլում |
| Խողովակների կատալոգներ, ոչ շրջանաձև խողովակներ, ոչ ուղղահայաց կառույցներ (կոներ, աստիճաններ, նստարաններ), կառուցվածքի դաս գրադարանում | Կառույցի տեսակներ պարամետրերից ([Խողովակաշար](topic:pipe-network)); խողովակներ տրամագծով |
| Խողովակներ պրոֆիլի տեսքում, կորագիծ խողովակներ | Կարդացեք ներքին մակարդակները և ծածկույթը աջ վահանակում |

## GIS և կոորդինատային համակարգեր

| Դեռ չկառուցված | Փոխարենը, այսօր |
|---|---|
| File Geodatabase; KML ոճեր, պատկերակներ, գետնի վրայի ծածկույթներ և ցանցային հղումներ | Նախ փոխարկեք GeoPackage, shapefile կամ GeoJSON-ի; KML նշանները կարդացվում են առանց իրենց ոճերի |
| GIS օբյեկտների կամ դրանց հատկանիշների խմբագրում | Խմբագրեք դրանք GIS ծրագրում և նորից ներմուծեք։ Analyze վահանակը ստեղծում է նոր շերտեր (buffer, overlay, join, selection) և ավելացնում է մակերեսի և երկարության դաշտեր, բայց չի խմբագրում օբյեկտը տեղում |
| Ցանցային և ռաստերային վերլուծություն, բուֆերներ հարթ կամ քառակուսի ծայրերով և միակողմանի բուֆերներ, տողեր ավելացնել կամ ջնջել և դաշտի տեսակը փոխել աթրիբուտների աղյուսակում, ձեռքով դասի գույներ, ոճի լեգենդ գծագրերում | Օգտագործեք Select՝ օբյեկտներ ընտրելու և դրանցից շերտ ստեղծելու համար; հարթ ծայրերը չեն առաջարկվում։ Գունավորումը ըստ հատկանիշի և աթրիբուտների աղյուսակը կառուցված են. տե՛ս [Ոճավորել շերտը հատկանիշով](topic:gis-symbology) և [Աշխատել շերտի աթրիբուտների աղյուսակի հետ](topic:gis-table) |
| Պիտակների ոճեր (չափ, տեղադրում) և պիտակներ, որ խուսափում են միմյանցից | Պիտակները մեկ չափի են և կարող են համընկնել, երբ օբյեկտները խիտ են |
| Ուղղաձիգ տվյալներ և geoid մոդելներ | Բարձրությունները օգտագործվում են այնպես, ինչպես տալիս է ֆայլը․ ստուգեք ուղղաձիգ տվյալը ինքներդ |

| Քարտեզի շերտեր DXF-ում կամ 3D արտահանումներում | Քարտեզի շերտերը գնում են PDF գծագրին, իսկ DWG-ի կողքին՝ որպես նկար |

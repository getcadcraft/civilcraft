ປຸ່ມຕົວອັກສອນດຽວໃຊ້ໄດ້ເມື່ອທ່ານບໍ່ໄດ້ພິມໃນຊ່ອງ. ປຸ່ມລັດທີ່ມີ {{key:Mod}} ໃຊ້ Command ໃນ Mac ແລະ Ctrl ບ່ອນອື່ນ. ເບິ່ງເພີ່ມເຕີມ [Keys in the browser](common:keys).

## ໄຟລ໌ ແລະ ການແກ້ໄຂ

| ປຸ່ມ | ການກະທຳ |
|---|---|
| {{key:Mod+O}} | ເປີດໄຟລ໌ຈຸດ, LandXML ຫຼື ໂຄງການ |
| {{key:Mod+S}} | ບັນທຶກໂຄງການ (ດາວໂຫຼດໄຟລ໌ `.civilcraft.json`) |
| {{key:Mod+P}} | ພິມແຜນຜັງເປັນ PDF (ເປີດກ່ອງໂຕ້ຕອບການພິມ, ບໍ່ແມ່ນການພິມຂອງບຣາວເຊີ) |
| {{key:Mod+Z}} | ຍ້ອນກັບ |
| {{key:Mod+Y}} | ເຮັດຊ້ຳ |
| {{key:Delete}} | ລຶບຈຸດສຳຫຼວດ, ແນວທາງ, ແທ່ນ, ໂຄງສ້າງ, ທໍ່ ຫຼື PVI ທີ່ເລືອກ |
| {{key:Mod+C}} | ສຳເນົາຈຸດສຳຫຼວດທີ່ເລືອກ (ແລະ ເປັນແຖວຈຸດສຳລັບສະເປຣດຊີດ) |
| {{key:Mod+X}} | ຕັດຈຸດສຳຫຼວດທີ່ເລືອກ |
| {{key:Mod+V}} | ວາງຈຸດ: ມັນຕາມຕົວຊີ້, ຄລິກບ່ອນທີ່ມັນຈະໄປ |
| {{key:Mod+Shift+V}} | ວາງໃນທີ່ເດີມ: ຢູ່ພິກັດຂອງຈຸດເອງ |
| {{key:Mod+D}} | ສ້າງສຳເນົາຈຸດທີ່ເລືອກ: ສຳເນົາຕາມຕົວຊີ້ |
| {{key:Mod+A}} | ເລືອກຈຸດສຳຫຼວດທັງໝົດ |
| {{key:Esc}} | ບໍ່ເລືອກຫຍັງ (ແລະ ຍົກເລີກການວາງ) |

{{key:Mod+S}}, {{key:Mod+O}} ແລະ {{key:Mod+P}} ໃຊ້ໄດ້ເຖິງແມ່ນຕອນທ່ານກຳລັງພິມໃນຊ່ອງ. {{key:Mod+Z}} ແລະ {{key:Mod+Y}} ໃນຊ່ອງຂໍ້ຄວາມຈະຍ້ອນ ຫຼື ເຮັດຊ້ຳການພິມຂອງທ່ານແທນ, ຕາມປົກກະຕິ, ແລະ ເຊັ່ນດຽວກັນກັບ {{key:Mod+C}}, {{key:Mod+X}}, {{key:Mod+V}} ແລະ {{key:Mod+A}}: ໃນຊ່ອງພວກມັນສຳເນົາ, ຕັດ, ວາງ ແລະ ເລືອກຂໍ້ຄວາມຂອງມັນ. ເມື່ອຂໍ້ຄວາມຖືກເລືອກຢູ່ໃນໜ້າ (ໃນແຜງ), {{key:Mod+C}} ສຳເນົາຂໍ້ຄວາມນັ້ນ. {{key:Mod+Shift+Z}} ບໍ່ເຮັດຫຍັງໃນ CivilCraft: ໃຫ້ໃຊ້ {{key:Mod+Y}} ຫຼື ປຸ່ມ {{ui:ເຮັດຊ້ຳ}}.

:::mac
ປຸ່ມ Mac ທີ່ມີປ້າຍ **delete** ແມ່ນ {{key:Backspace}} ສຳລັບບຣາວເຊີ. ເພື່ອລຶບການເລືອກ, ກົດ {{key:Delete}} (Fn ແລະ delete), ຫຼື ເລືອກ {{ui:ລຶບ}} ໃນເມນູ {{ui:ເພີ່ມເຕີມ}} ຂອງແຖບເຄື່ອງມື.
:::

## ມຸມມອງແຜນຜັງ

| ປຸ່ມ ຫຼື ການກະທຳ | ຜົນ |
|---|---|
| ລໍ້ | ຊູມເຂົ້າ ຫຼື ອອກ ຢູ່ຕົວຊີ້ |
| ລາກບ່ອນຫວ່າງ | ເລື່ອນມຸມມອງ (ໃນເຄື່ອງມືໃດກໍໄດ້; ການຄລິກສັ້ນຍັງຄລິກຢູ່; ຖ້າກົດ {{key:Shift}} ຄ້າງໄວ້ມັນຈະແຕ້ມກ່ອງເລືອກແທນ) |
| ລາກດ້ວຍປຸ່ມກາງ | ເລື່ອນມຸມມອງ |
| ລາກດ້ວຍປຸ່ມຂວາ | ເລື່ອນມຸມມອງ (ບໍ່ມີເມນູເປີດ) |
| {{key:Space}} ແລະ ລາກ | ເລື່ອນມຸມມອງ |
| ຄລິກ | ເລືອກ (ດ້ວຍ {{ui:ເລືອກ}}), ຫຼື ວາງຈຸດ (ດ້ວຍເຄື່ອງມືແຕ້ມ) |
| {{key:Shift}} ແລະ ຄລິກ | ເພີ່ມຈຸດສຳຫຼວດເຂົ້າໃນການເລືອກ, ຫຼື ເອົາອອກ |
| {{key:Shift}} ແລະ ລາກ | ແຕ້ມກ່ອງ: ຈຸດສຳຫຼວດທີ່ຢູ່ໃນນັ້ນຈະຖືກເພີ່ມເຂົ້າໃນການເລືອກ. ລາກວົນຮອບພວກມັນເພື່ອໃຊ້ [lasso](topic:lasso-selection) |
| {{key:Space}} ຕອນແຕ້ມ lasso | ໜ້າຕ່າງ, ແລ້ວຂ້າມ, ແລ້ວຮົ້ວ |
| ຄລິກຕອນວາງ | ວາງຈຸດທີ່ວາງໄວ້ບ່ອນນັ້ນ ({{key:Enter}} ວາງພວກມັນທີ່ພິກັດຂອງຕົນເອງ) |
| ລາກຈຸດຈັບ | ຍ້າຍ PI, ມຸມແທ່ນ ຫຼື ໂຄງສ້າງ (ໜຶ່ງຂັ້ນຍ້ອນກັບ) |
| {{key:Up}} {{key:Down}} {{key:Left}} {{key:Right}} | ເລື່ອນມຸມມອງ, ເມື່ອແຜນຜັງມີໂຟກັດ (ຄລິກກ່ອນ) |

## ມຸມມອງໜ້າຕັດຕາມຍາວ

| ການກະທຳ | ຜົນ |
|---|---|
| ຄລິກເມື່ອ {{ui:ເພີ່ມ PVI}} ເປີດ | ເພີ່ມ PVI ຕຳແໜ່ງນັ້ນ |
| ຄລິກ PVI | ເລືອກມັນ |

| {{key:Delete}} ຫຼື {{key:Backspace}} | ລຶບ PVI ທີ່ເລືອກ ({{key:Backspace}} ເທົ່ານັ້ນເມື່ອມຸມມອງໜ້າຕັດຕາມຍາວມີໂຟກັດ) |

ມຸມມອງໜ້າຕັດຕາມຍາວບໍ່ຊູມ ຫຼື ເລື່ອນ.

## ໜ້າຈໍ ແລະ ວິທີໃຊ້

| ປຸ່ມ | ການກະທຳ |
|---|---|
| {{key:F1}} | ເປີດ ຫຼື ປິດວິທີໃຊ້ນີ້ (ແຜງດ້ານຂ້າງ); {{ui:ວິທີໃຊ້}} ໃນແຖບແອັບເຮັດແບບດຽວກັນ |
| {{key:Esc}} | ປິດແຜງວິທີໃຊ້ເມື່ອມັນເປີດຢູ່ |
| {{key:Ctrl+Shift+F}} | ສະຫຼັບໂໝດໜ້າຈໍ: ເຕັມຈໍ, ເຕັມຈໍທີ່ເຊື່ອງແຖບ, ປົກກະຕິ |
| {{key:Esc}} | ອອກຈາກເຕັມຈໍ (ປຸ່ມຂອງບຣາວເຊີເອງ) |

{{key:F1}} ໄປຮອດວິທີໃຊ້ກ່ອນທີ່ CivilCraft ຈະເຫັນ, ດັ່ງນັ້ນມັນໃຊ້ໄດ້ໃນເຄື່ອງມືໃດກໍໄດ້. ໃນແປ້ນພິມ Mac ສ່ວນໃຫຍ່, ກົດ fn ກັບ F1, ຫຼື ຄລິກ {{ui:ວິທີໃຊ້}}. {{key:Ctrl+Shift+F}} ໃຊ້ປຸ່ມ Control ໃນທຸກແພລັດຟອມ, ລວມທັງ Mac. ເບິ່ງ [Using help](common:help) ສຳລັບວິທີຄົ້ນຫາວິທີໃຊ້ນີ້.

## ເມົາສ໌, trackpad ແລະ ໜ້າຈໍສຳຜັດ

:::mouse
- ລໍ້ຊູມຢູ່ຕົວຊີ້. ເມົາສ໌ທີ່ມີລໍ້ໝຸນອິດສະຫຼະຈະຊູມໄວ: ໃຫ້ໝຸນສັ້ນໆ.
- ເລື່ອນມຸມມອງດ້ວຍການລາກບ່ອນຫວ່າງໃດກໍໄດ້, ປຸ່ມກາງ, ປຸ່ມຂວາ, ຫຼື {{key:Space}} ແລະ ລາກ.
:::

:::mac
ໃນ trackpad ຂອງ Mac:

- ການເລື່ອນດ້ວຍສອງນິ້ວ **ຊູມ** (ມັນບໍ່ເລື່ອນມຸມມອງ), ແລະ ການບີບກໍຊູມເຊັ່ນກັນ.
- ເພື່ອເລື່ອນມຸມມອງ, ກົດ ແລະ ລາກບ່ອນຫວ່າງດ້ວຍນິ້ວດຽວ, ຫຼື ຖື {{key:Space}} ແລ້ວລາກ.
- ການຄລິກດ້ວຍສອງນິ້ວ (ຄລິກຂວາ) ບໍ່ເປີດເມນູ ແລະ ບໍ່ເຮັດຫຍັງດ້ວຍຕົວມັນເອງ.
:::

:::touch
ໃນໜ້າຈໍສຳຜັດ:

- ການສຳຜັດຄັ້ງທຳອິດເຮັດໃຫ້ປຸ່ມ ແລະ ແຖວເມນູມີຂະໜາດເທົ່ານິ້ວ.
- ແຕະເພື່ອເລືອກ ຫຼື ວາງຈຸດ; ນິ້ວດຽວທີ່ລາກບ່ອນຫວ່າງຈະເລື່ອນມຸມມອງ. ການແຕະອາດສັ່ນໜ້ອຍໜຶ່ງ: ມັນຈະເລື່ອນມຸມມອງພຽງເມື່ອນິ້ວເຄື່ອນປະມານ 10 pixels.
- ສອງນິ້ວບີບເພື່ອຊູມ ແລະ ເຄື່ອນນຳກັນເພື່ອເລື່ອນມຸມມອງ.
- ລາກຈຸດຈັບ ຫຼື PVI ດ້ວຍນິ້ວດຽວ. ຈຸດຈັບຮັບພື້ນທີ່ເທົ່າຄວາມກວ້າງນິ້ວອ້ອມຮອບ.
- ຕອນທ່ານແຕ້ມແນວທາງ, ແທ່ນ, ເສັ້ນຕັດຂອບ, ຂອບເຂດ, ເສັ້ນທໍ່, ເສັ້ນລັກສະນະ ຫຼື ຕອນດິນ, ແຖບເທິງແຜນຜັງສະເໜີ {{ui:ສຳເລັດ}} ({{key:Enter}}), {{ui:ຍ້ອນຈຸດ}} ({{key:Backspace}}) ແລະ {{ui:ຍົກເລີກ}} ({{key:Esc}}). ການກົດຄ້າງ (ເຄິ່ງວິນາທີໂດຍບໍ່ເຄື່ອນ) ກໍສຳເລັດເຊັ່ນກັນ.
- ໃນ {{ui:ເລືອກ}}, ການກົດຄ້າງທີ່ຈຸດສຳຫຼວດຈະເພີ່ມມັນເຂົ້າການເລືອກ, ຫຼື ເອົາອອກ, ຄືກັບ {{key:Shift}}+ຄລິກ.
- ໃນມຸມມອງ 3D, ນິ້ວດຽວໝຸນວົງ, ສອງນິ້ວບີບ ແລະ ເລື່ອນ, ແລະ ການແຕະຈະເລືອກ.
- ບໍ່ມີການຊີ້ໂດຍບໍ່ກົດໃນໜ້າຈໍສຳຜັດ, ດັ່ງນັ້ນຄ່າອ່ານໃນແຖບສະຖານະຈະອັບເດດພຽງຕອນທີ່ນິ້ວກົດຢູ່.
:::

## ປຸ່ມຂອງບຣາວເຊີທີ່ຊະນະ

ບາງປຸ່ມເປັນຂອງບຣາວເຊີ ແລະ ບໍ່ເຄີຍໄປຮອດ CivilCraft, ຕົວຢ່າງ {{key:Mod+W}} (ປິດແຖບ), {{key:Mod+T}} (ແຖບໃໝ່), {{key:Mod+N}} (ໜ້າຕ່າງໃໝ່) ແລະ {{key:F11}} (ເຕັມຈໍໃນບຣາວເຊີ Windows ແລະ Linux). CivilCraft ບໍ່ໃຊ້ມັນ. ຖ້າປຸ່ມລັດເປີດບາງຢ່າງໃນບຣາວເຊີແທນ, ໃຫ້ຄລິກແຜນຜັງໜຶ່ງເທື່ອເພື່ອໃຫ້ໜ້າມີໂຟກັດ, ແລ້ວລອງອີກຄັ້ງ.

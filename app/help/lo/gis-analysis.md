ເມື່ອໂຄງການມີເລເຢີ GIS ແລ້ວ (ເບິ່ງ [ນຳເຂົ້າຂໍ້ມູນ GIS](topic:gis-import)), ປຸ່ມ **ວິເຄາະ** ໃນກຸ່ມ GIS (ພິມ `GISANALYSIS`, `ANALYZE` ຫຼື `BUFFER`) ຈະເປີດແຜງທີ່ມີ 5 ແຖບ. ແຜງນີ້ເປີດຄ້າງໄວ້ຂ້າງແຜນຜັງ ດັ່ງນັ້ນສິ່ງທີ່ທ່ານເລືອກຈະຖືກແຕ້ມໃນແຜນຜັງໃນຂະນະທີ່ທ່ານເຮັດວຽກ.

ທຸກເຄື່ອງມືທີ່ສ້າງບາງສິ່ງ **ຈະເພີ່ມເລເຢີໃໝ່** ແລະ ປ່ອຍເລເຢີທີ່ມັນອ່ານໄວ້ໃຫ້ຄືເກົ່າ. ແຕ່ລະອັນເປັນຂັ້ນຕອນຍ້ອນກັບໜຶ່ງຄັ້ງ: {{ui:ຍ້ອນກັບ}} ໃນແຜງ (ຫຼື Ctrl+Z) ຈະລຶບເລເຢີໃໝ່ນັ້ນອອກ. ສົ່ງອອກຜົນລັບເໝືອນເລເຢີໃດໜຶ່ງດ້ວຍ [ສົ່ງອອກຂໍ້ມູນ as-built ສຳລັບ GIS](topic:gis-export) ເປັນ shapefile, GeoJSON ຫຼື GeoPackage.

ຕາຕະລາງຄຸນລັກສະນະຂອງເລເຢີແບບເຕັມ ພ້ອມການຈັດລຽງ, ການແກ້ໄຂ ແລະ ເຄື່ອງຄຳນວນຟີລ໌ດ ຢູ່ໃນ [ເຮັດວຽກກັບຕາຕະລາງຄຸນລັກສະນະຂອງເລເຢີ](topic:gis-table); ການໃສ່ສີຕາມຟີລ໌ດຢູ່ໃນ [ກຳນົດຮູບແບບເລເຢີຕາມຄຸນລັກສະນະ](topic:gis-symbology).

ທຸກຢ່າງເຮັດວຽກໃນແຜນຜັງ, ໃນໜ່ວຍຂອງໂຄງການ (feet ຫຼື meters). ໂຄງການຢູ່ໃນລະບົບພິກັດແບບ projected ຫຼື {{ui:ທ້ອງຖິ່ນ}} ສະເໝີ, ດັ່ງນັ້ນໄລຍະ 50 ໝາຍເຖິງ 50 feet ຫຼື 50 meters, ບໍ່ເຄີຍເປັນ degrees. ຄ່າລະດັບຄວາມສູງ (z) ບໍ່ຖືກເກັບໄວ້ໃນຜົນລັບ.

## ບັບເຟີ

ແຕ້ມເຂດໃນໄລຍະທີ່ກຳນົດອ້ອມແຕ່ລະຟີເຈີ ເປັນເລເຢີໂພລີກອນໃໝ່. ຈຸດກາຍເປັນວົງມົນ, ເສັ້ນກາຍເປັນທາງແຄບທີ່ປາຍມົນ, ໂພລີກອນຂະຫຍາຍອອກ. ໄລຍະ **ລົບ** ເຮັດໃຫ້ໂພລີກອນຫົດລົງ (ສີ່ຫຼ່ຽມ 100 × 100 ທີ່ຫົດດ້ວຍ 5 ເປັນ 90 × 90; ຫົດດ້ວຍ 60 ແມ່ນບໍ່ເຫຼືອຫຍັງເລີຍ ແລະ ແຜງຈະບອກແບບນັ້ນ). ໃຫ້ເອົາໄລຍະມາຈາກຟີລ໌ດຕົວເລກເພື່ອໃຫ້ແຕ່ລະຟີເຈີມີໄລຍະຂອງຕົນເອງ, ຫຼື ໃສ່ເຄື່ອງໝາຍ **ລວມບັບເຟີທັງໝົດເປັນຮູບດຽວ** ເພື່ອລະລາຍພວກມັນ.

ສ່ວນໂຄ້ງມົນແມ່ນເສັ້ນຊື່ທີ່ແຕ້ມຢູ່ດ້ານໃນຂອງເສັ້ນໂຄ້ງຈິງ, ດັ່ງນັ້ນບັບເຟີຈະນ້ອຍກວ່າວົງມົນທີ່ແທ້ຈິງເລັກນ້ອຍ: ປະມານ 0.6 % ໃນເນື້ອທີ່ທີ່ການຕັ້ງຄ່າປົກກະຕິ, 0.16 % ທີ່ Fine. ໃຫ້ໃຊ້ Fine ສຳລັບສິ່ງໃດກໍຕາມທີ່ທ່ານຈະວັດ.

## ການຊ້ອນທັບ

| ເຄື່ອງມື | ສິ່ງທີ່ທ່ານໄດ້ຮັບ |
|---|---|
| Intersect | ສ່ວນຕ່າງໆບ່ອນທີ່ເລເຢີປ້ອນເຂົ້າພົບກັບໂພລີກອນຊ້ອນທັບ, ແຕ່ລະອັນມີຟີລ໌ດຂອງທັງສອງ. ເສັ້ນ ແລະ ຈຸດຖືກຕັດໃຫ້ຢູ່ໃນໂພລີກອນ. |
| Union | ເລເຢີໂພລີກອນທັງສອງຖືກຕັດຕາມຂອບຂອງກັນແລະກັນ: ສ່ວນທີ່ໃຊ້ຮ່ວມກັນມີຟີລ໌ດຂອງທັງສອງເລເຢີ, ສ່ວນທີ່ເຫຼືອມີຟີລ໌ດຂອງເລເຢີດຽວ (ຟີລ໌ດຂອງອີກອັນຈະວ່າງ). |
| Erase | ໂພລີກອນປ້ອນເຂົ້າທີ່ເອົາໂພລີກອນຊ້ອນທັບອອກ. ຟີລ໌ດຍັງຢູ່ກັບປ້ອນເຂົ້າ. ຟີເຈີທີ່ຖືກລຶບອອກທັງໝົດຈະບໍ່ຖືກເກັບໄວ້ (ແຜງນັບຈຳນວນໃຫ້). |
| Dissolve | ລວມໂພລີກອນທີ່ສຳຜັດ ຫຼື ຊ້ອນກັນ, ທັງໝົດ ຫຼື ເປັນຮູບດຽວສຳລັບແຕ່ລະຄ່າຂອງຟີລ໌ດ. ເພີ່ມ `COUNT` ແລະ `AREA`. |

ຊື່ຟີລ໌ດທີ່ທັງສອງເລເຢີມີ ຈະຖືກເກັບໄວ້ສຳລັບເລເຢີທຳອິດ, ແລະ ຂອງເລເຢີທີສອງຈະຖືກຂຽນດ້ວຍ `_2`. ຟີເຈີພາຍໃນເລເຢີດຽວບໍ່ຄວນຊ້ອນກັນເອງ: ບ່ອນໃດທີ່ຊ້ອນ, Union ຈະນັບການຊ້ອນໃນທັງສອງ.

## ການເຊື່ອມໂຍງ

ການເຊື່ອມໂຍງຕາມພື້ນທີ່ຄັດລອກຄຸນລັກສະນະຈາກເລເຢີ **ຕົ້ນທາງ** ໄປໃສ່ແຕ່ລະຟີເຈີ **ເປົ້າໝາຍ** ທີ່ສຳຜັດກັບມັນ ແລະ ໃຫ້ເລເຢີໃໝ່ທີ່ມີຮູບຮ່າງຂອງເປົ້າໝາຍ. ເລືອກເວລາທີ່ພວກມັນພົບກັນ: ສຳຜັດ ຫຼື ຊ້ອນທັບ, ເປົ້າໝາຍຢູ່ພາຍໃນໂພລີກອນຕົ້ນທາງ, ເປົ້າໝາຍຖືຟີເຈີຕົ້ນທາງ, ຟີເຈີຕົ້ນທາງທີ່ໃກ້ທີ່ສຸດ (ມີຂີດຈຳກັດໄດ້), ຫຼື ຟີເຈີຕົ້ນທາງໃດກໍໄດ້ພາຍໃນໄລຍະໜຶ່ງ.

ເມື່ອຟີເຈີຕົ້ນທາງຫຼາຍອັນກົງກັນ ທ່ານຈະໄດ້ຄຸນລັກສະນະຂອງອັນທຳອິດ (ອັນທີ່ໃກ້ທີ່ສຸດ ສຳລັບການເຊື່ອມໂຍງແບບໃກ້ທີ່ສຸດ ແລະ ໄລຍະ; `DISTANCE` ຖືກເພີ່ມ), ຫຼື **ນັບພວກມັນ ແລະ ລວມຟີລ໌ດຕົວເລກຂອງພວກມັນ**: `COUNT`, ແລະ `SUM_`, `MEAN_`, `MIN_`, `MAX_` ສຳລັບແຕ່ລະຟີລ໌ດຕົວເລກ. ເອົາເຄື່ອງໝາຍອອກຈາກ **ເກັບຟີເຈີເປົ້າໝາຍທີ່ບໍ່ພົບການກົງກັນ** ເພື່ອຕັດພວກມັນອອກ. ຟີລ໌ດທີ່ເຊື່ອມໂຍງຈະວ່າງບ່ອນທີ່ບໍ່ມີການກົງກັນ, ແລະ ແຜງນັບຈຳນວນທີ່ບໍ່ກົງກັນ.

## ເລືອກ

ພິມຄຳຖາມກ່ຽວກັບຄຸນລັກສະນະ ຫຼື ຮູບຮ່າງ, ກົດ **ເລືອກ**, ແລະ ຟີເຈີຈະຖືກແຕ້ມໃນແຜນຜັງພ້ອມຈຳນວນ, ຕາຕະລາງ ແລະ ຜົນລວມຂອງເນື້ອທີ່, ຄວາມຍາວ ຫຼື ຈຳນວນ. ຈາກນັ້ນທ່ານສາມາດເຮັດໃຫ້ພວກມັນເປັນເລເຢີຂອງຕົນເອງ, ຊູມໄປຫາພວກມັນ ຫຼື ລຶບການເລືອກອອກ.

| ທ່ານສາມາດຂຽນ | ຕົວຢ່າງ |
|---|---|
| ຟີລ໌ດດ້ວຍຊື່; ໃຊ້ "ເຄື່ອງໝາຍຄຳຄູ່" ຫຼື [ວົງເລັບສີ່ຫຼ່ຽມ] ຖ້າຊື່ມີຊ່ອງຫວ່າງ | `VALUE`, `"Lot Number"` |
| ຕົວເລກ, 'ຂໍ້ຄວາມ', true, false, null | `Use_ = 'Res'` |
| `=` `!=` `<>` `<` `<=` `>` `>=` | `VALUE >= 250` |
| `contains` `startswith` `endswith` `like` `ilike` (ຂໍ້ຄວາມບໍ່ສົນໃຈຕົວພິມໃຫຍ່-ນ້ອຍ; ໃນ `like`, `%` ແມ່ນຫຼາຍຕົວອັກສອນໃດກໍໄດ້ ແລະ `_` ແມ່ນໜຶ່ງຕົວອັກສອນ) | `Notes contains 'corner'` |
| `is null`, `is not null` (ຄ່າວ່າງນັບເປັນ null) | `Notes is null` |
| `in (…)`, `not in (…)`, `between … and …` | `Use_ in ('Com', 'Ind')` |
| `+ - * /` ແລະ ວົງເລັບ | `VALUE / 2 > 100` |
| `and`, `or`, `not` | `Use_ = 'Res' and VALUE > 200` |
| ຄ່າຮູບຮ່າງ `$area` `$perimeter` `$length` `$x` `$y` `$vertices` | `$area > 5000` |

ຄຳຖາມທີ່ບໍ່ສົມບູນ ຫຼື ອ້າງຊື່ຟີລ໌ດທີ່ເລເຢີບໍ່ມີ ຈະຖືກປະຕິເສດດ້ວຍປະໂຫຍກທີ່ບອກວ່າຜິດຢູ່ໃສ.

## ວັດ

ສະແດງເນື້ອທີ່ ແລະ ເສັ້ນຮອບທັງໝົດ, ຄວາມຍາວ ຫຼື ຈຳນວນຂອງເລເຢີ, ແລະ **ເພີ່ມຟີລ໌ດ** ໃສ່ມັນ: `AREA` ແລະ `PERIMETER` ສຳລັບໂພລີກອນ, `LENGTH` ສຳລັບເສັ້ນ (ຄວາມຍາວໃນແຜນຜັງ), `X` ແລະ `Y` ສຳລັບຈຸດ. ຟີລ໌ດທີ່ມີຢູ່ແລ້ວຈະບໍ່ຖືກຂຽນທັບ: ອັນໃໝ່ຈະຊື່ `AREA_2`. ນີ້ແມ່ນຂັ້ນຕອນຍ້ອນກັບໜຶ່ງຄັ້ງ. **ສະຖິຕິ** ໃຫ້ຈຳນວນ, ຜົນບວກ, ຄ່າສະເລ່ຍ, ຄ່າຕ່ຳສຸດ ແລະ ສູງສຸດຂອງຟີລ໌ດຕົວເລກ, ແລະ ເລືອກໄດ້ໃຫ້ແຕ່ລະຄ່າຂອງຟີລ໌ດອື່ນ.

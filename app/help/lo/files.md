CivilCraft ເປີດໄຟລ໌ຈາກຄອມພິວເຕີຂອງທ່ານ ແລະ ບັນທຶກໂດຍດາວໂຫຼດໄຟລ໌ກັບມາທີ່ເຄື່ອງ. ບໍ່ມີການອັບໂຫຼດຫຍັງ ແລະ ບໍ່ມີຫຍັງຖືກເກັບໄວ້ເທິງເຊີບເວີ. ເບິ່ງເພີ່ມເຕີມ [ໄຟລ໌ຂອງທ່ານ](common:your-files).

## ສິ່ງທີ່ເປີດໄດ້

ກົດ {{ui:Open}} (ຫຼື ກົດ {{key:Mod+O}}) ແລ້ວເລືອກໄຟລ໌, ຫຼື ລາກໄຟລ໌ຈາກ {{pick:mac=Finder|windows=File Explorer|linux=ໂປຣແກຣມຈັດການໄຟລ໌ຂອງທ່ານ}} ມາວາງໃສ່ແຜນທີ່. ເປີດໄດ້ຄັ້ງລະໜຶ່ງໄຟລ໌; ໄຟລ໌ທີ່ໃຫຍ່ກວ່າ 200 MB ຈະຖືກປະຕິເສດ.

| ປະເພດ | ຊື່ໄຟລ໌ | ສິ່ງທີ່ເກີດຂຶ້ນ |
|---|---|---|
| ໄຟລ໌ຈຸດ | `.csv`, `.txt`, `.pnt`, `.xyz` (ໄຟລ໌ຂໍ້ຄວາມໃດກໍໄດ້) | ກ່ອງ **ນຳເຂົ້າຈຸດ** ເປີດຂຶ້ນ. ຈຸດຈະແທນທີ່ຈຸດຂອງໂຄງການ; ແນວທາງ, ແທ່ນ ແລະ ທໍ່ຍັງຄົງຢູ່. |
| LandXML | `.xml`, `.landxml` | ສ້າງ **ໂຄງການໃໝ່** ຈາກໄຟລ໌ (ຈະຖາມກ່ອນຖ້າໂຄງການປັດຈຸບັນມີການປ່ຽນແປງທີ່ຍັງບໍ່ໄດ້ບັນທຶກ). |
| ໄຟລ໌ໂຄງການ CivilCraft | `.civilcraft.json` (ໄຟລ໌ `.json` ໃດກໍໄດ້) | ໂຄງການເປີດຕາມທີ່ບັນທຶກໄວ້ (ຈະຖາມກ່ອນຖ້າໂຄງການປັດຈຸບັນມີການປ່ຽນແປງທີ່ຍັງບໍ່ໄດ້ບັນທຶກ). |

CivilCraft ຕັດສິນໃຈຈາກສ່ວນທ້າຍຂອງໄຟລ໌ ແລະ ຈາກຕົວອັກສອນທຳອິດ: ຂໍ້ຄວາມທີ່ເລີ່ມດ້ວຍ `{` ຖືກອ່ານເປັນໄຟລ໌ໂຄງການ, ທີ່ເລີ່ມດ້ວຍ `<` ເປັນ LandXML, ອັນອື່ນເປັນໄຟລ໌ຈຸດ. ໄຟລ໌ທີ່ກ່ອງເປີດເຮັດເປັນສີເທົາ ຍັງສາມາດລາກມາວາງໃສ່ແຜນທີ່ໄດ້.

:::note
ການນຳເຂົ້າໄຟລ໌ຈຸດໃສ່ໂຄງການທີ່ມີຈຸດຢູ່ແລ້ວ ຈະແທນທີ່ຈຸດເຫຼົ່ານັ້ນໂດຍບໍ່ຖາມ, ແລະ ຈະລຶບປະຫວັດການຍ້ອນກັບ (ການເປີດໄຟລ໌ໃດກໍຕາມແມ່ນເລີ່ມໃໝ່ສຳລັບການຍ້ອນກັບ). ຖ້າພື້ນຜິວມາຈາກ LandXML, ການນຳເຂົ້າຈຸດຈະປ່ຽນມັນກັບໄປເປັນພື້ນຜິວທີ່ສ້າງຈາກຈຸດ. ບັນທຶກກ່ອນ ຖ້າທ່ານອາດຢາກໄດ້ຈຸດເກົ່າຄືນ.
:::

ລາຍລະອຽດ: [ຮູບແບບໄຟລ໌ຈຸດ](topic:point-file-formats), [LandXML: ອ່ານ ແລະ ຂຽນຫຍັງແດ່](topic:landxml-reference).

## ສິ່ງທີ່ບັນທຶກ

{{ui:Save}} ({{key:Mod+S}}) ຂຽນໄຟລ໌ສອງອັນຄຽງຂ້າງກັນ, ຕັ້ງຊື່ຕາມ **Name** ໃນແຜງດ້ານຊ້າຍ: `<name>.civilcraft.json`, ໂຄງການທີ່ທ່ານຈະແກ້ໄຂຕໍ່ໄປ, ແລະ `<name>.ifc`, ແບບດຽວກັນໃນຮູບແບບ IFC 4.3 ສຳລັບແອັບອື່ນ (ເບິ່ງ [ການສົ່ງອອກ ແລະ ນຳເຂົ້າ IFC](topic:ifc)). ແຕ່ລະໄຟລ໌ບັນທຶກອີກອັນໄວ້, ແລະ IFC ຍັງມີສຳເນົາທີ່ຖືກບີບອັດຂອງໂຄງການ, ດັ່ງນັ້ນ IFC ທີ່ສົ່ງໂດຍລຳພັງກໍຍັງເປີດໄດ້ຄົບ ແລະ ແກ້ໄຂໄດ້.

- **ໃນ Studio** ທັງສອງໄຟລ໌ຖືກຂຽນໄວ້ຄຽງຂ້າງກັນ, ໃນຕຳແໜ່ງເດີມ.
- **ໃນ Chrome ແລະ Edge** ການບັນທຶກຄັ້ງທຳອິດຈະຖາມຫາໂຟນເດີ ແລ້ວຂຽນທັງສອງເຂົ້າໄປ; ການບັນທຶກຄັ້ງຕໍ່ໄປຈະໄປທີ່ໂຟນເດີດຽວກັນ. ຍົກເລີກຄຳຖາມກ່ຽວກັບໂຟນເດີ ເພື່ອດາວໂຫຼດທັງສອງແທນ.
- **ໃນ browser ອື່ນໆ** ທັງສອງໄຟລ໌ຖືກດາວໂຫຼດ, ໄຟລ໌ໂຄງການກ່ອນ.

ການເປີດໄຟລ໌ໃດກໍຕາມຈະຊອກຫາອີກອັນ. ເປີດທັງສອງພ້ອມກັນ (ຫຼື ລາກມາວາງທັງສອງ), ຫຼື ເປີດອັນດຽວ: ໃນ Studio ຈະພົບອີກອັນໃນໂຟນເດີດຽວກັນ; ໃນ browser CivilCraft ຈະຖາມໃຫ້ເພີ່ມມັນ, ຫຼື ໃຫ້ດຳເນີນຕໍ່ດ້ວຍອັນທີ່ມີ. ຖ້າ IFC ຖືກປ່ຽນໂດຍໂປຣແກຣມອື່ນຫຼັງຈາກ CivilCraft ບັນທຶກມັນ, ຫຼື ໜຶ່ງໃນໄຟລ໌ເກົ່າກວ່າອີກອັນ, ໂຄງການຈະເປີດຈາກແບບທີ່ໃໝ່ກວ່າ ແລະ ແຜງບັນຫາຈະບອກວ່າເກີດຫຍັງຂຶ້ນ, ພ້ອມ **ບັນທຶກດຽວນີ້** (ຂຽນທັງສອງໄຟລ໌ຄືນ) ແລະ **ສະແດງຮູບຮ່າງຂອງ IFC ເປັນເອກະສານອ້າງອີງ**. IFC ດ່ຽວໆທີ່ໂປຣແກຣມອື່ນປ່ຽນແປງຈະເປີດຈາກສຳເນົາໂຄງການຂອງມັນ ໂດຍໃຊ້ສ່ວນທີ່ຍັງກົງກັນ: ແນວທາງທີ່ມັນປ່ຽນຈະໃຊ້ຮູບຮ່າງຂອງມັນ, ວັດຖຸທີ່ມັນລຶບອອກຈະຖືກຕັດອອກ, ແລະ ການປ່ຽນແປງທີ່ເຫຼືອຈະຖືກລາຍການໄວ້ ແຕ່ບໍ່ຖືກນຳໃຊ້. ໄຟລ໌ໂຄງການກ່ອນ 0.7.1 ຍັງເປີດຕາມເກົ່າ.

ໄຟລ໌ໂຄງການເກັບ:

- ທຸກຈຸດ (ໝາຍເລກ, ພິກັດ, ລະດັບຄວາມສູງ, ລາຍລະອຽດ) ແລະ ຊື່ໄຟລ໌ຈຸດທີ່ມາຈາກ
- ການຕັ້ງຄ່າພື້ນຜິວ: ການເລືອກກຸ່ມ, ເສັ້ນຕັດຂອບທີ່ແຕ້ມແລ້ວ, ຂອບເຂດ, ຂອບນອກທີ່ຍາວທີ່ສຸດ, ແລະ TIN ທີ່ອ່ານຈາກ LandXML
- ການຕັ້ງຄ່າການສະແດງຜົນ
- ແນວທາງພ້ອມ PI, ລັດສະໝີ ແລະ ສະຖານີເລີ່ມຕົ້ນ, ໜ້າຕັດຕາມຍາວອອກແບບ (PVI ແລະ ຄວາມຍາວເສັ້ນໂຄ້ງ) ແລະ ການຕັ້ງຄ່າຄໍຣິດໍ
- ແທ່ນ ແລະ ເຄືອຂ່າຍທໍ່ພ້ອມກົດລະບຽບ

ມັນບໍ່ເກັບປະຫວັດການຍ້ອນກັບ. ພື້ນຜິວ, ເສັ້ນຊັ້ນລະດັບ, ເສັ້ນ daylight ແລະ ປະລິມານ ບໍ່ຖືກເກັບໄວ້; ພວກມັນຖືກສ້າງຄືນຈາກຂໍ້ມູນທີ່ບັນທຶກໄວ້ເມື່ອໂຄງການເປີດ. ໄຟລ໌ໂຄງການຈາກ CivilCraft ທີ່ໃໝ່ກວ່າຈະຖືກປະຕິເສດ ດ້ວຍຂໍ້ຄວາມທີ່ລະບຸສະບັບຂອງມັນ.

## ບ່ອນທີ່ໄຟລ໌ໄປ

ໄຟລ໌ທີ່ບັນທຶກ ແລະ ສົ່ງອອກຈະໄປບ່ອນທີ່ browser ຂອງທ່ານເກັບການດາວໂຫຼດ, ໂດຍປົກກະຕິແມ່ນໂຟນເດີ Downloads. ເພື່ອເລືອກໂຟນເດີທຸກຄັ້ງ:

:::chromium
ເປີດ **ການຕັ້ງຄ່າ** ຂອງ browser, ແລ້ວ **ດາວໂຫຼດ**, ແລະ ເປີດ **ຖາມວ່າຈະບັນທຶກແຕ່ລະໄຟລ໌ໄວ້ໃສ ກ່ອນດາວໂຫຼດ**.
:::

:::firefox
ເປີດ **ການຕັ້ງຄ່າ**, ແລ້ວ **ທົ່ວໄປ**, ແລະ ພາຍໃຕ້ **ໄຟລ໌ ແລະ ແອັບພລິເຄຊັນ** ເລືອກ **ຖາມທຸກຄັ້ງວ່າຈະບັນທຶກໄຟລ໌ໄວ້ໃສ**.
:::

:::safari
ເປີດ **Safari > ການຕັ້ງຄ່າ > ທົ່ວໄປ** ແລະ ຕັ້ງ **ບ່ອນດາວໂຫຼດໄຟລ໌** ເປັນ **ຖາມສຳລັບທຸກການດາວໂຫຼດ**.
:::

ຖ້າທ່ານບັນທຶກສອງຄັ້ງດ້ວຍຊື່ດຽວກັນ, browser ອາດເພີ່ມໝາຍເລກໃສ່ໄຟລ໌ທີສອງ, ຕົວຢ່າງ `Site (1).civilcraft.json`. ຄັ້ງໜ້າໃຫ້ເປີດອັນທີ່ໃໝ່ສຸດ.

## ອອນໄລນ໌ ແລະ ອອບໄລນ໌

CivilCraft ເຮັດວຽກພຽງໃນຄອມພິວເຕີຂອງທ່ານບໍ່ວ່າຈະແນວໃດ: ການເປີດອ່ານໄຟລ໌ໃນ browser, ການບັນທຶກດາວໂຫຼດມັນ. ເພື່ອເປີດ CivilCraft ໂດຍບໍ່ມີການເຊື່ອມຕໍ່ເລີຍ, ໃຫ້ບັນທຶກສຳລັບໃຊ້ແບບອອບໄລນ໌ກ່ອນ:

1. ໃນຂະນະທີ່ອອນໄລນ໌, ກົດ {{ui:Save for offline}} ໃນ ແຖບແອັບ ດ້ານເທິງ.
2. ປຸ່ມຈະນັບເພີ່ມ ("ກຳລັງບັນທຶກ 12 ຈາກ 30") ແລ້ວສະແດງ {{ui:Offline ready}}. CivilCraft ມີຂະໜາດນ້ອຍ (ປະມານ 0.6 MB), ດັ່ງນັ້ນໃຊ້ເວລາໜ້ອຍໜຶ່ງ. ສຳເນົາທີ່ບັນທຶກລວມເຖິງຄູ່ມືນີ້ ແລະ ສະຖານທີ່ຕົວຢ່າງ.
3. ເມື່ອບໍ່ມີການເຊື່ອມຕໍ່, ເປີດທີ່ຢູ່ດຽວກັນ (ຫຼື bookmark ຂອງມັນ). ທຸກຢ່າງເຮັດວຽກ, ລວມທັງ {{ui:Open the sample site}}.

ປຸ່ມມີສະຖານະອື່ນດັ່ງນີ້:

- {{ui:Could not save}}: ໄຟລ໌ບາງອັນດາວໂຫຼດບໍ່ສຳເລັດ. ກວດການເຊື່ອມຕໍ່ ແລະ ກົດມັນເພື່ອລອງອີກ.
- {{ui:Offline not available}}: ໜ້າຕ່າງ browser ນີ້ບໍ່ສາມາດເກັບສຳເນົາອອບໄລນ໌ໄດ້ (ໜ້າຕ່າງສ່ວນຕົວ ແລະ ຄອມພິວເຕີທີ່ຈັດການບາງເຄື່ອງຈະບລັອກມັນ). ໃຊ້ໜ້າຕ່າງປົກກະຕິ.

ກົດ {{ui:Offline ready}} ເພື່ອເບິ່ງວ່າສຳເນົາຖືກບັນທຶກເມື່ອໃດ, ມີສອງທາງເລືອກ: {{ui:Save again (get the newest version)}} ແລະ {{ui:Remove the offline copy}}. ບັນທຶກອີກຄັ້ງກ່ອນໄປຢ້ຽມຢາມສະຖານທີ່, ເພື່ອໃຫ້ສຳເນົາກົງກັບ build ໃໝ່ສຸດ. ເພີ່ມເຕີມໃນ [ອອບໄລນ໌](common:offline).

:::offline
ຕອນນີ້ທ່ານອອບໄລນ໌. ຖ້າ CivilCraft ຖືກບັນທຶກສຳລັບໃຊ້ແບບອອບໄລນ໌, ທຸກຢ່າງເຮັດວຽກ, ລວມທັງສະຖານທີ່ຕົວຢ່າງ. ຖ້າບໍ່ໄດ້, ໃຫ້ເຮັດວຽກຕໍ່ໃນແຖບນີ້, ແຕ່ຢ່າ reload ຈົນກວ່າຈະອອນໄລນ໌ອີກຄັ້ງ; ຖ້າບໍ່ມີສຳເນົາທີ່ບັນທຶກໄວ້, {{ui:Open the sample site}} ຈະລົ້ມເຫຼວດ້ວຍຂໍ້ຄວາມ "ບໍ່ສາມາດໂຫຼດຕົວຢ່າງໄດ້".
:::

:::tip
ສຳລັບການໃຊ້ງານໃນສະຖານທີ່, ໃຫ້ບັນທຶກ CivilCraft ສຳລັບໃຊ້ແບບອອບໄລນ໌ ແລະ ເອົາໄຟລ໌ຈຸດການວັດແທກຂອງທ່ານໄປໄວ້ໃນແລັບທັອບເອງ. ໂຄງການ ແລະ ການສົ່ງອອກຈະບັນທຶກເປັນການດາວໂຫຼດໂດຍບໍ່ຕ້ອງມີການເຊື່ອມຕໍ່, ດັ່ງນັ້ນທ່ານສາມາດນຳເຂົ້າການວັດແທກຂອງມື້ນັ້ນ, ກວດພື້ນຜິວ ແລະ ບັນທຶກໂຄງການຢູ່ສະຖານທີ່.
:::

ຍັງບໍ່ມີການບັນທຶກເທິງຄລາວ, ແລະ build ສຳລັບ desktop ກໍຍັງບໍ່ອອກ. ໃນປັດຈຸບັນ, ໄຟລ໌ທີ່ທ່ານບັນທຶກແມ່ນສຳເນົາດຽວເທົ່ານັ້ນ: ໃຫ້ເກັບໄວ້ບ່ອນທີ່ມີການສຳຮອງຂໍ້ມູນ.

## ສ່ວນເສີມທີ່ໄຟລ໌ໃຊ້

ເມື່ອທ່ານບັນທຶກໂຄງການທີ່ມີຂໍ້ມູນຈາກສ່ວນເສີມ (ຊ່ອງໝາຍ ກົດລະບຽບອາຄານ, ຫຼື ແຫຼ່ງ ທີ່ຢູ່ເຖິງສະຖານທີ່), ໄຟລ໌ຈະບັນທຶກວ່າສ່ວນເສີມໃດ ແລະ ສະບັບໃດ. ເປີດມັນໃນຄອມພິວເຕີທີ່ບໍ່ມີສ່ວນເສີມນັ້ນ, ແຖບທີ່ຢູ່ເໜືອແຜນທີ່ຈະບອກ ແລະ ສະເໜີໃຫ້ເພີ່ມມັນຈາກລາຍການໃນບັນຊີຂອງທ່ານ. ບັນທຶກນີ້ເປັນພຽງໝາຍເຫດ: ໄຟລ໌ເປີດໄດ້ທັງສອງທາງ.

## ຍ້ອນກັບຈາກ Studio

ພາຍໃນ CadCraft Studio, ແຕ່ລະຂັ້ນຕອນທີ່ທ່ານສຳເລັດໃນ CivilCraft ຈະຖືກແຈ້ງໃຫ້ Studio ຮູ້, ເພື່ອໃຫ້ການຍ້ອນກັບລະດັບໂຄງການຂອງມັນສາມາດຍ້ອນຂັ້ນຕອນລ່າສຸດຂ້າມແອັບໄດ້. Studio ຈະຍ້ອນຂັ້ນຕອນໜຶ່ງກໍຕໍ່ເມື່ອສະແຕັກການຍ້ອນກັບຂອງ CivilCraft ເອງຢູ່ໃນສະພາບດຽວກັບທີ່ຂັ້ນຕອນນັ້ນປະໄວ້; ຫຼັງຈາກທີ່ທ່ານເປີດໄຟລ໌ອື່ນ, ມັນຈະຂ້າມໜ້າຕ່າງນີ້.

## ປິດເມື່ອມີການປ່ຽນແປງທີ່ຍັງບໍ່ໄດ້ບັນທຶກ

ເມື່ອໂຄງການມີການປ່ຽນແປງທີ່ຍັງບໍ່ໄດ້ບັນທຶກ ແລະ ທ່ານປິດແຖບ, reload, ຫຼື ອອກຈາກໜ້າ, browser ຈະຖາມວ່າທ່ານຕ້ອງການອອກຫຼືບໍ່. ຂໍ້ຄວາມ ແລະ ຮູບລັກສະນະຂອງມັນເປັນຂອງ browser, CivilCraft ບໍ່ສາມາດປ່ຽນແປງໄດ້. {{ui:New}}, ແລະ ການເປີດໂຄງການ ຫຼື ໄຟລ໌ LandXML, ຈະຖາມໃນກ່ອງ **ການປ່ຽນແປງທີ່ຍັງບໍ່ໄດ້ບັນທຶກ** ຂອງ CivilCraft ເອງແທນ, ພ້ອມ {{ui:Cancel}}, {{ui:Don’t save}} ແລະ {{ui:Save a copy}}.

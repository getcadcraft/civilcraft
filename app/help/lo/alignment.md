ແນວທາງໃນ CivilCraft ແມ່ນລຳດັບຂອງເສັ້ນສຳຜັດຜ່ານຈຸດຕັດກັນ (PI), ໂດຍມີເສັ້ນໂຄ້ງວົງມົນຢູ່ PI ພາຍໃນທີ່ມີລັດສະໝີ. ມັນຖືກໃສ່ station ຈາກ station ເລີ່ມຕົ້ນທີ່ທ່ານເລືອກ. ໂຄງການໜຶ່ງສາມາດມີຫຼາຍແນວທາງ.

## ແຕ້ມແນວທາງ

1. ກົດ {{key:A}}, ຫຼື ກົດ {{ui:Alignment}} ໃນກຸ່ມ **ການອອກແບບ**.
   ຄຳແນະນຳເວົ້າວ່າ "ແນວທາງ: ກົດ PI ຕາມລຳດັບ. Enter ຫຼື ກົດສອງຄັ້ງເພື່ອສຳເລັດ, Backspace ເພື່ອລຶບອັນສຸດທ້າຍ, Esc ເພື່ອຍົກເລີກ."
2. ກົດ PI ທຳອິດ (ຈຸດເລີ່ມຕົ້ນຂອງແນວທາງ).
3. ກົດ PI ຕໍ່ໄປແຕ່ລະອັນຕາມລຳດັບ. ເສັ້ນສີແດງຕາມຕົວຊີ້ ແລະ ສະແດງຄວາມຍາວ ແລະ ທິດທາງ (bearing) ຂອງເສັ້ນສຳຜັດທີ່ທ່ານກຳລັງແຕ້ມ, ເຊັ່ນ "212.40 ft  N 63°12'05" E".
4. ກົດ PI ສຸດທ້າຍ (ຈຸດສິ້ນສຸດຂອງແນວທາງ).
5. ກົດ {{key:Enter}}.
   ແນວທາງຖືກແຕ້ມພ້ອມ station ແລະ ຖືກເລືອກ. ແຖບສະຖານະບອກ, ເຊັ່ນ "ແນວທາງ 1: 386.36 ft, ໂຄ້ງລັດສະໝີ 100 ft ບ່ອນທີ່ພໍດີ. ແກ້ລັດສະໝີໃນ ຄຸນສົມບັດ; ໜ້າຕັດຕາມຍາວ (R) ເພື່ອອອກແບບຄວາມລາດ."

ຂະນະແຕ້ມ: {{key:Backspace}} ລຶບ PI ສຸດທ້າຍ, {{key:Esc}} ຍົກເລີກ, ແລະ ລາກເທິງພື້ນທີ່ວ່າງຈະເລື່ອນມຸມມອງໂດຍບໍ່ເພີ່ມ PI.

:::warning
ສຳເລັດດ້ວຍ {{key:Enter}}. ການກົດສອງຄັ້ງກໍສຳເລັດເຊັ່ນກັນ, ແຕ່ໃນເວີຊັນນີ້ມັນຈະລຶບ PI ທີ່ທ່ານກົດສອງຄັ້ງ. ກົດ PI ສຸດທ້າຍໜຶ່ງຄັ້ງ, ແລ້ວກົດ {{key:Enter}}.
:::

ທຸກ PI ພາຍໃນຈະໄດ້ເສັ້ນໂຄ້ງ 100 ft (30 m ໃນໂຄງການແມັດ), ຫຼື ລັດສະໝີຈຳນວນເຕັມທີ່ໃຫຍ່ສຸດທີ່ພໍດີກັບເຄິ່ງໜຶ່ງຂອງແຕ່ລະເສັ້ນສຳຜັດ ຖ້າ 100 ft ບໍ່ພໍດີ. PI ທີ່ແຫຼມຫຼາຍ ຫຼື ເສັ້ນຊື່ຜ່ານຈະບໍ່ໄດ້ເສັ້ນໂຄ້ງ.

## ກຳນົດລັດສະໝີ ແລະ ພິກັດ

ເມື່ອເລືອກແນວທາງ, ແຜງຂວາສະແດງ **ແນວທາງ**:

1. **ຊື່** ແລະ **station ເລີ່ມຕົ້ນ**. ພິມ station ເປັນ `10+00` (feet) ຫຼື `0+500` (ແມັດ), ຫຼື ເປັນຕົວເລກທຳມະດາ. ເບິ່ງ [ຫົວໜ່ວຍ, station ແລະ ຮູບແບບຕົວເລກ](topic:units-and-stations).
2. **ຄວາມຍາວ** ແລະ **station ສິ້ນສຸດ** ຖືກຄຳນວນໃຫ້ທ່ານ.
3. ຕາຕະລາງ **PIs** ສະແດງ **Easting** ແລະ **Northing** ຂອງແຕ່ລະ PI, ແລະ **Radius** ສຳລັບແຕ່ລະ PI ພາຍໃນ. ພິມຄ່າໃໝ່ ແລ້ວກົດ {{key:Enter}}.
   - ລັດສະໝີ 0 ເຮັດໃຫ້ເປັນຈຸດມຸມໂດຍບໍ່ມີເສັ້ນໂຄ້ງ.
   - PI ທຳອິດ ແລະ ສຸດທ້າຍບໍ່ມີລັດສະໝີເລີຍ.
   - ໂຕ x ນ້ອຍຢູ່ທ້າຍແຖວຈະລຶບ PI ນັ້ນອອກ (ແນວທາງຕ້ອງມີຢ່າງໜ້ອຍສອງ PI).
4. ອ່ານລາຍການ **Curves**: ສຳລັບແຕ່ລະໂຄ້ງ, station PC ແລະ PT, ລັດສະໝີ R, ມຸມເບນ Δ ແລະ ທິດທາງ (ຊ້າຍ ຫຼື ຂວາ), ຄວາມຍາວ L, ເສັ້ນສຳຜັດ T, ຄ່າພາຍນອກ E ແລະ chord.
5. ເສັ້ນທີ່ຢູ່ລຸ່ມໂຄ້ງໃຫ້ທິດທາງຂອງເສັ້ນສຳຜັດທຳອິດ.

## ເມື່ອໂຄ້ງບໍ່ພໍດີ

ຖ້າໂຄ້ງຕ້ອງການເສັ້ນສຳຜັດຫຼາຍກວ່າທີ່ມີລະຫວ່າງ PI ຂອງມັນ, ແນວທາງບໍ່ມີຜົນເລີຍ: ມັນບໍ່ຖືກແຕ້ມຢ່າງຖືກຕ້ອງຈົນກວ່າທ່ານຈະແກ້ໄຂ, ແລະ ມັນຖືກຕັດອອກຈາກການສົ່ງອອກ LandXML. ກ່ອງສີແດງບອກເຫດຜົນເປັນຕົວເລກ ແລະ ສະເໜີສິ່ງທີ່ຈະພໍດີ:

- "ໂຄ້ງຢູ່ PI 2 ແລະ PI 3 ຕ້ອງການເສັ້ນສຳຜັດ 240.00 ft ລະຫວ່າງກັນ (130.00 + 110.00), ແຕ່ PI ຫ່າງກັນ 180.00 ft." ຫຼື, ເມື່ອມີພຽງອັນໜຶ່ງທີ່ມີໂຄ້ງ, "ໂຄ້ງຢູ່ PI 2 ຕ້ອງການ 240.00 ft ຂອງເສັ້ນສຳຜັດໄປທາງ PI 1 …".
- ປຸ່ມສຳລັບແຕ່ລະ PI ຕັ້ງ **ລັດສະໝີໃຫຍ່ສຸດທີ່ພໍດີ** ຢູ່ບ່ອນນັ້ນ ໂດຍໂຄ້ງອີກອັນຄົງເດີມ (ມັນຕ້ອງພໍດີກັບເສັ້ນສຳຜັດອີກເສັ້ນຂອງ PI ນັ້ນດ້ວຍ). ບ່ອນທີ່ທັງສອງ PI ມີໂຄ້ງ, **ທັງສອງ** ຈະຫຼຸດລັດສະໝີທັງສອງຕາມອັດຕາສ່ວນ ເພື່ອໃຫ້ພໍດີກັນພໍດີ.
- ເມື່ອໂຄ້ງດຽວຍາວກວ່າເສັ້ນສຳຜັດ, ກ່ອງຈະບອກວ່າບໍ່ມີໂຄ້ງໃດຢູ່ PI ອື່ນທີ່ພໍດີໃນຂະນະທີ່ມັນໃຫຍ່ຂະໜາດນັ້ນ.
- PI ທີ່ຫັນກັບຫຼັງຊື່ໆບໍ່ສາມາດມີໂຄ້ງໄດ້; ກ່ອງຈະສະເໜີ **ບໍ່ມີໂຄ້ງຢູ່ PI n**.

ແຕ່ລະປຸ່ມເປັນໜຶ່ງຂັ້ນຕອນ: {{key:Mod+Z}} ຈະເອົາລັດສະໝີກັບຄືນ. ລັດສະໝີທີ່ສະເໜີຖືກປັດລົງເປັນ 0.01 ເພື່ອໃຫ້ມັນພໍດີສະເໝີ.

### ລັດສະໝີຕ່ຳສຸດໃນການອອກແບບ

ພິມ **ລັດສະໝີຕ່ຳສຸດໃນການອອກແບບ** (ເຊັ່ນ ຈາກຄວາມໄວອອກແບບຂອງທ່ານ) ເພື່ອໃຫ້ທຸກໂຄ້ງຖືກກວດກັບມັນ; ປ່ອຍວ່າງຖ້າບໍ່ມີ. ໂຄ້ງທີ່ຕ່ຳກວ່ານັ້ນຖືກລາຍການພ້ອມປຸ່ມສຳລັບ **ລັດສະໝີນ້ອຍສຸດທີ່ຕອບສະໜອງຄ່າຕ່ຳສຸດ**, ເມື່ອລັດສະໝີນັ້ນພໍດີ. ເມື່ອມັນບໍ່ພໍດີ, ກ່ອງຈະບອກແບບນັ້ນ ແລະ ໃຫ້ລັດສະໝີໃຫຍ່ສຸດທີ່ເສັ້ນສຳຜັດອະນຸຍາດ, ເພື່ອໃຫ້ທ່ານຮູ້ວ່າຕ້ອງຍ້າຍ PI ຫຼື ຫຼຸດຄ່າຕ່ຳສຸດ.

## ຍ້າຍ PI ເທິງແຜນຜັງ

1. ເມື່ອ {{ui:Select}} ເປີດໃຊ້ຢູ່, ກົດແນວທາງເພື່ອເລືອກມັນ. ຈຸດຈັບສີ່ຫຼ່ຽມຈະປາກົດຢູ່ PI ຂອງມັນ.
2. ລາກຈຸດຈັບ. ແນວທາງ, station, ໜ້າຕັດ ແລະ ຄໍຣິດໍ ຈະຕາມໄປ.
3. ປ່ອຍ. ການຍ້າຍເປັນໜຶ່ງຂັ້ນ undo.

ການເພີ່ມ PI ລະຫວ່າງສອງ PI ທີ່ມີຢູ່ຍັງບໍ່ມີ: ໃຫ້ລຶບແນວທາງ ແລ້ວແຕ້ມໃໝ່, ຫຼື ພິມພິກັດໃໝ່ສຳລັບ PI ທີ່ທ່ານມີ.

## ອ່ານ station ແລະ offset

ເລື່ອນຕົວຊີ້ເທິງແຜນຜັງ. ແຖບສະຖານະສະແດງແນວທາງທີ່ໃກ້ທີ່ສຸດ (ຫຼື ອັນທີ່ເລືອກ) ພ້ອມ station ແລະ offset, **L** ຫຼື **R** ເບິ່ງຕາມ station ເພີ່ມ, ເຊັ່ນ "ແນວທາງ 1: Sta 2+15.30, offset 18.42 R". ເກີນປາຍທັງສອງດ້ານ ມັນຈະເພີ່ມ "(ເກີນປາຍ)".

## ສິ່ງທີ່ຖືກແຕ້ມ

ເທິງແຜນຜັງ, ໃນ DXF ແລະ PDF: centerline (ເສັ້ນສຳຜັດເປັນເສັ້ນ, ໂຄ້ງເປັນເສັ້ນໂຄ້ງແທ້), ເຄື່ອງໝາຍທຸກ 50 ft (20 m) ພ້ອມເຄື່ອງໝາຍຍາວກວ່າ ແລະ ປ້າຍ station ທຸກ 100 ໜ່ວຍ, ແລະ ເຄື່ອງໝາຍ PC ແລະ PT ພ້ອມປ້າຍ station ຂອງມັນ.

## ຄວາມໄວອອກແບບ ແລະ ຊັ້ນ

ໃຕ້ **ຄຸນສົມບັດ** ຂອງແນວທາງ, **ຄວາມໄວອອກແບບ** (km/h ຫຼື mph) ແລະ **ຊັ້ນອອກແບບ** ຖືກເກັບໄວ້ກັບແນວທາງ, ບັນທຶກໃນໂຄງການ ແລະ ຂຽນລົງ IFC (Pset_RoadDesignCriteriaCommon). CivilCraft ບໍ່ມີຕາຕະລາງທີ່ເຊື່ອມຄວາມໄວກັບລັດສະໝີຕ່ຳສຸດ, ດັ່ງນັ້ນບໍ່ມີການກວດຈາກມັນ: ໃຫ້ກຳນົດ **ລັດສະໝີຕ່ຳສຸດ** ຕາມມາດຕະຖານການອອກແບບຂອງທ່ານເອງ.

## ສະໄປຣໍ (Spirals)

ໂຄ້ງສາມາດມີສະໄປຣໍ clothoid ຢູ່ປາຍໃດປາຍໜຶ່ງ: ເສັ້ນສຳຜັດ, ສະໄປຣໍ, ໂຄ້ງ, ສະໄປຣໍ, ເສັ້ນສຳຜັດ. ໃນຕາຕະລາງ PI, ພິມຄວາມຍາວໃນ **Spiral in** ແລະ **Spiral out** ສຳລັບ PI ທີ່ມີລັດສະໝີ. PI ຍັງຢູ່ບ່ອນເດີມ; ໂຄ້ງຈະເລື່ອນເຂົ້າມາເພື່ອໃຫ້ມີບ່ອນ, ສະນັ້ນໄລຍະເສັ້ນສຳຜັດເພີ່ມຂຶ້ນຕາມ offset ຂອງສະໄປຣໍ. ສອງຄວາມຍາວອາດຕ່າງກັນ, ແລະ PI ທີ່ມີພຽງຄວາມຍາວດຽວຈະໄດ້ສະໄປຣໍພຽງປາຍດຽວ.

ລາຍການໂຄ້ງຈະອ່ານ TS, SC, CS ແລະ ST (ເສັ້ນສຳຜັດຫາສະໄປຣໍ, ສະໄປຣໍຫາໂຄ້ງ, ໂຄ້ງຫາສະໄປຣໍ, ສະໄປຣໍຫາເສັ້ນສຳຜັດ) ພ້ອມມຸມສະໄປຣໍ θs, ໄລຍະເສັ້ນສຳຜັດ ແລະ ໄລຍະພາຍນອກ. Station ໄປຕາມສະໄປຣໍເໝືອນທຸກບ່ອນ. ສະໄປຣໍທີ່ລວມກັນໝຸນຫຼາຍກວ່າໂຄ້ງຈະຖືກປະຕິເສດ ພ້ອມຊື່ PI; ສະໄປຣໍທີ່ຍາວກວ່າເສັ້ນສຳຜັດອະນຸຍາດຈະເປັນການທັບຊ້ອນ, ເໝືອນໂຄ້ງໃດໆ. Superelevation ໃຊ້ສະໄປຣໍເປັນ runoff (ເບິ່ງ [Corridor](topic:corridor)).

ສ່ວນ **ພືດ** ຂອງແຜງດ້ານຊ້າຍລະບຸພືດທຸກຊະນິດທີ່ທ່ານສາມາດວາງໄດ້. ຄລິກໜຶ່ງເພື່ອເບິ່ງຂະໜາດຂອງມັນ ແລະ ເຮັດໃຫ້ມັນເປັນພືດທີ່ **ພືດ**, **ແປງ** ແລະ **ຮົ້ວພຸ່ມ** ໃຊ້.

## ຄົ້ນຫາ ແລະ ກັ່ນຕອງ

ພິມໃນ **ຄົ້ນຫາ**: ຄຳໃດກໍໄດ້ໃນຊື່ພືດ ເປັນພາສາໃດກໍໄດ້ (ອັງກິດ, ສະເປນ, ໂປຕຸຍເກດ), ຊື່ວິທະຍາສາດ, ປະເພດ ຫຼື ຄຳໃນໝາຍເຫດ. ທຸກຄຳທີ່ທ່ານພິມຕ້ອງກົງກັນ, ດັ່ງນັ້ນ `quercus evergreen` ຈະພົບໄມ້ໂອ໊ກຜັດໃບຕະຫຼອດປີ. ເຄື່ອງໝາຍສຽງບໍ່ມີຜົນຕໍ່ການຄົ້ນຫາ.

ຈຳກັດລາຍການດ້ວຍ **ປະເພດ**, **ແສງ**, **ນ້ຳ** ແລະ **ເຂດຄວາມທົນທານ** (ເຂດ USDA ທີ່ສະຖານທີ່ຂອງທ່ານຢູ່: ພືດຈະຖືກລະບຸເມື່ອເຂດຢູ່ໃນຂອບເຂດຂອງມັນ).

## ຂໍ້ມູນທີ່ພືດມີ

| ຊ່ອງ | ຄວາມໝາຍ |
|---|---|
| ປະເພດ | ຕົ້ນໄມ້, ໄມ້ພຸ່ມ, ຮົ້ວພຸ່ມ, ຫຍ້າ (ລວມທັງສະໜາມຫຍ້າ), ໄມ້ຍືນຕົ້ນ, ພືດປົກຄຸມດິນ ຫຼື ພືດເລື້ອຍ |
| ເມື່ອໂຕເຕັມທີ່ | ຄວາມສູງ ແລະ ຄວາມກວ້າງຊົງພຸ່ມຂອງພືດທີ່ປູກໃນສວນ ຫຼື ຕາມຖະໜົນ, ເປັນແມັດ |
| ຕອນປູກ | ຂະໜາດທີ່ປູກລົງ ແລະ ພາຊະນະຂອງມັນ |
| ໄລຍະຫ່າງ | ຈາກຈຸດກາງຫາຈຸດກາງໃນແປງ ຫຼື ຕາມຮົ້ວພຸ່ມ |
| ເຂດຄວາມທົນທານ | ເຂດ USDA ທີ່ມັນມັກຈະທົນໄດ້ |
| ແສງ, ນ້ຳ, ດິນ | ສິ່ງທີ່ມັນຕ້ອງການ |
| ໝາຍເຫດ | ການນຳໃຊ້ ແລະ ຂໍ້ຄວນລະວັງ, ເຊັ່ນ ສ່ວນທີ່ເປັນພິດ ຫຼື ພືດທີ່ແຜ່ຂະຫຍາຍ |

:::note
ລາຍການໃນຕົວຖືກຂຽນສຳລັບ CadCraft ຈາກຄວາມຮູ້ດ້ານການຈັດສວນທົ່ວໄປ: ຂະໜາດທົ່ວໄປ, ປັດເສດ. ມັນບໍ່ແມ່ນລາຍການສິນຄ້າຂອງສວນອະນຸບານໃດໆ. ໃຫ້ກວດສອບຂະໜາດ ແລະ ຄວາມທົນທານກັບສວນອະນຸບານທ້ອງຖິ່ນ. ພືດຮຸກຮານທີ່ຮູ້ຈັກດີທີ່ສຸດຂອງ Iberia ແລະ ຂອງເຂດອຸນຫະພູມປານກາງສ່ວນໃຫຍ່ຖືກຕັດອອກໂດຍເຈດຕະນາ, ແລະ ພືດບາງຊະນິດທີ່ຮຸກຮານໃນບາງບ່ອນຈະມີໝາຍເຫດ.
:::

## ພືດຂອງທ່ານເອງ

- **ເພີ່ມເຂົ້າລາຍການຂອງໂຄງການນີ້** ຄັດລອກພືດເຂົ້າລາຍການຂອງໂຄງການ, ບ່ອນທີ່ມັນຖືກບັນທຶກກັບໂຄງການ. ພືດໃນລາຍການຂອງທ່ານຈະແທນທີ່ພືດໃນຕົວທີ່ມີລະຫັດດຽວກັນ, ດັ່ງນັ້ນທ່ານສາມາດປ່ຽນຂະໜາດຂອງມັນໃຫ້ເໝາະກັບພາກພື້ນຂອງທ່ານ.
- **ນຳເຂົ້າລາຍການພືດ…** ອ່ານໄຟລ໌ CSV (ຫຼື ໄຟລ໌ພືດ). CSV ຕ້ອງມີຖັນທີ່ມີຊື່ວິທະຍາສາດ ແລະ ຖ້າເປັນໄປໄດ້ ປະເພດ, ຄວາມສູງ ແລະ ຄວາມກວ້າງຊົງພຸ່ມ; ຊື່ຖັນໃນຄຳຂອງທ່ານເອງກໍໃຊ້ໄດ້ (Latin, Common name, Height, Spread, Width, Zone). ເຄື່ອງໝາຍຈຸດ, ເຄື່ອງໝາຍຈຸດຈຸລະພາກ ຫຼື ແທັບ ແລະ ຈຸດທົດສະນິຍົມແບບຈຸດຈຸລະພາກ ຈະຖືກອ່ານ. ຂະໜາດປູກ, ໄລຍະຫ່າງ ແລະ ພາຊະນະທີ່ວ່າງຈະໃຊ້ຄ່າເລີ່ມຕົ້ນທີ່ເໝາະສົມຕາມປະເພດ.
- **ສົ່ງອອກເປັນ CSV** ບັນທຶກລາຍການຂອງທ່ານ (ຫຼື ຖ້າບໍ່ມີ, ພືດທີ່ການຄົ້ນຫາສະແດງ) ເພື່ອເປີດໃນສເປຣດຊີດ.

ລາຍການພືດຖືກອ່ານຄືກັບໄຟລ໌ຈາກພາຍນອກທຸກອັນ: ສ່ວນໃດທີ່ໃຊ້ບໍ່ໄດ້ຈະຖືກຕັດອອກ ແລະ ນັບໄວ້.

## ພືດໃນແອັບອື່ນ

ລາຍການພືດເປັນຄັງດຽວສຳລັບທຸກແອັບ CadCraft: BimCraft ແລະ ModelCraft ມີລາຍການດຽວກັນ, ແຕ່ **ວາງຈາກຄັງ** ຂອງພວກມັນຍັງບໍ່ສະເໜີພືດ. ປັດຈຸບັນພືດເຂົ້າສູ່ແບບຈຳລອງ BIM ຜ່ານ IFC ຂອງ Landscape ຂອງ CivilCraft (ພືດແຕ່ລະຕົ້ນເປັນ `IfcGeographicElement`). ເບິ່ງ [ການປູກພືດ](topic:planting#ifc).

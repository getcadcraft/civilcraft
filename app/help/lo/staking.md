ເລືອກແນວທາງ ແລ້ວກົດ **ລາຍງານການປັກໝຸດ** ໃນ **ຄຸນສົມບັດ** ຂອງມັນ.

## ໝຸດຢູ່ສະຖານີ ແລະ ໄລຍະຫ່າງຈາກແນວ

1. **ຈາກ** ແລະ **ຫາ**: ສະຖານີທີ່ຈະປັກໝຸດ (1+50 ຫຼື 150).
2. **ທຸກ**: ໄລຍະຊ່ວງ. ໝຸດຈະຢູ່ທຸກຈຳນວນຄູນຂອງມັນ, ທັງສອງປາຍ, ແລະ (ເມື່ອຕິກຊ່ອງ) ບ່ອນທີ່ໂຄ້ງຂອງແນວທາງເລີ່ມ ແລະ ສິ້ນສຸດ.
3. **ໄລຍະຫ່າງຈາກແນວ**: ຊ້າຍ ແລະ ຂວາຂອງແນວທາງ, ເບິ່ງໄປທາງສະຖານີ: `12 L, 0, 12 R`, `L12 CL R12` ຫຼື `-12, 0, 12` (ຊ້າຍແມ່ນເຄື່ອງໝາຍລົບ). ແນວທາງທີ່ມີຄໍຣິດໍເລີ່ມດ້ວຍຂອບຂອງພື້ນຜິວທາງ ແລະ ໄຫຼ່ທາງ.
4. **ນັບຈາກ** ແລະ **ມີຕົວນຳໜ້າ** ຕັ້ງຊື່ໝຸດ: 1, 2, 3, ຫຼື S101, S102.

## ຈຸດສຳຫຼວດໃກ້ແນວທາງ

ເລືອກ **ຈຸດສຳຫຼວດໃກ້ແນວທາງ** ແລະ ໄລຍະໃກ້ປານໃດ. ແຕ່ລະຈຸດທີ່ຢູ່ໃນໄລຍະນັ້ນຈະໄດ້ສະຖານີ ແລະ ໄລຍະຫ່າງຈາກແນວ, ການອອກແບບຢູ່ບ່ອນນັ້ນ, ແລະ ລະດັບຂອງມັນເອງເປັນພື້ນດິນ: ການກວດສອບຈຸດທີ່ປັກໝຸດ ຫຼື ວັດຕາມສະພາບກໍ່ສ້າງຈິງ.

## ລາຍງານບອກຫຍັງ

| ຄໍລຳ | ມັນແມ່ນຫຍັງ |
|---|---|
| ຈຸດ | ຊື່ຂອງໝຸດ, ຫຼື ໝາຍເລກຂອງຈຸດສຳຫຼວດ |
| ສະຖານີ, ໄລຍະຫ່າງຈາກແນວ | ບ່ອນຢູ່ຕາມແນວທາງ: L ຊ້າຍ, R ຂວາ |
| ພິກັດເໜືອ-ໃຕ້, ພິກັດຕາເວັນອອກ-ຕາເວັນຕົກ | ພິກັດຂອງມັນ |
| ລະດັບອອກແບບ | ພື້ນຜິວຂອງຄໍຣິດໍທີ່ຖືກປັບລະດັບຢູ່ບ່ອນນັ້ນ (ຈາກເສັ້ນຂອບດິນໄປຫາເສັ້ນຂອບດິນ), ຖ້າບໍ່ມີ ແມ່ນໂປຣໄຟລ໌ອອກແບບເທິງເສັ້ນກາງ |
| ລະດັບພື້ນດິນ | ພື້ນຜິວທີ່ມີຢູ່ແລ້ວຢູ່ບ່ອນນັ້ນ, ຫຼື ລະດັບຂອງຈຸດສຳຫຼວດເອງ |
| ຕັດ/ຖົມ | C ເມື່ອພື້ນດິນສູງກວ່າການອອກແບບ (ຕ້ອງຂຸດລົງ), F ເມື່ອຕ່ຳກວ່າ (ຕ້ອງຖົມຂຶ້ນ), ລະອຽດເຖິງຮ້ອຍສ່ວນ |

ໝຸດທີ່ບໍ່ມີລະດັບອອກແບບ (ຢູ່ນອກຄໍຣິດໍ, ຫຼື ໃນແນວທາງທີ່ບໍ່ມີ ຢູ່ຫ່າງຈາກເສັ້ນກາງ) ຈະບໍ່ມີການຕັດ ຫຼື ຖົມ; ກ່ອງໂຕ້ຕອບຈະບອກວ່າມີຈັກອັນ.

## ບັນທຶກ

- **CSV**: ແຖວຊື່ເລື່ອງໜຶ່ງແຖວ, ແລ້ວຕາມດ້ວຍຄໍລຳທີ່ກ່າວມາຂ້າງເທິງ, ພ້ອມການຕັດ ຫຼື ຖົມເປັນຕົວເລກມີເຄື່ອງໝາຍ (ພື້ນດິນລົບອອກແບບ) ສຳລັບສະເປຣດຊີດ ແລະ ເຄື່ອງເກັບຂໍ້ມູນ.
- **PDF**: ໜ້າຕາຕະລາງຕາມເຈ້ຍທີ່ທ່ານເລືອກ, ໜຶ່ງໝຸດຕໍ່ແຖວ, ການຕັດເປັນສີສົ້ມ ແລະ ການຖົມເປັນສີຂຽວ, ພ້ອມແຖບຊື່ເລື່ອງຂອງແຜ່ນອື່ນໆ.

:::note
ໝຸດຖືກຄຳນວນຈາກການອອກແບບໃນໂຄງການ. ກວດສອບກັບແຜນທີ່ທີ່ໄດ້ອະນຸມັດແລ້ວ ກ່ອນຈະກໍ່ສ້າງສິ່ງໃດ.
:::

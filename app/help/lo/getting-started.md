CivilCraft ເປັນແອັບອອກແບບວິສະວະກຳໂຍທາ ແລະ ພື້ນທີ່ໃນຕະກູນ CadCraft. ມັນຮັບຈຸດການສຳຫຼວດ ແລ້ວປ່ຽນເປັນພື້ນຜິວ (TIN) ພ້ອມເສັ້ນຊັ້ນລະດັບ, ຈາກນັ້ນໃຫ້ທ່ານວາງແນວທາງດ້ວຍໜ້າຕັດຕາມຍາວອອກແບບ, ກວາດຄໍຣິດໍເສັ້ນທາງງ່າຍໆ, ປັບລະດັບແທ່ນອາຄານໃຫ້ເຂົ້າກັບ daylight, ກວດເຄືອຂ່າຍທໍ່ແຮງໂນ້ມຖ່ວງຕາມກົດລະບຽບຂອງທ່ານ ແລະ ເບິ່ງປະລິມານຂຸດ ແລະ ຖົມ. ມັນອ່ານ ແລະ ຂຽນ LandXML, ສົ່ງອອກແຜນທີ່ເປັນ DXF ແລະ ພິມເປັນ PDF.

ຖ້າທ່ານເຄີຍໃຊ້ Civil 3D, ແນວຄິດຈະຄຸ້ນເຄີຍ: ຈຸດ, ກຸ່ມຈຸດ, ເສັ້ນຕັດຂອບ, ແນວທາງຕາມ PI, ໜ້າຕັດຕາມຍາວຕາມ PVI, ຄໍຣິດໍ, ການປັບລະດັບ, ເຄືອຂ່າຍທໍ່. ວິທີເຮັດວຽກແຕກຕ່າງ ແລະ ນ້ອຍກວ່າຫຼາຍ: ບໍ່ມີ command line, ບໍ່ມີ style ແລະ ບໍ່ມີໄຟລ໌ແບບແຕ້ມ. ອ່ານ [ມາຈາກຊອບແວວິສະວະກຳໂຍທາອື່ນ](topic:coming-from) ໜຶ່ງຄັ້ງ ກ່ອນວຽກຈິງທຳອິດຂອງທ່ານ.

## ສິ່ງທີ່ທ່ານຕ້ອງການ

- browser ສຳລັບ desktop ທີ່ໃໝ່: Chrome, Edge, Firefox ຫຼື Safari. ເບິ່ງ [Browsers](common:browsers).
- ເມົ້າ ຫຼື trackpad ແລະ ແປ້ນພິມ, ຫຼື ໜ້າຈໍສຳຜັດ: ການແຕ້ມມີປຸ່ມ {{ui:Finish}}, {{ui:Undo point}} ແລະ {{ui:Cancel}} ຢູ່ເທິງໜ້າຈໍ (ເບິ່ງ [ເມົ້າ, trackpad ແລະ ການສຳຜັດ](topic:keyboard#mouse-trackpad-and-touch)).
- ແຜນທີ່ແຕ້ມເປັນ 2D ດ້ວຍ canvas ຂອງ browser. [ມຸມມອງ 3D](topic:site-3d) ໃຊ້ກຣາຟິກ WebGL ຂອງ browser; ຖ້າມັນເລີ່ມບໍ່ໄດ້, ແຖບສະຖານະຈະບອກເຫດຜົນ ແລະ ແຜນທີ່ຍັງເຮັດວຽກຢູ່.
- ບໍ່ຕ້ອງມີບັນຊີ ແລະ ບໍ່ມີການອັບໂຫຼດ. ໄຟລ໌ເປີດໃນຄອມພິວເຕີຂອງທ່ານ ແລະ ບັນທຶກເປັນການດາວໂຫຼດ. ເບິ່ງ [ໄຟລ໌ຂອງທ່ານ](common:your-files).

:::note
ປັດຈຸບັນ CivilCraft ເຮັດວຽກເປັນ build browser ຕົ້ນໆທີ່ຍັງຢູ່ໃນການພັດທະນາ. Build ສຳລັບ desktop ຍັງບໍ່ມີ, ແລະ ການບັນທຶກເທິງຄລາວກໍຍັງບໍ່ມີ. ທຸກຢ່າງທີ່ທ່ານສ້າງຈະຢູ່ໃນຄອມພິວເຕີຂອງທ່ານ ຈົນກວ່າທ່ານຈະບັນທຶກ ຫຼື ສົ່ງອອກ.
:::

## ເປີດ CivilCraft

1. ເປີດ CivilCraft ໃນ browser ຂອງທ່ານ.
2. ລໍຖ້າຈົນໜ້າຈໍເຕັມ: ແຖບເຄື່ອງມືດ້ານເທິງ, ແຜງດ້ານຊ້າຍ, ແຜນທີ່ຢູ່ກາງ ແລະ ແຜງ **ຄຸນສົມບັດ** ດ້ານຂວາ.
3. ໃນແຜນທີ່ເປົ່າ ທ່ານຈະເຫັນກ່ອງຊື່ **ເລີ່ມດ້ວຍຈຸດການສຳຫຼວດ**. ມັນລາຍການຂັ້ນຕອນທຳອິດ ແລະ ມີລິ້ງ {{ui:Open the sample site}}.

ເພື່ອໃຊ້ CivilCraft ໂດຍບໍ່ມີການເຊື່ອມຕໍ່ໃນພາຍຫຼັງ, ໃຫ້ກົດ {{ui:Save for offline}} ໃນແຖບແອັບ ແລ້ວລໍຖ້າ {{ui:Offline ready}}. ມັນລວມເຖິງຄູ່ມືນີ້, ສະຖານທີ່ຕົວຢ່າງ, ແລະ ຄັງ 3D ແລະ GIS. ເບິ່ງ [ອອບໄລນ໌](common:offline). ກົດ {{key:F1}} ຫຼື ກົດ {{ui:Help}} ເວລາໃດກໍໄດ້ ເພື່ອເປີດຄູ່ມືນີ້ຄຽງຂ້າງແອັບ.

## ສິບນາທີທຳອິດຂອງທ່ານ: ສະຖານທີ່ຕົວຢ່າງ

ສະຖານທີ່ຕົວຢ່າງເປັນການສຳຫຼວດຂະໜາດນ້ອຍໃນ US feet: 276 ຈຸດໃນພິກັດ state plane, ສັນເຂົາ, ຮ່ອງນ້ຳ (swale) ທີ່ມີເສັ້ນໄຫຼ ແລະ ຂອບຝັ່ງສອງດ້ານ. ມັນມາພ້ອມກັບແອັບ, ດັ່ງນັ້ນທ່ານສາມາດເຮັດຕາມໄດ້ໂດຍບໍ່ຕ້ອງມີໄຟລ໌ຂອງຕົນເອງ.

1. ກົດ {{ui:Open the sample site}} ໃນກ່ອງເທິງແຜນທີ່.
   ກ່ອງ **ນຳເຂົ້າຈຸດ** ເປີດຂຶ້ນ. ມັນບອກວ່າ "ອ່ານ 276 ຈຸດເປັນ PNEZD (ຈາກແຖວຫົວ), ແຍກດ້ວຍເຄື່ອງໝາຍຈຸລະພາກ." ແລະ ສະແດງແຖວທຳອິດ.
2. ກົດ {{ui:Import}}.
   ແຜນທີ່ເຕັມໄປດ້ວຍຈຸດ, ເສັ້ນຊັ້ນລະດັບ ແລະ ຂອບພື້ນຜິວ. ແຖບສະຖານະດ້ານລຸ່ມບອກວ່າໄດ້ນຳເຂົ້າຈຸດແລ້ວ ແລະ ພື້ນຜິວມີສາມຫຼ່ຽມຈັກອັນ (546).
3. ເບິ່ງແຜງດ້ານຊ້າຍພາຍໃຕ້ **ຈຸດ**. ຈຸດຖືກຈັດເປັນກຸ່ມຕາມຄຳທຳອິດຂອງລາຍລະອຽດ: CP, FL, GRD, RIDGE, TBN, TBS ແລະ TREE.
4. ໃນຖັນ **ພື້ນຜິວ** ຂອງຕາຕະລາງນັ້ນ, ຕັ້ງ **FL**, **RIDGE**, **TBN** ແລະ **TBS** ເປັນ {{ui:Breakline}}.
   ພື້ນຜິວຈະສ້າງໃໝ່ທັນທີ. ຂໍ້ເທັດຈິງຂອງ **ພື້ນຜິວ** ດຽວນີ້ບອກວ່າ "ເສັ້ນແບ່ງ: 4", ແລະ ເສັ້ນຊັ້ນລະດັບຈະງໍຢ່າງແຫຼມຕາມເສັ້ນໄຫຼ ແລະ ສັນເຂົາ ແທນທີ່ຈະຕັດຂ້າມ.
5. ເລື່ອນຕົວຊີ້ເທິງແຜນທີ່. ແຖບສະຖານະສະແດງພິກັດ easting ແລະ northing ໃຕ້ຕົວຊີ້ ແລະ ລະດັບຄວາມສູງພື້ນດິນຕຳແໜ່ງນັ້ນ.
6. ພາຍໃຕ້ **ການສະແດງຜົນ**, ຕັ້ງ {{ui:Contours every}} ເປັນ 0.5 ft ແລະ ເປີດ {{ui:Elevation bands}}. ແຖບສີປາກົດພ້ອມຕຳນານພາຍໃຕ້ຊ່ອງໝາຍ. ປິດແຖບອີກຄັ້ງເມື່ອທ່ານສຳເລັດ.

ດຽວນີ້ທ່ານມີພື້ນຜິວພື້ນດິນທີ່ມີຢູ່ແລ້ວ. ຕໍ່ໄປ, ເສັ້ນທາງ.

## ວາງແນວທາງເສັ້ນທາງສັ້ນ

1. ກົດ {{key:A}} (ຫຼື ກົດ {{ui:Alignment}} ໃນກຸ່ມ **ການອອກແບບ**).
2. ກົດສາມຈຸດຂ້າມພື້ນທີ່, ຕາມລຳດັບ. ເສັ້ນສີແດງຕາມຕົວຊີ້ ແລະ ສະແດງຄວາມຍາວ ແລະ ທິດທາງຂອງ tangent ຕໍ່ໄປ.
3. ກົດ {{key:Enter}} ເພື່ອສຳເລັດ. ແນວທາງປາກົດພ້ອມການກຳນົດສະຖານີ. ແຜງດ້ານຂວາສະແດງ **ແນວທາງ**: ຄວາມຍາວ, ຕາຕະລາງ PI ແລະ ເສັ້ນໂຄ້ງຢູ່ PI ກາງ (ລັດສະໝີ 100 ft, ຫຼື ນ້ອຍກວ່າຖ້າ 100 ft ບໍ່ພໍ).
4. ໃນແຜງດ້ານຂວາ, ພາຍໃຕ້ **ໜ້າຕັດຕາມຍາວອອກແບບ**, ກົດ {{ui:Start from the ground}}. ມຸມມອງໜ້າຕັດຕາມຍາວເປີດຂຶ້ນພາຍໃຕ້ແຜນທີ່ ພ້ອມພື້ນດິນທີ່ມີຢູ່ ແລະ ລະດັບອອກແບບເສັ້ນຊື່ຈາກປາຍຫາປາຍ.
5. ກົດ {{key:I}} ເພື່ອເປີດ {{ui:Add PVIs}}, ແລ້ວກົດຄັ້ງໜຶ່ງໃນມຸມມອງໜ້າຕັດຕາມຍາວໃກ້ກາງ. PVI ໜຶ່ງປາກົດ.
6. ໃນຕາຕະລາງ PVI ດ້ານຂວາ, ພິມຄວາມຍາວເສັ້ນໂຄ້ງ (ເຊັ່ນ 100) ໃນຊ່ອງ **Curve L** ຂອງ PVI ກາງ ແລ້ວກົດ {{key:Enter}}. ໜ້າຕັດຕາມຍາວດຽວນີ້ມີເສັ້ນໂຄ້ງແນວຕັ້ງ, ພ້ອມປ້າຍຄ່າ K.
7. ພາຍໃຕ້ **Corridor**, ຕິກ **ກວາດ assembly ຕາມໜ້າຕັດຕາມຍາວອອກແບບ**.
   ເສັ້ນທາງຖືກປັບລະດັບລົງໃນພື້ນດິນ: ເລນ, ໄຫຼ່ທາງ ແລະ ລາດຂ້າງ ຈົນເຖິງ daylight. ບລັອກ **ວຽກດິນ** ສະແດງການຂຸດ ແລະ ຖົມ.

ຢ່າກັງວົນກັບຄ່າທີ່ແນ່ນອນ. ທຸກຕົວເລກສາມາດປ່ຽນໄດ້ໃນແຜງດ້ານຂວາ, ແລະ {{key:Mod+Z}} ຍ້ອນການປ່ຽນແປງຄັ້ງສຸດທ້າຍ.

## ບັນທຶກວຽກຂອງທ່ານ

1. ພິມຊື່ໃນ **ຊື່** ດ້ານເທິງຂອງແຜງດ້ານຊ້າຍ.
2. ກົດ {{key:Mod+S}} (ຫຼື ກົດ {{ui:Save}}). browser ຈະດາວໂຫຼດໄຟລ໌ທີ່ຕັ້ງຊື່ຕາມສະຖານທີ່, ລົງທ້າຍດ້ວຍ `.civilcraft.json`. ມັນເກັບຈຸດ, ການຕັ້ງຄ່າພື້ນຜິວ, ແນວທາງ, ໜ້າຕັດຕາມຍາວ, ຄໍຣິດໍ, ແທ່ນ ແລະ ທໍ່.
3. ເພື່ອສືບຕໍ່ໃນພາຍຫຼັງ, ກົດ {{ui:Open}} (ຫຼື ກົດ {{key:Mod+O}}) ແລ້ວເລືອກໄຟລ໌ນັ້ນ, ຫຼື ລາກມາວາງໃສ່ແຜນທີ່.

:::warning
ບໍ່ມີການບັນທຶກອັດຕະໂນມັດ. ຖ້າທ່ານປິດແຖບທີ່ມີການປ່ຽນແປງທີ່ຍັງບໍ່ໄດ້ບັນທຶກ, browser ຈະຖາມວ່າຈະອອກຫຼືບໍ່; ຖ້າທ່ານອອກ, ການປ່ຽນແປງຈະຫາຍໄປ. ບັນທຶກເລື້ອຍໆ.
:::

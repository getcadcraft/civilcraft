ເລເຢີແຜນທີ່ແມ່ນຮູບທີ່ແຕ້ມຢູ່ໃຕ້ການອອກແບບຂອງທ່ານ: ຮູບຖ່າຍທາງອາກາດພ້ອມ world file ຂອງມັນ, ຫຼື ແຜນທີ່ຈາກເຊີບເວີໃນອິນເຕີເນັດ. ພວກມັນເປັນບໍລິບົດສະຖານທີ່ໃນໜ້າຈໍເທົ່ານັ້ນ: ພວກມັນ **ບໍ່ຢູ່** ໃນການພິມ PDF, ການສົ່ງອອກ DXF ຫຼື DWG, ຫຼື ມຸມມອງ 3D.

ເລືອກ {{ui:ແຜນທີ່}} ໃນກຸ່ມ {{ui:GIS}}. ກ່ອງໂຕ້ຕອບ **ເລເຢີແຜນທີ່** ລາຍການເລເຢີຂອງໂປຣເຈັກ ແລະ ເພີ່ມເລເຢີໃໝ່. ເລເຢີແຜນທີ່ຕ້ອງການລະບົບພິກັດຂອງໂປຣເຈັກ ([ຕັ້ງລະບົບພິກັດຂອງໂປຣເຈັກ](topic:coordinate-systems)), ຍົກເວັ້ນຮູບທີ່ world file ໃຊ້ພິກັດຂອງໂປຣເຈັກເອງ.

## ການຕັ້ງຄ່າອິນເຕີເນັດ

CivilCraft ບໍ່ເຄີຍຂໍຫຍັງຈາກເຊີບເວີແຜນທີ່ຈົນກວ່າທ່ານຈະອະນຸຍາດ: {{ui:ການຕັ້ງຄ່າ}}, {{ui:CivilCraft}}, **ເລເຢີແຜນທີ່ຈາກອິນເຕີເນັດ**: **ປິດ** (ເລີ່ມຕົ້ນ) ຫຼື **ເປີດ**.

:::note
ເມື່ອເປີດ, CivilCraft ຂໍຮູບຂອງພື້ນທີ່ໃນໜ້າຈໍຈາກເຊີບເວີແຜນທີ່ທີ່ທ່ານເພີ່ມ. ແບບແຕ້ມຂອງທ່ານຢູ່ໃນຄອມພິວເຕີເຄື່ອງນີ້; ເຊີບເວີເຫັນພື້ນທີ່ ແລະ ທີ່ຢູ່ອິນເຕີເນັດຂອງທ່ານ.
:::

ໃນຂະນະທີ່ປິດ, ເລເຢີອິນເຕີເນັດຖືກລາຍການໃນກ່ອງໂຕ້ຕອບແຕ່ເປັນສີເທົາ, ພ້ອມເຫດຜົນ, ແລະ ບໍ່ມີຫຍັງຖືກແຕ້ມ ຫຼື ຂໍ. ການເປີດໂປຣເຈັກທີ່ລະບຸເຊີບເວີແຜນທີ່ກໍບໍ່ຕິດຕໍ່ພວກມັນເຊັ່ນກັນ. ຮູບຈາກໄຟລ໌ໃຊ້ໄດ້ທັງສອງແບບ. ປຸ່ມ {{ui:ເປີດການຕັ້ງຄ່າ}} ຂອງກ່ອງໂຕ້ຕອບພາທ່ານໄປທີ່ນັ້ນ.

## ຮູບທີ່ມີພິກັດ (ໃຊ້ໄດ້ແບບອອບໄລນ໌)

1. ໃນ **ເພີ່ມເລເຢີ**, ເກັບ **ຮູບທີ່ມີພິກັດ** ໄວ້ ແລະ ເລືອກໄຟລ໌: ຮູບ (PNG ຫຼື JPEG) **ພ້ອມກັບ** world file ຂອງມັນ (`.pgw` ສຳລັບ PNG, `.jgw` ສຳລັບ JPEG, ຫຼື `.wld`) ແລະ, ຖ້າມີ, `.prj` ຂອງມັນ. ທ່ານສາມາດວາງພວກມັນໃສ່ແຜນຜັງພ້ອມກັນໄດ້ເຊັ່ນກັນ.
2. ຖ້າບໍ່ມີ `.prj`, CivilCraft ຖາມວ່າ world file ໃຊ້ລະບົບໃດ: {{ui:ລະບົບຂອງໂປຣເຈັກ}} (ທົ່ວໄປທີ່ສຸດ), {{ui:ເລືອກລະບົບ…}}, ຫຼື, ໃນໂປຣເຈັກທີ່ບໍ່ມີລະບົບ, ພິກັດຂອງໂປຣເຈັກ.
3. ຮູບປາກົດໃຕ້ແຜນຜັງ ແລະ {{ui:ພໍດີ}} ລວມມັນ.

GeoTIFF RGB (ຮູບຖ່າຍທາງອາກາດທີ່ບັນທຶກເປັນ GeoTIFF) ມີການຈັດວາງ ແລະ ລະບົບຂອງຕົນເອງ: ໃຫ້ເປີດມັນໂດຍຕົວຂອງມັນເອງ. ຮູບຖືກເກັບ **ໄວ້ໃນໄຟລ໌ໂປຣເຈັກ** (ສູງສຸດ 25 MB); ຮູບທີ່ໃຫຍ່ກວ່າຈະຖືກປະຕິເສດພ້ອມຂະໜາດຂອງມັນ, ດັ່ງນັ້ນໃຫ້ບັນທຶກສຳເນົາທີ່ນ້ອຍກວ່າ (pixels ໜ້ອຍກວ່າ, ຫຼື JPEG).

## ແຜ່ນກະເບື້ອງ, WMS, WMTS ແລະ ບໍລິການແຜນທີ່

ເປີດ **ເລເຢີແຜນທີ່ຈາກອິນເຕີເນັດ** ກ່ອນ. ຈາກນັ້ນ, ໃນ **ເພີ່ມເລເຢີ**:

| ຈາກ | ວາງຫຍັງ | CivilCraft ເຮັດຫຍັງ |
|---|---|---|
| URL ຂອງແຜ່ນກະເບື້ອງ | ແມ່ແບບທີ່ມີ `{z}`, `{x}` ແລະ `{y}` (ຫຼື `{-y}`), ແລະ `{s}` ສຳລັບຕົວອັກສອນເຊີບເວີ, ຕົວຢ່າງ `https://tile.example.org/{z}/{x}/{y}.png`. ໃຫ້ຊື່ ແລະ ການໃຫ້ເຄຣດິດຂອງມັນ. | ແຜ່ນກະເບື້ອງໃນ web Mercator ສຳລັບພື້ນທີ່ ແລະ ການຊູມໃນໜ້າຈໍ. |
| ເຊີບເວີ WMS | ທີ່ຢູ່ຂອງເຊີບເວີ, ຫຼື ລິ້ງ GetCapabilities ຂອງມັນ. ເລືອກ {{ui:ດຶງເລເຢີ}}, ຈາກນັ້ນເລເຢີ. | ຮູບໜຶ່ງຂອງພື້ນທີ່ໃນໜ້າຈໍ, ຂໍດ້ວຍລະຫັດ EPSG ຂອງໂປຣເຈັກເມື່ອເຊີບເວີສະໜອງໃຫ້, ຖ້າບໍ່ດັ່ງນັ້ນໃນ web Mercator ຫຼື WGS 84. |
| ເຊີບເວີ WMTS | ທີ່ຢູ່ຂອງເຊີບເວີ, ຫຼື `WMTSCapabilities.xml` ຂອງມັນ. ເລືອກ {{ui:ດຶງເລເຢີ}}, ຈາກນັ້ນເລເຢີ ແລະ ຊຸດ tile matrix. | ແຜ່ນກະເບື້ອງຈາກຊຸດໃນລະບົບຂອງໂປຣເຈັກເມື່ອມີ, ຖ້າບໍ່ດັ່ງນັ້ນ web Mercator. |
| ບໍລິການແຜນທີ່ ArcGIS (REST) | URL ທີ່ລົງທ້າຍດ້ວຍ `/MapServer` ຫຼື `/ImageServer`. ເລືອກ {{ui:ອ່ານບໍລິການ}}. | ບໍລິການ web Mercator ທີ່ເກັບໄວ້ຖືກແຕ້ມຈາກແຜ່ນກະເບື້ອງຂອງມັນ; ອັນອື່ນຖືກຂໍເປັນຮູບໜຶ່ງຂອງພື້ນທີ່ໃນໜ້າຈໍ. |

ບໍ່ມີເຊີບເວີຕັ້ງໄວ້ລ່ວງໜ້າ. ຕົວຢ່າງສາທາລະນະ, ທັງໝົດຈາກ USGS National Map (ສາທາລະນະ):

- WMS: `https://basemap.nationalmap.gov/arcgis/services/USGSTopo/MapServer/WMSServer`
- WMTS: `https://basemap.nationalmap.gov/arcgis/rest/services/USGSTopo/MapServer/WMTS/1.0.0/WMTSCapabilities.xml`
- ບໍລິການແຜນທີ່: `https://basemap.nationalmap.gov/arcgis/rest/services/USGSTopo/MapServer` (ຫຼື `USGSImageryOnly` ສຳລັບຮູບຖ່າຍທາງອາກາດ)

ພະແນກ GIS ຂອງຫຼາຍເມືອງ ແລະ ເຂດ ເຜີຍແຜ່ WMS ຫຼື ບໍລິການແຜນທີ່ຂອງຕົນເອງ; ໜ້າ GIS ຂອງພວກເຂົາໃຫ້ທີ່ຢູ່. ເຊີບເວີທີ່ຂໍການເຂົ້າສູ່ລະບົບ ຫຼື ກຸນແຈຈະໃຊ້ບໍ່ໄດ້: CivilCraft ບໍ່ສົ່ງຊື່ຜູ້ໃຊ້, ລະຫັດຜ່ານ ຫຼື ກຸນແຈ.

## ວິທີແຕ້ມເລເຢີ

- ຮູບໃນລະບົບອື່ນຈາກລະບົບຂອງໂປຣເຈັກຖືກບິດເຂົ້າໄປ: ຮູບຖືກຕັດເປັນຊິ້ນ, ແຕ່ລະອັນຖືກວາງໃຫ້ຢູ່ພາຍໃນ 1/4 pixel ຂອງໜ້າຈໍຈາກບ່ອນທີ່ການແປງທີ່ແນ່ນອນວາງມັນ.
- ແຜ່ນກະເບື້ອງຖືກເລືອກສຳລັບພື້ນທີ່ໃນໜ້າຈໍ ແລະ ການຊູມ: ບໍ່ເກີນ 64 ສຳລັບມຸມມອງ, 6 ພ້ອມກັນ. ເມື່ອທ່ານເລື່ອນ ຫຼື ຊູມ, ຄຳຂໍສຳລັບມຸມມອງເກົ່າຈະຖືກຍົກເລີກ. ປະມານ 200 ແຜ່ນກະເບື້ອງຖືກເກັບໄວ້ໃນໜ່ວຍຄວາມຈຳ (ບໍ່ມີຫຍັງຖືກເກັບໃນດິສກ໌).
- ຮູບ WMS ຫຼື ບໍລິການແຜນທີ່ຖືກຂໍເມື່ອມຸມມອງຢຸດເຄື່ອນ; ຈົນກວ່າມັນຈະມາເຖິງ, ອັນສຸດທ້າຍຈະຢູ່ຄືເກົ່າ.
- ການໃຫ້ເຄຣດິດຂອງແຕ່ລະເລເຢີໃນໜ້າຈໍສະແດງເປັນຕົວນ້ອຍຢູ່ມຸມລຸ່ມຂວາຂອງແຜນຜັງ.

## ປ່ຽນ, ຈັດລຳດັບ ແລະ ລຶບເລເຢີ

ໃນກ່ອງໂຕ້ຕອບ, ແຕ່ລະເລເຢີມີຊ່ອງໝາຍຖືເພື່ອສະແດງ ຫຼື ເຊື່ອງ, ແຖບເລື່ອນ **ຄວາມໂປ່ງ**, ລູກສອນເພື່ອແຕ້ມມັນກ່ອນ (ຕ່ຳກວ່າ) ຫຼື ຫຼັງ (ຢູ່ເທິງ), ປຸ່ມຊູມ (ຮູບ) ແລະ ປຸ່ມລຶບ. ເລເຢີທຳອິດໃນລາຍການຖືກແຕ້ມຢູ່ດ້ານລຸ່ມ. ແຕ່ລະການປ່ຽນແປງແມ່ນໜຶ່ງຂັ້ນຕອນຍ້ອນກັບ.

## ເມື່ອເລເຢີບໍ່ສະແດງຫຍັງ

## ສິ່ງທີ່ໄດ້ກວດສອບ

- ໝາຍເລກແຜ່ນກະເບື້ອງໄດ້ຖືກກວດສອບກັບການແບ່ງແຜ່ນ web Mercator ມາດຕະຖານ; ຄຳຕອບ WMS 1.1.1 ແລະ 1.3.0, WMTS ແລະ ບໍລິການແຜນທີ່ຖືກອ່ານຈາກໄຟລ໌ທີ່ຂຽນດ້ວຍມື ແລະ ຈາກຄຳຕອບຈິງທີ່ບັນທຶກຈາກ USGS National Map ແລະ ເຊີບເວີ terrestris OpenStreetMap; ຄຳຂໍ WMS 1.3.0 ໃສ່ latitude ກ່ອນສຳລັບ EPSG:4326, ຕາມມາດຕະຖານ.
- ການບິດໄດ້ຖືກປຽບທຽບກັບການແປງທີ່ແນ່ນອນຕໍ່ pixel ຜ່ານຕົວເລກຂອງ PROJ: ພາຍໃນ 0.13 px ສຳລັບແຜ່ນກະເບື້ອງ, ຮູບ WMS ແລະ ຮູບຂະໜາດເຂດ, ໃນຂະໜາດສະຖານທີ່ ແລະ ເມື່ອຊູມອອກ.
- ຮູບພ້ອມ world file ຂອງມັນ ແລະ GeoTIFF RGB ທີ່ຂຽນໂດຍ GDAL (ຜ່ານ rasterio) ຖືກແຕ້ມຢູ່ບ່ອນທີ່ການຈັດວາງຂອງພວກມັນບອກ, ກວດສອບທີລະ pixel ໃນບຣາວເຊີ.
- ໃນບຣາວເຊີ, ຕໍ່ກັບເຊີບເວີທົດແທນໃນຄອມພິວເຕີທົດສອບ: ແຜ່ນກະເບື້ອງຕົກຢູ່ໃນແຜ່ນທີ່ PROJ ວາງແຕ່ລະຈຸດ, ຮູບ WMS ຕົກພາຍໃນ 2 px, ຄຳຂໍສູງສຸດ 6 ພ້ອມກັນ, ແລະ ເມື່ອການຕັ້ງຄ່າປິດ ບໍ່ມີຄຳຂໍອອກຈາກໜ້າ. ບໍລິການແຜນທີ່ USGS National Map ຂ້າງເທິງຖືກອ່ານ ແລະ ແຕ້ມສົດໃນບຣາວເຊີໜຶ່ງຄັ້ງ (ແຜ່ນກະເບື້ອງຂອງມັນມາເຖິງ ແລະ ຖືກແຕ້ມ, ພ້ອມຂໍ້ຄວາມລິຂະສິດ); ເຊີບເວີສາທາລະນະອື່ນໆຖືກອ່ານຈາກຄຳຕອບທີ່ບັນທຶກໄວ້ເທົ່ານັ້ນ.

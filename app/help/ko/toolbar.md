도구 모음은 앱 상단에 일곱 개 그룹으로 배치되어 있습니다. 각 버튼 위에 마우스를 올리면 설명과 단축키가 표시됩니다.

## 파일

| 버튼 | 단축키 | 기능 |
|---|---|---|
| {{ui:New}} | 없음 | 빈 프로젝트를 시작합니다. 저장되지 않은 변경 사항이 있으면 먼저 묻습니다. |
| {{ui:Open}} | {{key:Mod+O}} | 점 파일(CSV, TXT), LandXML 또는 CivilCraft 프로젝트를 엽니다. |
| {{ui:Save}} | {{key:Mod+S}} | 프로젝트를 `<name>.civilcraft.json`으로 다운로드합니다. |

## 내보내기

| 버튼 | 단축키 | 기능 |
|---|---|---|
| {{ui:LandXML}} | 없음 | `<name>.xml`을 다운로드합니다. 점, 지표면, 선형, 종단면도, 관망을 LandXML 1.2로 담습니다. 프로젝트가 비어 있으면 "내보낼 항목이 아직 없습니다."가 표시됩니다. |
| {{ui:DXF}} | 없음 | `<name>.dxf`를 다운로드합니다. 평면 선 요소를 R12 DXF로 담습니다. |
| {{ui:PDF}} | {{key:Mod+P}} | **평면도를 PDF로 출력**을 엽니다. 프로젝트가 비어 있으면 "출력할 항목이 아직 없습니다."가 표시됩니다. |

## 지표면

| 버튼 | 단축키 | 기능 |
|---|---|---|
| {{ui:Breakline}} | {{key:B}} | 측량점을 순서대로 누르고, 마치려면 {{key:Enter}}를 누릅니다. 단절선은 점들의 표고를 사용합니다. |
| {{ui:Boundary}} | {{key:O}} | 외곽 경계의 모서리를 누르고, 마치려면 {{key:Enter}}를 누릅니다. 기존 경계를 대체합니다. |

두 도구 모두 지표면이 없으면 "지표면이 아직 없습니다. 먼저 측량점을 여십시오."라고 표시합니다.

## 설계

| 버튼 | 단축키 | 기능 |
|---|---|---|
| {{ui:Alignment}} | {{key:A}} | PI를 순서대로 누르고, 마치려면 {{key:Enter}}를 누릅니다. |
| {{ui:Pad}} | {{key:G}} | 패드의 모서리를 누르고, 마치려면 {{key:Enter}}를 누릅니다. 지표면 도구처럼 지표면이 없으면 경고합니다. 패드는 지표면 위에서만 경사를 줄 수 있습니다. |
| {{ui:Pipes}} | {{key:P}} | 구조물을 상류에서 하류 순서로 누르고(기존 구조물을 누르면 연결됨), 마치려면 {{key:Enter}}를 누릅니다. |
| {{ui:Profile}} | {{key:R}} | 평면도 아래의 종단면도 보기를 켜거나 끕니다. |

## 편집

| 버튼 | 단축키 | 기능 |
|---|---|---|
| {{ui:Undo}} | {{key:Mod+Z}} | 마지막 변경을 실행 취소합니다(최대 200단계). 취소할 것이 없으면 비활성화됩니다. |
| {{ui:Redo}} | {{key:Mod+Y}} | 실행 취소한 것을 다시 실행합니다. 다시 실행할 것이 없으면 비활성화됩니다. |
| {{ui:Copy}} | {{key:Mod+C}} | 선택한 측량점을 복사하고, 스프레드시트에서 읽을 수 있는 점 행으로 클립보드에 담습니다. 점을 선택하기 전까지 비활성화됩니다. |
| {{ui:Paste}} | {{key:Mod+V}} | 점을 붙여넣습니다. 점은 포인터를 따라다니며, 누르면 다른 점과 겹치지 않는 번호로 놓입니다. 스프레드시트에서 복사한 점 행도 붙여넣을 수 있습니다. |
| {{ui:More}} | 없음 | 아래의 메뉴를 엽니다. |

{{ui:More}} 메뉴:

| 항목 | 단축키 | 기능 |
|---|---|---|
| {{ui:Cut}} | {{key:Mod+X}} | 선택한 점을 복사하고 삭제합니다(실행 취소 한 단계). |
| {{ui:Copy}} | {{key:Mod+C}} | {{ui:Copy}} 버튼과 같습니다. |
| {{ui:Paste}} | {{key:Mod+V}} | {{ui:Paste}} 버튼과 같습니다. |
| {{ui:Paste in place}} | {{key:Mod+Shift+V}} | 점을 원래 좌표에 붙여넣으며, 다른 점과 겹치지 않는 번호를 부여합니다. |
| {{ui:Duplicate}} | {{key:Mod+D}} | 선택한 점의 복사본이 포인터를 따라다닙니다. 놓을 위치를 누르십시오. 클립보드는 그대로 둡니다. |
| {{ui:Delete}} | {{key:Delete}} | 선택한 측량점, 또는 선택한 선형, 패드, 구조물(그 관 포함), 관, PVI를 삭제합니다. |
| {{ui:Select all points}} | {{key:Mod+A}} | 모든 측량점을 선택합니다. |
| {{ui:Select none}} | {{key:Esc}} | 선택을 해제합니다. |

지금 실행할 수 없는 항목은 비활성화되며, 그 설명에 이유가 표시됩니다. 자세한 내용은 [측량점 선택, 복사, 붙여넣기](topic:copy-paste-points)를 참조하십시오.

실행 취소는 설계, 지표면 설정, 측량점(붙여넣기, 잘라내기, 복제, 삭제)의 편집을 다룹니다. 표시 설정은 다루지 않으며, 파일을 열거나 가져오면 실행 취소 기록이 지워집니다.

## GIS

| 버튼 | 단축키 | 기능 |
|---|---|---|
| {{ui:Coordinates}} | 없음 | **좌표계** 대화상자를 엽니다. 프로젝트가 어떤 좌표계인지 지정하거나 지상 좌표 또는 지역 좌표를 사용할 수 있습니다. [프로젝트 좌표계 설정](topic:coordinate-systems)과 [지상 및 지역 좌표](topic:ground-and-local-coordinates)를 참조하십시오. |
| {{ui:Import}} | 없음 | GIS 데이터를 가져옵니다. shapefile, GeoJSON, GeoPackage, 표고 격자, LiDAR입니다. [GIS 데이터 가져오기](topic:gis-import)를 참조하십시오. |
| {{ui:Export}} | 없음 | 준공 데이터를 GIS 부서용으로 내보냅니다. [GIS용 준공 데이터 내보내기](topic:gis-export)를 참조하십시오. |
| {{ui:Analyze}} | 없음 | GIS 분석 패널을 엽니다. 버퍼, 중첩, 공간 결합, 속성으로 선택, 측정 기능이 있습니다. [GIS 도면층 분석](topic:gis-analysis)을 참조하십시오. |
| {{ui:Attribute table}} | 없음 | 지표면 › 더보기에 있습니다. GIS 도면층의 속성 테이블을 엽니다. 정렬, 필터, 선택, 편집, 필드 추가, 계산, CSV로 저장이 가능합니다. [도면층 속성 테이블 사용](topic:gis-table)을 참조하십시오. |
| {{ui:Map}} | 없음 | **지도 레이어** 대화상자를 엽니다. 좌표가 있는 그림 또는 추가한 지도 서버를 평면도 아래에 그립니다. [평면도 아래에 지도 레이어 표시](topic:map-layers)를 참조하십시오. |

GIS 도구는 이 버튼 중 하나를 처음 사용하거나, GIS 파일을 열거나, 좌표계 또는 GIS 레이어가 있는 프로젝트를 열 때 로드됩니다.

## 보기

| 버튼 | 단축키 | 기능 |
|---|---|---|
| {{ui:Select}} | {{key:V}} 또는 {{key:Esc}} | 클릭하여 선형, 패드, 구조물, 관, 점을 선택합니다({{key:Shift}}와 클릭 또는 드래그로 점을 추가). 그립을 드래그하여 PI, 패드 모서리, 구조물을 옮깁니다. |
| {{ui:Fit}} | {{key:F}} | 평면도를 지표면, 점, 선형, 패드가 보이도록 확대합니다(3D 보기에서는 모든 것을 보여 줍니다). |
| {{ui:3D}} | {{key:D}} | 평면도 위에 부지를 3D로 보여 주거나, 평면도로 돌아갑니다. 3D 보기 위의 막대에서 시점, 과장, 색상, 표시 항목을 설정하며, GLB 또는 OBJ로 내보냅니다. [3D로 부지 보기](topic:site-3d)를 참조하십시오. |

## 패널의 버튼

| 버튼 | 위치 | 기능 |
|---|---|---|
| {{ui:Open the sample site}} | 빈 평면도의 상자 | 샘플 측량을 불러옵니다(연결이 필요하며, CivilCraft를 오프라인 사용으로 저장한 경우는 예외). |
| {{ui:Remove the boundary}} | 왼쪽 패널, 지표면 | 외곽 경계를 제거합니다. |
| {{ui:Remove drawn breaklines}} | 왼쪽 패널, 지표면 | 도구로 그린 모든 단절선을 제거합니다(단절선 그룹은 제외). |
| {{ui:Rebuild the surface from the points}} | 왼쪽 패널, 지표면(LandXML 지표면에만 해당) | LandXML TIN을 버리고 점으로부터 다시 만듭니다. 실행 취소할 수 없습니다. |
| {{ui:Start from the ground}} | 오른쪽 패널, 선형 | 양 끝의 지반 위에 PVI를 두고 설계 종단면도를 시작합니다. |
| {{ui:Profile view}} | 오른쪽 패널, 선형 | 이 선형의 종단면도 보기를 엽니다. |
| {{ui:Add PVIs}} | 종단면도 막대 | 눌려 있는 동안 종단면도를 누르면 PVI가 추가됩니다. |
| {{ui:Set every invert from the rules}} | 오른쪽 패널, 관망 | 모든 관의 관저를 규칙에 따라 정합니다. |
| {{ui:Set its inverts from the rules}} | 오른쪽 패널, 관 | 이 관의 관저를 규칙에 따라 정합니다. |

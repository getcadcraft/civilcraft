점 파일은 한 줄에 점 하나씩 들어 있는 텍스트 파일입니다. 점 번호, Northing, Easting, 표고, 설명이 쉼표, 탭, 세미콜론 또는 공백으로 구분되어 어떤 순서로든 들어 있습니다. CivilCraft는 브라우저에서 파일을 읽고, 바로 표면을 만듭니다.

## 시작하기 전에

- 가능하면 파일의 열 순서를 알아 두십시오(PNEZD와 PENZD는 컴퓨터에게는 똑같아 보입니다).
- 단위를 알아 두십시오. CivilCraft는 단위를 변환하지 않으므로, 왼쪽 패널의 **단위**를 파일에 맞게 설정하십시오([단위, 측점, 숫자 형식](topic:units-and-stations) 참조).
- 좌표는 클 수 있습니다(평면 직각 좌표계의 Northing과 Easting이 수백만이어도 괜찮습니다).

## 파일 가져오기

1. 도구 모음의 {{ui:Open}}을 클릭하거나 {{key:Mod+O}}를 누른 뒤 파일을 고르십시오. 평면도로 끌어 놓을 수도 있습니다.
   **점 가져오기** 대화상자가 열리며, 파일 이름, **열** 목록(기본값 {{ui:Detect}}), 요약 줄, 처음 여섯 개의 점이 표시됩니다.
2. 요약 줄을 읽으십시오. 몇 개의 점을 읽었는지, 어떤 열 순서인지, 그 순서를 어떻게 찾았는지, 열을 무엇으로 구분하는지 알려 줍니다. 순서를 찾는 방법은 세 가지입니다.
   - "머리글 행에서": 첫 줄이 열 이름을 적고 있습니다(Point, Northing, Easting, Elevation, Description, 또는 X, Y, Z …). 가장 안전합니다.
   - "선택된 대로": **열**에서 순서를 직접 고르셨습니다.
   - "열 개수와 점 행 설정(PNEZD)으로 추정함 — Northing과 Easting이 뒤바뀌지 않았는지 확인하십시오": 쓸 만한 머리글이 없었습니다. 파일이 대개 Easting을 먼저 쓴다면, [CivilCraft 설정](topic:settings)에서 **점 행**을 P, E, N, Z, D로 설정하십시오.
3. 미리 보기 표를 확인하십시오. 파일이 어떤 순서를 쓰든 열은 항상 **점**, **Northing**, **Easting**, **표고**, **설명**입니다. 실제 현장의 Northing과 Easting은 보통 크기가 뚜렷이 다릅니다. 둘이 뒤바뀐 것처럼 보이면 추정이 틀린 것입니다.
4. 순서가 틀렸다면 **열**에서 맞는 순서를 고르십시오(예: {{ui:PENZD — point, easting, northing, elevation, description}}). 요약과 미리 보기가 즉시 갱신됩니다.
5. 미리 보기 아래의 **읽지 않은 행**을 확인하십시오. 각 줄에는 파일의 줄 번호, 이유, 행의 시작 부분이 표시됩니다. [읽지 않은 행](topic:import-points#rows-that-are-not-read)을 보십시오.
6. {{ui:Import}} 버튼을 클릭하십시오.
   점이 평면도에 나타나고, 보기가 점들에 맞춰지며, 표면이 만들어집니다. 상태 표시줄에는 예를 들어 "site.csv에서 점 276개를 가져왔습니다. 표면: 삼각형 546개."와 같이 표시됩니다.

프로젝트에 아직 이름이 없다면 파일 이름을 가져옵니다.

## 그룹 확인

모든 점은 **설명의 첫 단어**로 이름 지어진 그룹에 속하며, 대문자로 표시됩니다. "GRD", "FL 12", "fl"은 각각 GRD, FL, FL 그룹입니다. 설명이 없는 점은 "(설명 없음)"에 들어갑니다.

1. 왼쪽 패널의 **점** 아래 표를 보십시오. 그룹, 점 개수, **표면** 선택이 있습니다.
2. 모든 그룹의 기본 설정은 {{ui:Points}}입니다. 흐름선, 포장 가장자리, 사면의 상단과 하단, 능선처럼 코드가 붙은 선은 {{ui:Breakline}} 설정으로 바꾸십시오. 지표면을 만들어서는 안 되는 그룹(기준점, 나무 꼭대기, 꼭대기에서 측량한 전주 등)은 {{ui:Left out}} 설정으로 두십시오.
3. 평면도의 점을 클릭하면({{ui:Select}} 사용) 오른쪽 패널에 그 번호, 좌표, 표고, 설명, 그룹이 표시됩니다.

:::warning
단절선 그룹은 **모든** 점을 점 번호 순서대로 **하나의** 선으로 잇습니다. 각 코드 선을 순서대로 자기 코드로 측량했다면 이것이 맞습니다. 둘 다 "FL"로 코드가 붙은 두 개의 흐름선은 둘 사이를 지그재그로 잇는 한 개의 선이 됩니다. 코드를 공유하고 있다면, 대신 {{ui:Breakline}} 도구로 각 선의 점을 클릭하십시오([표면 만들기와 다듬기](topic:build-surface) 참조).
:::

## 읽지 않은 행

| 표시된 이유 | 의미 | 할 일 |
|---|---|---|
| "Northing 또는 Easting이 숫자가 아닙니다" | 좌표 열에 텍스트가 있습니다 | 열 순서를 확인하거나, 파일 가운데에 있는 텍스트 행을 찾으십시오 |
| "표고가 숫자가 아닙니다" | 표고 열에 텍스트가 있습니다 | 열 순서가 틀렸거나, 표고 열에 설명이 들어 있습니다 |
| "점 번호가 없습니다" | 점 열이 비어 있습니다 | 점에 번호를 매기거나, P가 없는 순서(NEZD, NEZ …)를 고르십시오. 그러면 점은 1, 2, 3 … 으로 번호가 매겨집니다 |
| "점 12가 두 번 나옵니다(첫 번째를 유지함)" | 두 행이 번호를 공유합니다 | 두 점이 모두 실제 측점이라면, 파일에서 하나의 번호를 바꾸십시오 |
| "열 3개, PNEZD 기준 5개 필요" | 행이 짧습니다 | 줄이 깨졌거나 열 순서가 틀렸습니다 |

표고가 비어 있는 점은 유지되지만 표면에는 쓰이지 않습니다. **점** 정보에는 표고가 있는 점의 개수가 표시됩니다.

`#`, `;` 또는 `//`로 시작하는 줄은 주석이므로 건너뜁니다. 빈 줄도 건너뜁니다.

## 점 교체 또는 추가

다시 가져오면 모든 점이 **교체**되며, 추가되지는 않습니다. 선형, 패드, 관, 그린 단절선, 경계는 그대로 남습니다. 실행 취소 기록이 지워지므로, 이전 점이 필요할 수도 있다면 먼저 프로젝트를 저장하십시오. 두 파일을 합치려면 가져오기 전에 텍스트 편집기나 스프레드시트에서 먼저 합치십시오(같은 점 번호가 반복되지 않도록 주의하십시오).

점은 아직 CivilCraft 안에서 옮기거나, 편집하거나, 삭제할 수 없습니다. 파일에서 고친 뒤 다시 가져오십시오.

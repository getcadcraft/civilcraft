측량 팀은 현장에서 모든 측점에 코드를 붙입니다. 포장 가장자리는 `EP`, 연석 상단은 `TC`, 건물 모서리는 `BLDG`입니다. 코드는 점 설명의 첫 단어입니다. CivilCraft는 이 코드로 점을 그룹화하고, 그 뒤의 선 코드를 선으로 바꿉니다.

## 선 코드

선 코드는 현장 코드 바로 뒤의 단어입니다:

| 설명 | 의미 |
|---|---|
| `EP B` | 이 점에서 새 포장 가장자리 선을 시작 |
| `EP` | 현재 EP 선을 계속 |
| `EP E` | 이 점에서 현재 EP 선을 끝냄 |
| `BLDG C` | 건물 닫기: 이 점을 선의 첫 번째 점과 다시 연결 |

같은 코드를 가진 점은 점 번호 순서대로 이어집니다. 그룹을 공유하더라도 코드가 다르면 다른 선이므로, `EP1`, `EP2`는 동시에 두 가장자리를 만듭니다. 선 코드를 쓰지 않는 코드는 이전 버전처럼 모든 점을 따라 이어집니다.

**단절선**으로 쓰이는 그룹의 선은 선마다 하나의 단절선이 됩니다. 그래서 틈이 있는 연석이 그 틈을 가로질러 늘어나지 않습니다. 다른 그룹의 선은 평면도에 그려지며(도면층 V-NODE-LINE), DXF, DWG 및 PDF로 내보내집니다.

시작, 끝, 닫기 단어는 `B`, `BEG`, `START`; `E`, `END`; `C`, `CLO`, `CLOSE`입니다. 이를 바꾸거나 선 코드를 끄려면 아래 대화상자를 사용하십시오.

## 설명 키

설명 키는 코드를 점 그룹, 용도와 긴 설명으로 바꿉니다.

1. **점** 아래에서 {{ui:Description keys and line codes}}를 클릭합니다.
2. {{ui:Add a key}}를 클릭하고 행을 채웁니다:
   - **코드**: 맞출 현장 코드. `*`는 임의의 문자, `?`는 한 문자를 뜻하므로 `EP*`는 EP, EP1, EP12를 모두 잡습니다.
   - **그룹**: 이 점들이 속할 점 그룹(비움 = 코드 자체). `EP*`를 그룹 `EP`로 두면 EP1과 EP2는 한 그룹에 들어가면서도 서로 다른 선으로 남습니다.
   - **용도**: 점, 단절선 또는 제외. 그룹이 처음 나타날 때 적용됩니다(또는 **점** 표에 맡기십시오).
   - **설명**: 긴 이름이며, 점의 **속성**에 표시됩니다.
3. **점** 열은 입력하는 동안 각 키가 잡는 점의 개수를 셉니다. 코드와 일치하는 첫 번째 키가 우선합니다.
4. {{ui:Apply}} 버튼을 클릭합니다. 그룹, 지표면, 평면도가 한 단계로 따라옵니다. {{key:Mod+Z}}로 실행 취소할 수 있습니다.

그룹은 **점** 표에서 받은 용도를 유지합니다. 키의 용도는 새 그룹에 대해서만 설정합니다. 키와 선 코드는 프로젝트 파일에 저장됩니다.

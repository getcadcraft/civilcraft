{{ui:DXF}}는 평면에 보이는 내용을 R12 형식의 DXF 파일로 저장합니다. 이 형식은 모든 CAD 프로그램이 열 수 있습니다. AutoCAD나 Civil 3D를 사용해 본 적이 있다면, 다른 DXF 파일과 같은 방법으로 열거나 삽입하면 됩니다.

## 내보내기

1. 원하는 도면 모양에 맞게 평면을 설정합니다. **표시** 아래에서 지표면(현황 또는 설계), 등고선 간격, 그리고 표시할 항목을 고릅니다(등고선, 라벨, 점, 점 라벨, {{ui:삼각형}}, 단절선, 지표면 가장자리, 관, 경사 화살표).
2. **내보내기** 그룹에서 {{ui:DWG/DXF}}를 클릭하고 {{ui:DXF (R12, 텍스트) — 일반 교환 파일}}을 고른 다음 {{ui:내려받기}}를 클릭합니다.
3. 브라우저가 `<name>.dxf` 파일을 내려받습니다. 상태 표시줄에 예를 들어 "R12 DXF 내보내기: 객체 2,140개; 라벨 크기 기준 1" = 40'. 표고 띠는 내보내지 않습니다."와 같이 표시됩니다.

좌표는 프로젝트 단위로 실제 값 그대로 기록됩니다(주 평면 좌표계 값도 그대로 유지됩니다). 아무것도 축척되거나 이동되지 않습니다.

## 파일에 들어 있는 내용

| 항목 | DXF 객체 | 도면층 |
|---|---|---|
| 보조 및 주 등고선 | 해당 표고의 2D 폴리선 | C-TOPO-MINR, C-TOPO-MAJR |
| 등고선 라벨 | 문자 | C-TOPO-TEXT |
| 삼각형 | 폴리선 | C-TOPO-TINN |
| 단절선과 경계 | 3D 폴리선 | C-TOPO-BRKL |
| 지표면 가장자리 | 폴리선 | C-TOPO-BNDY |
| 경사 화살표 | 폴리선 | C-TOPO-SLOP |
| 측량점과 그 라벨 | 점(표고 포함), 문자 | V-NODE, V-NODE-TEXT |
| 선 코드에서 만든 선 | 3D 폴리선 | V-NODE-LINE |
| 선형 중심선 | 선과 호 | C-ROAD-CNTR |
| 측점 눈금과 라벨 | 폴리선, 문자 | C-ROAD-STAN |
| 도로 구간 가장자리 | 폴리선 | C-ROAD-CORR |
| 샘플 선 | 폴리선 | C-ROAD-SCTN |
| 패드, 사면 끝점선, 경사선 | 폴리선 | C-GRAD-PADS, C-GRAD-DAYL, C-GRAD-SLOP |
| 피처 선 | 3D 폴리선(호는 0.01 이내의 조각으로; [피처 선](topic:feature-lines) 참조) | C-GRAD-FEAT |
| 차량 회전 궤적 | 폴리선, 문자 | C-ROAD-SWPT |
| 관, 구조물, 라벨 | 폴리선, 문자 | C-STRM-PIPE, C-STRM-STRC, C-STRM-TEXT |
| 문제가 있는 관과 구조물 | 폴리선 | C-STRM-PROB |

각 도면층에는 색이 지정되어 있습니다. 전체 목록은 [평면 도면층](topic:plan-layers)에 있습니다.

## 라벨 크기

문자는 도면 단위의 크기를 가져야 합니다. CivilCraft는 전체 평면이 타블로이드 용지(피트 단위)나 A3 용지(미터 단위)에 맞는 축척에 맞춰 라벨 크기를 정하며, 상태 메시지에 그 축척을 알려 줍니다. CAD 프로그램에서 다른 축척으로 출력한다면, 그곳에서 문자 크기를 조정하십시오.

## 내보내지 않는 것

- 표고 띠(화면 전용).
- 종단면도 보기. 종단면은 도면이 아니라 LandXML로 내보냅니다.
- 3D 객체로서의 지표면 자체. TIN이 필요하면 LandXML을 사용하거나, {{ui:삼각형}}을 켜서 삼각형의 가장자리를 선 도형으로 얻으십시오.
- **표시** 아래에서 끈 모든 것.

## DWG

{{ui:DWG/DXF}}는 같은 선 도형을 DWG 도면으로도 저장합니다. 대화상자에서 형식을 묻습니다: DXF 또는 2000, 2004, 2007, 2010, 2013, 2018 형식의 DWG. 2000 형식은 오래된 프로그램과 최신 프로그램 거의 모두에서 열립니다. 도면을 받는 사람이 요청하면 더 새로운 형식을 고르십시오. 선택한 형식은 이 브라우저에 기억됩니다.

1. **내보내기** 그룹에서 {{ui:DWG}}를 클릭합니다.
2. **형식**을 고르고 **DWG 내려받기**를 클릭합니다.
3. 브라우저가 `<name>.dwg` 파일을 내려받습니다. 상태 표시줄에 무엇이 들어갔는지 표시됩니다. 예: "DWG 내보내기(2018 형식): 폴리선 12개, 라벨 40개, 도면층 9개"

DWG에는 DXF와 같은 도면층, 색, 등고선(해당 표고의 폴리선), 3D 단절선, 라벨, 점이 같은 좌표로 들어 있습니다. DWG가 담을 수 없는 도면층 이름은 바뀌며, 상태 메시지에 그 사실이 표시됩니다. CivilCraft는 자체 코드로 DWG를 쓰므로 어떤 것도 컴퓨터 밖으로 나가지 않습니다.

### DWG의 지도 레이어

DWG 도면은 내부에 그림을 담을 수 없습니다. CAD 프로그램은 도면 옆에 놓인 그림으로 보여 줍니다. 지도 레이어가 표시되어 있으면 대화상자에 **지도 레이어를 도면 옆의 그림으로** 옵션이 나타납니다. 이를 선택하면 내려받는 파일은 `<name>.zip`이며, 여기에는 `<name>.dwg`, `<name>-map.png`(도면 전체에 걸친 지도 레이어, 가로 최대 4,096픽셀), `<name>-map.pgw`(GIS 프로그램용 월드 파일)가 들어 있습니다. 도면에는 G-MAP-IMAG 도면층에 이미지로 제자리에 표시됩니다. 파일을 한 폴더에 풀고 함께 보관하십시오.

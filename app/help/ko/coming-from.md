Civil 3D를 사용해 보았다면 CivilCraft의 개념은 이미 알고 있습니다. 점과 점 그룹, 단절선과 경계가 있는 TIN 지표면, PI로 만드는 선형, PVI로 만드는 종단면도, 조립체를 쓸어 만드는 도로 구간, 지표면에 맞춘 사면 끝점까지의 정지, 중력식 관망, LandXML이 그렇습니다. 다른 점은 이들을 둘러싼 거의 모든 것입니다. 도면 파일이 없고, 명령행이 없으며(제도 클래식 메뉴 방식을 고르지 않는 한), 스타일도, Prospector도, 설정 대화상자도 없습니다. CivilCraft는 브라우저에서 작동하는 작고 집중된 도구이며, 이 빌드에서는 완전한 토목 패키지가 하는 일의 일부만 합니다. 이 페이지는 익숙한 것이 여기에서 무엇에 해당하는지 연결해 줍니다.

:::tip
Civil 3D의 리본이 익숙하다면, {{ui:설정}} › {{ui:CivilCraft}} › {{ui:메뉴, 키, 마우스}}에서 {{ui:토목 리본}} 메뉴 방식을 고르십시오. 홈, 지표면, 수정, 지리 위치, 보기 및 출력 탭이 생기며, 가운데 버튼으로 초점을 이동하고, {{key:Shift}} 키와 가운데 버튼으로 3D 보기를 궤도 회전합니다. 명령을 입력하려면 {{ui:제도 클래식}} 방식이 명령행(ALIGNMENT, PAD, PROFILE, ZOOM …)을 추가합니다. 참조: [메뉴, 키, 마우스](topic:menus-keys-and-mouse)
:::

## 작업 흐름 대응표

| 하고 싶은 일 | 익숙한 방식 | CivilCraft에서 |
|---|---|---|
| 측량 점 가져오기 | 점 파일 형식으로 점 가져오기 | {{ui:열기}} 후 **측량 점 가져오기** 대화상자에서 열 순서를 확인([측량 점 가져오기](topic:import-points)) |
| 점 정렬 | 점 그룹, 설명 키 | 설명의 첫 단어로 자동 그룹화됨. 설명 키는 없음 |
| 점 편집 | 점 편집기, 그립 | 클릭하고 **속성**에 입력하거나 끌기([측량 점 편집](topic:edit-points)) |
| 기존 지반 만들기 | 지표면 만들기, 점 그룹을 데이터로 추가 | 자동: 입력이 바뀔 때마다 지표면이 다시 만들어짐 |
| 단절선 추가 | 폴리선 또는 지형선으로 단절선 추가 | 점 그룹을 {{ui:단절선}} 값으로 설정하거나, {{ui:단절선}} 도구({{key:B}})로 점 클릭 |
| 지표면 다듬기 | 외곽 경계, 숨김 경계, 최대 삼각형 길이 | {{ui:경계}}({{key:O}}, 바깥만) 및 **가장 긴 바깥 모서리** |
| 등고선 표시 | 지표면 스타일 | 왼쪽 패널의 **표시**: 간격, 주곡선 간격, 라벨, 띠, 경사 화살표 |
| 중심선 배치 | 선형 작성 도구, 곡선 및 나선 설정 | {{ui:선형}}({{key:A}}): PI 클릭 후 {{key:Enter}} 키. 반지름과 나선 길이는 PI 표에서 입력 |
| 종단면도 보기 만들기 | 종단면도 보기 마법사, 띠 | {{ui:종단면도}}({{key:R}}): 평면 아래에 종단면도 보기 하나, 항상 맞춤 |
| 경사 설계 | 종단면 배치 도구 | {{ui:지반에서 시작}}, {{ui:PVI 추가}}({{key:I}}), PVI 끌기, **곡선 L** 입력 |
| 도로 만들기 | 조립체, 하위 조립체, 도로 구간, 대상, 영역 | 선형 아래에서 **설계 종단면을 따라 조립체 쓸기**를 체크. 양쪽마다 차로, 갓길, 측면 경사, 또는 부품(측구, 연석, 보도 …)으로 만든 쪽 |
| 패드 정지 | 지형선, 정지 그룹, 정지 기준 | {{ui:패드}}({{key:G}}): 절토와 성토 사면이 사면 끝점까지 이어지는 평평한 패드 |
| 토공 계산 | 체적 지표면, 체적 대시보드 | 오른쪽 패널의 **토공**, 격자 방법, 실시간 갱신 |
| 우수 또는 오수 배관 배치 | 부품 목록과 규칙이 있는 관망 | {{ui:관}}({{key:P}}): 하류 구조물을 클릭. 사용자가 정하는 규칙 세 가지. 관저 자동 계산 |
| 다른 프로그램과 교환 | LandXML 가져오기 및 내보내기 | LandXML 파일은 {{ui:열기}}로 열고, 내보내기는 {{ui:LandXML}} 버튼([LandXML 교환](topic:landxml)) |
| 선형 데이터를 CAD로 보내기 | DWG로 내보내기 | {{ui:DWG}}(2000에서 2018 형식) 또는 {{ui:DXF}}(R12) |
| 플롯 | 레이아웃, 뷰포트, 시트 세트 | {{ui:PDF}}: 선택한 축척의 평면 가로 시트 한 장. 평면 및 종단면 시트와 단면 시트를 PDF로 |
| 파일 사이에서 작업 공유 | 데이터 바로 가기, 참조 | 지원하지 않음: 파일 하나에 프로젝트 하나 |
| 실행 취소 | 실행 취소 | {{key:Mod+Z}} 및 {{key:Mod+Y}}, 200단계. 표시 설정은 실행 취소 단계가 아닙니다 |

## 헷갈리기 쉬운 차이점

**명령행이 없습니다.** {{ui:제도 클래식}} 메뉴 방식을 고르지 않는 한 그렇습니다. 도구는 도구 모음 버튼과 한 글자 단축키입니다: {{key:A}} 선형, {{key:G}} 패드, {{key:P}} 관, {{key:B}} 단절선, {{key:O}} 경계, {{key:R}} 종단면도, {{key:I}} PVI 추가, {{key:V}} 선택, {{key:F}} 맞춤. 다른 메뉴 방식에서는 명령 이름을 입력해도 아무 일도 일어나지 않습니다. 참조: [키와 마우스](topic:keyboard)

**Enter 키로 완료하며, 더블클릭은 위험합니다.** 마지막 점을 한 번 클릭한 다음 {{key:Enter}} 키를 누르십시오. 이 빌드에서는 더블클릭으로도 완료되지만, 더블클릭한 점이 제거됩니다. 오른쪽 버튼 클릭은 완료하거나 반복하지 않으며, 끌 때만 화면을 이동합니다.

**모든 것이 항상 동적입니다.** 점 그룹, 반지름, PVI 또는 패드 경사를 바꾸면 지표면, 등고선, 도로 구간, 사면 끝점선, 토량이 즉시 갱신됩니다. 다시 만들 것이 없으며, 오래된 것도 없습니다.

**도면 객체는 없습니다.** 평면은 설계를 보여 주는 화면이며, CAD 명령으로 편집할 수 있는 도면이 아닙니다. 직접 선이나 문자를 추가할 수 없고, 도면층의 색을 바꿀 수 없으며, 무엇이든 분해할 수 없습니다. DXF로 내보낸 다음 CAD 프로그램에서 도면을 마무리하십시오.

**스타일이 없습니다.** 색, 선 가중치, 라벨 크기, 도면층 이름은 고정되어 있습니다(참조: [평면 도면층](topic:plan-layers)). 앱 막대의 **종이**와 **모델**은 밝은 화면과 어두운 화면을 전환합니다.

**프로젝트마다 하나씩입니다.** 프로젝트마다 기존 지반 지표면 하나, 정지 결과 하나, 관망 하나입니다. 선형과 패드는 여러 개 있어도 괜찮습니다.

**단위는 표시일 뿐입니다.** {{ui:미국 측량 피트}} 또는 {{ui:미터}} 단위를 선택해도 아무것도 변환되지 않습니다. 도면 축척은 없습니다. 좌표계는 선택 사항입니다. {{ui:좌표}} 아래에서 설정해도 아무것도 움직이지 않으며, 숫자가 무엇을 뜻하는지 밝힐 뿐입니다(참조: [프로젝트 좌표계 설정](topic:coordinate-systems)). LandXML로 쓸 때 피트는 미국 측량 피트로 취급됩니다.

**단절선 그룹은 점 번호 순서로 이어집니다.** {{ui:단절선}} 값으로 설정된 그룹은 번호 순서대로 모든 점을 지나는 한 줄이 됩니다. 코드를 공유하면(두 흐름선이 모두 "FL"로 코드가 붙은 경우) 지그재그 한 줄이 되므로, 그런 것은 직접 그리십시오.

**측점 표기는 같지만 미터는 다릅니다.** 피트는 100 ft 측점(12+34.56)을, 미터는 1000 m 측점(1+234.567)을 씁니다.

**Mac에서 삭제.** delete라고 표시된 Mac 키는 브라우저에서 Backspace 역할을 합니다. 선택 항목을 삭제하려면 Fn 및 delete 키를 사용하거나 {{ui:삭제}} 버튼을 사용하십시오.

**파일은 다운로드됩니다.** {{ui:저장}} 버튼을 누르면 매번 `.civilcraft.json` 파일이 다운로드됩니다. "열린 파일에 덮어쓰기" 저장은 없습니다. 저장하지 않은 작업의 복구 사본은 이 브라우저에 보관됩니다([저장하지 않은 작업 복구](common:recover)). 점 파일을 열면 묻지 않고 점이 교체됩니다. 참조: [열고, 저장하고, 내보낼 수 있는 파일](topic:files)

**규칙은 사용자가 정합니다.** 관망 규칙과 도로 구간의 조립체는 표준이 아닌 임시 값으로 시작합니다. 검사를 믿기 전에 직접 설정하십시오.

**토량은 격자 기반입니다.** 절토와 성토는 두 지표면 사이, 사면 끝점선 안쪽의 촘촘한 격자에서 나오며, 팽창과 수축은 적용하지 않습니다. TIN 간 토량과 가깝지만 같지는 않습니다.

## 아직 만들지 않은 기능

클로소이드 이외의 나선, 도로를 따라 바뀌는 조립체, 경사진 패드, 유입구 용량 및 저류, 부품 카탈로그, 종단면도의 관, 필지 배치 및 필지 크기 산정, 최소제곱 조정과 측량 데이터베이스, DWG 열기 등이 빠져 있으며, 그 밖에도 있습니다. 지금 대신 할 수 있는 방법을 포함한 전체 목록은 [아직 만들지 않은 기능](topic:not-built-yet)에 있습니다.

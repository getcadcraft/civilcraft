CivilCraft에서는 컴퓨터의 파일을 열고, 저장하면 파일이 컴퓨터에 다운로드됩니다. 파일은 업로드되지 않으며 서버에 보관되지 않습니다. 함께 보기: [내 파일](common:your-files).

## 열 수 있는 파일

{{ui:열기}} 버튼을 클릭하거나({{key:Mod+O}} 키) 파일을 선택하거나, {{pick:mac=Finder|windows=파일 탐색기|linux=파일 관리자}}에서 파일을 평면 위에 끌어다 놓습니다. 한 번에 파일 하나만 열 수 있으며, 크기가 200 MB를 넘는 파일은 열 수 없습니다.

| 종류 | 파일 이름 | 동작 |
|---|---|---|
| 점 파일 | `.csv`, `.txt`, `.pnt`, `.xyz` (텍스트 파일 아무거나) | **점 가져오기** 대화상자가 열립니다. 가져온 점이 프로젝트의 기존 점을 대체하며, 선형, 패드, 관로는 그대로 남습니다. |
| LandXML | `.xml`, `.landxml` | 파일에서 새 프로젝트 하나가 만들어집니다(현재 프로젝트에 저장되지 않은 변경 사항이 있으면 먼저 묻습니다). |
| CivilCraft 프로젝트 | `.civilcraft.json` (`.json` 파일 아무거나) | 저장된 상태 그대로 프로젝트가 열립니다(현재 프로젝트에 저장되지 않은 변경 사항이 있으면 먼저 묻습니다). |

프로그램은 먼저 파일 확장자를 보고, 다음으로 파일의 첫 글자를 봅니다. `{`로 시작하는 텍스트는 프로젝트로, `<`로 시작하는 텍스트는 LandXML로 읽고, 그 밖의 텍스트는 점 파일로 읽습니다. 열기 상자에서 흐리게 표시된 파일도 평면 위에 끌어다 놓을 수 있습니다.

:::note
점이 있는 프로젝트에 점 파일을 가져오면 묻지 않고 기존 점을 대체하며, 실행 취소 기록도 지워집니다(파일을 열면 실행 취소는 새로 시작합니다). 표면이 LandXML에서 왔다면 점을 가져올 때 표면이 점에서 만든 표면으로 되돌아갑니다. 기존 점을 되돌리고 싶을 수 있다면 먼저 저장하십시오.
:::

자세한 내용: [점 파일 형식](topic:point-file-formats), [LandXML: 읽고 쓰는 내용](topic:landxml-reference).

## 저장되는 파일

{{ui:저장}} 버튼({{key:Mod+S}})을 누르면 왼쪽 패널의 **이름** 기준으로 파일 두 개가 나란히 저장됩니다. `<name>.civilcraft.json`은 계속 편집하는 프로젝트이고, `<name>.ifc`는 같은 설계를 IFC 4.3 형식으로 담아 다른 사용자가 쓸 수 있는 파일입니다([IFC 내보내기 및 가져오기](topic:ifc) 참조). 각 파일은 서로를 기록합니다. IFC에는 프로젝트의 압축 사본도 들어 있어, IFC 파일만 따로 보내도 편집할 수 있는 상태로 다시 열립니다.

- **Studio에서는** 두 파일이 제자리에 나란히 저장됩니다.
- **Chrome 및 Edge에서는** 처음 저장할 때 폴더를 묻고 두 파일을 그 폴더에 씁니다. 이후 저장은 같은 폴더로 갑니다. 폴더 질문을 취소하면 대신 두 파일을 다운로드합니다.
- **다른 브라우저에서는** 두 파일이 모두 다운로드되며, 프로젝트 파일이 먼저입니다.

파일을 열면 짝이 되는 다른 파일을 찾습니다. 두 파일을 함께 열거나(또는 둘 다 끌어다 놓거나) 하나만 열 수 있습니다. Studio에서는 같은 폴더에서 다른 파일을 찾고, 브라우저에서는 짝 파일을 추가할지 묻거나 가진 파일만으로 계속할지 묻습니다. CivilCraft가 저장한 뒤 다른 프로그램이 IFC를 바꾸었거나 한 파일이 다른 파일보다 오래되었다면, 더 새로운 설계에서 프로젝트를 열고 문제 패널에 상황이 표시됩니다. 패널에는 **지금 저장**(두 파일을 다시 씀)과 **IFC의 형상을 참조로 표시** 버튼이 있습니다. 다른 프로그램이 바꾼 IFC만 따로 열면, 그 IFC의 프로젝트 사본에서 일치하는 부분만 열립니다. 변경된 선형은 IFC의 형상을 쓰고, 삭제된 객체는 빠지며, 나머지 변경 사항은 적용하지 않고 목록으로만 표시됩니다. 0.7.1 이전의 프로젝트 파일은 이전과 같이 열립니다.

프로젝트 파일에는 다음이 저장됩니다.

- 모든 점(번호, 좌표, 고도, 설명)과 그 점이 온 점 파일의 이름
- 표면 설정: 그룹 선택, 그려진 단절선, 경계, 가장 긴 바깥 모서리, LandXML에서 읽은 TIN
- 표시 설정
- 선형과 PI, 반지름, 시작 측점, 설계 종단면(PVI와 곡선 길이), 도로 구간 설정
- 패드와 규칙이 있는 관로망

실행 취소 기록은 저장하지 않습니다. 표면, 등고선, 채광선, 토량은 저장하지 않고, 프로젝트를 열 때 저장된 입력으로부터 다시 만듭니다. 더 새로운 CivilCraft에서 만든 프로젝트 파일은 버전을 밝히는 메시지와 함께 열리지 않습니다.

## 내보낼 수 있는 파일

| 버튼 | 파일 | 내용 |
|---|---|---|
| {{ui:LandXML}} | `<name>.xml` | LandXML 1.2: 점, 기존 지반(설계 표면이 있으면 설계 표면도)을 TIN 표면으로, 선형, 지반 및 설계 종단면, 관로망 |
| {{ui:DXF}} | `<name>.dxf` | 화면에 표시된 그대로의 평면 선 도형을 이름 있는 도면층에 담은 R12 DXF |
| {{ui:DWG}} | `<name>.dwg` | 같은 선 도형을 DWG 도면으로 저장합니다. 형식은 2000부터 2018까지 중에서 고릅니다 |
| {{ui:PDF}} | `<name>.pdf` | 선택한 축척으로 시트에 그린 평면의 벡터 플롯 |
| {{ui:GLB}} 또는 {{ui:OBJ}} (3D 보기 막대에 있음) | `<name>-3d.glb`, `<name>-3d.obj` | 3D 보기에 보이는 3D 모델: 미터 단위, Y축이 위, 실제 축척, 기록된 로컬 원점 기준 |

각 내보내기에서 빠지는 내용: [LandXML 교환](topic:landxml), [평면을 DXF로 내보내기](topic:dxf-export) (DWG도 같음), [평면을 PDF로 플롯](topic:plot-pdf), [대지를 3D로 내보내기](topic:export-3d).

## 파일이 저장되는 위치

저장하거나 내보낸 파일은 브라우저가 다운로드를 보내는 곳(보통 다운로드 폴더)에 저장됩니다. 매번 폴더를 고르려면 다음과 같이 하십시오.

:::chromium
브라우저의 **설정**을 열고 **다운로드**에서 **다운로드하기 전에 각 파일을 저장할 위치 묻기**를 켭니다.
:::

:::firefox
**설정**을 열고 **일반**에서 **파일 및 애플리케이션** 항목의 **파일을 저장할 위치를 항상 묻기**를 고르십시오.
:::

:::safari
**Safari > 설정 > 일반**을 열고 **파일 다운로드 위치**를 **각 다운로드마다 묻기**로 설정합니다.
:::

같은 이름으로 두 번 저장하면 브라우저가 두 번째 파일에 번호를 붙일 수 있습니다(예: `Site (1).civilcraft.json`). 다음번에는 가장 최근 파일을 여십시오.

## 온라인과 오프라인

두 경우 모두 컴퓨터에서만 작동합니다. 열기는 브라우저에서 파일을 읽고, 저장은 파일을 다운로드합니다. 연결이 전혀 없을 때도 열려면 먼저 오프라인 사용을 위해 저장하십시오.

1. 온라인 상태에서 상단 앱 바의 {{ui:오프라인용 저장}} 버튼을 클릭합니다.
2. 버튼에 "저장 중 12 / 30"처럼 진행 상황이 표시되고, 끝나면 {{ui:오프라인 사용 준비됨}}가 표시됩니다. 앱은 약 0.6 MB로 작아서 잠시 걸립니다. 저장된 사본에는 이 도움말과 예제 대지도 들어 있습니다.
3. 연결이 없는 상태에서 같은 주소(또는 그 주소의 즐겨찾기)를 여십시오. 모든 기능이 동작하며, {{ui:예제 대지 열기}}도 포함됩니다.

버튼의 다른 상태는 다음과 같습니다.

- {{ui:저장하지 못했습니다}}: 일부 파일을 다운로드하지 못했습니다. 연결을 확인하고 다시 누르십시오.
- {{ui:오프라인 사용 불가}}: 이 브라우저 창은 오프라인 사본을 보관할 수 없습니다(비공개 창과 일부 관리되는 컴퓨터는 이를 막습니다). 일반 창을 사용하십시오.

{{ui:오프라인 사용 준비됨}}를 클릭하면 사본이 저장된 시점을 볼 수 있고, 두 가지 중 하나를 고를 수 있습니다: {{ui:다시 저장 (최신 버전 받기)}} 및 {{ui:오프라인 사본 제거}}. 현장 방문 전에는 사본이 최신 빌드와 맞도록 다시 저장하십시오. 자세한 내용은 [오프라인](common:offline) 항목을 보십시오.

:::offline
지금 오프라인 상태입니다. 앱이 오프라인용으로 저장되었다면 예제 대지를 포함해 모든 기능이 동작합니다. 저장되지 않았다면 이 탭에서 계속 작업할 수 있지만, 온라인으로 돌아갈 때까지 새로 고치지 마십시오. 저장된 사본이 없으면 {{ui:예제 대지 열기}}는 "예제를 불러올 수 없습니다"라는 메시지와 함께 실패합니다.
:::

:::tip
현장에서는 앱을 오프라인용으로 저장하고, 점 파일을 노트북에 직접 넣어 두십시오. 연결이 없어도 프로젝트와 내보내기는 다운로드로 저장되므로, 하루 동안 측량한 데이터를 가져와 표면을 확인하고 현장에서 프로젝트를 저장할 수 있습니다.
:::

클라우드 저장은 아직 사용할 수 없고, 데스크톱 빌드도 아직 나오지 않았습니다. 지금은 저장한 파일이 유일한 사본이므로, 백업되는 곳에 보관하십시오.

## 파일이 사용하는 애드온

애드온의 데이터(건축 법규 체크 항목 또는 주소 기반 현장 소스)를 담은 프로젝트를 저장하면, 파일에 사용한 애드온과 버전이 기록됩니다. 애드온이 없는 컴퓨터에서 파일을 열면 평면 위에 알림 막대가 나타나 계정의 목록에서 애드온을 추가할지 묻습니다. 이 기록은 참고용이므로 파일은 어느 쪽이든 열립니다.

## Studio에서 실행 취소

CadCraft Studio 안에서는 CivilCraft에서 마친 각 단계가 Studio에 알려집니다. 그래서 Studio의 프로젝트 단위 실행 취소가 여러 앱에 걸쳐 가장 최근 단계를 되돌릴 수 있습니다. Studio는 CivilCraft 자체 실행 취소 스택이 그 단계를 끝냈을 때 그대로인 경우에만 단계를 되돌립니다. 다른 파일을 연 뒤에는 이 구간을 건너뜁니다.

## 저장되지 않은 변경 사항이 있을 때 닫기

프로젝트에 저장되지 않은 변경 사항이 있는데 탭을 닫거나, 새로 고치거나, 페이지를 떠나면 브라우저가 떠날지 묻습니다. 그 문구와 모양은 브라우저가 정하며 CivilCraft가 바꿀 수 없습니다. {{ui:새로}}를 누르거나 프로젝트 또는 LandXML 파일을 열면, 대신 CivilCraft 자체의 **저장되지 않은 변경 사항** 상자가 열리며, 여기에는 {{ui:취소}}, {{ui:저장하지 않음}}, {{ui:복사본 저장}} 버튼이 있습니다.

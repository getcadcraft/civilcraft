## 기능

지표면 › 더 보기 › 주소에서 대상지 정보 얻기는 한 지점에 대해 다음을 알려 줍니다: 그 지점이 속한 필지, 주변 건물, 용도 지역, 토양, 홍수 구역. 데이터는 공개 데이터입니다. 직접 추가하는 파일(GeoJSON, shapefile, KML, GeoPackage)과, 추가 기능을 켜면 나타나는 버튼을 사용합니다. 각 버튼은 공개 서비스 하나에 요청합니다.

## 사용 방법

1. 주소를 입력하고 주소 검색 버튼(추가 기능 "주소 검색")을 누르거나, 위도와 경도를 입력합니다.
2. "파일 추가"로 파일을 추가하거나, 다른 소스 버튼(홍수 구역, 건물, 토양, 지반 높이, 군 단위 필지)을 사용합니다. 서비스는 해당 버튼을 누를 때만 요청되며, 시작할 때는 아무것도 가져오지 않습니다.
3. 실행 버튼을 누르면 문장으로 된 결과와 CSV를 받습니다.
4. "대상지를 파일로 저장" 또는 "BimCraft에 제안으로 보내기"를 누르면 윤곽선이 BimCraft 또는 ModelCraft로 전달됩니다. 두 프로그램은 윤곽선을 목록으로 보여 주며, 사용자가 체크한 항목만 추가합니다.

## 알아 둘 점

- 주소 검색은 getcadcraft.com을 거쳐 OpenStreetMap의 Nominatim에 요청합니다. 요청은 최대 초당 한 번이며, 응답은 90일간 보관하므로 같은 주소를 다시 묻지 않습니다. 저장되는 것은 주소의 해시뿐이며, 누가 요청했는지는 저장하지 않습니다. 다른 버튼은 브라우저에서 각 서비스로 직접 요청합니다.
- 각 데이터 소스에는 고유한 라이선스가 있습니다. OpenStreetMap은 ODbL이므로 출처 표시 문구를 유지하십시오.
- 레이어의 정확도는 지역의 공개 데이터 수준에 따릅니다. 중요한 사항은 측량 자료와 대조해 확인하십시오.

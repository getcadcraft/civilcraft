CivilCraft에는 설정 대화상자나 템플릿이 없습니다. 아래는 항목이 시작하는 값입니다. **자리 표시자**로 표시된 값은 어떤 표준에서도 가져온 것이 아닙니다. 검사나 물량에 의존하기 전에 프로젝트 기준으로 바꾸십시오.

## 새 프로젝트

| 설정 | 값 |
|---|---|
| 이름 | 이름 없는 현장 (첫 점 파일의 이름이 이를 대체합니다) |
| 단위 | US 피트 |
| 지표면 이름 | {{ui:Existing ground}} |
| 점 그룹 | 모든 그룹은 {{ui:Points}} 용도로 시작합니다 |
| 가장 긴 바깥 모서리 | 0 (모든 삼각형 유지) |
| 보관하는 실행 취소 단계 | 200 |

## 표시

| 설정 | 값 |
|---|---|
| 지표면 | {{ui:Existing ground}} |
| 등고선 간격 | 1 (ft 또는 m) |
| 주등고선 간격 | 다섯 번째 등고선 |
| 띠 수 | 8 |
| 켜짐 | 등고선, 등고선 라벨, 점, 단절선, 지표면 가장자리, 배관 |
| 꺼짐 | 삼각형, 표고 띠, 사면 화살표, 점 라벨 |

## 선형과 종단면

| 설정 | 값 |
|---|---|
| 이름 | {{ui:Alignment}} 1, {{ui:Alignment}} 2 … |
| 시작 측점 | 0+00 |
| 각 내부 PI의 곡선 반경 | 100 ft 또는 30 m, 각 접선의 절반에 맞지 않으면 더 작게 |
| 설계 종단면도 | 시작하기 전까지는 없음. {{ui:Start from the ground}} 기능은 각 끝의 지반에 PVI를 둡니다 |
| 종곡선 길이 | 입력할 때까지 0(곡선 없음) |

## 패드

| 설정 | 값 |
|---|---|
| 이름 | 패드 1, 패드 2 … |
| 표고 | 패드 중심의 지반, 0.1 단위로 반올림 (중심이 지표면 밖이면 0) |
| 절토 경사 | 2 : 1 (자리 표시자) |
| 성토 경사 | 3 : 1 (자리 표시자) |

## 구간 어셈블리 (자리 표시자)

| 설정 | US 피트 | 미터 |
|---|---|---|
| 차로 너비 | 12 ft | 3.6 m |
| 차로 경사 | 2% | 2% |
| 갓길 너비 | 4 ft | 1.2 m |
| 갓길 경사 | 4% | 4% |
| 절토 경사 | 2 : 1 | 2 : 1 |
| 성토 경사 | 3 : 1 | 3 : 1 |
| 단면 간격 | 10 ft | 5 m |

## 배관망

| 설정 | US 피트 | 미터 |
|---|---|---|
| 이름과 종류 | 우수 (Storm), 우수 (storm) | 우수 (Storm), 우수 (storm) |
| 최소 경사 (자리 표시자) | 0.50% | 0.50% |
| 최소 덮개 (자리 표시자) | 2 ft | 0.6 m |
| 구조물 낙차 (자리 표시자) | 0.10 ft | 0.03 m |
| 새 구조물 지름 | 48 in | 1200 mm |
| 새 관 지름 | 12 in | 300 mm |
| 집수정 깊이 | 0 | 0 |
| 림 | 지표면에서 | 지표면에서 |

LandXML에서 연 배관망도 이 규칙을 사용합니다. LandXML은 이 규칙을 담지 않기 때문입니다.

## 토량

| 설정 | 값 |
|---|---|
| 방법 | 격자, 사면 끝점선 안쪽의 셀 중심에서 샘플링 |
| 셀 크기 | 정지된 면적의 경계 사각형에 셀이 약 250,000개 들어가도록 선택(10의 거듭제곱에 1, 2 또는 5를 곱한 값) |
| 팽창과 수축 | 없음 |

## 플롯

| 설정 | 값 |
|---|---|
| 영역 | {{ui:Everything}} |
| 용지 | Tabloid 11 × 17 in (피트 프로젝트), ISO A3 (미터 프로젝트); 항상 가로 방향 |
| 축척 | 모든 것이 들어가는 가장 큰 목록 축척 |
| 잉크 | {{ui:Layer colors}} |

DXF 라벨은 모든 것이 Tabloid(피트) 또는 A3(미터)에 들어가는 축척에 맞춰 크기가 정해집니다.

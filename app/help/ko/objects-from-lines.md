{{ui:From a line}} 명령(조경 › {{ui:More}})을 실행한 다음, 피처 선을 클릭하거나 가져온 DWG/DXF 레이어의 선 또는 윤곽을 클릭합니다. 닫힌 선으로는 포장, 잔디밭, 식재 화단, 초원, 지피식물, 화단 또는 플랫폼을 만들 수 있고, 열린 선으로는 길, 벽, 연석, 계단(첫 점과 마지막 점 사용), 경사로, 생울타리 또는 배수로를 만들 수 있습니다. 어느 쪽이든 **피처 선**을 만들 수 있지만, 피처 선 자체는 제외됩니다.

## 선에서 만든 피처 선

선에서 만든 피처 선은 선의 점을 그대로 가져오며, 선이 닫혀 있었다면 닫힌 상태가 됩니다. 높이는 현황 지반에 맞춰 설정되며(아직 지반이 없으면 0), 사용 방식은 **끔**입니다. 즉 사용 방식을 고르고 속성에서 높이를 설정하기 전에는 지반을 바꾸지 않습니다. 선이 움직일 때 점 개수가 같은 피처 선은 설정해 둔 각 높이를 유지하며, 점이 늘거나 줄면 높이를 지반에 다시 맞춥니다. [피처 선](topic:feature-lines)을 참조하십시오.

새 객체는 원래 선에 대한 **연결**을 유지합니다. 선이 움직이면(점을 끌거나 도면을 옮기거나 다시 읽을 때) 객체는 같은 실행 취소 단계에서 새 모양을 따르고, 지반 수정자를 통해 계획 지반도 따라갑니다. 속성에는 연결된 대상이 표시되며, {{ui:Break link}} 명령을 쓰면 연결이 끊어집니다.

선은 먼저 검사합니다. 선에는 최소 2개(윤곽은 3개)의 점이 필요하고, 최대 5000개까지이며, 모두 실수여야 합니다. 윤곽은 닫혀 있어야 하며 스스로 교차하면 안 됩니다. 검사에 실패한 선은 사용되지 않으며, 객체는 이전 상태를 유지하고 문제 패널에 이유가 표시됩니다. 선을 삭제하면 객체는 남고 문제 패널에 그 사실이 기록됩니다.

## SuperCad Studio에서

같은 프로젝트에서 현장과 2D 도면을 엽니다. 2D 도면에서 선 또는 폴리선 하나를 고르고 {{key:Ctrl+K}} 키를 누른 다음 "선택한 도면 선으로 조경 객체 만들기" 명령을 실행합니다. CivilCraft가 위에서처럼 무엇을 만들지 묻고, 객체는 도면의 그 선에 계속 연결됩니다. 도면에서 선을 바꾼 뒤 {{key:Ctrl+K}} 키를 누르고 "도면에서 조경 업데이트" 명령을 실행하면 객체가 따라가며, 선마다 실행 취소 단계가 하나씩 생깁니다. 프로젝트의 연결 파일에는 어떤 객체가 어떤 선을 따르는지 기록됩니다. SuperCad Studio 자체 도움말에 조경 항목이 있습니다.

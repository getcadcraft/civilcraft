## 배울 내용

AI 어시스턴트(MCP를 지원하는 어시스턴트 모두)가 지금 열린 대지에서 작업하도록 하는 방법, 어시스턴트가 할 수 있는 일과 할 수 없는 일, 그리고 연결을 끊는 방법을 설명합니다.

## CivilCraft에서 어시스턴트가 할 수 있는 일

| 요청 항목 | 받는 내용 | 필요 권한 |
|---|---|---|
| 대지 | 이름, 단위, 좌표계, 점 그룹, 선형, 지표면, 패드, 필지, 관 | 읽기 |
| 측량 점 | 번호, Easting, Northing, 높이, 설명. 그룹별, 설명별 또는 상자 안에 있는 점 | 읽기 |
| 지표면 높이 | 요청한 지점의 지반 높이(또는 설계된 지표면 높이) | 읽기 |
| 측점과 오프셋 | 선형을 따라 있는 점의 측점과 오프셋, 또는 측점의 좌표와 지반 높이 | 읽기 |
| 종단면 | 선형을 따라 지정한 간격(피트 또는 미터)마다 지반, 설계 종단면, 설계 지표면의 높이 | 읽기 |
| 절토와 성토 | 지반과 설계 지표면 사이의 토량(각 패드와 도로 구간 포함), 또는 지반과 기준 수평면 사이의 토량 | 읽기 |
| 필지 | 모서리, 면적(에이커 또는 헥타르 단위), 둘레, 법적 기술서 | 읽기 |
| 선택 | 어시스턴트가 지정한 점이 평면에서 사용자가 직접 고른 것처럼 선택됨 | 편집 |
| 새 측량 점 | 어시스턴트가 지정한 번호 또는 다음 빈 번호로 추가된 점. 각 호출은 실행 취소할 수 있는 한 단계입니다 | 편집 |
| 저장 | CivilCraft 자체의 {{ui:저장}} | 저장 |
| LandXML 또는 DWG | {{ui:LandXML}} 및 {{ui:DWG}} 버튼과 같은 파일 | 내보내기 |
| 3D 대지 | 3D 보기가 내보내는 지반, 설계 지표면, 패드, 관의 OpenUSD(.usdz, .usda 또는 .usdc) | 내보내기 |
| 식재와 식재 일람표 | 식물 목록에서 어떤 이름으로든 찾은 식물과 식재 일람표의 수량 | 읽기 |
| 식재와 정지 | 식물, 화단 또는 생울타리를 배치하거나, 플랫폼, 둑, 배수로, 정지 구역을 추가. 각각 실행 취소할 수 있는 한 단계이며 절토와 성토를 포함 | 편집 |
| 관개 검사 | 각 구역의 유량, 밸브와 공급원에서 필요한 수압, 최악의 경우 수두, 운전 시간, 문제점, 부품표. 관개 설계자가 확인하는 계산 보조 자료로 제공 | 읽기 |

열려 있는 대지에서 작동합니다. Studio에서는 아래에서 선택한 폴더에 저장하고 내보낼 수도 있습니다. 폴더가 없으면 파일은 버튼으로 할 때와 같이 다운로드됩니다.

## 켜기

어시스턴트는 사용자의 컴퓨터에서 CadCraft Studio를 통해 CivilCraft에 연결됩니다. 일반 브라우저로는 연결할 수 없습니다.

1. {{ui:설정}} 창을 열고 **CivilCraft** 탭을 선택합니다.
2. **어시스턴트** 아래에서 **AI 어시스턴트와 스크립트가 CivilCraft를 사용하도록 허용**을 체크합니다.
3. **읽기**는 기본으로 체크되어 있습니다. 어시스턴트에 필요할 때만 **편집**, **저장** 또는 **내보내기**를 체크하십시오.
4. 어시스턴트가 폴더에 저장하고 내보내게 하려면, **사용할 수 있는 폴더** 아래에서 {{ui:폴더 추가…}} 버튼을 선택하고 Studio 대화상자에서 폴더를 고르십시오. {{ui:제거}} 버튼은 그 폴더를 즉시 회수하며, 그 밖의 경로는 거부됩니다.
5. Studio에서 어시스턴트를 연결합니다. Studio에 주소와 붙여넣을 설정이 표시됩니다.

## 어시스턴트가 연결된 동안

오른쪽 패널 위쪽의 메모에는 어떤 어시스턴트가 연결되어 있고 무엇을 할 수 있는지 표시됩니다. {{ui:연결 끊기}} 버튼을 클릭하면 세션이 즉시 끝나며, 계속하려면 다시 연결해야 합니다.

**활동**은 설정의 **어시스턴트** 아래에 있으며, 어시스턴트가 한 모든 호출을 최신순으로 나열하고 성공 여부를 표시합니다.

:::tip
"Main Street를 따라 50 ft마다 지표면 높이는 얼마입니까?", "패드에 필요한 절토와 성토는 얼마입니까?", 또는 "이 좌표에 기준점을 추가하십시오."처럼 일상적인 말로 요청하십시오. 어시스턴트는 대지를 읽고 답하거나, 실행 취소할 수 있는 한 단계로 변경을 수행합니다.
:::

## 연결하지 않고 사용하기

어시스턴트용 CadCraft 파일 서버(`npx @getcadcraft/mcp`)와 `cadcraft` 명령행은 창을 열지 않고 저장된 CivilCraft 프로젝트(`.civilcraft.json`)와 점 파일을 CivilCraft 자체 코드로 엽니다. 읽기 도구, 점 추가, 프로젝트 저장, LandXML, 3D 대지(OpenUSD)를 같은 방식으로 제공합니다. `cadcraft convert site.civilcraft.json site.xml` 명령은 명령행에서 LandXML을 작성합니다. LandXML 열기, DWG 내보내기, Landscape 작업 공간의 도구는 여전히 CivilCraft 창이 필요합니다.

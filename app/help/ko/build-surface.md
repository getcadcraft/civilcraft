CivilCraft에는 프로젝트마다 기존 지반 지표면이 하나 있습니다. 점으로 만든 TIN(불규칙 삼각망, triangulated irregular network)이며, 입력이 바뀔 때마다 자동으로 다시 만들어집니다. '다시 만들기' 명령은 없으며, 오래된 지표면도 없습니다.

## 지표면에 들어가는 것

- {{ui:점}} 설정 그룹에 속하고 높이가 있는 모든 점.
- {{ui:단절선}} 설정 그룹 전체(점 번호 순으로 이어짐).
- {{ui:단절선}} 도구로 그린 모든 단절선.
- 그린 외곽 경계(있는 경우).
- **가장 긴 바깥 모서리** 설정.

삼각형은 단절선을 가로지르지 않습니다. 지표면은 단절선을 따르도록 강제되며, 그 주변은 가능한 한 고르게 만들어집니다(그 밖에서는 모두 Delaunay 방식).

## 코드가 붙은 선을 단절선으로 만들기

1. 왼쪽 패널의 **점** 아래에서 해당 그룹(예: FL)을 찾습니다.
2. 그룹의 **지표면** 항목을 {{ui:단절선}} 값으로 설정합니다.
   지표면이 다시 만들어지고, 선이 주황색으로 그려집니다({{ui:단절선}} 항목이 **표시** 아래에서 켜져 있을 때). 지표면 정보의 **단절선** 수가 하나 늘어납니다.
3. 평면에서 선을 확인합니다. 선은 측량한 순서대로 점에서 점으로 이어져야 합니다. 지그재그로 보인다면 그룹에 선이 여러 개 있거나, 점 번호가 순서대로 되어 있지 않은 것입니다. 그럴 때는 그룹 설정을 {{ui:점}} 값으로 되돌리고, 아래 절처럼 선을 직접 그리십시오.

## 점을 지나는 단절선 그리기

1. {{key:B}} 키를 누르거나 **지표면** 그룹에서 {{ui:단절선}} 버튼을 클릭합니다.
   힌트에 "단절선: 측량 점을 순서대로 클릭하십시오(점의 높이를 사용합니다). Enter 키로 완료합니다."가 표시됩니다.
2. 포인터를 점 가까이 옮기면 작은 주황색 사각형이 사용할 점을 표시합니다.
3. 선의 점들을 차례로 클릭합니다. 각 클릭은 점과 높이를 상태 표시줄에 표시합니다.
4. {{key:Enter}} 키를 눌러 완료합니다.
   상태 표시줄에 "단절선 1 추가됨. 지표면을 다시 만들었습니다."가 표시됩니다.

클릭은 높이가 있는 측량 점 위에 있어야 합니다. 다른 곳을 클릭하면 "높이가 있는 측량 점을 클릭하십시오: 단절선은 점의 높이를 사용합니다."라는 메시지와 함께 거부됩니다. {{key:Backspace}} 키는 마지막 점을 제거하고, {{key:Esc}} 키는 선 전체를 취소합니다.

:::warning
{{key:Enter}} 키로 완료하십시오. 더블클릭으로도 완료되지만 이 빌드에서는 더블클릭한 점을 제거합니다. 마지막 점을 한 번 클릭한 다음 {{key:Enter}} 키를 누르십시오.
:::

그린 단절선을 한 번에 모두 지우려면 **지표면** 구역에서 {{ui:그린 단절선 제거}} 버튼을 클릭합니다. 마지막 것만 제거하려면 {{key:Mod+Z}} 키를 사용합니다. 그린 단절선은 아직 하나씩 선택하거나 편집할 수 없습니다.

## 외곽 경계 그리기

경계는 지표면을 신뢰하는 영역으로 잘라냅니다. 예를 들어 측량 구역의 한계로 자르면, 측량하지 않은 모서리를 가로지르는 긴 삼각형이 사라집니다.

1. {{key:O}} 키를 누르거나 {{ui:경계}} 버튼을 클릭합니다.
2. 영역 둘레의 모서리를 순서대로 클릭합니다. 점선이 모양을 보여 줍니다.
3. {{key:Enter}} 키를 누릅니다.
   상태 표시줄에 "경계 설정됨. 경계 바깥의 삼각형은 없어졌습니다."가 표시됩니다. 지표면 정보의 **경계** 항목에 "예"와 모서리 수가 표시됩니다.

알아 둘 점:

- 경계는 하나뿐입니다. 새로 그리면 기존 경계를 대체합니다. {{ui:경계 제거}} 버튼을 누르면 경계가 없어집니다.
- 경계는 줄이는 방향으로만 작동합니다. 점을 넘어서는 경계는 점들의 외곽선까지 잘리며, "경계가 점을 넘어서 있어 점들의 외곽선까지 잘렸습니다."라는 메모가 표시됩니다.
- 경계의 모서리는 지표면에서 높이를 가져오므로, 가장자리는 지반을 정확히 따릅니다.
- 숨김(내부) 경계는 아직 사용할 수 없습니다.

## 긴 바깥 삼각형 자르기

경계가 없으면 지표면은 점들의 외곽선 전체를 채우며, 오목한 가장자리를 가로지르는 길고 가는 삼각형도 포함합니다.

1. **지표면**에서 **가장 긴 바깥 모서리**에 길이를 입력하고 {{key:Enter}} 키를 누릅니다. 일반적인 측량 간격의 두세 배 정도에서 시작하십시오.
2. 바깥 모서리가 그보다 긴 바깥 삼각형은 제거되며, 모든 바깥 모서리가 충분히 짧아질 때까지 안쪽으로 계속합니다. 단절선인 모서리는 제거하지 않습니다.
3. 0을 입력하면 모든 삼각형을 다시 유지합니다.

## 지표면 보고서 읽기

지표면 정보 아래의 상자에 빌더가 한 작업이 나열됩니다. 왼쪽에 주황색 막대가 있으면 정보이고, 빨간색 막대가 있으면 오류이며 지표면이 없습니다.

| 메시지 | 의미 |
|---|---|
| "점 3개가 다른 점과 같은 위치에 있어 그 점에 연결되었습니다." | 평면에서 0.0001보다 가까운 점들이 하나의 꼭짓점이 되었습니다(첫 번째 점을 유지). |
| "2곳에 서로 다른 두 높이가 있습니다 …" | 겹쳐 있는 점이나 교차하는 단절선의 높이가 서로 다릅니다. 단절선의 높이가 우선하며, 그다음은 처음 것입니다. |
| "단절선 조각 1개를 지표면에 맞출 수 없었습니다." | 매우 짧거나 거의 겹치는 단절선 조각이 맞지 않았습니다. 해당 위치를 확인하십시오. |
| "지표면에는 높이가 있는 점이 최소 세 개 필요합니다." | 점이 너무 적습니다. 열 순서와 그룹을 확인하십시오. |
| "점이 모두 한 직선 위에 있습니다: 삼각형 없음." | 점에 폭이 없습니다. 예: 하나의 트래버스 선. |
| "경계가 점과 겹치지 않습니다." | 경계가 다른 곳에 있습니다. 흔히 단위 또는 좌표계가 섞인 경우입니다. |
| "경계 안에 남은 삼각형이 없습니다." | 경계가 너무 작거나 위치가 잘못되었습니다. |

## LandXML에서 읽은 지표면

LandXML을 열면 첫 번째 TIN 지표면이 그대로 사용됩니다. **지표면** 제목에 "지표면(LandXML에서)"이라고 표시되고, **가장 긴 바깥 모서리**는 회색으로 흐리게 표시됩니다. 그 지표면을 사용하는 동안에는 단절선 그룹, 그린 단절선, 새 경계가 지표면을 바꾸지 않습니다. 파일의 점으로 지표면을 만들려면 {{ui:점으로부터 지표면 다시 만들기}} 버튼을 클릭하십시오. {{key:Mod+Z}} 키를 누르면 LandXML 지표면이 돌아옵니다.

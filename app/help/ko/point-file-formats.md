점 파일은 한 줄에 점 하나씩 들어 있는 일반 텍스트입니다. 브라우저 안에서 읽으며, 아무것도 업로드되지 않습니다.

## 열 순서

글자는 왼쪽에서 오른쪽으로 열을 나타냅니다: **P** 점 번호 또는 이름, **N** Northing, **E** Easting, **Z** 표고, **D** 설명.

| 순서 | 열 | 예시 줄 |
|---|---|---|
| PNEZD | 점, Northing, Easting, 표고, 설명 | `101,2080000.00,6150000.00,250.00,GRD` |
| PENZD | 점, Easting, Northing, 표고, 설명 | `101,6150000.00,2080000.00,250.00,GRD` |
| PNEZ | 점, Northing, Easting, 표고 | `101,2080000.00,6150000.00,250.00` |
| PENZ | 점, Easting, Northing, 표고 | `101,6150000.00,2080000.00,250.00` |
| NEZD | Northing, Easting, 표고, 설명 | `2080000.00,6150000.00,250.00,GRD` |
| ENZD | Easting, Northing, 표고, 설명 | `6150000.00,2080000.00,250.00,GRD` |
| NEZ | Northing, Easting, 표고 | `2080000.00 6150000.00 250.00` |
| ENZ | Easting, Northing, 표고 | `6150000.00 2080000.00 250.00` |

P가 없는 순서에서는 점을 파일 순서대로 1, 2, 3 …으로 번호 매깁니다. X는 Easting이고 Y는 Northing입니다.

## 구분 기호

처음 20줄을 살펴보고, 그중 60 % 이상의 줄에 나타나는 첫 번째 구분 기호를 고릅니다. 후보는 쉼표, 탭, 세미콜론입니다. 그런 기호가 없으면 연속된 공백으로 나눕니다.

- 쉼표, 탭, 세미콜론 파일에서는 큰따옴표로 묶인 필드가 구분 기호를 포함할 수 있으며(`"FL, NORTH"`), 따옴표 안의 `""`는 따옴표 하나를 뜻합니다.
- 공백으로 구분된 파일에서는 줄 끝의 설명에 공백이 들어갈 수 있습니다. 마지막 좌표 열 뒤의 모든 내용이 설명입니다.
- `#`, `;` 또는 `//`로 시작하는 줄과 빈 줄은 건너뜁니다.
- 파일 맨 앞의 바이트 순서 표시(BOM)는 무시합니다.

## 머리글 행

첫 줄은 필드 중 숫자가 두 개 미만이면 머리글로 취급합니다. 머리글의 모든 필드가 인식되는 이름이면, 열 순서를 머리글 행에서 가져옵니다("머리글 행에서"). 이름은 대소문자, 공백, 점, 밑줄, 하이픈, 괄호를 구분하지 않고 맞춥니다.

| 열 | 인식되는 이름 |
|---|---|
| P | pt, pnt, point, point no, point number, number, no, id, name, pt#, point#, # |
| N | n, north, northing, y, y coord, lat, latitude |
| E | e, east, easting, x, x coord, lon, long, longitude |
| Z | z, elev, elevation, el, height, h, z coord, rl |
| D | d, desc, description, code, raw description, full description, note, notes, feature |

인식되지 않는 머리글 이름이 있거나, 이름들이 여덟 가지 순서 중 하나를 이루지 못하면 머리글은 건너뛰고 열 개수로 순서를 추측합니다.

:::warning
위도 열(`lat`, `latitude`)과 경도 열(`lon`, `long`, `longitude`)을 모두 이름으로 지정한 머리글은 Northing과 Easting이 아니라 도 단위로 읽습니다. {{ui:가져오기}}에서 점은 프로젝트의 좌표계를 통해 변환되며, 좌표계가 없는 프로젝트는 먼저 선택하도록 요청합니다. 위도 ±90° 또는 경도 ±180° 범위를 벗어난 행은 거부됩니다. [GIS 데이터 가져오기](topic:gis-import#point-files-with-latitude-and-longitude)를 참조하십시오.
:::

## 열 개수로 추측

사용할 수 있는 머리글이 없고 **열** 설정이 {{ui:감지}}인 경우:

- 열이 5개 이상: PNEZD.
- 열이 4개: 첫 열이 검사한 모든 줄에서 정수이고 네 번째 열이 숫자이면 PNEZ, 그렇지 않으면 NEZD.
- 열이 3개: NEZ.

PNEZD와 PENZD는 숫자만으로 구별할 수 없습니다. 추측은 [CivilCraft 설정](topic:settings)의 **점 행**을 따릅니다. 앞에서부터 P, N, E, Z, D이거나 P, E, N, Z, D입니다(후자의 경우 열 4개는 PENZ, 열 3개는 ENZ로 읽습니다). 대화상자에는 "열 개수로 추측함 — Northing과 Easting이 바뀌지 않았는지 확인하십시오."라고 표시됩니다. 미리 보기가 잘못되면 **열**에서 올바른 순서를 선택하십시오.

## 행 검사 방식

- 행에서 설명을 생략할 수 있습니다.
- Northing과 Easting은 숫자여야 합니다. 표고는 비워 둘 수 있습니다(점은 유지되지만 표면에는 사용되지 않습니다).
- 점 번호는 어떤 텍스트든 가능합니다(`CP1`처럼 문자를 포함해도 됩니다). 다만 비워 둘 수는 없습니다.
- 점 번호가 반복되면 첫 행을 유지하고, 나머지는 읽지 않은 것으로 나열합니다.
- 설명은 200자까지 유지되며, 제어 문자는 공백이 됩니다.
- 대화상자에는 읽지 않은 행을 최대 200개까지 보관하며(25개 표시), 모두 집계합니다.

## 점 그룹

점의 그룹은 설명의 첫 단어를 대문자로 쓴 것입니다. "GRD", "grd shot", "Grd"는 모두 그룹 GRD입니다. 설명이 없는 점은 "(설명 없음)" 그룹에 속합니다. [측량 점 가져오기](topic:import-points)를 참조하십시오.

## 점 쓰기

점 텍스트 파일 내보내기는 아직 지원하지 않습니다. 점은 LandXML(CgPoints 요소), 프로젝트 파일, 그리고 GIS {{ui:내보내기}}로 보낼 수 있습니다. GIS 내보내기에서는 P, N, E, Z, D 필드를 가진 shapefile, GeoPackage 또는 GeoJSON으로 나갑니다([준공 데이터를 GIS로 내보내기](topic:gis-export)). [아직 만들지 않았습니다](topic:not-built-yet)를 참조하십시오.

한 글자 키는 상자에 입력하고 있지 않을 때 작동합니다. {{key:Mod}}가 들어간 단축키는 Mac에서는 Command를, 그 밖의 환경에서는 Ctrl을 사용합니다. [브라우저의 키](common:keys)도 참조하십시오.

## 파일과 편집

| 키 | 동작 |
|---|---|
| {{key:Mod+O}} | 점 파일, LandXML 또는 프로젝트를 엽니다 |
| {{key:Mod+S}} | 프로젝트를 저장합니다(`.civilcraft.json` 파일을 내려받습니다) |
| {{key:Mod+P}} | 평면도를 PDF로 플롯합니다(브라우저의 인쇄가 아니라 플롯 대화상자를 엽니다) |
| {{key:Mod+Z}} | 실행 취소 |
| {{key:Mod+Y}} | 다시 실행 |
| {{key:Delete}} | 선택한 측량점, 선형, 패드, 구조물, 관 또는 PVI를 삭제합니다 |
| {{key:Mod+C}} | 선택한 측량점을 복사합니다(스프레드시트용 점 행으로도 복사됨) |
| {{key:Mod+X}} | 선택한 측량점을 잘라냅니다 |
| {{key:Mod+V}} | 점을 붙여넣습니다. 점이 포인터를 따라가며, 놓을 곳을 클릭하십시오 |
| {{key:Mod+Shift+V}} | 제자리에 붙여넣기: 점 자신의 좌표에 붙여넣습니다 |
| {{key:Mod+D}} | 선택한 점을 복제합니다. 복사본이 포인터를 따라갑니다 |
| {{key:Mod+A}} | 모든 측량점을 선택합니다 |
| {{key:Esc}} | 선택을 모두 해제합니다(붙여넣기도 취소합니다) |

{{key:Mod+S}}, {{key:Mod+O}}, {{key:Mod+P}}는 상자에 입력하는 중에도 작동합니다. 텍스트 상자에서는 {{key:Mod+Z}}와 {{key:Mod+Y}}가 평소처럼 입력을 실행 취소하거나 다시 실행합니다. {{key:Mod+C}}, {{key:Mod+X}}, {{key:Mod+V}}, {{key:Mod+A}}도 마찬가지로, 상자 안에서는 그 텍스트를 복사, 잘라내기, 붙여넣기, 선택합니다. 페이지(패널)에서 텍스트를 선택한 상태라면 {{key:Mod+C}}는 그 텍스트를 복사합니다. {{key:Mod+Shift+Z}}는 CivilCraft에서 아무 일도 하지 않습니다. {{key:Mod+Y}} 또는 {{ui:Redo}} 버튼을 사용하십시오.

:::mac
Mac에서 **delete**라고 표시된 키는 브라우저에서는 {{key:Backspace}}입니다. 선택 항목을 삭제하려면 {{key:Delete}}(Fn과 delete)를 누르거나, 도구 모음의 {{ui:More}} 메뉴에서 {{ui:Delete}}를 선택하십시오.
:::

## 도구

| 키 | 도구 |
|---|---|
| {{key:V}} | {{ui:Select}} |
| {{key:M}} | {{ui:Measure}}: 평면도에서 거리, 면적, 경사를 측정합니다([측정](topic:measure)) |
| {{key:A}} | {{ui:Alignment}} |
| {{key:G}} | {{ui:패드}} |
| {{key:P}} | {{ui:Pipes}} |
| {{key:B}} | {{ui:Breakline}} |
| {{key:O}} | {{ui:Boundary}} |
| {{key:R}} | 프로파일 보기를 표시하거나 숨깁니다 |
| {{key:I}} | {{ui:Add PVIs}}를 켜거나 끕니다(닫혀 있으면 프로파일 보기를 엽니다) |
| {{key:F}} | {{ui:Fit}}: 모두 표시합니다 |
| {{key:D}} | {{ui:3D}}: 현장을 3D로 표시하거나, 평면도로 돌아갑니다 |
| {{key:E}} | 모든 피처 선을 따라 구배와 표고를 표시하거나 숨깁니다(화면에서만) |

활성 도구의 키를 다시 누르면 {{ui:Select}}로 돌아갑니다. Shift를 함께 누른 문자 키는 아무 일도 하지 않습니다.

## 그리는 중

| 키 | 동작 |
|---|---|
| {{key:Enter}} | 선형, 패드, 관 구간, 단절선 또는 경계를 마칩니다 |
| {{key:Backspace}} | 마지막으로 클릭한 점을 제거합니다 |
| {{key:C}} | 피처 선: 호를 켜거나 끕니다(꼭짓점 뒤에 곡선 위의 점을 클릭한 다음, 끝점을 클릭합니다) |
| {{key:Esc}} | 그리기(또는 붙여넣기)를 취소합니다. 다시 누르면(또는 그린 것이 없으면) {{ui:Select}}로 돌아가 선택을 해제합니다 |

## 평면 보기

| 키 또는 동작 | 결과 |
|---|---|
| 휠 | 포인터 위치에서 줌 인 또는 줌 아웃합니다 |
| 빈 공간에서 드래그 | 초점 이동(모든 도구에서 가능합니다. 짧게 클릭하면 여전히 클릭으로 처리되며, {{key:Shift}}를 누른 채로 하면 선택 상자를 그립니다) |
| 가운데 버튼 드래그 | 초점 이동 |
| 오른쪽 버튼 드래그 | 초점 이동(메뉴가 열리지 않습니다) |
| {{key:Space}}를 누른 채 드래그 | 초점 이동 |
| 클릭 | {{ui:Select}}로 선택하거나, 그리기 도구로 점을 놓습니다 |
| {{key:Shift}}를 누른 채 클릭 | 측량점을 선택에 추가하거나 선택에서 뺍니다 |
| {{key:Shift}}를 누른 채 드래그 | 상자를 그립니다. 안에 있는 측량점이 선택에 추가됩니다. 주위를 드래그하면 [올가미](topic:lasso-selection)가 됩니다 |
| 올가미를 그리는 동안 {{key:Space}} | 윈도우, 걸침, 울타리 순서로 바뀝니다 |
| 붙여넣기 중 클릭 | 붙여넣은 점을 그곳에 놓습니다({{key:Enter}}를 누르면 자신의 좌표에 놓입니다) |
| 그립 드래그 | PI, 패드 모서리 또는 구조물을 옮깁니다(실행 취소 한 단계) |
| {{key:Up}} {{key:Down}} {{key:Left}} {{key:Right}} | 평면도에 초점이 있을 때 초점을 이동합니다(먼저 클릭하십시오) |
| {{key:Plus}} 및 {{key:Minus}} | 평면도에 초점이 있을 때 가운데에서 줌 인과 줌 아웃합니다 |

= 키는 {{key:Plus}} 키처럼 줌 인하므로 Shift를 누를 필요가 없습니다.

## 프로파일 보기

| 동작 | 결과 |
|---|---|
| {{ui:Add PVIs}}를 켠 상태에서 클릭 | 그곳에 PVI를 추가합니다 |
| PVI 클릭 | 선택합니다 |
| PVI 드래그 | 옮깁니다(실행 취소 한 단계) |
| {{key:Delete}} 또는 {{key:Backspace}} | 선택한 PVI를 제거합니다(Backspace는 프로파일 보기에 초점이 있을 때만 작동합니다) |

프로파일 보기는 줌하거나 초점을 이동하지 않습니다.

## 화면과 도움말

| 키 | 동작 |
|---|---|
| {{key:F1}} | 이 도움말(측면 패널)을 열거나 닫습니다. 앱 바의 {{ui:Help}}도 같은 일을 합니다 |
| {{key:Esc}} | 도움말 패널이 열려 있으면 닫습니다 |
| {{key:Ctrl+Shift+F}} | 화면 모드를 순환합니다: 전체 화면, 막대를 숨긴 전체 화면, 일반 |
| {{key:Esc}} | 전체 화면을 나갑니다(브라우저 고유의 키입니다) |

{{key:F1}}은 CivilCraft보다 먼저 브라우저가 가로채므로 어떤 도구에서든 작동합니다. 대부분의 Mac 키보드에서는 fn과 F1을 함께 누르거나 {{ui:Help}}를 클릭하십시오. {{key:Ctrl+Shift+F}}는 Mac을 포함한 모든 플랫폼에서 Control 키를 사용합니다. 이 도움말을 검색하는 방법은 [도움말 사용](common:help)을 보십시오.

## 마우스, 트랙패드, 터치

:::mouse
- 휠은 포인터 위치에서 줌합니다. 자유롭게 도는 휠 마우스는 빠르게 줌하므로, 짧게 돌리십시오.
- 빈 공간을 어떤 방식으로 드래그하든, 가운데 버튼, 오른쪽 버튼, 또는 {{key:Space}}를 누른 채 드래그하면 초점이 이동합니다.
:::

:::mac
Mac 트랙패드에서:

- 두 손가락 스크롤은 초점이 아니라 **줌**입니다. 핀치도 줌합니다.
- 초점을 이동하려면 빈 공간을 한 손가락으로 누른 채 드래그하거나, {{key:Space}}를 누른 채 드래그하십시오.
- 두 손가락 클릭(오른쪽 클릭)은 메뉴를 열지 않으며, 그 자체로는 아무 일도 하지 않습니다.
:::

:::touch
터치 화면에서:

- 처음 터치하면 버튼과 메뉴 항목이 손가락 크기로 커집니다.
- 탭하여 선택하거나 점을 놓습니다. 빈 공간에서 한 손가락으로 드래그하면 초점이 이동합니다. 탭이 살짝 흔들릴 수 있으므로, 손가락이 약 10픽셀 움직인 뒤에야 초점이 이동합니다.
- 두 손가락을 벌리면 줌하고, 함께 움직이면 초점이 이동합니다.
- 한 손가락으로 그립이나 PVI를 드래그합니다. 그립은 손가락 너비만큼의 여유를 둡니다.
- 선형, 패드, 단절선, 경계, 관 구간, 피처 선 또는 필지를 그리는 동안 평면 위의 막대에 {{ui:Finish}}({{key:Enter}}), {{ui:Undo point}}({{key:Backspace}}), {{ui:Cancel}}({{key:Esc}})가 나타납니다. 길게 누르기(0.5초 동안 움직이지 않음)도 그리기를 마칩니다.
- {{ui:Select}} 상태에서 측량점을 길게 누르면, {{key:Shift}}+클릭과 같이 선택에 추가하거나 선택에서 뺍니다.
- 3D 보기에서는 한 손가락으로 궤도 회전, 두 손가락으로 핀치와 초점 이동, 탭으로 선택합니다.
- 터치에는 호버가 없으므로 상태 표시줄의 값은 손가락이 닿아 있는 동안에만 갱신됩니다.
:::

## 브라우저 키가 우선하는 경우

일부 키는 브라우저의 것이므로 CivilCraft에 도달하지 않습니다. 예를 들어 {{key:Mod+W}}(탭 닫기), {{key:Mod+T}}(새 탭), {{key:Mod+N}}(새 창), {{key:F11}}(Windows와 Linux 브라우저의 전체 화면)가 그렇습니다. CivilCraft는 이 키들을 사용하지 않습니다. 단축키가 대신 브라우저에서 무언가를 연다면, 평면도를 한 번 클릭해 페이지에 초점을 준 뒤 다시 시도하십시오.

## 이동은 어디에 있나요

이동 명령은 없습니다. {{ui:Select}}를 선택하고 점이나 꼭짓점을 드래그하거나, {{ui:Properties}}에서 좌표를 편집하십시오. [점 편집](topic:edit-points)을 보십시오.

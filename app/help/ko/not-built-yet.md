CivilCraft는 아직 초기 단계입니다. 이 페이지는 현재 빌드가 하지 않는 기능을 나열하므로, 찾지 않아도 됩니다. 어떤 기능도 날짜를 약속하지 않습니다.

## 점

| 아직 만들지 않은 기능 | 대신 지금은 |
|---|---|
| 점 파일 두 개를 하나로 합치기 | 텍스트 편집기나 스프레드시트에서 파일을 먼저 합칩니다 |
| 점 텍스트 파일 내보내기 | LandXML을 내보내거나(점은 CgPoints로 저장됨), GIS {{ui:Export}}를 사용하거나(P, N, E, Z, D 필드가 있는 점), 점을 {{ui:Copy}}하여 스프레드시트에 붙여넣습니다 |
| 점 레이블 스타일, 설명 키별 기호, 선 코드에서 만드는 곡선(호), 프로젝트 사이에서 공유하는 설명 키 파일 | 레이블에는 번호, 높이, 설명을 표시하거나 그보다 적게 표시하며([CivilCraft 설정](topic:settings)), 키는 프로젝트 파일에 보관됩니다 |
| 단위 변환 | 가져오기 전에 파일을 변환합니다. **단위** 설정은 이름만 바꿉니다 |

## 지표면

| 아직 만들지 않은 기능 | 대신 지금은 |
|---|---|
| 점으로 만든 지표면 여러 개 | 프로젝트 하나에 지표면 하나 |
| (안쪽) 경계 숨기기 | **가장 긴 바깥 모서리**를 사용하거나 바깥 경계를 사용합니다 |
| 그린 단절선 하나를 선택하거나 편집하기 | {{key:Mod+Z}} 키를 누르거나, {{ui:Remove drawn breaklines}} 명령을 쓴 뒤 다시 그립니다 |
| LandXML에서 읽은 지표면 편집(단절선, 경계) | {{ui:Rebuild the surface from the points}} |
| 높이 격자로 만든 지표면 편집 | 격자를 다른 옵션으로 다시 가져옵니다 |
| 좌표계가 바뀔 때 LandXML에서 읽은 지표면 변환 | 먼저 {{ui:Rebuild the surface from the points}}를 실행합니다 |
| 높이 표시가 있는 지점 높이와 경사 값 | 상태 표시줄에서 값을 읽거나, 조경 작업 공간의 **경사 분석**으로 지표면을 경사별로 색칠합니다([조경 정지](topic:landscape-grading#grading-checks)) |

## 선형과 종단면도

| 아직 만들지 않은 기능 | 대신 지금은 |
|---|---|
| 클로소이드 이외의 완화 곡선, 두 곡선 사이의 완화 곡선(복합 전이) | 곡선 끝의 클로소이드 완화 곡선은 사용할 수 있습니다. 나머지는 이름이 붙고 LandXML 가져오기에서 건너뜁니다 |
| 두 PI 사이에 PI 삽입 | 선형을 다시 그리거나 PI 좌표를 다시 입력합니다 |
| 객체로 만든 선형, 간격 띄우기, 폭 넓히기 | PI로 그립니다 |
| 수직 곡선에 K 입력 | L을 입력합니다(K가 표시됩니다) |
| 원형 및 비대칭 수직 곡선 | 대칭 포물선 곡선만 |
| 선형 하나당 설계 종단면도 여러 개 | 변형마다 선형 하나 |
| 종단면도 보기 확대/축소, 종단면도 아래의 띠 | 종단면도 보기는 전체 선형에 맞춰집니다. [평면 및 종단면 시트](topic:plan-profile-sheets)에 출력합니다 |
| DWG 또는 LandXML의 횡단면 | 횡단면 시트는 PDF로, 면적과 체적은 CSV로 저장합니다 |
| 비스듬한 샘플 선, 또는 도로를 따라 폭이 다른 샘플 선 | 선형 전체에 한쪽마다 폭 하나를 사용합니다 |

## 도로 구간

| 아직 만들지 않은 기능 | 대신 지금은 |
|---|---|
| 중앙 분리대, 방호 울타리, 템플릿을 회전시키는 편경사 | 템플릿으로 그립니다([도로 구간 템플릿](topic:corridor-templates)). 측점별 템플릿은 아직 편경사를 반영하지 않습니다 |
| 두 구간 템플릿 사이의 점진적 변화(전이, 테이퍼) | 측점에서 템플릿을 바꾸거나, 테이퍼로 그린 선에 폭 목표를 줍니다 |
| 모서리를 중심으로 한 회전, LandXML의 편경사 | 원형 곡선에서 편경사는 중심선을 기준으로 회전합니다. 차선 폭은 폭 목표를 지정한 피처 선으로 넓힙니다 |
| 비탈면 목표(선이나 지표면까지의 사면 끝점), 도로 구간 고유 지표면 | 목표는 포장과 갓길의 가장자리를 움직입니다([도로 구간](topic:corridor)). 도로 구간은 계획 지표면에 정지됩니다 |
| LandXML 도로로 내보내는 도로 구간, IFC 내보내기에서 선형에 두 번째 도로 구간 | 계획 지표면이 내보내집니다 |
| 3D나 횡단면에서 계획 지표면을 바꾸는 지형 템플릿 | 각 층의 면적과 체적을 구합니다([지형 템플릿](topic:corridor-templates#terrain-templates)) |
| 속도, 타이어 미끄럼, 조향 시간, 조향 트레일러, 차체 여유를 고려한 차량 통과 궤적, 표준 설계 차량 라이브러리, 차량을 끌어서 그리는 통과 궤적 | 지형선이나 선형을 따라 저속 차량 통과 궤적을 만들며, 직접 정한 차량 크기를 사용합니다([차량 통과 궤적](topic:swept-paths)) |

## 토공과 체적

| 아직 만들지 않은 기능 | 대신 지금은 |
|---|---|
| 단(벤치), 설계에 정지되는 열린 피처 선, 다른 곳의 피처 선까지 정지 | 피처 선을 닫거나([피처 선](topic:feature-lines)), 기존 지반의 단절선으로 사용합니다 |
| 피처 선 꼭짓점 추가 또는 제거 | 선을 다시 그리거나, 간격 띄우기로 계단식 복사본을 만듭니다 |
| 그린 단절선의 호(측량점을 지나는), 피처 선의 완화 곡선 | 호가 있는 피처 선을 그린 뒤 기존 지반의 단절선으로 사용합니다 |
| 거리, 높이, 또는 다른 지표면까지 정지 | 기존 지반까지만 사면 끝점을 맞춥니다 |
| 패드 모서리 추가 또는 제거 | 패드를 삭제한 뒤 다시 그립니다 |
| TIN 간 체적(프리즘), 격자 셀 크기 선택 | 격자 방식을 쓰며, 셀 크기는 자동으로 정해집니다 |
| 팽창과 수축, 표토, 포장 깊이 | 보고된 수치에 계수를 직접 적용합니다 |
| 무료 운반 및 초과 운반 비용, 서로 다른 선형 간 운반, 평면에 배치한 토취장과 사토장 | 균형점이 있는 토적곡선, 흙 이동량, 평균 운반 거리 |

## 관로망

| 아직 만들지 않은 기능 | 대신 지금은 |
|---|---|
| 프로젝트 하나에 관로망 여러 개 | 우수와 오수는 별도 프로젝트로 나눕니다 |
| 상수도 본관: 수질과 수령, 규칙 기반 제어, 다른 밸브 종류(유량 조절, 스로틀, 유지 밸브), 동력으로 정해진 펌프, 압력에 따라 달라지는 수요, Darcy–Weisbach 옵션, 두께와 압력 등급을 갖춘 관 카탈로그. 나머지 압력망은 실험실 단계입니다: [상수도 본관](topic:water-mains) | 상수도 설계 소프트웨어에서 확인합니다. 오수 설계 유량은 [오수 설계 유량](topic:sanitary-design)에 있습니다 |
| 시간에 따른 하수 유량(수문곡선, 동적 배수 경로, 저류, 펌프, 월류) | [오수 설계 유량](topic:sanitary-design)은 설계 시트가 쓰는 정상 상태 최대 유량을 제공합니다 |
| 유입구 용량, 측구 확산, 저류지 배수 경로, 수문곡선, 접합부 계수 하나 이외의 에너지 손실 | 다른 소프트웨어에서 확인합니다. 유량, 크기, 수리 구배선은 [우수 배수](topic:storm-drainage)에 있습니다 |
| PDF 도면, DWG, DXF, LandXML의 집수 구역, 지표면에서 만든 집수 구역(분수령) | 집수 구역을 직접 그립니다. 프로젝트 파일에 저장됩니다 |
| 관 카탈로그, 원형이 아닌 관, 직립 상자나 원통이 아닌 구조물(원뿔, 계단, 벤칭), 라이브러리의 배수 분류 | 매개변수로 구조물 종류를 만들고([관로망](topic:pipe-network)), 지름이 있는 관을 씁니다 |
| 종단면도 보기의 관, 곡선 관 | 오른쪽 패널에서 관저와 최소 복토를 읽습니다 |

## 파일과 출력

| 아직 만들지 않은 기능 | 대신 지금은 |
|---|---|
| DWG나 DXF의 문자, 해치, 치수, 종이 공간, 연결된 도면(xref), 바이너리 DXF | 모형 공간의 선 작업은 열립니다([DWG 또는 DXF를 선 작업으로 열기](topic:open-dwg-dxf)). 연결된 도면은 따로 엽니다 |
| 여러 점을 한꺼번에 끌어서 이동 | 잘라내기 및 붙여넣기를 하거나, 하나씩 편집합니다 |
| 세로 방향 시트, 직접 만든 표제란, 직접 배치하는 뷰포트, DWG의 평면 및 종단면 시트 | PDF 한 장당 가로 방향 평면 시트 한 장, 또는 선형을 따라 평면 및 종단면 시트(PDF) |
| 높이 띠와 종단면도 플롯 | 띠는 화면에서만 보입니다. 필요하면 화면 캡처를 합니다 |
| 도면층 이름, 색상 또는 레이블 스타일 변경 | DXF 내보내기 후 CAD 프로그램에서 바꿉니다 |
| 클라우드 저장과 버전 기록 | .civilcraft.json 파일을 저장하고 백업해 둡니다. 한 프로젝트를 함께 작업하려면 CadCraft Studio의 실시간 세션을 사용합니다([현장 하나를 함께 실시간으로 설계하기](topic:work-live)) |
| iPad와 iPhone용 CadCraft Studio, Google Play 설치 | 기기의 브라우저에서 CivilCraft를 사용합니다. Android에서는 getcadcraft.com/download에서 APK 파일을 받아 CadCraft Studio를 설치합니다 |
| 여러 점 파일이나 프로젝트 파일을 한꺼번에 열기 | 한 번에 파일 하나씩 엽니다(예를 들어 shapefile의 구성 파일처럼 함께 속하는 GIS 파일은 함께 열립니다) |

## 조경

| 아직 만들지 않은 기능 | 대신 지금은 |
|---|---|
| 제조사의 헤드와 노즐 | 일반 헤드를 쓰거나, 파일에서 직접 헤드를 추가합니다. 제조사가 허가하면 제조사 데이터가 들어옵니다 |
| 점적 관의 최대 측관 길이, 시간에 따른 유량, 펌프, 순환 관망 | 점적 배관은 제조사가 공개한 길이를 지킵니다. 이 검사에는 분기 관망이 필요합니다 |
| 오목한 자유형 객체의 정확한 윤곽, 지하 체적의 정확한 측정 | 볼록 껍질을 정지하고, 지하 체적은 추정값입니다(속성에 표시됨) |
| BimCraft와 ModelCraft의 라이브러리에서 배치하는 식물 | 조경 IFC를 내보낸 뒤 건물 옆에서 BimCraft로 엽니다 |
| 3D 보기의 상세 식물 모델(잎, 가지, 계절), 3D 보기의 자유형 객체와 관개 | 식물은 식물 목록의 크기를 따르는 단순한 형태로 3D에 표시됩니다([3D로 현장 보기](topic:site-3d)). ModelCraft의 산포 기능으로 식재 그림을 만듭니다 |
| 지표면에서 정지된 높이를 뒤에서 받치는 하드스케이프 벽 | 플랫폼이나 패드에 수직 측면을 주면 지표면의 옹벽이 됩니다([정지](topic:grading)) |
| 직접 만든 기호의 SVG 변환, 직접 만든 GLB 식물 모델의 질감과 색상, 압축된 GLB 형상 | 그리기 프로그램에서 변환을 먼저 풀고, 모델은 식물 색상으로 그려집니다. GLB는 압축하지 않고 내보냅니다([식물 그래픽](topic:plant-graphics)) |
| 라이브러리 계정에 보관된 직접 만든 식물 목록(앱에서 편집) | 식물 표에서 프로젝트 목록을 편집하고 식물 파일로 저장합니다 |
| 창 없이 어시스턴트가 쓰는 조경 도구(파일 서버와 명령행) | CivilCraft 창을 열어 두면 작동합니다([AI 어시스턴트가 현장에서 작업하도록 하기](topic:assistants)) |

| 국가 기준의 기본 내장(하중 케이스, 이격 거리, 계수) | {{ui:Load cases and limits…}}에서 기준 값을 설정하고 저장하며, 라이브러리와 함께 팩으로 저장해 재사용하고 공유합니다([팩](topic:sag-and-tension#packs-rules-and-a-library-for-a-country)) |
| 도체에서 나무 수관이나 선 옆 벽까지의 수평 거리 | 선이 가로지르는 식물과 벽 위의 수직 이격 거리([전력선 검사](topic:power-line-checks#clearances)) |
| 도체 크리프와 새 도체의 신장 | 가선표의 온도로 이를 반영합니다 |
| 매설 케이블의 열 정격(시설 방식에 따른 허용 전류) | 케이블 항목에 공급자의 허용 전류를 입력합니다 |
| 단락, 보호, 접지 검토 | 전용 전기 프로그램을 사용합니다. CivilCraft는 망의 길이와 케이블을 제공합니다 |
| 부재 단위로 설계하는 격자 철탑, 지반의 버팀줄 앵커 | 지지물은 공칭 하중으로, 버팀줄은 정격 하중으로 검사합니다 |
| 읽는 프로그램에서 검사하는 `.DON` 검토 파일 | 해당 프로그램에서 파일을 검사합니다. 실제 파일로 테스트할 수 있도록 샘플을 보내 주십시오 |
| 3D 보기와 IFC의 전력선 | 평면, 선로 종단면도, 시트, GIS 레이어 |
| 창 없이 어시스턴트가 쓰는 전력선 도구 | CivilCraft 창을 열어 두면 작동합니다([AI 어시스턴트가 현장에서 작업하도록 하기](topic:assistants)) |

## 건물 매스

| 아직 만들지 않은 기능 | 대신 지금은 |
|---|---|
| 용도지역 코드나 도시별 규정의 라이브러리 | 직접 조례에서 한계 값을 입력합니다([용도지역 한계](topic:zoning-limits)) |
| 벽면의 천공광(파사드 채광), 바람 | [일조 시간](topic:sun-hours)은 직사광만 셉니다 |
| 나무, 식물 또는 매스로 그리지 않은 것의 그림자 | 이웃 건물을 매스로 그립니다 |
| 매스의 지붕 모양 | 평지붕 매스 |
| BimCraft에서 매스를 전개할 때의 개구부, 지붕, 벽 종류 | BimCraft는 모든 층에 기본 외벽과 바닥을 만들며, 나머지는 거기서 추가합니다 |

## GIS와 좌표계

| 아직 만들지 않은 기능 | 대신 지금은 |
|---|---|
| File Geodatabase, KML 스타일, 아이콘, 지상 오버레이, 네트워크 링크 | GeoPackage, shapefile 또는 GeoJSON으로 먼저 변환합니다. KML 장소 표시는 스타일 없이 읽힙니다 |
| GIS 객체 또는 속성 편집 | GIS 프로그램에서 편집한 뒤 다시 가져옵니다. 분석 패널은 새 레이어(버퍼, 중첩, 결합, 선택)를 만들고 면적과 길이 필드를 추가하지만, 객체를 그 자리에서 편집하지는 않습니다 |
| 네트워크와 래스터 분석, 평평하거나 사각형 끝의 버퍼와 한쪽 버퍼, 속성 표에서 행 추가나 삭제, 속성 표에서 필드 형식 변경, 수동 분류 색상, 플롯의 스타일 범례 | 선택 도구로 객체를 고르고 그것으로 레이어를 만듭니다. 평평한 끝은 제공되지 않습니다. 속성별 색칠과 속성 표는 이미 만들어져 있습니다: [속성으로 레이어 스타일 지정](topic:gis-symbology), [레이어의 속성 표 작업](topic:gis-table) |
| 레이블 스타일(크기, 배치)과 서로 겹치지 않는 레이블 | 레이블은 한 가지 크기이며, 객체가 밀집한 곳에서는 겹칠 수 있습니다 |
| 수직 기준과 지오이드 모델 | 파일이 준 높이를 그대로 사용합니다. 수직 기준은 직접 확인합니다 |
| 지역별로 추천되는 NAD27에서 NAD83으로의 격자 이동 외의 격자 이동(OSTN15; 다른 기준의 NTv2는 파일을 추가하면 작동), 여러 격자 동시 사용, 수직 격자 | 기준에 맞는 격자 파일을 직접 추가합니다. 프로젝트마다 격자 하나 |
| DXF나 3D 내보내기의 지도 레이어 | 지도 레이어는 PDF 플롯에 들어가며, DWG에는 그림으로 옆에 놓입니다 |
| 로그인, 키, 토큰이 필요한 지도 서버 | 공개 서비스를 쓰거나 지리 참조된 이미지 파일을 사용합니다 |
| 지표면, 지반 모델, 높이 격자와 LiDAR 도구에서 LAS 또는 LAZ 파일 쓰기 | 지표면을 GeoTIFF 높이 격자로 내보냅니다. [포인트 클라우드](topic:point-clouds) 추가 기능은 정리된 클라우드를 LAS 1.4 또는 LAZ로 씁니다 |
| LiDAR 강도, 색상, 반환(return) 값, 여러 밴드의 높이 격자, 200 MB를 넘는 격자 또는 LiDAR 파일 | LiDAR는 분류별로만 걸러지며, 격자는 첫 번째 밴드를 사용합니다. 큰 파일은 먼저 타일로 나눕니다 |

## 입력

| 아직 만들지 않은 기능 | 대신 지금은 |
|---|---|
| 터치로 상자 선택({{key:Shift}} 키 필요) | 각 측량점을 길게 눌러 추가합니다 |
| 그리는 동안 입력하는 좌표나 거리 | 대략 그린 다음, 선형의 PI 표에서 정확한 PI 좌표를 입력합니다 |
| 패드 모서리와 구조물의 좌표 입력 | 그립을 끌고, 정밀하게 하려면 확대하여 상태 표시줄의 E와 N을 확인합니다 |
| 객체에 스냅(단절선용 측량점은 제외) | 확대하고 상태 표시줄을 살펴봅니다 |

## 3D 보기

| 아직 만들지 않은 기능 | 대신 지금은 |
|---|---|
| 3D 보기에서 그리기 또는 편집 | 평면에서 그리고 편집합니다. 3D 보기는 모든 편집을 따라갑니다 |
| 3D에서 클릭하여 도로 구간 피처 선이나 GIS 객체 선택 | 평면에서 클릭합니다 |
| 과장된 보기나 피트 단위로 내보내기 | 내보내기는 미터의 실제 축척입니다. [3D로 현장 내보내기](topic:export-3d)를 참조하십시오 |
| GLB 또는 OBJ 내보내기의 레이블, 3D의 레이블 크기와 스타일 | 레이블은 3D 보기에만 표시되며 한 가지 크기입니다. [3D로 현장 보기](topic:site-3d)를 참조하십시오 |
| 사진에서 가져온 질감, 주행 동영상 녹화, 현장 밖의 그림자, 3D 보기의 일조 시간 | 지표면 위에 씌운 지도 레이어, 주행 보기와 한 시점의 태양 위치, 하루나 계절의 [일조 시간](topic:sun-hours)은 평면에서 확인합니다 |

CivilCraft는 초기 단계입니다. 이 페이지는 현재 빌드가 하지 않는 것을 나열하므로, 찾아 헤매지 않아도 됩니다. 여기 나열된 어떤 것도 날짜가 약속되어 있지 않습니다.

## 점

| 아직 만들지 않음 | 지금은 대신 |
|---|---|
| 첫 번째 점 파일에 두 번째 점 파일을 추가하기 | 먼저 텍스트 편집기나 스프레드시트에서 파일을 결합하십시오 |
| 점 텍스트 파일 내보내기 | LandXML로 내보내기(점은 CgPoints로 나갑니다), GIS {{ui:내보내기}} 사용(P, N, E, Z, D 필드를 가진 점), 또는 점을 스프레드시트에 {{ui:복사}} |
| 점 레이블 스타일, 설명 키별 기호, 선 코드에서 만든 곡선(호), 프로젝트 간에 공유할 설명 키 파일 | 레이블은 번호, 표고, 설명 또는 그보다 적게 표시됩니다([CivilCraft 설정](topic:settings)). 키는 프로젝트 파일에 보관됩니다 |
| 단위 변환 | 가져오기 전에 파일을 변환하십시오. **단위**는 표시만 바꿉니다 |

## 지표면

| 아직 만들지 않음 | 지금은 대신 |
|---|---|
| 점으로 만든 지표면 둘 이상 | 지표면마다 프로젝트 하나 |
| (내부) 경계 숨기기 | **가장 긴 바깥 가장자리**를 사용하거나 바깥 경계를 사용하십시오 |
| 그린 단절선 하나를 선택하거나 편집하기 | {{key:Mod+Z}} 키, 또는 {{ui:그린 단절선 제거}} 후 다시 그리기 |
| LandXML에서 읽은 지표면(단절선, 경계) 편집 | {{ui:점으로부터 지표면 다시 만들기}} |
| 높이 격자로 만든 지표면 편집 | 다른 옵션으로 격자를 다시 가져오기 |
| 좌표계가 바뀔 때 LandXML에서 읽은 지표면 변환 | 먼저 {{ui:점으로부터 지표면 다시 만들기}} |
| 레이블이 붙은 지점 표고와 경사 값 | 상태 표시줄에서 읽거나, 조경 작업 공간의 **경사 분석**으로 경사에 따라 지표면을 색칠하십시오([조경 정지](topic:landscape-grading#grading-checks) 참조) |

## 선형과 종단면도

| 아직 만들지 않음 | 지금은 대신 |
|---|---|
| 클로소이드 이외의 나선. 두 곡선 사이의 나선(복합 전이) | 곡선 끝의 클로소이드 나선은 사용할 수 있습니다. 다른 나선은 이름이 붙고 LandXML 가져오기에서 건너뜁니다 |
| 두 다른 PI 사이에 PI 삽입 | 선형을 다시 그리거나, PI 좌표를 다시 입력하십시오 |
| 객체, 오프셋, 확폭에서 만든 선형 | PI로 그리십시오 |
| 수직 곡선에 K를 입력하기 | L을 입력하십시오(K가 표시됩니다) |
| 원형 및 비대칭 수직 곡선 | 대칭 포물선 곡선만 |
| 선형당 설계 종단면도 둘 이상 | 변형마다 선형 하나 |
| 종단면 보기 확대/축소, 프로파일 아래의 종단 띠 | 종단면 보기는 전체 선형에 맞춰집니다. [평면 및 종단면 시트](topic:plan-profile-sheets)에서 출력하십시오 |
| DWG 또는 LandXML의 단면 | PDF로 된 단면 시트, 면적과 체적의 {{ui:CSV}} |
| 비스듬한 샘플 선, 또는 도로를 따라 너비가 다른 샘플 선 | 선형 전체에 대해 측면마다 너비 하나 |

## 도로 구간

| 아직 만들지 않음 | 지금은 대신 |
|---|---|
| 중앙분리대, 방호벽, 템플릿을 회전시키는 편경사 | 템플릿으로 그리십시오([도로 구간 템플릿](topic:corridor-templates)). 측점별 템플릿은 아직 편경사를 받지 않습니다 |
| 두 지역 템플릿 사이의 점진적 변화(전이, 테이퍼) | 측점에서 템플릿을 바꾸거나, 테이퍼로 그린 선에 점의 너비 목표를 주십시오 |
| 가장자리를 기준으로 한 회전, LandXML의 편경사 | 원곡선에서 편경사는 중심선을 기준으로 회전합니다. 피처 선에 너비 목표를 주어 차로를 넓히십시오 |
| 사면 끝점선(선이나 지표면까지)에 대한 목표, 자체 지표면을 가진 도로 구간 | 목표는 포장 가장자리와 갓길을 움직입니다([도로 구간](topic:corridor) 참조). 도로 구간은 설계 지표면에 정지됩니다 |
| 교차로에 정지된 연석 회전부, 회전 차로와 교통섬. 비스듬한 교차에서 측면 도로의 끝을 주도로 가장자리에 맞춰 자르기. 평면상 길이와 면적에서 도로에 연결된 경로 | 만나는 도로는 직각으로 연결되며, 주도로의 가장자리를 열고 측면 도로를 그쪽으로 완만하게 연결합니다([도로가 만나는 곳](topic:corridor#where-roads-meet-roads-pads-and-paths)). 경로는 설계 지표면과 3D에서 도로 가장자리에 멈춥니다 |
| 도로 구간을 LandXML 도로로 내보내기. 선형에 두 번째 도로 구간을 IFC로 내보내기 | 설계 지표면이 내보내집니다 |
| 설계 지표면을 바꾸는 지형 템플릿(3D 또는 단면에서) | 각 층의 면적과 체적을 제공합니다([지형 템플릿](topic:corridor-templates#terrain-templates)) |
| 속도, 타이어 미끄러짐, 조향 시간, 조향 트레일러 또는 차체 간극을 포함한 회전 궤적. 표준 설계 차량 라이브러리. 차량을 끌어서 그리는 회전 궤적 | 지정한 차량 크기로 피처 선이나 선형을 따른 저속 회전 궤적([차량 회전 궤적](topic:swept-paths)) |

## 굴착과 토공량

| 아직 만들지 않음 | 지금은 대신 |
|---|---|
| 벤치, 설계로 정지되는 열린 피처 선, 다른 곳의 피처 선으로 정지하기 | 피처 선을 닫으십시오([피처 선](topic:feature-lines)), 또는 기존 지반의 단절선으로 사용하십시오 |
| 피처 선 꼭짓점 삽입 또는 제거 | 선을 다시 그리거나, 그 계단형 오프셋을 만드십시오 |
| 그린 단절선의 호(측량점을 지나는), 피처 선의 나선 | 호가 있는 피처 선을 그려 기존 지반의 단절선으로 사용하십시오 |
| 거리, 표고 또는 다른 지표면으로 정지하기 | 기존 지반으로만 사면 끝점을 정지하십시오 |
| 포장 모서리 추가 또는 제거 | 포장을 삭제하고 다시 그리십시오 |
| TIN 대 TIN(프리즘) 체적, 격자 셀 크기 선택 | 격자 방식, 셀 크기는 자동 선택 |
| 팽창과 수축, 표토, 포장 두께 | 보고된 수치에 계수를 직접 적용하십시오 |
| 자유 반출 및 과반출 비용, 서로 다른 선형 간 반출, 평면에 배치한 차입장과 사토장 | 균형점, 이동된 체적과 평균 운반 거리가 있는 토적곡선 |

## 관로망

| 아직 만들지 않음 | 지금은 대신 |
|---|---|
| 프로젝트당 망 둘 이상 | 우수와 오수는 별도 프로젝트 |
| 상수도 본관: 수질과 수령 기간, 규칙 기반 제어, 다른 밸브 종류(유량 조절, 스로틀, 유지), 동력으로 주어진 펌프, 압력에 따라 달라지는 수요, Darcy–Weisbach 옵션, 벽 두께와 압력 등급이 있는 관 카탈로그. 나머지 압력 관망은 실험실에 있습니다: [상수도 본관](topic:water-mains) | 이를 상수도 배포 소프트웨어에서 확인하십시오. 하수 설계 유량은 [하수 설계 유량](topic:sanitary-design)에 있습니다 |
| 시간에 따른 하수 유량(수문곡선, 동적 배수, 저류, 펌프, 월류) | [하수 설계 유량](topic:sanitary-design)은 설계 시트가 쓰는 정상 상태 최대 유량을 제공합니다 |
| 유입구 용량, 측구 확산, 저류지 배수 계산, 수문곡선, 한 접합부 계수 이외의 에너지 손실 | 다른 소프트웨어에서 확인하십시오. 유량, 크기와 구배선은 [우수 배수](topic:storm-drainage)에 있습니다 |
| PDF 도면, DWG, DXF 또는 LandXML의 집수 구역. 지표면에서 만든 집수 구역(분수령) | 집수 구역은 손으로 그리십시오. 프로젝트 파일에 저장됩니다 |
| 관 카탈로그, 원형이 아닌 관, 똑바로 선 상자나 원통이 아닌 구조물(원뿔, 계단, 벤치 등). 라이브러리의 배수 분류 | 매개변수에서 만든 구조물 종류([관로망](topic:pipe-network)). 지름이 있는 관 |
| 종단면 보기의 관, 곡선 관 | 오른쪽 패널에서 역(inverts)과 덮개를 읽으십시오 |

## 필지

| 아직 만들지 않음 | 지금은 대신 |
|---|---|
| 면적 또는 전면 길이로 필지 배치, 주변 선에서 필지 만들기, 통행권 | 각 필지를 모서리로 그리거나, 그 측선을 입력하십시오 |
| 평면의 곡선 표와 선 표, 손으로 옮긴 레이블 | 모든 측선은 자신을 따라 레이블이 붙습니다 |
| LandXML의 필지 | 필지는 프로젝트 파일에 저장되며 PDF, DWG, DXF로 나갑니다 |

## 트래버스

| 아직 만들지 않음 | 지금은 대신 |
|---|---|
| 최소 제곱 조정, 트랜싯 규칙, 각도를 거리에 따라 가중하기 | 컴퍼스 규칙 |
| 편각, 천정각과 사거리, 삼각 수준 측량에 의한 표고 | 수평 거리와 각도로 올바르게 환산하거나, 방위를 사용하십시오 |
| 측면 측점, 데이터 수집기의 원시 데이터 파일 | 점 파일로 점을 가져오십시오 |

## 말뚝 설치

| 아직 만들지 않음 | 지금은 대신 |
|---|---|
| 오프셋 말뚝(말뚝에서 뒤로 물린 기준점), 접촉점의 사면 말뚝 | 필요한 오프셋에서 말뚝을 설치하십시오. 갓길 너머도 포함됩니다 |
| 데이터 수집기의 자체 형식으로 말뚝을 바로 보내기 | CSV는 대부분의 데이터 수집기 사무 소프트웨어에서 열립니다 |
| 관로, 포장, 필지의 말뚝 설치 | 선형 근처의 측량점이나 필지의 측선을 사용하십시오 |

## 파일과 출력

| 아직 만들지 않음 | 지금은 대신 |
|---|---|
| DWG 또는 DXF의 텍스트, 해치, 치수. 종이 공간. 연결된 도면(외부 참조). 이진 DXF | 모델 공간의 선 도면은 열립니다([DWG 또는 DXF를 선 도면으로 열기](topic:open-dwg-dxf)). 연결된 도면은 따로 여십시오 |
| 여러 점을 한꺼번에 드래그로 이동 | 잘라내기와 붙여넣기 하거나, 한 번에 하나씩 편집하십시오 |
| 세로 용지 시트, 자체 표제란, 배치할 수 있는 뷰포트, DWG의 평면 및 종단면 시트 | PDF당 가로 평면 시트 하나, 또는 선형을 따른 평면 및 종단면 시트(PDF) |
| 표고 띠와 종단면 그리기 | 띠는 화면에만 있습니다. 필요하면 화면 캡처를 하십시오 |
| 레이어 이름, 색 또는 레이블 스타일 변경 | DXF 내보내기 후 CAD 프로그램에서 변경하십시오 |
| 클라우드 저장과 버전 기록 | `.civilcraft.json` 파일을 저장하고 백업해 두십시오. 한 프로젝트를 함께 작업하려면 CadCraft Studio의 라이브 세션을 사용하십시오([현장을 함께 라이브로 설계](topic:work-live)) |
| iPad 및 iPhone용 CadCraft Studio, Google Play의 CadCraft Studio | 기기의 브라우저에서 CivilCraft를 사용하십시오. Android에서는 getcadcraft.com/download의 APK로 CadCraft Studio를 설치합니다 |
| 여러 점 파일 또는 프로젝트 파일을 한꺼번에 열기 | 한 번에 파일 하나를 엽니다(셰이프파일의 부분처럼 함께 속하는 GIS 파일은 함께 열립니다) |

## 조경

| 아직 만들지 않음 | 지금은 대신 |
|---|---|
| 제조사의 헤드와 노즐 | 일반 헤드를 쓰거나, 파일에서 자신의 헤드를 추가하십시오. 제조사 데이터는 허가를 받는 대로 들어옵니다 |
| 점적 라인의 최대 측면 길이, 시간에 따른 유량, 펌프, 루프형 관망 | 점적 구간은 제조사가 공개한 길이를 넘지 않게 하십시오. 점검에는 분기형 관망이 필요합니다 |
| 오목한 자유형 객체의 정확한 윤곽, 지하 체적의 정확한 측정 | 볼록 껍질이 정지되며, 지하 체적은 추정치입니다(특성에 표시됩니다) |
| BimCraft 및 ModelCraft 자체의 라이브러리에서 배치(Place)하는 식물 | 조경 IFC를 내보내고 건물 옆에서 BimCraft로 여십시오 |
| 3D 보기의 상세한 식물 모델(잎, 가지, 계절), 자유형 객체와 관개 | 식물은 식물 목록의 크기로 만든 단순한 형태로 3D에 나타납니다([3D로 현장 보기](topic:site-3d)). ModelCraft의 산포 기능으로 식재 그림을 만듭니다 |
| 지표면에서 정지된 레벨 뒤를 막는 경성 포장 벽 | 플랫폼이나 포장에 수직 측면을 주십시오. 지표면에서 옹벽이 됩니다([정지](topic:grading)) |
| 자체 기호의 SVG 변환, 자체 GLB 식물 모델의 질감과 색, 압축된 GLB 기하 | 그리기 프로그램에서 변환을 먼저 평면화하십시오. 모델은 식물 색으로 그려집니다. GLB는 압축 없이 내보내십시오([식물 그래픽](topic:plant-graphics)) |
| 자신의 Library 계정에 보관한 식물 목록(앱에서 편집) | 식물 표에서 프로젝트 자체 목록을 편집하고 식물 파일로 저장하십시오 |
| 창 없이 조경 도구를 쓰는 보조 도구(파일 서버와 명령행) | CivilCraft 창이 열려 있을 때 작동합니다([AI 어시스턴트가 현장에서 작업하기](topic:assistants)) |

## GIS와 좌표계

| 아직 만들지 않음 | 지금은 대신 |
|---|---|
| 파일 지오데이터베이스. KML 스타일, 아이콘, 지상 오버레이와 네트워크 링크 | 먼저 GeoPackage, 셰이프파일 또는 GeoJSON으로 변환하십시오. KML 표시 기호는 스타일 없이 읽힙니다 |
| GIS 객체나 그 속성 편집 | GIS 프로그램에서 편집한 뒤 다시 가져오십시오. 분석 패널은 새 레이어(버퍼, 중첩, 결합, 선택)를 만들고 면적과 길이 필드를 추가하지만, 객체를 제자리에서 편집하지는 않습니다 |
| 네트워크 및 래스터 분석, 평평하거나 사각형 끝을 가진 버퍼와 한쪽 버퍼, 속성 테이블에서 행 추가 또는 삭제와 필드 형식 변경, 수동 등급 색, 출력의 스타일 범례 | 선택 도구로 객체를 고른 뒤 그로부터 레이어를 만드십시오. 평평한 끝은 제공되지 않습니다. 속성에 따른 색칠과 속성 테이블은 구현되어 있습니다: [속성에 따라 레이어 스타일 지정](topic:gis-symbology)과 [레이어 속성 테이블 사용](topic:gis-table)을 참조하십시오 |
| 레이블 스타일(크기, 배치)과 서로 겹치지 않는 레이블 | 레이블은 한 가지 크기이며, 객체가 조밀한 곳에서는 겹칠 수 있습니다 |
| 수직 기준면과 지오이드 모델 | 파일이 주는 표고를 그대로 사용합니다. 수직 기준면은 직접 확인하십시오 |
| 지역별 제안에 따른 NAD27에서 NAD83 이외의 격자 이동(OSTN15, 다른 기준면용 NTv2는 파일을 추가하면 작동), 여러 격자 동시 사용, 수직 격자 | 기준면의 격자 파일을 직접 추가하십시오. 프로젝트마다 격자 하나 |
| DXF나 3D 내보내기의 지도 레이어 | 지도 레이어는 PDF 도면에 들어가며, DWG 옆에는 그림으로 들어갑니다 |
| 로그인, 키 또는 토큰이 필요한 지도 서버 | 공개 서비스를 사용하거나, 지리 참조된 이미지 파일을 사용하십시오 |
| 지표면, 지반 모델 또는 표고 격자와 LiDAR 도구에서 LAS 또는 LAZ 파일 쓰기 | 지표면을 GeoTIFF 표고 격자로 내보내십시오. [점군](topic:point-clouds) 애드온은 정리된 점군을 LAS 1.4 또는 LAZ로 씁니다 |
| LiDAR 강도, 색과 반환; 여러 밴드의 표고 격자; 200 MB를 넘는 격자 또는 LiDAR 파일 | LiDAR는 분류별로만 걸러지며, 격자는 첫 번째 밴드를 사용합니다. 큰 파일은 먼저 타일로 나누십시오 |

## 입력

| 아직 만들지 않음 | 지금은 대신 |
|---|---|
| 터치로 상자 선택(이때 {{key:Shift}} 키가 필요합니다) | 측량점마다 길게 눌러 추가하십시오 |
| 그리는 중 입력한 좌표나 거리 | 대략 그린 뒤 선형의 PI 표에서 정확한 PI 좌표를 입력하십시오 |
| 포장 모서리나 구조물의 좌표 입력 | 그립을 드래그하고, 정확도를 위해 확대한 뒤 상태 표시줄의 E와 N을 확인하십시오 |
| 객체에 스냅(측점 제외, 단절선용 측량점은 가능) | 확대하고 상태 표시줄을 보십시오 |

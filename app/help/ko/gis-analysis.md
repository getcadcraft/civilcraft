프로젝트에 GIS 레이어가 있으면([GIS 데이터 가져오기](topic:gis-import) 참조), GIS 그룹의 **분석** 버튼(명령: `GISANALYSIS`, `ANALYZE`, `BUFFER`)을 누르면 탭이 다섯 개인 패널이 열립니다. 이 패널은 평면 옆에 계속 열려 있으므로, 선택한 항목이 작업하는 동안 평면에 표시됩니다.

무언가를 만드는 도구는 **새 레이어를 추가**하며, 읽은 레이어는 원래대로 둡니다. 각 작업은 실행 취소 한 단계입니다. 패널의 {{ui:실행 취소}}(또는 Ctrl+Z)를 누르면 새 레이어가 제거됩니다. 결과는 다른 레이어와 마찬가지로 [GIS용 준공 데이터 내보내기](topic:gis-export)로 셰이프파일, GeoJSON 또는 GeoPackage로 내보낼 수 있습니다.

정렬, 편집, 필드 계산기를 포함한 레이어의 전체 표는 [레이어 속성 테이블 사용](topic:gis-table)에 있으며, 필드 값으로 색을 지정하는 방법은 [속성으로 레이어 스타일 지정](topic:gis-symbology)에 있습니다.

모든 작업은 프로젝트 단위(피트 또는 미터)로 평면에서 이루어집니다. 프로젝트는 항상 투영 좌표계 또는 로컬 좌표계이므로, 거리 50은 50피트 또는 50미터를 뜻하며 도(degree)가 아닙니다. 높이(z)는 결과에 유지되지 않습니다.

## 버퍼

각 피처 주변에 설정한 거리만큼의 영역을 새 폴리곤 레이어로 그립니다. 점은 원이 되고, 선은 끝이 둥근 통로가 되며, 폴리곤은 커집니다. **음수** 거리는 폴리곤을 줄입니다(100 x 100 사각형을 5만큼 줄이면 90 x 90이 되고, 60만큼 줄이면 아무것도 남지 않으며 패널에 그렇게 표시됩니다). 숫자 필드에서 거리를 가져오면 피처마다 다른 거리를 줄 수 있고, **모든 버퍼를 하나의 도형으로 병합**을 선택하면 모두 디졸브합니다.

둥근 부분은 실제 곡선 안쪽의 직선 조각으로 그려지므로, 버퍼는 정확한 원보다 약간 작습니다. 기본 설정에서는 면적의 약 0.6 %, '세밀' 설정에서는 0.16 % 작습니다. 측정에 쓸 결과에는 '세밀'을 사용하십시오.

## 중첩 분석

| 도구 | 결과 |
|---|---|
| 교차 | 입력 레이어가 중첩 폴리곤과 만나는 조각들이며, 각 조각은 두 레이어의 필드를 모두 가집니다. 선과 점은 폴리곤에 맞춰 잘립니다. |
| 합집합 | 두 폴리곤 레이어가 서로의 가장자리를 따라 잘립니다. 공유된 조각은 두 레이어의 필드를 모두 가지며, 나머지는 한 레이어의 필드만 가집니다(다른 레이어의 필드는 비어 있습니다). |
| 지우기 | 입력 폴리곤에서 중첩 폴리곤을 뺀 결과입니다. 필드는 입력 쪽에 남습니다. 완전히 지워진 피처는 제외됩니다(패널이 개수를 셉니다). |
| 디졸브 | 닿거나 겹치는 폴리곤을 병합합니다. 전부 하나로 합치거나, 필드의 값마다 하나의 도형으로 만듭니다. `COUNT`와 `AREA`를 추가합니다. |

두 레이어에 모두 있는 필드 이름은 첫 번째 레이어 것을 유지하고, 두 번째 레이어의 필드는 `_2`를 붙여 씁니다. 한 레이어 안의 피처는 서로 겹치지 않아야 합니다. 겹치면 합집합에서 겹친 부분을 양쪽에서 모두 셉니다.

## 조인

공간 조인은 **원본** 레이어의 속성을 만나는 각 **대상** 피처에 복사하고, 대상의 도형을 가진 새 레이어를 만듭니다. 만나는 조건을 고르십시오: 닿거나 겹침, 대상이 원본 폴리곤 안에 놓임, 대상이 원본 피처를 포함, 가장 가까운 원본 피처(선택적으로 거리 제한 포함), 또는 거리 안에 있는 원본 피처입니다.

원본 피처가 여러 개 맞으면 첫 번째 피처의 속성을 사용합니다(가장 가까운 조인과 거리 조인에서는 가장 가까운 피처이며, `DISTANCE`가 추가됩니다). 또는 개수를 세고 숫자 필드의 합계를 냅니다: `COUNT`, 그리고 숫자 필드마다 `SUM_`, `MEAN_`, `MIN_`, `MAX_`. **일치하는 항목이 없는 대상 피처 유지**를 해제하면 이런 피처는 제외됩니다. 일치하는 것이 없는 곳의 조인 필드는 비어 있으며, 패널은 일치하지 않은 개수를 셉니다.

## 선택

속성이나 도형에 대한 조건을 입력하고 **선택**을 누르면, 피처가 개수, 표, 총 면적·길이 또는 개수와 함께 평면에 표시됩니다. 그런 다음 이를 별도의 레이어로 만들거나, 여기로 확대하거나, 선택을 해제할 수 있습니다.

| 입력 가능한 형식 | 예 |
|---|---|
| 이름으로 지정한 필드. 이름에 공백이 있으면 "따옴표" 또는 [대괄호] 사용 | `VALUE`, `"Lot Number"` |
| 숫자, '텍스트', true, false, null | `Use_ = 'Res'` |
| `=` `!=` `<>` `<` `<=` `>` `>=` | `VALUE >= 250` |
| `contains` `startswith` `endswith` `like` `ilike` (텍스트는 대소문자를 무시합니다. `like`에서 `%`는 임의의 문자열, `_`는 한 글자) | `Notes contains 'corner'` |
| `is null`, `is not null` (빈 값은 null로 봅니다) | `Notes is null` |
| `in (…)`, `not in (…)`, `between … and …` | `Use_ in ('Com', 'Ind')` |
| `+ - * /` 및 괄호 | `VALUE / 2 > 100` |
| `and`, `or`, `not` | `Use_ = 'Res' and VALUE > 200` |
| 도형 값 `$area` `$perimeter` `$length` `$x` `$y` `$vertices` | `$area > 5000` |

조건이 미완성이거나 레이어에 없는 필드 이름을 쓰면, 어디가 잘못되었는지 알려주는 문장과 함께 거부됩니다.

## 측정

레이어의 총 면적과 둘레, 길이 또는 개수를 보여주고, 레이어에 **필드를 추가**합니다. 폴리곤에는 `AREA`와 `PERIMETER`, 선에는 `LENGTH`(평면 길이), 점에는 `X`와 `Y`가 추가됩니다. 이미 있는 필드는 절대 덮어쓰지 않으며, 새 필드는 `AREA_2`처럼 이름이 붙습니다. 이 작업도 실행 취소 한 단계입니다. **통계**는 숫자 필드의 개수, 합계, 평균, 최솟값, 최댓값을 구하며, 선택적으로 다른 필드의 값마다 계산할 수 있습니다.

:::note
이 도구들의 검산은 테스트(`node bin/test-civilcraft-gisanalysis.mjs`)에서 손으로 수행합니다. 예를 들어, 100 x 100 필지가 100 x 80 구역과 만나면 교차 면적은 3,000 + 3,000이고, 길이 100인 선을 10만큼 버퍼링하면 2,000 + 원입니다.
:::

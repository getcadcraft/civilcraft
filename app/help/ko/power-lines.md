전력선 작업 공간은 이미 있는 CivilCraft 현장에 가공선과 지중 케이블을 올려 놓습니다. 같은 측량 점, 같은 지면, 같은 프로젝트 파일을 사용합니다.

:::warning
설계 보조 도구입니다. 이 작업 공간은 **사용자의** 하중 케이스와 한계에 따라 처짐, 장력, 이격 거리, 하중을 계산하며, 어떤 국가의 표준도 내장하고 있지 않습니다. 무엇인가 시공하기 전에 기술자가 적용 가능한 표준에 따라 모든 결과를 확인해야 합니다.
:::

## 열기

{{ui:지표면}} › {{ui:더보기}} › {{ui:전력선 작업 공간}}을 선택하거나, 작업 공간 아래의 **전력선**을 선택합니다. 그러면 도구 모음에 **전력선** 그룹이 나타나고, 설계 그룹과 GIS 그룹은 물러납니다. 작업 공간 아래에서 **토목**을 선택하면 돌아갑니다. CivilCraft는 이 컴퓨터에서 마지막으로 사용한 작업 공간을 기억합니다.

왼쪽 패널 상단에 두 섹션이 추가됩니다.

- **전력선**: 하중 케이스와 한계, 프로젝트의 선로와 케이블, 그리고 항상 최신 상태인 **검사**. 검사 항목을 클릭하면 그 문제와 관련된 대상이 선택됩니다.
- **라이브러리**: 내 전선, 케이블, 지지물, 장비, 트렌치 유형. [내 전력선 라이브러리](topic:power-line-library)를 참조하십시오.

## 전력선 그룹의 도구

| 도구 | 기능 | 주제 |
|---|---|---|
| **선로** | 가공선. 각 지지물을 클릭합니다 | [가공선 그리기](topic:overhead-line) |
| **지지물** | 경간에 지지물을 추가합니다 | [가공선 그리기](topic:overhead-line) |
| **케이블** | 트렌치 안의 지중 케이블 경로 | [지중 케이블](topic:underground-cables) |
| **장비** | 함체, 변압기, 접속재, 또는 네트워크에 전원을 공급하는 전원 | [지중 케이블](topic:underground-cables) |
| **장애물** | 선로가 가로지르는 것: 도로, 건물, 다른 선로 | [검사](topic:power-line-checks) |
| **종단면도** | 선로 종단면: 지면, 지지물, 각 하중 케이스의 전선 | [가공선 그리기](topic:overhead-line#the-line-profile) |
| **더보기** | 하중 케이스 및 한계, 가선 표, 물량, 시트 및 보고서, GIS, 검토 파일 | [처짐과 장력](topic:sag-and-tension), [출력물](topic:power-line-outputs), [검토 파일](topic:power-line-study-file) |

추가하는 모든 항목은 실행 취소 한 단계이며, 프로젝트 파일에 저장됩니다. 또한 `C-POWR-…` 이름의 도면층에 평면도로 그려지므로, DXF, DWG, PDF 내보내기에도 포함됩니다.

Бир тамгалуу баскычтар, сиз кутуга текст терип жатпаганыңызда иштейт. {{key:Mod}} менен жарлыктар Mac'та Command, калган жерлерде Ctrl колдонот. Ошондой эле караңыз: [Браузердеги баскычтар](common:keys).

## Файлдар жана түзөтүү

| Баскыч | Аракет |
|---|---|
| {{key:Mod+O}} | Чекит файлын, LandXML же долбоорду ачуу |
| {{key:Mod+S}} | Долбоорду сактоо (`.civilcraft.json` файлын жүктөйт) |
| {{key:Mod+P}} | Планды PDFке басуу (браузердин басмасы эмес, басуу диалогун ачат) |
| {{key:Mod+Z}} | Артка кайтаруу |
| {{key:Mod+Y}} | Кайра аткаруу |
| {{key:Delete}} | Тандалган чекиттерди, трассаны, платформаны, структураны, түтүктү же PVIни өчүрүү |
| {{key:Mod+C}} | Тандалган чекиттерди көчүрүү (электрондук таблица үчүн сап катары да) |
| {{key:Mod+X}} | Тандалган чекиттерди кесип алуу |
| {{key:Mod+V}} | Чекиттерди чаптоо: алар көрсөткүчтү ээрчийт, жайгашкан жерди басыңыз |
| {{key:Mod+Shift+V}} | Ордунда чаптоо: чекиттердин өз координаттарында |
| {{key:Mod+D}} | Тандалган чекиттерди көчүрмөлөө: көчүрмө көрсөткүчтү ээрчийт |
| {{key:Mod+A}} | Бардык чекиттерди тандоо |
| {{key:Esc}} | Эч нерсени тандабоо (жана чаптоону жокко чыгаруу) |

{{key:Mod+S}}, {{key:Mod+O}} жана {{key:Mod+P}} кутуга текст терип жатканда да иштейт. Кутуда {{key:Mod+Z}} жана {{key:Mod+Y}} адаттагыдай терилген текстти артка кайтарат, ошондой эле {{key:Mod+C}}, {{key:Mod+X}}, {{key:Mod+V}} жана {{key:Mod+A}}: кутуда алар анын текстин көчүрөт, кесет, чаптайт жана тандайт. Баракта (панелде) тандалган текст менен {{key:Mod+C}} ошол текстти көчүрөт. {{key:Mod+Shift+Z}} CivilCraft'та эч нерсе кылбайт: {{key:Mod+Y}} же {{ui:Кайра аткаруу}} баскычын колдонуңуз.

:::mac
Mac'тагы **delete** деп белгиленген баскыч браузерге {{key:Backspace}} болуп саналат. Тандоону өчүрүү үчүн {{key:Delete}} басыңыз (Fn жана delete), же куралдар тилкесиндеги {{ui:Дагы}} менюсунан {{ui:Өчүрүү}} тандаңыз.
:::

## Чийүүдө

| Баскыч | Аракет |
|---|---|
| {{key:Enter}} | Трассаны, платформаны, түтүк сабын, бөлүүчү сызыкты же чек араны бүтүрүү |
| {{key:Backspace}} | Акыркы басылган чекитти алып салуу |

| {{key:Esc}} | Чийүүнү (же чаптоону) жокко чыгаруу; кайра басканда (же эч нерсе чийилбесе), {{ui:Тандоо}}га кайтып, тандоону тазалоо |

| Баскыч же аракет | Натыйжа |

| Ортоңку баскычты сүйрөө | Жылдыруу |
| Оң баскычты сүйрөө | Жылдыруу (меню ачылбайт) |
| {{key:Space}} жана сүйрөө | Жылдыруу |
| Чыкылдатуу | {{ui:Тандоо}} менен тандоо, же чийүү куралы менен чекит коюу |
| {{key:Shift}} жана чыкылдатуу | Тандоого чекит кошуу же алып салуу |
| {{key:Shift}} жана сүйрөө | Кутуча чийүү: анын ичиндеги чекиттер тандоого кошулат. Аларды айлантып сүйрөсөңүз, [аркан](topic:lasso-selection) болот |
| Аркан чийип жатканда {{key:Space}} | Терезе, андан кийин кесилиш, андан кийин тосмо |
| Чаптап жатканда чыкылдатуу | Чапталган чекиттерди ошол жерге коюу ({{key:Enter}} аларды өз координаттарына коёт) |
| Тутканды сүйрөө | PIди, платформанын бурчун же структураны жылдыруу (бир кадам артка кайтаруу) |
| {{key:Up}} {{key:Down}} {{key:Left}} {{key:Right}} | Жылдыруу, план фокуста болгондо (адегенде аны басыңыз) |

= баскычы {{key:Plus}} сыяктуу чоңойтат, ошондуктан Shift керек эмес.

| Аракет | Натыйжа |

Профиль көрүнүшү чоңойбойт жана жылбайт.

## Экран жана жардам

| Баскыч | Аракет |
|---|---|
| {{key:F1}} | Бул жардамды ачуу же жабуу (капталдагы панель); колдонмонун тилкесиндеги {{ui:Жардам}} дагы ушуну кылат |
| {{key:Esc}} | Жардам панели ачык болсо, аны жабуу |
| {{key:Ctrl+Shift+F}} | Экран режимдерин айлантуу: толук экран, тилкелери жашырылган толук экран, кадимки |
| {{key:Esc}} | Толук экрандан чыгуу (браузердин өз баскычы) |

{{key:F1}} CivilCraft аны көрмөй туруп браузер аны кабыл алат, ошондуктан ар кандай куралда иштейт. Көпчүлүк Mac клавиатураларында fn менен F1 басыңыз же {{ui:Жардам}} баскычын басыңыз. {{key:Ctrl+Shift+F}} ар бир платформада, Mac'та да Control баскычын колдонот. Жардамдан издөөнү билүү үчүн [Жардамды колдонуу](common:help) караңыз.

## Чычкан, сенсордук тактача жана сенсордук экран

:::mouse
- Дөңгөлөк көрсөткүч турган жерде чоңойтат. Эркин айлануучу дөңгөлөктүү чычкан тез чоңойтат: кыска бурулуштарды бериңиз.
- Бош жерди каалаган сүйрөө, ортоңку баскыч, оң баскыч же {{key:Space}} жана сүйрөө менен жылдырыңыз.
:::

:::mac
Mac сенсордук тактачасында:

- Эки манжа менен сыдыруу **чоңойтат** (жылдырбайт), кысуу дагы чоңойтат.
- Жылдыруу үчүн бош жерди бир манжа менен басып сүйрөңүз, же {{key:Space}} кармап сүйрөңүз.
- Эки манжа менен чыкылдатуу (оң чыкылдатуу) меню ачпайт жана өзү эч нерсе кылбайт.
:::

:::touch
Сенсордук экранда:

- Биринчи басуу баскычтарды жана меню саптарын манжага ылайыктайт.
- Тандоо же чекит коюу үчүн таптаңыз; бош жерде бир манжа менен сүйрөө жылдырат. Таптоо бир аз титиреши мүмкүн: манжа 10 пиксельдей жылгандан кийин гана жылдырат.
- Эки манжа кысып чоңойтат, жана бирге жылып жылдырат.
- Тутканды же PVIни бир манжа менен сүйрөңүз. Тутканы айлана манжанын туурасындай жерди жабат.
- Трассаны, платформаны, бөлүүчү сызыкты, чек араны, түтүк сабын, белги сызыгын же участканы чийип жатканыңызда планда тилке {{ui:Бүтүрүү}} ({{key:Enter}}), {{ui:Чекитти артка кайтаруу}} ({{key:Backspace}}) жана {{ui:Жокко чыгаруу}} ({{key:Esc}}) сунуш кылат. Узак басуу (бир аз жылбай жарым секунд) дагы бүтүрөт.
- {{ui:Тандоо}}да чекиттин узак басуусу аны тандоого кошот же алып салат, {{key:Shift}}+чыкылдатуудай.
- 3D көрүнүштө бир манжа айлантат, эки манжа кысып жылдырат, таптоо тандайт.
- Сенсордо hover жок, ошондуктан статус тилкесинин көрсөткүчтөрү манжа басылып турганда гана жаңырат.
:::

## Браузердин баскычтары жеңет

Кээ бир баскычтар браузерге таандык жана CivilCraft'ка эч качан жетпейт, мисалы {{key:Mod+W}} (өтмөктү жабуу), {{key:Mod+T}} (жаңы өтмөк), {{key:Mod+N}} (жаңы терезе) жана {{key:F11}} (Windows жана Linux браузерлериндеги толук экран). CivilCraft аларды колдонбойт. Эгер жарлык браузерде бир нерсе ачса, планды бир жолу басыңыз, ошондо барак фокуска ээ болот, кайра аракет кылыңыз.

## Жылдыруу кайда турат

Жылдыруу командасы жок: {{ui:Тандоо}}ну тандап, чекитти же тутканы сүйрөңүз, же анын координаттарын {{ui:Касиеттер}}де түзөтүңүз. Караңыз: [Чекиттерди түзөтүү](topic:edit-points).

CivilCraft азырынча ишке ашып жатат. Бул бет учурдагы версия эмнени аткарбаганын көрсөтөт, ошондуктан аны издебей коюңуз. Бул жерде эч нерсе датага убада берилбейт.

## Чекиттер

| Азырынча курулган эмес | Ордуна, азыр |
|---|---|
| Экинчи чекит файлын биринчисине кошуу | Адегенде файлдарды текст редакторунда же электрондук таблицада бириктириңиз |
| Чекиттик текст файлын экспорттоо | LandXML экспорттоңуз (чекиттер CgPoints катары чыгат), {{ui:Экспорт}} GIS (P, N, E, Z жана D талаалары менен чекиттер) колдонуңуз же чекиттерди электрондук таблицага {{ui:Көчүрүү}} |
| Чекиттердин жазуу стилдери, сүрөттөө ачкычы боюнча символдор, сызык коддорунан ийрилер (аркалар), долбоорлор ортосунда бөлүшүү үчүн сүрөттөө ачкыч файлы | Жазуулар номерди, бийиктикти жана сүрөттөмөнү же андан азыраагын көрсөтөт ([CivilCraft жөндөөлөрү](topic:settings)); ачкычтар долбоор файлында сакталат |
| Бирдиктерди которуу | Импорттоодон мурун файлды которуңуз; **Бирдиктер** жөн гана белгилерди өзгөртөт |

| LandXML жолдору катары экспорттолгон коридорлор; IFC экспортундагы трассадагы экинчи коридор | Долбоордук бет экспорттолот |
| Долбоордук бетти өзгөрткөн рельеф шаблондору, 3Dде же кесилиштерде | Алар ар бир катмардын аянттарын жана көлөмдөрүн берет ([Рельеф шаблондору](topic:corridor-templates#terrain-templates)) |

| PDF басып чыгарууда, DWGде, DXFте же LandXMLде суу жыйноочу аймактар; беттен суу бөлгүчтөр | Суу жыйноочу аймактарды кол менен тартыңыз; алар долбоордук файлда сакталат |
| Түтүк каталогдору, тегерек эмес түтүктөр, кутуча же цилиндр эмес түзүлүштөр (конус, баскычтар, сүйөөчтөр) | Параметрлерден түзүлүш түрлөрү ([Түтүк тармагы](topic:pipe-network)); диаметри бар түтүктөр |
| Профиль көрүнүшүндөгү түтүктөр, ийри түтүктөр | Оң панелден инверттерди жана жабууну окуңуз |

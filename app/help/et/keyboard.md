Üksikud tähtklahvid töötavad, kui sa ei kirjuta kasti. Otseteed {{key:Mod}}-iga kasutavad Macil Command-klahvi ja mujal Ctrl-klahvi. Vaata ka [Klahvid brauseris](common:keys).

## Failid ja redigeerimine

| Klahv | Toiming |
|---|---|
| {{key:Mod+O}} | Ava punktifail, LandXML või projekt |
| {{key:Mod+S}} | Salvesta projekt (laeb alla faili `.civilcraft.json`) |
| {{key:Mod+P}} | Prindi plaan PDF-iks (avab plaanide printimise dialoogi, mitte brauseri printimise) |
| {{key:Mod+Z}} | Võta tagasi |
| {{key:Mod+Y}} | Tee uuesti |
| {{key:Delete}} | Kustuta valitud mõõdistuspunktid, joondus, plats, rajatis, toru või PVI |
| {{key:Mod+C}} | Kopeeri valitud mõõdistuspunktid (ka punktiridadena tabelarvutusse) |
| {{key:Mod+X}} | Lõika valitud mõõdistuspunktid |
| {{key:Mod+V}} | Kleebi punktid: need järgivad kursorit, klõpsa, kuhu nad lähevad |
| {{key:Mod+Shift+V}} | Kleebi paika: punktide enda koordinaatidel |
| {{key:Mod+D}} | Dubleeri valitud punktid: koopia järgib kursorit |
| {{key:Mod+A}} | Vali kõik mõõdistuspunktid |
| {{key:Esc}} | Ära vali midagi (ja tühista kleepimine) |

{{key:Mod+S}}, {{key:Mod+O}} ja {{key:Mod+P}} töötavad ka siis, kui kirjutad kasti. {{key:Mod+Z}} ja {{key:Mod+Y}} tekstikastis võtavad tagasi sinu kirjutamise, nagu tavaliselt, ning samamoodi {{key:Mod+C}}, {{key:Mod+X}}, {{key:Mod+V}} ja {{key:Mod+A}}: kastis need kopeerivad, lõikavad, kleebivad ja valivad teksti. Kui lehel (paneelis) on tekst valitud, kopeerib {{key:Mod+C}} selle teksti. {{key:Mod+Shift+Z}} CivilCraftis ei tee midagi: kasuta {{key:Mod+Y}} või nuppu {{ui:Tee uuesti}}.

:::mac
Macis klaviatuuril, kus klahvil on silt **delete**, on brauseri jaoks {{key:Backspace}}. Valiku kustutamiseks vajuta {{key:Delete}} (Fn ja delete) või vali tööriistariba menüüst {{ui:Veel}} käsk {{ui:Kustuta}}.
:::

## Tööriistad

| Klahv | Tööriist |
|---|---|
| {{key:V}} | {{ui:Vali}} |
| {{key:M}} | {{ui:Mõõda}}: kaugused, pindalad ja kalded plaanil ([Mõõda](topic:measure)) |
| {{key:A}} | {{ui:Trass}} |
| {{key:G}} | {{ui:Plats}} |
| {{key:P}} | {{ui:Torud}} |
| {{key:B}} | {{ui:Murdejoon}} |
| {{key:O}} | {{ui:Piirjoon}} |
| {{key:R}} | Näita või peida pikiprofiili vaade |
| {{key:I}} | Lülita {{ui:Lisa PVI-d}} sisse või välja (avab pikiprofiili vaate, kui see on suletud) |
| {{key:F}} | {{ui:Sobita}}: näita kõike |
| {{key:D}} | {{ui:3D}}: näita objekti 3D-vaates või mine tagasi plaanile |
| {{key:E}} | Näita või peida kalded ja kõrgused mööda iga tunnusjoont (ainult ekraanil) |

Aktiivse tööriista klahvi uuesti vajutamine viib tagasi tööriistale {{ui:Vali}}. Shiftiga tehtud tähtklahvid ei tee midagi.

## Joonistamise ajal

| Klahv | Toiming |
|---|---|
| {{key:Enter}} | Lõpeta joondus, plats, torujooks, murdejoon või piir |
| {{key:Backspace}} | Eemalda viimati klõpsatud punkt |
| {{key:C}} | Tunnusjoon: lülita kaared sisse või välja (pärast tippu klõpsa kõvera punkti, siis selle lõppu) |
| {{key:Esc}} | Tühista joonistamine (või kleepimine); kui vajutad uuesti (või kui midagi pole joonistatud), mine tagasi tööriistale {{ui:Vali}} ja tühista valik |

## Plaanivaade

| Klahv või toiming | Tulemus |
|---|---|
| Ratas | Suumi sisse või välja kursori kohal |
| Lohistamine tühjal alal | Nihuta (igas tööriistas; lühike klõps klõpsab ikka; kui {{key:Shift}} on all, joonistab see valikukasti) |
| Lohistamine keskmise nupuga | Nihuta |
| Lohistamine parema nupuga | Nihuta (menüü ei avane) |
| {{key:Space}} ja lohistamine | Nihuta |
| Klõps | Vali (tööriistaga {{ui:Vali}}) või aseta punkt (joonistamistööriistaga) |
| {{key:Shift}} ja klõps | Lisa mõõdistuspunkt valikusse või eemalda see |
| {{key:Shift}} ja lohistamine | Joonista kast: selles olevad mõõdistuspunktid lisatakse valikusse. Lohista ümber nende [lasso](topic:lasso-selection) jaoks |
| {{key:Space}} lasso joonistamise ajal | Aken, siis ristumine, siis piirdeaed |
| Klõps kleepimise ajal | Aseta kleebitud punktid sinna ({{key:Enter}} paneb need nende enda koordinaatidele) |
| Lohista käepidet | Teisalda PI, platsi nurk või rajatis (üks tagasivõtmise samm) |
| {{key:Up}} {{key:Down}} {{key:Left}} {{key:Right}} | Nihuta, kui plaanil on fookus (klõpsa kõigepealt sellele) |
| {{key:Plus}} ja {{key:Minus}} | Suumi keskelt sisse ja välja, kui plaanil on fookus |

Klahv = suumib sisse nagu {{key:Plus}}, nii et Shifti pole vaja.

## Pikiprofiili vaade

| Toiming | Tulemus |
|---|---|
| Klõps, kui {{ui:Lisa PVI-d}} on sees | Lisa sinna PVI |
| Klõps PVI-l | Vali see |
| Lohista PVI | Teisalda see (üks tagasivõtmise samm) |
| {{key:Delete}} või {{key:Backspace}} | Eemalda valitud PVI ({{key:Backspace}} ainult siis, kui pikiprofiili vaates on fookus) |

Pikiprofiili vaade ei suumi ega nihuta.

## Ekraan ja abi

| Klahv | Toiming |
|---|---|
| {{key:F1}} | Ava või sulge see abi (külgpaneel); rakenduse ribal {{ui:Abi}} teeb sama |
| {{key:Esc}} | Sulge abipaneel, kui see on avatud |
| {{key:Ctrl+Shift+F}} | Vaheta ekraanirežiime: täisekraan, täisekraan peidetud ribadega, tavaline |
| {{key:Esc}} | Lahku täisekraanilt (brauseri enda klahv) |

{{key:F1}} jõuab brauserini enne CivilCraftit, nii et see töötab igas tööriistas. Enamikul Maci klaviatuuridel vajuta fn koos F1-ga või kliki {{ui:Abi}}. {{key:Ctrl+Shift+F}} kasutab igal platvormil Control-klahvi, sh Macil. Selle abi otsimise kohta vaata [Abi kasutamine](common:help).

## Hiir, puuteplaat ja puutetundlik ekraan

:::mouse
- Ratas suumib kursori kohal. Vabalt pöörlev ratas suumib kiiresti: tee lühikesi pöördeid.
- Nihuta mis tahes lohistusega tühjal alal, keskmise nupuga, parema nupuga või {{key:Space}} ja lohistamisega.
:::

:::mac
Macis puuteplaadil:

- Kahe sõrmega kerimine **suumib** (ei nihuta) ja näpistamine suumib samuti.
- Nihutamiseks vajuta ja lohista tühjal alal ühe sõrmega või hoia {{key:Space}} all ja lohista.
- Kahe sõrmega klõps (paremklõps) ei ava menüüd ega tee midagi iseseisvalt.
:::

:::touch
Puutetundlikul ekraanil:

- Esimene puude teeb nupud ja menüüread sõrmesuuruseks.
- Puuduta valimiseks või punkti paigutamiseks; ühe sõrmega lohistamine tühjal alal nihutab. Puudutus võib veidi kõikuda: nihutamine algab alles siis, kui sõrm liigub umbes 10 pikslit.
- Kaks sõrme näpistavad suumimiseks ja liikudes koos nihutamiseks.
- Lohista käepidet või PVI-d ühe sõrmega. Käepidemete ümber on sõrme laiune ala.
- Kui joonistad joondust, platsi, murdejoont, piiri, torujooksu, tunnusjoont või parsellit, pakub plaani kohal riba {{ui:Lõpeta}} ({{key:Enter}}), {{ui:Võta punkt tagasi}} ({{key:Backspace}}) ja {{ui:Loobu}} ({{key:Esc}}). Pikk vajutus (pool sekundit liikumata) lõpetab samuti.
- Valikus {{ui:Vali}} lisab pikk vajutus mõõdistuspunkti valikusse või eemaldab selle, nagu {{key:Shift}}+klõps.
- 3D-vaates üks sõrm pöörleb, kaks näpistavad ja nihutavad ning puudutus valib.
- Puutega ei ole hiireliikumist, nii et olekuriba näidud uuenevad ainult siis, kui sõrm on all.
:::

## Brauseri klahvid, mis võidavad

Mõned klahvid kuuluvad brauserile ja ei jõua CivilCraftini, näiteks {{key:Mod+W}} (sulge vahekaart), {{key:Mod+T}} (uus vahekaart), {{key:Mod+N}} (uus aken) ja {{key:F11}} (täisekraan Windowsi ja Linuxi brauserites). CivilCraft neid ei kasuta. Kui otsetee avab brauseris midagi muud, klõpsa plaanil korra, et leht saaks fookuse, ja proovi uuesti.

## Kus asub teisaldamine

Teisaldamise käsku ei ole: vali {{ui:Vali}} ja lohista punkt või tipp, või muuda selle koordinaate {{ui:Omadused}}-s. Vaata [Punktide muutmine](topic:edit-points).

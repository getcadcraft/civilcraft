Зарим агаарын шугамын програм судалгаагаа `.DON` файлд (XML текст) хадгалдаг. CivilCraft нэг шугамыг ийм файл болгон бичиж, мөн түүний тулгуурыг уншиж чадна.

:::warning
**Туршаагүй.** Бид үүнийг хэрэглэгчийн хуваалцсан форматын талбарын нэрсийн жагсаалтаас бүтээсэн, бодит файлаас биш, мөн бид файлаа тэдгээрийг уншдаг програмд нээж үзээгүй. Файлыг тэнд нээж, найдахаасаа өмнө утга бүрийг шалгана уу. Хэрэв та `.DON` файлыг (үйлчлүүлэгчийн мэдээллийг арилгаад) хуваалцаж чадвал энэ нь биднийг зөв болгоход тусална.
:::

## Судалгааны файл хадгалах

1. Шугамдаа дамжуулагч өгч, үр дүн байгааг шалгана (Шинж чанаруудад «тооцоолоогүй» гэсэн зүйл байхгүй).
2. {{ui:Бусад}} › {{ui:Судалгааны файл (.DON) хадгалах…}}, шугамыг сонгоно, тайлбар ба ажлын дугаар нэмнэ.
3. {{ui:Судалгааны файлыг хадгалах}}.

Файлд шугамын тулгуурууд (координат, газар, өндөр, үүрэг, хөндлөн тулгуур, хадгалсан эсвэл санал болгосон тулгуур, ачааллын тохиолдол бүрийн ачаалал, суурь) байна; зангилаа хоорондын зам бүр нэг хэсэг (дамжуулагч, хүчдэл, дүрмийн завсар, завсрууд, татах хүч ба өргөлтийн параметр, ачааллын тохиолдол бүрийн хамгийн их татах хүч) болж; мөн утас татах хүснэгтүүд. Уртыг метрээр, хүчийг daN-ээр бичнэ; текст Latin-1-ээр бичигдэх тул түүнээс гадуурх тэмдэгт `?` болно.

## Судалгааны файл унших

{{ui:Бусад}} › {{ui:Судалгааны файл (.DON) нээх…}} нь тулгуурыг шинэ шугамд уншина. Дамжуулагч, тулгуур, хөндлөн тулгуурыг таны номын санд нэрээр нь таарууллаа; олдохгүй зүйлийг Шинж чанаруудаас сонгохоор үлдээнэ.

Нэг үсгийн товчлуурууд текст бичдэг хайрцагт байхгүй үед ажиллана. {{key:Mod}}-тай товчлолууд Mac дээр Command, бусад дээр Ctrl ашиглана. Мөн [Хөтөч дэх товчлуурууд](common:keys)-ийг үзнэ үү.

## Файл ба засвар

| Товч | Үйлдэл |
|---|---|
| {{key:Mod+O}} | Цэгийн файл, LandXML эсвэл төсөл нээх |
| {{key:Mod+S}} | Төслийг хадгалах (`.civilcraft.json` файл татна) |
| {{key:Mod+P}} | Төлөвлөгөөг PDF болгон хэвлэх (хэвлэх харилцах цонх нээгдэнэ, хөтчийн хэвлэлт биш) |
| {{key:Mod+Z}} | Буцаах |
| {{key:Mod+Y}} | Дахин хийх |
| {{key:Delete}} | Сонгосон хэмжилтийн цэгүүд, трасс, тавцан, бүтэц, хоолой эсвэл PVI устгах |
| {{key:Mod+C}} | Сонгосон хэмжилтийн цэгүүдийг хуулах (мөн хүснэгтийн мөр мэт) |
| {{key:Mod+X}} | Сонгосон хэмжилтийн цэгүүдийг таслах |
| {{key:Mod+V}} | Цэг буулгах: тэд заагчийг дагана, очих газраа дарна |
| {{key:Mod+Shift+V}} | Яг тэр байрлалд буулгах: цэгүүдийн өөрийн координатад |
| {{key:Mod+D}} | Сонгосон цэгүүдийг давхардуулах: хуулбар заагчийг дагана |
| {{key:Mod+A}} | Бүх хэмжилтийн цэгийг сонгох |
| {{key:Esc}} | Юуг ч сонгохгүй (мөн буулгахыг цуцлах) |

{{key:Mod+S}}, {{key:Mod+O}} ба {{key:Mod+P}} хайрцагт бичиж байсан ч ажиллана. Хайрцагт {{key:Mod+Z}} ба {{key:Mod+Y}} таны бичсэн текстийг буцаана, {{key:Mod+C}}, {{key:Mod+X}}, {{key:Mod+V}} ба {{key:Mod+A}} ч мөн адил: хайрцагт тэд текстийг хуулж, таслаж, буулгаж, сонгоно. Хуудсан дээр (самбарт) текст сонгогдсон үед {{key:Mod+C}} тэр текстийг хуулна. {{key:Mod+Shift+Z}} CivilCraft-д ямар ч үйлдэлгүй: {{key:Mod+Y}} эсвэл {{ui:Дахин хийх}} товчийг ашиглана.

:::mac
Mac дээр **delete** гэж тэмдэглэгдсэн товч хөтөчид {{key:Backspace}} болдог. Сонголтыг устгахын тулд {{key:Delete}} (Fn ба delete) дарна, эсвэл хэрэгслийн самбарын {{ui:Бусад}} цэснээс {{ui:Устгах}}-ыг сонгоно.
:::

| {{key:A}} | {{ui:Трасс}} |
| {{key:G}} | {{ui:Тавцан}} |

| {{key:B}} | {{ui:Тасалгааны шугам}} |
| {{key:O}} | {{ui:Хил}} |

| {{key:I}} | {{ui:PVI нэмэх}}-ийг асаах эсвэл унтраах (профайлын харагдацыг нээнэ, хэрэв хаалттай бол) |

Идэвхтэй хэрэгслийн товчийг дахин дарвал {{ui:Сонгох}} руу буцна. Shift-тэй үсгүүд ямар ч үйлдэлгүй.

## Зурах явцад

| Товч | Үйлдэл |
|---|---|
| {{key:Enter}} | Трасс, тавцан, хоолойн зам, тасалгааны шугам эсвэл хил дуусгах |
| {{key:Backspace}} | Сүүлд дарсан цэгийг устгах |
| {{key:C}} | Шинж шугам: нумыг асаах эсвэл унтраах (оройн цэгийн дараа муруй дээрх цэгийг, дараа нь төгсгөлийг дарна) |
| {{key:Esc}} | Зурахыг цуцлах (эсвэл буулгахыг); дахин дарвал (эсвэл юу ч зураагүй үед) {{ui:Сонгох}} руу буцаж сонголтыг арилгана |

| Товч эсвэл үйлдэл | Үр дүн |
|---|---|

| Дунд товчоор чирэх | Шилжүүлэх |
| Баруун товчоор чирэх | Шилжүүлэх (цэс нээгдэхгүй) |
| {{key:Space}} ба чирэх | Шилжүүлэх |
| Дарах | {{ui:Сонгох}}-оор сонгох, эсвэл зурах хэрэгслээр цэг байрлуулах |
| {{key:Shift}} ба дарах | Хэмжилтийн цэгийг сонголтод нэмэх эсвэл хасах |
| {{key:Shift}} ба чирэх | Хайрцаг зурах: доторх хэмжилтийн цэгүүд сонголтод нэмэгдэнэ. Тэдгээрийг тойрон чирвэл [лассо](topic:lasso-selection) |
| Лассо зурах явцад {{key:Space}} | Цонх, дараа нь огтлолцол, дараа нь хашаа |
| Буулгах явцад дарах | Буулгасан цэгүүдийг тэнд тавина ({{key:Enter}} нь тэдгээрийг өөрийн координатад тавина) |
| Бариул чирэх | PI, тавцангийн булан эсвэл бүтцийг зөөнө (нэг буцаах алхам) |
| {{key:Up}} {{key:Down}} {{key:Left}} {{key:Right}} | Шилжүүлэх, төлөвлөгөө фокустай үед (эхлээд дарна уу) |
| {{key:Plus}} ба {{key:Minus}} | Голд нь томруулах ба жижигрүүлэх, төлөвлөгөө фокустай үед |

{{key:=}} товч {{key:Plus}}-тай адил томруулна, тиймээс Shift хэрэггүй.

|---|---|

Профайлын харагдац томруулахгүй, шилжихгүй.

## Дэлгэц ба тусламж

| Товч | Үйлдэл |
|---|---|
| {{key:F1}} | Энэ тусламжийг нээх эсвэл хаах (хажуугийн самбар); апп-ын самбар дээрх {{ui:Тусламж}} ч мөн адил |
| {{key:Esc}} | Тусламжийн самбар нээлттэй үед хаах |
| {{key:Ctrl+Shift+F}} | Дэлгэцийн горимуудыг эргүүлэх: бүтэн дэлгэц, туузгүй бүтэн дэлгэц, энгийн |
| {{key:Esc}} | Бүтэн дэлгэцээс гарах (хөтчийн өөрийн товч) |

{{key:F1}} нь CivilCraft-д хүрэхээсээ өмнө тусламжид хүрдэг тул ямар ч хэрэгсэлд ажиллана. Ихэнх Mac-ийн гарт fn-тэй F1-ийг дарна, эсвэл {{ui:Тусламж}}-ийг дарна. {{key:Ctrl+Shift+F}} бүх платформд, Mac дээр ч Control товч ашиглана. Энэ тусламжаас хайх талаар [Тусламж ашиглах](common:help)-ыг үзнэ үү.

## Хулгана, трекпад ба мэдрэгч

:::mouse
- Дугуй нь заагч дээр томруулна. Эргэдэг дугуйтай хулгана хурдан томруулна: богино эргүүлэлт өг.
- Хоосон зайн дээрх чирэлт, дунд товч, баруун товч, эсвэл {{key:Space}} ба чирэх замаар шилжүүлнэ.
:::

:::mac
Mac-ийн трекпад дээр:

- Хоёр хурууны гүйлгэлт **томруулна** (шилжүүлэхгүй), нугалах нь бас томруулна.
- Шилжүүлэхийн тулд нэг хурууг хоосон зайд дарж чирэх эсвэл {{key:Space}}-ийг барьж чирнэ.
- Хоёр хурууны дарах (баруун товч) ямар ч цэс нээхгүй, өөрөө ямар ч үйлдэлгүй.
:::

:::touch
Мэдрэгч дэлгэц дээр:

- Анхны хүрэлт товч ба цэсний мөрүүдийг хурууны хэмжээтэй болгоно.
- Дарах нь сонгох эсвэл цэг тавих; хоосон зайд нэг хуруу чирвэл шилжүүлнэ. Дарахад бага зэрэг сэгсэрч болно: хуруу ойролцоогоор 10 пиксел шилжсэний дараа л шилжүүлнэ.
- Хоёр хуруу нугалж томруулна, хамт зөөвөл шилжүүлнэ.
- Бариул эсвэл PVI-г нэг хуруугаар чирнэ. Бариул хурууны өргөнтэй зайг эргэн тойронд авна.
- Трасс, тавцан, тасалгааны шугам, хил, хоолойн зам, шинж шугам эсвэл газрын хэсэг зурж байх үед төлөвлөгөөн дээрх мөр {{ui:Дуусгах}} ({{key:Enter}}), {{ui:Цэг буцаах}} ({{key:Backspace}}) ба {{ui:Цуцлах}} ({{key:Esc}}) санал болгоно. Урт дарах (хагас секунд хөдөлгөөнгүй) бас дуусгана.
- {{ui:Сонгох}}-д хэмжилтийн цэг дээр урт дарвал {{key:Shift}}+дарах шиг сонголтод нэмнэ эсвэл хасна.
- 3D харагдацад нэг хуруу эргүүлнэ, хоёр хуруу нугалж шилжүүлнэ, дарах нь сонгоно.
- Мэдрэгч дээр заагч байхгүй тул статус мөрийн уншилт зөвхөн хуруу дарагдсан үед шинэчлэгдэнэ.
:::

## Хөтчийн давуу товчлуурууд

Зарим товч хөтчийнх бөгөөд CivilCraft-д хүрдэггүй, жишээ нь {{key:Mod+W}} (табыг хаах), {{key:Mod+T}} (шинэ таб), {{key:Mod+N}} (шинэ цонх) ба {{key:F11}} (Windows ба Linux хөтчүүд дээр бүтэн дэлгэц). CivilCraft эдгээрийг ашигладаггүй. Хэрэв товчлол хөтөчид нээгдэж байвал хуудас фокустай болохын тулд төлөвлөгөөг нэг удаа дараад, дахин оролдоно уу.

## Зөөх командын байршил

Төлөвлөгөөнд зөөх команд байхгүй: {{ui:Сонгох}}-ыг сонгоод цэг эсвэл оройг чирнэ, эсвэл {{ui:Шинж чанар}}-т координатыг нь засна. [Цэг засах](topic:edit-points)-ыг үзнэ үү.

CivilCraft компьютерээс файл нээж, файлыг буцаан татаж хадгалдаг. Юуг ч байршуулахгүй, серверт юу ч хадгалагдахгүй. Мөн харна уу: [Таны файлууд](common:your-files).

## Юуг нээдэг вэ

{{ui:Нээх}} ({{key:Mod+O}} дарж болно) товчийг дараад файл сонгох, эсвэл файлыг {{pick:mac=Finder|windows=Файл хөтлөгч|linux=таны файлын менежер}}-ээс планд чирнэ. Нэг удаад нэг файл; 200 MB-аас том файлыг татгалзана.

| Төрөл | Файлын нэр | Юу болох вэ |
|---|---|---|
| Цэгийн файл | `.csv`, `.txt`, `.pnt`, `.xyz` (ямар ч текст файл) | **Цэгүүдийг импортлох** харилцах цонх нээгдэнэ. Цэгүүд төслийн цэгүүдийг солино; трасс, тавцан, хоолойнууд хэвээр үлдэнэ. |
| LandXML | `.xml`, `.landxml` | Файлаас **шинэ төсөл** үүснэ (одоогийн төсөлд хадгалаагүй өөрчлөлт байвал эхлээд асууна). |
| CivilCraft төсөл | `.civilcraft.json` (ямар ч `.json`) | Төсөл хадгалсан байдлаараа нээгдэнэ (одоогийн төсөлд хадгалаагүй өөрчлөлт байвал эхлээд асууна). |

CivilCraft файлын төгсгөлөөр шийднэ, дараа нь эхний тэмдэгтүүдээр: `{`-ээр эхэлсэн текстийг төсөл, `<`-ээр эхэлсэнийг LandXML, бусдыг цэгийн файл гэж уншина. Нээх цонхонд харагдахгүй файлыг ч планд чирж оруулж болно.

:::note
Цэгтэй төсөлд цэгийн файлыг импортлоход асуухгүйгээр цэгүүдийг сольж, буцаах түүхийг цэвэрлэнэ (ямар ч файл нээх нь буцаах үйлдлийн шинэ эхлэл). Гадаргуу LandXML-ээс ирсэн бол цэг импортлох нь үүнийг цэгүүдээс бүтсэн гадаргуу руу буцаана. Хуучин цэгүүдээ буцаах магадлалтай бол эхлээд хадгална уу.
:::

Дэлгэрэнгүй: [Цэгийн файлын формат](topic:point-file-formats), [LandXML: юуг уншиж, бичдэг вэ](topic:landxml-reference).

## Юуг хадгалдаг вэ

{{ui:Хадгалах}} ({{key:Mod+S}}) хоёр файлыг зэрэгцүүлэн бичнэ. Файлын нэрийг зүүн самбарын **Нэр** талбараас авна: `<name>.civilcraft.json` нь засаж байгаа төсөл, `<name>.ifc` нь ижил загварыг бусдад зориулсан IFC 4.3 хэлбэрээр агуулна (см. [IFC экспорт ба импорт](topic:ifc)). Файл бүр нөгөөгөө дурдана. IFC нь төслийн шахсан хуулбарыг мөн агуулдаг тул ганцаараа илгээсэн IFC ч бүрэн засагдах боломжтойгоор нээгдэнэ.

- **Studio-д** хоёр файл зэрэгцэн, байрандаа бичигдэнэ.
- **Chrome ба Edge-д** анхны хадгалалт фолдер асууна ба хоёуланг нь тэнд бичнэ; дараагийн хадгалалтууд ижил фолдерт очно. Фолдерын асуултыг цуцалвал хоёуланг нь татна.
- **Бусад хөтөчид** хоёр файл татагдана, төслийн файл эхэлж.

Аль нэг файлыг нээхэд нөгөөг нь хайна. Хоёуланг нь хамт нээ (эсвэл хоёуланг нь чирнэ), эсвэл нэгийг нь нээ: Studio-д нөгөөг нь ижил фолдероос олно; хөтөчид CivilCraft түүнийг нэмэхийг асуух эсвэл одоо байгаа файлаараа үргэлжлүүлэхийг санал болгоно. Хэрэв CivilCraft хадгалсныхаа дараа IFC-г өөр программ өөрчилсөн, эсвэл нэг файл нөгөөгөөсөө хуучин бол төсөл шинэ загвараас нээгдэж, Асуудлын самбар юу болсныг хэлнэ; **Одоо хадгалах** (хоёуланг нь дахин бичнэ) болон **IFC-ийн геометрийг лавлах болгон харуулах** сонголттой. Өөр программ өөрчилсөн ганцаарчилсан IFC нь өөрийн төслийн хуулбараас нээгдэж, тохирч байгаа зүйлээр: өөрчилсөн трассууд өөрийн геометрийг авна, устгасан объектууд гарна, бусад өөрчлөлтүүд жагсаагдах боловч автоматаар авахгүй. 0.7.1-ээс өмнөх төслийн файл хуучнаараа нээгдэнэ.

Төслийн файл дараахыг хадгална:

- цэг бүрийг (дугаар, координат, өндөр, тайлбар) болон тэдгээр ирсэн цэгийн файлын нэрийг
- гадаргуугийн тохиргоо: бүлгийн сонголт, зурсан тасалгааны шугамууд, хил, гадна талын хамгийн урт ирмэг, LandXML-ээс уншсан TIN
- харагдацын тохиргоо
- трассууд PI, радиус, эхлэх станц, дизайн профайлууд (PVI ба муруйн урт) болон коридорын тохиргоо
- тавцанууд болон дүрмүүдтэй хоолойн сүлжээ

Буцаах түүхийг хадгалахгүй. Гадаргуу, горизонталь шугам, daylight шугам, эзлэхүүнийг хадгалахгүй; төсөл нээгдэхэд хадгалсан оролтоос дахин бүтээгдэнэ. Шинэ CivilCraft-ийн төслийн файлыг хувилбарын мэдээлэлтэйгээр татгалзана.

## Файлууд хаана очдог вэ

Хадгалсан болон экспортолсон файлууд хөтөчийн татаж авах байршилд очно, ихэвчлэн Downloads фолдерт. Файл бүрийг хаана хадгалахыг асуулгахын тулд:

:::chromium
Хөтөчийнхөө **Settings** руу орж, **Downloads** хэсгийг нээгээд **Ask where to save each file before downloading**-ийг асаа.
:::

:::firefox
**Settings** руу орж, **General**-ийг нээгээд **Files and Applications** доор **Always ask you where to save files**-ийг сонго.
:::

:::safari
**Safari > Settings > General** руу орж **File download location**-ийг **Ask for each download** болго.
:::

Хоёр удаа ижил нэрээр хадгалбал хөтөч хоёр дахь файлд дугаар нэмж болно, жишээ нь `Site (1).civilcraft.json`. Дараагийн удаа хамгийн шинэ файлыг нээ.

## Онлайн ба офлайн

CivilCraft аль ч тохиолдолд зөвхөн таны компьютер дээр ажиллана: нээхэд файлыг хөтөчид уншина, хадгалахад татна. Ямар ч холболтгүйгээр CivilCraft нээхийн тулд эхлээд офлайн хэрэглээнд хадгал:

1. Онлайн байхдаа дээд талын аппын мөр дэх {{ui:Офлайнд хадгалах}}-ыг дар.
2. Товч тоолно ("Saving 12 of 30") дараа нь {{ui:Офлайнд бэлэн}} гарна. CivilCraft жижиг (ойролцоогоор 0.6 MB) тул хэдэн секунд хүлээнэ. Хадгалсан хуулбарт энэ тусламж болон жишээ талбай орно.
3. Холболтгүй үед ижил хаягаар (эсвэл тэмдэглэгээгээр) нээ. Бүгд ажиллана, {{ui:Жишээ талбайг нээх}} ч мөн адил.

Товчны бусад төлөв:

- {{ui:Хадгалж чадсангүй}}: зарим файл татагдаагүй. Холболтоо шалгаад дахин дар.
- {{ui:Офлайн боломжгүй}}: энэ хөтчийн цонх офлайн хуулбар хадгалж чадахгүй (хувийн цонх, зарим удирдаж буй компьютер хориглодог). Энгийн цонх ашигла.

{{ui:Офлайнд бэлэн}} дарвал хуулбарыг хэзээ хадгалснаа харуулж, хоёр сонголттой: {{ui:Дахин хадгалах (хамгийн шинэ хувилбарыг авах)}} ба {{ui:Офлайн хуулбарыг устгах}}. Талбарт очихоосоо өмнө дахин хадгалаарай, ингэснээр хуулбар хамгийн сүүлийн хувилбартай таарна. Дэлгэрэнгүй: [Офлайн](common:offline).

:::offline
Та одоо офлайн байна. Хэрэв CivilCraft офлайн хэрэглээнд хадгалагдсан бол бүгд ажиллана, жишээ талбар ч орно. Үгүй бол энэ таб дээр ажилласаар байж болно, гэхдээ онлайн болтол дахин ачаалахгүй; хадгалсан хуулбаргүй бол {{ui:Жишээ талбайг нээх}} «Жишээг ачаалж чадсангүй» гэж алдаа өгнө.
:::

:::tip
Талбарт ажиллахдаа CivilCraft-ийг офлайн хэрэглээнд хадгалж, цэгийн файлуудаа лаптоп дээрээ авч яв. Төсөл, экспорт нь холболтгүйгээр татаж авах байдлаар хадгалагдана, тиймээс өдрийн хэмжилтийг импортолж, гадаргууг шалгаж, төслөө талбар дээрээс хадгалж болно.
:::

Үүлэн хадгалалт одоогоор байхгүй, desktop хувилбар хараахан гараагүй. Одоогоор таны хадгалсан файлууд л ганц хуулбар: тэдгээрийг нөөцөлдөг газар хадгал.

## Таны файл ашигладаг нэмэлтүүд

Нэмэлтийн (Барилгын журмын тэмдэглэгээ эсвэл Хаягаас талбай руу эх үүсвэр) өгөгдөлтэй төсөл хадгалахад файл ашигласан нэмэлтүүд болон тэдгээрийн хувилбарыг бүртгэнэ. Тэдгээр нэмэлтгүй компьютер дээр нээвэл планын дээрх мөр үүнийг хэлж, дансныхаа жагсаалтаас нэмэхийг санал болгоно. Бүртгэл зөвхөн тэмдэглэл: файл ямар ч байсан нээгдэнэ.

## Studio-оос буцаах

CadCraft Studio дотор CivilCraft-д дуусгасан алхам бүр Studio-д мэдэгдэх тул түүний төслийн түвшний буцаах үйлдэл программуудын хооронд сүүлийн алхамыг буцаана. Studio зөвхөн CivilCraft-ийн өөрийн буцаах стек тухайн алхам үлдээсэнтэй яг адил байвал л алхмыг буцаана; өөр файл нээсний дараа энэ цонхыг алгасна.

## Хадгалаагүй өөрчлөлттэй хаах

Төсөлд хадгалаагүй өөрчлөлт байхад таб хаахад, дахин ачаалахад эсвэл хуудаснаас гарахад хөтөч гарах эсэхийг асууна. Асуултын үг ба харагдац нь хөтчийнх бөгөөд CivilCraft үүнийг өөрчилж чадахгүй. {{ui:Шинэ}}, мөн төсөл эсвэл LandXML файл нээхэд CivilCraft-ийн өөрийн **Хадгалаагүй өөрчлөлтүүд** харилцах цонхоор асууна, сонголтууд: {{ui:Цуцлах}}, {{ui:Хадгалахгүй}} ба {{ui:Хуулбарыг хадгалах}}.

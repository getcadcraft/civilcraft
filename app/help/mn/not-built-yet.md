CivilCraft эрт үе шатандаа байна. Энэ хуудас одоогийн хувилбар юу хийдэггүйг жагсаана, ингэснээр та үүнийг хайж бүү цаг үрээрэй. Энд жагсаасан зүйлсийн аль нь ч огноо амлагдаагүй.

## Цэгүүд

| Одоогоор хийгдээгүй | Одоо оронд нь |
|---|---|
| Хоёр дахь цэгийн файлыг эхнийхэд нэгтгэх | Файлуудыг эхлээд текст редактор эсвэл хүснэгтэд нэгтгэнэ |
| Цэгийн текст файлыг экспортлох | LandXML-ээр экспортлох (цэгүүд CgPoints хэлбэрээр гарна), эсвэл GIS {{ui:Экспорт}} ашиглах (P, N, E, Z, D талбартай цэгүүд), эсвэл цэгүүдийг {{ui:Хуулах}} хийгээд хүснэгтэд оруулах |
| Цэгийн шошгын хэв маяг, тайлбарын түлхүүр бүрт тэмдэг, шугамын кодоос муруй (нум), төслүүдийн хооронд хуваалцах тайлбарын түлхүүрийн файл | Шошгууд нь дугаар, өндөр, тайлбарыг харуулна, эсвэл үүнээс бага ([CivilCraft тохиргоо](topic:settings)); түлхүүрүүд төслийн файлд хадгалагдана |
| Нэгж хөрвүүлэлт | Импортлохоосоо өмнө файлаа хөрвүүлнэ; **Нэгжүүд** зөвхөн шошгыг солино |

## Гадаргуу

| Одоогоор хийгдээгүй | Одоо оронд нь |
|---|---|
| Цэгүүдээс бүтээсэн нэгээс илүү гадаргуу | Төсөл тус бүрт нэг гадаргуу |
| Дотоод хилийн шугамыг нуух | **Хамгийн урт гадна ирмэг** эсвэл гадна хилийн шугамыг ашиглах |
| Зурсан нэг газрын тасалгч шугамыг сонгох эсвэл засах | {{key:Mod+Z}}, эсвэл {{ui:Зурсан тасалгч шугамуудыг устгах}} хийгээд дахин зурах |
| LandXML-ээс уншсан гадаргуу (тасалгч шугамууд, хил) засах | {{ui:Цэгүүдээс гадаргууг дахин бүтээх}} |
| Газрын торон хэмжээнээс бүтээсэн гадаргууг засах | Торыг өөр сонголттойгоор дахин импортлох |
| Координатын систем өөрчлөгдөхөд LandXML-ээс уншсан гадаргууг хөрвүүлэх | Эхлээд {{ui:Цэгүүдээс гадаргууг дахин бүтээх}} |
| Шошготой цэгийн өндрүүд ба налууны утгууд | Статус мөрөөс уншина уу, эсвэл Ландшафтын ажлын орчны [Ландшафтын тэгшлэлт](topic:landscape-grading#grading-checks)-д **Налууны шинжилгээ**-гээр гадаргууг налуугаар будна |

| Объектууд, офсет, өргөтгөлөөс трасс үүсгэх | PI-аар зурах |
| Босоо муруйд K бичих | L бичнэ (K харагдана) |
| Дугуй ба тэгш бус босоо муруй | Зөвхөн тэгш параболын босоо муруй |
| Трасс бүрт нэгээс илүү загварын профиль | Вариант бүрт нэг трасс |
| Профилийн харагдацыг томруулах, профиль доорх профилийн зурвас | Профилийн харагдац бүх трассыг багтаана; [Төлөвлөгөө ба профилийн хуудсууд](topic:plan-profile-sheets) дээр хэвлэнэ |
| DWG эсвэл LandXML дээрх зүсэлтүүд | PDF хэлбэрийн зүсэлтийн хуудсууд; талбай ба эзэлхүүний {{ui:CSV}} |
| Налуу өнцөгтэй жишиг шугамууд, эсвэл замын дагуу өөр өргөнтэй шугамууд | Трассын бүх уртын туршид нэг өргөн, тал тус бүрт |

| Налуу хэсгийн зорилтууд (шугам эсвэл гадаргуу руу тэгш налуу), коридорын өөрийн гадаргуу | Зорилтууд хучилт ба хөвөөний ирмэгийг зөөнө ([Коридорууд](topic:corridor)); коридор шинэ гадаргуу руу тэгшлэгдэнэ |
| Уулзвар дээр булангийн бордюрын муруй, эргэх эгнээ ба арлууд тэгшлэгдсэн; дэд замын төгсгөлийг хоёр зам байгаа налуутай үндсэн замын ирмэг хүртэл тайрах; замыг план дээр уулзвартай холбох, урт ба талбайд | Таарсан замууд перпендикуляраар холбогдож, үндсэн замын ирмэг нээгдэж, дэд зам түүн рүү тэгшлэгдэнэ ([Зам зам дээр тулах](topic:corridor#where-roads-meet-roads-pads-and-paths)); замнал шинэ гадаргууд ба 3D-д замын ирмэгт зогсоно |
| LandXML-д коридорыг зам болгон экспортлох; IFC экспортод трассын хоёр дахь коридор | Шинэ гадаргуу экспортлогдоно |
| Шинэ гадаргууг өөрчилдөг газрын загварууд, 3D эсвэл зүсэлтэд | Тэд давхарга тус бүрийн талбай ба эзэлхүүнийг өгнө ([Газрын загварууд](topic:corridor-templates#terrain-templates)) |
| Хурдтай, дугуйны шүргэлттэй, жолоодлогын хугацаатай, чирэгдэх тэвштэй, биеийн зайтай хөдөлгөөний зам; стандарт дизайны машины сан; машиныг чирж зурсан хөдөлгөөний зам | Өндөр шугам эсвэл трассын дагуу бага хурдны хөдөлгөөний зам, өөрийн машины хэмжээгээр ([Машины хөдөлгөөний зам](topic:swept-paths)) |

## GIS ба координатын систем

| Одоогоор хийгдээгүй | Одоо оронд нь |
|---|---|
| Файлын геодатабаз; KML хэв маяг, дүрс, газрын давхарга ба сүлжээний холбоос | Эхлээд GeoPackage, shapefile эсвэл GeoJSON руу хөрвүүлнэ; KML тэмдгүүдийг хэв маяггүйгээр уншина |
| GIS объект эсвэл түүний шинж чанарыг засах | GIS программд засаад дахин импортлоно. Шинжилгээний самбар шинэ давхарга (буфер, давхцал, холбоо, сонголт) үүсгэж, талбай ба уртын талбар нэмнэ, гэхдээ объектыг байрандаа засдаггүй |
| Сүлжээ ба растерын шинжилгээ; тэгш эсвэл дөрвөлжин үзүүртэй буфер ба нэг талын буфер; шинж чанарын хүснэгтэд мөр нэмэх эсвэл устгах, талбарын төрлийг өөрчлөх; гараар ангиллын өнгө; графикт хэв маягийн тайлбар | Сонголтоор объект сонгоод, тэдгээрээс давхарга үүсгэнэ; тэгш үзүүрийг санал болгодоггүй. Шинж чанараар будах ба шинж чанарын хүснэгт бэлэн: см. [Давхаргыг шинж чанараар загварчлах](topic:gis-symbology) ба [Давхаргын шинж чанарын хүснэгттэй ажиллах](topic:gis-table) |
| Шошгын хэв маяг (хэмжээ, байрлал) ба бие биенээсээ зайлсхийх шошгууд | Шошгууд нэг хэмжээтэй, объект нягт байвал давхцаж болно |
| Босоо датум ба геоид загварууд | Өндрийг файл өгсөн байдлаар ашиглана; босоо датумыг өөрөө шалгана |
| NAD27-ээс NAD83 руу бусад торон шилжилт, талбайгаар санал болгосон OSTN15, NTv2 (өөр датумд файл нэмэхэд ажиллана), хэд хэдэн торон нэг дор, босоо торон | Датумдаа торон файлыг өөрөө нэмнэ; төсөлд нэг торон |

| Нэвтрэлт шаардах газрын зургийн сервер, түлхүүр эсвэл токен | Нийтийн үйлчилгээ, эсвэл газарзүйн зөв байрлалтай зургийн файл ашиглана |
| Гадаргуугаас LAS эсвэл LAZ файл бичих, газрын загвар, өндрийн тор ба LiDAR хэрэгслүүд | Гадаргуугийн өндрийн торыг GeoTIFF болгон экспортлоно. [Цэгийн үүл](topic:point-clouds) нэмэлт нь цэвэрлэсэн үүлийг LAS 1.4 эсвэл LAZ хэлбэрээр бичнэ |
| LiDAR-ын эрчим, өнгө ба буцах дохио; олон сувагтай өндрийн тор; 200 MB-аас том тор эсвэл LiDAR файл | LiDAR зөвхөн ангиллаар шүүгдэнэ, тор нь эхний сувгийг ашиглана; том файлуудыг эхлээд хэсгүүдэд хуваана |

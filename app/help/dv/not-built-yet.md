CivilCraft އަކީ ފަށައިގެން ހުރި ޕްރޮޖެކްޓެކެވެ. މި ޞަފްހާގައި މިހާރުގެ ބިލްޑް ނުކުރާ ކަންތައްތައް ލިސްޓް ކުރެވިފައިވެއެވެ، ތިބާ އެ ކަންތައްތަކަށް ނުބަލާށެވެ. މިތަނުގައި އެއްވެސް ކަމެއް ތާރީޚެއްގައި ވައުދު ނުދެއެވެ.

## ޕޮއިންޓްތައް

| ހަދާ ނުފައިވާ | މިހާރު ކުރެވޭ ގޮތް |
|---|---|
| ޕޮއިންޓް ފައިލެއް އަނެއް ފައިލަކާ އެކު ޖޮއިން ކުރުން | ފުރަތަމަ ފައިލްތައް ޓެކްސްޓް އެޑިޓަރ ނުވަތަ ސްޕްރެޑްޝީޓުގައި ޖޯޑު ކުރޭ |
| ޕޮއިންޓް ޓެކްސްޓް ފައިލް އެކްސްޕޯޓް ކުރުން | LandXML އެކްސްޕޯޓް ކުރޭ (ޕޮއިންޓްތައް CgPoints އެ ގޮތުން ދެވޭ)، ނުވަތަ GIS {{ui:Export}} ބޭނުން ކުރޭ (P, N, E, Z އަދި D ފީލްޑުތަކާއެކު ޕޮއިންޓްތައް)، ނުވަތަ ޕޮއިންޓްތައް ސްޕްރެޑްޝީޓަށް {{ui:Copy}} ކުރޭ |
| ޕޮއިންޓް ލޭބަލް ސްޓައިލްތައް، ކޮންމެ ޑިސްކްރިޕްޝަން ކީއަކަށް ސިމްބަލްތައް، ލައިންކޯޑުން އާކް ކަރވް ހެދުން، ޕްރޮޖެކްޓްތަކުގެ ދެމެދު ޝެއާ ކުރެވޭ ޑިސްކްރިޕްޝަން ކީ ފައިލް | ލޭބަލްތަކުގައި ނަންބަރު، އުސްމިން އަދި ޑިސްކްރިޕްޝަން ފެންނާނެ، ނުވަތަ އެއާ ކުޑަ ގޮތަކަށް ([CivilCraft settings](topic:settings))؛ ކީތައް ޕްރޮޖެކްޓް ފައިލުގައި ރައްކާ ވެއެވެ |
| ޔުނިޓް ބަދަލު ކުރުން | އިމްޕޯޓް ކުރުމުގެ ކުރިން ފައިލް ބަދަލު ކުރޭ؛ **Units** ހަމައެކަނި ލޭބަލް ބަދަލު ކުރޭ |

## ސަރފޭސްތައް

| ހަދާ ނުފައިވާ | މިހާރު ކުރެވޭ ގޮތް |
|---|---|
| ޕޮއިންޓްތަކުން ހަދާ ސަރފޭސް އެއްވުރެ ގިނަ ހުރުން | ސަރފޭހެއް އެއް ޕްރޮޖެކްޓަކަށް |
| (ތެރޭގެ) ބައުންޑަރީތައް ފޮރުން | **Longest outside edge** ނުވަތަ ބޭރު ބައުންޑަރީއެއް ބޭނުން ކުރޭ |
| ޑްރޯ ކުރެވުނު ބްރޭކްލައިނެއް ޚިޔާރުކުރުން ނުވަތަ އެޑިޓް ކުރުން | {{key:Mod+Z}}، ނުވަތަ {{ui:Remove drawn breaklines}} ކޮށް އަލުން ޑްރޯ ކުރޭ |
| LandXML ން ކިޔުނު ސަރފޭހެއް އެޑިޓް ކުރުން (ބްރޭކްލައިންތައް، ބައުންޑަރީ) | {{ui:Rebuild the surface from the points}} |
| އެލިވޭޝަން ގްރިޑުން ހަދާ ސަރފޭހެއް އެޑިޓް ކުރުން | ގްރިޑް އަލުން އިމްޕޯޓް ކުރޭ އެހެން ޗޮއިސްތަކާއެކު |
| ކޯޑިނޭޓް ސިސްޓަމް ބަދަލުވުމުން LandXML ން ކިޔުނު ސަރފޭހެއް ކަންވާރު ކުރުން | ފުރަތަމަ {{ui:Rebuild the surface from the points}} |
| ލޭބަލް ކުރެވުނު ސްޕޮޓް އެލިވޭޝަންތަކާއި ސްލޯޕް ވެލިއުތައް | ސްޓޭޓަސް ބާރުގައި ކިޔާ، ނުވަތަ Landscape ވޯކްސްޕޭސްގައި **Slope analysis** އިން ސަރފޭހަށް ސްލޯޕް އިން ރަން ކުރޭ ([Grading for landscape](topic:landscape-grading#grading-checks)) |

## އެލައިންމަންޓްތަކާއި ޕްރޮފައިލްތައް

| ހަދާ ނުފައިވާ | މިހާރު ކުރެވޭ ގޮތް |
|---|---|
| clothoid ނޫން ސްޕައިރަލްތައް؛ ދެ ކާވަކާ ދެމެދު ސްޕައިރަލް (ކޮމްޕައުންޑް ޓްރާންޒިޝަން) | ކާވެއްގެ ކޮޅުތަކުގައި clothoid ސްޕައިރަލްތައް ލިބެއެވެ؛ އެހެންތައް ނަން ކޮށް LandXML އިމްޕޯޓުން ފަހަށް ދެވޭ |
| ދެ އެހެން PI ތަކާ ދެމެދު PI އެއް ޖަހުން | އެލައިންމަންޓް އަލުން ޑްރޯ ކުރޭ، ނުވަތަ PI ކޯޑިނޭޓްތައް އަލުން ޓައިޕް ކުރޭ |
| އޮބްޖެކްޓްތަކުން އެލައިންމަންޓް ހެދުން، އޮފްސެޓްތަކާއި ފަރާތް ފުޅާ ކުރުން | PI ތަކުން ޑްރޯ ކުރޭ |
| ވާޓިކަލް ކާވަށް K ޓައިޕް ކުރުން | L ޓައިޕް ކުރޭ (K ފެންނާނެ) |
| ސަރކިއުލަރ އަދި ނޭގެ ސިމެޓްރިކަލް ނޫން ވާޓިކަލް ކާވްތައް | ސިމެޓްރިކަލް ޕެރާބޮލިކް ވާޓިކަލް ކާވްތަކެއް ބޭނުން ކުރޭ |
| އެއް އެލައިންމަންޓަކަށް ޑިޒައިން ޕްރޮފައިލް އެއްވުރެ ގިނަ ހުރުން | ކޮންމެ ވޭރިއަންޓަކަށް އެއް އެލައިންމަންޓް |
| ޕްރޮފައިލް ވިއު ޒޫމް ކުރުން، ޕްރޮފައިލްގެ ދަށުގައި ޕްރޮފައިލް ބޭންޑްތައް | ޕްރޮފައިލް ވިއު މުޅި އެލައިންމަންޓް ފިޓް ކުރޭ؛ ޕްލޮޓް ކުރޭ [plan and profile sheets](topic:plan-profile-sheets) ގައި |
| DWG ނުވަތަ LandXML ގައި ސެކްޝަންތައް | ސެކްޝަން ޝީޓްތައް PDF ގެ ގޮތުން؛ ހުރިހާ ހިސާބުގެ CSV އަށް {{ui:CSV}} |
| ރޯޑުގެ ދިގުމިނުގައި ސަމްޕަލް ލައިންތައް އެންގަލްގައި، ނުވަތަ ފުޅާމިން ތަފާތު ވުން | އެލައިންމަންޓްގެ ފަރާތް ކޮންމެ ފަރާތަކަށް ފުޅާމިން އެއް |

## ކޮރިޑޯތައް

| ހަދާ ނުފައިވާ | މިހާރު ކުރެވޭ ގޮތް |
|---|---|
| މެޑިއަންތައް، ބެރިއަރތައް، އަދި ޓެމްޕްލޭޓްތަކާއި ޓެމްޕްލޭޓް ފެރާ ކުރާ ސުޕަރ އެލެވޭޝަން | ޓެމްޕްލޭޓްތަކަކަށް ޑްރޯ ކުރޭ ([Corridor templates](topic:corridor-templates))؛ ސްޓޭޝަން މައްޗަށް ޓެމްޕްލޭޓްތަކުން އަދި ސުޕަރ އެލެވޭޝަން ނުނަގާ |
| ދެ ރީޖަން ޓެމްޕްލޭޓްތަކާ ދެމެދު ފުޅު ބަދަލު (ޓްރާންޒިޝަން، ޓޭޕަރ) | ސްޓޭޝަނުގައި ޓެމްޕްލޭޓް ބަދަލު ކުރޭ، ނުވަތަ ޓޭޕަރ ގޮތުގައި ޑްރޯ ކުރާ ލައިނަށް ޕޮއިންޓަކަށް ފުޅާމިން ޓާގެޓް ދޭ |
| ކަނާރާ ރޮޓޭޝަން، LandXML ގައި ސުޕަރ އެލެވޭޝަން | ސަރކިއުލަރ ކާވްތަކުގައި ސުޕަރ އެލެވޭޝަން ސެންޓަރލައިން ފަރާތުން ރޮޓޭޓް ކުރޭ؛ ފުޅާ ކުރާ ފީޗަރ ލައިނަކަށް ފުޅާމިން ޓާގެޓް ދީ ލޭން ފުޅާ ކުރޭ |
| ސައިޑް ސްލޯޕްތަކަށް ޓާގެޓްތައް (ލައިނަށް ނުވަތަ ސަރފޭހަށް ޑޭލައިޓް)، ކޮރިޑޯ އަމިއްލަ ސަރފޭހު | ޓާގެޓްތައް ފަރުމާ އަދި ޝޯލްޑަރ ކިނާރުތައް ހިއްލާ ކުރޭ ([Corridors](topic:corridor))؛ ކޮރިޑޯ ޑިޒައިން ސަރފޭހަށް ގްރޭޑް ކުރެވެއެވެ |
| LandXML ގައި ކޮރިޑޯ ރޯޑްވޭސް ގެ ގޮތުން އެކްސްޕޯޓް، ނުވަތަ IFC އެކްސްޕޯޓުގައި އެލައިންމަންޓެއްގެ ދެވަނަ ކޮރިޑޯ | ޑިޒައިން ސަރފޭހު އެކްސްޕޯޓް ކުރޭ |
| ޑިޒައިން ސަރފޭހު ބަދަލު ކުރާ ޓެރެއިން ޓެމްޕްލޭޓްތައް، 3D ގައި ނުވަތަ ސެކްޝަންތަކުގައި | ކޮންމެ ލޭޔަރެއްގެ ފުޅާމިންނާއި ވޮލިއުމް ދެއެވެ ([Terrain templates](topic:corridor-templates#terrain-templates)) |

## ގްރޭޑިންގާއި ވޮލިއުމްތައް

| ޑްރޯ ކުރެވުނު ބްރޭކްލައިންތަކުގެ އާކްސް (ސަރވޭ ޕޮއިންޓްތަކުން)، ފީޗަރ ލައިންތަކުގެ ސްޕައިރަލްތައް | އާކްސް ހުރި ފީޗަރ ލައިނެއް ޑްރޯ ކޮށް، ބިމުގެ ބްރޭކްލައިނެއްގެ ގޮތުން ބޭނުން ކުރޭ |
| ދުރަށް، އުސްމިނަށް ނުވަތަ އެހެން ސަރފޭހަކަށް ގްރޭޑިންގ | މައުޖޫދު ބިމަށް ޑޭލައިޓް ކުރޭ |
| ޕެޑް ކޯނަރ ބޮޑުކުރުން ނުވަތަ ފޮހެލުން | ޕެޑް ފޮހެލާ އަދި އަލުން ޑްރޯ ކުރޭ |

| ފްރީ ހޯލް އަދި އޯވަރ ހޯލް ޚަރަދު، އެހެން އެލައިންމަންޓްތަކާ ދެމެދު ހޯލް، ޕްލޭނުގައި ކެނޑުނު ބޯރޮ ސައިޓްތާ ކުނި ސައިޓްތައް | ބެލެންސް ޕޮއިންޓްތަކާއެކު މާސް ހޯލް ޑަޔަގްރާމް، ގެންދޭ ވޮލިއުމްތަކާއި ސަރެހެއްޓަ ހޯލް ދުރު |

## ޕައިޕް ނެޓްވޯކްތައް

| ހަދާ ނުފައިވާ | މިހާރު ކުރެވޭ ގޮތް |
|---|---|
| ޕްރޮޖެކްޓަކަށް ނެޓްވޯކް އެއްވުރެ ގިނަ ހުރުން | ސްޓޯމާއި ސެނިޓަރީ އަށް ވަކި ޕްރޮޖެކްޓް |
| ވޮޓަރ މެއިންސް: ވޮޓަރ ކުޅޭ އަދި ހަދާ ސައިޒް، ރޫލް ބޭސްޑް ކޮންޓްރޯލްތައް، އެހެން ވާލްވް ވާތަކެތި (ފްލޯ ކޮންޓްރޯލް، ތްރޮޓަލް، ސަސްޓެއިނިންގ)، ޕަމްޕްތައް ޕާވަރުން، ޕްރެޝަރުން ބޭރުގައި ޑިމާންޑް، Darcy–Weisbach އޮޕްޝަން، ޕައިޕް ކެޓަލޮގް ފުޅުތަކާއި ޕްރެޝަރ ކްލާސްތައް. ބާކީ ޕްރެޝަރ ނެޓްވޯކްތައް ލެބް ގައި: [Water mains](topic:water-mains) | ވޮޓަރ ޑިސްޓްރިބިއުޝަން ސޮފްޓްވެއާ ފަހަށް ބަލާ؛ ސެނިޓަރީ ޑިޒައިން ފްލޯތައް [Sanitary design flows](topic:sanitary-design) ގައި |
| ވަގުތާއެކު ފްލޯތައް (ހައިޑްރޯގްރާފް، ޑައިނަމިކް ރޫޓިންގ، ސްޓޯރޭޖް، ޕަމްޕްސް، އޯވަރ ފްލޯ) | [Sanitary design flows](topic:sanitary-design) ގައި ޑިޒައިން ޝީޓް ބޭނުން ކުރާ ސްޓެޑީ ޕީކް ފްލޯ |
| އިންލެޓް ކެޕެސިޓީ، ގަޓަރ ސްޕްރެޑް، ޑިޓެންޝަން ރޫޓިންގ، ހައިޑްރޯގްރާފްސް، އެއް ޖަންކްޝަން ކޯފިޝިއެންޓަށް ހިލާ އެނާޖީ ލޮސް | އެތަންތަން އެހެން ސޮފްޓްވެއާން ބަލާ؛ ފްލޯ، ސައިޒް އަދި ގްރޭޑް ލައިން [Storm drainage](topic:storm-drainage) ގައި |
| PDF ޕްލޮޓް، DWG، DXF ނުވަތަ LandXML ގައި ކެޗްމަންޓްތައް؛ ސަރފޭހުން ކެޗްމަންޓްތައް (ވޮޓަރ ޝެޑްސް) | ކެޗްމަންޓްތައް އަތުން ޑްރޯ ކުރޭ؛ ޕްރޮޖެކްޓް ފައިލުގައި ރައްކާ ވެއެވެ |
| ޕައިޕް ކެޓަލޮގްތައް، ގުނޑު ނޫން ޕައިޕްތައް، ކޯނު، ސްޓެޕްސް، ބެންޗިން ފަދަ ބޮކްސް ނޫން ސްޓްރަކްޗަރތައް، ލައިބްރަރީގައި ޑްރެއިނޭޖް ކެޓަގަރީ | ޕެރާމީޓަރުންނާ ހަދާ ސްޓްރަކްޗަރ ޓައިޕްތައް ([Pipe network](topic:pipe-network))؛ ޑަޔާމީޓަރ ހުރި ޕައިޕްތައް |
| ޕްރޮފައިލް ވިއުގައި ޕައިޕްތައް، ވަށު ޕައިޕްތައް | ޓޮޕް އަދި ކަވަރ ރައިޓް ޕެނަލުން ކިޔާ |

## ބިމުގެ ފަރާތް (Landscape)

|---|---|
| މެނިފެކްޗަރަރުންގެ ހެޑްސް އަދި ނޯޒަލްސް | ޖެނެރިކް ހެޑްސް، ނުވަތަ ފައިލަކުން އަމިއްލަ ހެޑްސް އިތުރު ކުރޭ؛ މޭކަރުންގެ ޑޭޓާ އެމީހުން ހުއްދަ ދޭ ވަގުތު ލިބޭ |

## GIS އަދި ކޯޑިނޭޓް ސިސްޓަމްތައް

| ހަދާ ނުފައިވާ | މިހާރު ކުރެވޭ ގޮތް |
|---|---|
| File Geodatabase؛ KML ސްޓައިލްތައް، އައިކަންތައް، ގްރައުންޑް އޯވަލޭތައް އަދި ނެޓްވޯކް ލިންކްތައް | GeoPackage، ޝޭޕްފައިލް، ނުވަތަ GeoJSON އަށް ކަންވާރު ކުރޭ؛ KML ޕްލޭސްމާކްތަކަށް ސްޓައިލް ނެތި ކިޔެވެއެވެ |
| GIS ފީޗަރތައް ނުވަތަ އެގެ އެޓްރިބިއުޓުތައް އެޑިޓް ކުރުން | GIS ޕްރޮގްރާމްގައި އެޑިޓް ކޮށް އަލުން އިމްޕޯޓް ކުރޭ. Analyze ޕެނަލުން އައު ލޭޔަރތައް (buffer، overlay، join، selection) ހަދައި، ފީލްޑް ބަލަކުން ފަރާތާއި ދިގުމިން އިތުރު ކުރޭ، ނަމަވެސް ފީޗަރއެއް އޭގައި އެޑިޓް ނުކުރޭ |
| ނެޓްވޯކް އަދި ރާސްޓަރ އެނާލިސިސް، ފްލެޓް ނުވަތަ ސްކެއަރ އެންޑް ބަފަރތައް، އެއް ފަރާތުގެ ބަފަރ، އެޓްރިބިއުޓް ޓޭބަލްގައި ރޯތައް ހަދުން ނުވަތަ ފީލްޑް ޓައިޕް ބަދަލު ކުރުން، އަތުން ކްލާސް ކުލަރ، ޕްލޮޓުގައި ސްޓައިލް ލެޖެންޑް | Select ބޭނުން ކޮށް ފީޗަރ ނެގުން އަދި އެންމެ ލޭޔަރެއް ހަދާ؛ ފްލެޓް ޝޭޕްތައް ނުދެވޭ. އެޓްރިބިއުޓުން ކުލަރ ދިނުމާއި އެޓްރިބިއުޓް ޓޭބަލް ހުރެއެވެ: [Style a layer by an attribute](topic:gis-symbology) އަދި [Work with a layer's attribute table](topic:gis-table) |
| ލޭބަލްގެ ސައިޒް އަދި ޕްލޭސްމަންޓް ސްޓައިލްތައް، އެކަކުގެ މަތީން އެކަކު ފޮރުގަނޑު ނުވާ ލޭބަލްތައް | ލޭބަލްތައް އެއް ސައިޒު، ފީޗަރތައް ގިނަ ނަމަ އޭގެ މަތީން ވައިޕު ވެދާނެ |
| ވާޓިކަލް ޑެޓަމްތަކާއި ޖިއޯއިޑް މޮޑެލްތައް | އުސްތައް ފައިލް ދޭ ގޮތުން ބޭނުން ކުރެވޭ؛ ވާޓިކަލް ޑެޓަމް ތިބާ ބަލާ |

| DXF ނުވަތަ 3D އެކްސްޕޯޓްތަކުގައި މެޕް ލޭޔަރތައް | މެޕް ލޭޔަރތައް PDF ޕްލޮޓަށް ދާ، DWG ގެ ކައިރީގައި ފޮޓޯއެއްގެ ގޮތުން |
| ސައިން އިން ލާޒިމް ވާ މެޕް ސާވިސްތައް | ފަހިގަނޑު ނޫން ސާވިސްތައް ބޭނުން ކުރޭ، ނުވަތަ ޖިއޯރެފަރެންސްކުރެވުނު އިމޭޖް ފައިލެއް |
| ސަރފޭހުން LAS ނުވަތަ LAZ ފައިލް ލިޔުން، ބިމުގެ މޮޑެލް، އެލިވޭޝަން ގްރިޑް ނުވަތަ LiDAR ޓޫލްތައް | ސަރފޭސްތައް GeoTIFF އެލިވޭޝަން ގްރިޑް ގެ ގޮތުން އެކްސްޕޯޓް ކުރޭ. [Point clouds](topic:point-clouds) އެޑް-އޮން ސާފު ކުރެވުނު ކްލައުޑް LAS 1.4 ނުވަތަ LAZ ލިޔެއެވެ |
| LiDAR އިންޓެންސިޓީ، ކުލަރ އަދި ރިޓާންސް؛ ބޭންޑް ގިނަ އެލިވޭޝަން ގްރިޑްތައް؛ 200 MB އަށްވުރެ ބޮޑު ގްރިޑް ނުވަތަ LiDAR ފައިލްތައް | LiDAR ކްލާސް އިން ފިލްޓަރ ކުރެވެއެވެ، ގްރިޑްތައް އެއްވަނަ ބޭންޑް ބޭނުން ކުރެވޭ؛ ބޮޑު ފައިލްތައް ފުރަތަމަ ޓައިލްތަކަށް ކަނޑާ |

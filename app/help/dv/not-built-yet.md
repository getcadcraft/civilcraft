CivilCraft އަދި ފެށުނު ފަދައިން. މި ޞަފްހާގައި މި ބިލްޑް ނުކުރާ ކަންތައް ލިސްޓުކުރެވިފައި ވޭ، ދެން ލޯބިވެވޭ ނުރައްކާ ކަންތައް ނުފެނޭ. މިތަނުގައި އެއްވެސް ކަމަކަށް ތާރީޚެއް ނުވަނީ.

## ޕޮއިންޓްތައް

| އަދި ހަދާފައި ނެތް | މިހާރު އޮތް ގޮތް |
|---|---|
| ފުރަތަމަ ފައިލަށް ދެވަނަ ޕޮއިންޓް ފައިލް އިތުރުކުރުން | ފައިލްތައް ޓެކްސްޓް އެޑިޓަރ ނުވަތަ ސްޕްރެޑްޝީޓަށް ކުރިން ގުނޭ |
| ޕޮއިންޓް ޓެކްސްޓް ފައިލް ނެރުން | LandXML އެކްސްޕޯޓްކުރޭ (ޕޮއިންޓްތައް CgPoints ގެ ގޮތުގައި ދެވޭ), GIS {{ui:Export}} ބޭނުން ކުރޭ (P, N, E, Z އަދި D ފީލްޑްތަކާއެކު ޕޮއިންޓްތައް), ނުވަތަ ޕޮއިންޓްތައް ސްޕްރެޑްޝީޓަށް {{ui:Copy}} ކުރޭ |
| ޕޮއިންޓް ލޭބަލް ސްޓައިލް، ޑިސްކްރިޕްޝަން ކީ އަށް ސިމްބޯލްތައް، ލައިން ކޯޑުންތަކުން ކަރވް (އާކް) ތައް، ޕްރޮޖެކްޓް ތެރެއިން ޝެއާކުރާ ޑިސްކްރިޕްޝަން ކީ ފައިލް | ލޭބަލްތައް ނަންބަރު، އުސްމިންނާއި ޑިސްކްރިޕްޝަން ފެންނޭ، ނުވަތަ އަދި އެންމެ ކުޑަ ([CivilCraft settings](topic:settings)); ކީތައް ޕްރޮޖެކްޓް ފައިލުގައި ރައްކާ ވޭ |
| ޔުނިޓް ކަންވާރޝަން | ކުރިން ފައިލް ކަންވާރޓް ކުރޭ؛ **Units** ހަމަ ލޭބަލް ބަދަލުކުރޭ |

## މެދުތަކުން

| އަދި ހަދާފައި ނެތް | މިހާރު އޮތް ގޮތް |
|---|---|
| ޕޮއިންޓްތައް ހަދާ ސަފޯސް ގިނަ ފަހަރުން | ސަފޯސް ކޮންމެ އެކަ ޕްރޮޖެކްޓް |
| (އެތެރެ) ސަރުހައްދު ހުޅުވާ ނުވާނެ | **Longest outside edge** ނުވަތަ ބޭރު ސަރުހައްދެއް ބޭނުން ކުރޭ |
| އެއް ޑްރޯކުރެވުނު ބްރޭކްލައިނެއް ޚިޔާރުކުރުން ނުވަތަ އެޑިޓްކުރުން | {{key:Mod+Z}}، ނުވަތަ {{ui:Remove drawn breaklines}} ކުރޭ އަދި އާ ޑްރޯކުރޭ |
| LandXML އިން ކިޔާ ސަފޯސް އެޑިޓްކުރުން (ބްރޭކްލައިންތައް، ސަރުހައްދު) | {{ui:Rebuild the surface from the points}} |
| އެލިވޭޝަން ގްރިޑުން ހަދާ ސަފޯސް އެޑިޓްކުރުން | ގްރިޑު އަލުން އިމްޕޯޓްކުރޭ އެހެން ޗޮއިސްތަކާއެކު |
| ކޯޑިނޭޓް ސިސްޓަމް ބަދަލުވާއިރު LandXML އިން ކިޔާ ސަފޯސް ކަންވާރޓް ކުރުން | ކުރިން {{ui:Rebuild the surface from the points}} |
| ލޭބަލް ކުރެވޭ ސްޕޮޓް އެލެވޭޝަންތައް އަދި ސްލޯޕް އަގުތައް | ސްޓޭޓަސް ބާރުން ކިޔާ، ނުވަތަ **ސްލޯޕް އެނަލިސިސް** ލޭންޑްސްކޭޕް ވޯކްސްޕޭސްގައި ސަފޯސް ރަތް ހެދޭ ([ލޭންޑްސްކޭޕް ގްރޭޑިންގ](topic:landscape-grading#grading-checks)) |

## އެލައިންމަންޓްތަކާއި ޕްރޮފައިލްތައް

| އަދި ހަދާފައި ނެތް | މިހާރު އޮތް ގޮތް |
|---|---|
| ކްލޮތޮއިޑް ނޫން ސްޕައިރަލްތައް؛ ދެ ކާވެއްގެ ތެރޭގެ ސްޕައިރަލް (ކޮމްޕައުންޑް ޓްރާންޒިޝަންސް) | ކާވްގެ ދެ ކޮނެއްގައި ކްލޮތޮއިޑް ސްޕައިރަލްތައް ހުރޭ؛ އެހެން ތަކެތި ނަމަކޮށް LandXML އިމްޕޯޓުން ފޮހެލާ |
| ދެ އެކުލެ PI ތެރޭގައި PI އިންސާޓް ކުރުން | އެލައިންމަންޓް އަލުން ޑްރޯކުރޭ، ނުވަތަ PI ކޯޑިނޭޓްތައް އަލުން ލިޔޭ |
| އޮބްޖެކްޓްތަކުން އެލައިންމަންޓް، އޮފްސެޓްތައް، ފުޅުކުރުން | PI ތަކުން ޑްރޯ ކުރޭ |
| ވަރޓިކަލް ކާވަކަށް K ލިޔުން | L ލިޔޭ (K ފެންނަ) |
| ސަރކިއުލަރ އަދި އޮފް-ސިމެޓްރިކް ވަރޓިކަލް ކާވްތައް | ސިމެޓްރިކް ޕެރަބޮލިކް ކާވްތަކެވެ |
| އެލައިންމަންޓަކަށް ދެ ޑިޒައިން ޕްރޮފައިލް އަށްވުރެ ގިނަ | އެލައިންމަންޓް ވޭރިއަންޓަކަށް ދެ ފަހަރު |
| ޕްރޮފައިލް ވިއުގައި ޒޫމްކުރުން، ޕްރޮފައިލް ފަހުން ބެންޑްސް | ޕްރޮފައިލް ވިއު ހުރިހާ އެލައިންމަންޓް ފިޓްކުރޭ؛ ޕްލޭން އަދި ޕްރޮފައިލް ޝީޓްތަކުގައި ޕްލޮޓް ކުރޭ ([ޕްލޭން އަދި ޕްރޮފައިލް ޝީޓްތައް](topic:plan-profile-sheets)) |
| ސެކްޝަންތައް DWG ނުވަތަ LandXML ގައި | ސެކްޝަން ޝީޓްތައް PDF އަށް؛ ކުލި އަދި ވޮލިއުމްތަކުގެ {{ui:CSV}} |
| ނިސްބަތް ކޯނުން ނުވަތަ އެލައިންމަންޓުގެ ދިގުމިނަށް ފުޅާމިން ފަރާތަކަށް ވަރަށް ފަރަގު ސޭމްޕަލް ލައިންތައް | އެލައިންމަންޓުގެ ހުރިހާ ދިގުމިނަށް ކޮންމެ ފަރާތަކަށް ފުޅާމިންއެއް |

## ކޯރިޑޯތައް

| އަދި ހަދާފައި ނެތް | މިހާރު އޮތް ގޮތް |
|---|---|
| މީޑިއަންތައް، ބެރިއަރތައް އަދި ޓެމްޕްލޭޓްތައް ފަދައިން ސުޕަރެލިވޭޝަން | ޓެމްޕްލޭޓްތަކަށް ހަދާ ([ކޯރިޑޯ ޓެމްޕްލޭޓުތައް](topic:corridor-templates)); ސްޓޭޝަން ޓެމްޕްލޭޓްތަކުން މިހާރު ސުޕަރެލިވޭޝަން ނުނެތެވެ |
| ދެ ރީޖަން ޓެމްޕްލޭޓުތަކާ ދެމެދު ހުންނަ ދަށުންނަ ބަދަލު (ޓްރާންޒިޝަންތައް، ޓޭޕަރތައް) | ސްޓޭޝަނުގައި ޓެމްޕްލޭޓް ބަދަލުކުރޭ، ނުވަތަ ޓޭޕަރގެ ގޮތުގައި ހަދާ ލައިނަށް ޕޮއިންޓަކަށް ފުޅާމިން ޓާގެޓް ދޭ |
| ރޯޑުގެ ކަނޑާ ވަށައި ސްވިވެލް ކުރުން، LandXML ގައި ސުޕަރެލިވޭޝަން | ސުޕަރެލިވޭޝަން ސާކިއުލަރ ކާވްތަކުގައި ސެންޓަލައިން ވަށައި ފެތޭ؛ ލޭންއެއް ފުޅާމިން ޓާގެޓް ކުރޭ ފީޗާ ލައިނަށް |
| ޑޭލައިޓް ސްލޯޕަށް ޓާގެޓްތައް (ލައިނަށް ނުވަތަ ސަފޯސަށް ޑޭލައިޓް)، ކޯރިޑޯ ސަފޯސްތައް އެމީހުންގެ އަމިއްލަ | ޓާގެޓްތަކުން ފަރުޝުގެ ކަނޑުތަކާއި ޝޯލްޑަރގެ ކަނޑުތައް ހަރުކުރޭ ([ކޯރިޑޯތައް](topic:corridor)); ކޯރިޑޯ ޕްރޮޕޯސްޑް ސަފޯހުގައި ގްރޭޑް ކުރެވޭ |
| ކަރބް ރިޓާންސް، ޓާނިންގ ލޭންތަކާއި އައިލޭންޑްތައް ޖަންކްޝަނުގައި ގްރޭޑް ކުރެވޭ؛ ސައިޑް ރޯޑުގެ ކޮނެހި މެއިން ރޯޑުގެ ކަނޑާ ސްކިއު ކުރެވޭ؛ ޕާތް ރޯޑާ ޕްލޭނުގައި ލެންތާއި ފަރުޝުން ޖޮއިން | ބައްދަލުވާ ރޯޑުތައް ސްކެވެ ޖޮއިން ކުރެވެ، މެއިން ރޯޑުގެ ކަނޑު ހުޅުވައި ސައިޑް ރޯޑް އޭގެ ގާތަށް މަލާ ([ރޯޑްތައް ބައްދަލުވާ ތަން](topic:corridor#where-roads-meet-roads-pads-and-paths)); ފަތް ޕްރޮޕޯސްޑް ސަފޯހުގައި އަދި 3D ގައި ރޯޑުގެ ކަނޑުން ހުއްޓޭ |
| ކޯރިޑޯތައް LandXML ރޯޑްވޭތަކަށް އެކްސްޕޯޓް؛ އެލައިންމަންޓެއްގައި ދެވަނަ ކޯރިޑޯ IFC އެކްސްޕޯޓުގައި | ޕްރޮޕޯސްޑް ސަފޯސް އެކްސްޕޯޓް ކުރެވެއެވެ |
| ޓެރެއިން ޓެމްޕްލޭޓްތައް ޕްރޮޕޯސްޑް ސަފޯސް ބަދަލުކުރޭ، 3D ގައި ނުވަތަ ސެކްޝަންތަކުގައި | އެތެތް ޑްލޭޔަރ އެރިޔާތަކާއި ވޮލިއުމްތައް ދެއެވެ ([ޓެރެއިން ޓެމްޕްލޭޓްތައް](topic:corridor-templates#terrain-templates)) |
| ސްޕީޑާއި، ޓައިރް ސްލިޕާއި، ސްޓީރިންގ ޓައިމާއި، ސްޓީރިން ޓްރެއިލަރސް ނުވަތަ ބޮޑީ ކްލިއަރެންސް އެކު ސްވޯޕްޑް ޕާތްތައް؛ ސްޓޭންޑާޑް ޑިޒައިން ވެހިކަލްތަކުގެ ލައިބްރަރީ؛ ޑްރޭ ކުރާ ވެހިކަލް ޑްރެގް ކުރުމުން ސްވޯޕްޑް ޕާތް | ފީޗާ ލައިން ނުވަތަ އެލައިންމަންޓާ ގާތުގައި ކުޑަ ސްޕީޑުގެ ސްވޯޕްޑް ޕާތްތައް، ތިބާގެ އަމިއްލަ ވެހިކަލް ސައިޒްތަކާއެކު ([ވެހިކަލް ސްވޯޕްޑް ޕާތްތައް](topic:swept-paths)) |

## ގްރޭޑިންގ އަދި ވޮލިއުމްތައް

| އަދި ހަދާފައި ނެތް | މިހާރު އޮތް ގޮތް |
|---|---|
| ބެންޗްތައް، ޑިޒައިންގައި ގްރޭޑް ކުރެވޭ ހުޅުވާ ފީޗާ ލައިންތައް، އެހެން ތަނެއްގެ ފީޗާ ލައިނަށް ގްރޭޑިންގ | ފީޗާ ލައިން ބަންދުކުރޭ ([ފީޗާ ލައިންތައް](topic:feature-lines))، ނުވަތަ މައުޖޫދު ބިމުގެ ބްރޭކްލައިނަކަށް ބޭނުން ކުރޭ |
| ފީޗާ ލައިނެއްގެ ވަރޓެކްސް އިންސާޓް ނުވަތަ ފޮހެލުން | ލައިން އަލުން ޑްރޯކުރޭ، ނުވަތަ އޭގެ ސްޓެޕްޑް އޮފްސެޓެއް ހަދާ |
| ޑްރޯކުރެވޭ ބްރޭކްލައިންތަކުގައި އާރކްތައް (ސާވޭ ޕޮއިންޓްތައް މެދުން)، ފީޗާ ލައިންތަކުގައި ސްޕައިރަލްތައް | ފީޗާ ލައިނެއް އާރކްތައް ހުރިއިރު ޑްރޯކޮށް މައުޖޫދު ބިމުގެ ބްރޭކްލައިނަކަށް ބޭނުން ކުރޭ |
| ދުރުމިނަކަށް، އުސްމިނަކަށް ނުވަތަ އެހެން ސަފޯހަކަށް ގްރޭޑިންގ | ހަމަ ޑޭލައިޓް މައުޖޫދު ބިމަށް |
| ޕެޑްގެ ކޯނަރ އިތުރުކުރުން ނުވަތަ ފޮހެލުން | ޕެޑް ފޮހެލާ އަދި އަލުން ޑްރޯކުރޭ |
| TIN އިން TIN އަށް (ޕްރިޒްމް) ވޮލިއުމްތައް، ގްރިޑް ސެލްގެ ސައިޒް ޗޮއިސްކުރުން | ގްރިޑް މެތަޑް، ގްރިޑް ސެލް ސައިޒް ތިބާއަށް ޗޮއިސް ކުރެވެ |
| ސްވެލް އަދި ޝްރިންކް، ޓޮޕްސޯލް، ފޫތް ޑެތް | ރިޕޯޓުކުރެވޭ އަދަދުތަކަށް ފެކްޓަރުތައް ތިބާ ހަމަ އެޕްލައި ކުރޭ |
| ފްރީ ހޯލް އަދި އޯވަރ ހޯލް ކުލިތައް، ހޯލް އެލައިންމަންޓްތަކުގެ ދެމެދު، ބޯރޯ ސައިޓްތައް ޕްލޭނުގައި ޖެހިފައި | ވޮލިއުމްތައް ބަލަންސް ފޮއިންޓްތާ ހަމަ ހުރި ވޮލިއުމް މަސަލާ ޑައިގްރާމް އަދި ސަރާސަރި ހޯލް ދުރުތައް |

## ޕައިޕް ނެޓްވޯކްތައް

| އަދި ހަދާފައި ނެތް | މިހާރު އޮތް ގޮތް |
|---|---|
| ޕްރޮޖެކްޓަކަށް ނެޓްވޯކް ކޮންމެ ގިނަ | ސްޓޯމް އަދި ސެނިޓަރީ އަށް ވަކި ޕްރޮޖެކްޓްތައް |
| ވޮޓާ މެއިންސް: ފެނުގެ ކުލިއަށް އަދި އުމުރަށް، ރޫލް ބޭސްޑް ކޮންޓްރޯލް، ހުރި ވާލްވްތަކުގެ އެހެން ބައިތައް (ފްލޯ ކޮންޓްރޯލް، ތްރޮޓަލް، ސަސްޓޭއިނިންގ)، ޕަންޕު ޕަވާރުން ކޮންމެ ފަރާތާއި، ޕްރެޝަރ މަތީގައި ބެލެވޭ ޑިމާންޑް، ޑާސީ-ވޭސްބާޗް އޮޕްޝަން، ޕައިޕު ކެޓަލޮގ ވާލް ތިކްނަސްތަކާއި ޕްރެޝަރ ކްލާސްތައް. ޕްރެޝަރ ނެޓްވޯކްތަކުގެ ބާކީ ބައި ލެބް ގައި: [ވޮޓާ މެއިންސް](topic:water-mains) | އެތަކެތި ވޮޓާ ޑިސްޓްރިބިއުޝަން ސޮފްޓްވެއަރުގައި ޗެކްކުރޭ؛ ސެނިޓަރީ ޑިޒައިން ފްލޯތައް [ސެނިޓަރީ ޑިޒައިން ފްލޯތައް](topic:sanitary-design) ގައި |
| ސީވާ ފްލޯތައް ވަގުތުގައި (ހައިޑްރޯގްރާފްސް، ޑައިނަމިކް ރޫޓިންގ، ސްޓޯރޭޖް، ޕަންޕްސް، އޮވަރފްލޯތައް) | [ސެނިޓަރީ ޑިޒައިން ފްލޯތައް](topic:sanitary-design) ޑިޒައިން ޝީޓް ބޭނުން ކުރާ ސްޓީޑީ ޕީކް ފްލޯ ދެއެވެ |
| އިންލެޓް ކެޕެސިޓީ، ގަޓަރ ސްޕްރެޑް، ޑިޓެންޝަން ރޫޓިންގ، ހައިޑްރޯގްރާފްސް، އިނަރޖީ ލޯސްތައް އެކެއް ޖަންކްޝަން ކޯއެފިޝިއެންޓުންނެވެ | އެތަކެތި އެހެން ސޮފްޓްވެއަރުގައި ޗެކްކުރޭ؛ ފްލޯތައް، ސައިޒްތައް އަދި ގްރޭޑް ލައިންތައް [ސްޓޯމް ޑްރޭނޭޖް](topic:storm-drainage) ގައި |
| PDF ޕްލޮޓުގައި، DWG، DXF ނުވަތަ LandXML ގައި ކެޗްމަންޓްތައް؛ ސަފޯހުން ކެޗްމަންޓްތައް (ވޮޓާޝެޑްސް) | ކެޗްމަންޓްތައް އަތުން ޑްރޯ ކުރޭ؛ ޕްރޮޖެކްޓް ފައިލްގައި ރައްކާ ވޭ |
| ޕައިޕް ކެޓަލޮގްތައް، ރައުންޑް ނޫން ޕައިޕްތައް، އުނި ބޮކްސް އަކީ ނުވާ ސްޓްރަކްޗަރތައް (ކޯން، ސްޓެޕްސް، ބެންޗިންގ)، ލައިބްރަރީގައި ޑްރެއިނޭޖް ކެޓެގަރީ | ޕެރާމީޓަރުތަކުން ސްޓްރަކްޗަރ ޓައިޕްތައް ([ޕައިޕް ނެޓްވޯކް](topic:pipe-network))؛ ޑަޔަމީޓަރާ އެކު ޕައިޕްތައް |
| ޕްރޮފައިލް ވިއުގައި ޕައިޕްތައް، ކަރވެޑް ޕައިޕްތައް | ރައިޓް ޕެނަލުން އިންވަރޓްސް އަދި ކަވަރ ކިޔާ |

## GIS އަދި ކޯޑިނޭޓް ސިސްޓަމް

| އަދި ހަދާފައި ނެތް | މިހާރު އޮތް ގޮތް |
|---|---|
| ފައިލް ޖިއޯޑޭޓަބޭސް؛ KML ސްޓައިލްސް، އައިކޮންތައް، ގްރައުންޑް އޯވަލޭސް އަދި ނެޓްވޯކް ލިންކްތައް | GeoPackage، ޝޭޕްފައިލް ނުވަތަ GeoJSON ކަށް ކަންވާރޓް ކުރޭ ކުރިން؛ KML ޕްލޭސްމާކްތައް ސްޓައިލްސް ނެތި ކިޔެވޭ |
| GIS ފީޗަރތައް ނުވަތަ އެމީހުންގެ އެޓްރިބިއުޓްތައް އެޑިޓްކުރުން | GIS ޕްރޮގްރާމްގައި އެޑިޓް ކޮށް އަލުން އިމްޕޯޓް ކުރޭ. އެނަލިސިސް ޕެނަލް އާ ލޭޔަރތައް ހަދަނީ (ބަފަރ، އޯވަލޭ، ޖޮއިން، ސެލެކްޝަން) އަދި ހަމަ ޕަތުގައި އެރިޔާ އަދި ލެންތް ފީލްޑްތައް ދެއެވެ، ނަމަވެސް ފީޗަރއެއް އެހެން ތަނުގައި އެޑިޓް ނުކުރެއެވެ |
| ނެޓްވޯކް އަދި ރާސްޓަރ އެނަލިސިސް، ފްލެޓް ނުވަތަ ސްކެއާ އެންޑްސް ހުރި ބަފަރ އަދި އެއްފަރާތު ބަފަރ، އެޓްރިބިއުޓް ޓޭބަލްގައި ރޯތައް އިތުރުކުރުން ނުވަތަ ފޮހެލުން އަދި ފީލްޑް ޓައިޕް ބަދަލުކުރުން، އަތުން ކްލާސް ރަން، ޕްލޮޓްތަކުގައި ސްޓައިލް ލެޖެންޑް | ފީޗަރ ހޯދަން Select ބޭނުން ކުރޭ، އަދި އޭގެން ލޭޔަރ ހަދާ؛ ފްލެޓް އެންޑްސް ނުދެވޭ. އެޓްރިބިއުޓުން ކުލަ ދިނުމާއި އެޓްރިބިއުޓް ޓޭބަލް ހަދާފައި ވޭ: [އެޓްރިބިއުޓުން ލޭޔަރ ސްޓައިލްކުރޭ](topic:gis-symbology) އަދި [ލޭޔަރ އެޓްރިބިއުޓް ޓޭބަލް](topic:gis-table) ބަލާ |
| ލޭބަލް ސްޓައިލް (ސައިޒް، ޕްލޭސްމަންޓް) އަދި އެކަކު އަނެކަކާ ބައްދަލުވާ ނުވާ ލޭބަލްތައް | ލޭބަލްތައް އެއް ސައިޒް، ފީޗަރ ގިނަ ކަމުން އޯވާލުވެދާނެ |
| ވަރޓިކަލް ޑެޓަމް އަދި ޖިއޯއިޑް މޮޑެލްތައް | އެލެވޭޝަންތައް ފައިލް ދޭ ގޮތަށް ބޭނުން ކުރެވޭ؛ ވަރޓިކަލް ޑެޓަމް ކަނޑުން ބަލާ |

| DXF ނުވަތަ 3D އެކްސްޕޯޓުގައި މެޕް ލޭޔަރތައް | މެޕް ލޭޔަރތައް PDF ޕްލޮޓަށް ދަނީ، އަދި DWG ގެ ކައިރީ ފޮޓޯއެއްގެ ގޮތުގައި |
| ސައިން އިން ކުރަން ބޭނުންވާ މެޕް ސަރވަރތައް؛ ކީ ނުވަތަ ޓޯކަން | ޕަބްލިކް ސަރވިސް ބޭނުން ކުރޭ، ނުވަތަ ޖިއޯރެފަރެންސް ކުރެވުނު އިމޭޖް ފައިލެއް |
| ސަފޯހުން LAS ނުވަތަ LAZ ފައިލް ލިޔުން، ނުވަތަ ގްރިޑް/LiDAR ޓޫލްތައް | ސަފޯހުން ގްރިޑް GeoTIFF ގައި އެކްސްޕޯޓް ކުރޭ. [ޕޮއިންޓް ކްލައުޑްސް](topic:point-clouds) އެޑް-އޮން ސާފު ކުރެވުނު ކްލައުޑް LAS 1.4 ނުވަތަ LAZ ގައި ލިޔޭ |
| LiDAR އިންޓެންސިޓީ، ކުލަ އަދި ރިޓާންސް؛ ގިނަ ބެންޑް ހުރި ގްރިޑް ފައިލްތައް؛ ގްރިޑް ނުވަތަ LiDAR ފައިލް 200 MB އަށްވުރެ ގިނަ | LiDAR ހުރީ ކްލާސް އިންދާ ފިލްޓަރ ކުރެވޭ، ގްރިޑްތައް އެމީހުންގެ ފުރަތަމަ ބެންޑު ބޭނުން ކުރޭ؛ ބޮޑު ފައިލްތައް ފުރަތަމަ ޓައިލްސް ކަނޑު ކުރޭ |

## 3D ވިއު

| އަދި ހަދާފައި ނެތް | މިހާރު އޮތް ގޮތް |
|---|---|
| 3D ވިއުގައި ޑްރޯކުރުން ނުވަތަ އެޑިޓްކުރުން | ޕްލޭނުގައި ޑްރޯ އަދި އެޑިޓް ކުރޭ؛ 3D ވިއުން ކޮންމެ އެޑިޓް ފަހަތުން ދެއެވެ |
| 3D ގައި ކޯރިޑޯ ފީޗަރ ލައިންތައް ނުވަތަ GIS ފީޗަރތައް ކްލިކްކޮށް ޚިޔާރުކުރުން | ޕްލޭނުގައި ކްލިކް ކުރޭ |
| އެކްސަޖެރޭޓެޑް ވިއު ނުވަތަ ފީޓުގައި އެކްސްޕޯޓް ކުރުން | އެކްސްޕޯޓްތައް ސްކޭލް ރަނގަޅަށް މީޓަރުގައި ހުންނާނެ؛ [3D އެކްސްޕޯޓް](topic:export-3d) ބަލާ |
| GLB ނުވަތަ OBJ އެކްސްޕޯޓްގައި ލޭބަލްތައް، 3D ގައި ލޭބަލް ސައިޒްތަކާއި ސްޓައިލްތައް | ލޭބަލްތައް 3D ވިއުގައި އެކަނި ފެންނާނެ، ސައިޒް އެކަ؛ [3D ވިއު](topic:site-3d) ބަލާ |
| ފޮޓޯތަކުން ޓެކްސްޗަރ، ޑްރައިވް އެއް ވީޑިޔޯ ރެކޯޑްކުރުން، ސައިޓަށް ބޭރުގެ ހިޔަ ހިތުން ޝޭޑޯތައް، ސަން ހަވަރު 3D ގައި | ނެކެޓްތަކުގައި ޕްލޭނުގައި ވިސްވުމުގައި ޑްރޭޕް ކުރެވޭ މެޕް ލޭޔަރތައް؛ ޑްރައިވް ކުރޭ އަދި ސަންގެ ފޮޒިޝަން ގެ އެއް ވަގުތު؛ [ސަން ހަވަރު](topic:sun-hours) ދުވަހަކަށް ނުވަތަ މޫސުމަކަށް ޕްލޭނުގައި |

އެހެން އޯވަރހެޑް ލައިން ޕްރޮގްރާމްތަކުން ސްޓަޑީއެއް `.DON` ފައިލެއްގައި (XML ޓެކްސްޓް) ރައްކާ ކުރެއެވެ. CivilCraft ން ލައިނެއް އެންމެ ފައިލެއްގެ ގޮތުން ލިޔެވެދާނެ، އަދި އެއްގެ ސަޕޯޓުތައް ކިޔެވެދާނެއެވެ.

:::warning
**ޓެސްޓު ނުކުރެވިފައެވެ.** މި ހަދާފައިވަނީ ފޯމެޓުގެ ފީލްޑު ނަންތައް ބައިވެރިވި ޔޫޒަރަކު ޝެއާ ކުރި ލިސްޓަކުން، ރިއަލް ފައިލަކުން ނޫން، އަދި ކިޔާ ޕްރޮގްރާމުގައި އަޅުގަޑުމެން އަމިއްލަ ފައިލްތައް ހުޅުވާފައެއް ނެތް. ޕްރޮގްރާމުގައި ފައިލް ހުޅުވައި، ކޮންމެ ވެލިއުއެއް ބަލާ ފަހު ބޭނުން ކުރާށެވެ. `.DON` ފައިލެއް (ކްލައިންޓްގެ ތަފްސީލު ފޮހެލައި) ޝެއާ ކުރެވިދާނެ ނަމަ، އެ މުޅި ކަންތައް ރަނގަޅު ކުރުމަށް އެކަން މަދަދު ކުރާނެއެވެ.
:::

## ސްޓަޑީ ފައިލް ރައްކާ ކުރޭ

1. ލައިނަކަށް ކޮންޑަކްޓަރއެއް ދީ، އޭގެ ނަތީޖާ ހުރިކަން ބަލާށެވެ (Properties ގައި "not worked out" ނެތް).
2. {{ui:More}} › {{ui:Save a study file (.DON)…}}، ލައިން ހޮވާ، ތަފްސީލު އަދި ޖޮބް ނަންބަރު ހިމެނިއްޖެ ކަމުގައި ބަލާށެވެ.
3. {{ui:Save the study file}} ފިތާލާށެވެ.

ފައިލުގައި ލައިނުގެ ސަޕޯޓުތައް ހިމެނޭ (ކޯޑިނޭޓްސް، ބިން، އުސްމިންތައް، ރޯލްތައް، ކްރޮސްބާމް، ހިފާފައިވާ ނުވަތަ ހުށަހަޅާފައިވާ ސަޕޯޓް، ކޮންމެ ލޯޑް ކޭހަށް ލޯޑްތައް، ފައުންޑޭޝަން)، ކޮންމެ ސެކްޝަނަކަށް ފަހުގައި ކުޑަ ފަރާތް (ކޮންޑަކްޓަރ، ވޯލްޓޭޖް، ރޫލިންގ ސްޕޭން، ސްޕޭންތައް، ޓެންޝަން އަދި ކެޓެނަރީ ޕެރާމީޓަރ، ކޮންމެ ލޯޑް ކޭހަށް ބޮޑު ޓެންޝަން) އަދި ސްޓްރިންގިން ޓޭބަލްތައް. ދިގުމިންތައް މީޓަރުގައި އަދި ފޯސްތައް daN ގައި؛ ޓެކްސްޓް Latin-1 ގައި ލިޔެވޭތީ، އެއިން ބޭރުގެ ކެރެކްޓަރަކަށް `?` ވެއެވެ.

## ސްޓަޑީ ފައިލް ކިޔާ

{{ui:More}} › {{ui:Open a study file (.DON)…}} ސަޕޯޓުތައް އައު ލައިނަކަށް ކިޔައެވެ. ކޮންޑަކްޓަރ، ސަޕޯޓު އަދި ކްރޮސްބާމްތައް ތިޔަ ލައިބްރަރީއާ ނަމުން ގުޅޭ؛ ނުފެނޭ ކޮންމެ އެއްޗެއް Properties ގައި ތިޔަ ހޮވުމަށް ބެހެއްޓެއެވެ.

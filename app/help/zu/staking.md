Khetha umzila bese ucindezela **Umbiko wokumisa izikhonkwane** kuzo **Izici** zawo.

## Izikhonkwane ezindaweni nasekukhashaneni

1. **Kusuka** no **kuya**: iziteshi ozofaka kuzo izikhonkwane (1+50 noma 150).
2. **njalo**: isikhala. Izikhonkwane zifakwa kuwo wonke amaphindu alo, emikhawulweni yombili, nalapho amajika omzila eqala khona futhi aphele (uma ibhokisi ikhonjiwe).
3. **Ukukhashana**: kwesobunxele nakwesokudla komzila, ubheka phezulu isiteshi: `12 L, 0, 12 R`, `L12 CL R12` noma `-12, 0, 12` (kwesobunxele kuyisibambo). Umzila onekhoridoro uqala ngemiphetho yomgwaqo nezinhlangothi zawo.
4. **Qala ngenombolo** nethi **nesiqalo** zinika izikhonkwane amagama: 1, 2, 3, noma S101, S102.

## Amaphoyinti okuhlola aseduze nomzila

Khetha **amaphoyinti okuhlola aseduze nomzila** nokuthi aseduze kangakanani. Iphoyinti ngalinye phakathi kwalobo bude lithola isiteshi nokukhashana kwalo, ukuklama lapho, nokuphakama kwalo njengomhlaba: ukuhlola amaphoyinti amiswe noma athathwe njengokwakhiwe.

## Okushiwo yumbiko

| Ikholomu | Yini |
|---|---|
| Iphoyinti | Igama lesikhonkwane, noma inombolo yephoyinti lokuhlola |
| Isiteshi, Ukukhashana | Lapho likhona emzileni: L kwesobunxele, R kwesokudla |
| Northing, Easting | Izindawo zalo |
| Ukuphakama kokuklama | Umphezulu wekhoridoro elakhiwe lapho (kusukela emugqeni wokukhanya kuye emugqeni wokukhanya), noma kungenjalo iprofayili yokuklama emgqeni maphakathi |
| Ukuphakama komhlaba | Umphezulu okhona lapho, noma ukuphakama kwephoyinti lokuhlola |
| Sika/Gcwalisa | C uma umhlaba ungaphezulu kokuklama (usike phansi), F uma ungaphansi (gcwalisa phezulu), kuya emakhulwini |

Isikhonkwane esingenakuphakama kokuklama (ngaphandle kwekhoridoro, noma emzileni ongenakho ngaphandle komgqa maphakathi) asinakusikwa noma sigcwaliswe; ingxoxo ikhombisa ukuthi zingaki.

## Gcina kona

- **CSV**: umugqa wesihloko, bese kulandela amakholomu angenhla, kanye nokusika noma ukugcwalisa njengenombolo enophawu (umhlaba ngaphandle kokuklama) yamashidi nezokuqoqa idatha.
- **PDF**: amakhasi etafula ephepheni oliqoke, isikhonkwane ngomugqa ngamunye, ukusika kubonakala ngewolintshi nokugcwaliswa ngaluhlaza, nombala wesihloko wezinye amashidi.

:::note
Izikhonkwane zibalwa kusuka ekuklameni kuphrojekthi. Zihlole ngokuqhathanisa namapulani avunyelwe ngaphambi kokuthi kwakhiwe noma yini.
:::

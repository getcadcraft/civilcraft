Ithuluzi lisebenza phezu kwohlelo ngamaqembu ayisikhombisa. Iqhosha ngalinye likhombisa usizo lwalo lombhalo nesinqamuleli uma uhamba ngayo.

## Ifayela

| Iqhosha | Isinqamuleli | Okwenzayo |
|---|---|---|
| {{ui:New}} | akukho | Iqala iphrojekthi engenalutho. Kuqala kubuze uma kukhona izinguquko ezingalondolozwanga. |
| {{ui:Open}} | {{key:Mod+O}} | Ivula ifayela lamaphoyinti (CSV, TXT), i-LandXML noma iphrojekthi ye-CivilCraft. |
| {{ui:Save}} | {{key:Mod+S}} | Ilanda iphrojekthi njenge `<name>.civilcraft.json`. |

## Thumela

| Iqhosha | Isinqamuleli | Okwenzayo |
|---|---|---|
| {{ui:LandXML}} | akukho | Ilanda `<name>.xml`: amaphoyinti, imiphezulu, imizila, iprofayili kanye nenethiwekhi yamapayipi njenge-LandXML 1.2. "Akukho okuthunyelwayo okwamanje." uma iphrojekthi ingenalutho. |
| {{ui:DXF}} | akukho | Ilanda `<name>.dxf`: imigqa yepulani njenge-R12 DXF. |
| {{ui:PDF}} | {{key:Mod+P}} | Ivula **Dweba ipulani ibe yi-PDF**. "Akukho okuzodwetshwa okwamanje." uma iphrojekthi ingenalutho. |

## Umphezulu

| Iqhosha | Isinqamuleli | Okwenzayo |
|---|---|---|
| {{ui:Breakline}} | {{key:B}} | Cindezela amaphoyinti okuhlola ngokulandelana, {{key:Enter}} ukuze uqedele. Umugqa wokuphula uthatha amaphakamo amaphoyinti. |
| {{ui:Boundary}} | {{key:O}} | Cindezela amakhona womngcele wangaphandle, {{key:Enter}} ukuze uqedele. Uyashintsha noma yimuphi umngcele. |

Zombili zithi "Asikho umphezulu okwamanje: vula amaphoyinti okuhlola kuqala." uma kungekho umphezulu.

## Ukwakha

| Iqhosha | Isinqamuleli | Okwenzayo |
|---|---|---|
| {{ui:Alignment}} | {{key:A}} | Cindezela ama-PI ngokulandelana, {{key:Enter}} ukuze uqedele. |
| {{ui:Pad}} | {{key:G}} | Cindezela amakhona esisekelo, {{key:Enter}} ukuze uqedele. Njengamathuluzi omphezulu, ilumbisa uma kungekho umphezulu; isisekelo silinganiswa kuphela kuwo. |
| {{ui:Pipes}} | {{key:P}} | Cindezela izakhiwo kusukela phezulu kuya phansi (cindezela eyodwa ekhona ukuze uyihlanganise), {{key:Enter}} ukuze uqedele. |
| {{ui:Profile}} | {{key:R}} | Ikhombisa noma ifihle ukubuka iprofayili ngaphansi kwepulani. |

## Hlela

| Iqhosha | Isinqamuleli | Okwenzayo |
|---|---|---|
| {{ui:Undo}} | {{key:Mod+Z}} | Ihlehlisa ushintsho lokugcina (kuze kube ngu-200). Ibonakala ibuthaka uma kungekho okuzohlehliswa. |
| {{ui:Redo}} | {{key:Mod+Y}} | Iphinda okuhlehliswe. Ibonakala ibuthaka uma kungekho okuzophindwa. |
| {{ui:Copy}} | {{key:Mod+C}} | Ikopisha amaphoyinti okuhlola akhethiwe, ibeke ibhodi lokopisha njengemigqa yamaphoyinti esilungele i-spreadsheet. Ibonakala ibuthaka kuze kukhethwe amaphoyinti. |
| {{ui:Paste}} | {{key:Mod+V}} | Inamathisela amaphoyinti: alandela isikhombi, futhi ukuchofoza kuwabeka phansi anezinombolo ezingekho kwelinye iphoyinti. Imigqa yamaphoyinti ekopishwe ku-spreadsheet nayo iyanamathiseleka. |
| {{ui:More}} | akukho | Ivula imenyu engezansi. |

Imenyu {{ui:Okuningi}}:

| Into | Isinqamuleli | Okwenzayo |
|---|---|---|
| {{ui:Cut}} | {{key:Mod+X}} | Ikopisha amaphoyinti akhethiwe bese iwasusa (isinyathelo esisodwa sokuhlehlisa). |
| {{ui:Copy}} | {{key:Mod+C}} | Njengeqhosha {{ui:Copy}}. |
| {{ui:Paste}} | {{key:Mod+V}} | Njengeqhosha {{ui:Paste}}. |
| {{ui:Paste in place}} | {{key:Mod+Shift+V}} | Inamathisela amaphoyinti ezindaweni zawo zokuxhumanisa, nezinombolo ezingekho kwelinye iphoyinti. |
| {{ui:Duplicate}} | {{key:Mod+D}} | Ikhophi yamaphoyinti akhethiwe ilandela isikhombi; chofoza lapho iya khona. Ibhodi lokopisha alishintshwa. |
| {{ui:Delete}} | {{key:Delete}} | Isusa amaphoyinti okuhlola akhethiwe, noma umzila, isisekelo, isakhiwo (namapayipi aso), ipayipi noma i-PVI ekhethiwe. |
| {{ui:Select all points}} | {{key:Mod+A}} | Ikhetha wonke amaphoyinti okuhlola. |
| {{ui:Select none}} | {{key:Esc}} | Ihlanza ukukhethwa. |

Into engenakwenza manje ibonakala ibuthaka, nosizo lwayo lombhalo lusho ukuthi kungani. Imininingwane: [Khetha, kopisha namathisele amaphoyinti okuhlola](topic:copy-paste-points).

Ukuhlehlisa kumboza ushintsho kuklame, izilungiselelo zomphezulu namaphoyinti okuhlola (namathisela, sika, phinda, susa). Akumboze izilungiselelo zokubonisa, futhi ukuvula noma ukungenisa noma yiliphi ifayela kuyayisula.

## GIS

| Iqhosha | Isinqamuleli | Okwenzayo |
|---|---|---|
| {{ui:Coordinates}} | akukho | Ivula ingxoxo **Uhlelo lokuxhumanisa**: tshela ukuthi iphrojekthi isesistimini esiphi, noma sebenzisa amakhoordinethi womhlaba noma endawo. Bona [Setha uhlelo lokuxhumanisa lweprojekthi](topic:coordinate-systems) kanye [Amakhoordinethi womhlaba nendawo](topic:ground-and-local-coordinates). |
| {{ui:Import}} | akukho | Ingenisa idatha ye-GIS: ama-shapefile, i-GeoJSON, i-GeoPackage, amagridi okuphakama nedatha ye-LiDAR. Bona [Ngenisa idatha ye-GIS](topic:gis-import). |
| {{ui:Export}} | akukho | Ithumela idatha njengokwakhiwe yomnyango we-GIS. Bona [Thumela idatha njengokwakhiwe ye-GIS](topic:gis-export). |
| {{ui:Analyze}} | akukho | Ivula iphaneli yokuhlaziya ye-GIS: ibhafa, ukumboza, ukuhlanganisa kwesikhala, ukukhetha ngesici, ukulinganisa. Bona [Hlaziya izingqimba ze-GIS](topic:gis-analysis). |
| {{ui:Attribute table}} | akukho | Ku-Umphezulu › Okuningi. Ivula ithebula lezici longqimba lwe-GIS: hlunga, khetha, hlela, engeza izinsimu, bala, gcina njenge-CSV. Bona [Sebenza nethebula lezici longqimba](topic:gis-table). |
| {{ui:Map}} | akukho | Ivula ingxoxo **Izingqimba zemephu**: isithombe esinesikhundla, noma amaseva emephu ongawengeza, adwetshwe ngaphansi kwepulani. Bona [Bonisa izingqimba zemephu ngaphansi kwepulani](topic:map-layers). |

Amathuluzi e-GIS alayisha ngokuqala uma usebenzisa enye yalawa maqhosha, uvula ifayela le-GIS, noma uvula iphrojekthi enohlelo lokuxhumanisa noma izingqimba ze-GIS.

## Buka

| Iqhosha | Isinqamuleli | Okwenzayo |
|---|---|---|
| {{ui:Select}} | {{key:V}} noma {{key:Esc}} | Chofoza ukukhetha imizila, izisekelo, izakhiwo, amapayipi namaphoyinti ({{key:Shift}} nokuchofoza noma ukudonsa kuwengeza amaphoyinti); donsa izibambo ukuze uhambise ama-PI, amakhona esisekelo nezakhiwo. |
| {{ui:Lingana}} | {{key:F}} | Isondeza ipulani ukuze ibonise umphezulu, amaphoyinti, imizila nezisekelo (kumbono we-3D: ibonisa konke). |
| {{ui:3D}} | {{key:D}} | Ibonisa isayithi nge-3D phezu kwepulani, noma ibuyele epulanini. Ibha ephezu kombono we-3D isetha umbono, ukukhulisa, imibala nokuthi yini ebonakalayo, futhi ithumela i-GLB noma i-OBJ. Bona [Buka isayithi nge-3D](topic:site-3d). |

Izinkinobho ezimfushane zisebenza uma ungabhali kubhokisi. Izinqamuleli ezinokuthi {{key:Mod}} zisebenzisa i-Command ku-Mac, ne-Ctrl kwezinye. Bona futhi [Izinkinobho esiphequluleni](common:keys).

## Amafayela nokuhlela

| Inkinobho | Isenzo |
|---|---|
| {{key:Mod+O}} | Vula ifayela lamaphoyinti, LandXML noma iphrojekthi |
| {{key:Mod+S}} | Londoloza iphrojekthi (ilanda ifayela le-`.civilcraft.json`) |
| {{key:Mod+P}} | Hlola ipulani ibe yi-PDF (ivula ingxoxo ye-plot, hhayi ukuphrinta kwesiphequluli) |
| {{key:Mod+Z}} | Hlehlisa |
| {{key:Mod+Y}} | Phinda wenze |
| {{key:Delete}} | Susa amaphoyinti okuhlola akhethiwe, i-alignment, ipedi, isakhiwo, ipayipi noma i-PVI |
| {{key:Mod+C}} | Kopisha amaphoyinti okuhlola akhethiwe (futhi njengemigqa yamaphoyinti ye-spreadsheet) |
| {{key:Mod+X}} | Sika amaphoyinti okuhlola akhethiwe |
| {{key:Mod+V}} | Namathisela amaphoyinti: alandela isikhombi, chofoza lapho ayakhona |
| {{key:Mod+Shift+V}} | Namathisela endaweni efanayo: ngokuhlangana kwamaphoyinti ngokwawo |
| {{key:Mod+D}} | Phinda amaphoyinti akhethiwe: ikhophi ilandela isikhombi |
| {{key:Mod+A}} | Khetha wonke amaphoyinti okuhlola |
| {{key:Esc}} | Khetha lutho (futhi ukhansele ukunamathisela) |

{{key:Mod+S}}, {{key:Mod+O}} kanye {{key:Mod+P}} zisebenza noma ngabe ubhala ebhokisini. {{key:Mod+Z}} kanye {{key:Mod+Y}} ebhokisini lombhalo zihlehlisa ukubhala kwakho, njengokujwayelekile, futhi kanjalo {{key:Mod+C}}, {{key:Mod+X}}, {{key:Mod+V}} kanye {{key:Mod+A}}: ebhokisini ziyakopisha, zisike, zinamathisele futhi zikhethe umbhalo walo. Umbhalo okhethiwe ekhasini (kuphaneli), {{key:Mod+C}} ikopisha lowo mbhalo. {{key:Mod+Shift+Z}} ayenzi lutho ku-CivilCraft: sebenzisa {{key:Mod+Y}} noma inkinobho ye-{{ui:Redo}}.

:::mac
Inkinobho yeMac ebhalwe **delete** iba {{key:Backspace}} kusiphequluli. Ukusula okukhethiwe, cindezela {{key:Delete}} (Fn kanye ne-delete), noma khetha {{ui:Delete}} kumenyu ethi {{ui:More}} yethuluzi.
:::

## Ngenkathi udweba

| Inkinobho | Isenzo |
|---|---|
| {{key:Enter}} | Qeda i-alignment, ipedi, umugqa wepayipi, umugqa wokuphula noma umkhawulo |
| {{key:Backspace}} | Susa iphoyinti lokugcina elichofozwe |
| {{key:C}} | Umugqa wesici: vula noma vala ama-arc (ngemva kwe-vertex, chofoza iphoyinti kujikijolo, bese uphelela) |
| {{key:Esc}} | Khansela ukudweba (noma ukunamathisela); uma ucindezela futhi (noma kungekho okudwetshiwe), buyela ku-{{ui:Select}} bese usula ukukhetha |

## Umbono wepulani

| Inkinobho noma isenzo | Umphumela |
|---|---|
| Ivili | Sondeza noma unciphise endaweni yomkhombisi |
| Hudula endaweni engenalutho | Shelelisa (kunoma iyiphi ithuluzi; ukuchofoza okufushane kusachofoza; uma kubanjwe {{key:Shift}} kudweba ibhokisi lokukhetha) |
| Hudula ngenkinobho ephakathi | Shelelisa |
| Hudula ngenkinobho yesokudla | Shelelisa (akukho menyu evulwayo) |
| {{key:Space}} nokuhudula | Shelelisa |
| Chofoza | Khetha (ngo-{{ui:Select}}), noma ubeke iphoyinti (ngethuluzi lokudweba) |
| {{key:Shift}} nokuchofoza | Engeza iphoyinti lokuhlola ekukhethweni, nomaususe |
| {{key:Shift}} nokuhudula | Dweba ibhokisi: amaphoyinti okuhlola angaphakathi kwalo angezwa ekukhethweni. Hudula uzungeze kuwo ukuze uthole [i-lasso](topic:lasso-selection) |
| {{key:Space}} lapho udweba i-lasso | Iwindi, bese ukuwela, bese ifensi |
| Chofoza lapho unamathisela | Beka amaphoyinti anamathisiwe lapho ({{key:Enter}} ayabeka endaweni yawo yokuhlangana) |
| Hudula isiphethu | Hambisa i-PI, ikhona lepedi noma isakhiwo (isinyathelo esisodwa sokuhlehlisa) |
| {{key:Up}} {{key:Down}} {{key:Left}} {{key:Right}} | Shelelisa, lapho ipulani igxile (chofoza kuqala) |
| {{key:Plus}} kanye {{key:Minus}} | Sondeza noma unciphise phakathi nendawo, lapho ipulani igxile |

Inkinobho ya = isondeza njenge-{{key:Plus}}, ngakho awudingi Shift.

## Umbono wephrofayili

| Isenzo | Umphumela |
|---|---|
| Chofoza ngo-{{ui:Add PVIs}} svuliwe | Engeza i-PVI lapho |
| Chofoza i-PVI | Khetha yona |
| Hudula i-PVI | Hambisa yona (isinyathelo esisodwa sokuhlehlisa) |
| {{key:Delete}} noma {{key:Backspace}} | Susa i-PVI ekhethiwe ({{key:Backspace}} kuphela uma umbono wephrofayili ugxile) |

Umbono wephrofayili awusondezi noma ushelelisi.

## Isikrini nosizo

| Inkinobho | Isenzo |
|---|---|
| {{key:F1}} | Vula noma vala lo sizo (iphaneli eseceleni); {{ui:Help}} ku-app bar yenza okufanayo |
| {{key:Esc}} | Vala iphaneli yosizo uma ivulekile |
| {{key:Ctrl+Shift+F}} | Shayela izimo zesikrini: isikrini esigcwele, isikrini esigcwele nemibhalo efihliwe, ejwayelekile |
| {{key:Esc}} | Phuma esikrinini esigcwele (inkinobho yesiphequluli ngokwayo) |

{{key:F1}} ifinyelela usizo ngaphambi kokuthi i-CivilCraft iyibone, ngakho isebenza kunoma iyiphi ithuluzi. Ezikhibhodini eziningi ze-Mac, cindezela fn kanye ne-F1, noma chofoza {{ui:Help}}. {{key:Ctrl+Shift+F}} isebenzisa inkinobho ye-Control kuzo zonke izinhlelo, kuhlanganise ne-Mac. Bona [Ukusebenzisa usizo](common:help) ukuthola indlela yokusesha kulo sizo.

## Imouse, i-trackpad nokuthinta

:::mouse
- Ivili lisondeza endaweni yomkhombisi. Imouse enevili elizungeza ngokukhululeka isondeza ngokushesha: sebenzisa ukugoqa okufushane.
- Shelelisa ngokuhudula noma yiluphi uhlangothi endaweni engenalutho, ngenkinobho ephakathi, ngenkinobho yesokudla, noma ngo-{{key:Space}} nokuhudula.
:::

:::mac
Ku-trackpad ye-Mac:

- Ukuskrola ngeminwe emibili **kuyasondeza** (akushelelisi), nokuncinza nakho kuyasondeza.
- Ukushelelisa, cindezela futhi uhudule endaweni engenalutho ngomunwe owodwa, noma bamba {{key:Space}} uhudule.
- Ukuchofoza ngeminwe emibili (ukuchofoza kwesokudla) akuvuli menyu futhi akwenzi lutho ngokwakho.
:::

:::touch
Esikrinini sokuthinta:

- Ukuthinta kokuqala kwenza izinkinobho nemigqa yemenyu ibe yobukhulu befingathi.
- Thinta ukuze ukhethe noma ubeke iphoyinti; umunwe owodwa ohudulela endaweni engenalutho ushelelisa. Ukuthinta kungashelela kancane: kushelelisa kuphela uma umunwe uhamba cishe ngamapikseli ayi-10.
- Iminwe emibili icincanisa ukusondeza nihambise ndawonye ukushelelisa.
- Hudula isiphethu noma i-PVI ngomunwe owodwa. Izinhlangothi zifuna ububanzi befingathi kuzo.
- Lapho udweba i-alignment, ipedi, umugqa wokuphula, umkhawulo, umugqa wepayipi, umugqa wesici noma ipaseli, ibha phezu kwepulani inikeza {{ui:Finish}} ({{key:Enter}}), {{ui:Undo point}} ({{key:Backspace}}) kanye {{ui:Cancel}} ({{key:Esc}}). Ukubamba isikhathi eside (isigamu sesekhondi ngaphandle kokunyakaza) nakho kuyaqeda.
- Ku-{{ui:Select}}, ukubamba isikhathi eside ephoyinti lokuhlola kulengeza ekukhethweni, noma kuyakhipha, njengoba kwenza {{key:Shift}}+ukuchofoza.
- Kumbono we-3D, umunwe owodwa uzungeza, iminwe emibili icincanisa futhi ihudula, nokuthinta kukhetha.
- Akukho ukuhamba phezu kokuthinta, ngakho izifundo zesimo sebha zibuyekezwa kuphela lapho umunwe usezansi.
:::

## Izinkinobho zesiphequluli ezinqoba

Ezinye izinkinobho zesiphequluli ngokwazo azifiki ku-CivilCraft, njengo-{{key:Mod+W}} (vala ithebhu), {{key:Mod+T}} (ithebhu entsha), {{key:Mod+N}} (iwindi elisha) kanye no-{{key:F11}} (isikrini esigcwele kuzisiphequluli zeWindows nezeLinux). I-CivilCraft ayisebenzisi lezi. Uma inqamuleli ivula okuthile esiphequluleni, chofoza ipulani kanye ukuze ikhasiligxile, bese uzama futhi.

## Lapho kuhlala Hambisa

Akukho umyalo othi Hambisa: khetha {{ui:Select}} bese uhudula iphoyinti noma i-vertex, noma uhlele izixhumanisi zalo ku-{{ui:Properties}}. Bona [Hlela amaphoyinti](topic:edit-points).

Umdwebo wokuhlola ungabukeka ulungile kodwa ungalungile ngomhlaba: izinyunithi zawo zingase zibe ziqagelwe, amakhontuwa awo angase ahlale esicaba ebude be-0, noma amazinga awo angase abhalwe njengombhalo ongewona ijiyomethri. Isigaba se-**Amazinga okuhlola nokuhlola** sengxoxo ye-{{ui:Imigqa}} (bona [Vula i-DWG noma i-DXF njengemigqa](topic:open-dwg-dxf)) sifunda la mazinga futhi sikutshele okubonakala kungalungile ngaphambi kokuthi kungezwe lutho.

## Amazinga abhalwe njengombhalo noma ezicini

Imidwebo eminingi yokuhlola inikeza izinga lendawo njengombhalo omncane eduze kwesiphambano, njenge `104.37` noma `EL 104.37`, noma njengesici sephoyinti lebhulokhi. Lezi azisimigqa, ngakho umfundi wemigqa uyazishiya. Isigaba sibala ukuthi zingaki ezitholakele futhi sikuvumela ukuthi uzithathe njengamaphoyinti okuhlola:

1. Khetha **Thatha … amazinga njengamaphoyinti okuhlola**. Azivulekile ekuqaleni, ngoba akukho nombolo yonke emdwebeni eyisiphakamo.
2. Umbhalo ufundwa uma kuyizinga eliyodwa: inombolo enengxenye yedesimali (`104.37`, `+104,37`, `-3.50`), noma inombolo elandela `EL`, `ELEV`, `RL`, `FFL`, `GL`, `TW`, `BW`, `INV`, `Z` noma `LEVEL`, nangokukhetha `m`, `ft` noma `'` kuyo. Inombolo ephelele yodwa (`12`) ifundwa njengenombolo yesiza noma yephepha, hhayi izinga; umbhalo onjengo `GATE 3` noma usuku awufundwa ngokuphelele. Amakhodi wokufometha umbhalo ayanakwa.
3. Kuzici zebhulokhi, khetha **Isici sebhulokhi esibamba izinga**. I-CivilCraft ithola ithegi elibizwa ngokuthi ELEV, Z, LEVEL, RL noma okufanayo ngokwayo; khetha elinye kuhlu uma umdwebo usebenzisa elawo. Ukukhetha kugcinwa ngegama lefayela kulo mshini, ngakho ukuvula kabusha kuqala ngalo thegi elifanayo. Ithegi oliliqokile lithatha namanombolo aphelele njengamazinga futhi.
4. Cindezela {{ui:Engeza}}. Amaphoyinti anikezwa izinombolo ngemva kwenombolo ephezulu kuphrojekthi, ngayinye ichazwe ngongqimba wayo (noma ibhulokhi yayo), nokuphakama kuguqulwe kube yizinyunithi zephrojekthi njengakho konke okunye komdwebo. Konke lokhu kungisinyathelo esisodwa: {{key:Mod+Z}} isusa amaphoyinti.

Umbhalo uhlala endaweni yawo yokufaka (noma indawo yokuhlanganisa uma unayo). Umbhalo ngaphakathi kwamabhulokhi awufundwa, futhi umdwebo awushintshwa.

## Ukuhlola

Ukuhlola kwenziwa kulokho okuzolethwa futhi kudwelela okutholakele, umugqa munye ngohlobo ngalunye lwenkinga:

| Ithi | Okusho |
|---|---|
| **Izinyunithi azichazwanga** | Umdwebo awuchazi izinyunithi zawo, ngakho izinombolo zawo zifundwa njengezinyunithi zephrojekthi. Hlola ibanga elilodwa oliyaziyo. |
| **Izinyunithi zishintshiwe** | Izinyunithi zomdwebo zihlukile kwezephrojekthi futhi ziyalinganiswa (isaziso, hhayi iphutha). |
| **Idatha ihlanganisa … km** noma **… m** | Ububanzi bungaphezu kuka-200 km noma buncane kuhhafu wemitha, okuvame ukusho iyunithi engafanele (amamilimitha afundwa njengamamitha, noma kuphambene). |
| **Akukho hlelo lokuxhumanisa** | Iphrojekthi ayinalo. Yisexwayiso uma idatha ikude no-zero, njengoba kwenza amakhoordinethi endiza yesifunda noma egridini kazwelonke. Bona [Amasistimu okuxhumanisa](topic:coordinate-systems). |
| **Kude nemvelaphi** | Idatha ikude ngaphezu kuka-100 km kusukela ku-zero. Ukude no-zero, imibonho ye-3D nokuthunyelwa kuyalahleka ukunemba futhi kuyanyakaza. |
| **Ungqimba wamakhontuwa … awunawo ukuphakama** | Ungqimba obizwa njengamakhontuwa (TOPO, CONT, CNTR, CONTOUR) ubamba imigqa ebude be-0, ngakho umhlaba owakhiwe kuyo wawuyoba yisicaba. |
| **Amazinga angu-0 ngokuqondile** | Amanye amazinga angu-0 kuyilapho izinga ejwayelekile likude nalo: mhlawumbe kuntuleka amaphakamo. |
| **Amazinga akude nakwamanye** | Amanye amazinga ahlala kude kakhulu nakwamanye (atholwa emaphakathini wawo wonke amazinga, ngakho isayithi elithambekile elinobubanzi obukhulu alibhalwa), noma ngaphezu kuka-9,000 m noma ngaphansi kuka--11,000 m. |
| **Amaphoyinti phezu kwephoyinti elinye** | Amaphoyinti amabili endaweni efanayo nezinga elifanayo, noma amazinga ahlukile. |

Uma ucindezela {{ui:Engeza}}, imigqa efanayo idlulela ku-**Izinkinga**, eyodwa ngohlobo ngalunye, negama lefayela, ukuze ukwazi ukubuyela kuzo. Ukuhlola kwahlulela umdwebo; akushintshi lutho kuwo, futhi akukuvimbi ekusebenziseni umdwebo.

:::tip
Uma ukuhlola kuthi amakhontuwa asicaba ku-0 kanti kukhona amazinga abhalwe njengombhalo, wathathe amazinga njengamaphoyinti okuhlola: avame ukuphatha amaphakamo angempela amakhontuwa angawanaki.
:::

## Okungahloliwe

Ukuhlola akuqhathanisi umdwebo nesivivinyo sesibili, futhi akukwazi ukutshela ukuthi umdwebo usesistimini yini yokuxhumanisa: ushoyo kuphela ukuthi akukho esethiwe.

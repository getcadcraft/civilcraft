Адзіночныя клавішы-літары працуюць, калі вы не друкуеце ў полі. Спалучэнні з {{key:Mod}} выкарыстоўваюць Command на Mac і Ctrl на іншых. Гл. таксама [Клавішы ў браўзеры](common:keys).

## Файлы і рэдагаванне

| Клавіша | Дзеянне |
|---|---|
| {{key:Mod+O}} | Адкрыць файл кропак, LandXML або праект |
| {{key:Mod+S}} | Захаваць праект (спампоўвае файл `.civilcraft.json`) |
| {{key:Mod+P}} | Вывесці план у PDF (адкрываецца дыялог вываду, а не друк браўзера) |
| {{key:Mod+Z}} | Адрабіць |
| {{key:Mod+Y}} | Паўтарыць |
| {{key:Delete}} | Выдаліць выбраныя кропкі здымкі, трасу, пляцоўку, канструкцыю, трубу або PVI |
| {{key:Mod+C}} | Капіяваць выбраныя кропкі здымкі (таксама як радкі кропак для табліцы) |
| {{key:Mod+X}} | Вырэзаць выбраныя кропкі здымкі |
| {{key:Mod+V}} | Уставіць кропкі: яны ідуць за паказальнікам, пстрыкніце, куды яны павінны ісці |
| {{key:Mod+Shift+V}} | Уставіць на месца: па ўласных каардынатах кропак |
| {{key:Mod+D}} | Дубляваць выбраныя кропкі: копія ідзе за паказальнікам |
| {{key:Mod+A}} | Выбраць усе кропкі здымкі |
| {{key:Esc}} | Зняць выбар (і адмяніць уставу) |

{{key:Mod+S}}, {{key:Mod+O}} і {{key:Mod+P}} працуюць нават тады, калі вы друкуеце ў полі. {{key:Mod+Z}} і {{key:Mod+Y}} у тэкставым полі адмяняюць ваш друк, як звычайна, і так жа {{key:Mod+C}}, {{key:Mod+X}}, {{key:Mod+V}} і {{key:Mod+A}}: у полі яны капіююць, вырэзаюць, уставяць і выбіраюць яго тэкст. Калі тэкст выбраны на старонцы (у панэлі), {{key:Mod+C}} капіюе гэты тэкст. {{key:Mod+Shift+Z}} у CivilCraft нічога не робіць: выкарыстоўвайце {{key:Mod+Y}} або кнопку {{ui:Паўтарыць}}.

:::mac
Клавіша на Mac з надпісам **delete** для браўзера — гэта {{key:Backspace}}. Каб выдаліць выбранае, націсніце {{key:Delete}} (Fn і delete) або абярыце {{ui:Выдаліць}} у меню {{ui:Яшчэ}} на панэлі інструментаў.
:::

## Інструменты

| Клавіша | Інструмент |
|---|---|
| {{key:V}} | {{ui:Выбраць}} |
| {{key:M}} | {{ui:Вымерыць}}: адлегласці, плошчы і ўхілы на плане ([Вымярэнне](topic:measure)) |
| {{key:A}} | {{ui:Траса}} |
| {{key:G}} | {{ui:Пляцоўка}} |
| {{key:P}} | {{ui:Трубы}} |
| {{key:B}} | {{ui:Лінія разрыву}} |
| {{key:O}} | {{ui:Мяжа}} |
| {{key:R}} | Паказаць або схаваць профільны выгляд |
| {{key:I}} | Уключыць або выключыць {{ui:Дадаць PVI}} (адкрывае профільны выгляд, калі ён закрыты) |
| {{key:F}} | {{ui:Па памеры}}: паказаць усё |
| {{key:D}} | {{ui:3D}}: паказаць участак у 3D або вярнуцца да плана |
| {{key:E}} | Паказаць або схаваць ухілы і адзнакі ўздоўж кожнай лініі рэльефу (толькі на экране) |

Націсненне клавішы актыўнага інструмента яшчэ раз вяртае да {{ui:Выбраць}}. Літары з Shift нічога не робяць.

## Пры маляванні

| Клавіша | Дзеянне |
|---|---|
| {{key:Enter}} | Завяршыць трасу, пляцоўку, ланцуг труб, лінію разрыву або мяжу |
| {{key:Backspace}} | Выдаліць апошнюю пстрыкнутую кропку |
| {{key:C}} | Лінія рэльефу: уключыць або выключыць дугі (пасля вяршыні пстрыкніце кропку на крывой, потым яе канец) |
| {{key:Esc}} | Скасаваць маляванне (або ўстаўку); націснуты яшчэ раз (або калі нічога не намалявана), вярнуцца да {{ui:Выбраць}} і ачысціць выбар |

## Від плана

| Клавіша або дзеянне | Вынік |
|---|---|
| Колца | Маштаб павялічваецца або памяншаецца ў месцы паказальніка |
| Перацягванне па пустой прасторы | Панарамаванне (у любым інструменце; кароткі пстрык усё яшчэ пстрыкае; з націснутым {{key:Shift}} малюецца блок выбару) |
| Перацягванне сярэдняй кнопкай | Панарамаванне |
| Перацягванне правай кнопкай | Панарамаванне (меню не адкрываецца) |
| {{key:Space}} і перацягванне | Панарамаванне |
| Пстрык | Выбраць (з {{ui:Выбраць}}) або паставіць кропку (з інструментам малявання) |
| {{key:Shift}} і пстрык | Дадаць кропку здымкі ў выбар або выняць яе |
| {{key:Shift}} і перацягванне | Намаляваць блок: кропкі здымкі ўнутры дадаюцца ў выбар. Абвядзіце іх для [лассо](topic:lasso-selection) |
| {{key:Space}} падчас малявання лассо | Акно, потым перасячэнне, потым агароджа |
| Пстрык падчас уставы | Паставіць устаўленыя кропкі там ({{key:Enter}} ставіць іх па ўласных каардынатах) |
| Перацягванне ручкі | Перамясціць PI, вугал пляцоўкі або канструкцыю (адзін крок адмены) |
| {{key:Up}} {{key:Down}} {{key:Left}} {{key:Right}} | Панарамаванне, калі план у фокусе (спачатку пстрыкніце па ім) |
| {{key:Plus}} і {{key:Minus}} | Павялічыць і паменшыць у цэнтры, калі план у фокусе |

Клавіша = павялічвае, як {{key:Plus}}, таму Shift не патрэбны.

## Профільны выгляд

| Дзеянне | Вынік |
|---|---|
| Пстрык з уключаным {{ui:Дадаць PVI}} | Дадаць PVI там |
| Пстрык па PVI | Выбраць яго |
| Перацягванне PVI | Перамясціць (адзін крок адмены) |
| {{key:Delete}} або {{key:Backspace}} | Выдаліць выбраны PVI ({{key:Backspace}} толькі калі профільны выгляд у фокусе) |

Профільны выгляд не змяняе маштаб і не панарамуе.

## Экран і даведка

| Клавіша | Дзеянне |
|---|---|
| {{key:F1}} | Адкрыць або закрыць гэту даведку (бакавая панэль); {{ui:Даведка}} на панэлі праграмы робіць тое самае |
| {{key:Esc}} | Закрыць панэль даведкі, калі яна адкрыта |
| {{key:Ctrl+Shift+F}} | Пераключаць рэжымы экрана: поўны экран, поўны экран са схаванымі панэлямі, звычайны |
| {{key:Esc}} | Выйсці з поўнаэкраннага рэжыму (уласная клавіша браўзера) |

{{key:F1}} трапляе ў даведку раней, чым CivilCraft яго бачыць, таму працуе ў любым інструменце. На большасці клавіятур Mac націсніце fn разам з F1 або пстрыкніце {{ui:Даведка}}. {{key:Ctrl+Shift+F}} выкарыстоўвае клавішу Control на кожнай платформе, у тым ліку на Mac. Гл. [Выкарыстанне даведкі](common:help) аб тым, як шукаць у гэтай даведцы.

## Мыш, сэнсарная панэль і сэнсарны экран

:::mouse
- Колца павялічвае ў месцы паказальніка. Мыш з вольна круцячыся колцам павялічвае хутка: рабіце кароткія павароты.
- Панарамаванне любым перацягваннем па пустой прасторы, сярэдняй кнопкай, правай кнопкай або {{key:Space}} і перацягваннем.
:::

:::mac
На сэнсарнай панэлі Mac:

- Прагортванне двума пальцамі **павялічвае** (не панарамуе), і шчыпок таксама павялічвае.
- Каб панарамаваць, націсніце і перацягніце па пустой прасторы адным пальцам або затрымайце {{key:Space}} і перацягніце.
- Пстрык двума пальцамі (правы пстрык) меню не адкрывае і сам па сабе нічога не робіць.
:::

:::touch
На сэнсарным экране:

- Першае дакрананне робіць кнопкі і радкі меню памерам з палец.
- Націсніце, каб выбраць або паставіць кропку; перацягванне адным пальцам па пустой прасторы панарамуе. Дакрананне можа крыху калыхнуцца: панарамаванне пачынаецца толькі тады, калі палец зрушыцца прыблізна на 10 пікселяў.
- Два пальцы шчыпаюць для павелічэння і рухаюцца разам для панарамавання.
- Перацягвайце ручку або PVI адным пальцам. Вакол ручак — зона ў шырыню пальца.
- Пакуль вы малюеце трасу, пляцоўку, лінію разрыву, мяжу, ланцуг труб, лінію рэльефу або парцэлу, над планам з’яўляецца панэль з {{ui:Завяршыць}} ({{key:Enter}}), {{ui:Адмяніць кропку}} ({{key:Backspace}}) і {{ui:Скасаваць}} ({{key:Esc}}). Доўгае націсканне (паўсекунды без руху) таксама завяршае.
- У {{ui:Выбраць}} доўгае націсканне на кропку здымкі дадае яе ў выбар або выдае, як {{key:Shift}}+пстрык.
- У 3D-выглядзе адзін палец круціць, два шчыпаюць і панарамуюць, а дакрананне выбірае.
- На сэнсарным экране няма наводкі курсора, таму паказанні ў радку стану абнаўляюцца толькі пакуль палец націснуты.
:::

## Клавішы браўзера, якія маюць перавагу

Некаторыя клавішы належаць браўзеру і ніколі не даходзяць да CivilCraft, напрыклад {{key:Mod+W}} (закрыць укладку), {{key:Mod+T}} (новая ўкладка), {{key:Mod+N}} (новае акно) і {{key:F11}} (поўны экран у браўзерах Windows і Linux). CivilCraft іх не выкарыстоўвае. Калі спалучэнне замест гэтага адкрывае нешта ў браўзеры, пстрыкніце план адзін раз, каб старонка атрымала фокус, і паспрабуйце зноў.

## Дзе знаходзіцца перамяшчэнне

Каманды «Перамясціць» няма: абярыце {{ui:Выбраць}} і перацягніце кропку або вяршыню, або змяніце іх каардынаты ў {{ui:Уласцівасці}}. Гл. [Рэдагаванне кропак](topic:edit-points).

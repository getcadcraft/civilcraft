CivilCraft знаходзіцца на ранім этапе. Гэтая старонка пералічвае, чаго бягучая зборка не робіць, каб вы не шукалі гэтага. Нічога тут не абяцаецца да пэўнай даты.

## Кропкі

| Яшчэ не зроблена | Замест гэтага, сёння |
|---|---|
| Даданне другога файла кропак да першага | Спачатку злучыце файлы ў тэкставым рэдактары або электроннай табліцы |
| Экспарт тэкставага файла кропак | Экспартуйце LandXML (кропкі выходзяць як CgPoints), выкарыстоўвайце GIS {{ui:Export}} (кропкі з палямі P, N, E, Z і D) або {{ui:Copy}} кропкі ў электронную табліцу |
| Стылі падпісаў кропак, сімвалы для кожнага ключа апісання, крывыя (дугі) з кодаў ліній, файл ключоў апісання для агульнага выкарыстання паміж праектамі | Падпісы паказваюць нумар, адзнаку і апісанне, або менш ([Налады CivilCraft](topic:settings)); ключы захоўваюцца ў файле праекта |
| Пераўтварэнне адзінак | Пераўтварыце файл перад імпартам; **{{ui:Units}}** толькі перапазначае |

## What you will learn

What happens to a project while several people work on it at the same time. CadCraft Studio starts and joins the Live TeamWork session (Share live, Join); this page is about the project itself.

## Everyone works at once

The host's points and design come to everyone who joins. Edit points, draw alignments, pads, feature lines and parcels as usual. Your own edits show at once; other people's appear a moment after they make them.

- **Points** merge one by one: two people moving two points both keep their changes.
- **Alignments, pads, feature lines and parcels** merge per object and setting; the same setting goes to the later change.
- **The surface** is built in every window from the same points and breaklines, so contours and volumes agree.

Not shared in a session: a surface loaded from a grid file, GIS layers' features, map pictures and grid shift files. They stay in the window that opened them.

## See each other

Everyone in the session has a color of their own. On the plan you see each person's pointer as an arrow in their color with their name beside it, and a dashed box in their color round the points and the object they have picked. While the 3D view is open over the plan, the pointers wait until you close it.

Pointers, names and selections are only for the session: they are never saved in the file and never go into anyone's undo. They glide to where each person is, so they stay smooth on a slow connection too.

## Undo undoes your own work

{{key:Mod+Z}} undoes your own last edit and leaves everyone else's alone. When someone changed the same thing since, nothing is undone and the status bar says who.

## Join from a browser

A teammate without Studio can scan the picture under the host's code with a phone, tablet or computer on the same network. CivilCraft opens in the browser and fills with the host's project once the host lets you in. An invite link lets someone join from another network: the host needs a Team Cloud Plan seat for the app, everyone else joins free, and the link works only while the host's session is open.

## When the session ends

Only the host saves the project. Everyone else keeps an unsaved copy: save it if you want to keep it.

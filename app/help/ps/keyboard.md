یو توري کیلي هغه وخت کار کوي کله چې په یوه بکس کې نه لیکئ. هغه شارټکټونه چې {{key:Mod}} لري، په Mac کې Command او نورو ځایونو کې Ctrl کاروي. هم وګورئ [په براوزر کې کیلي](common:keys).

## فایلونه او سمول

| کیلي | عمل |
|---|---|
| {{key:Mod+O}} | د ټکو فایل، LandXML یا پروژه پرانیزئ |
| {{key:Mod+S}} | پروژه خوندي کړئ (یو `.civilcraft.json` فایل ډاونلوډ کوي) |
| {{key:Mod+P}} | پلان په PDF کې چاپ کړئ (د چاپ ډیالوګ پرانیزي، د براوزر چاپ نه) |
| {{key:Mod+Z}} | بېرته کول |
| {{key:Mod+Y}} | بیا کول |
| {{key:Delete}} | ټاکل شوي سروې ټکي، الاینمنټ، پیډ، جوړښت، نل یا PVI ړنګ کړئ |
| {{key:Mod+C}} | ټاکل شوي سروې ټکي کاپي کړئ (د سپریډ شیټ لپاره د ټکو قطارونو په توګه هم) |
| {{key:Mod+X}} | ټاکل شوي سروې ټکي پرې کړئ |
| {{key:Mod+V}} | ټکي سرېښئ: دوی د اشاره ګر تعقیبوي، هغه ځای کلیک وکړئ چېرې چې ځي |
| {{key:Mod+Shift+V}} | په ځای کې سرېښل: د ټکو په خپلو همغړیو کې |
| {{key:Mod+D}} | ټاکل شوي ټکي دوپلیکېټ کړئ: یوه کاپي اشاره ګر تعقیبوي |
| {{key:Mod+A}} | ټول سروې ټکي وټاکئ |
| {{key:Esc}} | هېڅ مه ټاکئ (او سرېښل لغوه کړئ) |

{{key:Mod+S}}، {{key:Mod+O}} او {{key:Mod+P}} حتی هغه وخت کار کوي چې تاسو په بکس کې لیکئ. {{key:Mod+Z}} او {{key:Mod+Y}} په متن بکس کې ستاسو لیکنه بېرته اخلي یا بیا کوي، لکه معمول، او همداسې {{key:Mod+C}}، {{key:Mod+X}}، {{key:Mod+V}} او {{key:Mod+A}}: په بکس کې دوی متن کاپي، پرې، سرېښي او ټاکي. کله چې په پاڼه کې متن ټاکل شوی وي (په یوه پینل کې)، {{key:Mod+C}} هغه متن کاپي کوي. {{key:Mod+Shift+Z}} په CivilCraft کې هېڅ نه کوي: {{key:Mod+Y}} یا د {{ui:Redo}} تڼۍ وکاروئ.

:::mac
په Mac کیبورډ کې هغه کیلي چې **delete** لیبل لري، براوزر ته {{key:Backspace}} ده. د ټاکنې د ړنګولو لپاره {{key:Delete}} (Fn او delete) کېکاږئ، یا د وسیلې بار د {{ui:More}} مینو کې {{ui:Delete}} وټاکئ.
:::

## وسیلې

| کیلي | وسیله |
|---|---|
| {{key:V}} | {{ui:Select}} |
| {{key:M}} | {{ui:Measure}}: واټنونه، مساحتونه او ډهلوانونه په پلان کې ([اندازه کول](topic:measure)) |
| {{key:A}} | {{ui:Alignment}} |
| {{key:G}} | {{ui:Pad}} |
| {{key:P}} | {{ui:Pipes}} |
| {{key:B}} | {{ui:Breakline}} |
| {{key:O}} | {{ui:Boundary}} |
| {{key:R}} | د پروفایل لید ښکاره یا پټ کړئ |
| {{key:I}} | {{ui:Add PVIs}} چالان یا بند کړئ (که پروفایل لید بند وي، پرانيزي) |
| {{key:F}} | {{ui:Fit}}: هرڅه ښکاره کړئ |
| {{key:D}} | {{ui:3D}}: ساېټ په 3D کې ښکاره کړئ، یا بېرته پلان ته ولاړ شئ |
| {{key:E}} | د هرې فیچر کرښې په اوږدو کې ډهلوانونه او لوړوالي ښکاره یا پټ کړئ (یوازې په پرده کې) |

د فعالې وسیلې کیلي بیا کېکاږل تاسو بېرته {{ui:Select}} ته وړي. د Shift سره توري هېڅ نه کوي.

## د ترسیم پر مهال

| کیلي | عمل |
|---|---|
| {{key:Enter}} | الاینمنټ، پیډ، نل لاین، بریک لاین یا پوله بشپړه کړئ |
| {{key:Backspace}} | وروستی کلیک شوی ټکی لرې کړئ |
| {{key:C}} | د فیچر کرښه: قوسونه چالان یا بند کړئ (له یو راس وروسته، په منحنۍ یو ټکی کلیک وکړئ، بیا یې پای) |
| {{key:Esc}} | ترسیم لغوه کړئ (یا سرېښل)؛ بیا کېکاږل، یا که هیڅ ترسیم نه وي، {{ui:Select}} ته ولاړ شئ او ټاکنه پاکه کړئ |

## د پلان لید

| کیلي یا عمل | پایله |
|---|---|
| څرخ | د اشاره ګر په ځای داخل یا بهر زوم کوي |
| په خالي ځای کې راکش | لید خوځول (په هره وسیله کې؛ لنډ کلیک لاهم کلیک کوي؛ د {{key:Shift}} سره یو د ټاکنې بکس ترسیموي) |
| منځنۍ تڼۍ سره راکش | لید خوځول |
| ښي تڼۍ سره راکش | لید خوځول (هېڅ مینو نه پرانيزي) |
| {{key:Space}} او راکش | لید خوځول |
| کلیک | ټاکل (د {{ui:Select}} سره)، یا یو ټکی ږدي (د ترسیم وسیلې سره) |
| {{key:Shift}} او کلیک | یو سروې ټکی د ټاکنې ته زیات کړئ یا له هغې لرې کړئ |
| {{key:Shift}} او راکش | بکس راکش کړئ: په هغه کې سروې ټکي د ټاکنې ته زیاتېږي. دوران ورکړئ ترڅو [لاسو](topic:lasso-selection) وکاروئ |
| {{key:Space}} د لاسو ترسیم پر مهال | کړکۍ، بیا تقاطع، بیا باړه |
| کلیک د پېسټ پر مهال | پېسټ شوي ټکي هلته ږدي ({{key:Enter}} دوی د خپلو همغړیو سره ږدي) |
| یو ګریپ راکش | PI، د پیډ ګوټ یا جوړښت حرکت کړئ (یو بېرته اخیستنه) |
| {{key:Up}} {{key:Down}} {{key:Left}} {{key:Right}} | لید خوځول، کله چې پلان تمرکز ولري (لومړی یې کلیک کړئ) |
| {{key:Plus}} او {{key:Minus}} | په منځ کې داخل او بهر زوم، کله چې پلان تمرکز ولري |

د = کیلي د {{key:Plus}} په څېر زوم کوي، نو تاسو ته Shift ته اړتیا نشته.

## د پروفایل لید

| عمل | پایله |
|---|---|
| کلیک د {{ui:Add PVIs}} سره چالان | هلته یو PVI زیات کړئ |
| د PVI کلیک | هغه وټاکئ |
| د PVI راکش | حرکت یې ورکړئ (یو بېرته اخیستنه) |
| {{key:Delete}} یا {{key:Backspace}} | ټاکل شوی PVI لرې کړئ ({{key:Backspace}} یوازې کله چې پروفایل لید تمرکز ولري) |

پروفایل لید نه زوم کوي او نه لید خوځوي.

## پرده او مرسته

| کیلي | عمل |
|---|---|
| {{key:F1}} | دا مرسته (د اړخ پینل) پرانیزئ یا بند کړئ؛ {{ui:Help}} په اپ بار کې همدا کار کوي |
| {{key:Esc}} | که خلاصه وي، د مرستې پینل بند کړئ |
| {{key:Ctrl+Shift+F}} | د پردې حالتونه وګرځوئ: بشپړه پرده، بشپړه پرده د بارونو پټ سره، عادي |
| {{key:Esc}} | بشپړه پرده پرېږدئ (د براوزر خپل کیلي) |

{{key:F1}} مخکې له دې چې CivilCraft یې وویني مرستې ته رسي، نو په هره وسیله کې کار کوي. په ډېرو Mac کیبورډونو کې، fn او F1 یوځای کېکاږئ، یا {{ui:Help}} کلیک وکړئ. {{key:Ctrl+Shift+F}} په هرې پلیټفارم کې د Control کیلي کاروي، د Mac په ګډون. د دې مرستې د لټولو لپاره [د مرستې کارول](common:help) وګورئ.

## موږک، ټچ پیډ او لمس

:::mouse
- څرخ د اشاره ګر په ځای زوم کوي. یو موږک چې آزاد څرخېدونکی څرخ لري ګړندی زوم کوي: لنډ حرکتونه ورکړئ.
- په خالي ځای کې هر راکش، منځنۍ تڼۍ، ښي تڼۍ، یا {{key:Space}} او راکش سره لید خوځوئ.
:::

:::mac
د Mac ټچ پیډ کې:

- دوه ګوتې سکرول **زوم** کوي (لید نه خوځوي)، او نیول هم زوم کوي.
- د لید خوځولو لپاره، په خالي ځای کې په یوه ګوته فشار ورکړئ او راکش کړئ، یا {{key:Space}} ونیسئ او راکش کړئ.
- د دوه ګوتو کلیک (ښي کلیک) هېڅ مینو نه پرانيزي او په خپله هېڅ نه کوي.
:::

:::touch
د ټچ سکرین کې:

- لومړی لمس تڼۍ او د مینو قطارونه د ګوتې اندازې ته جوړوي.
- د ټاکلو یا د ټکي ځای پرځای کولو لپاره ټک وکړئ؛ په خالي ځای کې یوه راکښ ګوته لید خوځوي. ټک کېدای شي یو څه وخوځېږي: یوازې هغه وخت لید خوځوي چې ګوته شاوخوا 10 pixels وخوځي.
- دوه ګوتې نیولو سره زوم کوي او یوځای حرکت کولو سره لید خوځوي.
- یوه ګوته ګریپ یا PVI راکش کړئ. ګریپونو شاوخوا د یوې ګوتې عرض هدف دی.
- کله چې الاینمنټ، پیډ، بریک لاین، پوله، نل لاین، فیچر کرښه یا پارسل ترسیموئ، د پلان پر سر یو بار {{ui:Finish}} ({{key:Enter}})، {{ui:Undo point}} ({{key:Backspace}}) او {{ui:Cancel}} ({{key:Esc}}) وړاندې کوي. یو اوږد فشار (نیم ثانیه بې حرکته) هم بشپړوي.
- په {{ui:Select}} کې، یو اوږد فشار په سروې ټکي د ټاکنې ته زیاتوي یا له هغې لرې کوي، لکه {{key:Shift}}+کلیک.
- د 3D لید کې، یوه ګوته ګرځي، دوه نیسي او لید خوځوي، او ټک انتخاب کوي.
- په ټچ کې هوور نشته، نو د حالت بار لوستل یوازې هغه وخت تازه کېږي چې ګوته ښکته وي.
:::

## د براوزر کیلي چې ګټي

ځینې کیلي د براوزر دي او هېڅکله CivilCraft ته نه رسي، د مثال په توګه {{key:Mod+W}} (ټب تړل)، {{key:Mod+T}} (نوی ټب)، {{key:Mod+N}} (نوې کړکۍ) او {{key:F11}} (بشپړه پرده په Windows او Linux براوزرونو کې). CivilCraft دوی نه کاروي. که شارټکټ په براوزر کې یو څه خلاص کړي، یو ځل پلان کلیک کړئ ترڅو پاڼه تمرکز ولري، او بیا هڅه وکړئ.

## Move چېرې دی

د Move کمانډ نشته: {{ui:Select}} وټاکئ او یو ټکی یا راس راکش کړئ، یا د {{ui:Properties}} کې د هغې همغړۍ سمه کړئ. وګورئ [ټکي سمول](topic:edit-points).

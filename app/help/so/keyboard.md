Furayaasha xarfa keliya ayaa shaqeeya marka aadan ku qorin sanduuq. Gaabinta leh {{key:Mod}} waxay isticmaalaan Command Mac-ka iyo Ctrl meelaha kale. Eeg sidoo kale [Furayaasha browser-ka](common:keys).

## Faylasha iyo tafatirka

| Furaha | Ficilka |
|---|---|
| {{key:Mod+O}} | Fur fayl barta, LandXML ama mashruuc |
| {{key:Mod+S}} | Kaydi mashruuca (wuxuu soo dejiyaa fayl `.civilcraft.json`) |
| {{key:Mod+P}} | Qorshaha ku rasm PDF (wuxuu furaa wada-hadalka rasmka, ma aha daabacaadda browser-ka) |
| {{key:Mod+Z}} | Ka noqo |
| {{key:Mod+Y}} | Samee mar kale |
| {{key:Delete}} | Tirtir barooyinka sahanka la doortay, xariiqda, padka, qaabka, tuubada ama PVI |
| {{key:Mod+C}} | Koobiyee barooyinka sahanka la doortay (sidoo kale safafka barta ee spreadsheet-ka) |
| {{key:Mod+X}} | Jar barooyinka sahanka la doortay |
| {{key:Mod+V}} | Dhaji barooyinka: waxay raacaan taliska, riix meesha ay tagayaan |
| {{key:Mod+Shift+V}} | Dhaji meeshaas: isku-xidhka barooyinka laftooda |
| {{key:Mod+D}} | Nuqul ka samee barooyinka la doortay: nuqulku wuxuu raacaa taliska |
| {{key:Mod+A}} | Dooro barooyinka sahan kasta |
| {{key:Esc}} | Midna ma dooro (oo joojin dhajinta) |

{{key:Mod+S}}, {{key:Mod+O}} iyo {{key:Mod+P}} way shaqeeyaan xitaa intaad sanduuq ku qorayso. {{key:Mod+Z}} iyo {{key:Mod+Y}} sanduuqa qorista waxay ka noqdaan qorista aad qortay halkii, sida caadiga ah, sidaas oo kale {{key:Mod+C}}, {{key:Mod+X}}, {{key:Mod+V}} iyo {{key:Mod+A}}: sanduuqa waxay nuqulaan, jaraan, dhajiyaan oo dooran qoraalkiisa. Qoraal la doortay bogga (panel-ka) {{key:Mod+C}} wuxuu nuqulaa qoraalkaas. {{key:Mod+Shift+Z}} wax ma sameeyo CivilCraft: isticmaal {{key:Mod+Y}} ama badhanka {{ui:Samee mar kale}}.

:::mac
Furaha Mac ee lagu calaamadeeyay **delete** browser-ka wuxuu u yahay {{key:Backspace}}. Si aad u tirtirto xulasho, riix {{key:Delete}} (Fn iyo delete), ama dooro {{ui:Tirtir}} menu-ka {{ui:Wax dheeraad ah}} ee qalabka sare.
:::

## Intii aad sawirayso

| Furaha | Ficilka |
|---|---|
| {{key:Enter}} | Dhammee jid-hagaha, padka, tuubada, xariiqa jabinta ama xadka |
| {{key:Backspace}} | Ka saar barta ugu dambaysa ee la riixay |
| {{key:C}} | Xariiqda sifada: shid ama dami qalooca (ka dib geesta, riix barta qalooca, kadibna dhamaadkiisa) |
| {{key:Esc}} | Jooji sawirka (ama dhajinta); mar labaad la riixo (ama wax la sawirin), dib u noqo {{ui:Dooro}} oo nadiifi xulashada |

## Muuqaalka qorshaha

| Furaha ama ficil | Natiija |
|---|---|
| Wheel-ka | Weynee ama yaree taliska ku yaal |
| Jiid meel bannaan | Dhaqaaqi (qalab kasta; riix gaaban wali waa riix; {{key:Shift}} oo la hayo wuxuu sawiraa sanduuq xulasho) |
| Jiid badhanka dhexe | Dhaqaaqi |
| Jiid badhanka midig | Dhaqaaqi (liis ma furmo) |
| {{key:Space}} iyo jiid | Dhaqaaqi |
| Riix | Dooro (adiga oo {{ui:Dooro}}), ama dhig barta (qalab sawir) |
| {{key:Shift}} iyo riix | Ku dar barta sahanka xulashada, ama ka saar |
| {{key:Shift}} iyo jiid | Sawir sanduuq: barooyinka sahanka gudahooda waa lagu daraa xulashada. Ku jiid goobahooda si aad u hesho [lasso](topic:lasso-selection) |
| {{key:Space}} intii lasso la sawirayo | Daaqad, markaas isgoyn, markaas xayndaab |
| Riix intii la dhajinayo | Dhig barooyinka dhajiska meeshaas ({{key:Enter}} wuxuu dhigaa isku-xidhkooda laftooda) |
| Jiid gripka | Dhaqaaqi PI, geesta padka ama qaabka (hal tallaabo ka noqosho) |
| {{key:Up}} {{key:Down}} {{key:Left}} {{key:Right}} | Dhaqaaqi, marka qorshuhu xoogga leeyahay (marka hore riix) |
| {{key:Plus}} iyo {{key:Minus}} | Weynee iyo yaree dhexda, marka qorshuhu xoogga leeyahay |

Furaha = wuxuu weynaysaa sida {{key:Plus}}, sidaas darteed uma baahnid Shift.

## Muuqaalka profile

| Ficil | Natiija |
|---|---|
| Riix {{ui:Ku dar PVI-yo}} oo shidan | Ku dar PVI meeshaas |
| Riix PVI | Dooro |
| Jiid PVI | Dhaqaaqi (hal tallaabo ka noqosho) |
| {{key:Delete}} ama {{key:Backspace}} | Ka saar PVI la doortay ({{key:Backspace}} kaliya marka muuqaalka profile-ku xoogga leeyahay) |

Muuqaalka profile-ku ma weynaado ma dhaqaaqo.

## Shaashadda iyo caawimaadda

| Furaha | Ficilka |
|---|---|
| {{key:F1}} | Fur ama xir caawimaadan (dhinaca); {{ui:Caawimaad}} qalabka sare wuxuu sameeyaa isla |
| {{key:Esc}} | Xir panel-ka caawimaadda marka uu furan yahay |
| {{key:Ctrl+Shift+F}} | Wareeg hab-shaashadaha: shaashad buuxa, shaashad buuxa oo xariijimaha qarsan, caadi |
| {{key:Esc}} | Ka bax shaashad buuxa (furaha browser-ka laftiisa) |

{{key:F1}} wuxuu gaaraa caawimaadda ka hor inta CivilCraft aanu arkin, sidaas darteed waxay shaqeysaa qalab kasta. Kiiboodhka Mac badankiisa, riix fn oo F1, ama riix {{ui:Caawimaad}}. {{key:Ctrl+Shift+F}} wuxuu isticmaalaa furaha Control nidaam kasta, oo ay ku jiro Mac. Eeg [Isticmaalka caawimaadda](common:help) si aad uga raadiso caawimaadan.

## Mouse, trackpad iyo taabasho

:::mouse
- Wheel-ku wuxuu weynaysaa taliska hortiisa. Mouse oo wheel-kiisu si xor ah u wareegaayo wuu si degdeg ah u weynaysaa: u sii wareegyo gaaban.
- Dhaqaaqi jiid kasta oo meel bannaan ah, badhanka dhexe, badhanka midig, ama {{key:Space}} iyo jiid.
:::

:::mac
Trackpad-ka Mac-ka:

- Jiidista laba farood **weynaysa** (ma dhaqaaqo), iyo cabbirka ku-qabsashada ayaa sidoo kale weynaysa.
- Si aad u dhaqaaqdo, riix oo jiid meel bannaan oo hal farood, ama hay {{key:Space}} oo jiid.
- Riix laba farood (riix midig) ma furo liis, mana samayso wax keligiis.
:::

:::touch
Shaashadda taabashada:

- Taabashada koowaad badhamada iyo safafka liiska waxay noqdaan cabbir farood.
- Taabo si aad u doorato ama aad u dhigto barta; hal farood oo jiidaysa meel bannaan wuu dhaqaajiyaa. Taabashadu way ka gariiri kartaa yar: waxay dhaqaajinaysaa kaliya marka farooshu ku dhaqaaqo qiyaastii 10 pixels.
- Laba farood ku qabso si aad u weynaysid, oo ku dhaqaaq wada si aad u dhaqaajiso.
- Jiid grip ama PVI hal farood. Gripku wuxuu qaadaa ballaca farood oo ku wareegsan.
- Intaad sawirayso jid-hagaha, padka, xariiqa jabinta, xadka, tuubada, xariiqa sifada ama parcel-ka, bar ku yaal qorshaha ayaa soo bandhigaya {{ui:Dhammee}} ({{key:Enter}}), {{ui:Ka noqo dhibicda}} ({{key:Backspace}}) iyo {{ui:Jooji}} ({{key:Esc}}). Riix dheer (nus ilbiriqsi oo aan dhaqaajin) ayaa sidoo kale dhammeeya.
- {{ui:Dooro}} dhexdeeda, riix dheer barta sahanka ayaa ku darta xulashada, ama ka saara, sida {{key:Shift}}+riix sameeyo.
- Muuqaalka 3D, hal farood wareegi, laba farood ku qabso oo dhaqaajiyo, taabashadu waxay doortaa.
- Taabashada ma jirto hover, sidaas darteed akhrinta sadarka xaaladda waxay cusboonaysiiyaa kaliya intaad farooshu hoos u taagan tahay.
:::

## Furayaasha browser-ku ku guuleysto

Furayaasha qaarkood waxay yihiin browser-ka oo marna CivilCraft ma gaaraan, tusaale ahaan {{key:Mod+W}} (xir tab), {{key:Mod+T}} (tab cusub), {{key:Mod+N}} (daaqad cusub) iyo {{key:F11}} (shaashad buuxa browser-yada Windows iyo Linux). CivilCraft ma isticmaalo. Haddii gaabintu wax kale ku furto browser-ka, riix qorshaha hal mar si bogga xoogga u yeesho, kadibna isku day mar kale.

## Halka Guuri ku jirto

Ma jiro amar Guuri: dooro {{ui:Dooro}} oo jiid barta ama geesta, ama tafatir isku-xidhkeeda {{ui:Sifooyinka}}. Eeg [Tafatir barooyinka](topic:edit-points).

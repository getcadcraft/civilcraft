CivilCraft ma leh sanduuq dejin ama qaab. Kuwani waa qiimayaasha wax kasta ku bilaabmaan. Qiimayaasha lagu calaamadiyay **meelo-hayeen** laguma soo qaadanin heer; ku beddel shuruudahaaga mashruuca ka hor inta aadan ku tiirsanaan hubinta ama tirada.

## Mashruuc cusub

| Dejinta | Qiime |
|---|---|
| Magac | Goob aan la magacaabin (magaca faylka barta ugu horreeya ayaa beddela) |
| Cutubka | Fiit US |
| Magaca dusha | Dhulka jira |
| Kooxaha barta | Kooxba kasta wuxuu ku bilaabmaa {{ui:Barood}} |
| Geeska dibada ugu dheer | 0 (ilaali saddexagal kasta) |
| Tallaabooyinka ka noqoshada la kaydiyo | 200 |

## Bandhig

| Dejinta | Qiime |
|---|---|
| Dusha | {{ui:Dhulka jira}} |
| Kontuur kasta | 1 (ft ama m) |
| Waaweyn kasta | Kontuurka 5aad |
| Xagaagaha | 8 |
| Shid | Kontuurada, calaamadaha kontuurka, barahaa, khadadka jebinta, geesta dusha, biibaanka |
| Demi | Saddexagallada, xagaagaha heerarka, fallaadaha naqaska, calaamadaha barta |

## Jidadka iyo profiles-ka

| Dejinta | Qiime |
|---|---|
| Magac | Jidka 1, Jidka 2 … |
| Isteeshanka bilowga | 0+00 |
| Radius-ka curve PI kasta oo dhex ah | 100 ft ama 30 m, yar haddii aanu ku habboon nus tangent kasta |
| Naqshadda profile-ka | Midna ilaa aad bilowdo; {{ui:Ka bilow dhulka}} wuxuu dhigaa PVI dhulka dhamaad kasta |
| Dhererka curve-ka kor-u-kaca | 0 (curve la'aan) ilaa aad qortid |

## Qorshaha

| Dejinta | Qiime |
|---|---|
| Aagga | {{ui:Wax walba}} |
| Warqadda | Tabloid 11 × 17 in (mashruucyada fiitka), ISO A3 (mashruucyada mitirka); had iyo jeer toosan |

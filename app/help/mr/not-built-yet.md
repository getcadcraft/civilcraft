CivilCraft अजून सुरुवातीच्या टप्प्यात आहे. हे पान सध्याची बिल्ड काय करत नाही ते सांगते, म्हणजे तुम्ही त्यासाठी शोधणार नाही. येथे काहीही तारखेसह वचन दिलेले नाही.

## पॉइंट्स

| अजून बांधलेले नाही | आज त्याऐवजी |
|---|---|
| पहिल्या फाइलमध्ये दुसरी पॉइंट फाइल जोडणे | प्रथम फाइल्स टेक्स्ट एडिटर किंवा स्प्रेडशीटमध्ये जोडा |
| पॉइंट टेक्स्ट फाइल निर्यात करणे | LandXML निर्यात करा (पॉइंट्स CgPoints म्हणून बाहेर जातात), GIS {{ui:निर्यात}} वापरा (P, N, E, Z आणि D फील्ड असलेले पॉइंट्स), किंवा पॉइंट्स स्प्रेडशीटमध्ये {{ui:कॉपी करा}} करा |
| पॉइंट लेबल शैली, वर्णन कीनुसार चिन्हे, लाइन कोडमधून वक्र (कंस), प्रकल्पांमध्ये शेअर करण्यासाठी वर्णन की फाइल | लेबल्स क्रमांक, उंची आणि वर्णन दाखवतात, किंवा त्याहून कमी ([CivilCraft सेटिंग्ज](topic:settings)); की प्रकल्प फाइलमध्ये ठेवल्या जातात |
| एककांचे रूपांतर | आयात करण्यापूर्वी फाइल रूपांतरित करा; **एकके** फक्त नाव बदलतात |

| (आतील) सीमा लपवणे | **सर्वात लांब बाह्य कड** किंवा बाहेरची सीमा वापरा |

| LandXML मधून वाचलेला पृष्ठभाग संपादित करणे (ब्रेकलाइन्स, सीमा) | {{ui:बिंदूंवरून पृष्ठभाग पुन्हा बनवा}} |
| उंची ग्रिडमधून बनवलेला पृष्ठभाग संपादित करणे | ग्रिड वेगळ्या पर्यायांसह पुन्हा आयात करा |
| निर्देशांक प्रणाली बदलल्यावर LandXML मधून वाचलेला पृष्ठभाग रूपांतरित करणे | प्रथम {{ui:बिंदूंवरून पृष्ठभाग पुन्हा बनवा}} |
| लेबल असलेल्या स्पॉट उंची आणि उतार मूल्ये | स्टेटस बारमध्ये वाचा, किंवा लँडस्केप वर्कस्पेसमधील **Slope analysis** ने पृष्ठभाग उतारानुसार रंगवा ([लँडस्केपसाठी ग्रेडिंग](topic:landscape-grading#grading-checks)) |

| प्रति अलाइनमेंट एकापेक्षा जास्त डिझाइन प्रोफाइल | प्रति प्रकार एक अलाइनमेंट |
| प्रोफाइल दृश्याचे झूम, प्रोफाइलखालील प्रोफाइल पट्टे | प्रोफाइल दृश्य संपूर्ण अलाइनमेंटमध्ये बसते; ते [प्लॅन आणि प्रोफाइल शीट्स](topic:plan-profile-sheets) वर छापा |
| DWG किंवा LandXML मधील सेक्शन | PDF मध्ये सेक्शन शीट्स; क्षेत्रे आणि घनफळांचे {{ui:CSV}} |
| कोनात नमुना रेषा, किंवा रस्त्याबरोबर वेगवेगळ्या रुंदीच्या | संपूर्ण अलाइनमेंटसाठी प्रत्येक बाजूला एक रुंदी |

## कॉरिडॉर

| अजून बांधलेले नाही | आज त्याऐवजी |
|---|---|
| मेडियन, बॅरियर आणि टेम्पलेट फिरवणारे सुपरएलिव्हेशन | टेम्पलेट म्हणून काढा ([कॉरिडॉर टेम्पलेट](topic:corridor-templates)); स्टेशननुसार टेम्पलेट्स अजून सुपरएलिव्हेशन घेत नाहीत |
| दोन प्रदेशांच्या टेम्पलेट्समधील हळूहळू बदल (संक्रमणे, टेपर) | स्टेशनवर टेम्पलेट बदला, किंवा टेपर म्हणून काढलेल्या रेषेसाठी बिंदूला रुंदी टार्गेट द्या |
| कडेभोवती फिरवणे, LandXML मधील सुपरएलिव्हेशन | सुपरएलिव्हेशन वर्तुळाकार वक्रांवर केंद्ररेषेभोवती फिरते; फीचर रेषेसाठी रुंदी टार्गेटने लेन रुंद करा |
| बाजू उतारांसाठी टार्गेट्स (रेषा किंवा पृष्ठभागाला डेलाइट), कॉरिडॉरची स्वतःची पृष्ठभाग | टार्गेट्स फरसबंदीच्या कडा आणि शोल्डर हलवतात ([कॉरिडॉर](topic:corridor)); कॉरिडॉर प्रस्तावित पृष्ठभागात उतारवला जातो |
| छेदनबिंदूमध्ये उतारवलेले कर्ब रिटर्न, वळण लेन आणि बेटे; तिरक्या रस्त्यावर बाजू रस्त्याचे टोक मुख्य रस्त्याच्या कडेपर्यंत कापलेले; प्लॅनमध्ये रस्त्याला जोडलेला मार्ग, त्याच्या लांबी आणि क्षेत्रासह | जोडलेले रस्ते काटकोनात जोडले जातात, मुख्य रस्त्याची कड उघडली जाते आणि बाजू रस्ता तिच्याकडे सौम्य केला जातो ([रस्ते मिळतात तिथे](topic:corridor#where-roads-meet-roads-pads-and-paths)); मार्ग प्रस्तावित पृष्ठभागात आणि 3D मध्ये रस्त्याच्या कडेला थांबतो |
| LandXML रोडवे म्हणून निर्यात केलेले कॉरिडॉर; IFC निर्यातीत अलाइनमेंटवरील दुसरा कॉरिडॉर | प्रस्तावित पृष्ठभाग निर्यात होतो |
| प्रस्तावित पृष्ठभाग बदलणारे भूभाग टेम्पलेट्स, 3D मध्ये किंवा सेक्शनमध्ये | ते प्रत्येक थराचे क्षेत्र आणि घनफळ देतात ([भूभाग टेम्पलेट्स](topic:corridor-templates#terrain-templates)) |
| वेग, टायर स्लिप, स्टीअरिंग वेळ, स्टीअरिंग ट्रेलर किंवा बॉडी क्लिअरन्स असलेले स्वीप्ट पाथ; मानक डिझाइन वाहनांची लायब्ररी; वाहन ओढून काढलेला स्वीप्ट पाथ | फीचर रेषा किंवा अलाइनमेंटबरोबर कमी-वेगाचे स्वीप्ट पाथ, तुमच्या वाहनाच्या आकारांसह ([वाहन स्वीप्ट पाथ](topic:swept-paths)) |

## ग्रेडिंग आणि घनफळे

|---|---|
| बेंच, डिझाइनमध्ये उतारवलेल्या उघड्या फीचर रेषा, इतरत्रून फीचर रेषेपर्यंत उतार | फीचर रेषा बंद करा ([फीचर रेषा](topic:feature-lines)), किंवा विद्यमान जमिनीची ब्रेकलाइन म्हणून वापरा |
| फीचर रेषेचे शिरोबिंदू घालणे किंवा काढणे | रेषा पुन्हा काढा, किंवा तिचा पायरीदार ऑफसेट करा |
| काढलेल्या ब्रेकलाइन्समधील कंस (सर्वेक्षण बिंदूंमधून), फीचर रेषांमधील सर्पिल | कंस असलेली फीचर रेषा काढा आणि विद्यमान जमिनीची ब्रेकलाइन म्हणून वापरा |
| अंतर, उंची किंवा दुसऱ्या पृष्ठभागापर्यंत उतार | फक्त विद्यमान जमिनीपर्यंत डेलाइट |

| TIN-ते-TIN (प्रिझम) घनफळे, ग्रिड सेलचा आकार निवडणे | ग्रिड पद्धत, सेल आकार तुमच्यासाठी निवडलेला |
| फुगवटा आणि आकुंचन, वरची माती, फरसबंदीची खोली | घटक नोंदवलेल्या संख्यांना स्वतः लावा |
| मुक्त-वाहतूक आणि ओव्हरहॉल खर्च, वेगवेगळ्या अलाइनमेंटवरून वाहतूक, प्लॅनवर ठेवलेले बॉरो खड्डे आणि कचरा जागा | संतुलन बिंदूंसह मास-हॉल आकृती, हलवलेली घनफळे आणि सरासरी वाहतूक अंतर |

## पाईप नेटवर्क

| अजून बांधलेले नाही | आज त्याऐवजी |
|---|---|
| प्रति प्रकल्प एकापेक्षा जास्त नेटवर्क | वादळी आणि सांडपाण्यासाठी वेगळे प्रकल्प |
| पाणी मुख्य लाइन्स: पाण्याची गुणवत्ता आणि वय, नियमाधारित नियंत्रणे, इतर व्हॉल्व्ह प्रकार (फ्लो कंट्रोल, थ्रॉटल, सस्टेनिंग), शक्तीने दिलेले पंप, दाबावर अवलंबून मागणी, Darcy–Weisbach पर्याय, भिंतीची जाडी आणि दाब वर्गांसह पाईप कॅटलॉग. दाब नेटवर्कचे उर्वरित भाग प्रयोगशाळेत आहेत: [पाणी मुख्य लाइन्स](topic:water-mains) | त्या पाणी वितरण सॉफ्टवेअरमध्ये तपासा; सांडपाण्याचे डिझाइन प्रवाह [सांडपाणी डिझाइन प्रवाह](topic:sanitary-design) मध्ये आहेत |
| कालांतराने सांडपाणी प्रवाह (हायड्रोग्राफ, डायनॅमिक राउटिंग, साठा, पंप, ओव्हरफ्लो) | [सांडपाणी डिझाइन प्रवाह](topic:sanitary-design) डिझाइन शीट वापरत असलेला स्थिर शिखर प्रवाह देते |
| इनलेट क्षमता, गटार विस्तार, डिटेन्शन राउटिंग, हायड्रोग्राफ, एका छेदनबिंदू गुणांकाव्यतिरिक्त ऊर्जा नुकसान | इतर सॉफ्टवेअरमध्ये तपासा; प्रवाह, आकार आणि ग्रेड रेषा [वादळी निचरा](topic:storm-drainage) मध्ये आहेत |
| PDF प्लॉट, DWG, DXF किंवा LandXML मधील पाणलोट क्षेत्रे; पृष्ठभागावरून पाणलोट क्षेत्रे (जलविभाजक) | पाणलोट क्षेत्रे हाताने काढा; ती प्रकल्प फाइलमध्ये जतन होतात |
| पाईप कॅटलॉग, गोल नसलेले पाईप, उभे बॉक्स किंवा सिलिंडर नसलेल्या रचना (शंकू, पायऱ्या, बेंचिंग), लायब्ररीमधील निचरा वर्ग | पॅरामीटर्सवरून रचना प्रकार ([पाईप नेटवर्क](topic:pipe-network)); व्यास असलेले पाईप |
| प्रोफाइल दृश्यातील पाईप, वक्र पाईप | उजव्या पॅनलमध्ये इन्व्हर्ट आणि कव्हर वाचा |

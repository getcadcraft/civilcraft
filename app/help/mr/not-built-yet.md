CivilCraft अजून सुरुवातीच्या टप्प्यात आहे. हे पान सध्याची बिल्ड काय करत नाही ते सांगते, म्हणजे तुम्ही ते शोधत बसू नका. येथे कुठल्याही गोष्टीसाठी तारीख दिलेली नाही.

## बिंदू

| अद्याप तयार नाही | आज त्याऐवजी |
|---|---|
| दुसरी बिंदू फाइल पहिल्यात जोडणे | आधी टेक्स्ट एडिटर किंवा स्प्रेडशीटमध्ये फाइल्स जोडा |
| बिंदूंची टेक्स्ट फाइल निर्यात करणे | LandXML निर्यात करा (बिंदू CgPoints म्हणून जातात), GIS {{ui:निर्यात}} वापरा (P, N, E, Z आणि D फील्डसह बिंदू), किंवा बिंदू स्प्रेडशीटमध्ये {{ui:कॉपी करा}} |
| बिंदू लेबल शैली, वर्णन कीनुसार चिन्हे, लाइन कोडमधून वक्र (आर्क), प्रकल्पांदरम्यान सामायिक करण्यासाठी वर्णन की फाइल | लेबलवर क्रमांक, उंची आणि वर्णन दिसते, किंवा त्याहून कमी ([CivilCraft सेटिंग्ज](topic:settings)); की प्रकल्प फाइलमध्ये जतन होतात |
| एककांचे रूपांतर | आयात करण्यापूर्वी फाइल रूपांतरित करा; **Units** फक्त लेबल बदलते |

## पृष्ठभाग

| अद्याप तयार नाही | आज त्याऐवजी |
|---|---|
| बिंदूंपासून एकापेक्षा जास्त पृष्ठभाग | प्रति पृष्ठभाग एक प्रकल्प |
| (आतील) सीमा लपवणे | **सर्वात लांब बाह्य कडा** वापरा किंवा बाह्य सीमा |
| काढलेली एक ब्रेकलाइन निवडणे किंवा संपादित करणे | {{key:Mod+Z}}, किंवा {{ui:काढलेल्या ब्रेकलाइन काढा}} आणि पुन्हा काढा |
| LandXML मधून वाचलेला पृष्ठभाग संपादित करणे (ब्रेकलाइन, सीमा) | {{ui:बिंदूंवरून पृष्ठभाग पुन्हा बनवा}} |
| उंचीच्या ग्रिडमधून बनवलेला पृष्ठभाग संपादित करणे | ग्रिड वेगळ्या पर्यायांसह पुन्हा आयात करा |
| निर्देशांक प्रणाली बदलल्यावर LandXML मधून वाचलेला पृष्ठभाग रूपांतरित करणे | आधी {{ui:बिंदूंवरून पृष्ठभाग पुन्हा बनवा}} |
| लेबल असलेले स्पॉट एलिव्हेशन आणि उताराची मूल्ये | स्टेटस बारमध्ये वाचा, किंवा लँडस्केप वर्कस्पेसमधील **उतार विश्लेषण** वापरून पृष्ठभागाला उतारानुसार रंग द्या ([लँडस्केपसाठी ग्रेडिंग](topic:landscape-grading#grading-checks)) |

| दोन इतरांमधील PI घालणे | अलाइनमेंट पुन्हा काढा, किंवा PI निर्देशांक पुन्हा टाइप करा |
| वस्तूंपासून, ऑफसेट्स, रुंदीकरणातून अलाइनमेंट | PI द्वारे काढा |
| उभ्या वक्रासाठी K टाइप करणे | L टाइप करा (K दाखवले जाते) |
| वर्तुळाकार आणि असममित उभे वक्र | फक्त सममित पॅराबोलिक वक्र |
| प्रति अलाइनमेंट एकापेक्षा जास्त डिझाइन प्रोफाइल | प्रति प्रकार एक अलाइनमेंट |
| प्रोफाइल दृश्य झूम करणे, प्रोफाइलखालील प्रोफाइल बँड | प्रोफाइल दृश्य संपूर्ण अलाइनमेंटला बसवले जाते; ते [प्लॅन आणि प्रोफाइल शीटवर](topic:plan-profile-sheets) प्लॉट करा |
| DWG किंवा LandXML मधील सेक्शन | PDF म्हणून सेक्शन शीट; क्षेत्रफळ आणि घनफळांचे {{ui:CSV}} |
| कोनातील नमुना रेषा, किंवा रस्त्यावर वेगवेगळ्या रुंदीच्या नमुना रेषा | संपूर्ण अलाइनमेंटसाठी प्रत्येक बाजूला एक रुंदी |

## कॉरिडॉर

| अद्याप तयार नाही | आज त्याऐवजी |
|---|---|
| मीडियन, बॅरियर्स, आणि टेम्प्लेट फिरवणारी सुपरएलिव्हेशन | टेम्प्लेट म्हणून काढा ([कॉरिडॉर टेम्प्लेट](topic:corridor-templates)); स्टेशननुसार टेम्प्लेटमध्ये अजून सुपरएलिव्हेशन नाही |
| दोन प्रदेशांच्या टेम्प्लेटदरम्यान हळूहळू बदल (ट्रांझिशन, टेपर) | स्टेशनवर टेम्प्लेट बदला, किंवा टेपरसाठी काढलेल्या रेषेला बिंदूचे रुंदीचे लक्ष्य द्या |
| कडेवर फिरवणे, LandXML मध्ये सुपरएलिव्हेशन | वर्तुळाकार वक्रांवर सुपरएलिव्हेशन सेंटरलाइनभोवती फिरते; लेनची रुंदी फीचर लाइनसाठी रुंदीच्या लक्ष्याने वाढवा |
| बाजूच्या उतारांसाठी लक्ष्ये (रेषा किंवा पृष्ठभागापर्यंत डेलाइट), स्वतःच्या कॉरिडॉर पृष्ठभागा | लक्ष्ये पेव्हमेंट आणि खांद्यांच्या कडा हलवतात ([कॉरिडॉर](topic:corridor)); कॉरिडॉर प्रस्तावित पृष्ठभागात ग्रेड केला जातो |
| LandXML रोडवे म्हणून निर्यात केलेले कॉरिडॉर; IFC निर्यातीत अलाइनमेंटवर दुसरा कॉरिडॉर | प्रस्तावित पृष्ठभाग निर्यात होतो |
| 3D मध्ये किंवा सेक्शनमध्ये प्रस्तावित पृष्ठभाग बदलणारे भूप्रदेश टेम्प्लेट | ते प्रत्येक थराचे क्षेत्रफळ आणि घनफळ देतात ([भूप्रदेश टेम्प्लेट](topic:corridor-templates#terrain-templates)) |
| वेगासह स्वीप्ट पाथ, टायर स्लिप, स्टिअरिंग वेळ, स्टिअरिंग ट्रेलर किंवा बॉडी क्लिअरन्स; मानक डिझाइन वाहनांची लायब्ररी; ओढून काढलेला स्वीप्ट पाथ | फीचर लाइन किंवा अलाइनमेंटसह कमी वेगाचे स्वीप्ट पाथ, तुमच्या स्वतःच्या वाहन आकारांसह ([वाहनांचे स्वीप्ट पाथ](topic:swept-paths)) |

## ग्रेडिंग आणि घनफळ

| अद्याप तयार नाही | आज त्याऐवजी |
|---|---|
| बेंच, डिझाइनमध्ये ग्रेड केलेल्या उघड्या फीचर लाइन्स, दुसऱ्या ठिकाणच्या फीचर लाइनपर्यंत ग्रेडिंग | फीचर लाइन बंद करा ([फीचर लाइन्स](topic:feature-lines)), किंवा ती विद्यमान जमिनीची ब्रेकलाइन म्हणून वापरा |
| फीचर लाइनचे शिरोबिंदू घालणे किंवा काढणे | रेषा पुन्हा काढा, किंवा तिचा पायऱ्यांचा ऑफसेट बनवा |
| काढलेल्या ब्रेकलाइनमधील आर्क (सर्वेक्षण बिंदूंमधून), फीचर लाइन्समधील स्पायरल | आर्कसह फीचर लाइन काढा आणि तिला विद्यमान जमिनीची ब्रेकलाइन म्हणून वापरा |
| अंतर, उंची किंवा दुसऱ्या पृष्ठभागापर्यंत ग्रेडिंग | फक्त विद्यमान जमिनीपर्यंत डेलाइट |
| पॅडचा कोपरा जोडणे किंवा काढणे | पॅड हटवा आणि पुन्हा काढा |
| TIN-ते-TIN (प्रिझम) घनफळ, ग्रिड सेलचा आकार निवडणे | ग्रिड पद्धत, सेलचा आकार तुमच्यासाठी निवडला जातो |
| फुगवटा आणि आकुंचन, टॉपसॉइल, पेव्हमेंटची खोली | नोंदवलेल्या आकड्यांना स्वतः घटक लावा |
| फ्री-हॉल आणि ओव्हरहॉल खर्च, वेगवेगळ्या अलाइनमेंटदरम्यान वाहतूक, योजनेवर ठेवलेले बॉरो पिट्स आणि कचरा स्थळे | संतुलन बिंदूंसह मास-हॉल आकृती, हलवलेले घनफळ आणि सरासरी वाहतूक अंतर |

## पाइप नेटवर्क

| अद्याप तयार नाही | आज त्याऐवजी |
|---|---|
| प्रति प्रकल्प एकापेक्षा जास्त नेटवर्क | वादळी पाणी आणि सांडपाणीसाठी वेगळे प्रकल्प |
| पाण्याच्या मुख्य वाहिन्या: पाण्याची गुणवत्ता आणि वय, नियम-आधारित नियंत्रणे, इतर व्हॉल्व्ह प्रकार (प्रवाह नियंत्रण, थ्रॉटल, सस्टेनिंग), पॉवरने दिलेले पंप, दाबावर अवलंबून मागणी, Darcy–Weisbach पर्याय, भिंतीची जाडी आणि दाब वर्गांसह पाइप कॅटलॉग. दाब नेटवर्कचा उर्वरित भाग प्रयोगशाळेत आहे: [पाण्याच्या मुख्य वाहिन्या](topic:water-mains) | ते पाणी वितरण सॉफ्टवेअरमध्ये तपासा; सांडपाणी डिझाइन प्रवाह [सांडपाणी डिझाइन प्रवाह](topic:sanitary-design) मध्ये आहेत |
| वेळेनुसार सांडपाणी प्रवाह (हायड्रोग्राफ, डायनॅमिक राउटिंग, साठवण, पंप, ओव्हरफ्लो) | [सांडपाणी डिझाइन प्रवाह](topic:sanitary-design) डिझाइन शीट वापरत असलेला स्थिर शिखर प्रवाह देते |
| इनलेट क्षमता, गटर स्प्रेड, डिटेन्शन राउटिंग, हायड्रोग्राफ, एका जंक्शन गुणांकाशिवाय इतर ऊर्जा नुकसान | ते इतर सॉफ्टवेअरमध्ये तपासा; प्रवाह, आकार आणि ग्रेड रेषा [वादळी पाण्याचा निचरा](topic:storm-drainage) मध्ये आहेत |
| PDF प्लॉट, DWG, DXF किंवा LandXML मधील कॅचमेंट; पृष्ठभागावरील कॅचमेंट (वॉटरशेड) | कॅचमेंट हाताने काढा; ते प्रकल्प फाइलमध्ये जतन होतात |
| पाइप कॅटलॉग, गोल नसलेले पाइप, सरळ बॉक्स किंवा सिलिंडर नसलेल्या रचना (शंकू, पायऱ्या, बेंचिंग), लायब्ररीतील निचरा वर्ग | पॅरामीटरवरून रचना प्रकार ([पाइप नेटवर्क](topic:pipe-network)); व्यासासह पाइप |
| प्रोफाइल दृश्यातील पाइप, वक्र पाइप | उजव्या पॅनेलमध्ये इनव्हर्ट आणि कव्हर वाचा |

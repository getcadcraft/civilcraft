सिंगल-अक्षर कळा तुम्ही बॉक्समध्ये टाइप करत नसताना काम करतात. {{key:Mod}} असलेले शॉर्टकट Mac वर Command वापरतात आणि इतरत्र Ctrl. हे देखील पहा [ब्राउझरमधील कळा](common:keys).

## फाइल्स आणि संपादन

| कळ | क्रिया |
|---|---|
| {{key:Mod+O}} | बिंदू फाइल, LandXML किंवा प्रकल्प उघडा |
| {{key:Mod+S}} | प्रकल्प जतन करा (`.civilcraft.json` फाइल डाउनलोड होते) |
| {{key:Mod+P}} | प्लॅन PDF मध्ये प्लॉट करा (प्लॉट डायलॉग उघडतो, ब्राउझरची प्रिंट नाही) |
| {{key:Mod+Z}} | पूर्ववत करा |
| {{key:Mod+Y}} | पुन्हा करा |
| {{key:Delete}} | निवडलेले सर्वेक्षण बिंदू, संरेखन, पॅड, संरचना, पाइप किंवा PVI हटवा |
| {{key:Mod+C}} | निवडलेले सर्वेक्षण बिंदू कॉपी करा (स्प्रेडशीटसाठी बिंदू ओळी म्हणूनही) |
| {{key:Mod+X}} | निवडलेले सर्वेक्षण बिंदू कट करा |
| {{key:Mod+V}} | बिंदू पेस्ट करा: ते पॉइंटरला फॉलो करतात, जिथे जावेत तिथे क्लिक करा |
| {{key:Mod+Shift+V}} | जागीच पेस्ट करा: बिंदूंच्या स्वतःच्या निर्देशांकांवर |
| {{key:Mod+D}} | निवडलेले बिंदू डुप्लिकेट करा: एक प्रत पॉइंटरला फॉलो करते |
| {{key:Mod+A}} | प्रत्येक सर्वेक्षण बिंदू निवडा |
| {{key:Esc}} | काहीही निवडू नका (आणि पेस्ट रद्द करा) |

{{key:Mod+S}}, {{key:Mod+O}} आणि {{key:Mod+P}} बॉक्समध्ये टाइप करत असतानाही काम करतात. बॉक्समधील मजकुरात {{key:Mod+Z}} आणि {{key:Mod+Y}} नेहमीप्रमाणे तुमचे टायपिंग पूर्ववत करतात, आणि तसेच {{key:Mod+C}}, {{key:Mod+X}}, {{key:Mod+V}} आणि {{key:Mod+A}}: बॉक्समध्ये ते मजकूर कॉपी, कट, पेस्ट आणि निवडतात. पानावर (पॅनेलमध्ये) मजकूर निवडलेला असताना {{key:Mod+C}} तो मजकूर कॉपी करतो. {{key:Mod+Shift+Z}} CivilCraft मध्ये काहीही करत नाही: {{key:Mod+Y}} किंवा {{ui:Redo}} बटण वापरा.

:::mac
Mac वर **delete** लेबल असलेली कळ ब्राउझरला {{key:Backspace}} आहे. निवड हटवण्यासाठी {{key:Delete}} दाबा (Fn आणि delete), किंवा टूलबारच्या {{ui:More}} मेनूमधून {{ui:Delete}} निवडा.
:::

## प्लॅन दृश्य

| कळ किंवा क्रिया | परिणाम |
|---|---|
| व्हील | पॉइंटरवर झूम इन किंवा आउट |
| रिकाम्या जागेवर ड्रॅग | पॅन (कोणत्याही साधनात; लहान क्लिक अजूनही क्लिक करतो; {{key:Shift}} धरून असल्यास निवड बॉक्स काढते) |
| मधल्या बटणाने ड्रॅग | पॅन |
| उजव्या बटणाने ड्रॅग | पॅन (मेनू उघडत नाही) |
| {{key:Space}} आणि ड्रॅग | पॅन |
| क्लिक | निवडा ({{ui:Select}} सह), किंवा बिंदू ठेवा (रेखाटन साधनासह) |
| {{key:Shift}} आणि क्लिक | सर्वेक्षण बिंदू निवडीत जोडा, किंवा काढा |
| {{key:Shift}} आणि ड्रॅग | बॉक्स काढा: त्यातील सर्वेक्षण बिंदू निवडीत जोडले जातात. [लॅसो](topic:lasso-selection) साठी त्याभोवती ड्रॅग करा |
| लॅसो काढताना {{key:Space}} | विंडो, मग क्रॉसिंग, मग फेन्स |
| पेस्ट करताना क्लिक | पेस्ट केलेले बिंदू तिथे ठेवा ({{key:Enter}} त्यांना त्यांच्या स्वतःच्या निर्देशांकांवर ठेवते) |
| ग्रिप ड्रॅग करा | PI, पॅड कोपरा किंवा संरचना हलवा (एक पूर्ववत पाऊल) |
| {{key:Up}} {{key:Down}} {{key:Left}} {{key:Right}} | पॅन, जेव्हा प्लॅनला फोकस असतो (आधी त्यावर क्लिक करा) |
| {{key:Plus}} आणि {{key:Minus}} | मध्यभागी झूम इन आणि आउट, जेव्हा प्लॅनला फोकस असतो |

= कळ {{key:Plus}} सारखी झूम इन करते, त्यामुळे Shift ची गरज नाही.

| क्रिया | परिणाम |

| {{key:Delete}} किंवा {{key:Backspace}} | निवडलेला PVI काढा ({{key:Backspace}} फक्त प्रोफाइल दृश्याला फोकस असताना) |

प्रोफाइल दृश्य झूम किंवा पॅन होत नाही.

## स्क्रीन आणि मदत

| कळ | क्रिया |
|---|---|
| {{key:F1}} | ही मदत (बाजूचा पॅनेल) उघडा किंवा बंद करा; अॅप बारमधील {{ui:Help}} तेच करते |
| {{key:Esc}} | उघडे असताना मदत पॅनेल बंद करा |
| {{key:Ctrl+Shift+F}} | स्क्रीन मोड बदला: फुल स्क्रीन, बार लपवलेले फुल स्क्रीन, सामान्य |
| {{key:Esc}} | फुल स्क्रीनमधून बाहेर पडा (ब्राउझरची स्वतःची कळ) |

{{key:F1}} CivilCraft पाहण्यापूर्वी मदतीपर्यंत पोहोचते, त्यामुळे ते कोणत्याही साधनात काम करते. बहुतेक Mac कीबोर्डवर F1 सह fn दाबा, किंवा {{ui:Help}} क्लिक करा. {{key:Ctrl+Shift+F}} प्रत्येक प्लॅटफॉर्मवर, Mac सह, Control कळ वापरते. ही मदत कशी शोधायची यासाठी [मदत वापरणे](common:help) पहा.

## माउस, ट्रॅकपॅड आणि टच

:::mouse
- व्हील पॉइंटरवर झूम करते. मोकळेपणाने फिरणारा व्हील असलेला माउस पटकन झूम करतो: लहान वळणे द्या.
- रिकाम्या जागेवर कोणत्याही ड्रॅगने, मधल्या बटणाने, उजव्या बटणाने, किंवा {{key:Space}} आणि ड्रॅगने पॅन करा.
:::

:::mac
Mac ट्रॅकपॅडवर:

- दोन-बोटी स्क्रोलिंग **झूम** करते (पॅन करत नाही), आणि पिंच देखील झूम करते.
- पॅन करण्यासाठी, रिकाम्या जागेवर एका बोटाने दाबा आणि ड्रॅग करा, किंवा {{key:Space}} धरा आणि ड्रॅग करा.
- दोन-बोटी क्लिक (उजवे-क्लिक) मेनू उघडत नाही आणि स्वतःहून काहीही करत नाही.
:::

:::touch
टच स्क्रीनवर:

- पहिला स्पर्श बटणे आणि मेनू ओळी बोटाच्या आकाराच्या करतो.
- टॅप करून निवडा किंवा बिंदू ठेवा; रिकाम्या जागेवर एक बोट ड्रॅग केल्यास पॅन होते. टॅप थोडा हलू शकतो: बोट सुमारे 10 पिक्सेल हलल्यावरच पॅन होते.
- दोन बोटे पिंच करून झूम करतात आणि एकत्र हलवून पॅन करतात.
- एका बोटाने ग्रिप किंवा PVI ड्रॅग करा. ग्रिपच्या भोवती बोटाच्या रुंदीएवढी जागा मिळते.
- संरेखन, पॅड, ब्रेकलाइन, सीमा, पाइप रन, वैशिष्ट्य रेषा किंवा पार्सल काढताना, प्लॅनवरील पट्टी {{ui:Finish}} ({{key:Enter}}), {{ui:Undo point}} ({{key:Backspace}}) आणि {{ui:Cancel}} ({{key:Esc}}) देते. दीर्घ दाब (हलवल्याशिवाय अर्धा सेकंद) देखील पूर्ण करतो.
- {{ui:Select}} मध्ये सर्वेक्षण बिंदूवर दीर्घ दाब दिल्यास तो निवडीत जोडला जातो, किंवा काढला जातो, जसे {{key:Shift}}+क्लिक करतो.
- 3D दृश्यात एक बोट फिरवते, दोन बोटे पिंच करून पॅन करतात, आणि टॅप निवडतो.
- टचवर होव्हर नसतो, त्यामुळे स्टेटस बार रीडआउट्स फक्त बोट खाली असतानाच अपडेट होतात.
:::

## ब्राउझरच्या कळा ज्या जिंकतात

काही कळा ब्राउझरच्या असतात आणि त्या कधीच CivilCraft पर्यंत पोहोचत नाहीत, उदाहरणार्थ {{key:Mod+W}} (टॅब बंद करा), {{key:Mod+T}} (नवीन टॅब), {{key:Mod+N}} (नवीन विंडो) आणि {{key:F11}} (Windows आणि Linux ब्राउझरमध्ये फुल स्क्रीन). CivilCraft त्या वापरत नाही. एखादा शॉर्टकट त्याऐवजी ब्राउझरमध्ये काहीतरी उघडत असेल तर, पानाला फोकस मिळण्यासाठी प्लॅनवर एकदा क्लिक करा, आणि पुन्हा प्रयत्न करा.

## हलवा कुठे आहे

हलवा (Move) कमांड नाही: {{ui:Select}} निवडा आणि बिंदू किंवा शिरोबिंदू ड्रॅग करा, किंवा त्याचे निर्देशांक {{ui:Properties}} मध्ये संपादित करा. पहा [बिंदू संपादित करा](topic:edit-points).

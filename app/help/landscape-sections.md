{{ui:Levels}} › {{ui:Section line}}: click the start and the end. Sections are named A, B, C… (rename them in Properties). A section draws, along its line:

- the existing ground (dashed) and the proposed ground;
- walls with their footings, where the line crosses them;
- paving and path build-ups, and planted-area mulch and topsoil (after clipping), hanging below the finished surface;
- steps in profile;
- plants within the set distance of the line, as silhouettes at mature size.

Properties sets that distance and a vertical exaggeration. In the Sheets dialog, **Sections** puts them on their own sheets, up to four to a sheet, each at a standard scale that fits.

## The publish set

{{ui:Publish set (.zip)}} in the Sheets dialog makes, in one .zip:

- one PDF that opens with the **sheet list** and then every landscape sheet, numbered L-1, L-2… (planting, grading, irrigation, details, sections, worksheets);
- a **DWG per plan sheet** with that sheet's layers (`L-*` names kept) and a DWG per section drawing.

Each section line on the plan says which sheet it is on (`A / L-5`); the number is worked out from the set every time, so adding, removing or renaming sections renumbers them.

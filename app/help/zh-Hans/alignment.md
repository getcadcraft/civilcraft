CivilCraft 中的路线是由交点（PI）连接而成的一系列切线；凡有半径的内部 PI 处都设有圆曲线。路线从你选定的起始桩号开始编号。一个项目可以包含多条路线。

## 绘制路线

1. 按{{key:A}}键，或点击**设计**组中的{{ui:路线}}。
   提示显示：“路线：按顺序点击 PI。按Enter键或双击结束，Backspace删除最后一个，Esc取消。”
2. 点击第一个 PI（路线的起点）。
3. 按顺序点击后续每个 PI。一条红线会跟随指针，并显示你正在绘制的切线的长度和方位角，例如“212.40 ft  N 63°12'05" E”。
4. 点击最后一个 PI（路线的终点）。
5. 按Enter键。
   路线按桩号绘制并被选中。状态栏会显示例如：“路线 1：386.36 ft，符合条件处曲线半径为 100 ft。在属性中编辑半径；用纵断面 (R) 设计其纵坡。”

绘制时，{{key:Backspace}}删除最后一个 PI，{{key:Esc}}取消，在空白处拖动则平移视图，不添加 PI。

:::warning
完成时请按{{key:Enter}}。双击也能结束，但在此版本中，它会删除你双击的那个 PI。请单击最后一个 PI 一次，然后按{{key:Enter}}。
:::

每个内部 PI 都会获得一条 100 ft 的曲线（米制项目为 30 m）；若 100 ft 放不下，则取能放入每条切线一半长度内的最大整数半径。过于尖锐或直线穿过的 PI 不设曲线。

## 设置半径和坐标

选中路线后，右侧面板显示**路线**：

1. **名称**和**起始桩号**。以 `10+00`（英尺）或 `0+500`（米）的形式输入桩号，也可以输入纯数字。参见[单位、桩号和数字格式](topic:units-and-stations)。
2. **长度**和**终止桩号**由程序自动计算。
3. **PI** 表列出每个 PI 的**东坐标**和**北坐标**，以及每个内部 PI 的**半径**。输入新值后按Enter键。
   - 半径为 0 时，该点为无曲线的折点。
   - 第一个和最后一个 PI 永远没有半径。
   - 行末的小 x 用于删除该 PI（路线至少保留两个 PI）。
4. 查看**曲线**列表：每条曲线的 PC 和 PT 桩号、半径 R、偏角 Δ 及方向（左或右）、长度 L、切线长 T、外距 E 以及弦长。
5. 曲线列表下方的一行给出第一条切线的方位角。

## 曲线放不下时

如果曲线所需的切线长超过其 PI 之间的距离，该路线无解：在修正之前不会正确绘制，并且会被排除在 LandXML 导出之外。红色方框会用数字说明原因，并给出可行的方案：

- “PI 2 和 PI 3 处的曲线之间共需 240.00 ft 的切线（130.00 + 110.00），但两个 PI 相距 180.00 ft。”或者，当只有其中一个 PI 有曲线时：“PI 2 处的曲线需要朝向 PI 1 的 240.00 ft 切线……”
- 每个 PI 旁都有一个按钮，可将该处的半径设为**能放入的最大半径**，另一条曲线保持不变（该半径还必须能放入该 PI 的另一条切线）。若两个 PI 都有曲线，**两者**按比例同时缩小两个半径，使其恰好相接。
- 当某一条曲线本身就比切线长时，方框会提示：当它这么大时，另一个 PI 处任何曲线都放不下。
- 完全折返的 PI 无法设置曲线；方框会提供**PI n 处不设曲线**。

每个按钮都是一步操作：{{key:Mod+Z}}可恢复原来的半径。提供的半径均向下取整到 0.01，以确保一定能放下。

### 设计最小半径

输入**设计最小半径**（例如根据设计速度确定），使每条曲线都按此进行检查；留空则不检查。半径小于该值的曲线会列出，并附有一个按钮，可将其设为**满足最小值的最小半径**（前提是该半径能放下）。若放不下，方框会说明此情况，并给出切线所允许的最大半径，以便你移动 PI 或降低最小值。

## 在平面图上移动 PI

1. 启用{{ui:选择}}后，点击路线将其选中。其 PI 处会出现方形夹点。
2. 拖动夹点。路线、其桩号、纵断面和道路模型会随之更新。
3. 松开鼠标。此次移动为一步撤销。

目前尚不支持在两个现有 PI 之间添加 PI：请删除该路线后重新绘制，或为现有 PI 输入新的坐标。

## 读取桩号和偏移

将指针移到平面图上。状态栏会显示最近的路线（或选中的路线）及其桩号和偏移，沿桩号增加方向看去，偏移位于左侧为**L**、右侧为**R**，例如“路线 1：桩号 2+15.30，偏移 18.42 R”。超出任一端时会加上“（超出端点）”。

## 绘制内容

在平面图、DXF 和 PDF 中：中线（切线为直线，曲线为真正的圆弧）；每 50 ft（20 m）一个刻度，每 100 个单位一个较长的刻度并标注桩号；PC 和 PT 刻度，并标注其桩号。

## 删除路线

选中路线后按{{key:Delete}}，或点击工具栏或右侧面板底部的{{ui:删除}}。其纵断面和道路模型也会一并删除。{{key:Mod+Z}}可将其恢复。

:::mac
在 Mac 键盘上，标有 **delete** 的键对浏览器而言是{{key:Backspace}}，不会删除选中的对象。请按{{key:Delete}}（Fn加delete），或使用{{ui:删除}}按钮。
:::

## 设计速度和等级

在路线的属性中，**设计速度**（km/h 或 mph）和**设计等级**与路线一并保存，写入项目文件并导出到 IFC（Pset_RoadDesignCriteriaCommon）。CivilCraft 没有将速度与最小半径对应起来的表格，因此不会根据它们进行检查：请根据你自己的设计标准设置**最小半径**。

## 回旋线

曲线两端均可设置回旋线：切线、回旋线、曲线、回旋线、切线。在 PI 表中，对于有半径的 PI，在**入口回旋线**和**出口回旋线**中输入长度。PI 位置不变；曲线向内移动以腾出空间，因此切线距离会增加回旋线的内移量。两个长度可以不同；若某个 PI 只输入一个长度，则只在该端设置回旋线。

随后曲线列表显示 TS、SC、CS 和 ST（切线到回旋线、回旋线到曲线、曲线到回旋线、回旋线到切线），并给出回旋线角 θs、切线距离和外距。桩号与其他处一样沿回旋线连续排列。若两段回旋线合计转角超过曲线本身，则会拒绝并指出相应 PI；回旋线长度超过切线所允许的长度即构成重叠，与任何曲线相同。超高采用回旋线作为过渡段（参见[道路模型](topic:corridor)）。

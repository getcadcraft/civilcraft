地形测量通常以图形形式提供：等高线为带高程的多段线，断裂线为三维多段线，场地边界为闭合多段线。CivilCraft 会将图形的**模型空间**按图层打开到平面图上，并可直接将这些线转换为曲面。

## 打开图形

1. 在**曲面**组中点击{{ui:线条}}（或{{ui:打开}}，或将文件拖放到平面图上），然后选择 `.dwg` 或 `.dxf` 文件。图形在本计算机上读取，不会上传任何内容。可读取 2000 至 2018 版本的 DWG 以及 ASCII DXF。
2. **线条**对话框列出图形中包含线、闭合图形或点的图层，以及这些图层是否具有**高程**。在图形中关闭的图层初始为未勾选状态。文字、图案填充、标注及其他非线条对象会被计数并排除（对话框会说明具体是哪些对象）。
3. 检查**图形单位**。若图形中注明了单位，CivilCraft 会将其换算为项目单位（毫米换算为米，米换算为英尺，英寸换算为英尺）。以英尺为单位的图形将按美国测量英尺读取而不做换算：两者相差百万分之二，若按此比例换算州平面坐标，会使其偏移数英尺。若图形中未注明单位，其数值将按项目单位读取；若单位不对，请在列表中选择正确的单位。
4. 在**用于曲面**中，选择各图层为曲面提供的内容（或保持**仅显示**）。名称类似等高线（TOPO、CONT、CNTR）且带有高程的图层，初始将作为断裂线。
5. 点击{{ui:添加}}。这些图层会出现在左侧面板的 **GIS 图层**下；每种用途都会加入曲面。每个部分各为一个步骤：{{key:Mod+Z}}可逐个撤销。

## 各类图层能提供什么

| 图层包含 | 用于曲面 |
|---|---|
| 等高线（带高程的多段线） | 按线本身的高程，或按 ELEV 字段的断裂线 |
| 三维多段线 | 按其自身高程的断裂线 |
| 闭合轮廓 | 曲面边界（最大的闭合图形，或所选的图形） |
| 带高程的点 | 测量点，以图层名称描述 |
| 高程为 0 的线（平面线条） | 无：保留在平面图上作为底图 |

CivilCraft 写入的图形会将其特征线保存为记住圆弧的三维多段线。此时对话框会显示**特征线**：保持勾选，则将其恢复为带圆弧和用途的特征线（一个撤销步骤）；取消勾选，则将其作为普通图层读取为线条。

之后，可在 **GIS 图层**下该图层的菜单中使用{{ui:用于曲面}}，对仅显示过的图层执行同样的操作。

## 由块生成测量点

测量图纸通常将其点绘制为块：每个测点处有一个小符号，并带有点号、描述和高程属性。当图形包含块参照时，对话框中会出现**由块生成测量点**部分：

1. 勾选要采用的块（表格会显示每个块有多少个参照、位于哪些图层以及包含哪些属性），或勾选图层以采用其上的所有块参照。
2. 选择每个点的**编号**、**描述**和**高程**来源：属性、块或图层名称、下一个可用编号，或插入点的 Z 值。CivilCraft 会优先采用可能的属性（PT、DESC、ELEV 等），且仅当块位于零高程时才从属性中取高程。
3. 若只需要点，请取消勾选线条图层，然后点击{{ui:添加}}。

每个参照在其插入点处生成一个测量点。仅计入放置在模型空间中的参照；嵌套在其他块中的块不计。项目中已有的编号，或在图形中出现两次的编号，将在最大编号之后获得新编号；若高程属性不是数字，则该点没有高程。状态栏会统计这两类情况。图形本身永远不会被修改，且每个点都会记住其块：其属性中的**来自块**会显示该块、图层和句柄。添加测量点为一个步骤，因此{{key:Mod+Z}}可一次撤销全部。

## 以文字形式写出的高程及检查

以文字形式书写的高程点（或不属于测量点块的块属性中的高程）不属于线条。**测量高程与检查**部分可将其作为测量点导入，并列出图形中可能存在的问题：单位、坐标系、距原点的距离、平坦的等高线、异常高程、重复点。参见[导入时检查测量图形](topic:survey-check)。

## 图形的读取方式

- 圆弧、圆、椭圆、带凸度的多段线线段和样条曲线会被转换为短直线段（每 5° 至多一段）。
- 块参照按其放置位置绘制，嵌套块也一样；块中位于 0 层的内容采用参照所在的图层。
- 在其他平面（不同拉伸方向）中绘制的对象，会按世界坐标放置。
- 坐标按原样读取：图形必须与项目使用相同的坐标（例如相同的州平面带）。外部参照（xref）不会被打开：请单独打开它们。
- 每个对象获得三个字段：LAYER、TYPE（对象类型）和 ELEV（当其所有点共享同一高程时的高程）。

:::tip
在等高线图形的山顶和洼地处加上几个高程点，可得到最佳曲面；仅有等高线时，这些位置会形成平坦的三角面。请将其添加为测量点，或从图形中的点图层添加。
:::

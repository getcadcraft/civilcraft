当[管网](topic:pipe-network)的{{ui:类型}}为{{ui:污水}}时，污水设计流量作用于该管网。未选择任何对象时，右侧面板将显示**污水设计流量**；而雨水管网则显示雨水排放。

## 输入汇入的水量

1. 选择一个检查井。在**污水设计流量**下，输入{{ui:在此汇入的人口}}和{{ui:在此汇入的面积}}（公制工程以公顷计，英尺工程以英亩计）。
2. 对于商店、办公或工业用地，输入当量人口：面积乘以所在机构规定的每公顷（或每英亩）人口数。无论哪种方式，面积均计入渗入量。
3. 对每个有街道或地块接入的检查井重复上述操作。无接入的检查井，两项均保持为 0。

每根管道承载其上游检查井及其以上所汇入的全部水量。选择某一检查井，即可查看经过该井的水量。

## 设置

| 设置 | 含义 |
|---|---|
| {{ui:每人流量}} | 每人每日的平均流量：升（公制工程）或美制加仑（英尺工程） |
| {{ui:渗入量}} | 渗入的地下水：每公顷每秒升数，或每英亩每日加仑数 |
| {{ui:高峰系数}} | Harmon，1 + 14 / (4 + √P)，或 Babbitt，5 / P^0.2，其中 P 为人口（千人） |
| {{ui:高峰系数不小于}} / {{ui:高峰系数不大于}} | 系数保持在这两个值之间 |
| {{ui:曼宁系数n}} | 用于过流能力和流速 |
| {{ui:最小流速}} / {{ui:最大流速}} | 以峰值流量在管中自身的水深计 |
| {{ui:满管容量的上限}} | 管道在峰值时可允许的充满程度，以满流输送能力的百分比表示 |

起始值为占位值，并非标准。应采用所在机构公布的数值。

## 计算内容

对每根管道，按水流顺序：

- 峰值流量 = 人口 × 每人流量 × 高峰系数 + 面积 × 渗入量
- 按管道坡度计算满流时的过流能力（曼宁公式），以及峰值流量使其达到的充满程度
- 峰值流量的正常水深及该处流速

**污水计算结果**表列出每根管道的人口、高峰系数、峰值流量（L/s，或 gpm 与 cubic feet per second）、充满度（百分比）和流速。其下方列出问题：管道充满度超过限值、流速低于最小流速（可能无法自净）、高于最大流速，或无坡降。{{ui:按这些流量确定管径}}为每根管道选出能将其峰值流量控制在限值内的最小标准管径（200 mm 或 8 英寸起）；按{{key:Mod+Z}}可撤销。

:::note
这是设计表格所计算的稳定峰值流量，已与公布的设计表格核对至其印刷的取整精度。它并非污水管随时间变化的模型：不含过程线、蓄存、泵站或溢流。见[尚未实现](topic:not-built-yet)。
:::

流速采用曼宁公式，各水深下的 n 值相同。部分机构的部分充满度图表允许 n 随水深变化，在充满度为 60% 至 70% 的管道中，流速会略低（约低 3%）。

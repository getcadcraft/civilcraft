项目中包含一个重力管网，雨水或污水。它由构筑物（检查井、雨水口）以及它们之间的直线管道组成。水流沿绘制的方向流动。CivilCraft 依据已设置的三条规则检查每根管道和每个构筑物，并可根据这些规则设置所有管内底标高。

## 绘制管段

没有曲面也可以绘制管道，但井口标高、覆土和自动管内底标高都需要曲面。

1. 按{{key:P}}，或点击**设计**组中的{{ui:管道}}。
   提示显示：“管道：从管段顶端向下依次点击构筑物（点击已有构筑物即可连接）。按{{key:Enter}}结束。”
2. 点击上游构筑物的位置，即放置一个构筑物。
3. 依次点击每个下游构筑物。若要连接到已有的构筑物，请点击它：状态栏显示“已连接 S3。”
4. 按{{key:Enter}}。
   管道随即绘制，其管内底已按规则设置，状态栏显示例如：“已绘制 3 条管道，12 个管内底已按规则设置；所有检查均通过。”

新构筑物依次命名为 S1、S2……，直径为 48 in（1200 mm）。新管道依次命名为 P1、P2……，直径为 12 in（300 mm）。在以英尺为单位的项目中，直径以英寸表示；在以米为单位的项目中，直径以毫米表示。

完成时按{{key:Enter}}。双击也可以完成，但若双击已有构筑物以在该处结束管段，连接将被取消：请先单击一次，然后按{{key:Enter}}。

## 设置规则

在未选择任何对象时，右侧面板（**项目**）中有一个**管网**区块：

| 设置 | 初始值 | 含义 |
|---|---|---|
| 类型 | 雨水 | {{ui:雨水}}或{{ui:污水}}；写入 LandXML |
| 最小坡度 | 0.50% | 每根管道的下降坡度须至少达到此值 |
| 最小覆土 | 2 ft（0.6 m） | 从地面到管顶的距离，沿整根管道计算 |
| 构筑物内跌落 | 0.10 ft（0.03 m） | 出水口管内底须至少比每个进水口管内底低这么多 |

**这些初始值只是占位值，并非标准。**请设置机构或项目要求的数值。覆土从地面量至管顶（管内底加内径）；壁厚不计入。若平台或道路已分级，则以分级后的曲面为地面。

## 由 CivilCraft 设置管内底标高

- {{ui:按规则设置所有管内底标高}}（位于**管网**区块中）：设置所有管道。
- {{ui:按规则设置其管内底标高}}（选中一根管道时）：仅设置该管道。

按自上游向下游的顺序，每段管道的起始端在其顶部构筑物处至少满足最小覆土，坡度至少达到最小坡度，每经过一个构筑物至少跌落指定的跌落量；并且，凡沿管道的地面会使覆土小于最小覆土的位置，管道会埋得更深。管内底标高向下取整至 0.01，绝不向上取整。状态栏会显示“管内底已设置：每段顶部满足最小覆土，至少达到最小坡度，每个构筑物内至少跌落指定量。”，或说明无法完成的原因。

## 编辑构筑物和管道

用{{ui:选择}}点击构筑物或管道，即可在右侧面板中查看其属性。

**构筑物**：**名称**、**井口**、**集水坑深度**、**直径**，然后是**使用的井口**、**集水坑**、**东坐标**和**北坐标**，以及进出该构筑物的管道及其管内底标高。

- 将**井口**留空即从曲面取值；框中会以灰色显示曲面值。输入数值即可固定井口标高。
- 在平面图上拖动构筑物的夹点即可移动它。其管道随之移动；其管内底标高保持不变，因此之后请检查问题。

**类型**：从本管网的构筑物类型（见下文）中选择，或选择无，即采用其自身直径的圆形构筑物。

**管道**：**名称**、其所连接的两个构筑物、**直径**、**上管内底**、**下管内底**，然后是**长度**、**坡度**和**最小覆土**。

在每个数值输入后按{{key:Enter}}。

## 查看并解决问题

**管网**区块列出所有问题（最多 40 项）；点击某一项即可选中相应的管道或构筑物。选中某根管道或某个构筑物时，它会列出自身的问题。若没有问题，则显示“所有管道和构筑物均符合规则。”

| 提示信息（示例） | 处理方法 |
|---|---|
| “P2 为上坡（-0.40%）。”或“……为平坡……” | 对调管内底，或按规则设置。 |
| “P2 坡度为 0.30%，比最小值 0.50% 更平缓。” | 降低下游管内底，或抬高上游管内底。 |
| “P3 沿线覆土为 1.40（位于 35 处），小于最小值 2。” | 降低管道；按规则设置其管内底标高。 |
| “在 S3 中，P4 出口处为 245.20，未比进入的 P3（245.25）低 0.1。” | 降低出水管的上管内底。 |
| “P1 的管顶高于 S1 的井口。” | 管道相对构筑物过高。 |
| “S2 有 2 根管道流出；重力管网中每个构筑物应只有一个出口。” | 删除一根流出管道，或将其按正确方向重新绘制。 |
| “管道形成了环路；水流必须汇至出口。” | 某段管道被绘制回到自身；请删除一根管道。 |
| “S5 位于曲面之外，没有井口标高。” | 输入井口标高，或将构筑物移至曲面上。 |
| “P6 部分位于曲面之外；该处覆土未知。” | 扩展曲面，或接受该处不检查覆土。 |
| “P7 尚无管内底标高。” | 输入管内底标高，或按规则设置。 |

存在问题的管道和构筑物也会在平面图上以红色标出。

## 构筑物类型

构筑物类型是由参数定义的构筑物：检查井、雨水口、连接井或出口，采用**圆形**（内径）或**矩形**（内宽和内长），并包含**壁厚**、**底板**、位于最低管道下方的**集水坑**，以及**井框和井盖**（圆形或矩形开口，井框高度）。类型属于管网，位于项目属性中的**构筑物类型**下。

1. 点击{{ui:新构筑物类型}}。对话框会在输入时同步绘制平面图和剖面图中的构筑物。
2. 点击{{ui:添加类型}}。
3. 选中一个构筑物，并在**类型**下选择该类型。它将采用该类型的尺寸和集水坑，但其自身的集水坑仍可更改。

修改某类型后，该类型的每个构筑物都会随之更新尺寸。删除某类型后，其构筑物保留为相同宽度的圆形构筑物。每次更改为一个步骤：{{key:Mod+Z}}可撤销。

矩形构筑物会绘制在平面图、DXF、DWG 和 PDF 中，并在三维中以矩形显示，其长边沿出水管方向；管道从其墙体处开始。LandXML 将其写为矩形构筑物（`RectStruct`），并带有壁厚，读取时也会将此类构筑物还原为类型。

### 通过库共享类型

{{ui:另存为库项目}}会将该类型写为 CadCraft 库项目（一个 `.json` 文件）：包括其平面符号、到典型深度的三维实体，以及所有尺寸。将其上传到库即可共享。{{ui:打开库项目}}会将以此方式保存的构筑物读回管网，并转换为项目单位。不是在 CivilCraft 中制作的构筑物库项目将被拒绝，并说明原因。

## 删除

选中一根管道并按{{key:Delete}}即可将其删除。删除构筑物时，与其相连的管道也会一并删除。在 Mac 上，请按 Fn 加删除键，或点击{{ui:删除}}。

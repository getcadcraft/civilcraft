左侧面板的**植物**部分列出所有可放置的植物。单击某种植物可查看其规格，并将其设为**植物**、**种植床**和**绿篱**所使用的植物。

## 搜索与筛选

在**搜索**中输入：任何语言的植物名称中的任一词（英语、西班牙语、葡萄牙语）、其拉丁学名、类型，或备注中的词语。输入的每个词都必须匹配，因此 `quercus evergreen` 可查找常绿栎。重音符号不影响搜索。

用**类型**、**光照**、**水分**和**耐寒区**缩小列表（**耐寒区**指站点所在的 USDA 区；只有当该区位于植物的适用范围内时，才会列出该植物）。

## 植物包含的信息

| 字段 | 含义 |
|---|---|
| 类型 | 乔木、灌木、绿篱、草本（包括草坪）、多年生草本、地被或攀缘植物 |
| 成熟时 | 植物在花园或街道中成熟时的高度和冠幅，单位为米 |
| 种植时 | 种植时的规格及其容器 |
| 间距 | 种植床内或沿绿篱的中心到中心距离 |
| 耐寒区 | 植物通常可耐寒的 USDA 区 |
| 光照、水分、土壤 | 其所需条件 |
| 备注 | 用途和注意事项，例如有毒部位或会蔓延的植物 |

:::note
内置列表是 CadCraft 根据一般园艺知识编写的：典型规格，已取整。它并非任何苗圃的目录。规格和耐寒性请向当地苗圃核实。伊比利亚半岛及温带地区大部分地方最知名的入侵植物已有意不收录，少数在某些地区有入侵性的植物会附注说明。
:::

## 自有植物

- **添加到本项目列表**会将植物复制到项目自有列表中，并随项目保存。列表中的植物会替换具有相同键的内置植物，因此可以为本地区更改其规格。
- **导入植物列表…**读取 CSV（或植物文件）。CSV 需要一列拉丁学名，最好还有类型、高度和冠幅列；列名可用任意用词（如 Latin、Common name、Height、Spread、Width、Zone）。可识别逗号、分号或制表符，以及小数逗号。空的种植规格、间距和容器将按类型采用合理的默认值。
- **导出为 CSV**会将列表保存下来（若无自有列表，则保存搜索结果中的植物），以便在电子表格中打开。

植物列表与其他外部文件一样读取：无法使用的内容会被略过并计数。

## 其他应用中的植物

植物列表是所有 CadCraft 应用共用的一个库：BimCraft 和 ModelCraft 使用相同的列表，但它们自己的**从库中放置**尚不提供植物。目前，植物是通过 CivilCraft 的景观 IFC 进入 BIM 模型的（每株植物为一个 `IfcGeographicElement`）。参见[种植](topic:planting#ifc)。

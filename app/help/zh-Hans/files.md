CivilCraft 从计算机打开文件，保存时则把文件下载回计算机。不会上传任何内容，也不会在服务器上保存任何内容。另请参阅 [文件](common:your-files)。

## 可打开的文件

点击 {{ui:Open}}（或按 {{key:Mod+O}}）并选择文件，或将文件从 {{pick:mac=Finder|windows=File Explorer|linux=your file manager}} 拖到平面图上。一次只打开一个文件；超过 200 MB 的文件会被拒绝。超过 32 MB 的 LandXML 或项目文件会分成约 4 MB 的片段读取，绝不会整体作为一段文本读入。打开 LandXML 时，内存占用约为文件大小的 13 倍（在我们的测试中，69 MB 的文件约占用 0.9 GB）。

| 类型 | 文件名 | 结果 |
|---|---|---|
| 点文件 | `.csv`、`.txt`、`.pnt`、`.xyz`（任何文本文件） | 将打开 **导入点** 对话框。这些点会替换项目中的点；线形、平台和管道保持不变。 |
| LandXML | `.xml`、`.landxml` | 由该文件创建一个 **新项目**（如果当前项目有未保存的更改，会先询问）。 |
| CivilCraft 项目 | `.civilcraft.json`（任何 `.json`） | 项目按保存时的状态打开（如果当前项目有未保存的更改，会先询问）。 |

CivilCraft 先根据文件的扩展名判断，再根据文件开头的字符判断：以 `{` 开头的文本作为项目读取，以 `<` 开头的作为 LandXML 读取，其他均作为点文件读取。打开对话框中显示为灰色的文件，仍可拖放到平面图上。

:::note
向已有点的项目导入点文件，会直接替换原有的点，不再询问，并且会清除撤销历史（打开任何文件都会重新开始撤销记录）。如果曲面来自 LandXML，导入点后会切换为由这些点生成的曲面。如果以后可能还需要旧的点，请先保存。
:::

详细信息：[点文件格式](topic:point-file-formats)、[LandXML：读取和写入的内容](topic:landxml-reference)。

## 保存的内容

{{ui:Save}}（{{key:Mod+S}}）会并排写入两个文件，文件名取自左侧面板中的 **名称**：`<name>.civilcraft.json`（用于继续编辑的项目），以及 `<name>.ifc`（相同设计的 IFC 4.3 文件，供其他软件使用，参见 [IFC 导出和导入](topic:ifc)）。两个文件互相记录对方，IFC 中还附带一份压缩的项目副本，因此单独发送的 IFC 仍可完整重新打开并编辑。

- **在 Studio 中**，两个文件会就地并排写入。
- **在 Chrome 和 Edge 中**，首次保存时会要求选择文件夹，并把两个文件都写入该文件夹；之后的保存都写入同一文件夹。在文件夹选择提示中点击 {{ui:Cancel}}，则改为下载两个文件。
- **在其他浏览器中**，两个文件都会下载，项目文件先下载。

打开其中任一文件时，都会查找另一个文件。可同时打开两个文件（或同时拖放两个文件），也可只打开一个：在 Studio 中，会在同一文件夹中找到另一个文件；在浏览器中，CivilCraft 会询问是否添加它，或继续使用当前这一个。如果 IFC 在 CivilCraft 保存后被其他程序修改，或者一个文件比另一个旧，项目会从较新的设计打开，问题面板会说明发生了什么，并提供 **立即保存**（重新写入两个文件）和 **将 IFC 的几何图形显示为参考**。若单独的 IFC 被其他程序修改，则会以其中的项目副本打开，并保留仍然匹配的内容：被修改的线形采用其几何图形，被删除的对象不予保留，其余更改仅列出，不予采用。0.7.1 之前的项目文件照常打开。

项目文件保存以下内容：

- 每个点（编号、坐标、高程、描述），以及这些点来源的点文件名称
- 曲面设置：分组选择、绘制的断裂线、边界、最长外边缘，以及从 LandXML 读取的 TIN
- 显示设置
- 线形，包括其交点（PI）、半径和起始桩号，其设计纵断面（竖曲线交点 PVI 和曲线长度），以及道路模型设置
- 平台和带规则的管网

不保存撤销历史。曲面、等高线、坡脚线和土方量不予存储；项目打开时会根据保存的输入数据重新生成。来自更新版 CivilCraft 的项目文件会被拒绝，并显示说明其版本号的消息。

## 导出的内容

| 按钮 | 文件 | 内容 |
|---|---|---|
| {{ui:LandXML}} | `<name>.xml` | LandXML 1.2：点、现状地面（有设计曲面时还包括设计曲面，均为 TIN 曲面）、线形、地面和设计纵断面、管网 |
| {{ui:DXF}} | `<name>.dxf` | 按当前显示状态导出的平面线条，R12 DXF 格式，位于命名图层上 |
| {{ui:DWG}} | `<name>.dwg` | 相同的线条，保存为 DWG 图形，版本可选（2000 至 2018） |
| {{ui:PDF}} | `<name>.pdf` | 平面图在图纸上的矢量打印，比例可选 |
| {{ui:GLB}} 或 {{ui:OBJ}}（位于 3D 视图工具栏上） | `<name>-3d.glb`、`<name>-3d.obj` | 3D 视图所显示的三维模型：单位为米，Y 轴朝上，真实比例，围绕记录的本地原点 |

各项未包含的内容：[LandXML 交换](topic:landxml)、[将平面图导出为 DXF](topic:dxf-export)（DWG 同样）、[将平面图打印为 PDF](topic:plot-pdf)、[将场地导出为 3D](topic:export-3d)。

## 文件保存位置

已保存和导出的文件会存放在浏览器下载内容的位置，通常是“下载”文件夹。若要每次都选择文件夹：

:::chromium
打开浏览器的 **设置**，然后选择 **下载内容**，并开启 **下载每个文件前询问保存位置**。
:::

:::firefox
打开 **设置**，然后选择 **常规**，在 **文件和应用程序** 下选择 **每次都询问保存文件的位置**。
:::

:::safari
打开 **Safari > 设置 > 通用**，并将 **文件下载位置** 设为 **每次下载时询问**。
:::

如果两次保存使用了相同的名称，浏览器可能会为第二个文件添加编号，例如 `Site (1).civilcraft.json`。下次请打开最新的那个。

## 联机和离线

无论哪种方式，CivilCraft 都只在计算机上运行：打开时在浏览器中读取文件，保存时则下载文件。若要在完全没有网络连接的情况下打开 CivilCraft，请先将其保存为离线使用：

1. 在联网时，点击顶部应用栏中的 {{ui:Save for offline}}。
2. 按钮会显示计数（“保存中（12 / 30）”），然后显示 {{ui:Offline ready}}。CivilCraft 体积较小（约 0.6 MB），因此这需要一点时间。保存的副本包括本帮助和示例场地。
3. 没有网络连接时，打开同一地址（或其书签）。一切功能正常，包括 {{ui:Open the sample site}}。

按钮的其他状态：

- {{ui:Could not save}}：部分文件未能下载。检查网络连接，然后点击它重试。
- {{ui:Offline not available}}：此浏览器窗口无法保存离线副本（私密窗口和某些受管理的计算机会阻止此操作）。请使用普通窗口。

点击 {{ui:Offline ready}} 可查看副本的保存时间，并有两个选项：{{ui:Save again (get the newest version)}} 和 {{ui:Remove the offline copy}}。在去现场之前重新保存，使副本与最新版本一致。更多信息见 [离线](common:offline)。

:::offline
当前处于离线状态。如果 CivilCraft 已保存为离线使用，一切功能正常，包括示例场地。如果没有，请继续在此标签页中工作，但在恢复联网前不要刷新页面；没有已保存的副本时，{{ui:Open the sample site}} 会失败，并显示“示例无法加载”。
:::

:::tip
外勤使用时，请将 CivilCraft 保存为离线使用，并把点文件直接带到笔记本电脑上。无连接时，项目和导出文件仍会作为下载保存，因此可以在现场导入当天的测量数据、检查曲面并保存项目。
:::

云端保存暂不可用，桌面版也尚未推出。目前，保存的文件是唯一的副本：请将其存放在有备份的位置。

## 文件使用的插件

保存包含插件数据的项目时（例如 **建筑法规** 复选框，或 **地址转场地** 数据源），文件会记录所用的插件及其版本。在缺少该插件的计算机上打开时，平面图上方会显示提示栏，并提供从账户列表中添加该插件的选项。该记录仅作备注：无论如何文件都能打开。

## 从 Studio 撤销

在 CadCraft Studio 中，您在 CivilCraft 中完成的每一步都会告知 Studio，因此其项目级撤销可以跨应用撤销最近一步。只有当 CivilCraft 自身的撤销栈与该步骤完成时的状态完全一致时，Studio 才会撤销该步骤；打开其他文件后，此窗口将被跳过。

## 有未保存更改时关闭

当项目有未保存的更改时关闭标签页、刷新或离开页面，浏览器会询问是否离开。其措辞和外观由浏览器决定，CivilCraft 无法更改。{{ui:New}}，以及打开项目或 LandXML 文件时，则会在 CivilCraft 自己的 **未保存的更改** 框中询问，其中有 {{ui:Cancel}}、{{ui:Don’t save}} 和 {{ui:Save a copy}}。

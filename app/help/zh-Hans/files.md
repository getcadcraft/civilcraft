CivilCraft 从电脑中打开文件，保存时通过下载把文件存回电脑。文件不会上传，也不会保存在服务器上。另请参阅 [你的文件](common:your-files)。

## 可打开的文件

点击 {{ui:打开}}（或按 {{key:Mod+O}}）并选择文件，或将文件从 {{pick:mac=访达|windows=文件资源管理器|linux=文件管理器}} 拖到平面图上。每次打开一个文件；超过 200 MB 的文件会被拒绝。

| 类型 | 文件名 | 结果 |
|---|---|---|
| 点文件 | `.csv`、`.txt`、`.pnt`、`.xyz`（任意文本文件） | 会打开 **导入点** 对话框。这些点会替换项目中的点；线形、场地和管道保持不变。 |
| LandXML | `.xml`、`.landxml` | 根据该文件创建**新项目**（如果当前项目有未保存的更改，会先询问）。 |
| CivilCraft 项目 | `.civilcraft.json`（任意 `.json`） | 项目会按保存时的状态打开（如果当前项目有未保存的更改，会先询问）。 |

CivilCraft 先根据文件结尾判断，再根据开头的字符判断：以 `{` 开头的文本按项目读取，以 `<` 开头的按 LandXML 读取，其他按点文件读取。打开框中显示为灰色的文件仍可拖放到平面图上。

:::note
如果项目中已有点，导入点文件会直接替换这些点，不再询问，并清空撤销历史（打开任何文件都会重新开始记录撤销）。如果曲面来自 LandXML，导入点后会改回由这些点生成的曲面。如果以后可能还需要旧的点，请先保存。
:::

详见：[点文件格式](topic:point-file-formats)、[LandXML：读取和写入的内容](topic:landxml-reference)。

## 保存的文件

{{ui:保存}}（{{key:Mod+S}}）会并排写入两个文件，文件名取自左侧面板中的**名称**：`<name>.civilcraft.json`，即你继续编辑的项目；以及 `<name>.ifc`，即同一设计的 IFC 4.3 版本，供其他软件使用（参见 [IFC 导出与导入](topic:ifc)）。两个文件相互记录对方，IFC 中还附带一份压缩的项目副本，因此单独发送的 IFC 仍可完整地重新打开并继续编辑。

- **在 Studio 中**，两个文件会就地并排写入。
- **在 Chrome 和 Edge 中**，首次保存会要求选择文件夹，并把两个文件都写入该文件夹；之后的保存会写入同一文件夹。在文件夹询问中点击取消，则改为下载这两个文件。
- **在其他浏览器中**，两个文件都会下载，项目文件先下载。

打开任一文件时都会查找另一个文件。可以同时打开两个文件（或同时拖放两个文件），也可以只打开一个：在 Studio 中，会在同一文件夹中找到另一个文件；在浏览器中，CivilCraft 会询问是否添加它，或继续使用当前这个文件。如果 IFC 在 CivilCraft 保存之后被其他程序修改过，或者其中一个文件比另一个旧，项目会从较新的设计打开，问题面板会说明发生了什么，并提供 **立即保存**（会重新写入两个文件）和 **将 IFC 的几何图形显示为参考** 两个选项。被其他程序修改过的单独 IFC 会从其中的项目副本打开，只保留仍然匹配的内容：被修改的线形采用其几何图形，被删除的对象将被排除，其余修改会列出但不会采用。0.7.1 之前的项目文件仍按原样打开。

项目文件保存以下内容：

- 每个点（编号、坐标、高程、描述），以及它们所来自的点文件名称
- 曲面设置：分组选择、绘制的断裂线、边界、最长外侧边，以及从 LandXML 读取的 TIN
- 显示设置
- 线形及其 PI、半径和起始桩号、设计纵断面（PVI 和曲线长度），以及道路模型设置
- 场地和管网及其规则

项目文件不保存撤销历史。曲面、等高线、坡脚线和土方量不会被存储；打开项目时，它们会根据保存的输入数据重新生成。来自更新版本 CivilCraft 的项目文件会被拒绝打开，并显示说明其版本号的消息。

## 导出的文件

| 按钮 | 文件 | 内容 |
|---|---|---|
| {{ui:LandXML}} | `<name>.xml` | LandXML 1.2：点、现状地面（如果有已设计的曲面，也包括在内）作为 TIN 曲面，线形，地面和设计纵断面，管网 |
| {{ui:DXF}} | `<name>.dxf` | R12 DXF，平面线划按当前显示的内容导出，并放在命名图层上 |
| {{ui:DWG}} | `<name>.dwg` | 相同的线划，导出为 DWG 图形，格式可选（2000至2018） |
| {{ui:PDF}} | `<name>.pdf` | 平面图的矢量图，按所选比例输出到图纸上 |
| {{ui:GLB}} 或 {{ui:OBJ}}（位于三维视图的工具栏） | `<name>-3d.glb`、`<name>-3d.obj` | 三维视图所显示的三维模型：单位为米，Y 轴向上，真实比例，以记录下来的本地原点为基准 |

各导出格式省略的内容：[交换 LandXML](topic:landxml)、[将平面图导出为 DXF](topic:dxf-export)（DWG 同样适用）、[将平面图打印为 PDF](topic:plot-pdf)、[三维导出场地](topic:export-3d)。

## 文件的保存位置

保存和导出的文件会放在浏览器下载的位置，通常是“下载”文件夹。要每次都选择文件夹：

:::chromium
打开浏览器的**设置**，然后进入**下载**，并开启**下载前询问每个文件的保存位置**。
:::

:::firefox
打开**设置**，然后进入**常规**，在**文件和应用程序**下选择**总是询问保存文件的位置**。
:::

:::safari
打开 **Safari > 设置 > 通用**，并将**文件下载位置**设为**每次下载都询问**。
:::

如果两次保存使用了相同的名称，浏览器可能会为第二个文件添加编号，例如 `Site (1).civilcraft.json`。下次打开编号最新的那个文件即可。

## 在线与离线

无论是否联网，CivilCraft 都只在电脑上工作：打开时在浏览器中读取文件，保存时将其下载到电脑。要在完全没有网络连接时打开 CivilCraft，请先在联网时保存为离线使用：

1. 联网时，点击顶部应用栏中的{{ui:保存以供离线使用}}。
2. 按钮数字会递增（“正在保存 12 / 30”），然后显示{{ui:离线可用}}。CivilCraft 较小（约 0.6 MB），因此需要片刻。保存的副本包括本帮助和示例场地。
3. 没有网络连接时，打开同一地址（或其书签）。一切都可以使用，包括{{ui:打开示例场地}}。

按钮的其他状态：

- {{ui:无法保存}}：部分文件未能下载。检查网络连接后再点击重试。
- {{ui:无法离线使用}}：此浏览器窗口无法保留离线副本（隐私窗口和部分受管理的电脑会阻止此功能）。请使用普通窗口。

点击{{ui:离线可用}}可查看副本的保存时间，并提供两个选项：{{ui:重新保存（获取最新版本）}}和{{ui:移除离线副本}}。现场查看前请先重新保存，使副本与最新版本一致。更多内容见 [离线](common:offline)。

:::offline
当前处于离线状态。如果 CivilCraft 已保存为离线使用，一切都可以使用，包括示例场地。如果没有，请留在此标签页中继续工作，但在恢复联网之前不要刷新页面；没有保存的副本时，{{ui:打开示例场地}}会失败，并显示“示例无法加载”。
:::

:::tip
在野外使用时，请将 CivilCraft 保存为离线使用，并把点文件直接放到笔记本电脑上。项目和导出文件在无网络时也会作为下载保存，因此可以在现场导入一天的测量数据、检查曲面并保存项目。
:::

云存储尚不可用，桌面版也尚未推出。目前保存的文件是唯一副本：请将它们存放在有备份的地方。

## 文件使用的插件

保存包含插件数据的项目时（例如“建筑法规”复选框，或“地址到场地”来源），文件会记录所用的插件及其版本。在未安装该插件的电脑上打开时，平面图上方会出现提示栏，并提供从账户中的列表添加该插件的选项。这一记录只是备注：无论如何文件都会打开。

## 在 Studio 中撤销

在 CadCraft Studio 中，你在 CivilCraft 里完成的每个步骤都会告知 Studio，因此 Studio 的项目级撤销可以在各应用之间撤销最近的一步。只有当 CivilCraft 自身的撤销栈与该步骤完成时的状态完全一致时，Studio 才会撤销该步骤；打开其他文件后，它会跳过此窗口。

## 关闭时有未保存的更改

当项目有未保存的更改，而你关闭标签页、刷新或离开页面时，浏览器会询问是否离开。其措辞和外观由浏览器决定，CivilCraft 无法更改。{{ui:新建}}，以及打开项目或 LandXML 文件，则会在 CivilCraft 自己的**未保存的更改**对话框中询问，并提供{{ui:取消}}、{{ui:不保存}}和{{ui:保存副本}}。

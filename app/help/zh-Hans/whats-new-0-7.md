本页说明 CivilCraft 0.7 相对 0.6 的变化。最主要的新增内容是电力线和景观工作空间以及建筑体量。

## 新增

### 景观工作空间

- **与同一场地共用的景观工作空间。** {{ui:曲面}} › {{ui:更多}} › {{ui:景观工作空间}} 会在你已有的场地上添加种植、平整、硬质景观和灌溉工具：使用相同的点、曲面和项目文件。在 **工作空间** 下选择 **土木** 即可返回。参见 [景观工作空间](topic:landscape)。
- **植物清单。** 约 420 种常见温带和地中海气候的乔木、灌木、绿篱、草本、多年生植物、地被植物和攀缘植物，包括种植时和成熟时的尺寸、耐寒区、光照、水分需求和株距。可用英文、西班牙语或葡萄牙语的任何名称搜索。可以将你自己的清单以 CSV 导入，并随项目保存。内置尺寸为典型值且经过取整：请向当地苗圃核实。参见 [植物清单](topic:plant-list)。
- **种植方案。** {{ui:植物}} 放置贴地的单株植物，并随后续平整而调整；{{ui:种植床}} 按植物株距在轮廓内填充，并按百分比混合；{{ui:绿篱}} 沿一条线设置一行或两行。植物会在图上标注。参见 [种植方案与明细表](topic:planting)。
- **植物明细表。** 更多 › {{ui:植物明细表…}} 按品种和种植规格统计植物数量。可保存为 CSV 或 XLSX，或发送至 TakeoffCraft 计价。参见 [植物明细表](topic:planting#the-plant-schedule)。
- **景观平整。** {{ui:平整}} 提供平台（水平或有坡度）、土堤、排水沟，以及可拖动的带标高点和等高线的平整区域。挖方和填方会随操作实时显示。**坡度分析** 按你自己设定的两个限值为曲面着色，**流向箭头和积水** 显示水流方向及可能积水的位置。所有内容都会加入与平台和道路模型相同的设计曲面。参见 [景观平整](topic:landscape-grading)。
- **铺装、小径、墙体、路缘、坡道和台阶。** {{ui:硬质景观}} 可绘制带横坡或向排水口放坡的铺装，并设置图案及其分层；可沿地面延伸的小径；带阶梯式基础的挡土墙和独立墙；路缘；以及按你设定的限值检查的坡道和台阶。高于1.2 m（4 ft）的挡土墙会被标记，提示由工程师复核。参见 [铺装、墙体与台阶](topic:hardscape)。
- **灌溉计算辅助。** {{ui:灌溉}} 可放置喷头、支管、主管、阀门、滴灌管和接入点。{{ui:检查系统…}} 会从管道中识别分区，并计算每个分区的流量、阀门处及水源所需的压力（Hazen–Williams 公式）、降水量、运行时间、覆盖率和材料清单。它只是计算辅助，而非设计认证：灌溉设计师需复核每项结果。喷头为通用类型，或为你从文件中导入的自有喷头。参见 [灌溉设计](topic:irrigation)。
- **景观图纸。** 更多 › {{ui:景观图纸…}} 生成种植、平整和灌溉图纸及其图例，并将墙体剖面、铺装构造和台阶的详图页合并为一个 PDF。参见 [景观图纸](topic:landscape-sheets)。
- **自由形态对象。** 更多 › {{ui:自由形态对象…}} 可放置在其他软件中制作的 STL、OBJ 或库网格，例如花盆或雕塑。它可以位于地面上或嵌入地面，并统计其体积、面积和占地面积。参见 [自由形态对象](topic:freeform-objects)。
- **景观 IFC。** 更多 › {{ui:导出景观 IFC}} 将植物（以带属性的植被形式）、硬质景观和自由形态对象保存为 IFC 4.3，用于 BIM 模型。参见 [IFC](topic:planting#ifc)。
- **从头到尾。** [从头到尾设计一个花园](topic:landscape-walkthrough) 以示例场地带你完整体验整个工作空间。

### 电力线工作空间

- **场地上的架空线路和地下电缆。** {{ui:曲面}} › {{ui:更多}} › {{ui:电力线工作空间}}：按支撑点绘制线路，沟槽中敷设电缆，并可绘制设备和障碍物，与地面及项目文件位于同一场所。参见 [电力线工作空间](topic:power-lines)。
- **你自己的库。** 导线、电缆、支撑、设备（横担、绝缘子、金具、拉线、变压器、柜体、接头）以及沟槽类型，按你命名的类别分类，可作为文件或电子表格共享。未内置任何国家或厂商的目录；示例会注明其仅为示例。参见 [电力线库](topic:power-line-library)。
- **按你的荷载工况计算垂度与张力。** 温度、风、覆冰以及单侧覆冰；张力限值取拉断强度的一定比例；每一跨均采用精确悬链线（包括坡地）；并生成架线表。参见 [垂度与张力](topic:sag-and-tension)。
- **随时更新的检查。** 对地面和障碍物的净距、相间距、绝缘子摆动、上拔、基于库尺寸的支撑荷载校核、拉线、金具、基础、缺失数据、断开的电缆、过载和电压降，均会在平面图和线路纵断面上标记。仅为设计辅助，需由工程师复核。参见 [电力线检查](topic:power-line-checks)。
- **表格、图纸与 GIS。** 架线表和支撑表，工程量（CSV、Excel、TakeoffCraft），平面和纵断面图纸及一份 PDF 中的研究报告，以及包含每项资产全部数据的 GIS 图层。参见 [电力线表格、工程量、图纸与 GIS](topic:power-line-outputs)。
- **首次尝试之后。** 线路纵断面跟随你选中的线路，并带有**线路**列表；可读取指针下的地面、导线和净距，并测量两点之间的距离。景观植物和墙体在线路下方视为障碍物；电缆路径和管道显示在线路纵断面中，并按你选择的净距规则与其交叉；每个净距旁的 **规则…** 会打开你自己的规则；带库的规则集可保存为按国家分享的规则包。参见 [电力线检查](topic:power-line-checks) 和 [规则包](topic:sag-and-tension#packs-rules-and-a-library-for-a-country)。
- **你自己的文件格式。** 电力线保存在 CivilCraft 项目文件中，库保存为 `.cclines.json` 或 CSV，规则集和规则包保存为各自的 JSON 文件：任何人都能读取或转换的开放格式。`.DON` 研究文件是与之并列的额外导入和导出格式。
- **研究文件（.DON），未经测试。** 可将线路保存为供另一款线路软件使用的 `.DON` 研究文件，或读取其中的支撑；该功能依据格式的字段名称编写，尚未与该软件进行测试。参见 [研究文件](topic:power-line-study-file)。

### 测量

- **测量工具。** {{ui:曲面}} › {{ui:更多}} › {{ui:测量}}（或 {{key:M}}）可在平面图上测量：每条边的长度和方位角、累计长度、沿地面的长度和坡度；闭合图形后还可测量面积和周长。测量不会在项目中绘制任何内容。参见 [测量](topic:measure)。

### 建筑体量

- **绘制建筑体量。** 在属性面板的 **建筑体量** 下，点击 {{ui:绘制体量}}（也可通过 {{ui:曲面}} › {{ui:更多}} › {{ui:体量}}）。为体量设置层数和层高，并读取其总建筑面积。选择它在坡地上的放置方式（阶梯式、裙房式或切挖式），并查看填方和挖方。体量会出现在平面图和 PDF 中，并在 DWG 和 DXF 中各自占用独立图层。参见 [在场地上绘制建筑体量](topic:building-masses)。
- **三维中的推拉。** 在三维视图中，拖动选中体量的屋顶，或按 {{key:PageUp}} 和 {{key:PageDown}}，即可按层逐层修改，并且只占一步撤销。**日照** 可投射体量的阴影。参见 [在三维视图中](topic:building-masses#in-the-3d-view)。
- **可输入的分区限制。** 从街道边线逐条设置退界，以及高度限制、天空暴露面、容积率和建筑密度。可建包络线会在平面图上绘制，每个体量针对每项限制都会显示勾或叉。CivilCraft 中没有任何分区规范：每个数值都需你从自己的条例中输入。参见 [按你输入的分区限制检查体量](topic:zoning-limits)。
- **日照时数。** 选择某一天或某个季节，并按名称或偏移量选择时区，即可读取每个体量每面墙体（逐层）及其周围地面的直射日照时数，并在平面图上绘制。可将墙体和地面保存为 CSV。项目需要设定坐标系。参见 [计算场地的日照时数](topic:sun-hours)。
- **导出为 IFC，并转至 BimCraft。** {{ui:体量导出为 IFC}} 将体量保存为 IFC4，项目设有坐标系时会放置在地图上。{{ui:在 BimCraft 中深化}} 会在新标签页中打开 BimCraft 并载入这些体量，其中 **深化此体量** 将在每个楼层建造墙体，并根据占地轮廓生成楼板。不会上传任何内容。参见 [发送到下一步](topic:building-masses#send-it-on)。

### 路线

- **回旋曲线。** 在 PI 表中为曲线输入 **入口缓和曲线** 和 **出口缓和曲线** 的长度：切线、缓和曲线、圆曲线、缓和曲线、切线，两侧长度可相同也可不同。平面图标注 TS、SC、CS 和 ST；曲线列表给出 θs 以及切线长和外距；桩号与偏移量沿缓和曲线连续。参见 [缓和曲线](topic:alignment#spirals)。
- **LandXML 中的缓和曲线。** LandXML 可写入和读取回旋曲线。含缓和曲线的路线（以前 CivilCraft 导入时会跳过）现在可以打开。参见 [交换 LandXML](topic:landxml)。

### 道路模型

- **分部件构建每一侧。** 开启 **分部件构建每一侧**，即可从中线向外为每一侧设置独立列表：车道、路肩、边沟、路缘、绿化带、人行道以及带有各自挖填的边坡。可从 {{ui:乡村道路}} 或 {{ui:城市街道}} 开始，并将一侧复制到另一侧。横断面会标记排水线、路缘和人行道，平整后的曲面包含路缘。参见 [分部件构建每一侧](topic:corridor#build-each-side-from-parts)。
- **回旋曲线上的超高。** 对于带缓和曲线的曲线，超高渐变段沿缓和曲线进行：在 TS 处为水平路拱，在 SC 处为完整超高。参见 [超高](topic:corridor#superelevation)。

### 三维文件

- **USD 导出。** 在三维视图中，{{ui:USD}} 会以真实比例和项目坐标，将场地写入 `.usda`、`.usdc` 或 `.usdz`：曲面、管道和构筑物为网格，路线（每条路线）及带编号的测量点也一并写入。参见 [将三维场地导出为 USD](topic:usd)。

### AI 助手

- **为助手提供更多功能。** 在 {{ui:设置}} › {{ui:CivilCraft}} 中开启助手后，助手现在还可以读取地块、填挖方和纵断面，添加点，保存项目，导出 LandXML、DWG 和 USD，并在 CadCraft Studio 中你选择的文件夹内工作。景观工作空间新增用于查找植物、放置植物、种植床和绿篱、平整以及检查灌溉的工具。文件服务器和 `cadcraft` 命令行可在没有窗口的情况下打开已保存的项目。参见 [让 AI 助手处理你的场地](topic:assistants)。

## 所有应用通用

- **单位。** {{ui:设置}} › {{ui:常规}} › {{ui:单位}} 为长度、面积、体积、角度和坡度各设一个列表，其尺寸与单位定义完全一致（美国测量英尺是独立单位）。关闭你从不使用的单位，它们会从单位列表中移除；为某个单位加星标，新工作便会以该单位开始。文件始终保留其自身的单位。在 CivilCraft 中，项目的 **单位** 列表随开关变化：公制长度加星标时新项目以米为单位（否则为英尺，即美国测量英尺）；面积或体积加星标则设定面积和体积的报告单位；长度输入框接受任何单位的符号，例如 `3 ch` 或 `450 mm`。参见 [单位、键入的数值与单位列表](common:unit-lists)。
- **更紧凑的布局，以及可收起的面板。** {{ui:设置}} › {{ui:常规}} › {{ui:布局密度}} › {{ui:紧凑}} 可在屏幕上容纳更多内容（触摸屏和手机保留较大按钮）。每个侧边面板都有细窄的标题栏：拖动即可停靠或浮动面板；将其放到另一面板的标题栏上，即可共用同一框架并以选项卡形式呈现；固定后可滑入边缘，或隐藏后从边缘调出。参见 [安排面板](common:arrange-panels#make-the-layout-denser)。
- **对话框可移动。** 拖动对话框的标题栏即可将其移出绘图区；它会回到你上次所在的位置。双击标题栏可重新居中。参见 [移动对话框](common:arrange-panels#move-a-dialog)。
- **AI 助手示例。** 为你自己的助手提供十个示例请求（整理图形、打印图纸集、检查图纸、向模型提问、汇总算量、试用零件变体……），每个都列出其调用的工具和所需权限，并由我们的测试重放。应用本身不包含 AI。参见 [AI 助手示例](common:assistants-recipes)。
- **语言。** **Português (Portugal)** 为 {{ui:设置}} › {{ui:常规}} › {{ui:语言}} 的新增语言。它与 **Português (Brasil)**、**Español (México)** 和 **Bahasa Indonesia** 现在都提供了全部应用文字，但均为尚未经母语者审校的草稿。帮助主题为英文，少数为西班牙文。
- **CadCraft Studio** 会说明更新检查失败的原因（尚无适用于你的系统的文件、无网络、签名错误），而不是只显示"完成"；并且在出现更新版本之前，不会再把你关闭的"新增功能"卡片调回来。

## 尚未包含在此版本中

- **0.7 未进行代码签名。** 签名以及 Microsoft Store 包已推迟到 0.8，因为证书验证尚未完成。请在 getcadcraft.com/download 上核对每个文件旁的 SHA-256。在 Windows 上，若 SmartScreen 阻止安装程序，请选择 {{ui:更多信息}}，然后选择 {{ui:仍要运行}}。在 Mac 上，首次运行时请右键点击 CadCraft Studio 并选择 {{ui:打开}}。CadCraft Studio 尚未在应用商店中上架，也暂无 iPad 或 iPhone 版本。
- {{ui:单位}} 中的角度和坡度列表已保存，但目前尚无输入框读取它们。
- 厂商的灌溉喷头：仅有通用喷头和你从文件导入的自有喷头。厂商数据仅在其许可的情况下提供，目前尚未获得任何许可。
- BimCraft 和 ModelCraft 带有植物清单，但其“从库放置”尚不提供植物。植物通过景观 IFC 进入 BimCraft。
- 面向助手的景观工具仅在 CivilCraft 窗口打开时工作；文件服务器和命令行目前尚不支持。
- 建筑体量：不包含立面的日照或风，不计算树木或未绘制为体量的物体造成的遮挡，不支持屋顶形状；日照时数显示在平面图上，而非三维视图中。在 BimCraft 中深化仅建造简单墙体和楼板，不含开洞或屋顶。
- 电力线：未内置任何国家标准（你需自行设定荷载工况、限值和净距）；不含导线蠕变、埋地电缆热定额、短路、保护或接地计算；三维视图和 IFC 中没有线路。`.DON` 研究文件尚未与读取它的软件进行测试。
- 除回旋曲线以外的缓和曲线、两条曲线之间的缓和曲线，以及特征线中的缓和曲线。缓和曲线已依据公式和 LandXML 架构进行核对，但尚未用其他软件生成的含缓和曲线的 LandXML 文件进行验证。
- 沿道路变化的道路模型断面组合、区域，以及边坡的目标值。
- 供水干管和压力管网（下一项土木工程）、随时间变化的流量，以及供水管网与雨水管网之间的连接。
- 绘制的断裂线中的圆弧。标准设计车辆表：随附的五种车辆均为占位符。在项目之间共享的特征线需等待团队项目功能。

其余内容见 [尚未实现](topic:not-built-yet)。

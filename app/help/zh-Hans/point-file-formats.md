点文件为纯文本，每行一个点。CivilCraft 在浏览器中读取它，不会上传任何内容。

## 列顺序

字母按从左到右的顺序表示各列：**P** 点号或名称，**N** 北坐标，**E** 东坐标，**Z** 高程，**D** 描述。

| 顺序 | 列 | 示例行 |
|---|---|---|
| PNEZD | 点号、北坐标、东坐标、高程、描述 | `101,2080000.00,6150000.00,250.00,GRD` |
| PENZD | 点号、东坐标、北坐标、高程、描述 | `101,6150000.00,2080000.00,250.00,GRD` |
| PNEZ | 点号、北坐标、东坐标、高程 | `101,2080000.00,6150000.00,250.00` |
| PENZ | 点号、东坐标、北坐标、高程 | `101,6150000.00,2080000.00,250.00` |
| NEZD | 北坐标、东坐标、高程、描述 | `2080000.00,6150000.00,250.00,GRD` |
| ENZD | 东坐标、北坐标、高程、描述 | `6150000.00,2080000.00,250.00,GRD` |
| NEZ | 北坐标、东坐标、高程 | `2080000.00 6150000.00 250.00` |
| ENZ | 东坐标、北坐标、高程 | `6150000.00 2080000.00 250.00` |

不含 P 的顺序按文件中的顺序将点编号为 1、2、3 … 。X 为东坐标，Y 为北坐标。

## 分隔符

CivilCraft 检查前 20 行，并选择其中至少在 60% 的行中出现的第一个分隔符：逗号、制表符、分号。否则按连续的空格分隔。

- 在逗号、制表符和分号分隔的文件中，双引号内的字段可以包含分隔符（`"FL, NORTH"`），引号内的 `""` 表示一个引号。
- 在空格分隔的文件中，行末的描述可以包含空格：最后一个坐标列之后的全部内容均为描述。
- 以 `#`、`;` 或 `//` 开头的行以及空行将被跳过。
- 文件开头的字节顺序标记将被忽略。

## 标题行

当第一行中数字字段少于两个时，该行被视为标题行。若标题的每个字段都是 CivilCraft 可识别的名称，则列顺序由标题决定（“来自标题行”）。名称匹配时不区分大小写，并忽略空格、点、下划线、连字符和括号：

| 列 | 可识别的名称 |
|---|---|
| P | pt, pnt, point, point no, point number, number, no, id, name, pt#, point#, # |
| N | n, north, northing, y, y coord, lat, latitude |
| E | e, east, easting, x, x coord, lon, long, longitude |
| Z | z, elev, elevation, el, height, h, z coord, rl |
| D | d, desc, description, code, raw description, full description, note, notes, feature |

若标题中有任何名称无法识别，或这些名称无法构成八种顺序之一，则跳过标题行，并根据列数推断顺序。

:::warning
同时包含纬度列（`lat`、`latitude`）和经度列（`lon`、`long`、`longitude`）的标题行，将按度读取，而不按北坐标和东坐标读取。在{{ui:导入}}时，点会通过项目的坐标系进行转换；若项目没有坐标系，则会先要求你选择。超出 ±90° 纬度或 ±180° 经度范围的行将被拒绝。参见[导入 GIS 数据](topic:gis-import#point-files-with-latitude-and-longitude)。
:::

## 根据列数推断

在没有可用标题且**列**保持为{{ui:检测}}的情况下：

- 5 列或更多：PNEZD。
- 4 列：当第一列在每个采样行中都是整数且第四列为数字时为 PNEZ；否则为 NEZD。
- 3 列：NEZ。

PNEZD 与 PENZD 无法仅凭数字区分。推断依据为 [CivilCraft 设置](topic:settings)中的**点行**：开头为 P、N、E、Z、D，或为 P、E、N、Z、D（此时四列读取为 PENZ，三列读取为 ENZ）。对话框会显示“根据列数推断——请检查北坐标和东坐标是否互换”。若预览有误，请在**列**中选择正确的顺序。

## 行的检查方式

- 行可以省略描述。
- 北坐标和东坐标必须为数字。高程可以为空（该点保留，但不用于曲面）。
- 点号可以是任意文本（也可包含字母，例如 `CP1`），但不能为空。
- 若点号重复，则保留第一行，其余行列为未读取。
- 描述最多保留 200 个字符；控制字符将被转换为空格。
- 最多保留 200 个未读取的行供对话框显示（显示 25 个），并对所有行进行计数。

## 点组

点所属的组为其描述中首个单词的大写形式。“GRD”、“grd shot”和“Grd”都属于 GRD 组。没有描述的点位于“（无描述）”组中。参见[导入测量点](topic:import-points)。

## 写入点

CivilCraft 尚不能导出点文本文件。点可以以 LandXML（作为 CgPoints）形式输出，保存在项目文件中，或通过 GIS 的{{ui:导出}}以带有 P、N、E、Z 和 D 字段的 shapefile、GeoPackage 或 GeoJSON 形式输出（[导出竣工数据到 GIS](topic:gis-export)）。参见[尚未实现](topic:not-built-yet)。

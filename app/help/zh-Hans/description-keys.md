测量人员在现场对每个测点进行编码：`EP` 表示路面边缘，`TC` 表示路缘石顶部，`BLDG` 表示建筑角点。编码即为点描述的第一个词。CivilCraft 据此对点进行分组，并将其后的线代码转换为线。

## 线代码

线代码即紧跟在现场编码之后的词：

| 描述 | 含义 |
|---|---|
| `EP B` | 在此点开始一条新的路面边缘线 |
| `EP` | 延续当前的 EP 线 |
| `EP E` | 在此点结束当前的 EP 线 |
| `BLDG C` | 闭合建筑：将此点与线的第一个点相连 |

编码相同的点按点号顺序连接。即使同属一个组，不同编码也代表不同的线，因此 `EP1` 和 `EP2` 会同时生成两条边线。从未使用线代码的编码，会如早期版本那样，依次连接其所有点。

用作**断裂线**的组中，各线分别成为断裂线（每条线一条），因此有缺口的路缘石不会横跨缺口延伸。其他组中的线绘制在平面图上（图层 V-NODE-LINE），并输出至 DXF、DWG 和 PDF。

表示起点、终点和闭合的词分别为 `B`、`BEG`、`START`；`E`、`END`；以及 `C`、`CLO`、`CLOSE`。可在下方的对话框中更改这些词，或关闭线代码。

## 描述关键字

描述关键字可将编码转换为点组、用途和详细描述。

1. 在**点数**下，单击{{ui:描述关键字和线代码}}。
2. 单击{{ui:添加关键字}}，并填写该行：
   - **编码**：要匹配的现场编码。`*` 代表任意多个字符，`?` 代表一个字符，因此 `EP*` 可匹配 EP、EP1 和 EP12。
   - **组**：这些点所归入的点组（留空 = 编码本身）。`EP*` 配合组 `EP` 可将 EP1 和 EP2 置于同一组，同时它们仍为各自独立的线。
   - **用途**：点、断裂线或不纳入，用于该组首次出现时（或交由**点数**表设定）。
   - **描述**：详细名称，显示在点的**属性**中。
3. 输入时统计每个关键字所匹配的点数。与编码匹配的第一个关键字生效。
4. 单击{{ui:应用}}。点组、曲面和平面图随之一步更新：{{key:Mod+Z}} 可将其撤销。

点组保留其在**点数**表中设定的用途；关键字的用途仅对新出现的点组生效。关键字和线代码保存在项目文件中。

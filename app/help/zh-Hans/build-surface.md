每个项目只有一个现状地面曲面。它是由你的点生成的 TIN（不规则三角网），每当输入发生变化时都会自动重建。没有“重建”命令，也不会出现过期的曲面。

## 曲面包含的内容

- 所有位于设为{{ui:点数}}的组中、且带有高程的点。
- 所有设为{{ui:断裂线}}的组，按点号顺序连接。
- 你用{{ui:断裂线}}工具绘制的每条断裂线。
- 外边界（如果你绘制了）。
- **最长外侧边**设置。

三角形绝不跨越断裂线：曲面被迫沿断裂线生成，然后在其周围尽可能均匀地划分（其余区域为 Delaunay 剖分）。

## 将编码线转为断裂线

1. 在左侧面板的**点数**下找到该组（例如 FL）。
2. 将其**曲面**选项设为{{ui:断裂线}}。
   曲面会重建，该线以橙色绘制（需在**显示**下开启{{ui:断裂线}}），曲面信息中的**断裂线**数量增加 1。
3. 在平面图上检查该线。它必须按测量时的顺序逐点相连。若出现折线，说明该组包含多条线，或点号顺序不正确：请将该组改回{{ui:点数}}，然后手动绘制这些线（见下一节）。

## 通过点绘制断裂线

1. 按{{key:B}}，或点击**曲面**组中的{{ui:断裂线}}。
   提示显示：“断裂线：按顺序点击测量点（采用其高程）。按Enter键结束。”
2. 将指针移近某个点，一个小橙色方块会标记它将采用的点。
3. 依次点击线上的各点。每次点击，状态栏都会显示该点的名称及其高程。
4. 按{{key:Enter}}结束。
   状态栏显示：“已添加断裂线 1；曲面已重建。”

点击必须落在带有高程的测量点上；点击其他位置会被拒绝，并提示：“请点击带有高程的测量点：断裂线采用各点的高程。”{{key:Backspace}}删除最后一个点，{{key:Esc}}取消整条线。

:::warning
完成时请按{{key:Enter}}。双击也能结束，但在此版本中，它会删除你双击的那个点。请单击最后一个点一次，然后按{{key:Enter}}。
:::

若要一次删除所有已绘制的断裂线，请点击**曲面**部分中的{{ui:移除已绘制的断裂线}}。若只删除最后一条，请使用{{key:Mod+Z}}。目前尚不能逐条选择或编辑已绘制的断裂线。

## 绘制外边界

边界将曲面裁剪到你可信的范围内，例如测量范围，从而去除跨越未测量角落的狭长三角形。

1. 按{{key:O}}，或点击{{ui:边界}}。
2. 沿区域的边角依次点击。虚线会显示其形状。
3. 按{{key:Enter}}。
   状态栏显示：“已设置边界；边界外的三角形已删除。”曲面信息中的**边界**显示“是”，并给出角点数。

注意事项：

- 只能有一个边界。再绘制一个会替换原有边界。{{ui:移除边界}}可将其移除。
- 边界只能去除内容：若边界超出了各点的范围，会被裁剪回这些点的轮廓，并附注：“边界超出了各点的范围；已裁剪至其轮廓。”
- 其角点的高程取自曲面，因此边缘会精确贴合地面。
- 暂不支持隐藏（内部）边界。

## 修剪外侧长三角形

没有边界时，曲面会填满各点的整个轮廓，包括跨越凹入边缘的狭长三角形。

1. 在**曲面**中，于**最长外侧边**中输入长度并按{{key:Enter}}。可从你常用测点间距的两到三倍开始。
2. 外边长于该值的外侧三角形会被删除，并逐步向内进行，直到所有外边都足够短。作为断裂线的边永远不会被剥离。
3. 输入 0 可恢复保留所有三角形。

## 阅读曲面报告

在曲面信息下方，一个方框列出了建模所执行的操作。左侧为赭色条的为信息；左侧为红色条的表示错误，且不会生成曲面。

| 消息 | 含义 |
|---|---|
| “3 个点与另一个点位于同一位置，并已与之合并。” | 平面上距离小于 0.0001 的点合并为一个顶点（保留第一个）。 |
| “有 2 处的高程不同……” | 重叠的点或相交的断裂线高程不一致。以断裂线的高程为准，其次取第一个。 |
| “有 1 段断裂线无法强制纳入曲面。” | 一段非常短或几乎重叠的断裂线无法契合；请检查该处。 |
| “曲面至少需要三个带高程的点。” | 点数过少：请检查列的顺序和组。 |
| “所有点都在同一条直线上：没有三角形。” | 这些点没有宽度，例如单条导线。 |
| “边界与各点不重叠。” | 边界位于别处，通常是单位或坐标混淆所致。 |
| “边界内已没有三角形。” | 边界过小或位置不对。 |

## 从 LandXML 读取的曲面

打开 LandXML 时，会原样使用其中第一个 TIN 曲面：**曲面**标题显示“曲面（来自 LandXML）”，**最长外侧边**呈灰色不可用。在使用该曲面期间，断裂线组、已绘制的断裂线和新的边界都不会改变它。若要改为使用文件中的点来生成曲面，请点击{{ui:由点重建曲面}}。{{key:Mod+Z}}可恢复 LandXML 曲面。

平面图上的所有内容都属于某个图层。图层名称遵循常见的土木图层命名规则（专业、主要分组、次要分组）。本版本中图层是固定的：无法重命名、更改颜色或添加自定义图层。在 DXF 中，每个图层都带有所示的颜色编号；在 PDF 中选择{{ui:图层颜色}}时使用相同的颜色；选择{{ui:黑色}}时，所有内容都以黑色打印。

| 图层 | 包含内容 | 颜色（DXF 编号） | 显示条件 |
|---|---|---|---|
| C-TOPO-MINR | 次要等高线 | 灰色(8) | {{ui:等高线}} |
| C-TOPO-MAJR | 主要等高线 | 白色或黑色(7) | {{ui:等高线}} |
| C-TOPO-TEXT | 等高线标注 | 白色或黑色(7) | {{ui:等高线}}和{{ui:等高线标注}} |
| C-TOPO-TINN | 三角形边 | 灰色(8) | {{ui:三角形}} |
| C-TOPO-BRKL | 断裂线和边界 | 橙色(30) | {{ui:断裂线}} |
| C-TOPO-BNDY | 曲面边缘 | 白色或黑色(7) | {{ui:曲面边缘}} |
| C-TOPO-SLOP | 坡向箭头 | 青色(4) | {{ui:坡向箭头}} |
| V-NODE | 测量点 | 绿色(3) | {{ui:点数}} |
| V-NODE-TEXT | 点标注：编号、高程、描述 | 绿色(3) | {{ui:点数}}和{{ui:点标注}} |
| V-NODE-LINE | 由线代码生成的线（非断裂线的分组） | 绿色(3) | {{ui:点数}} |
| C-ROAD-CNTR | 线形中线 | 红色(1) | 始终 |
| C-ROAD-STAN | 桩号刻度和标注，PC 和 PT | 红色(1) | 始终 |
| C-ROAD-CORR | 道路模型边缘 | 黄色(2) | 始终 |
| C-ROAD-SCTN | 采样线（剖面切取处） | 灰色(8) | 线形有采样线时 |
| C-GRAD-PADS | 平台轮廓 | 蓝色(5) | 始终 |
| C-GRAD-DAYL | 坡脚线 | 洋红色(6) | 始终 |
| C-GRAD-SLOP | 场地平整坡线 | 洋红色(6) | 始终 |
| C-GRAD-FEAT | 特征线（三维） | 绿色(3) | 始终 |
| C-ROAD-SWPT | 车辆轨迹：轮廓、最外侧车轮轨迹、名称 | 橙色(30) | 始终 |
| C-STRM-PIPE | 管道 | 蓝色(5) | {{ui:管道}} |
| C-STRM-STRC | 构筑物 | 蓝色(5) | {{ui:管道}} |
| C-STRM-TEXT | 管道和构筑物标注 | 蓝色(5) | {{ui:管道}} |
| C-STRM-PROB | 有问题的管道和构筑物 | 红色(1) | {{ui:管道}} |

只有在**显示**下的**曲面**为{{ui:现状地面}}时才绘制断裂线；边界则在两种曲面下都会绘制。

## PDF 中的线宽

| 线宽 | 图层 |
|---|---|
| 0.50 mm | 线形中线、平台、管道、有问题的管道 |
| 0.35 mm | 主要等高线、坡脚线、构筑物 |
| 0.25 mm | 断裂线 |
| 0.13 mm | 次要等高线 |
| 0.09 mm | 三角形边、场地平整坡线 |
| 0.18 mm | 其他全部 |

DXF 文件不包含线宽；请在 CAD 程序中按图层设置。

## 标注尺寸

标注按图纸上的尺寸确定：等高线标注2.0 mm，桩号标注1.8 mm，PC 和 PT 标注以及管道和构筑物标注1.6 mm，点标注1.5 mm。管道标注包含名称、管径和坡度；构筑物标注包含名称和井口标高。在屏幕上，缩放时它们保持相同大小。在 DXF 中，标注按导出信息中所示的比例进行缩放；参见[将平面图导出为 DXF](topic:dxf-export)。

## 不在任何图层上显示的内容

高程带仅在屏幕上绘制，位于线条下方。纵断面视图不属于平面图。

CivilCraft 没有设置对话框或模板。以下为各项内容的初始值。标注为**占位值**的数值并非取自任何标准：在依赖某项检查或工程量之前，请以项目的设计准则替换它们。

## 新项目

| 设置项 | 值 |
|---|---|
| 名称 | 未命名场地（第一个点文件的名称会替换它） |
| 单位 | 美国英尺 |
| 曲面名称 | 现状地面 |
| 点组 | 每个组初始均为{{ui:点数}} |
| 最长外边 | 0（保留每个三角形） |
| 保留的撤销步数 | 200 |

## 显示

| 设置项 | 值 |
|---|---|
| 曲面 | {{ui:现状地面}} |
| 等高线间距 | 1（ft 或 m） |
| 计曲线间隔 | 第 5 条等高线 |
| 带数 | 8 |
| 开 | 等高线、等高线标注、点、断裂线、曲面边缘、管道 |
| 关 | 三角形、高程带、坡向箭头、点标注 |

## 路线和纵断面

| 设置项 | 值 |
|---|---|
| 名称 | 路线 1、路线 2…… |
| 起点桩号 | 0+00 |
| 各内部 PI 处的曲线半径 | 100 ft 或 30 m；若装不下每段切线的一半，则取更小的值 |
| 设计纵断面 | 开始前无；{{ui:从地面开始}}会在两端的地面上各放置一个 PVI |
| 竖曲线长度 | 0（无曲线），直至输入数值 |

## 平台

| 设置项 | 值 |
|---|---|
| 名称 | 平台 1、平台 2…… |
| 高程 | 平台中部的地面高程，取整至 0.1（若中部不在曲面上则为 0） |
| 挖方边坡 | 2 : 1（占位值） |
| 填方边坡 | 3 : 1（占位值） |

## 道路模型断面组合（占位值）

| 设置项 | 美国英尺 | 米 |
|---|---|---|
| 车道宽度 | 12 ft | 3.6 m |
| 车道横坡 | 2% | 2% |
| 路肩宽度 | 4 ft | 1.2 m |
| 路肩横坡 | 4% | 4% |
| 挖方边坡 | 2 : 1 | 2 : 1 |
| 填方边坡 | 3 : 1 | 3 : 1 |
| 断面间距 | 10 ft | 5 m |

## 管网

| 设置项 | 美国英尺 | 米 |
|---|---|---|
| 名称和类型 | 雨水, 雨水 | 雨水, 雨水 |
| 最小坡度（占位值） | 0.50% | 0.50% |
| 最小覆土（占位值） | 2 ft | 0.6 m |
| 构筑物内跌落（占位值） | 0.10 ft | 0.03 m |
| 新构筑物直径 | 48 in | 1200 mm |
| 新管道直径 | 12 in | 300 mm |
| 集水坑深度 | 0 | 0 |
| 井口 | 取自曲面 | 取自曲面 |

从 LandXML 打开的管网同样采用这些规则，因为 LandXML 不包含这些规则。

## 体积

| 设置项 | 值 |
|---|---|
| 方法 | 格网，在坡脚线范围内于网格单元中心取样 |
| 单元尺寸 | 选取使放坡区域的外接矩形约含 250,000 个单元的尺寸（为 10 的整数次幂的 1、2 或 5 倍） |
| 膨胀和收缩 | 无 |

## 出图

| 设置项 | 值 |
|---|---|
| 范围 | {{ui:全部}} |
| 图纸 | Tabloid 11 × 17 in（英尺制项目），ISO A3（米制项目）；始终横向 |
| 比例 | 列出的、能容纳全部内容的最大比例 |
| 墨水颜色 | {{ui:图层颜色}} |

DXF 标注的尺寸按全部内容恰好能容纳于 Tabloid（英尺制）或 A3（米制）时的比例确定。

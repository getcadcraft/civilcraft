任何路线都可以成为铁路轨道。其曲线随后获得缓和曲线和超高（钢轨的横向倾斜），其走廊按轨道建造：钢轨铺设在轨枕上，轨枕坐落在道砟床上，并像道路一样按地面标高整平。道岔和渡线可按桩号设置，限界包络可沿线扫描，并与轨道旁的物体进行核对。

以下所有数值均为**占位值**，并非标准。铁路应根据线路速度、轨道类型和所在国家设定其限值；请依据本单位的铁路标准设置。CivilCraft 未内置任何国家的数值表。

## 将路线设为铁路

1. 选择路线，并在**属性**中找到**铁路**。
2. 勾选**此路线为铁路轨道**。每次更改为一个撤销步骤。
3. 在路线属性顶部设置**设计速度**：这是超高所依据校核的线路速度。**最慢列车**（位于铁路区块中）是用于校核过超高所依据的速度。

## 缓和曲线

在 PI 表中为每个曲线的两端设置缓和曲线长度（**入口缓和曲线**、**出口缓和曲线**），然后在铁路区块的曲线表中选择其类型，或使用**所有曲线采用缓和曲线**：

| 类型 | 缓和段上的曲率 |
|---|---|
| 回旋线 | 均匀增长（道路缓和曲线） |
| 三次抛物线 | y = x³ / (6·R·L)，L 沿切线量取；曲线本身略长 |
| Bloss | 完整曲率的 3u² − 2u³（u 为长度的比例）：起点和终点都很平缓 |
| Helmert | 两段抛物线，先为 2u²，然后为 1 − 2(1 − u)² |
| 正弦半波 | (1 − cos πu) / 2 |
| 正弦 | u − sin(2πu) / 2π |

除三次抛物线外，其余各类型均与回旋线一样，转角为 L / 2R。桩号沿实际长度推算。LandXML 保留其类型（spiType 为 clothoid、cubicParabola、bloss、biquadratic、cosine、sinusoid）。

## 超高

以毫米为单位输入每个曲线的**超高**。表格为每个曲线显示：

- **平衡超高** = G·v² / (g·R)，其中 G 为钢轨中心距（**钢轨中心距**，即轨距加上钢轨头宽，除非另行输入）。当 G = 1500 mm 时，即常见的 11.8·V² / R（V 以 km/h 计，R 以 m 计）。
- **欠超高** = 线路速度下的平衡超高 − 实设超高。
- **过超高** = 实设超高 − 最慢列车速度下的平衡超高。
- **顺坡**：沿其坡段的最陡超高坡度，单位为 mm/m。

超高在每个缓和曲线上逐步升高，其形状与曲率相同：回旋线或三次抛物线为直线，Bloss 为 Bloss 形，依此类推。曲线端部没有缓和曲线时，超高顺坡会在其前方的直线段上进行，长度满足超高坡度限值的要求，并会予以说明：此时超高的变化与曲率的变化不同步。

**超高绕轴旋转**说明哪一根钢轨保持在设计纵断面上：**低侧钢轨**（通常情况）、**内侧钢轨**，或**轨道中心**（每根钢轨移动超高的一半）。此处的设计纵断面即钢轨顶面。

**超高图**沿桩号在纵断面上绘制每根钢轨的高度。纵断面视图以及平面与纵断面图页会在纵断面下方以同样的带状形式显示相同内容。

## 超高限值与警告

对每个曲线检查**最大实设超高**、**最大欠超高**、**最大过超高**、**最陡超高坡度**和**最快超高变化**（线路速度下的坡度，单位 mm/s）。超过限值的数值在铁路区块和问题面板中以警告形式显示，并同时给出限值和实际数值。若未设置设计速度，则不检查欠超高和变化率（会有说明）。

## 轨道

设置**轨距**（标准 1435 mm、宽轨、米轨或窄轨预设值，或自定义）、**钢轨断面**（60E1、54E1、49E1、115RE、136RE：仅采用其公布的尺寸）、**轨道**数量及其**轨道中心距**，然后设置**轨枕与道砟**：轨枕材料、长度、宽度、高度和间距；轨枕下道砟的厚度（位于低侧钢轨处）、道砟肩宽、坡度，以及道砟顶面低于轨枕顶面的距离；底砟厚度、道砟坡脚以外的路肩宽度，以及路基横坡。

按**生成轨道**。这将在路线的走廊上开启，按设计纵断面将其建造为轨道：钢轨和轨枕随超高倾斜，路基则不倾斜。挖方和填方的放坡线从走廊的挖方和填方边坡处的路肩边缘延伸，轨道则像道路一样整平到设计地面。

- **平面**：每条轨道的两根钢轨（图层 C-RAIL-TRAK），以及在多于一条轨道时的每条轨道中心线（C-RAIL-CNTR）。它们显示在屏幕上，并输出至 DXF、DWG、PDF 以及平面与纵断面图页。
- **断面**：各断面中的轨枕、钢轨、道砟底面和底砟底面。
- **3D**：钢轨、每根轨枕和道砟床（显示 › 轨道），也可输出为 GLB、OBJ 和 USD。
- **工程量**：轨道长度、钢轨（每条轨道的两根钢轨，沿各自轨道的线路计算）、轨枕、道砟床，以及扣除轨枕后的道砟，还有底砟。工程量采用断面之间的平均端面积法计算。

## 轨道几何检查

除超高外，铁路区块还将线路本身与另外六项限值进行对比（均为占位值，均需自行设定）：

- **设计纵断面的最陡坡度**，单位 mm/m。
- **最小竖曲线半径**，以系数 k 表示，满足 R ≥ k·V²（R 以 m 计，V 以 km/h 计）。两个坡度之间长度为 L 的抛物线竖曲线，其半径为 L 除以坡度变化量。
- **最短竖曲线**。
- **平面最小曲线半径**（为 0 时关闭该检查）。
- **最短圆弧或直线**，以线路速度下的行车秒数表示：长度短于该距离的圆弧，或两曲线之间的直线，将发出警告。1.8 秒即常见的“公里每小时速度的一半，以米计”。
- **沿每个缓和曲线的欠超高变化率**，以线路速度下的 mm/s 计。

**轨道几何**列出所发现的最陡坡度，以及每个竖曲线的半径和线路速度所需的半径。位于缓和曲线或超高顺坡上的竖曲线会附有说明。若无设计纵断面或无设计速度，则需要它们的检查将跳过，并会有说明。

## 道岔与渡线

在**道岔与渡线**下，按**添加道岔**。道岔放置于最长直线段上；在表中设置：

- **尖轨尖端桩号**：道岔在此路线上的起点。
- **辙叉**：辙叉号 N（1:N）。辙叉角为 2·atan(1 / 2N)。
- **侧向**：左或右，沿桩号增加方向观察。
- **渡线间距**，单位为米：大于 0 时，道岔将成为通往与之平行、相距该距离的另一条轨道的渡线（两个道岔及其间的直线）。

表中显示**引导长度**（尖轨尖端至辙叉）、导曲线的**半径**，以及在欠超高限值下且无超高时，该半径所允许的**侧向允许速度**。**生成其轨道**将侧向线路转换为独立的路线（尖轨、导曲线，然后以辙叉角直行），并使用相同的铁路设置，可直接延长。

平面绘制每个道岔的两根侧向钢轨、其中心线、尖轨尖端和辙叉处的短刻线，以及“1:N”（图层 C-RAIL-TURN）。它们显示在屏幕上，并输出至 DXF、DWG、PDF 和图页。3D 视图以主线的高度绘制侧向钢轨。

该形状为**占位值**：直线尖轨，加上依据辙叉号确定的一条导曲线。已建成的道岔应遵循铁路标准及厂家图纸。警告情况包括：道岔超出路线范围、位于曲线、缓和曲线、超高或竖曲线之上，或与其他道岔重叠；线路速度高于其侧向允许速度时会有说明。

## 限界包络

勾选**沿此轨道扫描限界包络**。选择**轮廓**（两种占位形状，或**自定义轮廓**，以一行一个点输入：距轨道中心的偏移，然后为轨顶以上的高度，单位为米）、**车辆长度**与**转向架中心距**，以及（如有）**站台边缘**（侧、距轨道中心的距离、钢轨以上的高度）。

在每个桩号，轮廓随低侧钢轨倾斜超高，并因曲线而加宽：车辆中部向内移动 b² / 8R，两端向外移动 (L² − b²) / 8R（b 为转向架中心距，L 为车辆长度，R 为该处半径，依缓和曲线变化）。该区块绘制直线段及最宽处的断面，并列出：

- **最宽包络**及其位置，
- **轨道中心距**，并与相邻两个包络所需的中心距进行对比，
- **站台边缘**处剩余的空间，或侵入的距离，
- **包络内**发现的每条特征线、管道结构及其他铁路路线。

带标高的特征线按其在钢轨以上的高度与轮廓进行判定。若无设计纵断面，或某点无标高，则仅按平面判定，列表中会有说明。平面以图层 C-RAIL-CLRN 显示包络的两条边，并在包络内的每个对象处绘制十字。

提供的轮廓均为**占位值，不是任何铁路的限界**。在依赖结果之前，请输入本铁路的建筑限界。

## 在其他程序中

- **LandXML**：铁路路线以其缓和曲线（spiType）及 `Cant` 区块写入，区块包括轨距、旋转点、线路速度，以及每个超高顺坡起点和终点所在的桩号，并给出实设超高、平衡超高及欠超高。打开包含 `Cant` 区块的 LandXML 文件，会使该路线成为具有这些超高的铁路。
- **IFC**：路线及其超高段、钢轨、轨枕、道砟和底砟。

选择一条路线，然后在其**属性**中单击**放样报告**。

## 按桩号和偏移布设放样点

1. **起点**和**终点**：要放样的桩号（1+50 或 150）。
2. **间距**：放样点的间隔。放样点设在间隔的每个整数倍处，两端都会布设；勾选该框时，路线曲线的起点和终点也会布设。
3. **偏移**：路线左侧和右侧的偏移，沿桩号增加方向观察：`12 L, 0, 12 R`、`L12 CL R12` 或 `-12, 0, 12`（左侧为负）。带有道路模型的路线，会从路面边缘和路肩开始。
4. **编号起始值**和**前缀**用于为放样点命名：1、2、3，或 S101、S102。

## 路线附近的测量点

选择**路线附近的测量点**，并设定距离。距离范围内的每个测量点都会得到其桩号和偏移、该处的设计值，并以其自身高程作为地面高程：用于检查已放样或已按竣工实测的点位。

## 报告内容

| 列 | 含义 |
|---|---|
| 点 | 放样点的名称，或测量点的编号 |
| 桩号，偏移 | 沿路线的位置：L 为左侧，R 为右侧 |
| 北坐标，东坐标 | 其坐标 |
| 设计高程 | 该处已放坡的道路模型曲面（从坡脚线到坡脚线），否则为中线上的设计纵断面 |
| 地面高程 | 该处的现状曲面，或测量点自身的高程 |
| 挖方/填方 | 地面高于设计时为 C（需挖方），低于设计时为 F（需填方），精确到 0.01 |

没有设计高程的放样点（位于道路模型范围之外，或位于无设计高程的路线上且偏离中线）没有挖方或填方数值；对话框会显示其数量。

## 保存报告

- **CSV**：一行标题，然后是上述各列，并附加带符号的挖方或填方数值（地面减设计），便于电子表格和数据采集器使用。
- **PDF**：按所选纸张排版的表格页，每个放样点占一行，挖方用橙色、填方用绿色标示，并带有其他图纸的标题栏。

:::note
放样点根据项目中的设计计算。施工前请对照已批准的图纸进行核对。
:::

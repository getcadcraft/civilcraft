只要不是在输入框中打字，单字母键即可使用。使用 {{key:Mod}} 的快捷键在 Mac 上为 Command 键，在其他系统上为 Ctrl 键。另见 [浏览器中的按键](common:keys)。

## 文件与编辑

| 按键 | 操作 |
|---|---|
| {{key:Mod+O}} | 打开点文件、LandXML 或项目 |
| {{key:Mod+S}} | 保存项目（下载一个 `.civilcraft.json` 文件） |
| {{key:Mod+P}} | 将平面图打印为 PDF（打开 CivilCraft 的打印对话框，而非浏览器的打印） |
| {{key:Mod+Z}} | 撤销 |
| {{key:Mod+Y}} | 重做 |
| {{key:Delete}} | 删除所选测量点、路线、平台、结构物、管道或 PVI |
| {{key:Mod+C}} | 复制所选测量点（也可作为点行粘贴到电子表格中） |
| {{key:Mod+X}} | 剪切所选测量点 |
| {{key:Mod+V}} | 粘贴点：点会跟随指针，单击即放置到该处 |
| {{key:Mod+Shift+V}} | 原位粘贴：使用点自身的坐标 |
| {{key:Mod+D}} | 复制所选点：副本跟随指针 |
| {{key:Mod+A}} | 选择所有测量点 |
| {{key:Esc}} | 取消全部选择（并取消粘贴） |

{{key:Mod+S}}、{{key:Mod+O}} 和 {{key:Mod+P}} 即使在输入框中输入时也有效。{{key:Mod+Z}} 和 {{key:Mod+Y}} 在文本框中仍照常撤销你的输入，{{key:Mod+C}}、{{key:Mod+X}}、{{key:Mod+V}} 和 {{key:Mod+A}} 同样如此：在输入框中，它们分别复制、剪切、粘贴和全选其中的文本。在页面（面板中）选中文本后，{{key:Mod+C}} 会复制该文本。{{key:Mod+Shift+Z}} 在 CivilCraft 中无效：请使用 {{key:Mod+Y}} 或 {{ui:重做}} 按钮。

:::mac
在浏览器中，标有 **delete** 的 Mac 键即 {{key:Backspace}}。若要删除所选内容，请按 {{key:Delete}}（Fn 和 delete），或在工具栏的 {{ui:更多}} 菜单中选择 {{ui:删除}}。
:::

## 工具

| 按键 | 工具 |
|---|---|
| {{key:V}} | {{ui:选择}} |
| {{key:M}} | {{ui:测量}}：在平面图上测量距离、面积和坡度（[测量](topic:measure)） |
| {{key:A}} | {{ui:路线}} |
| {{key:G}} | {{ui:平台}} |
| {{key:P}} | {{ui:管道}} |
| {{key:B}} | {{ui:断裂线}} |
| {{key:O}} | {{ui:边界}} |
| {{key:R}} | 显示或隐藏纵断面视图 |
| {{key:I}} | 打开或关闭 {{ui:添加变坡点}}（若纵断面视图已关闭，则会将其打开） |
| {{key:F}} | {{ui:适合}}：显示全部 |
| {{key:D}} | {{ui:3D}}：在三维中显示场地，或返回平面图 |
| {{key:E}} | 沿每条特征线显示或隐藏坡度和高程（仅在屏幕上） |

再次按下当前工具的按键会返回 {{ui:选择}}。带 Shift 的字母键无效。

## 绘图时

| 按键 | 操作 |
|---|---|
| {{key:Enter}} | 完成路线、平台、管道段、断裂线或边界 |
| {{key:Backspace}} | 删除最后单击的点 |
| {{key:C}} | 特征线：开启或关闭圆弧（在顶点之后，单击曲线上的一点，然后单击其终点） |
| {{key:Esc}} | 取消绘制（或粘贴）；再次按下（或未绘制任何内容时），返回 {{ui:选择}} 并清除选择 |

## 平面视图

| 按键或操作 | 结果 |
|---|---|
| 滚轮 | 以指针位置为中心缩放 |
| 在空白处拖动 | 平移（在任何工具中都有效；短促单击仍会执行点击；按住 {{key:Shift}} 时则改为绘制选择框） |
| 按住中键拖动 | 平移 |
| 按住右键拖动 | 平移（不打开菜单） |
| {{key:Space}} 并拖动 | 平移 |
| 单击 | 选择（使用 {{ui:选择}} 时），或放置点（使用绘图工具时） |
| {{key:Shift}} 并单击 | 将测量点加入选择，或将其移出选择 |
| {{key:Shift}} 并拖动 | 绘制一个框：框内的测量点被加入选择。拖动绘制其周围即为 [套索](topic:lasso-selection) |
| 绘制套索时按 {{key:Space}} | 依次切换为窗口、窗交、栏选 |
| 粘贴时单击 | 将粘贴的点放在该处（按 {{key:Enter}} 则放在其自身坐标处） |
| 拖动夹点 | 移动 PI、平台角点或结构物（为一步撤销） |
| {{key:Up}} {{key:Down}} {{key:Left}} {{key:Right}} | 平移（平面图获得焦点时；先单击它） |
| {{key:Plus}} 和 {{key:Minus}} | 在中心处放大和缩小（平面图获得焦点时） |

= 键与 {{key:Plus}} 一样放大，因此无需按 Shift。

## 纵断面视图

| 操作 | 结果 |
|---|---|
| 开启 {{ui:添加变坡点}} 时单击 | 在该处添加一个 PVI |
| 单击某个 PVI | 选择它 |
| 拖动某个 PVI | 移动它（为一步撤销） |
| {{key:Delete}} 或 {{key:Backspace}} | 删除所选 PVI（仅当纵断面视图获得焦点时才使用 Backspace） |

纵断面视图不支持缩放或平移。

## 屏幕与帮助

| 按键 | 操作 |
|---|---|
| {{key:F1}} | 打开或关闭本帮助（侧边面板）；应用栏中的 {{ui:帮助}} 功能相同 |
| {{key:Esc}} | 帮助面板打开时将其关闭 |
| {{key:Ctrl+Shift+F}} | 循环切换屏幕模式：全屏、隐藏栏的全屏、普通 |
| {{key:Esc}} | 退出全屏（浏览器自身的按键） |

{{key:F1}} 会先于 CivilCraft 被浏览器接收，因此在任何工具中都有效。在大多数 Mac 键盘上，请按 fn 加 F1，或单击 {{ui:帮助}}。{{key:Ctrl+Shift+F}} 在所有平台（包括 Mac）上都使用 Control 键。有关如何搜索本帮助，参见 [使用帮助](common:help)。

## 鼠标、触控板与触摸

:::mouse
- 滚轮在指针处缩放。自由旋转的鼠标滚轮会快速缩放：请使用短距离转动。
- 在空白处任意拖动、按中键、按右键，或按住 {{key:Space}} 并拖动，均可平移。
:::

:::mac
在 Mac 触控板上：

- 双指滚动会**缩放**（而非平移），捏合同样会缩放。
- 若要平移，请用一根手指在空白处按下并拖动，或按住 {{key:Space}} 并拖动。
- 双指点击（右键）不会打开菜单，本身也不起任何作用。
:::

:::touch
在触摸屏上：

- 首次触摸会使按钮和菜单行变为手指大小。
- 轻触即可选择或放置点；一根手指在空白处拖动即可平移。轻触时可能会轻微晃动：只有手指移动约 10 像素后才会平移。
- 双指捏合即可缩放，双指一起移动即可平移。
- 用一根手指拖动夹点或 PVI。夹点周围会留出手指宽度的范围。
- 绘制路线、平台、断裂线、边界、管道段、特征线或地块时，平面图上方会出现一个栏，提供 {{ui:完成}}（{{key:Enter}}）、{{ui:撤销上一点}}（{{key:Backspace}}）和 {{ui:取消}}（{{key:Esc}}）。长按（不移动半秒）也会完成绘制。
- 在 {{ui:选择}} 模式中，长按一个测量点即可将其加入选择，或将其移出选择，效果与 {{key:Shift}}+单击相同。
- 在三维视图中，一根手指旋转视图，两根手指捏合和平移，轻触则拾取对象。
- 触摸时没有悬停，因此状态栏的读数仅在手指按下时更新。
:::

## 浏览器优先的按键

某些按键属于浏览器，永远不会到达 CivilCraft，例如 {{key:Mod+W}}（关闭标签页）、{{key:Mod+T}}（新建标签页）、{{key:Mod+N}}（新建窗口）以及 {{key:F11}}（在 Windows 和 Linux 浏览器中为全屏）。CivilCraft 不使用这些按键。如果某个快捷键改为在浏览器中打开了其他内容，请先单击一次平面图，使页面获得焦点，然后重试。

## 移动命令在哪里

CivilCraft 没有“移动”命令：选择 {{ui:选择}} 后拖动某个点或顶点，或在 {{ui:特性}} 中编辑其坐标。参见 [编辑点](topic:edit-points)。

如果你用过 Civil 3D，就已经了解 CivilCraft 中的概念：点和点组、带断裂线和边界的 TIN 曲面、由 PI 定义的路线、由 PVI 定义的纵断面、扫掠成道路模型的断面组合、平整至坡脚线、重力管网以及 LandXML。不同之处几乎都在这些概念之外：没有图形文件，没有命令行（除非你选择{{ui:经典绘图}}菜单样式），没有样式，没有 Prospector，也没有设置对话框。CivilCraft 是浏览器中一款小巧而专注的工具，在此版本中，它只完成了完整土木软件功能的一小部分。本页将你已经熟悉的内容与这里的功能对应起来。

:::tip
如果你喜欢 Civil 3D 的功能区，请在{{ui:设置}} › {{ui:CivilCraft}} › {{ui:菜单、按键和鼠标}}中选择{{ui:土木功能区}}菜单样式：包括“首页”、“曲面”、“修改”、“地理定位”、“视图”和“输出”选项卡；中键用于平移，{{key:Shift}}加中键可环绕三维视图旋转。如果你习惯输入命令，{{ui:经典绘图}}会添加命令行（ALIGNMENT、PAD、PROFILE、ZOOM …）。参见[菜单、按键和鼠标](topic:menus-keys-and-mouse)。
:::

## 工作流程对照

| 你想做的事 | 熟悉的做法 | 在 CivilCraft 中 |
|---|---|---|
| 导入测量点 | 用点文件格式导入点 | {{ui:打开}}，然后在**导入点**中检查列的顺序（[导入测量点](topic:import-points)） |
| 对点排序 | 点组、描述关键字 | 按描述第一个词自动分组；没有描述关键字 |
| 编辑点 | 点编辑器、夹点 | 点击后在属性中输入，或拖动它（[编辑测量点](topic:edit-points)） |
| 建立现状地面 | 创建曲面，将点组作为数据添加 | 自动：每当输入变化，曲面都会重建 |
| 添加断裂线 | 从多段线或特征线添加断裂线 | 将点组设为{{ui:断裂线}}，或用{{ui:断裂线}}工具点击各点（{{key:B}}） |
| 修剪曲面 | 外边界、隐藏边界、最大三角形边长 | {{ui:边界}}（{{key:O}}，仅外边界）和**最长外侧边** |
| 显示等高线 | 曲面样式 | 左侧面板中的**显示**：间隔、主曲线间隔、标注、色带、坡度箭头 |
| 布设中线 | 路线创建工具、曲线和回旋线设置 | {{ui:路线}}（{{key:A}}）：点击各 PI，按{{key:Enter}}；半径和回旋线长度在 PI 表中设置 |
| 创建纵断面视图 | 纵断面视图向导、色带 | {{ui:纵断面}}（{{key:R}}）：平面图下方一个纵断面视图，始终自动适配 |
| 设计坡度 | 纵断面布设工具 | {{ui:从地面开始}}、{{ui:添加变坡点}}（{{key:I}}）、拖动 PVI，输入**曲线长 L** |
| 建造道路 | 断面组合、子断面、道路模型、目标、区域 | 在路线下勾选**沿设计纵断面扫掠断面组合**；每侧设置一条车道、路肩和边坡，或由各部件组成（边沟、路缘石、人行道 …） |
| 平整场地平台 | 特征线、平整组、平整标准 | {{ui:平台}}（{{key:G}}）：平整的平台，挖填方边坡放至坡脚线 |
| 计算土方 | 体积曲面、体积仪表板 | 右侧面板中的**土方**，采用网格法，实时更新 |
| 布设雨水或污水管网 | 带零件表的管网、规则 | {{ui:管道}}（{{key:P}}）：依次点击下游的构筑物；三条由你设置的规则；自动计算管底标高 |
| 与他人交换数据 | LandXML 导入和导出 | 用{{ui:打开}}打开 LandXML 文件；用{{ui:LandXML}}导出（[交换 LandXML](topic:landxml)） |
| 将线条发送到 CAD | 导出为 DWG | {{ui:DWG}}（2000至2018格式）或{{ui:DXF}}（R12） |
| 出图 | 布局、视口、图纸集 | {{ui:PDF}}：按选定比例输出平面图的一张横向图纸；平面图和纵断面图纸以及剖面图纸也输出为 PDF |
| 在文件之间共享工作 | 数据快捷方式、外部参照 | 不支持：每个文件一个项目 |
| 撤销 | 撤销 | {{key:Mod+Z}}和{{key:Mod+Y}}，共 200 步；显示设置不计入撤销步骤 |

## 容易出错的差异

**没有命令行**，除非你选择{{ui:经典绘图}}菜单样式。工具是工具栏按钮和单个字母：{{key:A}} 路线，{{key:G}} 平台，{{key:P}} 管道，{{key:B}} 断裂线，{{key:O}} 边界，{{key:R}} 纵断面，{{key:I}} 添加 PVI，{{key:V}} 选择，{{key:F}} 适合窗口。在其他菜单样式中，输入命令名称不会有任何作用。参见[按键和鼠标](topic:keyboard)。

**按Enter键结束；双击有风险。**单击最后一个点一次，然后按{{key:Enter}}。在此版本中，双击也能结束，但会删除你双击的那个点。右键既不能结束也不能重复操作；只有在拖动时才用于平移。

**一切始终是动态的。**更改点组、半径、PVI 或平台坡度，曲面、等高线、道路模型、坡脚线和体积都会立即更新。没有需要重建的内容，也不会有过期的内容。

**所有内容都不是图形对象。**平面图是设计的视图，而不是可以用 CAD 命令编辑的图形。你无法添加自己的线条或文字，无法更改图层颜色，也无法分解任何对象。请导出为 DXF，并在 CAD 程序中完成图纸。

**没有样式。**颜色、线宽、标注文字大小和图层名称都是固定的（参见[平面图图层](topic:plan-layers)）。应用栏中的**图纸**和**模型**可在浅色和深色界面之间切换。

**每样各一个。**每个项目只有一个现状地面曲面、一个平整结果和一个管网。路线和平台可以有多个。

**单位只是标签。**选择{{ui:美国英尺}}或{{ui:米}}并不会进行任何换算。没有绘图比例。坐标系是可选的：在{{ui:坐标}}下设置坐标系，不会移动任何内容，它只说明这些数字的含义（参见[设置项目的坐标系](topic:coordinate-systems)）。写入 LandXML 时，英尺按美国测量英尺处理。

**断裂线组按点号顺序连接。**设为{{ui:断裂线}}的组会按编号顺序，形成一条穿过其所有点的线。共用编码（两条排水线都编码为“FL”）会形成一条折线；请手动绘制这些线。

**桩号外观相同，米制不同。**英尺制使用 100 ft 桩号（12+34.56）；米制使用 1000 m 桩号（1+234.567）。

**Mac 上的删除。**在 Mac 上，标有 delete 的键对浏览器而言是 Backspace。若要删除选中的对象，请使用 Fn 加 delete，或{{ui:删除}}按钮。

**文件即下载。**每次{{ui:保存}}都会下载一个 `.civilcraft.json` 文件；没有“覆盖当前打开的文件”这一操作。未保存工作的恢复副本保存在此浏览器中（[恢复未保存的内容](common:recover)）。打开点文件时会直接替换现有的点，不作询问。参见[可打开、保存和导出的文件](topic:files)。

**规则由你决定。**管网规则和道路模型的断面组合起始时使用的是占位值，并非标准值。在信任任何检查结果之前，请先设置你自己的规则。

**体积基于网格。**挖方和填方来自两个曲面之间、坡脚线以内的精细网格，不计松散和压实系数。它们与 TIN 对 TIN 的体积接近，但并不相同。

## 尚未提供的功能

除回旋线外的其他螺旋线、沿道路变化的断面组合、带坡度的平台、雨水口排水能力与调蓄、零件目录、纵断面中的管道、地块布置和地块大小划分、最小二乘平差和测量数据库、打开 DWG 文件，以及更多功能。完整列表及目前的替代做法见[尚未实现](topic:not-built-yet)。

## 布置系统

1. 在左侧的 **灌溉** 部分中，选择 **喷头**、其 **弧度** 及弧度起点，以及支管和干管的管径。
2. {{ui:灌溉}} › {{ui:接入点}}：单击供水接入的位置。在 **特性** 中设置其 **压力**、**可用流量**，以及水表和回流防止器的损失。
3. {{ui:灌溉}} › {{ui:阀门}}：单击每个分区阀门的位置。阀门即开始一个分区。
4. {{ui:灌溉}} › {{ui:喷头}}：单击放置喷头；每次单击放置一个。
5. {{ui:灌溉}} › {{ui:支管}}：从阀门开始，经过其喷头单击，然后按 {{key:Enter}}。{{ui:干管}}：从接入点到每个阀门。

管道端点会吸附到喷头、阀门、供水以及其他管道端点，因此管网能够连接起来。分区是从其阀门沿支管可以到达的全部部分；干管每次只输送一个分区。

## 滴灌

{{ui:灌溉}} › {{ui:滴灌管线}}：沿线单击，从其供给端（支管末端或阀门）开始。在 **特性** 中设置 **滴头流量** 和 **间距**；其流量即沿线各滴头流量之和。

## 检查

{{ui:灌溉}} › {{ui:检查系统…}} 会列出每个分区：

| 列 | 计算方式 |
|---|---|
| 流量 | 各喷头（及滴灌管线）的流量之和 |
| 阀门处 | 最不利喷头的工作压力，加上到该处的管道损失（Hazen–Williams，管道内径，高程变化），再加上通过阀门的损失 |
| 供水处 | 同上，再加上干管输送该分区时的损失，以及水表和回流防止器的损失 |
| 喷灌强度 | 按相邻喷头间距，喷头流量除以其所灌溉的面积 |
| 每周分钟数 | 按 **每周浇水** 设置换算 |
| 问题 | 超过限值的流速，喷头超出其压力范围，同一阀门上同时有喷雾与旋转喷头，供水处压力或流量不足，未归属任何分区的喷头，环路 |

选择一个阀门，即可在平面图上查看其分区的数据，并以圆圈标出其最不利喷头。材料清单按类型和弧度统计喷头，按管径统计管道，并统计阀门、滴灌管线和滴头，以及控制器的站数。**保存为 CSV** 可保存这两部分内容。

灌溉部分中的设置包括：**Hazen–Williams C**（新型塑料管取 150）、管内**最大流速**（1.5 m/s）、**通过阀门的损失**，以及**每周浇水**。它们均为标注的默认值。

## 覆盖范围

{{ui:灌溉}} › {{ui:显示覆盖范围}} 会显示喷头未覆盖的面积比例、被两个或更多喷头同时覆盖的比例，以及哪些喷头未能到达相邻的喷头（相邻喷头间距）。

## 喷头

所列喷头为 CadCraft 依据设计喷灌强度编写的**通用**类型（固定喷头、旋转喷嘴、齿轮式旋转喷头、冒泡器、微喷头、滴头），并非任何厂商的产品。**从文件添加喷头…** 可以读取你自己的喷头（一个 JSON 列表，包含每个喷头的射程、流量或喷灌强度，以及压力范围）；它们会随项目一起保存。厂商公布的数据仅在该厂商留有书面许可的情况下才会加入。

在通用喷头下方的列表中是 **典型喷头**（其名称以“典型值”结尾）：固定喷头、旋转喷嘴、齿轮式旋转喷头、微喷头、冒泡器和滴头的喷嘴尺寸，附有半径、流量和压力范围。它们由 CadCraft 依据公开的数学公式（流量采用孔口方程，射程采用射流射程比例换算）以及名义流量等级计算得出，仅使用公开来源；未复制任何厂商的表格。选择某一项后，选取器会显示其依据和许可。使用了典型喷头的项目会在项目文件中保留该喷头及其来源。它们仅供规划使用：施工前请查阅实际喷头自身的数据。

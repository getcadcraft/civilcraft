3D 视图将场地显示为一个模型：现有地面及平整后的曲面，其上覆盖等高线，断裂线及曲面边缘，每条路线位于其设计纵断面上并标有桩号刻度，走廊特征线及道路本身（车道、路肩、排水沟、路缘、带状绿化及人行道，各以其颜色显示），带放坡线的平台，以实际标高显示的管网（管道及构筑物），以及来自景观工作区的植物、铺装、小径、墙、路缘、坡道和台阶。它读取与平面相同的工程，因此每次编辑在两处均会显示。

## 打开 3D 视图

1. 打开测量点（或 LandXML 或工程文件），使其存在曲面。仅有植物、铺装或坡道时，也足以打开该视图。
2. 按{{key:D}}，或单击工具栏{{ui:视图}}组中的{{ui:3D}}。
   3D 视图将在平面上方打开，从东南方向观察整个场地。首次打开时需要稍候加载。
3. 再次按{{key:D}}，或再次单击{{ui:3D}}，即可返回平面。选择诸如{{ui:路线}}或{{ui:平台}}之类的绘图工具，同样会返回平面，因为绘图在平面上进行。

## 移动视角

| 操作 | 方法 |
|---|---|
| 环绕 | 拖动左键或中键 |
| 平移 | 拖动右键，或按住{{key:Shift}}并拖动 |
| 缩放 | 转动滚轮；缩放以指针为中心 |
| 在触控板上环绕 | 双指滑动（{{key:Shift}}加滑动为平移） |
| 在触控板上缩放 | 双指捏合 |
| 触摸 | 单指环绕；双指捏合缩放，移动则平移 |
| 键盘（视图获得焦点时） | {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} 环绕，配合{{key:Shift}}则平移；{{key:Plus}}与{{key:Minus}}缩放 |

视图上方的工具栏包含其余内容：

- 视图列表：**等轴测**、**俯视**、**仰视**、**前视**（朝北观察）、**后视**、**左视**、**右视**。
- {{ui:透视}}：按下时为透视视图；单击则切换为平行投影（无透视缩短）。
- {{ui:范围}}：重新显示全部内容。在 3D 视图打开时，按{{key:F}}同样可执行该操作。

## 视图立方体

右上角的视图立方体随视图转动。单击某一面、棱或角，即可从该方向观察场地（除非系统要求减少动态效果，否则摄像机将平滑转动）。拖动立方体可环绕旋转。其下方的指北环显示北向（网格北，+Y）：拖动该环可使场地绕竖向轴转动，或单击 N、E、S 或 W 从该侧观察。左上角的小房子图标{{ui:开始}}则返回整个场地的等轴测视图。使用键盘时：按{{key:Tab}}切换至立方体，方向键选择某一面、棱或角，按{{key:Enter}}从该方向观察。

在平面上，同一立方体显示顶面。单击其他任一面、棱或角（或拖动它），即可打开从该方向观察的 3D 视图：这是从某一方向进入 3D 的最快方式。若要将立方体换成小坐标轴图标或将其隐藏，请见 [CivilCraft 设置](topic:settings) 中的**角落指示器**。

## 竖向夸大

场地通常远宽于其高度，因此起始时标高以 **2×** 拉伸。可在工具栏的列表中选择 **1×**、**2×**、**3×**、**5×** 或 **10×**，或在 [CivilCraft 设置](topic:settings) 中的 **3D 竖向夸大**下选择（两者为同一设置）。仅视图发生变化：土方量、纵断面及导出保持实际比例。

## 着色曲面

- **标高色带**：与平面标高色带相同的色带和颜色（色带数量在左侧面板的**显示**下设置）。每个色带边界精确地切在其标高处。
- **单一颜色**：现有地面和平整后的曲面各使用一种单色。
- **地图图层**：平面下方显示的地图图层（带地理参考的图片、地图瓦片或地图服务；见[地图图层](topic:map-layers)）如贴图一般覆盖于曲面之上，因此航拍照片会显示在山坡上。尚在加载的图片将随到达而逐步填充。若无地图图层显示，曲面则保留其标高色带，视图中会有说明。该图片仅用于屏幕显示：GLB 和 OBJ 导出不包含它。

同时显示两个曲面时，现有地面在平整后的曲面上呈半透明，因此可看到挖方（高于设计的地面）和填方。

## 选择显示内容

在工具栏上单击{{ui:显示}}，勾选或取消勾选：

| 项目 | 内容 |
|---|---|
| 现有地面 | 由测量点建立（或从 LandXML 读取）的曲面 |
| 平整曲面 | 带走廊和平台平整的现有地面（仅在存在时显示） |
| 三角网边线 | 每条 TIN 边，以线显示 |
| 等高线 | 显示各曲面的首曲线和计曲线，间距与平面相同 |
| 曲面边缘 | 显示的每个曲面的外边缘，位于其标高处 |
| 断裂线 | 每条断裂线，位于其标高处 |
| 路线与桩号 | 每条路线位于其设计纵断面上（无纵断面处位于地面上），并每 50 ft 或 20 m 设刻度 |
| 走廊特征线 | 两侧的路面边缘、路肩和放坡线 |
| 道路面层 | 每个走廊依其断面构建的道路：车道、路肩、排水沟、路缘、带状绿化及人行道，各以其颜色显示，位于平整曲面上 |
| 植物 | 每一株植物，以及花坛和绿篱中的植物，按植物清单尺寸显示为简单形体：乔木为树干和圆形树冠（针叶树为锥形，棕榈为高干上的一簇），灌木、绿篱植物、多年生植物和地被为圆顶，草为簇状，攀缘植物为细柱。它们立于平整曲面（或现有地面）上，尺寸与平面所示相同：成熟尺寸或种植时尺寸 |
| 硬景 | 带坡度的铺装和小径，墙、路缘、台阶，以及以平台相隔、逐段攀升的坡道 |
| 平台与放坡线 | 每个平台轮廓及其标高，以及其放坡线 |
| 管道与构筑物 | 管道以圆管显示，位于其管底之间；构筑物自井口至集水坑 |
| 测量点 | 每个带标高的点显示为一个圆点（初始为关） |
| GIS 图层 | 平面上所示的 GIS 图层，以其颜色显示：线和轮廓以其自身标高显示，其他则铺设于现有地面上（完全贴合）；点显示为小十字。曲面以外且无标高的图形不显示，视图中会说明数量 |
| 标注 | 始终面向观察者的名称和数值：每条路线的名称（位于其起点）及每 100 ft（或 100 m）的桩号，每条首曲线的标高，平台、特征线及构筑物的名称，勾选**测量点**时还显示每个点的编号和标高 |

无论如何旋转或缩放，标注的大小始终不变且保持直立，位于标注前方的山丘会将其遮挡。当标注过于密集时，最重要的先显示，其余的待放大后显示：依次为路线、构筑物、平台、特征线、桩号、等高线及点，较近者优先。标注仅显示在屏幕上；导出和打印输出中不包含标注。

所做选择、竖向夸大及着色均保存在本浏览器中。

道路建立于现有地面之上。若有路线和走廊，但尚无测量点或曲面，则目前道路将绘制于平坦的替代地面上：其标高为设计纵断面的平均标高；若亦无纵断面，则位于标高 0 的水平面上。3D 视图底部及走廊属性中会有警告予以说明。这仅为示意图：不由其计算土方量或断面。打开测量点或曲面后，道路将自动移至真实地面上。

竖向夸大仅拉伸地面，不拉伸植物：植物立于夸大后的地面上，并保持其真实高度和冠幅，因此无论设置如何，树木看起来都像树木。植物为简单形体，而非详细模型：即使数以千计，也能快速转动和缩放。

## 管道与构筑物

- 管道以其设定的管底内底标高绘制，管顶内侧（管冠）高于管底一个内径。直径在英尺工程中以英寸为单位，在公制工程中以毫米为单位，与右侧面板一致。
- 构筑物自其井口（输入值，或取自曲面）向下延伸至集水坑（最低管底内底减去集水坑深度）。若无任何管底内底，则绘制为 5 ft（1.5 m）深。
- 存在问题的管道和构筑物（见右侧面板中的管网检查）以红色绘制。
- 无管底内底的管道不予绘制；视图底部的说明会注明数量。

## 从 3D 视图中选择

单击路线（或其道路）、平台、特征线、管道、构筑物、测量点、植物、坡道或其他硬景。其选中方式与在平面上单击相同：其属性在右侧面板中打开，可在其中编辑，并以选择颜色绘制于 3D 中所有内容之上。在平面上选中的任何对象在 3D 中也会高亮。指针旁的提示会标明所单击对象的名称及其东坐标、北坐标和标高。即使管道和构筑物位于地下，也可单击；位于山丘后方的线则无法透过山丘单击。

单击断裂线可查看其为哪一条：该线将高亮显示，状态栏会给出其名称（断裂线本身没有属性）。

单击地面，可在提示中读取该处的东坐标、北坐标和标高。

## 沿路线行驶

在 3D 工具栏上单击**行驶**，然后选择一条路线。视图移至驾驶座位：位于道路以上 3.5 ft（1.07 m），处于其设计纵断面上（若尚无纵断面，则位于沿中线的现有地面上），沿路线向前观察。

- **播放**或{{key:Space}}以所选速度行驶（10 至 65 mph，或 15 至 100 km/h）；再次按{{key:Space}}则暂停。到达终点时停止；此后**播放**将从头开始。
- 滑块可跳至任一桩号；{{key:Left}}与{{key:Right}}分别后退和前进 10 ft（5 m）。
- 在视图中拖动将暂停，并可环顾四周。
- **停止**或{{key:Esc}}使视图恢复至原位。

行驶时竖向夸大同样适用：将其设为 1× 即可查看道路建成后的实际样子。

## 太阳光照

在 3D 工具栏上打开**太阳**，并勾选**太阳光照**。输入日期、时刻及其时区（与 UTC 的偏移量：夏季则为夏令时偏移），以及场地的纬度和经度。若工程设有坐标系，则这些值将由其自动填入。

随后场地将按太阳所在方向照明，并在地面、走廊及平台上显示**阴影**；菜单会说明太阳的方位角及其高度，或说明其位于地平线以下。位置依据 NOAA 太阳方程计算。无论何种夸大倍数，阴影方向均正确，但会止于场地边缘：边缘以外的山丘和建筑不投射阴影。

## 导出 3D 视图

在工具栏上单击{{ui:GLB}}或{{ui:OBJ}}。视图所示内容将以实际比例（无夸大）、以米为单位、Y 轴向上保存。详情见：[导出 3D 场地](topic:export-3d)。

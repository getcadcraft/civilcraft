测量图纸看上去可能正确，但用于地面仍可能有误：其单位可能是猜测的，其等高线可能全部位于高程 0 的平面上，或其标高可能是并非几何图形的文字。{{ui:Linework}} 对话框中的**测量标高与检查**部分（参见[将 DWG 或 DXF 作为线条打开](topic:open-dwg-dxf)）会读取这些标高，并在添加任何内容之前告诉你哪些地方有问题。

## 以文字或属性形式写出的标高

许多测量图纸会在十字标记旁用小字注出点标高，如 `104.37` 或 `EL 104.37`，或作为点块的属性。这些并非线条，因此线条读取器会将其忽略。该部分会列出找到的数量，并允许你将其作为**测量点**导入：

1. 勾选**将 … 个标高作为测量点导入**。默认未勾选，因为图纸中并非每个数字都是高程。
2. 只有独立的标高文字才会被读取：带小数部分的数字（`104.37`、`+104,37`、`-3.50`），或位于 `EL`、`ELEV`、`RL`、`FFL`、`GL`、`TW`、`BW`、`INV`、`Z` 或 `LEVEL` 之后的数字，其后可带可选的 `m`、`ft` 或 `'`。单独的整数（`12`）会被视为地块号或图号，而非标高；`GATE 3` 之类的文字或日期则从不读取。文字格式代码会被忽略。
3. 对于块属性，选择**存放标高的块属性**。CivilCraft 会自动查找名为 ELEV、Z、LEVEL、RL 或类似的标记；若图纸使用自定义标记，请从列表中选择其他标记。该选择会按文件名记录在本计算机上，因此再次打开时仍从同一标记开始。你所选的标记中，整数也会被视为标高。
4. 单击{{ui:Add}}。测量点的编号接续项目中的最大编号，每个点都以其图层（或其块）进行描述，高程与图纸其余部分一样换算为项目单位。整个过程为一步：{{key:Mod+Z}} 可将这些点移除。

文字位于其自身的插入点处（若有对齐点，则位于对齐点处）。块内的文字不会被读取，图纸本身也不会被修改。

## 检查

检查针对即将导入的内容进行，并列出发现的问题，每类问题一行：

| 提示 | 含义 |
|---|---|
| **未注明单位** | 图纸未说明其单位，因此其数值按项目单位读取。请核对一个已知距离。 |
| **单位已换算** | 图纸单位与项目单位不同，已按比例换算（仅为提示，并非错误）。 |
| **数据跨度为 … km** 或 **… m** | 范围大于 200 km 或小于半米，通常意味着单位错误（毫米被当作米，或相反）。 |
| **无坐标系** | 项目未设置坐标系。当数据远离零点时（如平面直角坐标或国家格网坐标）会发出警告。参见[坐标系](topic:coordinate-systems)。 |
| **远离原点** | 数据距零点超过 100 km。远离零点时，3D 视图和导出会损失精度并出现抖动。 |
| **等高线图层 … 无高程** | 名称类似等高线（TOPO、CONT、CNTR、CONTOUR）的图层中的线位于高程 0，因此由其生成的地面将是平的。 |
| **标高恰好为 0** | 部分标高为 0，而典型标高与之相差甚远：很可能是缺少高程。 |
| **标高与其他值相差过大** | 少数标高远离其他值（以全部标高的中位数为基准判断，因此高差大的陡峭场地不会被标记），或高于 9,000 m 或低于 -11,000 m。 |
| **点位重叠** | 两个点位于同一位置，且标高相同或不同。 |

单击{{ui:Add}}后，同样的提示会按类别各记一条，并附上文件名，记入**问题**中，以便你日后返回查看。检查仅对图纸作出判断，不会修改图纸，也不会阻止你使用该图纸。

:::tip
若检查提示等高线高程为 0，且存在以文字写出的标高，请将这些标高作为测量点导入：它们往往带有等高线所缺少的真实高程。
:::

## 未检查的内容

检查不会将图纸与第二份测量成果进行比对，也无法判断图纸使用的是哪种坐标系：它只能告知你尚未设置坐标系。

## 你将学到的内容

如何让 AI 助手（任何支持 MCP 的助手）处理你打开的场地，它能做什么、不能做什么，以及如何将其停止。

## 助手在 CivilCraft 中能做什么

| 请求内容 | 获得的内容 | 所需权限 |
|---|---|---|
| 场地 | 名称、单位、坐标系、点组、路线、曲面、平台、地块和管道 | 读取 |
| 测量点 | 编号、东坐标、北坐标、高程和描述，按组、按描述或按框内范围 | 读取 |
| 曲面高程 | 其指定点处的现状地面（或平整后曲面） | 读取 |
| 桩号和偏移 | 点沿路线的桩号和偏移，或桩号处的坐标和地面高程 | 读取 |
| 纵断面 | 沿路线每隔若干英尺或米的地面、设计纵断面和平整后曲面高程 | 读取 |
| 挖方和填方 | 现状地面与平整后曲面之间的体积（每个平台和道路模型也一样），或地面与某一水平面之间的体积 | 读取 |
| 地块 | 角点、面积（以英亩或公顷计）、周长和法定描述 | 读取 |
| 选择 | 其指定的点会在平面图上被选中，如同你亲自选择一样 | 编辑 |
| 新测量点 | 以其给定的编号或下一个可用编号添加的点。每次调用为一步，可撤销 | 编辑 |
| 保存 | CivilCraft 自身的{{ui:保存}} | 保存 |
| LandXML 或 DWG | 与{{ui:LandXML}}和{{ui:DWG}}按钮相同的文件 | 导出 |
| 三维场地 | 地面、平整后曲面、平台和管道的 OpenUSD（.usdz、.usda 或 .usdc），与 3D 视图导出的一致 | 导出 |
| 植物和植物表 | 通过任意名称在植物列表中找到的植物，以及植物表的数量 | 读取 |
| 种植和平整 | 放置的植物、花坛或绿篱，或添加的平台、护坡、浅沟或平整区域，每项为一步可撤销，并附带其挖填方 | 编辑 |
| 灌溉检查 | 每个分区的流量、其阀门处和供水处所需的压力、最不利水头、运行时间、问题以及材料清单，作为供灌溉设计师核对的计算辅助 | 读取 |

它只处理当前打开的场地。在 Studio 中，它还可以保存并导出到你选择的文件夹（见下文）；若未选择文件夹，其文件将与按钮的下载方式相同，直接下载。

## 开启

助手通过你计算机上的 CadCraft Studio 连接 CivilCraft；普通浏览器无法接入。

1. 打开{{ui:设置}}，并选择 **CivilCraft** 选项卡。
2. 在**助手**下，勾选**允许 AI 助手和脚本使用 CivilCraft**。
3. **读取**已为你勾选。只有当助手需要时，才勾选**编辑**、**保存**或**导出**。
4. 若要允许其保存并导出到某个文件夹，请在**允许使用的文件夹**下选择{{ui:添加文件夹…}}，并在 Studio 的对话框中选择该文件夹。{{ui:移除}}会立即将其收回；其他任何路径都会被拒绝。
5. 在 Studio 中连接助手（Studio 会显示地址以及需要粘贴到助手中的设置）。

## 助手连接期间

右侧面板顶部的提示会说明已连接的助手以及它能做什么。点击{{ui:断开连接}}可立即结束其会话；若要继续，它必须重新连接。

设置中**助手**下的**活动**会列出助手发出的每次调用，最新的在前，并显示是否成功。

:::tip
用平实的语言提问即可，例如“沿主街每 50 ft 的地面高程是多少？”“这些平台需要多少挖方和填方？”或“在这些坐标处添加一个控制点”。助手会读取场地并给出答复，或将修改作为一步操作完成，并可撤销。
:::

## 无需打开 CivilCraft

供助手使用的 CadCraft 文件服务器（`npx @getcadcraft/mcp`）以及 `cadcraft` 命令行，可使用 CivilCraft 自身的代码打开已保存的 CivilCraft 项目（`.civilcraft.json`）和测量点文件，无需打开窗口：支持相同的读取工具、添加点、保存项目、LandXML 以及以 OpenUSD 导出三维场地。`cadcraft convert site.civilcraft.json site.xml` 可通过命令行写出 LandXML。打开 LandXML、导出 DWG 以及 Landscape 工作空间的工具仍需要 CivilCraft 窗口。

## 关闭

取消勾选**允许 AI 助手和脚本使用 CivilCraft**。所有助手会立即断开连接，该设置会保留，供下次使用。

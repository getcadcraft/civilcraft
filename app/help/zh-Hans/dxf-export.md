{{ui:DXF}} 会将平面图所显示的内容写入 R12 格式的 DXF 文件，这是所有 CAD 程序都能打开的版本。若已使用过 AutoCAD 或 Civil 3D，可像打开或插入任何 DXF 一样打开或插入它。

## 导出

1. 在**显示**下设置平面图，使其符合所需图形：选择曲面（现状或设计）、等高距，以及开启哪些内容（等高线、标注、点、点标注、三角形、断裂线、曲面边界、管道、坡度箭头）。
2. 在**导出**组中点击{{ui:DWG/DXF}}，选择{{ui:DXF（R12，文本）——通用交换文件}}，然后点击{{ui:下载}}。
3. 浏览器会下载 `<name>.dxf`。状态栏会显示例如 “已导出 R12 DXF：2,140 个对象；标签按 1" = 40' 设定大小。高程带不导出。”

坐标以项目单位写入，保持实际数值（州平面坐标保持原样）。不进行任何缩放或移动。

## 文件内容

| 内容 | DXF 实体 | 图层 |
|---|---|---|
| 次要和主要等高线 | 位于其高程处的二维多段线 | C-TOPO-MINR, C-TOPO-MAJR |
| 等高线标注 | 文字 | C-TOPO-TEXT |
| 三角形 | 多段线 | C-TOPO-TINN |
| 断裂线和边界 | 三维多段线 | C-TOPO-BRKL |
| 曲面边界 | 多段线 | C-TOPO-BNDY |
| 坡度箭头 | 多段线 | C-TOPO-SLOP |
| 测量点及其标注 | 点（带高程）、文字 | V-NODE, V-NODE-TEXT |
| 来自线码的线 | 三维多段线 | V-NODE-LINE |
| 路线中线 | 直线和圆弧 | C-ROAD-CNTR |
| 桩号刻度和标注 | 多段线、文字 | C-ROAD-STAN |
| 道路模型边缘 | 多段线 | C-ROAD-CORR |
| 采样线 | 多段线 | C-ROAD-SCTN |
| 平台、坡脚线、坡线 | 多段线 | C-GRAD-PADS, C-GRAD-DAYL, C-GRAD-SLOP |
| 特征线 | 三维多段线（圆弧分段，误差在 0.01 以内；参见[特征线](topic:feature-lines)） | C-GRAD-FEAT |
| 扫掠路径 | 多段线、文字 | C-ROAD-SWPT |
| 管道、构筑物及其标注 | 多段线、文字 | C-STRM-PIPE, C-STRM-STRC, C-STRM-TEXT |
| 有问题的管道和构筑物 | 多段线 | C-STRM-PROB |

每个图层都有颜色。完整列表参见[平面图图层](topic:plan-layers)。

## 标注大小

文字必须以图形单位指定大小。CivilCraft 按使整个平面图恰好放入 Tabloid 图纸（英尺）或 A3 图纸（米）的比例设定标注大小，并在状态信息中说明所用比例。若在 CAD 程序中以其他比例出图，请在该程序中调整文字比例。

## 不导出的内容

- 高程带（仅屏幕显示）。
- 纵断面视图。纵断面以 LandXML 导出，而非图形。
- 曲面本身作为三维对象。如需 TIN，请使用 LandXML；或开启{{ui:三角形}}，以线条形式获取其边线。
- 在**显示**下关闭的任何内容。

## DWG

{{ui:DWG/DXF}} 也会将相同的线条写为 DWG 图形。其对话框会询问格式：DXF，或 2000、2004、2007、2010、2013 或 2018 版的 DWG。2000 版几乎可在所有新旧 CAD 程序中打开；当图形接收方提出要求时，再选择较新的版本。所选项会保存在此浏览器中。

1. 在**导出**组中点击{{ui:DWG}}。
2. 选择**格式**，然后点击**下载 DWG**。
3. 浏览器会下载 `<name>.dwg`。状态栏会说明写入的内容，例如 “已导出 DWG（2018 格式）：12 条多段线，9 个图层上的 40 个标注”。

该 DWG 与 DXF 具有相同的图层、颜色、等高线（为位于其高程处的多段线）、三维断裂线、标注和点，坐标也相同。DWG 无法容纳的图层名称会被更改，状态信息中会注明。CivilCraft 使用自有代码写入 DWG，因此数据不会离开本机。

### DWG 中的地图图层

DWG 图形无法在内部容纳图片：CAD 程序显示的是位于图形旁边的图片。显示地图图层时，对话框会提供**以图像形式将地图图层置于图形旁边**选项。勾选后，下载的是一个 `.zip`，内含 `<name>.dwg`、`<name>-map.png`（覆盖整个图形的地图图层，宽度最多 4,096 像素）和 `<name>-map.pgw`（其世界文件，供 GIS 程序使用）。图形会将该图片作为图像置于 G-MAP-IMAG 图层上的原位。请将文件解压到同一文件夹中并保持它们在一起。

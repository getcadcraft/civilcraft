CivilCraft 仍处于早期阶段。本页列出当前版本尚未实现的功能，以免白费时间去寻找。以下内容均不承诺任何时间表。

## 点

| 尚未实现 | 目前可以这样做 |
|---|---|
| 将第二个点文件添加到第一个点文件中 | 先在文本编辑器或电子表格中合并文件 |
| 导出点文本文件 | 导出 LandXML（点以 CgPoints 形式输出），使用 GIS {{ui:导出}}（包含 P、N、E、Z 和 D 字段的点），或将点{{ui:复制}}到电子表格中 |
| 点标注样式、按描述关键字设置符号、由线码生成曲线（圆弧），以及可在项目之间共享的描述关键字文件 | 标注显示编号、高程和描述，或显示更少内容（[CivilCraft 设置](topic:settings)）；关键字保存在项目文件中 |
| 单位换算 | 导入前先转换文件；**单位**仅更改标注的单位名称 |

## 曲面

| 尚未实现 | 目前可以这样做 |
|---|---|
| 由点创建多个曲面 | 每个曲面使用一个项目 |
| 隐藏（内部）边界 | 使用**最长外边缘**或外部边界 |
| 选择或编辑单条已绘制的断裂线 | {{key:Mod+Z}}，或{{ui:移除已绘制的断裂线}}后重新绘制 |
| 编辑从 LandXML 读取的曲面（断裂线、边界） | {{ui:由点重建曲面}} |
| 编辑由高程网格生成的曲面 | 使用其他选项重新导入网格 |
| 坐标系变化时转换从 LandXML 读取的曲面 | 先执行{{ui:由点重建曲面}} |
| 带标注的标高点和坡度值 | 在状态栏中读取，或在景观工作区中使用**坡度分析**按坡度为曲面着色（[景观分级](topic:landscape-grading#grading-checks)） |

## 线形和纵断面

| 尚未实现 | 目前可以这样做 |
|---|---|
| 除回旋线以外的缓和曲线；两条曲线之间的缓和曲线（复合过渡） | 曲线两端可使用回旋线缓和曲线；其他类型在导入 LandXML 时会被标注名称并跳过 |
| 在两个其他 PI 之间插入 PI | 重新绘制线形，或重新输入 PI 坐标 |
| 由对象、偏移或加宽创建线形 | 通过 PI 绘制 |
| 输入 K 设置竖曲线 | 输入 L（界面显示 K） |
| 圆形和非对称竖曲线 | 仅支持对称抛物线竖曲线 |
| 每条线形多个设计纵断面 | 每个方案使用一条线形 |
| 缩放纵断面视图，纵断面下方的纵断面带 | 纵断面视图会适合整条线形；可在[平面和纵断面图纸](topic:plan-profile-sheets)上输出 |
| DWG 或 LandXML 中的断面 | 以 PDF 形式输出断面图纸；输出面积和土方量的 {{ui:CSV}} |
| 斜向的采样线，或沿道路宽度变化的采样线 | 整条线形两侧各采用一个统一宽度 |

## 道路模型

| 两个区域模板之间的渐变过渡（过渡段、渐变段） | 在某个桩号更改模板，或为绘制为渐变段的线设置点的宽度目标 |
| 绕边缘旋转，LandXML 中的超高 | 圆曲线上的超高绕中线旋转；使用宽度目标将特征线加宽 |
| 侧坡目标（坡脚线延伸至线或曲面），以及道路自身的曲面 | 目标用于移动路面和路肩的边缘（[道路](topic:corridor)）；道路会被分级到设计曲面中 |
| 以 LandXML 道路形式导出的道路；IFC 导出中线形上的第二条道路 | 导出设计曲面 |
| 改变三维或断面中设计曲面的地形模板 | 地形模板给出每个图层的面积和土方量（[地形模板](topic:corridor-templates#terrain-templates)） |
| 带速度、轮胎打滑、转向时间、转向挂车或车身净空的车辆转弯轨迹；标准设计车辆库；通过拖动车辆绘制的转弯轨迹 | 沿特征线或线形的低速车辆转弯轨迹，使用自定义车辆尺寸（[车辆转弯轨迹](topic:swept-paths)） |

## 分级和土方

| 尚未实现 | 目前可以这样做 |
|---|---|
| 台阶，开放的特征线分级到设计中，分级到其他位置的特征线 | 闭合特征线（[特征线](topic:feature-lines)），或将其用作原地面的断裂线 |
| 插入或删除特征线的顶点 | 重新绘制该线，或对其进行阶梯式偏移 |
| 绘制断裂线中的圆弧（经过测量点），特征线中的螺旋线 | 绘制带圆弧的特征线，并将其用作原地面的断裂线 |
| 分级到某一距离、高程或另一曲面 | 仅支持坡脚线接原地面 |
| 增加或删除平台的角点 | 删除平台后重新绘制 |
| TIN 到 TIN（棱柱体）土方量，选择网格单元尺寸 | 网格法，网格单元尺寸由程序自动选定 |
| 膨胀和收缩系数、表土、路面厚度 | 自行对报告的数值应用系数 |
| 自由运距和超运距费用，跨不同线形的运距，在平面图上放置的取土场和弃土场 | 带平衡点的土方调配图，给出调运土方量和平均运距 |

## GIS 和坐标系

| 尚未实现 | 目前可以这样做 |
|---|---|
| 文件地理数据库；KML 样式、图标、地面叠加层和网络链接 | 先转换为 GeoPackage、shapefile 或 GeoJSON；KML 标记在读取时不带样式 |
| 编辑 GIS 要素或其属性 | 在 GIS 程序中编辑后重新导入。分析面板会创建新图层（缓冲区、叠加、连接、选择集），并添加面积和长度字段，但不会原地编辑要素 |
| 网络和栅格分析；平端或方端的缓冲区，以及单侧缓冲区；在属性表中添加或删除行、更改字段类型；手动设置分类颜色；图纸中的样式图例 | 使用选择工具挑选要素，并由其创建图层；不提供平端。按属性着色和属性表已经实现：参见[按属性为图层设置样式](topic:gis-symbology)和[使用图层属性表](topic:gis-table) |
| 标签样式（大小、位置），以及避免相互重叠的标签 | 标签为统一大小，在要素密集处可能重叠 |
| 垂直基准和大地水准面模型 | 高程按文件给出的值使用；请自行检查垂直基准 |
| 除按区域推荐的 NAD27 转 NAD83 之外的格网偏移（OSTN15，添加文件后其他基准的 NTv2 可用）；同时使用多个格网；垂直格网 | 为所用基准自行添加格网文件；每个项目一个格网 |
| DXF 或三维导出中的地图图层 | 地图图层输出到 PDF 图纸中，并在 DWG 中以图片形式放置 |
| 需要登录、密钥或令牌的地图服务 | 使用公共服务，或使用经过地理配准的图像文件 |
| 从曲面、地面模型，或从高程网格和 LiDAR 工具写入 LAS 或 LAZ 文件 | 将曲面导出为 GeoTIFF 高程网格。[点云](topic:point-clouds)插件可将清理后的点云写为 LAS 1.4 或 LAZ |
| LiDAR 强度、颜色和回波；包含多个波段的高程网格；超过 200 MB 的网格或 LiDAR 文件 | LiDAR 仅按类别过滤，网格使用第一个波段；请先将大文件切分为小块 |

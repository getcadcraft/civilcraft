CivilCraft 仍处于早期阶段。本页列出当前版本尚未实现的功能，以便你不必去寻找。本页所列功能均未承诺任何日期。

## 点

| 尚未实现 | 目前的替代做法 |
|---|---|
| 将第二个点文件并入第一个 | 先在文本编辑器或电子表格中合并文件 |
| 导出点的文本文件 | 导出 LandXML（点以 CgPoints 输出），或使用 GIS {{ui:Export}}（包含 P、N、E、Z 和 D 字段的点），或将点{{ui:Copy}}到电子表格中 |
| 点的标注样式、每个描述关键字对应的符号、由线码生成的曲线（圆弧），以及可在项目之间共享的描述关键字文件 | 标注仅显示编号、标高和描述，或更少（[CivilCraft 设置](topic:settings)）；关键字保存在项目文件中 |
| 单位换算 | 导入前先转换文件；**单位**仅改变标注 |

## 曲面

| 尚未实现 | 目前的替代做法 |
|---|---|
| 由点生成多个曲面 | 每个项目一个曲面 |
| 隐藏（内部）边界 | 使用**最长外边缘**或外边界 |
| 选择或编辑单条已绘制的断裂线 | {{key:Mod+Z}}撤销，或使用{{ui:Remove drawn breaklines}}后重新绘制 |
| 编辑从 LandXML 读取的曲面（断裂线、边界） | {{ui:Rebuild the surface from the points}} |
| 编辑由高程网格生成的曲面 | 以其他选项重新导入网格 |
| 坐标系变化时转换从 LandXML 读取的曲面 | 先执行{{ui:Rebuild the surface from the points}} |
| 带标注的点高程和坡度值 | 在状态栏中读取，或在景观工作区中使用**坡度分析**为曲面着色（[景观放坡](topic:landscape-grading#grading-checks)） |

## 线形与纵断面

| 尚未实现 | 目前的替代做法 |
|---|---|
| 除回旋线（clothoid）外的缓和曲线；两条曲线之间的缓和曲线（复合过渡） | 曲线两端的回旋线可用；其他类型会被命名，并在 LandXML 导入时跳过 |
| 在两个其他 PI 之间插入 PI | 重新绘制线形，或重新输入 PI 坐标 |
| 由对象、偏移、加宽生成线形 | 通过 PI 绘制 |
| 为竖曲线输入 K | 输入 L（会显示 K） |
| 圆形及不对称竖曲线 | 仅支持对称抛物线竖曲线 |
| 每条线形多于一个设计纵断面 | 每个方案一条线形 |
| 缩放纵断面视图，纵断面下方的纵断面带 | 纵断面视图会适合整条线形；请在[平面与纵断面图纸](topic:plan-profile-sheets)上输出 |
| DWG 或 LandXML 中的横断面 | 以 PDF 输出横断面图页；面积和体积的 {{ui:CSV}} |
| 斜向的采样线，或沿道路宽度不同的采样线 | 整条线形两侧各采用一个宽度 |

## 道路模型

| 尚未实现 | 目前的替代做法 |
|---|---|
| 中央分隔带、护栏，以及会旋转模板的超高 | 将其绘制为模板（[道路模型模板](topic:corridor-templates)）；按桩号的模板暂不支持超高 |
| 两个区域模板之间的渐变过渡（过渡段、渐缩） | 在某一桩号更换模板，或为绘制为渐变段的线设置点的宽度目标 |
| 绕边缘旋转，LandXML 中的超高 | 圆曲线上的超高绕中线旋转；使用宽度目标将车道加宽至特征线 |
| 坡脚线边坡的目标（坡脚线到直线或曲面），道路模型自身的曲面 | 目标移动路面边缘和路肩（[道路模型](topic:corridor)）；道路模型被放坡到设计曲面中 |
| 交叉口中的路缘石转角、转弯车道和交通岛放坡；斜交时将支路端部切至主路边缘；平面上与道路连接的小路及其长度和面积 | 相交的道路以直角连接，打开主路边缘并将支路缓坡接入（[道路相交](topic:corridor#where-roads-meet-roads-pads-and-paths)）；小路在设计曲面和三维中停在道路边缘 |
| 以 LandXML 道路导出道路模型；IFC 导出中线形上的第二条道路模型 | 导出设计曲面 |
| 改变设计曲面的地形模板（在三维或断面中） | 它们给出各层的面积和体积（[地形模板](topic:corridor-templates#terrain-templates)） |
| 带速度、轮胎滑移、转向时间、转向拖车或车身净空的转弯轨迹；标准设计车辆库；通过拖动车辆绘制的转弯轨迹 | 沿特征线或线形的低速转弯轨迹，使用你自己的车辆尺寸（[车辆转弯轨迹](topic:swept-paths)） |

## 放坡与土方

| 尚未实现 | 目前的替代做法 |
|---|---|
| 马道、在设计中放坡的开放特征线、放坡至其他地方的特征线 | 闭合特征线（[特征线](topic:feature-lines)），或将其作为原地面的断裂线 |
| 插入或删除特征线的顶点 | 重新绘制该线，或对其做阶梯式偏移 |
| 已绘制断裂线中的圆弧（经过测量点），特征线中的缓和曲线 | 用圆弧绘制特征线，并将其作为原地面的断裂线 |
| 放坡至某一距离、标高或另一曲面 | 仅放坡至现有地面（坡脚线） |
| 增加或删除平台角点 | 删除平台后重新绘制 |
| TIN 到 TIN（棱柱）体积，选择网格单元尺寸 | 网格法，单元尺寸由系统为你选定 |
| 松方与压实系数，表土，路面厚度 | 自行对报告的数值应用系数 |
| 自由运输和超运输费用，跨不同线形的运输，平面上布置的借土场和弃土场 | 带平衡点、调运土方量和平均运距的土方调配图 |

| 保存在你的 Library 账户中的你自己的植物清单（在应用中编辑） | 在植物表中编辑项目自身的清单，并将其保存为植物文件 |
| 不打开窗口的景观工具（供 AI 助手使用的文件服务器和命令行） | 在 CivilCraft 窗口打开时使用（[让 AI 助手处理你的场地](topic:assistants)） |

## GIS 与坐标系

| 尚未实现 | 目前的替代做法 |
|---|---|
| File Geodatabase；KML 的样式、图标、地面叠加和网络链接 | 先转换为 GeoPackage、shapefile 或 GeoJSON；KML 地标会在读取时不带样式 |
| 编辑 GIS 要素或其属性 | 在 GIS 程序中编辑后重新导入。分析面板会创建新图层（缓冲、叠加、连接、选择），并添加面积和长度字段，但不会就地编辑要素 |
| 网络和栅格分析，平端或方端的缓冲区及单侧缓冲区，在属性表中添加或删除行以及更改字段类型，手动设置类别颜色，图件中的样式图例 | 使用**选择**选取要素并由其生成图层；不提供平端。按属性着色和属性表已经实现：见 [按属性设置图层样式](topic:gis-symbology) 和 [使用图层属性表](topic:gis-table) |
| 标注样式（大小、位置）以及避免相互重叠的标注 | 标注为统一大小，在要素密集处可能重叠 |
| 竖向基准和大地水准面模型 | 高程按文件提供的数值使用；请自行核对竖向基准 |
| 除按区域建议的 NAD27 至 NAD83 以外的网格偏移（OSTN15；添加文件后，其他基准的 NTv2 可用），多个网格同时使用，竖向网格 | 为你的基准添加网格文件；每个项目一个网格 |
| DXF 或三维导出中的地图图层 | 地图图层输出到 PDF 图中，并在 DWG 中以图片形式显示 |
| 需要登录、密钥或令牌的地图服务器 | 使用公共服务，或使用带地理参照的图像文件 |
| 从曲面、地面模型或高程网格及 LiDAR 工具写出 LAS 或 LAZ 文件 | 将曲面导出为 GeoTIFF 高程网格。[点云](topic:point-clouds) 插件可将清理后的点云写为 LAS 1.4 或 LAZ |
| LiDAR 强度、颜色和回波；多波段高程网格；超过 200 MB 的网格或 LiDAR 文件 | LiDAR 仅按类别过滤，网格使用其第一波段；请先将大文件切分为图块 |

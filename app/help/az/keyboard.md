Mətn yazmadığınız zaman tək hərfli düymələr işləyir. {{key:Mod}} ilə olan qısayollar Mac-də Command, digər yerlərdə Ctrl istifadə edir. Həmçinin bax: [Brauzerdə düymələr](common:keys).

## Fayllar və redaktə

| Düymə | Əməliyyat |
|---|---|
| {{key:Mod+O}} | Nöqtə faylı, LandXML və ya layihə açın |
| {{key:Mod+S}} | Layihəni saxlayın (`.civilcraft.json` faylı yükləyir) |
| {{key:Mod+P}} | Planı PDF-ə çap edin (brauzerin çapı deyil, çap dialoqunu açır) |
| {{key:Mod+Z}} | Geri qaytar |
| {{key:Mod+Y}} | Təkrarla |
| {{key:Delete}} | Seçilmiş survey nöqtələrini, trassanı, platformanı, strukturu, borunu və ya PVI-ni silin |
| {{key:Mod+C}} | Seçilmiş survey nöqtələrini kopyalayın (həm də cədvəl üçün nöqtə sətirləri kimi) |
| {{key:Mod+X}} | Seçilmiş survey nöqtələrini kəsin |
| {{key:Mod+V}} | Nöqtələri yapışdırın: onlar göstəricini izləyir, harada getməlidirsə klik edin |
| {{key:Mod+Shift+V}} | Yerində yapışdırın: nöqtələrin öz koordinatlarında |
| {{key:Mod+D}} | Seçilmiş nöqtələri dublikat edin: nüsxə göstəricini izləyir |
| {{key:Mod+A}} | Bütün survey nöqtələrini seçin |
| {{key:Esc}} | Heç nə seçməyin (və yapışdırmanı ləğv edin) |

{{key:Mod+S}}, {{key:Mod+O}} və {{key:Mod+P}} qutuya yazarkən də işləyir. Mətn qutusunda {{key:Mod+Z}} və {{key:Mod+Y}} adi qaydada yazdığınızı geri alır; {{key:Mod+C}}, {{key:Mod+X}}, {{key:Mod+V}} və {{key:Mod+A}} da eynidir: qutuda mətni kopyalayır, kəsir, yapışdırır və seçir. Səhifədə (paneldə) mətn seçilmişsə {{key:Mod+C}} həmin mətni kopyalayır. {{key:Mod+Shift+Z}} CivilCraft-da heç nə etmir: {{key:Mod+Y}} və ya {{ui:Redo}} düyməsindən istifadə edin.

:::mac
Mac klaviaturasında **delete** yazılmış düymə brauzer üçün {{key:Backspace}}-dir. Seçimi silmək üçün {{key:Delete}} basın (Fn və delete), və ya alətlər panelinin {{ui:More}} menyusundan {{ui:Delete}} seçin.
:::

| Düymə | Əməliyyat |
|---|---|
| {{key:Enter}} | Trassanı, platformanı, boru xəttini, sınma xəttini və ya sərhədi bitirin |
| {{key:Backspace}} | Sonuncu klik edilmiş nöqtəni silin |
| {{key:C}} | Xarakterik xətt: qövsləri açın və ya bağlayın (təpədən sonra əyrinin nöqtəsinə, sonra onun sonuna klik edin) |
| {{key:Esc}} | Çəkilişi (və ya yapışdırmanı) ləğv edin; yenidən basılsa (və ya heç nə çəkilməyibsə) {{ui:Select}}-ə qayıdın və seçimi təmizləyin |

## Plan görünüşü

| Düymə və ya əməliyyat | Nəticə |
|---|---|
| Çarx | Göstəricidə yaxınlaşdırın və ya uzaqlaşdırın |
| Boş yerdə sürükləmə | Sürüşdürün (istənilən alətdə; qısa klik yenə klik edir; {{key:Shift}} basılı olduqda seçim qutusu çəkir) |
| Orta düymə ilə sürükləmə | Sürüşdürün |
| Sağ düymə ilə sürükləmə | Sürüşdürün (menyu açılmır) |
| {{key:Space}} və sürükləmə | Sürüşdürün |
| Klik | Seçin ({{ui:Select}} ilə) və ya nöqtə qoyun (çəkmə aləti ilə) |
| {{key:Shift}} və klik | Seçimə nöqtə əlavə edin və ya çıxarın |
| {{key:Shift}} və sürükləmə | Qutu çəkin: içindəki nöqtələr seçimə əlavə olunur. Onların ətrafında sürükləyin, [laso](topic:lasso-selection) |
| {{key:Space}} laso çəkərkən | Pəncərə, sonra kəsişmə, sonra hasar |
| Yapışdırarkən klik | Yapışdırılmış nöqtələri oraya qoyun ({{key:Enter}} onları öz koordinatlarında qoyur) |
| Tutacağı sürükləmə | PI, platforma künci və ya strukturu köçürün (bir geri alma addımı) |
| {{key:Up}} {{key:Down}} {{key:Left}} {{key:Right}} | Plan fokusda olduqda sürüşdürün (əvvəlcə ona klik edin) |
| {{key:Plus}} və {{key:Minus}} | Plan fokusda olduqda ortada yaxınlaşdırın və uzaqlaşdırın |

= düyməsi {{key:Plus}} kimi yaxınlaşdırır, buna görə Shift lazım deyil.

## Profil görünüşü

| Əməliyyat | Nəticə |
|---|---|
| {{ui:Add PVIs}} açıq olarkən klik | Orada PVI əlavə edin |
| PVI-yə klik | Onu seçin |
| PVI-ni sürükləyin | Köçürün (bir geri alma addımı) |
| {{key:Delete}} və ya {{key:Backspace}} | Seçilmiş PVI-ni silin ({{key:Backspace}} yalnız profil görünüşü fokusda olduqda) |

Profil görünüşü miqyaslanmır və sürüşmür.

## Ekran və kömək

| Düymə | Əməliyyat |
|---|---|
| {{key:F1}} | Bu köməyi açın və ya bağlayın (yan panel); tətbiq panelindəki {{ui:Help}} da eynisini edir |
| {{key:Esc}} | Açıq olduqda kömək panelini bağlayın |
| {{key:Ctrl+Shift+F}} | Ekran rejimləri arasında keçin: tam ekran, panellər gizlədilmiş tam ekran, normal |
| {{key:Esc}} | Tam ekrandan çıxın (brauzerin öz düyməsi) |

{{key:F1}} CivilCraft görməmişdən əvvəl brauzer tərəfindən qəbul olunur, buna görə hər alətdə işləyir. Əksər Mac klaviaturalarında F1 ilə birlikdə fn basın, və ya {{ui:Help}} klik edin. {{key:Ctrl+Shift+F}} hər platformada, o cümlədən Mac-də Control düyməsini istifadə edir. Bu köməkdə axtarış üçün bax: [Köməkdən istifadə](common:help).

## Siçan, trackpad və toxunma

:::mouse
- Çarx göstəricidə yaxınlaşdırır. Sərbəst fırlanan çarxlı siçan sürətlə yaxınlaşdırır: qısa fırlanmalar edin.
- Boş yerdə istənilən sürükləmə, orta düymə, sağ düymə və ya {{key:Space}} və sürükləmə ilə sürüşdürün.
:::

:::mac
Mac trackpad-də:

- İki barmaqla sürüşdürmə **yaxınlaşdırır** (sürüşdürmür), sıxma da yaxınlaşdırır.
- Sürüşdürmək üçün boş yerdə bir barmaqla basın və sürükləyin, və ya {{key:Space}} basıb sürükləyin.
- İki barmaqla klik (sağ klik) menyu açmır və təkbaşına heç nə etmir.
:::

:::touch
Toxunma ekranında:

- İlk toxunma düymələri və menyu sətirlərini barmaq ölçüsündə edir.
- Seçmək və ya nöqtə qoymaq üçün toxunun; boş yerdə bir barmağı sürükləmək sürüşdürür. Toxunma bir az titrəyə bilər: barmaq təxminən 10 piksel hərəkət etdikdə sürüşdürür.
- İki barmaqla sıxın — yaxınlaşdırır; birlikdə hərəkət etdirin — sürüşdürür.
- Tutacağı və ya PVI-ni bir barmaqla sürükləyin. Tutacaqların ətrafında barmağın eni qədər yer var.
- Trassa, platforma, sınma xətti, sərhəd, boru xətti, xarakterik xətt və ya parsel çəkərkən plan üzərində çubuq {{ui:Finish}} ({{key:Enter}}), {{ui:Undo point}} ({{key:Backspace}}) və {{ui:Cancel}} ({{key:Esc}}) təklif edir. Uzun basış (tərpənmədən yarım saniyə) da bitirir.
- {{ui:Select}}-də survey nöqtəsinə uzun basış onu seçimə əlavə edir və ya çıxarır, {{key:Shift}}+klik kimi.
- 3D görünüşdə bir barmaq ətrafında fırladır, iki barmaq sıxıb sürüşdürür, toxunma seçir.
- Toxunmada hover yoxdur, buna görə status paneli oxunuşları yalnız barmaq basılı olduqda yenilənir.
:::

## Brauzerin qalib gəldiyi düymələr

Bəzi düymələr brauzerə məxsusdur və heç vaxt CivilCraft-a çatmır, məsələn {{key:Mod+W}} (sekmə bağlamaq), {{key:Mod+T}} (yeni sekmə), {{key:Mod+N}} (yeni pəncərə) və {{key:F11}} (Windows və Linux brauzerlərdə tam ekran). CivilCraft onları istifadə etmir. Əgər qısayol əvəzinə brauzerdə nəsə açırsa, səhifənin fokusda olması üçün plana bir dəfə klik edin və yenidən cəhd edin.

## Move haradadır

CivilCraft-da Move əmri yoxdur: {{ui:Select}} seçin və nöqtəni və ya təpəni sürükləyin, ya da koordinatlarını {{ui:Properties}}-də redaktə edin. Bax: [Nöqtələri redaktə edin](topic:edit-points).

Viena burta taustiņi darbojas, kad nerakstāt lodziņā. Īsceļi ar {{key:Mod}} izmanto Command uz Mac un Ctrl citur. Skatiet arī [Taustiņi pārlūkprogrammā](common:keys).

## Faili un rediģēšana

| Taustiņš | Darbība |
|---|---|
| {{key:Mod+O}} | Atvērt punktu failu, LandXML vai projektu |
| {{key:Mod+S}} | Saglabāt projektu (lejupielādē `.civilcraft.json` failu) |
| {{key:Mod+P}} | Izdrukāt plānu uz PDF (atver izdrukas dialogu, nevis pārlūkprogrammas drukāšanu) |
| {{key:Mod+Z}} | Atsaukt |
| {{key:Mod+Y}} | Atkārtot |
| {{key:Delete}} | Dzēst atlasītos uzmērījuma punktus, trasi, platformu, konstrukciju, cauruli vai PVI |
| {{key:Mod+C}} | Kopēt atlasītos uzmērījuma punktus (arī kā punktu rindas izklājlapai) |
| {{key:Mod+X}} | Izgriezt atlasītos uzmērījuma punktus |
| {{key:Mod+V}} | Ielīmēt punktus: tie seko kursoram, noklikšķiniet, kur tie jāieliek |
| {{key:Mod+Shift+V}} | Ielīmēt vietā: punktu paša koordinātēs |
| {{key:Mod+D}} | Dublēt atlasītos punktus: kopija seko kursoram |
| {{key:Mod+A}} | Atlasīt visus uzmērījuma punktus |
| {{key:Esc}} | Noņemt atlasi (un atcelt ielīmēšanu) |

{{key:Mod+S}}, {{key:Mod+O}} un {{key:Mod+P}} darbojas arī tad, kad rakstāt lodziņā. {{key:Mod+Z}} un {{key:Mod+Y}} lodziņā atsauc jūsu rakstīšanu, kā parasti, tāpat kā {{key:Mod+C}}, {{key:Mod+X}}, {{key:Mod+V}} un {{key:Mod+A}}: lodziņā tie kopē, izgriež, ielīmē un atlasa tā tekstu. Ja lapā (panelī) ir atlasīts teksts, {{key:Mod+C}} kopē šo tekstu. {{key:Mod+Shift+Z}} CivilCraft nedara nekā: izmantojiet {{key:Mod+Y}} vai pogu {{ui:Atkārtot}}.

:::mac
Mac taustiņš, kas apzīmēts **delete**, pārlūkprogrammai ir {{key:Backspace}}. Lai dzēstu atlasi, nospiediet {{key:Delete}} (Fn un delete) vai izvēlieties {{ui:Dzēst}} rīkjoslas izvēlnē {{ui:Vairāk}}.
:::

| {{key:P}} | {{ui:Caurules}} |
| {{key:B}} | {{ui:Lūzumlīnija}} |
| {{key:O}} | {{ui:Robeža}} |
| {{key:R}} | Rādīt vai slēpt profila skatu |
| {{key:I}} | Ieslēgt vai izslēgt {{ui:Pievienot PVI}} (atver profila skatu, ja tas ir aizvērts) |
| {{key:F}} | {{ui:Pielāgot}}: rādīt visu |
| {{key:D}} | {{ui:3D}}: rādīt vietu 3D vai atgriezties plānā |

Nospiežot aktīvā rīka taustiņu vēlreiz, atgriezīsieties pie {{ui:Atlasīt}}. Burti ar Shift nedara neko.

## Zīmēšanas laikā

| Taustiņš | Darbība |
|---|---|
| {{key:Enter}} | Pabeigt trasi, platformu, cauruļu posmu, lūzumlīniju vai robežu |
| {{key:Backspace}} | Noņemt pēdējo noklikšķināto punktu |
| {{key:C}} | Raksturlīnija: ieslēgt vai izslēgt lokus (pēc virsotnes noklikšķiniet punktu uz līknes, tad tās galu) |
| {{key:Esc}} | Atcelt zīmēšanu (vai ielīmēšanu); nospiežot vēlreiz (vai ja nekas nav zīmēts), atgriezties pie {{ui:Atlasīt}} un notīrīt atlasi |

## Plāna skats

| Taustiņš vai darbība | Rezultāts |
|---|---|
| Ritenītis | Tālummaiņa tuvināt vai tālināt pie kursora |
| Velciet tukšā vietā | Panoramēt (jebkurā rīkā; īss klikšķis joprojām klikšķina; ja turat {{key:Shift}}, tas zīmē atlases lodziņu) |
| Velciet ar vidējo pogu | Panoramēt |
| Velciet ar labo pogu | Panoramēt (izvēlne neatveras) |
| {{key:Space}} un velciet | Panoramēt |
| Klikšķis | Atlasīt (ar {{ui:Atlasīt}}) vai novietot punktu (ar zīmēšanas rīku) |
| {{key:Shift}} un klikšķis | Pievienot uzmērījuma punktu atlasei vai izņemt to |
| {{key:Shift}} un velciet | Zīmēt lodziņu: uzmērījuma punkti tajā tiek pievienoti atlasei. Velciet ap tiem, lai izmantotu [lasso](topic:lasso-selection) |
| {{key:Space}} zīmējot lasso | Logs, tad šķērsošana, tad žogs |
| Klikšķis ielīmējot | Novietot ielīmētos punktus tur ({{key:Enter}} tos novieto pie to paša koordinātēm) |
| Velciet rokturi | Pārvietot PI, platformas stūri vai konstrukciju (viens atsaukšanas solis) |
| {{key:Up}} {{key:Down}} {{key:Left}} {{key:Right}} | Panoramēt, kad plānam ir fokuss (vispirms noklikšķiniet uz tā) |
| {{key:Plus}} un {{key:Minus}} | Tālummaiņa tuvināt un tālināt vidū, kad plānam ir fokuss |

Taustiņš = tuvina kā {{key:Plus}}, tāpēc Shift nav vajadzīgs.

## Profila skats

| Darbība | Rezultāts |
|---|---|
| Klikšķis ar ieslēgtu {{ui:Pievienot PVI}} | Pievienot PVI tajā vietā |
| Noklikšķināt PVI | Atlasīt to |
| Velkot PVI | Pārvietot to (viens atsaukšanas solis) |
| {{key:Delete}} vai {{key:Backspace}} | Noņemt atlasīto PVI ({{key:Backspace}} tikai tad, kad profila skatam ir fokuss) |

Profila skats netuvina un nepanoramē.

## Ekrāns un palīdzība

| Taustiņš | Darbība |
|---|---|
| {{key:F1}} | Atvērt vai aizvērt šo palīdzību (sānu paneli); {{ui:Palīdzība}} lietotnes joslā dara to pašu |
| {{key:Esc}} | Aizvērt palīdzības paneli, kad tas ir atvērts |
| {{key:Ctrl+Shift+F}} | Pārslēgt ekrāna režīmus: pilnekrāns, pilnekrāns ar paslēptām joslām, parastais |
| {{key:Esc}} | Iziet no pilnekrāna (pārlūkprogrammas pašas taustiņš) |

{{key:F1}} sasniedz palīdzību, pirms CivilCraft to redz, tāpēc tas darbojas jebkurā rīkā. Uz lielākās daļas Mac tastatūru nospiediet fn ar F1 vai noklikšķiniet {{ui:Palīdzība}}. {{key:Ctrl+Shift+F}} visās platformās izmanto Control taustiņu, arī Mac. Skatiet [Palīdzības lietošana](common:help), lai uzzinātu, kā šajā palīdzībā meklēt.

## Pele, skārienpanelis un skārieni

:::mouse
- Ritenītis tuvina pie kursora. Pele ar brīvi griežamu riteni tuvina ātri: dodiet tam īsus pagriezienus.
- Panoramējiet ar jebkuru velkšanu tukšā vietā, vidējo pogu, labo pogu vai {{key:Space}} un velciet.
:::

:::mac
Mac skārienpanelī:

- Divu pirkstu ritināšana **tuvina** (nepanoramē), un savilkšana arī tuvina.
- Lai panoramētu, nospiediet un velciet tukšā vietā ar vienu pirkstu vai turiet {{key:Space}} un velciet.
- Divu pirkstu klikšķis (labais klikšķis) neatver izvēlni un pats par sevi nedara neko.
:::

:::touch
Skārienekrānā:

- Pirmais pieskāriens padara pogas un izvēlņu rindas pirksta lielumā.
- Pieskarieties, lai atlasītu vai novietotu punktu; viens pirksts, velkot tukšā vietā, panoramē. Pieskāriens var nedaudz svārstīties: tas panoramē tikai tad, kad pirksts pārvietojas par aptuveni 10 pikseļiem.
- Divi pirksti savelk, lai tuvinātu, un pārvietojas kopā, lai panoramētu.
- Velciet rokturi vai PVI ar vienu pirkstu. Rokturiem ap tiem ir vienas pirksta platuma zona.
- Kamēr zīmējat trasi, platformu, lūzumlīniju, robežu, cauruļu posmu, raksturlīniju vai parcelu, virs plāna parādās josla ar {{ui:Pabeigt}} ({{key:Enter}}), {{ui:Atsaukt punktu}} ({{key:Backspace}}) un {{ui:Atcelt}} ({{key:Esc}}). Ilgs nospiediens (puse sekundes bez kustības) arī pabeidz.
- {{ui:Atlasīt}} režīmā ilgs nospiediens uz uzmērījuma punkta pievieno to atlasei vai izņem, kā dara {{key:Shift}}+klikšķis.
- 3D skatā viens pirksts griež, divi savelk un panoramē, un pieskāriens izvēlas.
- Skārienekrānā nav uzvilkšanas efekta, tāpēc statusa joslas rādījumi atjaunojas tikai tad, kad pirksts ir uz ekrāna.
:::

## Pārlūkprogrammas taustiņi, kas uzvar

Daži taustiņi pieder pārlūkprogrammai un nekad nesasniedz CivilCraft, piemēram, {{key:Mod+W}} (aizvērt cilni), {{key:Mod+T}} (jauna cilne), {{key:Mod+N}} (jauns logs) un {{key:F11}} (pilnekrāns Windows un Linux pārlūkprogrammās). CivilCraft tos neizmanto. Ja īsceļš tā vietā atver kaut ko pārlūkprogrammā, vienreiz noklikšķiniet plānā, lai lapa saņemtu fokusu, un mēģiniet vēlreiz.

## Kur ir pārvietošana

Komandas Pārvietot nav: izvēlieties {{ui:Atlasīt}} un velciet punktu vai virsotni, vai rediģējiet tā koordinātas sadaļā {{ui:Rekvizīti}}. Skatiet [Rediģēt punktus](topic:edit-points).

У CivilCraft немає діалогу налаштувань чи шаблону. Це значення, з яких щось починається. Значення, позначені **заготовка**, не взяті з жодного стандарту: замініть їх критеріями вашого проєкту, перш ніж покладатися на перевірку чи кількість.

## Новий проєкт

| Налаштування | Значення |
|---|---|
| Назва | Ділянка без назви (назву замінює назва першого файлу точок) |
| Одиниці | US feet |
| Назва поверхні | Наявний ґрунт |
| Групи точок | Кожна група починається як {{ui:Точок}} |
| Найдовший зовнішній край | 0 (зберігати кожен трикутник) |
| Збережено кроків скасування | 200 |

## Відображення

| Налаштування | Значення |
|---|---|
| Поверхня | {{ui:Наявний ґрунт}} |
| Горизонталі з кроком | 1 (ft або m) |
| Основні через | 5-та горизонталь |
| Смуги | 8 |
| Увімкнено | Горизонталі, написи горизонталей, точки, лінії розриву, край поверхні, труби |
| Вимкнено | Трикутники, смуги відміток, стрілки укосів, написи точок |

## Траси і профілі

| Налаштування | Значення |
|---|---|
| Назва | Траса 1, Траса 2 … |
| Початковий пікет | 0+00 |
| Радіус кривої в кожному внутрішньому PI | 100 ft або 30 m, менший, якщо він не вміщується в половині кожного дотичного відрізка |
| Проєктний профіль | Немає, доки ви його не почнете; {{ui:Почати від ґрунту}} ставить PVI на ґрунт на кожному кінці |
| Довжина вертикальної кривої | 0 (без кривої), доки ви її не введете |

## Обсяги

| Налаштування | Значення |
|---|---|
| Метод | Сітка, відбирається в центрах клітинок всередині ліній врізки |
| Розмір клітинки | Обирається так, щоб прямокутник, що охоплює спланповану площу, містив близько 250,000 клітинок (1, 2 або 5 разів степінь десяти) |
| Розпушення і усадка | Немає |

## Друк

| Налаштування | Значення |
|---|---|
| Область | {{ui:Усе}} |
| Папір | Tabloid 11 × 17 in (проєкти у футах), ISO A3 (проєкти в метрах); завжди альбомна орієнтація |
| Масштаб | Найбільший зі списку масштаб, що вміщується |
| Чорнило | {{ui:Кольори шарів}} |

Написи DXF мають розмір, підібраний під масштаб, у якому все вміщується на Tabloid (фути) або A3 (метри).

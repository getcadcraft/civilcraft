ខ្សែផ្លូវក្នុង CivilCraft គឺជាខ្សែនៃតង់ហ្សង់ត៍ តាមចំណុចប្រសព្វ (PI) ជាមួយធ្នូរាងជុំនៅ PI ខាងក្នុងណាមួយដែលមានកាំ។ វាមានស្ថានីយដែលដាក់ពីស្ថានីយចាប់ផ្ដើមដែលអ្នកជ្រើសរើស។ គម្រោងមួយអាចមានខ្សែផ្លូវជាច្រើន។

## គូសខ្សែផ្លូវ

1. ចុច {{key:A}} ឬចុច {{ui:ខ្សែផ្លូវ}} ក្នុងក្រុម **ការរចនា**។
   ការណែនាំនិយាយថា "ខ្សែផ្លូវ៖ ចុច PI តាមលំដាប់។ Enter ឬចុចទ្វេដង បញ្ចប់ Backspace លុប PI ចុងក្រោយ Esc បោះបង់។"
2. ចុច PI ដំបូង (ការចាប់ផ្ដើមនៃខ្សែផ្លូវ)។
3. ចុច PI បន្ទាប់នីមួយៗតាមលំដាប់។ បន្ទាត់ក្រហមដើរតាមកណ្ដុរ ហើយបង្ហាញប្រវែង និងទិសនៃតង់ហ្សង់ត៍ដែលអ្នកកំពុងគូស ឧទាហរណ៍ "212.40 ft  N 63°12'05" E"។
4. ចុច PI ចុងក្រោយ (ទីបញ្ចប់នៃខ្សែផ្លូវ)។
5. ចុច {{key:Enter}}។
   ខ្សែផ្លូវត្រូវបានគូសជាមួយការដាក់ស្ថានីយ ហើយត្រូវបានជ្រើសរើស។ របារស្ថានភាពនិយាយ ឧទាហរណ៍ "Alignment 1: 386.36 ft, curves of 100 ft radius where they fit. Edit radii in Properties; Profile (R) to design its grade."

ពេលកំពុងគូស៖ {{key:Backspace}} លុប PI ចុងក្រោយ {{key:Esc}} បោះបង់ ហើយអូសលើចន្លោះទទេ ផ្លាស់ទីទិដ្ឋភាពដោយមិនបន្ថែម PI។

:::warning
បញ្ចប់ដោយ {{key:Enter}}។ ចុចទ្វេដងក៏បញ្ចប់ដែរ ប៉ុន្តែក្នុងកំណែនេះវាលុប PI ដែលអ្នកបានចុចទ្វេដង។ ចុច PI ចុងក្រោយមួយដង បន្ទាប់មកចុច {{key:Enter}}។
:::

PI ខាងក្នុងនីមួយៗទទួលធ្នូ 100 ft (30 m ក្នុងគម្រោងម៉ែត្រ) ឬកាំគត់ធំបំផុតដែលសមនៅពាក់កណ្ដាលនៃតង់ហ្សង់ត៍នីមួយៗ ប្រសិនបើ 100 ft មិនសម។ PI ដែលមុតខ្លាំង ឬ PI ត្រង់ពេញ នឹងមិនទទួលធ្នូឡើយ។

## កំណត់កាំ និងកូអរដោនេ

នៅពេលខ្សែផ្លូវត្រូវបានជ្រើសរើស បន្ទះស្ដាំបង្ហាញ **ខ្សែផ្លូវ**៖

1. **ឈ្មោះ** និង **ស្ថានីយចាប់ផ្ដើម**។ វាយស្ថានីយដូចជា `10+00` (ហ្វីត) ឬ `0+500` (ម៉ែត្រ) ឬជាលេខធម្មតា។ សូមមើល [ឯកតា ស្ថានីយ និងទម្រង់លេខ](topic:units-and-stations)។
2. **ប្រវែង** និង **ស្ថានីយបញ្ចប់** ត្រូវបានគណនាសម្រាប់អ្នក។
3. តារាង **PI** បញ្ជីនូវ **Easting** និង **Northing** របស់ PI នីមួយៗ ហើយ **កាំ** សម្រាប់ PI ខាងក្នុងនីមួយៗ។ វាយតម្លៃថ្មី ហើយចុច {{key:Enter}}។
   - កាំ 0 ធ្វើឱ្យចំណុចមុំគ្មានធ្នូ។
   - PI ដំបូង និង PI ចុងក្រោយមិនដែលមានកាំឡើយ។
   - សញ្ញា x តូចនៅចុងជួរ លុប PI នោះ (ខ្សែផ្លូវត្រូវមានយ៉ាងហោចណាស់ពីរ)។
4. អានបញ្ជី **ធ្នូ**៖ សម្រាប់ធ្នូនីមួយៗ ស្ថានីយ PC និង PT របស់វា កាំ R ដេរីវេស Δ និងទិស (ឆ្វេង ឬស្ដាំ) ប្រវែង L តង់ហ្សង់ត៍ T ចម្ងាយខាងក្រៅ E និងអង្កត់ធ្នូ។
5. បន្ទាត់នៅក្រោមធ្នូផ្ដល់ទិសនៃតង់ហ្សង់ត៍ដំបូង។

## នៅពេលធ្នូមិនសម

ប្រសិនបើធ្នូត្រូវការតង់ហ្សង់ត៍ច្រើនជាងដែលមាននៅចន្លោះ PI របស់វា ខ្សែផ្លូវគ្មានដំណោះស្រាយ៖ វាមិនត្រូវបានគូសត្រឹមត្រូវទេ រហូតដល់អ្នកកែ ហើយវាត្រូវបានលុបចេញពីការនាំចេញ LandXML។ ប្រអប់ក្រហមនិយាយមូលហេតុជាលេខ ហើយផ្ដល់អ្វីដែលនឹងសម៖

- "The curves at PI 2 and PI 3 need 240.00 ft of tangent between them (130.00 + 110.00), but the PIs are 180.00 ft apart." — ឬនៅពេលមានតែមួយក្នុងចំណោមពួកវាមានធ្នូ "The curve at PI 2 needs 240.00 ft of tangent towards PI 1 …"។
- ប៊ូតុងសម្រាប់ PI នីមួយៗកំណត់ **កាំធំបំផុតដែលសម** នៅទីនោះ ដោយធ្នូមួយទៀតនៅដដែល (វាក៏ត្រូវសមជាមួយតង់ហ្សង់ត៍ផ្សេងទៀតរបស់ PI)។ នៅពេល PI ទាំងពីរមានធ្នូ **Both** បង្រួមកាំទាំងពីរតាមសមាមាត្រ ដូច្នេះវាជួបគ្នាពេញលេញ។
- នៅពេលធ្នូតែមួយវែងជាងតង់ហ្សង់ត៍ ប្រអប់និយាយថាគ្មានធ្នូនៅ PI ផ្សេងណាអាចសមបានខណៈដែលវាធំ។
- PI ដែលត្រលប់ត្រង់ទៅក្រោយមិនអាចទទួលធ្នូបានឡើយ; ប្រអប់ផ្ដល់ **គ្មានធ្នូនៅ PI n**។

ប៊ូតុងនីមួយៗជាជំហានមួយ៖ {{key:Mod+Z}} ដាក់កាំត្រឡប់មកវិញ។ កាំដែលផ្ដល់ត្រូវបានបង្គត់ចុះដល់ 0.01 ដូច្នេះវាតែងតែសម។

### កាំអប្បរមារចនា

វាយ **កាំអប្បរមារចនា** (ឧទាហរណ៍ពីល្បឿនរចនារបស់អ្នក) ដើម្បីឱ្យធ្នូនីមួយៗត្រូវបានពិនិត្យជាមួយវា; ទុកវាទទេបើគ្មាន។ ធ្នូដែលតូចជាងវាត្រូវបានបញ្ជីជាមួយប៊ូតុង **កាំតូចបំផុតដែលបំពេញអប្បរមា** នៅពេលកាំនោះសម។ នៅពេលវាមិនសម ប្រអប់និយាយដូច្នេះ ហើយផ្ដល់កាំធំបំផុតដែលតង់ហ្សង់ត៍អនុញ្ញាត ដូច្នេះអ្នកដឹងថាត្រូវផ្លាស់ទី PI ឬបន្ថយអប្បរមា។

## ផ្លាស់ទី PI លើប្លង់

1. ជាមួយ {{ui:ជ្រើសរើស}} សកម្ម ចុចខ្សែផ្លូវដើម្បីជ្រើសរើសវា។ ចំណុចចាប់ការ៉េលេចឡើងនៅ PI របស់វា។
2. អូសចំណុចចាប់មួយ។ ខ្សែផ្លូវ ការដាក់ស្ថានីយ ប្រូហ្វាយ និងច្រកផ្លូវ ដើរតាម។
3. បញ្ចេញ។ ការផ្លាស់ទីគឺជាជំហានមិនធ្វើវិញមួយ។

ការបន្ថែម PI រវាង PI ដែលមានស្រាប់ពីរមិនទាន់មានសម្រាប់ពេលនេះទេ៖ លុបខ្សែផ្លូវ ហើយគូសវាឡើងវិញ ឬវាយកូអរដោនេថ្មីសម្រាប់ PI ដែលអ្នកមាន។

## អានស្ថានីយ និងការឆ្លងពីអ័ក្ស

ផ្លាស់ទីកណ្ដុរលើប្លង់។ របារស្ថានភាពបង្ហាញខ្សែផ្លូវដែលនៅជិតបំផុត (ឬដែលបានជ្រើស) ជាមួយស្ថានីយ និងការឆ្លង **L** ឬ **R** ដែលមើលទៅស្ថានីយខាងមុខ ឧទាហរណ៍ "Alignment 1: Sta 2+15.30, offset 18.42 R"។ លើសពីចុងណាមួយ វាបន្ថែម "(beyond the end)"។

## អ្វីដែលត្រូវបានគូស

នៅលើប្លង់ ក្នុង DXF និងក្នុង PDF៖ បន្ទាត់កណ្ដាល (តង់ហ្សង់ត៍ជាបន្ទាត់ ធ្នូជាធ្នូពិត) សញ្ញាគូសរៀងរាល់ 50 ft (20 m) ជាមួយសញ្ញាគូសវែងជាង និងស្លាកស្ថានីយរៀងរាល់ 100 ឯកត្តា ព្រមទាំងសញ្ញាគូស PC និង PT ដែលមានស្លាកជាស្ថានីយរបស់ពួកវា។

ក្រោម Properties របស់ខ្សែផ្លូវ **ល្បឿនរចនា** (km/h ឬ mph) និង **ថ្នាក់រចនា** ត្រូវបានរក្សាជាមួយខ្សែផ្លូវ រក្សាទុកក្នុងគម្រោង និងសរសេរទៅ IFC (Pset_RoadDesignCriteriaCommon)។ CivilCraft គ្មានតារាងណាដែលភ្ជាប់ល្បឿនជាមួយកាំអប្បរមាទេ ដូច្នេះគ្មានអ្វីត្រូវបានពិនិត្យពីវាឡើយ៖ កំណត់ **កាំអប្បរមា** ពីស្ដង់ដាររចនារបស់អ្នកផ្ទាល់។

## ខ្សែវង់ស្ពៀរ

ធ្នូអាចមានខ្សែវង់ស្ពៀរ clothoid នៅចុងណាមួយ៖ តង់ហ្សង់ត៍ ស្ពៀរ ធ្នូ ស្ពៀរ តង់ហ្សង់ត៍។ នៅក្នុងតារាង PI វាយប្រវែងក្នុង **ស្ពៀរចូល** និង **ស្ពៀរចេញ** សម្រាប់ PI ដែលមានកាំ។ PI នៅទីតាំងដដែល; ធ្នូផ្លាស់ទីចូលដើម្បីធ្វើកន្លែង ដូច្នេះចម្ងាយតង់ហ្សង់ត៍កើនឡើងតាមការផ្លាស់ទីនៃស្ពៀរ។ ប្រវែងទាំងពីរអាចខុសគ្នា ហើយ PI ដែលមានប្រវែងតែមួយទទួលស្ពៀរតែនៅចុងនោះ។

បញ្ជីធ្នូបន្ទាប់មកអាន TS, SC, CS និង ST (តង់ហ្សង់ត៍ទៅស្ពៀរ ស្ពៀរទៅធ្នូ ធ្នូទៅស្ពៀរ ស្ពៀរទៅតង់ហ្សង់ត៍) ជាមួយមុំស្ពៀរ θs ចម្ងាយតង់ហ្សង់ត៍ និងចម្ងាយខាងក្រៅ។ ស្ថានីយដើរតាមស្ពៀរដូចគ្នានឹងកន្លែងផ្សេងទៀត។ ស្ពៀរដែលបត់ច្រើនជាងធ្នូត្រូវបានបដិសេធ ដោយបញ្ជាក់ឈ្មោះ PI; ស្ពៀរដែលវែងជាងតង់ហ្សង់ត៍អនុញ្ញាតគឺជាការត្រួតស៊ីគ្នា ដូចធ្នូណាមួយ។ ការលើកកម្ពស់ផ្លូវកោងប្រើស្ពៀរជាចន្លោះចុះ (សូមមើល [ច្រកផ្លូវ](topic:corridor))។

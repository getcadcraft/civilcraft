ជ្រើសខ្សែតម្រឹម ហើយចុច **របាយការណ៍ដោតស្លាក** ក្នុង **លក្ខណៈ** របស់វា។

## ស្លាកតាមស្ថានី និងចម្ងាយដាច់

1. **ពី** និង **ដល់**៖ ស្ថានីដែលត្រូវដោតស្លាក (1+50 ឬ 150) ។
2. **រៀងរាល់**៖ ចន្លោះ។ ស្លាកដាក់នៅគ្រប់ពហុគុណរបស់វា នៅចុងទាំងពីរ និង (ពេលប្រអប់ត្រូវបានធីក) កន្លែងដែលខ្សែកោងនៃខ្សែតម្រឹមចាប់ផ្ដើម និងបញ្ចប់។
3. **ចម្ងាយដាច់**៖ ខាងឆ្វេង និងខាងស្ដាំនៃខ្សែតម្រឹម មើលទៅតាមស្ថានីកើន៖ `12 L, 0, 12 R`, `L12 CL R12` ឬ `-12, 0, 12` (ឆ្វេងជាដកលេខ) ។ ខ្សែតម្រឹមដែលមានច្រកចាប់ផ្ដើមដោយគែមកម្រាលផ្លូវ និងស្មាផ្លូវ។
4. **ដាក់លេខចាប់ពី** និង **ជាមួយបុព្វបទ** ដាក់ឈ្មោះស្លាក៖ 1, 2, 3 ឬ S101, S102 ។

## ចំណុចវាស់ក្បែរខ្សែតម្រឹម

ជ្រើស **ចំណុចវាស់ក្បែរខ្សែតម្រឹម** និងកម្រិតជិតនោះ។ ចំណុចនីមួយៗក្នុងចម្ងាយនោះទទួលបានស្ថានី និងចម្ងាយដាច់ របស់វា ការរចនានៅទីនោះ និងកម្ពស់ផ្ទាល់របស់វាជាដី៖ ជាការពិនិត្យចំណុចដែលបានដោតស្លាក ឬថតដូចសាងសង់។

## របាយការណ៍និយាយអ្វី

| ជួរ | ជាអ្វី |
|---|---|
| ចំណុច | ឈ្មោះស្លាក ឬលេខចំណុចវាស់ |
| ស្ថានី, ចម្ងាយដាច់ | កន្លែងវានៅតាមខ្សែតម្រឹម៖ L ឆ្វេង R ស្ដាំ |
| ទិសខាងជើង, ទិសខាងកើត | កូអរដោនេរបស់វា |
| កម្ពស់ការរចនា | ផ្ទៃច្រកដែលបានកាត់ស្តង់ដារនៅទីនោះ (ពីខ្សែកាត់ដីដល់ខ្សែកាត់ដី) បើមិនដូច្នេះទេ ប្លង់ការរចនានៅលើខ្សែកណ្ដាល |
| កម្ពស់ដី | ផ្ទៃដែលមានស្រាប់នៅទីនោះ ឬកម្ពស់ផ្ទាល់របស់ចំណុចវាស់ |
| កាត់/បំពេញ | C ពេលដីខ្ពស់ជាងការរចនា (កាត់ចុះ) F ពេលទាបជាង (បំពេញឡើង) ដល់ទសភាគទីពីរ |

ស្លាកដែលគ្មានកម្ពស់ការរចនា (នៅក្រៅច្រក ឬនៅលើខ្សែតម្រឹមដែលគ្មានច្រក ឆ្ងាយពីខ្សែកណ្ដាល) មិនមានការកាត់ ឬបំពេញទេ; ប្រអប់បញ្ជាក់ចំនួនរបស់វា។

## រក្សាទុក

- **CSV**៖ បន្ទាត់ចំណងជើង បន្ទាប់ដោយជួរខាងលើ បូកការកាត់ ឬបំពេញជាលេខមានសញ្ញា (ដីដកការរចនា) សម្រាប់សៀវភៅគណនា និងឧបករណ៍ប្រមូលទិន្នន័យ។
- **PDF**៖ ទំព័រតារាងលើក្រដាសដែលអ្នកជ្រើស ស្លាកមួយជួរ ការកាត់ជាពណ៌ទឹកក្រូច និងការបំពេញជាពណ៌បៃតង ជាមួយបន្ទាត់ចំណងជើងនៃសន្លឹកផ្សេង។

:::note
ស្លាកត្រូវបានគណនាពីការរចនានៅក្នុងគម្រោង។ ពិនិត្យវាជាមួយប្លង់ដែលបានអនុម័ត មុនពេលសាងសង់អ្វីទាំងអស់។
:::

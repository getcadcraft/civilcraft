នៅពេលគម្រោងមានស្រទាប់ GIS (សូមមើល [នាំចូលទិន្នន័យ GIS](topic:gis-import)) ប៊ូតុង **វិភាគ** ក្នុងក្រុម GIS (វាយ `GISANALYSIS`, `ANALYZE` ឬ `BUFFER`) បើកផ្ទាំងមួយដែលមានផ្ទាំងរងប្រាំ។ ផ្ទាំងនេះនៅបើកក្បែរប្លង់ ដូច្នេះអ្វីដែលអ្នកជ្រើសរើសត្រូវបានគូរលើប្លង់ខណៈពេលអ្នកធ្វើការ។

ឧបករណ៍ណាដែលបង្កើតអ្វីមួយ **បន្ថែមស្រទាប់ថ្មី** ហើយទុកស្រទាប់ដែលវាបានអាន ឲ្យនៅដូចដើមបេះបិទ។ ការនីមួយៗជាជំហានមិនធ្វើវិញមួយ៖ {{ui:មិនធ្វើវិញ}} ក្នុងផ្ទាំង (ឬ Ctrl+Z) លុបស្រទាប់ថ្មី។ នាំចេញលទ្ធផលដូចស្រទាប់ណាមួយ ជាមួយ [នាំចេញទិន្នន័យ as-built សម្រាប់ GIS](topic:gis-export) ជាទម្រង់ shapefile, GeoJSON ឬ GeoPackage។

តារាងពេញរបស់ស្រទាប់ ជាមួយការរៀប ការកែ និងម៉ាស៊ីនគិតវាល នៅក្នុង [ធ្វើការជាមួយតារាងគុណលក្ខណៈរបស់ស្រទាប់](topic:gis-table); ការផ្ទៀងពណ៌តាមវាល នៅក្នុង [កំណត់ស្ទីលស្រទាប់តាមគុណលក្ខណៈ](topic:gis-symbology)។

ការគណនាទាំងអស់ធ្វើលើប្លង់ ជាមួយឯកតារបស់គម្រោង (feet ឬ meters)។ គម្រោងតែងតែនៅក្នុងប្រព័ន្ធដែលបានបញ្ចាំង ឬប្រព័ន្ធក្នុងតំបន់ ដូច្នេះចម្ងាយ 50 មានន័យថា 50 feet ឬ 50 meters មិនមែនដឺក្រេទេ។ កម្ពស់ (z) មិនត្រូវបានរក្សាទុកក្នុងលទ្ធផលទេ។

## ផ្ទៃព័ទ្ធជុំវិញ (Buffer)

គូរតំបន់មួយមានចម្ងាយកំណត់ជុំវិញវត្ថុនីមួយៗ ជាស្រទាប់ពហុកោណថ្មី។ ចំណុចក្លាយជារង្វង់ បន្ទាត់ក្លាយជាច្រករបៀងមានចុងមូល ហើយពហុកោណធំឡើង។ ចម្ងាយ **អវិជ្ជមាន** បង្រួមពហុកោណ (ការ៉េ 100 គុណ 100 ដែលបានបង្រួមដោយ 5 គឺ 90 គុណ 90; បើបង្រួមដោយ 60 គ្មានអ្វីនៅសល់ ហើយផ្ទាំងនឹងប្រាប់)។ យកចម្ងាយពីវាលលេខ ដើម្បីឲ្យវត្ថុនីមួយៗមានចម្ងាយផ្ទាល់ខ្លួន ឬធីក **បញ្ចូលផ្ទៃព័ទ្ធជុំវិញទាំងអស់ទៅជារូបរាងតែមួយ** ដើម្បីបញ្ចូលគ្នា។

ផ្នែកមូលគឺជាបន្ទាត់ត្រង់ៗដែលគូរនៅខាងក្នុងខ្សែកោងពិត ដូច្នេះផ្ទៃព័ទ្ធជុំវិញតូចជាងរង្វង់ពិតបន្តិច៖ ប្រហែល 0.6 % ក្នុងផ្ទៃក្នុងការកំណត់ធម្មតា និង 0.16 % នៅ ល្អិត។ ប្រើ ល្អិត សម្រាប់អ្វីដែលអ្នកនឹងវាស់។

## ការត្រួតគ្នា (Overlay)

| ឧបករណ៍ | អ្វីដែលអ្នកទទួលបាន |
|---|---|
| Intersect | ចំណែកដែលស្រទាប់បញ្ចូលជួបពហុកោណត្រួតគ្នា ម្នាក់ៗមានវាលនៃទាំងពីរ។ បន្ទាត់ និងចំណុចត្រូវបានកាត់ឲ្យចូលក្នុងពហុកោណ។ |
| Union | ពហុកោណស្រទាប់ទាំងពីរកាត់តាមគែមគ្នាទៅវិញទៅមក៖ ចំណែកដែលចែករំលែកមានវាលរបស់ស្រទាប់ទាំងពីរ ចំណែកផ្សេងទៀតមានវាលរបស់ស្រទាប់មួយ (វាលរបស់ស្រទាប់ទៀតនៅទទេ)។ |
| Erase | ពហុកោណបញ្ចូលដែលត្រូវបានយកពហុកោណត្រួតគ្នាចេញ។ វាលនៅជាមួយបញ្ចូល។ វត្ថុដែលត្រូវបានលុបទាំងស្រុងនឹងត្រូវបានដកចេញ (ផ្ទាំងរាប់ចំនួនពួកវា)។ |
| Dissolve | បញ្ចូលពហុកោណដែលប៉ះ ឬត្រួតគ្នា ទាំងអស់ ឬរូបរាងមួយសម្រាប់តម្លៃនីមួយៗនៃវាលមួយ។ បន្ថែម `COUNT` និង `AREA`។ |

ឈ្មោះវាលដែលស្រទាប់ទាំងពីរមាន ត្រូវបានរក្សាទុកសម្រាប់ស្រទាប់ទីមួយ ហើយវាលរបស់ស្រទាប់ទីពីរត្រូវបានសរសេរជាមួយ `_2`។ វត្ថុក្នុងស្រទាប់មួយមិនគួរត្រួតគ្នាឯង៖ កន្លែងណាដែលត្រួតគ្នា ការរួមបញ្ចូលនឹងរាប់ការត្រួតគ្នានោះនៅក្នុងទាំងពីរ។

## ការភ្ជាប់ (Join)

ការភ្ជាប់តាមទីតាំងចម្លងគុណលក្ខណៈពីស្រទាប់ **ប្រភព** ទៅវត្ថុ **គោលដៅ** នីមួយៗដែលជួបវា ហើយផ្ដល់ស្រទាប់ថ្មីដែលមានរូបរាងរបស់គោលដៅ។ ជ្រើសរើសពេលណាពួកវាជួបគ្នា៖ ប៉ះ ឬត្រួតគ្នា, គោលដៅនៅក្នុងពហុកោណប្រភព, គោលដៅផ្ទុកវត្ថុប្រភព, វត្ថុប្រភពដែលនៅជិតបំផុត (ជាមួយដែនកំណត់ជាជម្រើស), ឬវត្ថុប្រភពណាមួយក្នុងចម្ងាយ។

នៅពេលវត្ថុប្រភពជាច្រើនត្រូវគ្នា អ្នកយកគុណលក្ខណៈរបស់ទីមួយ (ដែលនៅជិតបំផុត សម្រាប់ការភ្ជាប់ជិតបំផុត និងចម្ងាយ; `DISTANCE` ត្រូវបានបន្ថែម) ឬ **រាប់ពួកវា ហើយបូកវាលលេខរបស់ពួកវា**៖ `COUNT`, និង `SUM_`, `MEAN_`, `MIN_`, `MAX_` សម្រាប់វាលលេខនីមួយៗ។ ដោះធីក **រក្សាវត្ថុគោលដៅដែលមិនបានរកឃើញការត្រូវគ្នា** ដើម្បីដកវាចេញ។ វាលដែលបានភ្ជាប់នឹងនៅទទេកន្លែងដែលគ្មានការត្រូវគ្នា ហើយផ្ទាំងរាប់វត្ថុដែលមិនត្រូវគ្នា។

## ជ្រើសរើស

វាយសំណួរអំពីគុណលក្ខណៈ ឬរូបរាង ចុច **ជ្រើសរើស** ហើយវត្ថុត្រូវបានគូរលើប្លង់ជាមួយចំនួនរបស់ពួកវា តារាង និងផ្ទៃក្រឡា ប្រវែង ឬចំនួនសរុប។ បន្ទាប់មក បង្កើតវាជាស្រទាប់ផ្ទាល់ខ្លួន ពង្រីកទៅពួកវា ឬសម្អាតការជ្រើសរើស។

| អ្វីដែលអ្នកអាចសរសេរ | ឧទាហរណ៍ |
|---|---|
| វាលតាមឈ្មោះ; ប្រើ "សញ្ញាសម្រង់" ឬ [ដង្កៀបការ៉េ] បើឈ្មោះមានចន្លោះ | `VALUE`, `"Lot Number"` |
| លេខ, 'អក្សរ', true, false, null | `Use_ = 'Res'` |
| `=` `!=` `<>` `<` `<=` `>` `>=` | `VALUE >= 250` |
| `contains` `startswith` `endswith` `like` `ilike` (អក្សរមិនយកចិត្តទុកដាក់ទៅលើអក្សរធំ-តូច; ក្នុង `like`, `%` ជាអ្វីៗណាមួយ និង `_` ជាអក្សរមួយ) | `Notes contains 'corner'` |
| `is null`, `is not null` (តម្លៃទទេរាប់ជា null) | `Notes is null` |
| `in (…)`, `not in (…)`, `between … and …` | `Use_ in ('Com', 'Ind')` |
| `+ - * /` និងដង្កៀប | `VALUE / 2 > 100` |
| `and`, `or`, `not` | `Use_ = 'Res' and VALUE > 200` |
| តម្លៃរូបរាង `$area` `$perimeter` `$length` `$x` `$y` `$vertices` | `$area > 5000` |

សំណួរដែលមិនពេញលេញ ឬដាក់ឈ្មោះវាលដែលស្រទាប់គ្មាន នឹងត្រូវបានបដិសេធ ជាមួយប្រយោគដែលប្រាប់ថានៅកន្លែងណា។

## វាស់ (Measure)

បង្ហាញផ្ទៃក្រឡាសរុប និងបរិមាត្រ ប្រវែង ឬចំនួនរបស់ស្រទាប់ ហើយ **បន្ថែមវាល** ទៅវា៖ `AREA` និង `PERIMETER` សម្រាប់ពហុកោណ, `LENGTH` សម្រាប់បន្ទាត់ (ប្រវែងលើប្លង់), `X` និង `Y` សម្រាប់ចំណុច។ វាលដែលមានរួចហើយមិនត្រូវបានសរសេរជាន់ឡើយ៖ វាលថ្មីមានឈ្មោះ `AREA_2`។ នេះជាជំហានមិនធ្វើវិញមួយ។ **ស្ថិតិ** ផ្ដល់ចំនួន ផលបូក មធ្យម តម្លៃអប្បបរមា និងអតិបរមានៃវាលលេខមួយ ជាជម្រើសសម្រាប់តម្លៃនីមួយៗនៃវាលមួយទៀត។

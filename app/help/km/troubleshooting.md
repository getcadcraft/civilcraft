សារបង្ហាញនៅក្នុងរបារស្ថានភាពនៅផ្នែកខាងក្រោមខាងស្ដាំ ក្នុងប្រអប់នៅក្នុងផ្ទាំងខាងឆ្វេង និងខាងស្ដាំ និងក្នុងប្រអប់មតិ។ ពួកវាត្រូវបានដកស្រង់នៅទីនេះដូចដែលកម្មវិធីបង្ហាញ។

## បើកឯកសារ

**"ឯកសារនេះធំជាង 200 MB; CivilCraft មិនទាន់បើកឯកសារធំបែបនេះបានទេ។"**
បំបែកឯកសារចំណុច ឬកាត់បន្ថយទិន្នន័យមុនពេលបើកវា។

**"មិនអាចបើក site.json៖ នេះមិនមែនជាឯកសារគម្រោង CivilCraft ទេ។"**
ឯកសារបញ្ចប់ដោយ `.json` ឬចាប់ផ្ដើមដោយ `{` ប៉ុន្តែមិនមែនជាគម្រោង CivilCraft ទេ។ ឯកសារចំណុចមិនត្រូវចាប់ផ្ដើមដោយ `{` ឡើយ។

**"មិនអាចបើក … ឯកសារគម្រោងនេះមកពី CivilCraft កំណែថ្មីជាង (កំណែទី 2)។"**
គម្រោងត្រូវបានរក្សាទុកដោយកំណែថ្មីជាង។ បើកវានៅទីនោះ ឬនាំចេញ LandXML ពីវា។

**"មិនអាចបើក … នេះជា XML ប៉ុន្តែមិនមែន LandXML (ធាតុឫសរបស់វាគឺ <…>)។"**
ឯកសារនេះជាប្រភេទ XML ផ្សេង។ នាំចេញ LandXML ពីកម្មវិធីផ្សេងនោះ។

**"… មិនមានចំណុច ផ្ទៃ TIN ឬខ្សែផ្លូវដែល CivilCraft អានបានទេ។"**
អ្វីៗទាំងអស់ក្នុងឯកសារគឺជាអ្វីដែល CivilCraft រំលង (ឧទាហរណ៍ មានតែផ្ទៃ grid ឬតែខ្សែផ្លូវ spiral)។ សារដែលនៅសល់ប្រាប់ពីអ្វីដែលមាន។ មើល [LandXML៖ អ្វីដែលត្រូវបានអាន និងសរសេរ](topic:landxml-reference)។

**"មិនអាចផ្ទុកគំរូបាន៖ …"**
{{ui:បើកគេហទំព័រគំរូ}} អានឯកសារពីគេហទំព័រ CadCraft។ បើគ្មានការតភ្ជាប់ វាដំណើរការតែនៅពេល CivilCraft ត្រូវបានរក្សាទុកសម្រាប់ប្រើក្រៅបណ្ដាញ (ប៊ូតុងក្នុងរបារកម្មវិធីបង្ហាញ {{ui:ត្រៀមខ្លួនសម្រាប់ក្រៅបណ្ដាញ}})។ ភ្ជាប់បណ្ដាញ ចុច {{ui:រក្សាទុកសម្រាប់ក្រៅបណ្ដាញ}} ហើយវានឹងដំណើរការក្រៅបណ្ដាញចាប់ពីពេលនោះ។ មើល [ក្រៅបណ្ដាញ](common:offline)។

**{{ui:រក្សាទុកសម្រាប់ក្រៅបណ្ដាញ}} បង្ហាញ {{ui:មិនអាចរក្សាទុកបាន}}។**
ឯកសារមួយចំនួនមិនបានទាញយក។ ពិនិត្យការតភ្ជាប់ ហើយចុចប៊ូតុងម្ដងទៀត។

**{{ui:រក្សាទុកសម្រាប់ក្រៅបណ្ដាញ}} បង្ហាញ {{ui:ក្រៅបណ្ដាញមិនអាចប្រើបាន}}។**
ផ្ទាំងកម្មវិធីរុករកនេះមិនអាចរក្សាច្បាប់ចម្លងក្រៅបណ្ដាញបានទេ ជាធម្មតាព្រោះវាជាផ្ទាំងឯកជន ឬកុំព្យូទ័រត្រូវបានគ្រប់គ្រង។ បើក CivilCraft ក្នុងផ្ទាំងធម្មតា។

**ក្រៅបណ្ដាញ កម្មវិធីមិនបើកទាល់តែសោះ។**
វាមិនត្រូវបានរក្សាទុកសម្រាប់ប្រើក្រៅបណ្ដាញនៅក្នុងកម្មវិធីរុករកនេះទេ ឬកម្មវិធីរុករកបានសម្អាតទិន្នន័យគេហទំព័ររបស់វា (Safari ធ្វើដូច្នេះចំពោះគេហទំព័រដែលមិនបានចូលទស្សនាអស់ជាច្រើនសប្ដាហ៍)។ ភ្ជាប់បណ្ដាញ បើក CivilCraft ហើយចុច {{ui:រក្សាទុកសម្រាប់ក្រៅបណ្ដាញ}}។

**ច្បាប់ចម្លងក្រៅបណ្ដាញគឺជាកំណែចាស់។**
ចុច {{ui:ត្រៀមខ្លួនសម្រាប់ក្រៅបណ្ដាញ}} បន្ទាប់មក {{ui:រក្សាទុកម្ដងទៀត (យកកំណែថ្មីបំផុត)}} ពេលភ្ជាប់បណ្ដាញ។

**ឯកសារមួយត្រូវបានធ្វើឱ្យស្លេកក្នុងប្រអប់បើក។**
ប្រអប់នេះបង្ហាញតែឯកសារចំណុច LandXML និងឯកសារគម្រោង តាមចុងបញ្ចប់របស់វា។ អូសឯកសារទៅលើប្លង់ជំនួសវិញ ឬប្ដូរឈ្មោះវាទៅជា `.txt`។

## នាំចូលចំណុច

**"មិនអាចអានចំណុចពីឯកសារនេះបានទេ។"**
ជ្រើសលំដាប់ជួរឈរក្នុង **ជួរឈរ** ដោយដៃ។ បើគ្មានអ្វីដំណើរការ បើកឯកសារក្នុងកម្មវិធីកែអត្ថបទ ហើយពិនិត្យថាវាជាចំណុចមួយក្នុងមួយបន្ទាត់ ហើយមានលេខនៅក្នុងនោះ។

**ផ្ទៃមើលទៅដូចជាត្រូវបានឆ្លុះ បង្វិល ឬលាតទៅជាបន្ទាត់។**
Northing និង easting ត្រូវបានប្ដូរទីតាំង។ សង្ខេបបាននិយាយថា "ទាយពីចំនួនជួរឈរ"។ ជ្រើស PENZD ជំនួស PNEZD (ឬផ្ទុយមកវិញ) ក្នុង **ជួរឈរ** ឬនាំចូលម្ដងទៀត។

**ចំណុចឆ្ងាយពីអ្វីដែលនៅសល់ ហើយប្លង់ត្រូវបានពង្រីកទៅជាចំណុចតូចមួយ។**
ជួរមួយមានកំហុសវាយក្នុងកូអរដោនេ ឬឯកសារលាយប្រព័ន្ធកូអរដោនេ។ ស្វែងរកចំណុចនោះ (ចុចវាដើម្បីមើលលេខរបស់វា) ហើយកែឯកសារ។

**ជួរដែលបានរាយក្រោម "ជួរមិនបានអាន"។**
មើលតារាងក្នុង [នាំចូលចំណុចវាស់វែងដី](topic:import-points#rows-that-are-not-read)។

**ចំណុចចាស់របស់ខ្ញុំបាត់ទៅហើយ។**
ការនាំចូលឯកសារចំណុចជំនួសចំណុចទាំងអស់ ហើយសម្អាតការត្រឡប់វិញ។ បើកគម្រោងដែលបានរក្សាទុករបស់អ្នកដើម្បីយកពួកវាមកវិញ។

## ផ្ទៃ

**"ផ្ទៃ៖ មិនទាន់បានសាងសង់" ជាមួយប្រអប់ក្រហម។**
ប្រអប់ប្រាប់ថាហេតុអ្វី៖ "ផ្ទៃត្រូវការចំណុចយ៉ាងតិចបីដែលមានកម្ពស់។" "ចំណុចទាំងអស់នៅលើបន្ទាត់តែមួយ៖ មិនមានត្រីកោណ។" "គ្មានចំណុចដែលមានកម្ពស់។" "ព្រំដែនមិនត្រួតលើចំណុចទេ។" ឬ "មិនមានត្រីកោណនៅសល់ក្នុងព្រំដែនទេ។" ពិនិត្យលំដាប់ជួរឈរ ក្រុមចំណុច (តើពួកវាស្ថិតក្នុង {{ui:ដកចេញ}} ទេ?) និងព្រំដែន។

**ខ្សែកម្ពស់ស្មើកាត់ត្រង់ឆ្លងកាត់ប្រឡាយ ឬកំពូល។**
បន្ទាត់នោះមិនមែនជាបន្ទាត់បំបែកទេ។ កំណត់ក្រុមរបស់វាទៅ {{ui:បន្ទាត់បំបែក}} ឬគូសវាដោយឧបករណ៍ {{ui:បន្ទាត់បំបែក}}។ មើល [សាងសង់ និងកែលម្អផ្ទៃ](topic:build-surface)។

**ក្រុមបន្ទាត់បំបែកគូសជាខ្សែហ្ស៊ីហ្ស៊ាក់។**
ក្រុមមានបន្ទាត់ច្រើនជាងមួយ ឬចំណុចរបស់វាមិនត្រូវបានដាក់លេខតាមបន្ទាត់។ កំណត់ក្រុមត្រឡប់ទៅ {{ui:ចំណុច}} ហើយគូសបន្ទាត់នីមួយៗដោយឧបករណ៍ {{ui:បន្ទាត់បំបែក}}។

**ត្រីកោណវែងស្ដើងតាមខាងក្រៅ។**
គូសព្រំដែន ({{key:O}}) ឬកំណត់ **គែមខាងក្រៅវែងបំផុត**។

**គ្មានខ្សែកម្ពស់ស្មើទាល់តែសោះ ទោះបីផ្ទៃត្រូវបានសាងសង់ក៏ដោយ។**
ទាំង {{ui:ខ្សែកម្ពស់ស្មើ}} ត្រូវបានបិទនៅក្រោម **បង្ហាញ** ឬចន្លោះមានតូចខ្លាំងដែលនឹងមានកម្រិតខ្សែកម្ពស់ស្មើច្រើនជាង 2,000។ ជ្រើសចន្លោះធំជាង។

**បន្ទាត់បំបែក ឬព្រំដែនមិនផ្លាស់ប្ដូរអ្វីទេ។**

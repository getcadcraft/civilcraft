ការស្ទង់ផែនទីតូប៉ូក្រាហ្វីជារឿយៗមកដល់ជាគំនូរ៖ ខ្សែកម្ពស់ស្មើជា polyline នៅកម្ពស់របស់វា បន្ទាត់បំបែកជា polyline 3D ព្រំដែនទីតាំងជា polyline បិទ។ CivilCraft បើក**ទំហំម៉ូដែល**របស់គំនូរជាស្រទាប់នៅលើប្លង់ ហើយអាចបម្លែងបន្ទាត់ទាំងនោះទៅជាផ្ទៃដោយផ្ទាល់។

## បើកគំនូរ

1. ចុច {{ui:បន្ទាត់គំនូរ}} នៅក្រុម **ផ្ទៃ** (ឬ {{ui:បើក}} ឬទម្លាក់ឯកសារនៅលើប្លង់) ហើយជ្រើសរើសឯកសារ `.dwg` ឬ `.dxf`។ គំនូរត្រូវបានអាននៅកុំព្យូទ័រនេះ; គ្មានអ្វីត្រូវបានផ្ទុកឡើងទេ។ DWG ពីឆ្នាំ 2000 ដល់ 2018 និង DXF ASCII ត្រូវបានអាន។
2. ប្រអប់ **បន្ទាត់គំនូរ** បញ្ជីស្រទាប់របស់គំនូរដែលមានបន្ទាត់ រាងបិទ ឬចំណុច និងថាតើពួកវាមាន**កម្ពស់**ឬទេ។ ស្រទាប់ដែលបិទនៅក្នុងគំនូរចាប់ផ្ដើមមិនត្រូវបានធីក។ អក្សរ ហាច់ វិមាត្រ និងវត្ថុផ្សេងដែលមិនមែនបន្ទាត់គំនូរត្រូវបានរាប់ ហើយត្រូវបានចាកចេញ (ប្រអប់បញ្ជាក់ថាមួយណា)។
3. ពិនិត្យ **ឯកតាគំនូរ**។ នៅពេលគំនូរប្រាប់ឯកតារបស់វា CivilCraft បម្លែងវាទៅជាឯកតារបស់គម្រោង (មីលីម៉ែត្រទៅម៉ែត្រ ម៉ែត្រទៅហ្វីត អ៊ីញ្ចទៅហ្វីត)។ គំនូរជាហ្វីតត្រូវបានអានជា US survey feet ដោយមិនបញ្ចូលមាត្រដ្ឋាន: ទាំងពីរខុសគ្នា 2 ក្នុងមួយលាន ហើយការបញ្ចូលមាត្រដ្ឋានកូអរដោនេ state plane តាមនោះនឹងផ្លាស់ទីវាជាហ្វីត។ នៅពេលគំនូរមិនប្រាប់ឯកតា លេខរបស់វាត្រូវបានអានជាឯកតារបស់គម្រោង; ជ្រើសឯកតាត្រឹមត្រូវនៅក្នុងបញ្ជី បើមិនដូច្នេះ។
4. នៅ **ប្រើសម្រាប់ផ្ទៃ** ជ្រើសរើសអ្វីដែលស្រទាប់នីមួយៗផ្ដល់ដល់ផ្ទៃ (ឬទុក **គ្រាន់តែបង្ហាញវា**)។ ស្រទាប់ដែលដាក់ឈ្មោះដូចខ្សែកម្ពស់ស្មើ (TOPO, CONT, CNTR) ដែលមានកម្ពស់ ចាប់ផ្ដើមជាបន្ទាត់បំបែក។
5. ចុច {{ui:បញ្ចូល}}។ ស្រទាប់បង្ហាញនៅក្រោម **ស្រទាប់ GIS** នៅក្នុងផ្ទាំងខាងឆ្វេង; ការប្រើប្រាស់នីមួយៗត្រូវបានដាក់ចូលទៅក្នុងផ្ទៃ។ ផ្នែកនីមួយៗជាជំហានមួយដាច់ដោយឡែក៖ {{key:Mod+Z}} យកវាមកវិញម្ដងមួយ។

## អ្វីដែលស្រទាប់នីមួយៗអាចផ្ដល់

|---|---|
| ខ្សែកម្ពស់ស្មើ (polyline នៅកម្ពស់) | បន្ទាត់បំបែកនៅកម្ពស់របស់បន្ទាត់ ឬនៅវាល ELEV |
| polyline 3D | បន្ទាត់បំបែកនៅកម្ពស់របស់វា |
| ខ្សែព័ទ្ធជុំវិញបិទ | ព្រំដែនផ្ទៃ (រាងបិទធំបំផុត ឬមួយដែលអ្នកបានជ្រើស) |
| ចំណុចមានកម្ពស់ | ចំណុចវាស់វែងដី ពិពណ៌នាដោយឈ្មោះស្រទាប់ |
| បន្ទាត់នៅកម្ពស់ 0 (បន្ទាត់គំនូរប្លង់) | គ្មានអ្វីទេ: វានៅលើប្លង់ជាគំនូរមូលដ្ឋាន |

គំនូរដែល CivilCraft បានសរសេរទុកបន្ទាត់លក្ខណៈជា polyline 3D ដែលចងចាំធ្នូរបស់វា។ ប្រអប់នោះបន្ទាប់មកបង្ហាញ **បន្ទាត់លក្ខណៈ**៖ ទុកឱ្យធីកដើម្បីនាំវាត្រឡប់ជាបន្ទាត់លក្ខណៈជាមួយធ្នូ និងការប្រើប្រាស់របស់វា (ជំហានមិនធ្វើវិញតែមួយ) ឬដោះធីកដើម្បីអានវាជាបន្ទាត់គំនូរដូចស្រទាប់ផ្សេងៗ។

ពេលក្រោយ ប្រើ {{ui:ប្រើសម្រាប់ផ្ទៃ}} នៅក្នុងម៉ឺនុយស្រទាប់ក្រោម **ស្រទាប់ GIS** ដើម្បីធ្វើដូចគ្នាសម្រាប់ស្រទាប់ដែលអ្នកគ្រាន់តែបានបង្ហាញ។

## ចំណុចវាស់វែងដីពីប្លុក

គំនូរស្ទង់ជារឿយៗផ្ទុកចំណុចរបស់វាជាប្លុក៖ និមិត្តសញ្ញាតូចនៅការថតនីមួយៗ ជាមួយលក្ខណៈសម្បត្តិសម្រាប់លេខចំណុច ការពិពណ៌នា និងកម្ពស់។ នៅពេលគំនូរមានយោងប្លុក ប្រអប់មានផ្នែក **ចំណុចវាស់វែងដីពីប្លុក**៖

1. ធីកប្លុកដែលត្រូវយក (តារាងបង្ហាញចំនួនយោងនីមួយៗ នៅស្រទាប់មួយណា និងលក្ខណៈមួយណា) ឬធីកស្រទាប់ដើម្បីយកយោងប្លុកទាំងអស់នៅលើវា។
2. ជ្រើសរើសកន្លែងដែល**លេខ** **ការពិពណ៌នា** និង**កម្ពស់**របស់ចំណុចនីមួយៗមកពី៖ លក្ខណៈ ឈ្មោះប្លុក ឬស្រទាប់ លេខទំនេរបន្ទាប់ ឬ Z របស់ចំណុចបញ្ចូល។ CivilCraft ចាប់ផ្ដើមនៅលក្ខណៈដែលទំនងជា (PT, DESC, ELEV និងស្រដៀងគ្នា) ហើយយកកម្ពស់ពីលក្ខណៈតែពេលប្លុកនៅសូន្យប៉ុណ្ណោះ។
3. ដោះធីកស្រទាប់បន្ទាត់គំនូរ ប្រសិនបើអ្នកចង់បានតែចំណុច បន្ទាប់មកចុច {{ui:បញ្ចូល}}។

យោងនីមួយៗក្លាយជាចំណុចវាស់វែងដីមួយនៅចំណុចបញ្ចូលរបស់វា។ តែយោងដែលដាក់ក្នុងទំហំម៉ូដែលប៉ុណ្ណោះត្រូវរាប់; ប្លុកដែលដាក់ក្នុងប្លុកផ្សេងមិនរាប់ទេ។ លេខដែលមានក្នុងគម្រោងរួចហើយ ឬត្រូវបានប្រើពីរដងក្នុងគំនូរ ទទួលបានលេខថ្មីបន្ទាប់ពីខ្ពស់បំផុត ហើយលក្ខណៈកម្ពស់ដែលមិនមែនជាលេខ ទុកឱ្យចំណុចនោះគ្មានកម្ពស់; របារស្ថានភាពរាប់ទាំងពីរ។ គំនូរមិនដែលត្រូវបានផ្លាស់ប្ដូរទេ ហើយចំណុចនីមួយៗចងចាំប្លុករបស់វា៖ លក្ខណៈសម្បត្តិរបស់វាបង្ហាញ **ពីប្លុក** ជាមួយប្លុក ស្រទាប់ និង handle។ ការបញ្ចូលចំណុចជាជំហានមួយ ដូច្នេះ {{key:Mod+Z}} យកវាទាំងអស់ចេញ។

## កម្ពស់សរសេរជាអក្សរ និងការពិនិត្យ

កម្ពស់ចំណុចដែលសរសេរជាអក្សរ (ឬនៅក្នុងលក្ខណៈប្លុកដែលមិនមែនជាប្លុកចំណុចវាស់វែងដី) មិនមែនជាបន្ទាត់គំនូរទេ។ ផ្នែក **កម្រិតវាស់វែងដី និងការពិនិត្យ** អាចយកវាជាចំណុចវាស់វែងដី ហើយបញ្ជីអ្វីដែលមើលទៅខុសក្នុងគំនូរ៖ ឯកតា ប្រព័ន្ធកូអរដោនេ ចម្ងាយពីសូន្យ ខ្សែកម្ពស់ស្មើរាប កម្រិតចម្លែក ចំណុចស្ទួន។ មើល [ពិនិត្យគំនូរស្ទង់ពេលនាំចូល](topic:survey-check)។

## របៀបដែលគំនូរត្រូវបានអាន

- ធ្នូ រង្វង់ ellipse ផ្នែក polyline ដែលប៉ោង និង spline ក្លាយជាផ្នែកត្រង់ខ្លីៗ (រៀងរាល់ 5° ច្រើនបំផុត)។
- យោងប្លុកត្រូវបានគូសនៅកន្លែងដែលវាដាក់ ប្លុកដែលដាក់ក្នុងប្លុកផងដែរ; អ្វីដែលប្លុកមាននៅស្រទាប់ 0 យកស្រទាប់របស់យោង។
- វត្ថុដែលគូសនៅប្លង់ផ្សេង (ទិសដៅ extrusion ផ្សេង) ត្រូវបានដាក់ក្នុងកូអរដោនេពិភពលោក។
- វត្ថុនីមួយៗទទួលបានវាលបី៖ LAYER, TYPE (ប្រភេទវត្ថុ) និង ELEV (កម្ពស់របស់វានៅពេលចំណុចទាំងអស់មានកម្ពស់ដូចគ្នា)។
- កូអរដោនេត្រូវបានយកតាមដែលវាជា: គំនូរត្រូវប្រើកូអរដោនេដូចគម្រោង (ឧទាហរណ៍ តំបន់ state plane ដូចគ្នា)។ គំនូរដែលភ្ជាប់ (xrefs) មិនត្រូវបានបើក: បើកវាដោយឡែក។

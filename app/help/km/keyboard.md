គន្លឹះអក្សរតែមួយដំណើរការនៅពេលអ្នកមិនវាយក្នុងប្រអប់។ ផ្លូវកាត់ជាមួយ {{key:Mod}} ប្រើ Command នៅលើ Mac និង Ctrl នៅកន្លែងផ្សេង។ មើលផងដែរ [គន្លឹះនៅក្នុងកម្មវិធីរុករក](common:keys)។

## ឯកសារ និងការកែ

| គន្លឹះ | សកម្មភាព |
|---|---|

| {{key:Mod+S}} | រក្សាទុកគម្រោង (ទាញយកឯកសារ `.civilcraft.json`) |
| {{key:Mod+P}} | បោះពុម្ពផែនទីជា PDF (បើកប្រអប់បោះពុម្ព មិនមែនការបោះពុម្ពរបស់កម្មវិធីរុករកទេ) |
| {{key:Mod+Z}} | មិនធ្វើវិញ |
| {{key:Mod+Y}} | ធ្វើវិញ |
| {{key:Delete}} | លុបចំណុចវាស់ដី បន្ទាត់ផ្លូវ ទីលាន រចនាសម្ព័ន្ធ បំពង់ ឬ PVI ដែលបានជ្រើសរើស |
| {{key:Mod+C}} | ចម្លងចំណុចវាស់ដីដែលបានជ្រើសរើស (ក៏ជាជួរចំណុចសម្រាប់សៀវភៅតារាង) |
| {{key:Mod+X}} | កាត់ចំណុចវាស់ដីដែលបានជ្រើសរើស |
| {{key:Mod+V}} | បិទភ្ជាប់ចំណុច៖ ពួកវាតាមសញ្ញាចង្អុល ចុចកន្លែងដែលពួកវាទៅ |
| {{key:Mod+Shift+V}} | បិទភ្ជាប់នៅកន្លែងដដែល៖ នៅកូអរដោនេផ្ទាល់របស់ចំណុច |
| {{key:Mod+D}} | ចម្លងចំណុចដែលបានជ្រើសរើសជាពីរ៖ ច្បាប់ចម្លងតាមសញ្ញាចង្អុល |
| {{key:Mod+A}} | ជ្រើសរើសចំណុចវាស់ដីទាំងអស់ |
| {{key:Esc}} | មិនជ្រើសរើសអ្វីទេ (ហើយបោះបង់ការបិទភ្ជាប់) |

{{key:Mod+S}}, {{key:Mod+O}} និង {{key:Mod+P}} ដំណើរការសូម្បីតែនៅពេលអ្នកកំពុងវាយក្នុងប្រអប់។ {{key:Mod+Z}} និង {{key:Mod+Y}} នៅក្នុងប្រអប់អត្ថបទវិញ មិនធ្វើវិញការវាយរបស់អ្នក ដូចធម្មតា ហើយ {{key:Mod+C}}, {{key:Mod+X}}, {{key:Mod+V}} និង {{key:Mod+A}} ក៏ដូច្នោះដែរ៖ នៅក្នុងប្រអប់ពួកវាចម្លង កាត់ បិទភ្ជាប់ និងជ្រើសរើសអត្ថបទរបស់វា។ ជាមួយអត្ថបទដែលបានជ្រើសនៅលើទំព័រ (នៅក្នុងបន្ទះ) {{key:Mod+C}} ចម្លងអត្ថបទនោះ។ {{key:Mod+Shift+Z}} មិនធ្វើអ្វីនៅក្នុង CivilCraft ទេ៖ ប្រើ {{key:Mod+Y}} ឬប៊ូតុង {{ui:ធ្វើវិញ}}។

គន្លឹះ Mac ដែលមានស្លាក **delete** គឺ {{key:Backspace}} ចំពោះកម្មវិធីរុករក។ ដើម្បីលុបការជ្រើសរើស ចុច {{key:Delete}} (Fn និង delete) ឬជ្រើស {{ui:លុប}} នៅក្នុងម៉ឺនុយ {{ui:ច្រើនទៀត}} របស់របារឧបករណ៍។

## អេក្រង់ និងជំនួយ

| គន្លឹះ | សកម្មភាព |
|---|---|
| {{key:F1}} | បើក ឬបិទជំនួយនេះ (បន្ទះចំហៀង); {{ui:ជំនួយ}} នៅក្នុងរបារកម្មវិធីធ្វើដូចគ្នា |
| {{key:Esc}} | បិទបន្ទះជំនួយនៅពេលវាបើក |
| {{key:Ctrl+Shift+F}} | ប្តូររបៀបអេក្រង់៖ ពេញអេក្រង់ ពេញអេក្រង់ជាមួយរបារលាក់ ធម្មតា |
| {{key:Esc}} | ចេញពីពេញអេក្រង់ (គន្លឹះផ្ទាល់របស់កម្មវិធីរុករក) |

{{key:F1}} ទៅដល់ជំនួយមុនពេល CivilCraft មើលឃើញវា ដូច្នេះវាដំណើរការនៅគ្រប់ឧបករណ៍។ នៅលើក្តារចុច Mac ភាគច្រើន ចុច fn ជាមួយ F1 ឬចុច {{ui:ជំនួយ}}។ {{key:Ctrl+Shift+F}} ប្រើគន្លឹះ Control នៅគ្រប់វេទិកា រួមទាំង Mac។ មើល [ការប្រើជំនួយ](common:help) សម្រាប់របៀបស្វែងរកជំនួយនេះ។

## គន្លឹះកម្មវិធីរុករកដែលឈ្នះ

គន្លឹះមួយចំនួនជារបស់កម្មវិធីរុករក ហើយមិនដែលទៅដល់ CivilCraft ឧទាហរណ៍ {{key:Mod+W}} (បិទផ្ទាំង), {{key:Mod+T}} (ផ្ទាំងថ្មី), {{key:Mod+N}} (បង្អួចថ្មី) និង {{key:F11}} (ពេញអេក្រង់នៅក្នុងកម្មវិធីរុករក Windows និង Linux)។ CivilCraft មិនប្រើវាទេ។ បើផ្លូវកាត់បើកអ្វីមួយនៅក្នុងកម្មវិធីរុករកវិញ ចុចផែនទីម្តងដើម្បីឲ្យទំព័រមានចំណុចផ្តោត ហើយព្យាយាមម្តងទៀត។

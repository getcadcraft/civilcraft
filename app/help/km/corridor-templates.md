## បង្កើតពុម្ព

{{ui:New template}} (ឬ {{ui:Edit}} លើពុម្ពគម្រោង) បើកកម្មវិធីកែពុម្ព។ គូរផ្នែកខាងស្ដាំ ចេញពីចំណុច 0,0 របស់ពុម្ព; ផ្នែកខាងឆ្វេងប្រើពុម្ពដូចគ្នាចេញទៅឆ្វេង។

1. ដាក់ឈ្មោះ និងប្រភេទ៖ **Pavement** (ពុម្ពបន្ទាប់ភ្ជាប់នៅចុងរបស់វា), **End condition** (វាជួបដី) ឬ **Terrain template**។
2. បន្ថែម **values**៖ លេខដែលមានឈ្មោះ ដូចជាទទឹង `w` ឬជម្រាល `s`។ ប្រអប់លេខនៅកន្លែងណាក៏បាននៃពុម្ពទទួលលេខ ឬឈ្មោះនៃ value; `-t` គឺជា value `t` ដែលត្រូវបានធ្វើឱ្យអវិជ្ជមាន។ ច្រកផ្លូវអាចផ្តល់ value ផ្ទាល់ខ្លួនដល់ការប្រើនីមួយៗនៃពុម្ព ដូច្នេះពុម្ពគែមថ្មតែមួយបម្រើកម្ពស់គែមគ្រប់ប្រភេទ។
3. បន្ថែម **points** តាមលំដាប់។ ចំណុចនីមួយៗត្រូវបានដាក់ពីចំណុចមុនមួយ (ឬចំណុច 0,0) តាមការកំណត់របស់វា៖

| ការកំណត់ | ដាក់ចំណុច |
|---|---|
| Offset at a slope | ការផ្លាស់ទីចេញខាងក្រៅ និងជម្រាល (ការឡើងក្នុងមួយការរត់; −0.02 ធ្លាក់ 2%) |
| Offset and rise | ការផ្លាស់ទី និងការឡើង |
| Straight up or down | ការឡើងតែមួយ |
| Side slope to the ground | ចេញពីចំណុចរបស់វាទៅដី ក្នុងអត្រាកាត់ កន្លែងដែលដីខ្ពស់ជាង និងអត្រាបំពេញ កន្លែងដែលវាទាបជាង |
| To the ground | ការផ្លាស់ទីមួយ បន្ទាប់មកឡើង ឬចុះត្រង់ទៅដី |
| Retaining wall | ជញ្ជាំងដែលមានកម្រាស់ដែលអ្នកផ្តល់; ក្នុងការកាត់ កំពូលរបស់វាជួបដីនៅមុខផ្លូវ ក្នុងការបំពេញ ផ្លូវឆ្លងពីលើវា ហើយមុខខាងក្រៅរបស់វាធ្លាក់ទៅដី |

   ធីក **Top** សម្រាប់ចំណុចដែលផ្ទៃបញ្ចប់ឆ្លងកាត់។ ចំណុចកំពូលចុងក្រោយគឺជាកន្លែងដែលពុម្ពបន្ទាប់នៅផ្នែកនោះចាប់ផ្តើម។ **Target** អនុញ្ញាតឱ្យច្រកផ្លូវផ្លាស់ទីចំណុច៖ ការផ្លាស់ទី ឬកម្ពស់របស់វាមកពីបន្ទាត់មួយ។
4. បន្ថែម **components**៖ រូបរាងបិទដោយកូដចំណុច (`0` គឺជាចំណុច 0,0)، ដែលនីមួយៗមានឈ្មោះ សម្ភារៈ និងប្រភេទ។ ផ្ទៃរបស់វាផ្តល់បរិមាណ។

ការគូរធ្វើតាមការផ្លាស់ប្តូរនីមួយៗក្នុងមាត្រាពិត ហើយបញ្ជីនៅក្រោមវានិយាយថាអ្វីខុស (ចំណុចដែលជួបដីមុនចុង តម្លៃដែលពុម្ពមិនមាន ធាតុដែលគ្មានផ្ទៃ)។ {{ui:Add to this project}} ឬ {{ui:Save}} រក្សាវាទុក ជាជំហានមិនធ្វើវិញតែមួយ។

## សាងសង់ច្រកផ្លូវពីពុម្ព

ជ្រើសខ្សែផ្លូវដែលមានច្រកផ្លូវ ហើយនៅក្នុង Properties របស់វា បើក {{ui:Build from templates by station}}។ ច្រកផ្លូវចាប់ផ្តើមជាមួយឧទាហរណ៍ផ្លូវពីរជាន់ និងពន្លឺថ្ងៃនៅសងខាង។

- **តំបន់**។ តំបន់នីមួយៗចាប់ផ្តើមនៅស្ថានីមួយ ហើយដំណើរទៅតំបន់បន្ទាប់។ {{ui:Add a region}} បន្ថែមមួយ; ផ្លាស់ប្តូរស្ថានីចាប់ផ្តើមរបស់វានៅក្នុងប្រអប់របស់វា។
- **ឆ្វេង និងស្ដាំដាច់ពីគ្នា**។ ផ្នែកនីមួយៗនៃតំបន់នីមួយៗមានបញ្ជី **Pavement** របស់ខ្លួន ពីបន្ទាត់កណ្ដាលទៅខាងក្រៅ និង **End condition** របស់ខ្លួន៖ ពន្លឺថ្ងៃ ប្រឡាយ ជញ្ជាំង ឬពុម្ពណាមួយដែលជួបដី។ បើគ្មានលក្ខខណ្ឌបញ្ចប់ ផ្នែកនោះនឹងឆ្លុះនៅជម្រាលកាត់ និងបំពេញរបស់ច្រកផ្លូវ។ {{ui:Copy left to right}} ចម្លងផ្នែកមួយ។
- **Values និងគោលដៅ**។ នៅក្រោមពុម្ពនីមួយៗនៅផ្នែកមួយ ប្រអប់មួយសម្រាប់ value នីមួយៗ (ទទេ = value ផ្ទាល់របស់ពុម្ព) និងសម្រាប់ចំណុចដែលទទួលគោលដៅ ខ្សែលក្ខណៈ ឬខ្សែច្រកផ្លូវផ្សេងទៀតដែលផ្លាស់ទីវា។
- **From និង To** កំណត់ច្រកផ្លូវទៅផ្នែកមួយនៃខ្សែផ្លូវ។

ផ្នែកកាត់ បន្ទាត់ផែនការសម្រាប់ចំណុចកូដនីមួយៗ ផ្ទៃដែលបានស្នើ ការដាក់ចំណុច និងការងារដី ធ្វើតាមទាំងអស់។ Properties បញ្ជីបរិមាណនៃធាតុនីមួយៗក្នុងផ្នែក និងតំបន់ (ផ្ទៃមធ្យមតាមបន្ទាត់កណ្ដាល)។ Superelevation និងគោលដៅគែមច្រកផ្លូវមិនត្រូវបានប្រើនៅពេលច្រកផ្លូវត្រូវបានសាងសង់ពីពុម្ពទេ។

នៅក្រោម **Corridors on this alignment** {{ui:Add a corridor}} បន្ថែមច្រកផ្លូវមួយលើផ្នែកដែលនៅសល់នៃខ្សែផ្លូវ៖ ច្រកផ្លូវទីមួយទទួលស្ថានីបញ្ចប់នៅកណ្ដាល (ឬរក្សារបស់ខ្លួន) ហើយច្រកផ្លូវថ្មីចាប់ផ្តើមនៅទីនោះជាមួយតំបន់ចុងក្រោយនៃពុម្ពរបស់ទីមួយ។ ច្រកផ្លូវនីមួយៗមានឈ្មោះ ជួរស្ថានី ពុម្ព និងការងារដីរបស់ខ្លួន។ បិទមួយដោយប្រអប់ {{ui:On}} របស់វា។ នៅកន្លែងដែលជួរពីរត្រួតគ្នា ច្រកផ្លូវក្រោយនឹងធ្វើកម្រិតលើច្រកផ្លូវមុន។

## ពុម្ពសណ្ឋានដី

ពុម្ពសណ្ឋានដីគ្របស្រទាប់របស់ពុម្ពលើសណ្ឋានដីពីចំណុច 0,0 របស់វា៖ ស្រទាប់ដែលនៅក្រោមចំណុច 0,0 ចូលទៅក្នុងដី (ដីលើដែលត្រូវលុប) ស្រទាប់ដែលនៅលើវាអង្គុយលើដី (មូលដ្ឋាន និងកម្រាលផ្លូវនៅលានចត)។ ទទឹង និងជម្រាលមិនសំខាន់ទេ មានតែជម្រៅនីមួយៗនៃធាតុនៅលើ ឬក្រោមចំណុច 0,0 ប៉ុណ្ណោះ។

បើក {{ui:Surface}} › {{ui:More}} › {{ui:Terrain templates…}} (ឬវាយ {{cmd:TERRAINTEMPLATES}}); ប្លុកនេះក៏នៅក្នុង Properties របស់គម្រោងដែរ។ {{ui:Add a terrain template}} បន្ថែមមួយជាមួយឧទាហរណ៍ដីលើ។ សម្រាប់នីមួយៗ ជ្រើស៖

- **ពុម្ព** (value របស់វាអាចផ្លាស់ប្តូរសម្រាប់មួយនេះ),
- **សណ្ឋានដី**៖ ដីដែលមានស្រាប់ ឬផ្ទៃដែលបានស្នើ,
- **រូបរាង** ដែលកាត់វា៖ សណ្ឋានដីទាំងមូល ដីឡូត៍ ទីលាន ឬខ្សែលក្ខណៈបិទ។ ពុម្ពសណ្ឋានដីច្រើនអាចប្រើរូបរាងផ្សេងគ្នានៅលើសណ្ឋានដីដូចគ្នា។

ស្រទាប់នីមួយៗបញ្ជីកម្រាស់ តំបន់ផែនការ និងបរិមាណរបស់វា។ បរិមាណគឺជាតំបន់ផែនការគុណនឹងកម្រាស់ កម្រាស់ត្រូវបានវាស់ត្រង់ចុះក្រោម; តំបន់ត្រូវបានវាស់នៅលើក្រឡាចត្រង្គ ហើយតំបន់ដែលគ្របដោយស្រទាប់ (ជម្រាល) ក៏ត្រូវបានផ្តល់ដែរ។ រូបរាងត្រូវបានគូរលើប្លង់នៅស្រទាប់ C-TOPO-TMPL។ ពុម្ពសណ្ឋានដីមិនផ្លាស់ប្តូរផ្ទៃដែលបានស្នើទេ។

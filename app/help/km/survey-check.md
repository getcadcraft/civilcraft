គំនូរវាស់ដីអាចមើលទៅត្រឹមត្រូវ ហើយនៅតែខុសសម្រាប់ដី៖ ឯកតារបស់វាអាចត្រូវបានទាយ ខ្សែកម្ពស់ស្មើរបស់វាអាចនៅរាបស្មើនៅកម្ពស់ 0 ឬកម្ពស់របស់វាអាចសរសេរជាអត្ថបទ ដែលមិនមែនជារូបធរណីមាត្រទាល់តែសោះ។ ផ្នែក **កម្ពស់វាស់ និងការពិនិត្យ** នៃផ្ទាំង {{ui:បន្ទាត់គំនូរ}} (សូមមើល [បើក DWG ឬ DXF ជាបន្ទាត់គំនូរ](topic:open-dwg-dxf)) អានកម្ពស់ទាំងនោះ ហើយប្រាប់អ្នកថាអ្វីដែលមើលទៅខុស មុនពេលបន្ថែមអ្វីទាំងអស់។

## កម្ពស់ជាអត្ថបទ ឬក្នុងគុណលក្ខណៈ

គំនូរវាស់ដីជាច្រើនផ្ដល់កម្ពស់ចំណុចជាអត្ថបទតូចក្បែរកាកបាច់ ដូចជា `104.37` ឬ `EL 104.37` ឬជាគុណលក្ខណៈនៃប្លុកចំណុច។ ទាំងនេះមិនមែនជាបន្ទាត់ទេ ដូច្នេះអ្នកអានបន្ទាត់មិនយកវាទេ។ ផ្នែកនេះបញ្ជីចំនួនដែលរកឃើញ ហើយអនុញ្ញាតឲ្យអ្នកយកវាជា **ចំណុចវាស់**៖

1. ធីក **យក … កម្ពស់ជាចំណុចវាស់** ។ ពួកវាចាប់ផ្ដើមដោយមិនធីក ពីព្រោះមិនមែនលេខទាំងអស់ក្នុងគំនូរជាកម្ពស់ទេ។
2. អត្ថបទត្រូវបានអានពេលវាជាកម្ពស់ដោយឯកឯង៖ លេខដែលមានផ្នែកទសភាគ (`104.37`, `+104,37`, `-3.50`) ឬលេខបន្ទាប់ពី `EL`, `ELEV`, `RL`, `FFL`, `GL`, `TW`, `BW`, `INV`, `Z` ឬ `LEVEL` ជាមួយ `m`, `ft` ឬ `'` ជាជម្រើសបន្ទាប់ពីវា។ លេខគត់តែឯង (`12`) ត្រូវបានអានជាលេខឡូត៍ ឬសន្លឹក មិនមែនកម្ពស់ទេ; អត្ថបទដូចជា `GATE 3` ឬកាលបរិច្ឆេទមិនដែលត្រូវបានអានទេ។ កូដធ្វើទម្រង់អត្ថបទត្រូវបានមិនអើពើ។
3. សម្រាប់គុណលក្ខណៈប្លុក ជ្រើស **គុណលក្ខណៈប្លុកដែលផ្ទុកកម្ពស់** ។ CivilCraft រកស្លាកដែលហៅថា ELEV, Z, LEVEL, RL ឬស្រដៀងគ្នាដោយខ្លួនឯង; ជ្រើសមួយផ្សេងពីបញ្ជីប្រសិនបើគំនូរប្រើរបស់ខ្លួន។ ជម្រើសនេះត្រូវបានចងចាំសម្រាប់ឈ្មោះឯកសារនោះនៅលើកុំព្យូទ័រនេះ ដូច្នេះការបើកវាម្ដងទៀតចាប់ផ្ដើមនៅស្លាកដដែល។ ស្លាកដែលអ្នកជ្រើសក៏យកលេខគត់ជាកម្ពស់ដែរ។
4. ចុច {{ui:បញ្ចូល}} ។ ចំណុចត្រូវបានរាប់លេខបន្ទាប់ពីលេខខ្ពស់បំផុតក្នុងគម្រោង ចំណុចនីមួយៗត្រូវបានពិពណ៌នាជាមួយស្រទាប់ (ឬប្លុក) របស់វា ហើយកម្ពស់ត្រូវបានបំលែងទៅជាឯកតាគម្រោង ដូចផ្នែកផ្សេងនៃគំនូរ។ ទាំងអស់ជាជំហានមួយ៖ {{key:Mod+Z}} យកចំណុចចេញ។

អត្ថបទស្ថិតនៅចំណុចបញ្ចូលរបស់វាផ្ទាល់ (ឬចំណុចតម្រឹមរបស់វា ប្រសិនបើមាន) ។ អត្ថបទនៅខាងក្នុងប្លុកមិនត្រូវបានអានទេ ហើយគំនូរមិនត្រូវបានផ្លាស់ប្ដូរឡើយ។

## ការពិនិត្យ

ការពិនិត្យដំណើរការលើអ្វីដែលអ្នកកំពុងនាំចូល ហើយរាយអ្វីដែលវារកឃើញ មួយបន្ទាត់សម្រាប់ប្រភេទបញ្ហានីមួយៗ៖

| វាប្រាប់ | មានន័យថា |
|---|---|
| **មិនបានបញ្ជាក់ឯកតា** | គំនូរមិនបានប្រាប់ថាឯកតារបស់វាជាអ្វីទេ ដូច្នេះលេខរបស់វាត្រូវបានអានជាឯកតាគម្រោង។ ពិនិត្យចម្ងាយមួយដែលអ្នកដឹង។ |
| **បានបំលែងឯកតា** | ឯកតាគំនូរខុសពីគម្រោង ហើយត្រូវបានកម្រិតធ្វើមាត្រដ្ឋាន (ជាការកត់សម្គាល់ មិនមែនជាកំហុសទេ) ។ |
| **ទិន្នន័យលាតសន្ធឹង … km** ឬ **… m** | ផ្ទៃធំជាង 200 km ឬតូចជាងកន្លះម៉ែត្រ ដែលជាធម្មតាមានន័យថាឯកតាខុស (មីលីម៉ែត្រត្រូវបានអានជាម៉ែត្រ ឬច្រាសមកវិញ) ។ |
| **គ្មានប្រព័ន្ធកូអរដោនេ** | គម្រោងមិនមាន។ វាជាការព្រមាន នៅពេលទិន្នន័យនៅឆ្ងាយពីសូន្យ ដូចកូអរដោនេរដ្ឋ ឬក្រឡាចត្រង្គជាតិ។ សូមមើល [ប្រព័ន្ធកូអរដោនេ](topic:coordinate-systems) ។ |
| **ឆ្ងាយពីចំណុចដើម** | ទិន្នន័យនៅឆ្ងាយជាង 100 km ពីសូន្យ។ ឆ្ងាយពីសូន្យ ទិដ្ឋភាព 3D និងការនាំចេញបាត់ភាពច្បាស់ ហើយញ័រ។ |
| **ស្រទាប់ខ្សែកម្ពស់ស្មើ … គ្មានកម្ពស់** | ស្រទាប់ដែលមានឈ្មោះដូចខ្សែកម្ពស់ស្មើ (TOPO, CONT, CNTR, CONTOUR) មានបន្ទាត់នៅកម្ពស់ 0 ដូច្នេះដីដែលសាងសង់ពីវានឹងរាបស្មើ។ |
| **កម្ពស់ពិតជា 0** | កម្ពស់មួយចំនួនជា 0 ខណៈកម្ពស់ធម្មតាឆ្ងាយពីវា៖ ប្រហែលជាកម្ពស់បាត់។ |
| **កម្ពស់ឆ្ងាយពីអ្វីផ្សេង** | កម្ពស់មួយចំនួនស្ថិតនៅឆ្ងាយខាងក្រៅអ្វីផ្សេង (រកឃើញធៀបនឹងកណ្ដាលនៃកម្ពស់ទាំងអស់ ដូច្នេះដីចោតដែលមានជួរធំមិនត្រូវបានសម្គាល់) ឬខ្ពស់ជាង 9,000 m ឬទាបជាង -11,000 m។ |
| **ចំណុចនៅលើចំណុចផ្សេង** | ចំណុចពីរនៅកន្លែងតែមួយ ដែលមានកម្ពស់ដូចគ្នា ឬកម្ពស់ផ្សេងគ្នា។ |

ក្រោយពេលចុច {{ui:បញ្ចូល}} បន្ទាត់ដូចគ្នាទៅ **បញ្ហា** ម្ដងសម្រាប់ប្រភេទនីមួយៗ ជាមួយឈ្មោះឯកសារ ដើម្បីឲ្យអ្នកអាចត្រលប់មកវិញ។ ការពិនិត្យវិនិច្ឆ័យគំនូរ; វាមិនផ្លាស់ប្ដូរអ្វីក្នុងវាទេ ហើយវាមិនបញ្ឈប់អ្នកពីការប្រើគំនូរនោះទេ។

ពេលការពិនិត្យនិយាយថាខ្សែកម្ពស់ស្មើរាបនៅ 0 ហើយមានកម្ពស់សរសេរជាអត្ថបទ យកកម្ពស់ទាំងនោះជាចំណុចវាស់៖ ពួកវាច្រើនតែមានកម្ពស់ពិតដែលខ្សែកម្ពស់ស្មើខ្វះ។

## អ្វីដែលមិនត្រូវបានពិនិត្យ

ការពិនិត្យមិនប្រៀបធៀបគំនូរជាមួយការវាស់ដីទីពីរទេ ហើយវាមិនអាចប្រាប់ថាគំនូរនៅក្នុងប្រព័ន្ធកូអរដោនេណាទេ៖ វាប្រាប់តែថាគ្មានមួយត្រូវបានកំណត់។

CivilCraft находится на раннем этапе. Эта страница перечисляет то, что текущая сборка не делает, чтобы вы не искали это напрасно. Ни одна из функций здесь не обещана к какой-либо дате.

## Точки

| Еще не создано | Сейчас вместо этого |
|---|---|
| Добавление второго файла точек к первому | Сначала объедините файлы в текстовом редакторе или таблице |
| Экспорт текстового файла точек | Экспортируйте LandXML (точки выводятся как CgPoints), используйте GIS {{ui:Экспорт}} (точки с полями P, N, E, Z и D) или {{ui:Копировать}} точки в таблицу |
| Стили подписей точек, условные знаки по ключу описания, кривые (дуги) по кодам линий, файл ключей описания для обмена между проектами | Подписи показывают номер, отметку и описание или меньше ([Настройки CivilCraft](topic:settings)); ключи хранятся в файле проекта |
| Пересчет единиц | Пересчитайте файл до импорта; **Единицы** только меняют подписи |

| Спирали, кроме клотоидных; спираль между двумя кривыми (составные переходы) | Клотоидные спирали в концах кривой доступны; остальные именуются и пропускаются при импорте LandXML |
| Вставка ВУ между двумя другими | Перерисуйте трассу или введите координаты ВУ заново |
| Трассы из объектов, смещений, уширений | Рисуйте по ВУ |
| Ввод K для вертикальной кривой | Введите L (K показывается) |
| Круговые и несимметричные вертикальные кривые | Только симметричные параболические кривые |
| Более одного проектного профиля на трассу | Одна трасса на каждый вариант |
| Масштабирование вида профиля, полосы под профилем | Вид профиля вмещает всю трассу; выведите его на [листах плана и профиля](topic:plan-profile-sheets) |
| Разрезы в DWG или LandXML | Листы разрезов в PDF; {{ui:CSV}} площадей и объемов |
| Пробные линии под углом или разной ширины вдоль дороги | Одна ширина с каждой стороны для всей трассы |

## ГИС и системы координат

| Еще не создано | Сейчас вместо этого |

| File Geodatabase; стили KML, значки, наложения и сетевые ссылки | Сначала преобразуйте в GeoPackage, shapefile или GeoJSON; метки KML читаются без стилей |
| Редактирование объектов GIS или их атрибутов | Редактируйте их в программе GIS и импортируйте снова. Панель анализа создает новые слои (буфер, наложение, объединение, выборка) и добавляет поля площади и длины, но не редактирует объект на месте |
| Сетевой и растровый анализ, буферы с плоскими или квадратными концами и односторонние буферы, добавление или удаление строк и смена типа поля в таблице атрибутов, собственные цвета классов вручную, легенда стилей в выводе | Используйте выбор, чтобы выбрать объекты, и создайте слой из них; плоские концы не предлагаются. Окраска по атрибуту и таблица атрибутов уже есть: см. [Стиль слоя по атрибуту](topic:gis-symbology) и [Работа с таблицей атрибутов слоя](topic:gis-table) |

| Серверы карт, требующие входа, ключа или токена | Используйте публичные службы или файл изображения с привязкой к координатам |
| Запись файлов LAS или LAZ из поверхности, модели рельефа или инструментов сетки отметок и LiDAR | Экспортируйте поверхности как сетку отметок GeoTIFF. Дополнение [Облака точек](topic:point-clouds) записывает очищенное облако как LAS 1.4 или LAZ |
| Интенсивность, цвет и отражения LiDAR; сетки отметок с несколькими каналами; файлы сеток или LiDAR больше 200 MB | LiDAR фильтруется только по классу, сетки используют первый канал; сначала разрежьте большие файлы на фрагменты |

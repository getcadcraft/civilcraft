CivilCraft находится на раннем этапе. Эта страница перечисляет, что текущая сборка не делает, чтобы вы не искали это. Ничего здесь не обещано к какой-либо дате.

## Точки

| Еще не создано | Что делать сейчас |
|---|---|
| Добавление второго файла точек к первому | Сначала объедините файлы в текстовом редакторе или электронной таблице |
| Экспорт текстового файла точек | Экспортируйте LandXML (точки выводятся как CgPoints), используйте GIS {{ui:Экспорт}} (точки с полями P, N, E, Z и D) или {{ui:Копировать}} точки в электронную таблицу |
| Стили подписей точек, условные знаки по ключу описания, кривые (дуги) по кодам линий, файл ключей описания для обмена между проектами | Подписи показывают номер, отметку и описание или меньше ([Настройки CivilCraft](topic:settings)); ключи хранятся в файле проекта |
| Преобразование единиц | Преобразуйте файл перед импортом; **Единицы** только меняют подписи |

## Поверхности

| Еще не создано | Что делать сейчас |
|---|---|

| Редактирование поверхности, построенной по сетке отметок | Импортируйте сетку заново с другими параметрами |
| Преобразование поверхности, прочитанной из LandXML, при смене системы координат | Сначала {{ui:Перестроить поверхность по точкам}} |
| Подписанные отметки и значения уклонов | Смотрите их в строке состояния или окрасьте поверхность по уклону с помощью **Анализ уклонов** в рабочей области Ландшафт ([Планировка для ландшафта](topic:landscape-grading#grading-checks)) |

| Траектории проезда с учетом скорости, бокового скольжения шин, времени поворота, прицепов или габаритов кузова; библиотека стандартных расчетных автомобилей; траектория, нарисованная перетаскиванием автомобиля | Траектории проезда на малой скорости вдоль характерной линии или трассы с размерами ваших автомобилей ([Траектории проезда автомобилей](topic:swept-paths)) |

Окраска по атрибуту и таблица атрибутов готовы: см. [Стиль слоя по атрибуту](topic:gis-symbology) и [Работа с таблицей атрибутов слоя](topic:gis-table) |
| Стили подписей (размер, размещение) и подписи, избегающие друг друга | Подписи одного размера и могут перекрываться там, где объекты густо расположены |
| Вертикальные системы высот и модели геоида | Отметки используются так, как их дает файл; проверьте систему высот сами |
| Сдвиги сетки, кроме перехода от NAD27 к NAD83, предлагаемого по району (OSTN15; NTv2 для других систем работает, когда вы добавите файл), несколько сеток сразу, вертикальные сетки | Добавьте файл сетки для вашей системы самостоятельно; одна сетка на проект |
| Слои карты в экспорте DXF или 3D | Слои карты попадают в вывод PDF, а рядом с DWG — как рисунок |
| Серверы карт, требующие входа, ключа или токена | Используйте публичные сервисы или файл привязанного изображения |
| Запись файлов LAS или LAZ из поверхности, модели рельефа или инструментов сетки отметок и LiDAR | Экспортируйте поверхности как сетку отметок GeoTIFF. Дополнение [Облака точек](topic:point-clouds) записывает очищенное облако как LAS 1.4 или LAZ |
| Интенсивность, цвет и отражения LiDAR; сетки отметок с несколькими каналами; файлы сетки или LiDAR больше 200 MB | LiDAR фильтруется только по классу, сетки используют первый канал; сначала разрежьте большие файлы на фрагменты |

Когда в проекте есть слои ГИС (см. [Импорт данных ГИС](topic:gis-import)), кнопка **Анализ** в группе **ГИС** (вводится как `GISANALYSIS`, `ANALYZE` или `BUFFER`) открывает панель с пятью вкладками. Она остается открытой рядом с планом, поэтому выбранное отображается на плане во время работы.

Каждый инструмент, который что-то создает, **добавляет новый слой** и не меняет слои, с которыми работает. Каждое действие — один шаг отмены: {{ui:Undo}} на панели (или Ctrl+Z) удаляет новый слой. Результат можно экспортировать, как любой слой, с помощью [Экспорт исполнительных данных для ГИС](topic:gis-export) в формате shapefile, GeoJSON или GeoPackage.

Полная таблица слоя с сортировкой, редактированием и калькулятором полей описана в [Работа с таблицей атрибутов слоя](topic:gis-table); окраска по полю — в [Стиль слоя по атрибуту](topic:gis-symbology).

Вся работа ведется на плане, в единицах проекта (футы или метры). Проект всегда находится в проекционной или местной системе, поэтому расстояние 50 означает 50 футов или 50 метров, но никогда не градусы. Высоты (z) в результатах не сохраняются.

## Буферная зона

Строит зону заданного расстояния вокруг каждого объекта в виде нового слоя полигонов. Точки становятся окружностями, линии — коридорами со скругленными концами, полигоны расширяются. **Отрицательное** расстояние сжимает полигоны (квадрат 100 на 100, сжатый на 5, становится 90 на 90; сжатый на 60, не остается ничего, и панель сообщает об этом). Расстояние можно взять из числового поля, чтобы задать каждому объекту свое, или включить **Объединить все буферы в одну фигуру**, чтобы их слить.

Скругленные части состоят из прямых отрезков, вписанных в истинную кривую, поэтому буфер немного меньше точной окружности: примерно на 0,6 % по площади при обычной настройке и на 0,16 % при «Точно». Используйте «Точно» для всего, что будете измерять.

## Наложение

| Инструмент | Что вы получаете |
|---|---|
| Пересечение | Части, где входной слой пересекает полигоны наложения, каждая с полями обоих слоев. Линии и точки обрезаются по полигонам. |
| Объединение | Оба слоя полигонов разрезаны по границам друг друга: общие части несут поля обоих слоев, остальные — поля одного слоя (поля другого пусты). |
| Вычитание | Входные полигоны без полигонов наложения. Поля остаются у входного слоя. Объект, полностью вычтенный, пропускается (панель их считает). |
| Слияние | Объединяет полигоны, которые касаются или перекрываются: все сразу или по одной фигуре для каждого значения поля. Добавляет `COUNT` и `AREA`. |

Имя поля, которое есть в обоих слоях, сохраняется для первого слоя, а поле второго слоя получает суффикс `_2`. Объекты внутри одного слоя не должны перекрываться: где они перекрываются, объединение учитывает перекрытие в обоих слоях.

## Соединение

Пространственное соединение копирует атрибуты из **исходного** слоя на каждый **целевой** объект, с которым он встречается, и создает новый слой с формами целевого. Выберите условие встречи: касание или перекрытие, целевой объект внутри полигона исходного слоя, целевой объект содержит объект исходного слоя, ближайший объект исходного слоя (с необязательным ограничением) или любой объект исходного слоя в пределах расстояния.

Когда подходит несколько объектов, берутся атрибуты первого (ближайшего — для соединений по ближайшему и по расстоянию; добавляется `DISTANCE`), или они **подсчитываются, и их числовые поля суммируются**: `COUNT`, а для каждого числового поля — `SUM_`, `MEAN_`, `MIN_`, `MAX_`. Снимите отметку **Сохранять целевые объекты без совпадений**, чтобы их исключить. Присоединенные поля пусты там, где совпадений нет, а панель считает такие объекты.

## Выборка

Введите вопрос об атрибутах или геометрии, нажмите **Выбрать**, и объекты отобразятся на плане с их количеством, таблицей и общей площадью, длиной или числом. Затем сделайте из них отдельный слой, приблизьте к ним или снимите выбор.

| Можно написать | Пример |
|---|---|
| Имя поля; используйте «кавычки» или [квадратные скобки], если в имени есть пробелы | `VALUE`, `"Lot Number"` |
| Числа, 'текст', true, false, null | `Use_ = 'Res'` |
| `=` `!=` `<>` `<` `<=` `>` `>=` | `VALUE >= 250` |
| `contains` `startswith` `endswith` `like` `ilike` (текст не учитывает регистр; в `like` `%` — любой набор символов, `_` — один символ) | `Notes contains 'corner'` |
| `is null`, `is not null` (пустое значение считается null) | `Notes is null` |
| `in (…)`, `not in (…)`, `between … and …` | `Use_ in ('Com', 'Ind')` |
| `+ - * /` и скобки | `VALUE / 2 > 100` |
| `and`, `or`, `not` | `Use_ = 'Res' and VALUE > 200` |
| Значения геометрии `$area` `$perimeter` `$length` `$x` `$y` `$vertices` | `$area > 5000` |

Вопрос, который неполон или называет поле, которого нет в слое, отклоняется с пояснением, где именно ошибка.

## Измерение

Показывает общую площадь и периметр, длину или количество объектов слоя и **добавляет поля** в слой: `AREA` и `PERIMETER` для полигонов, `LENGTH` для линий (длина на плане), `X` и `Y` для точек. Существующее поле никогда не перезаписывается: новое получает имя `AREA_2`. Это один шаг отмены. **Статистика** дает количество, сумму, среднее, минимум и максимум числового поля, при необходимости для каждого значения другого поля.

:::note
Расчеты, на которых основаны эти проверки, выполнены вручную в тесте (`node bin/test-civilcraft-gisanalysis.mjs`): например, участки 100 на 100 под зоной 100 на 80 пересекаются по 3 000 плюс 3 000, а линия длиной 100, буферизованная на 10, дает 2 000 плюс окружность.
:::

Некоторые программы для воздушных линий хранят расчет в файле `.DON` (текст XML). CivilCraft может записать одну линию в такой файл и прочитать опоры из такого файла.

:::warning
**Не проверено.** Мы создали это по списку имен полей формата, которым поделился пользователь, а не по реальному файлу, и мы не открывали свои файлы в программе, которая их читает. Откройте там файл и проверьте каждое значение, прежде чем на него полагаться. Если вы можете поделиться файлом `.DON` (с удаленными данными клиента), это поможет нам сделать всё правильно.
:::

## Сохранение файла расчета

1. Задайте линии провод и убедитесь, что у неё есть результаты (в её «Свойствах» нет пометки «не рассчитано»).
2. {{ui:Ещё}} › {{ui:Сохранить файл расчета (.DON)…}}, выберите линию, добавьте описание и номер работы.
3. {{ui:Сохранить файл расчета}}.

Файл содержит опоры линии (координаты, грунт, высоты, роли, траверсу, оставленную или предложенную опору, нагрузки по расчетным режимам, фундамент), по одному участку между анкерными опорами (провод, напряжение, расчетный пролет, пролеты, натяжение и параметр цепной линии, наибольшее натяжение по каждому расчетному режиму) и таблицы монтажа. Длины — в метрах, усилия — в daN; текст записывается в Latin-1, поэтому символ вне этой кодировки становится `?`.

## Чтение файла расчета

{{ui:Ещё}} › {{ui:Открыть файл расчета (.DON)…}} читает опоры в новую линию. Провод, опоры и траверсы сопоставляются с вашей библиотекой по имени; то, что не найдено, остается для выбора в «Свойствах».

Ошибочный замер, неверная высота рейки, описание, набранное с ошибкой: исправьте одну точку, и поверхность обновится следом.

## Изменение значений точки

1. С помощью {{ui:Выбор}} щелкните точку на плане. В разделе **Свойства** в полях показаны ее номер, восток, север, **Отметка** и описание.
2. Введите новое значение и нажмите {{key:Enter}} (или щелкните в другом месте). Оставьте поле **Отметка** пустым для точки без отметки.
3. Поверхность, горизонтали и все, что построено по ним, обновляются сразу.

Каждое изменение — один шаг: {{key:Mod+Z}} отменяет его, {{key:Mod+Y}} возвращает его. Значение, которое CivilCraft не может использовать (номер, уже присвоенный другой точке, буквы в координате), не принимается: поле выделяется рамкой, а в строке состояния написано, почему.

Новый ключ описания создает новую группу точек, как и при импорте (см. [Построение поверхности](topic:build-surface)).

## Перемещение точки на плане

1. Выберите точку (вокруг нее появится кольцо).
2. Перетащите кольцо. В строке состояния показаны восток и север, куда точка переместится.
3. Отпустите кнопку мыши, чтобы переместить точку; ее отметка сохраняется. Нажмите {{key:Esc}} до отпускания, чтобы вернуть точку на место.

## Структурные линии следуют за точкой

Структурная линия, нарисованная инструментом {{ui:Структурная линия}}, копирует точки, через которые проходит. Когда вы перемещаете точку или меняете ее отметку, углы структурной линии в этой точке перемещаются вместе с ней в одном шаге. Группы структурных линий, созданные по описаниям, всегда перестраиваются по точкам.

:::note
Поверхность, прочитанная из файла LandXML, сохраняет собственные треугольники: изменения точек меняют ее только после {{ui:Перестроить поверхность по точкам}}.
:::

В CivilCraft нет диалога настроек или шаблона. Ниже перечислены значения, с которых всё начинается. Значения, помеченные **заготовка**, не взяты ни из одного стандарта: замените их критериями вашего проекта, прежде чем опираться на проверку или объем.

## Новый проект

| Параметр | Значение |
|---|---|
| Имя | Участок без названия (его заменяет имя первого файла точек) |
| Единицы | US feet |
| Имя поверхности | {{ui:Существующий рельеф}} |
| Группы точек | Каждая группа начинается как {{ui:Точек}} |
| Самая длинная внешняя сторона | 0 (сохранять все треугольники) |
| Сохраняемых шагов отмены | 200 |

## Отображение

| Параметр | Значение |
|---|---|
| Поверхность | {{ui:Существующий рельеф}} |
| Горизонтали через | 1 (ft или m) |
| Основные через | каждая 5-я горизонталь |
| Полос | 8 |
| Вкл. | Горизонтали, {{ui:Подписи горизонталей}}, точки, структурные линии, граница поверхности, трубы |
| Выкл. | Треугольники, полосы отметок, стрелки уклонов, подписи точек |

## Трассы и профили

| Параметр | Значение |
|---|---|
| Имя | Трасса 1, Трасса 2 … |
| Начальный пикет | 0+00 |
| Радиус кривой в каждом внутреннем ВУ | 100 ft или 30 m, меньше, если он не помещается в половину каждого прямого участка |
| Проектный профиль | Нет, пока вы его не начнете; {{ui:Начать от рельефа}} помещает ВВ на рельеф в каждом конце |
| Длина вертикальной кривой | 0 (кривой нет), пока вы её не введете |

## Площадки

| Параметр | Значение |
|---|---|
| Имя | Площадка 1, Площадка 2 … |
| Отметка | Рельеф в середине площадки, округленный до 0.1 (0, если середина вне поверхности) |
| Откос выемки | 2 : 1 (заготовка) |
| Откос насыпи | 3 : 1 (заготовка) |

## Сборка коридора (заготовки)

| Параметр | Футы US | Метры |
|---|---|---|
| Ширина полосы | 12 ft | 3.6 m |
| Уклон полосы | 2% | 2% |
| Ширина обочины | 4 ft | 1.2 m |
| Уклон обочины | 4% | 4% |
| Откос выемки | 2 : 1 | 2 : 1 |
| Откос насыпи | 3 : 1 | 3 : 1 |
| Поперечник через | 10 ft | 5 m |

## Трубопроводная сеть

| Параметр | Футы US | Метры |
|---|---|---|
| Имя и тип | Ливневая, ливневая | Ливневая, ливневая |
| Наименьший уклон (заготовка) | 0.50% | 0.50% |
| Наименьшее заглубление (заготовка) | 2 ft | 0.6 m |
| Перепад в колодцах (заготовка) | 0.10 ft | 0.03 m |
| Диаметр нового колодца | 48 in | 1200 mm |
| Диаметр новой трубы | 12 in | 300 mm |
| Глубина приямка | 0 | 0 |
| Верх люка | С поверхности | С поверхности |

Трубопроводная сеть, открытая из LandXML, тоже использует эти правила, поскольку LandXML их не хранит.

## Объемы

| Параметр | Значение |
|---|---|
| Метод | Сетка, отсчеты в центрах ячеек внутри линий врезки |
| Размер ячейки | Выбирается так, чтобы описанный прямоугольник спланированной области содержал около 250,000 ячеек (1, 2 или 5 умножить на степень десяти) |
| Разрыхление и уплотнение | Нет |

## Печать

| Параметр | Значение |
|---|---|
| Область | {{ui:Всё}} |
| Бумага | Tabloid 11 × 17 in (проекты в футах), ISO A3 (проекты в метрах); всегда альбомная |
| Масштаб | Самый крупный из перечисленных масштабов, который помещается |
| Чернила | {{ui:Цвета слоев}} |

Подписи DXF выбраны по размеру для масштаба, при котором всё помещается на Tabloid (футы) или A3 (метры).

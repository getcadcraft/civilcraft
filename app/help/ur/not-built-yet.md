CivilCraft ابھی ابتدائی مرحلے میں ہے۔ یہ صفحہ بتاتا ہے کہ موجودہ بلڈ کیا نہیں کرتا، تاکہ آپ اسے تلاش نہ کریں۔ اس میں سے کسی چیز کے لیے کوئی تاریخ نہیں دی گئی۔

## نقاط

| ابھی تیار نہیں | اس کے بجائے، آج |
|---|---|
| ایک نقاط کی فائل میں دوسری نقاط کی فائل جوڑنا | پہلے فائلوں کو ٹیکسٹ ایڈیٹر یا اسپریڈشیٹ میں جوڑیں |
| نقاط کی ٹیکسٹ فائل برآمد کرنا | LandXML برآمد کریں (نقاط CgPoints کے طور پر جاتے ہیں)، GIS {{ui:Export}} استعمال کریں (P، N، E، Z اور D فیلڈز کے ساتھ نقاط)، یا نقاط کو اسپریڈشیٹ میں {{ui:Copy}} کریں |
| نقطہ لیبل اسٹائلز، ہر وضاحتی کلید کے لیے علامتیں، لائن کوڈز سے کمانیں (آرکس)، پروجیکٹس کے درمیان شیئر ہونے والی وضاحتی کلید کی فائل | لیبل نمبر، ایلیویشن اور وضاحت دکھاتے ہیں، یا اس سے کم ([CivilCraft کی ترتیبات](topic:settings))؛ کلیدیں پروجیکٹ فائل میں محفوظ رہتی ہیں |
| اکائی کی تبدیلی | امپورٹ سے پہلے فائل کو تبدیل کریں؛ **Units** صرف لیبل بدلتا ہے |

| لیبل والے اسپاٹ ایلیویشنز اور ڈھلوان کی قدریں | انہیں اسٹیٹس بار میں پڑھیں، یا Landscape ورک اسپیس میں **Slope analysis** سے سطح کو ڈھلوان کے لحاظ سے رنگ دیں ([لینڈ اسکیپ کے لیے گریڈنگ](topic:landscape-grading#grading-checks)) |

| clothoid کے علاوہ اسپائرلز؛ دو موڑوں کے درمیان اسپائرل (مرکب منتقلیاں) | موڑ کے سروں پر clothoid اسپائرلز دستیاب ہیں؛ دوسری کے نام لکھے جاتے ہیں اور LandXML امپورٹ میں چھوڑ دی جاتی ہیں |
| دو دیگر PIs کے درمیان PI ڈالنا | ایلائنمنٹ دوبارہ کھینچیں، یا PI کے کوآرڈینیٹس دوبارہ ٹائپ کریں |
| آبجیکٹس سے ایلائنمنٹس، آفسیٹس، چوڑا کرنا | PIs سے کھینچیں |
| عمودی منحنی کے لیے K ٹائپ کرنا | L ٹائپ کریں (K دکھایا جاتا ہے) |
| دائروی اور غیر متناسب عمودی منحنیاں | صرف متناسب پیرابولک منحنیاں |
| ایک ایلائنمنٹ پر ایک سے زیادہ ڈیزائن پروفائل | ہر متبادل کے لیے ایک ایلائنمنٹ |
| پروفائل ویو کو زوم کرنا، پروفائل کے نیچے پروفائل بینڈز | پروفائل ویو پوری ایلائنمنٹ کو فٹ کرتا ہے؛ اسے [پلان اور پروفائل شیٹس](topic:plan-profile-sheets) پر پلاٹ کریں |
| DWG یا LandXML میں سیکشنز | PDF میں سیکشن شیٹس؛ رقبوں اور حجموں کا {{ui:CSV}} |
| ترچھے یا سڑک کے ساتھ مختلف چوڑائی کے سیمپل لائنز | پوری ایلائنمنٹ کے لیے ہر طرف ایک چوڑائی |

## کوریڈورز

| ابھی تیار نہیں | اس کے بجائے، آج |
|---|---|
| میڈینز، بیریئرز، اور ایسی سپرایلیویشن جو ٹیمپلیٹس کو گھماتی ہو | انہیں ٹیمپلیٹس کے طور پر بنائیں ([کوریڈور ٹیمپلیٹس](topic:corridor-templates))؛ اسٹیشن کے لحاظ سے ٹیمپلیٹس ابھی سپرایلیویشن نہیں لیتے |
| دو خطوں کے ٹیمپلیٹس کے درمیان بتدریج تبدیلی (منتقلیاں، ٹیپرز) | ایک اسٹیشن پر ٹیمپلیٹ بدلیں، یا ٹیپر کے طور پر کھینچی گئی لائن پر نقطے کو چوڑائی کا ہدف دیں |
| کنارے کے گرد گھمانا، LandXML میں سپرایلیویشن | گول موڑوں پر سپرایلیویشن سینٹر لائن کے گرد گھومتی ہے؛ فیچر لائن کے ہدف کے ساتھ لین کو چوڑا کریں |
| سائیڈ ڈھلوانوں کے اہداف (ڈے لائٹ کو لائن یا سطح تک)، کوریڈور کی اپنی سطحیں | اہداف پیومنٹ اور شولڈر کے کنارے منتقل کرتے ہیں ([کوریڈورز](topic:corridor))؛ کوریڈور تجویز شدہ سطح میں گریڈ ہوتا ہے |
| کرب ریٹرنز، ٹرننگ لینز اور آئی لینڈز جو جنکشن میں گریڈ ہوں؛ ترچھے زاویے پر ذیلی سڑک کا سرا مین سڑک کے کنارے تک کٹا ہوا؛ پلان میں راستہ جو سڑک سے جڑا ہو، اس کی لمبائی اور رقبے میں | جو سڑکیں ملتی ہیں وہ زاویہ قائمہ پر جڑتی ہیں، مین سڑک کا کنارہ کھلا ہوتا ہے اور ذیلی سڑک اس تک ہموار ہوتی ہے ([جہاں سڑکیں ملتی ہیں](topic:corridor#where-roads-meet-roads-pads-and-paths))؛ راستہ تجویز شدہ سطح اور 3D میں سڑک کے کنارے پر رکتا ہے |
| LandXML میں کوریڈور بطور روڈ ویز برآمد، IFC برآمد میں ایک ایلائنمنٹ پر دوسرا کوریڈور | تجویز شدہ سطح برآمد ہوتی ہے |
| ٹیرین ٹیمپلیٹس جو تجویز شدہ سطح بدلیں، 3D میں یا سیکشنز میں | یہ ہر تہہ کے رقبے اور حجم دیتے ہیں ([ٹیرین ٹیمپلیٹس](topic:corridor-templates#terrain-templates)) |
| رفتار، ٹائر سلپ، اسٹیئرنگ وقت، اسٹیئرنگ ٹریلرز یا باڈی کلیئرنس کے ساتھ سویپڈ پاتھز؛ معیاری ڈیزائن گاڑیوں کی لائبریری؛ گاڑی کو گھسیٹ کر بنایا گیا سویپڈ پاتھ | فیچر لائن یا ایلائنمنٹ کے ساتھ کم رفتار کے سویپڈ پاتھز، اپنی گاڑی کے سائز کے ساتھ ([گاڑیوں کے سویپڈ پاتھز](topic:swept-paths)) |

| فری ہال اور اوور ہال لاگت، مختلف ایلائنمنٹس کے درمیان ہال، پلان پر رکھے گئے بورو پٹس اور ویسٹ سائٹس | توازن کے نقطوں، منتقل شدہ حجم اور اوسط ہال فاصلوں کے ساتھ ماس ہال ڈایاگرام |

| وقت کے ساتھ سیور فلوز (ہائیڈروگراف، متحرک روٹنگ، اسٹوریج، پمپس، اوور فلوز) | [سینیٹری ڈیزائن فلوز](topic:sanitary-design) ڈیزائن شیٹ کے لیے مستقل چوٹی بہاؤ دیتا ہے |
| انلیٹ کی گنجائش، گٹر اسپریڈ، ڈیٹینشن روٹنگ، ہائیڈروگراف، ایک جنکشن کوایفیشنٹ کے علاوہ توانائی کے نقصانات | انہیں دوسرے سافٹ ویئر میں جانچیں؛ فلوز، سائز اور گریڈ لائنیں [اسٹارم ڈرینیج](topic:storm-drainage) میں ہیں |
| PDF پلاٹ، DWG، DXF یا LandXML میں کیچمنٹس؛ سطح سے کیچمنٹس (واٹر شیڈز) | کیچمنٹس ہاتھ سے بنائیں؛ وہ پروجیکٹ فائل میں محفوظ ہوتی ہیں |

| NAD27 سے NAD83 کے علاوہ گرڈ شفٹس جو علاقے کے لحاظ سے تجویز ہوں (OSTN15، NTv2 دوسرے ڈیٹمز کے لیے، جب آپ فائل شامل کریں)، ایک ساتھ کئی گرڈز، عمودی گرڈز | اپنے ڈیٹم کے لیے گرڈ فائل خود شامل کریں؛ ایک پروجیکٹ میں ایک گرڈ |

| سائن ان، کی یا ٹوکن درکار نقشہ سرورز | عوامی سروسز استعمال کریں، یا جیو ریفرنسڈ تصویری فائل |
| سطح، زمینی ماڈل یا ایلیویشن گرڈ اور LiDAR ٹولز سے LAS یا LAZ فائلیں لکھنا | سطحیں GeoTIFF ایلیویشن گرڈ کے طور پر برآمد کریں۔ [Point clouds](topic:point-clouds) ایڈ آن صاف کلاؤڈ کو LAS 1.4 یا LAZ میں لکھتا ہے |

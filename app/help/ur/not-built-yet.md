CivilCraft ابھی ابتدائی مرحلے میں ہے۔ یہ صفحہ بتاتا ہے کہ موجودہ بلڈ کیا نہیں کرتا، تاکہ آپ اسے ڈھونڈنے میں وقت ضائع نہ کریں۔ یہاں کسی چیز کے لیے کسی تاریخ کا وعدہ نہیں ہے۔

## پوائنٹس

| ابھی تیار نہیں | اس کے بجائے، آج |
|---|---|
| دوسری پوائنٹ فائل کو پہلی میں شامل کرنا | فائلوں کو پہلے ٹیکسٹ ایڈیٹر یا اسپریڈشیٹ میں جوڑیں |
| پوائنٹ ٹیکسٹ فائل ایکسپورٹ کرنا | LandXML ایکسپورٹ کریں (پوائنٹس CgPoints کے طور پر جاتے ہیں)، GIS {{ui:ایکسپورٹ}} استعمال کریں (P، N، E، Z اور D فیلڈز والے پوائنٹس)، یا پوائنٹس کو اسپریڈشیٹ میں {{ui:نقل کریں}} کریں |
| پوائنٹ لیبل کے انداز، ہر وضاحتی کلید کے لیے علامات، لائن کوڈز سے قوس (منحنی)، ایک وضاحتی کلید فائل جو پروجیکٹس کے درمیان شیئر ہو | لیبل نمبر، بلندی اور وضاحت دکھاتے ہیں، یا اس سے کم ([CivilCraft کی ترتیبات](topic:settings))؛ کلیدیں پروجیکٹ فائل میں محفوظ رہتی ہیں |
| یونٹ کی تبدیلی | امپورٹ سے پہلے فائل تبدیل کریں؛ **اکائیاں** صرف لیبل بدلتا ہے |

## ایلائنمنٹس اور پروفائلز

| ابھی تیار نہیں | اس کے بجائے، آج |
|---|---|
| کلوتھائیڈ کے علاوہ دوسری اسپائرلز؛ دو منحنیوں کے درمیان اسپائرل (کمپاؤنڈ ٹرانزیشنز) | منحنی کے سروں پر کلوتھائیڈ اسپائرلز دستیاب ہیں؛ باقی کے نام لیے جاتے ہیں اور LandXML امپورٹ میں چھوڑ دیے جاتے ہیں |
| دو دوسرے PIs کے درمیان PI داخل کرنا | ایلائنمنٹ دوبارہ ڈرا کریں، یا PI کوآرڈینیٹس دوبارہ ٹائپ کریں |
| اشیاء، آفسیٹس یا چوڑا کرنے سے ایلائنمنٹس | PIs سے ڈرا کریں |
| عمودی منحنی کے لیے K ٹائپ کرنا | L ٹائپ کریں (K دکھایا جاتا ہے) |
| دائروی اور غیر متناسب عمودی منحنی | صرف متناسب پیرابولک منحنی |
| ہر ایلائنمنٹ کے لیے ایک سے زیادہ ڈیزائن پروفائل | ہر ویریئنٹ کے لیے ایک ایلائنمنٹ |
| پروفائل ویو کو زوم کرنا، پروفائل کے نیچے پروفائل بینڈز | پروفائل ویو پوری ایلائنمنٹ کو فٹ کرتا ہے؛ اسے [پلان اور پروفائل شیٹس](topic:plan-profile-sheets) پر پلاٹ کریں |
| DWG یا LandXML میں سیکشنز | PDF میں سیکشن شیٹس؛ علاقوں اور حجم کا {{ui:CSV}} |
| زاویے پر سیمپل لائنز، یا سڑک کے ساتھ مختلف چوڑائیوں کی | پوری ایلائنمنٹ کے لیے ہر طرف ایک چوڑائی |

| کوریڈورز LandXML roadways کے طور پر، IFC ایکسپورٹ میں ایک ایلائنمنٹ پر دوسرا کوریڈور | تجویز کردہ سطح ایکسپورٹ ہوتی ہے |
| زمینی ٹیمپلیٹس جو تجویز کردہ سطح بدلیں، 3D میں یا سیکشنز میں | یہ ہر تہہ کے رقبے اور حجم دیتے ہیں ([زمینی ٹیمپلیٹس](topic:corridor-templates#terrain-templates)) |
| رفتار، ٹائر سلپ، اسٹیئرنگ وقت، اسٹیئرنگ ٹریلرز یا باڈی کلیئرنس کے ساتھ سویپٹ پاتھز؛ معیاری ڈیزائن گاڑیوں کی لائبریری؛ گاڑی کو گھسیٹ کر بنایا گیا سویپٹ پاتھ | فیچر لائن یا ایلائنمنٹ کے ساتھ کم رفتار والے سویپٹ پاتھز، اپنی گاڑی کے سائز کے ساتھ ([گاڑیوں کے سویپٹ پاتھز](topic:swept-paths)) |

| سوِیل اور شرنک، ٹاپ سوائل، پیوومنٹ کی گہرائی | رپورٹ شدہ اعداد پر عوامل خود لاگو کریں |
| فری ہال اور اوور ہال لاگت، مختلف ایلائنمنٹس پر ہال، پلان پر رکھی گئی بورو پٹس اور ویسٹ سائٹس | توازنی نقاط، منتقل شدہ حجم اور اوسط ہال فاصلوں کے ساتھ ماس ہال ڈایاگرام |

| انلیٹ کی صلاحیت، گٹر اسپریڈ، ڈیٹینشن روٹنگ، ہائیڈروگراف، جنکشن کوایفیشنٹ کے علاوہ توانائی کے نقصانات | انہیں دوسرے سافٹ ویئر میں جانچیں؛ فلوز، سائز اور گریڈ لائنیں [اسٹارم ڈرینیج](topic:storm-drainage) میں ہیں |
| PDF پلاٹ، DWG، DXF یا LandXML میں کیچمنٹس؛ سطح سے کیچمنٹس (واٹرشیڈز) | کیچمنٹس ہاتھ سے ڈرا کریں؛ وہ پروجیکٹ فائل میں محفوظ ہوتی ہیں |
| پائپ کیٹلاگس، غیر گول پائپس، سیدھے باکس یا سلنڈر کے علاوہ ڈھانچے (کون، سیڑھیاں، بینچنگ)، لائبریری میں ڈرینیج کیٹیگری | پیرامیٹرز سے ڈھانچے کی اقسام ([پائپ نیٹ ورک](topic:pipe-network))؛ قطر والے پائپس |
| پروفائل ویو میں پائپس، خمدار پائپس | دائیں پینل میں انورٹس اور کور پڑھیں |

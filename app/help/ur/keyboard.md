ایک حرفی کیز تب کام کرتی ہیں جب آپ کسی باکس میں ٹائپ نہ کر رہے ہوں۔ {{key:Mod}} والے شارٹ کٹس میک پر Command اور باقی جگہوں پر Ctrl استعمال کرتے ہیں۔ یہ بھی دیکھیں [براؤزر میں کیز](common:keys)۔

## فائلیں اور ترمیم

| کی | عمل |
|---|---|
| {{key:Mod+O}} | پوائنٹ فائل، LandXML یا پروجیکٹ کھولیں |
| {{key:Mod+S}} | پروجیکٹ محفوظ کریں (`.civilcraft.json` فائل ڈاؤن لوڈ کرتا ہے) |
| {{key:Mod+P}} | پلان کو PDF میں پلاٹ کریں (پلاٹ ڈائیلاگ کھولتا ہے، براؤزر کی پرنٹ نہیں) |
| {{key:Mod+Z}} | کالعدم کریں |
| {{key:Mod+Y}} | دوبارہ کریں |
| {{key:Delete}} | منتخب سروے پوائنٹس، الائنمنٹ، پیڈ، ڈھانچہ، پائپ یا PVI حذف کریں |
| {{key:Mod+C}} | منتخب سروے پوائنٹس نقل کریں (اسپریڈشیٹ کے لیے پوائنٹ قطاروں کے طور پر بھی) |
| {{key:Mod+X}} | منتخب سروے پوائنٹس کاٹیں |
| {{key:Mod+V}} | پوائنٹس چسپاں کریں: یہ پوائنٹر کے ساتھ چلتے ہیں، جہاں جانے ہوں وہاں کلک کریں |
| {{key:Mod+Shift+V}} | اسی جگہ چسپاں کریں: پوائنٹس کے اپنے کوآرڈینیٹس پر |
| {{key:Mod+D}} | منتخب پوائنٹس کا ڈپلیکیٹ بنائیں: نقل پوائنٹر کے ساتھ چلتی ہے |
| {{key:Mod+A}} | سب سروے پوائنٹس منتخب کریں |
| {{key:Esc}} | انتخاب ختم کریں (اور چسپاں کرنا منسوخ کریں) |

{{key:Mod+S}}، {{key:Mod+O}} اور {{key:Mod+P}} تب بھی کام کرتی ہیں جب آپ کسی باکس میں ٹائپ کر رہے ہوں۔ باکس میں {{key:Mod+Z}} اور {{key:Mod+Y}} معمول کے مطابق آپ کی ٹائپنگ کالعدم یا دوبارہ کرتی ہیں، اور یہی {{key:Mod+C}}، {{key:Mod+X}}، {{key:Mod+V}} اور {{key:Mod+A}} کرتی ہیں: باکس میں یہ اس کا متن نقل، کاٹ، چسپاں یا منتخب کرتی ہیں۔ صفحے پر (کسی پینل میں) متن منتخب ہو تو {{key:Mod+C}} وہ متن نقل کرتی ہے۔ {{key:Mod+Shift+Z}} CivilCraft میں کچھ نہیں کرتی: {{key:Mod+Y}} یا {{ui:دوبارہ کریں}} بٹن استعمال کریں۔

:::mac
میک پر **delete** کے لیبل والی کی براؤزر کے لیے {{key:Backspace}} ہے۔ منتخب شے حذف کرنے کے لیے {{key:Delete}} دبائیں (Fn اور delete)، یا ٹول بار کے {{ui:مزید}} مینو میں سے {{ui:حذف کریں}} چنیں۔
:::

## پلان ویو

| کی یا عمل | نتیجہ |
|---|---|
| وہیل | پوائنٹر پر زوم ان یا آؤٹ |
| خالی جگہ پر گھسیٹیں | پین (کسی بھی ٹول میں؛ چھوٹا کلک اب بھی کلک ہوتا ہے؛ {{key:Shift}} دبا کر یہ منتخب کرنے کا باکس بناتا ہے) |
| درمیانی بٹن سے گھسیٹیں | پین |
| دائیں بٹن سے گھسیٹیں | پین (کوئی مینو نہیں کھلتا) |
| {{key:Space}} اور گھسیٹیں | پین |
| کلک | منتخب کریں ({{ui:منتخب کریں}} کے ساتھ)، یا پوائنٹ رکھیں (ڈرائنگ ٹول کے ساتھ) |
| {{key:Shift}} اور کلک | منتخب میں سروے پوائنٹ شامل کریں، یا نکال دیں |
| {{key:Shift}} اور گھسیٹیں | باکس بنائیں: اس کے اندر کے سروے پوائنٹس منتخب میں شامل ہو جاتے ہیں۔ [لاسو](topic:lasso-selection) کے لیے ان کے گرد گھسیٹیں |
| لاسو بناتے ہوئے {{key:Space}} | ونڈو، پھر کراسنگ، پھر باڑ |
| چسپاں کرتے وقت کلک | چسپاں پوائنٹس وہاں رکھیں ({{key:Enter}} انہیں ان کے اپنے کوآرڈینیٹس پر رکھتا ہے) |
| گرپ گھسیٹیں | PI، پیڈ کا کونا یا ڈھانچہ منتقل کریں (ایک کالعدم قدم) |
| {{key:Up}} {{key:Down}} {{key:Left}} {{key:Right}} | پین، جب پلان کو فوکس ہو (پہلے اس پر کلک کریں) |
| {{key:Plus}} اور {{key:Minus}} | درمیان میں زوم ان اور آؤٹ، جب پلان کو فوکس ہو |

= کی {{key:Plus}} کی طرح زوم ان کرتی ہے، اس لیے Shift کی ضرورت نہیں۔

## اسکرین اور مدد

| کی | عمل |
|---|---|
| {{key:F1}} | یہ مدد کھولیں یا بند کریں (سائیڈ پینل)؛ ایپ بار میں {{ui:مدد}} بھی یہی کرتا ہے |
| {{key:Esc}} | مدد کا پینل کھلا ہو تو اسے بند کریں |
| {{key:Ctrl+Shift+F}} | اسکرین موڈز باری باری بدلیں: مکمل اسکرین، بارز چھپے ہوئے مکمل اسکرین، عام |
| {{key:Esc}} | مکمل اسکرین سے نکلیں (براؤزر کی اپنی کی) |

{{key:F1}} مدد تک CivilCraft کے دیکھنے سے پہلے پہنچتی ہے، اس لیے یہ کسی بھی ٹول میں کام کرتی ہے۔ زیادہ تر میک کی بورڈز پر fn کے ساتھ F1 دبائیں، یا {{ui:مدد}} پر کلک کریں۔ {{key:Ctrl+Shift+F}} ہر پلیٹ فارم پر Control کی استعمال کرتی ہے، میک پر بھی۔ اس مدد میں تلاش کے طریقے کے لیے [مدد استعمال کرنا](common:help) دیکھیں۔

## ماؤس، ٹریک پیڈ اور ٹچ

:::mouse
- وہیل پوائنٹر پر زوم کرتا ہے۔ آزادانہ گھومنے والے وہیل کا ماؤس تیزی سے زوم کرتا ہے: اسے چھوٹے موڑ دیں۔
- خالی جگہ پر کسی بھی گھسیٹنے، درمیانی بٹن، دائیں بٹن، یا {{key:Space}} اور گھسیٹنے سے پین کریں۔
:::

:::mac
میک ٹریک پیڈ پر:

- دو انگلیوں سے اسکرول کرنا **زوم** کرتا ہے (پین نہیں کرتا)، اور چٹکی لینا بھی زوم کرتا ہے۔
- پین کرنے کے لیے خالی جگہ پر ایک انگلی سے دبائیں اور گھسیٹیں، یا {{key:Space}} دبائے رکھیں اور گھسیٹیں۔
- دو انگلیوں سے کلک (رائٹ کلک) کوئی مینو نہیں کھولتا اور خود سے کچھ نہیں کرتا۔
:::

:::touch
ٹچ اسکرین پر:

- پہلا ٹچ بٹنوں اور مینو قطاروں کو انگلی کے سائز کا بنا دیتا ہے۔
- منتخب کرنے یا پوائنٹ رکھنے کے لیے ٹیپ کریں؛ خالی جگہ پر ایک انگلی گھسیٹنے سے پین ہوتا ہے۔ ٹیپ تھوڑا ہل سکتا ہے: انگلی تقریباً 10 pixels حرکت کرے تب ہی پین ہوتا ہے۔
- دو انگلیوں کی چٹکی زوم کرتی ہے اور ایک ساتھ حرکت پین کرتی ہے۔
- ایک انگلی سے گرپ یا PVI گھسیٹیں۔ گرپس کے گرد انگلی کی چوڑائی جتنی جگہ لی جاتی ہے۔
- الائنمنٹ، پیڈ، بریک لائن، باؤنڈری، پائپ رن، فیچر لائن یا قطعہ بناتے ہوئے، پلان کے اوپر ایک بار {{ui:مکمل}} ({{key:Enter}})، {{ui:نقطہ کالعدم کریں}} ({{key:Backspace}}) اور {{ui:منسوخ کریں}} ({{key:Esc}}) پیش کرتا ہے۔ لمبا دبانا (بغیر ہلائے آدھا سیکنڈ) بھی مکمل کرتا ہے۔
- {{ui:منتخب کریں}} میں سروے پوائنٹ پر لمبا دبانا اسے منتخب میں شامل کرتا ہے، یا نکال دیتا ہے، جیسے {{key:Shift}}+کلک کرتا ہے۔
- 3D منظر میں ایک انگلی گھماتی ہے، دو انگلیوں کی چٹکی اور پین، اور ٹیپ منتخب کرتا ہے۔
- ٹچ پر ہوور نہیں ہوتا، اس لیے اسٹیٹس بار کی معلومات صرف اس وقت اپ ڈیٹ ہوتی ہیں جب کوئی انگلی دبی ہو۔
:::

## براؤزر کی وہ کیز جو جیت جاتی ہیں

کچھ کیز براؤزر کی ہوتی ہیں اور کبھی CivilCraft تک نہیں پہنچتیں، مثلاً {{key:Mod+W}} (ٹیب بند کریں)، {{key:Mod+T}} (نیا ٹیب)، {{key:Mod+N}} (نئی ونڈو) اور {{key:F11}} (ونڈوز اور لینکس براؤزرز میں مکمل اسکرین)۔ CivilCraft انہیں استعمال نہیں کرتا۔ اگر کوئی شارٹ کٹ اس کے بجائے براؤزر میں کچھ کھولے تو پلان پر ایک بار کلک کریں تاکہ صفحے کو فوکس ملے، اور دوبارہ کوشش کریں۔

## Move کہاں ہے

کوئی Move کمانڈ نہیں ہے: {{ui:منتخب کریں}} چنیں اور کوئی پوائنٹ یا ورٹیکس گھسیٹیں، یا {{ui:پراپرٹیز}} میں اس کے کوآرڈینیٹس میں ترمیم کریں۔ دیکھیں [پوائنٹس میں ترمیم](topic:edit-points)۔

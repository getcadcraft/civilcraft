電力線工作區的**程式庫**區段保存線路與電纜可以使用的所有項目。其中的項目不與特定國家或製造商綁定：所需的項目由自己建立。

## 三種項目

| 類型 | 存放位置 | 可以變更嗎？ |
|---|---|---|
| **範例** | 隨 CivilCraft 附帶，數值為依材料特性推算的一般數字 | 否：請先{{ui:複製到我的程式庫}} |
| **專案中的項目** | 隨開啟的專案檔案一併載入 | 否：請先{{ui:複製到我的程式庫}} |
| **自建項目** | 自行建立的項目，保存於此瀏覽器中 | 可以，變更會立即儲存 |

每個專案都會保存其使用的每個項目的副本，因此專案可以在任何電腦上開啟，並帶著自己的導線與電桿。

:::warning
範例項目僅供參考：請依供應商資料核對每個數值。地下電纜刻意不提供電流額定值，因為這取決於電纜的敷設方式。
:::

## 建立項目

1. 在**程式庫**中選擇**類型**（架空導線、地下電纜、支撐物、設備或溝槽類型）。
2. 按一下{{ui:新增項目}}，或選擇一個範例後按{{ui:複製到我的程式庫}}或{{ui:複製}}。
3. 填寫其欄位。標有 `*` 的欄位是檢查所需的；缺少欄位的項目會標示 `!`，並在某條線路使用它時列於**檢查**中。
4. 指定**類別**，層級之間以 `/` 分隔：`Overhead/LV/Bundled`、`Supports/Concrete/12 m`。分類樹會依類別建立。

各類型需要的欄位：

| 類型 | 檢查所需的欄位 |
|---|---|
| 架空導線 | 截面積、直徑、每公尺質量、斷裂強度、彈性模數、熱膨脹係數 |
| 地下電纜 | 芯數、截面積、電壓、直徑、電阻、電流額定值 |
| 支撐物 | 總長度、標稱載重（取於頂部以下某點）、地下深度 |
| 設備 | 其類型；橫擔、金具與拉線的額定載重；橫擔的相間距與壓降；絕緣子的長度；拉線的角度 |
| 溝槽類型 | 深度、寬度、電纜上方的覆土 |

## 分享

- {{ui:儲存我的程式庫}}會將所有自建項目儲存為一個 `.cclines.json` 檔案；{{ui:開啟程式庫…}}會讀回該檔案（鍵相同的項目會被取代）。
- {{ui:儲存為 CSV}}會將目前檢視的類型儲存為試算表；{{ui:開啟程式庫…}}會讀回該類型的 CSV。欄位順序可任意；以分號分隔的檔案可使用小數點逗號。

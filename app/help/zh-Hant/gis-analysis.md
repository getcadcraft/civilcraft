有了專案的 GIS 圖層後（請見[匯入 GIS 資料](topic:gis-import)），GIS 群組中的 **分析** 按鈕（輸入 `GISANALYSIS`、`ANALYZE` 或 `BUFFER`）會開啟一個有五個索引標籤的面板。面板會停留在平面圖旁，因此你選取的內容會在平面圖上繪出，方便你一邊作業一邊查看。

每個會產生結果的工具都會**新增一個圖層**，並保持其所讀取的圖層完全不變。每項操作都是一個復原步驟：面板中的{{ui:復原}}（或按Ctrl+Z）會移除新圖層。像其他圖層一樣，可以使用[匯出竣工資料供 GIS 使用](topic:gis-export)將結果匯出為 shapefile、GeoJSON 或 GeoPackage。

圖層的完整屬性表（含排序、編輯與欄位計算機）請見[使用圖層的屬性表](topic:gis-table)；依欄位上色請見[依屬性設定圖層樣式](topic:gis-symbology)。

所有計算都在平面圖上以專案單位（英尺或公尺）進行。專案一律採用投影或局部座標系統，因此距離 50 即表示 50 英尺或 50 公尺，絕不會是度。結果中不保留高度（z）。

## 緩衝區

為每個地物繪出指定距離的範圍，並成為新的面圖層。點會變成圓形，線會變成兩端圓角的走廊，面則會向外擴大。**負**距離會使面縮小（100 × 100 的正方形縮小 5 會變成 90 × 90；縮小 60 則什麼都不剩，面板會告知）。可以從數值欄位取得距離，讓每個地物各有自己的距離；或勾選**將所有緩衝區合併成一個形狀**以融合它們。

圓角部分是以位於真實曲線內側的直線段繪製，因此緩衝區會略小於精確的圓：在一般設定下面積約小 0.6 %，在精細設定下約小 0.16 %。若要量測，請使用精細設定。

## 疊加

| 工具 | 結果 |
|---|---|
| 交集 | 輸入圖層與疊加面相交的部分，每個部分都帶有兩個圖層的欄位。線和點會被裁剪到面的範圍內。 |
| 聯集 | 兩個面圖層彼此沿對方的邊界切開：共用的部分帶有兩個圖層的欄位，其餘部分只帶有其中一個圖層的欄位（另一個圖層的欄位為空）。 |
| 擦除 | 輸入面扣除疊加面後的結果。欄位保留輸入圖層的。若地物被完全擦除，會被排除（面板會計算數量）。 |
| 融合 | 合併相接或重疊的面，可全部合併，或依某欄位的每個值各合併成一個形狀。會新增 `COUNT` 與 `AREA`。 |

兩個圖層都有的欄位名稱會保留第一個圖層的，第二個圖層的則會寫成 `_2`。同一圖層內的地物不應彼此重疊：若有重疊，聯集會在兩邊都計入重疊部分。

## 連接

空間連接會將**來源**圖層的屬性複製到與之相接的每個**目標**地物上，並產生一個具有目標形狀的新圖層。請選擇兩者的接觸條件：相接或重疊、目標位於來源面之內、目標包含來源地物、最近的來源地物（可選擇加上上限），或距離內的任何來源地物。

若有多個來源地物符合，會取第一個的屬性（最近連接與距離連接時取最近者，並新增 `DISTANCE`），或**計數並加總其數值欄位**：`COUNT`，以及每個數值欄位的 `SUM_`、`MEAN_`、`MIN_`、`MAX_`。取消勾選**保留未找到符合項目的目標地物**即可排除這些地物。沒有符合項目的位置，連接欄位為空，面板會計算未符合的數量。

## 選取

輸入有關屬性或形狀的查詢，按**選取**，地物就會在平面圖上繪出，並顯示其數量、一張表格，以及總面積、總長度或總數。接著可將它們建立為獨立的圖層、縮放至它們，或清除選取。

| 可輸入的內容 | 範例 |
|---|---|
| 依名稱指定欄位；若名稱含空格，請使用 "引號" 或 [方括號] | `VALUE`、`"Lot Number"` |
| 數字、'文字'、true、false、null | `Use_ = 'Res'` |
| `=` `!=` `<>` `<` `<=` `>` `>=` | `VALUE >= 250` |
| `contains` `startswith` `endswith` `like` `ilike`（文字不分大小寫；在 `like` 中，`%` 代表任意字串，`_` 代表一個字元） | `Notes contains 'corner'` |
| `is null`、`is not null`（空值視為 null） | `Notes is null` |
| `in (…)`、`not in (…)`、`between … and …` | `Use_ in ('Com', 'Ind')` |
| `+ - * /` 與括號 | `VALUE / 2 > 100` |
| `and`、`or`、`not` | `Use_ = 'Res' and VALUE > 200` |
| 形狀值 `$area` `$perimeter` `$length` `$x` `$y` `$vertices` | `$area > 5000` |

不完整的查詢，或指定了圖層沒有的欄位，都會被拒絕，並附上說明問題所在的句子。

## 量測

顯示圖層的總面積與周長、總長度或總數，並會為其**新增欄位**：面為 `AREA` 與 `PERIMETER`，線為 `LENGTH`（平面長度），點為 `X` 與 `Y`。已存在的欄位絕不會被覆寫，新欄位會命名為 `AREA_2`。此操作為一個復原步驟。**統計**會計算某數值欄位的個數、總和、平均值、最小值與最大值，也可依另一欄位的每個值分別計算。

:::note
這些工具背後的檢查，是在測試中以手算方式進行（`node bin/test-civilcraft-gisanalysis.mjs`）：例如，100 × 100 的地籍位於 100 × 80 的分區之下，其交集為 3,000 加 3,000；長度 100 的線以 10 進行緩衝，則為 2,000 加一個圓。
:::

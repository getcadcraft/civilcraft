3D 檢視會將基地呈現為單一模型：既有地面與整地後的曲面、貼附於其上的等高線、斷線與曲面邊緣、各路線及其設計縱斷面與樁號刻度、廊道特徵線與道路本身（車道、路肩、排水溝、路緣、分隔帶與人行道，各以自己的顏色表示）、含坡腳線的平台，以及管網（管段與構造物以其實際高程呈現）；若在景觀工作區中，則包括植栽、鋪面、步道、牆、路緣、坡道與階梯。它與平面讀取的是同一個專案，因此任何編輯都會同時顯示在兩者中。

## 開啟 3D 檢視

1. 開啟測量點（或 LandXML 或專案檔案），以建立曲面。單獨的植栽、鋪面或坡道也足以開啟它。
2. 按{{key:D}}，或按工具列{{ui:View}}群組中的{{ui:3D}}。
   3D 檢視會開啟於平面之上，從東南方向觀看整個基地。第一次開啟時需要稍候片刻載入。
3. 再按一次{{key:D}}或{{ui:3D}}，即可返回平面。選擇{{ui:Alignment}}或{{ui:Pad}}等繪圖工具，也會返回平面，因為繪圖是在平面上進行的。

## 移動

| 目的 | 操作 |
|---|---|
| 環繞 | 以左鍵或中鍵拖曳 |
| 平移 | 以右鍵拖曳，或按住{{key:Shift}}並拖曳 |
| 縮放 | 轉動滾輪；縮放會朝向指標位置 |
| 在觸控板上環繞 | 以兩指滑動（按住{{key:Shift}}並滑動則為平移） |
| 在觸控板上縮放 | 以兩指捏合 |
| 觸控 | 一指環繞；兩指捏合縮放，移動則為平移 |
| 按鍵（檢視取得焦點時） | {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} 環繞，搭配{{key:Shift}}則為平移；{{key:Plus}} 與 {{key:Minus}} 縮放 |

檢視上方的工具列提供其餘功能：

- 檢視清單：**等角**、**俯視**、**仰視**、**前視**（面向北）、**後視**、**左視**、**右視**。
- {{ui:Perspective}}：按下時為透視檢視；再按一次則改為平行投影（無透視縮短）。
- {{ui:Extents}}：重新顯示全部內容。在 3D 檢視開啟時，{{key:F}}的功能相同。

## 視圖方塊

右上角的視圖方塊會隨視角轉動。點擊一個面、邊或角，即可從該處觀看基地（除非你的系統要求減少動態效果，否則相機會平順轉動）。拖曳方塊即可環繞。其下的指北環會顯示北方（格網北，+Y）：拖曳指北環可繞垂直軸旋轉基地，或點擊 N、E、S 或 W 從該側觀看。{{ui:Home}}位於其左上角的小房子圖示，會返回整個基地的等角視圖。以鍵盤操作：按{{key:Tab}}移至方塊，以方向鍵選擇面、邊或角，按{{key:Enter}}即從該處觀看。

在平面上，同一方塊顯示俯視。點擊任一其他面、邊或角（或拖曳它），即可開啟從該方向觀看的 3D 檢視：這是由某一方向進入 3D 最快的方式。若要將方塊換成小型座標軸圖示，或將其隱藏，請參見 [CivilCraft 設定](topic:settings)中的**角落指示器**。

## 誇大高程

基地通常寬遠大於高，因此高程起始即以 **2×** 拉伸。請在工具列的清單中選擇 **1×**、**2×**、**3×**、**5×** 或 **10×**，或於 [CivilCraft 設定](topic:settings)中的**3D 垂直誇大倍率**下選擇（兩者為同一項設定）。只有檢視會改變：土方量、縱斷面與匯出維持真實比例。

## 曲面著色

- **高程分帶**：與平面上的高程分帶相同的分帶與顏色（分帶數量於左側面板的**顯示**下設定）。每個分帶邊界皆精確切於其高程。
- **單一顏色**：既有地面與整地後的曲面各以單純的顏色呈現。
- **地圖圖層**：平面下方顯示的地圖圖層（具地理參照的圖片、地圖圖塊或地圖服務；請參見[地圖圖層](topic:map-layers)），會如一張片子鋪於曲面上，因此航照可顯示於山丘上。仍在載入的圖片會隨其到達而逐步填入。若無地圖圖層顯示，曲面會保留其高程分帶，檢視中會加以說明。此圖片僅供螢幕顯示：GLB 與 OBJ 匯出不包含它。

當兩個曲面都顯示時，既有地面會以半透明方式覆於整地後的曲面之上，因此你可看見挖方（設計以上的地面）與填方。

## 選擇要顯示的內容

點擊工具列上的{{ui:Show}}，然後勾選或取消勾選：

| 項目 | 說明 |
|---|---|
| 既有地面 | 由測量點（或自 LandXML 讀取）建立的曲面 |
| 整地後的曲面 | 加入廊道與平台整地後的既有地面（僅在有此類設定時顯示） |
| 三角形邊 | 每條 TIN 邊，以線條顯示 |
| 等高線 | 每個曲面的次要與主要等高線，採用平面上的間距 |
| 曲面邊緣 | 每個曲面的外緣，位於其高程上 |
| 斷線 | 每條斷線，位於其高程上 |
| 路線與樁號 | 每條路線位於其設計縱斷面上（若無縱斷面則位於地面上），每 50 ft 或 20 m 有刻度 |
| 廊道特徵線 | 兩側的路面邊緣、路肩與坡腳線 |
| 道路曲面 | 每條廊道依其斷面所建置的道路：車道、路肩、排水溝、路緣、分隔帶與人行道，各以自己的顏色表示，位於整地後的曲面上 |
| 植栽 | 每一株植栽，以及花圃與樹籬中的植栽，以依植栽清單大小所呈現的簡單造型表示：樹木為樹幹加圓形樹冠（針葉樹為圓錐，棕櫚為高樹幹上的一簇葉），灌木、樹籬植物、多年生植物與地被為圓頂，草為一簇，攀緣植物為細柱。它們立於整地後的曲面（或既有地面）上，大小與平面所示一致：成熟狀或種植時 |
| 硬質景觀 | 含坡度的鋪面與步道、牆、路緣、階梯，以及以水平平台相隔、逐段攀升的坡道 |
| 平台與坡腳線 | 每個平台的輪廓位於其高程上，並附其坡腳線 |
| 管線與構造物 | 管段以其底部與頂部之間的圓管表示，構造物則自井蓋延伸至集水井 |
| 測量點 | 每個具有高程的點皆以一個小點表示（起始為關閉） |
| GIS 圖層 | 平面上顯示的 GIS 圖層，依其顏色呈現：線與輪廓位於其自身高程上，其他則鋪於既有地面上（完全依其起伏）；點以小十字表示。不具高程且位於曲面外的形狀會被略去，檢視中會說明略去的數量 |
| 標籤 | 無論你如何旋轉或縮放，都始終面向你的名稱與數值：每條路線的名稱位於其起點，樁號每 100 ft（或 100 m）標示一次，主要等高線的高程，平台、特徵線與構造物的名稱；若勾選**測量點**，則顯示每個點的編號與高程 |

無論你如何旋轉或縮放，標籤的大小與方向都保持不變；位於標籤前方的山丘會將其遮住。當標籤過於擁擠時，最重要的標籤會先顯示，其餘則待你放大後才顯示：依序為路線、構造物、平台、特徵線、樁號、等高線與點位，距離較近者優先。標籤僅顯示於螢幕上；匯出與列印則不含標籤。

你的選擇、誇大倍率與著色會記憶於此瀏覽器中。

道路是建置於既有地面上的。若有路線與廊道，但尚無測量點或曲面，道路會暫以平坦的替代地面繪出：位於其設計縱斷面的平均高程，若也無縱斷面，則位於高程 0 的水平面。3D 檢視底部與廊道的屬性中會有警告說明此點。它僅為示意圖：不會由此產生土方量或斷面。開啟測量點或曲面後，道路會自動移至真實地面上。

垂直誇大倍率只拉伸地面，不拉伸植栽：植栽立於經誇大的地面上，並保持其真實高度與展幅，因此無論設定為何，樹木看起來都像樹木。植栽為簡單的造型，而非詳細的模型：數千株植栽仍能快速旋轉與縮放。

## 管線與構造物

- 管段以其底部位於你所設定的管底高程、頂部（管頂）位於其上方一個內徑處的方式繪出。英制專案的直徑以英吋表示，公制專案以毫米表示，與右側面板一致。
- 構造物自其井蓋（可輸入，或取自曲面）向下延伸至集水井（最低管底減去集水井深度）。若無任何管底高程，則以 5 ft（1.5 m）深度繪出。
- 有問題的管線與構造物（見右側面板中的管網檢查）以紅色繪出。
- 沒有管底高程的管段不會繪出；檢視底部的附註會說明有多少管段未繪出。

## 從 3D 檢視中選取

點擊路線（或其道路）、平台、特徵線、管段、構造物、測量點、植栽、坡道或其他硬質景觀，即可選取它。其選取方式與在平面上點擊完全相同：其屬性會於右側面板中開啟，供你編輯，並以選取顏色繪於 3D 中所有物件之上。你在平面上選取的物件，也會在 3D 中被醒目標示。指標旁的提示會說明你所點擊的物件，並列出其東座標、北座標與高程。管線與構造物即使位於地面以下，也可被點擊；被山丘遮住的線條則無法穿透點擊。

點擊斷線即可得知它是哪一條：它會被醒目標示，狀態列也會顯示其名稱（斷線沒有自己的屬性）。

點擊地面即可在提示中讀取該處的東座標、北座標與高程。

## 沿路線駕駛

在 3D 工具列上按**駕駛**，並選擇一條路線。視角會移至駕駛座：位於道路上方 3.5 ft（1.07 m）處，沿其設計縱斷面（若尚無縱斷面，則沿中心線位於既有地面上），向前看向路線方向。

- **播放**或{{key:Space}}會以你所選的速度駕駛（10 至 65 mph，或 15 至 100 km/h）；再按一次{{key:Space}}即暫停。到達終點時會停止；此時**播放**會從頭開始。
- 滑桿可跳至任一樁號；{{key:Left}}與{{key:Right}}每次向後或向前移動 10 ft（5 m）。
- 在檢視中拖曳會暫停，並讓你環顧四周。
- **停止**或{{key:Esc}}會將檢視恢復至原來的位置。

垂直誇大倍率在駕駛時同樣適用：將其設為 1×，即可看到道路建成後的實際樣子。

## 太陽光

在 3D 工具列上開啟**太陽**，並勾選**來自太陽的光**。輸入日期、時刻與其時區（與 UTC 的時差：夏季則為日光節約時間），以及基地的緯度與經度。若專案具有座標系統，這些數值會自其中填入。

基地隨即會依太陽所在位置照明，並在地面、廊道與平台上顯示**陰影**；選單會顯示太陽的方位角與高度，或說明太陽位於地平線以下。太陽位置取自 NOAA 的太陽方程式。無論誇大倍率為何，陰影的方向都正確，但在基地邊緣處停止：超出邊界的山丘與建築物不會投下陰影。

## 匯出 3D 檢視

在工具列上按{{ui:GLB}}或{{ui:OBJ}}。檢視中所呈現的內容會以真實比例（無誇大）、單位為公尺、Y 軸向上儲存。詳情請見：[將基地匯出為 3D](topic:export-3d)。

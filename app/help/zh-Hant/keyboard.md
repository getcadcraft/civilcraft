單字母按鍵只有在未於輸入框中輸入文字時才有作用。使用 {{key:Mod}} 的快速鍵在 Mac 上為 Command，其他平台為 Ctrl。另請參閱[瀏覽器中的按鍵](common:keys)。

## 檔案與編輯

| 按鍵 | 動作 |
|---|---|
| {{key:Mod+O}} | 開啟點檔案、LandXML 或專案 |
| {{key:Mod+S}} | 儲存專案（下載 `.civilcraft.json` 檔案） |
| {{key:Mod+P}} | 將平面圖列印為 PDF（開啟列印對話方塊，而非瀏覽器的列印） |
| {{key:Mod+Z}} | 復原 |
| {{key:Mod+Y}} | 取消復原 |
| {{key:Delete}} | 刪除所選測量點、路線、平台、構造物、管線或 PVI |
| {{key:Mod+C}} | 複製所選測量點（也可複製為試算表用的點列） |
| {{key:Mod+X}} | 剪下所選測量點 |
| {{key:Mod+V}} | 貼上點：點會跟隨指標，按一下放置位置 |
| {{key:Mod+Shift+V}} | 原位貼上：貼至點自身的座標 |
| {{key:Mod+D}} | 建立所選點的副本：副本跟隨指標 |
| {{key:Mod+A}} | 選取所有測量點 |
| {{key:Esc}} | 取消選取（並取消貼上） |

即使在輸入框中輸入文字時，{{key:Mod+S}}、{{key:Mod+O}} 與 {{key:Mod+P}} 仍可使用。在文字框中，{{key:Mod+Z}} 與 {{key:Mod+Y}} 會如一般情況般復原你的輸入，{{key:Mod+C}}、{{key:Mod+X}}、{{key:Mod+V}} 與 {{key:Mod+A}} 也同樣如此：在輸入框中，它們會複製、剪下、貼上並全選其中的文字。若頁面上（面板中）有選取的文字，{{key:Mod+C}} 會複製該文字。{{key:Mod+Shift+Z}} 在 CivilCraft 中沒有作用：請改用 {{key:Mod+Y}} 或{{ui:Redo}}按鈕。

:::mac
對瀏覽器而言，Mac 上標示為 **delete** 的按鍵就是 {{key:Backspace}}。若要刪除所選內容，請按 {{key:Delete}}（Fn 與 delete），或在工具列的{{ui:More}}功能表中選擇{{ui:Delete}}。
:::

## 工具

| 按鍵 | 工具 |
|---|---|
| {{key:V}} | {{ui:Select}} |
| {{key:M}} | {{ui:Measure}}：在平面圖上量測距離、面積與坡度（[量測](topic:measure)） |
| {{key:A}} | {{ui:Alignment}} |
| {{key:G}} | {{ui:Pad}} |
| {{key:P}} | {{ui:Pipes}} |
| {{key:B}} | {{ui:Breakline}} |
| {{key:O}} | {{ui:Boundary}} |
| {{key:R}} | 顯示或隱藏縱斷面檢視 |
| {{key:I}} | 開啟或關閉{{ui:Add PVIs}}（若縱斷面檢視已關閉，會將其開啟） |
| {{key:F}} | {{ui:Fit}}：顯示全部 |
| {{key:D}} | {{ui:3D}}：以 3D 顯示基地，或返回平面圖 |
| {{key:E}} | 顯示或隱藏沿每條特徵線的坡度與高程（僅限螢幕上） |

再次按下目前工具的按鍵，會返回{{ui:Select}}。搭配 Shift 的字母鍵沒有作用。

## 繪圖時

| 按鍵 | 動作 |
|---|---|
| {{key:Enter}} | 完成路線、平台、管線段、斷線或邊界 |
| {{key:Backspace}} | 移除最後點按的點 |
| {{key:C}} | 特徵線：開啟或關閉圓弧（在頂點後，點按曲線上的一點，再點按其終點） |
| {{key:Esc}} | 取消繪圖（或貼上）；再按一次（或尚未繪製任何內容時），返回{{ui:Select}}並清除選取 |

## 平面檢視

| 按鍵或動作 | 結果 |
|---|---|
| 滾輪 | 在指標位置放大或縮小 |
| 在空白處拖曳 | 平移（任何工具皆可；短暫點按仍會點選；按住 {{key:Shift}} 時則繪製選取框） |
| 以中鍵拖曳 | 平移 |
| 以右鍵拖曳 | 平移（不會開啟功能表） |
| 按住{{key:Space}}並拖曳 | 平移 |
| 點按 | 點選（使用{{ui:Select}}時），或放置點（使用繪圖工具時） |
| 按住 {{key:Shift}} 並點按 | 將測量點加入選取或從選取中移除 |
| 按住 {{key:Shift}} 並拖曳 | 繪製選取框：框內的測量點會加入選取。拖曳環繞它們可改用[套索](topic:lasso-selection) |
| 繪製套索時按 {{key:Space}} | 依序為視窗、交叉、圍籬 |
| 貼上時點按 | 將貼上的點放在該處（按 {{key:Enter}} 則放在其自身座標） |
| 拖曳夾點 | 移動 PI、平台角點或構造物（一個復原步驟） |
| {{key:Up}} {{key:Down}} {{key:Left}} {{key:Right}} | 平面圖具焦點時（先點按一下）平移 |
| {{key:Plus}} 與 {{key:Minus}} | 平面圖具焦點時，於中央放大與縮小 |

= 鍵的放大方式與 {{key:Plus}} 相同，因此不需要按 Shift。

## 縱斷面檢視

| 動作 | 結果 |
|---|---|
| 開啟{{ui:Add PVIs}}時點按 | 在該處新增 PVI |
| 點按 PVI | 選取該 PVI |
| 拖曳 PVI | 移動（一個復原步驟） |
| {{key:Delete}} 或 {{key:Backspace}} | 移除所選 PVI（僅在縱斷面檢視具焦點時使用 Backspace） |

縱斷面檢視不支援縮放或平移。

## 螢幕與說明

| 按鍵 | 動作 |
|---|---|
| {{key:F1}} | 開啟或關閉此說明（側邊面板）；應用程式列中的{{ui:Help}}功能相同 |
| {{key:Esc}} | 說明面板開啟時，關閉說明面板 |
| {{key:Ctrl+Shift+F}} | 循環切換螢幕模式：全螢幕、隱藏工具列的全螢幕，以及一般模式 |
| {{key:Esc}} | 離開全螢幕（瀏覽器自身的按鍵） |

{{key:F1}} 會先於 CivilCraft 接收到，因此在任何工具中皆可使用。在大多數 Mac 鍵盤上，請按 fn 加 F1，或按一下{{ui:Help}}。{{key:Ctrl+Shift+F}} 在所有平台（包括 Mac）皆使用 Control 鍵。若要了解如何搜尋本說明，請參閱[使用說明](common:help)。

## 滑鼠、觸控板與觸控

:::mouse
- 滾輪會在指標位置縮放。滾輪可自由旋轉的滑鼠縮放很快：請以短幅度轉動。
- 在空白處以任意方式拖曳、以中鍵、以右鍵，或按住{{key:Space}}並拖曳，皆可平移。
:::

:::mac
在 Mac 觸控板上：

- 雙指捲動會**縮放**（不會平移），捏合同樣會縮放。
- 若要平移，請以單指在空白處按住並拖曳，或按住{{key:Space}}並拖曳。
- 雙指點按（右鍵）不會開啟功能表，本身也沒有其他作用。
:::

:::touch
在觸控螢幕上：

- 第一次觸控會使按鈕與功能表列的大小適合手指操作。
- 輕觸以選取或放置點；單指在空白處拖曳即可平移。輕觸時可能會稍有晃動：手指移動約 10 像素後才會平移。
- 雙指捏合可縮放，一起移動可平移。
- 以單指拖曳夾點或 PVI。夾點周圍會保留一根手指寬度的範圍。
- 繪製路線、平台、斷線、邊界、管線段、特徵線或地籍時，平面圖上方的列會提供{{ui:Finish}}（{{key:Enter}}）、{{ui:Undo point}}（{{key:Backspace}}）與{{ui:Cancel}}（{{key:Esc}}）。長按（未移動半秒）也會完成繪製。
- 在{{ui:Select}}中，長按測量點會將其加入選取或取消選取，效果與{{key:Shift}}加點按相同。
- 在 3D 檢視中，單指旋轉，雙指捏合與平移，輕觸則選取。
- 觸控沒有懸停功能，因此狀態列的讀數只會在手指按下時更新。
:::

## 瀏覽器優先的按鍵

部分按鍵屬於瀏覽器，永遠不會傳到 CivilCraft，例如 {{key:Mod+W}}（關閉分頁）、{{key:Mod+T}}（新增分頁）、{{key:Mod+N}}（新增視窗）與 {{key:F11}}（Windows 與 Linux 瀏覽器中的全螢幕）。CivilCraft 不會使用這些按鍵。若快速鍵改為在瀏覽器中開啟其他內容，請先在平面圖上按一下使頁面取得焦點，再重試一次。

## 移動功能的位置

沒有「移動」指令：請選擇{{ui:Select}}後拖曳點或頂點，或在{{ui:Properties}}中編輯其座標。請參閱[編輯點](topic:edit-points)。

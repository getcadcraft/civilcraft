CivilCraft 仍在早期階段。本頁列出目前版本尚未提供的功能，讓您不必再去尋找。此處的項目均未承諾日期。

## 點

| 尚未實作 | 目前替代做法 |
|---|---|
| 將第二個點檔案加入第一個 | 先在文字編輯器或試算表中合併檔案 |
| 匯出點的文字檔 | 匯出 LandXML（點輸出為 CgPoints），使用 GIS {{ui:匯出}}（含 P、N、E、Z 與 D 欄位的點），或將點{{ui:複製}}到試算表 |
| 點標註樣式、依描述代碼的符號、由線碼產生的曲線（圓弧），以及可在專案之間共用的描述代碼檔 | 標註會顯示編號、高程與描述，或更少內容（[CivilCraft 設定](topic:settings)）；代碼保存於專案檔中 |
| 單位換算 | 匯入前先轉換檔案；**單位**只會重新標示 |

## 曲面

| 尚未實作 | 目前替代做法 |
|---|---|
| 由點建置超過一個曲面 | 每個曲面一個專案 |
| 隱藏（內部）邊界 | 使用**最長外緣**或外側邊界 |
| 選取或編輯單一已繪製的斷線 | {{key:Mod+Z}}，或{{ui:移除已繪製的斷線}}後重新繪製 |
| 編輯從 LandXML 讀入的曲面（斷線、邊界） | {{ui:依點重建曲面}} |
| 編輯由高程格網建立的曲面 | 以其他選項重新匯入格網 |
| 座標系統變更時，轉換從 LandXML 讀入的曲面 | 先{{ui:依點重建曲面}} |
| 附標註的高程點與坡度值 | 在狀態列讀取，或在景觀工作區使用**坡度分析**依坡度為曲面上色（[景觀整地](topic:landscape-grading#grading-checks)） |

## 路線與縱斷面

| 尚未實作 | 目前替代做法 |
|---|---|
| 回旋曲線（clothoid）以外的緩和曲線；兩曲線之間的緩和曲線（複合過渡） | 曲線兩端的回旋曲線（clothoid）可用；其他類型會在匯入 LandXML 時被略過並加以命名 |
| 在兩個 PI 之間插入 PI | 重新繪製路線，或重新輸入 PI 座標 |
| 由物件、偏移與加寬建立路線 | 以 PI 繪製 |
| 為垂直曲線輸入 K | 輸入 L（會顯示 K） |
| 圓形與非對稱垂直曲線 | 僅限對稱拋物線垂直曲線 |
| 每條路線多於一個設計縱斷面 | 每個變體一條路線 |
| 縮放縱斷面檢視，縱斷面下方的縱斷面帶 | 縱斷面檢視會符合整條路線；可於[平面與縱斷面圖紙](topic:plan-profile-sheets)上列印 |
| DWG 或 LandXML 中的斷面 | 斷面圖紙（PDF）；面積與土方量的 {{ui:CSV}} |
| 斜向的取樣線，或沿道路寬度不同的取樣線 | 每側為整條路線的單一寬度 |

## 廊道

| 尚未實作 | 目前替代做法 |
|---|---|
| 中央分隔帶、護欄，以及使範本旋轉的超高 | 將其繪製為範本（[廊道範本](topic:corridor-templates)）；依樁號的範本尚不接受超高 |
| 兩個區段範本之間的漸變（過渡、漸縮） | 在某樁號變更範本，或為繪製為漸縮的線給定點的寬度目標 |
| 繞邊緣旋轉，以及 LandXML 中的超高 | 圓形曲線上的超高繞中心線旋轉；以寬度目標將車道加寬至特徵線 |
| 邊坡的目標（坡腳線至某線或某曲面），以及各自的廊道曲面 | 目標會移動路面邊緣與路肩（[廊道](topic:corridor)）；廊道整地納入設計曲面 |
| 整地納入交叉口的路緣石轉角、轉向車道與安全島；斜交時將支路端點切至主路邊緣；平面上與道路相接的步道，其長度與面積 | 相接的道路以直角相接，開出主路邊緣並使支路緩和至該邊緣（[道路相接處](topic:corridor#where-roads-meet-roads-pads-and-paths)）；步道停在設計曲面與 3D 中道路的邊緣 |
| 以 LandXML 道路匯出的廊道；IFC 匯出中路線上的第二條廊道 | 匯出設計曲面 |
| 會改變設計曲面的地形範本（於 3D 或斷面中） | 提供各層的面積與體積（[地形範本](topic:corridor-templates#terrain-templates)） |
| 含速度、輪胎滑移、轉向時間、拖車轉向或車身淨空的掃掠路徑；標準設計車輛程式庫；以拖曳車輛繪製的掃掠路徑 | 沿特徵線或路線、使用自訂車輛尺寸的低速掃掠路徑（[車輛掃掠路徑](topic:swept-paths)） |

## 整地與土方量

| 尚未實作 | 目前替代做法 |
|---|---|
| 階台、整地進設計中的開放特徵線，以及整地至其他地方特徵線 | 將特徵線封閉（[特徵線](topic:feature-lines)），或將其作為現有地面的斷線 |
| 插入或刪除特徵線的頂點 | 重新繪製該線，或製作其階梯式偏移 |

| 依距離、高程或另一曲面整地 | 僅能整地至現有地面（坡腳線） |
| 新增或刪除平台角點 | 刪除平台並重新繪製 |
| TIN 對 TIN（角柱）體積，選擇格網儲存格大小 | 格網法，儲存格大小由系統為您選擇 |
| 膨脹與收縮、表土、鋪面厚度 | 自行將係數套用於報告的數字 |
| 免費運距與超運費用、跨不同路線的運土，以及於平面上放置的借土場與廢土場 | 土方調配圖，含平衡點、搬運土方量與平均運距 |

## GIS 與座標系統

| 尚未實作 | 目前替代做法 |
|---|---|
| File Geodatabase；KML 樣式、圖示、地面疊加與網路連結 | 先轉換為 GeoPackage、shapefile 或 GeoJSON；KML 地標會在不含樣式的情況下讀取 |
| 編輯 GIS 要素或其屬性 | 在 GIS 程式中編輯後重新匯入。{{ui:分析}}面板會建立新圖層（緩衝區、疊合、連接、選取），並新增面積與長度欄位，但不會就地編輯要素 |
| 網路與柵格分析、平端或方端的緩衝區與單側緩衝區、在屬性表中新增或刪除列以及變更欄位類型、手動類別顏色、圖表中的樣式圖例 | 使用{{ui:選取}}挑選要素，並由其建立圖層；不提供平端。依屬性上色與屬性表已建置：見[依屬性設定圖層樣式](topic:gis-symbology)與[使用圖層屬性表](topic:gis-table) |
| 標註樣式（大小、位置）與互相避讓的標註 | 標註大小一致，要素密集時可能重疊 |
| 垂直基準與大地水準面模型 | 高程依檔案提供的值使用；請自行檢查垂直基準 |
| 除依地區建議由 NAD27 轉換至 NAD83 外的格網位移（OSTN15；加入檔案後，NTv2 適用於其他基準）、同時使用多個格網、垂直格網 | 自行為所用基準加入格網檔；每個專案一個格網 |
| DXF 或 3D 匯出中的地圖圖層 | 地圖圖層輸出至 PDF 圖，並以圖片形式置於 DWG 旁 |
| 需要登入、金鑰或權杖的地圖伺服器 | 使用公開服務，或使用具地理參考的影像檔 |
| 由曲面、地面模型或高程格網與 LiDAR 工具寫出 LAS 或 LAZ 檔 | 將曲面匯出為 GeoTIFF 高程格網。[點雲](topic:point-clouds) 外掛可將清理後的點雲寫為 LAS 1.4 或 LAZ |
| LiDAR 強度、顏色與回波；多波段高程格網；超過 200 MB 的格網或 LiDAR 檔案 | LiDAR 僅依類別篩選，格網使用其第一個波段；請先將大型檔案切割為圖塊 |

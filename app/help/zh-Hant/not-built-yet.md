CivilCraft仍在早期階段。本頁列出目前版本尚未實作的功能，避免白費心思尋找。本頁所列功能均未承諾日期。

## 點

| 尚未實作 | 目前可改用的做法 |
|---|---|
| 將第二個點檔案併入第一個 | 先在文字編輯器或試算表中合併檔案 |
| 匯出點的文字檔 | 匯出LandXML（點會以CgPoints輸出）、使用GIS{{ui:Export}}（點含P、N、E、Z與D欄位），或將點{{ui:Copy}}到試算表中 |
| 點標籤樣式、依描述代碼的符號、由線條代碼建立的曲線（圓弧），以及可在專案之間共用的描述代碼檔案 | 標籤會顯示點號、高程與描述，或顯示更少內容（[CivilCraft設定](topic:settings)）；代碼保留於專案檔案中 |
| 單位換算 | 匯入前先轉換檔案；**單位**僅改變標示 |

## 曲面

| 尚未實作 | 目前可改用的做法 |
|---|---|
| 由點建立多個曲面 | 每個專案一個曲面 |
| 隱藏（內部）邊界 | 使用**最長外緣**或外部邊界 |
| 選取或編輯單一已繪製的斷線 | {{key:Mod+Z}}，或{{ui:Remove drawn breaklines}}後重新繪製 |
| 編輯從LandXML讀取的曲面（斷線、邊界） | {{ui:Rebuild the surface from the points}} |
| 編輯由高程格網建立的曲面 | 以其他選項重新匯入格網 |
| 座標系統變更時，轉換從LandXML讀取的曲面 | 先{{ui:Rebuild the surface from the points}} |
| 帶標註的點高程與坡度值 | 在狀態列中讀取，或在景觀工作區使用**坡度分析**依坡度為曲面上色（[景觀整地](topic:landscape-grading#grading-checks)） |

## 路線與縱斷面

| 尚未實作 | 目前可改用的做法 |
|---|---|
| 回旋曲線以外的緩和曲線；兩曲線之間的緩和曲線（複合緩和曲線） | 曲線兩端可使用回旋曲線（clothoid）緩和曲線；其他類型在匯入LandXML時會列出名稱並略過 |
| 在其他兩個PI之間插入PI | 重新繪製線形，或重新輸入PI座標 |
| 由物件建立路線、偏移、加寬 | 以PI繪製 |
| 在豎曲線中輸入K | 輸入L（會顯示K） |
| 圓形與不對稱豎曲線 | 僅支援對稱拋物線豎曲線 |
| 每條路線多個設計縱斷面 | 每個變體一條路線 |
| 縮放縱斷面檢視、縱斷面下方的縱斷面帶 | 縱斷面檢視會符合整條路線的範圍；請將其列印於[平面與縱斷面圖紙](topic:plan-profile-sheets) |
| DWG或LandXML中的橫斷面 | 橫斷面圖紙以PDF輸出；面積與體積的{{ui:CSV}}檔案 |
| 斜向取樣線，或沿道路寬度不同的取樣線 | 整條路線每側各使用一個寬度 |

## 廊道

| 尚未實作 | 目前可改用的做法 |
|---|---|
| 中央分隔島、護欄，以及會旋轉標準斷面的超高 | 以標準斷面繪製（[廊道標準斷面](topic:corridor-templates)）；依樁號設定的標準斷面尚未支援超高 |
| 兩個區段標準斷面之間的漸變（過渡段、漸縮段） | 在某樁號變更標準斷面，或對繪製為漸縮段的線設定某點的寬度目標 |
| 繞邊緣旋轉、LandXML中的超高 | 超高會在圓曲線上繞中心線旋轉；若要加寬車道，請對特徵線設定寬度目標 |
| 邊坡的目標（坡腳線至線條或曲面）、廊道自有曲面 | 目標會移動路面與路肩邊緣（[廊道](topic:corridor)）；廊道會整地至設計曲面 |
| 以LandXML道路匯出廊道；IFC匯出中同一路線上的第二個廊道 | 匯出設計曲面 |
| 會改變設計曲面的地形標準斷面（於3D或橫斷面中） | 它們會提供每一層的面積與體積（[地形標準斷面](topic:corridor-templates#terrain-templates)） |
| 含速度、輪胎滑移、轉向時間、轉向拖車或車身淨空的迴轉軌跡；標準設計車輛程式庫；以拖曳車輛繪製的迴轉軌跡 | 沿特徵線或路線的低速迴轉軌跡，使用自訂車輛尺寸（[車輛迴轉軌跡](topic:swept-paths)） |

## 整地與土方

| 尚未實作 | 目前可改用的做法 |
|---|---|
| 階台（bench）、整地至設計的開放特徵線、整地至其他地方的特徵線 | 將特徵線封閉（[特徵線](topic:feature-lines)），或將其作為現況地面的斷線使用 |
| 在特徵線中插入或移除頂點 | 重新繪製線條，或為其製作階梯式偏移 |
| 已繪製斷線中的圓弧（通過測量點）、特徵線中的緩和曲線 | 繪製含圓弧的特徵線，並將其作為現況地面的斷線使用 |
| 依距離、高程或其他曲面整地 | 僅可整地至現況地面（坡腳線） |
| 新增或移除平台角點 | 刪除平台後重新繪製 |
| TIN至TIN（稜柱）體積、選擇格網儲存格大小 | 格網法，儲存格大小由程式選定 |
| 膨脹與收縮、表土、路面厚度 | 自行將係數套用於報告的數值 |
| 免費運距與超運成本、跨不同路線運土、在平面圖上放置的借土場與廢土場 | 含平衡點、已移動土方量與平均運距的土方調配圖 |

## 管網

| 尚未實作 | 目前可改用的做法 |
|---|---|
| 每個專案多於一個管網 | 雨水與污水分為不同專案 |
| 供水管：水質與管齡、以規則控制、其他閥類（流量控制、節流、維持）、以功率給定的泵、取決於壓力的用水量、Darcy–Weisbach選項、含管壁厚度與壓力等級的管材目錄。其餘壓力管網功能仍在實驗中：[供水管](topic:water-mains) | 請在供水分析軟體中檢查；污水設計流量見[污水設計流量](topic:sanitary-design) |
| 隨時間變化的污水流量（流量歷時曲線、動態演算、儲存、泵、溢流） | [污水設計流量](topic:sanitary-design)提供設計圖表所用的穩定尖峰流量 |
| 進水口容量、側溝水流寬度、滯洪演算、流量歷時曲線、除一個接合點係數以外的能量損失 | 請在其他軟體中檢查；流量、尺寸與水力坡降線見[雨水排水](topic:storm-drainage) |
| PDF出圖、DWG、DXF或LandXML中的集水區；由曲面產生的集水區（分水嶺） | 手動繪製集水區；其會保存於專案檔案中 |
| 管材目錄、非圓形管、非直立箱形或圓柱形的結構物（錐形、踏步、階梯基座）、程式庫中的排水類別 | 由參數建立的結構物類型（[管網](topic:pipe-network)）；具直徑的管線 |
| 縱斷面檢視中的管線、彎曲管線 | 在右側面板中讀取管底與覆土深度 |

| 雲端儲存與版本紀錄 | 儲存`.civilcraft.json`檔案並備份；如需與他人共同編輯同一專案，請使用CadCraft Studio的即時協作（[即時共同設計一處工地](topic:work-live)） |
| 適用於iPad與iPhone的CadCraft Studio，以及來自Google Play的版本 | 在裝置上使用瀏覽器中的CivilCraft；在Android上，CadCraft Studio可從getcadcraft.com/download取得APK安裝 |
| 同時開啟多個點檔或專案檔 | 每次開啟一個檔案（相互關聯的GIS檔案，例如shapefile的各部分，會一併開啟） |

## 景觀

| 尚未實作 | 目前可改用的做法 |
|---|---|
| 製造商的噴頭與噴嘴 | 一般噴頭，或由檔案加入自訂噴頭；製造商的資料會在其同意後加入 |
| 滴灌管的最大側管長度、隨時間變化的流量、泵、環狀管網 | 滴灌管段應依製造商公布的長度；此檢查需要分支式管網 |
| 凹面自由形物件的精確外框；其地下體積的精確量測 | 以凸包整地，地下體積為估算值（於內容中說明） |
| BimCraft與ModelCraft自有的「從程式庫放置」中的植物 | 匯出景觀IFC，並在BimCraft中與建築物並列開啟 |
| 3D檢視中的詳細植物模型（葉、枝、四季）；3D檢視中的自由形物件與灌溉 | 植物在3D中以依植物清單尺寸設定的簡化形狀顯示（[在3D中檢視基地](topic:site-3d)）；ModelCraft的散佈功能可製作種植示意圖 |
| 在曲面上擋住後方整地高程的硬質擋土牆 | 為平台或平台加上垂直邊：它們會成為曲面上的擋土牆（[整地](topic:grading)） |
| 自訂符號中的SVG變形；自有GLB植物模型的材質與顏色；壓縮的GLB幾何 | 先在繪圖程式中展開變形；模型以植物顏色繪製；匯出GLB時不壓縮（[植物圖形](topic:plant-graphics)） |
| 保存於程式庫帳戶中的自有植物清單（於應用程式內編輯） | 在植物表中編輯專案自有的清單，並儲存為植物檔 |
| 無視窗的助理所用景觀工具（檔案伺服器與指令列） | 需開啟CivilCraft視窗才能使用（[讓AI助理處理基地](topic:assistants)） |

## 電力線

| 尚未實作 | 目前可改用的做法 |
|---|---|
| 內建國家標準（載重組合、淨空、係數） | 在{{ui:Load cases and limits…}}中設定標準值並儲存，連同程式庫一併存為套件以便重複使用與分享（[套件](topic:sag-and-tension#packs-rules-and-a-library-for-a-country)） |
| 導線到樹冠或線路旁牆面的水平距離 | 對線路下方穿越的植物與牆面，直向上的淨空（[電力線檢查](topic:power-line-checks#clearances)） |
| 導線潛變與新導線的伸長 | 透過架設表中的溫度加以考量 |
| 地下電纜的熱額定（依敷設方式的電流額定） | 在電纜項目上輸入供應商的電流額定 |
| 短路、保護與接地研究 | 使用專用電氣軟體；CivilCraft提供網路的長度與電纜 |
| 逐桿設計的格構式鐵塔，以及土壤中的拉線錨碇 | 支撐物依其標稱載重檢查；拉線依其額定載重檢查 |
| 在讀取該檔案的程式中檢查`.DON`研究檔 | 請在該程式中檢查檔案；寄送範例供測試，以便用實際檔案比對 |
| 3D檢視與IFC中的電力線 | 平面圖、線路縱斷面、圖紙與GIS圖層 |
| 無視窗的助理所用電力線工具 | 需開啟CivilCraft視窗才能使用（[讓AI助理處理基地](topic:assistants)） |

## GIS與座標系統

| 尚未實作 | 目前可改用的做法 |
|---|---|
| 檔案式地理資料庫（File Geodatabase）；KML樣式、圖示、地面疊加與網路連結 | 先轉換為GeoPackage、shapefile或GeoJSON；KML標記點會在無樣式的情況下讀取 |
| 編輯GIS要素或其屬性 | 在GIS程式中編輯後重新匯入。分析面板會建立新圖層（緩衝、疊合、連接、選取），並新增面積與長度欄位，但不會就地編輯要素 |
| 網路與點陣分析、平頭或方頭端點的緩衝與單側緩衝、在屬性表中新增或刪除列以及變更欄位型別、手動分類顏色、列印圖中的樣式圖例 | 使用選取工具挑選要素並由其建立圖層；不提供平頭端點。依屬性上色與屬性表已可使用：請見[依屬性設定圖層樣式](topic:gis-symbology)與[使用圖層屬性表](topic:gis-table) |
| 標籤樣式（大小、位置）與避免彼此重疊的標籤 | 標籤大小一致，要素密集時可能重疊 |
| 垂直基準與大地水準面模型 | 高程依檔案提供的數值使用；請自行檢查垂直基準 |
| 除依地區建議的NAD27至NAD83以外的格網位移（OSTN15；加入檔案後可用於其他基準的NTv2）、同時使用多個格網、垂直格網 | 自行為所用基準加入格網檔；每個專案一個格網 |
| DXF或3D匯出中的地圖圖層 | 地圖圖層會輸出至PDF出圖，並以圖片形式置於DWG旁 |
| 需登入、金鑰或權杖的地圖伺服器 | 使用公開服務，或使用經地理參照的影像檔 |
| 由曲面、地面模型或高程格網與LiDAR工具寫出LAS或LAZ檔 | 將曲面匯出為GeoTIFF高程格網。[點雲](topic:point-clouds)外掛可將清理過的點雲寫為LAS 1.4或LAZ |
| LiDAR強度、顏色與回波；多波段高程格網；超過200 MB的格網或LiDAR檔 | LiDAR僅依類別篩選，格網使用第一個波段；請先將大型檔案切割成圖塊 |

## 輸入

| 尚未實作 | 目前可改用的做法 |
|---|---|
| 以觸控進行框選（需要Shift） | 長按每個測量點以加入 |
| 繪製時輸入座標或距離 | 先大致繪製，再於路線的PI表中輸入精確的PI座標 |
| 輸入平台角點與結構物的座標 | 拖曳其夾點；放大以求精確，並在狀態列中觀察E與N |
| 物件鎖點（斷線用的測量點除外） | 放大並在狀態列中觀察 |

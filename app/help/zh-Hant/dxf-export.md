{{ui:DXF}} 會將平面圖所顯示的內容寫成 R12 格式的 DXF 檔案，這是每個 CAD 程式都能開啟的版本。若你用過 AutoCAD 或 Civil 3D，開啟或插入此檔案的方式與其他 DXF 相同。

## 匯出

1. 依你想要的圖形樣式設定平面圖：在 **顯示** 下，選擇曲面（原地面或設計面）、等高線間距，以及要開啟的項目（等高線、標註、點、點標註、三角形、斷線、曲面邊緣、管線、坡度箭頭）。
2. 在 **匯出** 群組中按一下 {{ui:DWG/DXF}}，選取 {{ui:DXF（R12，文字）— 單純的交換檔案}}，然後按 {{ui:下載}}。
3. 瀏覽器會下載 `<name>.dxf`。狀態列會顯示例如「已匯出 R12 DXF：2,140 個物件；標註大小依 1" = 40' 設定。不匯出高程帶。」

座標以專案單位寫入，為實際數值（州平面座標保持原樣）。不會縮放或移動任何內容。

## 檔案內容

| 項目 | DXF 實體 | 圖層 |
|---|---|---|
| 次要與主要等高線 | 依高程的 2D 聚合線 | C-TOPO-MINR, C-TOPO-MAJR |
| 等高線標註 | 文字 | C-TOPO-TEXT |
| 三角形 | 聚合線 | C-TOPO-TINN |
| 斷線與邊界 | 3D 聚合線 | C-TOPO-BRKL |
| 曲面邊緣 | 聚合線 | C-TOPO-BNDY |
| 坡度箭頭 | 聚合線 | C-TOPO-SLOP |
| 測量點及其標註 | 點（含高程）、文字 | V-NODE, V-NODE-TEXT |
| 由線碼產生的線 | 3D 聚合線 | V-NODE-LINE |
| 路線中心線 | 直線與圓弧 | C-ROAD-CNTR |
| 樁號刻度與標註 | 聚合線、文字 | C-ROAD-STAN |
| 道路模型邊緣 | 聚合線 | C-ROAD-CORR |
| 取樣線 | 聚合線 | C-ROAD-SCTN |
| 平台、坡腳線、邊坡線 | 聚合線 | C-GRAD-PADS, C-GRAD-DAYL, C-GRAD-SLOP |
| 特徵線 | 3D 聚合線（圓弧以誤差 0.01 內的小段表示；見[特徵線](topic:feature-lines)） | C-GRAD-FEAT |
| 迴轉軌跡 | 聚合線、文字 | C-ROAD-SWPT |
| 管線、構造物、標註 | 聚合線、文字 | C-STRM-PIPE, C-STRM-STRC, C-STRM-TEXT |
| 有問題的管線與構造物 | 聚合線 | C-STRM-PROB |

每個圖層都有顏色。完整清單見[平面圖圖層](topic:plan-layers)。

## 標註大小

文字必須在圖形單位中有大小。CivilCraft 會依整張平面圖恰好放進 Tabloid 紙張（英尺）或 A3 紙張（公尺）的比例設定標註大小，並在狀態訊息中說明使用的比例。若你在 CAD 程式中以其他比例列印，請在該程式中縮放文字。

## 不匯出的內容

- 高程帶（僅限螢幕顯示）。
- 縱斷面視圖。縱斷面以 LandXML 匯出，而非圖形。
- 曲面本身作為 3D 物件。若要取得 TIN，請使用 LandXML，或開啟 {{ui:三角形}} 以取得其邊線。
- 在 **顯示** 下關閉的任何項目。

## DWG

{{ui:DWG/DXF}} 也會將相同的線條寫成 DWG 圖形。其對話方塊會詢問格式：DXF，或 2000、2004、2007、2010、2013 或 2018 版的 DWG。2000 版幾乎所有新舊 CAD 程式都能開啟；若收件者要求較新的版本，再選擇較新的版本即可。你的選擇會在此瀏覽器中記住。

1. 在 **匯出** 群組中按一下 {{ui:DWG}}。
2. 選取 **格式**，然後按一下 **下載 DWG**。
3. 瀏覽器會下載 `<name>.dwg`。狀態列會說明寫入的內容，例如「已匯出 DWG（2018 格式）：12 條聚合線、40 個標註，分布於 9 層」。

DWG 與 DXF 具有相同的圖層、顏色、等高線（依高程的聚合線）、3D 斷線、標註及點，座標也相同。DWG 無法容納的圖層名稱會被更改，狀態訊息會說明。CivilCraft 以自有程式碼寫入 DWG，因此不會有任何內容離開你的電腦。

### DWG 中的地圖圖層

DWG 圖形無法在內部容納影像：CAD 程式會以位於圖形旁的影像顯示。當地圖圖層顯示時，對話方塊會提供 **將地圖圖層作為圖形旁的影像**。勾選後，下載的會是 `.zip`，內含 `<name>.dwg`、`<name>-map.png`（整張圖形上方的地圖圖層，寬度最多 4,096 像素）以及 `<name>-map.pgw`（其世界檔，供 GIS 程式使用）。圖形會以影像形式顯示在圖層 G-MAP-IMAG 上，位於原處。請將檔案解壓縮至同一資料夾並保持在一起。

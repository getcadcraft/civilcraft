平面圖上的所有內容都屬於某個圖層。名稱遵循常見的土木圖層命名模式（專業、主要分組、次要分組）。本版本的圖層是固定的：無法重新命名、變更顏色或新增自己的圖層。在 DXF 中，每個圖層都有所示的顏色編號；在 PDF 中使用{{ui:圖層顏色}}時，會沿用相同的顏色；選擇{{ui:黑色}}時，所有內容都會以黑色列印。

| C-TOPO-MINR | 次要等高線 | 灰色 (8) | {{ui:等高線}} |
| C-TOPO-MAJR | 主要等高線 | 白色或黑色 (7) | {{ui:等高線}} |
| C-TOPO-TEXT | 等高線標註 | 白色或黑色 (7) | {{ui:等高線}}與{{ui:等高線標註}} |
| C-TOPO-TINN | 三角形邊線 | 灰色 (8) | {{ui:三角形}} |

| C-TOPO-SLOP | 坡向箭頭 | 青色 (4) | {{ui:坡向箭頭}} |
| V-NODE | 測量點 | 綠色 (3) | {{ui:點數}} |

只有在「顯示」下的**曲面**為{{ui:既有地面}}時，才會繪製斷線；兩種曲面都會繪製邊界。

## PDF 中的線寬

| 線寬 | 圖層 |
|---|---|
| 0.50 mm | 路線中心線、平台、管線、有問題的管線 |
| 0.35 mm | 主要等高線、坡腳線、構造物 |
| 0.25 mm | 斷線 |
| 0.13 mm | 次要等高線 |
| 0.09 mm | 三角形邊線、整地坡度線 |
| 0.18 mm | 其他所有圖層 |

DXF 檔案不含線寬；請在 CAD 程式中依圖層設定。

## 標註大小

標註以圖紙上的尺寸定義：等高線標註 2.0 mm、樁號標註 1.8 mm、PC 與 PT 標註以及管線與構造物標註 1.6 mm、點標註 1.5 mm。管線標註顯示名稱、直徑與坡度；構造物標註顯示名稱與井蓋高程。在螢幕上，縮放時標註大小保持不變。在 DXF 中，標註會依匯出訊息中所列的比例縮放；請參閱[將平面圖匯出為 DXF](topic:dxf-export)。

## 不在任何圖層上顯示的內容

高程帶只會在螢幕上繪製於線條下方。縱斷面視圖不屬於平面圖。

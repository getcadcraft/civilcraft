LandXML 是大多數土木軟體都能讀取與寫入的開放交換格式。CivilCraft 可讀取與寫入 LandXML 1.2。若曾使用 Civil 3D，其 LandXML 匯入與匯出對話方塊最為相近；此處無需做任何選擇，註記會說明略過了哪些內容。

## 開啟 LandXML 檔案

1. 點選{{ui:開啟}}（或按下{{key:Mod+O}}），選擇 `.xml` 或 `.landxml` 檔案，或將其拖放到平面上。
2. 若目前的專案有尚未儲存的變更，CivilCraft 會先詢問。選擇{{ui:儲存副本}}、{{ui:不儲存}}或{{ui:取消}}。
3. 會建立**新專案**。狀態列會說明讀取了什麼，例如「已開啟 site.xml：412 個點、2 個曲面、3 條路線」。
4. 查看**曲面**資訊下方的方塊。其中會列出所有被略過或變更的內容，例如：
   - 「只開啟了第一個曲面（"EG"）；檔案中還有 1 個。」
   - 「路線 "Ramp A" 含有 CivilCraft 尚無法繪製的元素（非直線、圓弧或克羅索緩和曲線）；已略過。」
   - 「檔案中沒有管網規則；目前使用預留值，請在專案中設定。」

對應關係：

| 檔案中的內容 | CivilCraft 中的內容 |
|---|---|
| 單位（Imperial 或 Metric） | 專案的**單位**（英尺或公尺） |
| 專案名稱 | 專案的**名稱** |
| CgPoints | 專案的點；描述（或代碼）決定群組 |
| 第一個 TIN 曲面 | 現有地面，原樣使用（「Surface (from LandXML)」） |
| 由直線、圓弧與克羅索緩和曲線組成的所有路線 | 依曲線重建的路線，含其 PI、半徑與緩和段長度 |
| 每條路線的第一個設計縱斷面 | 其設計縱斷面，含拋物線豎曲線 |
| 第一個管網 | 管網，含井蓋、集水井與管底高程 |
| 直線與圓弧的平面特徵 | 保留特徵線與圓弧；來自其他程式時，會以**僅繪製**開始 |

完整的元素與屬性清單請見[LandXML：讀取與寫入的內容](topic:landxml-reference)。

:::note
從 LandXML 讀取的曲面，在你變更點群組或繪製斷線時不會重建。請在**曲面**區段中點選{{ui:依點重建曲面}}，改為從點建立曲面（{{key:Mod+Z}} 可還原 LandXML 曲面）。
:::

## 匯出 LandXML

1. 在**匯出**群組中點選{{ui:LandXML}}。
2. 瀏覽器會下載 `<name>.xml`。狀態列會說明寫入了哪些內容，例如「已匯出 LandXML 1.2：276 個點、2 個曲面、1 條路線、管網。平台不包含在 LandXML 中；整地後的曲面則包含。」

檔案包含：

- **Units**：美國測量英尺或公尺。
- **CgPoints**：每個點，其點號為名稱，其描述為說明，其群組為代碼。
- **Surfaces**：現有地面以 TIN 表示，並以其斷線與外側邊界作為來源資料；若平台或道路走廊進行整地，則另有一個名為「Proposed」的第二個 TIN 曲面。
- **Alignments**：直線、圓弧與克羅索緩和曲線及其樁號；每條路線皆附有一個縱斷面。當路線含有至少兩個 PVI 時，縱斷面包含沿路線取樣的現有地面與設計縱斷面（PVI 與拋物線豎曲線）。
- **PipeNetworks**：構造物及其井蓋、集水井與每條管線的管底高程，以及管線的直徑、長度與坡度。
- **PlanFeatures**：每條特徵線以直線與圓弧表示，並含兩端高程，以及其用途。

## 不會被帶過去的內容

- 作為物件的平台與道路走廊。其結果位於「Proposed」曲面中。
- 有錯誤的路線（例如曲線重疊）：會略過，並計入狀態訊息中。
- 缺少兩端管底的管線，以及少於兩個構造物的網路。
- 取自曲面的井蓋會以固定值寫入。重新開啟後，即使曲面變更，構造物仍保留該數值。
- 網路規則（最小坡度、覆土、落差）：LandXML 沒有存放這些規則的位置。
- 顯示設定與點群組的曲面選擇：這些請儲存為 CivilCraft 專案。

開啟時，CivilCraft 不會讀取克羅索以外的緩和曲線、格網曲面、只參照其他點的點、地籍、平面特徵中的緩和曲線、道路或測量資料。每一項都會在註記中列出，絕不猜測。

## 往返交換

若要將工作交給使用其他土木軟體的人再取回，請匯出 LandXML，讓對方編輯，並將其 LandXML 開啟為新專案。也請保留自己的 `.civilcraft.json`：它是唯一保存 CivilCraft 所有內容的檔案。

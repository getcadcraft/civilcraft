測量隊會在野外為每個測點編碼：`EP` 代表路面邊緣，`TC` 代表路緣頂部，`BLDG` 代表建築物角點。代碼即為點描述的第一個字。CivilCraft 會依代碼將點分群，並將其後的線碼轉為線條。

## 線碼

線碼即緊接在野外代碼之後的字詞：

| 描述 | 意義 |
|---|---|
| `EP B` | 在此點開始新的路面邊緣線 |
| `EP` | 延續目前的 EP 線 |
| `EP E` | 在此點結束目前的 EP 線 |
| `BLDG C` | 封閉建築物：將此點與該線的第一點相連 |

具有相同代碼的點會依點號順序連接。不同的代碼即為不同的線，即使它們共用同一群組也一樣，因此 `EP1` 與 `EP2` 會同時產生兩條邊。未使用線碼的代碼，會如早期版本一樣，將其所有點依序連接。

在作為**斷線**使用的群組中，每條線都會成為一條斷線，因此有缺口的路緣不會橫跨缺口延伸。其他群組中的線會繪製於平面圖上（圖層 V-NODE-LINE），並會匯出至 DXF、DWG 與 PDF。

表示起點、終點與封閉的字詞分別為 `B`、`BEG`、`START`；`E`、`END`；以及 `C`、`CLO`、`CLOSE`。你可以在下方的對話方塊中變更它們，或將線碼關閉。

## 描述代碼

描述代碼會將代碼轉為點群組、用途與完整描述。

1. 在**點**下，按一下{{ui:Description keys and line codes}}。
2. 按一下{{ui:Add a key}}並填寫該列：
   - **代碼**：要比對的野外代碼。`*` 代表任意字元，`?` 代表一個字元，因此 `EP*` 可符合 EP、EP1 與 EP12。
   - **群組**：這些點所加入的點群組（空白 = 代碼本身）。以群組 `EP` 使用 `EP*` 時，EP1 與 EP2 會位於同一群組，但仍為各自獨立的線。
   - **用途**：點、斷線或排除，於群組首次出現時設定（或交由**點數**表格設定）。
   - **描述**：完整名稱，顯示於點的**屬性**中。
3. **點數**欄會在你輸入時統計每個描述代碼所符合的點數。第一個符合某代碼的描述代碼會生效。
4. 按一下{{ui:Apply}}。群組、曲面與平面圖會在一個步驟中一併更新：{{key:Mod+Z}}可將其撤銷。

群組會保留你在**點數**表格中指定的用途；描述代碼的用途僅在群組為新群組時才會設定。描述代碼與線碼會儲存於專案檔中。

工具列位於應用程式頂端，共分為七個群組。每個按鈕在滑鼠停留時都會顯示其提示與快速鍵。

## 檔案

| 按鈕 | 快速鍵 | 功能 |
|---|---|---|
| {{ui:新增}} | 無 | 開啟空白專案。若有尚未儲存的變更，會先詢問。 |
| {{ui:開啟}} | {{key:Mod+O}} | 開啟點位檔案（CSV、TXT）、LandXML 或 CivilCraft 專案。 |
| {{ui:儲存}} | {{key:Mod+S}} | 將專案下載為 `<name>.civilcraft.json`。 |

## 匯出

| 按鈕 | 快速鍵 | 功能 |
|---|---|---|
| {{ui:LandXML}} | 無 | 下載 `<name>.xml`：點、曲面、路線、縱斷面與管線網路，格式為 LandXML 1.2。專案為空時顯示「尚無可匯出的內容。」 |
| {{ui:DXF}} | 無 | 下載 `<name>.dxf`：平面線條，格式為 R12 DXF。 |
| {{ui:PDF}} | {{key:Mod+P}} | 開啟**將平面圖列印為 PDF**。專案為空時顯示「尚無可列印的內容。」 |

## 曲面

| 按鈕 | 快速鍵 | 功能 |
|---|---|---|
| {{ui:斷線}} | {{key:B}} | 依序按一下測量點，按 {{key:Enter}} 結束。斷線會採用這些點的高程。 |
| {{ui:邊界}} | {{key:O}} | 依序按一下外部邊界的角點，按 {{key:Enter}} 結束。會取代既有的邊界。 |

在沒有曲面時，這兩項都會顯示「尚無曲面，須先開啟測量點。」

## 設計

| 按鈕 | 快速鍵 | 功能 |
|---|---|---|
| {{ui:路線}} | {{key:A}} | 依序按一下各 PI，按 {{key:Enter}} 結束。 |
| {{ui:平台}} | {{key:G}} | 按一下平台的角點，按 {{key:Enter}} 結束。與曲面工具相同，沒有曲面時會發出警告；平台只能依曲面整平。 |
| {{ui:管線}} | {{key:P}} | 由上游往下游依序按一下構造物（按一下既有的構造物即可接上），按 {{key:Enter}} 結束。 |
| {{ui:縱斷面}} | {{key:R}} | 顯示或隱藏平面圖下方的縱斷面檢視。 |

## 編輯

| 按鈕 | 快速鍵 | 功能 |
|---|---|---|
| {{ui:復原}} | {{key:Mod+Z}} | 復原上一個變更（最多 200 次）。沒有可復原的內容時呈灰色停用。 |
| {{ui:取消復原}} | {{key:Mod+Y}} | 重做已復原的內容。沒有可重做的內容時呈灰色停用。 |
| {{ui:複製}} | {{key:Mod+C}} | 複製所選測量點，並以試算表可讀取的點列放入剪貼簿。未選取測量點時呈灰色停用。 |
| {{ui:貼上}} | {{key:Mod+V}} | 貼上測量點：它們會跟隨指標移動，按一下即可放下，並使用其他點都沒有的編號。在試算表中複製的點列也可貼上。 |
| {{ui:更多}} | 無 | 開啟下方的功能表。 |

{{ui:更多}} 功能表：

| 項目 | 快速鍵 | 功能 |
|---|---|---|
| {{ui:剪下}} | {{key:Mod+X}} | 複製所選測量點並將其刪除（一個復原步驟）。 |
| {{ui:複製}} | {{key:Mod+C}} | 同 {{ui:複製}} 按鈕。 |
| {{ui:貼上}} | {{key:Mod+V}} | 同 {{ui:貼上}} 按鈕。 |
| {{ui:原位貼上}} | {{key:Mod+Shift+V}} | 將測量點貼在其原本的座標上，並使用其他點都沒有的編號。 |
| {{ui:複製}} | {{key:Mod+D}} | 所選測量點的副本會跟隨指標移動；按一下即可放置。剪貼簿不受影響。 |
| {{ui:刪除}} | {{key:Delete}} | 刪除所選測量點，或所選的路線、平台、構造物（連同其管線）、管線或 PVI。 |
| {{ui:全選測量點}} | {{key:Mod+A}} | 選取所有測量點。 |
| {{ui:取消全部選取}} | {{key:Esc}} | 清除選取。 |

目前無法執行的項目會呈灰色停用，其提示會說明原因。詳情：[選取、複製與貼上測量點](topic:copy-paste-points)。

復原涵蓋設計、曲面設定與測量點的編輯（貼上、剪下、複製、刪除）。不涵蓋顯示設定；開啟或匯入任何檔案都會清除復原紀錄。

## GIS

| 按鈕 | 快速鍵 | 功能 |
|---|---|---|
| {{ui:座標}} | 無 | 開啟**座標系統**對話方塊：指定專案所用的系統，或使用地面或本地座標。請見[設定專案座標系統](topic:coordinate-systems)與[地面與本地座標](topic:ground-and-local-coordinates)。 |
| {{ui:匯入}} | 無 | 匯入 GIS 資料：shapefile、GeoJSON、GeoPackage、高程格網與 LiDAR。請見[匯入 GIS 資料](topic:gis-import)。 |
| {{ui:匯出}} | 無 | 為 GIS 部門匯出竣工資料。請見[為 GIS 匯出竣工資料](topic:gis-export)。 |
| {{ui:分析}} | 無 | 開啟 GIS 分析面板：緩衝區、疊圖、空間連接、依屬性選取、量測。請見[分析 GIS 圖層](topic:gis-analysis)。 |
| {{ui:屬性表}} | 無 | 位於曲面 › 更多中。開啟 GIS 圖層的屬性表：排序、篩選、選取、編輯、新增欄位、計算、另存新檔為 CSV。請見[處理圖層的屬性表](topic:gis-table)。 |
| {{ui:地圖}} | 無 | 開啟**地圖圖層**對話方塊：可加入經地理參照的圖片或地圖伺服器，繪製於平面圖下方。請見[在平面圖下顯示地圖圖層](topic:map-layers)。 |

第一次使用這些按鈕時、開啟 GIS 檔案時，或開啟具有座標系統或 GIS 圖層的專案時，GIS 工具才會載入。

## 檢視

| 按鈕 | 快速鍵 | 功能 |
|---|---|---|
| {{ui:選取}} | {{key:V}} 或 {{key:Esc}} | 按一下以選取路線、平台、構造物、管線與點（按住 {{key:Shift}} 並按一下或拖曳可加選點）；拖曳夾點可移動 PI、平台角點與構造物。 |
| {{ui:符合}} | {{key:F}} | 縮放平面圖，以顯示曲面、測量點、路線與平台（在 3D 檢視中：顯示全部）。 |
| {{ui:3D}} | {{key:D}} | 在平面圖上以 3D 顯示場地，或返回平面圖。3D 檢視上方的工具列可設定視角、誇張比例、著色與顯示內容，並可匯出 GLB 或 OBJ。請見[以 3D 檢視場址](topic:site-3d)。 |

## 面板中的按鈕

| 按鈕 | 位置 | 功能 |
|---|---|---|
| {{ui:開啟範例場地}} | 空白平面圖上的方框 | 載入範例測量資料（需要連線，除非 CivilCraft 已儲存為可離線使用） |
| {{ui:移除邊界}} | 左側面板，曲面 | 移除外部邊界 |
| {{ui:移除已繪製的斷線}} | 左側面板，曲面 | 移除所有以此工具繪製的斷線（不包括斷線群組） |
| {{ui:依點重建曲面}} | 左側面板，曲面（僅限 LandXML 曲面） | 捨棄 LandXML TIN，並依點重新建立；無法復原 |
| {{ui:自地面開始}} | 右側面板，路線 | 在每一端的地面上建立含 PVI 的設計縱斷面 |
| {{ui:縱斷面檢視}} | 右側面板，路線 | 開啟此路線的縱斷面檢視 |
| {{ui:加入 PVI}} | 縱斷面工具列 | 按下期間，在縱斷面中按一下即可加入 PVI |
| {{ui:依規則設定每個管底高程}} | 右側面板，管線網路 | 依規則設定每條管線的管底高程 |
| {{ui:依規則設定其管底高程}} | 右側面板，管線 | 依規則設定此管線的管底高程 |

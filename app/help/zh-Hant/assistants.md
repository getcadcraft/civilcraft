## 學習內容

如何讓 AI 助理（任何支援 MCP 的助理）與你開啟的基地協作、它能做與不能做的事，以及如何停止。

## 助理在 CivilCraft 中能做什麼

| 助理要求 | 取得內容 | 所需權限 |
|---|---|---|
| 基地 | 名稱、單位、座標系統、點群組、路線、曲面、平台、地籍與管線 | 讀取 |
| 測量點 | 點號、東座標、北座標、高程與描述，依群組、依描述或範圍框內篩選 | 讀取 |
| 曲面高程 | 其指定各點上的既有地面（或整地後曲面）高程 | 讀取 |
| 樁號與偏距 | 點沿路線的樁號與偏距，或樁號的座標與地面高程 | 讀取 |
| 縱斷面 | 沿路線每隔指定的英尺或公尺數，取得地面、設計縱斷面與整地曲面的高程 | 讀取 |
| 挖方與填方 | 既有地面與整地曲面之間的土方量（每個平台與道路模型亦同），或地面與某一水平面之間的土方量 | 讀取 |
| 地籍 | 角點、面積（可用英畝或公頃）、周長與法定描述 | 讀取 |
| 選取 | 其指定的點會在平面上被選取，如同你手動選取一般 | 編輯 |
| 新測量點 | 以其指定的點號新增，或使用下一個可用點號。每次呼叫為一個可復原的步驟 | 編輯 |
| 儲存 | CivilCraft 自身的{{ui:儲存}} | 儲存 |
| LandXML 或 DWG | 與{{ui:LandXML}}及{{ui:DWG}}按鈕相同的檔案 | 匯出 |
| 3D 基地 | 地面、整地曲面、平台與管線的 OpenUSD（.usdz、.usda 或 .usdc），與 3D 檢視匯出的內容相同 | 匯出 |
| 植栽與植栽明細 | 依任何名稱在植栽清單中找到的植栽，以及植栽明細表的數量 | 讀取 |
| 植栽與整地 | 放置植栽、花床或樹籬，或新增平台、土堤、排水溝或整地區，每項皆為一個可復原的步驟，並含其挖填方 | 編輯 |
| 灌溉檢查 | 每個區域的流量、其閥門與供水端所需的壓力、最不利水頭、運轉時間、問題與材料清單，作為供灌溉設計師查核的計算輔助 | 讀取 |

助理只會作用於已開啟的基地。在 Studio 中，它也可以儲存並匯出到你選擇的資料夾（見下文）；若未設定資料夾，其檔案會如按鈕一般下載。

## 開啟方式

助理需透過你電腦上的 CadCraft Studio 連線至 CivilCraft；一般瀏覽器無法連線。

1. 開啟{{ui:設定}}，並選擇**CivilCraft**索引標籤。
2. 在**助理**下，勾選**允許 AI 助理與指令稿使用 CivilCraft**。
3. **讀取**已為你勾選。只有在助理需要時，才勾選**編輯**、**儲存**或**匯出**。
4. 若要讓它儲存並匯出至某資料夾，請在**允許使用的資料夾**下選擇{{ui:新增資料夾…}}，並在 Studio 的對話方塊中選取該資料夾。{{ui:移除}}可立即收回；其他任何路徑都會被拒絕。
5. 在 Studio 中連線助理（Studio 會顯示位址與需貼入助理的設定）。

## 助理連線期間

右側面板頂端的註記會顯示已連線的助理及其可執行的操作。按一下{{ui:中斷連線}}可立即結束其工作階段；若要繼續，它必須重新連線。

在設定的**助理**下，**活動**會列出助理的每一次呼叫，最新的在前，並標示是否成功。

:::tip
請用平實的語句提問，例如「沿 Main Street 每 50 英尺的地面高程是多少？」、「平台需要多少挖方與填方？」或「依這些座標新增一個控制點」。助理會讀取基地並回覆，或將變更作為一個可復原的步驟執行。
:::

## 不開啟 CivilCraft 時

供助理使用的 CadCraft 檔案伺服器（`npx @getcadcraft/mcp`）與 `cadcraft` 命令列，會使用 CivilCraft 自身的程式碼開啟已儲存的 CivilCraft 專案（`.civilcraft.json`）與點檔，無需開啟視窗：提供相同的讀取工具、新增點、儲存專案、LandXML，以及 OpenUSD 格式的 3D 基地。`cadcraft convert site.civilcraft.json site.xml` 可由命令列寫出 LandXML。開啟 LandXML、DWG 匯出與景觀工作區的工具，仍需要 CivilCraft 視窗。

## 關閉方式

取消勾選**允許 AI 助理與指令稿使用 CivilCraft**。所有助理會立即中斷連線，此設定會保留至下次使用。

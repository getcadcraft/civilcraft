CivilCraft 沒有設定對話方塊或範本。以下是事物開始時所使用的值。標記為**佔位**的值並非取自任何標準：在依賴檢查或數量之前，請以你的專案準則取代它們。

## 新專案

| 設定 | 值 |
|---|---|
| 名稱 | 未命名場地（第一個點檔的名稱會取代它） |
| 單位 | 美國英尺 |
| 曲面名稱 | 既有地面 |
| 點群組 | 每個群組一開始都是{{ui:Points}} |
| 最長外緣邊 | 0（保留每個三角形） |
| 保留的復原步驟數 | 200 |

## 顯示

| 設定 | 值 |
|---|---|
| 曲面 | {{ui:Existing ground}} |
| 等高線間距 | 1（ft 或 m） |
| 主等高線間距 | 第 5 條等高線 |
| 色帶數 | 8 |
| 開啟 | 等高線、等高線標註、點、斷線、曲面邊界、管線 |
| 關閉 | 三角形、高程色帶、坡向箭頭、點標註 |

## 路線與縱斷面

| 設定 | 值 |
|---|---|
| 名稱 | 路線 1、路線 2 … |
| 起始樁號 | 0+00 |
| 每個內部 PI 的曲線半徑 | 100 ft 或 30 m，若無法放入每段切線的一半則取較小值 |
| 設計縱斷面 | 在你開始建立之前為無；{{ui:Start from the ground}}會在每一端於地面上放置一個 PVI |
| 豎曲線長度 | 0（無曲線），直到你輸入為止 |

## 平台

| 設定 | 值 |
|---|---|
| 名稱 | 平台 1、平台 2 … |
| 高程 | 平台中心處的地面高程，四捨五入至 0.1（若中心位於曲面之外則為 0） |
| 挖方坡度 | 2 : 1（佔位） |
| 填方坡度 | 3 : 1（佔位） |

## 道路模型組合（佔位）

| 設定 | 美國英尺 | 公尺 |
|---|---|---|
| 車道寬度 | 12 ft | 3.6 m |
| 車道坡度 | 2% | 2% |
| 路肩寬度 | 4 ft | 1.2 m |
| 路肩坡度 | 4% | 4% |
| 挖方坡度 | 2 : 1 | 2 : 1 |
| 填方坡度 | 3 : 1 | 3 : 1 |
| 斷面間距 | 10 ft | 5 m |

## 管線網路

| 設定 | 美國英尺 | 公尺 |
|---|---|---|
| 名稱與類型 | 雨水、雨水 | 雨水、雨水 |
| 最小坡度（佔位） | 0.50% | 0.50% |
| 最小覆土（佔位） | 2 ft | 0.6 m |
| 結構物落差（佔位） | 0.10 ft | 0.03 m |
| 新結構物直徑 | 48 in | 1200 mm |
| 新管直徑 | 12 in | 300 mm |
| 集水井深度 | 0 | 0 |
| 井蓋 | 取自曲面 | 取自曲面 |

從 LandXML 開啟的管線網路同樣採用這些規則，因為 LandXML 並不記錄這些規則。

## 土方

| 設定 | 值 |
|---|---|
| 方法 | 格網，於挖填邊界內的格網中心取樣 |
| 格網大小 | 選擇使挖填面積的外接矩形約容納 250,000 個格網（1、2 或 5 乘以 10 的冪次） |
| 膨脹與收縮 | 無 |

## 出圖

| 設定 | 值 |
|---|---|
| 範圍 | {{ui:Everything}} |
| 圖紙 | Tabloid 11 × 17 in（英尺制專案）、ISO A3（公尺制專案）；一律為橫向 |
| 比例 | 列出的最大比例中，能容納全部內容者 |
| 墨色 | {{ui:Layer colors}} |

DXF 的標註大小，依全部內容能容納於 Tabloid（英尺制）或 A3（公尺制）的比例設定。

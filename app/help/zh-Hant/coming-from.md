如果你用過 Civil 3D，就已經了解 CivilCraft 的概念：點與點群組、含斷線與邊界的 TIN 曲面、以交點定義的路線、以 PVI 定義的縱斷面、掃掠成道路模型的斷面組合、整地至坡腳線、重力式管線網路、LandXML。不同之處在於其周邊的幾乎一切：沒有圖面檔案、沒有指令列（除非你選擇{{ui:經典繪圖}}功能表樣式）、沒有樣式、沒有 Prospector，也沒有設定對話方塊。CivilCraft 是一個在瀏覽器中運作、功能精簡的小型工具，在此版本中只涵蓋完整土木套件功能的一小部分。本頁將你已知的內容對應到此處的功能。

:::tip
若你喜歡 Civil 3D 的功能區，請在{{ui:設定}} › {{ui:CivilCraft}} › {{ui:功能表、快速鍵與滑鼠}}中選擇{{ui:土木功能區}}功能表樣式：包括首頁、曲面、修改、地理定位、檢視與輸出等索引標籤，中鍵可平移，按住{{key:Shift}}加中鍵可環繞 3D 檢視旋轉。若你習慣輸入指令，{{ui:經典繪圖}}會加入指令列（ALIGNMENT、PAD、PROFILE、ZOOM …）。請參閱[功能表、快速鍵與滑鼠](topic:menus-keys-and-mouse)。
:::

## 工作流程對照

| 你想做的事 | 熟悉的做法 | 在 CivilCraft 中 |
|---|---|---|
| 匯入測量點 | 以點檔格式匯入點 | 以{{ui:開啟}}開啟，然後在**匯入點**中檢查欄位順序（[匯入測量點](topic:import-points)） |
| 整理點 | 點群組、描述代碼 | 依描述的第一個詞自動分組；沒有描述代碼 |
| 編輯點 | 點編輯器、夾點 | 按一下後在**屬性**中輸入，或直接拖曳（[編輯測量點](topic:edit-points)） |
| 建立既有地面 | 建立曲面，將點群組加入為資料 | 自動：只要輸入變更，曲面便會重建 |
| 新增斷線 | 由聚合線或特徵線新增斷線 | 將點群組設為{{ui:斷線}}，或以{{ui:斷線}}工具按一下點（{{key:B}}） |
| 修剪曲面 | 外部邊界、隱藏邊界、最大三角形邊長 | {{ui:邊界}}（{{key:O}}，僅外部）與**最長外緣邊** |
| 顯示等高線 | 曲面樣式 | 左側面板中的**顯示**：間距、主要間隔、標註、色帶、坡向箭頭 |
| 配置中心線 | 路線建立工具、曲線與緩和曲線設定 | {{ui:路線}}（{{key:A}}）：按一下交點，按{{key:Enter}}；半徑與緩和曲線長度在交點表中設定 |
| 建立縱斷面檢視 | 縱斷面檢視精靈、色帶 | {{ui:縱斷面}}（{{key:R}}）：平面下方一個縱斷面檢視，永遠符合視窗 |
| 設計坡度 | 縱斷面配置工具 | {{ui:自地面開始}}、{{ui:加入 PVI}}（{{key:I}}）、拖曳 PVI，並輸入**曲線 L** |
| 建造道路 | 斷面組合、子斷面、道路模型、目標、區域 | 在路線下勾選**沿設計縱斷面掃掠斷面組合**；每側一條車道、路肩與邊坡，或由組件（排水溝、路緣、人行道……）組成每一側 |
| 整平平台 | 特徵線、整地群組、整地準則 | {{ui:平台}}（{{key:G}}）：平坦的平台，其挖方與填方坡面延伸至坡腳線 |
| 計算土方 | 體積曲面、體積儀表板 | 右側面板中的**土方**，採格網法，即時更新 |
| 配置雨水或污水 | 含零件清單與規則的管線網路 | {{ui:管線}}（{{key:P}}）：依水流方向依序按一下構造物；三項由你設定的規則；自動計算管底高程 |
| 與他人交換 | LandXML 匯入與匯出 | 以{{ui:開啟}}開啟 LandXML 檔案；按{{ui:LandXML}}匯出（[交換 LandXML](topic:landxml)） |
| 將線稿送至 CAD | 匯出為 DWG | {{ui:DWG}}（2000 至 2018 格式）或{{ui:DXF}}（R12） |
| 列印 | 配置、視埠、圖紙集 | {{ui:PDF}}：以所選比例輸出平面的一張橫向圖紙；平面與縱斷面圖紙及斷面圖紙皆可輸出為 PDF |
| 在檔案之間共用工作 | 資料捷徑、參考 | 目前尚未實作：每個檔案一個專案 |
| 復原 | 復原 | {{key:Mod+Z}}與{{key:Mod+Y}}，共 200 步；顯示設定不屬於復原步驟 |

## 容易造成困擾的差異

**沒有指令列**，除非你選擇{{ui:經典繪圖}}功能表樣式。工具為工具列按鈕與單一字母鍵：{{key:A}} 路線、{{key:G}} 平台、{{key:P}} 管線、{{key:B}} 斷線、{{key:O}} 邊界、{{key:R}} 縱斷面、{{key:I}} 加入 PVI、{{key:V}} 選取、{{key:F}} 符合視窗。在其他功能表樣式中，輸入指令名稱不會有任何作用。請參閱[快速鍵與滑鼠](topic:keyboard)。

**按{{key:Enter}}完成；連按兩下有風險。**請按一下最後一點，再按{{key:Enter}}。在此版本中，連按兩下也會完成，但會捨去你連按兩下的那一點。按滑鼠右鍵不會完成或重複指令；只有按住拖曳時才會平移。

**一切隨時都是動態的。**變更點群組、半徑、PVI 或平台坡度，曲面、等高線、道路模型、坡腳線與土方量都會立即更新。沒有需要重建的內容，也不會有過期的部分。

**沒有任何內容是圖面物件。**平面只是設計的檢視，而非可用 CAD 指令編輯的圖面。你無法新增自己的線條或文字、變更圖層顏色，或分解任何物件。請匯出為 DXF，並在 CAD 程式中完成圖面。

**沒有樣式。**顏色、線寬、標註文字大小與圖層名稱皆為固定（請參閱[平面圖層](topic:plan-layers)）。應用程式列中的「圖紙」與「模型」可在淺色與深色畫面之間切換。

**每樣各一個。**每個專案一個既有地面曲面、一個整地結果、一個管線網路。路線與平台則可以有很多個。

**單位只是標示。**選擇{{ui:美國英尺}}或{{ui:公尺}}不會進行任何換算。沒有圖面比例。座標系統為選用：在{{ui:座標}}下設定後，不會有任何移動，它只說明數字的意義（請參閱[設定專案的座標系統](topic:coordinate-systems)）。寫入 LandXML 時，英尺會被視為美國測量英尺。

**斷線群組依點號順序連接。**設為{{ui:斷線}}的群組會成為通過其所有點的一條線，依點號排序。共用代碼（兩條水流線皆編碼為「FL」）會形成一條鋸齒線；這類線請手動繪製。

**樁號外觀相同，公尺則不同。**英尺以 100 ft 為一樁號（12+34.56）；公尺以 1000 m 為一樁號（1+234.567）。

**Mac 上的刪除。**在 Mac 上，標示為 delete 的鍵在瀏覽器中相當於{{key:Backspace}}。若要刪除選取項目，請使用 Fn 加 delete，或{{ui:刪除}}按鈕。

**檔案即下載。**每次按{{ui:儲存}}都會下載一個 `.civilcraft.json` 檔案；沒有「覆寫已開啟的檔案」的選項。未儲存工作的復原複本會保留在此瀏覽器中（[復原尚未儲存的內容](common:recover)）。開啟點檔會直接取代現有的點，不會詢問。請參閱[可開啟、儲存與匯出的檔案](topic:files)。

**規則由你決定。**管線網路規則與道路模型的斷面組合，起始值僅為佔位值，並非任何標準。在採信任何檢查結果之前，請先設定你自己的規則。

**土方量以格網為基礎。**挖方與填方來自兩個曲面之間、坡腳線以內的細密格網，不計膨脹或收縮。結果接近但不等同於 TIN 對 TIN 的體積。

CivilCraft 每個專案只有一個既有地面曲面。它是由你的點建立的 TIN（三角不規則網），每當輸入變更時會自動重建。沒有「重建」指令，也不會有過期的曲面。

## 曲面包含的內容

- 所有位於設為{{ui:點數}}的群組中、且具有高程的點。
- 所有設為{{ui:斷線}}的群組，依點號順序連接。
- 你以{{ui:斷線}}工具繪製的每一條斷線。
- 外部邊界（若你有繪製）。
- **最長外緣邊**設定。

三角形絕不跨越斷線：曲面會被強制沿斷線生成，並在其周圍盡量均勻（其他地方採用 Delaunay 三角剖分）。

## 將編碼線轉為斷線

1. 在左側面板的**點數**下找到該群組（例如 FL）。
2. 將其**曲面**選項設為{{ui:斷線}}。
   曲面會重建，該線會以橘色繪出（需在**顯示**下開啟{{ui:斷線}}），且曲面資訊中的**斷線**數量會增加一。
3. 在平面上檢查該線。它必須依測設順序逐點連接。若呈鋸齒狀，表示該群組含有一條以上的線，或點號不是依序編號：請將群組改回{{ui:點數}}，並以手動方式繪製（見下一節）。

## 沿點繪製斷線

1. 按下{{key:B}}，或按一下**曲面**群組中的{{ui:斷線}}。
   提示文字為「斷線：依序按一下測量點（會取用其高程）。按Enter鍵結束。」
2. 將指標移到某點附近，會出現一個小橘色方塊，標示將被取用的點。
3. 依序按一下線上的各點。每次按一下，狀態列都會顯示該點的名稱與其高程。
4. 按{{key:Enter}}結束。
   狀態列會顯示「已新增斷線 1，曲面已重建。」

按一下必須落在具有高程的測量點上；點在其他位置會被拒絕，並顯示「請按一下具有高程的測量點：斷線會取用各點的高程。」{{key:Backspace}}會捨去最後一點；{{key:Esc}}會取消整條線。

:::warning
按{{key:Enter}}結束。連按兩下也會結束，但在此版本中會捨去你連按兩下的那一點。請先按一下最後一點，再按{{key:Enter}}。
:::

若要一次移除所有已繪製的斷線，請在**曲面**區段中按一下{{ui:移除已繪製的斷線}}。若只想移除最後一條，請使用{{key:Mod+Z}}。已繪製的斷線目前尚無法逐條選取或編輯。

## 繪製外部邊界

邊界會將曲面修剪至你信賴的範圍內，例如測量範圍，使跨越未測量角落的長三角形得以移除。

1. 按下{{key:O}}，或按一下{{ui:邊界}}。
2. 依序沿範圍周圍按一下各角點。虛線會顯示形狀。
3. 按{{key:Enter}}。
   狀態列會顯示「已設定邊界；邊界外的三角形已移除。」曲面資訊中的**邊界**會顯示「是」及角點數量。

注意事項：

- 只能有一個邊界；繪製新邊界會取代舊邊界。{{ui:移除邊界}}可將其移除。
- 邊界只能縮減：若邊界超出點的範圍，會被裁切回點的外框，並附註「邊界超出點的範圍，已裁切回其外框。」
- 其角點的高程取自曲面，因此邊緣能精確貼合地面。
- 目前尚未實作隱藏（內部）邊界。

## 修剪過長的外側三角形

沒有邊界時，曲面會填滿點的整個外框，包括跨越凹入邊的細長三角形。

1. 在**曲面**中，於**最長外緣邊**輸入長度並按Enter鍵。起始值可設為典型測點間距的兩到三倍。
2. 外緣邊長於此值的外側三角形會被移除，並逐步向內進行，直到所有外緣邊都夠短為止。作為斷線的邊永遠不會被剝除。
3. 輸入 0 即可再次保留所有三角形。

## 閱讀曲面報告

在曲面資訊下方，一個方框會列出建置程式所執行的內容。左側為赭黃色條時表示資訊；為紅色條時表示錯誤，且不會產生曲面。

| 訊息 | 說明 |
|---|---|
| 「3 個點與其他點位於相同位置，已併入其中。」 | 平面上距離小於 0.0001 的點會合併為一個頂點（保留第一個）。 |
| 「2 處有兩個不同的高程……」 | 位置重疊的點，或交叉的斷線，高程不一致。以斷線的高程為準，其次為第一個。 |
| 「1 段斷線無法強制納入曲面。」 | 極短或幾乎重疊的斷線段無法套入；請檢查該處。 |
| 「曲面至少需要三個具有高程的點。」 | 點數太少：請檢查欄位順序與群組。 |
| 「所有點都在同一直線上：沒有三角形。」 | 點沒有寬度，例如單一導線。 |
| 「邊界與點不重疊。」 | 邊界位於別處，常見原因為單位或座標混淆。 |
| 「邊界內已無三角形。」 | 邊界過小或位置不當。 |

## 從 LandXML 讀取的曲面

開啟 LandXML 時，會直接使用其第一個 TIN 曲面：**曲面**標題會顯示「曲面（來自 LandXML）」，**最長外緣邊**呈灰色不可用。使用該曲面期間，斷線群組、繪製的斷線與新邊界都不會改變它。若要改由檔案中的點建立曲面，請按一下{{ui:依點重建曲面}}。按{{key:Mod+Z}}即可還原 LandXML 曲面。

專案包含一個重力管網，可為雨水或污水。管網由結構物（人孔、進水口）與結構物之間的直管組成。水流方向為繪製的方向。CivilCraft會依設定的三項規則檢查每條管線與結構物，並可依這些規則設定所有管底高程。

## 繪製管段

沒有曲面也能繪製管線，但井口、覆土與自動管底高程需要曲面。

1. 按{{key:P}}，或點選**設計**群組中的{{ui:Pipes}}。
   提示會顯示：「管線：從管段頂端往下依序點選結構物（點選既有的結構物即可接合），按Enter結束。」
2. 點選上游結構物的位置，即會放置一個結構物。
3. 依序點選每個下游結構物。若要接到既有的結構物，請直接點選它：狀態列會顯示「已接合S3。」
4. 按{{key:Enter}}。管線會被繪製，管底高程依規則設定，狀態列會顯示例如「已繪製3條管線，已依規則設定12個管底高程；所有檢查皆通過。」

新結構物依序命名為S1、S2……，直徑為48英吋（1200 mm）。新管線依序命名為P1、P2……，直徑為12英吋（300 mm）。英尺專案中的直徑以英吋為單位，公尺專案中則以毫米為單位。

以{{key:Enter}}結束。雙擊也可以，但若在既有結構物上雙擊以在該處結束管段，接合會被捨棄：請先點選一次，再按{{key:Enter}}。

## 設定規則

未選取任何物件時，右側面板（**專案**）中有**管網**區塊：

| 設定 | 初始值 | 意義 |
|---|---|---|
| 類型 | 雨水 | {{ui:Storm}}或{{ui:Sanitary}}；寫入LandXML |
| 最小坡度 | 0.50% | 每條管線至少須有此坡降 |
| 最小覆土 | 2 ft（0.6 m） | 地面至管頂，沿整條管線 |
| 結構物落差 | 0.10 ft（0.03 m） | 出口管底必須低於每個進口管底至少此距離 |

**這些初始值僅為暫定值，並非標準。** 請設定主管機關或專案所要求的數值。覆土自地面量至管頂（管底加內徑）；井壁厚度不計入。在有平台或廊道整地的地方，整地後的曲面即為地面。

## 由CivilCraft設定管底高程

- {{ui:Set every invert from the rules}}（位於**管網**區塊中）會設定所有管線。
- {{ui:Set its inverts from the rules}}（選取一條管線時）僅設定該管線。

依下游方向依序計算：每段管段在其頂端結構物處至少達到最小覆土，至少達到最小坡度，通過每個結構物時至少有一段落差；若地面沿管線會使覆土小於最小覆土，則再加深。管底高程無條件捨去至0.01，不會進位。狀態列會顯示「已設定管底高程：各段頂端符合最小覆土，至少符合最小坡度，每個結構物至少符合落差。」，或說明無法完成的項目。

## 編輯結構物與管線

使用{{ui:Select}}點選結構物或管線，即可在右側面板中檢視。

**結構物**：**名稱**、**井口**、**集水坑深度**、**直徑**，接著是**使用井口**、**集水坑**、**東座標**與**北座標**，以及進出的管線與其管底高程。

- 將**井口**留空即可取自曲面；此時方框會以灰色顯示曲面數值。輸入數值即可固定井口。
- 在平面圖上拖曳結構物的夾點即可移動它。其管線會跟隨移動；其管底高程則保持不變，因此之後應檢查問題。

**類型**：選擇管網中的一種結構物類型（如下），或選擇無，即為具自身直徑的圓形結構物。

**管線**：**名稱**、其連接的結構物、**直徑**、**上管底高程**、**下管底高程**，接著是**長度**、**坡度**與**最小覆土**。

在每個數值後按{{key:Enter}}。

## 讀取與修正問題

**管網**區塊會列出每個問題（最多40項）；點選某項即可選取該管線或結構物。選取某條管線或結構物時，會列出其自身的問題。若沒有任何問題，會顯示「所有管線與結構物皆符合規則。」

| 訊息（範例） | 處理方式 |
|---|---|
| 「P2 呈上坡流動（-0.40%）。」或「……呈平坡……」 | 互換管底高程，或依規則設定管底高程。 |
| 「P2 在 0.30% 時比最小值 0.50% 平緩。」 | 降低下游管底高程，或提高上游管底高程。 |
| 「P3 沿線覆土 1.40，低於最小值 2。」 | 降低管線；依規則設定其管底高程。 |
| 「S3 中，P4 出口管底為 245.20，未比進入的 P3（245.25）低至少 0.1。」 | 降低出口管線的上管底高程。 |
| 「P1 的管頂高於 S1 的井口。」 | 管線相對於結構物過高。 |
| 「S2 有 2 條管線流出；重力管網每個結構物應只有一個出口。」 | 刪除一條流出管線，或依正確方向重新繪製。 |
| 「管線形成環路；水流必須終止於出口。」 | 管段被繪製回到自身；請刪除一條管線。 |
| 「S5 位於曲面之外，沒有井口高程。」 | 輸入井口高程，或將結構物移至曲面上。 |
| 「P6 部分位於曲面之外；該處覆土未知。」 | 延伸曲面，或接受該處不檢查覆土。 |
| 「P7 尚未有管底高程。」 | 輸入管底高程，或依規則設定。 |

有問題的管線與結構物也會在平面圖上以紅色標示。

## 結構物類型

結構物類型是依其參數建立的結構物：人孔、進水口、接線盒或出口，為**圓形**（內徑）或**矩形**（內寬與內長），並具有**牆厚**、**底板**、位於最低管線下方的**集水坑**，以及**框架與井蓋**（圓形或矩形開口，框架高度）。類型屬於管網，位於專案內容中的**結構物類型**下。

1. 點選{{ui:New structure type}}。對話方塊會在輸入時於平面圖與剖面中繪製結構物。
2. 點選{{ui:Add the type}}。
3. 選取一個結構物，並在**類型**下選擇該類型。它會採用該類型的尺寸與集水坑，但其自身集水坑仍可變更。

編輯類型後，該類型的所有結構物都會跟隨其尺寸變更。移除類型後，其結構物會保留為相同寬度的圓形結構物。每次變更為一個步驟：{{key:Mod+Z}}可復原。

矩形結構物會繪製於平面圖、DXF、DWG與PDF中，並在3D中以矩形呈現，其長邊沿出口管線方向；管線自其牆面開始。LandXML會將其寫為矩形結構物（`RectStruct`），並包含其牆厚；讀取時會將此類結構物還原為類型。

### 透過程式庫共用類型

{{ui:Save as library item}}會將類型寫為CadCraft程式庫項目（`.json`檔）：包含其平面符號、至一般深度的3D實體，以及所有尺寸。上傳至程式庫即可共用。{{ui:Open a library item}}會將以此方式儲存的結構物讀回管網，並換算為專案單位。非由CivilCraft建立的結構物程式庫項目會被拒絕，並說明原因。

## 刪除

選取一條管線後按{{key:Delete}}即可移除。刪除結構物時，連接其上的管線也會一併移除。在Mac上，按Fn加{{key:Delete}}，或點選{{ui:Delete}}。

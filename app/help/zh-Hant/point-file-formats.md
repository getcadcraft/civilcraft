點檔案是純文字，每行一個點。CivilCraft 在瀏覽器中讀取它；不會上傳任何內容。

## 欄位順序

字母依由左至右的欄位命名：**P** 點號或名稱、**N** 北座標、**E** 東座標、**Z** 高程、**D** 描述。

| 順序 | 欄位 | 範例列 |
|---|---|---|
| PNEZD | 點、北座標、東座標、高程、描述 | `101,2080000.00,6150000.00,250.00,GRD` |
| PENZD | 點、東座標、北座標、高程、描述 | `101,6150000.00,2080000.00,250.00,GRD` |
| PNEZ | 點、北座標、東座標、高程 | `101,2080000.00,6150000.00,250.00` |
| PENZ | 點、東座標、北座標、高程 | `101,6150000.00,2080000.00,250.00` |
| NEZD | 北座標、東座標、高程、描述 | `2080000.00,6150000.00,250.00,GRD` |
| ENZD | 東座標、北座標、高程、描述 | `6150000.00,2080000.00,250.00,GRD` |
| NEZ | 北座標、東座標、高程 | `2080000.00 6150000.00 250.00` |
| ENZ | 東座標、北座標、高程 | `6150000.00 2080000.00 250.00` |

沒有 P 的順序會依檔案順序將點編號為 1、2、3 …。X 為東座標，Y 為北座標。

## 分隔符號

CivilCraft 會檢視前 20 行，並選取其中至少出現在 60% 行中的第一個分隔符號：逗號、定位字元（Tab）、分號。否則會以連續空白字元分隔。

- 在逗號、定位字元與分號檔案中，以雙引號括住的欄位可包含分隔符號（`"FL, NORTH"`），而引號內的 `""` 代表一個引號字元。
- 在以空白分隔的檔案中，行尾的描述可包含空白：最後一個座標欄位之後的所有文字都是描述。
- 以 `#`、`;` 或 `//` 開頭的行，以及空白行，都會被略過。
- 檔案開頭的位元組順序標記（BOM）會被忽略。

## 標題列

若第一行中少於兩個欄位是數字，該行會被視為標題列。若標題的每個欄位都是 CivilCraft 可辨識的名稱，欄位順序即由標題決定（「依標題列」）。名稱比對時不分大小寫，並忽略空白、句點、底線、連字號與括號：

| 欄位 | 可辨識的名稱 |
|---|---|
| P | pt, pnt, point, point no, point number, number, no, id, name, pt#, point#, # |
| N | n, north, northing, y, y coord, lat, latitude |
| E | e, east, easting, x, x coord, lon, long, longitude |
| Z | z, elev, elevation, el, height, h, z coord, rl |
| D | d, desc, description, code, raw description, full description, note, notes, feature |

若有任何標題名稱無法辨識，或這些名稱無法組成上述八種順序之一，則會略過標題列，並依欄數推測順序。

:::warning
同時命名緯度欄位（`lat`、`latitude`）與經度欄位（`lon`、`long`、`longitude`）的標題，會被讀取為度數，而非北座標與東座標。在{{ui:匯入}}時，點會透過專案的座標系統轉換；沒有座標系統的專案會要求先選擇座標系統。超出 ±90° 緯度或 ±180° 經度的列會被拒絕。請參閱[匯入 GIS 資料](topic:gis-import#point-files-with-latitude-and-longitude)。
:::

## 依欄數推測

若沒有可用的標題，且**欄位**保留為{{ui:偵測}}：

- 5 欄或以上：PNEZD。
- 4 欄：若每個取樣行的第一欄都是整數、第四欄是數字，則為 PNEZ；否則為 NEZD。
- 3 欄：NEZ。

PNEZD 與 PENZD 無法單憑數字區分。推測會依 [CivilCraft 設定](topic:settings)中的**點列**：P、N、E、Z、D 位於開頭，或 P、E、N、Z、D（此時四欄讀作 PENZ，三欄讀作 ENZ）。對話方塊會顯示「依欄數推測 — 請確認北座標與東座標未對調」。若預覽看起來不對，請在**欄位**中選擇正確的順序。

## 列的檢查方式

- 列可以省略描述。
- 北座標與東座標必須是數字。高程可以留空（該點會保留，但不用於曲面）。
- 點號可以是任何文字（也可包含字母，例如 `CP1`），但不可為空。
- 若點號重複，則保留第一列，其餘列會列為未讀取。
- 描述最多保留 200 個字元；控制字元會轉為空白。
- 最多保留 200 列未讀取的列供對話方塊顯示（顯示 25 列），且全部都會計數。

## 點群組

點的群組是其描述中以大寫書寫的第一個字詞。"GRD"、"grd shot" 與 "Grd" 都屬於群組 GRD。沒有描述的點會歸入「（無描述）」。請參閱[匯入測量點](topic:import-points)。

## 寫出點

CivilCraft 尚未匯出點的文字檔。點可輸出為 LandXML（作為 CgPoints）、專案檔案，並可透過 GIS{{ui:匯出}}輸出為含 P、N、E、Z 與 D 欄位的 shapefile、GeoPackage 或 GeoJSON（[匯出竣工資料至 GIS](topic:gis-export)）。請參閱[尚未實作](topic:not-built-yet)。

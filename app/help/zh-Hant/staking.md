選取路線，然後在其**屬性**中按一下**放樣報表**。

## 依樁號與偏移放樣

1. **從**與**到**：要放樣的樁號（1+50 或 150）。
2. **每隔**：間距。放樣點會設在其倍數的位置，兩端都會設；若勾選方塊，也會設在路線曲線的起點與終點。
3. **偏移**：路線左側與右側（面向樁號遞增的方向）：`12 L, 0, 12 R`、`L12 CL R12` 或 `-12, 0, 12`（左側為負）。若路線有路廊，會先列出路面邊緣與路肩。
4. **起始編號**與**前綴**為放樣點命名：1、2、3，或 S101、S102。

## 路線附近的測量點

選取**路線附近的測量點**並設定距離。距離之內的每個點都會取得其樁號與偏移、該處的設計高程，以及其自身的高程作為地面高程：可用來檢查已放樣或竣工實測的點。

## 報表內容

| 欄位 | 說明 |
|---|---|
| 點 | 放樣點的名稱，或測量點的編號 |
| 樁號、偏移 | 沿路線的位置：L 為左，R 為右 |
| 北座標、東座標 | 其座標 |
| 設計高程 | 該處已配置路廊的曲面（從邊坡線到邊坡線），否則為中心線上的設計縱斷面 |
| 地面高程 | 該處的現況地表，或測量點自身的高程 |
| 挖/填 | 地面高於設計時為 C（挖除），低於設計時為 F（填土），精確到小數點後兩位 |

沒有設計高程的放樣點（不在路廊上，或在沒有路廊的路線上且不在中心線上）沒有挖填量；對話方塊會顯示其數量。

## 保存

- **CSV**：一行標題，接著是上述欄位，另外加上有正負號的挖填值（地面減設計），方便試算表與資料蒐集器使用。
- **PDF**：依所選紙張列出表格頁，每個放樣點一列，挖方以橘色、填方以綠色標示，並附上其他圖紙的標題欄。

:::note
放樣點是依專案中的設計計算。施工前請與核准的圖說核對。
:::

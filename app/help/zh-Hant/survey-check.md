測量圖說看起來可能正確，但對地面而言仍可能有誤：其單位可能是猜測的，等高線可能平貼在高度 0，或其高程可能是以完全不屬於幾何的文字寫成。{{ui:線條}} 對話方塊中的**測量高程與檢查**區段（參見[以線條開啟 DWG 或 DXF](topic:open-dwg-dxf)）會讀取這些高程，並在加入任何內容前告知哪些地方看起來有問題。

## 以文字或屬性記載的高程

許多測量圖說會將高程以小型文字標示在十字記號旁，例如 `104.37` 或 `EL 104.37`，或作為點圖塊的屬性。這些並非線條，因此線條讀取器會略過它們。該區段會列出找到的數量，並可選擇將其作為**測量點**：

1. 勾選**將 … 個高程作為測量點**。預設為不勾選，因為並非圖說中的每個數字都是高度。
2. 單獨成立的文字會被讀取為高程：即含有小數部分的數字（`104.37`、`+104,37`、`-3.50`），或位於 `EL`、`ELEV`、`RL`、`FFL`、`GL`、`TW`、`BW`、`INV`、`Z` 或 `LEVEL` 之後的數字，後面可選擇性加上 `m`、`ft` 或 `'`。單獨的整數（`12`）會被視為地號或圖號，而非高程；`GATE 3` 之類的文字或日期則絕不會被讀取。文字格式碼會被忽略。
3. 對於圖塊屬性，請選擇**記錄高程的圖塊屬性**。CivilCraft 會自行找到名為 ELEV、Z、LEVEL、RL 或類似的標籤；若圖說使用自訂標籤，請從清單中選擇其他標籤。此選擇會記憶在本電腦上該檔名的設定中，因此再次開啟時會從同一標籤開始。所選的標籤也會將整數視為高程。
4. 按一下 {{ui:新增}}。點會依專案中最大的編號接續編號，每個點會以其圖層（或圖塊）描述，高度會依與圖說其餘部分相同的方式換算為專案單位。整個操作為一個步驟：按 {{key:Mod+Z}} 即可移除這些點。

文字位於其自身的插入點（若有對齊點則為對齊點）。圖塊內的文字不會被讀取，圖說本身也絕不會被更動。

## 檢查

檢查會針對即將匯入的內容執行，並依問題類型列出每一項發現：

| 顯示內容 | 代表意思 |
|---|---|
| **未設定單位** | 圖說未說明其單位，因此其數值會被視為專案單位。請核對一段已知的距離。 |
| **已換算單位** | 圖說單位與專案單位不同，已依比例換算（屬提示，非錯誤）。 |
| **資料範圍為 … 公里** 或 **… 公尺** | 範圍大於 200 公里或小於半公尺，通常表示單位錯誤（毫米被讀成公尺，或反之）。 |
| **未設定座標系統** | 專案沒有座標系統。當資料距離零點很遠時（例如州平面或國家座標網格的座標），會以警告顯示。請見[座標系統](topic:coordinate-systems)。 |
| **距原點過遠** | 資料距離零點超過 100 公里。距離零點過遠時，3D 檢視與匯出會失去精度並晃動。 |
| **圖層 … 沒有高度** | 名稱類似等高線的圖層（TOPO、CONT、CNTR、CONTOUR）包含高度為 0 的線條，因此以其建立的地面會是平的。 |
| **高程正好為 0** | 部分高程為 0，而一般高程遠非如此：可能是遺漏了高度值。 |
| **高程與其他值相差甚遠** | 有少數高程遠離其他高程（以所有高程的中間值為基準判斷，因此範圍很大的陡峭場地不會被標記），或高於 9,000 公尺或低於 -11,000 公尺。 |
| **點位於另一點之上** | 兩點位於相同位置，且高程相同或不同。 |

按一下 {{ui:新增}} 之後，相同的內容會列在**問題**中，每種問題一行，並附上檔名，方便之後回來查看。檢查只判斷圖說，不會更動其內容，也不會阻止使用該圖說。

:::tip
若檢查顯示等高線高度為 0，且有以文字寫成的高程，請將這些高程作為測量點匯入：它們通常包含等高線缺少的實際高度。
:::

## 未檢查的項目

檢查不會將圖說與第二份測量成果比對，也無法判斷圖說使用的是哪一種座標系統：它只會告知尚未設定座標系統。

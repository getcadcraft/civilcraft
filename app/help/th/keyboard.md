ปุ่มตัวอักษรเดี่ยวใช้งานได้เมื่อคุณไม่ได้พิมพ์อยู่ในช่องข้อความ ปุ่มลัดที่มี {{key:Mod}} ใช้ Command บน Mac และ Ctrl บนระบบอื่น ดูเพิ่มเติมที่ [ปุ่มในเบราว์เซอร์](common:keys)

## ไฟล์และการแก้ไข

| ปุ่ม | การกระทำ |
|---|---|
| {{key:Mod+O}} | เปิดไฟล์จุด, LandXML หรือโครงการ |
| {{key:Mod+S}} | บันทึกโครงการ (ดาวน์โหลดไฟล์ `.civilcraft.json`) |
| {{key:Mod+P}} | พล็อตแปลนเป็น PDF (เปิดกล่องโต้ตอบพล็อต ไม่ใช่การพิมพ์ของเบราว์เซอร์) |
| {{key:Mod+Z}} | เลิกทำ |
| {{key:Mod+Y}} | ทำซ้ำ |
| {{key:Delete}} | ลบจุดสำรวจ แนวสายทาง แท่น โครงสร้าง ท่อ หรือ PVI ที่เลือก |
| {{key:Mod+C}} | คัดลอกจุดสำรวจที่เลือก (ทั้งเป็นแถวจุดสำหรับสเปรดชีต) |
| {{key:Mod+X}} | ตัดจุดสำรวจที่เลือก |
| {{key:Mod+V}} | วางจุด: จุดจะตามตัวชี้ คลิกตรงที่จะวาง |
| {{key:Mod+Shift+V}} | วางที่เดิม: ที่พิกัดของจุดเอง |
| {{key:Mod+D}} | ทำสำเนาจุดที่เลือก: สำเนาจะตามตัวชี้ |
| {{key:Mod+A}} | เลือกจุดสำรวจทั้งหมด |
| {{key:Esc}} | ยกเลิกการเลือกทั้งหมด (และยกเลิกการวาง) |

{{key:Mod+S}}, {{key:Mod+O}} และ {{key:Mod+P}} ทำงานได้แม้ขณะที่คุณพิมพ์อยู่ในช่อง {{key:Mod+Z}} และ {{key:Mod+Y}} ในช่องข้อความจะเลิกทำการพิมพ์ของคุณแทนตามปกติ และ {{key:Mod+C}}, {{key:Mod+X}}, {{key:Mod+V}} และ {{key:Mod+A}} ก็เช่นกัน: ในช่องจะคัดลอก ตัด วาง และเลือกข้อความในช่องนั้น เมื่อมีข้อความที่เลือกบนหน้า (ในพาเนล) {{key:Mod+C}} จะคัดลอกข้อความนั้น {{key:Mod+Shift+Z}} ไม่ทำอะไรใน CivilCraft: ใช้ {{key:Mod+Y}} หรือปุ่ม {{ui:ทำซ้ำ}} แทน

:::mac
ปุ่มบน Mac ที่มีป้าย **delete** คือ {{key:Backspace}} สำหรับเบราว์เซอร์ เพื่อลบส่วนที่เลือก กด {{key:Delete}} (Fn และ delete) หรือเลือก {{ui:ลบ}} ในเมนู {{ui:เพิ่มเติม}} ของแถบเครื่องมือ
:::

## เครื่องมือ

| ปุ่ม | เครื่องมือ |
|---|---|
| {{key:V}} | {{ui:เลือก}} |
| {{key:M}} | {{ui:วัด}}: ระยะทาง พื้นที่ และความลาดบนแปลน ([วัด](topic:measure)) |
| {{key:A}} | {{ui:การจัดแนว}} |
| {{key:G}} | {{ui:แท่น}} |
| {{key:P}} | {{ui:ท่อ}} |
| {{key:B}} | {{ui:เส้นแบ่งลาด}} |
| {{key:O}} | {{ui:ขอบเขต}} |
| {{key:R}} | แสดงหรือซ่อนมุมมองโปรไฟล์ |
| {{key:I}} | เปิดหรือปิด {{ui:เพิ่ม PVI}} (เปิดมุมมองโปรไฟล์ถ้าปิดอยู่) |
| {{key:F}} | {{ui:พอดี}}: แสดงทุกอย่าง |
| {{key:D}} | {{ui:3D}}: แสดงไซต์ใน 3D หรือกลับไปยังแปลน |
| {{key:E}} | แสดงหรือซ่อนความลาดและระดับความสูงตามเส้นลักษณะทุกเส้น (บนหน้าจอเท่านั้น) |

กดปุ่มของเครื่องมือที่ใช้งานอยู่อีกครั้งจะกลับไปที่ {{ui:เลือก}} ตัวอักษรที่กดพร้อม {{key:Shift}} จะไม่ทำอะไร

## ขณะวาด

| ปุ่ม | การกระทำ |
|---|---|
| {{key:Enter}} | จบการจัดแนว แท่น การวางท่อ เส้นแบ่งลาด หรือขอบเขต |
| {{key:Backspace}} | ลบจุดสุดท้ายที่คลิก |
| {{key:C}} | เส้นลักษณะ: เปิดหรือปิดส่วนโค้ง (หลังจุดยอด คลิกจุดบนเส้นโค้ง แล้วจุดปลาย) |
| {{key:Esc}} | ยกเลิกการวาด (หรือการวาง) เมื่อกดอีกครั้ง (หรือเมื่อยังไม่มีอะไรวาด) กลับไปที่ {{ui:เลือก}} และล้างการเลือก |

## มุมมองแปลน

| ปุ่มหรือการกระทำ | ผลลัพธ์ |
|---|---|
| ล้อเลื่อน | ซูมเข้าหรือออกที่ตัวชี้ |
| ลากบนพื้นที่ว่าง | แพน (ในเครื่องมือใดก็ได้ การคลิกสั้นยังคลิกได้; เมื่อกด {{key:Shift}} ค้างไว้ จะวาดกรอบเลือกแทน) |
| ลากด้วยปุ่มกลาง | แพน |
| ลากด้วยปุ่มขวา | แพน (ไม่มีเมนูเปิด) |
| {{key:Space}} แล้วลาก | แพน |
| คลิก | เลือก (ด้วย {{ui:เลือก}}) หรือวางจุด (ด้วยเครื่องมือวาด) |
| {{key:Shift}} แล้วคลิก | เพิ่มจุดสำรวจเข้าที่เลือก หรือเอาออก |
| {{key:Shift}} แล้วลาก | วาดกรอบ: จุดสำรวจที่อยู่ในกรอบจะถูกเพิ่มเข้าที่เลือก ลากวนรอบจุดเหล่านั้นเพื่อใช้[ลาสโซ](topic:lasso-selection) |
| {{key:Space}} ขณะวาดลาสโซ | หน้าต่าง จากนั้นข้าม จากนั้นรั้ว |
| คลิกขณะวาง | วางจุดที่วางตรงนั้น ({{key:Enter}} จะวางที่พิกัดของมันเอง) |
| ลาก{{ui:กริป}} | ย้าย PI มุมแท่น หรือโครงสร้าง (หนึ่งขั้นการเลิกทำ) |
| {{key:Up}} {{key:Down}} {{key:Left}} {{key:Right}} | แพน เมื่อแปลนมีโฟกัส (คลิกที่แปลนก่อน) |
| {{key:Plus}} และ {{key:Minus}} | ซูมเข้าและออกที่จุดกึ่งกลาง เมื่อแปลนมีโฟกัส |

ปุ่ม = ซูมเข้าเหมือน {{key:Plus}} จึงไม่ต้องกด {{key:Shift}}

## มุมมองโปรไฟล์

| การกระทำ | ผลลัพธ์ |
|---|---|
| คลิกขณะเปิด {{ui:เพิ่ม PVI}} | เพิ่ม PVI ตรงนั้น |
| คลิก PVI | เลือกมัน |
| ลาก PVI | ย้ายมัน (หนึ่งขั้นการเลิกทำ) |
| {{key:Delete}} หรือ {{key:Backspace}} | ลบ PVI ที่เลือก (Backspace ใช้ได้เฉพาะเมื่อมุมมองโปรไฟล์มีโฟกัส) |

มุมมองโปรไฟล์ไม่ซูมหรือแพน

## หน้าจอและช่วยเหลือ

| ปุ่ม | การกระทำ |
|---|---|
| {{key:F1}} | เปิดหรือปิดช่วยเหลือนี้ (แผงด้านข้าง); {{ui:ช่วยเหลือ}} บนแถบแอปก็ทำเช่นเดียวกัน |
| {{key:Esc}} | ปิดแผงช่วยเหลือเมื่อเปิดอยู่ |
| {{key:Ctrl+Shift+F}} | สลับโหมดหน้าจอ: เต็มหน้าจอ เต็มหน้าจอโดยซ่อนแถบ และปกติ |
| {{key:Esc}} | ออกจากเต็มหน้าจอ (ปุ่มของเบราว์เซอร์เอง) |

{{key:F1}} ไปถึงช่วยเหลือก่อนที่ CivilCraft จะเห็น จึงทำงานได้ในทุกเครื่องมือ บนแป้นพิมพ์ Mac ส่วนใหญ่ ให้กด fn พร้อม F1 หรือคลิก {{ui:ช่วยเหลือ}} {{key:Ctrl+Shift+F}} ใช้ปุ่ม Control บนทุกแพลตฟอร์ม รวมถึง Mac ดู [การใช้ช่วยเหลือ](common:help) เพื่อดูวิธีค้นหาในช่วยเหลือนี้

## เมาส์ แทร็กแพด และการสัมผัส

:::mouse
- ล้อเลื่อนซูมที่ตัวชี้ เมาส์ที่ล้อหมุนอิสระจะซูมเร็ว ให้หมุนเป็นช่วงสั้น ๆ
- แพนด้วยการลากบนพื้นที่ว่างใดก็ได้ ปุ่มกลาง ปุ่มขวา หรือ {{key:Space}} แล้วลาก
:::

:::mac
บนแทร็กแพดของ Mac:

- การเลื่อนด้วยสองนิ้ว**ซูม** (ไม่แพน) และการพินช์ก็ซูมเช่นกัน
- เพื่อแพน ให้กดและลากบนพื้นที่ว่างด้วยนิ้วเดียว หรือกด {{key:Space}} ค้างแล้วลาก
- การคลิกสองนิ้ว (คลิกขวา) ไม่เปิดเมนูและไม่ทำอะไรด้วยตัวมันเอง
:::

:::touch
บนหน้าจอสัมผัส:

- การแตะครั้งแรกทำให้ปุ่มและแถวเมนูมีขนาดเท่านิ้ว
- แตะเพื่อเลือกหรือวางจุด; ลากนิ้วเดียวบนพื้นที่ว่างเพื่อแพน การแตะอาจสั่นเล็กน้อย: จะแพนก็ต่อเมื่อนิ้วขยับราว 10 พิกเซล
- สองนิ้วพินช์เพื่อซูม และเคลื่อนไปด้วยกันเพื่อแพน
- ลากกริปหรือ PVI ด้วยนิ้วเดียว กริปเผื่อพื้นที่รอบนิ้วหนึ่งนิ้ว
- ขณะที่คุณวาดแนวสายทาง แท่น เส้นแบ่งลาด ขอบเขต การวางท่อ เส้นลักษณะ หรือแปลงที่ดิน แถบเหนือแปลนจะมี {{ui:เสร็จ}} ({{key:Enter}}) {{ui:เลิกจุด}} ({{key:Backspace}}) และ {{ui:ยกเลิก}} ({{key:Esc}}) การกดค้างนาน (ครึ่งวินาทีโดยไม่เลื่อน) ก็จบการวาดเช่นกัน
- ใน{{ui:เลือก}} การกดค้างนานบนจุดสำรวจจะเพิ่มเข้าที่เลือกหรือเอาออก เหมือนการคลิกพร้อม {{key:Shift}}
- ในมุมมอง 3D นิ้วเดียวหมุนรอบ สองนิ้วพินช์และแพน และการแตะเลือก
- ไม่มีการโฮเวอร์บนหน้าจอสัมผัส ดังนั้นค่าในแถบสถานะจะอัปเดตเฉพาะขณะที่นิ้วแตะอยู่
:::

## ปุ่มของเบราว์เซอร์ที่ชนะ

ปุ่มบางปุ่มเป็นของเบราว์เซอร์และไม่ไปถึง CivilCraft เช่น {{key:Mod+W}} (ปิดแท็บ) {{key:Mod+T}} (แท็บใหม่) {{key:Mod+N}} (หน้าต่างใหม่) และ {{key:F11}} (เต็มหน้าจอในเบราว์เซอร์ Windows และ Linux) CivilCraft ไม่ได้ใช้ปุ่มเหล่านี้ หากปุ่มลัดเปิดบางอย่างในเบราว์เซอร์แทน ให้คลิกแปลนหนึ่งครั้งเพื่อให้หน้าได้โฟกัส แล้วลองอีกครั้ง

## ที่ตั้งของคำสั่งย้าย

ไม่มีคำสั่งย้าย: เลือก {{ui:เลือก}} แล้วลากจุดหรือจุดยอด หรือแก้พิกัดใน {{ui:คุณสมบัติ}} ดู [แก้ไขจุด](topic:edit-points)

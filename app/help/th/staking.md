เลือกแนวสายทางแล้วคลิก **รายงานการปักหมุด** ในพาเนล **คุณสมบัติ** ของแนวสายทางนั้น

## หมุดที่สถานีและออฟเซ็ต

1. **จาก** และ **ถึง**: สถานีที่จะปักหมุด (1+50 หรือ 150)
2. **ทุก**: ระยะห่าง หมุดจะถูกปักที่ทุกตำแหน่งที่เป็นผลคูณของค่านี้ ที่ปลายทั้งสองด้าน และ (เมื่อทำเครื่องหมายช่องไว้) ตรงจุดที่โค้งของแนวสายทางเริ่มและสิ้นสุด
3. **ออฟเซ็ต**: ซ้ายและขวาของแนวสายทาง มองตามทิศทางสถานีที่เพิ่มขึ้น: `12 L, 0, 12 R`, `L12 CL R12` หรือ `-12, 0, 12` (ซ้ายเป็นค่าลบ) แนวสายทางที่มีแนวถนนกำหนดไว้จะเริ่มจากขอบผิวทางและไหล่ทาง
4. **เริ่มนับจาก** และ **ใช้คำนำหน้า** ตั้งชื่อหมุด: 1, 2, 3 หรือ S101, S102

## จุดสำรวจใกล้แนวสายทาง

เลือก **จุดสำรวจใกล้แนวสายทาง** และระบุระยะที่ใกล้ จุดแต่ละจุดที่อยู่ภายในระยะนั้นจะได้สถานีและออฟเซ็ต ค่าออกแบบ ณ ตำแหน่งนั้น และระดับของตัวจุดเองเป็นระดับพื้นดิน ใช้เป็นการตรวจสอบจุดที่ปักหมุดหรือวัดไว้เป็นแบบก่อสร้างจริง

## รายงานแสดงอะไร

| คอลัมน์ | ความหมาย |
|---|---|
| จุด | ชื่อหมุด หรือหมายเลขของจุดสำรวจ |
| สถานี, ออฟเซ็ต | ตำแหน่งตามแนวสายทาง: L ซ้าย, R ขวา |
| พิกัดทิศเหนือ, พิกัดทิศตะวันออก | พิกัดของหมุด |
| ระดับออกแบบ | ผิวของแนวถนนที่ปรับระดับแล้ว ณ ตำแหน่งนั้น (จากเส้นขอบงานถึงเส้นขอบงาน) ไม่เช่นนั้นใช้โปรไฟล์ออกแบบที่แนวกึ่งกลาง |
| ระดับพื้นดิน | ผิวที่มีอยู่ ณ ตำแหน่งนั้น หรือระดับของจุดสำรวจนั้นเอง |
| ขุด/ถม | C เมื่อพื้นดินสูงกว่าการออกแบบ (ต้องขุดลง) F เมื่อต่ำกว่า (ต้องถมขึ้น) ละเอียดถึงทศนิยมสองตำแหน่ง |

หมุดที่ไม่มีระดับออกแบบ (อยู่นอกแนวถนน หรืออยู่บนแนวสายทางที่ไม่มีระดับออกแบบนอกแนวกึ่งกลาง) จะไม่มีค่าขุดหรือถม กล่องโต้ตอบจะบอกจำนวนหมุดเหล่านี้

## บันทึกรายงาน

- **CSV**: บรรทัดชื่อเรื่อง ตามด้วยคอลัมน์ข้างต้น และค่าขุดหรือถมเป็นตัวเลขมีเครื่องหมาย (พื้นดินลบค่าออกแบบ) สำหรับสเปรดชีตและเครื่องเก็บข้อมูลภาคสนาม
- **PDF**: หน้าตารางบนกระดาษที่คุณเลือก หนึ่งหมุดต่อหนึ่งแถว ค่าขุดเป็นสีส้มและค่าถมเป็นสีเขียว พร้อมตารางชื่อเรื่องเหมือนแผ่นอื่น

:::note
หมุดคำนวณจากการออกแบบในโปรเจกต์ ตรวจสอบกับแบบที่ได้รับอนุมัติก่อนเริ่มก่อสร้างทุกครั้ง
:::

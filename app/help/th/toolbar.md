แถบเครื่องมืออยู่ด้านบนของแอปแบ่งเป็นเจ็ดกลุ่ม ทุกปุ่มจะแสดงคำแนะนำและคีย์ลัดเมื่อคุณวางเมาส์เหนือปุ่มนั้น

## ไฟล์

| ปุ่ม | คีย์ลัด | หน้าที่ |
|---|---|---|
| {{ui:ใหม่}} | ไม่มี | เริ่มโปรเจกต์เปล่า จะถามก่อนหากมีการเปลี่ยนแปลงที่ยังไม่ได้บันทึก |
| {{ui:เปิด}} | {{key:Mod+O}} | เปิดไฟล์จุด (CSV, TXT), LandXML หรือโปรเจกต์ CivilCraft |
| {{ui:บันทึก}} | {{key:Mod+S}} | ดาวน์โหลดโปรเจกต์เป็น `<name>.civilcraft.json` |

## ส่งออก

| ปุ่ม | คีย์ลัด | หน้าที่ |
|---|---|---|
| {{ui:LandXML}} | ไม่มี | ดาวน์โหลด `<name>.xml`: จุด พื้นผิว แนวสายทาง โปรไฟล์ และเครือข่ายท่อในรูปแบบ LandXML 1.2 แสดง "ยังไม่มีอะไรให้ส่งออก" เมื่อโปรเจกต์ว่าง |
| {{ui:DXF}} | ไม่มี | ดาวน์โหลด `<name>.dxf`: เส้นของแผนในรูปแบบ R12 DXF |
| {{ui:PDF}} | {{key:Mod+P}} | เปิด **พล็อตแผนเป็น PDF** แสดง "ยังไม่มีอะไรให้พล็อต" เมื่อโปรเจกต์ว่าง |

## พื้นผิว

| ปุ่ม | คีย์ลัด | หน้าที่ |
|---|---|---|
| {{ui:เส้นแบ่งลาด}} | {{key:B}} | คลิกจุดสำรวจตามลำดับ แล้วกด {{key:Enter}} เพื่อจบ เส้นแบ่งลาดจะใช้ระดับความสูงของจุดเหล่านั้น |
| {{ui:ขอบเขต}} | {{key:O}} | คลิกมุมของขอบเขตด้านนอก แล้วกด {{key:Enter}} เพื่อจบ จะแทนที่ขอบเขตเดิมทั้งหมด |

ทั้งสองปุ่มจะแสดง "ยังไม่มีพื้นผิว: เปิดจุดสำรวจก่อน" เมื่อไม่มีพื้นผิว

## การออกแบบ

| ปุ่ม | คีย์ลัด | หน้าที่ |
|---|---|---|
| {{ui:การจัดแนว}} | {{key:A}} | คลิก PI ตามลำดับ แล้วกด {{key:Enter}} เพื่อจบ |
| {{ui:แท่น}} | {{key:G}} | คลิกมุมของแท่น แล้วกด {{key:Enter}} เพื่อจบ เช่นเดียวกับเครื่องมือพื้นผิว จะเตือนเมื่อไม่มีพื้นผิว และแท่นจะปรับระดับได้เฉพาะบนพื้นผิวเท่านั้น |
| {{ui:ท่อ}} | {{key:P}} | คลิกโครงสร้างจากต้นน้ำลงสู่ปลายน้ำ (คลิกโครงสร้างที่มีอยู่เพื่อต่อเข้าด้วยกัน) แล้วกด {{key:Enter}} เพื่อจบ |
| {{ui:โปรไฟล์}} | {{key:R}} | แสดงหรือซ่อนมุมมองโปรไฟล์ใต้แผน |

## แก้ไข

| ปุ่ม | คีย์ลัด | หน้าที่ |
|---|---|---|
| {{ui:เลิกทำ}} | {{key:Mod+Z}} | เลิกทำการเปลี่ยนแปลงล่าสุด (ได้สูงสุด 200 ครั้ง) จะเป็นสีเทาเมื่อไม่มีอะไรให้เลิกทำ |
| {{ui:ทำซ้ำ}} | {{key:Mod+Y}} | ทำซ้ำสิ่งที่ถูกเลิกทำ จะเป็นสีเทาเมื่อไม่มีอะไรให้ทำซ้ำ |
| {{ui:คัดลอก}} | {{key:Mod+C}} | คัดลอกจุดสำรวจที่เลือก และวางลงคลิปบอร์ดเป็นแถวจุดที่สเปรดชีตนำไปใช้ได้ จะเป็นสีเทาจนกว่าจะเลือกจุด |
| {{ui:วาง}} | {{key:Mod+V}} | วางจุด: จุดจะเคลื่อนตามตัวชี้ และการคลิกจะวางจุดลงพร้อมหมายเลขที่ไม่ซ้ำกับจุดอื่น แถวจุดที่คัดลอกจากสเปรดชีตก็วางได้เช่นกัน |
| {{ui:เพิ่มเติม}} | ไม่มี | เปิดเมนูด้านล่าง |

เมนู {{ui:เพิ่มเติม}}:

| รายการ | คีย์ลัด | หน้าที่ |
|---|---|---|
| {{ui:ตัด}} | {{key:Mod+X}} | คัดลอกจุดที่เลือกแล้วลบออก (เป็นการเลิกทำหนึ่งขั้น) |
| {{ui:คัดลอก}} | {{key:Mod+C}} | เหมือนปุ่ม {{ui:คัดลอก}} |
| {{ui:วาง}} | {{key:Mod+V}} | เหมือนปุ่ม {{ui:วาง}} |
| {{ui:วางที่เดิม}} | {{key:Mod+Shift+V}} | วางจุดที่พิกัดของตัวเอง พร้อมหมายเลขที่ไม่ซ้ำกับจุดอื่น |
| {{ui:ทำสำเนา}} | {{key:Mod+D}} | สำเนาของจุดที่เลือกจะเคลื่อนตามตัวชี้ คลิกเพื่อวางตำแหน่ง คลิปบอร์ดจะไม่เปลี่ยนแปลง |
| {{ui:ลบ}} | {{key:Delete}} | ลบจุดสำรวจที่เลือก หรือแนวสายทาง แท่น โครงสร้าง (พร้อมท่อของโครงสร้างนั้น) ท่อ หรือ PVI ที่เลือก |
| {{ui:เลือกจุดสำรวจทั้งหมด}} | {{key:Mod+A}} | เลือกจุดสำรวจทุกจุด |
| {{ui:ยกเลิกการเลือก}} | {{key:Esc}} | ล้างการเลือก |

รายการที่ไม่สามารถทำงานได้ในขณะนี้จะเป็นสีเทา และคำแนะนำจะบอกเหตุผล รายละเอียด: [เลือก คัดลอก และวางจุดสำรวจ](topic:copy-paste-points)

การเลิกทำครอบคลุมการแก้ไขการออกแบบ การตั้งค่าพื้นผิว และจุดสำรวจ (วาง ตัด ทำสำเนา ลบ) ไม่ครอบคลุมการตั้งค่าการแสดงผล และการเปิดหรือนำเข้าไฟล์ใดๆ จะล้างประวัติการเลิกทำ

## GIS

| ปุ่ม | คีย์ลัด | หน้าที่ |
|---|---|---|
| {{ui:พิกัด}} | ไม่มี | เปิดกล่องโต้ตอบ **ระบบพิกัด** ระบุว่าโปรเจกต์อยู่ในระบบใด หรือใช้พิกัดพื้นดินหรือพิกัดท้องถิ่น ดู [ตั้งค่าระบบพิกัดของโปรเจกต์](topic:coordinate-systems) และ [พิกัดพื้นดินและพิกัดท้องถิ่น](topic:ground-and-local-coordinates) |
| {{ui:นำเข้า}} | ไม่มี | นำเข้าข้อมูล GIS: shapefile, GeoJSON, GeoPackage, กริดความสูง และ LiDAR ดู [นำเข้าข้อมูล GIS](topic:gis-import) |
| {{ui:ส่งออก}} | ไม่มี | ส่งออกข้อมูลแบบก่อสร้างจริงให้แผนก GIS ดู [ส่งออกข้อมูลแบบก่อสร้างจริงสำหรับ GIS](topic:gis-export) |
| {{ui:วิเคราะห์}} | ไม่มี | เปิดพาเนลวิเคราะห์ GIS: บัฟเฟอร์ ซ้อนทับ การเชื่อมเชิงพื้นที่ เลือกตามแอตทริบิวต์ วัด ดู [วิเคราะห์เลเยอร์ GIS](topic:gis-analysis) |
| {{ui:ตารางแอตทริบิวต์}} | ไม่มี | อยู่ใน พื้นผิว › เพิ่มเติม เปิดตารางแอตทริบิวต์ของเลเยอร์ GIS: เรียง กรอง เลือก แก้ไข เพิ่มฟิลด์ คำนวณ บันทึกเป็น CSV ดู [ทำงานกับตารางแอตทริบิวต์ของเลเยอร์](topic:gis-table) |
| {{ui:แผนที่}} | ไม่มี | เปิดกล่องโต้ตอบ **เลเยอร์แผนที่**: รูปภาพที่มีการอ้างอิงพิกัดแล้ว หรือเซิร์ฟเวอร์แผนที่ที่คุณเพิ่ม วาดอยู่ใต้แผน ดู [แสดงเลเยอร์แผนที่ใต้แผน](topic:map-layers) |

เครื่องมือ GIS จะโหลดครั้งแรกเมื่อคุณใช้ปุ่มใดปุ่มหนึ่งเหล่านี้ เปิดไฟล์ GIS หรือเปิดโปรเจกต์ที่มีระบบพิกัดหรือเลเยอร์ GIS

## มุมมอง

| ปุ่ม | คีย์ลัด | หน้าที่ |
|---|---|---|
| {{ui:เลือก}} | {{key:V}} หรือ {{key:Esc}} | คลิกเพื่อเลือกแนวสายทาง แท่น โครงสร้าง ท่อ และจุด ({{key:Shift}} กับการคลิกหรือลากจะเพิ่มจุด) ลากกริปเพื่อย้าย PI มุมแท่น และโครงสร้าง |
| {{ui:พอดี}} | {{key:F}} | ซูมแผนให้แสดงพื้นผิว จุด แนวสายทาง และแท่น (ในมุมมอง 3D: แสดงทุกอย่าง) |
| {{ui:3D}} | {{key:D}} | แสดงไซต์ใน 3D ซ้อนบนแผน หรือกลับไปที่แผน แถบเหนือมุมมอง 3D ใช้ตั้งค่ามุมมอง การขยายความสูง การระบายสี และสิ่งที่แสดง และส่งออก GLB หรือ OBJ ดู [ดูไซต์ใน 3D](topic:site-3d) |

| {{ui:นำขอบเขตออก}} | พาเนลซ้าย พื้นผิว | นำขอบเขตด้านนอกออก |

| {{ui:ตั้งระดับท้องท่อทุกเส้นตามกฎ}} | พาเนลขวา เครือข่ายท่อ | ตั้งระดับท้องท่อของทุกท่อตามกฎ |
| {{ui:ตั้งระดับท้องท่อตามกฎ}} | พาเนลขวา ท่อ | ตั้งระดับท้องท่อของท่อนี้ตามกฎ |

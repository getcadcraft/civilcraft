แบบสำรวจอาจดูถูกต้องแต่ก็ยังไม่เหมาะกับพื้นดินได้ เช่น หน่วยอาจเป็นการคาดเดา เส้นชั้นความสูงอาจราบอยู่ที่ความสูง 0 หรือระดับอาจเขียนเป็นข้อความที่ไม่ใช่รูปทรงเรขาคณิตเลย ส่วน **ระดับสำรวจและการตรวจสอบ** ของกล่องโต้ตอบ {{ui:เส้น}} (ดู [เปิด DWG หรือ DXF เป็นเส้น](topic:open-dwg-dxf)) จะอ่านระดับเหล่านั้นและบอกว่ามีอะไรผิดปกติก่อนที่จะเพิ่มสิ่งใดเข้ามา

## ระดับที่เขียนเป็นข้อความหรือในแอตทริบิวต์

แบบสำรวจจำนวนมากระบุระดับจุดเป็นข้อความเล็กๆ ข้างเครื่องหมายกากบาท เช่น `104.37` หรือ `EL 104.37` หรือเป็นแอตทริบิวต์ของบล็อกจุด ข้อมูลเหล่านี้ไม่ใช่เส้น ตัวอ่านเส้นจึงไม่นำมาด้วย ส่วนนี้จะแสดงจำนวนที่พบและให้คุณนำไปใช้เป็น **จุดสำรวจ** ได้:

1. ทำเครื่องหมาย **นำระดับ … ไปใช้เป็นจุดสำรวจ** ตอนเริ่มต้นจะไม่ได้ทำเครื่องหมาย เพราะตัวเลขทุกตัวในแบบไม่ได้เป็นความสูงเสมอไป
2. ข้อความจะถูกอ่านเมื่อเป็นระดับโดยลำพัง คือตัวเลขที่มีทศนิยม (`104.37`, `+104,37`, `-3.50`) หรือตัวเลขที่อยู่หลัง `EL`, `ELEV`, `RL`, `FFL`, `GL`, `TW`, `BW`, `INV`, `Z` หรือ `LEVEL` โดยอาจมี `m`, `ft` หรือ `'` ต่อท้ายก็ได้ จำนวนเต็มเพียงลำพัง (`12`) จะถูกอ่านเป็นหมายเลขแปลงหรือหมายเลขแผ่น ไม่ใช่ระดับ ข้อความเช่น `GATE 3` หรือวันที่จะไม่ถูกอ่านเลย รหัสจัดรูปแบบข้อความจะถูกละเว้น
3. สำหรับแอตทริบิวต์ของบล็อก ให้เลือก **แอตทริบิวต์ของบล็อกที่เก็บระดับ** CivilCraft จะค้นหาแท็กชื่อ ELEV, Z, LEVEL, RL หรือที่คล้ายกันเองโดยอัตโนมัติ หากแบบใช้แท็กของตัวเอง ให้เลือกจากรายการ การเลือกนี้จะถูกจำไว้สำหรับชื่อไฟล์นั้นบนคอมพิวเตอร์เครื่องนี้ ดังนั้นเมื่อเปิดอีกครั้งจะเริ่มที่แท็กเดิม แท็กที่คุณเลือกเองจะถือว่าจำนวนเต็มเป็นระดับด้วย
4. คลิก {{ui:เพิ่ม}} จุดต่างๆ จะถูกกำหนดหมายเลขต่อจากหมายเลขที่สูงที่สุดในโปรเจกต์ แต่ละจุดจะมีคำอธิบายเป็นเลเยอร์ (หรือบล็อก) และความสูงจะถูกแปลงเป็นหน่วยของโปรเจกต์เหมือนส่วนอื่นๆ ของแบบ ทั้งหมดนี้เป็นการทำงานหนึ่งขั้น {{key:Mod+Z}} จะลบจุดเหล่านั้นออก

ข้อความจะอยู่ที่จุดแทรกของตัวเอง (หรือจุดจัดแนวหากมี) ข้อความภายในบล็อกจะไม่ถูกอ่าน และแบบจะไม่ถูกเปลี่ยนแปลงเลย

## การตรวจสอบ

การตรวจสอบทำงานกับสิ่งที่คุณกำลังจะนำเข้า และแสดงสิ่งที่พบ หนึ่งบรรทัดต่อปัญหาหนึ่งประเภท:

| ข้อความที่แสดง | ความหมาย |
|---|---|
| **ไม่ระบุหน่วย** | แบบไม่ได้ระบุหน่วย ตัวเลขจึงถูกอ่านเป็นหน่วยของโปรเจกต์ ให้ตรวจระยะที่คุณรู้ค่าหนึ่งระยะ |
| **แปลงหน่วยแล้ว** | หน่วยของแบบต่างจากโปรเจกต์และถูกปรับขนาด (เป็นหมายเหตุ ไม่ใช่ข้อผิดพลาด) |
| **ข้อมูลครอบคลุม … km** หรือ **… m** | ขอบเขตใหญ่กว่า 200 km หรือเล็กกว่าครึ่งเมตร ซึ่งมักหมายถึงหน่วยผิด (มิลลิเมตรถูกอ่านเป็นเมตร หรือกลับกัน) |
| **ไม่มีระบบพิกัด** | โปรเจกต์ไม่มีระบบพิกัด จะเป็นคำเตือนเมื่อข้อมูลอยู่ไกลจากศูนย์ เช่น state plane หรือพิกัดกริดแห่งชาติ ดู [ระบบพิกัด](topic:coordinate-systems) |
| **อยู่ไกลจากจุดกำเนิด** | ข้อมูลอยู่ห่างจากศูนย์เกิน 100 km เมื่ออยู่ไกลจากศูนย์ มุมมอง 3D และการส่งออกจะสูญเสียความแม่นยำและกระตุก |
| **เลเยอร์เส้นชั้นความสูง … ไม่มีความสูง** | เลเยอร์ที่ชื่อคล้ายเส้นชั้นความสูง (TOPO, CONT, CNTR, CONTOUR) มีเส้นที่ความสูง 0 ดังนั้นพื้นดินที่สร้างจากเส้นเหล่านี้จะราบ |
| **ระดับเท่ากับ 0 พอดี** | บางระดับเป็น 0 ทั้งที่ระดับทั่วไปไม่ใกล้ 0 เลย: อาจเป็นความสูงที่หายไป |
| **ระดับที่ห่างจากระดับอื่น** | ระดับบางค่าอยู่นอกช่วงของค่าอื่นมาก (ตรวจเทียบกับค่ากลางของระดับทั้งหมด ดังนั้นพื้นที่ลาดชันที่มีช่วงกว้างจะไม่ถูกทำเครื่องหมาย) หรือสูงกว่า 9,000 m หรือต่ำกว่า -11,000 m |
| **จุดซ้อนทับจุดอื่น** | จุดสองจุดอยู่ตำแหน่งเดียวกันและมีระดับเดียวกัน หรือมีระดับต่างกัน |

หลังจากคลิก {{ui:เพิ่ม}} บรรทัดเดียวกันจะไปที่ **ปัญหา** โดยมีหนึ่งรายการต่อประเภท พร้อมชื่อไฟล์ เพื่อให้คุณกลับมาดูได้ การตรวจสอบเพียงประเมินแบบ ไม่เปลี่ยนแปลงอะไรในแบบ และไม่ได้หยุดคุณไม่ให้ใช้แบบนั้น

:::tip
เมื่อการตรวจสอบบอกว่าเส้นชั้นความสูงราบที่ 0 และมีระดับที่เขียนเป็นข้อความ ให้นำระดับเหล่านั้นไปใช้เป็นจุดสำรวจ เพราะมักมีความสูงจริงที่เส้นชั้นความสูงขาดไป
:::

## สิ่งที่ไม่ได้ตรวจ

การตรวจสอบไม่ได้เปรียบเทียบแบบกับการสำรวจอีกชุด และไม่สามารถบอกได้ว่าแบบอยู่ในระบบพิกัดใด บอกได้เพียงว่าไม่ได้ตั้งค่าระบบพิกัดไว้

{{ui:DXF}} เขียนสิ่งที่ผังแสดงอยู่เป็นไฟล์ DXF ในรูปแบบ R12 ซึ่งเป็นเวอร์ชันที่โปรแกรม CAD ทุกตัวเปิดได้ ถ้าคุณเคยใช้ AutoCAD หรือ Civil 3D ให้เปิดหรือแทรกไฟล์นี้เหมือนไฟล์ DXF อื่นๆ

## ส่งออก

1. ตั้งค่าผังตามที่ต้องการสำหรับแบบ ภายใต้ **การแสดงผล** เลือกพื้นผิว (ที่มีอยู่หรือที่เสนอ) ระยะห่างเส้นชั้นความสูง และสิ่งที่จะเปิด (เส้นชั้นความสูง ป้ายกำกับ จุด ป้ายกำกับจุด สามเหลี่ยม เส้นแบ่งลาด ขอบพื้นผิว ท่อ ลูกศรความลาด)
2. คลิก {{ui:DWG/DXF}} ในกลุ่ม **ส่งออก** แล้วเลือก {{ui:DXF (R12, ข้อความ) — ไฟล์แลกเปลี่ยนธรรมดา}} จากนั้นคลิก {{ui:ดาวน์โหลด}}
3. เบราว์เซอร์ดาวน์โหลดไฟล์ `<name>.dxf` แถบสถานะแสดงข้อความ เช่น "ส่งออก R12 DXF: วัตถุ 2,140 ชิ้น; ป้ายกำกับมีขนาดสำหรับ 1" = 40'. ไม่ได้ส่งออกแถบระดับ."

พิกัดถูกเขียนในหน่วยของโครงการ ตามค่าจริง (พิกัด state plane ยังคงเดิม) ไม่มีการปรับขนาดหรือย้ายตำแหน่งใดๆ

## สิ่งที่อยู่ในไฟล์

| สิ่งนั้น | เอนทิตี DXF | เลเยอร์ |
|---|---|---|
| เส้นชั้นความสูงรองและหลัก | โพลีไลน์ 2D ที่ระดับความสูงของมัน | C-TOPO-MINR, C-TOPO-MAJR |
| ป้ายกำกับเส้นชั้นความสูง | ข้อความ | C-TOPO-TEXT |
| สามเหลี่ยม | โพลีไลน์ | C-TOPO-TINN |
| เส้นแบ่งลาดและขอบเขต | โพลีไลน์ 3D | C-TOPO-BRKL |
| ขอบพื้นผิว | โพลีไลน์ | C-TOPO-BNDY |
| ลูกศรความลาด | โพลีไลน์ | C-TOPO-SLOP |
| จุดสำรวจและป้ายกำกับ | จุด (พร้อมระดับความสูง), ข้อความ | V-NODE, V-NODE-TEXT |
| เส้นจากรหัสเส้น | โพลีไลน์ 3D | V-NODE-LINE |
| เส้นกึ่งกลางแนวสายทาง | เส้นและส่วนโค้ง | C-ROAD-CNTR |
| เครื่องหมายและป้ายกำกับ STA | โพลีไลน์, ข้อความ | C-ROAD-STAN |
| ขอบแนวถนน | โพลีไลน์ | C-ROAD-CORR |
| เส้นตัวอย่าง | โพลีไลน์ | C-ROAD-SCTN |
| แท่นฐาน เส้น daylight เส้นลาด | โพลีไลน์ | C-GRAD-PADS, C-GRAD-DAYL, C-GRAD-SLOP |
| เส้นลักษณะ | โพลีไลน์ 3D (ส่วนโค้งแบ่งเป็นช่วงภายใน 0.01; ดู [เส้นลักษณะ](topic:feature-lines)) | C-GRAD-FEAT |
| เส้นทางการกวาด | โพลีไลน์, ข้อความ | C-ROAD-SWPT |
| ท่อ โครงสร้าง และป้ายกำกับ | โพลีไลน์, ข้อความ | C-STRM-PIPE, C-STRM-STRC, C-STRM-TEXT |
| ท่อและโครงสร้างที่มีปัญหา | โพลีไลน์ | C-STRM-PROB |

แต่ละเลเยอร์มีสี รายการทั้งหมดอยู่ใน [เลเยอร์ของผัง](topic:plan-layers)

## ขนาดป้ายกำกับ

ข้อความต้องมีขนาดในหน่วยของแบบ CivilCraft กำหนดขนาดป้ายกำกับให้เข้ากับมาตราส่วนที่ทั้งผังพอดีกับกระดาษ Tabloid (ฟุต) หรือ A3 (เมตร) และแจ้งมาตราส่วนนั้นในข้อความสถานะ ถ้าคุณพล็อตที่มาตราส่วนอื่นในโปรแกรม CAD ให้สเกลข้อความในโปรแกรมนั้น

## สิ่งที่ไม่ได้ส่งออก

- แถบระดับความสูง (แสดงบนหน้าจอเท่านั้น)
- มุมมองโปรไฟล์ โปรไฟล์ถูกส่งออกเป็น LandXML ไม่ใช่เป็นแบบ
- พื้นผิวเองในฐานะวัตถุ 3D ให้ใช้ LandXML สำหรับ TIN หรือเปิด {{ui:สามเหลี่ยม}} เพื่อให้ได้ขอบของมันเป็นเส้น
- สิ่งที่คุณปิดไว้ภายใต้ **การแสดงผล**

## DWG

{{ui:DWG/DXF}} เขียนเส้นชุดเดียวกันเป็นแบบ DWG ด้วย กล่องโต้ตอบจะถามรูปแบบ: DXF หรือ DWG เวอร์ชัน 2000, 2004, 2007, 2010, 2013 หรือ 2018 เวอร์ชัน 2000 เปิดได้ในโปรแกรม CAD เกือบทุกตัว ทั้งรุ่นเก่าและใหม่ เลือกเวอร์ชันใหม่กว่าเมื่อผู้รับแบบขอ ตัวเลือกของคุณจะถูกจำไว้ในเบราว์เซอร์นี้

1. คลิก {{ui:DWG}} ในกลุ่ม **ส่งออก**
2. เลือก **รูปแบบ** แล้วคลิก **ดาวน์โหลด DWG**
3. เบราว์เซอร์ดาวน์โหลด `<name>.dwg` แถบสถานะแสดงสิ่งที่ถูกใส่ เช่น "ส่งออก DWG (รูปแบบ 2018): โพลีไลน์ 12 เส้น, ป้ายกำกับ 40 รายการใน 9 เลเยอร์"

DWG มีเลเยอร์ สี เส้นชั้นความสูง (เป็นโพลีไลน์ที่ระดับความสูงของมัน) เส้นแบ่งลาด 3D ป้ายกำกับ และจุดชุดเดียวกับ DXF ในพิกัดเดียวกัน ชื่อเลเยอร์ที่ DWG เก็บไม่ได้จะถูกเปลี่ยน และข้อความสถานะจะแจ้งให้ทราบ CivilCraft เขียน DWG ด้วยโค้ดของตัวเอง ดังนั้นไม่มีอะไรออกจากคอมพิวเตอร์ของคุณ

### เลเยอร์แผนที่ใน DWG

แบบ DWG เก็บรูปภาพไว้ข้างในไม่ได้ โปรแกรม CAD จะแสดงภาพที่วางอยู่ข้างแบบ เมื่อเลเยอร์แผนที่กำลังแสดง กล่องโต้ตอบจะเสนอ **เลเยอร์แผนที่เป็นภาพข้างแบบ** เมื่อติ๊กตัวเลือกนี้ การดาวน์โหลดจะเป็นไฟล์ `.zip` ที่มี `<name>.dwg`, `<name>-map.png` (เลเยอร์แผนที่ทั้งแบบ กว้างสูงสุด 4,096 พิกเซล) และ `<name>-map.pgw` (ไฟล์ world สำหรับโปรแกรม GIS) แบบจะแสดงภาพเป็นรูปบนเลเยอร์ G-MAP-IMAG ณ ตำแหน่งเดิม แตกไฟล์ทั้งหมดลงในโฟลเดอร์เดียวกันและเก็บไว้ด้วยกัน

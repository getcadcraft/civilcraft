การสำรวจภูมิประเทศมักมาเป็นแบบ: เส้นชั้นความสูงเป็นโพลีไลน์ที่ระดับของมัน เส้นแบ่งลาดเป็นโพลีไลน์ 3 มิติ ขอบเขตไซต์เป็นโพลีไลน์ปิด CivilCraft เปิด**พื้นที่โมเดล**ของแบบเป็นเลเยอร์บนผัง และสามารถแปลงเส้นเหล่านั้นให้เป็นพื้นผิวได้ทันที

## เปิดแบบ

1. คลิก {{ui:เส้น}} ในกลุ่ม **พื้นผิว** (หรือ {{ui:เปิด}} หรือวางไฟล์ลงบนผัง) แล้วเลือกไฟล์ `.dwg` หรือ `.dxf` แบบจะถูกอ่านบนคอมพิวเตอร์เครื่องนี้ ไม่มีการอัปโหลดอะไร อ่านไฟล์ DWG ตั้งแต่ปี 2000 ถึง 2018 และ DXF แบบ ASCII
2. กล่องโต้ตอบ **เส้น** จะแสดงรายการเลเยอร์ของแบบที่มีเส้น รูปปิด หรือจุด และว่ามี**ระดับความสูง**หรือไม่ เลเยอร์ที่ปิดอยู่ในแบบจะไม่ถูกเลือกตั้งแต่แรก ข้อความ แฮตช์ ไดเมนชัน และวัตถุอื่นที่ไม่ใช่เส้นจะถูกนับและไม่นำเข้า (กล่องโต้ตอบจะระบุว่าเป็นอะไร)
3. ตรวจสอบ **หน่วยของแบบ** เมื่อแบบระบุหน่วย CivilCraft จะแปลงเป็นหน่วยของโปรเจกต์ (มิลลิเมตรเป็นเมตร เมตรเป็นฟุต นิ้วเป็นฟุต) แบบที่เป็นฟุตจะถูกอ่านเป็นฟุตสำรวจของสหรัฐโดยไม่ปรับสเกล เพราะทั้งสองต่างกันเพียง 2 ส่วนในล้านส่วน และการปรับสเกลพิกัดระนาบรัฐ (state plane) ด้วยค่านั้นจะเลื่อนพิกัดเป็นฟุต เมื่อแบบไม่ได้ระบุหน่วย ตัวเลขจะถูกอ่านตามหน่วยของโปรเจกต์ หากไม่ถูกต้อง ให้เลือกหน่วยที่ถูกในรายการ
4. ใน **ใช้สำหรับพื้นผิว** เลือกว่าแต่ละเลเยอร์จะให้อะไรกับพื้นผิว (หรือคงไว้เป็น **แสดงอย่างเดียว**) เลเยอร์ที่ตั้งชื่อคล้ายเส้นชั้นความสูง (TOPO, CONT, CNTR) ที่มีระดับความสูงจะเริ่มเป็นเส้นแบ่งลาด
5. คลิก {{ui:เพิ่ม}} เลเยอร์จะปรากฏใต้ **เลเยอร์ GIS** ในพาเนลซ้าย และการใช้งานแต่ละอย่างจะถูกใส่เข้าไปในพื้นผิว แต่ละส่วนเป็นขั้นตอนของตัวเอง {{key:Mod+Z}} จะเลิกทำทีละขั้น

## เลเยอร์แต่ละชนิดให้อะไรได้บ้าง

| เลเยอร์มี | ใช้สำหรับพื้นผิว |
|---|---|
| เส้นชั้นความสูง (โพลีไลน์ที่ระดับความสูง) | เส้นแบ่งลาดที่ระดับของเส้นเอง หรือที่ฟิลด์ ELEV |
| โพลีไลน์ 3 มิติ | เส้นแบ่งลาดที่ระดับของตนเอง |
| เส้นขอบปิด | ขอบเขตพื้นผิว (รูปปิดที่ใหญ่ที่สุด หรือรูปที่คุณเลือก) |
| จุดที่มีระดับความสูง | จุดสำรวจ อธิบายด้วยชื่อเลเยอร์ |
| เส้นที่ระดับ 0 (เส้นบนผัง) | ไม่มี: คงไว้บนผังเป็นแบบพื้นฐาน |

แบบที่ CivilCraft เขียนไว้จะเก็บเส้นฟีเจอร์เป็นโพลีไลน์ 3 มิติที่จำส่วนโค้งของมัน กล่องโต้ตอบจะแสดง **เส้นฟีเจอร์** ให้คงติ๊กไว้เพื่อนำกลับมาเป็นเส้นฟีเจอร์พร้อมส่วนโค้งและการใช้งาน (หนึ่งขั้นตอนการเลิกทำ) หรือเอาติ๊กออกเพื่ออ่านเป็นเส้นเหมือนเลเยอร์อื่น

ภายหลัง ใช้ {{ui:ใช้สำหรับพื้นผิว}} ในเมนูของเลเยอร์ใต้ **เลเยอร์ GIS** เพื่อทำเช่นเดียวกันกับเลเยอร์ที่คุณเพียงแสดงไว้

## จุดสำรวจจากบล็อก

แบบสำรวจมักบรรจุจุดเป็นบล็อก: สัญลักษณ์เล็ก ๆ ที่แต่ละจุดยิง พร้อมแอตทริบิวต์สำหรับหมายเลขจุด คำอธิบาย และระดับความสูง เมื่อแบบมีการอ้างอิงบล็อก กล่องโต้ตอบจะมีส่วน **จุดสำรวจจากบล็อก**:

1. ติ๊กบล็อกที่จะนำเข้า (ตารางจะบอกว่าแต่ละบล็อกมีการอ้างอิงกี่รายการ อยู่บนเลเยอร์ใด และมีแอตทริบิวต์อะไร) หรือติ๊กเลเยอร์เพื่อนำการอ้างอิงบล็อกทั้งหมดบนเลเยอร์นั้น
2. เลือกว่า**หมายเลข** **คำอธิบาย** และ**ระดับความสูง** ของแต่ละจุดมาจากไหน: แอตทริบิวต์ ชื่อของบล็อกหรือเลเยอร์ หมายเลขว่างถัดไป หรือค่า Z ของจุดแทรก CivilCraft จะเริ่มจากแอตทริบิวต์ที่น่าจะเป็น (PT, DESC, ELEV และคล้ายกัน) และจะนำระดับความสูงจากแอตทริบิวต์ก็ต่อเมื่อบล็อกอยู่ที่ศูนย์
3. เอาติ๊กเลเยอร์เส้นออกหากต้องการเฉพาะจุด แล้วคลิก {{ui:เพิ่ม}}

แต่ละการอ้างอิงจะกลายเป็นจุดสำรวจหนึ่งจุดที่จุดแทรก นับเฉพาะการอ้างอิงที่วางในพื้นที่โมเดล บล็อกที่ซ้อนอยู่ในบล็อกอื่นจะไม่นับ หมายเลขที่มีอยู่แล้วในโปรเจกต์ หรือที่ใช้ซ้ำสองครั้งในแบบ จะได้หมายเลขใหม่ต่อจากค่าสูงสุด และแอตทริบิวต์ระดับความสูงที่ไม่ใช่ตัวเลขจะทำให้จุดนั้นไม่มีระดับความสูง แถบสถานะจะนับทั้งสองกรณี แบบจะไม่ถูกเปลี่ยนแปลงเลย และแต่ละจุดจะจำบล็อกของมัน คุณสมบัติจะแสดง **จากบล็อก** พร้อมชื่อบล็อก เลเยอร์ และ handle การเพิ่มจุดเป็นหนึ่งขั้นตอน ดังนั้น {{key:Mod+Z}} จะลบทั้งหมดได้ในครั้งเดียว

## ระดับที่เขียนเป็นข้อความ และการตรวจสอบ

ระดับจุดที่เขียนเป็นข้อความ (หรือในแอตทริบิวต์บล็อกที่ไม่ใช่บล็อกจุดสำรวจ) ไม่ใช่เส้น ส่วน **ระดับการสำรวจและการตรวจสอบ** สามารถนำมาเป็นจุดสำรวจได้ และแสดงรายการสิ่งที่ดูผิดปกติในแบบ: หน่วย ระบบพิกัด ระยะจากศูนย์ เส้นชั้นความสูงแบน ระดับที่แปลก จุดที่ซ้ำกัน ดู [ตรวจสอบแบบสำรวจเมื่อนำเข้า](topic:survey-check)

## วิธีอ่านแบบ

- ส่วนโค้ง วงกลม วงรี ส่วนโพลีไลน์ที่มีการโป่ง และสไปลน์จะกลายเป็นเส้นตรงสั้น ๆ (ทุกไม่เกิน 5°)
- การอ้างอิงบล็อกจะถูกวาดตรงตำแหน่งที่วาง บล็อกซ้อนก็เช่นกัน สิ่งที่บล็อกมีบนเลเยอร์ 0 จะใช้เลเยอร์ของการอ้างอิง
- วัตถุที่วาดในระนาบอื่น (ทิศทางการอัดรีดต่างกัน) จะถูกวางในพิกัดโลก
- วัตถุแต่ละชิ้นจะได้ฟิลด์สามฟิลด์: LAYER, TYPE (ชนิดวัตถุ) และ ELEV (ระดับความสูงเมื่อทุกจุดมีระดับเดียวกัน)
- พิกัดจะถูกนำมาตามที่เป็น แบบต้องใช้พิกัดเดียวกับโปรเจกต์ (เช่น โซน State Plane เดียวกัน) แบบที่เชื่อมโยง (xref) จะไม่ถูกเปิด: เปิดแยกต่างหาก

:::tip
แบบเส้นชั้นความสูงจะให้พื้นผิวที่ดีที่สุดเมื่อมีระดับจุดบางจุดบนยอดเขาและในหุบเขา ซึ่งเส้นชั้นความสูงเพียงอย่างเดียวจะทิ้งสามเหลี่ยมแบน เพิ่มเป็นจุดสำรวจ หรือจากเลเยอร์จุดในแบบ
:::

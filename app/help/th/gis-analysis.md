เมื่อโปรเจกต์มีเลเยอร์ GIS แล้ว (ดู [นำเข้าข้อมูล GIS](topic:gis-import)) ปุ่ม **วิเคราะห์** ในกลุ่ม GIS (พิมพ์ `GISANALYSIS`, `ANALYZE` หรือ `BUFFER`) จะเปิดพาเนลที่มีห้าแท็บ พาเนลนี้เปิดค้างอยู่ข้างผัง ดังนั้นสิ่งที่เลือกจะถูกวาดบนผังขณะที่ทำงาน

ทุกเครื่องมือที่สร้างผลลัพธ์จะ **เพิ่มเลเยอร์ใหม่** และคงเลเยอร์ที่ใช้อ่านไว้เหมือนเดิม แต่ละการทำงานคือหนึ่งขั้นของการเลิกทำ: {{ui:เลิกทำ}} ในพาเนล (หรือ Ctrl+Z) จะลบเลเยอร์ใหม่ออก ส่งออกผลลัพธ์เหมือนเลเยอร์อื่นได้ด้วย [ส่งออกข้อมูลตามที่สร้างจริงสำหรับ GIS](topic:gis-export) เป็น shapefile, GeoJSON หรือ GeoPackage

ตารางเต็มของเลเยอร์ ที่มีการเรียง แก้ไข และเครื่องคำนวณฟิลด์ อยู่ใน [ทำงานกับตารางแอตทริบิวต์ของเลเยอร์](topic:gis-table) การระบายสีตามฟิลด์อยู่ใน [กำหนดสไตล์เลเยอร์ตามแอตทริบิวต์](topic:gis-symbology)

ทุกอย่างทำงานบนผัง ด้วยหน่วยของโปรเจกต์ (ฟุตหรือเมตร) โปรเจกต์อยู่ในระบบฉายแผนที่หรือระบบท้องถิ่นเสมอ ดังนั้นระยะ 50 หมายถึง 50 ฟุตหรือ 50 เมตร ไม่ใช่องศา ค่าความสูง (z) จะไม่ถูกเก็บในผลลัพธ์

## บัฟเฟอร์

วาดโซนที่มีระยะกำหนดรอบแต่ละฟีเจอร์ เป็นเลเยอร์โพลีกอนใหม่ จุดกลายเป็นวงกลม เส้นกลายเป็นทางเดินที่ปลายมน โพลีกอนขยายออก ระยะ **ติดลบ** จะหดโพลีกอนลง (สี่เหลี่ยม 100 คูณ 100 หดลง 5 เหลือ 90 คูณ 90 หดลง 60 จะไม่เหลืออะไรเลย และพาเนลจะแจ้งไว้) ดึงระยะจากฟิลด์ตัวเลขเพื่อให้แต่ละฟีเจอร์มีระยะของตัวเอง หรือทำเครื่องหมาย **รวมบัฟเฟอร์ทั้งหมดเป็นรูปเดียว** เพื่อยุบรวม

ส่วนโค้งเป็นเส้นตรงสั้นๆ ที่วาดอยู่ด้านในของเส้นโค้งจริง ดังนั้นบัฟเฟอร์จะเล็กกว่าวงกลมที่แม่นตรงเล็กน้อย: ประมาณ 0.6 % ของพื้นที่ที่การตั้งค่าปกติ และ 0.16 % ที่ระดับละเอียด ใช้ระดับละเอียดกับสิ่งที่จะวัด

## ซ้อนทับ

| เครื่องมือ | ผลที่ได้ |
|---|---|
| ตัดกัน | ส่วนที่เลเยอร์ข้อมูลไปพบกับโพลีกอนซ้อนทับ แต่ละส่วนมีฟิลด์ของทั้งสองเลเยอร์ เส้นและจุดถูกตัดตามโพลีกอน |
| รวม | โพลีกอนของทั้งสองเลเยอร์ถูกตัดตามขอบของกันและกัน ส่วนที่ซ้อนกันมีฟิลด์ของทั้งสองเลเยอร์ ส่วนที่เหลือมีฟิลด์ของเลเยอร์เดียว (ฟิลด์ของอีกเลเยอร์จะว่าง) |
| ลบ | โพลีกอนของข้อมูลเข้า โดยนำโพลีกอนซ้อนทับออก ฟิลด์ยังเป็นของข้อมูลเข้า ฟีเจอร์ที่ถูกลบออกทั้งหมดจะไม่ถูกเก็บ (พาเนลนับจำนวนให้) |
| ยุบรวม | รวมโพลีกอนที่สัมผัสหรือซ้อนทับกัน ทั้งหมดหรือเป็นรูปเดียวสำหรับแต่ละค่าของฟิลด์ เพิ่ม `COUNT` และ `AREA` |

ชื่อฟิลด์ที่เลเยอร์ทั้งสองมีร่วมกันจะเก็บของเลเยอร์แรก ส่วนของเลเยอร์ที่สองจะเขียนด้วย `_2` ฟีเจอร์ภายในเลเยอร์เดียวไม่ควรซ้อนทับกันเอง เพราะหากซ้อนทับ การรวม (Union) จะนับส่วนที่ซ้อนในทั้งสองด้าน

## เชื่อม

การเชื่อมเชิงพื้นที่คัดลอกแอตทริบิวต์จากเลเยอร์ **ต้นทาง** ไปยังแต่ละฟีเจอร์ **เป้าหมาย** ที่มาบรรจบกัน และให้เลเยอร์ใหม่ที่มีรูปร่างของเป้าหมาย เลือกได้ว่าจะให้มาบรรจบกันเมื่อใด: สัมผัสหรือซ้อนทับ เป้าหมายอยู่ภายในโพลีกอนต้นทาง เป้าหมายครอบฟีเจอร์ต้นทาง ฟีเจอร์ต้นทางที่ใกล้ที่สุด (มีขีดจำกัดเลือกได้) หรือฟีเจอร์ต้นทางใดก็ได้ภายในระยะหนึ่ง

เมื่อฟีเจอร์ต้นทางหลายตัวตรงกัน จะใช้แอตทริบิวต์ของตัวแรก (ตัวที่ใกล้ที่สุดสำหรับการเชื่อมแบบใกล้ที่สุดและแบบระยะ โดยเพิ่ม `DISTANCE`) หรือ **นับจำนวนและรวมฟิลด์ตัวเลข**: `COUNT` และ `SUM_`, `MEAN_`, `MIN_`, `MAX_` สำหรับแต่ละฟิลด์ตัวเลข เอาเครื่องหมายถูกออกจาก **เก็บฟีเจอร์เป้าหมายที่ไม่พบรายการตรงกัน** เพื่อตัดฟีเจอร์เหล่านั้นทิ้ง ฟิลด์ที่เชื่อมจะว่างเมื่อไม่มีอะไรตรงกัน และพาเนลจะนับจำนวนที่ไม่ตรงกัน

## เลือก

พิมพ์คำถามเกี่ยวกับแอตทริบิวต์หรือรูปร่าง กด **เลือก** แล้วฟีเจอร์จะถูกวาดบนผังพร้อมจำนวน ตาราง และผลรวมพื้นที่ ความยาว หรือจำนวน จากนั้นทำให้เป็นเลเยอร์ของตัวเอง ซูมไปยังฟีเจอร์เหล่านั้น หรือล้างการเลือก

| สิ่งที่เขียนได้ | ตัวอย่าง |
|---|---|
| ฟิลด์ตามชื่อ ใช้ "อัญประกาศ" หรือ [วงเล็บเหลี่ยม] ถ้าชื่อมีช่องว่าง | `VALUE`, `"Lot Number"` |
| ตัวเลข, 'ข้อความ', true, false, null | `Use_ = 'Res'` |
| `=` `!=` `<>` `<` `<=` `>` `>=` | `VALUE >= 250` |
| `contains` `startswith` `endswith` `like` `ilike` (ข้อความไม่สนตัวพิมพ์; ใน `like` เครื่องหมาย `%` คือกลุ่มอักขระใดก็ได้ และ `_` คืออักขระหนึ่งตัว) | `Notes contains 'corner'` |
| `is null`, `is not null` (ค่าว่างนับเป็น null) | `Notes is null` |
| `in (…)`, `not in (…)`, `between … and …` | `Use_ in ('Com', 'Ind')` |
| `+ - * /` และวงเล็บ | `VALUE / 2 > 100` |
| `and`, `or`, `not` | `Use_ = 'Res' and VALUE > 200` |
| ค่าของรูปร่าง `$area` `$perimeter` `$length` `$x` `$y` `$vertices` | `$area > 5000` |

คำถามที่ไม่สมบูรณ์หรือระบุฟิลด์ที่เลเยอร์ไม่มี จะถูกปฏิเสธพร้อมประโยคที่บอกว่าปัญหาอยู่ตรงไหน

## วัด

แสดงพื้นที่และเส้นรอบรูปรวม ความยาวรวม หรือจำนวนรวมของเลเยอร์ และ **เพิ่มฟิลด์** ให้เลเยอร์: `AREA` และ `PERIMETER` สำหรับโพลีกอน `LENGTH` สำหรับเส้น (ความยาวบนผัง) `X` และ `Y` สำหรับจุด ฟิลด์ที่มีอยู่แล้วจะไม่ถูกเขียนทับ ฟิลด์ใหม่จะชื่อ `AREA_2` การทำงานนี้เป็นหนึ่งขั้นของการเลิกทำ **สถิติ** ให้จำนวน ผลรวม ค่าเฉลี่ย ค่าต่ำสุด และค่าสูงสุดของฟิลด์ตัวเลข โดยเลือกแยกตามค่าของฟิลด์อื่นได้

:::note
การตรวจสอบเบื้องหลังเครื่องมือเหล่านี้ทำด้วยมือในการทดสอบ (`node bin/test-civilcraft-gisanalysis.mjs`) เช่น แปลงที่ดินขนาด 100 คูณ 100 ภายใต้โซนขนาด 100 คูณ 80 ตัดกันได้ 3,000 บวก 3,000 และเส้นยาว 100 ที่ทำบัฟเฟอร์ด้วยระยะ 10 มีพื้นที่ 2,000 บวกวงกลม
:::

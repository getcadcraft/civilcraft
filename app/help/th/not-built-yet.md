CivilCraft ยังอยู่ในระยะเริ่มต้น หน้านี้แสดงสิ่งที่รุ่นปัจจุบันยังไม่ทำ เพื่อให้คุณไม่ต้องไปหา ไม่มีรายการใดในที่นี้ที่ถูกสัญญาว่าจะมีวันกำหนด

## จุด

| ยังไม่ได้สร้าง | แทนที่ในปัจจุบัน |
|---|---|
| เพิ่มไฟล์จุดไฟล์ที่สองเข้ากับไฟล์แรก | รวมไฟล์ในโปรแกรมแก้ไขข้อความหรือสเปรดชีตก่อน |
| ส่งออกไฟล์ข้อความของจุด | ส่งออก LandXML (จุดจะออกเป็น CgPoints) ใช้ {{ui:Export}} ของ GIS (จุดที่มีฟิลด์ P, N, E, Z และ D) หรือ {{ui:Copy}} จุดไปยังสเปรดชีต |
| รูปแบบป้ายจุด สัญลักษณ์ตามคีย์คำอธิบาย เส้นโค้ง (ส่วนโค้ง) จากรหัสเส้น ไฟล์คีย์คำอธิบายเพื่อแชร์ระหว่างโครงการ | ป้ายแสดงหมายเลข ระดับ และคำอธิบาย หรือน้อยกว่านั้น ([การตั้งค่า CivilCraft](topic:settings)) คีย์เก็บในไฟล์โครงการ |
| การแปลงหน่วย | แปลงไฟล์ก่อนนำเข้า **Units** เพียงเปลี่ยนป้ายกำกับ |

## พื้นผิว

| ยังไม่ได้สร้าง | แทนที่ในปัจจุบัน |
|---|---|
| พื้นผิวมากกว่าหนึ่งพื้นผิวที่สร้างจากจุด | หนึ่งโครงการต่อหนึ่งพื้นผิว |
| ซ่อนขอบเขต (ภายใน) | ใช้ **Longest outside edge** หรือขอบเขตด้านนอก |
| เลือกหรือแก้ไขเส้นแบ่งลาดที่วาดเพียงเส้นเดียว | {{key:Mod+Z}} หรือ {{ui:Remove drawn breaklines}} แล้ววาดใหม่ |
| แก้ไขพื้นผิวที่อ่านจาก LandXML (เส้นแบ่งลาด ขอบเขต) | {{ui:Rebuild the surface from the points}} |
| แก้ไขพื้นผิวที่สร้างจากกริดระดับความสูง | นำเข้ากริดอีกครั้งด้วยตัวเลือกอื่น |
| แปลงพื้นผิวที่อ่านจาก LandXML เมื่อระบบพิกัดเปลี่ยน | {{ui:Rebuild the surface from the points}} ก่อน |
| ค่าระดับจุดและค่าความลาดที่มีป้ายกำกับ | อ่านในแถบสถานะ หรือทำสีพื้นผิวตามความลาดด้วย **การวิเคราะห์ความลาด** ในพื้นที่ทำงานภูมิสถาปัตย์ ([การไล่ระดับสำหรับภูมิสถาปัตย์](topic:landscape-grading#grading-checks)) |

## เส้นแนวสายและโปรไฟล์

| ยังไม่ได้สร้าง | แทนที่ในปัจจุบัน |
|---|---|
| เกลียวอื่นนอกจากคลอทอยด์ เกลียวระหว่างโค้งสองโค้ง (การเปลี่ยนผ่านแบบผสม) | เกลียวคลอทอยด์ที่ปลายโค้งมีให้ใช้ เกลียวอื่นถูกระบุชื่อและข้ามเมื่อนำเข้า LandXML |
| แทรก PI ระหว่างอีกสองจุด | วาดเส้นแนวสายใหม่ หรือพิมพ์พิกัด PI ใหม่ |
| แนวสายจากวัตถุ ออฟเซ็ต การขยาย | วาดด้วย PI |
| พิมพ์ K สำหรับโค้งแนวดิ่ง | พิมพ์ L (แสดง K) |
| โค้งแนวดิ่งแบบวงกลมและไม่สมมาตร | โค้งพาราโบลาแบบสมมาตรเท่านั้น |
| มากกว่าหนึ่งโปรไฟล์ออกแบบต่อแนวสาย | หนึ่งแนวสายต่อหนึ่งตัวเลือก |
| ซูมมุมมองโปรไฟล์ แถบโปรไฟล์ใต้โปรไฟล์ | มุมมองโปรไฟล์พอดีกับแนวสายทั้งหมด พิมพ์บน[แผ่นแปลนและโปรไฟล์](topic:plan-profile-sheets) |
| ภาพตัดใน DWG หรือ LandXML | แผ่นภาพตัดเป็น PDF และ {{ui:CSV}} ของพื้นที่และปริมาตร |
| เส้นตัวอย่างที่เฉียง หรือความกว้างต่างกันตามถนน | ความกว้างหนึ่งค่าต่อด้านสำหรับทั้งแนวสาย |

## แนวถนน

| ยังไม่ได้สร้าง | แทนที่ในปัจจุบัน |
|---|---|
| เกาะกลาง แบริเออร์ และความลาดเอียงที่หมุนแม่แบบ | วาดเป็นแม่แบบ ([แม่แบบแนวถนน](topic:corridor-templates)) แม่แบบตามสถานียังไม่รองรับความลาดเอียง |
| การเปลี่ยนแปลงแบบค่อยเป็นค่อยไประหว่างแม่แบบของสองภูมิภาค (การเปลี่ยนผ่าน การเรียว) | เปลี่ยนแม่แบบที่สถานี หรือให้จุดมีเป้าหมายความกว้างไปยังเส้นที่วาดเป็นการเรียว |
| การหมุนรอบขอบ ความลาดเอียงใน LandXML | ความลาดเอียงหมุนรอบเส้นกึ่งกลางในโค้งวงกลม ขยายช่องจราจรด้วยเป้าหมายความกว้างไปยังเส้นลักษณะ |
| เป้าหมายสำหรับความลาดข้าง (เส้นจุดตัดลาดเอียงไปยังเส้นหรือพื้นผิว) และพื้นผิวแนวถนนของตัวเอง | เป้าหมายย้ายขอบผิวทางและไหล่ทาง ([แนวถนน](topic:corridor)) แนวถนนถูกปรับระดับลงในพื้นผิวที่เสนอ |
| มุมโค้งของขอบ ช่องเลี้ยว และเกาะที่ถูกปรับระดับในทางแยก ปลายถนนสายรองที่ตัดตามขอบถนนสายหลักบนมุมเฉียง ทางเดินที่เชื่อมกับถนนในแปลน ในความยาวและพื้นที่ | ถนนที่มาบรรจบถูกเชื่อมแบบมุมฉาก โดยเปิดขอบถนนสายหลักและปรับถนนสายรองให้ลงมาหาขอบ ([ที่ถนนมาบรรจบ](topic:corridor#where-roads-meet-roads-pads-and-paths)) ทางเดินหยุดที่ขอบถนนในพื้นผิวที่เสนอและใน 3D |
| ส่งออกแนวถนนเป็น LandXML roadways แนวถนนที่สองบนแนวสายในการส่งออก IFC | ส่งออกพื้นผิวที่เสนอ |
| แม่แบบภูมิประเทศที่เปลี่ยนพื้นผิวที่เสนอ ใน 3D หรือในภาพตัด | แม่แบบให้พื้นที่และปริมาตรของแต่ละชั้น ([แม่แบบภูมิประเทศ](topic:corridor-templates#terrain-templates)) |
| เส้นทางการหมุนของยานพาหนะที่มีความเร็ว การลื่นของยาง เวลาเลี้ยว ส่วนลากเลี้ยว หรือระยะห่างตัวถัง คลังยานพาหนะมาตรฐาน เส้นทางการหมุนที่ลากยานพาหนะ | เส้นทางการหมุนความเร็วต่ำตามเส้นลักษณะหรือแนวสาย พร้อมขนาดยานพาหนะของคุณเอง ([เส้นทางการหมุนของยานพาหนะ](topic:swept-paths)) |

## การปรับระดับและปริมาตร

| ยังไม่ได้สร้าง | แทนที่ในปัจจุบัน |
|---|---|
| ขั้นบันได (bench) เส้นลักษณะเปิดที่ถูกปรับระดับเข้าการออกแบบ การปรับระดับไปยังเส้นลักษณะจากที่อื่น | ปิดเส้นลักษณะ ([เส้นลักษณะ](topic:feature-lines)) หรือใช้เป็นเส้นแบ่งลาดของพื้นดินเดิม |
| เพิ่มหรือลบจุดยอดของเส้นลักษณะ | วาดเส้นใหม่ หรือทำการออฟเซ็ตเป็นขั้น |
| ส่วนโค้งในเส้นแบ่งลาดที่วาด (ผ่านจุดสำรวจ) เกลียวในเส้นลักษณะ | วาดเส้นลักษณะที่มีส่วนโค้ง แล้วใช้เป็นเส้นแบ่งลาดของพื้นดินเดิม |
| ปรับระดับไปยังระยะทาง ระดับความสูง หรือพื้นผิวอื่น | ปรับระดับลงพื้นดินเดิมเท่านั้น |
| เพิ่มหรือลบมุมแท่นฐาน | ลบแท่นและวาดใหม่ |
| ปริมาตรแบบ TIN-to-TIN (ปริซึม) การเลือกขนาดเซลล์กริด | วิธีกริด ขนาดเซลล์เลือกให้คุณ |
| การพองตัวและการหดตัว หน้าดิน ความลึกของผิวทาง | ใช้ตัวคูณกับตัวเลขที่รายงานด้วยตัวคุณเอง |
| ค่าขนส่งฟรีและค่าขนส่งเกิน การขนย้ายข้ามแนวสายต่างกัน บ่อยืม และที่ทิ้งที่วางบนแปลน | แผนภาพการขนดินพร้อมจุดสมดุล ปริมาณที่ย้าย และระยะขนส่งเฉลี่ย |

## ระบบท่อ

| ยังไม่ได้สร้าง | แทนที่ในปัจจุบัน |
|---|---|
| มากกว่าหนึ่งเครือข่ายต่อโครงการ | โครงการแยกสำหรับระบบระบายน้ำฝนและน้ำเสีย |
| ท่อจ่ายน้ำ: คุณภาพและอายุน้ำ การควบคุมตามกฎ ชนิดวาล์วอื่น (ควบคุมการไหล ลดการไหล รักษาความดัน) ปั๊มที่กำหนดด้วยกำลัง ความต้องการที่ขึ้นกับความดัน ตัวเลือก Darcy–Weisbach แคตตาล็อกท่อพร้อมความหนาผนังและชั้นความดัน ส่วนที่เหลือของเครือข่ายแรงดันอยู่ในแล็บ: [ท่อจ่ายน้ำ](topic:water-mains) | ตรวจสิ่งเหล่านั้นในซอฟต์แวร์จ่ายน้ำ อัตราการไหลของน้ำเสียเพื่อการออกแบบอยู่ใน [อัตราการไหลน้ำเสียเพื่อการออกแบบ](topic:sanitary-design) |
| การไหลของน้ำเสียตามเวลา (ไฮโดรกราฟ การเดินท่อแบบไดนามิก การกักเก็บ ปั๊ม น้ำล้น) | [อัตราการไหลน้ำเสียเพื่อการออกแบบ](topic:sanitary-design) ให้อัตราการไหลสูงสุดแบบคงที่ที่แผ่นออกแบบใช้ |
| ความจุของช่องรับน้ำ การกระจายของรางน้ำ การเดินท่อของการหน่วงน้ำ ไฮโดรกราฟ การสูญเสียพลังงานนอกจากค่าสัมประสิทธิ์ที่จุดต่อเดียว | ตรวจในซอฟต์แวร์อื่น อัตราการไหล ขนาด และเส้นระดับอยู่ใน [การระบายน้ำฝน](topic:storm-drainage) |
| แคตชเมนต์ในไฟล์ PDF plot, DWG, DXF หรือ LandXML แคตชเมนต์จากพื้นผิว (แนวสันเขา) | วาดแคตชเมนต์ด้วยมือ บันทึกในไฟล์โครงการ |
| แคตตาล็อกท่อ ท่อที่ไม่กลม โครงสร้างที่ไม่ใช่กล่องหรือทรงกระบอกตั้งตรง (กรวย ขั้น การทำขั้นบันได) หมวดระบายน้ำในไลบรารี | ชนิดโครงสร้างจากพารามิเตอร์ ([เครือข่ายท่อ](topic:pipe-network)) ท่อที่มีเส้นผ่านศูนย์กลาง |
| ท่อในมุมมองโปรไฟล์ ท่อโค้ง | อ่านระดับท้องท่อและความลึกกลบในพาเนลด้านขวา |

## แปลงที่ดิน

| ยังไม่ได้สร้าง | แทนที่ในปัจจุบัน |
|---|---|
| จัดแปลงตามพื้นที่หรือความยาวด้านหน้า แปลงจากเส้นรอบ ๆ สิทธิทาง | วาดแต่ละแปลงตามมุมของมัน หรือป้อนค่าเส้นทาง |
| ตารางโค้งและตารางเส้นบนแปลน ป้ายที่ย้ายด้วยมือ | ทุกช่วงเส้นมีป้ายกำกับตามแนวของมันเอง |
| แปลงในไฟล์ LandXML | แปลงถูกบันทึกในไฟล์โครงการ และส่งไป PDF, DWG และ DXF |

## โพลีกอนวัด (traverse)

| ยังไม่ได้สร้าง | แทนที่ในปัจจุบัน |
|---|---|
| การปรับแบบกำลังสองน้อยที่สุด กฎเวลา การถ่วงน้ำหนักมุมตามระยะทาง | กฎเข็มทิศ |
| มุมเบี่ยงเบน มุมเซนิทและระยะเอียง ระดับความสูงด้วยการวัดระดับตรีโกณมิติ | ลดเป็นระยะราบและมุมให้ถูกต้อง หรือใช้มุมทิศ |
| ระยะด้านข้าง ไฟล์ข้อมูลดิบจากเครื่องเก็บข้อมูล | นำเข้าจุดเป็นไฟล์จุด |

## การปักหมุด

| ยังไม่ได้สร้าง | แทนที่ในปัจจุบัน |
|---|---|
| หมุดอ้างอิงออฟเซ็ต (ตั้งห่างจากหมุด) หมุดลาดที่จุดตัด | ปักหมุดที่ออฟเซ็ตที่คุณต้องการ รวมถึงเลยขอบไหล่ทาง |
| ส่งหมุดตรงไปยังรูปแบบของเครื่องเก็บข้อมูล | ไฟล์ CSV เปิดได้ในซอฟต์แวร์สำนักงานของเครื่องเก็บข้อมูลส่วนใหญ่ |
| ปักหมุดท่อ แท่นฐาน และแปลง | ใช้จุดสำรวจใกล้แนวสาย หรือช่วงเส้นของแปลง |

## ไฟล์และผลลัพธ์

| ยังไม่ได้สร้าง | แทนที่ในปัจจุบัน |
|---|---|
| ข้อความ แฮตช์ และไดเมนชันจาก DWG หรือ DXF พื้นที่กระดาษ ภาพที่เชื่อมโยง (xref) DXF แบบไบนารี | งานเส้นจากพื้นที่โมเดลเปิดได้ ([เปิด DWG หรือ DXF เป็นงานเส้น](topic:open-dwg-dxf)) เปิดภาพที่เชื่อมโยงแยกต่างหาก |
| ย้ายหลายจุดพร้อมกันด้วยการลาก | ตัดและวางจุดเหล่านั้น หรือแก้ไขทีละจุด |
| แผ่นแนวตั้ง บล็อกชื่อเรื่องของคุณเอง วิวพอร์ตที่คุณจัดได้ แผ่นแปลนและโปรไฟล์ใน DWG | แผ่นแปลนแนวนอนหนึ่งแผ่นต่อ PDF หรือแผ่นแปลนและโปรไฟล์ตามแนวสาย (PDF) |
| พล็อตแถบระดับความสูงและโปรไฟล์ | แถบแสดงบนหน้าจอเท่านั้น ถ่ายภาพหน้าจอถ้าต้องการ |
| เปลี่ยนชื่อเลเยอร์ สี หรือสไตล์ป้าย | เปลี่ยนในโปรแกรม CAD หลังส่งออก DXF |
| บันทึกบนคลาวด์และประวัติเวอร์ชัน | บันทึกไฟล์ `.civilcraft.json` และสำรองไว้ เพื่อทำงานโครงการเดียวกันร่วมกัน ใช้เซสชันสดใน CadCraft Studio ([ออกแบบพื้นที่หนึ่งร่วมกันแบบสด](topic:work-live)) |
| CadCraft Studio สำหรับ iPad และ iPhone และจาก Google Play | ใช้ CivilCraft ในเบราว์เซอร์บนอุปกรณ์ บน Android ติดตั้ง CadCraft Studio จาก APK ที่ getcadcraft.com/download |
| เปิดไฟล์จุดหรือไฟล์โครงการหลายไฟล์พร้อมกัน | หนึ่งไฟล์ต่อการเปิดหนึ่งครั้ง (ไฟล์ GIS ที่เกี่ยวข้องกัน เช่น ส่วนประกอบของ shapefile เปิดพร้อมกันได้) |

## ภูมิสถาปัตย์

| ยังไม่ได้สร้าง | แทนที่ในปัจจุบัน |
|---|---|
| หัวและหัวฉีดของผู้ผลิต | หัวทั่วไป หรือเพิ่มหัวของคุณเองจากไฟล์ ข้อมูลของผู้ผลิตจะเข้ามาเมื่อพวกเขาอนุญาต |
| ความยาวด้านข้างสูงสุดของสายหยด อัตราการไหลตามเวลา ปั๊ม เครือข่ายท่อแบบวน | จำกัดสายหยดให้อยู่ในความยาวที่ผู้ผลิตประกาศ การตรวจต้องใช้เครือข่ายแบบแตกกิ่ง |
| รูปร่างเค้าโครงที่แน่นอนของวัตถุอิสระที่เว้า ปริมาตรใต้ดินที่วัดได้อย่างแม่นยำ | ปรับระดับเปลือกนูน และปริมาตรใต้ดินเป็นค่าประมาณ (แจ้งในคุณสมบัติ) |
| พืชในไลบรารีของ BimCraft และ ModelCraft ที่วางจากไลบรารี | ส่งออก IFC ภูมิสถาปัตย์และเปิดใน BimCraft คู่กับอาคาร |
| โมเดลพืชโดยละเอียด (ใบ กิ่ง ฤดูกาล) ในมุมมอง 3D วัตถุอิสระและระบบให้น้ำในมุมมอง 3D | พืชแสดงใน 3D เป็นรูปทรงง่าย ๆ ตามขนาดจากรายการพืช ([ดูไซต์ใน 3D](topic:site-3d)) การกระจายของ ModelCraft สร้างภาพการปลูก |
| กำแพงรับพื้นของระดับที่ปรับแล้วบนพื้นผิว | ให้แท่นหรือแท่นฐานมีด้านตั้ง จะเป็นกำแพงกันดินบนพื้นผิว ([การปรับระดับ](topic:grading)) |
| การแปลงแบบ SVG ในสัญลักษณ์ของคุณเอง พื้นผิวและสีของโมเดลพืช GLB ของคุณเอง เรขาคณิต GLB แบบบีบอัด | ทำการแปลงให้เรียบในโปรแกรมวาดก่อน โมเดลวาดด้วยสีของพืช ส่งออก GLB โดยไม่บีบอัด ([กราฟิกพืช](topic:plant-graphics)) |
| รายการพืชของคุณเองที่เก็บในบัญชีไลบรารีของคุณ (แก้ไขในแอป) | แก้ไขรายการของโครงการในตารางพืช และบันทึกเป็นไฟล์พืช |
| เครื่องมือภูมิสถาปัตย์สำหรับผู้ช่วยโดยไม่มีหน้าต่าง (เซิร์ฟเวอร์ไฟล์และบรรทัดคำสั่ง) | ทำงานได้เมื่อหน้าต่าง CivilCraft เปิดอยู่ ([ให้ผู้ช่วย AI ทำงานกับไซต์ของคุณ](topic:assistants)) |

## สายส่งไฟฟ้า

| ยังไม่ได้สร้าง | แทนที่ในปัจจุบัน |
|---|---|
| มาตรฐานของประเทศที่ติดตั้งไว้แล้ว (กรณีโหลด ระยะห่าง ตัวคูณ) | ตั้งค่ามาตรฐานของคุณใน {{ui:Load cases and limits…}} แล้วบันทึกพร้อมไลบรารีของคุณเป็นแพ็ก เพื่อนำกลับมาใช้และแชร์ ([แพ็ก](topic:sag-and-tension#packs-rules-and-a-library-for-a-country)) |
| ระยะด้านข้างจากสายตัวนำถึงยอดไม้หรือกำแพงข้างสาย | ระยะห่างในแนวดิ่งเหนือพืชและกำแพงที่สายข้าม ([การตรวจสายส่ง](topic:power-line-checks#clearances)) |
| การคืบของสายตัวนำและการยืดตัวของสายใหม่ | เผื่อไว้ผ่านอุณหภูมิในตารางการขึง |
| การจัดอันดับความร้อนของสายเคเบิลฝังดิน (กระแสที่จัดตามวิธีการวาง) | ใส่ค่ากระแสของซัพพลายเออร์บนรายการสายเคเบิล |
| การศึกษาลัดวงจร การป้องกัน และการลงกราวด์ | ใช้โปรแกรมไฟฟ้าโดยเฉพาะ CivilCraft ให้ความยาวและสายเคเบิลของเครือข่าย |
| เสาโครงเหล็กที่ออกแบบทีละชิ้น และสมอยึดในดิน | ตรวจค่ารับน้ำที่กำหนดของเสา สมอยึดตามแรงที่กำหนด |
| ไฟล์การศึกษา `.DON` ที่ตรวจในโปรแกรมที่อ่านมัน | ตรวจไฟล์ในโปรแกรมนั้น ส่งตัวอย่างมาให้เราเพื่อทดสอบกับไฟล์จริง |
| สายส่งในมุมมอง 3D และ IFC | แปลน โปรไฟล์สาย แผ่นงาน และเลเยอร์ GIS |
| เครื่องมือสายส่งสำหรับผู้ช่วยโดยไม่มีหน้าต่าง | ทำงานได้เมื่อหน้าต่าง CivilCraft เปิดอยู่ ([ให้ผู้ช่วย AI ทำงานกับไซต์ของคุณ](topic:assistants)) |

## GIS และระบบพิกัด

| ยังไม่ได้สร้าง | แทนที่ในปัจจุบัน |
|---|---|
| File Geodatabase สไตล์ KML ไอคอน การซ้อนพื้นดิน และลิงก์เครือข่าย | แปลงเป็น GeoPackage, shapefile หรือ GeoJSON ก่อน เครื่องหมายสถานที่ KML จะอ่านโดยไม่มีสไตล์ |
| แก้ไขฟีเจอร์ GIS หรือแอตทริบิวต์ | แก้ไขในโปรแกรม GIS แล้วนำเข้าอีกครั้ง พาเนลการวิเคราะห์สร้างเลเยอร์ใหม่ (บัฟเฟอร์ ซ้อนทับ เชื่อม การเลือก) และเพิ่มฟิลด์พื้นที่และความยาว แต่ไม่แก้ไขฟีเจอร์ในที่ |
| การวิเคราะห์เครือข่ายและราสเตอร์ บัฟเฟอร์ที่มีปลายเรียบหรือเหลี่ยมและบัฟเฟอร์ด้านเดียว การเพิ่มหรือลบแถวและเปลี่ยนชนิดของฟิลด์ในตารางแอตทริบิวต์ สีคลาสด้วยมือ คำอธิบายสไตล์ในการพล็อต | ใช้ Select เพื่อเลือกฟีเจอร์และสร้างเลเยอร์จากมัน ปลายเรียบไม่มีให้ การระบายสีตามแอตทริบิวต์และตารางแอตทริบิวต์มีให้แล้ว: ดู [กำหนดสไตล์เลเยอร์ตามแอตทริบิวต์](topic:gis-symbology) และ [ทำงานกับตารางแอตทริบิวต์ของเลเยอร์](topic:gis-table) |
| สไตล์ป้าย (ขนาด การวาง) และป้ายที่หลีกเลี่ยงกัน | ป้ายมีขนาดเดียว และอาจทับกันเมื่อฟีเจอร์หนาแน่น |
| ดาตัมแนวดิ่งและโมเดลจีออยด์ | ค่าระดับใช้ตามที่ไฟล์ให้ไว้ ตรวจดาตัมแนวดิ่งด้วยตัวคุณเอง |
| การเลื่อนกริดอื่นนอกจาก NAD27 เป็น NAD83 ตามพื้นที่ (OSTN15, NTv2 สำหรับดาตัมอื่นใช้ได้เมื่อคุณเพิ่มไฟล์) หลายกริดพร้อมกัน กริดแนวดิ่ง | เพิ่มไฟล์กริดสำหรับดาตัมของคุณเอง หนึ่งกริดต่อโครงการ |
| เลเยอร์แผนที่ในการส่งออก DXF หรือ 3D | เลเยอร์แผนที่ไปในการพล็อต PDF และคู่กับ DWG เป็นรูปภาพ |
| เซิร์ฟเวอร์แผนที่ที่ต้องลงชื่อเข้าใช้ คีย์ หรือโทเค็น | ใช้บริการสาธารณะ หรือไฟล์ภาพที่มีพิกัดอ้างอิง |
| เขียนไฟล์ LAS หรือ LAZ จากพื้นผิว โมเดลพื้นดิน หรือเครื่องมือกริดระดับความสูงและ LiDAR | ส่งออกพื้นผิวเป็นกริดระดับความสูง GeoTIFF ส่วนเสริม[จุดกลุ่มเมฆ](topic:point-clouds) เขียนกลุ่มเมฆที่ทำความสะอาดแล้วเป็น LAS 1.4 หรือ LAZ |
| ความเข้มและสี และการตอบกลับ (returns) ของ LiDAR กริดระดับความสูงที่มีหลายแถบ ไฟล์กริดหรือ LiDAR เกิน 200 MB | LiDAR กรองตามคลาสเท่านั้น กริดใช้แถบแรก ตัดไฟล์ขนาดใหญ่เป็นไทล์ก่อน |

## การป้อนข้อมูล

| ยังไม่ได้สร้าง | แทนที่ในปัจจุบัน |
|---|---|
| การเลือกกล่องด้วยการสัมผัส (ต้องใช้ {{key:Shift}}) | กดค้างที่จุดสำรวจแต่ละจุดเพื่อเพิ่ม |
| พิมพ์พิกัดหรือระยะขณะวาด | วาดคร่าว ๆ แล้วพิมพ์พิกัด PI ที่แน่นอนในตาราง PI ของแนวสาย |
| พิมพ์พิกัดสำหรับมุมแท่นฐานและโครงสร้าง | ลากกริปของมัน ซูมเข้าเพื่อความแม่นยำ และดู E และ N ในแถบสถานะ |
| การจับยึด (snap) กับวัตถุ (นอกจากจุดสำรวจสำหรับเส้นแบ่งลาด) | ซูมเข้าและดูแถบสถานะ |

## มุมมอง 3 มิติ

| ยังไม่ได้สร้าง | แทนที่ในปัจจุบัน |
|---|---|
| การวาดหรือแก้ไขในมุมมอง 3D | วาดและแก้ไขในแปลน มุมมอง 3D ตามทุกการแก้ไข |
| การเลือกเส้นลักษณะของแนวถนนหรือฟีเจอร์ GIS โดยคลิกใน 3D | คลิกในแปลน |
| การส่งออกมุมมองที่ขยายเกินจริง หรือเป็นฟุต | การส่งออกเป็นมาตราส่วนจริงเป็นเมตร ดู [ส่งออกไซต์ใน 3D](topic:export-3d) |
| ป้ายในการส่งออก GLB หรือ OBJ ขนาดและสไตล์ป้ายใน 3D | ป้ายแสดงใน 3D เท่านั้น ขนาดเดียว ดู [ดูไซต์ใน 3D](topic:site-3d) |
| พื้นผิวจากภาพถ่าย การบันทึกการขับรถเป็นวิดีโอ เงาจากนอกไซต์ ชั่วโมงแดดที่แสดงใน 3D | เลเยอร์แผนที่วางทับบนพื้นผิว ขับรถและตำแหน่งดวงอาทิตย์ ณ เวลาหนึ่ง [ชั่วโมงแดด](topic:sun-hours) สำหรับวันหรือฤดูบนแปลน |

CivilCraft ยังอยู่ในระยะแรก หน้านี้แสดงสิ่งที่บิลด์ปัจจุบันยังไม่ทำ เพื่อไม่ให้คุณต้องไปหา ไม่มีสิ่งใดในหน้านี้ที่สัญญาวันที่ไว้

## จุด

| ยังไม่ได้สร้าง | ทำแทนได้ตอนนี้ |
|---|---|
| การเพิ่มไฟล์จุดที่สองเข้าไฟล์แรก | รวมไฟล์ในโปรแกรมแก้ไขข้อความหรือสเปรดชีตก่อน |
| การส่งออกไฟล์ข้อความของจุด | ส่งออก LandXML (จุดจะออกเป็น CgPoints) ใช้ {{ui:ส่งออก}} ของ GIS (จุดที่มีฟิลด์ P, N, E, Z และ D) หรือ {{ui:คัดลอก}} จุดไปวางในสเปรดชีต |
| รูปแบบป้ายชื่อจุด สัญลักษณ์ต่อคีย์คำอธิบาย เส้นโค้ง (ส่วนโค้ง) จากรหัสเส้น ไฟล์คีย์คำอธิบายที่ใช้ร่วมกันระหว่างโปรเจกต์ | ป้ายชื่อแสดงหมายเลข ระดับความสูง และคำอธิบาย หรือน้อยกว่านั้น ([การตั้งค่า CivilCraft](topic:settings)) คีย์เก็บอยู่ในไฟล์โปรเจกต์ |
| การแปลงหน่วย | แปลงไฟล์ก่อนนำเข้า; **หน่วย** เพียงเปลี่ยนป้ายกำกับ |

## พื้นผิว

| ยังไม่ได้สร้าง | ทำแทนได้ตอนนี้ |
|---|---|
| มีพื้นผิวมากกว่าหนึ่งพื้นผิวที่สร้างจากจุด | หนึ่งโปรเจกต์ต่อหนึ่งพื้นผิว |
| ซ่อนขอบเขต (ภายใน) | ใช้ **ขอบด้านนอกที่ยาวที่สุด** หรือขอบเขตด้านนอก |
| การเลือกหรือแก้ไขเส้นแบ่งลาดที่วาดไว้เส้นเดียว | {{key:Mod+Z}} หรือ {{ui:นำเส้นแบ่งลาดที่วาดออก}} แล้ววาดใหม่ |
| การแก้ไขพื้นผิวที่อ่านจาก LandXML (เส้นแบ่งลาด ขอบเขต) | {{ui:สร้างพื้นผิวใหม่จากจุด}} |
| การแก้ไขพื้นผิวที่สร้างจากตารางระดับความสูง | นำเข้าตารางใหม่โดยเลือกตัวเลือกอื่น |
| การแปลงพื้นผิวที่อ่านจาก LandXML เมื่อระบบพิกัดเปลี่ยน | ใช้ {{ui:สร้างพื้นผิวใหม่จากจุด}} ก่อน |
| ระดับความสูงจุดพร้อมป้ายชื่อและค่าความลาดชัน | อ่านค่าจากแถบสถานะ หรือให้สีพื้นผิวตามความลาดชันด้วย **การวิเคราะห์ความลาดชัน** ในพื้นที่ทำงานภูมิทัศน์ ([การปรับระดับสำหรับภูมิทัศน์](topic:landscape-grading#grading-checks)) |

## แนวสายทางและโปรไฟล์

| ยังไม่ได้สร้าง | ทำแทนได้ตอนนี้ |
|---|---|
| สไปรัลอื่นนอกจากคล็อธอยด์ สไปรัลระหว่างเส้นโค้งสองเส้น (การเปลี่ยนผ่านแบบผสม) | สไปรัลคล็อธอยด์ที่ปลายของเส้นโค้งมีให้ใช้ ส่วนอื่นจะถูกตั้งชื่อและข้ามเมื่อนำเข้า LandXML |
| การแทรก PI ระหว่างอีกสองจุด | วาดแนวสายทางใหม่ หรือพิมพ์พิกัด PI ใหม่ |
| แนวสายทางจากวัตถุ ออฟเซ็ต การขยายความกว้าง | วาดด้วย PI |
| การพิมพ์ K สำหรับเส้นโค้งแนวดิ่ง | พิมพ์ L (ระบบแสดง K) |
| เส้นโค้งแนวดิ่งแบบวงกลมและไม่สมมาตร | เฉพาะเส้นโค้งพาราโบลาสมมาตร |
| มีโปรไฟล์การออกแบบมากกว่าหนึ่งต่อแนวสายทาง | หนึ่งแนวสายทางต่อหนึ่งตัวเลือก |
| การซูมมุมมองโปรไฟล์ แถบโปรไฟล์ใต้โปรไฟล์ | มุมมองโปรไฟล์จะพอดีกับทั้งแนวสายทาง และพิมพ์บน[แผ่นแผนและโปรไฟล์](topic:plan-profile-sheets) |
| หน้าตัดในไฟล์ DWG หรือ LandXML | แผ่นหน้าตัดเป็น PDF และ {{ui:CSV}} ของพื้นที่และปริมาตร |
| เส้นตัวอย่างที่เอียง หรือมีความกว้างต่างกันตามถนน | ความกว้างหนึ่งค่าในแต่ละด้านสำหรับทั้งแนวสายทาง |

## คอร์ริดอร์

| ยังไม่ได้สร้าง | ทำแทนได้ตอนนี้ |
|---|---|
| เกาะกลาง แนวกั้น และความลาดเอียงข้างที่หมุนแม่แบบ | วาดเป็นแม่แบบ ([แม่แบบคอร์ริดอร์](topic:corridor-templates)); แม่แบบตามสถานียังไม่รองรับความลาดเอียงข้าง |
| การเปลี่ยนแปลงแบบค่อยเป็นค่อยไประหว่างแม่แบบสองช่วง (การเปลี่ยนผ่าน การเรียว) | เปลี่ยนแม่แบบที่สถานี หรือให้จุดมีเป้าหมายความกว้างกับเส้นที่วาดเป็นส่วนเรียว |
| การหมุนรอบขอบ ความลาดเอียงข้างใน LandXML | ความลาดเอียงข้างหมุนรอบเส้นศูนย์กลางบนโค้งวงกลม; ขยายช่องจราจรด้วยเป้าหมายความกว้างไปยังเส้นฟีเจอร์ |
| เป้าหมายสำหรับลาดด้านข้าง (ลาดจนบรรจบเส้นหรือพื้นผิว) พื้นผิวคอร์ริดอร์ของตัวเอง | เป้าหมายจะเลื่อนขอบของผิวทางและไหล่ทาง ([คอร์ริดอร์](topic:corridor)); คอร์ริดอร์ถูกปรับระดับเป็นพื้นผิวที่เสนอ |
| คอร์ริดอร์ที่ส่งออกเป็นถนนใน LandXML คอร์ริดอร์ที่สองบนแนวสายทางในการส่งออก IFC | ส่งออกพื้นผิวที่เสนอ |
| แม่แบบภูมิประเทศที่เปลี่ยนพื้นผิวที่เสนอ ใน 3D หรือในหน้าตัด | ให้พื้นที่และปริมาตรของแต่ละชั้น ([แม่แบบภูมิประเทศ](topic:corridor-templates#terrain-templates)) |
| เส้นทางการกวาดรถที่มีความเร็ว การลื่นของยาง เวลาบังคับเลี้ยว รถพ่วงบังคับเลี้ยว หรือระยะห่างตัวรถ; คลังยานพาหนะการออกแบบมาตรฐาน; เส้นทางการกวาดที่วาดโดยการลากยานพาหนะ | เส้นทางการกวาดความเร็วต่ำตามเส้นฟีเจอร์หรือแนวสายทาง ด้วยขนาดยานพาหนะของคุณเอง ([เส้นทางการกวาดของยานพาหนะ](topic:swept-paths)) |

## การปรับระดับและปริมาตร

| ยังไม่ได้สร้าง | ทำแทนได้ตอนนี้ |
|---|---|
| เบิร์ม เส้นฟีเจอร์ที่เปิดซึ่งปรับระดับเข้าแบบ การปรับระดับไปยังเส้นฟีเจอร์จากที่อื่น | ปิดเส้นฟีเจอร์ ([เส้นฟีเจอร์](topic:feature-lines)) หรือใช้เป็นเส้นแบ่งลาดของพื้นดินเดิม |
| การแทรกหรือลบจุดยอดของเส้นฟีเจอร์ | วาดเส้นใหม่ หรือทำออฟเซ็ตแบบขั้นบันไดจากเส้นนั้น |
| ส่วนโค้งในเส้นแบ่งลาดที่วาด (ผ่านจุดสำรวจ) สไปรัลในเส้นฟีเจอร์ | วาดเส้นฟีเจอร์ที่มีส่วนโค้ง แล้วใช้เป็นเส้นแบ่งลาดของพื้นดินเดิม |
| การปรับระดับไปยังระยะ ระดับความสูง หรือพื้นผิวอื่น | ลาดเข้าหาพื้นดินเดิมเท่านั้น |
| การเพิ่มหรือลบมุมแท่นฐาน | ลบแท่นฐานแล้ววาดใหม่ |
| ปริมาตร TIN-ถึง-TIN (ปริซึม) การเลือกขนาดช่องตาราง | วิธีกริด ขนาดช่องเลือกให้โดยอัตโนมัติ |
| การพองตัวและการหดตัว หน้าดิน ความลึกของผิวทาง | นำตัวคูณไปใช้กับตัวเลขที่รายงานด้วยตัวคุณเอง |
| ต้นทุนการขนส่งฟรีและเกินระยะ การขนส่งข้ามแนวสายทางต่างกัน บ่อยืมและที่ทิ้งวางบนผัง | แผนภาพการขนดินพร้อมจุดสมดุล ปริมาตรที่ขนย้าย และระยะขนส่งเฉลี่ย |

## เครือข่ายท่อ

| ยังไม่ได้สร้าง | ทำแทนได้ตอนนี้ |
|---|---|
| มีมากกว่าหนึ่งเครือข่ายต่อโปรเจกต์ | โปรเจกต์แยกสำหรับระบายน้ำฝนและน้ำเสีย |
| ท่อประปาหลัก: คุณภาพและอายุน้ำ การควบคุมตามกฎ วาล์วชนิดอื่น (ควบคุมการไหล ลดแรงดัน ค่าคงที่) ปั๊มที่กำหนดด้วยกำลัง ความต้องการที่ขึ้นกับแรงดัน ตัวเลือก Darcy–Weisbach แคตตาล็อกท่อพร้อมความหนาผนังและชั้นแรงดัน เครือข่ายแรงดันส่วนที่เหลืออยู่ในช่วงทดลอง: [ท่อประปาหลัก](topic:water-mains) | ตรวจสอบเหล่านั้นในซอฟต์แวร์การกระจายน้ำ; อัตราการไหลออกแบบน้ำเสียอยู่ใน [อัตราการไหลออกแบบน้ำเสีย](topic:sanitary-design) |
| การไหลของท่อน้ำเสียตามเวลา (ไฮโดรกราฟ การกำหนดเส้นทางแบบไดนามิก การกักเก็บ ปั๊ม การล้น) | [อัตราการไหลออกแบบน้ำเสีย](topic:sanitary-design) ให้อัตราการไหลสูงสุดคงที่ที่แผ่นออกแบบใช้ |
| ความจุช่องรับน้ำ การกระจายของรางน้ำ การกำหนดเส้นทางการกักเก็บน้ำ ไฮโดรกราฟ การสูญเสียพลังงานนอกจากค่าสัมประสิทธิ์จุดต่อเดียว | ตรวจสอบในซอฟต์แวร์อื่น อัตราการไหล ขนาด และเส้นระดับพลังงานอยู่ใน [การระบายน้ำฝน](topic:storm-drainage) |
| พื้นที่รับน้ำในพล็อต PDF, DWG, DXF หรือ LandXML; พื้นที่รับน้ำจากพื้นผิว (ลุ่มน้ำ) | วาดพื้นที่รับน้ำด้วยมือ; บันทึกไว้ในไฟล์โปรเจกต์ |
| แคตตาล็อกท่อ ท่อที่ไม่กลม โครงสร้างที่ไม่ใช่กล่องหรือทรงกระบอกตั้งตรง (กรวย ขั้นบันได การทำขั้นบันได) หมวดการระบายน้ำในไลบรารี | ประเภทโครงสร้างจากพารามิเตอร์ ([เครือข่ายท่อ](topic:pipe-network)); ท่อที่มีเส้นผ่านศูนย์กลาง |
| ท่อในมุมมองโปรไฟล์ ท่อโค้ง | อ่านระดับท้องท่อและความลึกกลบในแผงด้านขวา |

## แปลงที่ดิน

| ยังไม่ได้สร้าง | ทำแทนได้ตอนนี้ |
|---|---|
| การจัดวางล็อตตามพื้นที่หรือหน้าแปลง แปลงจากเส้นรอบข้าง สิทธิทางผ่าน | วาดแต่ละแปลงด้วยมุม หรือป้อนรายการเส้นของแปลง |
| ตารางเส้นโค้งและตารางเส้นบนผัง ป้ายชื่อที่ย้ายด้วยมือ | ทุกช่วงเส้นมีป้ายชื่อไปตามตัวเอง |
| แปลงใน LandXML | แปลงบันทึกในไฟล์โปรเจกต์และออกไปยัง PDF, DWG และ DXF |

## โพลีกอนวัด (traverse)

| ยังไม่ได้สร้าง | ทำแทนได้ตอนนี้ |
|---|---|
| การปรับแก้กำลังสองน้อยที่สุด กฎทรานซิต การถ่วงน้ำหนักมุมกับระยะ | กฎคอมพาส |
| มุมเบี่ยงเบน มุมเซนิธ และระยะเอียง ระดับความสูงด้วยการระดับตรีโกณมิติ | ปรับเป็นระยะราบและมุมให้ถูกต้อง หรือใช้ทิศทาง |
| การยิงด้านข้าง ไฟล์ข้อมูลดิบจากเครื่องรับข้อมูล | นำเข้าจุดเป็นไฟล์จุด |

## การปักหมุด

| ยังไม่ได้สร้าง | ทำแทนได้ตอนนี้ |
|---|---|
| หมุดออฟเซ็ต (จุดอ้างอิงที่ตั้งห่างจากหมุด) หมุดลาดที่จุดรับ | ปักหมุดที่ออฟเซ็ตที่ต้องการ รวมถึงเกินไหล่ทาง |
| การส่งหมุดตรงเข้ารูปแบบของเครื่องรับข้อมูลเอง | CSV เปิดได้ในซอฟต์แวร์สำนักงานของเครื่องรับข้อมูลส่วนใหญ่ |
| การปักหมุดท่อ แท่นฐาน และแปลง | ใช้จุดสำรวจใกล้แนวสายทาง หรือรายการเส้นของแปลง |

## ไฟล์และผลลัพธ์

| ยังไม่ได้สร้าง | ทำแทนได้ตอนนี้ |
|---|---|
| ข้อความ แฮตช์ และไดเมนชันจาก DWG หรือ DXF; พื้นที่กระดาษ; แบบที่เชื่อมโยง (xref); DXF แบบไบนารี | เส้นจากพื้นที่โมเดลเปิดได้ ([เปิด DWG หรือ DXF เป็นเส้น](topic:open-dwg-dxf)); เปิดแบบที่เชื่อมโยงแยกต่างหาก |
| การย้ายหลายจุดพร้อมกันโดยการลาก | ตัดและวางจุด หรือแก้ไขทีละจุด |
| แผ่นแนวตั้ง ตารางชื่อเรื่องของคุณเอง วิวพอร์ตที่คุณจัดวาง แผ่นผังและโปรไฟล์ใน DWG | แผ่นผังแนวนอนหนึ่งแผ่นต่อ PDF หรือแผ่นผังและโปรไฟล์ตามแนวสายทาง (PDF) |
| การพล็อตแถบระดับความสูงและโปรไฟล์ | แถบแสดงเฉพาะบนหน้าจอ; ใช้ภาพหน้าจอหากต้องการ |
| การเปลี่ยนชื่อเลเยอร์ สี หรือรูปแบบป้ายชื่อ | เปลี่ยนในโปรแกรม CAD หลังส่งออก DXF |
| การบันทึกบนคลาวด์และประวัติเวอร์ชัน | บันทึกไฟล์ `.civilcraft.json` และสำรองไว้; เพื่อทำงานร่วมกันในโปรเจกต์เดียว ใช้เซสชันสด (live) ใน CadCraft Studio ([ออกแบบพื้นที่หนึ่งร่วมกันแบบสด](topic:work-live)) |
| CadCraft Studio สำหรับ iPad และ iPhone และจาก Google Play | ใช้ CivilCraft ในเบราว์เซอร์บนอุปกรณ์; บน Android ติดตั้ง CadCraft Studio จากไฟล์ APK ที่ getcadcraft.com/download |
| การเปิดไฟล์จุดหรือโปรเจกต์หลายไฟล์พร้อมกัน | หนึ่งไฟล์ต่อการเปิดหนึ่งครั้ง (ไฟล์ GIS ที่เกี่ยวข้องกัน เช่นส่วนประกอบของ shapefile จะเปิดพร้อมกัน) |

## ภูมิทัศน์

| ยังไม่ได้สร้าง | ทำแทนได้ตอนนี้ |
|---|---|
| หัวและหัวฉีดของผู้ผลิต | หัวทั่วไป หรือเพิ่มหัวของคุณเองจากไฟล์; ข้อมูลของผู้ผลิตจะเข้ามาเมื่อได้รับอนุญาต |
| ความยาวด้านข้างสูงสุดของสายหยด การไหลตามเวลา ปั๊ม เครือข่ายท่อแบบวงปิด | เก็บความยาวสายหยดให้ตามที่ผู้ผลิตเผยแพร่; การตรวจสอบต้องใช้เครือข่ายแบบแยกสาขา |
| เส้นขอบที่แน่นอนของวัตถุอิสระเว้า; ปริมาตรใต้ดินที่วัดได้อย่างแน่นอน | ปรับระดับเปลือกนูน (convex hull) และปริมาตรใต้ดินเป็นค่าประมาณ (แสดงในคุณสมบัติ) |
| พืชในคำสั่งวางจากไลบรารีของ BimCraft และ ModelCraft | ส่งออก IFC ภูมิทัศน์และเปิดใน BimCraft ข้างอาคาร |
| โมเดลพืชแบบละเอียด (ใบ กิ่ง ฤดูกาล) ใน 3D; วัตถุอิสระและระบบรดน้ำใน 3D | พืชแสดงใน 3D เป็นรูปทรงอย่างง่ายตามขนาดจากรายการพืช ([ดูไซต์ใน 3D](topic:site-3d)); การกระจายใน ModelCraft สร้างภาพการปลูกพืช |
| กำแพงฮาร์ดสเคปที่กั้นระดับที่ปรับแล้วไว้ด้านหลังบนพื้นผิว | ให้แท่นหรือแท่นฐานมีด้านตั้ง: จะเป็นกำแพงกันดินบนพื้นผิว ([การปรับระดับ](topic:grading)) |
| การแปลง SVG ในสัญลักษณ์ของคุณเอง พื้นผิวและสีของโมเดลพืช GLB ของคุณเอง รูปทรง GLB ที่บีบอัด | ทำให้การแปลงในแบบของคุณเรียบก่อนในโปรแกรมวาด; โมเดลวาดด้วยสีของพืช; ส่งออก GLB โดยไม่บีบอัด ([กราฟิกพืช](topic:plant-graphics)) |
| รายการพืชของคุณเองที่เก็บในบัญชีไลบรารี (แก้ไขในแอป) | แก้ไขรายการของโปรเจกต์ในตารางพืช แล้วบันทึกเป็นไฟล์พืช |
| เครื่องมือภูมิทัศน์สำหรับผู้ช่วยโดยไม่ต้องมีหน้าต่าง (เซิร์ฟเวอร์ไฟล์และบรรทัดคำสั่ง) | ทำงานเมื่อหน้าต่าง CivilCraft เปิดอยู่ ([ให้ผู้ช่วย AI ทำงานกับไซต์ของคุณ](topic:assistants)) |

## สายไฟฟ้าแรงสูง

| ยังไม่ได้สร้าง | ทำแทนได้ตอนนี้ |
|---|---|
| มาตรฐานของประเทศที่บิลต์อินมาให้ (กรณีโหลด ระยะห่าง ตัวคูณ) | ตั้งค่าของมาตรฐานของคุณใน {{ui:กรณีโหลดและขีดจำกัด…}} แล้วบันทึกพร้อมไลบรารีเป็นแพ็กเพื่อนำกลับมาใช้และแชร์ ([แพ็ก](topic:sag-and-tension#packs-rules-and-a-library-for-a-country)) |
| ระยะทางด้านข้างจากสายตัวนำถึงยอดต้นไม้หรือกำแพงข้างสาย | ระยะห่างแนวดิ่งเหนือพืชและกำแพงที่สายข้าม ([การตรวจสอบสายไฟฟ้า](topic:power-line-checks#clearances)) |
| การคืบของสายตัวนำและการยืดของสายใหม่ | คำนึงถึงสิ่งเหล่านี้ผ่านอุณหภูมิในตารางการขึง |
| พิกัดความร้อนของสายเคเบิลฝังดิน (พิกัดกระแสจากวิธีการวาง) | ป้อนพิกัดกระแสของผู้จำหน่ายในรายการสายเคเบิล |
| การศึกษาการลัดวงจร การป้องกัน และการต่อลงดิน | ใช้โปรแกรมไฟฟ้าโดยเฉพาะ; CivilCraft ให้ความยาวและสายเคเบิลของเครือข่าย |
| เสาโครงถักที่ออกแบบทีละชิ้นส่วน และสมอสายค้ำในดิน | โครงรองรับตรวจด้วยกรณีโหลดที่กำหนด; สายค้ำด้วยโหลดที่กำหนด |
| ไฟล์การศึกษา `.DON` ที่ตรวจในโปรแกรมที่อ่านไฟล์นั้น | ตรวจไฟล์ในโปรแกรมนั้น; ส่งตัวอย่างมาให้เราเพื่อทดสอบกับไฟล์จริง |
| สายไฟฟ้าแรงสูงใน 3D และ IFC | ผัง โปรไฟล์สายไฟ แผ่น และเลเยอร์ GIS |
| เครื่องมือสายไฟฟ้าแรงสูงสำหรับผู้ช่วยโดยไม่ต้องมีหน้าต่าง | ทำงานเมื่อหน้าต่าง CivilCraft เปิดอยู่ ([ให้ผู้ช่วย AI ทำงานกับไซต์ของคุณ](topic:assistants)) |

## GIS และระบบพิกัด

| ยังไม่ได้สร้าง | ทำแทนได้ตอนนี้ |
|---|---|
| File Geodatabase; รูปแบบ KML ไอคอน การซ้อนทับพื้นดิน และลิงก์เครือข่าย | แปลงเป็น GeoPackage, shapefile หรือ GeoJSON ก่อน; เครื่องหมายสถานที่ KML จะถูกอ่านโดยไม่มีรูปแบบ |
| การแก้ไขฟีเจอร์ GIS หรือแอตทริบิวต์ | แก้ไขในโปรแกรม GIS แล้วนำเข้าใหม่ แผงวิเคราะห์ (Analyze) สร้างเลเยอร์ใหม่ (บัฟเฟอร์ ซ้อนทับ รวม การเลือก) และเพิ่มฟิลด์พื้นที่และความยาว แต่ไม่แก้ไขฟีเจอร์ในที่เดิม |
| การวิเคราะห์เครือข่ายและแรสเตอร์ บัฟเฟอร์ที่มีปลายแบนหรือปลายสี่เหลี่ยมและบัฟเฟอร์ด้านเดียว การเพิ่มหรือลบแถว และการเปลี่ยนชนิดฟิลด์ในตารางแอตทริบิวต์ สีคลาสที่กำหนดเอง คำอธิบายสัญลักษณ์ในพล็อต | ใช้เลือกเพื่อเลือกฟีเจอร์และสร้างเลเยอร์จากฟีเจอร์นั้น; ไม่มีปลายแบน การระบายสีตามแอตทริบิวต์และตารางแอตทริบิวต์มีให้แล้ว: ดู [กำหนดสไตล์เลเยอร์ตามแอตทริบิวต์](topic:gis-symbology) และ [ทำงานกับตารางแอตทริบิวต์ของเลเยอร์](topic:gis-table) |
| รูปแบบป้ายชื่อ (ขนาด ตำแหน่ง) และป้ายชื่อที่หลีกเลี่ยงกัน | ป้ายชื่อมีขนาดเดียวและอาจทับกันเมื่อฟีเจอร์หนาแน่น |
| ดาตัมแนวดิ่งและแบบจำลองจีออยด์ | ใช้ระดับความสูงตามที่ไฟล์ให้มา; ตรวจสอบดาตัมแนวดิ่งด้วยตัวเอง |
| การเลื่อนกริดอื่นนอกจาก NAD83 จาก NAD27 ที่แนะนำตามพื้นที่ (OSTN15, NTv2 สำหรับดาตัมอื่นใช้ได้เมื่อคุณเพิ่มไฟล์) กริดหลายชุดพร้อมกัน กริดแนวดิ่ง | เพิ่มไฟล์กริดสำหรับดาตัมของคุณเอง; หนึ่งกริดต่อโปรเจกต์ |
| เลเยอร์แผนที่ในการส่งออก DXF หรือ 3D | เลเยอร์แผนที่ไปอยู่ในพล็อต PDF และอยู่ข้าง DWG เป็นภาพ |
| เซิร์ฟเวอร์แผนที่ที่ต้องเข้าสู่ระบบ คีย์ หรือโทเคน | ใช้บริการสาธารณะ หรือไฟล์ภาพที่จัดตำแหน่งทางภูมิศาสตร์แล้ว |
| การเขียนไฟล์ LAS หรือ LAZ จากพื้นผิว โมเดลพื้นดิน หรือเครื่องมือตารางระดับความสูงและ LiDAR | ส่งออกพื้นผิวเป็นตารางระดับความสูง GeoTIFF โดย[กลุ่มจุดเมฆ](topic:point-clouds) (ส่วนเสริม) เขียนกลุ่มเมฆที่ทำความสะอาดแล้วเป็น LAS 1.4 หรือ LAZ |
| ความเข้มข้น สี และการสะท้อนกลับของ LiDAR; ตารางระดับความสูงหลายแบนด์; ไฟล์กริดหรือ LiDAR ที่เกิน 200 MB | LiDAR กรองตามคลาสเท่านั้น ตารางใช้แบนด์แรก; ตัดไฟล์ขนาดใหญ่เป็นไทล์ก่อน |

## มุมมอง 3D

| ยังไม่ได้สร้าง | ทำแทนได้ตอนนี้ |

| การวาดหรือแก้ไขใน 3D | วาดและแก้ไขในผัง มุมมอง 3D จะตามทุกการแก้ไข |
| การเลือกเส้นฟีเจอร์ของคอร์ริดอร์หรือฟีเจอร์ GIS ด้วยการคลิกใน 3D | คลิกที่ผัง |
| การส่งออกมุมมองที่ขยายเกินจริงหรือเป็นฟุต | การส่งออกเป็นสเกลจริงในเมตร ดู [ส่งออกไซต์ใน 3D](topic:export-3d) |

| พื้นผิวจากภาพถ่าย การบันทึกการขับชมเป็นวิดีโอ เงาจากนอกไซต์ ชั่วโมงแดดที่แสดงใน 3D | เลเยอร์แผนที่ที่วางบนพื้นผิว; การขับชมและตำแหน่งดวงอาทิตย์ ณ เวลาเดียว; [ชั่วโมงแดด](topic:sun-hours) สำหรับวันหรือฤดูบนผัง |

แนวสายทางใน CivilCraft คือโซ่ของแทนเจนต์ที่ผ่านจุดตัด (PI) โดยมีโค้งวงกลมที่ PI ภายในใดก็ได้ที่มีรัศมี กำหนดสถานีจากสถานีเริ่มต้นที่คุณเลือก โปรเจกต์หนึ่งเก็บแนวสายทางได้หลายเส้น

## วาดแนวสายทาง

1. กด {{key:A}} หรือคลิก {{ui:Alignment}} ในกลุ่ม **ออกแบบ**
   คำใบ้จะขึ้นว่า "การจัดแนว: คลิก PI ตามลำดับ Enter หรือดับเบิลคลิกเพื่อจบ Backspace เพื่อลบ PI สุดท้าย Esc เพื่อยกเลิก"
2. คลิก PI แรก (จุดเริ่มต้นของแนวสายทาง)
3. คลิก PI ถัดไปตามลำดับ เส้นสีแดงจะตามตัวชี้และแสดงความยาวและทิศทางของแทนเจนต์ที่คุณกำลังวาด เช่น "212.40 ft  N 63°12'05" E"
4. คลิก PI สุดท้าย (จุดสิ้นสุดของแนวสายทาง)
5. กด {{key:Enter}}
   แนวสายทางจะถูกวาดพร้อมการกำหนดสถานีและถูกเลือก แถบสถานะจะแสดง เช่น "การจัดแนว 1: 386.36 ft, โค้งรัศมี 100 ft ในตำแหน่งที่พอดี แก้ไขรัศมีได้ที่คุณสมบัติ; โปรไฟล์ (R) เพื่อออกแบบความลาดของแนว"

ขณะวาด: {{key:Backspace}} ลบ PI สุดท้าย {{key:Esc}} ยกเลิก และการลากบนพื้นที่ว่างจะแพนโดยไม่เพิ่ม PI

:::warning
จบด้วย {{key:Enter}} การดับเบิลคลิกก็จบได้ แต่ในบิลด์นี้จะลบ PI ที่คุณดับเบิลคลิก คลิก PI สุดท้ายหนึ่งครั้ง แล้วกด {{key:Enter}}
:::

PI ภายในแต่ละจุดจะได้โค้ง 100 ft (30 m ในโปรเจกต์หน่วยเมตร) หรือรัศมีจำนวนเต็มที่ใหญ่ที่สุดที่พอดีกับครึ่งหนึ่งของแทนเจนต์แต่ละเส้น หาก 100 ft ไม่พอดี PI ที่แหลมมากหรือเป็นเส้นตรงจะไม่มีโค้ง

## ตั้งค่ารัศมีและพิกัด

เมื่อเลือกแนวสายทาง พาเนลด้านขวาจะแสดง **การจัดแนว**:

1. **ชื่อ** และ **สถานีเริ่มต้น** พิมพ์สถานีเป็น `10+00` (ฟุต) หรือ `0+500` (เมตร) หรือเป็นตัวเลขธรรมดา ดู [หน่วย สถานี และรูปแบบตัวเลข](topic:units-and-stations)
2. **ความยาว** และ **สถานีสิ้นสุด** คำนวณให้คุณ
3. ตาราง **PIs** แสดง **Easting** และ **Northing** ของแต่ละ PI และ **รัศมี** สำหรับ PI ภายในแต่ละจุด พิมพ์ค่าใหม่แล้วกด {{key:Enter}}
   - รัศมี 0 ทำให้เป็นจุดหักมุมที่ไม่มีโค้ง
   - PI แรกและ PI สุดท้ายไม่มีรัศมีเลย
   - กากบาทเล็กที่ท้ายแถวจะนำ PI นั้นออก (แนวสายทางต้องมีอย่างน้อยสองจุด)
4. อ่านรายการ **โค้ง**: สำหรับแต่ละโค้ง สถานี PC และ PT, รัศมี R, มุมเบี่ยงเบน Δ และทิศทาง (ซ้ายหรือขวา), ความยาว L, แทนเจนต์ T, ระยะภายนอก E และคอร์ด
5. บรรทัดใต้โค้งจะให้ทิศทางของแทนเจนต์แรก

## เมื่อโค้งไม่พอดี

ถ้าโค้งต้องใช้แทนเจนต์มากกว่าที่มีระหว่าง PI ของโค้ง แนวสายทางจะไม่มีคำตอบ: จะไม่ถูกวาดอย่างถูกต้องจนกว่าคุณจะแก้ไข และจะถูกตัดออกจากการส่งออก LandXML กล่องสีแดงจะบอกเหตุผลเป็นตัวเลข และเสนอค่าที่พอดี:

- "โค้งที่ PI 2 และ PI 3 ต้องใช้แทนเจนต์ 240.00 ft ระหว่างกัน (130.00 + 110.00) แต่ PI ห่างกัน 180.00 ft" หรือเมื่อมีโค้งเพียงหนึ่งเดียว "โค้งที่ PI 2 ต้องใช้แทนเจนต์ 240.00 ft ไปทาง PI 1 …"
- ปุ่มสำหรับแต่ละ PI จะตั้ง **รัศมีที่ใหญ่ที่สุดที่พอดี** ที่ PI นั้น โดยคงโค้งอีกด้านไว้ (ต้องพอดีกับแทนเจนต์อีกเส้นของ PI ด้วย) เมื่อ PI ทั้งสองมีโค้ง **ทั้งคู่** จะลดสองรัศมีตามสัดส่วนให้มาบรรจบพอดี
- เมื่อโค้งเดียวยาวกว่าแทนเจนต์เอง กล่องจะบอกว่าไม่มีโค้งที่ PI อีกด้านที่จะพอดีได้ขณะที่โค้งนั้นยังมีขนาดนี้
- PI ที่หักกลับตรง ๆ รับโค้งไม่ได้ กล่องจะเสนอ **ไม่มีโค้งที่ PI n**

แต่ละปุ่มเป็นหนึ่งขั้นตอน: {{key:Mod+Z}} คืนรัศมีเดิม รัศมีที่เสนอจะปัดลงถึง 0.01 เพื่อให้พอดีเสมอ

### รัศมีต่ำสุดของการออกแบบ

พิมพ์ **รัศมีต่ำสุดของการออกแบบ** (เช่น จากความเร็วออกแบบ) เพื่อให้ตรวจทุกโค้งกับค่านี้ เว้นว่างไว้หากไม่ต้องการ โค้งที่ต่ำกว่าค่านี้จะแสดงพร้อมปุ่มสำหรับ **รัศมีที่เล็กที่สุดที่ตรงตามค่าต่ำสุด** เมื่อรัศมีนั้นพอดี เมื่อไม่พอดี กล่องจะบอกและให้รัศมีที่ใหญ่ที่สุดที่แทนเจนต์รองรับได้ เพื่อให้คุณรู้ว่าต้องย้าย PI หรือลดค่าต่ำสุดลง

## ย้าย PI บนแผน

1. เมื่อ {{ui:Select}} ทำงานอยู่ คลิกแนวสายทางเพื่อเลือก จุดจับสี่เหลี่ยมจะปรากฏที่ PI ของมัน
2. ลากจุดจับ แนวสายทาง การกำหนดสถานี โปรไฟล์ และแนวถนนจะตามไป
3. ปล่อย การย้ายเป็นหนึ่งขั้นตอนที่เลิกทำได้

การเพิ่ม PI ระหว่าง PI สองจุดที่มีอยู่ยังไม่รองรับ: ลบแนวสายทางแล้ววาดใหม่ หรือพิมพ์พิกัดใหม่สำหรับ PI ที่มีอยู่

## อ่านสถานีและออฟเซ็ต

เลื่อนตัวชี้เหนือแผน แถบสถานะจะแสดงแนวสายทางที่ใกล้ที่สุด (หรือที่เลือก) พร้อมสถานีและออฟเซ็ต **L** หรือ **R** เมื่อมองไปตามสถานี เช่น "การจัดแนว 1: สถานี 2+15.30, ออฟเซ็ต 18.42 R" เลยปลายใดปลายหนึ่งจะเพิ่ม "(เลยปลาย)"

## สิ่งที่ถูกวาด

บนแผน ใน DXF และใน PDF: แนวศูนย์กลาง (แทนเจนต์เป็นเส้น โค้งเป็นส่วนโค้งจริง) ขีดทุก 50 ft (20 m) โดยขีดที่ยาวกว่าและป้ายสถานีทุก 100 หน่วย และขีด PC กับ PT พร้อมป้ายสถานี

## ความเร็วออกแบบและชั้น

ภายใต้คุณสมบัติของแนวสายทาง **ความเร็วออกแบบ** (km/h หรือ mph) และ **ชั้นการออกแบบ** จะถูกเก็บไว้กับแนวสายทาง บันทึกในโปรเจกต์และเขียนลง IFC (Pset_RoadDesignCriteriaCommon) CivilCraft ไม่มีตารางที่เชื่อมความเร็วกับรัศมี ดังนั้นไม่มีการตรวจสอบจากค่าเหล่านี้: ตั้ง **รัศมีต่ำสุดของการออกแบบ** ตามมาตรฐานการออกแบบของคุณเอง

## สไปรัล

โค้งสามารถมีสไปรัลแบบ clothoid ที่ปลายทั้งสองด้าน: แทนเจนต์ สไปรัล โค้ง สไปรัล แทนเจนต์ ในตาราง PI พิมพ์ความยาวใน **สไปรัลเข้า** และ **สไปรัลออก** สำหรับ PI ที่มีรัศมี PI คงอยู่ที่เดิม โค้งเลื่อนเข้ามาเพื่อเปิดที่ว่าง ทำให้ระยะแทนเจนต์เพิ่มขึ้นตามออฟเซ็ตของสไปรัล ความยาวทั้งสองอาจต่างกัน และ PI ที่มีความยาวเพียงค่าเดียวจะมีสไปรัลเฉพาะปลายนั้น

รายการโค้งจะแสดง TS, SC, CS และ ST (แทนเจนต์ไปสไปรัล, สไปรัลไปโค้ง, โค้งไปสไปรัล, สไปรัลไปแทนเจนต์) พร้อมมุมสไปรัล θs ระยะแทนเจนต์ และระยะภายนอก สถานีวิ่งไปตามสไปรัลเหมือนทุกที่ สไปรัลที่หมุนรวมกันมากกว่าโค้งจะถูกปฏิเสธพร้อมระบุชื่อ PI สไปรัลที่ยาวกว่าที่แทนเจนต์รองรับได้จะเป็นการทับซ้อน เช่นเดียวกับโค้งทุกแบบ ความเอียงยกขอบใช้สไปรัลเป็นช่วงลดระดับ (ดู [แนวถนน](topic:corridor))

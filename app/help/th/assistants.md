## สิ่งที่คุณจะได้เรียนรู้

วิธีให้ผู้ช่วย AI (ผู้ช่วยใดก็ได้ที่ใช้ MCP) ทำงานกับไซต์ที่คุณเปิดอยู่ สิ่งที่ทำได้และทำไม่ได้ และวิธีหยุดมัน

## ผู้ช่วยทำอะไรได้บ้างใน CivilCraft

| ต้องการ | ที่ได้รับ | ต้องใช้สิทธิ์ |
|---|---|---|
| ไซต์ | ชื่อ หน่วย ระบบพิกัด กลุ่มจุด แนวสายทาง พื้นผิว แท่น แปลงที่ดิน และท่อ | อ่าน |
| จุดสำรวจ | หมายเลข ค่าตะวันออก ค่าเหนือ ระดับความสูง และคำอธิบาย ตามกลุ่ม ตามคำอธิบาย หรือภายในกรอบ | อ่าน |
| ระดับพื้นผิว | พื้นดินเดิม (หรือพื้นผิวที่ปรับระดับแล้ว) ที่จุดใดก็ได้ที่ระบุ | อ่าน |
| สถานีและออฟเซ็ต | สถานีและออฟเซ็ตของจุดตามแนวสายทาง หรือพิกัดและระดับพื้นดินของสถานี | อ่าน |
| โปรไฟล์ | ระดับพื้นดิน โปรไฟล์ออกแบบ และพื้นผิวที่ปรับระดับแล้วตามแนวสายทาง ทุกระยะที่กำหนดเป็นฟุตหรือเมตร | อ่าน |
| ตัดและถม | ปริมาตรระหว่างพื้นดินเดิมกับพื้นผิวที่ปรับระดับแล้ว (ทุกแท่นและแนวถนนด้วย) หรือระหว่างพื้นดินกับระดับเรียบ | อ่าน |
| แปลงที่ดิน | มุม พื้นที่ (เป็นเอเคอร์หรือเฮกตาร์) เส้นรอบรูป และคำอธิบายทางกฎหมาย | อ่าน |
| การเลือก | จุดที่ระบุจะถูกเลือกบนแผน เสมือนคุณเลือกเอง | แก้ไข |
| จุดสำรวจใหม่ | จุดที่เพิ่มด้วยหมายเลขที่ให้มา หรือหมายเลขว่างถัดไป แต่ละครั้งที่เรียกเป็นหนึ่งขั้นตอนที่เลิกทำได้ | แก้ไข |
| บันทึก | {{ui:Save}} ของ CivilCraft เอง | บันทึก |
| LandXML หรือ DWG | ไฟล์เดียวกับปุ่ม {{ui:LandXML}} และ {{ui:DWG}} | ส่งออก |
| ไซต์ในรูป 3D | OpenUSD (.usdz, .usda หรือ .usdc) ของพื้นดิน พื้นผิวที่ปรับระดับ แท่น และท่อ ตามที่มุมมอง 3D ส่งออก | ส่งออก |
| พืชและตารางพืช | พืชที่พบในรายการพืชด้วยชื่อใดก็ได้ และจำนวนจากตารางพืช | อ่าน |
| การปลูกและการปรับระดับ | วางพืช แปลง หรือแนวพุ่มไม้ หรือเพิ่มแท่น คันดิน ร่องน้ำ หรือพื้นที่ปรับระดับ แต่ละอย่างเป็นหนึ่งขั้นตอนที่เลิกทำได้ พร้อมการตัดและถม | แก้ไข |
| การตรวจระบบน้ำ | อัตราการไหลของแต่ละโซน แรงดันที่ต้องการที่วาล์วและที่แหล่งจ่าย ค่าหัวน้ำกรณีแย่ที่สุด เวลารันระบบ ปัญหา และรายการวัสดุ เป็นเครื่องมือช่วยคำนวณที่ผู้ออกแบบระบบน้ำตรวจสอบ | อ่าน |

ผู้ช่วยทำงานกับไซต์ที่เปิดอยู่ ใน Studio ผู้ช่วยยังบันทึกและส่งออกไปยังโฟลเดอร์ที่คุณเลือกได้ (ด้านล่าง) หากไม่มีโฟลเดอร์ ไฟล์จะดาวน์โหลดเหมือนที่ปุ่มทำ

## เปิดใช้งาน

ผู้ช่วยเข้าถึง CivilCraft ผ่าน CadCraft Studio บนคอมพิวเตอร์ของคุณ เบราว์เซอร์ธรรมดาไม่มีทางเข้า

1. เปิด {{ui:Settings}} แล้วเลือกแท็บ **CivilCraft**
2. ภายใต้ **ผู้ช่วย** ติ๊ก **ให้ผู้ช่วย AI และสคริปต์ใช้ CivilCraft**
3. **อ่าน** ถูกติ๊กให้คุณแล้ว ติ๊ก **แก้ไข** **บันทึก** หรือ **ส่งออก** เฉพาะเมื่อผู้ช่วยต้องการ
4. หากต้องการให้ผู้ช่วยบันทึกและส่งออกไปยังโฟลเดอร์ ให้เลือก {{ui:Add a folder…}} ภายใต้ **โฟลเดอร์ที่ใช้ได้** แล้วเลือกโฟลเดอร์ในกล่องโต้ตอบของ Studio {{ui:Remove}} จะนำโฟลเดอร์นั้นออกทันที เส้นทางอื่นทุกเส้นจะถูกปฏิเสธ
5. เชื่อมต่อผู้ช่วยใน Studio (Studio แสดงที่อยู่และการตั้งค่าที่ต้องวางลงในผู้ช่วย)

## ขณะที่ผู้ช่วยเชื่อมต่ออยู่

ข้อความที่ด้านบนของพาเนลขวาจะบอกว่าผู้ช่วยใดเชื่อมต่ออยู่และทำอะไรได้ คลิก {{ui:Disconnect}} เพื่อจบเซสชันทันที ผู้ช่วยต้องเชื่อมต่อใหม่จึงจะทำงานต่อได้

**กิจกรรม** ภายใต้ **ผู้ช่วย** ในการตั้งค่า แสดงทุกการเรียกที่ผู้ช่วยทำ เรียงจากใหม่ไปเก่า พร้อมบอกว่าสำเร็จหรือไม่

:::tip
ถามด้วยคำพูดธรรมดา เช่น "ระดับพื้นดินทุก 50 ft ตามถนน Main Street เป็นเท่าไร?" "แท่นต้องตัดและถมเท่าไร?" หรือ "เพิ่มจุดควบคุมที่พิกัดเหล่านี้" ผู้ช่วยจะอ่านไซต์และตอบ หรือทำการเปลี่ยนแปลงเป็นหนึ่งขั้นตอนที่คุณเลิกทำได้
:::

## โดยไม่ต้องเปิด CivilCraft

เซิร์ฟเวอร์ไฟล์ของ CadCraft สำหรับผู้ช่วย (`npx @getcadcraft/mcp`) และบรรทัดคำสั่ง `cadcraft` เปิดโปรเจกต์ CivilCraft ที่บันทึกไว้ (`.civilcraft.json`) และไฟล์จุดด้วยโค้ดของ CivilCraft เอง โดยไม่มีหน้าต่าง: เครื่องมืออ่านชุดเดียวกัน การเพิ่มจุด การบันทึกโปรเจกต์ LandXML และไซต์ในรูป 3D เป็น OpenUSD `cadcraft convert site.civilcraft.json site.xml` เขียน LandXML จากบรรทัดคำสั่ง การเปิด LandXML การส่งออก DWG และเครื่องมือของพื้นที่ทำงาน Landscape ยังต้องใช้หน้าต่าง CivilCraft

## ปิดการใช้งาน

ยกเลิกการติ๊ก **ให้ผู้ช่วย AI และสคริปต์ใช้ CivilCraft** ผู้ช่วยทุกตัวจะถูกตัดการเชื่อมต่อทันที และการตั้งค่าจะถูกจำไว้สำหรับครั้งหน้า

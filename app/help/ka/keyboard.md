ერთასოიანი კლავიშები მუშაობს, როცა ველში ტექსტს არ წერთ. მალსახმობები {{key:Mod}}-ით იყენებენ Command-ს Mac-ზე და Ctrl-ს დანარჩენზე. ასევე იხილეთ [კლავიშები ბრაუზერში](common:keys).

## ფაილები და რედაქტირება

| კლავიში | მოქმედება |
|---|---|
| {{key:Mod+O}} | წერტილების ფაილის, LandXML-ის ან პროექტის გახსნა |
| {{key:Mod+S}} | პროექტის შენახვა (ჩამოიტვირთება `.civilcraft.json` ფაილი) |
| {{key:Mod+P}} | გეგმის გატანა PDF-ში (ხსნის გატანის დიალოგს, არა ბრაუზერის ბეჭდვას) |
| {{key:Mod+Z}} | დაბრუნება |
| {{key:Mod+Y}} | გამეორება |
| {{key:Delete}} | არჩეული კვლევის წერტილების, ტრასის, მოედნის, ნაგებობის, მილის ან PVI-ის წაშლა |
| {{key:Mod+C}} | არჩეული კვლევის წერტილების კოპირება (ასევე წერტილების სტრიქონებად ცხრილისთვის) |
| {{key:Mod+X}} | არჩეული კვლევის წერტილების ამოჭრა |
| {{key:Mod+V}} | წერტილების ჩასმა: ისინი მაჩვენებელს მიჰყვება, დააწკაპუნეთ, სადაც უნდა მოხვდნენ |
| {{key:Mod+Shift+V}} | ადგილზე ჩასმა: წერტილების საკუთარ კოორდინატებზე |
| {{key:Mod+D}} | არჩეული წერტილების დუბლირება: ასლი მაჩვენებელს მიჰყვება |
| {{key:Mod+A}} | ყველა კვლევის წერტილის არჩევა |
| {{key:Esc}} | არაფრის არჩევა (და ჩასმის გაუქმება) |

{{key:Mod+S}}, {{key:Mod+O}} და {{key:Mod+P}} მუშაობს ველში ტექსტის წერისასაც. {{key:Mod+Z}} და {{key:Mod+Y}} ტექსტურ ველში თქვენს აკრეფას აბრუნებს, როგორც ჩვეულებრივ, და ასევე {{key:Mod+C}}, {{key:Mod+X}}, {{key:Mod+V}} და {{key:Mod+A}}: ველში ისინი კოპირებენ, ჭრიან, ჩასვამენ და ირჩევენ მის ტექსტს. გვერდზე (პანელში) მონიშნულ ტექსტთან {{key:Mod+C}} ამ ტექსტს აკოპირებს. {{key:Mod+Shift+Z}} CivilCraft-ში არაფერს არ აკეთებს: გამოიყენეთ {{key:Mod+Y}} ან ღილაკი {{ui:გამეორება}}.

:::mac
Mac-ზე კლავიში, რომელსაც **delete** ეწერება, ბრაუზერისთვის {{key:Backspace}}-ია. არჩეულის წასაშლელად დააჭირეთ კლავიშს {{key:Delete}} (Fn და delete), ან აირჩიეთ {{ui:წაშლა}} ხელსაწყოთა პანელში {{ui:მეტი}} მენიუდან.
:::

## ეკრანი და დახმარება

| კლავიში | მოქმედება |
|---|---|
| {{key:F1}} | ამ დახმარების გახსნა ან დახურვა (გვერდითი პანელი); იგივეს აკეთებს აპლიკაციის ზოლში {{ui:დახმარება}} |
| {{key:Esc}} | დახმარების პანელის დახურვა, როცა ის ღიაა |
| {{key:Ctrl+Shift+F}} | ეკრანის რეჟიმების გადართვა: სრული ეკრანი, სრული ეკრანი ზოლების დამალვით, ჩვეულებრივი |
| {{key:Esc}} | სრული ეკრანიდან გასვლა (ბრაუზერის საკუთარი კლავიში) |

{{key:F1}} ბრაუზერში CivilCraft-მდე აღწევს, ამიტომ მუშაობს ნებისმიერ ხელსაწყოში. Mac-ის უმეტეს კლავიატურაზე დააჭირეთ fn-ს F1-თან ერთად, ან დააწკაპუნეთ ღილაკზე {{ui:დახმარება}}. {{key:Ctrl+Shift+F}} ყველა პლატფორმაზე იყენებს Control კლავიშს, მათ შორის Mac-ზეც. იხილეთ [დახმარების გამოყენება](common:help), თუ როგორ მოძებნოთ ეს დახმარება.

## მაუსი, სენსორული პანელი და შეხება

:::mouse
- ბორბალი მასშტაბირებს მაჩვენებელთან. მაუსი თავისუფლად მბრუნავი ბორბლით სწრაფად მასშტაბირებს: ატრიალეთ მოკლედ.
- ხედის გადაადგილება ცარიელ სივრცეზე ნებისმიერი გადათრევით, შუა ღილაკით, მარჯვენა ღილაკით, ან {{key:Space}} და გადათრევა.
:::

:::mac
Mac-ის სენსორულ პანელზე:

- ორი თითით სქროლვა **ასახლოვებს** (არ გადაადგილებს), და შეკუმშვაც ასახლოვებს.
- ხედის გადასაადგილებლად ერთი თითით დააჭირეთ და გადაათრიეთ ცარიელ სივრცეზე, ან ეკავოთ {{key:Space}} და გადაათრიოთ.
- ორი თითით დაწკაპუნება (მარჯვენა დაწკაპუნება) მენიუს არ ხსნის და თავისთავად არაფერს არ აკეთებს.
:::

:::touch
სენსორულ ეკრანზე:

- პირველი შეხება ღილაკებსა და მენიუს სტრიქონებს თითის ზომას აძლევს.
- შეხებით არჩევა ან წერტილის დასმა; ერთი თითით ცარიელ სივრცეზე გადათრევა ახდენს ხედის გადაადგილებას. შეხება შეიძლება ოდნავ გადაიხაროს: ხედი მხოლოდ მაშინ გადაადგილდება, როცა თითი დაახლოებით 10 პიქსელს გადაინაცვლებს.
- ორი თითით შეკუმშვა მასშტაბირებს, ერთად გადატანა კი ხედს გადაადგილებს.
- სახელურის ან PVI-ის გადათრევა ერთი თითით. სახელურებს გარშემო თითის სიგანის ზონა აქვთ.
- ტრასის, მოედნის, გარღვევის ხაზის, საზღვრის, მილის ხაზის, დამახასიათებელი ხაზის ან ნაკვეთის ხაზვისას გეგმის ზემოთ ზოლი გთავაზობთ {{ui:დასრულება}} ({{key:Enter}}), {{ui:წერტილის გაუქმება}} ({{key:Backspace}}) და {{ui:გაუქმება}} ({{key:Esc}}). გრძელი დაჭერა (ნახევარი წამი უმოძრაოდ) ასევე ასრულებს.
- {{ui:არჩევა}} ხელსაწყოში კვლევის წერტილზე გრძელი დაჭერა ამატებს მას არჩევანში ან ხსნის, როგორც {{key:Shift}}+დაწკაპუნება.
- 3D ხედში ერთი თითი ბრუნავს, ორი შეკუმშავს და გადააადგილებს, შეხება კი ირჩევს.
- შეხებით ეკრანზე ჰოვერი არ არის, ამიტომ მდგომარეობის ზოლის ჩვენებები მხოლოდ თითის დაჭერისას განახლდება.
:::

## ბრაუზერის კლავიშები, რომლებიც იმარჯვებს

ზოგი კლავიში ბრაუზერს ეკუთვნის და CivilCraft-ს არასდროს აღწევს, მაგალითად {{key:Mod+W}} (ჩანართის დახურვა), {{key:Mod+T}} (ახალი ჩანართი), {{key:Mod+N}} (ახალი ფანჯარა) და {{key:F11}} (სრული ეკრანი Windows და Linux ბრაუზერებში). CivilCraft მათ არ იყენებს. თუ მალსახმობი ბრაუზერში რამეს ხსნის, ერთხელ დააწკაპუნეთ გეგმაზე, რომ გვერდს ფოკუსი ჰქონდეს, და სცადეთ ხელახლა.

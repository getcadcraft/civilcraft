測量図面は、見た目が正しくても、地盤として見ると誤っている場合があります。単位が推定されていたり、等高線が高さ 0 で平坦に並んでいたり、標高が幾何ではない文字として書かれていたりします。{{ui:線データ}} ダイアログの**測量の標高と確認**セクション (参照: [DWG または DXF を線データとして開く](topic:open-dwg-dxf)) は、これらの標高を読み取り、何かを追加する前に問題の可能性を示します。

## 文字またはブロック属性として書かれた標高

多くの測量図面では、標高点は十字の横にある小さな文字 (`104.37` や `EL 104.37` など) や、点ブロックの属性として書かれています。これらは線ではないため、線データの読み取りでは除外されます。このセクションは見つかった件数を示し、それらを**測量点**として取り込むことができます。

1. **標高 … 件を測量点として取り込む**にチェックを付けます。初期状態はチェックなしです。図面内のすべての数値が高さとは限らないためです。
2. 文字は、単独の標高である場合に読み取ります。つまり、小数部のある数値 (`104.37`、`+104,37`、`-3.50`)、または `EL`、`ELEV`、`RL`、`FFL`、`GL`、`TW`、`BW`、`INV`、`Z`、`LEVEL` の後に続く数値 (後ろに任意で `m`、`ft`、`'` が付くことがあります) です。整数だけの数値 (`12`) は標高ではなく、区画番号や図面番号として扱われるため読み取りません。`GATE 3` や日付などの文字も読み取りません。文字書式のコードは無視されます。
3. ブロック属性の場合は、**標高を持つブロック属性**を選びます。CivilCraft は ELEV、Z、LEVEL、RL などの名前のタグを自動で見つけます。図面が独自のタグを使っている場合は、一覧から別のタグを選んでください。この選択は、このコンピューター上のそのファイル名について記憶されるため、再度開いたときも同じタグから始まります。選んだタグでは、整数も標高として扱われます。
4. {{ui:追加}} をクリックします。点には、プロジェクト内の最大番号の次から番号が振られ、各点にはレイヤー (またはブロック) による説明が付き、標高は図面の他の部分と同様にプロジェクトの単位へ換算されます。これらはすべて1回の操作として記録され、{{key:Mod+Z}} で点を取り消せます。

文字は、その挿入点 (または、設定がある場合は位置合わせ点) にあるものとして扱います。ブロック内の文字は読み取られず、図面は変更されません。

## 確認

確認は、これから取り込むデータに対して実行し、見つかった問題を種類ごとに1行ずつ一覧にします:

| 表示 | 意味 |
|---|---|
| **単位が指定されていません** | 図面に単位が書かれていないため、その数値はプロジェクトの単位として読み取られます。既知の距離を1つ確認してください。 |
| **単位を換算しました** | 図面の単位がプロジェクトと異なるため、拡大縮小されます (注意であり、不具合ではありません)。 |
| **データの範囲は … km** または **… m** | 範囲が 200 km より大きい、または 0.5 m より小さいことを示します。通常、単位の誤り (ミリメートルがメートルとして読まれた、またはその逆) を意味します。 |
| **座標系がありません** | プロジェクトに座標系がありません。データが国家座標系のように原点から遠くに位置する場合は警告になります。[座標系](topic:coordinate-systems) を参照してください。 |
| **原点から遠い** | データが原点から 100 km より遠くにあります。原点から遠いと、3D 表示や書き出しで精度が落ち、表示がぶれます。 |
| **等高線レイヤー … に高さがありません** | TOPO、CONT、CNTR、CONTOUR のような名前のレイヤーに、高さ 0 の線があります。そのため、これらから作成した地盤は平坦になります。 |
| **標高が正確に 0** | 典型的な標高から大きく外れて、標高が 0 のものがあります。おそらく標高の欠落です。 |
| **他から大きく外れた標高** | 他の標高から大きく外れた標高がいくつかあります (すべての標高の中央値との比較で判定するため、範囲の広い急斜面は対象になりません)。また、9,000 m を超える、または -11,000 m を下回る標高も対象です。 |
| **別の点と同じ位置にある点** | 同じ位置にあり、同じ標高、または異なる標高の2つの点です。 |

{{ui:追加}} をクリックした後、同じ内容が**問題**に、種類ごとに1件ずつ、ファイル名とともに送られるため、後から確認できます。確認は図面を判定するだけで、図面は何も変更せず、その図面を使うことを妨げません。

:::tip
確認で等高線が高さ 0 で平坦と示され、かつ文字として書かれた標高がある場合は、その標高を測量点として取り込んでください。等高線に欠けている実際の高さを、それらの標高が持っていることがよくあります。
:::

## 確認されない内容

確認は、図面を別の測量結果と比較しません。また、図面がどの座標系にあるかを判定できません。座標系が設定されていないことだけを示します。

{{ui:DXF}}は、平面図に表示されているものを R12 形式の DXF ファイルとして書き出します。R12 は、どのCADプログラムでも開ける版です。AutoCAD や Civil 3D を使ったことがあれば、ほかの DXF と同じように、開くか挿入してください。

## 書き出し

1. 図面に合わせて平面図を設定します。**表示設定**で、地表面 (現況または計画)、等高線の間隔、および表示する項目 (等高線、ラベル、点、点のラベル、三角形分割、地性線、地表面の端、管、勾配矢印) を選びます。
2. **書き出し**グループの{{ui:DWG/DXF}}をクリックし、{{ui:DXF (R12、テキスト) — 標準的な交換ファイル}} を選んでから、{{ui:ダウンロード}} をクリックします。
3. ブラウザーは `<name>.dxf` をダウンロードします。ステータスバーには、たとえば「R12 DXF を書き出しました: オブジェクト 2,140 個。ラベルは 1" = 40' の縮尺に合わせています。帯は書き出されません。」と表示されます。

座標は、プロジェクトの単位のまま実際の値で書き出されます (平面座標もそのまま)。拡大縮小や移動は行われません。

## ファイルの内容

| 項目 | DXF の要素 | レイヤー |
|---|---|---|
| 補助等高線と計曲線 | 標高位置の2Dポリライン | C-TOPO-MINR、C-TOPO-MAJR |
| 等高線のラベル | 文字 | C-TOPO-TEXT |
| 三角形分割 | ポリライン | C-TOPO-TINN |
| 地性線と境界 | 3Dポリライン | C-TOPO-BRKL |
| 地表面の端 | ポリライン | C-TOPO-BNDY |
| 勾配矢印 | ポリライン | C-TOPO-SLOP |
| 測量点とそのラベル | 点 (標高付き)、文字 | V-NODE、V-NODE-TEXT |
| 線コードによる線 | 3Dポリライン | V-NODE-LINE |
| 線形の中心線 | 線分と円弧 | C-ROAD-CNTR |
| 測点の目盛りとラベル | ポリライン、文字 | C-ROAD-STAN |
| コリドーの端 | ポリライン | C-ROAD-CORR |
| 横断測線 | ポリライン | C-ROAD-SCTN |
| 造成面、法尻線、勾配線 | ポリライン | C-GRAD-PADS、C-GRAD-DAYL、C-GRAD-SLOP |
| フィーチャーライン | 3Dポリライン (円弧は 0.01 以内の短い線分に分割。[フィーチャーライン](topic:feature-lines) を参照) | C-GRAD-FEAT |
| 走行軌跡 | ポリライン、文字 | C-ROAD-SWPT |
| 管、構造物、ラベル | ポリライン、文字 | C-STRM-PIPE、C-STRM-STRC、C-STRM-TEXT |
| 問題のある管と構造物 | ポリライン | C-STRM-PROB |

各レイヤーには色があります。全一覧は [平面レイヤー](topic:plan-layers) を参照してください。

## ラベルのサイズ

文字には、図面単位でのサイズが必要です。CivilCraft は、平面全体が Tabloid 用紙 (フィート) または A3 用紙 (メートル) に収まる縮尺に合わせてラベルのサイズを決め、その縮尺をステータスメッセージに表示します。別の縮尺で CAD プログラムから印刷する場合は、そこで文字の拡大縮小を行ってください。

## 書き出されないもの

- 標高帯 (画面表示のみ)。
- 縦断図。縦断は図面ではなく LandXML として書き出されます。
- 3Dオブジェクトとしての地表面そのもの。TIN には LandXML を使うか、{{ui:三角形分割}}をオンにして、その辺を線画として書き出してください。
- **表示設定**でオフにした項目。

## DWG

{{ui:DWG/DXF}}は、同じ線画を DWG 図面としても書き出せます。ダイアログで形式を尋ねられます: DXF、または 2000、2004、2007、2010、2013、2018 形式の DWG。2000 形式は、古いものも新しいものも、ほぼすべてのCADプログラムで開けます。図面を受け取る相手が指定したら、新しい版を選んでください。選択内容はこのブラウザーに記憶されます。

1. **書き出し**グループの{{ui:DWG}}をクリックします。
2. **形式**を選び、**DWG をダウンロード** をクリックします。
3. ブラウザーは `<name>.dwg` をダウンロードします。ステータスバーには、書き出された内容が表示されます。たとえば「DWG を書き出しました (2018 形式): ポリライン 12 本、ラベル 40 個、レイヤー 9 個」。

DWG には、DXF と同じレイヤー、色、等高線 (標高位置のポリラインとして)、3D の地性線、ラベル、点が、同じ座標で入ります。DWG で使えないレイヤー名は変更され、その旨がステータスメッセージに表示されます。CivilCraft は DWG を独自のコードで書き出すため、データがコンピューターの外へ送られることはありません。

### DWG 内の地図レイヤー

DWG 図面には画像を埋め込めません。CADプログラムでは、図面の横に置かれた画像として表示されます。地図レイヤーが表示されている場合、ダイアログに **図面の横に画像として置く地図レイヤー** が表示されます。これをオンにすると、ダウンロードは `.zip` ファイルになり、中に `<name>.dwg`、`<name>-map.png` (図面全体に重ねた地図レイヤー、幅は最大 4,096ピクセル)、`<name>-map.pgw` (GIS プログラム用のワールドファイル) が入ります。図面では、その画像がレイヤー G-MAP-IMAG 上の同じ位置に表示されます。ファイルはすべて1つのフォルダーに解凍し、まとめて保管してください。

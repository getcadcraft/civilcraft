線形を選択し、そのプロパティで**杭打ちレポート**をクリックします。

## 測点とオフセットでの杭

1. **開始**と**終了**: 杭を打つ測点 (1+50 または 150)。
2. **間隔**: 杭は間隔の倍数の位置に、両端に、そして (チェックを入れた場合は) 線形の曲線の始点と終点に打たれます。
3. **オフセット**: 測点方向を向いたときの線形の左と右: `12 L, 0, 12 R`、`L12 CL R12`、または `-12, 0, 12` (左はマイナス)。コリドーを含む線形では、舗装端と路肩から始まります。
4. **番号の開始**と**接頭語**で杭の名前を付けます: 1、2、3、または S101、S102。

## 線形の近くの測量点

**線形の近くの測量点**を選び、距離を指定します。その距離以内にある各点には、測点とオフセット、その位置の設計標高、そして地盤標高としてその点自身の標高が与えられます。これは、杭打ち済みまたは出来形として測量された点を確認するためのチェックです。

## レポートの内容

| 列 | 内容 |
|---|---|
| 点 | 杭の名前、または測量点の番号 |
| 測点, オフセット | 線形に沿った位置: L は左、R は右 |
| 北距, 東距 | 座標 |
| 設計標高 | その位置の造成済みコリドーの地表面 (法尻線から法尻線まで)。なければ中心線上の設計縦断 |
| 地盤標高 | その位置の既存地表面、または測量点自身の標高 |
| 切土/盛土 | 地盤が設計より高い場合は C (切り下げ)、低い場合は F (盛り上げ)。小数第2位まで |

設計標高のない杭 (コリドーの外、または中心線から離れた設計線形のない場所) には切土と盛土がありません。その件数はダイアログに表示されます。

## 保存する

- **CSV**: タイトル行、その後に上記の列と、符号付きの数値としての切土と盛土 (地盤から設計を引いた値) を出力します。表計算ソフトやデータ収集機器で使えます。
- **PDF**: 選択した用紙に表のページを出力します。1行に1杭を置き、切土はオレンジ、盛土は緑で表示し、他のシートと同じ表題欄を付けます。

:::note
杭は、プロジェクト内の設計から計算されます。何かを施工する前に、承認済みの図面と照合してください。
:::

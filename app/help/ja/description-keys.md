測量班は現場で、測定点のすべてにコードを付けます: 舗装端には `EP`、縁石の天端には `TC`、建物の角には `BLDG`。コードは、点の記述の最初の単語です。CivilCraft はそのコードで点をグループ化し、その後に続く線コードを線に変換します。

## 線コード

線コードは、フィールドコードの直後の単語です:

| 記述 | 意味 |
|---|---|
| `EP B` | この点から新しい舗装端の線を開始します |
| `EP` | 現在の EP の線を続けます |
| `EP E` | この点で現在の EP の線を終了します |
| `BLDG C` | 建物を閉じます。この点を線の最初の点に結び戻します |

同じコードの点は、点番号の順に結ばれます。異なるコードは、グループを共有していても別の線になります。そのため `EP1` と `EP2` は、同時に 2 つの辺を作ります。線コードを使わないコードは、以前のバージョンと同様に、そのすべての点を通って結ばれます。

グループの **地性線** として使用されるグループの線は、それぞれ 1 本の地性線になるため、隙間のある縁石がその隙間をまたいで伸びることはありません。他のグループの線は平面図に描かれ（レイヤー V-NODE-LINE）、DXF、DWG、PDF に出力されます。

開始、終了、閉合の単語は、`B`、`BEG`、`START`、`E`、`END`、`C`、`CLO`、`CLOSE` です。これらを変更するか、線コードをオフにするには、下のダイアログで行います。

## 記述キー

記述キーは、コードを点グループ、用途、詳細な記述に変換します。

1. **点数** の下で、{{ui:Description keys and line codes}} をクリックします。
2. {{ui:Add a key}} をクリックし、行に入力します:
   - **コード**: 一致させるフィールドコード。`*` は任意の文字列、`?` は 1 文字を表します。そのため `EP*` は EP、EP1、EP12 に一致します。
   - **グループ**: これらの点が参加する点グループ（空欄 = コード自体）。グループ `EP` の `EP*` は、EP1 と EP2 を 1 つのグループにまとめますが、それらは別々の線のままです。
   - **用途**: 点数、地性線、または除外。そのグループが最初に現れたときの用途です（または **点数** の表に任せます）。
   - **記述**: 長い名前。点の **プロパティ** に表示されます。
3. **点数** 列は、入力中に各キーが一致させる点の数を数えます。最初に一致したキーが優先されます。
4. {{ui:Apply}} をクリックします。グループ、地表面、平面図は 1 回の操作で従います: {{key:Mod+Z}} で元に戻せます。

グループは **点数** の表で設定された用途を保持します。キーの用途は、新しいグループにのみ設定されます。キーと線コードは、プロジェクトファイルに保存されます。

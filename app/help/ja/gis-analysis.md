GISレイヤーがあるプロジェクトでは（[GISデータのインポート](topic:gis-import)を参照）、GISグループの **分析** ボタン（`GISANALYSIS`、`ANALYZE`、`BUFFER` と入力）を押すと、5つのタブを持つパネルが開きます。パネルは平面図の横に開いたままになるため、選択したものは作業中も平面図に描画されます。

レイヤーを作成するツールはすべて、**新しいレイヤーを追加**し、読み取り元のレイヤーはそのまま残します。各操作は1回の元に戻す操作になります。パネルの {{ui:元に戻す}}（または Ctrl+Z）を押すと、新しいレイヤーが削除されます。結果は、[GIS向けに出来形データを書き出す](topic:gis-export)でシェープファイル、GeoJSON、GeoPackage として書き出せます。

レイヤーの全属性を表として表示し、並べ替え、編集、フィールド計算を行う方法は [GISレイヤーの属性テーブルの操作](topic:gis-table) を、属性の値で色分けする方法は [属性によるGISレイヤーのスタイル設定](topic:gis-symbology) を参照してください。

すべての操作は、プロジェクトの単位（フィートまたはメートル）で平面図上に行われます。プロジェクトは常に投影座標系またはローカル座標系で扱われるため、距離 50 は 50 フィートまたは 50 メートルを意味し、度を表すことはありません。高さ（z）は結果に保持されません。

## バッファー

各フィーチャーの周囲に、指定した距離の範囲を新しいポリゴンレイヤーとして描画します。点は円に、線は両端が丸い回廊に、ポリゴンは外側に広がります。**負の**距離を指定するとポリゴンは縮小します（100 by 100 の正方形を 5 縮小すると 90 by 90 になります。60 縮小すると何も残らず、パネルにその旨が表示されます）。距離は数値フィールドから取得して各フィーチャーごとに個別に設定できます。または **すべてのバッファーを1つの形状に結合** にチェックを入れると、それらをディゾルブできます。

円弧の部分は真の曲線の内側の直線で描かれるため、バッファーは正確な円よりわずかに小さくなります。通常の設定では面積の約0.6%、**精細** 設定では0.16%です。計測に使う場合は精細を使用してください。

## オーバーレイ

| ツール | 得られるもの |
|---|---|
| 交差 | 入力レイヤーがオーバーレイのポリゴンと交わる部分。各部分は両方のフィールドを持ちます。線と点はポリゴンでクリップされます。 |
| ユニオン | 両方のポリゴンレイヤーを、互いの辺に沿って切り分けます。共有部分は両方のレイヤーのフィールドを持ち、それ以外は一方のレイヤーのフィールドだけを持ちます（もう一方のフィールドは空になります）。 |
| 消去 | 入力ポリゴンから、オーバーレイのポリゴンを取り除いたもの。フィールドは入力側に残ります。完全に消去されたフィーチャーは含まれません（パネルに件数が表示されます）。 |
| ディゾルブ | 接している、または重なっているポリゴンを、すべてまたはフィールドの値ごとに1つの形状に結合します。`COUNT` と `AREA` を追加します。 |

両方のレイヤーにあるフィールド名は、1つ目のレイヤーのものが残り、2つ目のレイヤーのものは `_2` を付けて書き込まれます。1つのレイヤー内のフィーチャー同士は重ならないようにしてください。重なっている場合、ユニオンでは重なった部分が両方でカウントされます。

## 空間結合

空間結合は、**ソース**レイヤーの属性を、それと接する各**ターゲット**フィーチャーにコピーし、ターゲットの形状を持つ新しいレイヤーを作成します。接する条件は、接触または重なり、ターゲットがソースのポリゴン内にある、ターゲットがソースのフィーチャーを含む、最も近いソースのフィーチャー（任意で上限を指定）、または指定した距離内の任意のソースのフィーチャーから選びます。

一致するソースのフィーチャーが複数ある場合は、最初のフィーチャーの属性を使用します（最近傍結合と距離結合では最も近いもの。`DISTANCE` が追加されます）。または、件数を数えて数値フィールドを合計することもできます。`COUNT` と、数値フィールドごとの `SUM_`、`MEAN_`、`MIN_`、`MAX_` が追加されます。**一致するものがなかったターゲットフィーチャーを残す** のチェックを外すと、一致しないものは除外されます。結合したフィールドは、一致しなかった場合は空になり、一致しなかった件数がパネルに表示されます。

## 選択

属性または形状についての条件を入力し、**選択** を押すと、フィーチャーが件数、テーブル、合計面積、長さ、または数とともに平面図に描画されます。その後、それらを独自のレイヤーにしたり、そこへズームしたり、選択を解除したりできます。

| 書けるもの | 例 |
|---|---|
| フィールドを名前で指定。名前にスペースがある場合は "二重引用符" または [角かっこ] で囲む | `VALUE`、`"Lot Number"` |
| 数値、'テキスト'、true、false、null | `Use_ = 'Res'` |
| `=` `!=` `<>` `<` `<=` `>` `>=` | `VALUE >= 250` |
| `contains` `startswith` `endswith` `like` `ilike`（テキストは大文字と小文字を区別しません。`like` では `%` は任意の文字列、`_` は1文字） | `Notes contains 'corner'` |
| `is null`、`is not null`（空の値は null とみなします） | `Notes is null` |
| `in (…)`、`not in (…)`、`between … and …` | `Use_ in ('Com', 'Ind')` |
| `+ - * /` と括弧 | `VALUE / 2 > 100` |
| `and`、`or`、`not` | `Use_ = 'Res' and VALUE > 200` |
| 形状の値 `$area` `$perimeter` `$length` `$x` `$y` `$vertices` | `$area > 5000` |

不完全な条件や、レイヤーにないフィールドを指定した条件は、どこが問題かを示す文とともに拒否されます。

## 計測

レイヤーの合計面積と周長、長さ、または数を表示し、レイヤーに**フィールドを追加**します。ポリゴンには `AREA` と `PERIMETER`、線には `LENGTH`（平面上の長さ）、点には `X` と `Y` が追加されます。既存のフィールドが上書きされることはなく、新しいフィールドは `AREA_2` のように名付けられます。これは1回の元に戻す操作です。**統計** では、数値フィールドの件数、合計、平均、最小値、最大値を求めます。必要に応じて、別のフィールドの値ごとに計算することもできます。

:::note
これらのツールの検証は、テスト（`node bin/test-civilcraft-gisanalysis.mjs`）で手作業により行われています。例えば、100 by 100 の区画と 100 by 80 のゾーンの交差は 3,000 + 3,000、長さ 100 の線を距離 10 でバッファーすると 2,000 と円になります。
:::

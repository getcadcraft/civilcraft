## この記事で学べること

AIアシスタント(MCP に対応する任意のアシスタント)に、開いている敷地を扱わせる方法、その範囲、および停止する方法です。

## CivilCraft でアシスタントができること

| 要求内容 | 得られるもの | 必要な権限 |
|---|---|---|
| 敷地 | 名前、単位、座標系、点グループ、線形、地表面、造成面、区画、パイプ | 読み取り |
| 測量点 | 番号、東距、北距、標高、記述。グループ別、記述別、または枠内で | 読み取り |
| 地表面の標高 | 指定した点の現況地盤(または造成地表面) | 読み取り |
| 測点と偏距 | 線形に沿った点の測点と偏距、または測点の座標と地盤標高 | 読み取り |
| 縦断 | 線形に沿った、地盤、設計縦断、造成地表面の標高。指定した間隔(フィートまたはメートル単位)ごと | 読み取り |
| 切土と盛土 | 現況地盤と造成地表面の間の土量(各造成面とコリドーも含む)、または地盤と水平面の間の土量 | 読み取り |
| 区画 | 角、面積(エーカーまたはヘクタール)、周長、法定記述 | 読み取り |
| 選択 | アシスタントが指定した点を、あなたが選んだかのように平面図上で選択します | 編集 |
| 新規測量点 | 指定された番号、または次の空き番号で追加される点。各呼び出しは 1 回ずつ元に戻せる操作です | 編集 |
| 保存 | CivilCraft 自身の{{ui:Save}} | 保存 |
| LandXML または DWG | {{ui:LandXML}} と {{ui:DWG}} ボタンと同じファイル | 書き出し |
| 3D の敷地 | 地盤、造成地表面、造成面、パイプの OpenUSD(.usdz、.usda、.usdc)。3D ビューが書き出すもの | 書き出し |
| 植物と植物表 | 植物リストで任意の名前で見つかった植物、植物表の数量 | 読み取り |
| 植栽と造成 | 植栽、花壇、生け垣の配置、または平台、小段、排水路、造成区域の追加。各操作は 1 回ずつ元に戻せ、切土と盛土も含みます | 編集 |
| 散水の確認 | 各ゾーンの流量、バルブと供給部で必要な水圧、最悪ケースの揚程、運転時間、問題点、部品表。散水設計者が確認する計算の補助として | 読み取り |

アシスタントは、開いている敷地に対して動作します。Studio では、選んだフォルダーへの保存と書き出しも行えます(下記参照)。フォルダーを指定しない場合、ファイルはボタンと同様にダウンロードされます。

## 有効にする

アシスタントは、お使いのコンピューター上の CadCraft Studio を経由して CivilCraft に接続します。通常のブラウザーからは接続できません。

1. {{ui:Settings}} を開き、**CivilCraft** タブを選びます。
2. **アシスタント** の下で、**AIアシスタントとスクリプトに CivilCraft の使用を許可する** にチェックを付けます。
3. **読み取り** は既定でチェックされています。アシスタントに必要な場合のみ、**編集**、**保存**、または **書き出し** にチェックを付けます。
4. アシスタントにフォルダーへの保存と書き出しを許可する場合は、**使用できるフォルダー** の下で {{ui:Add a folder…}} を選び、Studio のダイアログでフォルダーを選択します。{{ui:Remove}} を押すと、すぐに取り消されます。それ以外のパスは拒否されます。
5. Studio でアシスタントを接続します(Studio に、アドレスと貼り付け用の設定が表示されます)。

## アシスタントが接続されている間

右パネルの上部に、接続中のアシスタントと、その可能な操作が表示されます。{{ui:Disconnect}} をクリックすると、すぐにセッションを終了します。続けるには、再度接続する必要があります。

設定の **アシスタント** の下にある **操作履歴** には、アシスタントが行ったすべての呼び出しが、新しいものから順に、成功したかどうかとともに表示されます。

:::tip
次のように、普通の言葉で依頼できます。たとえば「メインストリートに沿って 50 フィートごとの地盤標高は?」「造成面に必要な切土と盛土はどれくらい?」「これらの座標に基準点を追加して」。アシスタントは敷地を読み取って回答するか、元に戻せる 1 回の操作として変更を行います。
:::

## CivilCraft を開かずに

アシスタント向けの CadCraft ファイルサーバー(`npx @getcadcraft/mcp`)と `cadcraft` コマンドラインは、CivilCraft 独自のコードを使い、ウィンドウを開かずに、保存済みの CivilCraft プロジェクト(`.civilcraft.json`)と点ファイルを開きます。同じ読み取りツール、点の追加、プロジェクトの保存、LandXML と、OpenUSD としての 3D の敷地を扱えます。`cadcraft convert site.civilcraft.json site.xml` を実行すると、コマンドラインから LandXML が書き出されます。LandXML の読み込み、DWG の書き出し、ランドスケープワークスペースのツールには、引き続き CivilCraft のウィンドウが必要です。

## 無効にする

**AIアシスタントとスクリプトに CivilCraft の使用を許可する** のチェックを外します。すべてのアシスタントはすぐに切断され、設定は次回のために保存されます。

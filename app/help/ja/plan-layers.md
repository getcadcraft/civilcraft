平面上のすべてのオブジェクトは、いずれかのレイヤーに属します。レイヤー名は、一般的な土木のレイヤー規則（分野、主なグループ、細かいグループ）に従います。このビルドではレイヤーは固定されており、名前の変更、色の変更、独自のレイヤーの追加はできません。DXF では、各レイヤーに表示された色番号が使われます。PDF で{{ui:レイヤーの色}}を使用すると同じ色が使われ、{{ui:黒}}を使用するとすべてが黒で印刷されます。

| レイヤー | 含むもの | 色（DXF 番号） | 表示条件 |
|---|---|---|---|
| C-TOPO-MINR | 主曲線 | グレー (8) | {{ui:等高線}} |
| C-TOPO-MAJR | 計曲線 | 白または黒 (7) | {{ui:等高線}} |
| C-TOPO-TEXT | 等高線のラベル | 白または黒 (7) | {{ui:等高線}} と {{ui:等高線のラベル}} |
| C-TOPO-TINN | 三角形の辺 | グレー (8) | {{ui:三角形分割}} |
| C-TOPO-BRKL | 地性線と境界 | オレンジ (30) | {{ui:地性線}} |
| C-TOPO-BNDY | 地表面の端 | 白または黒 (7) | {{ui:地表面の端}} |
| C-TOPO-SLOP | 勾配の矢印 | シアン (4) | {{ui:勾配の矢印}} |
| V-NODE | 測量点 | 緑 (3) | {{ui:点数}} |
| V-NODE-TEXT | 点のラベル: 番号、標高、記述 | 緑 (3) | {{ui:点数}} と {{ui:点のラベル}} |
| V-NODE-LINE | 線コードによる線（地性線ではないグループ） | 緑 (3) | {{ui:点数}} |
| C-ROAD-CNTR | 線形の中心線 | 赤 (1) | 常に |
| C-ROAD-STAN | 測点の目盛りとラベル、PC と PT | 赤 (1) | 常に |
| C-ROAD-CORR | コリドーの縁 | 黄 (2) | 常に |
| C-ROAD-SCTN | 横断測線（断面を切る位置） | グレー (8) | 線形に横断測線がある場合 |
| C-GRAD-PADS | 造成面の輪郭 | 青 (5) | 常に |
| C-GRAD-DAYL | 法尻線 | マゼンタ (6) | 常に |

| C-STRM-PROB | 問題のある管と構造物 | 赤 (1) | {{ui:管}} |

地性線は、**表示**の**地表面**が{{ui:現況地盤}}のときだけ描かれます。境界はどちらの地表面でも描かれます。

## PDF の線の太さ

| 太さ | レイヤー |
|---|---|
| 0.50 mm | 線形の中心線、造成面の輪郭、管、問題のある管 |
| 0.35 mm | 計曲線、法尻線、構造物 |
| 0.25 mm | 地性線 |
| 0.13 mm | 主曲線 |
| 0.09 mm | 三角形の辺、造成の勾配線 |
| 0.18 mm | その他すべて |

DXF ファイルには線の太さは含まれません。CAD プログラムでレイヤーごとに設定してください。

## ラベルのサイズ

ラベルのサイズは用紙上で決まります。等高線のラベルは 2.0 mm、測点のラベルは 1.8 mm、PC と PT のラベル、管と構造物のラベルは 1.6 mm、点のラベルは 1.5 mm です。管のラベルは名前、直径、勾配を、構造物のラベルは名前と天端を表示します。画面上では、ズームしてもサイズは変わりません。DXF では、書き出しメッセージに示された縮尺に合わせて拡縮されます。[平面をDXFに書き出す](topic:dxf-export)を参照してください。

## どのレイヤーにも表示されないもの

標高帯は、画面上でのみ線の下に描かれます。縦断図は平面の一部ではありません。

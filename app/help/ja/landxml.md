LandXML は、多くの土木ソフトが読み書きするオープンなやり取り形式です。CivilCraft は LandXML 1.2 を読み書きします。Civil 3D を使っていた場合は、その LandXML のインポートとエクスポートのダイアログが最も近いものです。ここでは選択する項目はなく、除外された内容は注記に示されます。

## LandXML ファイルを開く

1. {{ui:開く}}（または {{key:Mod+O}} を押す）をクリックし、`.xml` または `.landxml` ファイルを選ぶか、平面図にドロップします。
2. 現在のプロジェクトに保存されていない変更がある場合、CivilCraft は先に確認します。{{ui:コピーを保存}}、{{ui:保存しない}}、{{ui:キャンセル}} から選びます。
3. **新しいプロジェクト** が作成されます。ステータスバーに、読み取った内容が表示されます（例:「site.xml を開きました: 412点、2地表面、3線形」）。
4. **地表面** の情報の下にあるボックスを確認します。読み飛ばされたもの、変更されたものが一覧表示されます。例:
   - 「地表面（"EG"）のみを開きました。ファイルにはあと1つあります。」
   - 「線形 "Ramp A" には、CivilCraft がまだ描けない要素があります（線、円弧、クロソイド緩和曲線以外）。読み飛ばしました。」
   - 「管網のルールはファイルにありませんでした。仮の値を使用しています。プロジェクトで設定してください。」

次の対応関係になります:

| ファイル内 | CivilCraft 内 |
|---|---|
| 単位（Imperial または Metric） | プロジェクトの **単位**（フィートまたはメートル） |
| プロジェクト名 | プロジェクトの **名前** |
| CgPoints | プロジェクトの点。説明（またはコード）がグループになります |
| 最初の TIN 地表面 | 現況地盤として、そのまま使用（「地表面（LandXML から）」） |
| 線、円弧、クロソイド緩和曲線のすべての線形 | 曲線から再構築された、PI、半径、緩和曲線長を持つ線形 |
| 各線形の最初の計画縦断 | 放物線の縦曲線を持つ計画縦断 |
| 最初の管網 | 天端、泥だめ、管底高を持つ管網 |
| 線と円弧の特徴線 | 円弧を保持した特徴線。他のプログラムからの場合は **描画のみ** で開始 |

要素と属性の全一覧は [LandXML: 読み書きする内容](topic:landxml-reference) にあります。

:::note
LandXML から読み込んだ地表面は、点グループを変更したり地性線を描いたりしても再構築されません。**地表面** セクションの {{ui:点から地表面を再構築}} をクリックすると、点から地表面を作り直せます（{{key:Mod+Z}} で LandXML の地表面に戻せます）。
:::

## LandXML を書き出す

1. **書き出し** グループの {{ui:LandXML}} をクリックします。
2. ブラウザーが `<name>.xml` をダウンロードします。ステータスバーに、書き出された内容が表示されます（例:「LandXML 1.2 を書き出しました: 276点、2地表面、1線形、管網。造成面はこの LandXML の対象外です。造成された地表面は対象です。」）。

ファイルには次が含まれます:

- **単位**: US 測量フィートまたはメートル。
- **CgPoints**: すべての点。番号を名前、説明を説明、グループを code として持ちます。
- **地表面**: 地性線と外周境界をソースデータとした TIN としての現況地盤。造成面やコリドーが造成されている場合は、"Proposed" という名前の2つ目の TIN 地表面。
- **線形**: 線、円弧、クロソイド緩和曲線と測点。PVI が2つ以上ある場合は、線形に沿ってサンプリングした現況地盤と計画縦断（PVI と放物線の曲線）を持つ縦断面。
- **管網**: 構造物（天端、泥だめ、管ごとの管底高）と、直径、長さ、勾配を持つ管。
- **PlanFeatures**: すべての特徴線。線と円弧として、各端の標高と用途とともに。

## 引き継がれないもの

- 造成面やコリドーのオブジェクト。その結果は "Proposed" 地表面にあります。
- エラーのある線形（例: 重なった曲線）。除外され、ステータスメッセージに数えられます。
- 両方の管底高がない管と、構造物が2つ未満のネットワーク。
- 地表面から取った天端は、固定された天端として書き出されます。再度開くと、地表面が変わっても構造物はその数値を保持します。
- 管網のルール（最小勾配、最小土被り、落差）。LandXML にはそれらを記録する場所がありません。
- 表示設定と点グループの地表面の選択。それらには CivilCraft プロジェクトを保存してください。

読み込み時、CivilCraft はクロソイド以外の緩和曲線、グリッド地表面、他の点を参照するだけの点、区画、平面特徴線内の緩和曲線、道路、測量データを読み取りません。それぞれは注記に示され、推測されることはありません。

## 往復作業

別の土木ソフトを使う人に作業を渡して戻してもらうには、LandXML を書き出し、編集してもらい、その LandXML を新しいプロジェクトとして開きます。CivilCraft の `.civilcraft.json` も保存してください。これは CivilCraft が扱うすべてを保持する唯一のファイルです。

1 文字のキーは、ボックスに入力していないときに機能します。{{key:Mod}} を使うショートカットは、Mac では Command、それ以外では Ctrl を使います。[ブラウザーでのキー](common:keys)も参照してください。

## ファイルと編集

| キー | 操作 |
|---|---|
| {{key:Mod+O}} | 点ファイル、LandXML、またはプロジェクトを開く |
| {{key:Mod+S}} | プロジェクトを保存（`.civilcraft.json` ファイルがダウンロードされます） |
| {{key:Mod+P}} | 平面図を PDF に印刷（ブラウザーの印刷ではなく、印刷ダイアログを開きます） |
| {{key:Mod+Z}} | 元に戻す |
| {{key:Mod+Y}} | やり直し |
| {{key:Delete}} | 選択した測量点、線形、造成面、構造物、管、または PVI を削除 |
| {{key:Mod+C}} | 選択した測量点をコピー（表計算ソフト用の点の行としてもコピー） |
| {{key:Mod+X}} | 選択した測量点を切り取り |
| {{key:Mod+V}} | 点を貼り付け: ポインターに従って動くので、置く位置をクリック |
| {{key:Mod+Shift+V}} | 同じ位置に貼り付け: 点それぞれの座標に貼り付け |
| {{key:Mod+D}} | 選択した点を複製: コピーがポインターに従って動く |
| {{key:Mod+A}} | すべての測量点を選択 |
| {{key:Esc}} | 選択解除（貼り付けもキャンセル） |

{{key:Mod+S}}、{{key:Mod+O}}、{{key:Mod+P}} は、ボックスに入力中でも機能します。テキストボックス内では、{{key:Mod+Z}} と {{key:Mod+Y}} は、通常どおり入力内容を元に戻し、やり直します。{{key:Mod+C}}、{{key:Mod+X}}、{{key:Mod+V}}、{{key:Mod+A}} も同様で、ボックス内では、テキストをコピー、切り取り、貼り付け、選択します。（パネル内の）ページ上でテキストを選択している場合、{{key:Mod+C}} はそのテキストをコピーします。{{key:Mod+Shift+Z}} は CivilCraft では機能しません。{{key:Mod+Y}} または {{ui:Redo}} ボタンを使ってください。

:::mac
Mac で **delete** と表示されているキーは、ブラウザーでは {{key:Backspace}} です。選択したものを削除するには、{{key:Delete}}（Fn と delete）を押すか、ツールバーの {{ui:More}} メニューから {{ui:Delete}} を選びます。
:::

## ツール

| キー | ツール |
|---|---|
| {{key:V}} | {{ui:Select}} |
| {{key:M}} | {{ui:Measure}}: 平面図上の距離、面積、勾配（[計測](topic:measure)） |
| {{key:A}} | {{ui:Alignment}} |
| {{key:G}} | {{ui:Pad}} |
| {{key:P}} | {{ui:Pipes}} |
| {{key:B}} | {{ui:Breakline}} |
| {{key:O}} | {{ui:Boundary}} |
| {{key:R}} | 縦断図を表示または非表示 |
| {{key:I}} | {{ui:Add PVIs}} をオンまたはオフにします（縦断図が閉じていれば開きます） |
| {{key:F}} | {{ui:Fit}}: すべてを表示 |
| {{key:D}} | {{ui:3D}}: 敷地を 3D で表示、または平面図に戻ります |
| {{key:E}} | すべてのフィーチャーラインに沿った勾配と標高を表示または非表示にします（画面上のみ） |

現在のツールのキーをもう一度押すと、{{ui:Select}} に戻ります。Shift と組み合わせた文字キーは機能しません。

## 描画中

| キー | 操作 |
|---|---|
| {{key:Enter}} | 線形、造成面、管路、地性線、境界線の描画を完了 |
| {{key:Backspace}} | 最後にクリックした点を削除 |
| {{key:C}} | フィーチャーライン: 円弧のオンとオフを切り替えます（頂点の後、曲線上の点をクリックし、その後その終点をクリック） |
| {{key:Esc}} | 描画（または貼り付け）をキャンセルします。もう一度押す（または何も描かれていない場合）と、{{ui:Select}} に戻り、選択を解除します |

## 平面図

| キーまたは操作 | 結果 |
|---|---|
| ホイール | ポインターの位置でズームイン/ズームアウト |
| 何もない場所をドラッグ | パン（どのツールでも可能。短くクリックすると通常どおりクリックになります。{{key:Shift}} を押しながらの場合は、代わりに選択ボックスを描きます） |
| 中ボタンでドラッグ | パン |
| 右ボタンでドラッグ | パン（メニューは開きません） |
| {{key:Space}} を押しながらドラッグ | パン |
| クリック | 選択（{{ui:Select}} で）、または点を配置（描画ツールで） |
| {{key:Shift}} を押しながらクリック | 測量点を選択に追加、または選択から外す |
| {{key:Shift}} を押しながらドラッグ | ボックスを描く: その中の測量点が選択に追加されます。[投げ縄](topic:lasso-selection)で囲むにはその周りをドラッグします |
| 投げ縄の描画中に {{key:Space}} | 窓選択、次に交差選択、次にフェンス |
| 貼り付け中にクリック | 貼り付けた点をそこに置きます（{{key:Enter}} で各点の座標に置きます） |
| グリップをドラッグ | PI、造成面の角、または構造物を移動（元に戻す 1 回分） |
| {{key:Up}} {{key:Down}} {{key:Left}} {{key:Right}} | 平面図にフォーカスがあるときにパン（先にクリックしてください） |
| {{key:Plus}} と {{key:Minus}} | 平面図にフォーカスがあるときに、中央でズームイン/ズームアウト |

= キーは {{key:Plus}} と同じくズームインするため、Shift は不要です。

## 縦断図

| 操作 | 結果 |
|---|---|
| {{ui:Add PVIs}} がオンの状態でクリック | その位置に PVI を追加 |
| PVI をクリック | 選択 |
| PVI をドラッグ | 移動（元に戻す 1 回分） |
| {{key:Delete}} または {{key:Backspace}} | 選択した PVI を削除（{{key:Backspace}} は縦断図にフォーカスがあるときのみ） |

縦断図はズームもパンもしません。

## 画面とヘルプ

| キー | 操作 |
|---|---|
| {{key:F1}} | このヘルプ（サイドパネル）を開く、または閉じる。アプリバーの {{ui:Help}} も同じ働きをします |
| {{key:Esc}} | ヘルプパネルが開いているときは閉じる |
| {{key:Ctrl+Shift+F}} | 画面モードを切り替え: 全画面表示、バーを非表示にした全画面表示、通常 |
| {{key:Esc}} | 全画面表示を終了（ブラウザー自身のキー） |

{{key:F1}} は CivilCraft より先にヘルプに届くため、どのツールでも機能します。ほとんどの Mac キーボードでは、fn と F1 を押すか、{{ui:Help}} をクリックします。{{key:Ctrl+Shift+F}} は、Mac を含むすべてのプラットフォームで Control キーを使います。このヘルプの検索方法は、[ヘルプの使い方](common:help)を参照してください。

## マウス、トラックパッド、タッチ

:::mouse
- ホイールでポインターの位置をズームします。自由回転するホイールのマウスは素早くズームするため、短く回してください。
- 何もない場所のドラッグ、中ボタン、右ボタン、または {{key:Space}} を押しながらのドラッグでパンします。
:::

:::mac
Mac のトラックパッドでは:

- 2 本指のスクロールで **ズーム** します（パンはしません）。ピンチでもズームします。
- パンするには、1 本指で何もない場所を押してドラッグするか、{{key:Space}} を押しながらドラッグします。
- 2 本指のクリック（右クリック）ではメニューは開かず、それ自体では何もしません。
:::

:::touch
タッチスクリーンでは:

- 最初のタッチで、ボタンとメニューの行が指で触れやすい大きさになります。
- タップで選択または点の配置を行います。1 本指で何もない場所をドラッグするとパンします。タップは少しぶれることがあります。指が約 10 ピクセル動いたときにのみパンします。
- 2 本指のピンチでズーム、2 本指を一緒に動かすとパンします。
- 1 本指でグリップまたは PVI をドラッグします。グリップは、指の幅ぶんの範囲を掴みます。
- 線形、造成面、地性線、境界線、管路、フィーチャーライン、区画を描いているときは、平面図の上のバーに {{ui:Finish}}（{{key:Enter}}）、{{ui:Undo point}}（{{key:Backspace}}）、{{ui:Cancel}}（{{key:Esc}}）が表示されます。長押し（動かさずに約 0.5 秒）でも完了します。
- {{ui:Select}} で、測量点を長押しすると、{{key:Shift}}+クリックと同じように選択に追加または選択から外します。
- 3D ビューでは、1 本指で軌道回転、2 本指でピンチとパン、タップで選択します。
- タッチにはホバーがないため、ステータスバーの表示は指が触れている間のみ更新されます。
:::

## ブラウザーが優先するキー

一部のキーはブラウザーに属し、CivilCraft には届きません。たとえば {{key:Mod+W}}（タブを閉じる）、{{key:Mod+T}}（新しいタブ）、{{key:Mod+N}}（新しいウィンドウ）、{{key:F11}}（Windows と Linux のブラウザーでの全画面表示）です。CivilCraft はこれらを使いません。ショートカットでブラウザー側の何かが開く場合は、平面図を 1 回クリックしてページにフォーカスを移し、もう一度試してください。

## 移動の場所

移動コマンドはありません。{{ui:Select}} を選び、点または頂点をドラッグするか、{{ui:Properties}} で座標を編集します。[点を編集](topic:edit-points)を参照してください。

CivilCraft の線形は、交点(PI)を通る接線の連なりです。半径を持つ中間の PI には円曲線が付きます。線形は、選んだ開始測点から測点が振られます。1 つのプロジェクトに複数の線形を含めることができます。

## 線形を描く

1. {{key:A}} を押すか、**設計**グループの {{ui:Alignment}} をクリックします。
   ヒントには「アラインメント: PI を順にクリックします。Enter キーまたはダブルクリックで完了、Backspace で最後の PI を削除、Esc でキャンセル。」と表示されます。
2. 最初の PI(線形の始点)をクリックします。
3. 以降の PI を順にクリックします。描いている接線の長さと方位を、赤い線がポインターに追従して示します(たとえば "212.40 ft  N 63°12'05" E")。
4. 最後の PI(線形の終点)をクリックします。
5. {{key:Enter}} を押します。
   線形が測点付きで描かれ、選択されます。ステータスバーには、たとえば「アラインメント 1: 386.36 ft、収まる箇所は半径 100 ft の曲線。半径はプロパティで編集、縦断 (R) で勾配を設計。」と表示されます。

描画中は、{{key:Backspace}} で最後の PI を削除し、{{key:Esc}} でキャンセルします。何もない場所をドラッグすると、PI を追加せずに画面を移動します。

:::warning
{{key:Enter}} で完了してください。ダブルクリックでも完了しますが、このビルドではダブルクリックした PI が削除されます。最後の PI を一度クリックしてから {{key:Enter}} を押してください。
:::

中間の各 PI には、100 ft(メートル単位のプロジェクトでは 30 m)の曲線が付きます。100 ft が収まらない場合は、各接線の半分に収まる最大の整数半径になります。非常に鋭角な PI や、直線が貫通する PI には曲線は付きません。

## 半径と座標を設定する

線形を選択すると、右のパネルに **アラインメント** が表示されます。

1. **名前** と **開始測点**。測点は `10+00`(フィート)または `0+500`(メートル)、あるいは単なる数値で入力します。[単位、測点、数値の形式](topic:units-and-stations)を参照してください。
2. **長さ** と **終了測点** は自動的に計算されます。
3. **PI** 表には、各 PI の **東距** と **北距**、および中間の各 PI の **半径** が表示されます。新しい値を入力して {{key:Enter}} を押します。
   - 半径を 0 にすると、曲線のない角点になります。
   - 始点と終点の PI には半径がありません。
   - 行末の小さい x は、その PI を削除します(線形には最低 2 つの PI が必要です)。
4. **曲線** の一覧を読みます。各曲線について、PC と PT の測点、半径 R、偏角 Δ と方向(左または右)、曲線長 L、接線長 T、外部距離 E、弦が表示されます。
5. 曲線の下の行には、最初の接線の方位が表示されます。

## 曲線が収まらない場合

曲線に必要な接線の長さが PI 間の長さを超える場合、線形には解がありません。修正するまで正しく描かれず、LandXML の書き出しからも除外されます。赤い枠に理由が数値で示され、収まる候補が提示されます。

- 「PI 2 と PI 3 の曲線には両者の間で 240.00 ft の接線が必要(130.00 + 110.00)ですが、PI 間の距離は 180.00 ft です。」。一方の PI だけに曲線がある場合は、「PI 2 の曲線には PI 1 方向へ 240.00 ft の接線が必要です …」と表示されます。
- 各 PI のボタンで、もう一方の曲線を変えずに、その PI に収まる**最大の半径**を設定します(PI のもう一方の接線にも収まる必要があります)。両方の PI に曲線がある場合は、**両方**ボタンで 2 つの半径を比例的に縮め、ちょうど接するようにします。
- 1 つの曲線だけで接線より長い場合、枠には、その大きさのままでは他の PI に曲線を収められないと表示されます。
- 完全に折り返す PI には曲線を付けられません。枠には **PI n に曲線なし** が提示されます。

各ボタンは 1 回の操作です。{{key:Mod+Z}} で半径が元に戻ります。提示される半径は、常に収まるように 0.01 単位で切り捨てられます。

### 設計最小半径

**設計最小半径** を入力すると、すべての曲線がその値と照合されます。空欄にすると照合しません。最小値より小さい曲線は、**最小値を満たす最小半径** のボタン付きで一覧表示されます(その半径が収まる場合)。収まらない場合は、接線が許す最大半径を示すので、PI を動かすか最小値を下げる判断ができます。

## 平面上で PI を動かす

1. {{ui:Select}} が有効な状態で、線形をクリックして選択します。PI に四角いグリップが表示されます。
2. グリップをドラッグします。線形、測点、縦断、コリドーが追従します。
3. 離すと、移動は 1 回の元に戻す操作になります。

既存の 2 つの PI の間に PI を追加する機能は、まだ利用できません。線形を削除して描き直すか、既存の PI の座標を入力し直してください。

## 測点と偏距を読む

平面図の上にポインターを動かします。ステータスバーには、最も近い線形(または選択中の線形)の測点と偏距が表示されます。偏距は、測点を進む方向に向いたとき、左なら **L**、右なら **R** で示されます。たとえば「アラインメント 1: 測点 2+15.30、偏距 18.42 R」のように表示されます。どちらかの端を超えた場合は、「(端の外)」が追加されます。

## 描かれる内容

平面図、DXF、PDF には次の内容が描かれます。中心線(接線は直線、曲線は正確な円弧)、50 ft(20 m)ごとの目盛り(100 単位ごとに長い目盛りと測点ラベル)、PC と PT の目盛り(それぞれの測点を表示)。

## 線形を削除する

線形を選択して {{key:Delete}} を押すか、ツールバーまたは右パネルの下部にある {{ui:Delete}} をクリックします。縦断とコリドーも一緒に削除されます。{{key:Mod+Z}} で元に戻せます。

:::mac
Mac のキーボードでは、delete と表示されたキーはブラウザーでは {{key:Backspace}} として働き、選択を削除しません。{{key:Delete}}(Fn と delete)を押すか、{{ui:Delete}} ボタンを使ってください。
:::

## 設計速度と区分

線形のプロパティにある **設計速度**(km/h または mph)と **設計区分** は線形とともに保存され、プロジェクトに保存されるほか、IFC にも書き出されます(Pset_RoadDesignCriteriaCommon)。CivilCraft には速度と最小半径を対応づける表がないため、これらの値から照合は行われません。**設計最小半径** は、お使いの設計基準に従って設定してください。

## スパイラル

曲線の両端には、クロソイドのスパイラルを付けられます。順序は、接線、スパイラル、曲線、スパイラル、接線です。PI 表で、半径を持つ PI の **入りのスパイラル** と **出のスパイラル** に長さを入力します。PI の位置は変わりません。曲線が内側に移動して空間をつくるため、接線の距離はスパイラルのずれ量だけ長くなります。2 つの長さは異なってもかまいません。片方だけ長さを入力した PI には、その端だけにスパイラルが付きます。

曲線の一覧には、TS、SC、CS、ST が表示されます(接線から緩和曲線へ、緩和曲線から円曲線へ、円曲線から緩和曲線へ、緩和曲線から接線へ)。これとともに、スパイラル角 θs、接線距離、外部距離が表示されます。測点は、他の場所と同様にスパイラルに沿って進みます。合計の回転角が曲線の回転角を超えるスパイラルは、PI 名を示して受け付けられません。接線が許す長さを超えるスパイラルは、どの曲線とも同様に重なりとして扱われます。片勾配は、スパイラルを擦り付け区間として使います([コリドー](topic:corridor)を参照)。

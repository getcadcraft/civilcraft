造成面は、1つの標高にある平らな領域です。その縁から、CivilCraft は地盤が造成面より高い場合は切土法面で、低い場合は盛土法面で、既存地盤に接するまで外側へ造成します。その接線が法尻線です。造成面とその法面は、法尻線の内側の既存地盤を置き換え、計画地表面を作ります。

## 造成面を描く

作業を始める前に、既存の地表面が必要です。

1. {{key:G}} を押すか、**設計** グループの {{ui:造成面}} をクリックします。
   ヒントには「造成面: 角をクリックします。Enter キーまたはダブルクリックで完了、Backspace で最後の角を削除、Esc でキャンセル。」と表示されます。
2. 角を順番にクリックします（時計回りでも反時計回りでも可）。青い輪郭がポインターに追従します。
3. 最後の角（3つ以上）をクリックしたあとで {{key:Enter}} を押します。
   造成面が描かれて選択されます。標高は中央の地表面の標高から始まり、0.1 単位に丸められます。切土法面は 2 : 1、盛土法面は 3 : 1 です。ステータスバーには、例えば「造成面1の標高は254.3（中央の地表）、切土 2:1、盛土 3:1。プロパティで変更できます。」と表示されます。

:::warning
{{key:Enter}} で完了してください。ダブルクリックでも完了しますが、このビルドではダブルクリックした角が削除されてしまいます。最後の角を1回クリックしてから、{{key:Enter}} を押してください。
:::

造成面の輪郭が自分自身と交差してはいけません（「造成面の輪郭が自分自身と交差しています。」）。

## 標高と法面を設定する

造成面を選択すると、右のパネルに **造成面** が表示されます。

1. **名前**。
2. **標高**: 造成面の平らな標高。
3. **切土法面** と **盛土法面**: H:V 形式で入力します（2 は 2 : 1 を意味します）。どちらも 0 より大きい値にしてください。
4. **造成面の面積** と **角の数** は参考として表示されます。

各値の後で {{key:Enter}} を押します。法尻線、計画地表面、土量は、すぐに更新されます。

フィールドの下には、例えば「法尻線: 48 本の法面線（切土 20 本、盛土 28 本）、最も遠いもので 31.20 ft」のような行が表示されます。平面図では、法尻線と法面線がマゼンタで描かれます。

## 法尻の求め方

- 法面線は、各辺から直角に、造成面の大きさのおよそ20分の1ごとに出ます。
- 外側の角では、10° ごとに扇状に広がるため、法面は角を回り込みます。
- 内側の角では、2つの辺からの法面が出会う二等分線に沿って1本の線が引かれます。
- 各線は、地表面に達するまで切土法面で上がるか、盛土法面で下がります。

## 辺ごとの法面と擁壁

造成面、平場、または小段の **プロパティ** の **辺と擁壁** の下で、各辺を個別の方法で造成できます。辺1は最初にクリックした角から2番目の角まで、辺2は2番目から3番目までというように続きます。

- **すべての辺**: **法面** は、上記の切土・盛土法面をすべての辺に使用します。**垂直: 擁壁** は、すべての辺に壁を設けます。
- 辺ごとに、**上の法面**、**この辺の法面**（その辺の切土と盛土の法面を入力）、または **垂直（擁壁）** を選びます。
- 法面は `3` または `3:1`（水平対垂直 1）、`33%`、`18.4°` と入力できます。表示は H:1 になります。造成面自体の **切土法面** と **盛土法面** も同じ形式です。
- 垂直の辺には盛土がありません。擁壁が辺に沿って、造成面から既存地盤まで（盛土の場合）、または地盤から造成面まで（切土の場合）下がります。**壁の厚さ**（初期値は 0.3 m または 1 ft）は、造成面の縁から既存地盤まで地盤が段差になる距離です。切土と盛土の土量からは、その辺にもう存在しない盛土部分が除外されます。
- 壁が法面のある辺と接する場合、法面は壁の端で回り込みます。2つの壁が接する場合は留め接合になります。
- フィールドの下には、壁の長さ、露出面（高さ × 長さ）、最大高さと平均高さが表示されます。

平面図では、各壁の外側面に短い目盛りが描かれ、両端と最も高い位置での高さが表示されます（擁壁レイヤー上に描かれ、DXF と DWG にも含まれます）。3D 表示では、壁が立体として表示され（表示 › 擁壁）、GLB、OBJ、USD の書き出しにも含まれます。辺を横切る断面には段差が表示されます。

**警告**（プロパティおよび問題パネル）: 壁の高さが **この高さを超えると警告**（初期値は 1.0 m または 3.3 ft）を超えた場合は、「エンジニアリングされた壁または許可が必要な場合があります。地域の規則を確認してください」と表示されます。また、**土が自立できる最急勾配** を入力すると、切土または盛土の法面がその値より急な辺が表示されます。これらは警告であり、造成は続行されます。すべての変更は {{key:Mod+Z}} で1回の操作として元に戻せます。

## 角を動かす

造成面を選択し、角の四角いグリップをドラッグします。各ドラッグは1回の元に戻す操作です。角の追加や削除はまだできません。造成面を削除して描き直してください。

## 造成できない場合

**土工** の下に赤い枠が表示され、造成面と問題が示されます。

| メッセージ | 対処 |
|---|---|
| 「3 本の法面線が、地表面に達する前に地表面の外へ出ています。造成面が地表面の端に近すぎるか、標高が高すぎるか低すぎます。」 | 造成面を地表面の端から内側へ移動するか、標高を地盤に近づけてください。 |
| 「法尻線が自分自身と交差しています（造成面の異なる辺からの法面が互いに入り込んでいます）。造成面の形を変えるか、法面を変更してください。」 | 深い切土や高い盛土で、細長い形や L 字型の造成面によく起こります。造成面を広げるか、高低差を小さくするか、法面を急にしてください。 |
| 「造成面の輪郭が自分自身と交差しています。」 | 造成面の周りの角を、順番に描き直してください。 |

問題のある造成面は、修正されるまで計画地表面と土量から除外されます。

## 結果を確認する

1. **表示** の下で、**地表面** を {{ui:計画（造成後）}} に設定します。
   等高線は造成面の上で水平になり、法面に沿って法尻線まで続きます。
2. 造成面にポインターを合わせると、ステータスバーに **地表面** と **造成後** の標高が表示されます。
3. **土工** の下で切土と盛土を確認します。[土量](topic:volumes) を参照してください。

造成面は、描かれた順に、コリドーの後に造成されます。後から描いた造成面は、その法尻線の内側にある以前の造成面を置き換えます。

## 造成面を削除する

造成面を選択して {{key:Delete}} を押します（Mac では Fn と削除）。または {{ui:削除}} をクリックします。

## 未対応の機能

造成面は平らです。傾斜した造成面、勾配が変わるフィーチャーライン、小段、距離や標高を目標とする造成は、まだ利用できません。[未対応の機能](topic:not-built-yet) を参照してください。

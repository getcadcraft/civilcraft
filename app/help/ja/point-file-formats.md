点ファイルはプレーンテキストで、1 行に 1 点です。CivilCraft はブラウザーで読み取ります。何もアップロードされません。

## 列の順序

文字は左から右への列を表します: **P** 点番号または名前、**N** 北距、**E** 東距、**Z** 標高、**D** 記述。

| 順序 | 列 | 行の例 |
|---|---|---|
| PNEZD | 点、北距、東距、標高、記述 | `101,2080000.00,6150000.00,250.00,GRD` |
| PENZD | 点、東距、北距、標高、記述 | `101,6150000.00,2080000.00,250.00,GRD` |
| PNEZ | 点、北距、東距、標高 | `101,2080000.00,6150000.00,250.00` |
| PENZ | 点、東距、北距、標高 | `101,6150000.00,2080000.00,250.00` |
| NEZD | 北距、東距、標高、記述 | `2080000.00,6150000.00,250.00,GRD` |
| ENZD | 東距、北距、標高、記述 | `6150000.00,2080000.00,250.00,GRD` |
| NEZ | 北距、東距、標高 | `2080000.00 6150000.00 250.00` |
| ENZ | 東距、北距、標高 | `6150000.00 2080000.00 250.00` |

P を含まない順序では、ファイル内の順に点を 1、2、3 … と番号付けします。X は東距、Y は北距です。

## 区切り文字

CivilCraft は最初の 20 行を調べ、そのうち少なくとも 60% に現れる次の文字のうち最初のものを選びます: コンマ、タブ、セミコロン。どれも該当しない場合は、連続した空白で分割します。

- コンマ、タブ、セミコロンのファイルでは、二重引用符で囲んだフィールドに区切り文字を含めることができ(`"FL, NORTH"`)、引用符の中の `""` は 1 つの引用符を表します。
- 空白区切りのファイルでは、行末の記述に空白を含めることができます。最後の座標列の後ろにあるすべてが記述になります。
- `#`、`;`、`//` で始まる行と空行はスキップされます。
- ファイルの先頭にあるバイトオーダーマークは無視されます。

## ヘッダー行

最初の行は、そのフィールドのうち数値が 2 つ未満の場合に、ヘッダーとして扱われます。ヘッダーのすべてのフィールドが CivilCraft が認識する名前であれば、列の順序はそこから決まります(「ヘッダー行から」)。名前は、大文字と小文字、空白、ドット、アンダースコア、ハイフン、角かっこの違いを無視して照合されます。

| 列 | 認識される名前 |
|---|---|
| P | pt, pnt, point, point no, point number, number, no, id, name, pt#, point#, # |
| N | n, north, northing, y, y coord, lat, latitude |
| E | e, east, easting, x, x coord, lon, long, longitude |
| Z | z, elev, elevation, el, height, h, z coord, rl |
| D | d, desc, description, code, raw description, full description, note, notes, feature |

認識されないヘッダー名がある場合、または名前が 8 つの順序のいずれにもならない場合は、そのヘッダーはスキップされ、順序は列数から推測されます。

:::warning
緯度列(`lat`、`latitude`)と経度列(`lon`、`long`、`longitude`)の両方を指定したヘッダーは、北距と東距ではなく、度単位として読み取られます。{{ui:インポート}} では、点はプロジェクトの座標系を通じて変換されます。座標系が設定されていないプロジェクトでは、先に選択を求められます。緯度が ±90° または経度が ±180° の範囲外の行は拒否されます。詳細は [GIS データのインポート](topic:gis-import#point-files-with-latitude-and-longitude) を参照してください。
:::

## 列数からの推測

有効なヘッダーがなく、**列**が {{ui:自動判別}} のままの場合:

- 5 列以上: PNEZD。
- 4 列: 最初の列がサンプルされたすべての行で整数で、4 番目が数値の場合は PNEZ。それ以外は NEZD。
- 3 列: NEZ。

PNEZD と PENZD は数値からは区別できません。推測は [CivilCraft の設定](topic:settings) の **点の行** に従います: 先頭が P、N、E、Z、D、または P、E、N、Z、D です(後者の場合、4 列は PENZ、3 列は ENZ として読み取られます)。ダイアログには「列数から推測しました。北距と東距が入れ替わっていないか確認してください」と表示されます。プレビューが正しくない場合は、**列**で正しい順序を選択してください。

## 行のチェック

- 行は記述を省略できます。
- 北距と東距は数値である必要があります。標高は空でもかまいません(点は保持されますが、表面では使用されません)。
- 点番号は任意の文字列(`CP1` のように英字を含むものも可)ですが、空であってはいけません。
- 点番号が重複する場合は、最初の行が保持され、他の行は読み込まれなかったものとして一覧に表示されます。
- 記述は 200 文字まで保持されます。制御文字は空白になります。
- 読み込まれなかった行は、ダイアログ用に最大 200 行まで保持されます(25 行を表示)。すべてが数えられます。

## 点グループ

点のグループは、記述の先頭語を大文字にしたものです。「GRD」、「grd shot」、「Grd」はすべてグループ GRD です。記述がない点は「(記述なし)」になります。[測量点のインポート](topic:import-points) を参照してください。

## 点ファイルへの書き出し

CivilCraft はまだ点のテキストファイルを書き出せません。点は LandXML(CgPoints として)、プロジェクトファイル、および GIS の {{ui:書き出し}} で、P、N、E、Z、D フィールドを持つシェープファイル、GeoPackage、または GeoJSON として出力されます([GIS 向けに出来形データを書き出す](topic:gis-export))。[まだ作成されていません](topic:not-built-yet) も参照してください。

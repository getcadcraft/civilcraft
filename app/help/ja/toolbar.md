ツールバーは、アプリの上部に7つのグループとして並んでいます。すべてのボタンは、カーソルを合わせるとツールチップとショートカットキーを表示します。

## ファイル

| ボタン | キー | 機能 |
|---|---|---|
| {{ui:新規}} | なし | 空のプロジェクトを開始します。未保存の変更がある場合は、先に確認します。 |
| {{ui:開く}} | {{key:Mod+O}} | 点ファイル (CSV、TXT)、LandXML、または CivilCraft プロジェクトを開きます。 |
| {{ui:保存}} | {{key:Mod+S}} | プロジェクトを `<name>.civilcraft.json` としてダウンロードします。 |

## 書き出し

| ボタン | キー | 機能 |
|---|---|---|
| {{ui:LandXML}} | なし | `<name>.xml` をダウンロードします。点、地表面、線形、縦断、管路網を LandXML 1.2 形式で出力します。プロジェクトが空の場合は「まだ書き出すものがありません。」と表示されます。 |
| {{ui:DXF}} | なし | `<name>.dxf` をダウンロードします。平面の線データを R12 DXF で出力します。 |
| {{ui:PDF}} | {{key:Mod+P}} | **平面図を PDF に出力**を開きます。プロジェクトが空の場合は「まだ出力するものがありません。」と表示されます。 |

## 地表面

| ボタン | キー | 機能 |
|---|---|---|
| {{ui:地性線}} | {{key:B}} | 測量点を順にクリックし、{{key:Enter}} で完了します。地性線は点の標高を使います。 |
| {{ui:境界}} | {{key:O}} | 外周境界の角を順にクリックし、{{key:Enter}} で完了します。既存の境界は置き換えられます。 |

どちらも、地表面がない場合は「まだ地表面がありません。先に測量点を開いてください。」と表示します。

## 設計

| ボタン | キー | 機能 |
|---|---|---|
| {{ui:アラインメント}} | {{key:A}} | PI を順にクリックし、{{key:Enter}} で完了します。 |
| {{ui:造成面}} | {{key:G}} | 造成面の角をクリックし、{{key:Enter}} で完了します。地表面ツールと同様、地表面がない場合は警告します。造成面は地表面上にのみ整形されます。 |
| {{ui:管}} | {{key:P}} | 上流から下流へ向かって構造物をクリックし (既存の構造物をクリックするとそれに接続します)、{{key:Enter}} で完了します。 |
| {{ui:縦断}} | {{key:R}} | 平面図の下にある縦断図を表示または非表示にします。 |

## 編集

| ボタン | キー | 機能 |
|---|---|---|
| {{ui:元に戻す}} | {{key:Mod+Z}} | 直前の変更を元に戻します (最大200回)。元に戻せるものがない場合はグレー表示になります。 |
| {{ui:やり直し}} | {{key:Mod+Y}} | 元に戻した操作をやり直します。やり直せるものがない場合はグレー表示になります。 |
| {{ui:コピー}} | {{key:Mod+C}} | 選択した測量点をコピーし、スプレッドシートに貼り付けられる点の行としてクリップボードに置きます。測量点が選択されるまでグレー表示になります。 |
| {{ui:貼り付け}} | {{key:Mod+V}} | 点を貼り付けます: 点はポインターに追従し、クリックするとどの点とも重複しない番号で配置されます。スプレッドシートでコピーした点の行も貼り付けられます。 |
| {{ui:その他}} | なし | 下のメニューを開きます。 |

{{ui:その他}} メニュー:

| 項目 | キー | 機能 |
|---|---|---|
| {{ui:切り取り}} | {{key:Mod+X}} | 選択した点をコピーして削除します (元に戻す1回分)。 |
| {{ui:コピー}} | {{key:Mod+C}} | {{ui:コピー}} ボタンと同じです。 |
| {{ui:貼り付け}} | {{key:Mod+V}} | {{ui:貼り付け}} ボタンと同じです。 |
| {{ui:同じ位置に貼り付け}} | {{key:Mod+Shift+V}} | 点を元の座標のまま貼り付けます。番号は他のどの点とも重複しません。 |
| {{ui:複製}} | {{key:Mod+D}} | 選択した点のコピーがポインターに追従します。クリックした位置に配置されます。クリップボードは変更されません。 |
| {{ui:削除}} | {{key:Delete}} | 選択した測量点、または選択した線形、造成面、構造物 (その管を含む)、管、PVI を削除します。 |
| {{ui:測量点をすべて選択}} | {{key:Mod+A}} | すべての測量点を選択します。 |
| {{ui:選択解除}} | {{key:Esc}} | 選択を解除します。 |

現在実行できない項目はグレー表示になり、そのツールチップに理由が表示されます。詳細: [測量点の選択、コピー、貼り付け](topic:copy-paste-points)。

元に戻す操作は、設計、地表面の設定、測量点の編集 (貼り付け、切り取り、複製、削除) を対象とします。表示設定は対象外です。また、どのファイルを開いても、または取り込んでも、元に戻す履歴は消去されます。

## GIS

| ボタン | キー | 機能 |
|---|---|---|
| {{ui:座標}} | なし | **座標系**ダイアログを開きます: プロジェクトがどの座標系にあるかを指定するか、地上座標またはローカル座標を使います。[プロジェクトの座標系を設定](topic:coordinate-systems) と [地上座標とローカル座標](topic:ground-and-local-coordinates) を参照してください。 |
| {{ui:インポート}} | なし | GIS データをインポートします: シェープファイル、GeoJSON、GeoPackage、標高グリッド、LiDAR。[GIS データのインポート](topic:gis-import) を参照してください。 |
| {{ui:書き出し}} | なし | 竣工データを GIS 部門向けに書き出します。[GIS 向けに竣工データを書き出す](topic:gis-export) を参照してください。 |
| {{ui:解析}} | なし | GIS 解析パネルを開きます: バッファ、オーバーレイ、空間結合、属性による選択、計測。[GIS レイヤーの解析](topic:gis-analysis) を参照してください。 |
| {{ui:属性テーブル}} | なし | 地表面 › その他 にあります。GIS レイヤーの属性テーブルを開きます: 並べ替え、フィルター、選択、編集、フィールドの追加、計算、CSV として保存。[レイヤーの属性テーブルの操作](topic:gis-table) を参照してください。 |
| {{ui:地図}} | なし | **地図レイヤー**ダイアログを開きます: 位置情報付きの画像、または追加した地図サーバーを、平面図の下に描画します。[平面図の下に地図レイヤーを表示](topic:map-layers) を参照してください。 |

GIS ツールは、これらのボタンを初めて使うとき、GIS ファイルを開くとき、または座標系や GIS レイヤーのあるプロジェクトを開くときに読み込まれます。

## 表示

| ボタン | キー | 機能 |
|---|---|---|
| {{ui:選択}} | {{key:V}} または {{key:Esc}} | クリックでアラインメント、造成面、構造物、管、点を選択します ({{key:Shift}} を押しながらクリックまたはドラッグすると点を追加)。グリップをドラッグして PI、造成面の角、構造物を移動します。 |
| {{ui:合わせる}} | {{key:F}} | 平面図を、地表面、測量点、線形、造成面が収まるように拡大表示します (3D ビューでは、すべてを表示します)。 |
| {{ui:3D}} | {{key:D}} | 平面図の上に敷地を 3D で表示するか、平面図に戻ります。3D ビューの上のバーで、表示角度、垂直誇張、色、表示内容を設定し、GLB または OBJ で書き出します。[3D で敷地を表示](topic:site-3d) を参照してください。 |

## パネル内のボタン

| ボタン | 場所 | 機能 |
|---|---|---|
| {{ui:サンプルの敷地を開く}} | 空の平面図上の枠 | サンプルの測量データを読み込みます (接続が必要です。ただし、CivilCraft をオフライン用に保存している場合を除きます) |
| {{ui:境界を削除}} | 左パネル、地表面 | 外周境界を取り除きます |
| {{ui:描いた地性線を削除}} | 左パネル、地表面 | ツールで描いた地性線をすべて削除します (地性線のグループは削除しません) |
| {{ui:点から地表面を再構築}} | 左パネル、地表面 (LandXML の地表面のみ) | LandXML の TIN を破棄し、点から作成し直します。元に戻せません。 |
| {{ui:地盤から開始}} | 右パネル、アラインメント | 両端に地盤上の PVI を置いて、設計縦断を開始します。 |
| {{ui:縦断図を開く}} | 右パネル、アラインメント | このアラインメントの縦断図を開きます。 |
| {{ui:PVI を追加}} | 縦断バー | 押している間、縦断図上でクリックすると PVI を追加します。 |
| {{ui:規則からすべての管底高を設定}} | 右パネル、管路網 | すべての管の管底高を規則から設定します。 |
| {{ui:規則から管底高を設定}} | 右パネル、管 | この管の管底高を規則から設定します。 |

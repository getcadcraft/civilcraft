3D ビューには、現場が 1 つのモデルとして表示されます。既存の地盤と造成後の表面、その上に投影された等高線、ブレークラインと表面の縁、設計縦断上の各線形と測点の目盛り、コリドーの地形線、道路そのもの（車線、路肩、側溝、縁石、中央帯、歩道を、それぞれ独自の色で）、法尻線付きの造成面、実際の標高に置かれた管と構造物からなる管網、そして造園ワークスペースからの植栽、舗装、歩道、擁壁、縁石、傾斜路、階段です。平面図と同じプロジェクトを読み込むため、どの編集もどちらにも反映されます。

## 3D ビューを開く

1. 測量点（または LandXML またはプロジェクトファイル）を開き、表面を用意します。植栽、舗装、傾斜路だけでも開けます。
2. {{key:D}} を押すか、ツールバーの{{ui:表示}}グループにある {{ui:3D}} をクリックします。
   3D ビューは平面図の上に開き、南東から現場全体を見た状態になります。初めて開くときは、読み込みに少し時間がかかります。
3. もう一度 {{key:D}} を押すか、{{ui:3D}} をクリックすると、平面図に戻ります。{{ui:アラインメント}} や {{ui:造成面}} などの作図ツールを選んでも、作図は平面図で行うため、平面図に戻ります。

## 移動する

| 操作 | 方法 |
|---|---|
| 軌道回転 | 左ボタンまたは中ボタンでドラッグ |
| パン | 右ボタンでドラッグ、または {{key:Shift}} を押しながらドラッグ |
| ズーム | ホイールを回す。ポインターの方向にズームします |
| トラックパッドで軌道回転 | 2 本の指でスワイプ（{{key:Shift}} を押しながらスワイプでパン） |
| トラックパッドでズーム | ピンチ |
| タッチ | 1 本の指で軌道回転。2 本の指でピンチしてズーム、動かしてパン |
| キー（ビューにフォーカスがあるとき） | {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} で軌道回転、{{key:Shift}} と併用するとパン。{{key:Plus}} と {{key:Minus}} でズーム |

バーには、残りの操作があります:

- ビューの一覧: **アイソメ**、**上面**、**下面**、**正面**（北向き）、**背面**、**左面**、**右面**。
- {{ui:透視投影}}: 押し込まれた状態は透視図です。クリックすると平行投影（遠近感なし）に切り替わります。
- {{ui:範囲}}: すべてを再表示します。3D ビューが開いている間は {{key:F}} でも同じです。

## ビューキューブ

右上隅のビューキューブは、表示に合わせて回転します。面、辺、角をクリックすると、その方向から現場を見ます（システムが動きを抑える設定の場合を除き、カメラはなめらかに回転します）。キューブをドラッグすると軌道回転します。その下の方位リングは北（グリッドの北、+Y）を示します。リングをドラッグすると現場を鉛直軸まわりに回転し、N、E、S、W をクリックすると、その方向から見ます。左上の小さな家のアイコン {{ui:ホーム}} は、現場全体のアイソメ表示に戻ります。キーボードでは、{{key:Tab}} でキューブに移動し、矢印で面、辺、角を選び、{{key:Enter}} でその方向から見ます。

平面図でも同じキューブが上面を示します。他の面、辺、角をクリックするか、ドラッグすると、その方向から見た 3D ビューが開きます。特定の方向から 3D に入る最も速い方法です。キューブを小さな軸アイコンに替えるか、非表示にするには、[CivilCraft の設定](topic:settings) の**コーナーインジケーター**を参照してください。

## 標高を誇張する

現場は通常、高さよりずっと広いため、標高は初期値で **2×** に引き伸ばされています。バーの一覧で **1×**、**2×**、**3×**、**5×**、**10×** を選ぶか、[CivilCraft の設定](topic:settings) の **3D の鉛直誇張率** で設定します（両者は同じ設定です）。変わるのは表示だけで、数量、縦断、書き出しは実寸のままです。

## 表面を着色する

- **標高帯**: 平面図の標高帯と同じ帯と色です（帯の数は左パネルの**表示**で設定します）。各帯の境界は、その標高で正確に切り取られます。
- **単色**: 既存の地盤と造成面を、それぞれ単色で表示します。
- **地図レイヤー**: 平面図の下に表示されている地図レイヤー（座標付き画像、地図タイル、または地図サービス。[地図レイヤー](topic:map-layers) を参照）を、シートのように表面の上に重ねます。そのため、空中写真が丘の上に表示されます。読み込み中の画像は、届いた順に埋まります。地図レイヤーが表示されていない場合、表面は標高帯のままで、その旨が表示されます。画像は画面用です。GLB と OBJ の書き出しには含まれません。

両方の表面を表示すると、既存の地盤が造成面の上に透けて見えるため、切土（設計より上の地盤）と盛土を確認できます。

## 表示する項目を選ぶ

バーの {{ui:表示}} をクリックし、次の項目をチェックまたは解除します:

| 項目 | 内容 |
|---|---|
| 既存の地盤 | 測量点から作成された表面（または LandXML から読み込んだもの） |
| 造成後の表面 | コリドーと造成面を反映した既存の地盤（ある場合のみ） |
| 三角形の辺 | すべての TIN の辺を線で表示 |
| 等高線 | 表示中の各表面の補助等高線と主等高線（平面図の間隔） |
| 表面の縁 | 表示中の各表面の外縁を、その標高で表示 |
| ブレークライン | すべてのブレークラインを、その標高で表示 |
| 線形と測点 | 各線形を設計縦断上に表示（縦断がない場合は地盤上）。50 ft または 20 m ごとに目盛り |
| コリドーの地形線 | 両側の舗装端、路肩、法尻線 |
| 道路面 | 各コリドーが、その横断構成から作る道路。車線、路肩、側溝、縁石、中央帯、歩道を、それぞれ独自の色で、造成後の表面上に表示 |
| 植栽 | すべての植物（花壇と生垣の植物を含む）。植物リストの寸法に基づく簡単な形状。樹木は幹と丸い樹冠（針葉樹は円錐、ヤシは高い幹の上の房）、低木、生垣の植物、多年草、地被植物はドーム形、草は房、つる植物は細い柱。造成後の表面（または既存の地盤）の上に、平面図で示される大きさ（成熟時、または植栽時）で立ちます |
| ハードスケープ | 勾配付きの舗装と歩道、擁壁、縁石、階段、そして段の間に水平な踊り場を挟んで登る傾斜路 |
| 造成面と法尻線 | 各造成面の輪郭をその標高で、その法尻線付きで表示 |
| 管と構造物 | 管は内側の底の間の丸い管として、構造物は天端からサンプまで表示 |
| 測量点 | 標高付きの各点の点（初期値はオフ） |
| GIS レイヤー | 平面図に表示されている GIS レイヤーを、その色で表示。線と輪郭はそれぞれの標高で、他は既存の地盤上に表示（地盤に正確に沿う）。点は小さな十字。表面から外れた標高のない形状は除外され、その数が表示されます |
| ラベル | 常にこちら側を向く名前と値。各線形の名前（始点）と 100 ft（または 100 m）ごとの測点、主等高線の標高、造成面、地形線、構造物の名前、**測量点**をチェックすると各点の番号と標高 |

ラベルは、向きや拡大率にかかわらず、同じ大きさで直立します。ラベルの前にある丘はラベルを隠します。混み合う場合、最も重要なものが表示され、残りはズームするまで待機します。順序は、線形、構造物、造成面、地形線、測点、等高線、点の順で、近いものが先です。ラベルは画面上だけに表示され、書き出しや印刷には含まれません。

表示の選択、誇張率、着色は、このブラウザーに記憶されます。

道路は既存の地盤の上に作られます。線形とコリドーがあるものの、測量点や表面がまだない場合、道路は仮の平坦な地盤の上に描かれます。その縦断の平均標高、縦断もなければ標高 0 の水平面です。3D ビューの下部とコリドーのプロパティに警告が表示されます。これは図としてのみのもので、数量や断面は得られません。測量点または表面を開くと、道路は自動的に実際の地盤へ移動します。

鉛直誇張率は地盤を伸ばしますが、植物は伸ばしません。植物は、誇張された地盤の上に、実際の高さと広がりで立つため、どの設定でも樹木は樹木に見えます。植物は詳細なモデルではなく簡単な形状なので、数千本あっても回転やズームが速く保たれます。

## 管と構造物

- 管は、設定した内側の底（インバート）から、内径 1 つ分上の内側の上端（天端）まで、丸い管として描かれます。径は、フィート法のプロジェクトではインチ、メートル法のプロジェクトではミリメートルで、右パネルと同じ単位です。
- 構造物は、天端（入力値、または表面から）から、サンプ（最も低いインバートからサンプの深さを引いた位置）まで伸びます。インバートがない場合、深さ 5 ft（1.5 m）で描かれます。
- 問題のある管と構造物（右パネルの管網の検査を参照）は赤で描かれます。
- インバートのない管は描かれません。ビューの下部の注記に、その数が表示されます。

## 3D ビューから選択する

線形（またはその道路）、造成面、地形線、管、構造物、測量点、植物、傾斜路、またはその他のハードスケープをクリックします。平面図でクリックした場合と同じように選択され、そのプロパティが右パネルに開いて編集できます。3D では、選択色ですべてよりも前に描かれます。平面図で選んだものも、3D でハイライトされます。ポインターの横のヒントには、クリックした対象の名前と、その東距、北距、標高が表示されます。管と構造物は地下にあってもクリックできますが、丘の陰にある線は、丘を通してクリックすることはできません。

ブレークラインをクリックすると、どれかがわかります。ハイライトされ、ステータスバーに名前が表示されます（ブレークラインには独自のプロパティはありません）。

地面をクリックすると、そこの東距、北距、標高をヒントに表示します。

## 線形に沿って走行する

3D バーの **走行** をクリックし、線形を選びます。ビューは運転席に移動します。道路の 3.5 ft（1.07 m）上で、その設計縦断上（まだない場合は中心線に沿った既存の地盤上）に置かれ、その先を見る状態です。

- **再生** または {{key:Space}} で、選んだ速度で走行します（10〜65 mph、または 15〜100 km/h）。{{key:Space}} をもう一度押すと一時停止します。終わりで停止し、**再生**を押すと最初から再び始まります。
- スライダーで任意の測点へ移動できます。{{key:Left}} と {{key:Right}} は、後ろへまたは前へ 10 ft（5 m）ずつ進みます。
- ビュー内をドラッグすると一時停止し、周囲を見回せます。
- **停止** または {{key:Esc}} で、ビューは元の位置に戻ります。

鉛直誇張率は走行中も適用されます。道路を完成時の姿で確認するには、1× に設定してください。

## 太陽光

3D バーの **太陽** を開き、**太陽からの光**をチェックします。日付、時刻、そのタイムゾーン（UTC からのずれ。夏時間の場合はその値）を入力し、現場の緯度と経度を入力します。プロジェクトに座標系がある場合は、そこから入力されています。

現場は太陽のある方向から照らされ、地盤、コリドー、造成面に**影**が落ちます。メニューには、太陽の方位と高度、または地平線の下であることが表示されます。位置は NOAA の太陽方程式から求めます。影は、どの誇張率でも正しい向きに落ちますが、現場の端で止まります。その外側の丘や建物は影を落としません。

## 3D ビューを書き出す

バーの {{ui:GLB}} または {{ui:OBJ}} をクリックします。表示中のものが、実寸（誇張なし）、メートル単位、Y 軸上向きで保存されます。詳細は [3D で現場を書き出す](topic:export-3d) を参照してください。

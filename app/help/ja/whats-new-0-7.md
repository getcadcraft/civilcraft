これは CivilCraft 0.6 と比べた 0.7 の変更点です。大きな新しい部分は、電力線ワークスペース、ランドスケープワークスペース、建物ボリュームです。

## 新機能

### ランドスケープワークスペース

- **同じ現場にランドスケープワークスペース。** {{ui:地表面}} › {{ui:その他}} › {{ui:ランドスケープワークスペース}} で、既存の現場（同じ測量点、地表面、プロジェクトファイル）に植栽、造成、ハードスケープ、灌水のツールが加わります。元に戻すには **ワークスペース** で **Civil** を選びます。詳しくは [ランドスケープワークスペース](topic:landscape) を参照してください。
- **植物リスト。** 温帯および地中海性気候の一般的な高木、低木、生垣、草本、多年草、グランドカバー、つる植物など約420種を収録し、植栽時と成木時の大きさ、耐寒性ゾーン、日当たり、水分、間隔を含みます。英語、スペイン語、ポルトガル語の名前で検索できます。独自の一覧は CSV で読み込め、プロジェクトに保存されます。内蔵の大きさは代表的な丸めた値なので、地元の園芸店で確認してください。詳しくは [植物リスト](topic:plant-list) を参照してください。
- **植栽計画。** {{ui:植物}} は地面に置かれ、後の造成に従う単独の植物を配置します。{{ui:植栽帯}} は輪郭内を植物の間隔に合わせ、割合で配合を決めて埋めます。{{ui:生垣}} は線に沿って 1 列または 2 列を設定します。植物は計画図上にラベル表示されます。詳しくは [植栽計画と集計表](topic:planting) を参照してください。
- **植物集計表。** その他 › {{ui:植物集計表…}} で、樹種と植栽サイズ別に植物を数えます。CSV または XLSX で保存するか、TakeoffCraft に送って積算できます。詳しくは [植物集計表](topic:planting#the-plant-schedule) を参照してください。
- **ランドスケープの造成。** {{ui:造成}} には、平場（水平または勾配付き）、小段、浅い排水路、標高点と等高線をドラッグして設定する造成領域があります。切土と盛土は操作中に表示されます。**斜面解析** は、ユーザーが設定した 2 つの限界値で地表面を色分けし、**流向矢印と滞水** は水の流れる方向と溜まる場所を示します。すべては、平場やコリドーと同じ計画地表面に反映されます。詳しくは [ランドスケープの造成](topic:landscape-grading) を参照してください。
- **舗装、歩道、擁壁、縁石、スロープ、階段。** {{ui:ハードスケープ}} では、横断勾配または排水への勾配を付けた舗装、パターンと各層、地面に沿う歩道、段付きの根入れを持つ擁壁と独立擁壁、縁石、設定した制限値で確認するスロープと階段を作図できます。高さ 1.2 m（4 ft）を超える擁壁は、技術者の確認対象として表示されます。詳しくは [舗装、擁壁、階段](topic:hardscape) を参照してください。
- **灌水の計算補助。** {{ui:灌水}} でヘッド、支線、本管、バルブ、点滴線、接続点を配置します。{{ui:システムを確認…}} は、管からゾーンを見つけ、各ゾーンの流量、バルブと供給側で必要な圧力（Hazen–Williams）、降水量、散水時間、カバレッジ、部材表を計算します。これは計算補助であり、設計の認証ではありません。灌水の設計者がすべての結果を確認してください。ヘッドは汎用の種類か、ファイルから読み込んだ独自のものを使用します。詳しくは [灌水設計](topic:irrigation) を参照してください。
- **ランドスケープシート。** その他 › {{ui:ランドスケープシート…}} で、植栽、造成、灌水の図面を凡例付きで作成し、擁壁の断面、舗装の構成、階段の詳細シートを 1 つの PDF にまとめます。詳しくは [ランドスケープシート](topic:landscape-sheets) を参照してください。
- **自由形状オブジェクト。** その他 › {{ui:自由形状オブジェクト…}} で、他のアプリで作成した STL、OBJ、またはライブラリ項目のメッシュを配置します。プランターや彫刻などが対象です。地面の上に置くことも、地面を切り込ませることもでき、体積、面積、占有面積が集計されます。詳しくは [自由形状オブジェクト](topic:freeform-objects) を参照してください。
- **ランドスケープ IFC。** その他 › {{ui:ランドスケープ IFC を書き出し}} で、植物（属性付きの植生として）、ハードスケープ、自由形状オブジェクトを BIM モデル用の IFC 4.3 として保存します。詳しくは [IFC](topic:planting#ifc) を参照してください。
- **最初から最後まで。** [最初から最後まで庭を設計する](topic:landscape-walkthrough) では、サンプル現場を使ってワークスペース全体を順に説明します。

### 電力線ワークスペース

- **現場の架空線と地中ケーブル。** {{ui:地表面}} › {{ui:その他}} › {{ui:電力線ワークスペース}}: 支持物で線を描き、ケーブルは管路に、機器と障害物も同じ地表面と同じプロジェクトファイルに配置します。詳しくは [電力線ワークスペース](topic:power-lines) を参照してください。
- **独自のライブラリ。** 導体、ケーブル、支持物、機器（クロスアーム、がいし、金具、支線、変圧器、キャビネット、接続部）、管路の種類を、自分で命名したカテゴリで管理し、ファイルや表計算として共有できます。国や製造者のカタログは組み込まれていません。例はあくまで例です。詳しくは [電力線ライブラリ](topic:power-line-library) を参照してください。
- **荷重条件に基づくたるみと張力。** 温度、風、着氷、片側の着氷、張力限界（破断強度の一定割合）、勾配を含む各径間の厳密なカテナリー、架線表。詳しくは [たるみと張力](topic:sag-and-tension) を参照してください。
- **常に最新の確認。** 地表面と障害物に対する離隔、相間隔、がいしの振れ、浮き上がり、ライブラリに基づく寸法決定を伴う支持物荷重、支線、金具、基礎、データの欠落、切断されたケーブル、過負荷、電圧降下を、計画図と線の縦断面図で警告表示します。設計補助ツールであり、技術者が確認してください。詳しくは [電力線の確認](topic:power-line-checks) を参照してください。
- **表、シート、GIS。** 架線表と支持物表、数量（CSV、Excel、TakeoffCraft）、計画図と縦断図のシートと検討報告書を 1 つの PDF に、すべての資産のデータを含む GIS レイヤー。詳しくは [電力線の表、数量、シート、GIS](topic:power-line-outputs) を参照してください。
- **最初の試行の後。** 線の縦断面図は選択した線に従い、**線** の一覧があります。ポインターの位置の地表面、導体、離隔を読み取り、2 点間を計測できます。ランドスケープの植物と擁壁は、線の下の障害物として扱われます。ケーブルルートと配管は縦断面図に表示され、選んだ離隔規則で交差判定されます。各離隔の横にある **規則…** で独自の規則を開けます。ライブラリ付きの規則セットは、国別に共有できるパックとして保存できます。詳しくは [電力線の確認](topic:power-line-checks) と [パック](topic:sag-and-tension#packs-rules-and-a-library-for-a-country) を参照してください。
- **独自のファイル形式。** 電力線は CivilCraft のプロジェクトファイルに、ライブラリは `.cclines.json` または CSV に、規則セットとパックはそれぞれ独自の JSON ファイルに保存されます。誰でも読み書きや変換できる公開形式です。`.DON` の検討ファイルは、これらに加えた追加の読み込みと書き出しです。
- **検討ファイル（.DON）、未テスト。** 線を別の送電線計算プログラム用の `.DON` 検討ファイルとして保存したり、そこから支持物を読み込んだりできます。形式のフィールド名に基づいて作成されており、そのプログラムではまだテストされていません。詳しくは [検討ファイル](topic:power-line-study-file) を参照してください。

### 計測

- **計測ツール。** {{ui:地表面}} › {{ui:その他}} › {{ui:計測}}（または {{key:M}}）で計画図上を計測します。各辺の長さと方位、累計、地面に沿った長さと勾配、形状を閉じると面積と周長を表示します。プロジェクトには何も描画されません。詳しくは [計測](topic:measure) を参照してください。

### 建物ボリューム

- **建物ボリュームの作図。** プロパティの **建物ボリューム** にある {{ui:ボリュームを作図}}（または {{ui:地表面}} › {{ui:その他}} › {{ui:ボリューム}}）。ボリュームに階数と階高を与え、延床面積を確認します。傾斜地での納まり（段状、ポディウム、切土）を選び、盛土と切土を確認します。ボリュームは計画図、PDF、DWG と DXF で、それぞれ専用のレイヤーに表示されます。詳しくは [現場に建物ボリュームを作図](topic:building-masses) を参照してください。
- **3D での押し引き。** 3D ビューで、選択したボリュームの屋根をドラッグするか、{{key:PageUp}} と {{key:PageDown}} を押すと、1 階ずつ 1 回の元に戻す操作で変更できます。**太陽** はボリュームの影を落とします。詳しくは [3D ビュー](topic:building-masses#in-the-3d-view) を参照してください。
- **入力する用途地域の制限。** 前面道路の線からのセットバックを 1 本ずつ、高さ制限、斜線制限、容積率、建ぺい率を設定できます。建築可能領域が計画図に描かれ、各ボリュームには制限ごとに ✓ または ✗ が表示されます。CivilCraft には用途地域の規則は組み込まれていません。すべての数値は、自分の条例から入力してください。詳しくは [入力した用途地域の制限でボリュームを確認](topic:zoning-limits) を参照してください。
- **日照時間。** 日付または季節と、名前またはオフセットで指定する時間帯を選ぶと、各ボリュームの各壁面と周囲の地面における、階ごとの直射日光の時間が計画図に表示されます。壁面と地面を CSV で保存できます。プロジェクトには座標系が必要です。詳しくは [現場の日照時間を求める](topic:sun-hours) を参照してください。
- **IFC のボリュームと BimCraft への受け渡し。** {{ui:ボリュームを IFC で保存}} は、プロジェクトに座標系がある場合は地図上の位置を保って IFC4 で保存します。{{ui:BimCraft で展開}} は、ボリュームを含む BimCraft を新しいタブで開き、**このボリュームを展開** で、フットプリントからすべての階の壁と床を作成します。何もアップロードされません。詳しくは [送り出す](topic:building-masses#send-it-on) を参照してください。

### 線形

- **クロソイド曲線。** 曲線の PI 表で **入口スパイラル** と **出口スパイラル** に長さを入力します。接線、スパイラル、曲線、スパイラル、接線の順で、長さは同じでも異なっても構いません。計画図には TS、SC、CS、ST が表示され、曲線一覧には θs と接線距離、外部距離が示され、測点とオフセットはスパイラルを通して計算されます。詳しくは [スパイラル](topic:alignment#spirals) を参照してください。
- **LandXML のスパイラル。** LandXML でクロソイド曲線を書き出しと読み込みができます。スパイラルを含む線形は、以前は読み込み時にスキップされていましたが、開けるようになりました。詳しくは [LandXML の交換](topic:landxml) を参照してください。

### コリドー

- **両側を部品から作成。** **両側を部品から作成** をオンにすると、各側に中心線から外側へ向かう個別の一覧（車線、路肩、側溝、縁石、植栽帯、歩道、独自の切土と盛土を持つ側面勾配）を設定できます。{{ui:地方道路}} または {{ui:市街地道路}} から始めて、片側を反対側にコピーできます。横断面には流末、縁石、歩道が表示され、計画地表面にも縁石が反映されます。詳しくは [両側を部品から作成](topic:corridor#build-each-side-from-parts) を参照してください。
- **スパイラル上の片勾配。** スパイラルのある曲線では、片勾配のすり付けがスパイラル上で行われ、TS で水平の路面、SC で片勾配が完全になります。詳しくは [片勾配](topic:corridor#superelevation) を参照してください。

### 3D ファイル

- **USD 書き出し。** 3D ビューで {{ui:USD}} を押すと、現場を実寸かつプロジェクト座標で `.usda`、`.usdc`、`.usdz` として書き出します。地表面、管、構造物はメッシュとして、線形の各線、測量点とその番号も含まれます。詳しくは [3D 現場を USD として書き出す](topic:usd) を参照してください。

### AI アシスタント

- **アシスタント向けの機能追加。** {{ui:設定}} › {{ui:CivilCraft}} でアシスタントをオンにすると、アシスタントは区画、切盛り、縦断面の読み取り、測量点の追加、プロジェクトの保存、LandXML、DWG、USD の書き出し、CadCraft Studio で選んだフォルダー内の作業が可能になります。ランドスケープワークスペースには、植物の検索、植物、植栽帯、生垣の配置、造成、灌水の確認のツールが加わりました。ファイルサーバーと `cadcraft` コマンドラインは、ウィンドウを開かずに保存済みプロジェクトを開きます。詳しくは [AI アシスタントに現場を任せる](topic:assistants) を参照してください。

## すべてのアプリ共通

- **単位。** {{ui:設定}} › {{ui:全般}} › {{ui:単位}} には、長さ、面積、体積、角度、勾配ごとの一覧があり、単位の定義どおりの正確な大きさが使われます（米国測量フィートは独自の単位です）。使わない単位をオフにすると単位一覧から消え、星印を付けた単位は新規作業で最初に使われます。ファイルは常に自身の単位を保持します。CivilCraft では、プロジェクトの **単位** 一覧がこの切り替えに従います。長さの星印がメートルならプロジェクトはメートルで始まり、それ以外はフィート（米国測量フィート）になります。面積または体積の星印は、面積と体積を報告する単位を決めます。長さの入力欄では、`3 ch` や `450 mm` など、どの単位の記号も入力できます。詳しくは [単位、入力値、単位一覧](common:unit-lists) を参照してください。
- **密度の高いレイアウトと格納できるパネル。** {{ui:設定}} › {{ui:全般}} › {{ui:レイアウトの密度}} › {{ui:コンパクト}} にすると、画面により多く表示されます（タッチ画面とスマートフォンは大きなボタンのまま）。各サイドパネルには細いタイトルバーがあり、ドラッグしてドッキングまたはフローティングにしたり、別のパネルのバーにドロップしてタブとして同じ枠を共有したり、ピン留めして端へ格納したり、非表示にして端から戻したりできます。詳しくは [パネルの配置](common:arrange-panels#make-the-layout-denser) を参照してください。
- **ダイアログの移動。** タイトルバーをドラッグすると、図面の邪魔にならない場所へ移動でき、閉じた場所に戻ります。タイトルバーをダブルクリックすると、再び中央に配置されます。詳しくは [ダイアログを移動](common:arrange-panels#move-a-dialog) を参照してください。
- **AI アシスタント向けのレシピ。** 独自のアシスタントに依頼する 10 個の例（図面の整理、シートの出力、図面の確認、モデルへの質問、積算の合計、部品のバリエーションの作成など）。それぞれ呼び出すツールと必要な権限があり、テストで再実行されます。アプリ自体には AI は含まれていません。詳しくは [AI アシスタント向けレシピ](common:assistants-recipes) を参照してください。
- **言語。** {{ui:設定}} › {{ui:全般}} › {{ui:言語}} に **Português (Portugal)** が新しく加わりました。これと **Português (Brasil)**、**Español (México)**、**Bahasa Indonesia** は、アプリのすべての語句が揃いました。ただし、ネイティブの校閲がまだ済んでいないドラフトです。ヘルプのトピックは英語で、一部がスペイン語です。
- **CadCraft Studio** は、更新の確認に失敗した理由（システム向けのファイルがまだない、ネットワークがない、署名が不正など）を表示するようになり、「完了」だけの表示をやめました。また、閉じた「新機能」カードは、新しいリリースが出るまで再表示されなくなりました。

## まだ未対応の項目

- **0.7 はコード署名されていません。** 署名と Microsoft ストア用パッケージは、証明書の検証がまだ完了していないため 0.8 に移りました。各ファイルの横にある SHA-256 を getcadcraft.com/download で確認してください。Windows で SmartScreen がインストーラーを止めた場合は、{{ui:詳細情報}} を選び、次に {{ui:実行}} を選びます。Mac では、初回に CadCraft Studio を右クリックして {{ui:開く}} を選びます。CadCraft Studio はまだアプリストアにありません。iPad と iPhone 向けのビルドもまだありません。
- {{ui:単位}} の角度と勾配の一覧は保存されますが、まだ読み取る箇所はありません。
- 製造者の灌水ヘッド：汎用ヘッドと、ファイルから読み込んだ独自のヘッドのみです。製造者のデータは、許可を得た場合にのみ取り込まれ、まだ許可はありません。
- BimCraft と ModelCraft には植物リストがありますが、ライブラリから配置では植物はまだ提供されません。植物は、ランドスケープ IFC を通じて BimCraft に渡されます。
- アシスタント向けのランドスケープツールは、CivilCraft のウィンドウが開いている間だけ動作します。ファイルサーバーとコマンドラインにはまだありません。
- 建物ボリューム：ファサードの採光や風、樹木やボリュームとして描かれていないものによる日陰、屋根形状はありません。日照時間は計画図に表示され、3D ビューには表示されません。BimCraft での展開は、開口部や屋根のない単純な壁と床だけを作成します。
- 電力線：組み込みの国別規格はありません（荷重条件、制限値、離隔は自分で設定します）。導体のクリープ、埋設ケーブルの熱容量、短絡、保護、接地の検討は行いません。3D ビューと IFC には線は表示されません。`.DON` の検討ファイルは、読み込むプログラムでまだテストされていません。
- クロソイド以外のスパイラル、2 つの曲線の間のスパイラル、地形線のスパイラル。スパイラルは公式と LandXML スキーマに対して確認されていますが、他のプログラムが作成したスパイラル付きの LandXML ファイルではまだ確認されていません。
- 道路に沿って変化するコリドーのアセンブリ、地域、法面勾配の目標値。
- 配水管と圧力管網（次の土木作業）、時間で変化する流量、配水と雨水の管網の連携。
- 描いたブレークラインの円弧。標準の設計車両表：付属の 5 種類の車両はプレースホルダーです。プロジェクト間で共有する地形線は、チームプロジェクトを待っています。

その他の項目は [まだ作成されていない項目](topic:not-built-yet) にあります。

1プロジェクトには1つの自然流下管網（雨水または汚水）があります。管網は構造物（マンホール、集水ます）と、それらの間の直線の管で構成されます。流れは描いた方向に流れます。CivilCraftは、各管と構造物を3つの規則で確認し、その規則から全管底高を設定できます。

## 管の区間を描く

地表面がなくても管は描けますが、天端、土被り、自動の管底高には地表面が必要です。

1. {{key:P}}を押すか、**設計**グループの{{ui:管}}をクリックします。
   ヒントには「管: 区間の上端から順に構造物をクリックします（既存の構造物をクリックすると接続します）。Enterで完了します。」と表示されます。
2. 上流の構造物を置く位置をクリックします。構造物が配置されます。
3. 次の下流の構造物を、順にクリックします。既存の構造物に接続するには、その上をクリックします。ステータスバーに「S3に接続しました。」と表示されます。
4. {{key:Enter}}を押します。
   管が描かれ、管底高が規則から設定され、ステータスバーには例えば「管3本を描画、12。管底高を規則から設定。すべての確認に合格しています。」と表示されます。

新しい構造物はS1、S2…と名付けられ、直径は48 in（1200 mm）です。新しい管はP1、P2…と名付けられ、直径は12 in（300 mm）です。直径は、フィート単位のプロジェクトでは in、メートル単位のプロジェクトでは mm で表示されます。

区間は{{key:Enter}}で終了します。ダブルクリックでも終了できますが、既存の構造物をダブルクリックして区間をそこで終えると、接続が外れます。その場合は、一度クリックしてから{{key:Enter}}を押してください。

## 規則を設定する

何も選択していないとき、右パネル（**プロジェクト**）には**管網**のブロックがあります:

| 項目 | 初期値 | 意味 |
|---|---|---|
| 種類 | {{ui:雨水}} | {{ui:雨水}}または{{ui:汚水}}。LandXMLに書き出されます |
| 最小勾配 | 0.50% | すべての管は、少なくともこの勾配で下がる必要があります |
| 最小土被り | 2 ft (0.6 m) | 地表から管の天端まで。管全体にわたります |
| 構造物内の落差 | 0.10 ft (0.03 m) | 排出口の管底高は、すべての流入口の管底高より、少なくともこの分低くなければなりません |

**これらの初期値は仮の値であり、標準ではありません。** 事業主体またはプロジェクトが求める値を設定してください。土被りは地表から天端（管底高＋内径）までで測ります。管壁の厚さは含みません。パッドまたはコリドーが造成されている場合は、造成後の地表面を地盤とします。

## 管底高を設定する

- {{ui:規則からすべての管底高を設定}}（**管網**のブロック内）で、すべての管を設定します。
- {{ui:規則から管底高を設定}}（管を1本選択した状態）で、その管だけを設定します。

上流から下流へ順に計算すると、各区間は上流の構造物で少なくとも土被りを確保し、少なくとも最小勾配で下がり、各構造物で少なくとも落差分だけ下がります。管に沿った地盤で土被りが最小値より小さくなる場合は、より深く配置されます。管底高は0.01単位で切り下げられ、切り上げられることはありません。ステータスバーには「管底高を設定: 各区間の上端で最小土被り、少なくとも最小勾配、各構造物で少なくとも落差。」と表示されます。または、設定できなかった内容が表示されます。

## 構造物と管を編集する

{{ui:選択}}で構造物または管をクリックすると、右パネルに表示されます。

**構造物**: **名前**、**天端**、**溜めの深さ**、**直径**、続いて**使用中の天端**、**溜め**、**東距**、**北距**、および流入と流出する管とその管底高。

- **天端**を空欄にすると、地表から値が取られ、ボックスには地表の値がグレーで表示されます。値を入力すると天端が固定されます。
- 平面図で構造物のグリップをドラッグして移動します。接続された管も追従しますが、管底高は変わらないので、後で問題を確認してください。

**種類**: 管網の構造物の種類（下記）から1つ選ぶか、なしを選ぶと、その直径の円形構造物になります。

**管**: **名前**、接続する構造物、**直径**、**上端の管底高**、**下端の管底高**、続いて**長さ**、**勾配**、**最小土被り**。

各値を入力した後は{{key:Enter}}を押します。

## 問題を読み、修正する

**管網**のブロックには、すべての問題が一覧表示されます（最大40件）。項目をクリックすると、その管または構造物が選択されます。管または構造物を選択すると、それ自身の問題が表示されます。何も選択していない場合は、「すべての管と構造物が規則に適合しています。」と表示されます。

| メッセージ（例） | 対処 |
|---|---|
| 「P2は上り勾配です(-0.40%)。」または「…は水平です…」 | 管底高を入れ替えるか、規則から設定します。 |
| 「P2は0.30%で、最小の0.50%より緩やかです。」 | 下流の管底高を下げるか、上流の管底高を上げます。 |
| 「P3の沿線で土被りが1.40(35)あり、最小の2未満です。」 | 管を下げ、規則から管底高を設定します。 |
| 「S3では、P4の流出管底高は245.20で、流入するP3の245.25より0.1未満しか低くありません。」 | 流出管の上端の管底高を下げます。 |
| 「P1の天端がS1の天端より上にあります。」 | 管が構造物に対して高すぎます。 |
| 「S2から2本の管が出ています。自然流下管網では、各構造物からの出口は1つであるべきです。」 | 出口の管を1本削除するか、正しい方向に描き直します。 |
| 「管がループしています。流れは排出口で終わる必要があります。」 | 区間が自身に戻るように描かれています。管を1本削除します。 |
| 「S5は地表の外にあり、天端の標高がありません。」 | 天端を入力するか、構造物を地表の上に移動します。 |
| 「P6は一部が地表の外を通っています。その部分の土被りは不明です。」 | 地表面を延ばすか、その部分の土被りは確認されないことを受け入れます。 |
| 「P7にはまだ管底高がありません。」 | 入力するか、規則から設定します。 |

問題のある管と構造物は、平面図でも赤で示されます。

## 構造物の種類

構造物の種類とは、そのパラメーターから作られる構造物です: マンホール、集水ます、接続ボックス、または排出口。**円形**（内径）または**矩形**（内幅と内長）で、**壁の厚さ**、**床スラブ**、最も低い管の下の**溜め**、そして**枠と蓋**（円形または矩形の開口、枠の高さ）を持ちます。種類は管網に属し、プロジェクトのプロパティの**構造物の種類**の下にあります。

1. {{ui:新しい構造物の種類}}をクリックします。ダイアログは、入力に合わせて構造物を平面図と断面図で描きます。
2. {{ui:種類を追加}}をクリックします。
3. 構造物を選択し、**種類**で種類を選びます。種類の寸法と溜めが適用されます。その構造物の溜めは、その後でも変更できます。

種類を編集すると、その種類のすべての構造物がサイズに追従します。種類を削除すると、構造物は同じ幅の円形構造物として残ります。変更は1回ごとに1つの操作です。{{key:Mod+Z}}で元に戻せます。

矩形の構造物は、平面図、DXF、DWG、PDFに描かれ、3Dでは長さを流出管に沿わせた長方形として表示されます。管は壁から始まります。LandXMLでは、壁の厚さとともに矩形構造物（`RectStruct`）として書き出され、そのような構造物は種類として読み込まれます。

### ライブラリで種類を共有する

{{ui:ライブラリ項目として保存}}は、種類をCadCraftのライブラリ項目（`.json`ファイル）として書き出します。平面図の記号、一般的な深さまでの3Dの形状、およびすべての寸法を含みます。ライブラリにアップロードすると共有できます。{{ui:ライブラリ項目を開く}}は、このように保存された構造物を管網に読み込み、プロジェクトの単位に変換します。CivilCraftで作られていない構造物のライブラリ項目は、理由とともに拒否されます。

## 削除

管を選択し、{{key:Delete}}を押すと削除されます。構造物を削除すると、それに接続された管も削除されます。Macでは、Fnを押しながら{{key:Delete}}を押すか、{{ui:削除}}をクリックします。

## まだ作成されていません

流量、管径、水力勾配線は[雨水排水](topic:storm-drainage)にあります。管のカタログ、円形以外の管、縦断ビューの管、曲がった管、プロジェクトあたり複数の管網は、まだ利用できません。詳しくは[まだ作成されていません](topic:not-built-yet)を参照してください。

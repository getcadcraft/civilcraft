CivilCraft はまだ初期段階です。このページには、現在のビルドでできないことを示しているので、探さずに済みます。ここに示す内容は、いつ実現するかの約束ではありません。

## 点

| まだ作成されていません | 現時点での代わりの方法 |
|---|---|
| 2 つ目の点ファイルを最初のファイルに追加すること | 先にテキストエディターまたは表計算ソフトでファイルを結合してください |
| 点のテキストファイルを書き出すこと | LandXML を書き出します（点は CgPoints として出力されます）。または GIS の{{ui:Export}}を使用します（P、N、E、Z、D のフィールドを持つ点）。または点を{{ui:Copy}}して表計算ソフトに貼り付けます |
| 点のラベルスタイル、記述キーごとの記号、線コードからの曲線（円弧）、プロジェクト間で共有する記述キーファイル | ラベルには番号、標高、記述のみを表示します（またはそれ以下）（[CivilCraft の設定](topic:settings)）。キーはプロジェクトファイルに保存されます |
| 単位の換算 | 読み込む前にファイルを換算してください。**単位**は表示名を変えるだけです |

## GIS と座標系

| まだ作成されていません | 現時点での代わりの方法 |
|---|---|
| ファイルジオデータベース。KML のスタイル、アイコン、地上オーバーレイ、ネットワークリンク | 先に GeoPackage、シェープファイル、または GeoJSON に変換してください。KML のプレースマークはスタイルなしで読み込まれます |
| GIS 要素またはその属性の編集 | GIS プログラムで編集し、再度読み込んでください。解析パネルは新しいレイヤー（バッファ、オーバーレイ、結合、選択）を作成し、面積と長さのフィールドを追加しますが、要素をその場で編集することはありません |
| ネットワーク解析とラスター解析、端が平らまたは四角のバッファと片側バッファ、属性テーブルでの行の追加または削除、フィールドの型の変更、手動のクラス色、図の凡例のスタイル | 選択を使って要素を選び、それから新しいレイヤーを作ってください。平らな端は提供されていません。属性による色分けと属性テーブルは作成済みです: [属性によるレイヤーのスタイル](topic:gis-symbology)、[レイヤーの属性テーブル](topic:gis-table)を参照 |
| ラベルのスタイル（サイズ、配置）、互いに重ならないラベル | ラベルは 1 つのサイズで、要素が密集した場所では重なることがあります |
| 鉛直基準と、ジオイドのモデル | 標高は、ファイルが与えるとおりに使われます。鉛直基準は自分で確認してください |
| NAD27 から NAD83 以外のグリッドシフト（地域に応じて提案される OSTN15、他の基準の NTv2 はファイルを追加すると使えます）、同時に複数のグリッド、鉛直グリッド | 基準に合ったグリッドファイルを自分で追加してください。プロジェクトごとに 1 つのグリッド |
| DXF または 3D の書き出しに含まれる地図レイヤー | 地図レイヤーは PDF の図に含まれ、DWG には画像として並べられます |
| サインイン、キー、トークンが必要な地図サーバー | 公開サービス、またはジオリファレンス付きの画像ファイルを使用してください |
| 地表面、地盤モデル、標高グリッドや LiDAR ツールから LAS または LAZ ファイルを書き込むこと | 地表面は GeoTIFF の標高グリッドとして書き出してください。[点群](topic:point-clouds)アドオンは、整理した点群を LAS 1.4 または LAZ として書き出します |

CivilCraftはまだ開発の初期段階です。このページは、現在のビルドで対応していない機能を示すもので、探す手間を省くためのものです。ここに記載された機能の提供時期は未定です。

## 点

| まだ作成されていません | 代わりに今日できること |
|---|---|
| 2つ目の点ファイルを1つ目に追加すること | 先にテキストエディターまたは表計算ソフトでファイルを結合します |
| 点のテキストファイルの書き出し | LandXMLを書き出します（点はCgPointとして出力されます）。GISの{{ui:書き出し}}を使います（P、N、E、Z、Dのフィールドを持つ点）。または、点を{{ui:コピー}}して表計算ソフトに貼り付けます |
| 点のラベルスタイル、記述キーごとの記号、線のコードからの曲線（円弧）、プロジェクト間で共有する記述キーファイル | ラベルには番号、標高、記述が表示されます（または一部のみ）（[CivilCraftの設定](topic:settings)）。キーはプロジェクトファイルに保存されます |
| 単位の変換 | インポート前にファイルを変換します。**単位**は表示上のラベルを変えるだけです |

| まだ作成されていません | 代わりに今日できること |
|---|---|
| File Geodatabase。KMLのスタイル、アイコン、地上オーバーレイ、ネットワークリンク | GeoPackage、シェープファイル、またはGeoJSONに先に変換します。KMLのプレースマークはスタイルなしで読み込まれます |

| ネットワーク解析とラスター解析、平端または角端のバッファーと片側バッファー、属性テーブルでの行の追加や削除、フィールドの型変更、手動のクラス色、プロットの凡例のスタイル | 選択ツールでフィーチャーを選び、そこからレイヤーを作成します。平端は提供していません。属性による色分けと属性テーブルは作成済みです: [属性でレイヤーのスタイルを設定](topic:gis-symbology)と[レイヤーの属性テーブルを扱う](topic:gis-table)を参照してください |
| ラベルのスタイル（サイズ、配置）とラベル同士の重なりの回避 | ラベルは1つのサイズで、フィーチャーが密集している場所では重なることがあります |
| 垂直基準と標高のジオイドモデル | 標高はファイルの値をそのまま使います。垂直基準は自分で確認してください |
| NAD27からNAD83以外のグリッドシフト（地域により提案されるOSTN15、他の測地系のNTv2は、ファイルを追加すると動作します）、複数グリッドの同時使用、垂直グリッド | 測地系に応じたグリッドファイルを自分で追加します。1つのプロジェクトにつきグリッド1つ |

| LiDARの強度、色、リターン。複数のバンドを持つ標高グリッド。200 MBを超えるグリッドまたはLiDARファイル | LiDARはクラスでのみフィルタリングされ、グリッドは最初のバンドを使用します。大きなファイルは先にタイルに分割します |

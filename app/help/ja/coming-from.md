Civil 3D を使ったことがあれば、CivilCraft の考え方はすでにご存じです。点と点グループ、地性線と境界を持つ TIN 地表面、PI による線形、PVI による縦断、コリドーに沿って掃引されたアセンブリ、法尻線までの造成、重力式の管路網、LandXML などです。違うのは、それらを取り巻くほぼすべてです。図面ファイルはなく、コマンドラインもありません(ただし {{ui:Drafting classic}} のメニュースタイルを選んだ場合を除く)。スタイルもなく、Prospector も設定ダイアログもありません。CivilCraft はブラウザーで動作する小さく焦点を絞ったツールで、このビルドでは、フル機能の土木パッケージができることのごく一部しか行えません。このページでは、お持ちの知識と、ここでの対応を結びつけます。

:::tip
Civil 3D のリボンが好みなら、{{ui:Settings}} › {{ui:CivilCraft}} › {{ui:Menus, keys and mouse}} で {{ui:Civil ribbon}} メニュースタイルを選んでください。ホーム、地表面、修正、位置情報、表示、出力の各タブが表示され、中ボタンで画面をパンでき、{{key:Shift}} と中ボタンで 3D ビューを軌道回転できます。コマンドを入力する場合は、{{ui:Drafting classic}} でコマンドラインが追加されます(ALIGNMENT、PAD、PROFILE、ZOOM …)。[メニュー、キー、マウス](topic:menus-keys-and-mouse)を参照してください。
:::

## ワークフローの対応表

| やりたいこと | 慣れた方法 | CivilCraftでの方法 |
|---|---|---|
| 測量点を読み込む | 点ファイル形式で点を読み込む | {{ui:Open}} のあと、**点の読み込み** で列の順番を確認([測量点を読み込む](topic:import-points)) |
| 点を並べ替える | 点グループ、記述キー | 説明の最初の語で自動的にグループ化されます。記述キーはありません |
| 点を編集する | 点エディター、グリップ | クリックしてプロパティで入力するか、ドラッグします([測量点を編集する](topic:edit-points)) |
| 現況地盤を作成する | 地表面を作成し、点グループをデータとして追加する | 自動: 入力が変わるたびに地表面が再構築されます |
| 地性線を追加する | ポリラインや地形線から地性線を追加する | 点グループを {{ui:Breakline}} に設定するか、{{ui:Breakline}} ツール({{key:B}})で点をクリックします |
| 地表面を切り取る | 外側の境界、非表示の境界、最大三角形長 | {{ui:Boundary}}({{key:O}}、外側のみ)と **外周辺の最長辺** |
| 等高線を表示する | 地表面スタイル | 左パネルの **表示**: 間隔、主曲線の間隔、ラベル、帯、勾配の矢印 |
| 中心線をレイアウトする | 線形作成ツール、曲線とスパイラルの設定 | {{ui:Alignment}}({{key:A}}): PI をクリックし、{{key:Enter}}。半径とスパイラルの長さは PI 表で入力 |
| 縦断ビューを作成する | 縦断ビューのウィザード、帯 | {{ui:Profile}}({{key:R}}): 平面図の下に 1 つの縦断ビューを表示し、常に全体に収まります |
| 勾配を設計する | 縦断のレイアウトツール | {{ui:Start from the ground}}、{{ui:Add PVIs}}({{key:I}})、PVI のドラッグ、**曲線 L** の入力 |
| 道路を作成する | アセンブリ、サブアセンブリ、コリドー、ターゲット、領域 | 線形の下で **設計縦断に沿ってアセンブリを掃引** にチェックを付けます。各側に車線、路肩、法面を設定するか、各側を部品(側溝、縁石、歩道など)から構成します |
| 造成面を作成する | 地形線、造成グループ、造成の基準 | {{ui:Pad}}({{key:G}}): 切土と盛土の法面が法尻線まで続く、平らな造成面 |
| 土量を計算する | 体積の地表面、体積のダッシュボード | 右パネルの **土工**。グリッド法で、リアルタイムに更新されます |
| 雨水や汚水をレイアウトする | 部品リストと規則付きの管路網 | {{ui:Pipes}}({{key:P}}): 下流の構造物をクリックします。設定する 3 つの規則と、自動の管底高 |
| 他のソフトとデータをやりとりする | LandXML の読み込みと書き出し | LandXML ファイルを {{ui:Open}}。書き出しは {{ui:LandXML}}([LandXML を交換する](topic:landxml)) |
| 線データをCADへ送る | DWG への書き出し | {{ui:DWG}}(2000〜2018 形式)または {{ui:DXF}}(R12) |
| 印刷する | レイアウト、ビューポート、シートセット | {{ui:PDF}}: 選んだ縮尺で平面図を 1 枚の横向きシートにします。平面・縦断図と断面図も PDF で出力できます |
| ファイル間で作業を共有する | データショートカット、参照 | 利用できません: 1 ファイルに 1 プロジェクト |
| 元に戻す | 元に戻す | {{key:Mod+Z}} と {{key:Mod+Y}}、200 ステップ。表示設定は元に戻す操作にはなりません |

## つまずきやすい違い

**コマンドラインはありません。** {{ui:Drafting classic}} メニュースタイルを選ばない限り、コマンドラインはありません。ツールはツールバーのボタンと 1 文字のキーです: {{key:A}} 線形、{{key:G}} 造成面、{{key:P}} 管路、{{key:B}} 地性線、{{key:O}} 境界、{{key:R}} 縦断、{{key:I}} PVI の追加、{{key:V}} 選択、{{key:F}} フィット。他のメニュースタイルでは、コマンド名を入力しても何も起こりません。[キーとマウス](topic:keyboard)を参照してください。

**Enter で完了します。ダブルクリックは危険です。** 最後の点を一度クリックしてから {{key:Enter}} を押してください。このビルドではダブルクリックでも完了しますが、ダブルクリックした点が削除されます。右クリックでは完了も繰り返しもできません。右ドラッグでは画面が移動するだけです。

**すべてが常に動的です。** 点グループ、半径、PVI、造成面の勾配を変更すると、地表面、等高線、コリドー、法尻線、土量がすぐに更新されます。再構築する必要はなく、古くなることもありません。

**何も図面オブジェクトではありません。** 平面図は設計の表示であり、CAD コマンドで編集できる図面ではありません。独自の線や文字を追加したり、レイヤーの色を変えたり、分解したりはできません。DXF に書き出して、CAD ソフトで図面を仕上げてください。

**スタイルはありません。** 色、線の太さ、ラベルの大きさ、レイヤー名は固定されています([平面レイヤー](topic:plan-layers)を参照)。アプリバーの **ペーパー** と **モデル** で、明るい画面と暗い画面を切り替えます。

**1 つずつです。** 1 プロジェクトにつき、既存地盤の地表面は 1 つ、造成結果は 1 つ、管路網は 1 つです。線形と造成面は複数あっても問題ありません。

**単位はラベルにすぎません。** {{ui:US feet}} または {{ui:Metres}} を選んでも、換算は行われません。図面の縮尺はありません。座標系は任意です。{{ui:Coordinates}} で設定しても何も移動せず、数値の意味を示すだけです([プロジェクトの座標系を設定する](topic:coordinate-systems)を参照)。LandXML に書き出す際、フィートは米国測量フィートとして扱われます。

**地性線のグループは点番号の順に結ばれます。** {{ui:Breakline}} に設定されたグループは、すべての点を番号順に通る 1 本の線になります。同じコードを共有する場合(2 本の流路線がともに「FL」とコード付けされている場合など)は、1 本のジグザグな線になります。そのような線は手で描いてください。

**測点は同じように見えても、メートルでは異なります。** フィートは 100 ft 単位の測点(12+34.56)、メートルは 1000 m 単位の測点(1+234.567)を使います。

**Mac での削除。** delete と表示された Mac のキーは、ブラウザーでは Backspace として働きます。選択を削除するには、Fn と delete、または {{ui:Delete}} ボタンを使ってください。

**ファイルはダウンロードです。** {{ui:Save}} を押すたびに `.civilcraft.json` ファイルがダウンロードされます。開いているファイルに上書き保存する機能はありません。未保存の作業の復元コピーは、このブラウザーに保存されます([未保存の作業を復元する](common:recover))。点ファイルを開くと、確認なしに点が置き換えられます。[開く、保存、書き出せるファイル](topic:files)を参照してください。

**規則はご自身で定めてください。** 管路網の規則とコリドーのアセンブリは、標準ではないプレースホルダーの値から始まります。確認結果を信頼する前に、ご自身の値を設定してください。

**土量はグリッドベースです。** 切土と盛土は、2 つの地表面の間の細かいグリッドから、法尻線の内側で求められます。膨張や収縮は考慮されません。TIN 間の土量計算に近いものですが、同一ではありません。

## まだ利用できない機能

クロソイド以外のスパイラル、道路に沿って変化するアセンブリ、勾配のある造成面、流入桝の処理能力と調整池、部品カタログ、縦断内の管、平面の区画レイアウトと区画の規模決定、最小二乗調整と測量データベース、DWG の読み込みなど。現時点での代替手段を含む全リストは、[まだ作成されていません](topic:not-built-yet)にあります。

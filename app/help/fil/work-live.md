## Ang matututunan mo

Ang nangyayari sa isang project habang maraming tao ang sabay na nagtatrabaho dito. Sinisimulan at sinasalihan ng CadCraft Studio ang Live TeamWork session (I-share nang live, Sumali); ang pahinang ito ay tungkol sa mismong project.

## Sabay-sabay ang lahat

Ang mga point at disenyo ng host ay napupunta sa bawat sumasali. I-edit ang mga point, gumuhit ng alignment, pad, feature line at parcel gaya ng dati. Agad lumalabas ang sarili mong mga edit; lumalabas ang sa iba pagkaraan ng sandali mula nang gawin nila ang mga ito.

- **Mga point** ay pinagsasama-sama isa-isa: dalawang taong gumagalaw ng dalawang point ay parehong napapanatili ang kanilang mga pagbabago.
- **Mga alignment, pad, feature line at parcel** ay pinagsasama-sama kada bagay at setting; ang parehong setting ay mapupunta sa mas huling pagbabago.
- **Ang surface** ay binubuo sa bawat window mula sa parehong point at breakline, kaya nagkakasundo ang contour at volume.

Hindi ibinabahagi sa session: isang surface na ikinarga mula sa grid file, mga feature ng GIS layer, mga map picture at grid shift file. Nananatili sila sa window na nagbukas sa mga ito.

## Makita ang isa't isa

May sariling kulay ang bawat tao sa session. Sa plano, makikita mo ang pointer ng bawat tao bilang arrow sa kanilang kulay na may pangalan sa tabi, at isang putol-putol na kahon sa kanilang kulay sa paligid ng mga point at object na napili nila. Habang bukas ang 3D view sa ibabaw ng plano, maghihintay ang mga pointer hanggang isara mo ito.

Ang mga pointer, pangalan at pagpili ay para lamang sa session: hindi sila kailanman sine-save sa file at hindi pumapasok sa undo ng sinuman. Dumudulas sila papunta sa kinaroroonan ng bawat tao, kaya nananatiling maayos ang galaw kahit mabagal ang koneksyon.

## Ang undo ay nag-u-undo ng sarili mong gawa

Binabawi ng {{key:Mod+Z}} ang sarili mong huling edit at iniiwan ang sa lahat ng iba. Kapag may nagbago ng parehong bagay mula noon, walang mababawi at sinasabi ng status bar kung sino.

## Sumali mula sa browser

Maaaring i-scan ng katrabahong walang Studio ang larawan sa ilalim ng code ng host gamit ang telepono, tablet o computer sa parehong network. Magbubukas ang CivilCraft sa browser at mapupuno ng project ng host kapag pinapasok ka ng host. Pinapayagan ng invite link ang pagsali mula sa ibang network: kailangan ng host ng Team Cloud Plan seat para sa app, libre ang lahat ng iba, at gumagana lamang ang link habang bukas ang session ng host.

## Kapag natapos ang session

Ang host lamang ang nagse-save ng project. Ang iba ay may sariling hindi naka-save na kopya: i-save ito kung gusto mong itago.

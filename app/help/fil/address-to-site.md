## Ano ang ginagawa nito

Surface › Higit pa › Address papunta sa site ay sumasagot, para sa isang punto: aling parcel ito nakapaloob, ang mga gusaling nakapalibot dito, ang zoning, ang lupa at ang flood zone. Bukas ang data: mga file na idinadagdag mo (GeoJSON, shapefile, KML, GeoPackage) at, kapag binuksan mo ang mga add-on, mga button na humihiling sa isang open service bawat isa.

## Paano gamitin

1. Mag-type ng address at pindutin ang address-search button (ang add-on na "Paghahanap ng address"), o mag-type ng latitude at longitude.
2. Magdagdag ng mga layer: mga file gamit ang "Magdagdag ng file", o ang iba pang source button (flood zone, mga gusali, lupa, taas ng lupa, county parcels). Hindi hihingin ang isang service maliban kung pinindot ang button nito; walang kinukuha sa simula.
3. Pindutin ang run button para sa sagot sa salita, kasama ang CSV.
4. Ang "I-save ang site bilang file" o "Ipadala sa BimCraft bilang mungkahi" ay nagbibigay ng mga outline sa BimCraft o ModelCraft; nakalista nila ang mga ito at idinadagdag lamang ang mga minarkahan mo.

## Dapat tandaan

- Dumadaan ang address search sa getcadcraft.com, na humihiling sa OpenStreetMap's Nominatim para sa iyo (isang request kada segundo, pinakamarami; ang mga sagot ay itinatago nang 90 araw para hindi na muling hihingin ang parehong address; hash lamang ng address ang nakaimbak, hindi kung sino ang nagtanong). Ang iba pang button ay dumidiretso mula sa browser mo papunta sa kanilang service.
- May sariling lisensya ang bawat source (ang OpenStreetMap ay ODbL: panatilihin ang credit line).
- Kasing-ganda ng open data sa lugar mo ang mga layer. Suriin ang mahahalagang bagay laban sa survey.

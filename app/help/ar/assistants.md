## ما ستتعلمه

كيف تسمح لمساعد ذكي (أي مساعد يتكلم MCP) بالعمل مع الموقع المفتوح لديك، وما يستطيع فعله وما لا يستطيعه، وكيف توقفه.

## ما يستطيع المساعد فعله في CivilCraft

| يطلب | ما يحصل عليه | يحتاج إلى |
|---|---|---|
| الموقع | الاسم والوحدات ونظام الإحداثيات ومجموعات النقاط والمحاور والأسطح والمنصات وقطع الأراضي والأنابيب | قراءة |
| نقاط المسح | الرقم والإحداثي الشرقي والشمالي والمنسوب والوصف، حسب المجموعة أو حسب الوصف أو داخل مستطيل | قراءة |
| مناسيب السطح | الأرض الموجودة (أو السطح المُسوّى) عند أي نقاط يسمّيها | قراءة |
| المحطات والإزاحات | المحطة والإزاحة للنقاط على امتداد محور، أو الإحداثيات ومنسوب الأرض للمحطات | قراءة |
| مقطع طولي | مناسيب الأرض والمقطع التصميمي والسطح المُسوّى على امتداد محور، كل عدد من الأقدام أو الأمتار | قراءة |
| القطع والردم | الأحجام بين الأرض الموجودة والسطح المُسوّى (وكذلك كل منصة وممر)، أو بين الأرض ومستوى | قراءة |
| قطع الأراضي | الأركان والمساحة (بالأكر أو الهكتار) والمحيط والوصف القانوني | قراءة |
| تحديد | النقاط التي يسمّيها تُحدَّد على المخطط كما لو التقطتها بنفسك | تحرير |
| نقاط مسح جديدة | نقاط تُضاف بالأرقام التي يعطيها، أو بالأرقام الحرة التالية. كل استدعاء خطوة واحدة يمكن التراجع عنها | تحرير |
| حفظ | الحفظ الخاص بـ CivilCraft {{ui:حفظ}} | حفظ |
| LandXML أو DWG | الملفات نفسها التي تكتبها أزرار {{ui:LandXML}} و{{ui:DWG}} | تصدير |
| الموقع ثلاثي الأبعاد | OpenUSD (‏.usdz أو .usda أو .usdc) للأرض والسطح المُسوّى والمنصات والأنابيب، كما يصدّرها عرض 3D | تصدير |
| النباتات وجدول النباتات | النباتات الموجودة في قائمة النباتات بأي اسم، وأعداد جدول النباتات | قراءة |
| الزراعة والتسوية | نباتات أو حوض أو سياج نباتي يُوضع، أو منصة أو تلّ ترابي أو قناة تصريف ضحلة أو منطقة تسوية تُضاف، كل منها خطوة واحدة يمكن التراجع عنها، مع قطعها وردمها | تحرير |
| فحص الري | تدفق كل منطقة، والضغط اللازم عند صمامها وعند التغذية، وأعلى ضغط في أسوأ الحالات، وأزمنة التشغيل، والمشكلات، وقائمة المواد، كأداة حساب يراجعها مصمم الري | قراءة |

يعمل المساعد مع الموقع المفتوح. وفي Studio يستطيع أيضًا الحفظ والتصدير إلى مجلدات تختارها (أدناه)، ومن دون مجلد تُنزَّل ملفاته كما تُنزّلها الأزرار.

## فعّله

تصل المساعدات إلى CivilCraft عبر CadCraft Studio على حاسوبك؛ أما المتصفح العادي فلا منفذ له.

1. افتح {{ui:الإعدادات}} واختر تبويب **CivilCraft**.
2. ضمن **المساعدون**، ضع علامة في مربع **السماح للمساعدين الذكيين والسكربتات باستخدام CivilCraft**.
3. **قراءة** مُفعّلة لك تلقائيًا. ضع علامة في **تحرير** أو **حفظ** أو **تصدير** فقط حين يحتاجها المساعد.
4. لتسمح له بالحفظ والتصدير إلى مجلد، اختر {{ui:إضافة مجلد…}} تحت **المجلدات المسموح باستخدامها**، واختر المجلد في مربع حوار Studio. يسحبه {{ui:إزالة}} فورًا، ويُرفض أي مسار آخر.
5. وصّل المساعد في Studio (يعرض Studio العنوان والإعدادات التي تلصقها فيه).

## أثناء اتصال مساعد

تظهر ملاحظة أعلى اللوحة اليمنى تحدد المساعد المتصل وما يستطيع فعله. انقر {{ui:فصل}} لإنهاء جلسته فورًا؛ عليه أن يعيد الاتصال ليكمل.

**النشاط**، تحت **المساعدون** في الإعدادات، يسرد كل استدعاء قام به المساعد، الأحدث أولًا، مع بيان نجاحه.

:::tip
اطلب بكلمات عادية، مثلًا "ما منسوب الأرض كل 50 قدمًا على طول Main Street؟"، "كم حجم القطع والردم الذي تحتاجه المنصات؟" أو "أضف نقطة تحكم عند هذه الإحداثيات". يقرأ المساعد الموقع ويجيب، أو يُجري التغيير كخطوة واحدة يمكن التراجع عنها.
:::

## بدون فتح CivilCraft

يفتح خادم ملفات CadCraft للمساعدين (`npx @getcadcraft/mcp`) وسطر الأوامر `cadcraft` مشاريع CivilCraft المحفوظة (`.civilcraft.json`) وملفات النقاط بالشيفرة الخاصة بـ CivilCraft دون نافذة: أدوات القراءة نفسها، وإضافة النقاط، وحفظ المشروع، وLandXML، والموقع ثلاثي الأبعاد بصيغة OpenUSD. يكتب `cadcraft convert site.civilcraft.json site.xml` ملف LandXML من سطر الأوامر. أما فتح LandXML وتصدير DWG وأدوات مساحة العمل Landscape فما زالت تحتاج إلى نافذة CivilCraft.

## أوقفه

ألغِ تحديد **السماح للمساعدين الذكيين والسكربتات باستخدام CivilCraft**. يُفصَل كل مساعد فورًا، ويُحفظ الإعداد للمرة القادمة.

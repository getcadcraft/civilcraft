تعمل مفاتيح الحرف الواحد عندما لا تكتب في مربع. تستخدم الاختصارات التي تحوي {{key:Mod}} مفتاح Command على Mac، ومفتاح Ctrl في غيره. انظر أيضًا [المفاتيح في المتصفح](common:keys).

## الملفات والتحرير

| المفتاح | الإجراء |
|---|---|
| {{key:Mod+O}} | افتح ملف نقاط أو LandXML أو مشروعًا |
| {{key:Mod+S}} | احفظ المشروع (ينزّل ملف `.civilcraft.json`) |
| {{key:Mod+P}} | اطبع المخطط إلى PDF (يفتح مربع حوار الطباعة الخاص بالبرنامج، لا طباعة المتصفح) |
| {{key:Mod+Z}} | تراجع |
| {{key:Mod+Y}} | إعادة |
| {{key:Delete}} | احذف نقاط المساحة المحددة، أو المحور، أو المنصة، أو المنشأة، أو الأنبوب، أو PVI |
| {{key:Mod+C}} | انسخ نقاط المساحة المحددة (وأيضًا كصفوف نقاط لجدول البيانات) |
| {{key:Mod+X}} | اقطع نقاط المساحة المحددة |
| {{key:Mod+V}} | الصق النقاط: تتبع المؤشر، وانقر حيث تريدها |
| {{key:Mod+Shift+V}} | لصق في المكان: عند إحداثيات النقاط نفسها |
| {{key:Mod+D}} | كرّر النقاط المحددة: تتبع النسخة المؤشر |
| {{key:Mod+A}} | حدّد كل نقاط المساحة |
| {{key:Esc}} | إلغاء التحديد (وإلغاء اللصق) |

تعمل {{key:Mod+S}} و{{key:Mod+O}} و{{key:Mod+P}} حتى أثناء الكتابة في مربع. أما {{key:Mod+Z}} و{{key:Mod+Y}} داخل مربع نص فتتراجع عن كتابتك كالمعتاد، وكذلك {{key:Mod+C}} و{{key:Mod+X}} و{{key:Mod+V}} و{{key:Mod+A}}: داخل المربع تنسخ النص وتقصّه وتلصقه وتحدده. وإذا حُدِّد نص في الصفحة (داخل لوحة)، فإن {{key:Mod+C}} ينسخ ذلك النص. {{key:Mod+Shift+Z}} لا يفعل شيئًا في CivilCraft: استخدم {{key:Mod+Y}} أو زر {{ui:Redo}}.

:::mac
المفتاح المكتوب عليه **delete** في Mac هو {{key:Backspace}} بالنسبة إلى المتصفح. لحذف تحديد، اضغط {{key:Delete}} (Fn و delete)، أو اختر {{ui:Delete}} من قائمة {{ui:More}} في شريط الأدوات.
:::

## الأدوات

| المفتاح | الأداة |
|---|---|
| {{key:V}} | {{ui:Select}} |
| {{key:M}} | {{ui:Measure}}: المسافات والمساحات والانحدارات على المخطط ([القياس](topic:measure)) |
| {{key:A}} | {{ui:Alignment}} |
| {{key:G}} | {{ui:Pad}} |
| {{key:P}} | {{ui:Pipes}} |
| {{key:B}} | {{ui:Breakline}} |
| {{key:O}} | {{ui:Boundary}} |
| {{key:R}} | إظهار عرض القطاع الطولي أو إخفاؤه |
| {{key:I}} | فعّل {{ui:Add PVIs}} أو أوقفه (يفتح عرض القطاع الطولي إن كان مغلقًا) |
| {{key:F}} | {{ui:Fit}}: إظهار كل شيء |
| {{key:D}} | {{ui:3D}}: عرض الموقع بثلاثة أبعاد، أو العودة إلى المخطط |

الضغط على مفتاح الأداة النشطة مرة أخرى يعيدك إلى {{ui:Select}}. الحروف مع Shift لا تفعل شيئًا.

## أثناء الرسم

| المفتاح | الإجراء |
|---|---|
| {{key:Enter}} | أنهِ المحور أو المنصة أو مسار الأنابيب أو خط الكسر أو الحد |
| {{key:Backspace}} | أزِل آخر نقطة نقرتها |
| {{key:C}} | خط الميزة: فعّل الأقواس أو أوقفها (بعد رأس، انقر نقطة على المنحنى ثم نهايته) |
| {{key:Esc}} | ألغِ الرسم (أو اللصق)؛ وعند الضغط مرة أخرى (أو عندما لا يكون هناك شيء مرسوم)، عُد إلى {{ui:Select}} وامسح التحديد |

## عرض المخطط

| المفتاح أو الإجراء | النتيجة |
|---|---|
| عجلة الفأرة | تكبير أو تصغير عند المؤشر |
| السحب على مساحة فارغة | تحريك (في أي أداة؛ النقرة القصيرة تبقى نقرة؛ ومع الضغط على {{key:Shift}} يرسم مربع تحديد بدلًا من ذلك) |
| السحب بالزر الأوسط | تحريك |
| السحب بالزر الأيمن | تحريك (لا تُفتح قائمة) |
| {{key:Space}} والسحب | تحريك |
| النقر | تحديد (مع {{ui:Select}})، أو وضع نقطة (مع أداة رسم) |
| {{key:Shift}} والنقر | إضافة نقطة مساحة إلى التحديد أو إزالتها |
| {{key:Shift}} والسحب | رسم مربع: تُضاف نقاط المساحة داخله إلى التحديد. اسحب حولها لاستخدام [اللاسو](topic:lasso-selection) |
| {{key:Space}} أثناء رسم اللاسو | نافذة، ثم عبور، ثم سياج |
| النقر أثناء اللصق | وضع نقاط اللصق هناك ({{key:Enter}} يضعها عند إحداثياتها الخاصة) |
| سحب مقبض | نقل نقطة PI أو زاوية منصة أو منشأة (خطوة تراجع واحدة) |
| {{key:Up}} {{key:Down}} {{key:Left}} {{key:Right}} | تحريك، عندما يكون المخطط في بؤرة التركيز (انقر عليه أولًا) |
| {{key:Plus}} و{{key:Minus}} | تكبير وتصغير من المنتصف، عندما يكون المخطط في بؤرة التركيز |

مفتاح = يكبّر مثل {{key:Plus}}، فلا تحتاج إلى Shift.

## عرض القطاع الطولي

| الإجراء | النتيجة |
|---|---|
| النقر مع تفعيل {{ui:Add PVIs}} | إضافة PVI هناك |
| النقر على PVI | تحديده |
| سحب PVI | نقله (خطوة تراجع واحدة) |
| {{key:Delete}} أو {{key:Backspace}} | إزالة PVI المحدد ({{key:Backspace}} فقط عندما يكون عرض القطاع الطولي في بؤرة التركيز) |

لا يكبّر عرض القطاع الطولي ولا يحرّكه.

## الشاشة والمساعدة

| المفتاح | الإجراء |
|---|---|
| {{key:F1}} | افتح هذه المساعدة أو أغلقها (اللوحة الجانبية)؛ و{{ui:Help}} في شريط التطبيق يفعل الشيء نفسه |
| {{key:Esc}} | أغلق لوحة المساعدة عندما تكون مفتوحة |
| {{key:Ctrl+Shift+F}} | تنقّل بين أوضاع الشاشة: ملء الشاشة، وملء الشاشة مع إخفاء الأشرطة، والعادي |
| {{key:Esc}} | الخروج من ملء الشاشة (مفتاح المتصفح نفسه) |

يصل {{key:F1}} إلى المساعدة قبل أن يراه CivilCraft، فيعمل في أي أداة. في معظم لوحات مفاتيح Mac، اضغط fn مع F1، أو انقر {{ui:Help}}. يستخدم {{key:Ctrl+Shift+F}} مفتاح Control على كل المنصات، بما فيها Mac. انظر [استخدام المساعدة](common:help) لمعرفة كيفية البحث في هذه المساعدة.

## الفأرة ولوحة اللمس واللمس

:::mouse
- عجلة الفأرة تكبّر عند المؤشر. الفأرة ذات العجلة الحرة الدوران تكبّر بسرعة: أدِرها بلفات قصيرة.
- حرّك بأي سحب على مساحة فارغة، أو بالزر الأوسط، أو بالزر الأيمن، أو بـ{{key:Space}} مع السحب.
:::

:::mac
على لوحة اللمس في Mac:

- التمرير بإصبعين **يكبّر** (ولا يحرّك)، والقرص يكبّر أيضًا.
- للتحريك، اضغط واسحب على مساحة فارغة بإصبع واحد، أو اضغط مع الاستمرار على {{key:Space}} واسحب.
- النقر بإصبعين (النقر الأيمن) لا يفتح قائمة ولا يفعل شيئًا وحده.
:::

:::touch
على الشاشة اللمسية:

- أول لمسة تجعل الأزرار وصفوف القوائم بحجم الإصبع.
- المس للتحديد أو لوضع نقطة؛ وسحب إصبع واحد على مساحة فارغة يحرّك. قد تهتز اللمسة قليلًا: لا يحرّك إلا بعد أن يتحرك الإصبع نحو 10 بكسل.
- إصبعان يقرصان للتكبير ويتحركان معًا للتحريك.
- اسحب مقبضًا أو PVI بإصبع واحد. تأخذ المقابض عرض إصبع حولها.
- أثناء رسم محور أو منصة أو خط كسر أو حد أو مسار أنابيب أو خط ميزة أو قطعة، يعرض شريط فوق المخطط {{ui:Finish}} ({{key:Enter}}) و{{ui:Undo point}} ({{key:Backspace}}) و{{ui:Cancel}} ({{key:Esc}}). الضغط المطوّل (نصف ثانية دون حركة) يُنهي أيضًا.
- في {{ui:Select}}، الضغط المطوّل على نقطة مساحة يضيفها إلى التحديد أو يزيلها، كما يفعل النقر مع {{key:Shift}}.
- في العرض ثلاثي الأبعاد، إصبع واحد يدور، وإصبعان يقرصان ويحرّكان، واللمسة تختار.
- لا يوجد تمرير مؤشر في اللمس، لذا تتحدّث قراءات شريط الحالة فقط أثناء وجود إصبع على الشاشة.
:::

## مفاتيح المتصفح التي تغلب

بعض المفاتيح تخص المتصفح ولا تصل أبدًا إلى CivilCraft، مثل {{key:Mod+W}} (إغلاق علامة التبويب)، و{{key:Mod+T}} (علامة تبويب جديدة)، و{{key:Mod+N}} (نافذة جديدة)، و{{key:F11}} (ملء الشاشة في متصفحات Windows وLinux). ولا يستخدمها CivilCraft. إن فتح اختصار شيئًا في المتصفح بدلًا من ذلك، فانقر المخطط مرة واحدة لتكون الصفحة في بؤرة التركيز، ثم جرّب مرة أخرى.

## أين يوجد النقل

لا يوجد أمر نقل: اختر {{ui:Select}} واسحب نقطة أو رأسًا، أو عدّل إحداثياتها في {{ui:Properties}}. انظر [تحرير النقاط](topic:edit-points).

একক-অক্ষরের কী তখনই কাজ করে যখন আপনি কোনো বাক্সে টাইপ করছেন না। {{key:Mod}} দিয়ে শর্টকাট ম্যাকে Command ও অন্যত্র Ctrl ব্যবহার করে। আরও দেখুন [ব্রাউজারে কী](common:keys)।

## ফাইল ও সম্পাদনা

| কী | কাজ |
|---|---|
| {{key:Mod+O}} | একটি বিন্দু ফাইল, LandXML বা প্রকল্প খুলুন |
| {{key:Mod+S}} | প্রকল্প সংরক্ষণ করুন (একটি `.civilcraft.json` ফাইল ডাউনলোড করে) |
| {{key:Mod+P}} | পরিকল্পনা PDF-এ প্লট করুন (প্লট ডায়ালগ খোলে, ব্রাউজারের প্রিন্ট নয়) |
| {{key:Mod+Z}} | পূর্বাবস্থায় ফিরুন |
| {{key:Mod+Y}} | আবার করুন |
| {{key:Delete}} | নির্বাচিত সার্ভে বিন্দু, অ্যালাইনমেন্ট, প্যাড, স্ট্রাকচার, পাইপ বা PVI মুছুন |
| {{key:Mod+C}} | নির্বাচিত সার্ভে বিন্দু কপি করুন (স্প্রেডশিটের জন্য বিন্দু সারি হিসেবেও) |
| {{key:Mod+X}} | নির্বাচিত সার্ভে বিন্দু কাট করুন |
| {{key:Mod+V}} | বিন্দু পেস্ট করুন: তারা পয়েন্টারকে অনুসরণ করে, যেখানে যাবে সেখানে ক্লিক করুন |
| {{key:Mod+Shift+V}} | জায়গামতো পেস্ট করুন: বিন্দুর নিজস্ব স্থানাঙ্কে |
| {{key:Mod+D}} | নির্বাচিত বিন্দুর নকল করুন: একটি কপি পয়েন্টারকে অনুসরণ করে |
| {{key:Mod+A}} | প্রতিটি সার্ভে বিন্দু নির্বাচন করুন |
| {{key:Esc}} | কিছুই নির্বাচন না করুন (এবং পেস্ট বাতিল করুন) |

{{key:Mod+S}}, {{key:Mod+O}} ও {{key:Mod+P}} বাক্সে টাইপ করার সময়ও কাজ করে। একটি টেক্সট বাক্সে {{key:Mod+Z}} ও {{key:Mod+Y}} বরং আপনার টাইপ পূর্বাবস্থায় ফেরায়, স্বাভাবিকভাবে, এবং একইভাবে {{key:Mod+C}}, {{key:Mod+X}}, {{key:Mod+V}} ও {{key:Mod+A}}: বাক্সে তারা টেক্সট কপি, কাট, পেস্ট ও নির্বাচন করে। পেজে (একটি প্যানেলে) টেক্সট নির্বাচিত থাকলে {{key:Mod+C}} সেই টেক্সট কপি করে। {{key:Mod+Shift+Z}} CivilCraft-এ কিছু করে না: {{key:Mod+Y}} বা {{ui:Redo}} বোতাম ব্যবহার করুন।

:::mac
লেবেলযুক্ত **delete** ম্যাক কীটি ব্রাউজারের কাছে {{key:Backspace}}। একটি নির্বাচন মুছতে {{key:Delete}} চাপুন (Fn ও delete), বা টুলবারের {{ui:More}} মেনু থেকে {{ui:Delete}} বেছে নিন।
:::

| {{key:Backspace}} | শেষ ক্লিক করা বিন্দু সরান |
| {{key:C}} | ফিচার লাইন: আর্ক চালু বা বন্ধ করুন (একটি ভার্টেক্সের পরে, বক্ররেখার উপর একটি বিন্দুতে ক্লিক করুন, তারপর তার শেষ) |
| {{key:Esc}} | আঁকা বা পেস্ট বাতিল করুন; আবার চাপলে (বা কিছু আঁকা না থাকলে) {{ui:Select}}-এ ফিরুন এবং নির্বাচন মুছুন |

## পরিকল্পনা ভিউ

| কী বা কাজ | ফল |
|---|---|
| হুইল | পয়েন্টারে জুম ইন বা আউট |
| ফাঁকা জায়গায় টেনে | প্যান (যেকোনো টুলে; ছোট ক্লিক এখনও ক্লিক করে; {{key:Shift}} ধরে রাখলে বদলে একটি নির্বাচন বাক্স আঁকে) |
| মাঝের বোতাম টেনে | প্যান |
| ডান বোতাম টেনে | প্যান (কোনো মেনু খোলে না) |
| {{key:Space}} ও টেনে | প্যান |
| ক্লিক | নির্বাচন ({{ui:Select}} দিয়ে), বা বিন্দু বসানো (একটি আঁকার টুল দিয়ে) |
| {{key:Shift}} ও ক্লিক | নির্বাচনে একটি সার্ভে বিন্দু যোগ করুন, বা তা বাদ দিন |
| {{key:Shift}} ও টেনে | একটি বাক্স আঁকুন: তার ভিতরের সার্ভে বিন্দুগুলো নির্বাচনে যোগ হয়। [ল্যাসো](topic:lasso-selection)-এর জন্য তাদের চারপাশে টানুন |
| ল্যাসো আঁকার সময় {{key:Space}} | উইন্ডো, তারপর ক্রসিং, তারপর ফেন্স |
| পেস্ট করার সময় ক্লিক | পেস্ট করা বিন্দু সেখানে রাখে ({{key:Enter}} তাদের নিজস্ব স্থানাঙ্কে রাখে) |
| একটি গ্রিপ টেনে | একটি PI, প্যাড কোণ বা স্ট্রাকচার সরান (একটি পূর্বাবস্থার ধাপ) |
| {{key:Up}} {{key:Down}} {{key:Left}} {{key:Right}} | প্যান, যখন পরিকল্পনার ফোকাস থাকে (আগে তাতে ক্লিক করুন) |
| {{key:Plus}} ও {{key:Minus}} | মাঝখানে জুম ইন ও আউট, যখন পরিকল্পনার ফোকাস থাকে |

= কী {{key:Plus}}-এর মতো জুম ইন করে, তাই Shift লাগে না।

## স্ক্রিন ও সাহায্য

| কী | কাজ |
|---|---|
| {{key:F1}} | এই সাহায্য খুলুন বা বন্ধ করুন (সাইড প্যানেল); অ্যাপ বারের {{ui:Help}} একই কাজ করে |
| {{key:Esc}} | সাহায্য প্যানেল খোলা থাকলে তা বন্ধ করুন |
| {{key:Ctrl+Shift+F}} | স্ক্রিন মোড ঘোরান: পূর্ণ স্ক্রিন, বার লুকানো পূর্ণ স্ক্রিন, সাধারণ |
| {{key:Esc}} | পূর্ণ স্ক্রিন থেকে বেরোন (ব্রাউজারের নিজস্ব কী) |

{{key:F1}} CivilCraft দেখার আগে সাহায্যে পৌঁছায়, তাই যেকোনো টুলে কাজ করে। বেশিরভাগ ম্যাক কিবোর্ডে fn-এর সাথে F1 চাপুন, বা {{ui:Help}} ক্লিক করুন। {{key:Ctrl+Shift+F}} সব প্ল্যাটফর্মে Control কী ব্যবহার করে, ম্যাকেও। এই সাহায্য কীভাবে অনুসন্ধান করতে হয় তা দেখুন [সাহায্য ব্যবহার](common:help)।

## মাউস, ট্র্যাকপ্যাড ও টাচ

:::mouse
- হুইল পয়েন্টারে জুম করে। একটি মুক্তভাবে ঘোরা হুইলের মাউস দ্রুত জুম করে: ছোট ঘুর্ণন দিন।
- ফাঁকা জায়গায় যেকোনো টানা, মাঝের বোতাম, ডান বোতাম, বা {{key:Space}} ধরে টেনে প্যান করুন।
:::

:::mac
একটি ম্যাক ট্র্যাকপ্যাডে:

- দুই-আঙুলের স্ক্রোল **জুম** করে (প্যান করে না), এবং পিঞ্চও জুম করে।
- প্যান করতে, এক আঙুলে ফাঁকা জায়গায় চেপে টানুন, বা {{key:Space}} ধরে রেখে টানুন।
- দুই-আঙুলের ক্লিক (ডান-ক্লিক) কোনো মেনু খোলে না এবং নিজে থেকে কিছু করে না।
:::

:::touch
একটি টাচ স্ক্রিনে:

- প্রথম স্পর্শ বোতাম ও মেনু সারিকে আঙুল-আকারের করে।
- ট্যাপ করে নির্বাচন বা বিন্দু বসান; ফাঁকা জায়গায় এক আঙুল টেনে প্যান। একটি ট্যাপ সামান্য কাঁপতে পারে: আঙুল প্রায় 10 pixels সরলে তবেই প্যান হয়।
- দুই আঙুলে পিঞ্চ করে জুম, একসাথে সরালে প্যান।
- একটি গ্রিপ বা PVI এক আঙুলে টানুন। গ্রিপ তাদের চারপাশে আঙুলের প্রস্থ নেয়।
- একটি অ্যালাইনমেন্ট, প্যাড, ব্রেকলাইন, সীমানা, পাইপ রান, ফিচার লাইন বা প্লট আঁকার সময়, পরিকল্পনার উপর একটি বার {{ui:Finish}} ({{key:Enter}}), {{ui:Undo point}} ({{key:Backspace}}) ও {{ui:Cancel}} ({{key:Esc}}) দেয়। একটি দীর্ঘ চাপ (নড়াচড়া ছাড়া আধা সেকেন্ড) এটিও শেষ করে।
- {{ui:Select}}-এ, একটি সার্ভে বিন্দুতে দীর্ঘ চাপ এটি নির্বাচনে যোগ বা বাদ দেয়, {{key:Shift}}+ক্লিকের মতো।
- 3D ভিউতে, এক আঙুল ঘোরায়, দুই আঙুল পিঞ্চ ও প্যান করে, এবং একটি ট্যাপ বাছে।
- টাচে কোনো হোভার নেই, তাই স্ট্যাটাস বারের রিডআউট শুধু একটি আঙুল নিচে থাকলে আপডেট হয়।
:::

## ব্রাউজারের কী যেগুলো আগে জেতে

কিছু কী ব্রাউজারের, তারা কখনো CivilCraft-এ পৌঁছায় না, উদাহরণস্বরূপ {{key:Mod+W}} (ট্যাব বন্ধ), {{key:Mod+T}} (নতুন ট্যাব), {{key:Mod+N}} (নতুন উইন্ডো) ও {{key:F11}} (Windows ও Linux ব্রাউজারে পূর্ণ স্ক্রিন)। CivilCraft এগুলো ব্যবহার করে না। যদি একটি শর্টকাট ব্রাউজারে কিছু খোলে, তাহলে পরিকল্পনায় একবার ক্লিক করুন যাতে পেজে ফোকাস যায়, এবং আবার চেষ্টা করুন।

## সরানো কোথায় থাকে

কোনো সরান কমান্ড নেই: {{ui:Select}} বেছে একটি বিন্দু বা ভার্টেক্স টানুন, বা {{ui:Properties}}-এ তার স্থানাঙ্ক সম্পাদনা করুন। দেখুন [বিন্দু সম্পাদনা](topic:edit-points)।

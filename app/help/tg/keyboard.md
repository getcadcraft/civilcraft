Тугмаҳои як ҳарфӣ вақте кор мекунанд, ки дар қуттача чизе навиштан намекунед. Мухтасарроҳо бо {{key:Mod}} дар Mac тугмаи Command ва дар ҷои дигар Ctrl истифода мебаранд. Инчунин нигаред ба [Тугмаҳо дар браузер](common:keys).

## Файлҳо ва таҳрир

| Тугма | Амал |
|---|---|
| {{key:Mod+O}} | Кушодани файли нуқта, LandXML ё лоиҳа |
| {{key:Mod+S}} | Захира кардани лоиҳа (файли `.civilcraft.json` зеркашӣ мешавад) |
| {{key:Mod+P}} | Нақшаро ба PDF чоп кардан (диалоги чопи нақша мекушояд, на чопи браузер) |
| {{key:Mod+Z}} | Баргардондан |
| {{key:Mod+Y}} | Такрор кардан |
| {{key:Delete}} | Нест кардани нуқтаҳои ченкунии интихобшуда, трасса, майдонча, сохтор, қубур ё PVI |
| {{key:Mod+C}} | Нусха бардоштани нуқтаҳои ченкунии интихобшуда (инчунин ҳамчун сатрҳои нуқта барои ҷадвал) |
| {{key:Mod+X}} | Буридани нуқтаҳои ченкунии интихобшуда |
| {{key:Mod+V}} | Гузоштани нуқтаҳо: онҳо ишоргарро пайравӣ мекунанд, ҷое ки мераванд, клик кунед |
| {{key:Mod+Shift+V}} | Гузоштан дар ҷои худ: дар координатаҳои худи нуқтаҳо |
| {{key:Mod+D}} | Дубора кардани нуқтаҳои интихобшуда: нусха ишоргарро пайравӣ мекунад |
| {{key:Mod+A}} | Интихоби ҳамаи нуқтаҳои ченкунӣ |
| {{key:Esc}} | Ҳеҷ интихоб накардан (ва бекор кардани гузоштан) |

{{key:Mod+S}}, {{key:Mod+O}} ва {{key:Mod+P}} ҳатто вақте кор мекунанд, ки шумо дар қуттача чизе менависед. {{key:Mod+Z}} ва {{key:Mod+Y}} дар қуттачаи матн, тавре ки маъмул аст, навиштаи шуморо бекор мекунанд, ва {{key:Mod+C}}, {{key:Mod+X}}, {{key:Mod+V}} ва {{key:Mod+A}} низ: дар қуттача онҳо матни онро нусха мегиранд, мебуранд, мегузоранд ва интихоб мекунанд. Вақте матн дар саҳифа (дар панел) интихоб шудааст, {{key:Mod+C}} ҳамон матнро нусха мекунад. {{key:Mod+Shift+Z}} дар CivilCraft кор намекунад: {{key:Mod+Y}} ё тугмаи {{ui:Redo}}-ро истифода баред.

:::mac
Тугмаи Mac бо label **delete** барои браузер {{key:Backspace}} аст. Барои нест кардани интихоб, {{key:Delete}}-ро пахш кунед (Fn ва delete), ё {{ui:Delete}}-ро дар меню {{ui:More}}-и панели асбобҳо интихоб кунед.
:::

Бори дигар пахш кардани тугмаи абзори фаъол ба {{ui:Select}} бармегардонад. Ҳарфҳо бо Shift ҳеҷ кор намекунанд.

## Ҳангоми кашидан

| Тугма | Амал |
|---|---|
| {{key:Enter}} | Анҷом додани трасса, майдонча, давраи қубур, хати шикаста ё сарҳад |
| {{key:Backspace}} | Нуқтаи охирини клик шударо хориҷ кардан |
| {{key:C}} | Хати хусусият: камонҳоро фаъол ё хомӯш кунед (пас аз қуллаа, нуқтаеро дар хам клик кунед, сипас анҷомашро) |
| {{key:Esc}} | Бекор кардани кашидан (ё гузоштан); бори дигар пахш кардан (ё вақте чизе кашида нашудааст), ба {{ui:Select}} бармегардад ва интихобро тоза мекунад |

## Намуди нақша

| Тугма ё амал | Натиҷа |
|---|---|
| Чарх | Калон ё хурд кардан дар ҷои ишоргар |
| Кашидан дар фазои холӣ | Ҷойивазкунӣ (дар ҳар абзор; клики кӯтоҳ ҳамчун клик мемонад; бо {{key:Shift}} нигоҳ дошта, ба ҷои он қуттачаи интихоб кашида мешавад) |
| Кашидан бо тугмаи миёна | Ҷойивазкунӣ |
| Кашидан бо тугмаи рост | Ҷойивазкунӣ (менюе кушода намешавад) |
| {{key:Space}} ва кашидан | Ҷойивазкунӣ |
| Клик | Интихоб (бо {{ui:Select}}), ё гузоштани нуқта (бо абзори кашидан) |
| {{key:Shift}} ва клик | Иловаи нуқтаи ченкунӣ ба интихоб, ё хориҷ кардани он |
| {{key:Shift}} ва кашидан | Кашидани қуттача: нуқтаҳои ченкунии дохили он ба интихоб илова мешаванд. Дар атрофашон кашед, то [лассо](topic:lasso-selection) гиред |
| {{key:Space}} ҳангоми кашидани лассо | Тиреза, сипас гузариш, сипас девор |
| Клик ҳангоми гузоштан | Нуқтаҳои гузошташударо дар он ҷо мегузорад ({{key:Enter}} онҳоро дар координатаҳои худашон мегузорад) |
| Кашидани дастак | Ҷойивазкунии PI, кунҷи майдонча ё сохтор (як қадами бозгардонӣ) |
| {{key:Up}} {{key:Down}} {{key:Left}} {{key:Right}} | Ҷойивазкунӣ, вақте ки нақша фокус дорад (аввал онро клик кунед) |
| {{key:Plus}} ва {{key:Minus}} | Калон ва хурд кардан дар марказ, вақте ки нақша фокус дорад |

Тугмаи = мисли {{key:Plus}} калон мекунад, аз ин рӯ Shift лозим нест.

## Намуди профил

| Амал | Натиҷа |
|---|---|
| Клик бо фаъол будани {{ui:Add PVIs}} | Дар он ҷо PVI илова мекунад |
| Клик ба PVI | Онро интихоб мекунад |
| Кашидани PVI | Ҷойивазкунии он (як қадами бозгардонӣ) |
| {{key:Delete}} ё {{key:Backspace}} | PVI-и интихобшударо хориҷ мекунад (Backspace танҳо вақте, ки намуди профил фокус дорад) |

Намуди профил калон намешавад ва ҷойивазкунӣ намекунад.

## Экран ва роҳнамо

| Тугма | Амал |
|---|---|
| {{key:F1}} | Кушодан ё пӯшидани ин роҳнамо (панели паҳлӯӣ); {{ui:Help}} дар панели барнома ҳамин корро мекунад |
| {{key:Esc}} | Пӯшидани панели роҳнамо, вақте ки кушода аст |
| {{key:Ctrl+Shift+F}} | Давра задани ҳолатҳои экран: экрани пурра, экрани пурра бо панелҳои пинҳоншуда, муқаррарӣ |
| {{key:Esc}} | Баромадан аз экрани пурра (тугмаи худи браузер) |

{{key:F1}} пеш аз он ки CivilCraft онро бинад, ба роҳнамо мерасад, аз ин рӯ дар ҳар абзор кор мекунад. Дар аксарияти клавиатураҳои Mac, fn-ро бо F1 пахш кунед ё {{ui:Help}}-ро клик кунед. {{key:Ctrl+Shift+F}} дар ҳар платформа, аз ҷумла Mac, тугмаи Control-ро истифода мебарад. Барои ҷустуҷӯ кардани ин роҳнамо нигаред ба [Истифодаи роҳнамо](common:help).

## Муш, трекпад ва ламс

:::mouse
- Чарх дар ҷои ишоргар калон мекунад. Муш бо чархи озодгардон зуд калон мекунад: ба он гардишҳои кӯтоҳ диҳед.
- Ҷойивазкунӣ бо ҳар кашидан дар фазои холӣ, тугмаи миёна, тугмаи рост ё {{key:Space}} ва кашидан.
:::

:::mac
Дар трекпади Mac:

- Скроллинг бо ду ангушт **калон мекунад** (ҷойивазкунӣ намекунад), ва чимчидан низ калон мекунад.
- Барои ҷойивазкунӣ, бо як ангушт дар фазои холӣ пахш кунед ва кашед, ё {{key:Space}}-ро нигоҳ дошта кашед.
- Клики ду ангушт (клики рост) менюро намекушояд ва худ аз худ ҳеҷ кор намекунад.
:::

:::touch
Дар экрани ламсӣ:

- Нахустин ламс тугмаҳо ва сатрҳои менюро ба андозаи ангушт месозад.
- Барои интихоб ё гузоштани нуқта пахш кунед; як ангушт, ки дар фазои холӣ кашида мешавад, ҷойивазкунӣ мекунад. Пахш каме лаппидан мумкин аст: он танҳо пас аз ҳаракати ангушт тақрибан 10 pixel ҷойивазкунӣ мекунад.
- Ду ангушт барои калон кардан чимчида мешаванд ва барои ҷойивазкунӣ якҷоя ҳаракат мекунанд.
- Дастак ё PVI-ро бо як ангушт кашед. Дастакҳо дар атрофашон ба андозаи паҳнои ангушт фазо мегиранд.
- Ҳангоми кашидани трасса, майдонча, хати шикаста, сарҳад, давраи қубур, хати хусусият ё парсел, дар болои нақша хатеро {{ui:Finish}} ({{key:Enter}}), {{ui:Undo point}} ({{key:Backspace}}) ва {{ui:Cancel}} ({{key:Esc}}) пешниҳод мекунад. Пахши дароз (нимсония бе ҳаракат) низ анҷом медиҳад.
- Дар {{ui:Select}} пахши дароз ба нуқтаи ченкунӣ онро ба интихоб илова ё аз он хориҷ мекунад, мисли {{key:Shift}}+клик.
- Дар намуди 3D як ангушт гардиш мекунад, ду ангушт чимчида ва ҷойивазкунӣ мекунанд, ва пахш интихоб мекунад.
- Дар ламс hover нест, аз ин рӯ хониши сатри ҳолат танҳо вақте нав мешавад, ки ангушт фишурда аст.
:::

## Тугмаҳои браузер, ки бартарӣ доранд

Баъзе тугмаҳо ба браузер тааллуқ доранд ва ҳеҷ гоҳ ба CivilCraft намерасанд, масалан {{key:Mod+W}} (пӯшидани варақа), {{key:Mod+T}} (варақаи нав), {{key:Mod+N}} (тирезаи нав) ва {{key:F11}} (экрани пурра дар браузерҳои Windows ва Linux). CivilCraft онҳоро истифода намебарад. Агар мухтасарроҳ ба ҷои он чизеро дар браузер кушояд, нақшаро як бор клик кунед, то саҳифа фокус гирад ва боз кӯшиш кунед.

## Ҷойи Move

Фармони Move вуҷуд надорад: {{ui:Select}}-ро интихоб кунед ва нуқта ё қуллааро кашед, ё координатаҳои онро дар {{ui:Properties}} таҳрир кунед. Нигаред ба [Таҳрири нуқтаҳо](topic:edit-points).

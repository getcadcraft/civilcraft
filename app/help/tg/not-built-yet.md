CivilCraft ҳанӯз дар оғоз аст. Ин саҳифа нишон медиҳад, ки нусхаи ҷорӣ чиро намекунад, то шумо барои он ҷустуҷӯ накунед. Ҳеҷ чизи инҷо барои ягон сана ваъда дода намешавад.

## Нуқтаҳо

| Ҳанӯз сохта нашудааст | Ҳоло ба ҷои он |
|---|---|
| Илова кардани файли дуюми нуқтаҳо ба файли аввал | Аввал файлҳоро дар муҳаррири матн ё ҷадвал пайваст кунед |
| Содироти файли матнии нуқтаҳо | Содироти LandXML (нуқтаҳо ҳамчун CgPoints мебароянд), {{ui:Содирот}}-и GIS (нуқтаҳо бо майдонҳои P, N, E, Z ва D), ё {{ui:Нусха бардоштан}}-и нуқтаҳо ба ҷадвал |
| Услубҳои нишонаи нуқта, рамзҳо барои ҳар калиди тавсиф, каҷҳо (камонҳо) аз рамзҳои хат, файли калидҳои тавсиф барои мубодила байни лоиҳаҳо | Нишонаҳо рақам, баландӣ ва тавсифро нишон медиҳанд ё камтар ([Танзимоти CivilCraft](topic:settings)); калидҳо дар файли лоиҳа нигоҳ дошта мешаванд |
| Табдили воҳидҳо | Файлро пеш аз воридкунӣ табдил диҳед; **Воҳидҳо** танҳо номашонро иваз мекунад |

## Сатҳҳо

| Ҳанӯз сохта нашудааст | Ҳоло ба ҷои он |
|---|---|
| Бештар аз як сатҳ, ки аз нуқтаҳо сохта шудааст | Як лоиҳа барои як сатҳ |
| Пинҳон кардани сарҳадҳои дохилӣ | Истифода баред **Канори берунии дарозтарин** ё сарҳади берунӣ |
| Интихоб ё таҳрири як хати шикастаи кашидашуда | {{key:Mod+Z}}, ё {{ui:Нест кардани хатҳои шикастаи кашидашуда}} ва аз нав кашидан |
| Таҳрири сатҳи аз LandXML хонда шуда (хатҳои шикаста, сарҳад) | {{ui:Сатҳро аз нуқтаҳо аз нав сохтан}} |
| Таҳрири сатҳи аз тӯри баландӣ сохташуда | Тӯрро бо интихоби дигар аз нав воридкунӣ кунед |
| Табдили сатҳи аз LandXML хондашуда вақте ки системаи координатҳо иваз мешавад | Аввал {{ui:Сатҳро аз нуқтаҳо аз нав сохтан}} |
| Баландиҳои нуқтавии номгузоришуда ва арзишҳои нишеб | Онҳоро дар сатри ҳолат хонед, ё сатҳро аз рӯи нишеб бо **Таҳлили нишеб** дар фазои кории Манзара ранг кунед ([Наққошӣ барои манзара](topic:landscape-grading#grading-checks)) |

## Трассаҳо ва профилҳо

| Ҳанӯз сохта нашудааст | Ҳоло ба ҷои он |
|---|---|
| Спиралҳо ғайр аз клотоид; спирал байни ду хам (гузариши мураккаб) | Спиралҳои клотоид дар канорҳои хам дастрас мебошанд; дигарҳо ном бурда шуда, ҳангоми воридкунии LandXML гузаронда мешаванд |
| Дохил кардани PI байни ду дигар | Трассаро аз нав кашед ё координатаҳои PI-ро аз нав ворид кунед |
| Трассаҳо аз объектҳо, офсетҳо, паҳнкуниҳо | Бо PI кашед |
| Тайп кардани K барои хами амудӣ | Тайп кунед L (K нишон дода мешавад) |
| Хамҳои амудии даврӣ ва нобаробар | Танҳо хамҳои параболии симметрӣ |
| Бештар аз як профили тарҳ барои як трасса | Як трасса барои ҳар вариант |
| Калон кардани намуди профил, панелҳои профил зери профил | Намуди профил тамоми трассаро ҷой медиҳад; онро дар [варақаҳои нақша ва профил](topic:plan-profile-sheets) чоп кунед |
| Бурришҳо дар DWG ё LandXML | Варақаҳои бурриш ҳамчун PDF; {{ui:CSV}}-и масоҳатҳо ва ҳаҷмҳо |
| Хатҳои намуна дар кунҷ ё бо паҳнии гуногун дар роҳ | Як паҳнӣ барои ҳар тараф барои тамоми трасса |

## Коридорҳо

| Ҳанӯз сохта нашудааст | Ҳоло ба ҷои он |
|---|---|
| Миёнаҳо, монеаҳо ва супербаландкунӣ, ки шаблонҳоро мегардонад | Онҳоро ҳамчун шаблон кашед ([Шаблонҳои коридор](topic:corridor-templates)); шаблонҳо бо пикет ҳоло супербаландкуниро қабул намекунанд |
| Гузариши ҳамвор байни шаблонҳои ду минтақа (гузаришҳо, тарофҳо) | Шаблонро дар пикет иваз кунед, ё ба хати кашидашуда ҳамчун тарофа нуқтаро бо ҳадафи паҳнӣ диҳед |
| Гардиш дар атрофи канор, супербаландкунӣ дар LandXML | Супербаландкунӣ дар хамҳои даврӣ дар атрофи маркази роҳ мегардад; ҳамвориро бо ҳадафи паҳнӣ ба хати хусусият васеъ кунед |
| Ҳадафҳо барои нишебҳои канор (то хат ё сатҳ), сатҳҳои коридор бо худашон | Ҳадафҳо канорҳои фарш ва китфро ҳаракат медиҳанд ([Коридорҳо](topic:corridor)); коридор ба сатҳи пешниҳодшуда ҳамвор карда мешавад |
| Коридорҳо ҳамчун роҳҳои LandXML содир шаванд; коридори дуюм дар трасса дар содироти IFC | Сатҳи пешниҳодшуда содир мешавад |
| Шаблонҳои замин, ки сатҳи пешниҳодшударо иваз мекунанд, дар 3D ё дар бурришҳо | Онҳо масоҳат ва ҳаҷми ҳар қабатро медиҳанд ([Шаблонҳои замин](topic:corridor-templates#terrain-templates)) |
| Роҳҳои гардиш бо суръат, лағжиши чарх, вақти рул, тиркаҳои рулӣ ё фосилаи бадана; китобхонаи мошинҳои стандартии тарҳ; роҳи гардиш бо кашидани мошин | Роҳҳои гардиши суръати паст бо хати хусусият ё трасса, бо андозаҳои мошини худатон ([Роҳҳои гардиши мошин](topic:swept-paths)) |

## Нишеб ва ҳаҷмҳо

| Ҳанӯз сохта нашудааст | Ҳоло ба ҷои он |
|---|---|
| Нишастгоҳҳо, хатҳои кушодаи хусусият, ки ба тарҳ наққошӣ мешаванд, наққошӣ ба хати хусусият аз ҷои дигар | Хати хусусиятро пӯшед ([Хатҳои хусусият](topic:feature-lines)) ё онро ҳамчун хати шикастаи замини мавҷуда истифода баред |
| Дохил ё хориҷ кардани рӯйи хати хусусият | Хатро аз нав кашед ё офсети зинапоя аз он созед |
| Камонҳо дар хатҳои шикастаи кашидашуда (аз миёни нуқтаҳои геодезӣ), спиралҳо дар хатҳои хусусият | Хати хусусиятро бо камон кашед ва ҳамчун хати шикастаи замини мавҷуда истифода баред |
| Наққошӣ то масофа, баландӣ ё сатҳи дигар | Бо замини мавҷуда танҳо барояндагӣ (баровардан) |
| Илова ё хориҷ кардани кунҷи майдон | Майдонро нест кунед ва аз нав кашед |
| Ҳаҷмҳои TIN-ба-TIN (призмаи), интихоби андозаи ҳуҷайра | Усули тӯр, андозаи ҳуҷайра барои шумо интихоб мешавад |
| Афзоиш ва коҳиш, хоки болоӣ, ғафсии фарш | Ба рақамҳои гузоришшуда омилҳоро худатон татбиқ кунед |
| Хароҷоти интиқоли озод ва барқароршаванда, интиқол аз трассаҳои гуногун, кӯлҳои қарзӣ ва партовгоҳҳо дар нақша | Диаграммаи интиқоли масса бо нуқтаҳои мувозинат, ҳаҷми кӯчонидашуда ва масофаҳои миёнаи интиқол |

## Шабакаҳои қубур

| Ҳанӯз сохта нашудааст | Ҳоло ба ҷои он |
|---|---|
| Бештар аз як шабака дар як лоиҳа | Лоиҳаҳои алоҳида барои борон ва санитарӣ |
| Қубурҳои об: сифат ва синни об, идоракунии қоидавӣ, намудҳои дигари клапан (назорати ҷараён, дроссел, нигоҳдорӣ), насосҳо бо қувват, талабот, ки ба фишор вобаста аст, варианти Дарси–Вайсбах, каталоги қубурҳо бо ғафсии девор ва синфҳои фишор. Қисми боқимондаи шабакаҳои фишор дар лаборатория аст: [Қубурҳои об](topic:water-mains) | Инҳоро дар нармафзори тақсимоти об санҷед; ҷараёнҳои тарҳи санитарӣ дар [Ҷараёнҳои тарҳи санитарӣ](topic:sanitary-design) ҳастанд |
| Ҷараёнҳои канализатсия дар вақт (гидрографҳо, масирдиҳии динамикӣ, нигоҳдорӣ, насосҳо, сарризҳо) | [Ҷараёнҳои тарҳи санитарӣ](topic:sanitary-design) ҷараёни пики доимиро медиҳад, ки варақаи тарҳ истифода мебарад |
| Иқтидори даромадгоҳ, паҳнии ҷӯйборҳо, масирдиҳии нигоҳдорӣ, гидрографҳо, талафоти энергия ғайр аз як коэффитсиенти пайвандгоҳ | Онҳоро дар нармафзори дигар санҷед; ҷараёнҳо, андозаҳо ва хатҳои градиенти гидравликӣ дар [Обрафтани борон](topic:storm-drainage) ҳастанд |
| Ҳавзаҳо дар PDF, DWG, DXF ё LandXML; ҳавзаҳо аз сатҳ (ҳавзаҳои обгузар) | Ҳавзаҳоро бо дасти худ кашед; онҳо дар файли лоиҳа захира мешаванд |
| Каталогҳои қубур, қубурҳои ғайридоиравӣ, сохторҳое, ки қуттиҳо ё силиндрҳои рост нестанд (конусҳо, зинапояҳо, зинаҳои поинтар), категорияи обрафтан дар китобхона | Намудҳои сохтор аз параметрҳо ([Шабакаи қубур](topic:pipe-network)); қубурҳо бо диаметр |
| Қубурҳо дар намуди профил, қубурҳои хамдор | Баландиҳои поёнӣ ва пӯшиш дар панели рост хонда мешаванд |

| Рӯйхати растаниҳои шумо дар китобхонаи ҳисоби шумо (таҳрир дар барнома) | Рӯйхати худи лоиҳаро дар Ҷадвали растаниҳо таҳрир кунед ва ҳамчун файли растаниҳо захира кунед |
| Асбобҳои манзара барои ёрдамчиёни бе тиреза (сервери файл ва хати фармон) | Онҳо бо кушодани тиреза ва CivilCraft кор мекунанд ([Бигзор ёрдамчии AI бо сайти шумо кор кунад](topic:assistants)) |

## GIS ва системаҳои координатӣ

| Ҳанӯз сохта нашудааст | Ҳоло ба ҷои он |
|---|---|
| File Geodatabase; услубҳо, нишонаҳо, қабатҳои замин ва пайвандҳои шабака дар KML | Аввал ба GeoPackage, shapefile ё GeoJSON табдил диҳед; нишонаҳои KML бе услубҳояшон хонда мешаванд |
| Таҳрири хусусиятҳои GIS ё атрибутҳои онҳо | Онҳоро дар барномаи GIS таҳрир кунед ва дубора ворид кунед. Панели таҳлил қабатҳои нав месозад (буфер, рӯйпӯш, пайваст, интихоб) ва майдонҳои масоҳат ва дарозиро илова мекунад, аммо хусусиятро дар ҷой таҳрир намекунад |
| Таҳлили шабака ва растр, буферҳо бо охирҳои ҳамвор ё мураббаъ ва буферҳои якҷониба, илова ё нест кардани сатрҳо ва иваз кардани навъи майдон дар ҷадвали атрибутҳо, ранги дастии синфҳо, легенда дар чопҳо | Интихобро барои интихоби хусусиятҳо ва сохтани қабат аз онҳо истифода баред; охирҳои ҳамвор пешниҳод нашудаанд. Ранг бо атрибут ва ҷадвали атрибутҳо тайёранд: [Услубдиҳии қабат аз рӯи атрибут](topic:gis-symbology) ва [Кор бо ҷадвали атрибути қабат](topic:gis-table) |
| Услуби нишонаҳо (андоза, ҷойгиршавӣ) ва нишонаҳое, ки аз ҳамдигар дурӣ мекунанд | Нишонаҳо як андоза доранд ва вақте ки хусусиятҳо зич ҳастанд, метавонанд ҳамдигарро пӯшонанд |
| Датумҳои амудӣ ва моделҳои геоид | Баландиҳо тавре истифода мешаванд, ки файл медиҳад; датуми амудиро худатон санҷед |
| Гузаришҳои тӯр ба ғайр аз NAD83 аз NAD27, ки аз рӯи минтақа пешниҳод мешаванд (OSTN15, NTv2 барои датумҳои дигар вақте ки файлашро илова мекунед кор мекунанд), якчанд тӯр якбора, тӯрҳои амудӣ | Файли тӯрро барои датуми худ худатон илова кунед; як тӯр дар як лоиҳа |
| Қабатҳои харита дар DXF ё содироти 3D | Қабатҳои харита ба PDF чоп мешаванд ва дар паҳлӯи DWG ҳамчун расм |
| Серверҳои харита, ки барои ворид шудан калид ё нишона талаб мекунанд | Хизматҳои оммавӣ ё файли тасвирии геореферӣ истифода баред |
| Навиштани файлҳои LAS ё LAZ аз сатҳ, модели замин ё асбобҳои тӯри баландӣ ва LiDAR | Сатҳҳоро ҳамчун тӯри баландии GeoTIFF содир кунед. Иловаи [Абрҳои нуқта](topic:point-clouds) абри тозашударо ҳамчун LAS 1.4 ё LAZ менависад |
| Шиддат, ранг ва бозгашти LiDAR; тӯрҳои баландӣ бо якчанд канал; файлҳои тӯр ё LiDAR аз 200 MB калонтар | LiDAR танҳо бо синф филтр мешавад, тӯрҳо канали аввалро истифода мебаранд; файлҳои калонро аввал ба порчаҳо бурида гиред |

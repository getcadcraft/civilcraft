CivilCraft ҳанӯз ибтидоӣ аст. Ин саҳифа он чиро, ки нусхаи ҷорӣ намекунад, номбар мекунад, то шумо онро наҷӯед. Ҳеҷ чизи инҷо барои санае ваъда дода нашудааст.

## Нуқтаҳо

| Ҳоло сохта нашудааст | Ба ҷои он, имрӯз |
|---|---|
| Илова кардани файли дуюми нуқта ба файли аввал | Аввал файлҳоро дар муҳаррири матн ё ҷадвал пайваст кунед |
| Содироти файли матнии нуқта | Содироти LandXML (нуқтаҳо ҳамчун CgPoints мебароянд), истифодаи {{ui:Содирот}} -и GIS (нуқтаҳо бо майдонҳои P, N, E, Z ва D) ё {{ui:Нусха бардоштан}} -и нуқтаҳо ба ҷадвал |
| Услубҳои нишонаи нуқта, рамзҳо барои ҳар калиди тавсиф, каҷҳо (камонҳо) аз рамзҳои хат, файли калиди тавсиф барои мубодила дар лоиҳаҳо | Нишонаҳо рақам, баландӣ ва тавсифро нишон медиҳанд ё камтар ([Танзимоти CivilCraft](topic:settings)); калидҳо дар файли лоиҳа нигоҳ дошта мешаванд |
| Табдили воҳидҳо | Файлро пеш аз воридот табдил диҳед; **Воҳидҳо** танҳо номро иваз мекунад |

## Сатҳҳо

| Ҳоло сохта нашудааст | Ба ҷои он, имрӯз |
|---|---|
| Бештар аз як сатҳ, ки аз нуқтаҳо сохта шудааст | Як лоиҳа барои як сатҳ |
| Пинҳон кардани марзҳои дохилӣ | Истифода баред **Дарозтарин канори беруна** ё марзи беруна |
| Интихоб ё таҳрири як хати шикастаи кашидашуда | {{key:Mod+Z}}, ё {{ui:Нест кардани хатҳои шикастаи кашидашуда}} ва аз нав кашидан |
| Таҳрири сатҳе, ки аз LandXML хонда шудааст (хатҳои шикаста, марз) | {{ui:Сатҳро аз нуқтаҳо аз нав сохтан}} |
| Таҳрири сатҳе, ки аз тӯри баландӣ сохта шудааст | Тӯрро бо интихобҳои дигар аз нав воридот кунед |
| Табдили сатҳе, ки аз LandXML хонда шудааст, вақте системаи координатаҳо тағйир меёбад | Аввал {{ui:Сатҳро аз нуқтаҳо аз нав сохтан}} |
| Баландии нуқтаҳои нишондодӣ ва арзишҳои нишеб бо нишонаҳо | Онҳоро дар панели ҳолат хонед ё сатҳро бо нишеб бо **Таҳлили нишеб** дар фазои Манзара ранг кунед ([Ҳамвориҳо барои манзара](topic:landscape-grading#grading-checks)) |

| Дохил кардани PI байни ду дигар | Трассаро аз нав кашед ё координатҳои PI-ро аз нав нависед |

| Бештар аз як профили тарҳ барои як трасса | Як трасса барои ҳар вариант |
| Намоиши профил бо наздикшавӣ, поясҳои профил дар зери профил | Намои профил тамоми трассаро мегирад; онро дар [варақҳои нақша ва профил](topic:plan-profile-sheets) чоп кунед |
| Бурришҳо дар DWG ё LandXML | Варақҳои бурриш ҳамчун PDF; {{ui:CSV}} -и масоҳатҳо ва ҳаҷмҳо |
| Намунаи хатҳо бо кунҷ ё бо паҳнии гуногун дар тӯли роҳ | Паҳнии ҳар тараф барои тамоми трасса |

## Долонҳо

| Ҳоло сохта нашудааст | Ба ҷои он, имрӯз |
|---|---|
| Миёнаҳо, монеаҳо ва супер-элевацияе, ки шаблонҳоро мегардонад | Онҳоро ҳамчун шаблонҳо кашед ([Шаблонҳои долон](topic:corridor-templates)); шаблонҳо аз рӯи пикет ҳоло супер-элевацияро намегиранд |
| Тағйири пайваста байни шаблонҳои ду минтақа (гузаришҳо, тасмаҳо) | Шаблонро дар пикет иваз кунед ё ба хати кашидашуда ҳамчун тасма ҳадафи паҳнии нуқта диҳед |
| Гардиш дар атрофи канор, супер-элевация дар LandXML | Супер-элевация дар каҷҳои доиравӣ дар атрофи хати марказӣ мегардад; роҳгузарро бо ҳадафи паҳнӣ ба хати хусусият паҳн кунед |
| Ҳадафҳо барои нишебҳои канор (рӯшноӣ ба хат ё сатҳ), сатҳҳои долонии худашон | Ҳадафҳо канорҳои сатҳи роҳ ва китфи роҳро ҳаракат медиҳанд ([Долонҳо](topic:corridor)); долон ба сатҳи тарҳшуда ҳамвор карда мешавад |
| Бордюрҳои гӯшаҳо, роҳгузарҳои гардиш ва ҷазираҳо, ки ба чорроҳа ҳамвор карда мешаванд; охири роҳи фаръӣ ба канори роҳи асосӣ дар кундаланги ғайримустақим бурида шавад; роҳча ба роҳ дар нақша, дар дарозӣ ва масоҳаташ пайваст шавад | Роҳҳое, ки мерасанд, рост пайваст мешаванд, канори роҳи асосӣ кушода мешавад ва роҳи фаръӣ ба он ҳамвор мешавад ([Ҷое, ки роҳҳо мерасанд](topic:corridor#where-roads-meet-roads-pads-and-paths)); роҳча дар сатҳи тарҳшуда ва дар 3D ба канори роҳ мерасад |
| Долонҳо ҳамчун роҳҳои LandXML содирот шаванд; долони дуюм дар трассаи содироти IFC | Сатҳи тарҳшуда содирот мешавад |
| Шаблонҳои замин, ки сатҳи тарҳшударо иваз мекунанд, дар 3D ё дар бурришҳо | Онҳо масоҳат ва ҳаҷми ҳар қабатро медиҳанд ([Шаблонҳои замин](topic:corridor-templates#terrain-templates)) |
| Роҳҳои гардиши хат бо суръат, лағзиши чарх, вақти фармон, трейлерҳои фармон ё тоза кардани бадана; китобхонаи мошинҳои тарҳи стандартӣ; роҳи гардиш бо кашидани мошин | Роҳҳои гардиши суръати паст дар тӯли хати хусусият ё трасса бо андозаҳои мошинҳои худатон ([Роҳҳои гардиши мошин](topic:swept-paths)) |

## Ҳамвориҳо ва ҳаҷмҳо

| Ҳоло сохта нашудааст | Ба ҷои он, имрӯз |
|---|---|
| Суфаҳо, хатҳои хусусияти кушода, ки ба тарҳ ҳамвор карда мешаванд, ҳамвор кардан ба хати хусусият аз ҷои дигар | Хати хусусиятро пӯшед ([Хатҳои хусусият](topic:feature-lines)) ё онро ҳамчун хати шикастаи замини мавҷуда истифода баред |
| Иловаи ё хориҷ кардани нуқтаи хати хусусият | Хатро аз нав кашед ё офсети поғонаии онро созед |
| Камонҳо дар хатҳои шикастаи кашидашуда (тавассути нуқтаҳои ченкунӣ), спиралҳо дар хатҳои хусусият | Хати хусусияти бо камонҳо кашед ва онро ҳамчун хати шикастаи замини мавҷуда истифода баред |
| Ҳамвор кардан то масофа, баландӣ ё сатҳи дигар | Танҳо то замини мавҷуда рӯшноӣ |
| Иловаи ё хориҷ кардани гӯшаи майдонча | Майдончаро нест кунед ва аз нав кашед |
| Ҳаҷмҳои TIN-ба-TIN (призма), интихоби андозаи ҳуҷайраи тӯр | Усули тӯр, андозаи ҳуҷайра барои шумо интихоб шудааст |
| Варам ва ҷамъшавӣ, хоки болоӣ, ғафсии фарш | Омилҳоро ба рақамҳои гузоришшуда худатон татбиқ кунед |
| Хароҷоти интиқоли ройгон ва зиёдатӣ, интиқол дар байни трассаҳои гуногун, конҳои қарз ва партовгоҳҳо дар нақша | Диаграммаи интиқоли масса бо нуқтаҳои мувозинат, ҳаҷмҳои кӯчонидашуда ва масофаҳои миёнаи интиқол |

## Шабакаҳои қубур

| Ҳоло сохта нашудааст | Ба ҷои он, имрӯз |
|---|---|
| Бештар аз як шабака дар як лоиҳа | Лоиҳаҳои алоҳида барои обборон ва канализатсия |
| Қубурҳои оби ошомиданӣ: сифат ва синни об, назоратҳои асоси қоида, дигар намудҳои клапан (танзими ҷараён, дарвоза, нигоҳдорӣ), насосҳо бо қуввати додашуда, талаб, ки ба фишор вобаста аст, варианти Дарси–Вейсбах, каталоги қубурҳо бо ғафсии девор ва синфҳои фишор. Боқии шабакаҳои фишор дар озмоишгоҳ аст: [Қубурҳои оби ошомиданӣ](topic:water-mains) | Инҳоро дар нармафзори таксимоти об санҷед; ҷараёнҳои тарроҳии канализатсия дар [Ҷараёнҳои тарроҳии канализатсия](topic:sanitary-design) ҳастанд |
| Ҷараёнҳои канализатсия дар вақт (гидрографҳо, маршрутизатсияи динамикӣ, захира, насосҳо, сарризҳо) | [Ҷараёнҳои тарроҳии канализатсия](topic:sanitary-design) ҷараёни устувори қуллаи истифодаро медиҳад, ки варақи тарроҳӣ истифода мебарад |
| Гунҷоиши даромадгоҳ, паҳншавии ҷӯйча, маршрутизатсияи ҳавза, гидрографҳо, талафоти энергия ғайр аз як коэффитсиенти ҷункшн | Онҳоро дар нармафзори дигар санҷед; ҷараёнҳо, андозаҳо ва хатҳои баландӣ дар [Обкашии тӯфон](topic:storm-drainage) ҳастанд |
| Ҳавзҳои ҷамъшавӣ дар нақшаи PDF, DWG, DXF ё LandXML; ҳавзҳои ҷамъшавӣ аз сатҳ (ҳавзаҳои обгузар) | Ҳавзҳои ҷамъшавиро бо дасти худ кашед; онҳо дар файли лоиҳа нигоҳ дошта мешаванд |
| Каталогҳои қубур, қубурҳои ғайридоиравӣ, сохторҳое, ки қуттиҳо ё силиндрҳои амудӣ нестанд (мухрутҳо, қадамҳо, нишебиҳо), категорияи обгузар дар китобхона | Намудҳои сохторро аз параметрҳо ([Шабакаи қубур](topic:pipe-network)); қубурҳо бо диаметр |
| Қубурҳо дар намои профил, қубурҳои хамшуда | Ҳудудҳо ва пӯшиш дар панели рост хонда мешаванд |

## Манзара

| Ҳоло сохта нашудааст | Ба ҷои он, имрӯз |
|---|---|

| Дарозии ҳадди ақали хатҳои қатра барои хатҳои қатрагӣ, ҷараёнҳо дар вақт, насосҳо, шабакаҳои қубури ҳалқавӣ | Ҷойҳои қатраро ба дарозии эълоншудаи истеҳсолкунанда нигоҳ доред; санҷиш шабакаи шохадорро талаб мекунад |

## GIS ва системаҳои координатӣ

| Ҳоло сохта нашудааст | Ба ҷои он, имрӯз |

| File Geodatabase; услубҳои KML, нишонаҳо, рӯйпӯшҳои замин ва пайвандҳои шабака | Аввал ба GeoPackage, shapefile ё GeoJSON табдил диҳед; нишонаҳои KML бе услубашон хонда мешаванд |
| Таҳрири хусусиятҳои GIS ё ҳусусиятҳои онҳо | Онҳоро дар барномаи GIS таҳрир кунед ва аз нав воридот кунед. Панели Таҳлил қабатҳои нав месозад (буфер, рӯйпӯш, пайваст, интихоб) ва майдонҳои масоҳат ва дарозиро илова мекунад, аммо хусусиятро дар ҷой таҳрир намекунад |
| Таҳлили шабака ва растр, буферҳо бо канорҳои ҳамвор ё мураббаъ ва буферҳои яксара, илова ё хориҷ кардани сатрҳо ва иваз кардани навъи майдон дар ҷадвали хусусиятҳо, ранги дастии синфҳо, легендаи услуб дар нақшаҳо | Барои интихоби хусусиятҳо Интихобро истифода баред ва аз онҳо қабат созед; канорҳои ҳамвор пешниҳод карда намешаванд. Ранг кардан аз рӯи хусусият ва ҷадвали хусусиятҳо сохта шудаанд: нигаред ба [Услуби қабат аз рӯи хусусият](topic:gis-symbology) ва [Кор бо ҷадвали хусусиятҳои қабат](topic:gis-table) |
| Услубҳои нишонаҳо (андоза, ҷойгиршавӣ) ва нишонаҳое, ки аз ҳамдигар дурӣ мекунанд | Нишонаҳо як андоза доранд ва дар ҷойҳои зич метавонанд рӯи ҳам бароянд |
| Дотумҳои баландӣ ва моделҳои геоид | Баландиҳо тавре истифода мешаванд, ки файл медиҳад; дотуми амудиро худатон санҷед |
| Тағйирёбии тӯр, ғайр аз NAD83 аз NAD27 тавре, ки аз рӯи минтақа пешниҳод шудааст (OSTN15, NTv2 барои дигар дотумҳо, вақте файлро илова мекунед), якчанд тӯр якбора, тӯрҳои амудӣ | Файли тӯри дотуми худро худатон илова кунед; як тӯр барои як лоиҳа |
| Қабатҳои харита дар содироти DXF ё 3D | Қабатҳои харита ба нақшаи PDF мераванд ва дар паҳлӯи DWG ҳамчун расм |
| Сервҳои харита, ки ворид шуданро, калид ё нишонро талаб мекунанд | Сервҳои ошкорро истифода баред ё файли расми геоӣ |
| Навиштани файлҳои LAS ё LAZ аз сатҳ, модели замин ё абзорҳои тӯри баландӣ ва LiDAR | Сатҳҳоро ҳамчун тӯри баландии GeoTIFF содирот кунед. Иловаи [Абрҳои нуқта](topic:point-clouds) абри тозашударо ҳамчун LAS 1.4 ё LAZ менависад |

# CivilCraft for iPad

**Not in the App Store yet.** CivilCraft comes to iPad (and later iPhone) inside CadCraft Studio, and Studio goes out through Apple's App Store, not from GitHub or the download page. The app is not in the store yet; the link will be on the [download page](https://getcadcraft.com/download#studio) when it is. Until then, use https://getcadcraft.com/use/civilcraft in Safari.

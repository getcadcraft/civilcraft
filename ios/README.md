# CivilCraft for iPad

**Not in the App Store yet.** CivilCraft comes to iPad (and later iPhone) inside CadCraft Studio, and Studio goes out through Apple's App Store, not from GitHub or the download page. Studio 0.8 was sent to Apple for review; the store link will be on the [download page](https://getcadcraft.com/download#studio) when Apple releases it. Until then, use https://getcadcraft.com/use/civilcraft in Safari.

# CivilCraft for Windows

CivilCraft comes inside [CadCraft Studio](https://github.com/getcadcraft/studio) (all eight apps in one install) from 0.5 on; there are no separate CivilCraft installers any more. Get Studio 0.7 from the [download page](https://getcadcraft.com/download#studio) or its [GitHub release](https://github.com/getcadcraft/studio/releases/tag/studio-v0.7.0). The Windows installer is not code-signed yet: SmartScreen shows "Windows protected your PC"; choose **More info › Run anyway**, and check the file against SHA256SUMS first. Signing and a Microsoft Store build come in 0.7. The 0.4 per-app installer stays on the 0.4 release.

## File types

- Opens by default unless another program already does: `.landxml` (LandXML file)
- Listed under "Open with": `.xml` (XML file), `.geojson` (GeoJSON file), `.kml` (KML file), `.kmz` (KMZ file), `.shp` (Shapefile), `.gpkg` (GeoPackage), `.las` (LAS point cloud), `.laz` (LAZ point cloud), `.dwg` (DWG drawing), `.dxf` (DXF drawing)
